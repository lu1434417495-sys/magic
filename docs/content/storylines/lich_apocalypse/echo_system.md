# 亡灵天灾回响系统详细设计

> 关联文档：`lich_apocalypse_design.md`  
> 核心功能：**低等级选择决定高等级结局**  
> 设计原则：选择有逻辑回响，但不对玩家隐藏数值；玩家能感受到因果，但无法简单"刷"出最优解

---

## 一、系统概述

### 1.1 什么是回响

回响系统不是传统的"善恶值"或"声望系统"。它记录的是玩家在天灾剧情线中**面对具体困境时的选择模式**，并在高等级时将这些模式"聚合"为一个符合逻辑的终局。

**关键设计原则**：

| 原则 | 说明 |
|------|------|
| **逻辑一致性** | 结局不是随机分配的。如果你一路杀光所有亡灵，最终不可能突然解锁"融合"结局 |
| **延迟反馈** | 低等级时的选择不会立即显示后果。后果在中等级和高等级时才逐步显现 |
| **不可逆性** | 大部分选择一旦做出无法回头。这制造真实的重量感 |
| **可理解性** | 玩家不需要看到隐藏数值。通过NPC对话、环境变化、信件等方式自然传达 |
| **非最优化** | 没有"完美结局"。每个结局都有代价，每个选择都有损失 |

### 1.2 与项目现有系统的整合

回响系统使用 `GameSession` 全局状态存储，与现有任务进度、声望系统并列。它不引入新的UI元素——所有反馈都通过**叙事事件**和**环境变化**传达。

## 二、回响状态架构

### 2.1 三层状态模型

回响状态分为三层：倾向层、标记层、势力层。

#### 倾向层（Dispositions）—— 3个浮点值，范围[-10, +10]

记录玩家在面对天灾时的**态度模式**。

| 倾向ID | 名称 | 负极（-10） | 正极（+10） | 初始值 |
|--------|------|-----------|-----------|--------|
| `disp_empathy` | 共情倾向 | 冷酷：将亡灵视为纯粹敌人，支持彻底销毁 | 仁慈：视亡灵为受害者，寻求救赎与共存 | 0 |
| `disp_pragmatism` | 务实倾向 | 理想主义：拒绝任何牺牲，坚持完美方案 | 实用主义：接受"必要的恶"以换取更大利益 | 0 |
| `disp_knowledge` | 求知倾向 | 恐惧：回避了解真相，拒绝与莫德洛斯接触 | 好奇：主动研究、保留样本、与敌人对话 | 0 |

**倾向值的变化规则**：
- 每个关键选择会触发 ±1 到 ±3 的变化
- 倾向值没有"阈值"概念——它描述的是**倾向程度**，不是"够不够好"
- 倾向值在剧情中**永不直接显示给玩家**

#### 标记层（Key Flags）—— 12个枚举值

记录**不可逆的关键事件**。

| 标记ID | 描述 | 可能值 |
|--------|------|--------|
| `flag_mourning_village` | 静眠村（Q201-Q203）的命运 | `saved` / `abandoned` / `purged` |
| `flag_ossus_first_dialogue` | Q220与莫德洛斯初次对话的基调 | `hostile` / `cautious` / `receptive` |
| `flag_plague_heart` | Q215瘟疫之心的处理方式 | `destroyed` / `preserved` / `studied` |
| `flag_lords_redeemed` | 救赎了几位黯影领主 | `0` / `1` / `2` / `3` / `4` / `5` / `6` / `7` |
| `flag_empire_purification` | 是否执行/支持帝国净化计划 | `executed` / `opposed` / `avoided` |
| `flag_viera_fate` | 学者薇拉的最终命运 | `alive` / `corrupted` / `dead` / `ascended` |
| `flag_federation_cure` | 联邦是否研制出解药 | `none` / `partial` / `full` |
| `flag_underground_knowledge` | 是否深入探究黯影帝国历史 | `surface` / `moderate` / `deep` |
| `flag_soul_binding` | 是否与莫德洛斯建立任何连接 | `none` / `touched` / `linked` / `sworn` |
| `flag_refugee_crisis` | 扩散期难民的处理方式 | `ignored` / `minimal` / `protected` / `sacrificed` |
| `flag_faith_response` | 玩家信仰的宗教对天灾的回应 | `rejected` / `questioned` / `integrated` |
| `flag_sacrifice_made` | 是否主动做出不可逆的个人牺牲 | `none` / `minor` / `major` / `ultimate` |

#### 势力层（Faction States）—— 3个整数，范围[0, 3]

记录三大势力对天灾的介入程度。

| 势力ID | 名称 | 0级 | 1级 | 2级 | 3级 |
|--------|------|-----|-----|-----|-----|
| `fac_empire` | 霜烬帝国 | 完全不知情 | 收到报告但未行动 | 积极研究/军事介入 | 全面控制净化计划 |
| `fac_federation` | 星陨联邦 | 完全不知情 | 收到报告但未行动 | 成立研究委员会 | 全面动员防御 |
| `fac_independent` | 独立势力（玩家/薇拉） | 未介入 | 初步调查 | 深度介入 | 成为主导力量 |

**势力层的变化**：由Q205的第一选择直接决定初始方向，后续任务中的选择可修正但不可完全逆转。

## 三、低等级选择的回响标记（逐任务详细）

### 3.1 Q201 掘墓人的噩梦（等级1）

**选择节点A：面对不安的遗骸**

| 玩家行动 | `disp_empathy` | `disp_pragmatism` | `flag_mourning_village`影响 |
|---------|---------------|-------------------|---------------------------|
| 直接销毁遗骸 | -1 | +1 | — |
| 观察后销毁 | 0 | +1 | — |
| 尝试与遗骸沟通（失败后才销毁） | +1 | 0 | — |
| 放走遗骸（让它离开墓地） | +2 | -2 | 向`saved`偏移 |

**选择节点B：掘墓人老卡特的真相**

| 玩家行动 | `disp_empathy` | `disp_knowledge` |
|---------|---------------|-----------------|
| 告诉他真相（异常现象是更大灾难的前兆） | 0 | +1 |
| 撒谎安抚（说是普通的墓地闹鬼） | +1 | -1 |
| 不告诉他，只让他离开 | -1 | 0 |

**回响延迟**：Q201的选择在Q203才会首次显现——如果你放走了遗骸，Q203中静眠村会出现更多"游荡的遗骸"，薇拉会评论："你当时的选择……让这里的情况更复杂了。"

---

### 3.2 Q202 不发臭的狼（等级2）

**选择节点A：废弃矿井中的石门**

| 玩家行动 | `disp_knowledge` | `flag_underground_knowledge` |
|---------|-----------------|----------------------------|
| 无视石门，只猎杀狼群 | -1 | 保持`surface` |
| 调查石门但不深入 | +1 | 向`moderate`偏移 |
| 尝试撬开/砸开石门 | +2 | 向`deep`偏移 |
| 记录符文并离开 | +1 | 向`moderate`偏移 |

**选择节点B：狼群巢穴中的帝国巡逻兵尸体**

| 玩家行动 | `disp_empathy` | `disp_pragmatism` |
|---------|---------------|-------------------|
| 带走尸体交给帝国 | 0 | +1 |
| 就地掩埋 | +1 | 0 |
| 无视尸体 | -1 | 0 |
| 搜索尸体并保留发现 | 0 | +1 |

**关键回响**：如果你在Q202中深入调查了石门，Q204中薇拉会给你一个额外选项："你在矿井中看到的那扇门……我知道它通向哪里。"这会解锁一条捷径，跳过Q204的部分追踪环节。

---

### 3.3 Q203 不速之客（等级3）

**选择节点A：护送路上的黯影行者**

| 玩家行动 | `disp_empathy` | `disp_pragmatism` | `flag_refugee_crisis`影响 |
|---------|---------------|-------------------|--------------------------|
| 避开它们，不交战 | +1 | 0 | 向`protected`偏移 |
| 主动攻击 | -1 | +1 | 向`ignored`偏移 |
| 观察后判断它们无害，放走 | +2 | -1 | 向`protected`偏移 |
| 尝试交流（失败后才攻击） | +1 | -1 | — |

**选择节点B：遭遇袭击时保护薇拉**

| 玩家行动 | `flag_viera_fate`影响 |
|---------|---------------------|
| 薇拉存活且未受伤 | 向`alive`偏移 |
| 薇拉存活但受伤 | 向`alive`偏移（但后续她会有伤病对话） |
| 薇拉濒死（你救了她但代价惨重） | 向`alive`偏移，`flag_sacrifice_made`向`minor`偏移 |
| 薇拉死亡（任务失败，但可以重试） | — |

**选择节点C：发现黯影帝国神庙后的态度**

| 玩家行动 | `disp_knowledge` | `flag_underground_knowledge` |
|---------|-----------------|----------------------------|
| 建议销毁神庙 | -2 | 保持`surface` |
| 建议封锁神庙 | -1 | 保持`surface` |
| 建议研究神庙 | +2 | 向`deep`偏移 |
| 不表态，让薇拉决定 | 0 | 向`moderate`偏移 |

**关键回响**：如果你建议研究神庙，Q205中薇拉会给你一本《黯影帝国简史》，解锁特殊对话选项。如果你建议销毁，Q204中联邦/帝国会派人烧毁该区域，你会失去一些情报来源。

---

### 3.4 Q204 瘟疫的第一滴（等级4）

**选择节点A：追踪病人时的处理方式**

| 玩家行动 | `disp_empathy` | `disp_pragmatism` |
|---------|---------------|-------------------|
| 强行拦下病人，带回哨站 | -1 | +1 |
| 跟随病人，观察他们去哪里 | +1 | 0 |
| 尝试与清醒的病人对话 | +2 | -1 |
| 杀死病人（防止他们传播瘟疫） | -3 | +2 |

**选择节点B：黯影涌泉的处理**

| 玩家行动 | `disp_knowledge` | `flag_underground_knowledge` |
|---------|-----------------|----------------------------|
| 立即封印涌泉 | -1 | 保持`surface` |
| 采集样本后封印 | +1 | 向`moderate`偏移 |
| 建立观察站，持续监测 | +2 | 向`deep`偏移 |
| 无视涌泉，只报告位置 | -1 | 保持`surface` |

**关键回响**：如果你杀死病人，Q205中薇拉会对你说："你做了当时认为正确的事。但那些病人……其中有一个是铁炉堡市长的女儿。市长现在悬赏你的人头。"这会开启一个可选的支线：面对市长的复仇。

---

### 3.5 Q205 第一块拼图（等级5）—— 最关键的分支点

**选择节点A：情报交给谁**

| 玩家行动 | `fac_empire` | `fac_federation` | `fac_independent` | 后续解锁路线 |
|---------|-----------|---------------|------------------|------------|
| 告诉霜烬帝国 | 设为2 | 保持0 | 保持0 | 帝国路线 |
| 告诉星陨联邦 | 保持0 | 设为2 | 保持0 | 联邦路线 |
| 保持沉默，与薇拉继续调查 | 保持0 | 保持0 | 设为2 | 独立路线 |
| 同时告诉双方（需要高魅力/说服） | 设为1 | 设为1 | 保持0 | 混合路线（后续极难） |

**选择节点B：对薇拉发现的态度**

| 玩家行动 | `disp_knowledge` | `disp_empathy` | `flag_viera_fate`影响 |
|---------|-----------------|---------------|---------------------|
| 支持她继续研究 | +2 | 0 | 向`alive`偏移 |
| 警告她这可能危险 | +1 | +1 | 向`alive`偏移 |
| 要求她停止研究 | -1 | +1 | 向`corrupted`偏移（她会偷偷继续） |
| 没收她的研究资料 | -2 | 0 | 向`dead`偏移（她会独自调查，遇险概率增加） |

**关键回响**：这个选择会直接决定Q206-Q210的任务发布者：
- 帝国路线：帝国军官发布任务，奖励以金钱和装备为主
- 联邦路线：联邦学者发布任务，奖励以知识和技能为主
- 独立路线：薇拉发布任务，奖励以独特情报和隐藏选项为主

## 四、中等级选择的回响标记

### 4.1 Q211 死者行军（等级6）

**选择节点：面对黯影骑士的劝降**

| 玩家行动 | `disp_empathy` | `flag_ossus_first_dialogue`影响 |
|---------|---------------|-------------------------------|
| 辱骂并攻击 | -2 | 向`hostile`偏移 |
| 拒绝但保持尊重 | 0 | 向`cautious`偏移 |
| 询问更多关于"永恒服役"的信息 | +1 | 向`receptive`偏移 |
| 假意同意（后续背叛） | 0 | 向`hostile`偏移（莫德洛斯会记住欺骗） |

**关键回响**：如果你询问更多信息，Q220中莫德洛斯会提到这次对话："你在断骨峡谷问了我的骑士一个问题。我现在给你答案。"

### 4.2 Q215 瘟疫之心（等级8）—— 道德核心任务

**选择节点A：潜入还是正面**

| 玩家行动 | `disp_pragmatism` | `flag_sacrifice_made` |
|---------|-------------------|---------------------|
| 潜入（耗时但更人道的方案） | -1 | — |
| 正面突破（更快但更暴力） | +1 | 向`minor`偏移 |

**选择节点B：瘟疫之源的处理**

| 玩家行动 | `disp_empathy` | `disp_pragmatism` | `disp_knowledge` | `flag_plague_heart` |
|---------|---------------|-------------------|-----------------|-------------------|
| 立即销毁脓包 | +1 | +1 | -1 | `destroyed` |
| 采集样本后销毁 | +1 | +2 | +1 | `destroyed` |
| 保留脓包，建立隔离观察区 | +2 | -1 | +2 | `preserved` |
| 深入研究，尝试与黯影居民交流 | +3 | -2 | +3 | `studied` |

**关键回响**：
- 如果你选择`studied`，Q220中莫德洛斯会说："你看到了静谧谷的居民。他们不需要食物，不需要睡眠，不需要恐惧。你理解我了。"
- 如果你选择`destroyed`，扩散期时会有一个事件：一位母亲找到你，她的孩子被感染后你销毁了脓包，孩子死了。她说："你救了我们村。但杀了我儿子。谢谢你。也恨你。"
- `flag_plague_heart`直接决定Q226中联邦是否能研制出解药：`destroyed`→`none`或`partial`；`preserved`/`studied`→`partial`或`full`（取决于后续选择）

### 4.3 Q220 巫妖的使者（等级10）—— 核心对话

**选择节点：与莫德洛斯投影的对话**

对话分为5轮，每轮有多个选项。系统记录玩家的**整体基调**。

| 基调判定 | 条件 | `flag_ossus_first_dialogue` | `flag_soul_binding` |
|---------|------|---------------------------|-------------------|
| `hostile` | 选择攻击/威胁/辱骂选项≥3次 | `hostile` | `none` |
| `cautious` | 选择回避/质疑/沉默选项≥3次 | `cautious` | `touched` |
| `receptive` | 选择倾听/询问/认同选项≥3次 | `receptive` | `linked` |

**关键回响**：
- `hostile`：高潮期时亡灵军团会优先攻击你，莫德洛斯在Q235中不会给你对话选项，只能战斗
- `cautious`：标准路线，保留所有选项
- `receptive`：Q235中解锁"永恒"和"融合"结局的前置对话选项；但同时，你的部分队友会开始不信任你

## 五、高等级选择的回响标记

### 5.1 Q226 帝国的最终方案（等级13）

**选择节点：面对帝国净化计划**

| 玩家行动 | `disp_empathy` | `disp_pragmatism` | `flag_empire_purification` | `flag_sacrifice_made` |
|---------|---------------|-------------------|--------------------------|---------------------|
| 执行命令 | -3 | +3 | `executed` | 向`major`偏移 |
| 违抗命令，被通缉 | +2 | -2 | `opposed` | 向`minor`偏移 |
| 尝试第三条路（净化而非销毁） | +2 | +1 | `avoided` | 向`major`偏移 |
| 沉默，不介入 | 0 | +1 | `avoided` | — |

**关键回响**：
- `executed`：Q230中你会在永黯王座遇到一个你"净化"过的村庄的亡灵——一个小女孩。她说："我记得你。你是那个放火的人。我不恨你。我只是想知道……为什么我不配活着？"
- `opposed`：帝国会在高潮期派出刺客追杀你，但同时联邦和独立势力会更信任你

### 5.2 Q230 天灾的核心（等级16）—— 领主救赎

**选择节点：每位黯影领主的命运**

面对每位领主时，玩家可以选择：

| 玩家行动 | `flag_lords_redeemed` | `disp_empathy` | 难度 |
|---------|----------------------|---------------|------|
| 直接消灭 | 不变 | -1 | 标准 |
| 尝试救赎（需要完成特殊机制） | +1 | +2 | 困难 |
| 与领主对话后让其自行选择 | 可能+1或不变 | +1 | 中等 |

**关键机制**：救赎每位领主需要不同的条件：
- **瘟疫领主**（前医师）：需要玩家展示Q215中保留的瘟疫样本，证明"生者世界仍在努力治愈"
- **战争领主**（前元帅）：需要玩家在战斗中不使用任何偷袭/陷阱，用正面荣誉对决击败他
- **饥荒领主**（前萨满）：需要玩家带来食物和水，证明"生者世界仍有丰饶"
- 其他领主各有条件……

**关键回响**：每位被救赎的领主会在Q235最终战中帮助玩家——不是作为战斗力，是作为"见证者"。他们会在莫德洛斯面前说出自己的故事，削弱莫德洛斯的力量。

## 六、阶段性回响事件

为了让玩家感受到"选择有后果"，系统在特定等级触发**回响事件**——不是任务，是自动发生的叙事片段。

### 6.1 等级6回响：第一滴血的回声

**触发条件**：完成Q201-Q205

**事件内容**：

玩家在任意城镇休息时，会收到一封信/遇到一个NPC/看到一个场景：

| 触发条件 | 回响事件 |
|---------|---------|
| Q201中放走了遗骸 | 静眠村的墓地已经完全荒废。村民集体搬迁。老卡特给你寄了一封信："它们每晚都回来。站在村口。不进来。只是站着。像是在等你。或者等你回去。" |
| Q202中深入调查石门 | 你遇到一位联邦学者，他说："你在矿井中看到的壁画……我们在另外七个地点发现了相同的图案。这不是孤立事件。" |
| Q203中支持研究神庙 | 薇拉给你寄来一份报告："神庙中的文献显示，莫德洛斯在一千年前就被预言会归来。预言者说：'他将从被遗忘处归来，而迎接他的人，将是亲手埋葬他的人。'" |
| Q204中杀死病人 | 铁炉堡市长公开发布对你的悬赏。但同时，一位神秘人给你送来匿名信："你做了肮脏但必要的事。这样的人不多。如果你需要盟友，去黑水巷找'无面人'。" |

## 七、结局判定引擎

### 7.1 结局类型与条件

Q235的最终结局由**四个维度**共同决定：

#### 维度1：最终对话选择（Q235第三阶段）

玩家在最终对话中的选择直接锁定结局方向：

| 对话选择 | 倾向结局 |
|---------|---------|
| "你错了。死亡是生命的一部分。我终结你。" | 终结 |
| "你说得对。我加入你。" | 永恒 |
| "我们不需要消灭你。也不需要服从你。" | 封印 |
| "永恒和生命不是对立的。让我证明。" | 融合 |

但**并非所有选项始终可用**。可用性由回响状态决定。

#### 维度2：结局可用性矩阵

| 结局 | 基础可用条件 | 完美达成条件 |
|------|------------|------------|
| **终结** | 始终可用 | `flag_ossus_first_dialogue` ≠ `receptive` 且 `flag_sacrifice_made` ≥ `minor` |
| **永恒** | `flag_ossus_first_dialogue` = `receptive` 或 `flag_soul_binding` ≥ `linked` | `flag_ossus_first_dialogue` = `receptive` 且 `flag_soul_binding` = `sworn` |
| **封印** | 完成Q183「巫妖的图书馆」或拥有特定信仰阶位 | 完成Q183 + `flag_underground_knowledge` = `deep` + `flag_lords_redeemed` ≥ 3 |
| **融合** | `flag_ossus_first_dialogue` = `receptive` + `flag_lords_redeemed` ≥ 3 + `disp_empathy` ≥ +5 | 上述全部 + `flag_sacrifice_made` = `ultimate` + 在Q235对话中连续选对5个关键选项 |

#### 维度3：结局变体

每个结局有**3种变体**，由势力层和标记层决定：

**终结结局变体**：

| 变体 | 条件 | 终局画面 |
|------|------|---------|
| 帝国的终结 | `fac_empire` ≥ 2 | 莫德洛斯被消灭，帝国接管黯影技术，建立"永恒守卫军团"。世界免于天灾，但帝国获得了更可怕的力量。 |
| 联邦的终结 | `fac_federation` ≥ 2 | 莫德洛斯被消灭，联邦公开所有研究，建立"生者保护公约"。世界免于天灾，但联邦的官僚体系让世界变得僵硬。 |
| 孤独的终结 | `fac_independent` ≥ 2 | 莫德洛斯被消灭，没有任何势力获得优势。世界恢复混乱的"正常"——饥饿、疾病、战争继续。你站在他的王座废墟上，不知道这是否值得。 |

**永恒结局变体**：

| 变体 | 条件 | 终局画面 |
|------|------|---------|
| 共治者 | `flag_sacrifice_made` < `ultimate` | 你成为莫德洛斯的副手，管理生者区域。你保留了部分人性，但每晚梦见自己逐渐变得像莫德洛斯。 |
| 新皇帝 | `flag_sacrifice_made` = `ultimate` | 你取代了莫德洛斯，成为新的半神巫妖。你比他更强大，也更孤独。游戏最后一个画面：你坐在永黯王座上，等待下一个挑战者。 |
| 被吞噬 | `flag_viera_fate` = `corrupted` 且薇拉存活 | 你和薇拉一起成为莫德洛斯的仆从。你们保留了彼此的记忆，但失去了自由意志。在永恒的服役中，你们偶尔会对视——那是对彼此的唯一慰藉。 |

**封印结局变体**：

| 变体 | 条件 | 终局画面 |
|------|------|---------|
| 学者的封印 | `flag_underground_knowledge` = `deep` | 你利用古代知识将莫德洛斯封印。封印需要持续维护，你和薇拉（如果她存活）成为终身守护者。 |
| 信仰的封印 | 信仰阶位高（任意信仰） | 你利用信仰力量将莫德洛斯封印。但封印消耗了你的信仰——你的神不再回应你。你获得了胜利，但失去了信仰。 |
| 交易的封印 | `flag_lords_redeemed` ≥ 5 | 被救赎的领主们自愿成为封印的基石。他们代替莫德洛斯进入永恒的囚禁。你拯救了世界，但代价是朋友的永恒痛苦。 |

**融合结局变体**（最难达成）：

| 变体 | 条件 | 终局画面 |
|------|------|---------|
| 新的契约 | 标准融合条件 | 你说服莫德洛斯放弃天灾，改为与活人世界签订"生死契约"：濒死者可以选择有尊严的亡灵化，但不强制。莫德洛斯成为"临终守护者"而非"征服者"。 |
| 双生王座 | `flag_sacrifice_made` = `ultimate` + `flag_viera_fate` = `alive` | 你和薇拉共同说服莫德洛斯。但代价是：你们三人共同承担半神巫妖的力量和责任。你们不会老去，不会死去，但也不会再被世界完全接受。 |
| 最后的对话 | `flag_lords_redeemed` = 7 + 所有支线完成 | 七位被救赎的领主、你、薇拉、莫德洛斯，进行了一场持续三天三夜的对话。没有战斗，没有胜利者。最终，莫德洛斯自愿消散——不是因为被打败，是因为他终于被理解了。 |

**等级18回响**：薇拉的书《我们如何面对终结》——全是问题，没有答案。

**终局（Q235）**：
- 可用结局：终结（孤独的终结）、封印（学者的封印——如果完成Q183）
- 玩家选择终结。
- **实际结局**：孤独的终结。莫德洛斯被消灭，没有任何势力获得优势。
- 终局画面：你站在永黯王座的废墟上。世界恢复了"正常"——混乱、痛苦、但活着。你不知道自己是否做了正确的事。但你知道，你做了一个选择。而在一个充满不确定的世界里，做出选择本身……就是意义。

## 九、向玩家传达回响的叙事手段

### 9.1 不使用的手段

为了维持沉浸感，回响系统**不使用以下方式**：

- ❌ 弹出窗口："你的共情倾向+2！"
- ❌ 任务日志中的数值显示
- ❌ 专门的"回响"UI面板
- ❌ 成就/奖杯提示与选择直接关联

### 9.2 使用的手段

| 手段 | 示例 | 使用频率 |
|------|------|---------|
| **NPC对话变化** | 同一NPC在不同选择后对同一事件的评价不同 | 高频 |
| **环境变化** | 村庄被拯救/毁灭后，地图上的建筑/居民发生变化 | 中频 |
| **信件/日记** | 关键NPC给玩家寄信，内容随选择变化 | 中频 |
| **队友反应** | 队友在营地对话中评论玩家的行为模式 | 高频 |
| **战前对话** | Boss战前的对话根据选择追加不同台词 | 低频（关键战） |
| **商人货物** | 某些物品只在特定选择后出现（如帝国路线的"净化勋章"） | 低频 |
| **随机遭遇** | 开放世界中遇到与玩家选择相关的事件（如被救赎领主的旧部寻求帮助） | 中频 |

### 9.3 关键传达示例

**示例1：队友对Q201选择的反应（等级2-3期间触发）**

假设玩家队伍中有标准队友索伦·铁誓（帝国路线老兵）：

| Q201选择 | 索伦的营地对话 |
|---------|--------------|
| 放走遗骸 | "你……让它们走了。不是杀，不是埋。是放走。我杀了一百四十七个兽人。从来没有放走过一个。你比我……仁慈。还是软弱？我还不知道。" |
| 直接销毁 | "干净。利落。不拖泥带水。我喜欢。但……你有没有想过，它们原本是人？不想也行。多数人不想。" |
| 尝试沟通 | "浪费时间。死人不会说话。……但你的耐心。让我想起了一个人。他也相信敌人可以说话。他死了。" |

**示例2：Q215的瘟疫之源选择对Q230环境的影响**

| Q215选择 | Q230永黯王座的环境 |
|---------|------------------|
| `destroyed` | 王座周围弥漫着怨恨的雾气。死去的黯影居民的灵魂在这里游荡，低语着你的名字。 |
| `preserved` | 王座的一部分被温暖的灰色光芒覆盖。你能感受到那些"活着的亡灵"的存在——它们在为你祈祷，或者诅咒你。 |
| `studied` | 王座周围出现了研究设施的痕迹——你的笔记、你的仪器、你的问题。莫德洛斯说："你比任何人都更接近理解我。这是最危险的距离。" |

## 十、系统边界与例外

### 10.1 不可控因素

以下情况**不影响**回响状态——它们是世界运行的结果，不是玩家的选择：

- 战斗中的随机暴击/闪避
- 队友的默认AI行为（除非玩家下达特定指令）
- 商人货物的随机刷新（非选择相关物品）
- 天气和时间变化

### 10.2 可修正的选择

少数选择允许后续修正，但**修正本身也是选择**：

- `flag_ossus_first_dialogue`：在Q220中确定后，Q235之前有一次机会通过特定支线任务改变（需要完成极其困难的说服/战斗挑战）
- `flag_viera_fate`：如果薇拉向`corrupted`偏移，玩家可以在Q226-Q230期间尝试拯救她（成功率取决于`disp_empathy`和`flag_sacrifice_made`）

### 10.3 多周目继承

二周目时，玩家可以选择"回响记忆"模式：

- 保留上一周目的全部回响状态
- 但可以做出不同的选择，看到不同路径的差异
- 这不改变当前周目的结局，只提供对比视角
- 三周目时，如果完成了所有四个主要结局，解锁"见证者模式"——玩家可以在最终战前自由查看所有回响状态，并选择任意可用结局（不影响当周目，仅用于体验）

## 十一、总结

| 维度 | 设计要点 |
|------|---------|
| **状态架构** | 三层模型：倾向层（3个浮点）、标记层（12个枚举）、势力层（3个整数） |
| **选择记录** | 每个关键任务有2-4个选择节点，影响不同维度 |
| **阶段性反馈** | 等级6/10/13/16/18各有一个回响事件，通过信件/对话/环境变化传达 |
| **结局判定** | 4种主结局 × 3种变体 = 12种终局画面，由对话选择+回响状态共同决定 |
| **叙事传达** | 无UI数值，纯通过NPC对话、环境、信件、队友反应传达 |
| **核心体验** | 玩家从1级到20级，每一步都在"写"自己的结局——只是要到最后一章才知道写的是什么 |

**核心原则**：
> "回响系统不是一个'打分系统'。它是一个'记忆系统'。世界记住了你做过的一切——好的、坏的、模糊的、矛盾的——并在最后，用这些记忆为你铸造一个只属于你自己的结局。"
