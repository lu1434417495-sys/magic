## 核心设计理念

本次扩展的四神信仰，不是独立的"新DLC"，而是**嵌入现有世界观的深层脉络**：

- **正义之神**是秩序之神的**分裂面**——当秩序变成暴政，正义就会觉醒
- **兽人之神**是战火尊的**另一面**——战火尊问"你战了吗"，兽人之神问"你为何而战"
- **生命女神**是Fortuna与Misfortune的**仲裁者**——她不在乎运气，只在乎生死之间的平衡
- **大地之神**是古根的**兄弟**——古根记得过去，大地承载现在

四神信仰的设计遵循现有框架：
- 5阶信仰体系，统一 `FaithDeityDef`/`FaithRankDef` schema
- 每神50个任务（主线20 + 支线20 + 隐藏10），共200个
- 编号 Q201-Q400
- 与现有 Q101-Q200、十轮战役、种族战争深度交织

# 第一神：正义之神「衡世者」艾奎斯（Aequus the Scale-Bearer）

## 一、神格定位

### 1.1 世界观嵌入

正义之神不是「善良」。它不保护弱者，不惩罚邪恶，它只做一件事：**称量**。

> "我不审判。我只称量。左边是你的罪，右边是你的功。如果左边沉了，你就坠下去。如果右边沉了，你就升上去。如果两边平衡——那你就是人。"

**正义之神与秩序之神的关系**（核心设定）：
- 秩序之神是霜烬帝国的国教，代表"规则、法律、服从"
- 正义之神是秩序之神在三百年前「分裂」出的另一面
- 分裂原因：灰烬王朝覆灭时，秩序之神选择了"维持规则"，哪怕规则会导致千万人死亡；正义之神选择了"打破规则"，哪怕打破规则意味着混乱
- 从此，秩序与正义成为对立的两极：秩序说"服从即正义"，正义说"正义即秩序之敌"

**关键叙事**：
- 在霜烬帝国，信仰正义之神是**死罪**
- 在星陨联邦，正义之神被容忍，但不受欢迎——因为联邦的"七族平等"也是一种规则，而正义之神会质疑任何规则
- 在玩家的祖国（多元种族帝国），正义之神是**合法信仰**，但信徒很少——因为"正义"太沉重了

### 1.2 与其他信仰的关系

| 信仰 | 与正义之神的关系 |
|------|----------------|
| **秩序之神** | **死敌**。秩序说"服从规则"，正义说"规则必须被称量" |
| **战火尊** | **复杂**。战火尊不问对错，正义之神只问对错。但正义之神承认：有些罪恶只能用战斗来称量 |
| **古根** | **尊重**。古根记录一切，正义之神称量一切。两者都相信"真相不会消失" |
| **Fortuna** | **蔑视**。正义之神说"运气是弱者的借口，强者的伪装" |
| **Misfortune** | **警惕**。碎镜女神说"厄运即真理"，正义之神说"厄运只是称量的一部分" |
| **生命女神** | **盟友**。两者都关注"个体价值"，但生命女神关注"存在"，正义之神关注"价值" |

### 1.3 正义之神在国家战争中的位置

**帝国的视角**：
- 正义之神信徒是"秩序的破坏者"、"法律的叛徒"
- 帝国有一个秘密组织"衡世猎手"，专门追杀正义之神信徒
- 但讽刺的是：帝国的某些高层也秘密信仰正义之神——因为他们知道帝国的"净化"是不义的

**联邦的视角**：
- 联邦欢迎正义之神信徒对抗帝国
- 但联邦也害怕正义之神——因为联邦的"七族平等"也是一种规则，正义之神会问："如果平等导致更多的死亡，它还正义吗？"

**玩家的位置**：
- 玩家不是正义之神的信徒（除非选择信仰）
- 玩家是"被正义之神注视的人"——因为玩家在Q101中做出了阵营选择，这个选择会被正义之神"称量"

## 二、信仰体系：五阶「称量」

正义之神不称量金银，称量**灵魂**。

| 阶位 | 称号 | 核心含义 | 所需条件 | 供奉 |
|:---:|------|---------|---------|------:|
| 一阶 | **观秤者** | 第一次见证"不正义"而不移开目光 | — | 500 |
| 二阶 | **执秤者** | 亲手做出一个"正义但痛苦"的选择 | 完成任意正义之神任务 | 2000 |
| 三阶 | **断罪者** | 有能力分辨"合法但邪恶"与"违法但正义" | 等级≥14 | 4500 |
| 四阶 | **衡世者** | 成为他人眼中的"正义化身" | 完成Q240 | 8000 |
| 五阶 | **天平之眼** | 可"称量"任何人的灵魂，看到其善恶比重 | 完成Q250 | 14000 |

### 各阶能力

**一阶·观秤者**：
- 「善恶感知」：可看到NPC的"罪孽值"（隐藏属性，范围-100到+100）
- 限制：只能看到"重大罪恶"（杀人、背叛、酷刑），看不到"小恶"（撒谎、贪婪）

**二阶·执秤者**：
- 「正义之誓」：接受任务时，可选择"以正义之名"完成——任务奖励翻倍，但失败惩罚也翻倍
- 「痛苦抉择」：某些任务会出现"正义但痛苦"的选项（如：杀死一个无辜者以拯救十个人）

**三阶·断罪者**：
- 「断罪之眼」：战斗中可看穿敌人的"罪恶"——罪恶越高的敌人，受到你的伤害越高（最高+30%）
- 「法外正义」：对"合法但邪恶"的敌人（如帝国的净化军官），伤害额外+20%

**四阶·衡世者**：
- 「天平衡量」：战斗中可选择"称量"一个敌人——如果其罪恶值>50，直接秒杀（对Boss无效，改为伤害×3）
- 「正义光环」：友方单位对"罪恶敌人"伤害+10%

**五阶·天平之眼**：
- 「灵魂称量」：与任何NPC对话时，可要求其"接受称量"——如果拒绝，说明其心中有鬼；如果接受，你会看到其一生的重大善恶事件
- 「最终审判」：战斗中可释放"天平之眼"——所有敌人显示其罪恶值，并根据罪恶值受到相应伤害（每点罪恶=1点真实伤害）

## 三、正义之神任务链（Q201-Q250）

### 3.1 任务链总览

| 篇章 | 任务编号 | 主题 | 核心冲突 |
|------|---------|------|---------|
| **觉醒篇** | Q201-Q210 | 玩家发现正义之神的存在，第一次称量 | 目睹帝国暴行，选择是否介入 |
| **衡世篇** | Q211-Q230 | 玩家成为正义之神的工具，执行"法外正义" | 合法但邪恶的目标，违法但正义的手段 |
| **分裂篇** | Q231-Q240 | 正义之神与秩序之神的正面冲突 | 帝国的"衡世猎手"追杀玩家 |
| **终章** | Q241-Q250 | 最终的称量——玩家自己接受审判 | 玩家一生的选择被称量 |

### 3.2 关键任务详细设计

#### Q201「秤的第一边」

**触发**：玩家在任意帝国占领区，目睹一次"净化"行动。

**剧情**：
1. 玩家看到帝国士兵将一群混血家庭赶出家园，理由是"血统不纯"
2. 一个帝国军官（不是索伦，是更低级的军官）在旁记录，他的记录本上写着："今日净化：12人。功绩+1。"
3. 玩家可以选择：
   - **不介入**：离开。当晚做梦，梦见一个手持天平的人看着你，天平左边是"12人的生命"，右边是"你的安全"。天平左边沉了下去。
   - **介入**：阻止士兵。会触发战斗（vs 6名帝国士兵）。战斗后，被帝国通缉。
4. 无论选择什么，当晚都会做梦。梦中，手持天平的人说："你看到了。你没有移开眼睛。这就是第一边。"

**奖励**：
- 选择不介入：获得debuff「观秤者的凝视」——48小时内，所有帝国NPC对你态度-10（因为他们感觉到你"看到了"）
- 选择介入：获得buff「观秤者的勇气」——48小时内，对帝国士兵伤害+10%
- 正义之神信仰解锁（可在信仰系统界面选择加入）

#### Q205「合法的邪恶」

**触发**：完成Q201，等级≥10。

**剧情**：
1. 玩家得知一个帝国法官——他从未亲手杀过人，但他签署的"净化令"导致了超过三千人死亡
2. 法官住在帝国城市「霜铠堡」中，受到重重保护
3. 玩家需要选择如何"审判"他：
   - **法庭路线**：收集证据，在帝国法庭起诉他。几乎不可能胜诉（法官就是法律），但如果成功，会引发帝国司法系统的地震
   - **暗杀路线**：潜入法官府邸，杀死他。简单直接，但会让你变成"恐怖分子"
   - **羞辱路线**：公开他的罪证，让他在社会性上死亡。最安全，但法官可能会自杀
4. 正义之神信徒特殊选项：「天平衡量」——直面法官，告诉他"你的罪恶值是87。你签署的文件，每一笔都是血。"

**奖励**：
- 法庭路线胜诉：解锁成就「法内正义」，获得称号「律令之刃」（对合法邪恶敌人伤害+15%）
- 暗杀路线：解锁成就「法外正义」，获得称号「夜衡者」（暗杀成功率+20%，但所有帝国NPC态度-30）
- 羞辱路线：法官自杀，解锁成就「无血之刃」，获得称号「言罪者」（说服力+10，但道德值-5）

#### Q210「秩序的分裂」

**触发**：完成Q205。

**剧情**：
1. 玩家发现一个秘密：秩序之神和正义之神在三百年前的分裂，不是因为"理念不同"，而是因为一个**人**
2. 那个人是灰烬王朝的最后一位公主。秩序之神选择了"保护王朝的规则"，即使这意味着公主必须死；正义之神选择了"保护公主的生命"，即使这意味着王朝会覆灭
3. 公主最终还是死了。秩序之神和正义之神从此分裂
4. 但传说中，公主的灵魂没有消散——她变成了"天平"本身
5. 玩家需要在灰烬交界找到公主的墓。墓中有一把古老的秤

**奖励**：
- 获得「公主之秤」——一个可在战斗中使用一次的道具：称量一个敌人的灵魂，如果其罪恶值>50，直接秒杀（Boss无效）
- 解锁二阶「执秤者」

#### Q220「衡世猎手」

**触发**：完成Q210，玩家在帝国区域活动。

**剧情**：
1. 帝国秘密组织"衡世猎手"开始追杀玩家。他们不是普通的士兵，是**信仰秩序之神的高阶审判官**
2. 衡世猎手的领袖叫「裁决者·瓦伦丁」（Valentine the Arbiter），一个70岁的老妇人， blind in one eye，但另一只眼睛能看到"规则的光芒"
3. 瓦伦丁不恨玩家。她说："你不是邪恶。你是**错误**。秩序不需要敌人，秩序需要**纠正错误**。"
4. 玩家可以选择：
   - **战斗**：杀死瓦伦丁。她是高阶Boss，战斗极其困难
   - **说服**：向她证明"秩序本身也需要被称量"。需要完成一系列前置任务
   - **转化**：让她看到帝国的"净化"是不义的。如果成功，她会成为玩家最强大的盟友——一个从秩序之神转向正义之神的审判官

**Boss机制**：
- 瓦伦丁使用「秩序锁链」——每回合召唤一条锁链束缚一个友方单位，被束缚单位无法行动，但受到的伤害转移到瓦伦丁身上（她在"承受规则的代价"）
- 正义之神信徒≥三阶可「断罪」——指出瓦伦丁的"罪恶"（她杀过无辜者以维持秩序），她会短暂失神，锁链松动

#### Q230「七族审判」

**触发**：完成Q220。

**剧情**：
1. 联邦邀请玩家参与"七族审判"——审判一名被指控"战争罪"的帝国战俘
2. 但问题在于：这名战俘是一个**被迫参战的农民**，他从未杀过人，只是在军队中做饭
3. 联邦的某些代表（特别是精灵代表）要求处死他，因为"帝国的人都该死"
4. 玩家作为"正义之神的代表"，需要做出裁决：
   - **释放他**：联邦内部的复仇派会愤怒，但玩家维护了"个体正义"
   - **处死他**：联邦满意，但玩家违背了正义之神的原则
   - **折中**：让他"赎罪"——在联邦的难民营中服务十年。但帝国会认为这是"奴隶制"
5. 正义之神信徒≥四阶可「天平衡量」——直接称量战俘的灵魂，证明其无辜。但代价是：你会看到所有人的灵魂，包括联邦代表的——他们中也有罪恶

**核心冲突**：
- 这不是"善恶对决"，是"正义vs正义"——联邦的"集体正义"（惩罚帝国）vs 正义之神的"个体正义"（保护无辜者）

#### Q240「天平的两端」

**触发**：完成Q230。

**剧情**：
1. 玩家得知一个终极秘密：正义之神和秩序之神的分裂，其实是**故意的**
2. 三百年前的分裂，是两位神共同的决定——因为只有分裂，才能"称量"人类在"秩序"和"正义"之间的选择
3. 换句话说：正义之神和秩序之神是**同一个存在的两面**，它们的"战争"是一场持续了三百年的实验
4. 玩家需要做出选择：
   - **支持秩序**：告诉世界"秩序即正义"，秩序之神和正义之神重新合并为"秩序-正义之神"
   - **支持正义**：让世界知道"正义高于秩序"，两位神继续分裂，但正义之神获得更高的地位
   - **拒绝选择**：说"我不选"。这是隐藏路线——玩家会发现，公主的灵魂（天平本身）一直在等待一个说"我不选"的人。因为"不选"也是一种选择

**奖励**：
- 支持秩序：获得「秩序之链」——可束缚任何敌人3回合，但自己也无法行动（"维持规则的代价"）
- 支持正义：获得「正义之秤」——战斗中可称量任意敌人，根据罪恶值造成伤害
- 拒绝选择：获得「公主之眼」——可看到所有NPC的隐藏罪恶值，且可选择"不称量"（尊重他人的隐私）

#### Q250「最终的称量」

**触发**：完成Q240，等级≥28。

**剧情**：
1. 玩家被召唤到"天平之间"——一个存在于现实与梦境之间的空间
2. 正义之神和秩序之神同时出现——它们不是人形，是两团光芒（金色=秩序，银色=正义）
3. 它们说："三百年来，你是第一个走到这里的人。现在，称量你自己。"
4. 玩家的所有选择被「称量」：
   - 杀过多少人？（每个无辜者-10分，每个罪恶者+5分）
   - 救过多少人？（每个无辜者+10分）
   - 说过多少次谎？（每次-1分）
   - 背叛过多少次？（每次-5分）
   - 帮助过多少次？（每次+2分）
5. 根据总分，玩家获得不同的结局：
   - **总分>100**：「正义化身」——获得五阶「天平之眼」，且所有正义之神技能永久增强50%
   - **总分0-100**：「凡人」——获得五阶，但技能无增强。正义之神说："你不是圣人，也不是恶魔。你是人。这是最难得的。"
   - **总分<0**：「罪人」——无法获得五阶。正义之神说："你的秤，左边沉了。但我不会杀你。因为杀人，会让我的秤也沉下去。"（玩家需要完成赎罪任务才能重新获得五阶）

# 第二神：兽人之神「血祖」古鲁什（Gurush the Blood Ancestor）

## 一、神格定位

### 1.1 世界观嵌入

兽人之神不是"战神"。战火尊问"你战了吗"，兽人之神问"你为何而战"。

> "战斗不是为了杀人。战斗是为了让敌人记住你的名字。当你的名字被遗忘时，你才真正死了。"

**兽人之神的本质**：
- 它是兽人种族的**集体记忆**——不是某个具体的神，是所有死去的兽人英雄的"名字"的集合
- 兽人相信：当一个人死去，他的名字会回归"血祖"；当血祖被呼唤时，所有名字会同时回应
- 因此，兽人之神的声音不是单一的，是**千万个声音的合唱**

**与战火尊的区别**（核心设定）：
- 战火尊："战斗证明存在。" → 存在主义，不问原因
- 兽人之神："战斗证明你是谁。" → 身份主义，只问原因
- 兽人可以同时信仰两者——在战斗前向战火尊祈祷"让我战斗"，战斗后向兽人之神祈祷"记住我的名字"

**与兽人帝国的关系**：
- 战争派（格罗姆）主要信仰**战火尊**——他们更关心"战斗本身"
- 和平派（萨娜）主要信仰**兽人之神**——他们更关心"为什么战斗"
- 但两者都会说："血祖记得一切。"

### 1.2 与其他信仰的关系

| 信仰 | 与兽人之神的关系 |
|------|----------------|
| **战火尊** | **盟友但不同**。可以共存，但核心理念不同 |
| **古根** | **尊重**。古根记住世界，血祖记住兽人。两者都相信"记忆即存在" |
| **正义之神** | **复杂**。血祖不问对错，只问"你是否忠于自己的名字" |

**核心冲突**：

   - **维护幻觉**：保护真相，让兽人继续相信血祖。这维持了兽人的团结，但也是欺骗
   - **重新定义**：说"血祖不存在，但我们的名字确实存在——在彼此的记忆中"。这是隐藏路线，需要≥16智慧

- 维护幻觉：获得「守护之誓」——所有兽人NPC态度+30，但你必须永远保守秘密
- 重新定义：获得「新血祖」——你成为"活着的血祖"，你的名字被千万兽人记住

#### Q300「万血归一」

**触发**：完成Q290，等级≥28。

# 第三神：生命女神「织命者」瑟拉娜（Serana the Weaver）

## 一、神格定位

### 1.1 世界观嵌入

生命女神不是"治愈者"。她不消除痛苦，她**编织痛苦**——把痛苦织进生命的纹理中，让它成为生命的一部分。

> "我不消除死亡。我编织死亡。每一条生命的结束，都是另一条生命的开始。我不是在救你，我是在继续编织。"

**生命女神的本质**：
- 她是"生命"这个概念本身的具象化——不是某个仁慈的母亲，是**编织命运的织女**
- 她手中的线不是丝线，是**血脉**——每个人的血脉都是她织锦中的一根线
- 她不在乎你是谁、你做了什么。她只在乎一件事：**你的线，是否还在织锦中**

**生命女神与死亡的关系**（核心设定）：
- 生命女神不否认死亡。她说："死亡是剪断线，不是结束编织。"
- 在生命女神的信仰中，"复活"不是让死者回来，是**把死者的线织入生者的织锦中**
- 因此，生命女神的"复活"仪式实际上是"记忆传承"——死者的记忆和技能被传递给生者

**与Fortuna/Misfortune的关系**（核心设定）：
- Fortuna问"你是否被命运选中"，Misfortune问"你是否能驾驭厄运"
- 生命女神说："命运和厄运都是线。我只是把它们织在一起。"
- 生命女神是Fortuna和Misfortune的**仲裁者**——当两者的力量失衡时，生命女神会"剪断"或"续接"某些线

### 1.2 与其他信仰的关系

| 信仰 | 与生命女神的关系 |
|------|----------------|
| **Fortuna** | **平衡**。Fortuna给予运气，生命女神决定运气的"代价" |
| **Misfortune** | **平衡**。Misfortune带来厄运，生命女神决定厄运的"终点" |
| **战火尊** | **对立**。战火尊以死亡证明存在，生命女神以存在超越死亡 |
| **古根** | **姐妹**。古根记住过去，生命女神编织现在。两者共同构成"时间" |
| **正义之神** | **尊重**。生命女神关注"存在"，正义之神关注"价值"。两者互不干涉 |
| **兽人之神** | **盟友**。兽人之神记住名字，生命女神延续血脉。两者共同构成"传承" |

### 1.3 生命女神在国家战争中的位置

**帝国的视角**：
- 帝国官方不禁止生命女神信仰（因为"治愈"有用）
- 但帝国严格控制生命女神的"复活"仪式——因为帝国害怕死者回来"说出真相"
- 帝国有一个秘密：在"净化"行动中死亡的人，他们的"线"被帝国强行"剪断"，防止生命女神的信徒通过织锦找到他们

**联邦的视角**：
- 联邦欢迎生命女神信仰，特别是在战争中救治伤员
- 但联邦也担心生命女神的"中立"——她不只救联邦的人，她也救帝国的人
- 联邦曾要求生命女神的"织命者"（高阶信徒）只救联邦士兵，被拒绝。生命女神说："我的线，不分颜色。"

**玩家的位置**：
- 如果玩家选择生命女神信仰，你会成为"战场上的中立者"——两边都会找你治愈，但两边也都会怀疑你

## 二、信仰体系：五阶「织命」

生命女神不称量灵魂，不铭记名字，她**编织血脉**。

| 阶位 | 称号 | 核心含义 | 所需条件 | 供奉 |
|:---:|------|---------|---------|------:|

### 各阶能力

**一阶·触线者**：
- 「生命线感知」：可看到自己和友方单位的"生命强度"（不是HP，是"生命的质量"——一个垂死的老人可能比健康的士兵有更高的"生命强度"）
- 「濒死感知」：可感知附近即将死亡的人（24小时内），但无法知道是谁或为什么

**二阶·织线者**：
- 「生命链接」：可与一个友方单位建立链接——你受到的伤害的30%转移到对方身上，对方受到的伤害的30%转移到你身上
- 「血脉共鸣」：与建立链接的单位同场作战时，双方HP恢复速度+50%

**三阶·断线者**：
- 「断线剪」：对敌人使用，切断其"生命之线"——不是直接伤害，是阻止其恢复HP（持续3回合）
- 「续线针」：对友方使用，如果友方在3回合内死亡，自动复活一次（恢复30%HP）

**四阶·织命者**：
- 「命运编织」：战斗中可选择"编织"——将两个友方单位的能力交换（持续2回合）
  - 例如：让坦克获得法师的攻击力，让法师获得坦克的防御力
- 「血脉继承」：战斗结束后，如果友方单位死亡，你可以"继承"其一项技能（永久，但每场战斗只能继承一次）

**五阶·命轮之眼**：
- 「命轮视界」：可看到整个战场的"生命之网"——每个单位都是网上的节点，你可以预测3回合后的战况（哪些单位会死、哪些会活）
- 「轮回」：战斗中可选择"重启"——将战斗倒退回3回合前的状态（每场战斗只能使用一次，且你自己失去3回合内获得的所有增益）

## 三、生命女神任务链（Q301-Q350）

### 3.1 任务链总览

| 篇章 | 任务编号 | 主题 | 核心冲突 |
|------|---------|------|---------|
| **触线篇** | Q301-Q310 | 玩家第一次看到生命之线，理解生命的脆弱 | 在战争中救治伤员，但救不了所有人 |
| **织线篇** | Q311-Q330 | 玩家学会编织生命之线，理解生命的连接 | 选择救谁、不救谁的道德困境 |

### 3.2 关键任务详细设计

#### Q301「第一次触线」

**触发**：玩家在任意战斗中，看到一个友方NPC死亡。

**剧情**：
1. 死亡发生时，玩家突然看到一条银色细线从死者的胸口延伸出来，缓缓飘向天空
2. 线在空中停留了三秒，然后消散了
3. 一个声音说："你看到了。那是生命之线。每个人的线，最终都会断。"
4. 玩家可以选择：
   - **恐惧**：闭上眼睛。获得debuff「线惧」——48小时内，无法看到任何NPC的HP（因为你害怕看到线断的那一刻）
   - **接受**：伸手触碰那条消散的线。获得buff「触线者」——可看到所有单位的"生命强度"
   - **追问**：问"那根线去了哪里？" 这会触发隐藏路线——生命女神说："去了织锦中。"

**奖励**：
- 接受路线：生命女神信仰解锁
- 追问路线：额外获得「织锦碎片」——一个道具，使用后可以看到任意NPC的"死亡时间"（但不是日期，是"还有多久"）

#### Q305「救不了的十个人」

**触发**：完成Q301，等级≥10。

**剧情**：
1. 玩家在战场上发现十名重伤士兵——5名帝国士兵，5名联邦士兵
2. 玩家只有足够的治疗资源救**5个人**
3. 玩家需要选择：
   - **救帝国士兵**：联邦会视你为叛徒，但帝国士兵会记住你
   - **救联邦士兵**：帝国会视你为敌人，但联邦会感谢你
   - **各救一半**：两边都不满意——"你为什么不救我们这边更多？"
   - **一个都不救**：把资源留给自己。这是最"理性"的选择，但也是最冷酷的
4. 生命女神信徒特殊选项：「织线」——将自己的生命之线与十个人同时连接，分担他们的伤害。你会承受巨大的痛苦（HP降至10%），但十个人都会活下来

**核心冲突**：
- 生命女神的教义："线不分颜色。"
- 但战争说："敌人的线，应该断。"
- 玩家的选择：成为"中立的治愈者"，还是"有阵营的医生"？

#### Q310「复活的代价」

**触发**：完成Q305。

**剧情**：
1. 玩家遇到一名生命女神的高阶信徒——「织命者·艾尔莎」（Elsa the Weaver）
2. 艾尔莎可以"复活"死者——但不是真正的复活，是"织入"：将死者的记忆和技能织入生者的织锦中
3. 她向玩家展示了一个仪式：
   - 选择一名死去的NPC（必须是玩家认识的）
   - 选择一名活着的NPC（必须是玩家认识的）
   - 死者的记忆会进入生者的梦中，生者会获得死者的一项技能
4. 但代价是：生者会"失去一部分自己"——一个记忆、一种情感、或一段关系
5. 玩家需要决定是否进行仪式：
   - **进行**：选择死者和生者。生者获得技能，但失去某样东西
   - **拒绝**：艾尔莎说："你害怕失去。但生命就是失去。"
   - **质疑**：问"这真的是复活吗？还是只是复制？" 艾尔莎会沉默很长时间，然后说："我不知道。"

**奖励**：
- 进行仪式：生者获得死者的一项技能，但随机失去一个关系（某个NPC对你的态度-30）
- 拒绝：获得「守线者」称号——你拒绝剪断任何人的线，即使是为了连接。所有生命女神技能效果+10%
- 质疑：解锁隐藏任务Q311「复制的灵魂」

#### Q320「帝国的剪线人」

**触发**：完成Q310，玩家在帝国区域活动。

**剧情**：
1. 玩家发现帝国有一个秘密组织"剪线人"——专门杀害生命女神的信徒，并"剪断"死者的生命之线
2. 剪线人的目的是：防止生命女神的信徒通过织锦找到"净化"行动的真相
3. 帝国的首席剪线人叫「断线者·维克托」（Victor the Line-Breaker），一个曾经是生命女神信徒的叛徒
4. 维克托说："我剪断线，不是为了杀人。是为了**保护活着的人**——如果死者回来，会带来更多的死亡。"
5. 玩家需要选择：
   - **杀死维克托**：结束剪线人的威胁，但维克托的线也被剪断了
   - **说服维克托**：让他重新信仰生命女神。需要证明"死者的记忆不会带来死亡，只会带来真相"
   - **利用维克托**：让他帮你剪断某个敌人的线。这是黑暗路线

**Boss机制**：
- 维克托使用「断线剪」——可瞬间杀死HP<20%的单位（无视防御）
- 生命女神信徒≥三阶可「续线」——在被剪断的瞬间自动复活一次

#### Q330「织命者的选择」

**触发**：完成Q320。

**剧情**：
1. 玩家成为正式的「织命者」，需要执行第一次"命运编织"
2. 任务：一名孕妇即将难产死亡，胎儿也活不了。但生命女神说："两条线，只能留一条。"
3. 玩家需要选择：
   - **救母亲**：剪断胎儿的线。母亲活下来，但会永远恨你
   - **救胎儿**：剪断母亲的线。胎儿活下来，但永远不会知道自己的母亲
   - **尝试两条都救**：几乎不可能。但如果玩家持有「钢铁盟约之印」（来自兽人帝国任务Q144），可以呼唤铁爪的灵魂协助——铁爪曾帮助人类母亲接生。成功率为30%
   - **拒绝选择**：说"我不选"。生命女神会亲自动手——随机选择一条线留下
4. 如果选择"两条都救"并成功：母亲和胎儿都活下来。但生命女神说："你改变了织锦。这很好。但改变织锦的人，最终也会被织锦改变。"

**核心冲突**：
- "有权力决定生死"是否意味着"应该决定生死"？
- 生命女神的答案是："我不决定。我只是继续编织。"

#### Q340「织锦的终点」

**触发**：完成Q330。

**剧情**：
1. 玩家看到生命女神的"织锦"——不是比喻，是**真实存在的巨大织物**，悬浮在虚空之中
2. 织锦上有千万根线，每根线代表一个生命
3. 但织锦有一个"终点"——所有的线都在某处汇聚，然后……停止
4. 生命女神说："那是'大断裂'——所有的线最终都会断。没有例外。"
5. 玩家问："谁在终点剪断所有的线？"
6. 生命女神说："没有人。线自己断。"
7. 但玩家发现：在"大断裂"之前，有一些线被**提前剪断**了——那是帝国"净化"行动的死者、那是战争中的牺牲者、那是……
8. 玩家意识到：生命女神不是中立的。她在"保护"某些线（让它们延续到终点），同时"放弃"另一些线（让它们提前断裂）
9. 玩家需要质问生命女神："你在选择谁该活、谁该死。"
10. 生命女神的回答："我不是在选择。我是在**编织**。有些线，注定要断。因为它们的断裂，会让其他线延续得更长。"

**核心 revelation**：
- 生命女神不是"仁慈的治愈者"，是**冷酷的编织者**
- 她的"治愈"不是无偿的——她治愈你，是因为你的延续对"织锦"有用
- 如果她认为你的"线"应该断，她会微笑着看着你死去

#### Q350「命轮之眼」

**触发**：完成Q340，等级≥28。

**剧情**：
1. 玩家被召唤到"织锦之间"——生命女神的居所
2. 生命女神问："你愿意看到织锦的全部吗？"
3. 玩家选择：
   - **愿意**：看到整个世界的生命之网。你会看到：
     - 哪些NPC会在未来死亡（以灰色显示）
     - 哪些NPC会在未来诞生（以金色显示）
     - 你自己的线——它会延伸到哪里？
   - **不愿意**：生命女神说："聪明的选择。看到全部的人，往往会发疯。"
4. 如果愿意，玩家会看到一个 shocking 的真相：
   - 玩家的线，与某个 Boss 的线**交织在一起**——这意味着玩家和那个 Boss 必须死一个，或者……两者都死
   - 那个 Boss 是：霜烬帝国的皇帝弗拉维斯三世（或者，如果玩家选择了帝国路线，是联邦的某位领袖）
5. 玩家需要做出最终选择：
   - **接受命运**：知道自己的死亡时间，但无法改变。获得五阶「命轮之眼」，但获得debuff「命运锁定」——无法通过任何方式延长自己的寿命
   - **反抗命运**：尝试改变自己的线的走向。这是隐藏路线，需要完成一系列极其困难的任务。如果成功，你会「跳出织锦」——不再受生命之线的束缚，但也无法再被治愈（生命女神说："你不属于我的织锦了。"）

# 第四神：大地之神「地脉者」特拉蒙（Terramon the Vein-Bearer）

## 一、神格定位

### 1.1 世界观嵌入

大地之神不是"自然之神"。他不关心森林、不关心动物，他只关心**岩石、土壤、矿物、地质**。

> "森林会枯萎，河流会干涸，动物会死亡。但岩石不会。岩石只是等待。等待森林枯萎，等待河流干涸，等待动物变成化石。然后，岩石会记住一切。"

**大地之神与古根的关系**（核心设定）：
- 古根是"世界根"——记住过去的世界
- 大地之神是"世界骨"——承载现在的世界
- 两者是**兄弟**：古根是"记忆"，大地是"存在"
- 古根问"你记得什么？"，大地问"你站在哪里？"

**大地之神的本质**：
- 他是"地质时间"的具象化——人类的历史在他眼中只是一瞬间
- 他不关心战争、不关心政治，他关心**矿脉的走向、地震的周期、火山的觉醒**
- 但当地下 something 被挖出来（如灰烬交界的界火、龙血药剂的材料、帝国的武器），大地之神就会"醒来"

### 1.2 与其他信仰的关系

| 信仰 | 与大地之神的关系 |
|------|----------------|
| **古根** | **兄弟**。记忆与存在，过去与现在。两者共同构成"世界" |
| **摩拉丹** | **盟友**。摩拉丹（锻造之神）需要矿物，大地提供矿物。但摩拉丹取走矿物时，大地会"痛" |
| **生命女神** | **尊重**。生命在地面上编织，大地在地下承载。两者互不干涉 |
| **龙神** | **复杂**。龙族盘踞在火山中，大地之神说"那是我的伤口"。但龙族也保护火山不爆发 |
| **Fortuna/Misfortune** | **无关**。大地不相信运气，只相信地质规律 |

### 1.3 大地之神在国家战争中的位置

**帝国的视角**：
- 帝国大量开采矿物，建造「冰龙舰队」、铸造武器
- 大地之神不恨帝国，但帝国的过度开采唤醒了"地下 something"
- 帝国不知道的是：他们建造的「霜墙」（边境防线），正好建在一座休眠火山的岩浆通道上

**联邦的视角**：
- 联邦的七塔（法师公会）需要界火燃料，这要求深入地下开采
- 大地之神对七塔说："你们取走的，不只是燃料。你们取走了我的记忆。"

**玩家的位置**：
- 如果玩家选择大地之神信仰，你会成为"地下的守护者"——阻止过度开采，保护地质平衡
- 但这意味着你会与帝国、联邦、甚至矮人都发生冲突（矮人最爱挖矿）

## 二、信仰体系：五阶「地脉」

大地之神不称量灵魂，不铭记名字，不编织血脉，他**承载一切**。

| 阶位 | 称号 | 核心含义 | 所需条件 | 供奉 |
|:---:|------|---------|---------|------:|
| 一阶 | **触地者** | 第一次感受到"地脉"——地下能量的流动 | — | 500 |
| 二阶 | **掘脉者** | 学会寻找矿脉、预测地震、感知地下空洞 | 完成任意大地之神任务 | 2000 |
| 三阶 | **地语者** | 能与大地"对话"——通过震动传递信息 | 等级≥14 | 4500 |
| 四阶 | **地脉行者** | 可以在地下行走，穿越岩石和土壤 | 完成Q390 | 8000 |
| 五阶 | **世界之骨** | 成为大地的化身，可以引发或阻止地震、火山爆发 | 完成Q400 | 14000 |

### 各阶能力

**一阶·触地者**：
- 「地脉感知」：可感知地下的矿脉、空洞、和" something "的位置
- 「震感」：可预测24小时内的小地震（对战斗无直接影响，但可用于解谜）

**二阶·掘脉者**：
- 「矿脉之眼」：在地图上显示附近的矿脉位置（可用于采集资源）
- 「地震预警」：战斗中如果场地有地震风险，会提前3回合预警

**三阶·地语者**：
- 「震波传递」：可与远方的友方单位通过震动传递信息（无视距离，但只能传递简单的信息如"危险"、"安全"）
- 「地牢感知」：可感知地下建筑（如矿洞、墓穴、秘密基地）的布局

**四阶·地脉行者**：
- 「遁地」：战斗中可选择遁入地下（无敌1回合，但无法行动），然后从任意位置出现
- 「岩甲」：AC+5，移动力-2（岩石覆盖身体）

**五阶·世界之骨**：
- 「地震」：引发地震，所有敌人受到2d6伤害并眩晕1回合（友方也受影响，除非提前预警）
- 「火山唤醒」：在有火山的地图中，可唤醒火山——全场持续受到火焰伤害，但友方获得火焰抗性

## 三、大地之神任务链（Q351-Q400）

### 3.1 任务链总览

| 篇章 | 任务编号 | 主题 | 核心冲突 |
|------|---------|------|---------|
| **触地篇** | Q351-Q360 | 玩家第一次感受到地脉，理解大地的力量 | 过度开采 vs 地质平衡 |

### 3.2 关键任务详细设计

#### Q351「第一次触地」

**触发**：玩家在矿山、洞穴、或地下城中，感受到"震动"——不是地震，是某种规律的、有节奏的震动。

**剧情**：
1. 玩家听到一个声音——不是从耳朵传来的，是从脚底传来的
2. 声音说："你站在我的骨头上。"
3. 玩家低头看地面，发现脚下的岩石在微微发光
4. 玩家可以选择：
   - **恐惧**：跳开。获得debuff「地惧」——48小时内，无法在石头/土地上恢复HP
   - **倾听**：蹲下，把手放在地面上。感受到"地脉"——地下能量的流动
   - **挖掘**：拿出工具开始挖掘。挖到10米深时，发现一块发光的矿石——那是"地脉石"，大地之神的"骨碎片"
5. 大地之神信仰解锁

**奖励**：
- 倾听路线：获得「地脉感知」能力（一阶）
- 挖掘路线：额外获得「地脉石」——一个道具，使用后可暂时看到地下100米的地质结构

#### Q355「帝国的矿难」

**触发**：完成Q351，等级≥10。

**剧情**：
1. 帝国的一座铁矿发生坍塌，500名矿工被困
2. 帝国不救援——因为矿工中80%是矮人和混血，帝国认为"不值得"
3. 玩家需要选择：
   - **救援**：潜入坍塌的矿井，救出矿工。这需要完成一系列解谜（找到安全通道、支撑摇摇欲坠的岩壁、避开有毒气体）
   - **不救**：离开。当晚做梦，梦见大地之神说："我的骨头里，卡着五百个灵魂。"
   - **揭露**：公开帝国的冷漠。这会引发舆论风暴，但帝国会追杀你
4. 大地之神信徒特殊选项：「地语」——与大地对话，问"安全的通道在哪里？" 大地会回应，通过震动指引你

**核心冲突**：
- 大地之神不"关心"矿工。他说："他们只是回到了我的骨头里。"
- 但玩家发现：大地之神虽然不"关心"，但他"记得"——每块岩石中都有矿工的"痕迹"

#### Q360「矮人的禁忌」

**触发**：完成Q355。

**剧情**：
1. 玩家深入矮人地下城，发现矮人有一个禁忌：不能挖到"某个深度"
2. 那个深度被称为"地骨之界"——大地之神的"骨头"开始的地方
3. 矮人传说：曾经有一支矮人部落挖穿了地骨之界，结果引发了地震，整个部落被埋葬
4. 但玩家发现：那支矮人部落不是被"埋葬"的，是**被大地之神"吸收"了**——他们的身体变成了岩石，他们的记忆变成了矿脉
5. 玩家需要选择：
   - **尊重禁忌**：不再向下挖掘。获得「守界者」称号——所有矮人NPC态度+20
   - **打破禁忌**：继续向下。你会发现大地之神的"真身"——不是神，是**一个巨大的、沉睡的生物**，它的身体就是整个大陆的地下结构
   - **记录禁忌**：把矮人的传说记录下来，但不亲自下去。这是最"学者"的选择

**核心 revelation**：
- 大地之神不是"神"，是**地质生物**——一个存在了亿万年的巨大存在，它的"意识"就是地质活动本身
- 矮人的"摩拉丹"（锻造之神），实际上是矮人对大地之神的**误解**——他们把大地的矿物当作"神的恩赐"，但大地之神说"那不是恩赐，是我的骨头"

#### Q370「霜墙之下」

**触发**：完成Q360，玩家在帝国北方边境活动。

**剧情**：
1. 玩家发现帝国的「霜墙」（边境防线）建在一座休眠火山的岩浆通道上
2. 如果火山爆发，霜墙会被彻底摧毁，帝国北方会陷入混乱
3. 帝国不知道这个地质风险——或者，他们知道但不在乎
4. 玩家需要选择：
   - **警告帝国**：告诉他们霜墙的危险。帝国会感谢你，但可能不会采取行动（"火山已经休眠了三百年"）
   - **利用这个信息**：告诉联邦或兽人帝国。这会给你巨大的谈判筹码，但可能导致战争升级
   - **修复地质**：使用大地之神的能力，改变岩浆通道的走向。这是最困难但最道德的选择
5. 大地之神信徒≥三阶可「地语」——直接问大地"火山什么时候爆发？" 大地会回答："当我的骨头，被压得太痛时。"

#### Q380「灰烬交界的真相」

**触发**：完成Q370。

**剧情**：
1. 玩家深入灰烬交界，发现「界火」不是普通的魔法能量——它是**大地之神的"血液"**
2. 灰烬王朝覆灭时，大地之神"受伤"了，它的血液（岩浆）渗出地表，形成了界火
3. 帝国和联邦争夺界火，实际上是在**抽取大地之神的血液**
4. 大地之神说："我不恨他们。他们只是太渺小了，看不到自己在做什么。"
5. 玩家需要选择：
   - **保护界火**：阻止任何人开采。这会与帝国、联邦、甚至矮人都发生冲突
   - **利用界火**：继续开采，但用大地之神的能力"治愈"大地的伤口（让界火稳定，不再扩散）
   - **传播真相**：告诉世界界火的真相。大多数人不会相信，但相信的人会加入你

#### Q390「地脉行者」

**触发**：完成Q380。

**剧情**：
1. 玩家学会「遁地」——在地下行走的能力
2. 第一次遁地时，玩家看到了"地下的世界"——不是黑暗的洞穴，是**发光的、有生命的地质结构**
3. 大地之神的"身体"不是死的，是**活的**——它的"血管"是岩浆通道，它的"神经"是矿脉，它的"意识"是地震
4. 玩家在地下遇到了"地脉生物"——不是动物，是**由矿物和能量构成的生命体**
5. 这些生物说："我们是大地之神的'梦'。当他醒来时，我们会消失。"
6. 玩家需要选择：
   - **与地脉生物交流**：了解大地的"梦境"
   - **猎杀地脉生物**：它们含有稀有的矿物（这是黑暗路线）
   - **保护地脉生物**：让大地之神继续"睡"，这样地脉生物就能继续存在

#### Q400「世界之骨」

**触发**：完成Q390，等级≥28。

**剧情**：
1. 玩家被召唤到"地心之间"——大地之神的"心脏"
2. 不是比喻。玩家真的来到了大陆的地下核心，看到了大地之神的"真身"——一个由岩石、岩浆、和矿物构成的巨大生物，它的大小相当于一个帝国
3. 大地之神说："我承载了一切。森林、河流、城市、战争。但我在'痛'。"
4. 玩家问："为什么痛？"
5. 大地之神说："因为你们在我的骨头上建造、在我的血管里抽取、在我的神经上行走。我不恨你们。但我会'醒'。"
6. 玩家意识到：如果大地之神"醒来"，大陆会经历毁灭性的地质灾难——所有火山同时爆发、所有地震同时发生、所有矿脉同时坍塌
7. 玩家需要做出最终选择：
   - **让大地继续沉睡**：使用自己的能力，安抚大地之神。代价是：你的一部分身体会变成岩石（永久失去一个肢体，获得一个岩石义肢）
   - **让大地醒来**：告诉世界大地的真相。大地会"醒"，灾难会发生，但人类（和其他种族）会学会尊重大地
   - **成为大地的一部分**：与大地之神融合。你不再是一个独立的个体，你成为了大地的"神经"之一——你可以感知整个大陆的地质活动，但你也失去了"人性"
