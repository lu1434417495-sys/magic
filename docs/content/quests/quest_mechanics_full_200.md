# 200任务完整机制设计

> 为全部200个任务补充详细的可玩机制：目标结构、战棋规则、敌人AI、环境交互、抉择分支、奖励差异。

---

## 第一部分：帝国战争十轮战役

### 战役总览：《霜烬与星陨》

**参战势力**：
- **霜烬帝国**（北方）：军事专制，信奉秩序之神。核心战力：重甲军团"霜铠师"、冰霜法师团"永冻院"。皇帝弗拉基斯三世，"永恒者"，传闻已活两百年。
- **星陨联邦**（南方）：城邦联盟，信奉自由与贸易。核心战力：轻骑兵"流星团"、元素法师公会"七塔"。最高议会由七大家族轮流执政。

**战争导火索**：灰烬交界裂隙中可提炼"界火燃料"——一种能让凡人物品获得魔法属性的战略资源。双方为争夺裂隙控制权，从代理人摩擦升级为全面战争。

**战役进度系统**：
- 双方各有"战争进度条"（0-100），玩家任务选择会影响进度。
- 帝国进度 > 联邦进度 +30：进入"帝国优势线"
- 联邦进度 > 帝国进度 +30：进入"联邦优势线"
- 差距 < 30：维持在"拉锯线"
- 每完成一轮战役任务，根据结果调整进度（±5至±15）

### 轮一：烽火初起

**任务**：Q101 征兵令 + Q102 商路封锁（序章）

**战场态势**：战争刚爆发，双方动员中。边境有小规模冲突，但主力尚未投入。

**Q101 征兵令 详细机制**：

**目标结构**：
1. `settlement_action(service_contract_board, 1)` — 接取时阵营选择
2. `defeat_enemy(wolf_raider, 3)` — 清理边境骚扰队（序章战斗）

**战棋设计**：
- 场地：8×8 边境哨站外围，有"拒马"（1格障碍，可攀爬消耗2AP）和"瞭望塔"（顶部射程+2）
- 敌人：`wolf_raider` ×3，AI为 `ranged_archer`，但骑乘状态移动力+2
- 特殊：这是玩家首次面对"骑射"敌人——它们射击后移动，不会原地挨打
- 友方NPC：哨站民兵×2（前排步兵，会主动挡在玩家前面）

**阵营选择机制**（通过 settlement_action 实现）：
- **A. 加入霜烬帝国**：
  - 获得"帝国征召兵"标签
  - 解锁帝国任务链（Q101-Q125中的帝国路线）
  - 战争进度：帝国+5
  - 特殊奖励：`iron_scale_mail`（帝国制式甲，AC+5）
- **B. 加入星陨联邦**：
  - 获得"联邦志愿兵"标签
  - 解锁联邦任务链
  - 战争进度：联邦+5
  - 特殊奖励：`scout_charm`（联邦侦察符，感知+1）
- **C. 拒绝双方（自由佣兵）**：
  - 获得"无阵营"标签
  - 所有阵营任务可接取，但无法获得阵营专属奖励和称号
  - 战争进度：不变
  - 特殊奖励：`travel_ration` ×10 + 金币200

**后续影响**：此选择永久锁定，影响轮二至轮十的所有任务可用性和NPC态度。

### 轮二：海上绞杀

**任务**：Q102 商路封锁 / Q106 刺杀行动

**战场态势**：联邦私掠舰队封锁北方海峡，帝国商路断绝。帝国需要突破封锁或斩首指挥官。

**根据轮一选择，解锁不同任务**：

**帝国路线 — Q102 商路封锁（正面突破）**：

**目标结构**：
1. `defeat_enemy(mist_harrier, 4)` — 清理私掠舰队上的飞行单位（敌方侦察/传讯）
2. `defeat_enemy(wolf_vanguard, 6)` — 跳帮击败甲板上的敌方战士
3. `settlement_action(service_contract_board, 1)` — 报告突破成功

**战棋设计**：
- 场地：三艘战舰拼接的16×10网格
  - 左侧：己方战舰（6×10），有弩炮×2（需1AP操作，3d8伤害，4格范围）
  - 中间：敌舰A（5×10），有桅杆（可攀爬，顶部射程+1但无掩体）
  - 右侧：敌舰B（5×10）
  - 战舰之间：2格"海面"（落入后每回合消耗2AP游泳，否则溺水受2d6伤害）
- 敌人：
  - `mist_harrier` ×4：飞行单位，可悬停于海面之上，优先攻击弩炮操作员
  - `wolf_vanguard` ×6：登船肉搏型，会从敌舰索荡至己舰（消耗1AP，落地后眩晕1回合）
- **海战特殊机制**：
  - 每3回合，三艘战舰相对位置移动1格，改变可通行路径
  - "船体破损"：敌方弩炮命中船体时，随机1格变为"破损"（该格及相邻格进入后需敏捷豁免DC12，失败滑落海中）
  - 风向：每回合随机改变，顺风移动-1AP，逆风+1AP
- 阶段：
  - 阶段1：清理敌方飞行单位（保护己方弩炮）
  - 阶段2：跳帮敌舰A（需要至少1名角色移动到敌舰上，触发阶段转换）
  - 阶段3：敌舰B的指挥官出现——`wolf_alpha` ×1（私掠舰队司令的坐骑/宠物），击败后任务完成

**联邦路线 — Q106 刺杀行动（潜入斩首）**：

**目标结构**：
1. `submit_item(sealed_dispatch, 1)` — 偷取舰队部署图
2. `defeat_enemy(mist_weaver, 1)` — 击败私掠舰队指挥官（可选）
3. `settlement_action(service_contract_board, 1)` — 撤离报告

**战棋设计**：
- 场地：单层敌舰旗舰（12×8），分为甲板区、船舱区、指挥舱
- **潜入机制**：
  - 敌人初始为"未警觉"状态，有固定巡逻路线（每回合移动2-4格，视野为3格锥形）
  - 玩家移动力+1（轻装），但穿戴重甲时移动力-1且潜行检定不利
  - "暗杀"：从背后（敌人视野盲区）接近可用1AP使单个敌人"昏迷"3回合（不触发警报，不获得击杀进度）
  - "攀爬船舷"：从外部攀爬进入船舱，避开甲板巡逻，但消耗3AP且需要敏捷检定DC13
- 敌人配置：
  - 甲板巡逻：`wolf_vanguard` ×4
  - 船舱守卫：`wolf_raider` ×2
  - 指挥舱：`mist_weaver` ×1（指挥官，有警戒结界，不可暗杀）+ `wolf_alpha` ×1（守卫）
- **警报机制**：
  - 若被敌人发现，触发警报，3回合内增援`wolf_vanguard` ×4从其他船只赶来
  - 若暗杀时敌人HP>50%，有50%概率挣扎并发出警报
- 收集目标：部署图在指挥舱的航海桌上，`submit_item` 需1AP且会触发指挥官察觉检定（若指挥官未昏迷）
- **可选Boss战**：若选择击杀指挥官，`mist_weaver` 会使用"预见"能力——每回合显示玩家下回合最可能使用的技能类型，并提前获得对应抗性。弱点：每3回合有1回合"计算过载"（无法预见，所有抗性归零）

**战争进度影响**：
- 帝国路线成功：帝国+10，联邦-5
- 联邦路线成功：联邦+10，帝国-5
- 失败：敌方+5

### 轮三：要塞之围

**任务**：Q105 冰霜要塞

**战场态势**：帝国北境要塞"冰崖"遭联邦主力围攻。要塞若失守，帝国北方门户大开。

**根据当前进度线，任务难度变化**：
- **帝国优势线**：联邦围攻兵力较弱（8波次→6波次），有帝国援军
- **拉锯线**：标准难度（8波次）
- **联邦优势线**：联邦有重型攻城武器，波次增加到10波次

**目标结构**：
1. `defeat_enemy(wolf_raider, N)` — 抵御多波次进攻（波次数量根据进度线变化）
2. `settlement_action(service_contract_board, 1)` — 报告要塞状态

**战棋设计**：
- 场地：14×10 要塞防御网格
  - 北侧：城墙（占据4格，AC20，50HP，友方在城墙后相邻格获得+4AC），城墙上有"城垛"（站立后射程+2，但暴露时无AC加成）
  - 中央：内院（6×6开阔地）
  - 南侧：城门（占据2格，30HP，AC15，破坏后敌人可进入内院）
  - 东南/西南：侧塔（各1格，有投石机，需2AP操作，8格范围，4d10伤害，冷却4回合）
- 友方NPC：
  - 要塞守军×6（前排步兵，HP12，AC14，会主动守在城门口）
  - 冰霜法师×2（后排，每3回合释放"冰锥术"——3格直线，2d8冷冻+移动力-1持续2回合）
- **敌人波次**（标准难度8波）：
  - 波次1-2：`wolf_raider` ×3/波（弓箭手，攻击城墙上的玩家）
  - 波次3-4：`wolf_vanguard` ×4/波（攻城型，优先攻击城门）
  - 波次5-6：`wolf_raider` ×2 + `wolf_vanguard` ×3（混合）
  - 波次7：`mist_beast` ×1 + `wolf_vanguard` ×4（精英波，mist_beast会撞击城墙）
  - 波次8：`wolf_alpha` ×1（联邦先锋将军的坐骑）+ `wolf_shaman` ×1（联邦随军萨满，会治疗敌方单位）
- **联邦优势线额外波次**：
  - 波次9：`mist_harrier` ×3（空中轰炸城墙）
  - 波次10：`mage_controller` ×1（联邦元素法师，每2回合轰击城墙1格，3d10力场伤害）
- **帝国优势线援军**：
  - 波次4时，帝国援军`wolf_vanguard` ×4从南方赶来，攻击敌方侧翼
  - 玩家可控制援军行动
- **冰霜要塞特殊机制**：
  - "护城河"：城墙外1格为护城河（冰冻状态），敌方进入后移动力-2，每回合有50%概率滑倒（失去本回合剩余AP）
  - "冰霜符文"：内院四角有符文柱，激活后（1AP）释放"冰霜新星"（3格范围，2d6冷冻+移动力归零1回合），每柱只能用1次
  - "士气"：每阵亡1名友方守军，剩余守军命中率-1（可叠加，最高-3）

**失败条件**：城门被破坏 + 内院被敌人占领（敌人在内院停留3回合）

**战争进度影响**：
- 成功防守：帝国+15（或联邦+15，若玩家选联邦路线）
- 失败：敌方+20

### 轮四：谍影重重

**任务**：Q103 谍影重重 + Q108 叛国者

**战场态势**：双方间谍战白热化。帝国发现军事机密泄露，联邦发现有人向帝国出售情报。但真相更复杂——第三方（灰烬交界势力）在操纵双方。

**Q103 谍影重重**：

**目标结构**：
1. `defeat_enemy(wolf_raider, 2)` — 潜入途中清理外围警卫
2. `submit_item(bandit_insignia, 1)` — 取得密函
3. `defeat_enemy(mist_weaver, 1)` — 遭遇敌方反间谍（可选战斗）
4. `settlement_action(service_contract_board, 1)` — 报告

**战棋设计**：
- 场地：双层建筑（上层8×8居住区，下层6×6密道区）
- 阶段1（外围）：2名 `wolf_raider` 在入口巡逻，暗杀或正面解决
- 阶段2（潜入/搜集）：
  - 上层有6个可搜查点（书架、床铺、地板暗格等），只有1个点有密函
  - 每次搜查消耗1AP，有30%概率触发陷阱（毒针，体质豁免DC14，失败中毒-2力量持续3回合）
  - 密函在"地板暗格"中，需要感知检定DC15发现，或 brute force 破坏地板（1AP，但发出噪音，下回合刷新2名守卫）
- 阶段3（遭遇反间谍）：
  - 取得密函后，敌方反间谍 `mist_weaver` ×1 出现（从镜中走出——这是联邦的"镜卫"特种部队）
  - 镜卫特性：会复制玩家的上一个技能（但伤害-30%），每3回合切换复制目标
  - 镜卫不会杀死玩家——目的是夺回密函并抹除记忆。若玩家HP降至10%以下，镜卫自动消失，但密函被夺回（任务失败）
  - 玩家可选择战斗击败镜卫，或逃跑（到达出口即成功）
- 隐藏发现：密函内容不是军事部署，是"裂隙坐标"——指向灰烬交界的一个特定位置。

**Q108 叛国者**：

**目标结构**：
1. `defeat_enemy(wolf_vanguard, 4)` — 突入叛国者庄园
2. `submit_item(calamity_shard, 1)` — 取得叛国证据
3. `settlement_action(service_contract_board, 1)` — 选择如何处理叛国者

**战棋设计**：
- 场地：10×10 贵族庄园，有花园（掩体+1AC）、主楼（双层，有楼梯连接）、地下室（入口隐藏）
- 敌人：`wolf_vanguard` ×4（叛国者私人卫队，装备精良，AC+2）
- **叛国者本人**：不是战斗单位——是 `settlement_action` 交互对象
  - 击败卫队后，叛国者（第三公爵）坐在书房里，不会反抗
  - 玩家通过 settlement_action 选择：
    - **A. 逮捕**：带回帝国受审。后续：公爵在狱中"自杀"（被灭口），玩家获得帝国信任但发现真相被掩盖
    - **B. 处决**：当场击杀。后续：公爵的家族开始追杀玩家
    - **C. 听他说**：公爵透露真相——他不是通敌，是在和灰烬交界的"余火守望者"交易。筹码是三千活人，换一块界火碎片。界火碎片可以让凡人获得龙一样的寿命。公爵想救自己得了绝症的女儿。
- 若选择C，任务变为新路线：
  - `submit_item(moonfern_sample, 3)` — 寻找治愈公爵女儿的方法（替代界火碎片）
  - 完成后公爵成为内应，后续帝国/联邦任务获得情报优势

**战争进度影响**：
- 成功揭露间谍：进度优势方+5
- 发现叛国者真相（路线C）：开启"第三方"隐藏线，战争进度冻结2轮

### 轮五：焦土千里

**任务**：Q109 焦土政策 + Q112 逃兵营

**战场态势**：帝国在劣势下下令焦土撤退，联邦推进。战争进入最残酷阶段。

**Q109 焦土政策**：

**目标结构**：
1. `defeat_enemy(wolf_vanguard, 3)` — 护送/监督焦土执行队
2. `settlement_action(service_contract_board, 1)` — 面对村庄抉择

**战棋设计**：
- 场地：12×8 乡村网格，有3个村庄建筑（农舍、磨坊、粮仓），每个建筑可"焚烧"（1AP，点燃后3回合内烧毁，产生2格烟雾区）
- 友方：帝国焦土队`wolf_vanguard` ×3（会主动焚烧建筑）
- 敌方：联邦先遣`wolf_raider` ×4（从东侧出现，试图阻止焦土）
- **核心抉择**：
  - 村庄中央有村民NPC×5（平民，无战斗能力，移动力2格/回合）
  - 帝国命令：焚烧一切，不留物资给敌人
  - 村民请求：给他们时间撤离，带走粮食和牲畜
  - 联邦先遣队目标：不是救村民，是夺取粮仓里的粮食
  - **玩家的选择通过 settlement_action 实现**：
    - **A. 严格执行焦土**：焚烧所有建筑，村民被迫逃离（可能有伤亡）。战争进度：帝国+10（削弱联邦补给）。后续：联邦任务难度+20%（敌人补给不足）
    - **B. 拖延执行**：保护村民撤离，假装执行焦土。战争进度：不变。后续：村民提供隐藏补给点信息，解锁隐藏商人
    - **C. 违抗命令**：保护村庄，击退焦土队和联邦先遣队。战争进度：帝国-10，联邦-5。后续：被帝国通缉，但获得"守护者"称号（魅力+2）

**Q112 逃兵营**：

**目标结构**：
1. `defeat_enemy(wolf_vanguard, 2)` 或 `settlement_action(negotiate)` — 面对逃兵营
2. `settlement_action(service_contract_board, 1)` — 报告

**战棋设计**：
- 场地：10×10 森林营地，逃兵们建立了简陋的防御工事（木栅栏，AC10，10HP）
- 逃兵：`wolf_vanguard` ×2（他们是老兵，有丰富战斗经验，但拒绝再杀）+ 平民NPC×8（无战斗能力）
- 帝国命令："处理"逃兵（意思是消灭）
- 联邦态度：想招募逃兵
- **玩家选择**：
  - **A. 执行命令**：战斗击败2名老兵，平民四散。战争进度：帝国+5。后续： morale 下降，帝国任务中友方NPC更弱
  - **B. 保护逃兵**：击退帝国和联邦的"处理队"。战争进度：帝国-5，联邦-5。后续：逃兵营成为第三方据点，提供中立任务
  - **C. 说服回归**：通过 settlement_action 谈判（需魅力检定DC16），让老兵重新加入帝国/联邦。战争进度：对应阵营+10。后续：老兵成为精英单位，在后续战役中出现助战

### 轮六：炼金狂潮

**任务**：Q107 炼金武器 + Q114 武器走私

**战场态势**：双方都在研发/购买"裂隙武器"——用灰烬交界能量驱动的战争兵器。这些武器不稳定，但威力巨大。

**Q107 炼金武器**：

**目标结构**：

  - **问：如何结束战争？** → "有三种方法：一，杀死我——不是杀这具身体，是摧毁记忆之棺。二，让我赢——统一大陆后，战争就没有对手了。三，取代我——你成为新的永恒者，用新的记忆覆盖旧的。"

  - **C. 暗杀皇帝**：摧毁记忆之棺。后续：皇帝真正死亡，帝国崩溃，联邦也元气大伤，大陆进入"无政府线"
  - **D. 成为新的永恒者**（隐藏选项，需满足条件：完成所有前九轮帝国路线任务 + 拥有`calamity_shard`×5）：玩家继承皇帝的记忆和头衔。后续：游戏进入"永恒者线"——玩家成为最终Boss，其他所有任务变为"反抗军"视角
  - **E. 找到第四种方法**（隐藏选项，需完成"第三方外交线"）：与灰烬交界合作，用界火能量重塑皇帝的记忆——不是继承旧记忆，是创造新记忆。后续："新帝国"线，皇帝存活但变成了另一个人，战争以和平协议结束
