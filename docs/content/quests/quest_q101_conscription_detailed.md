# Q101 种族抉择令 —— 详细设计文档

> 十轮战役·第一轮：种族战争的开端
>
> 设计理念：灰炉镇曾经是人类与矮人、精灵共同采矿的混居地。现在，**霜烬帝国**（人类至上的外来侵略者）称这里为"收复失地"，**星陨联邦**（多元种族抵抗组织）称这里为"最后的避难所"。而炉，还是那口炉。只是烧炉的人，已经换了。
>
> **关键前提**：玩家出生在**多元种族共存的正常人类帝国**，不是霜烬帝国。玩家以**旅行者**身份来到被占领的灰炉镇。所有种族均可选择任何路线，但**叙事含义完全不同**。

---

## 零、世界观前提（种族战争叙事基础）

### 0.1 大陆帝国格局

- **人类不是统一的**。大陆上有**多个人类帝国**，意识形态各不相同：
  - **霜烬帝国**（Frostburn Empire）：人类至上、种族隔离、净化非人类。灰炉镇的占领者。
  - ** player's home empire **（玩家出生帝国）：多元种族共存的正常人类帝国。精灵、矮人、兽人、龙裔等在该帝国内拥有完整公民权。
  - **其他人类帝国**：沿海贸易联邦、北方军事同盟等，各自有不同的种族政策。

- **兽人帝国**：**血喉帝国**（Gor'Khar Empire），位于西方草原。不是联邦成员，也不是帝国盟友，是独立的第三方势力。
  - **战争派（血喉正统）**：占70%，主张征服人类，大酋长格罗姆·血喉每年发动边境劫掠。这是霜烬帝国"净化"政策的**现实借口**——帝国 propaganda 说"兽人每三年劫掠一次，我们必须建立高墙"。
  - **和平派（静语氏族）**：占30%，主张贸易共存，女酋长萨娜·静语被驱逐到帝国边缘的干旱草原， secretly 向联邦和玩家祖国出口马匹。

- **玩家身份**：玩家出生在**多元种族的人类帝国**，不是霜烬帝国。玩家是以**旅行者/冒险者**身份来到灰炉镇，不是霜烬帝国的公民或士兵。

- **关键背景**：霜烬帝国的种族隔离政策，最初是**防御性**的——为了应对战争派兽人的持续劫掠。后来才演变为**意识形态性的"净化"**。这意味着帝国的"人类至上"不是凭空产生的，是有历史根源的。但这**不意味着它是正确的**——和平派兽人同样被帝国迫害，而帝国的"解决方案"（净化所有非人类）远远超出了"防御"的范畴。

### 0.2 为什么这解决了种族兼容性问题

| 玩家种族 | 在玩家祖国的地位 | 在灰炉镇（霜烬占领区）的处境 | 路线选择 |
|---------|----------------|---------------------------|---------|
| 人类 | 正常公民 | 被霜烬帝国视为"可招募的同胞" | 三条路线全开放 |
| 精灵 | 正常公民 | 被霜烬帝国视为"需要驱逐的异种"，但玩家是**外来旅行者**，不是占领区居民 | 三条路线全开放（帝国路线 = 背叛自己的价值观） |
| 矮人 | 正常公民 | 同上 | 三条路线全开放 |
| 龙裔 | 正常公民 | 同上 | 三条路线全开放 |
| 半精灵 | 正常公民 | 被霜烬帝国视为"污染"，但玩家是**外来者** | 三条路线全开放（帝国路线 = 承认自己是"污染"） |
| 半兽人 | 正常公民 | 同上 | 三条路线全开放 |

- **核心区别**：霜烬帝国对**占领区居民**执行净化政策，但对**外来旅行者**采取"招募优先"策略——他们想要的是**战斗力**，不是**血统 purity**。
  - 人类玩家："你的帝国太软弱。加入我们，建立真正的秩序。"
  - 非人类玩家："你的帝国欺骗了你。他们让你以为你是平等的。来我这里，我让你看到真相——然后选择站哪边。"
  - 混血玩家："你的存在本身就是混乱。但混乱也可以被利用。"

### 0.3 叙事效果

- **所有种族都可以选择任何路线**，但**叙事含义完全不同**：
  - 人类选帝国 = "认同更极端的版本"
  - 非人类选帝国 = "背叛自己的种族/价值观"（或"务实选择"、或"被欺骗"）
  - 人类选联邦 = "人道主义"
  - 非人类选联邦 = "自保+正义"
  - 任何种族选自由佣兵 = "我只看钱"

- **道德复杂度**：非人类玩家选择帝国路线时，会面临更残酷的道德考验。索伦不会直接说"加入我们"，他会说"证明你比你的种族更有价值"。

## 一、场景设定

### 1.1 地点A：灰炉镇（Grayforge）——帝国占领区

- **位置**：大陆中部矿脉区，曾是人类、矮人、精灵共同开采的混居矿镇。三个月前被帝国"净化军团"占领，现在是非人类禁区。
- **地貌**：广场中央有一口废弃的熔铁炉，炉壁上刻着三种文字——人类的通用语、矮人的符文语、精灵的叶脉文。矮人符文被凿掉了大半，精灵叶脉文被白漆涂掉了大半，只剩下人类的通用语还清晰。
- **天气**：清晨，薄雾从北方漫过来，带着帝国的消毒水味。南方没有暖风，只有寂静。
- **声音**：远处有狼嚎，近处有帝国巡逻队的皮靴声。铁匠铺的招牌只剩下一半——矮人符文的部分被斧子劈掉了。
- **气味**：铁锈、灰烬、消毒水。

**无法忽视的事实**：
- 广场边缘的民居门窗紧闭，门上画着白色手掌（帝国占领标记）。偶尔有窗帘动一下，但很快又静下来。
- 酒馆门口贴着告示："本店仅接待纯血人类。混血请向东街报到。异种禁止入内。"
- 东街是隔离区，被木栅栏围起来，里面住着被帝国驱逐但未离开的混血和非人类。栅栏外有帝国士兵巡逻。
- 铁匠铺的招牌只剩下一半，矮人符文被斧子劈掉了。铁匠是个纯血人类，但他不会修矮人的熔炉，所以炉是冷的。
- 广场中央，8名帝国士兵站成两排，中央是征兵官索伦·铁誓。他们在征兵，不是在对峙——因为这里没有人可以对峙。

### 1.2 地点B：灰炉镇外·废弃矿洞（Old Mine 7）——联邦秘密联络点

- **位置**：灰炉镇东南方向约半里，曾经的矮人矿脉第7号井。矿洞入口被碎石和杂草半掩，从镇上看不到。
- **地貌**：矿洞内部有矮人开凿的阶梯和支架，墙壁上有矮人符文和精灵照明的苔藓。深处有一个地下湖，湖水冰冷。
- **进入方式**：
  - 方式1：与老马库斯对话后，他会暗示"镇外的矿洞还有人挖矿"。
  - 方式2：玩家在世界地图上移动时，概率遭遇"联邦逃兵"（一名受伤的矮人工程师），他会带路。
  - 方式3：玩家自行探索，发现矿洞入口有新鲜的脚印。
- **内部状态**：
  - 联邦成员5人：精灵弓箭手（放哨）、兽人战士（守卫入口）、矮人工程师（修陷阱）、龙裔法师（照明）、半身人盗贼（探路）。
  - **兽人战士身份**：他叫「克鲁格·断角」（Krug Brokenhorn），静语氏族（兽人帝国和平派）出身。他的角不是自己磨平的——是被战争派刺客砍断的。他逃到联邦，因为"在静语草原，我被人类商人欺负；在血喉城，我被格罗姆的人追杀。只有在联邦，我可以既不是叛徒，也不是敌人。"
  - 中央是艾莉亚·星风，她在整理地图和名单。
  - 洞壁上挂着七色布条，每色代表一个种族。
  - 地上有伤员用的草席和草药。

**无法忽视的事实**：
- 矿洞入口有矮人设的陷阱，非联邦成员进入会触发（除非有矮人带路或老马库斯的提示）。
- 帝国巡逻队每2小时经过矿洞上方的地面一次。洞内的人必须保持安静。
- 艾莉亚的左耳银铃被布包住了——因为铃声会传到地面。

### 1.3 场景状态总览

```
[世界地图]
    │
    ▼
[灰炉镇] ——帝国占领—— 索伦·铁誓在广场征兵
    │
    │ 老马库斯的暗示 / 逃兵带路 / 自行探索
    │
    ▼
[废弃矿洞] ——联邦秘密据点—— 艾莉亚·星风在洞内招募
```

**关键设计**：玩家不会在同一个地点看到双方。接触联邦需要主动离开帝国控制的城镇，进入野外。这种空间隔离本身就是种族战争的体现——双方不敢在对方控制区公开活动。

## 二、NPC角色档案

### 2.1 索伦·铁誓（Soren Ironsworn）— 帝国净化军团征兵官

| 属性 | 描述 |
|------|------|
| 种族 | 纯血人类（他自称"净化者"，不承认混血） |
| 年龄 | 47岁 |
| 外貌 | 左脸从眉骨到下颌有一条霜冻伤疤，像是被某种冰魔法划过。右眼琥珀色，左眼混浊灰白（瞎了）。铠甲上画着白色手掌印记，手掌向下。 |
| 穿着 | 帝国净化军团板甲，甲面上刻着名字——不是他带过的士兵，而是他"净化"过的非人类的名字。 |
| 声音 | 低，慢，每个词之间有明显的停顿，像是在给每个词称重。 |
| 立场 | 他不恨其他种族。他认为他们在"生物学上劣等"。这不是仇恨，是"事实"。 |
| 秘密 | 二十年前，他曾与一名兽人战士并肩作战，对抗迷雾兽潮。那名兽人为了救他，被迷雾吞噬。战后，帝国命令他"净化"那个兽人的村庄。他照做了。那道伤疤就是兽人战士临死前抓的。**那名兽人战士名叫「铁爪·老静语」（Ironclaw Oldwhisper），是静语氏族的一员——兽人帝国和平派女酋长萨娜的叔叔，战争派大酋长格罗姆的挚友。格罗姆之所以下令"净化"他，不是因为他是人类的朋友，而是因为他是「与人类停战」的倡导者。在格罗姆眼中，这是背叛。** |

**对话特征**：
- 不说"你"，说"这个人"
- 不说"非人类"，说"异种"或"劣等种"
- 每次提到"混血"时，会微微侧头，像是在闻到某种气味
- 会主动说出帝国的残酷："我们会驱逐他们。会烧毁他们的村庄。会杀死他们的孩子。但我们会建立秩序。"
- 他的甲面上有一个名字比其他名字刻得更深——那是一个兽人名字。

### 2.2 艾莉亚·星风（Aria Starwind）— 联邦各族盟约信使

| 属性 | 描述 |
|------|------|
| 种族 | 半精灵（母亲精灵，父亲人类） |
| 年龄 | 24岁 |
| 外貌 | 短发，左耳尖长（精灵耳），右耳圆短（人类耳）。左耳戴着一串七颗小银铃，走路时会响。手腕上有墨水痕迹。右脸颊有一道淡色的烧伤疤痕——帝国"净化"留下的。 |
| 穿着 | 联邦游侠轻装皮甲，甲上别着各种纸片。披风是七色的，每色代表一个种族。 |
| 声音 | 快，轻，但说到某些词时会突然变重。 |
| 立场 | 她相信共存不是因为道德，而是因为必要——单独的种族都无法对抗帝国，也无法对抗迷雾。 |
| 秘密 | 她的父亲是人类，十二年前在帝国的"净化"中被杀。母亲带她逃到了精灵森林。她的七颗银铃中，有一颗是父亲的怀表熔的，有一颗是母亲的箭簇熔的。 |

**对话特征**：
- 会反问玩家"你是哪一边的？"然后不等回答就说"没关系，两边都不对"
- 会说"你觉得呢？"作为每段话的结尾
- 提到"帝国"时用"北边"代替，提到"净化"时用"那个词"代替
- 会主动说出联邦的弱点："我们不会强迫你。不会命令你。不会保护你。这意味着你要和兽人吵架，和矮人争矿，和精灵学礼仪。"
- 她的烧伤疤痕会在提到"净化"时微微发红。

### 2.3 老马库斯（Old Marcus）— 酒馆老板

| 属性 | 描述 |
|------|------|
| 种族 | 矮人与人类的混血（身高介于两者之间，坐在台阶上脚够不着地） |
| 年龄 | 说不清，可能80，可能100（矮人血统让他活得更久） |
| 外貌 | 只剩一只眼睛，另一只的位置是一个光滑的疤痕。手指缺了两根（矿难）。胡子是棕红色的，但有一半已经白了。 |
| 穿着 | 一件穿了三十年、补丁比原布还多的围裙，上面有三种图案——人类的十字架、矮人的锤子、精灵的树叶。 |
| 立场 | 他不站任何一边，因为他两边都不是。 |
| 作用 | 提供第三条路的信息，以及灰炉镇的真实历史 |

### 2.4 灰袍刻字者（The Graver）— 隐藏NPC

- 种族：混血（尖耳朵+圆耳朵，但没有哪一边完全像）
- 只在玩家拒绝双方阵营后出现
- 不回头，不报名字
- 在墙上刻的字是："两边都想要我。两边都不想要我。"
- 如果玩家问他"你是谁"，他会说："我是一个没有选择种族的人。这个选择也有代价。你想知道吗？"

## 三、完整对话脚本

### 3.0 进入灰炉镇时的环境描述

```
【灰炉镇入口 · 清晨 · 玩家作为外来旅行者】

你沿着商道走来时，就注意到了变化。

三个月前离开这里时，镇口的木牌上还有三种文字——人类的通用语、矮人的符文语、精灵的叶脉文。
现在，矮人符文被斧子劈掉了，精灵文字被白漆涂掉了。
只剩人类的通用语，而且内容变了：
"灰炉镇——霜烬帝国领土。纯血人类居所。非人类请绕行。"

镇门口的帝国士兵拦住了你。
他先看你的装备——旅行者的斗篷，磨损的皮甲，不是本地居民。
然后他才问："种族？"
（你回答）

【如果玩家是人类】
士兵的眼神变了。不是敌意，是评估。
"旅行者？"他问，"从哪里来？"
（你回答你的祖国——那个多元种族的人类帝国）
士兵点头："软弱的帝国。但你是人类。"
他侧身让开："进去吧。广场上有征兵官。霜烬帝国欢迎所有认同秩序的人类。"

【如果玩家是非人类（精灵/矮人/龙裔等）】
士兵的手按在了剑柄上。但只是按住了，没有拔出来。
"旅行者？"他问，声音冷了，"非人类。来灰炉镇做什么？"
（你回答）
士兵打量你，目光在你脸上停留了太久——他在评估威胁。
"你的帝国。"他说，"让你以为。你可以。到处走。"
他冷笑，但没有拔剑："霜烬帝国。不一样。"
他侧身让开，但动作很慢："进去吧。征兵官。想见你。"

【如果玩家是混血（半精灵/半兽人等）】
士兵的手按在剑柄上。这次握紧了。
"混血。"他说，像是在确认一个诊断。
他盯着你的耳朵、你的眼睛、你的下巴——在找比例。
"你的帝国。"他说，"让你活着。是仁慈。还是。软弱？"
他没有等你回答："进去吧。征兵官。对混血。有兴趣。"

你走进镇子。街道空荡荡的，门窗紧闭。
偶尔有窗帘动一下，但很快又静下来。
东街有木栅栏，围着一个隔离区。栅栏外有士兵巡逻。
栅栏里有几个人影——一个矮人、一个半精灵、一个侏儒。
他们看着你，但不说话。因为栅栏外的士兵也在看着你。

【如果玩家是非人类或混血】
隔离区里的半精灵看着你，眼神复杂。
不是求助。是审视。
他在判断：你是囚犯，还是帮凶？

你走到广场。

广场中央有一口废弃的熔铁炉，炉壁上三种文字只剩一种还清晰。
8名帝国士兵站成两排，铠甲上的白色手掌在晨光中刺眼。
中央站着一个高个子男人，左脸有一道从眉骨到下颌的伤疤。
那只琥珀色的右眼。那只混浊的灰白色左眼。
他看着你。不是看本地居民。是看一个需要被说服的人。

广场西侧，酒馆门口贴着告示：
"本店仅接待纯血人类。混血请向东街报到。异种禁止入内。"
台阶上坐着一个人，脚够不着地，悬在半空晃着。
他看着你，独眼在晨光中反光。
"新来的？"他说，"别站着。进来。"

东街隔离区，木栅栏围着的角落。
一个穿灰袍的人背对栅栏站着，面对墙壁，在刻着什么。
帝国士兵没有管他——也许是因为他的灰袍让人看不清他是哪边，也许是因为他太安静了。
隔离区里的其他人——矮人、半精灵、侏儒——都看着他，但不敢靠近。
你走近看，是两行字：
"两边都想要我。"
"两边都不想要我。"

你注意到他的耳朵——一只尖的，一只圆的。
```

### 3.1 接近帝国征兵官索伦·铁誓

#### 【第一次交互】

## 五、战棋设计 —— 十轮战役完整战场框架

### 5.0 设计总则

**地图尺寸**：所有战斗地图最小 **40×30**，大规模会战使用 **50×40** 或 **60×40**。不再使用 20×12 的小规模冲突地图——Q101 是种族战争的开端，从第一场战斗起就要展现战争场面。

**战争场面体现**：
- 每方兵力从 Q102 的 10-16 单位递增至 Q110 的 50-80 单位
- 引入"援军波次"机制：战斗中途从地图边缘涌入新单位
- 引入"士气崩溃"机制：损失超过 50% 时敌方可能溃散或死战
- 引入"环境破坏"：建筑可焚毁、桥梁可炸断、城墙可坍塌

**操控单位限制**：玩家直接操控的单位上限为 **4 人**（玩家自身 + 最多 3 名友军）。其余友方单位为 **AI 控制的友军团**，玩家可通过消耗 1 个标准动作下达军团命令（进攻/防守/撤退/集火目标/呼叫炮击），但无法直接操控其具体移动和攻击。大地图的战争场面由AI友军团与敌方军团的对冲来呈现，玩家小队负责执行关键战术目标。

**每轮特色原则**：每一场战斗必须有独特的地形机制或胜利条件，禁止重复"全灭敌方即胜利"。

**敌方成长原则**：敌方从 Q102 的民兵/巡逻队级别成长至 Q110 的精英军团，具体体现为：
- 单位数量增加
- 出现新的兵种（从基础步兵到施法者、攻城器械、英雄单位）
- AI 行为更复杂（从简单冲锋到包抄、诱敌、坚守待援）
- 装备和属性提升

### 5.2 帝国路线战斗序列

#### 5.2.1 Q102 · 边境净化 —— "裂谷净化战"

**地图**：40×30 裂谷战场
- 地形：中央是一条 6 格宽、20 格长的裂谷"净化带"，谷底有圣光岩浆（每回合对非人类造成 2d6 伤害）
- 两侧高地：东、西各有一条 8 格宽的高地，高地有矮人废弃弩炮阵地
- 北部：联邦边境哨站（木制堡垒，3层围墙）
- 南部：帝国前锋营地（帐篷、拒马、圣光祭坛）

**友方（玩家操控，最多4人）**：玩家 + 帝国先锋骑士×1（高机动/冲锋）+ 帝国牧师×1（治疗/可激活祭坛）+ 帝国工兵×1（占领弩炮/布置陷阱）
**友方（AI军团，不可操控）**：帝国步兵×8 + 帝国弓手×4（由帝国前锋营地发起正面推进，玩家每回合可用 1 个标准动作下达军团命令：【冲锋】【坚守】【撤退】【集火目标】）
**敌方（联邦残部）**：兽人战士×4 + 精灵弓箭手×4 + 矮人工程师×2 + 人类逃兵×3 + 联邦医疗兵×2

**特色机制**：
1. **操控限制**：玩家小队 4 人负责突破敌方防线、占领弩炮阵地、激活祭坛。AI 军团负责正面牵制。
2. **圣光祭坛**：地图南部有 3 座祭坛，玩家操控的牧师可在祭坛施法使"净化带"范围扩大 2 格，持续 2 回合
3. **弩炮阵地**：高地弩炮可被玩家工兵占领，每 2 回合发射一次，8 格直线穿透，4d10 伤害。若被敌方矮人工程师占领，则转向攻击 AI 友军团
4. **军团命令**：消耗 1 个标准动作，AI 军团执行命令 1 回合。例如【冲锋】时 AI 步兵移动力+2；【坚守】时 AI 弓手射程+2；【集火】时所有 AI 单位优先攻击指定目标
5. **士气崩溃**：联邦单位损失 60% 后，人类逃兵会投降（变为中立），兽人会死战（攻击+3）

1. **操控限制**：玩家直接控制 1 艘快船 + 3 个关键单位（其中 1 艘运输船必须保护）。AI 护卫舰自动护航，玩家可命令【分散拦截】【集中护卫】【撞击火船】。
2. **护送目标**：玩家操控的矮人运输船和 1 艘 AI 运输船必须到达北部逃脱点。若玩家运输船沉没，任务直接失败。
3. **迷雾召唤**：玩家操控的精灵海歌者可召唤大范围迷雾（持续 3 回合，敌方远程命中-5，但己方也受影响）
4. **接舷反制**：联邦护卫舰（AI 操控）装载"反接舷 nets"，接舷时敌方先手优势取消。玩家快船也可主动接舷牵制敌舰
5. **海妖对抗**：帝国海妖驯养师召唤海妖时，玩家操控的龙裔飞行单位可从空中攻击驯养师（海妖会随之消散）
6. **军团命令**：消耗 1 个标准动作，命令 AI 护卫舰【拦截指定敌舰】【保护运输船】【撞击火船】
7. **胜利条件**：至少 1 艘运输船逃脱 且 物资保留 2 批以上；完美胜利：2 艘运输船全逃 + 玩家击沉 2 艘帝国战舰

**敌方强度**：Q104 中级。帝国 AI 会优先攻击运输船而非护卫舰。

#### 5.3.4 Q105 · 空艇拦截 —— "风暴云巅遭遇战"

**地图**：40×30 高空战场（3层立体：低空/中空/高空，每层40×30）
- 地形：云层（提供掩护，但随机雷电每回合对云层中单位造成 1d8 伤害）、空艇残骸（可临时躲避）、气流通道（顺气流移动力+5）

**友方（玩家操控，最多4人）**：玩家（联邦改装空艇，载 2 名翼弓手 + 1 名矮人空降兵作为副地图单位）+ 联邦空艇×1（僚机，可切换操控或设为跟随）+ 龙裔喷火兵×1（跨层火焰攻击）+ 精灵翼弓手×1（精确狙击）
**友方（AI编队，不可操控）**：联邦空艇×1（自动巡航）+ 精灵翼弓手×3（自动射击）+ 矮人空降兵×3（自动索降敌艇）+ 龙裔喷火兵×1（自动掩护）
**敌方（帝国空袭编队）**：帝国轰炸飞艇×3 + 帝国狮鹫骑士×6 + 帝国空降突击队×8（乘飞艇，可索降至联邦空艇）+ **精英单位**：帝国天空领主（骑乘机械龙，范围火焰吐息）

**特色机制**：
1. **操控限制**：玩家直接控制 1 艘主空艇（含舰载人员）+ 3 个精英单位。AI 编队自动交战。玩家可切换操控僚机空艇（原主空艇变为 AI 控制）。
2. **立体战斗**：三层空间独立计算，玩家翼弓手和龙裔喷火兵可跨层攻击（射程-2）
3. **空降接舷**：玩家矮人空降兵可索降敌艇，触发甲板白刃战（副地图 4 人小队）；敌方突击队也会索降己方空艇，玩家必须回防
4. **空艇核心**：每艘空艇有"核心锅炉"（100 HP），破坏后空艇 3 回合后坠毁（艇上单位若未撤离则死亡）。玩家需保护己方空艇核心，或优先摧毁敌方轰炸飞艇核心
5. **军团命令**：消耗 1 个标准动作，命令 AI 编队【集中攻击指定敌艇】【索降指定目标】【掩护玩家空艇】【撤退至云层】
6. **风暴雷电**：每 2 回合随机劈下雷电（3 格范围，4d8 伤害，不分敌我）
7. **胜利条件**：玩家小队击落 2 艘帝国轰炸飞艇 或 击杀天空领主；失败条件：己方全部空艇坠毁

**敌方强度**：Q105 高级。首次出现立体战场和多层空间机制。

#### 5.3.5 Q106 · 潜入帝国 —— "霜烬城下水道渗透战"

**地图**：50×40 城市地下战场（双层：地面层 50×40 + 下水道层 50×40，通过 8 个井口连通）
- 地形：下水道（狭窄，2格宽通道，移动力-1，毒素水面每回合 1d6 毒伤）、地面层（帝国街区，巡逻队定时经过）、帝国监狱（中央，4层，关押着联邦战俘）

**友方（玩家操控，最多4人）**：玩家 + 半身人盗贼×1（开锁/隐身/破坏警报钟）+ 精灵法师×1（传送/幻术/群体隐身）+ 兽人狂战士×1（营救后参战/近战突破）
**友方（AI支援，不可操控）**：人类间谍×1（在地图边缘提供情报标记，显示巡逻队实时位置，玩家可命令【标记索伦位置】【干扰巡逻路线】）+ 营救后的联邦战俘（属性较低，自动跟随玩家，可命令【分散逃跑】【跟随玩家】【吸引火力】）
**敌方（帝国守军）**：帝国巡逻队×6（地面层定时巡逻）+ 帝国狱卒×4 + 帝国黑暗守卫×4（高感知，反隐身）+ 帝国警报钟×3（触发后 2 回合内援军从地图边缘涌入）+ **英雄单位**：索伦·铁誓（如果在 Q101 未击杀他，他会在此作为敌方英雄巡逻地面层）

**特色机制**：
1. **操控限制**：玩家 4 人小队负责潜入、开锁、营救、断后。AI 间谍提供情报支持，营救后的战俘可简单指挥。
2. **双层渗透**：玩家可在下水道潜行（躲避地面巡逻），但某些区域必须上到地面（监狱正门需从地面进入）
3. **巡逻路线**：帝国巡逻队按固定路线移动，AI 人类间谍自动标记巡逻队位置（每回合更新）。玩家也可亲自侦察
4. **警报系统**：3 个警报钟若被敲响，2 回合后帝国援军×12 从边缘涌入；玩家操控的半身人盗贼可提前破坏警报钟（需开锁检定，1 回合）
5. **战俘营救**：监狱内关押 8 名联邦战俘，玩家小队营救后变为 AI 友方单位（属性较低，自动跟随）。玩家可用标准动作命令战俘【分散逃跑】（向不同方向引开敌人）或【跟随玩家】或【吸引火力】
6. **索伦巡逻**：如果索伦在地面层，他的感知范围是 10 格（普通单位 5 格），被发现即触发全面警报。AI 间谍可每 3 回合标记索伦实时位置
7. **胜利条件**：玩家小队营救至少 5 名战俘并抵达地图边缘逃脱点；完美胜利：营救全部 8 名 + 不触发任何警报

**敌方强度**：Q106 大规模+潜入。40+ 单位（含援军）。AI 巡逻队有固定路线，但警报触发后会转为全面搜捕。

### 5.4 自由佣兵路线战斗序列

#### 5.4.1 Q102 · 第三方 —— "裂谷旁观战"

**地图**：40×30 裂谷战场（同帝国/联邦 Q102，但中央有"中立观察区"）

**友方（玩家操控，最多4人）**：玩家 + 自由佣兵×3（玩家可控制）
**敌方（帝国）**：帝国步兵×4 + 帝国弓手×2
**敌方（联邦）**：兽人战士×2 + 精灵弓箭手×2

**特色机制**：
1. **操控限制**：玩家直接控制 4 人佣兵小队，没有 AI 友军团——自由佣兵路线强调小规模精锐作战。
2. **三方混战**：帝国和联邦互相攻击，玩家可选择帮助任意一方、两边都打、或完全旁观
3. **观察区**：地图中央 8×8 区域为"中立观察区"，玩家在此区域内不会被任何一方主动攻击（但范围伤害仍会命中）
4. **拾荒机制**：战斗中每有 1 个单位死亡，玩家可在其尸体上拾取装备（随机获得消耗品或低级装备）
5. **声望浮动**：帮助帝国则联邦关系-20，帮助联邦则帝国关系-20，两边都打则两边各-10，旁观无变化
6. **胜利条件**：无固定胜利条件。战斗持续 8 回合后双方会自动撤退，玩家存活即可完成任务；或主动击杀全部单位（不推荐）

**敌方强度**：Q102 基础级。帝国和联邦 AI 互相优先攻击，玩家是第三方。

#### 5.4.2 Q103 · 情报贩子 —— "黑市码头混战"

**地图**：40×30 港口黑市区
- 地形：码头（货物堆提供掩护）、酒馆（2层，可进入）、水道（小船可快速移动）、货舱（密闭空间，近战优势）

**友方（自由佣兵）**：玩家 + 混血佣兵×3
**敌方（多方势力）**：帝国密探×3 + 联邦刺客×3 + 血喉兽人海盗×4 + 第三方竞争者×3（其他佣兵）

**特色机制**：
1. **四方混战**：四方势力互相敌对，玩家可利用任何一方的矛盾
2. **情报货物**：地图中央有一箱"情报货物"，任何一方将其带至自己的逃脱点即胜利；玩家也可以抢夺
3. **黑市规则**：在码头区域内不可使用范围法术（会伤及中立商人，导致黑市关闭）
4. **雇佣临时盟友**：玩家可花费 100G 临时雇佣 2 个中立佣兵（持续 3 回合）
5. **胜利条件**：将情报货物带至任意逃脱点 或 全灭其他三方；特殊胜利：将情报同时卖给两方（需混血玩家特有对话）

**敌方强度**：Q103 进阶级。四方 AI 各自为战，会争夺情报货物。

#### 5.4.3 Q104 · 海上孤狼 —— "破碎海峡独航"

**地图**：50×40 海洋战场

**友方（自由佣兵）**：玩家（单艘改装快船）+ 可雇佣水手×2（若有钱）
**敌方**：帝国巡逻艇×2 + 联邦侦察船×2 + 血喉海盗船×2 + 海怪×1（中立，攻击最近单位）

**特色机制**：
1. **孤狼作战**：玩家只有 1 艘船（+2 名水手），面对 6 艘敌船 + 1 只海怪
2. **挑拨离间**：玩家可攻击帝国船引发帝国-联邦交火，或攻击海盗船引发三方混战
3. **海怪利用**：海怪会攻击最近单位，玩家可引诱它撞向敌方大船
4. **改装系统**：玩家船只有 3 个改装槽（火炮/装甲/风帆/货舱），不同改装改变战术
5. **胜利条件**：存活 12 回合（海 storm 来临，所有敌船被迫撤退）或 击沉 3 艘敌船；特殊胜利：让海怪击沉 2 艘敌船

**敌方强度**：Q104 中级。以弱胜强设计。敌方 AI 有派系仇恨，会优先攻击敌对派系。

#### 5.4.4 Q105 · 混血者试炼 —— "灰烬平原三族围猎"

**地图**：60×40 草原战场（同帝国 Q105，但时间线是夜间）

**友方（自由佣兵）**：玩家 + 混血佣兵×2
**敌方（帝国狩猎队）**：帝国猎犬×4 + 帝国猎手×4 + 帝国法师×1（照明术）
**敌方（联邦巡逻队）**：精灵夜巡者×3 + 兽人追踪者×3
**敌方（血喉兽人）**：兽人狼骑兵×4（三方都不认，见人就打）

**特色机制**：
1. **夜间战场**：视野范围减半（5 格），照明弹可临时扩大视野至 10 格
2. **猎物身份**：玩家被三方同时视为"目标"——帝国要"净化混血"，联邦要"审查立场"，兽人要"抢劫"
3. **利用矛盾**：可引诱帝国猎犬追踪兽人狼骑兵，或让联邦夜巡者与帝国猎手交火
4. **逃亡路线**：地图边缘有 4 个逃脱点，分别通向不同后续（帝国/联邦/黑市/静语氏族）
5. **胜利条件**：抵达任意逃脱点并存活；特殊条件：混血玩家可利用【双重血脉】伪装成任意一方（每回合需重新判定）

**敌方强度**：Q105 高级。15+ 敌方单位追杀 3 个友方单位。AI 会追踪玩家足迹（每回合留下"足迹"标记，敌方可追踪）。

#### 5.4.5 Q106 · 灰色地带 —— "灰烬之城废墟商人"

**地图**：50×40 城市战场（帝国 Q106 攻城战后 3 天的同一座城市，80% 建筑已焚毁）

**友方（自由佣兵）**：玩家 + 混血医疗兵×1 + 人类拾荒者×1
**敌方（帝国残余）**：帝国散兵×3（失控，攻击一切）

**中立（难民）**：平民难民×15（需要护送/治疗/物资）

**特色机制**：
1. **非战斗任务**：此战以救援和物资运输为主，不是杀戮
2. **医疗资源有限**：混血医疗兵有 5 次治疗机会，需分配给 15 名难民

5. **拾荒与交易**：废墟中有隐藏物资箱，找到后可与难民交易（换取情报或黑市 access）
6. **胜利条件**：成功护送 10 名难民至安全屋 或 治疗 8 名以上难民；失败条件：难民死亡超过 5 名

**敌方强度**：Q106 特殊。敌方单位少（6 个），但任务目标是保护而非击杀。AI 散兵会随机攻击难民。

### 5.5 Q107-Q110 设计理念概述

#### 5.5.1 Q107 · 要塞攻坚战（帝国）/ 要塞保卫战（联邦）/ 要塞走私（自由）

**地图**：60×40 山地要塞
**规模**：40-50 单位
**特色**：垂直战场（山地 4 层高度差）、城门/吊桥/密道多重入口、投石机对轰
**敌方新单位**：帝国/联邦的禁卫军（重甲、不可击退）、战争巨兽（巨型单位，占 2×2 格）
**每轮特色**：帝国从正面强攻+密道潜入；联邦利用高度差以少胜多；自由佣兵通过走私密道偷运物资，不参与正面交战

#### 5.5.2 Q108 · 种族决战前哨 —— "古战场回响"

**地图**：50×40 古战场遗迹
**规模**：45-60 单位
**特色**：双方阵营领袖（索伦/艾莉亚）亲征，战场中央有古代神器可争夺；古代亡灵被战斗唤醒，不分敌我攻击
**敌方新单位**：双方传奇英雄（各 3 个被动技能）、古代亡灵（骷髅军团×20，从地下随机涌出）
**每轮特色**：此战引入"第四方"——古代亡灵。帝国和联邦必须同时面对彼此和亡灵，玩家可选择暂时合作或趁乱偷袭

#### 5.5.3 Q109 · 史诗会战 —— "迷雾平原最终对峙"

**地图**：60×40 平原 + 两侧森林 + 后方河流
**规模**：60-80 单位（三方混战版本可达 100+）
**特色**：三线作战（左翼/中军/右翼），玩家可自由调配兵力；援军波次 5 轮；战场天气系统（迷雾/暴雨/烈日轮流影响不同种族）
**敌方新单位**：战争泰坦（4×4 巨型单位，一击可摧毁建筑）、神话生物（龙/凤凰/元素巨人，作为精英单位登场）
**每轮特色**：此战是"战争沙盘"——玩家操控 4 人精英小队执行关键战术目标（斩首/夺旗/破坏），同时通过【战略层命令】每回合指挥 AI 军团的左翼/中军/右翼（进攻/防守/撤退）。大地图上的 80+ 单位会战由 AI 自动演算，玩家的战略命令会影响战局走向，但具体战斗由 AI 执行。

#### 5.5.4 Q110 · 最终决战 —— "界火之巅"

**地图**：50×40 多阶段战场（第一阶段：平原会战；第二阶段：传送至古代祭坛；第三阶段：神性对决）
**规模**：50-80 单位 + 最终 Boss
**特色**：
- 帝国路线：净化之光仪式——玩家协助/阻止召唤可覆盖整个大陆的圣光，Boss 为"净化化身"（巨大光元素）
- 联邦路线：七族共鸣仪式——七族代表同时在场激活古代防御，Boss 为"裂隙吞噬者"（从种族仇恨中诞生的怪物）
- 自由佣兵路线：界火觉醒——灰袍刻字者揭示真实身份（古代混血神性的残留），玩家必须在帝国、联邦、灰袍者三方中做出最终选择（此战可改变阵营）
**敌方新单位**：敌方阵营领袖（Q110 专属 Boss，拥有 5 个技能、3 个阶段变身）
**每轮特色**：三阶段战场转换 + 剧情抉择直接影响战斗难度和结局

### 5.6 通用战场机制库

### 5.8 大地图性能与分块加载建议

由于所有战斗地图最小为 40×30（1,200 格），最大达 60×40（2,400 格），且 Q110 可能同时存在 100+ 单位，建议采用以下技术方案：

1. **视锥剔除**：仅渲染玩家单位视野范围内的格子（通常 10-15 格半径），视野外以战争迷雾覆盖
2. **单位 LOD**：远距离单位使用简化模型/图标，近距离才加载完整动画
3. **回合制异步计算**：敌方 AI 在玩家回合结束时后台计算，减少等待时间
4. **地图分块**：将 60×40 地图分为 4 个 30×20 区块，镜头跨区时预加载相邻区块
5. **援军延迟加载**：援军波次单位在到达地图边缘前不实例化，仅以图标预告

### 6.9 奖励平衡性设计说明

- **帝国路线**：前期最强直接战斗加成（+3命中、+1 AC、额外圣光伤害），适合偏好战斗效率的玩家；代价是社交面极度受限，后期剧情选择最少（很多和平/外交选项被锁定）。非人类/混血玩家获得更高金钱补偿，但承受更严重的社交惩罚——这是"道德补偿机制"，不是鼓励，是标价。

- **联邦路线**：最均衡的成长曲线，团队协作加成在高难度战斗中收益显著；适合喜欢队友互动和故事深度的玩家。人类玩家放弃特权获得道德高度（联邦报酬+10%），非人类玩家获得身份认同（同族欢迎礼），混血玩家成为外交王牌（桥梁指环）。

- **自由佣兵路线**：前期最弱（无直接战斗加成，报酬-20%），但信息优势和选择权最大；适合喜欢探索完整剧情、不急于战斗效率的玩家。混血玩家在此路线后期（Q111-Q115）获得最高回报——"混血者之路"是游戏中最长的个人任务线，揭示灰袍刻字者的真实身份和整个种族战争的隐藏真相。

- **经济曲线**：帝国路线前期收入最稳定（固定军饷+高额奖金），联邦路线中期收入最高（协作任务声望转化为折扣和礼物），自由佣兵路线后期潜力最大（黑市+情报交易的复利效应）。

- **隐藏奖励总价值**：完成全部5个隐藏奖励的玩家，相当于获得约 800G 等价的额外道具和永久检定加成。这些隐藏奖励的设计意图是奖励"仔细阅读对话、探索环境、不急于选边"的玩家。

## 七、关键设计决策

1. **种族不是标签，是伤口**：每个NPC的种族身份都带有创伤。索伦的伤疤来自兽人救他，艾莉亚的烧伤来自帝国杀她父亲，老马库斯的混血让他两边都不是，灰袍刻字者的混血让他两边都不要。种族战争不是抽象的政治，是每个人身上的疤。

2. **帝国不说"恨"，说"秩序"**：帝国征兵官从不使用仇恨语言。他说"分开"、"秩序"、"净化"。这比对骂更可怕——他把种族主义包装成理性。

3. **联邦不说"爱"，说"共存"**：联邦信使也不使用道德语言。她说"约定"、"投票"、"差异在一起"。共存不是乌托邦，是七族吵吵闹闹的日常。

4. **混血是镜子**：混血NPC（老马库斯、灰袍刻字者、艾莉亚）是玩家的镜子。他们提示玩家：无论你选哪边，都会有人受伤。

5. **第三条路不是"更好"的**：自由佣兵路线不是"正确"答案。它没有阵营专属奖励，两边NPC都警惕你。但它提供了唯一的完整视野——你能看到两边的故事。

6. **炉的隐喻升级**：铁炉上三种文字（人类通用语被保留、矮人符文被帝国凿掉、精灵叶脉文被帝国涂掉但还在），是整场冲突的物质象征。炉不说话，但它在见证。

7. **兽人帝国是"原因"不是"借口"**：霜烬帝国的"净化"政策有现实根源——战争派兽人格罗姆·血喉三十年的边境劫掠确实造成了十万人类平民死亡。但这不意味着"净化所有非人类"是正确的。玩家将在后续任务（Q141-Q150）中面对这个悖论：当你知道兽人帝国确实有战争派在杀人，你还能反对帝国的种族隔离吗？

## 八、神灵线剧情设计 —— 界火古神篇

> 第二轮十轮战役·神灵觉醒：种族战争的底层真相
>
> 设计理念：帝国的"净化"和联邦的"共存"不是政治选择，而是**古神复苏的仪式**。霜烬帝国的"秩序"是人类古神的低语，联邦的"差异在一起"是平衡古神的呼唤。而灰袍刻字者——他不是什么混血弃儿。他是**界火**，是众神陨落时留下的**灰烬**。
>
> **关键前提**：神灵线不是独立于种族战争的支线，而是**种族战争的底层真相**。玩家可以在任何时间点（Q101之后）触发神灵线，但最佳入口是完成Q110或Q125后。神灵线的抉择会**覆盖或重构**种族战争线的结局。

---

### 8.0 神灵世界观前提

#### 8.0.1 古神不是神，是种族的倒影

- **古神的本质**：这个世界没有"创造万物"的神。古神是种族**集体潜意识的具现化**——当足够多的精灵相信"森林有灵"，世界树之神就真的诞生了；当足够多的人类渴望"秩序"，秩序之火就燃烧了。
- **古神与种族的关系**：不是神创造了种族，是种族的信仰创造了神。古神依赖信徒存在，信徒越多神越强，但神也必须符合信徒的想象——秩序之神不能表现出仁慈，因为信徒相信秩序需要铁腕。
- **古神的死亡**：当种族之间爆发第一次全面战争（史称"大分裂"，约三千年前），古神们被迫互相吞噬。精灵的世界树被人类的秩序之火焚毁，兽人的血喉撕裂了矮人的深岩，最终所有古神同归于尽。
- **界火的诞生**：古神陨落时，它们的残骸混合在一起，形成了一种新的能量——**界火**（Borderfire）。界火不属于任何单一种族，它是**混血的能量**，存在于所有混血者的血脉中。

#### 8.0.2 大分裂后的三千年

- **第一千年**：古神死亡，但它们的"尸体"仍在。世界各地的"圣地"其实是古神的尸骸——精灵森林的"永眠树"是世界树之神的脊椎，矮人最深的矿坑是深岩之神的颅腔，血喉草原的"战鼓丘"是血喉之神的心脏。
- **第二千年**：凡人忘记了古神，开始建立自己的王国和帝国。但古神的残骸仍在散发微弱的能量，影响着历史走向——霜烬帝国的崛起不是偶然的，是秩序之火尸体在"召唤"信奉秩序的人。
- **第三千年（现在）**：种族战争达到了三千年来最激烈的程度。足够多的仇恨、足够多的信仰、足够多的混血者诞生——**古神开始复苏**。但不是作为单一神复苏，而是作为三种可能性：
  - **秩序之火的复苏**（帝国路线终点）：吞噬其他所有神性，建立唯一神统治的绝对秩序世界
  - **平衡之轮的复苏**（联邦路线终点）：让所有古神碎片重新共存，但种族永远无法分离
  - **界火之神的诞生**（自由佣兵/混血专属）：不恢复旧神，而是创造一个**新的神**——超越种族的存在

#### 8.0.3 灰炉镇熔炉的真相

- 灰炉镇不是普通的矿镇。它建在一个**古神尸骸交汇点**上——秩序之火（人类）、世界树（精灵）、深岩（矮人）的残骸在此交汇。
- 那口熔铁炉不是普通的炉子。它是三千年前七族共同建造的**原初之火祭坛**，用于祭祀"所有种族共同的神"——但那个神在大分裂之前就被遗忘了。
- 炉壁上的三种文字不是普通的标识。它们是**封印**：人类的通用语封印着秩序之火，矮人的符文封印着深岩，精灵的叶脉文封印着世界树。帝国凿掉矮人符文、涂掉精灵文字，**无意间解开了封印的一部分**——这就是为什么灰炉镇成为了神灵线的起点。
- **铁炉是冷的，因为原初之火熄灭了。但灰烬还在。灰袍刻字者，就是灰烬。**

#### 8.0.4 界火与混血

| 概念 | 解释 |
|------|------|
| **界火** | 古神陨落后混合的神性能量，存在于所有混血者血脉中 |
| **界火载体** | 混血浓度极高的个体，可以作为界火的容器。灰袍刻字者是目前已知最强的载体 |
| **神性污染** | 长期接触古神尸骸的凡人会被神性侵蚀，表现出"被神选中"的症状。索伦的伤疤、艾莉亚的烧伤都是轻度污染 |
| **神性觉醒** | 界火载体在极端情绪或仪式下，可以短暂释放古神级别的力量。代价是自我意识的丧失 |
| **新神诞生** | 界火载体与自愿的凡人融合，可以创造一个全新的神性存在——既非旧神复苏，也非纯血凡胎 |

### 8.1 场景设定

#### 8.1.1 地下神域（The Under sanctuary）—— 灰炉镇熔炉下方

- **位置**：从灰炉镇广场熔炉的炉底裂缝进入，向下约三百尺。裂缝只有灰袍刻字者知道如何打开——需要同时在炉壁上用三种语言写下"开启"。
- **地貌**：巨大的地下洞穴，天花板高逾百尺，上面刻着已经风化的壁画——画的是七个种族围着一个火焰跪拜。地面是黑色的结晶，每一步都会发出清脆的碎裂声。
- **光源**：没有火把，没有魔法灯。光源来自墙壁上的**界火结晶**——半透明的黑色晶体，内部有微弱的、不断变换颜色的火焰。走近时会听到低语，但听不清内容。
- **核心区域**：洞穴中央是一个干涸的池子，池底有三圈同心圆。内圈刻着人类的秩序符文，中圈刻着精灵的生命符文，外圈刻着矮人的坚韧符文。三圈之间是空白——那是兽人、龙裔、半身人、侏儒的符文，在大分裂中被毁了。
- **进入方式**：
  - 方式1：完成Q111-Q115后与灰袍刻字者对话，他会带你下来
  - 方式2：在Q110最终决战中选择"触碰祭坛"，直接被传送到这里
  - 方式3：携带"灰炉镇旧地图"（隐藏奖励）+ 学会三种文字中的任意两种，自行解开封印

**无法忽视的事实**：
- 界火结晶会对非混血者造成伤害——纯血人类每回合受到1d4心灵伤害，纯血精灵每回合受到1d4灵魂伤害。混血者不受伤害，反而会恢复1HP/回合。
- 池子中央有一个盘腿坐着的人形轮廓——那是**原初之火最后的祭司**，已经死了三千年，但尸体没有腐烂。他的耳朵一只尖、一只圆、一只像兽人的、一只像龙裔的——他是**七族混血**。
- 墙壁上每隔十尺就有一句用七种文字写的话，内容相同："我们创造了神。神死了。我们还在。"

#### 8.1.2 界火裂隙（The Rift）—— 神性位面与现实的交界处

- **位置**：不固定。界火裂隙会在极端种族冲突的地方随机出现。Q110最终决战的古代祭坛就是一个裂隙。血喉草原的战鼓丘下方是另一个。精灵森林的永眠树核心是第三个。
- **地貌**：裂隙内部的空间法则是混乱的。重力方向不固定（某些区域天花板才是地面），时间流速不一致（某些区域一回合等于外界三回合），因果关系扭曲（某些攻击会在发动前就已经命中）。
- **视觉**：所有颜色都是"错误的"——血是银色的，天空是棕色的，火焰是黑色的。生物的轮廓会有轻微的"重影"，仿佛同时存在于两个位置。
- **危险**：在裂隙中停留过久会被"神性污染"。每经过5回合，所有单位必须进行意志检定，失败则获得一个"神性污染层"。积累3层后，单位会暂时被古神意志控制1d4回合。

#### 8.1.3 古神尸骸（The Divine Remains）—— 秩序之火/世界树/深岩的遗体

- **秩序之火尸骸**：位于霜烬帝国首都地下。不是火焰，是一具**水晶骨架**，高约三十尺，形状像一个由几何线条构成的人形。骨架内部有微弱的橙色光在流动。帝国大祭司梵恩·白焰每天在此祈祷——他的祈祷不是向神请求，是**向神提供能量**。
- **世界树尸骸**：位于精灵森林最深处。不是树，是一棵**倒生长的巨树**——树根朝天，树冠深入地底。树皮已经石化，但每年春季会有一片叶子变绿。精灵长老们守护着它，不让任何人靠近。
- **深岩尸骸**：位于矮人最深的矿坑之下。不是岩石，是一个**不断收缩和膨胀的空腔**，仿佛巨大的肺。站在空腔边缘可以听到心跳声——但那是矮人矿工的镐子敲击产生的共振，还是深岩之神的心脏，无人知晓。

### 8.2 神灵线NPC角色档案

#### 8.2.1 无铭（Nameless）—— 灰袍刻字者的真身

| 属性 | 描述 |
|------|------|
| 种族 | 无（他是界火的容器，不是生物） |
| 外貌 | 与灰袍刻字者相同，但在地下神域中，他的身体会变得半透明，内部可以看到七种颜色的火焰在缓慢旋转。他的脸没有五官——只有一张平滑的皮肤，但当你看向他时，你会"感觉"到他在看你 |
| 声音 | 不是从一个方向传来的。他的声音同时从四面八方、从你的内心深处、从墙壁的反射中传来 |
| 立场 | 他不关心种族战争谁赢谁输。他只关心一件事：**旧神不应该复苏**。秩序之火和平衡之轮都是三千年前就应该死去的存在，它们的复苏只会让历史重演 |
| 秘密 | 他不是"最后一个界火载体"。他是**第一个**——三千年前大分裂发生时，原初之火祭司自愿成为界火的容器，以阻止古神完全毁灭世界。他已经在地下神域中等待了三千年，等待有人做出第四个选择：不选秩序，不选平衡，不选逃避——而是**创造新神** |

**对话特征**：
- 不说"我"，说"我们"——因为他体内有三千年来所有混血死者的记忆
- 不说"神"，说"它们"或"我们创造的幻影"
- 每次提到"秩序之火"或"平衡之轮"时，他的身体对应的颜色会变得更亮（提到秩序时橙色亮，提到平衡时绿色亮）
- 会主动说出最残酷的真相："你们以为种族战争是为了土地、资源、尊严。不是。是为了**喂养它们**。每一个死在战场上的士兵，都是古神的祭品。帝国和联邦，都是祭坛。"

#### 8.2.2 梵恩·白焰（Vahn Whiteflame）—— 帝国大祭司，秩序之火的代行者

| 属性 | 描述 |
|------|------|
| 种族 | 纯血人类（他自称"秩序之火的第一个孩子"） |
| 年龄 | 67岁，但看起来不超过40岁——秩序之火的能量延缓了他的衰老 |
| 外貌 | 全身皮肤是半透明的淡橙色，可以看到下面的血管——但血管里流动的不是血，是发光的液体。眼睛没有瞳孔，只有两团白色的火焰。穿着帝国大祭司的白金长袍，袍子上绣着几何图案，图案会缓慢移动 |
| 声音 | 温暖、理性、极具说服力。每个句子都像数学公式一样精确 |
| 立场 | 他认为古神不是迷信，是**客观存在的力量**。秩序之火是真实的，而且正在复苏。他的目标不是"信仰"秩序之火，而是**完成秩序之火的复苏**，让这个世界有一个唯一、绝对、永恒的秩序 |
| 秘密 | 三十年前，他是联邦的成员。他曾经是艾莉亚·星风的导师——是的，他教给她"共存"的理念。但他在精灵森林的世界树尸骸前听到了秩序之火的低语，那低语告诉他："共存是拖延。秩序是唯一答案。"他离开了联邦，加入了帝国，成为了大祭司。艾莉亚脸上的烧伤，不是帝国士兵造成的——是梵恩离开时，用秩序之火的能量"净化"她的记忆时留下的 |

**对话特征**：
- 不说"杀死"，说"净化"或"归入秩序"
- 不说"混血"，说"未分类变量"
- 会引用数学和几何："共存是无限循环的不收敛级数。秩序是收敛于唯一解的极限。"

- **霜烬帝国首都**：地下秩序之火尸骸开始发光，从地下裂缝中透出的橙光照亮了整个城市。帝国公民称之为"神恩之光"。任何非纯血人类在橙光下会感到持续的灼烧感（每回合1d4圣光伤害）。
- **精灵森林**：世界树的石化树皮开始开裂，裂缝中流出黑色的树液——不是血，是**被秩序之火压制的生命能量**。精灵们陷入恐慌，部分精灵开始疯狂攻击任何人类。
- **灰炉镇熔炉**：人类的通用语封印完全激活，熔炉内部开始产生微弱的橙色火焰。帝国士兵在熔炉边祈祷，炉壁上的矮人符文和精灵文字被彻底熔化。
- **梵恩·白焰**：他会亲自教导玩家秩序仪式的每一个步骤。但他不会告诉你的是——当秩序之火完全复苏时，所有混血者会"蒸发"，因为他们的存在本身就是"秩序的例外"。

**种族差异**：
- **人类玩家**：你是"秩序之火的第一个孩子"，梵恩称你为"弟弟/妹妹"。你可以进入秩序之火尸骸的核心区域，触摸水晶骨架不会受伤。但你的祖国（多元种族帝国）会对你的态度变为-100（视你为种族灭绝的帮凶）。
- **非人类玩家**：秩序之火"容忍"你的存在，因为你是"可以被净化的素材"。你必须佩戴"秩序枷锁"（不可拆卸的饰品，AC+3但移动力-2），否则每回合受到3d6圣光伤害。
- **混血玩家**：秩序之火视你为"最大的错误"。梵恩会告诉你一个"解决方案"—— undergo "秩序重塑"仪式，这会移除你的混血血统（选择保留父方或母方），让你变成纯血。代价是永久失去另一种族的所有技能和被动。

#### 8.4.2 选择平衡之轮后的世界

**通用变化**：
- **精灵森林**：永眠树的倒生根须开始向下生长（原本是朝天），树冠开始向上生长。精灵长老说这是"世界树在重新学会如何生长"。但人类观察者注意到，根须和树冠的生长方向会定期互换——仿佛树本身在"犹豫"。
- **霜烬帝国**：秩序之火的复苏被阻止了，但帝国没有崩溃。相反，帝国和联邦之间出现了一道"平衡之墙"——一道由绿色光构成的屏障，任何试图攻击对方的单位会被屏障弹回。战争停止了，但不是通过和平，是通过**强制隔离**。
- **灰炉镇熔炉**：三圈同心圆同时发光——橙色、绿色、和阴影。熔炉不再是冷的，但也不热。它处于某种"永恒的温吞"状态，就像平衡本身。
- **瑟拉·根语**：她会告诉你平衡的真正代价——种族之间永远不能有真正的分离，但永远也不能有真正的融合。混血者永远是"桥梁"，不是"人"。如果你质疑这一点，她会问你："你想让桥梁变成墙，还是想让桥梁消失？"

**种族差异**：
- **人类玩家**：你是"异类中的异类"——一个人类选择了让所有种族共存。平衡之轮会给你"生长之种"（饰品），当你死亡时，你会在最近的森林中复活（一次性的第二次生命）。但你的帝国背景会让你被所有纯血人类视为"叛徒"。
- **非人类玩家**：你是"回归者"。平衡之轮视你为"失落的枝叶"。你的同族会给你"根系连接"（被动），在同族附近时自动恢复1HP/回合。但代价是——你永远不能长时间离开同族，否则会枯萎（属性下降）。
- **混血玩家**：你是"桥梁的化身"。平衡之轮会给你"双向通道"（被动），你可以在任意两个种族之间"传递"效果——例如把精灵的治疗魔法传递给兽人，或把矮人的坚韧传递给人类。但代价是，你自己不能享受任何种族专属加成——桥梁只通行，不停留。

#### 8.4.3 选择界火新神后的世界

**通用变化**：
- **灰炉镇熔炉**：熔炉不再是冷的。它开始燃烧一种**黑色的火焰**——不热，不发光，但所有靠近它的人都能看到自己的"另一种可能"。纯血人类会看到自己如果是混血的样子，混血者会看到自己如果是纯血的样子。这造成了极大的心理冲击。
- **无铭的状态**：他不再只是灰袍刻字者。他会在特定时刻（完成七族任务后）以"半实体"状态跟随玩家——不是作为队友，是作为一种"环境效果"。当玩家遇到困难时，他偶尔会干预（例如让敌人的攻击"意外"偏移，或让玩家的治疗"意外"增强），但这消耗他的存在——每次干预，他的半透明身体就会变得更透明。
- **秩序之火和平衡之轮**：它们都感觉到了威胁。梵恩和瑟拉会同时派人来接触你——不是攻击，是"谈判"。梵恩会说"界火是混乱"，瑟拉会说"界火是未平衡的不确定"。但他们的真实目的是评估你是否真的能成功。
- **七族任务的状态**：每完成一个种族的任务，原初之石上的一个裂纹会亮起对应的颜色。完成全部七个后，原初之石会变成一个**微型太阳**，悬浮在玩家的胸口——但不是一直存在，只有在玩家"需要力量"的时候才会出现。

**种族差异**：
- **人类玩家**：你证明了人类可以超越自身的种族边界。无铭会说"你选择了不是人类的答案，但这恰恰证明了人类的潜力"。你的七族任务中，人类的"秩序"任务会有特殊版本——不是理解秩序，是**质疑秩序**。
- **非人类玩家**：你证明了非人类种族不必被自己的神定义。无铭会说"你是兽人/精灵/矮人，但你选择了不是兽人/精灵/矮人的道路"。你的七族任务中，同族的任务是最难的——因为你必须"背叛"同族的期望才能理解它。
- **混血玩家**：你是最天然的界火载体。无铭会告诉你"你不需要理解七族——你就是七族"。你的七族任务会大幅简化（自动完成3个），但最后的融合仪式会有额外风险——因为你的身体已经在承载界火，再与无铭融合可能导致"过载"。

### 8.5 神灵线战棋设计

#### 8.5.0 神灵线战斗总则

**战场性质**：神灵线的战斗发生在**神性位面**（界火裂隙）或**古神尸骸内部**。物理法则被扭曲：
- 重力方向可能不固定（某些区域天花板才是地面）
- 时间流速不一致（某些区域一回合等于外界三回合）
- 因果关系扭曲（某些攻击会在发动前就已经命中）

**神性污染机制**：
- 所有单位在神性位面中，每经过5回合必须进行意志检定（DC=10+轮次数）。失败则获得1层"神性污染"。
- 积累3层后，单位会被古神意志控制1d4回合（自动攻击最近的友方单位）。
- 混血玩家和界火路线玩家免疫神性污染。秩序路线玩家对秩序之火污染免疫，但对其他污染脆弱。平衡路线玩家对所有污染的检定+3。

**操控单位限制**：与种族战争线一致，玩家直接操控上限为4人（玩家自身+最多3名友军）。其余友方单位为AI控制的"神性眷属"或"古神碎片"，玩家可消耗1个标准动作下达【神性命令】。

**地图尺寸**：所有神灵线战斗地图最小 **40×30**，古神核心战斗使用 **50×40**。

#### 8.5.2 秩序之火路线战斗序列

##### Q201 · 秩序之庭 —— "水晶迷宫肃清"

**地图**：40×30 水晶迷宫（霜烬帝国首都地下秩序之火尸骸的外围）
- 地形：墙壁和地面由半透明橙色水晶构成，光线会在水晶之间反射，某些区域有"镜面陷阱"（走进去会被传送到迷宫另一处）
- 特殊：秩序之火的光芒从天花板透下，所有非人类单位在此光芒下每回合受到1d6圣光伤害；混血玩家受到2d6

**友方（玩家操控，最多4人）**：玩家 + 秩序骑士×1（重甲/圣光攻击）+ 秩序牧师×1（净化/治疗）+ 秩序猎手×1（追踪/破隐）
**友方（AI神性眷属，不可操控）**：秩序之火碎片×6（漂浮的光球，自动攻击最近的非人类敌人，玩家可命令【集火】【护卫】【扩散】）
**敌方（平衡之轮的渗透者）**：根须刺客×4（从地面根须中突然袭击）+ 树皮卫士×4（高AC，被攻击时反弹1d4伤害）+ 孢子法师×2（范围毒雾，降低命中）+ **半神单位**：裂根者（精灵/树的混合体，神性技能【根系囚禁】——3格范围内所有敌人被束缚2回合）

**特色机制**：
1. **镜面迷宫**：40%的墙壁是镜面，走进去会被随机传送到地图另一处。秩序猎手可以用【追踪】动作标记安全路径
2. **秩序之光**：每3回合，天花板的秩序之火会进行一次"净化闪光"——所有非人类单位受到3d8圣光伤害，友方人类单位恢复2d8HP
3. **神性污染**：非秩序路线的玩家每5回合需意志检定，失败获得1层污染。3层后被秩序之火控制1d4回合（自动攻击最近的非人类/混血友方）
4. **神性命令**：消耗1个标准动作，命令AI秩序碎片【集火指定目标】【护卫玩家】【扩散包围】
5. **胜利条件**：击杀裂根者 或 净化50%地图区域（将镜面墙壁转化为橙色水晶，消除传送陷阱）

**敌方强度**：Q201基础级。首次出现神性单位和神性污染机制。

##### Q202 · 世界树根系 —— "倒生深渊的净化"

**地图**：40×30 倒生森林（精灵森林永眠树的根系区域）
- 地形：天花板是地面，根须像瀑布一样"向下"生长（实际上是向上）。玩家需要适应"反向重力"——某些区域的地面其实是天花板
- 特殊：根系会分泌绿色树液，站在树液中每回合恢复1HP（非人类）或受到1HP腐蚀（人类）

**友方（玩家操控，最多4人）**：玩家 + 秩序工程师×1（爆破/烧根）+ 秩序骑士×1 + 秩序弓手×1（火焰箭）
**友方（AI神性眷属）**：秩序之火碎片×4 + 帝国工兵×4（自动焚烧根须，玩家可命令【加速焚烧】【建立防火带】【掩护工兵】）
**敌方（世界树的防御系统）**：根系触手×6（从地面/天花板伸出，束缚攻击）+ 孢子云×3（2格范围毒雾，持续3回合）+ 树灵×4（半透明，只有火焰攻击能命中）+ **半神单位**：根须之母（巨大的根系核心，神性技能【生命洪流】——所有敌方单位恢复3d8HP）

**特色机制**：
1. **反向重力**：地图30%区域重力反转（天花板是地面）。单位进入这些区域时需要进行平衡检定，失败则摔倒并失去本回合移动力
2. **焚烧机制**：玩家工兵和工程师可以焚烧根须。每焚烧一根主根须，根须之母失去10%HP。但焚烧会释放孢子云（范围毒雾）
3. **树液区域**：绿色树液区域对非人类是恢复（+1HP/回合），对人类是腐蚀（-1HP/回合）。秩序路线玩家可以选择"净化树液"（将其转化为圣水，恢复人类但伤害非人类）
4. **神性命令**：消耗1个标准动作，命令AI工兵【焚烧指定根须】【建立防火带阻止孢子扩散】【紧急撤退】
5. **胜利条件**：焚烧主根须×5（根须之母HP降至50%以下后逃入深层）或 直接击杀根须之母

**敌方强度**：Q202进阶级。出现重力反转和焚烧机制。

##### Q203 · 深岩空腔 —— "心跳矿坑的沉默"

**地图**：40×30 地下空腔（矮人最深矿坑下方的深岩之神尸骸外围）
- 地形：巨大的天然洞穴，墙壁是不断收缩膨胀的岩石（仿佛呼吸）。地面不稳定，每回合有20%概率发生"岩波"（所有站立单位需平衡检定，失败摔倒）
- 特殊：空腔中央有一个"心跳核心"——每3回合发出一次冲击波，所有单位被推开2格并受到2d6音波伤害

**友方（玩家操控，最多4人）**：玩家 + 秩序骑士×1 + 秩序法师×1（音波抗性/沉默术）+ 秩序工兵×1（放置支撑柱稳定地面）
**友方（AI神性眷属）**：秩序之火碎片×5 + 帝国矿工×6（自动开采稳定岩石，玩家可命令【放置支撑】【撤离危险区】【开采音石】）
**敌方（深岩的防御系统）**：岩石傀儡×6（高AC，被摧毁后分裂为2个小傀儡）+ 岩浆蠕虫×3（地下移动，突然袭击）+ 晶簇射手×4（从墙壁发射晶体碎片）+ **半神单位**：深岩之肺（巨大的呼吸空腔，神性技能【窒息】——3格范围内所有单位无法呼吸，每回合失去2d6HP，持续3回合）

**特色机制**：
1. **呼吸地面**：每回合20%概率发生岩波。玩家工兵可以放置支撑柱（消耗1回合），将周围3格区域的岩波概率降至5%
2. **心跳冲击**：每3回合的冲击波不分敌我。秩序法师可以用【沉默术】抵消一次冲击波（冷却5回合）
3. **岩浆蠕虫**：在地下移动（不可见），只在攻击时现身。玩家可以用【音波探测】（法师技能）或【重踏地面】（骑士技能）迫使它们现身
4. **开采音石**：AI矿工可以开采特殊岩石"音石"，投掷后产生局部沉默效果（免疫下一次心跳冲击或深岩之肺的窒息）
5. **神性命令**：消耗1个标准动作，命令AI矿工【放置支撑柱】【开采音石】【紧急撤离】
6. **胜利条件**：放置支撑柱稳定70%地图 或 击杀深岩之肺（使其"窒息"，停止呼吸和心跳）

**敌方强度**：Q203中级。出现环境动态机制（岩波+心跳）。

##### Q204 · 血喉战鼓丘 —— "兽人之心的秩序化"

**地图**：50×40 草原+地下（血喉草原的战鼓丘，表层是草原，地下是血喉之神心脏的空腔）
- 地形：表层是开阔草原（同帝国Q105），但地下有一个巨大的心脏形空腔——墙壁是暗红色的肌肉纹理，地面有节奏地起伏（模拟心跳）。空腔中有血管状的通道连接各个区域

4. **风暴元素控制**：风暴元素是中立的（攻击最近单位）。龙裔法师可以用【雷电共鸣】暂时控制一个风暴元素（持续3回合），让它攻击秩序部队
5. **胜利条件**：击落秩序之翼 或 保护联邦空艇完成【平衡天幕】仪式（需3回合，期间空艇不能移动，仪式完成后全场雷电停止，秩序法师引雷能力失效）

**敌方强度**：Q205高级。立体空战+环境争夺。

##### Q206 · 世界树核心 —— "倒生巨树的神性对决"

**地图**：50×40 古神尸骸内部（世界树的倒生核心，不是建筑，是在**树的体内战斗**）
- 地形：树壁构成天然走廊，树液河流在"下方"流动（实际上是上方，因为树是倒生的），孢子云 constantly 从树壁释放

**友方（玩家操控，最多4人）**：玩家 + 精灵树卫×1 + 兽人狂战士×1 + 矮人盾卫×1
**友方（AI神性眷属）**：世界树碎片×10 + 瑟拉·根语的投影×1（AI控制的强力治疗者，自动使用范围治愈术，玩家可命令【全力治疗】【保护玩家】【释放孢子风暴】）
**敌方（秩序之火的最终入侵+界火干扰）**：秩序泰坦×2（2×2巨型单位，火焰攻击）+ 净化之焰×1 + 秩序之眼×2 + 火焰元素×6 + 界火干扰体×2（同秩序路线Q206，中立，随机攻击）

**特色机制**：
1. **树液河流**：地图上流淌着绿色树液河。站在河中每回合恢复3d8HP（非人类）或受到2d6腐蚀（人类）。树卫可以【改变树液流向】，使河流改道（改变恢复/伤害区域）
2. **孢子风暴**：瑟拉的投影每3回合自动释放【治愈孢子风暴】（全场友方恢复2d8HP）或【剧毒孢子风暴】（全场敌方中毒，-3命中）。玩家可以命令她选择释放哪种
3. **树壁再生**：被破坏的树壁会在2回合后自动再生。但秩序泰坦的【焚毁】可以永久破坏树壁（产生火焰区域，3d6火焰伤害/回合）
4. **界火干扰**：同秩序路线Q206，无铭的碎片随机攻击任意一方
5. **神性污染**：非平衡路线玩家每3回合需意志检定，失败获得2层污染
6. **胜利条件**：击杀净化之焰 或 保护瑟拉的投影完成七族共鸣仪式（需10回合，期间瑟拉不能移动，玩家必须保护她）

**敌方强度**：Q206大规模。35+单位+多个巨型单位+界火干扰。

#### 8.5.4 界火新神路线战斗序列

界火路线的战斗与其他两条路线完全不同——玩家没有AI神性眷属军团。界火路线的核心体验是**孤独**：玩家只有4人小队，面对秩序和平衡双方的攻击，利用界火的扭曲能力以弱胜强。

##### Q201 · 地下神域试炼 —— "界火的第一次燃烧"

**地图**：40×30 地下神域（界火结晶洞穴）
- 地形：黑色结晶地面，界火结晶墙壁。某些结晶是"活性"的——触碰后会释放随机的神性效果（可能是恢复、伤害、传送、或时间倒流1回合）

**友方（玩家操控，最多4人）**：玩家 + 混血佣兵×3（无AI军团——界火路线没有阵营后台）
**敌方（秩序之火和平衡之轮的共同试炼）**：秩序之火碎片×3 + 世界树碎片×3（它们互相攻击，但也攻击玩家——试炼的目的是"筛选"）+ 神性构造体×4（岩石+火焰+根须的混合体，攻击最近单位）

**特色机制**：
1. **界火觉醒**：玩家每回合可以选择【点燃界火】——消耗20%当前HP，本回合所有攻击无视AC和抗性，直接造成真实伤害。但HP低于20%时不能使用
2. **活性结晶**：地图上有12个界火结晶。触碰后随机效果（骰1d6：1-恢复2d8HP；2-受到2d8伤害；3-传送至随机位置；4-时间倒流1回合（撤销上一回合的所有伤害和移动）；5-获得1层神性污染；6-获得1层"界火共鸣"（攻击+2，持续3回合））
3. **双方试炼**：秩序之火碎片和世界树碎片互相攻击（秩序vs平衡），但也攻击玩家（测试玩家是否有资格成为新神）。玩家可以选择帮助一方（获得该方的临时加成，但另一方敌意增加），或两边都打（难度极高）
4. **无军团命令**：界火路线没有AI友军团。玩家只能操控4人小队
5. **胜利条件**：存活10回合（试炼自动结束）或 摧毁6个活性结晶（释放足够界火能量迫使试炼终止）或 击杀所有神性构造体

**敌方强度**：Q201基础级。首次出现"以弱胜强+随机性"的界火体验。

##### Q202 · 人类秩序试炼 —— "理解秩序"

**地图**：40×30 秩序之火水晶迷宫的投影（界火创造的幻境，不是真实地点）
- 地形：完美的几何迷宫，所有墙壁都是直角，所有走廊都是等宽的。没有随机性，没有意外——**绝对的秩序**

**友方（玩家操控，最多4人）**：玩家 + 混血佣兵×3
**敌方（秩序的化身）**：几何卫士×8（人形，由完美的几何线条构成，移动路径必须是直线，转弯必须是90度）+ 绝对镜像×2（复制玩家小队的镜像，拥有相同属性和技能，但受秩序约束）+ **半神单位**：方程核心（巨大的数学公式漂浮在空中，神性技能【收敛】——指定3格区域，该区域内的所有随机效果被消除，所有单位必须按照"最优路径"移动，否则受到3d8伤害）

**特色机制**：
1. **秩序约束**：在这个幻境中，所有单位（包括玩家）的移动必须遵守"秩序规则"——每回合移动方向改变不能超过90度，不能走回头路，不能跳过格子。违反规则受到2d8秩序伤害
2. **绝对镜像**：镜像会完全复制玩家小队的配置和当前HP。但镜像受秩序约束更严格（不能改变方向，必须直线攻击最近的敌人）。玩家可以利用这一点引诱镜像走入死胡同
3. **界火扭曲**：玩家可以使用【界火扭曲】（消耗1个标准动作）——暂时无视秩序约束1回合。但每使用一次，无铭的声音会警告"扭曲太多，你会迷失"
4. **理解秩序**：此战的核心不是击杀，是**理解**。玩家必须找到迷宫中央的"秩序之核"（需要走一条完美的直线），触碰它即可完成试炼。但路上有重重阻碍
5. **胜利条件**：触碰秩序之核 或 击杀方程核心（但击杀它会触发"秩序崩溃"，全场受到5d8伤害）

**敌方强度**：Q202进阶级。解谜+战斗结合。

##### Q203 · 精灵生长试炼 —— "理解生长"

**地图**：40×30 世界树内部的幻境（无限的树壁走廊，没有尽头，每走一步身后的路就会消失）
- 地形：活的树壁，会缓慢移动改变地形。某些区域的树壁会"生长"出新的通道，某些区域会"枯萎"封闭旧的通道

**友方（玩家操控，最多4人）**：玩家 + 混血佣兵×3
**敌方（生长的化身）**：根须幽灵×6（半透明，只有移动时才会被攻击到）+ 孢子云×4（不断扩大的毒雾区域）+ 生长巨口×2（树壁上的巨大嘴巴，吞噬经过的单位）+ **半神单位**：年轮之心（巨大的树轮，神性技能【时间生长】——指定1个单位，该单位"老化"3回合：AC-3、攻击-3、移动力-2，持续5回合）

**特色机制**：
1. **无限生长**：地图没有固定边界。每3回合，地图边缘会生长出新的区域（10×10），同时旧的区域会枯萎消失（其中的单位如果没有及时撤离则死亡）。玩家必须不断向"中心"移动
2. **生长与枯萎**：玩家可以用【界火】焚烧树壁（开辟新通道）或【安抚】树壁（阻止其枯萎）。但焚烧会释放孢子云，安抚会消耗1个标准动作
3. **根须幽灵**：只有移动中的根须幽灵可以被攻击。如果玩家站在原地等待，幽灵会消失（无法被攻击），但会在玩家移动时从背后袭击
4. **理解生长**：此战的核心是**接受变化**。找到"世界树之种"（不断移动的目标，每回合随机出现在地图某处），触碰它3次即可完成试炼
5. **胜利条件**：触碰世界树之种×3 或 击杀年轮之心（但击杀它会导致全场加速枯萎，玩家有3回合逃离）

**敌方强度**：Q203中级。动态地图+移动战术。

##### Q204 · 兽人血性试炼 —— "理解血性"

**地图**：50×40 血喉战鼓丘的幻境（无尽的战场，天空是血红色的，地面 constantly 有新的武器从地下冒出）
- 地形：开阔战场，但地面每回合会随机冒出武器（剑、斧、矛、盾）。拾取武器的单位当回合攻击+3，但下回合必须丢弃（否则武器会"反噬"，造成2d6伤害）

**友方（玩家操控，最多4人）**：玩家 + 混血佣兵×3
**敌方（血性的化身）**：战争幽灵×10（死去士兵的灵魂，不断复活，每次复活攻击+1但HP-5）+ 嗜血兽×4（攻击最近单位，不分敌我）+ 战鼓幻象×2（每回合给所有敌方单位+1攻击）+ **半神单位**：血喉之忆（巨大的兽人骸骨，神性技能【无尽狂暴】——全场所有单位（包括玩家）进入【狂暴】状态：攻击+5、AC-3、自动攻击最近单位，持续3回合）

**特色机制**：
1. **武器冒出**：每回合随机10个格子冒出武器。拾取后本回合攻击+3，下回合必须丢弃。玩家可以选择不拾取（保持机动性）或频繁更换武器（高输出但消耗动作）
2. **无尽复活**：战争幽灵被击杀后会在3回合后从地下复活（在死亡位置）。每次复活攻击+1但HP-5（第4次复活时HP=0，彻底死亡）。玩家可以用【界火】焚烧尸体（阻止复活）
3. **狂暴控制**：血喉之忆的【无尽狂暴】影响全场，包括玩家。玩家必须利用地形（某些区域有"平静之泉"，进入后取消狂暴）或提前准备【镇静药剂】（隐藏奖励物品）
4. **理解血性**：此战的核心是**控制而非释放**。玩家必须在不击杀血喉之忆的情况下，在战场上存活8回合并保护至少3个"和平印记"（地图上随机出现的白色石碑，敌对单位会优先攻击它们）
5. **胜利条件**：保护3个和平印记存活8回合 或 击杀血喉之忆（但击杀它会释放更多战争幽灵）

**敌方强度**：Q204高级。高输出+复活机制+全场控制。

##### Q205 · 矮人坚韧试炼 —— "理解坚韧"

**地图**：40×30 深岩空腔的幻境（不断收缩的空间，墙壁每回合向中央移动1格，生存空间不断缩小）
- 地形：初始40×30，但每回合墙壁向中央收缩1格。20回合后地图变为20×10。站在墙壁上的单位每回合受到5d6挤压伤害

**友方（玩家操控，最多4人）**：玩家 + 混血佣兵×3
**敌方（坚韧的化身）**：岩石卫士×6（极高AC，免疫物理攻击，只有界火/爆炸能伤害）+ 岩浆流×3（每回合向随机方向流动3格，站在上面的单位受到3d6火焰伤害）+ 压力核心×2（2×2巨型单位，神性技能【增压】——指定区域重力加倍，移动力减半，跳跃/飞行无效）+ **半神单位**：深岩之忆（巨大的岩石心脏，神性技能【绝对挤压】——墙壁收缩速度加倍，持续3回合）

**特色机制**：
1. **空间收缩**：每回合墙壁向中央移动1格。玩家必须不断向中央移动，但中央区域有最强的敌人。20回合后地图极小，几乎不可能躲避
2. **界火爆破**：玩家可以用【界火】爆破岩石（开辟安全区域或炸毁岩石卫士）。但每次爆破会加速墙壁收缩（额外+0.5格/回合）
3. **岩浆流控制**：岩浆流每回合随机方向流动。玩家可以引导它们流向岩石卫士（对其造成额外伤害）或远离自己
4. **理解坚韧**：此战的核心是**在绝境中坚持**。玩家必须在地图收缩至20×10之前，找到并破坏3个"压力阀门"（隐藏在岩石中的机关，破坏后该区域的墙壁停止收缩）。破坏全部3个后，深岩之忆的【绝对挤压】失效
5. **胜利条件**：破坏3个压力阀门 或 击杀深岩之忆（但它有300HP和极高AC，极难击杀）

**敌方强度**：Q205高级。时间压力+空间管理。

##### Q206 · 融合仪式前的最终试炼 —— "三方围猎·神性版"

**地图**：50×40 界火裂隙（神性位面，重力/时间/因果全部扭曲）
- 地形：50%区域重力反转（天花板是地面），30%区域时间加速（1回合=2回合），20%区域因果扭曲（攻击在发动前就已经命中，意味着你无法躲避，但可以"撤销"攻击）

**友方（玩家操控，最多4人）**：玩家 + 混血佣兵×3（无AI军团）
**敌方（秩序之火+平衡之轮的联合猎杀）**：秩序骑士×4 + 秩序之火碎片×3 + 精灵树卫×3 + 世界树碎片×3 + **半神单位**：秩序之眼×1 + 净化之手×1（它们互相也会攻击！但优先攻击玩家）

**特色机制**：
1. **三方混战**：秩序和平衡互相攻击（秩序vs平衡），但都优先攻击玩家（玩家是"最大的威胁"）。玩家可以利用它们的矛盾，引诱它们互相消耗
2. **重力反转**：50%区域重力反转。进入这些区域时需要进行平衡检定，失败则摔倒。但摔倒后可以利用重力反转"掉"到天花板上，躲避地面攻击
3. **时间加速**：30%区域时间加速。站在其中的单位每回合可以行动2次（但HP消耗也加倍）
4. **因果扭曲**：20%区域因果扭曲。在此区域中，任何攻击都无法躲避（闪避/格挡无效），但玩家可以用【界火·因果切断】（消耗1个标准动作）"撤销"上一回合对自己造成的1次伤害
5. **无铭的干预**：每5回合，无铭会以界火形态干预一次（随机效果：1-全场敌方受到3d8界火伤害；2-玩家小队恢复至满HP；3-时间倒流2回合；4-召唤1个界火构造体帮助玩家，持续3回合）
6. **胜利条件**：存活12回合（无铭完成融合准备）或 击杀秩序之眼和净化之手（极难）或 引诱秩序和平衡双方互相全灭

**敌方强度**：Q206超大规模。25+敌方单位+2个半神+三方混战+多重空间扭曲。界火路线的最难战斗。

#### 8.5.5 Q207-Q210 神灵线最终战设计理念概述

##### Q207 · 神性要塞（三条路线）

**敌方新单位**：神性泰坦（4×4巨型单位，一击可摧毁建筑）、神话神性生物（被完全神性改造的龙/凤凰）

##### Q210 · 最终神性决战 —— "原初之火祭坛"

**地图**：50×40 多阶段战场（第一阶段：地下神域；第二阶段：界火裂隙；第三阶段：现实重构）

### 8.7 神灵线关键设计决策

1. **神不是答案，是问题**：秩序之火、平衡之轮、界火新神，三条路线都不是"正确"的。秩序是安全的监狱，平衡是永恒的僵局，界火是未知的赌博。玩家选择的不是"救世界"，是"选择世界变成什么样子"。

2. **种族战争的底层是神性战争**：Q101-Q110的所有NPC——索伦、艾莉亚、老马库斯、灰袍刻字者——都不知道自己在参与古神复苏。索伦以为自己在建立秩序，其实他是秩序之火的祭品。艾莉亚以为自己在追求共存，其实她是平衡之轮的培养皿。只有老马库斯（两边都不是）和灰袍刻字者（无铭）隐约感觉到了真相。

3. **混血者是钥匙，也是锁**：界火存在于混血者体内，所以混血者是唯一能创造新神的存在。但这也意味着混血者一直是古神战争的"资源"——帝国净化混血是为了消灭界火，联邦保护混血是为了控制界火，自由佣兵路线的混血者才是真正的"自由"——但他们也承担了最大的风险。

4. **熔炉的终极隐喻**：灰炉镇的熔炉从Q101到Q210经历了完整的变化——冷→微温→燃烧→黑焰→原初之火。熔炉不说话，但它是整个故事的见证者。最后熔炉之心的台词"烧完了。告诉我，你还冷吗？"是对玩家的终极提问：你经历了战争、神性、抉择之后，是否找到了自己的温度？

5. **无铭不是导师，是同伴**：无铭不会给玩家正确答案。他甚至不会给玩家任务。他只是——等待。三千年的等待让他疲惫到不再相信任何解决方案。玩家的选择不是为了拯救世界，是为了给无铭一个答案：我们是否值得再试一次？

6. **神灵线的战斗不是"打怪"，是"与神性共处"**：神灵线的敌人不是"邪恶的生物"，是"古神的本能"——秩序之火不是恨你，它只是认为你是方程中的错误。平衡之轮不是爱你，它只是害怕再次分裂。理解这一点，比击败它们更重要。

7. **三条神灵路线与三条种族路线的对应与超越**：
   - 帝国→秩序：从"人类至上"到"秩序至上"，从种族净化到神性净化
   - 联邦→平衡：从"种族共存"到"神性强制的永恒共存"，从自由联盟到无法分离的绑定
   - 自由佣兵→界火：从"两边都不选"到"创造第三种可能"，从观察者到参与者到超越者
   - 关键区别：种族战争的第三条路（自由佣兵）是"逃避选择"，神灵线的第三条路（界火）是"创造选择"。
