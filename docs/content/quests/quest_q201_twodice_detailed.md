# Q201 双骰之誓 —— 详细设计文档

> 十轮战役·第二轮：信仰战争的开端
>
> 设计理念：双骰镇曾经是大陆最著名的赌博圣地。人们来这里祈求幸运，也来这里咒骂厄运。现在，幸运女神的信徒说这里应该只有金色。厄运女神的信徒说这里应该只有黑色。而骰子本身——它有两面。只是没人记得了。

---

## 一、场景设定

### 1.1 地点：双骰镇（Twodice）中央广场

- **位置**：大陆中部两条河流交汇处，曾是商队、赌徒、占卜师聚集的繁华小镇。现在是信仰战争的前线——不是因为资源，而是因为"定义权"：幸运和厄运，谁才是命运的真相
- **地貌**：广场中央有一尊巨大的石制骰子雕塑，约三人高，二十面，每一面曾经刻着不同的符号——幸运的面是金色的太阳、四叶草、满杯；厄运的面是黑色的裂月、枯骨、空杯。现在，骰子的上半部分被漆成了纯金色，下半部分被漆成了纯黑色，中间有一道粗糙的分界线，像是一道伤疤
- **天气**：黄昏，太阳正在两河之间的峡谷下沉，光线恰好被峡谷切成两半——一半照在骰子的金色面上，闪闪发亮；一半照在黑色面上，像被吞噬了一样
- **声音**：北侧有金铃的叮当声（幸运信徒的仪式），南侧有镜子碎裂的声音（厄运信徒的净化仪式），中间有骰子在石盘上滚动的咕噜声——那是老千维克在用脚趾掷骰子
- **气味**：北侧飘来甜腻的熏香（幸运仪式用的金桂和蜂蜜），南侧飘来焦糊的铁锈味（碎镜教团焚烧护身符的烟雾），中间是麦酒、汗味和某种说不清的陈旧气息——那是维克酒馆里的味道，也是这个镇原本的味道

### 1.2 场景状态

玩家第一次进入双骰镇时，广场被分成了两半：

- **北侧（金色半区）**：金骰教团的"祈福阵列"，十二名信徒跪成扇形，中央是高台。高台上站着先知塞拉菲娜·金铃。她的信徒们穿着金色的袍子，但很多人的袍子已经洗得发白，有些人的袍角有补丁。他们每个人的脖子上都挂着至少三个护身符——四叶草、马蹄铁、幸运眼。地上铺满了金粉画出的法阵，法阵中央是一个不断旋转的小型金色骰子（魔法装置）。
- **南侧（黑色半区）**：碎镜教团的"裂镜祭坛"，九名信徒站成倒三角形，中央是一面被砸碎后又用黑铁重新拼接的巨大镜子。先知莫尔登·裂镜站在镜子前，镜中的他裂成了十几块。信徒们穿着黑色的破袍，但每一道裂口都裁剪得极其精确——他们不是贫穷，是在展示"破损的美感"。地上散落着被砸碎的金色护身符碎片，那是他们从幸运信徒那里抢来并砸碎的战利品。
- **骰子雕塑东侧台阶**：老千维克的"中立酒馆"——实际上只是一个没有墙的酒摊，几张木桶当桌子。维克坐在台阶上，用脚夹着三颗骰子，正在和几个面色尴尬的商队保镖赌博。他的双手——没有手指，只有两个光秃秃的手掌，像肉色的铲子。
- **骰子雕塑底部阴影处**：一个年轻人蹲在阴影里，手里拿着半块面包。他刚咬了一口，头顶的石雕突然掉下一小块碎石，砸在他的肩膀上。他叹了口气，继续吃。如果你注意看，会发现他的左手戴着一枚金戒指（幸运的象征），右手手腕上缠着一条黑布（厄运的标记）。

**无法忽视的事实**：
- 广场周围的店铺——北侧的招牌都换成了金色，南侧的招牌都被砸碎或涂黑了。中间的几家店挂了两块招牌，一块金色一块黑色，像是要同时讨好两边。
- 石骰子的分界线不是笔直的——金色漆向上蔓延了一些，黑色漆也向下渗透了一些，像两股液体在互相侵蚀。如果你仔细看，会发现分界线附近有一些细小的裂纹，裂纹里长出了灰色的苔藓——那是这个镇原本的颜色。

## 二、NPC角色档案

### 2.1 塞拉菲娜·金铃（Seraphina Goldbell）— 金骰教团先知

| 属性 | 描述 |
|------|------|
| 种族 | 人类 |
| 年龄 | 39岁（看起来25岁，因为她用幸运仪式维持容貌） |
| 外貌 | 金发，但发根是灰白色的——仪式只能维持表面。眼睛是淡金色的，不像是人类的眼睛，像是两枚磨损的金币。身上挂满小金铃，走路时响，但响声不均匀——有些铃哑了。 |
| 穿着 | 金骰教团先知的仪式长袍，金线刺绣，但金线在某些地方已经脱落，露出底下的灰布。腰间系着一条由七十个护身符串成的腰带——每多一个信徒，她就加一个护身符。 |
| 声音 | 高，亮，像铃铛，但说到某些词时会突然哑掉，像铃舌断了。 |
| 立场 | 她真心相信幸运是善良的力量，厄运是世界的疾病。但她维持这份"真心"的方式，是把周围人的幸运吸到自己身上。 |
| 秘密 | 二十年前，她是一个贫农的女儿。她向幸运女神祈求丰收，女神回应了——但代价是隔壁田地的歉收。她以为自己只是"被选中"，直到她成为先知后看到教团的账本：每次大型祈福仪式后，镇上都会有一场瘟疫、一次火灾、一个家庭的破产。她的幸运从来不是凭空产生的，是从别人那里转移来的。 |

**对话特征**：
- 不说"厄运"，说"黑暗"或"缺失"
- 不说"失败"，说"尚未被祝福"
- 每次提到"金骰女神"时，会下意识地摸腰间最旧的那个护身符——那是她母亲留给她的，但已经裂开了，她用金漆涂上了
- 会主动说出教团的代价："我们吸收不幸。我们承受不幸。所以你不必承受。"
- 她的护身符腰带上有三个铃铛是黑色的——那是"被封印的厄运"，但她从不解释

### 2.2 莫尔登·裂镜（Morden Crackmirror）— 碎镜教团先知

| 属性 | 描述 |
|------|------|
| 种族 | 半精灵（但他从不提自己的精灵血统，只说"我是被厄运选中的人"） |
| 年龄 | 52岁 |
| 外貌 | 瘦高，背有点驼。左脸有一道从太阳穴延伸到下巴的伤疤，是自己用碎镜划的——"厄运之痕"。右眼是深褐色的，左眼是乳白色的（失明）——不是被攻击，是他在某次仪式中"自愿献祭"的视力。头发黑色夹杂着大量白发，但他把白发染成了更黑的黑色，所以看起来像是戴着一顶假发。 |
| 穿着 | 碎镜教团的黑袍，布料上等但故意剪破，每一道裂口都对应着某个"被接受的厄运"。脖子上挂着一面巴掌大的碎镜，用黑铁丝捆着——镜中永远照不出他的完整影像。 |
| 声音 | 低，哑，像砂纸摩擦木头。但说到激动处会突然清亮，像年轻人在假扮老人。 |
| 立场 | 他不恨幸运。他恨的是"幸运的幻觉"——人们以为可以逃避厄运，结果在厄运来临时毫无准备。他认为拥抱厄运才是唯一的诚实。 |
| 秘密 | 三十年前，他是双骰镇最幸运的赌徒。连续七年，他掷出的骰子从来没有低于十五点。他赢得了三栋房子、两艘船、一个贵族头衔。然后，在一个雨夜，他输掉了所有——不是因为他运气用完了，而是因为他发现了真相：那七年里，有人在骰子里灌了铅。他从来不是幸运，他只是被欺骗了。于是他砸碎了所有的镜子（"我不愿再看到虚假的自己"），转向了厄运女神——不是因为信仰，是因为绝望。如果幸运是假的，那至少厄运是真实的。 |

**对话特征**：
- 不说"幸运"，说"幻觉"或"麻醉"
- 不说"痛苦"，说"觉醒"或"真实"
- 每次提到"碎镜女神"时，会摸自己的左眼（失明的那个）
- 会主动说出教团的残酷："我们会让你失去。会让你破碎。会让你看到自己真正的样子。但你会因此自由。"
- 他的碎镜中，如果玩家仔细看，会看到不止一个倒影——里面有三个模糊的人影，但他只有一个人

### 2.3 老千维克（Vic the Thumb）— 酒馆老板/退役赌徒

| 属性 | 描述 |
|------|------|
| 种族 | 人类 |
| 年龄 | 61岁 |
| 外貌 | 矮胖，光头，满脸通红的酒糟鼻。双手没有手指——十根手指全没了，只剩下两个光秃秃的手掌。脚趾倒是完整，而且异常灵活，能夹起骰子、硬币、甚至酒杯。 |
| 穿着 | 一件油腻的背心，上面印着褪色的骰子图案。脖子上没有护身符，也没有黑布——只有一个简单的铜项链，上面挂着一把小钥匙（酒窖的钥匙）。 |
| 立场 | 他不信神。他只信概率。他说："幸运和厄运都是形容词，不是名词。它们描述的是结果，不是力量。" |
| 作用 | 提供第三条路的信息，以及双骰镇被两边教团毁掉之前的真实历史 |

### 2.4 双运者（The Twice-Blessed）— 隐藏NPC

- 种族：人类
- 名字：里奥（Leo），但他不说
- 只在玩家拒绝双方教团后出现
- 蹲在骰子雕塑的阴影里，左手戴金戒指，右手缠黑布
- 不主动搭话，但如果你给他一杯酒，他会说："谢谢你。但等一下，这杯酒可能会让我噎到。"然后他真的噎到了

## 三、完整对话脚本

### 3.0 进入广场时的环境描述

```
【双骰镇中央广场 · 黄昏】

你走进广场时，太阳正卡在两条河之间的峡谷里。

北侧亮得刺眼。十二个人跪成扇形，金色的袍子在暮光中像一团火。
中央高台上站着一个金发女人。她身上挂着数不清的小金铃，
但响声不均匀——有些清脆，有些哑了。
她看着你。那双淡金色的眼睛。像两枚磨损的旧金币。

南侧暗得压抑。九个人站成倒三角，黑色的破袍像裂开的夜空。
中央是一面被砸碎后又拼起来的巨大镜子。
镜子前站着一个高瘦男人。他的左脸有一道伤疤，从左眼下方一直延伸到下巴。
他的右眼是深褐色的，左眼是乳白色的。
镜子里有十几个他，每一个都裂开了。
他也在看着你。那只褐色的右眼。那只失明的左眼。

广场中央，巨大的石骰子被漆成了两半。
上半部分是金色的。下半部分是黑色的。
中间的交界处，灰色的苔藓从裂缝里长出来——
那是这个骰子原本的颜色。

东侧的台阶上，一个没有手指的矮胖男人坐着。
他用脚趾夹着三颗骰子，正在掷。
骰子在石盘上滚动，发出咕噜咕噜的声音。
"来得正好，"他说，没有抬头，"他们吵了七天了。
我建议你选第三个选项：都不选，然后请我喝一杯。"

石骰子的阴影里蹲着一个年轻人。
他左手戴着金戒指，右手缠着黑布。
他咬了一口面包，头顶的石雕突然掉下一小块碎石，
砸在他的肩膀上。
他叹了口气，把面包吃完。
```

### 3.1 接近金骰教团先知塞拉菲娜·金铃

#### 【第一次交互】

```
塞拉菲娜没有动。但她身边的信徒动了——不是站起，是跪得更深。
他们的额头触地，护身符发出碰撞的轻响。

塞拉菲娜："你来了。"
（她的铃铛响了一声，但中间有一个哑了）
塞拉菲娜："我已经。祈求过了。金骰女神。告诉我。今天。会有人来。"
（她微笑，但那笑容只到嘴角，没到眼睛）
塞拉菲娜："你是来。寻求幸运的。还是来。被幸运。寻求的。"
（不等回答，她继续说）
塞拉菲娜："不重要。"
（她走下高台，金铃响，但有几个不响）
塞拉菲娜："重要的是。这个人。站在。光明这边。还是。黑暗那边。"
（她微微侧头，像是在听什么声音——但广场上只有她的铃声和南侧的碎裂声）

塞拉菲娜："金骰教团。在收集。世界上的。不幸。"
（她数着手指，但她的手指在抖）

（她补充）
塞拉菲娜："这。是。慈悲。"
```

## 五、战棋设计（Q201后的第一场战斗）

### 5.1 金骰教团路线 · Q202 祈福远征

- **场地**：16×16 祈福祭坛，中央4×4为"金骰法阵"（我方单位站在上面时，每回合开始时进行一次"幸运掷骰"：1-3无效果，4-5回复5HP，6获得一次额外行动机会）
- **友方**：金骰信徒×4（AI为 `blessed_support`——专注于给友方施加"幸运护盾"）+ 金骰祭司×1（AI为 `fortune_weaver`——每3回合发动一次"厄运转移"，将己方一个单位的负面状态转移给随机敌方）
- **敌方**：碎镜信徒×5 + 碎镜先知护卫×1（高防御，自带"破碎意志"——受到控制效果时反而获得攻击力加成）
- **特殊规则**：
  - "幸运借贷"：我方单位每次触发幸运效果时，战场随机位置生成一个"厄运残留"地形（下回合开始时，站在上面的单位受到3d6真实伤害）
  - "金骰狂热"：我方单位HP高于50%时，攻击有20%概率造成双倍伤害；HP低于50%时，有20%概率攻击落空
  - 碎镜先知护卫的"碎镜反射"：受到远程攻击时，有30%概率将攻击反弹给攻击者

### 5.2 碎镜教团路线 · Q202 裂镜远征

- **场地**：16×16 破碎神庙，全场散布"裂镜碎片"地形（进入时受到2d4切割伤害，但获得"真相之眼"——可以看破隐形单位和陷阱，持续2回合）
- **友方**：碎镜信徒×4（AI为 `mirror_berserker`——HP越低攻击力越高，自带"濒死狂热"）+ 碎镜祭司×1（AI为 `doom_harbinger`——每回合可以选择一名友方单位，使其下一次受到的伤害由祭司代为承受，但祭司承受时伤害翻倍）
- **敌方**：金骰信徒×5 + 金骰先知护卫×1（高闪避，自带"幸运闪避"——每受到3次攻击，自动闪避第4次）
- **特殊规则**：
  - "痛苦转化"：我方单位受到伤害时，获得等量"痛苦值"；消耗10点痛苦值可以发动一次无视防御的攻击
  - "破碎协同"：相邻的碎镜信徒互相分享受到的伤害（各承受50%）
  - 金骰先知护卫的"幸运风暴"：每4回合发动一次，随机赋予敌方单位一个增益或我方单位一个减益——纯粹随机，无法预测

### 5.3 概率行者路线 · Q202 第三方

- **场地**：14×14 三角战场，三个角分别为金骰法阵、碎镜祭坛、中立酒馆（老千维克的酒摊）
- **友方**：自由佣兵×3（玩家控制）+ 双运者×1（AI控制，不可直接指挥，但每回合会根据战场状态自动选择行动——有50%概率帮助玩家，50%概率造成意外的全场效果）
- **敌方**：金骰信徒×3 + 碎镜信徒×3（他们互相也会攻击！）
- **特殊规则**：
  - 三方混战：金骰和碎镜的AI互相也会攻击（优先级：概率行者单位 > 对方阵营 > 同阵营）
  - "概率中立"：玩家单位不受任何基于"幸运/厄运"的状态效果影响，包括地形效果、敌方技能、己方增益
  - 双运者的"祸福相依"：每回合开始时随机触发一个效果——可能是全场友方回复10HP，可能是全场敌方获得一次额外行动，可能是金骰和碎镜的AI暂时联手攻击玩家，可能是石骰子雕塑倒塌砸死随机一个单位（不分敌我）
  - 中立酒馆：占据后老千维克会投掷三颗骰子，根据点数触发不同效果（3-6：全场单位移动力-2；7-10：无事发生；11-14：玩家获得一瓶"概率之酒"，可以在任意时刻重掷一次任何随机判定；15-18：全场单位攻击力翻倍，持续2回合）

## 七、关键设计决策

1. **幸运和厄运不是对立，是同一枚硬币的两面**：塞拉菲娜的"转移不幸"本质上是在制造厄运；莫尔登的"揭示厄运"本质上是在拒绝幸运。他们做的其实是同一件事——把世界分成两半，然后只承认其中一半。

2. **幸运不说"谎"，说"慈悲"**：塞拉菲娜从不使用"掠夺"或"转移"这样的词。她说"收集"、"保护"、"慈悲"。这比直接承认剥削更可怕——她把剥削包装成了拯救。

3. **厄运不说"恨"，说"真相"**：莫尔登也不使用"虐待"或"自残"这样的词。他说"觉醒"、"自由"、"真实"。这比对骂更深刻——他把自我毁灭包装成了诚实。

4. **混血是镜子**：双运者（里奥）是两面信仰的"混血儿"——他的母亲信幸运，父亲信厄运。他是两个女神的战场，正如混血NPC是两个种族的战场。他提示玩家：无论你选哪边，都会有人承受代价。

5. **第三条路不是"更好"的**：概率行者路线不是"正确"答案。它没有教团专属奖励，两边NPC都警惕你。但它提供了唯一的完整视野——你能看到两边的虚妄。

6. **骰子的隐喻**：石骰子上的灰色苔藓、维克手中的空白骰子、里奥左手的金戒指和右手的黑布——它们都是同一个信息：世界不是二元的。幸运和厄运之间，有无限多的灰色地带。而真正的勇气，是承认你不知道下一次掷骰会是什么结果，但仍然愿意掷下去。
