# 《元素水晶共鸣镶嵌》

## 基础信息

- **书籍 ID**：`book_工艺制作_0141`
- **关联技能**：`crafting_elemental_gem_socket`
- **使用效果**：阅读后解锁 `crafting_elemental_gem_socket`；若已学会，提升 `current_mastery +140`，并使下一次镶嵌的元素水晶对应元素伤害 +3。
- **阅读要求**：角色职业标签含 `mage`、`enchanter` 或 `druid`；基础 `智力 ≥ 13`。
- **稀有度**：史诗（Epic）
- **建议投放**：元素高塔、水晶矿脉、元素领主任务奖励。

## 书籍内容

元素水晶共鸣镶嵌是把天然水晶变成武器或护甲能量核心的技术。作者从水晶挑选开始：火水晶内部应有类似熔岩的纹路，冰水晶则要清澈到能看见内部冻结的气泡，雷水晶会在暗处发出微弱噼啪声。书中强调镶嵌前必须先让水晶与装备同温，温差过大会让水晶在第一次受击时开裂。后半本讲解了共鸣槽的切割深度与角度，指出太浅会接触不良，太深则会削弱装备结构。作者还附有一张不同元素水晶与金属亲和度的对照表。书中还提到，水晶镶嵌完成后需要用佩戴者的魔力温养三日，期间水晶可能会出现轻微震动或变色，这是正常现象。他进一步提醒，绝对不能把两种相克元素的水晶镶嵌在同一件装备上，否则它们会在战斗中互相抵消甚至引发爆炸。最后一页写着：水晶是活的，它会选择是否回应你，而不是你单方面使用它。

## 设计意图

为装备系统引入元素水晶镶嵌机制，让玩家根据敌人弱点灵活调整属性，深化Build自定义空间。
