# 《毒素精炼：蛛行麻痹》

- **书籍 ID**：`book_工艺制作_0128`
- **关联技能**：`crafting_spider_venom`

## 书籍内容

蛛行麻痹是一本从巨型蜘蛛毒腺中提取毒素的实操手册。作者从辨认蜘蛛种类开始：黑寡妇的神经毒素、跳蛛的肌肉麻痹液、以及穴居蛛的凝血毒各不相同。书中详细讲解了如何用活捉的蜘蛛获取毒液，并在提取后立即用低温保存以维持活性。作者强调剂量控制：太少无法生效，太多会让目标直接死亡从而暴露行踪。后半本记录了稳定剂的配方，以及如何把液态毒素浓缩成便于涂抹在刀刃上的膏体。作者还提醒，不同种族对毒素的耐受差异很大，对人类有效的剂量对兽人可能毫无作用，因此书中附有一张粗略的种族剂量换算表。他进一步警告，蜘蛛毒液在离开毒腺后十二个时辰内活性最高，超过这个时间即使添加稳定剂也会明显下降。最后一页用黑框标注：不要在自己使用的武器上试毒，即使戴着手套也不行，因为手套上可能有你看不见的细小破口。
