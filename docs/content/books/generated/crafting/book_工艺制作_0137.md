# 《灵魂束缚卷轴》

- **书籍 ID**：`book_工艺制作_0137`
- **关联技能**：`crafting_soul_binding_scroll`

- **阅读要求**：角色职业标签含 `mage`、`warlock` 或 `necromancer`；基础 `智力 ≥ 13`、意志 `≥ 10`。

## 书籍内容

灵魂束缚卷轴是一种将目标精神与施术者意志暂时连接的黑暗技艺。作者从墨水配方开始：除了常规材料，还需要加入受术者的一滴血液或一缕头发作为定向锚点。书中强调绘制束缚符文时必须保持绝对专注，任何杂念都会让卷轴反噬使用者。后半本讲解了如何根据目标意志强度调整符文复杂度，并附有一张“常见反噬症状”表，包括头痛、幻觉与短暂失语。作者警告：束缚不等于奴役，强行控制过强的灵魂会让卷轴在激活时自燃。书中还提到，完成后的卷轴应当用黑曜石匣盛放，避免月光直射，否则束缚的意志可能在夜间自行松动。他进一步提醒，使用灵魂束缚卷轴后，施术者会在梦中隐约感知到被束缚者的情绪，这种状态会持续数日。最后一页写着：当你握住别人的灵魂时，别忘了自己的灵魂也在被别人注视。

## 设计意图

为施法者提供控制型卷轴制作，增加异常状态与召唤体系的深度，同时用风险机制约束滥用。
