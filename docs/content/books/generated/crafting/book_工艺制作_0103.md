# 《草药瓶与止血药膏》

## 基础信息

- **书籍 ID**：`book_工艺制作_0103`
- **关联技能**：`crafting_healing_salve`
- **使用效果**：阅读后解锁 `crafting_healing_salve`；若已学会，提升 `current_mastery +80`，并使下一次制作的药膏治疗效果 +10%。
- **阅读要求**：无职业限制；基础 `智力 ≥ 6`。
- **稀有度**：普通（Common）
- **建议投放**：草药师帐篷、修道院厨房、野外急救箱。

## 书籍内容

止血药膏的配方写在一本被草药汁浸透的小册子里，字迹已经发绿。作者从辨认三种基本草药开始：止血草的锯齿叶、金盏花的皱边花瓣、以及紫云根的块状根茎。书中警告说，紫云根必须晒干后研磨，否则膏体会发黑并刺激皮肤。调配步骤被编成口诀：一煮二滤三收膏，火大则焦，火小则稀。后半部分列举了不同伤口的处理方式：割裂伤先压后敷，刺伤要留孔透气，烧伤忌用油脂。作者特别提醒，盛放药膏的容器最好选用陶罐或竹筒，金属容器容易与草药成分发生反应而降低药效。他还记录了一个战场故事：某次战役中，一位军医因用铁锅熬制药膏，导致整批伤员伤口溃烂，从此全军禁用铁器制药。最后一页贴着一块干涸的药膏样本，旁边写着“这罐救过十七个人，其中包括一个不肯承认自己被砍中的战士”。

## 设计意图

提供战斗外恢复手段的制造入口，让玩家在资源有限时也能自给自足，同时把药剂制作与角色智力属性挂钩。
