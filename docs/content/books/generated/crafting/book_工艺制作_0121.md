# 《铆钉与板甲接合》

## 基础信息

- **书籍 ID**：`book_工艺制作_0121`
- **关联技能**：`crafting_plate_riveting`
- **使用效果**：阅读后解锁 `crafting_plate_riveting`；若已学会，提升 `current_mastery +110`，并使下一次接合的板甲物理减伤 +2%。
- **阅读要求**：角色职业标签含 `warrior` 或 `paladin`；基础 `力量 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：精锐铁匠铺、骑士团军械库、重甲任务奖励。

## 书籍内容

铆钉与板甲接合是重型护甲工艺的进阶门槛。作者从铆钉的选材讲起，指出熟铁铆钉韧性好但强度低，钢铆钉强度高却容易在反复冲击下脆断，真正讲究的板甲会根据受力部位混用两种铆钉。书中详细描述了板材重叠处的处理：重叠太少会撕裂，重叠太多则增重。后半本讲解了胸甲与背甲在肩部的活动接合，强调要在防护与灵活之间取得平衡。作者还附有一张铆钉排列图，标注“肩部用活节、肋部用密排、腰部用疏排”的原则。书中还提到，一位著名骑士的板甲曾在战斗中救下他三次，每次受伤后他都会回到同一位铁匠处修补，因为陌生人无法读懂这件 armor 上每一颗铆钉背后的故事。作者进一步指出，板甲修补时使用的铆钉应当比原铆钉稍软，这样在下次受击时新铆钉会先变形，从而保护周围的板材。最后一页写着：板甲不是一整块铁，而是无数小块铁在正确位置互相支撑的艺术。

## 设计意图

为重甲职业提供高阶护甲制作，强调结构力学与部位差异化设计，提升坦克构筑的深度。
