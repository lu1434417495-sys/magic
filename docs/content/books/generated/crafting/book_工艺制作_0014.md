# 《普通墨水与卷轴》

## 书籍内容

《普通墨水与卷轴》是一本枯燥但极其实用的手册。书中先讲解鞣酸铁墨水的调配：栎五倍子、硫酸亚铁与阿拉伯胶的比例决定墨水的浓淡与防水性。接着介绍羊皮纸与棉浆纸的保存差异，前者耐久但昂贵，后者便宜却怕潮。中段详细说明抄录卷轴时的符文规范，笔画断裂会导致魔力泄漏，字间距不均会让施法延迟。后半本讨论如何用蜡封与丝带固定卷轴，以及如何识别受潮霉斑。最末一页附有一张空白卷轴样品，背面写着"先练一万笔直线，再谈符文之美"。作者在最后几行提醒，抄写卷轴前务必净手并保持案台整洁，一滴普通墨水混入符文墨水中，都可能让整卷法术在激活时产生不可控的偏转。书中还附有一份常见纸张吸墨性测试方法，帮助初学者选择最适合当前墨水的卷轴材质。

## 设计意图

为法师与牧师提供卷轴自给自足的路径，让玩家在法力不足时仍有战术储备。
