# 《鞣革进阶：硬化皮革》

## 基础信息

- **书籍 ID**：`book_工艺制作_0125`
- **关联技能**：`crafting_hardened_leather`
- **使用效果**：阅读后解锁 `crafting_hardened_leather`；若已学会，提升 `current_mastery +110`，并使下一次制作的硬化皮甲物理减伤 +1。
- **阅读要求**：无职业限制；基础 `敏捷 ≥ 9`、力量 `≥ 7`。
- **稀有度**：稀有（Rare）
- **建议投放**：高级猎人营地、皮革大师工坊、野兽狩猎奖励。

## 书籍内容

硬化皮革工艺让柔软的皮料获得接近金属的防护能力，同时保持轻便。作者从选皮开始：牛皮厚实、鹿皮柔韧、犀牛皮自带天然硬度，而龙皮则是传说中的终极材料。书中详细讲解了蜡煮法与树脂浸渍法：前者把皮革浸入熔化的蜂蜡，后者则用稀释的树脂渗透纤维。作者强调温度控制是核心，太高会硬化过度变脆，太低则渗透不均。后半本讲解了硬化后如何塑形：趁皮革温热时固定在模具上，冷却后保持定型。作者还附有一张不同硬化程度的弯折测试标准。书中还提到，硬化皮革的缺点是会随时间慢慢软化，因此需要定期重新浸蜡，一件精心维护的硬化皮甲可以使用数十年。他进一步建议，在关节处保留少量柔软区域，否则穿戴者会在战斗中因无法弯曲而丧失机动性。最后一页写着：硬化皮革的 wearer 应该 forget 自己穿着护甲，而敌人应该 remember 自己打不穿它。

## 设计意图

为轻甲路线提供中期升级选项，让皮甲在防护性能上接近重甲，同时保留敏捷职业的定位优势。
