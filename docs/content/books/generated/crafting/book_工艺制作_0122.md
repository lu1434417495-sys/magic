# 《淬火秘要：刀刃硬化》

## 基础信息

- **书籍 ID**：`book_工艺制作_0122`
- **关联技能**：`crafting_blade_quenching`
- **使用效果**：阅读后解锁 `crafting_blade_quenching`；若已学会，提升 `current_mastery +110`，并使下一次淬火的武器暴击伤害 +3%。
- **阅读要求**：无职业限制；基础 `力量 ≥ 9`、智力 `≥ 7`。

- **建议投放**：矮人锻造坊、火山营地、名师任务奖励。

## 书籍内容

淬火秘要是一本被师傅们反复誊抄的热处理手册。作者认为淬火是锻造中最具欺骗性的步骤：它能让刀刃变硬，也能让刀刃开裂。书中详细记录了不同钢材的临界温度与冷却介质选择，强调油温、水温与盐浴的区别。作者警告：加热不足会导致硬度不均，过热则会让晶粒粗大无法挽救。后半本讲解了回火的重要性，指出淬火后的钢虽然硬却极脆，必须通过适当回火才能用于实战。作者还附有一张根据成品用途调整硬度的对照表。书中还记载了一位刀匠用眼泪淬火的传说，说真正的名刀需要匠人在淬火时投入强烈的情感，但作者本人在旁边批注：emotion 不能替代温度控制。他进一步建议，初学者应当先用废旧刀片练习至少五十次淬火，直到能凭声音判断冷却速度再接触正式材料。最后一页写着：淬火的声音能告诉你一切，安静的是好钢，尖叫的是即将裂开的钢。

## 设计意图

作为武器强化的进阶工艺，让玩家理解热处理对武器性能的决定性作用，为高等级武器打造铺垫。
