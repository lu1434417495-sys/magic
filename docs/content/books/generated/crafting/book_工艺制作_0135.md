# 《强效恢复药剂调和》

## 基础信息

- **书籍 ID**：`book_工艺制作_0135`
- **关联技能**：`crafting_greater_healing_potion`
- **使用效果**：阅读后解锁 `crafting_greater_healing_potion`；若已学会，提升 `current_mastery +140`，并使下一次调制的恢复药剂额外恢复 15% 生命值。
- **阅读要求**：无职业限制；基础 `智力 ≥ 11`、意志 `≥ 9`。
- **稀有度**：史诗（Epic）
- **建议投放**：高阶草药师、教会医院、深渊探索奖励。

## 书籍内容

强效恢复药剂的调和不是简单地把更多草药丢进锅里，而是精确控制每种成分的活性释放时间。作者从高级草药的处理开始：生命之叶需要快速煮沸以保留绿色精华，龙血树脂则要低温长时间萃取。书中强调辅料的重要性：蜂蜜不仅调味，还能稳定药效；少量酒精能加速吸收，但过量会延缓愈合。后半本讲解了如何判断药剂是否“起胶”——一种表示有效成分充分融合的视觉标志。作者还附有一张“常见污染症状”表，包括变色、沉淀与异味。书中还提到，真正的高级恢复药剂在倒入杯中时会形成一层转瞬即逝的彩虹薄膜，这被老炼金术士称为“生命之相”。他进一步警告，如果彩虹薄膜持续超过三息不散，说明药剂过于浓缩，饮用后可能导致心跳过快。最后一页写着：救命的药和害人的药之间，往往只差一滴。

## 设计意图

作为高级恢复道具的制作入口，提升玩家在艰苦战斗中的续航能力，同时保持制作过程的仪式感。
