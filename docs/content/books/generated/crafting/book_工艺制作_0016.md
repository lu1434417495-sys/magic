# 《铁匠炉温度控制》

## 书籍内容

《铁匠炉温度控制》把火候从经验变成可观察的指标。书中介绍如何利用火焰颜色判断炉温：暗红约六百度，橙红约九百度，亮黄则超过一千二。作者详细讲解风门、炉膛高度与燃料堆叠方式对温度分布的影响，强调高温区应集中在工件正下方。中段记录了几种常见燃料的热值对比：木炭稳定、焦煤持久、魔晶残片炽热但难以控制。后半本讨论如何利用余温进行回火，以及如何避免工件因温差过大而开裂。最末一页是一张炉温记录表模板，鼓励读者每次锻造后记录数据，逐渐形成自己的手感。作者最后提醒，频繁开关风门会造成炉温剧烈波动，初学者应养成提前规划加热步骤的习惯，而非临时救火式地调整风量。书中还附有一张常见金属变色温度对照图，方便学徒用肉眼快速判断工件状态。

## 设计意图

把锻造从试错推向可控工艺，为中高级金属加工提供效率提升路径，强化专业工匠的成长感。
