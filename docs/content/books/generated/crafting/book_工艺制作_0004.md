# 《针线裁缝入门》

## 书籍内容

《针线裁缝入门》的封面被咖啡渍染黄，显示出它曾被无数次翻阅。书中从穿针引线开始，逐步讲到锁边、打褶、衬里和滚边。作者强调量体要三次，下剪要一次，因为布料不会原谅鲁莽的裁切。中段用图解展示了七种基础缝法，其中回针法最牢，藏针法最隐蔽，适合法师长袍的表面无缝处理。后半本介绍如何给布甲加衬垫、缝口袋与固定饰品扣。最后一章列出常见织物特性：亚麻透气但易燃，羊毛保暖却吸水，丝绸轻滑却难以上色。书尾附言："缝补不是卑微的工作，它让勇士免于裸露地死去。"作者还强调，缝制深色布料时应在浅色衬纸上打样，否则针脚走向难以辨认，容易在成品上留下歪斜的线条。作者最后提醒，裁布剪刀必须专人专用，若被他人用来剪纸或裁剪硬物，刃口受损后难以恢复锋利。对于初学者，作者建议先用碎布练习直线缝法，直到针脚均匀再动正式材料。

## 设计意图

为布甲职业提供维护与自制装备的能力，让玩家理解布甲不仅是防御，也是施法者的随身仪式场。
