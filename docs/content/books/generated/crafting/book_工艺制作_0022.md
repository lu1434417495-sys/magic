# 《魔法水晶粗切割》

## 基础信息

- **书籍 ID**：`book_工艺制作_0022`
- **关联技能**：`crafting_crystal_cutting`
- **使用效果**：阅读后解锁 `crafting_crystal_cutting`；若已学会，提升该技能 `current_mastery +100`，并减少镶嵌时水晶碎裂概率 15%。
- **阅读要求**：角色职业标签含 `mage` 或 `priest`；已学会 `crafting_alchemy_basic` 或 `crafting_scroll_ink`；基础 `智力 ≥ 7`。
- **稀有度**：精良（Uncommon）
- **建议投放**：魔法学院矿晶系、水晶洞穴营地、元素位面入口。

## 书籍内容

《魔法水晶粗切割》警告读者：水晶不是石头，是凝固的魔力，粗暴对待会释放不稳定能量。书中先教读者辨认解理面，沿解理下刀能事半功倍，逆解理则会让整块水晶粉碎。中段介绍切割工具，铁锯会污染水晶的导魔性，推荐使用铜镶金刚石锯片或超声波切割。后半本讨论如何用细砂研磨与亚麻油抛光，让切面既能聚焦魔力又不易划伤。最末一页是几种基础切型图：圆形、椭圆形与祖母绿形，分别适合法杖、戒指与护符。书页间夹着一片失败品的碎屑，作者标注："这块碎屑曾是一枚戒指，记住它的教训。"书中还强调，切割时双手必须稳定，任何微小抖动都会在水晶内部留下应力线，成为日后施法时爆裂的隐患。作者最后提醒，切割后的水晶碎屑不可随意丢弃，应集中掩埋于远离居住区的地方。

## 设计意图

为法系职业打开魔导器制作分支，让水晶、宝石从原材料变成可加工的施法组件。
