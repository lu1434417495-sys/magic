# 《圣水蒸馏工艺》

## 基础信息

- **书籍 ID**：`book_工艺制作_0039`
- **关联技能**：`crafting_holy_water_distill`
- **使用效果**：阅读后解锁 `crafting_holy_water_distill`；若已学会，提升该技能 `current_mastery +110`，并提高圣水对亡灵与恶魔的伤害 12%。
- **阅读要求**：角色职业标签含 `priest` 或 `warrior`；已学会 `crafting_holy_symbol_casting` 或 `crafting_alchemy_distillation`；基础 `信仰 ≥ 7`。
- **稀有度**：稀有（Rare）
- **建议投放**：大教堂地下室、圣骑士要塞、亡灵地城入口祭坛。

## 书籍内容

《圣水蒸馏工艺》讲述如何把祝福之力融入液体。书中说明圣水的基础是纯净泉水，再经过祈祷、圣盐与少量银叶的仪式化处理。作者强调蒸馏器必须先用圣火净化，否则普通容器会削弱祝福的效力。中段讲解祝福的"保质期"，过度稀释会让圣水退化为普通盐水，而保存得当的圣水在玻璃瓶中可以维持数年。后半本讨论圣水的多种用途：泼洒、涂抹武器、封印不死生物以及制作神圣药膏。最末一页附有一个小型祝福仪式流程，提醒制作者保持心念纯净，因为"不诚的祝福只会烫伤自己的手"。作者最后提醒，蒸馏过程中若发现水体变黑或散发异味，必须立即停止，这通常意味着容器或原料已被不洁之力污染。书中还建议，圣水应储存在避光的圣银瓶中，普通玻璃瓶会让祝福之力在数月内逐渐流失。
