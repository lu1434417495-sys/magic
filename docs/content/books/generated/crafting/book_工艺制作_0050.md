# 《创世熔炉图录》

## 基础信息

- **书籍 ID**：`book_工艺制作_0050`
- **关联技能**：`crafting_primordial_forge_lore`
- **使用效果**：阅读后解锁 `crafting_primordial_forge_lore`；若已学会，提升该技能 `current_mastery +150`，并解锁传说品质装备的自主打造权限。
- **阅读要求**：无职业限制；已学会至少五项高级制作技能；基础 `智力 ≥ 10`、力量 ≥ 9、体质 ≥ 9。
- **稀有度**：传说（Legendary）
- **建议投放**：世界树根系、创世神殿、终极工匠试炼奖励。

## 书籍内容

《创世熔炉图录》不是教人如何做东西，而是教人如何让东西"成为"。书中说明世间万物皆由原始熔炉中流出，最高明的工匠能借来一丝创世之火，让平凡材料获得近乎神性的形态。作者强调传说装备的制作需要三种燃料：珍稀材料、精湛技艺与制作者的一部分自我。缺少任何一样，成品都只会是精良的凡物。中段展示了几件传说中的造物简图，每件旁边都标注了制作者付出的代价。后半本讨论失败的风险，强行打造传说装备会反噬制作者的生命力与记忆。最末一页空白，只留一行烫金小字："你准备好，成为器物故事的一部分了吗？"作者最后提醒，传说装备在完成后会自行选择主人，若制作者心术不正，器物宁可自毁也不会为其效力。书中还提到，每一次使用传说装备都会消耗持有者的部分意志，因此真正的强者才能长期驾驭它们。

## 设计意图

作为工艺制作系列的巅峰之书，为玩家提供终极目标与成就，让传说装备不再是随机掉落，而是工匠修行的终点。
