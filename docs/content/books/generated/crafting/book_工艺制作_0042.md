# 《魔力回路蚀刻》

## 基础信息

- **书籍 ID**：`book_工艺制作_0042`
- **关联技能**：`crafting_mana_circuit_etch`
- **使用效果**：阅读后解锁 `crafting_mana_circuit_etch`；若已学会，提升该技能 `current_mastery +120`，并提高魔导器上附加法术的触发概率 5%。
- **阅读要求**：角色职业标签含 `mage`；已学会 `crafting_rune_engraving_basic` 或 `crafting_crystal_cutting`；基础 `智力 ≥ 9`。
- **稀有度**：史诗（Epic）
- **建议投放**：古代魔导工坊、浮空城遗迹、大法师私人藏书室。

## 书籍内容

《魔力回路蚀刻》把装备变成法术的载体。书中说明魔力回路不是装饰，而是让法术在器物内部循环不息的通道。作者强调回路的连续性，任何断裂都会让魔力泄漏，严重时引发爆炸。中段介绍蚀刻介质，酸蚀适合金属，激光蚀刻适合水晶，而生物材料则需要用活体菌丝引导。后半本讨论回路与触发器的关系，储能节点决定能释放几次，触发节点决定响应条件。最末一页展示了一个典型的"冰霜护甲"回路图，从魔力输入到护盾输出，共十七条细线交织成雪花形状。书尾警告："蚀刻前先画十遍，因为修正比重刻更痛苦。"作者最后提醒，蚀刻完成后必须用探针逐段检测导通性，肉眼看不见的微裂纹是魔导器最危险的隐患。书中还提到，回路蚀刻最好在无风无尘的环境中进行，一粒灰尘落入沟槽都会让魔力在某处形成湍流。

## 设计意图

为高端法系装备提供核心制作工艺，让法术触发类装备成为后期 Build 的重要组成部分。
