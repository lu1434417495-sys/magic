# 《贤者之石残篇》

## 基础信息

- **书籍 ID**：`book_工艺制作_0146`
- **关联技能**：`crafting_philosopher_stone_fragment`
- **使用效果**：阅读后解锁 `crafting_philosopher_stone_fragment`；若已学会，提升 `current_mastery +170`，并使下一次炼制的贤者之石残片在制作时返还 25% 材料。
- **阅读要求**：角色职业标签含 `mage` 或 `alchemist`；基础 `智力 ≥ 15`、意志 `≥ 12`。
- **稀有度**：传说（Legendary）
- **建议投放**：世界尽头遗迹、贤者密室、终极炼金任务奖励。

## 书籍内容

贤者之石残篇是一本不完整的手稿，据说完整版能让人点石成金、逆转生死。残篇中记录的是一种不稳定的小块贤者之石制作方法：将七种金属在特定星相下熔合，并加入施术者的一缕头发作为催化剂。作者反复强调这种碎片只能使用一次，之后就会裂成普通矿石。书中详细描述了炼成阵的绘制：圆环代表循环，三角代表转化，中心的眼睛图案则是用来“注视”物质变化的象征。后半本记录了十九次失败实验，其中三次引发了小型爆炸，一次让实验室里的所有金属生锈。书中还提到，贤者之石碎片在碎裂时会发出类似叹息的声音，老炼金术士认为这是被转化的物质在表达不舍。他进一步警告，炼制过程中若听到金属发出呜咽般的低鸣，必须立刻停止加热，否则炼成阵可能会反噬制作者的记忆。最后一页只写了一句话：完整版的代价不是材料，而是你愿意放弃什么。

## 设计意图

作为炼金路线的传说级目标，提供一次性但强力的材料返还效果，同时用“残篇”设定暗示更高级的终极工艺存在。
