# 《盾牌包边与握把加固》

## 基础信息

- **书籍 ID**：`book_工艺制作_0115`
- **关联技能**：`crafting_shield_reinforce`
- **使用效果**：阅读后解锁 `crafting_shield_reinforce`；若已学会，提升 `current_mastery +80`，并使下一次加固的盾牌格挡值 +1。
- **阅读要求**：角色职业标签含 `warrior` 或 `paladin`；基础 `力量 ≥ 7`。

- **建议投放**：军营铁匠铺、盾卫训练营、防御任务奖励。

## 书籍内容

盾牌包边与握把加固是前线战士的实用手册。作者指出，大多数盾牌不是被正面击碎，而是从边缘开始开裂，所以包边是延长寿命的关键。书中详细介绍了如何用熟铁条沿盾缘箍紧，并用铆钉固定，同时注意不要过度增重导致举盾迟缓。握把章节强调绑带的位置必须贴合前臂，太松会转动，太紧会在受击时勒伤肌肉。后半本讲解了不同盾型的包边差异：圆盾需要连续箍圈，塔盾则要在四角加强。作者还建议在盾面内侧贴一层软布，既能吸汗防滑，又能在长途行军时减少手臂磨损。他进一步提醒，握把的固定点应当略低于盾牌重心，这样在举盾时才能用最省力的姿势保持平衡。更换握把时，旧握把留下的压痕位置是新握把最佳的安装参考。最后一页写着：盾牌是你与死亡之间的最后一道墙，而握把是这道墙与你手臂之间的唯一连接。
