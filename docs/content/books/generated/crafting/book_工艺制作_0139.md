# 《圣水蒸馏与祝福仪式》

## 基础信息

- **书籍 ID**：`book_工艺制作_0139`
- **关联技能**：`crafting_blessed_water`
- **使用效果**：阅读后解锁 `crafting_blessed_water`；若已学会，提升 `current_mastery +140`，并使下一次蒸馏的圣水对亡灵伤害 +5。
- **阅读要求**：角色职业标签含 `priest`、`cleric` 或 `paladin`；基础 `意志 ≥ 12`。
- **稀有度**：史诗（Epic）
- **建议投放**：大教堂地下室、神圣泉眼、驱魔任务奖励。

## 书籍内容

圣水蒸馏与祝福仪式是一门把信仰转化为可携带力量的工艺。作者从水源选择开始：山泉代表洁净，雨水代表天恩，而被祝福过的井水则最为常用。书中详细讲解了蒸馏装置的清洁要求，任何残留都会污染圣水的效力。祝福仪式部分强调施术者的心境比祷词本身更重要，怀疑会让圣水失去光泽，虔诚则能让普通的水发出微弱的银光。后半本讲解了圣水的保存方式：银瓶最佳，玻璃瓶次之，绝对不能用铁器盛装。书中还提到，圣水在对抗强大亡灵时可能会沸腾甚至汽化，这是正常现象，说明两种力量正在激烈交锋。作者进一步建议，在月蚀之夜制作的圣水效力最强，但也最容易吸引不洁之物的注意，因此制作时必须有人在门外守护。最后一页写着：圣水之所以有效，不是因为水本身，而是因为承载水的人愿意相信光明。

## 设计意图

为牧师系职业提供针对性伤害道具制作，让信仰资源可以通过工艺转化为实际战斗力。
