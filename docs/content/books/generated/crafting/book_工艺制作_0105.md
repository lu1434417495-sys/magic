# 《磨刀石与刃口保养》

## 基础信息

- **书籍 ID**：`book_工艺制作_0105`
- **关联技能**：`crafting_blade_honing`
- **使用效果**：阅读后解锁 `crafting_blade_honing`；若已学会，提升 `current_mastery +80`，并使你下一次磨刀获得的伤害加成额外 +1。
- **阅读要求**：无职业限制；基础 `敏捷 ≥ 5`、力量 `≥ 5`。
- **稀有度**：普通（Common）
- **建议投放**：军营磨刀摊、铁匠铺柜台、新手任务奖励。

## 书籍内容

磨刀石与刃口保养是战士们最爱携带的小册子，因为它比任何盔甲都更能保住性命。作者从区分粗磨石与细磨石开始，强调磨刀时要保持固定角度，像拉大提琴弓一样匀速拉动。书中警告最常见的错误：用力按压以为能更快出锋，其实只会把刃口磨成圆角。后半部分教人如何用皮带和研磨膏做最后抛光，并判断刀刃是否出现“卷刃”或“崩口”。作者还画了一幅示意图，标注不同武器的最佳刃角：短剑三十度、战斧二十五度、匕首二十度。书中还记录了作者的一位老战友如何在战前夜把全家传的佩刀磨到能切断飘落的头发，却在冲锋时因刃口过薄而折断。作者由此得出结论：锋利与脆弱往往只有一线之隔。最后一页写着：锋利的刀不会卡在骨头里，卡在骨头里的刀会让你的手在关键时刻滑开。

## 设计意图

作为近战武器的日常维护技能，让玩家在战斗间隙通过制作行为提升战斗力，强化战前准备的仪式感。
