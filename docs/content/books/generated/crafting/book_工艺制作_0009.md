# 《绳索编织与保养》

## 基础信息

- **书籍 ID**：`book_工艺制作_0009`
- **关联技能**：`crafting_rope_weaving`
- **使用效果**：阅读后解锁 `crafting_rope_weaving`；若已学会，提升该技能 `current_mastery +80`，并提高绳网、套索类道具的捕获成功率 10%。

## 书籍内容

《绳索编织与保养》声称一根好绳能救人也能杀人。书中先教读者将麻纤维捻成股，再把三股反向搓成绳，强调张力均匀才能避免使用中突然断裂。中段收录十几种实用绳结：称人结承重、八字结防脱、活结方便快速释放。后半本讨论绳索的保养禁忌，潮湿会让麻绳腐烂，暴晒会让纤维脆化，因此绳子不用时应悬挂在阴凉通风处。最末一页画着一个简易绳梯与一副猎网，说明绳索不只是攀爬工具，也能成为陷阱核心。书页间夹着一小段旧绳，作者让读者亲手感受纤维老化程度，以判断何时该更换。作者最后提醒，编绳时双手用力必须均匀，一段紧一段松的绳索在承重时会从薄弱处突然崩解，造成不可挽回的事故。书中还附有一张绳网网眼尺寸图，说明网眼过大猎物易脱逃，过小则会增加重量。

## 设计意图

为盗贼、游侠与探险类角色提供通用工具制作能力，增强野外探索与陷阱布置的战术深度。
