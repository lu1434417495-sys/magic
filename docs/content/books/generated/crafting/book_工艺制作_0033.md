# 《治疗药膏制作》

## 基础信息

- **书籍 ID**：`book_工艺制作_0033`
- **关联技能**：`crafting_healing_salve`
- **使用效果**：阅读后解锁 `crafting_healing_salve`；若已学会，提升该技能 `current_mastery +110`，并提高治疗药膏的即时恢复量 10%。
- **阅读要求**：无职业限制；已学会 `crafting_herb_grinding` 或 `crafting_alchemy_distillation`；基础 `智力 ≥ 7`。
- **稀有度**：稀有（Rare）
- **建议投放**：神庙医务室、战地医院、高级炼金商。

## 书籍内容

《治疗药膏制作》专注于战场急救而非长生不老。书中说明好药膏需要同时满足止血、消炎与促进愈合三个目标。作者推荐以蜂蜡与猪油为基质，加入金盏花、紫草与少量蜂蜜，既能覆盖伤口又能缓慢释放药效。中段讲解乳化技巧，油相与水相必须借助少量蜂蜡与不停搅拌才能稳定融合，否则会分层失效。后半本讨论包扎前的清创与药膏厚度，过厚会阻碍透气，过薄则药效不持久。最末一页附有不同伤口的处理建议，以及一份保质期判断表。书尾写道："好药膏让战士第二天还能站起来，伟大药膏让他忘了昨天流过血。"作者还提醒，盛装药膏的容器必须彻底消毒，任何残留的杂质都可能让伤口感染，使原本有效的药剂反而成为祸根。书中最后建议，药膏应存放在阴凉处，阳光直射会让其中的蜂蜜发酵变质。

## 设计意图

强化战斗外恢复手段，让玩家在战前准备阶段就能生产关键耗材，降低对牧师治疗的绝对依赖。
