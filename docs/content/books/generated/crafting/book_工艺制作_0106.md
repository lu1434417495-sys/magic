# 《锁甲环扣编织法》

## 基础信息

- **书籍 ID**：`book_工艺制作_0106`

## 书籍内容

锁甲编织是一本需要双手配合才能读懂的书，因为每一页都配有小环扣的穿插图。作者把锁甲称为“铁的织物”，强调环扣的开口方向必须一致，否则受力时会像拉链一样崩开。书中从四合一编法开始教起，逐步过渡到六合一与八合一的密织法。作者提醒：每完成一片就要用锤子轻轻敲平，让环扣咬合更紧。后半本讲解如何根据穿着者的体型调整胸围与肩部弧度，并附有一张“环扣数量速查表”。作者还建议在编织前先用绳索制作一个等比例小样，以避免正式编到一半发现尺寸错误而全部返工。他补充说，有经验的织甲师能通过掂量一小片锁甲的重量判断整体成品的防护等级。初学者往往低估了这项工作所需的时间，一件胸甲通常需要数百小时才能完成。最后一页贴着一小段锈迹斑斑的锁甲残片，旁边写着“这件锁甲挡住了三箭， wearer 只受了淤伤”。

## 设计意图

提供中等护甲的制作路径，介于皮甲与板甲之间，强调体力劳动与精细编织的结合，适合战士与牧师早期过渡。
