# 《箭羽粘合与箭杆校直》

## 基础信息

- **书籍 ID**：`book_工艺制作_0104`
- **关联技能**：`crafting_arrow_fletching`
- **使用效果**：阅读后解锁 `crafting_arrow_fletching`；若已学会，提升 `current_mastery +80`，并使下一次制作的箭矢射程 +1 格。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；基础 `敏捷 ≥ 6`。
- **稀有度**：普通（Common）

## 书籍内容

这是一本被箭油浸透的薄册，专门讲解如何让一支箭飞得又直又远。作者认为箭杆比箭头更重要，因为弯曲的箭杆会让最好的箭头也偏离目标。书中详细介绍了用火烤法校正箭杆：将木杆在炭火上缓慢转动，眼睛对准光源观察弯曲处，然后用手腕施加恰到好处的力。箭羽部分则强调三只羽毛的重量必须一致，粘合时胶量不能渗入羽根。后半本记录了不同风向下的羽毛角度调整，并附有一张“羽毛螺旋度对照表”。作者还在空白处补充道，优质箭杆应当产自向阳山坡生长的白蜡木或紫杉木，阴湿处的木材容易藏着看不见的虫眼。他进一步说明，同一棵树朝南面的枝条比朝北面的更致密，是制作箭杆的首选材料。最后一页用红笔写着：每支箭都要命名，这样射失后你才能知道是哪一步做错了。
