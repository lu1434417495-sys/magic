# 《大音希声章》

## 书籍内容

大音希声章认为最大的声音是听不见的，因为它不是振动空气，而是直接作用于意识。练习者需在完全寂静中等待一种并非来自耳膜的聆听，作者称之为心耳。书中说，当练习者能用心耳听见他人的杀意、恐惧或谎言时，沉默便不再是空白，而是一种可以施加的压力。作者记载，有人修炼此术后能在敌人施法前让其陷入短暂失语，因为对方的咒语还未来得及成形，就被更响亮的寂静震碎了。书末有一页乐谱，上面没有任何音符，只在标题处写着：此处应有大音。真正的沉默能让最喧嚣的咒语自惭形秽。控制型法师精通此章后，其沉默效果会多延续一个回合，因为被施加沉默的敌人尚未从那份沉重的寂静中恢复过来，仍在下意识地寻找已经不存在的声音，这一回合的延宕常常能打乱整个敌阵的节奏。

## 设计意图

为控制型法师提供沉默强化，把老子的大音希声转化为战棋中的控制时长增益，拓展冥想战斗维度。
