# 《道法自然诀》

## 基础信息

- **书籍 ID**：`book_meditation_0149`
- **关联技能**：`meditation_tao_nature`（待新增，标签 `meditation`）
- **使用效果**：阅读后解锁冥想技能 `meditation_tao_nature`（`practice_tier = legendary`）；若已学会，提升 `current_mastery +200`，并根据当前战场环境自动获得一项小型 MP 或伤害增益。
- **阅读要求**：无职业限制；已掌握至少五种冥想技能；基础 `智力 ≥ 15` 且 `意志 ≥ 15`。
- **稀有度**：传说（Legendary）
- **建议投放**：自然神殿、终焉图书馆、世界树遗迹。

## 书籍内容

道法自然诀主张人法地、地法天、天法道、道法自然，最高的修行是让行为与所处环境完全合拍。练习者需在冥想中打开全部感官，感受风、湿度、温度、地磁的细微差异，然后让自己的魔力循环与这些自然节律同步。书中说，任何强行施法都是对自然的冒犯，而顺应自然的法术几乎不需要额外消耗。最高境界者会根据战场环境自动获得增益：雨中回复更快，烈日下伤害更高，风中射程更远。书末有一片随风飘落的树叶标本，题词：道法自然，不是模仿自然，而是让自己成为自然愿意借用的那部分。修习此诀的法师，每到一处新战场，都会感到环境本身在悄悄调整他的魔力流动，带来意想不到的小幅强化，仿佛天地也在替他选择最合适的战术，让每一次出手都事半功倍。修习道法自然诀的人，最终会成为环境的一部分，而不是环境的对抗者。

## 设计意图

作为环境响应型传说冥想，为全环境 build 提供自适应增益，鼓励玩家关注战场场景与生态。
