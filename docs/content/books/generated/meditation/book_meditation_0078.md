# 《负重羽化诀》

## 基础信息

- **书籍 ID**：`book_meditation_0078`
- **关联技能**：`meditation_weighted_ascension`（待新增，标签 `meditation`）
- **使用效果**：阅读后解锁冥想技能 `meditation_weighted_ascension`（`practice_tier = master`）；若已学会，提升 `current_mastery +180`，并在下次战斗中使负重状态下的移动速度惩罚降低 20%。
- **阅读要求**：无职业限制；已掌握至少两种冥想技能；基础 `体质 ≥ 13` 或 `意志 ≥ 13`。

- **建议投放**：苦修者修道院、高山朝圣路、重甲骑士训练营。

## 书籍内容

负重羽化诀认为，轻盈不是来自卸下重担，而是来自学会与重担一起呼吸。书中要求练习者背负重物冥想，从一块石头开始，逐渐增加到与自己体重相当的沙袋。前半本教授如何把重量分布到全身，而不是让某个关节独自承担。后半本则讲述‘羽化’的悖论：当身体完全接受重量时，意识会感到一种奇异的上升感，仿佛灵魂正在摆脱地心引力。书中夹着一根折断的扁担，批注写道：‘它断在我终于不再抱怨重量的那天。’作者警告，有脊柱或关节疾病的人不应尝试实物负重，可以用想象代替。苦修者修道院的台阶上常年有背着石块上下行走的人，他们说每上一级，羽毛就轻一分。朝圣路的终点有一块石碑，刻着：‘负担即翅膀。’许多骑士在此碑前落泪，因为他们终于理解了铠甲的重量。朝圣归来的骑士们说，铠甲从此不再压迫他们的梦。

## 设计意图

把负重与机动性结合，为重甲、重武器施法者提供独特的战斗机动优势，拓展冥想系统的职业兼容性。
