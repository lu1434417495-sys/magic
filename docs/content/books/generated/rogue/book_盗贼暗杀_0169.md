# 《神经毒素学：延迟死亡的配方》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0169`
- **关联技能**：`rogue_nerve_toxin`
- **使用效果**：阅读后解锁 `rogue_nerve_toxin`；若已学会，提升 `current_mastery +150`，并使中毒敌人在死亡前传播毒素给邻近敌人的概率 `+12%`。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `智力 ≥ 12`；已学会 `rogue_poison_resistance`。
- **稀有度**：史诗（Epic）
- **建议投放**：毒龙巢穴遗迹、黑市剧毒商人、大师级毒理任务奖励。

## 书籍内容

神经毒素不是为了立刻杀死目标，而是为了在目标仍站立时接管他的身体，这种技术被称为「活尸术」的前身。这本书深入讲解了几种作用于神经传导的剧毒：如何让手指失去握力、如何让眼皮无法睁开、如何让呼吸变成需要思考的事情。作者强调配方必须精确，剂量稍多会提前致死，失去战略价值；稍少则会让目标有机会呼救。中间章节教授从动植物中提取毒素的方法，以及如何用载体延迟发作时间。作者强调，神经毒素的解药往往与毒物同源，因此毒师必须先让自己中毒再解毒。后半本转入应用场景：在宴会酒水中下毒、涂在门把手上、混入书信封口。末页用暗色墨水写着：最好的神经毒素不会让目标倒下，会让他带着微笑走进棺材。书页散发着淡淡的杏仁苦味。作者警告，调配时任何一步顺序错误都会让整锅毒液瞬间汽化。

## 设计意图

为高阶毒系盗贼提供控制与扩散型毒素，强化群体削弱与社交暗杀。
