# 《毒抗训练：以毒攻毒》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0123`
- **关联技能**：`rogue_poison_resist`
- **使用效果**：阅读后解锁 `rogue_poison_resist`；若已学会，提升 `current_mastery +110`，并使中毒后的伤害减免 +5%。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `体质 ≥ 10`。
- **稀有度**：精良（Uncommon）
- **建议投放**：毒沼炼金师、刺客公会医疗室、邪教祭坛。

## 书籍内容

用毒者必须先学会不被毒死。这本书记录了一套循序渐进的毒抗训练：从微量麻痹草开始，逐步增加剂量与种类，让身体学会在毒素入侵时保持基本机能。作者警告，这种方法会缩短寿命，因此只适合那些已经把命抵押给任务的人。书中详细讲解了不同毒素的症状与紧急处理：神经毒会让手指发麻，血液毒会让呼吸急促，腐蚀毒则会让伤口溃烂。中间章节还讨论了心理耐受：许多中毒者死于恐慌而非毒素本身。末页贴着一张训练计划表，从第一天到第三百天，剂量逐渐增加，旁边用红笔写着：能活下来不是胜利，是资格。

书脊处有褐色污渍，疑似反复接触药草后留下的痕迹；末页贴着一张训练计划表，从第一天到第三百天逐渐增加剂量，旁边标注着几位前辈的死因。封底画着一个正在颤抖的人体轮廓，旁边写着：毒抗训练的第一步是学会不怕抖。

## 设计意图

为盗贼系提供防御向被动技能，降低用毒玩法的自我风险，鼓励毒药构筑。
