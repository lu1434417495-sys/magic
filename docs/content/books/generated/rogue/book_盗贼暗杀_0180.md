# 《刺客的临终一课：如何死去》

## 书籍内容

一个刺客可以决定何时杀人，但更应该决定何时死去，这本书的每一章都以一位著名刺客的死亡案例开头。这本书不讲逃生，而讲如何在无法逃脱时把死亡变成最后的武器。作者认为，刺客的遗体不应泄露情报，因此书中教授多种自我终结的方法，以及如何在最后一刻摧毁身上的密信、毒药和身份证明。中间章节讲解如何利用自己的死亡为同伴创造机会：引爆炸药、触发机关、或者仅仅是用身体堵住一扇门。作者写道，刺客的死亡应当像他的刀一样：精准、安静、不留下多余的痕迹。后半本转入心理准备：如何在接受死亡后保持平静，因为慌乱会让最后的牺牲失去价值。末页用稳重的笔迹写着：最好的刺客不是活着离开的人，是让自己的死值得的人。书脊上刻着一行小字：为了同伴。作者认为，一个刺客若从未考虑过死亡，就不配谈论生存。
