# 《盗火者：窃取敌人的增益》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0174`
- **关联技能**：`rogue_buff_steal`
- **使用效果**：阅读后解锁 `rogue_buff_steal`；若已学会，提升 `current_mastery +130`，并使成功窃取时自身获得该增益 `50%` 持续时间。
- **阅读要求**：角色职业标签含 `rogue`；基础 `敏捷 ≥ 13` 且 `智力 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：灰烬交界遗迹、叛逆法师藏身处、高阶盗贼挑战奖励。

## 书籍内容

敌人的力量不一定是用来摧毁的，有时候是用来借用的，这本书的作者据说曾从一位大法师身上偷走了三天的护盾。这本书教授如何在近身接触时抽取对方身上的魔法增益、斗气加持或药剂效果。作者把窃取比作拔河：你必须找到对方能量流转的节点，在那一瞬间把自己的空容器贴上去。中间章节讲解不同能量类型的触感：火焰像灼热的沙、冰霜像黏腻的油、神圣能量会灼烧不义之手。作者警告，窃取神圣增益时若心术不正，会遭受比敌人攻击更严重的反噬。后半本转入应用：窃取后何时立刻使用、何时保存、何时反手还给敌人制造混乱。末页用烧焦的字体写着：火从你身上夺走，我也能把它偷回来。封面被火焰燎过，留下不规则的黑色边界。作者提醒，窃取来的增益若与原主产生共鸣，会暴露自己的位置。

## 设计意图

为盗贼系提供资源逆转与反制能力，针对依赖增益的敌人有战略价值。
