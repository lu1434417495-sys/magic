# 《陷阱：别人踩过的路》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0132`
- **关联技能**：`rogue_trap_setting`
- **使用效果**：阅读后解锁 `rogue_trap_setting`；若已学会，提升 `current_mastery +110`，并使陷阱触发后的伤害 +5%。
- **阅读要求**：角色职业标签含 `rogue` 或 `ranger`；基础 `智力 ≥ 9`。
- **稀有度**：精良（Uncommon）
- **建议投放**：猎人营地、军事废墟、边境哨所。

## 书籍内容

最好的陷阱不是隐藏得多好，而是让猎物自愿走上去。这本书从心理学角度设计陷阱：人在追逐时会忽略脚下的细节，在黑暗中会贴墙行走，在疲惫时会选择最短路径。作者教人如何利用这些本能布置绊索、陷坑与落石。中间章节详细讲解了几种经典机关的构造：翻板、套索、压发弩与毒刺，每一种都配有材料清单与组装步骤。书中还强调伪装的重要性：陷阱周围的环境必须比陷阱本身更自然，一片刻意清理过的地面反而会引起怀疑。末页画着一只踩中套索的兔子，旁边写着：猎人不追猎物，猎人只是让猎物追向自己。

书中夹着几根细线，是某位前辈留下的绊索样品；封底画着一个简笔小人，正踩中翻板向下坠落，旁边标注着"早了""晚了""对了"三种结局。某页边缘有人用红笔画着一只被绊索套住的兔子，旁边写着"这是陷阱的艺术"。

## 设计意图

为盗贼系提供环境控制与预判技能，强化撤退路线与伏击点的战术价值。
