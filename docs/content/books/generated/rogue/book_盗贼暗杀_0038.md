# 《刺客的早餐：毒与日常》

## 书籍内容

这本书把下毒还原为最日常的行为：早餐、酒水、药汤。作者认为，最不容易被察觉的毒剂不是涂在武器上的，而是混在目标每天都会摄入的东西里。书中详细讲解了不同食物对毒剂效果的掩盖与加速作用：油脂会延缓吸收，酸性液体会加速发作，高温则可能破坏某些植物毒素。中间章节是一本伪装食谱，教导如何把毒剂做成与常见调味品相似的气味与色泽。后半本转入风险评估：如何在目标周围人也会食用的食物中精确下毒，以及如何利用侍者或厨师作为不知情的中介。末页有一段被划掉的家族菜谱，下面用另一种笔迹补充：最好的毒宴，是连下毒者自己都愿意吃一口的菜。

附录是家常毒宴食材搭配表，列哪些菜肴最易掩盖毒剂气味。表末写着：宴会下毒者最大风险，是自己也忘了哪一杯干净。

## 设计意图
