# 《假面：易容入门》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0107`
- **关联技能**：`rogue_disguise`
- **使用效果**：阅读后解锁 `rogue_disguise`；若已学会，提升 `current_mastery +110`，并延长伪装持续时间 15%。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `魅力 ≥ 9` 或 `智力 ≥ 9`。
- **稀有度**：稀有（Rare）
- **建议投放**：剧团后台、密探训练营、贵族化妆间。

## 书籍内容

易容不是变成另一个人，而是让别人愿意把你当成另一个人。作者从戏剧化妆术中偷来了底色、阴影与轮廓，却把舞台效果反着用：不是突出特征，而是抹除特征。书中强调，最成功的伪装是让旁观者事后无法准确描述你。中间章节讲解如何扮演身份：士兵要站姿僵硬，仆人要目光低垂，商人要计算对方口袋里有多少钱。作者还提醒，伪装最怕的是习惯动作，比如挠鼻子、握拳的方式、走路时先迈哪只脚。末页贴着一张空白面具，面具背面写着：你戴上面具不是为了 hiding，而是为了让你真正的脸成为另一张面具。

书中夹着半张面具模具，边缘还沾着干涸的石膏；末页有十几个不同身份的名字，每个都被划掉又重新写了一遍，仿佛作者在选择下一个扮演的自己。封面被人用利器刻了一个面具轮廓，轮廓内的五官每天都会被重新划伤一次。

## 设计意图

为盗贼系提供社交渗透技能，把伪装从单纯外观判定扩展为行为模仿与身份扮演。
