# 《伪装死亡：闭气与诈尸》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0135`
- **关联技能**：`rogue_play_dead`
- **使用效果**：阅读后解锁 `rogue_play_dead`；若已学会，提升 `current_mastery +100`，并使诈死状态下的生命恢复速度 +10%。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `体质 ≥ 9` 或 `意志 ≥ 9`。
- **稀有度**：稀有（Rare）
- **建议投放**：殡仪馆密室、战地医院、刺客公会逃生课程。

## 书籍内容

死亡是最好的隐身术，前提是你能 convincing 地演好它。这本书教人如何通过控制呼吸、心跳与肌肉松弛来伪装死亡：先用腹式呼吸把胸腔起伏降到最低，再放松面部与四肢，最后让目光涣散。作者指出，最难骗过的是经验丰富的杀手，他们会检查瞳孔、脉搏与体温，因此书中还教授了几种伪造这些指标的方法。中间章节讲解了最佳诈死时机：在敌人以为已经获胜、注意力最松懈的瞬间。末页贴着一张褪色的死亡证明，姓名处被墨水涂黑，旁边写着：装死不是耻辱，耻辱是装死后真的死去。

末页贴着一张真正的死亡证明残片，姓名处已被烧毁；书页边缘有淡淡的药草味，可能是伪装时使用的材料残留，也可能是作者本人最后的呼吸。空白处有人用铅笔反复画着闭气时的胸腔剖面图，直到纸张被擦破。

## 设计意图

为盗贼系提供极端逃生技能，把诈死从剧情选项转化为可主动触发的战斗机制。
