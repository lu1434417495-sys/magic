# 《割包术：人群中取物的毫秒》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0152`
- **关联技能**：`rogue_cutpurse`
- **使用效果**：阅读后解锁 `rogue_cutpurse`；若已学会，提升 `current_mastery +100`，并在人多的场景下首次偷窃成功率 `+10%`。
- **阅读要求**：角色职业标签含 `rogue`；基础 `敏捷 ≥ 8`。

## 书籍内容

这本书最早出现在港口城市的跳蚤市场，据说作者是一名从未被抓获的码头窃贼。割包术不是关于手快，而是关于手在正确的时间消失。作者指出，人群中真正的掩护不是拥挤本身，而是注意力的节律：叫卖声、推车颠簸、路人的肩膀碰撞，都是可以被借用的节拍。书中把一次成功的割包拆成零点几秒的瞬间：靠近、遮挡、接触、撤离，每一个环节都必须在目标眨眼前完成。中间章节讲解如何用空手的动作吸引注意，让另一只手完成真正的工作，例如假装跌倒或指向某个方向。后半本则教授失败后的应对：如何把赃物瞬间转交，如何在第一时间让目标怀疑旁边的人，以及如何在卫兵赶到前把赃物藏进预先安排的暗格。末页有一行被反复描粗的警告：永远不要在同一条街练习两次。封皮内侧画着一只手的轮廓，指尖指向街道。

## 设计意图

服务于盗贼系早期经济获取与城镇互动，成功率加成让新手更容易体会潜行窃贼的爽快感。
