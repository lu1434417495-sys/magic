# 《听风：脚步预判》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0110`
- **关联技能**：`rogue_sound_reading`
- **使用效果**：阅读后解锁 `rogue_sound_reading`；若已学会，提升 `current_mastery +100`，并使对移动中敌人的首次反击伤害 +6%。
- **阅读要求**：角色职业标签含 `rogue`；基础 `感知 ≥ 10`。
- **稀有度**：精良（Uncommon）
- **建议投放**：盲眼导师居所、盗贼公会密室、废弃钟楼。

## 书籍内容

眼睛会骗人，但脚步很少撒谎。这本书要求练习者蒙眼行走，通过鞋底与地面的接触声判断材质、坡度与附近障碍。作者把敌人的脚步分为重步、碎步、拖步、踮步四种，每一种都对应不同的心理状态：重步是自信或愤怒，碎步是紧张或试探，拖步是疲惫或伪装，踮步则是猎手。书中还讲解了如何利用回声定位走廊拐角后的目标，以及如何通过呼吸声判断对方是否发现了你。末页只有一行大字：听到对方脚步变轻的时候，说明他也开始听你。

空白页画着一只巨大的耳朵，耳廓内标注着不同脚步的振动频率；书脊中夹着一根细线，据说曾用来测试听力灵敏度，线头已经磨损得发亮。封底粘着一小片干涸的蜡，像是某位读者曾经把耳朵贴在上面练习听声辨位。书中还讨论了如何在移动中保持听感专注，这是大多数练习者最容易在实战中丢失的能力。

## 设计意图

为盗贼系提供感知向技能，把听觉信息转化为战斗先机，强化埋伏与反击玩法。
