# 《绳艺：束缚与攀爬》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0111`
- **关联技能**：`rogue_rope_work`
- **使用效果**：阅读后解锁 `rogue_rope_work`；若已学会，提升 `current_mastery +90`，并使绳索陷阱的束缚时间延长 0.5 秒。
- **阅读要求**：角色职业标签含 `rogue` 或 `ranger`；基础 `敏捷 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：码头工会、游侠营地、废弃剧院道具间。

## 书籍内容

绳子是盗贼最古老的朋友之一，能救人也能绑人。这本书从打结开始讲起，介绍了八字结、称人结、活套结与滑结在不同场景下的优劣。作者强调，绑人不是让对手不能动，而是让对手越挣扎越紧；最佳的绳结应该让对方在慌乱中自己完成加固。中间章节转入攀爬：如何用绳索无声上楼，如何用单绳下降控制速度，以及如何把绳索作为绊索布置在撤退路线上。书中还附带了几种常见陷阱的绳结构造图，比如悬铃警报与翻板。末页画着一只被绳圈套住脚踝的小鸟，旁边批注：最快的囚禁不是铁牢，是希望。

封皮带有一道整齐的割痕，像是从某个危险情境中被救出；内页贴满不同绳结的实物样本，有些已被磨得发亮，旁边标注着各自的承重极限。书中还记录着一种用唾液临时加固绳结的方法，据说在紧急时刻能救一命。

## 设计意图

为盗贼系提供多功能工具技能，兼顾探索机动与战场控场，增加环境互动维度。
