# 《匕首双持：左手不是辅助》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0115`
- **关联技能**：`rogue_dual_wield`
- **使用效果**：阅读后解锁 `rogue_dual_wield`；若已学会，提升 `current_mastery +130`，并使副手攻击的攻速 +3%。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `敏捷 ≥ 10`。
- **稀有度**：精良（Uncommon）
- **建议投放**：双刃武馆、角斗士训练营废墟、传奇佣兵遗物。

## 书籍内容

双持匕首的人常犯一个错误：把左手当作右手的跟班。这本书主张，左手应该是独立的威胁，有自己的节奏与目标。作者要求练习者先单独训练左手一个月，直到左手能独立完成刺、割、挑三种动作，再把两只手合起来。书中详细讲解了三种双持架势：一手牵制一手刺杀、双手同时攻击不同目标、以及交叉防守后的反击。中间章节用大量线条图展示如何利用双匕制造连续的攻击压力，让敌人无法判断下一次攻击来自哪一侧。末页有一句话被刀刻进纸里：两只手拿两把刀，不是两份力量，是两种选择。

空白处有人画了两只手，左手明显比右手练习得更久；封底内侧粘着一小段绷带，上面渗着早已干枯的血迹，像是在提醒读者双持的代价。书中还讨论如何在双持时避免自己的两把刀互相碰撞，这是新手最常犯的错误。

## 设计意图

为盗贼系提供双持武器战斗风格，通过主副手独立节奏提升近身作战的复杂度与爽感。
