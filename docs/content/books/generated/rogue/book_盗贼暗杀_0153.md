# 《背刺者的步法：死角移动》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0153`
- **关联技能**：`rogue_dead_angle_move`
- **使用效果**：阅读后解锁 `rogue_dead_angle_move`；若已学会，提升 `current_mastery +130`，并使从目标背后接近时被发现距离 `-15%`。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `敏捷 ≥ 12`；已学会 `rogue_flank_attack`。
- **稀有度**：稀有（Rare）
- **建议投放**：影行者导师、暗杀任务密室、高阶潜行训练场。

## 书籍内容

一位自称「灰影」的刺客写下了这本书，他声称自己从未正面杀过人。这本书的核心观点很简单：每个人都有看不见的死角，而背刺者的任务就是站在那里面。作者把人体背后的危险区域画成一张不断收缩的圆锥图，指出大多数人只会转动眼睛和脖子，只有受过训练的人才会转动躯干。书中教导如何利用这个生理弱点，在敌人侧后方保持移动而不进入其视野边缘。中间章节讲解步法的节奏：与对方重心转换同步，在支撑脚离地的瞬间迈步，可以最大程度掩盖脚步声，甚至让敌人把脚步误以为是自己的回声。后半本转入多人场景，分析如何从两名敌人的死角交界处穿过，以及如何利用家具和地形制造新的死角。末页有一张被血点污染的示意图，标注着：真正的死角不在敌人身后，在他自以为安全的地方。某些页角被血黏在一起，撕开会损坏插图。

## 设计意图

把盗贼的绕后能力从位移推进到空间博弈，为背刺与暴击机制提供稳定发动条件。
