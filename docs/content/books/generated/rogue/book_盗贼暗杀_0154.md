# 《毒物亲和：让血适应毒素》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0154`
- **关联技能**：`rogue_poison_resistance`
- **使用效果**：阅读后解锁 `rogue_poison_resistance`；若已学会，提升 `current_mastery +110`，并使自身中毒后的持续时间 `-20%`。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `体质 ≥ 10`。

- **建议投放**：毒药师藏身处、沼泽据点医师、黑市解毒剂商人。

## 书籍内容

长期与毒物打交道的人，要么死得很快，要么学会让自己的身体成为毒的宿主。这本书属于后者，扉页上写着「献给所有没死成的学徒」。作者从微量毒理入手，教授如何用递增剂量的毒素刺激肝脏与血液，建立一种类似免疫的耐受机制。书中强调，毒物亲和不是为了让人百毒不侵，而是为了在中毒后仍能完成动作、撤离现场或反杀敌人。中间章节列举十几种常见毒草与毒虫的处理方式，从研磨到萃取都有简易配方，并标注了哪些毒素可以互相中和、哪些会叠加致命。后半本则讲述心理层面的适应：许多暗杀者不是死于毒，而是死于对毒的恐惧，那种恐惧会让呼吸急促、判断混乱。书中还警告，某些毒素会在体内沉积数年，最终导致慢性衰竭。末页用红笔写着：让毒进入你，但不要让它决定你。书脊用某种防水皮革重新装订过。

## 设计意图

为毒系盗贼提供生存容错，鼓励主动使用毒刃而不惧自伤或敌方反制。
