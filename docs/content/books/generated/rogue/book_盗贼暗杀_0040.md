# 《蛇行：地面移动的低姿态艺术》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0040`
- **关联技能**：`rogue_serpent_move`
- **使用效果**：阅读后解锁 `rogue_serpent_move`；若已学会，提升 `current_mastery +120`，并使匍匐或低姿态移动时被发现距离 `-10%`。
- **阅读要求**：基础 `敏捷 ≥ 10`；已学会 `rogue_silent_step`。

## 书籍内容

蛇行不是爬，而是一种让身体贴近地面并持续移动的艺术。作者认为，人类的眼睛更习惯捕捉直立的轮廓，因此低姿态移动天然具有隐蔽优势。书中把蛇行分为贴地、贴墙与贴影三种，每一种都要求练习者重新分配身体重量，避免肩膀和臀部在移动中上下起伏。中间章节讲解如何利用手臂和脚尖推动身体前进，如何在穿越草地时避免压倒草茎，以及如何在泥土或沙地上不留明显痕迹。后半本转入速度控制，指出蛇行最大的敌人是急躁，因为一旦速度超过某个阈值，身体就会不自觉地抬高。末页有一张被汗水浸湿的练习表，记录了一位学员从每次只能移动三步到能无声穿越整个庭院的过程，旁边批注：越低，越像阴影；越像阴影，越不属于这个世界。

附录是低姿态移动训练表，记录从三步到三十步的进步标准。表下写着：蛇行的秘密不是贴近地面，是让自己忘记直立曾是一种选择。

## 设计意图

为盗贼系提供进阶移动隐蔽技能，发现距离缩减与侦察、潜入玩法高度契合。
