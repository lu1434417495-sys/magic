# 《锁心：简易机关解析》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0103`
- **关联技能**：`rogue_lockpicking`
- **使用效果**：阅读后解锁 `rogue_lockpicking`；若已学会，提升 `current_mastery +120`，并使下一次开锁必定触发 `quiet_open`（不发出声响）。
- **阅读要求**：角色职业标签含 `rogue` 或 `thief`；基础 `敏捷 ≥ 9` 或 `智力 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：盗贼公会入门考核奖励、旧城区锁匠铺、废弃金库。

## 书籍内容

锁不是门，是门的语言。作者把开锁比作与制锁师隔空对话：每一道弹子都是他提出的一个问题，你的撬棍就是回答。书中从最基础的片锁讲起，强调手指要先学会听金属的回应，而不是用蛮力逼迫。作者画了大量耳朵贴近锁孔的示意图，并在旁边标注：别用眼睛看，用骨头听。中间章节列举十二种常见机关陷阱的触发逻辑，比如压板、拉线、温度感应，每一种都配有反面教材他撬开了锁，却点燃了灯。末页是一段用暗语写成的口诀，翻译成白话只有一句：最快的开锁方式是拿到钥匙，第二快的方式是让钥匙自己走过来。

空白处有人用铅笔反复写着"先听，后动"，字迹从潦草到工整，显然经过长期练习；某页还粘着一小段断裂的撬针，针尖已经弯成优雅的弧形。封底画着一把简易片锁的剖面图，每个弹子旁边都标注了正确的撬动顺序。

## 设计意图

解锁盗贼系基础探索能力，把开锁从单纯判定扩展为听感判断与陷阱预知的综合玩法。
