# 《双生刃：左右手的背叛》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0023`
- **关联技能**：`rogue_dual_wield`
- **使用效果**：阅读后解锁 `rogue_dual_wield`；若已学会，提升 `current_mastery +140`，并使双持时的副手攻击伤害 `+4%`。
- **阅读要求**：基础 `敏捷 ≥ 11`；已装备两把单手武器。
- **稀有度**：精良（Uncommon）
- **建议投放**：双刀武者营地、竞技场冠军奖励、东方武器商人。

## 书籍内容

双生刃的作者认为，两只手同时持有武器的人，首先要学会的是让左右手互相背叛。主手负责引诱与压迫，副手负责终结与补刀，如果两只手都想做同一件事，动作就会 predictable。书中把双持训练分为三个阶段：第一阶段只练主手，让副手像挂件一样安静；第二阶段只练副手，让主手成为诱饵；第三阶段才让两只手各自承担不同节奏。中间章节讲解身体重心的分配，指出双持最大的误区是站得太正，真正有效的双持刀客总是侧对敌人，把身体宽度压缩到最小。后半本转入心理训练：如何同时关注两把刀的状态，如何在一只手被格挡时不让另一只手犹豫。末页有一幅对称的插图，两只手握着刀互相指向对方， caption 写着：最忠诚的刀，是随时准备背叛的那一把。

书末附两把木剑握法对比图，标注双持时重心变化曲线。图下写着：左右手若总是同意，便等于只有一只手。

## 设计意图

建立盗贼系双持武器战斗风格，副手增伤鼓励玩家投资双持构筑。
