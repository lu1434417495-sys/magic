# 《谎言的重量：如何让人自己开口》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0164`
- **关联技能**：`rogue_interrogation_soft`
- **使用效果**：阅读后解锁 `rogue_interrogation_soft`；若已学会，提升 `current_mastery +100`，并使对话中获取情报的成功率 `+10%`。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `魅力 ≥ 9` 或 `智力 ≥ 10`。
- **稀有度**：普通（Common）
- **建议投放**：密探训练所、酒馆情报贩子、间谍任务奖励。

## 书籍内容

真正的情报很少来自拷问，更多来自让对方觉得你已经在帮他，这本书的作者是一名曾经担任宫廷顾问的间谍大师。作者把软性审讯拆成几个阶段：建立共同立场、制造安全感、用已知信息换取未知信息、再让对方以为这些是他自己主动说的。书中强调，最高明的谎言是说七分真话，只在关键处留一个缺口。中间章节列举了几种常用的误导话术：假装已经知道答案、用沉默迫使对方补充、把问题包装成关心。后半本转入风险控制：如何判断对方是否在反向套取你的情报，以及何时该停止追问避免打草惊蛇。书中还记录了几种不能使用的谎言：容易被验证的、与对方情感深度绑定的，以及会伤害无辜者的。末页用潦草的字迹写着：让他开口的最好办法，是让他觉得自己在保护你。书的空白处写满了读者自己的谎言练习。

## 设计意图

为盗贼系提供社交情报获取能力，扩展非战斗任务解决路径。
