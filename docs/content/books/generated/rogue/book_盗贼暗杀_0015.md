# 《欺诈师的眼神课》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0015`
- **关联技能**：`rogue_deception`
- **使用效果**：阅读后解锁 `rogue_deception`；若已学会，提升 `current_mastery +100`，并在下一次与商人或守卫对话时获得 `+5%` 说服加成。
- **阅读要求**：基础 `智力 ≥ 9` 或 `魅力 ≥ 8`；角色职业标签含 `rogue`。

## 书籍内容

眼神课的作者不是杀手，而是骗子，但他认为最好的谎言与最干净的暗杀 share 同一种眼神：坚定得不像在隐藏什么。书中把眼神交流分为四个阶段：建立信任时注视对方眉心，施加压力时移向鼻梁，释放善意时短暂看向眼睛，结束对话时则垂下视线表示无害。作者警告，最危险的反应不是对方识破谎言，而是对方假装相信。中间章节教授如何用手势辅助欺骗：手掌向上的姿态暗示坦白，手指轻敲桌面可以引导对方加快判断，而过度解释反而会触发警觉。后半本转入自我欺骗训练，因为作者认为最好的欺诈师必须先让自己相信自己的故事。末页有一段被反复涂改的练习题：对着镜子说三句真话，再说一句谎话，直到连你自己都分不清哪一句是谎话。

每章末尾都有练习题，如对镜说谎三十秒不眨眼。最后一题答案空白处写着：最好的谎言七分真三分假，最好的眼神让对方以为看穿了全部。

## 设计意图

为盗贼系提供社交与剧情分支能力，小型对话加成让非战斗玩法也能感知成长。
