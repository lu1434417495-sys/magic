# 《血腥味管理》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0128`
- **关联技能**：`rogue_scent_control`
- **使用效果**：阅读后解锁 `rogue_scent_control`；若已学会，提升 `current_mastery +90`，并使野兽型敌人的侦测范围降低 8%。
- **阅读要求**：角色职业标签含 `rogue` 或 `ranger`；基础 `感知 ≥ 9`。
- **稀有度**：普通（Common）
- **建议投放**：猎人营地、草药师小屋、兽巢边缘宝箱。

## 书籍内容

人可以不看，但不能不呼吸；野兽可以不听，但不能不闻。这本书教人如何管理自己的气味：出发前用皂草清洗身体，避免使用香料，用腐叶或泥土掩盖鞋底的脚臭。作者还讲解了如何利用风向：永远站在上风处接近目标，让气味先于你抵达安全区域。书中记录了多种天然除臭剂与误导性气味的配方，比如用松针掩盖人味，用猎物血腥味吸引野兽离开路线。中间章节讨论心理压力：许多人因为紧张而分泌特殊体味，这种体味无法被草药完全遮盖。末页只有一行字被烟熏黑：你可以骗过眼睛和耳朵，但鼻子只相信本能。

书页间夹着干燥的松针与一小片腐叶，是作者推荐的掩盖材料；空白处记录着不同季节最佳的气味干扰配方，以及几种野兽最讨厌的草药组合。书中还讨论了雨水对气味管理的致命影响，以及如何在雨中重新建立气味屏障。

## 设计意图

为盗贼系提供环境感知对抗技能，降低野兽与嗅觉敏感敌人的侦测效率。
