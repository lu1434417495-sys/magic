# 《死亡标记：猎杀优先级》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0120`
- **关联技能**：`assassin_death_mark`
- **使用效果**：阅读后解锁 `assassin_death_mark`；若已学会，提升 `current_mastery +140`，并使被标记目标的击杀奖励经验 +8%。
- **阅读要求**：角色职业标签含 `assassin`；基础 `智力 ≥ 11`。
- **稀有度**：稀有（Rare）
- **建议投放**：刺客公会高阶任务奖励、黑暗神殿祭坛、传奇暗杀者遗物。

## 书籍内容

在混乱的战场上，刺客必须决定谁先死。这本书教授一种古老的标记术：在战斗开始前用目光、手势或暗器锁定一个目标，并在所有行动中优先瓦解该目标。作者指出，优先级不是基于威胁，而是基于价值——医疗者会让敌人持久，指挥官会让敌人有序，法师会让敌人致命。书中还讲解了如何利用标记制造心理压力：当敌人发现你始终盯着同一个人时，他们的阵型会自然倾斜。中间章节列出了十二种常见职业的击杀顺序建议，并警告：标记一旦确定，中途更换会让你的节奏崩溃。末页只有一句话：死在你标记下的人，是战场上唯一该死的人。

末页是空白的，只画了一个被反复涂抹的红圈；空白处用铅笔写着："标记即承诺，承诺即死亡"，字迹从深到浅，像是被反复描摹了许多遍。封底内侧贴着一张小小的目标照片，照片的眼睛被两枚钉子钉穿。

## 设计意图

为刺客系提供战术核心技能，强化目标选择与战场决策，提升团战中的 assassin 价值。
