# 《空无之境：战斗中消失一瞬》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0173`
- **关联技能**：`rogue_void_moment`
- **使用效果**：阅读后解锁 `rogue_void_moment`；若已学会，提升 `current_mastery +160`，并使战斗中首次闪避成功后进入短暂无敌。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `敏捷 ≥ 15` 且 `意志 ≥ 12`。
- **稀有度**：史诗（Epic）
- **建议投放**：虚无裂隙导师、影界试炼奖励、传说刺客遗物。

## 书籍内容

空无之境不是隐身，而是在战斗的缝隙中把自己抽离一瞬，这种技艺只在虚无裂隙附近才有人能够传授。作者认为每一次攻击都有零点几秒的间隔，那就是世界眨眼的时刻。书中前半部训练极限反应：在武器挥来的瞬间判断其轨迹，而不是用肌肉硬抗。中间章节讲解如何利用这个间隙调整位置、重置姿态、甚至绕过敌人背后。书中记载，初学者可以通过瀑布下修行来感受世界眨眼的节奏。后半本转入精神状态：必须放弃所有多余的念头，只留下一个清晰的意图，否则身体会犹豫，犹豫会把你拉回实体。末页有一幅抽象画，看起来像是一个人正在被黑白两色撕开，配文：敌人击中你的那一刻，你已经在另一个瞬间。翻阅时纸页会发出类似流水声的轻响。书中记载，真正掌握空无之境的人会在日常生活中也偶尔闪避不存在的攻击。

## 设计意图

为高阶盗贼提供极限闪避与无敌帧机制，提升高风险操作的上限。
