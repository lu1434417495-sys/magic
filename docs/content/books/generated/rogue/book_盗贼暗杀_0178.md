# 《刃舞：在敌人包围中开花》

## 书籍内容

刃舞不是舞蹈，而是把围攻者的数量变成自己优势的思维方式，据说这种技艺诞生于奴隶角斗场。作者认为，包围你的人越多，他们就越容易误伤彼此，也越难预测你的移动。作者认为，包围是一种幻象，当敌人以为你无处可逃时，他们之间的距离反而成了你的走廊。书中教授如何在人群中找到最薄弱的一环作为突破口，如何利用旋转和滑步同时威胁多个方向。中间章节讲解距离控制：始终保持一臂距离，既不让敌人合抱，也不让自己陷入孤立。后半本转入心态：恐惧会让人僵住，而刃舞要求你在最危险的时刻反而放松肩膀、加快呼吸。末页画着一朵由刀刃组成的花，花瓣向外张开，配文：花开在人群最密的地方。封面上画着一朵由刀刃构成的抽象花朵。书中强调，刃舞的核心不是杀伤，而是让敌人彼此成为障碍。

## 设计意图

为盗贼系提供被包围时的反击技能，鼓励高风险、高回报的近身缠斗。
