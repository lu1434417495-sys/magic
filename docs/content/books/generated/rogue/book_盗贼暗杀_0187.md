# 《沉默坠落：从任意高度着陆》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0187`
- **关联技能**：`rogue_silent_fall`
- **使用效果**：阅读后解锁 `rogue_silent_fall`；若已学会，提升 `current_mastery +110`，并使高处坠落后 `2` 秒内移动速度 `+15%`。
- **阅读要求**：角色职业标签含 `rogue`；基础 `敏捷 ≥ 11` 且 `体质 ≥ 9`。
- **稀有度**：精良（Uncommon）
- **建议投放**：城市飞贼导师、杂技艺人、屋顶追逐任务奖励。

## 书籍内容

屋顶之间总有空隙，而从空隙落下时不发出声音是一门独立的技艺，这本书的作者曾是王室御用杂技团的首席演员。这本书教授如何利用翻滚、缓冲和身体张力把坠落转化为可控的着陆。作者强调，关键不是落在柔软的东西上，而是让身体在触地瞬间把力量分散到多个部位。中间章节讲解不同高度的应对策略：低矮屋檐可以直接屈膝吸收，中等高度需要侧滚，更高处则需要借助墙壁或绳索分段减速。作者建议练习者从矮墙开始，逐步增加高度，直到能从三层楼安全落下。后半本转入应用场景：如何在落地后立刻恢复移动，如何利用坠落制造突袭角度。末页画着一个人从屋顶翻滚而下的连续动作，旁边写着：掉下来不丢人，丢人的是掉下来时让全世界都知道。封面上画着一个从屋顶翻滚而下的简笔人。

## 设计意图

为盗贼系提供垂直机动与着陆容错，扩展城市追逐与潜入路径。
