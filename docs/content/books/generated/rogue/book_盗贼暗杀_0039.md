# 《消失的证人：处理目击者的策略》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0039`
- **关联技能**：`rogue_witness_silence`
- **使用效果**：阅读后解锁 `rogue_witness_silence`；若已学会，提升 `current_mastery +110`，并降低暗杀任务中目击者引发警报的 `10%` 概率。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `智力 ≥ 9` 或 `意志 ≥ 9`。
- **稀有度**：精良（Uncommon）
- **建议投放**：清理人公会、密探组织、犯罪现场证据室。

## 书籍内容

作者认为，暗杀者最大的失败往往不是任务失败，而是任务成功后留下太多会说话的东西。这本书把目击者分为三类：直接目击者、间接目击者和事后推理者，对每一类都给出处理策略。直接目击者需要被控制或说服，间接目击者需要被误导，事后推理者则需要被喂以错误的线索。中间章节讲解如何在行动中减少目击者产生：选择视野受限的路径、利用噪音掩盖异常、在目标周围制造混乱以分散注意力。后半本转入说服与恐吓的平衡，警告过度使用暴力会让更多人成为潜在目击者。末页有一张流程图，最后一格被圈出：如果无法让证人沉默，就让他们的话变得不可信。

书中附目击者分类与处理策略速查卡，方便任务前翻阅。卡片背面写着：让人沉默不难，难的是让他开口后仍没人相信他。

## 设计意图

为盗贼与刺客系提供任务执行辅助技能，警报概率降低强化潜行任务完成度。
