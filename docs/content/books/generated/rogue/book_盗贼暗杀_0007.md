# 《影袭：匕首的两次心跳》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0007`
- **关联技能**：`rogue_dagger_mastery`
- **使用效果**：阅读后解锁 `rogue_dagger_mastery`；若已学会，提升 `current_mastery +130`，并使双持匕首时的首次攻击 `+6%` 暴击伤害。
- **阅读要求**：基础 `敏捷 ≥ 10`；已装备匕首。
- **稀有度**：精良（Uncommon）
- **建议投放**：匕首锻造坊、暗杀训练场、黑市武器商人。

## 书籍内容

作者把匕首攻击分为两次心跳：第一次是目标尚未意识到危险时的心跳，第二次是刀刃进入身体后目标试图理解发生了什么时的心跳。真正的高手在这两次心跳之间完成出手与撤离。书中花了大量篇幅讨论握法，反对影视中常见的反手持刃，认为正手在突刺与割划之间更灵活，反手只适合已控制住目标后的终结。中间章节详细分析匕首长度与战术的关系：短刃容错低但隐蔽，长刃杀伤大但抽离慢。作者还提出锋刃保养比 sharpening 更重要，因为钝刃会造成不必要的肌肉撕裂声。后半本是一本刺杀节奏练习册，要求读者用木桩模拟目标，在两次心跳的间隔内完成接近、出手、后退。末页有一张表格，记录不同体型目标的理想入刀角度，表格下方只有一句话：第二次心跳响起时，你已经不在那里。

每章末尾都有刀语短评，讨论匕首在不同文化中的命名与忌讳

## 设计意图

强化盗贼系短刃武器的专精路线，暴击伤害加成绑定双持玩法，推动构筑多样性。
