# 《影子拍卖：赃物出手》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0149`
- **关联技能**：`rogue_fence_network`
- **使用效果**：阅读后解锁 `known_knowledge_id: fence_contacts`，可在主要城市以更高价格出售赃物；若已学会，提升 `current_mastery +80`。
- **阅读要求**：角色职业标签含 `rogue` 或 `thief`；基础 `魅力 ≥ 9`。
- **稀有度**：普通（Common）
- **建议投放**：黑市拍卖行、走私者酒馆、盗贼公会财务室。

## 书籍内容

偷来的东西只有在卖出去之后才真正属于你。这本书教人如何找到可靠的销赃渠道：从街头小贩到拍卖行老板，从旅行商人到贵族收藏家，每一个渠道都有不同的折扣与风险。作者强调，销赃的关键不是价格最高，而是最安全——一个急于出手的贼最容易被钓鱼执法。书中还讲解了如何洗掉赃物的来历：重新镶嵌宝石、熔毁金属印记、把艺术品拆分出售。中间章节有几条警示案例：有人因为贪心把赃物卖回给原主人，结果落入圈套。末页贴着一张写满名字与代号的纸条，旁边写着：最好的买家，是那些永远不会承认买过的人。

封底内侧粘着一小段吹管，管内壁还残留着绿色痕迹；书脊中夹着一小包解毒草药，标签写着"以防万一"，草药已经干枯成褐色的碎末。某页边缘有人用密码写着一个地点，据说是全城最安全的情报交易场所。

## 设计意图

作为知识类书籍扩展盗贼系的经济循环，让非法获取的物品有稳定的变现渠道。
