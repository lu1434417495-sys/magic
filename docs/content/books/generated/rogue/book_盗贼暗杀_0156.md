# 《刺客账本：目标的价值评估》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0156`
- **关联技能**：`assassin_contract_valuation`
- **使用效果**：阅读后解锁 `assassin_contract_valuation`；若已学会，提升 `current_mastery +100`，并使完成暗杀委托时额外获得 `5%` 金币与声望。
- **阅读要求**：角色职业标签含 `assassin`；基础 `智力 ≥ 9`。
- **稀有度**：普通（Common）
- **建议投放**：刺客公会前台、情报商人、委托发布者。

## 书籍内容

这本书把暗杀从艺术还原成了一门生意，作者是一名退休的刺客公会会计。作者认为，一个合格的刺客在拔刀之前，必须先学会计算目标的身价、护卫成本、逃脱难度和后续风险。书中用大量表格展示如何为一次委托定价：目标的政治地位加多少，是否有魔法师随行再加多少，是否需要制造意外假象又要加多少。中间章节讨论定金、尾款与灭口条款的写法，提醒读者永远不要把真实姓名写进任何契约，也不要在酒馆里炫耀自己的报价。后半本转入心理账：有些目标看起来报酬丰厚，但会引来无休止的追杀；有些目标报酬一般，却能换来长久的安宁。书中还附有一张空白报价单，供读者在接委托前逐项勾选。末页用歪扭的字迹写着：最贵的不是人头，是你接下来要睡的每一个安稳觉。最后一页夹着一张未填写的报价单。

## 设计意图

为刺客系提供委托经济收益加成，把任务选择与经济成长联系起来。
