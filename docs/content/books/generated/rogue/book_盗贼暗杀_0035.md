# 《暗影斗篷：把自己藏进自己的影子里》

## 书籍内容

暗影斗篷不是一件实体斗篷，而是一种让身体与周围阴影共振的技巧。作者认为，每个人都有影子，而高手能让自己的影子看起来比实际更大、更浓、更不稳定，从而迷惑敌人的瞄准。书中教授如何利用光源角度让身体处于影子的边界，如何利用移动让影子与周围阴影融合，以及如何在必要时让影子突然拉长或收缩以制造假象。中间章节讲解暗影斗篷的局限：它无法让你在正午无影的空地上消失，也无法抵挡范围攻击。后半本转入高级技巧，教导如何在斗篷状态下发动攻击而不破坏阴影共振。末页有一段用银粉写的警告：不要让影子比你更了解黑暗，否则它会拒绝在黎明时还给你。

书末附暗影斗篷练习姿势图，人影正蹲在墙角与阴影融为一体。图下写着：斗篷不是 hide，是变成黑暗愿意忽略的形状。

为盗贼系提供防御型暗影技能，远程闪避加成鼓励玩家主动寻找阴影地形。
