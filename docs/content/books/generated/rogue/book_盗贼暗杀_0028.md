# 《鹰爪与蛇信：擒拿与点穴入门》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0028`
- **关联技能**：`rogue_grapple`、`rogue_numbing_strike`
- **使用效果**：阅读后随机解锁 `rogue_grapple` 或 `rogue_numbing_strike`；若均已学会，提升 `current_mastery +120`，并使擒拿成功后目标 `-10%` 闪避（持续 2 回合）。
- **阅读要求**：基础 `敏捷 ≥ 10` 或 `力量 ≥ 9`；角色职业标签含 `rogue`。
- **稀有度**：精良（Uncommon）
- **建议投放**：东方武馆、流亡拳师、地下格斗场。

## 书籍内容

这本书把擒拿与点穴视作同一技术的两面：鹰爪负责固定，蛇信负责阻断。作者强调，擒拿不是比力气，而是比谁先破坏对方的重心；点穴不是 magic，而是精确打击神经与血流的交汇点。中间章节用大量插图说明人体脆弱节点，从颈侧到腋下，从膝弯到脚踝，每一个点都标注了对应效果：麻木、刺痛、失力、僵直。作者提醒，最有效的点穴往往只有短暂窗口，因为敌人会本能地保护被击中的位置。后半本转入组合应用，教授如何在擒拿成功后接点穴，让目标在数秒内既无法挣脱也无法反击。末页有一段关于武德的讨论，作者写道：学来制人，不可欺人；学来自保，不可逞强。这段文字旁边有人用铅笔打了个叉。

附录收录数种穴位按压效果与风险，警告未经训练者不可尝试。末页写着：点穴是借用人体疼痛开关，滥用者终被自己的开关反噬。

## 设计意图

为盗贼系提供控制与打断手段，擒拿与点穴的组合丰富了近战技能链。
