# 《夜幕下的交易：黑市议价》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0158`
- **关联技能**：`rogue_blackmarket`
- **使用效果**：阅读后解锁 `rogue_blackmarket`；若已学会，提升 `current_mastery +90`，并使在黑市商人处购买赃物或情报时价格 `-8%`。
- **阅读要求**：角色职业标签含 `rogue`；基础 `魅力 ≥ 8` 或 `智力 ≥ 9`。
- **稀有度**：普通（Common）
- **建议投放**：黑市入口乞丐、销赃商人、地下赌场庄家。

## 书籍内容

黑市不是一条街，而是一种语言，这本书的作者据说是七座城市黑市的共同创始人之一。作者认为黑市议价的关键不是压低价格，而是让对方相信你知道底价。书中列举了几种常见的开场方式：假装见过更好的货、暗示有另一个买家、用身体语言表达随时会离开。中间章节讲解如何识别假货与陷阱，特别是那些看起来太便宜的赃物和过于热情的中间人。后半本转入危险交易的脱身策略：约定暗号、安排接应、提前确认逃跑路线，以及如何在交易失败时把损失降到最低。作者还提醒，黑市没有法律，但有自己的规矩，破坏规矩的人会被所有商人共同封杀。末页有一张被烧掉一半的价目表，旁边写着：在黑市，太贵的东西可能是骗局，太便宜的东西一定是麻烦。书的扉页被人用黑市印章盖了半枚。

## 设计意图

为盗贼系提供经济向辅助能力，鼓励与黑市商人互动并获取非法资源。
