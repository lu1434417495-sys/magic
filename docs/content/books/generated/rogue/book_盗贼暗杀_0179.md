# 《无面者的面具》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0179`
- **关联技能**：`rogue_faceless_mask`
- **使用效果**：阅读后解锁 `rogue_faceless_mask`；若已学会，提升 `current_mastery +170`，并使伪装成任意非特定目标时识破难度 `+25%`。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `魅力 ≥ 12` 且 `智力 ≥ 12`。

- **建议投放**：无面者圣殿、传说级间谍任务、世界BOSS掉落。

## 书籍内容

无面者没有脸，所以他们可以拥有任何一张脸，这本书是无面者组织唯一允许外传的典籍。这本书记载了制作与佩戴无面者面具的秘术：面具不是贴在脸上，而是贴在观看者的记忆里。作者解释，真正有效的伪装不在于改变五官，而在于改变他人看到五官后的第一反应。中间章节讲解如何用姿态、声音和气味构建一个新的人格，如何在切换身份时不留下旧习惯的痕迹。书中还记载，无面者每年必须有一天摘下面具，否则将永远忘记自己的声音。后半本转入禁忌知识：如何在面具被损毁后依然维持伪装，以及长期佩戴面具后如何找回自己的脸。末页有一枚空白面具的素描，五官处只有几个淡淡的轮廓，配文：当你不再需要自己的脸时，你才真正开始看见别人。书的内页贴着半张空白面具的拓片。

作为传说级伪装技能，提供通用型社会渗透能力，适合大型潜入与身份操控任务。
