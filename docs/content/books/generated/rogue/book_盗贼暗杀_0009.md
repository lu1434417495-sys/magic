# 《眠草与叹息：非致命毒理学》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0009`
- **关联技能**：`rogue_sleep_poison`、`rogue_weakness_poison`
- **使用效果**：阅读后解锁 `rogue_sleep_poison`；若已学会，提升 `current_mastery +120`，并使眠草类毒剂持续时间 `+1` 回合。
- **阅读要求**：基础 `智力 ≥ 9` 或 `感知 ≥ 10`；已学会 `rogue_basic_poison`。
- **稀有度**：精良（Uncommon）
- **建议投放**：草药师黑市、医师叛徒藏书、贵族地下审讯室。

## 书籍内容

作者在开篇声明，本书只讨论让人暂时失去行动能力的毒剂，任何致死配方都已刻意撕去。眠草章节讲解如何让目标进入深度睡眠而非短暂眩晕，强调剂量与体重的关系，并警告呼吸抑制与真正睡眠的界限极其狭窄。叹息章节则讲肌肉松弛剂，让目标保持清醒却无法移动，适用于需要套取情报的场合。书中反复出现同一个警告：非致命意味着更不可控，因为活人比死人更擅长发出意外。中间章节记录了十二种常见解毒植物，作者提醒解毒者必须先判断毒剂类型再施救，错误的解毒有时会加速发作。后半本转入伦理困境：一个无法还手的目标是否仍是敌人。末页是一段空白，只有页边有一行小字：留下空白，是因为有些决定不该由书本替你做。

书脊内藏一页撕下的医师笔记，记录唤醒眠草过量者的方法。边缘字：让人沉睡易，让他醒来后不怪你，才是真技术。

## 设计意图

扩展毒系技能的控制分支，非致命定位让盗贼在潜行与情报任务中有更多选择。
