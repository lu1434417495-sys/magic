# 《影步：穿过敌人视线的缝隙》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0020`
- **关联技能**：`rogue_shadow_step`
- **使用效果**：阅读后解锁 `rogue_shadow_step`；若已学会，提升 `current_mastery +150`，并减少该技能首次使用的 `stamina` 消耗 1 点（一次性战斗增益）。
- **阅读要求**：基础 `敏捷 ≥ 12`；已学会 `rogue_silent_step` 与 `rogue_flank_attack`。
- **稀有度**：稀有（Rare）
- **建议投放**：影行者导师、异界裂隙营地、高阶潜行任务奖励。

## 书籍内容

影步不是快速移动，而是利用敌人视线的盲区完成位置跳跃。作者认为，战场上存在大量未被意识到的缝隙：一名敌人转头与同伴交谈的瞬间，火把闪烁造成的阴影变化，甚至目标眨眼时的短暂黑暗。影步就是训练自己识别并穿越这些缝隙。书中把训练分为三步：先静止不动，观察周围所有人的视线落点；再在不引起注意的前提下小幅度移动；最后才尝试长距离位移。中间章节讲解如何在穿越缝隙后保持自然，因为许多人失败不是因为在移动中被发现，而是在抵达新位置后显得格格不入。后半本转入高级应用，教导如何在多人混战中制造视线重叠，让数个敌人同时认为你在另一个人的警戒范围内。末页有一幅被多次折叠的地图，上面用虚线标出了一条不可能的路径，旁边写着：缝隙只存在于那些相信目光是直线的人之间。
