# 《陷阱共鸣：让机关互相欺骗》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0172`
- **关联技能**：`rogue_trap_resonance`
- **使用效果**：阅读后解锁 `rogue_trap_resonance`；若已学会，提升 `current_mastery +140`，并使设置的陷阱触发后引发连锁反应的概率 `+15%`。
- **阅读要求**：角色职业标签含 `rogue`；基础 `智力 ≥ 12` 且 `感知 ≥ 10`。
- **稀有度**：史诗（Epic）
- **建议投放**：机关工坊、古代盗贼陵墓、大师级陷阱任务奖励。

## 书籍内容

单个陷阱是谋杀，连锁陷阱才是艺术，作者是一名曾经为古代帝国设计陵墓机关的工匠。这本书教授如何让不同机关之间产生共鸣，让敌人踩中一个后自动走向第二个。作者从基础力学讲起：张力、杠杆、触发延迟与力的传导。中间章节列举了几种经典组合：毒针触发绊索、绊索释放落石、落石砸开油罐、油罐点燃预先布置的引火物。作者还提醒，布置连锁陷阱时必须先画草图，因为现场往往会让人高估空间距离。后半本转入布局思维：如何预测敌人的逃跑路线，如何把最显眼的陷阱当作诱饵，真正致命的机关藏在反直觉的位置。末页有一幅复杂的机关图，线条交错如蛛网，旁边写着：最好的陷阱不是藏在暗处，是让敌人自己按下开关。书中夹着几根用过的机关弹簧。作者建议每次布置完成后都要亲自踩一遍，以验证连锁是否顺畅。

## 设计意图

为陷阱型盗贼提供连锁控制能力，强化阵地战与区域控制玩法。
