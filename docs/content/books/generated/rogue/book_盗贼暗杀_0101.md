# 《影步：无声落地法》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0101`
- **关联技能**：`rogue_silent_landing`
- **使用效果**：阅读后解锁 `rogue_silent_landing`；若已学会，提升 `current_mastery +110`，并减少从任意高度落地后的硬直时间 0.2 秒（一次性战斗增益，最多累计 3 次）。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `敏捷 ≥ 9`。
- **稀有度**：普通（Common）
- **建议投放**：盗贼公会基础训练室、贫民窟屋顶宝箱、游侠商人。

## 书籍内容

这本书的扉页被撕去一半，只剩一句警告：落地之前，别让自己相信已经安全。作者把落地分成三个阶段：触地前的准备、触地时的分散、触地后的姿态。她要求练习者在空中就调整重心，让双脚先后触地而非同时砸下，像猫从高处跳下那样把冲击拆解成两次轻响。中间章节详细讲解不同材质地面的声音差异：木板会放大震颤，石板会反弹回音，泥地则会暴露脚印。书中还记录了一种反直觉技巧：刻意让肩膀轻微撞向墙面，用布料摩擦声掩盖脚步声，作者称之为借噪。末页有一幅被水渍晕开的插图，一个人影正从屋檐滑向地面，旁边批注：真正的无声不是完全没有声音，而是让声音融入环境本身的节奏。

书页边缘布满炭笔批注，有人补画不同地面的脚印示意图，有人记录失败时脚踝扭伤的教训；末页夹着一张被水渍晕开的训练表，记录着某位前辈三个月的落地练习数据。

## 设计意图

为盗贼系提供基础机动与落地控制技能，降低高处切入的惩罚，强化环境利用意识。
