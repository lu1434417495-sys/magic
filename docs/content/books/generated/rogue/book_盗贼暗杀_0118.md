# 《蹬墙跃：垂直城市》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0118`
- **关联技能**：`rogue_wall_run`
- **使用效果**：阅读后解锁 `rogue_wall_run`；若已学会，提升 `current_mastery +120`，并使蹬墙跃后的首次攻击伤害 +4%。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `敏捷 ≥ 11`。
- **稀有度**：精良（Uncommon）
- **建议投放**：城市跑酷导师、盗贼公会高阶训练场、屋顶宝箱。

## 书籍内容

城市的墙壁不是边界，而是被竖起来的地面。这本书教人如何在狭窄巷道中使用蹬墙跃：第一步不是向上跳，而是斜向墙面冲刺，用脚掌蹬击墙面获得横向推力；第二步是在空中调整姿态，让另一只手或脚找到下一个支点。作者强调，蹬墙跃的关键在于信任自己的第一步——犹豫会让墙面反作用力分散，导致高度不足。书中还讲解了不同墙面的脚感：砖墙粗糙但稳定，粉刷墙容易打滑，木质墙可能凹陷。末页画了一座想象中的垂直街道，人影在窗户与阳台之间跳跃，旁边写着：当街道变成陷阱，屋顶才是唯一的道路。

书页角落画满小箭头，标注着不同墙面的最佳蹬击点；封底用胶水粘着一小块碎砖，作为墙面质感的参考，砖面上还留着半个鞋印的压痕。空白处有人用炭笔画了十几个失败的蹬墙动作，每个都标注了"重心太靠后"。

## 设计意图

为盗贼系提供垂直机动技能，扩展城市探索维度并与战斗切入结合。
