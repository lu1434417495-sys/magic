# 《灰烬潜行：在燃烧后的世界移动》

## 书籍内容

灰烬潜行不是普通的潜行，而是在一个永远有轻微燃烧声、空气中漂浮着反光颗粒的世界里移动。作者指出，灰烬交界的特殊环境既是阻碍也是掩护：漂浮的灰烬会暴露快速移动的身影，但也会模糊慢速移动的轮廓。书中建议在灰烬区域压低身姿，因为站立时肩膀会扰乱灰烬下沉的纹理。中间章节讲解如何利用余烬的光源变化，在敌人眨眼或转头时穿越开阔地带，以及如何在脚下踩到未熄灭的炭火时控制表情和呼吸。后半本转入灰烬怪物的行为模式，指出它们中的许多并不依赖视觉，而是依赖热量与震动，因此传统的潜行技巧需要大幅调整。末页有一幅烧焦的地图，上面的路线都以灰烬厚度标注，旁边写着：在这里，静止不是安全的代名词，融入灰烬才是。

书末夹着烧焦半边的地图，标注灰烬交界几处潜行路线。背面写着：在灰烬里，移动本身就是证据，静止才是最好的伪装。
