# 《袖剑折叠：机关构造与维护》

## 书籍内容

袖剑不是普通的短刀，而是一种需要与手臂共同呼吸的机关，据说最早由一名失去左手的刺客发明。这本书详细拆解了袖剑的弹簧、卡榫、滑轨与保险装置，指出最致命的故障往往不是发不出刀，而是在不该发的时候自己弹出来。作者教授如何根据自己的腕围调整绑带，如何在出汗、碰撞和急速移动中保持机关稳定。作者提醒，袖剑的保险装置比触发装置更重要，一次意外弹出可能暴露整个任务。中间章节讲解几种经典触发方式：握拳、屈腕、以及用另一只手的暗扣。后半本转入维护：如何用细布擦拭滑轨，如何给弹簧上油，如何在刀身见血后防止血痂卡住机关。末页有一幅袖剑剖面图，每个零件都被编号，旁边写着：袖剑是刺客的手臂，不是刺客的武器。每一页都画有袖剑零件的放大图。

## 设计意图

为刺客系提供标志性武器技能，首次命中加成强化其爆发定位。
