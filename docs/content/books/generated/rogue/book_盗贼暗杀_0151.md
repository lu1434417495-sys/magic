# 《无声开锁：倾听金属的呼吸》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0151`
- **关联技能**：`rogue_lockpicking_advanced`
- **使用效果**：阅读后解锁 `rogue_lockpicking_advanced`；若已学会，提升 `current_mastery +120`，并使开锁所需时间 `-15%`。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `敏捷 ≥ 10` 且 `感知 ≥ 9`。

## 书籍内容

老锁匠科林在临终前把这卷手稿交给了一名小偷。作者把锁匠比作乐师，而锁就是需要被倾听的金属乐器。真正的开锁从不是蛮力对抗，而是用手指与耳朵完成的一场对话。书中把过程拆成三步：先听弹子所处的位置，再感受弹簧的张力，最后决定用多少力气去迎合金属的意愿。作者明确反对暴力撬锁，因为那等于告诉全世界有人来过。中间章节详细记录七种常见锁芯的内部结构，每一种都配有作者手绘的剖面图和推荐的挑针角度，甚至标注了不同季节金属热胀冷缩的影响。后半本转入反制思维：如何在开锁后复原锁舌痕迹，如何让锁看起来像是自然损坏。末页夹着一枚弯曲的旧铜针，旁边写着：最好的开锁者不是打开锁的人，是让锁相信自己从未被打开过的人。书页边缘布满细小的挑针划痕。

## 设计意图

为盗贼系提供中阶探索与解谜能力，缩短开锁时间强化潜入流畅感。
