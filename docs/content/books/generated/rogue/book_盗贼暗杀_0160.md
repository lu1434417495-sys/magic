# 《幻影步：留下残影的撤退》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0160`
- **关联技能**：`rogue_phantom_step`
- **使用效果**：阅读后解锁 `rogue_phantom_step`；若已学会，提升 `current_mastery +140`，并使首次触发撤退时移动速度 `+20%`（一次性战斗增益）。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `敏捷 ≥ 13`；已学会 `rogue_shadow_step`。
- **稀有度**：稀有（Rare）
- **建议投放**：影行者高阶导师、传奇盗贼遗物、深渊裂隙营地。

## 书籍内容

幻影步不是让敌人看不见你，而是让他们看见一个已经不在那里的你，传说作者是影界的一名逃亡者。作者通过分析人眼视觉暂留现象，指出快速横向移动时会在原处留下短暂残像，而高阶盗贼可以主动利用这一点。书中前半部训练爆发力：如何在瞬间蹬地、摆臂、把身体抛向侧翼，同时保持重心不偏离逃跑路线。中间章节讲解残像的方向控制：要向光源相反的方向移动，让影子被光线冲淡，使敌人误以为自己仍在原地。后半本转入组合应用：如何在制造残像的同时掷出烟雾弹或暗器，让敌人分不清该追哪一边。练习时需要在墙上悬挂铃铛，若铃铛发出声响，便意味着残像失败了。末页有一张被反复折叠的步法图，轨迹像是一个扭曲的之字，旁边写着：真正的撤退不是跑，是让对方跑向你的影子。封面上有一道斜向的焦痕，像被高速掠过。

## 设计意图

为高阶盗贼提供战术撤退与位置欺骗技能，强化机动性在战斗中的价值。
