# 《锁心术：打开人心的锁》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0194`
- **关联技能**：`rogue_heart_lockpick`
- **使用效果**：阅读后解锁 `rogue_heart_lockpick`；若已学会，提升 `current_mastery +150`，并使对话说服成功率 `+12%`。
- **阅读要求**：角色职业标签含 `rogue`；基础 `魅力 ≥ 13` 且 `智力 ≥ 12`。
- **稀有度**：史诗（Epic）
- **建议投放**：宫廷间谍导师、魅惑术士藏身处、史诗级社交任务奖励。

## 书籍内容

人心比任何铁锁都复杂，但锁匠的逻辑同样适用，这本书的作者曾是一位王室的宠臣，后来被发现同时服务于三个敌国。这本书教授如何观察一个人的欲望、恐惧和习惯，然后像撬动弹子一样撬动他的决定。作者认为，说服不是辩论，而是让对方自己得出结论。中间章节讲解几种心理锁芯：渴望被认可的人需要赞美、害怕失去的人需要安全感、愤怒的人需要一个替罪羊。作者提醒，锁心术不能用于真正信任你的人，因为那种背叛会在施术者心中留下裂痕。后半本转入风险控制：如何判断对方是否在假装被说服，以及如何在操控失败后优雅退场。末页有一把心形锁的素描，锁孔被画成一只眼睛，配文：不要试图打破人心，找到它的机关，轻轻一拨。封面画着一把心形锁和一根细长的挑针。书中列举了几种最难以撬动的性格：完全无私者与彻底疯狂者。

## 设计意图

为盗贼系提供高阶社交操控能力，扩展非战斗任务解决与剧情互动深度。
