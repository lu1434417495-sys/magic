# 《脱身衣：快速换装》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0125`
- **关联技能**：`rogue_quick_change`
- **使用效果**：阅读后解锁 `rogue_quick_change`；若已学会，提升 `current_mastery +100`，并使换装后的首次潜行判定 +5。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `敏捷 ≥ 9`。
- **稀有度**：精良（Uncommon）
- **建议投放**：剧院更衣室、贵族裁缝铺、间谍安全屋。

## 书籍内容

最危险的瞬间不是作案时，而是作案后从凶手变回路人的那几秒钟。这本书教人如何在三秒内完成外套、帽子、披肩与鞋子的切换，让目击者的描述在追逐中自相矛盾。作者强调，快速换装的关键不是手快，而是预先设计好每一层衣物的穿脱顺序。书中还讲解了如何利用环境中的杂物增加变化：一把伞、一条围巾、一个布袋都能让同一个人看起来完全不同。中间章节有十多个换装步骤图，每一步都标注了耗时。末页用针脚缝着一句话：目击者记住的是衣服，不是你；要让他们记住衣服，就别让他们看清脸。

书内夹着几枚不同颜色的纽扣，是快速换装时的标记物；末页画着换装步骤图，每一步都标注了耗时，总时间被红笔从三秒改到两秒又改回三秒。书中还教人如何在换装时快速改变发型，这是一般伪装指南最容易忽略的细节。

## 设计意图

为盗贼系提供战后逃生与伪装支援技能，把换装从剧情演出扩展为可玩的判定机制。
