# 《窒息的艺术：无声绞杀》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0189`
- **关联技能**：`rogue_suffocation`
- **使用效果**：阅读后解锁 `rogue_suffocation`；若已学会，提升 `current_mastery +120`，并使绞杀成功后 `5` 秒内附近敌人警戒范围 `-15%`。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `力量 ≥ 11` 且 `敏捷 ≥ 10`。
- **稀有度**：精良（Uncommon）
- **建议投放**：拷问者密室、海盗船舱、暗杀训练场奖励。

## 书籍内容

无声绞杀不是力量的较量，而是对呼吸节奏的精确控制，这本书的作者声称曾在一条海盗船上用这种方式解决了整支守夜小队。这本书教授如何从背后用绳索或双臂压迫目标颈动脉，在数秒内让其失去意识而不发出声音。作者强调，成功的关键在于一开始就控制目标的下巴和手臂，防止任何挣扎和喊叫。中间章节讲解不同体型的技巧：高大者需要破坏重心，强壮者需要快速收紧，瘦弱者则要防止气管被压碎发出异响。作者强调，绞杀前必须先确认目标没有同伴在视线范围内，否则一切安静都毫无意义。后半本转入收尾：确认昏迷、决定是否补刀、如何处理遗体。末页有一根磨损的绞索被夹在书中，旁边写着：不要憎恨被你勒住的人，他只是选择了站在错误的安静里。书页间缠着一根磨损的绞索纤维。

## 设计意图

为盗贼系提供近距离无声击杀能力，强化潜入与单挑刺客玩法。
