# 《猫的九条命：坠落与翻滚》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0046`
- **关联技能**：`rogue_cat_fall`
- **使用效果**：阅读后解锁 `rogue_cat_fall`；若已学会，提升 `current_mastery +110`，并使从高处落下受到的伤害 `-15%`。
- **阅读要求**：基础 `敏捷 ≥ 10`；已学会 `rogue_silent_step`。
- **稀有度**：普通（Common）
- **建议投放**：城市屋顶训练师、盗贼公会体能室、杂技团遗物。

## 书籍内容

猫的九条命不是迷信，而是一套关于落地与缓冲的肌肉记忆。作者认为，从高处坠落时最危险的不是高度本身，而是落地瞬间身体僵硬。书中把安全落地分为三个动作：触地前伸展四肢增加空气阻力，落地时弯曲关节分散冲击力，触地后顺势翻滚把垂直动能转化为水平移动。中间章节讲解不同高度和地面的应对策略，以及如何在落地后立即恢复战斗姿态。后半本转入心理训练，教导如何在坠落时保持清醒，因为恐慌会让人忘记所有技巧。作者还记录了几次自己从高墙跌落后的修复过程，提醒读者即使掌握了技巧也要敬畏高度。末页有一幅简笔画，一只猫正从屋檐跃下，旁边写着：猫不是不会摔死，猫只是知道怎么不让自己摔成不能动的样子。

附录是坠落训练记录表，从低台到高墙逐级标注学习进度。表下写着：猫不是不会死，只是比大多数人更懂得在坠落时改变形状。

## 设计意图

为盗贼系提供立体机动生存能力，坠落减伤鼓励玩家利用城市地形进行垂直移动。
