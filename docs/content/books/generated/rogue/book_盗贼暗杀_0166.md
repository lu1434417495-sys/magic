# 《死者的身份：如何盗取人生》

## 书籍内容

盗取一个人的身份比杀一个人更难，因为你要同时拿走他的习惯、语气、记忆和恐惧，这本书的作者无名无姓，据说已经换过二十多个身份。这本书从收集目标物品开始：信件、首饰、衣物上的气味、甚至他惯用的口头禅。作者强调，模仿外表只是第一层，真正的身份盗窃需要理解目标与周围人的关系，知道他对谁恭敬、对谁敷衍、对谁撒谎。中间章节讲解如何处理突发质问：用模糊回答争取时间，把问题抛回去，或者假装情绪激动来中断对话。书中还警告，盗取身份过久的人会在梦中用目标的名字称呼自己。后半本转入心理代价：长期扮演另一个人会让自己的记忆产生裂痕。末页贴着半张撕毁的画像，画像旁写着：当你连镜子都认不出自己时，你才刚刚入门。书中夹着半张被涂抹的贵族画像。
