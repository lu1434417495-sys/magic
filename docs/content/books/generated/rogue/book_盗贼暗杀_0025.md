# 《恐惧播种：刺客的心理战》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0025`
- **关联技能**：`assassin_fear_seed`
- **使用效果**：阅读后解锁 `assassin_fear_seed`；若已学会，提升 `current_mastery +120`，并使被恐惧目标在下一次行动中 `-8%` 命中率。
- **阅读要求**：角色职业标签含 `assassin`；基础 `智力 ≥ 10` 或 `意志 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：心理战教官、恐怖组织据点、黑暗神殿藏书。

## 书籍内容

恐惧播种不是制造恐慌，而是让目标自己开始怀疑周围的一切。作者把恐惧分为三层：第一层怕死，第二层怕痛，第三层怕未知。最高明的刺客不杀目标，而是让目标在重重保护中依然感到不安全。书中教授如何在行动前留下暗示：一片不属于当地的羽毛、一滴排在特定位置的血、一句只有目标能听懂的低语。中间章节讲解节奏的掌握，恐惧需要时间来发酵，过早现身会让目标从恐惧转为愤怒。后半本转入自我防护，提醒施术者不要沉浸于扮演恐惧本身，否则会被自己制造的氛围反噬。末页有一段被涂黑的案例摘要，只剩一句话可见：他最终不是死于刀，而是死于不敢睡觉。

每章都以恐怖小故事结尾，最后一章结尾被整页涂黑。涂黑页边角写着：恐惧最深处的样子，不该被文字固定，只能在实践中体会。

## 设计意图

为刺客系提供控场与削弱技能，心理战定位扩展战斗外的剧情威慑选项。
