# 《瞳孔控制：在黑暗中视物》

- **书籍 ID**：`book_盗贼暗杀_0191`
- **关联技能**：`rogue_night_eye_advanced`

## 书籍内容

这本书教的不只是夜视，而是如何在黑暗中主动控制眼睛的适应能力，作者是一群被称为「夜之子」的地下种族成员。作者指出，突然从光亮处进入黑暗的人会暂时失明，而训练有素的盗贼可以通过闭眼、侧视和缓慢移动来缩短这个适应期。中间章节讲解如何利用边缘视觉：直视黑暗中的物体反而看不清楚，用余光捕捉轮廓和运动更有效。后半本转入反制光源：如何在火把、闪电或魔法光芒闪过时不被致盲，以及如何利用敌人的光源判断其位置。书中还教授如何在完全没有光的情况下依靠声音和温度来感知周围。末页有一幅眼球剖面图，瞳孔被放大，旁边写着：黑暗不是你看不见，是你还没学会用另一种方式看。书的插图瞳孔被刻意放大到不自然的程度。作者建议长期在地下活动的人每隔一段时间就要回到阳光下恢复视力。

## 设计意图

为盗贼系提供环境感知强化，让夜间与地下潜入更具优势。
