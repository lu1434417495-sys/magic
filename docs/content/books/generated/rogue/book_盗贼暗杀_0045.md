# 《心脏的弱点：穿透护甲的最后一击》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0045`
- **关联技能**：`rogue_piercing_strike`
- **使用效果**：阅读后解锁 `rogue_piercing_strike`；若已学会，提升 `current_mastery +130`，并使对重甲目标的首次攻击护甲穿透 `+6%`。
- **阅读要求**：基础 `敏捷 ≥ 11` 或 `力量 ≥ 10`；已装备匕首或短剑。
- **稀有度**：稀有（Rare）
- **建议投放**：护甲工匠黑市、军事刺客遗物、重甲敌人营地宝箱。

## 书籍内容

作者认为，任何护甲都有心脏，只是大多数人找不到它。书中用大量图解分析常见护甲的弱点：板甲的腋下、链甲的领口、皮甲的腰部接缝、鳞甲的腋下与胯部。作者强调，穿透护甲不是靠蛮力，而是靠角度、速度与精确度的结合。中间章节讲解一种名为针穿的技巧：把全身力量集中在刀尖一点，像缝纫针刺入布料一样穿透金属环或皮革层。后半本转入时机判断，指出重甲目标最脆弱的时刻不是静止时，而是抬手、转身或迈步时，因为这些动作会拉扯护甲的接缝。末页有一段关于武器选择的建议：细刃适合穿刺，重刃适合劈砍，但不要试图用错工具完成正确的事。

书末附护甲接缝穿透角度表，标注不同护甲最脆弱位置。表下写着：重甲战士相信钢铁保护自己，你的工作是找到钢铁之间的缝隙。

## 设计意图

为盗贼系提供反重甲能力，护甲穿透加成让盗贼在面对战士系敌人时不至于完全无力。
