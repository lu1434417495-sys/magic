# 《影之庭院：建立自己的暗影据点》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0199`
- **关联技能**：`rogue_shadow_court`
- **使用效果**：阅读后解锁 `rogue_shadow_court`；若已学会，提升 `current_mastery +180`，并使在据点内休息时潜行类技能熟练度成长 `+15%`。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `智力 ≥ 14` 且 `魅力 ≥ 12`。
- **稀有度**：传说（Legendary）
- **建议投放**：盗贼公会总会、隐藏势力据点任务、世界建造事件奖励。

## 书籍内容

真正的刺客不只是一个杀手，而是一个拥有一片影之庭院的人，这本书的作者是第一位统一地下盗贼公会的女王。这本书教授如何建立属于自己的秘密据点：从选址、人员招募到信息流转与资金洗白。作者认为，影之庭院的核心不是豪华，而是不可见：每个入口都有三重伪装，每个成员只知道自己的一小块拼图。中间章节讲解几种据点类型：城市地下网络、荒野废弃堡垒、移动的马车队、甚至是伪装成普通商铺的幌子。书中还讨论了据点扩张的极限：太大则难以隐藏，太小则无法自保。后半本转入统治：如何在不被发现的情况下管理一个阴影组织，如何让忠诚与恐惧保持平衡。末页有一张被涂黑的建筑平面图，只在角落写着：庭院越深，你自己也越难走出来。封面被涂黑，只在角落露出建筑轮廓。

## 设计意图

作为传说级组织经营技能，把个人成长扩展到据点与势力建设，强化后期玩法目标。
