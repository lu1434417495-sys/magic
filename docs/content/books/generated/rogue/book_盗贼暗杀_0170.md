# 《刺客的沉默誓言：心理封锁》

## 书籍内容

刺客可以失败，可以死亡，但不能开口，这条誓言被写在这本书的每一页页眉上。这本书教授如何在意识深处建立一道自我封印，让关键信息在极端压力下仍然无法被提取。作者把心理封锁比作一间上了无数把锁的房间：每把锁由不同的记忆、情绪和习惯守护，单独打破任何一把都无法进入核心。中间章节讲解自我暗示技术：把真实情报与痛苦记忆绑定，让敌人在逼问时反而触发自我保护机制。书中记载，最坚固的封印不是忘记，而是把真实记忆藏在无数相似的假记忆之中。后半本转入日常训练：如何在睡眠、醉酒和迷药作用下保持防线，如何识别并抵抗新式的精神魔法。末页只有一句话，反复写了九十九遍：我能说的，都是他们早已知道的。每一章开头都写着同一句话作为封印。据说这本书的读者中有三分之一最终选择了自我封印记忆。
