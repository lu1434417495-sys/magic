# 《盗贼的修炼：斗气潜行》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0193`
- **关联技能**：`cultivation_rogue_aura`
- **使用效果**：阅读后解锁 `cultivation_rogue_aura`（标签 `cultivation`）；若已学会，提升 `current_mastery +130`，并使斗气状态下潜行被发现距离 `-10%`。
- **阅读要求**：角色职业标签含 `rogue`；基础 `敏捷 ≥ 12` 且 `体质 ≥ 10`；已解锁 `AURA` 资源链。
- **稀有度**：稀有（Rare）
- **建议投放**：武馆暗影分支、斗气导师、盗贼公会传承任务。

## 书籍内容

斗气通常与正面搏杀联系在一起，但这本书探索了它的另一种用途：把斗气压缩在体表之下，让身体动作变得轻而无声。据说这种功法来自一位不愿正面作战的武者。作者认为，盗贼的斗气不该外放，而该内收，像一层紧贴骨骼的薄膜，既能增强爆发力，又不会泄露行踪。中间章节讲解如何在潜行时抑制斗气的波动，如何在出手瞬间把积蓄的斗气灌注到武器上。书中还附有一套专门强化脚踝与膝盖的静功，以保证在收敛斗气时仍能快速移动。后半本转入呼吸与斗气的配合：每一次呼气都是一次收敛，每一次吸气都是一次蓄力。末页有一幅经脉图，斗气流动的路径被画成虚线，旁边写着：最强的潜行不是没有气息，是让气息只属于你的刀。书页上有明显的斗气修炼者手印汗渍。书中警告，斗气内收过久会让盗贼在正面战斗中难以发力。

## 设计意图

把修炼系统与盗贼职业结合，提供资源联动与职业特色强化。
