# 《影织：用阴影编织斗篷》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0155`
- **关联技能**：`rogue_shadow_weave`
- **使用效果**：阅读后解锁 `rogue_shadow_weave`；若已学会，提升 `current_mastery +160`，并使低光环境下静止隐蔽 `+20%`。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `敏捷 ≥ 14` 且 `智力 ≥ 10`；已学会 `rogue_shadow_meld` 或 `rogue_silent_step`。
- **稀有度**：史诗（Epic）
- **建议投放**：影界裂隙导师、古代刺客陵墓、史诗级潜行任务奖励。

## 书籍内容

影织不是幻术，而是一种对光线的极致利用，作者自称曾在影界生活过三年。作者认为阴影并非空无，而是由无数微弱光线被遮挡后形成的褶皱，熟练者可以把自己的轮廓藏进这些褶皱之中。书中前半部教授如何观察光源的位置、强度和移动规律，从而预判阴影何时会加深、何时会消失，甚至如何利用云层的移动改变大片战场的光影。中间章节讲解披风、衣物与皮肤在阴影中的反光差异，教导如何用深色织物与煤灰调整自身亮度，使皮肤看起来接近石墙或树皮。后半本转入移动中的影织：如何在阴影边缘滑行而不踏入光亮，如何利用敌人举起的火把制造新的遮蔽。末页有一幅几何图形，像是把一个人拆成了无数黑色碎片，配文：先成为阴影的一部分，再让阴影替你穿衣。封面材质像某种暗色鳞片，摸起来却比丝绸更凉。读者翻阅时常会觉得自己的影子在变重。

## 设计意图

为高阶盗贼提供环境互动型隐蔽能力，强化光影地形在潜行玩法中的策略价值。
