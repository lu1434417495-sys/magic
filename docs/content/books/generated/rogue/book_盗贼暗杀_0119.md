# 《昏睡粉：非致命选项》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0119`
- **关联技能**：`rogue_sleep_powder`
- **使用效果**：阅读后解锁 `rogue_sleep_powder`；若已学会，提升 `current_mastery +110`，并使昏睡效果的持续时间延长 0.8 秒。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `智力 ≥ 8`。
- **稀有度**：精良（Uncommon）
- **建议投放**：草药师暗室、医院地下室、慈善修女会暗格。

## 书籍内容

不是所有任务都需要尸体。这本书介绍了一种用蓝铃花、曼陀罗籽与蜂蜜调和的昏睡粉，能在十秒内让目标陷入可逆的深睡。作者详细记录了不同体型与体质的生效时间差异，并警告：对呼吸疾病患者可能致命，使用前必须观察目标是否有哮喘或慢性咳嗽。书中还讲解了投放方式：吹管适合远距离，手帕适合近身，混入饮品适合长期潜伏。中间有一章专门讨论解药与急救，强调非致命意味着你也要对目标醒来后的状态负责。末页用娟秀字迹写着：让人睡去很容易，难的是让他醒来后不恨你。

封皮内侧贴着一小包用蜡封好的蓝色粉末，标签写着"慎用"；书脊中藏着一根细小的吹管，内壁还残留着药粉，散发出淡淡的甜腻气息。书中还讲解了一种特殊的呼吸法，能让施术者在投放粉末时不被自己的药物反噬。

## 设计意图

为盗贼系提供非致命控场技能，扩展潜行玩法的道德与战术选择空间。
