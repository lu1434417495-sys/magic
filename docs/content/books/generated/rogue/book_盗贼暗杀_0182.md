# 《情报网络：线人培养手册》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0182`
- **关联技能**：`rogue_informant_network`
- **使用效果**：阅读后解锁 `rogue_informant_network`；若已学会，提升 `current_mastery +110`，并使城镇中随机获得额外情报事件的概率 `+15%`。
- **阅读要求**：角色职业标签含 `rogue`；基础 `魅力 ≥ 10` 且 `智力 ≥ 10`。
- **稀有度**：精良（Uncommon）
- **建议投放**：盗贼公会情报室、酒馆老板、城市密探任务奖励。

## 书籍内容

一个人的眼睛看不了整座城市，但一群人的眼睛可以，这本书的作者曾掌控过一个王都的地下情报网。这本书教授如何建立和维护线人网络：从乞丐、侍女、车夫到小官吏，每个人都有自己的价码和信息半径。作者把线人分成三种：靠钱驱动的、靠恐惧驱动的、靠理想驱动的，每种都需要不同的维护方式。作者认为，最好的线人往往不是贪婪者，而是有秘密需要守护的人。中间章节讲解情报交叉验证：如何通过多个线人的描述拼出真相，以及如何识别有人被收买后提供的假情报。后半本转入网络保护：如何让线人彼此不知道对方存在，如何在某个节点暴露时迅速切断联系。末页是一张密密麻麻的关系图，节点用小圆点表示，旁边写着：信息不会自己流动，它需要被喂养。书中夹着一张画满节点的关系草图。

## 设计意图

为盗贼系提供探索与世界互动增益，鼓励建立长期情报资产。
