# 《血之回响：追踪伤口的技能》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0031`
- **关联技能**：`rogue_blood_track`
- **使用效果**：阅读后解锁 `rogue_blood_track`；若已学会，提升 `current_mastery +110`，并使追踪受伤目标时移动速度 `+5%`。
- **阅读要求**：基础 `感知 ≥ 11`；角色职业标签含 `rogue` 或 `ranger`。
- **稀有度**：精良（Uncommon）
- **建议投放**：猎人营地、刺客追踪者、血迹斑斑的猎物尸体旁。

## 书籍内容

血之回响的作者是一名猎手，但他追踪的不是足迹，而是伤口。书中认为，一个有伤在身的人会留下比正常人更丰富的信息：血迹的形状说明移动速度，滴落的间隔说明是否被搀扶，血液的颜色说明伤势轻重。中间章节教授如何区分新旧血迹，如何判断目标是否在中途停下来包扎，以及如何识别故意制造的假血迹。作者还提醒，追踪者最大的危险不是跟丢，而是跟得太近被反埋伏。后半本转入战斗应用，讲解如何在追踪过程中推测目标剩余体力，从而决定是追击还是设伏。末页有一段手写笔记，记录了一次长达三天的追踪，最后一行写着：我追上他的时候，他已经没有血可以再流了，但我的眼睛还在追。

书末附血迹形态速查表，从滴落形状到喷溅角度都有图示。表下写着：追踪不是追赶，是从目标伤口里读取他的下一步。

## 设计意图

为盗贼系提供追击与狩猎能力，移动速度加成让追踪玩法更具反馈感。
