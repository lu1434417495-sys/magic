# 《兽筋弓弦再造》

## 基础信息

- **书籍 ID**：`book_弓手射术_0078`
- **关联技能**：`archer_bow_crafting`、`archer_bow_maintenance`
- **使用效果**：阅读后解锁 `archer_bow_crafting`；若已学会，提升 `current_mastery +130`，并解锁复合弓配方 `composite_bow_beast_sinew`。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；已学会 `archer_bow_maintenance`；基础 `力量 ≥ 10`，`智力 ≥ 8`。
- **稀有度**：精良（Uncommon）
- **建议投放**：部落制弓师、荒野工匠营地、野兽狩猎大师奖励。

## 书籍内容

《兽筋弓弦再造》记录了北方部落用野兽肌腱制作复合弓的古老技艺。作者详细描述了如何挑选合适的肌腱：龙筋太强，凡人拉不动；鹿筋太弱，不适合战斗；牛筋和麋鹿筋的混合比例被反复测试。书中还讲解了如何将肌腱与木胎、角片层层粘合，以及如何在制作过程中用体温让胶料保持柔软。最困难的部分是“调弦”：新弓在最初几天会不断变形，制弓师必须每天微调弦长。作者也提到，用智慧生物的筋制作弓弦会带来诅咒，这一点在多个部落传说中都有印证。书的后半部是一部短诗集，歌颂那些为制作强弓而献出生命的野兽。部落里的制弓师会把失败品埋在图腾柱下，相信这样能安抚野兽的灵魂。部落的年轻制弓师需先亲手猎取第一只野兽，方可学习此法。习得此法需要相当的耐心。

## 设计意图

将弓手与装备制造系统连接，为生活型玩家提供成长路径。
