# 《箭囊管理与速取术》

## 基础信息

- **书籍 ID**：`book_弓手射术_0005`
- **关联技能**：`archer_quiver_manage`、`archer_quick_draw`
- **使用效果**：阅读后解锁 `archer_quiver_manage`；若已学会，提升 `current_mastery +70`，并使战斗中首次换箭动作加快 15%。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；基础 `敏捷 ≥ 7`。
- **稀有度**：普通（Common）
- **建议投放**：游侠补给站、野外猎人营地、初级装备商人。

## 书籍内容

《箭囊管理与速取术》的作者自称曾在一场遭遇战中因取错箭而失去了三根手指。全书围绕一个核心问题展开：在混乱中，你的手能不能在不到一秒内找到正确的箭。书中介绍了三种常见箭囊布局：按用途分区、按箭长排列、按箭头重量分层。作者还提醒，箭羽必须保持完整，断裂的羽尾会严重影响飞行稳定性。后半本讲解了不同姿势下的取箭路线，包括站姿、跪姿和移动中的动作优化。书中附有一张手绘的箭囊剖面图，标注了每个格子的理想内容。最后一句话被加粗：战场上没有慢动作，你的手指必须比眼睛更快。作者还建议在箭囊外侧用不同颜色的布条标记特殊箭矢，以便在黑暗中凭触觉快速区分，避免在关键时刻摸到一支错误的箭。真正经历过混战的人都明白，胜负有时不取决于射得多准，而取决于你能否在下一支箭到来之前把它握在手里。

## 设计意图

为弓手系引入资源管理与操作节奏概念，让玩家意识到射速不仅取决于弓，也取决于准备工作。
