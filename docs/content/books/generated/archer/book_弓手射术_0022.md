# 《听声辨位射术》

## 基础信息

- **书籍 ID**：`book_弓手射术_0022`
- **关联技能**：`archer_sound_shot`、`archer_night_shot`
- **使用效果**：阅读后解锁 `archer_sound_shot`；若已学会，提升 `current_mastery +110`，并在目盲或浓雾中首次射击命中判定 +10%。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；已学会 `archer_night_shot`；基础 `感知 ≥ 11`。
- **稀有度**：精良（Uncommon）
- **建议投放**：盲眼射手传承、雾中哨塔、感知训练教官。

## 书籍内容

《听声辨位射术》是一本为极端环境写的书。作者假设读者已经看不见目标，只能依靠声音判断方位、距离和体型。书中详细讲解了不同材质盔甲、不同体型生物移动时发出的声音差异，以及如何通过回声判断周围地形。作者设计了一套蒙眼练习：由同伴在不同位置发出声响，射手必须在三秒内完成转向、拉弓和射击。后半本讨论了风声、雨声和其他环境噪音如何干扰判断，并提供了几种降噪与聚焦的方法。最末页只有一句话：当眼睛休息的时候，耳朵要学会成为眼睛。据说盲眼射手组织的入门试炼就是凭这本书完成的第一箭，而能够通过试炼的人，往往能在最浓的雾中射中目标。在浓雾或漆黑中，听力成了唯一的瞄准器，而那些曾经嘲笑这种训练的人，往往会在第一次失去视力后重新捡起这本书。

## 设计意图

扩展弓手在低能见度环境下的作战能力，与 debuff/环境机制联动。
