# 《恐惧箭》

## 基础信息

- **书籍 ID**：`book_弓手射术_0177`
- **关联技能**：`archer_terror_arrow`（待新增）
- **使用效果**：阅读后解锁 `archer_terror_arrow`；若已学会，提升该技能 `current_mastery +110`，并使恐惧箭命中后下一回合降低敌人 `15%` 攻击力。
- **阅读要求**：职业标签含 `archer` 或 `ranger`；基础 `感知 ≥ 12` 且 `意志 ≥ 11`。
- **稀有度**：稀有（Rare）
- **建议投放**：暗影行会、心理战训练营、恐怖传说事件。

## 书籍内容

《恐惧箭》教授如何利用特殊的鸣镝与造型在敌人心中播撒恐惧。作者认为，弓手不仅能杀伤肉体，还能瓦解敌人士气。前半本讲解箭镞造型：镂空铁镞在风中会发出尖啸，酷似夜枭啼鸣。中章讨论射击位置选择，从阴影与高处射出的箭更容易让敌人感到被未知力量监视。后半本介绍如何配合假目标与回声制造"无处不在"的错觉。书中还提到，恐惧效果对意志薄弱的敌人最为显著，面对精英单位则大打折扣。作者提醒，恐惧箭不应滥杀无辜，否则射手自身也会被恐惧反噬。末尾附有一张心理承受力测试表，帮助判断目标是否易受恐惧影响。

书页间夹着一根猫头鹰羽毛，旁边标注：声音本身就能让意志薄弱者腿软。作者还建议使用涂黑的箭杆与消音羽毛，让敌人在听见尖叫前已经中箭倒地。

## 设计意图

为弓手提供软控与心理战能力，通过减益效果削弱敌人输出，增强战术多样性。
