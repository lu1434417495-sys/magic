# 《寒霜晶簇箭》

## 基础信息

- **书籍 ID**：`book_弓手射术_0061`
- **关联技能**：`archer_frost_arrow`、`archer_flame_arrow`
- **使用效果**：阅读后解锁 `archer_frost_arrow`；若已学会，提升 `current_mastery +140`，并使寒霜箭对燃烧目标额外造成一次碎裂伤害。
- **阅读要求**：角色职业标签含 `archer` 或 `mage`；基础 `智力 ≥ 9`，`感知 ≥ 8`。
- **稀有度**：精良（Uncommon）
- **建议投放**：冰封峡谷据点、元素法师藏书、霜巨人战利品。

## 书籍内容

《寒霜晶簇箭》的作者是北方冻原一位兼具法师身份的游侠，她声称低温本身就可以成为一种箭矢。书中教导读者如何在箭镞上镶嵌细小的冰晶簇，这些冰晶在命中时会爆裂开来，将寒气注入伤口周围。与普通火焰箭追求持续燃烧不同，寒霜箭的价值在于“迟滞”：让敌人的关节僵硬、动作变慢，甚至让金属护甲与皮肤冻在一起。作者特别写了一章关于“热震”的战术，即先用火焰箭加热护甲，再用寒霜箭急速冷却，造成金属脆裂。她也警告这种技巧对射手自己的弓弦损耗极大，必须在每次战斗后重新上蜡保养。书页边缘结着一层薄薄的霜，仿佛它一直存放在某个永远冬天的房间里。北方冻原的游侠把这种箭称为“冬天的邀请函”，因为被命中者往往会在数分钟内失去行动能力。冰晶簇必须在使用前一刻安装，否则会提前吸收周围湿气。

## 设计意图

提供与火焰箭形成联动的元素控制技能，鼓励玩家尝试元素反应流派。
