# 《多重瞄准》

## 书籍内容

《多重瞄准》训练弓手在瞬息之间切换多个目标并维持较高命中率。作者认为，战场不会只有一个敌人，僵化地盯死一人往往错失战机。前半本讲解眼球快速移动：在目标之间跳跃时不失去中心视野。中章提供优先级切换口诀，根据威胁程度与距离决定下一箭射向谁。后半本介绍如何在移动靶之间分配注意力，避免被单一目标的复杂动作带乱节奏。书中还提到，多重瞄准适合配合速射使用，在敌群中制造混乱。作者提醒，初学者容易陷入"看多射少"的困境，应先练双目标再扩至多目标。末尾附有训练靶位图，要求从左中右三个方向连续射击。

一位战术家在书页上批注：战场上的弓手不是狙击手，而是节奏指挥官。他建议先以多重瞄准锁定威胁最高的三名敌人，再按距离与移动方向依次射杀。

## 设计意图

为弓手提供多目标处理能力，提升混战中的输出效率与战术灵活性。
