# 《弓弦消音术》

## 基础信息

- **书籍 ID**：`book_弓手射术_0050`
- **关联技能**：`archer_bow_silence`、`archer_forest_stealth`
- **使用效果**：阅读后解锁 `archer_bow_silence`；若已学会，提升 `current_mastery +100`，并使首次偷袭射击的破空声降低 30%。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；已学会 `archer_forest_stealth`；基础 `敏捷 ≥ 9`。
- **稀有度**：精良（Uncommon）
- **建议投放**：潜行专家营地、刺客公会边缘书架、夜间猎手任务。

## 书籍内容

《弓弦消音术》是为那些需要安静结束战斗的射手写的。作者指出，弓弦震动的声音有时比箭矢破空声更致命，因为它会暴露射手的位置。书中讲解了如何通过上蜡、加装弦减震器和调整拉距来降低弦音，以及如何选择低噪音的箭杆材质。作者还提醒，消音不能以牺牲威力为代价，否则就会从暗杀变成提醒。后半本收录了几次成功潜入行动中的消音射击案例。最末页有一句话：最好的箭，是目标倒下后周围人才意识到的箭。潜行专家营地的学员会在结业前接受一项测试：在寂静的夜里射中烛火，而不惊醒隔壁房间里的人，因为真正的无声射手连火光都会替他们保密，也连敌人最后的惊愕都吝啬给予。训练场上的教官们，总是把这本书放在最显眼的位置。无论是新手还是老兵，只要还在拉弓，就值得偶尔重读这本书。
