# 《双人配合：牵制与收割》

## 书籍内容

《双人配合：牵制与收割》认为，两名弓手配合时的威力远大于两人各自为战。作者介绍了一压一收的基本模式：一名弓手用连续射击压制目标的移动，另一名则在目标停顿的瞬间完成致命一击。书中详细讲解了换位、交替装填和火力衔接的时机，并强调沟通比技术更重要。作者还提供了几套简单的口令，方便在噪音环境中快速协调。后半本分析了双人配合中常见的失误，比如同时射向同一个目标或同时进入装填空档。最末页有一句话：两个弓手之间最远的距离，不是站位，是默契。边境巡逻队经常让新人弓手结对练习，直到他们能无声完成一压一收，因为真正的配合不需要语言。两个人配合的最高境界，是压制者知道收割者何时会出手，而收割者也信任压制者会为他创造出那一刻。

## 设计意图

鼓励多人协作，为组队玩法中的弓手配合提供机制奖励。
