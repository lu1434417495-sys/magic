# 《血祭追魂箭》

## 基础信息

- **书籍 ID**：`book_弓手射术_0084`
- **关联技能**：`archer_blood_arrow`、`archer_critical_eye`
- **使用效果**：阅读后解锁 `archer_blood_arrow`；若已学会，提升 `current_mastery +200`，并使血祭箭命中弱点时回复造成伤害 10% 的生命值。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；已学会 `archer_critical_eye`；基础 `感知 ≥ 14`，`意志 ≥ 12`。

- **建议投放**：血月祭坛、禁忌猎场、远古猎人墓穴宝箱。

## 书籍内容

《血祭追魂箭》是一本被大多数正派游侠销毁的禁典，但仍有一些抄本在黑暗中流传。书中记载了一种古老的血箭术：射手用自己的血涂抹箭镞，使箭矢与目标的血脉产生共鸣，无论对方逃到何处都难以摆脱追踪。作者警告，这种技艺代价巨大，每次使用都会消耗射手的生命力，如果使用过于频繁，箭矢会先追到自己身上。书中还记载了如何以敌人的血为引进行反向追踪，以及如何在月圆之夜强化血箭的威力。最恐怖的章节描述了一群被称为“血猎者”的古代弓手，他们会把敌人的血封存在箭囊中，让每一支箭都记住仇恨。书的纸张呈暗红色，似乎本身就被血浸泡过。血猎者的后裔至今仍在暗中活动，他们用祖先传下的血囊延续着这场古老的猎杀。血箭一旦离弦，射手与目标之间会产生短暂的精神连接。

## 设计意图

作为高风险高回报的生命汲取型技能，为后期弓手提供极限续航选项。
