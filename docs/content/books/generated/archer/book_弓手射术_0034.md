# 《雨天射箭要诀》

## 基础信息

- **书籍 ID**：`book_弓手射术_0034`
- **关联技能**：`archer_rain_shot`、`archer_wind_reading`
- **使用效果**：阅读后解锁 `archer_rain_shot`；若已学会，提升 `current_mastery +90`，并在雨天降低箭矢受风力偏移的惩罚。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；基础 `感知 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：湿地哨塔、雨季游侠营地、气象观测站藏书。

## 书籍内容

《雨天射箭要诀》开篇就说：雨不是风的替代品，它是风的帮凶。作者讲解了雨滴对箭矢飞行的多重影响：增加重量、改变重心、模糊视线，以及让弓弦吸水后弹性下降。书中建议雨天使用更重的箭头以抵抗下坠，并在箭羽上涂抹防水油脂。作者还提醒，湿滑的手指容易在放弦时打滑，必须保持护具干燥。后半本讨论了不同雨势下的射击策略：小雨可以继续精准射击，大雨则应转为压制或撤退。最末页有一句话：雨会让敌人也变慢，所以不要怕雨，要学会比雨更快。湿地哨塔的守军把这句话刻在箭台上，作为雨季执勤的座右铭，因为抱怨天气从来不会让箭矢飞得更直，只会让你分心。弓手公会把它列为入门考核的参考书目之一。弓手公会把它列为入门考核的参考书目，也是许多人成长的第一块基石。
