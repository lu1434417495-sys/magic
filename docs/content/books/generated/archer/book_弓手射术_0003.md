# 《瞄准：三点一线》

## 基础信息

- **书籍 ID**：`book_弓手射术_0003`
- **关联技能**：`archer_basic_aim`、`archer_aimed_shot`
- **使用效果**：阅读后解锁 `archer_basic_aim`；若已学会，提升 `current_mastery +80`，并在下一次战斗中为首次命中弱点提供 +5% 伤害加成。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；基础 `感知 ≥ 7`。
- **稀有度**：普通（Common）
- **建议投放**：风息哨塔训练场、新手游侠委托奖励、基础射术商人。

## 书籍内容

《瞄准：三点一线》把复杂的瞄准过程简化为一句口诀：箭尾、箭首、目标，连成一线。作者用大量插图展示不同距离下准星与目标的相对位置，提醒读者不要死盯箭头，而要让整条箭杆成为参考线。书中列举了新手的三大错觉：以为瞄得越高射得越远、以为眼睛看的是目标其实看的是弓、以为静止就能命中其实忽略了弓弦的回弹。每一章结尾都有一张靶纸示意图，标注了常见偏差的修正方向。作者在最后写道：瞄准不是把箭放出去，而是让身体相信箭已经在了。许多教官把这句话写在训练场墙上。初学者往往要花上几周才能体会其中含义，因为真正的瞄准发生在大脑里，而不是眼睛里，只有当你不再刻意寻找目标时，目标才会清晰地出现在箭尖上。真正掌握后，你会发现目标不再是一个点，而是一条由箭杆延伸出去的线，终点自然而然地落在它该落的地方。

## 设计意图

作为弓手基础命中技能的教学书，降低射击上手难度，同时预埋弱点命中机制的教学。
