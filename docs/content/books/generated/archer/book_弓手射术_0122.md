# 《夜眼弓手守则》

## 基础信息

- **书籍 ID**：`book_弓手射术_0122`
- **关联技能**：`archer_night_shot`（待新增）
- **使用效果**：阅读后解锁 `archer_night_shot`；若已学会，提升该技能 `current_mastery +120`，并提升夜间首次射击的暴击率。
- **阅读要求**：职业标签含 `archer` 或 `ranger`；基础 `感知 ≥ 12`。
- **稀有度**：精良（Uncommon）
- **建议投放**：夜巡队据点、月神殿藏书房、盗贼区情报站。

## 书籍内容

夜眼弓手守则的每一页都用暗色墨水写成，在正常光线下难以辨认，但在月光下却清晰可见。作者是一位专精于夜间行动的游侠。前半本讲夜视保护：如何在白天保持瞳孔敏感，如何在进入黑暗前闭眼适应。中章讲夜间瞄准的技巧：不要直接看目标，而要看目标周围的光影变化；月亮位置如何影响视野，如何利用敌人的火把暴露其位置。后半本讨论夜间射击的心理压力：黑暗会放大声音，也会放大恐惧。作者建议射手在夜战前进行冥想，稳定心跳。作者在最后提醒，夜间射击时最忌讳盯着火把或月光看，因为瞳孔收缩后需要数秒才能恢复。真正的高手会利用敌人的光源，同时让自己的眼睛始终适应黑暗。

守则中还有一种"借光瞄准"技巧：当敌人举着火把靠近时，利用火光在对方脸上投下的阴影判断其朝向。这需要极强的夜视能力和冷静心态。

## 设计意图

为弓手提供夜间作战专长，与刺客、盗贼的夜战定位形成差异化互补。
