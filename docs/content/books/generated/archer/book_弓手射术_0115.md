# 《磷火箭制作简编》

## 基础信息

- **书籍 ID**：`book_弓手射术_0115`
- **关联技能**：`archer_flame_arrow`（待新增）
- **使用效果**：阅读后解锁 `archer_flame_arrow`；若已学会，提升该技能 `current_mastery +110`，并提升火焰箭对可燃环境的伤害加成。
- **阅读要求**：职业标签含 `archer` 或 `ranger`；基础 `智力 ≥ 9`。

- **建议投放**：军械库、炼金商人、灰烬交界营地。

## 书籍内容

磷火箭制作简编是一本被烧掉三分之一的书，但剩下的部分依然实用。作者详细记录了磷粉的配比、引火布的卷法、以及如何在箭头上固定燃料而不影响飞行平衡。前半本讲原理：火焰会扰乱箭尾气流，因此火箭的羽毛必须更短更硬，重心要略向前移。中章收集了七种引火配方，从廉价的松脂混合物到昂贵的炼金磷油。后半本讨论战术使用：点燃草垛制造混乱、射击敌方储油罐、在夜间用火箭传递信号。书中还记载了"冷火箭"与"热火箭"的区别：前者用磷粉缓慢引燃适合持续烧伤，后者用油脂猛烈燃烧适合瞬间爆发。作者特别提醒，火箭射手必须计算好风向，否则火星会反扑自己。

热火箭的配方旁有一个骷髅标记，表示这种配方曾在训练中引发过严重烧伤。作者建议只有经验丰富的射手才能使用，新手应从冷火箭开始。

## 设计意图

为弓手提供元素射击与场景互动能力，增强战斗中的环境利用维度。
