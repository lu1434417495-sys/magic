# 《射手的呼吸课》

## 基础信息

- **书籍 ID**：`book_弓手射术_0002`
- **关联技能**：`archer_breath_control`、`archer_aimed_shot`
- **使用效果**：阅读后解锁 `archer_breath_control`；若已学会，提升该技能 `current_mastery +70`，并使下一次战斗中的首次瞄准时间缩短 10%。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；基础 `体质 ≥ 7`。
- **稀有度**：普通（Common）
- **建议投放**：风息哨塔入门书架、游侠导师基础课程、初级呼吸法教官。

## 书籍内容

《射手的呼吸课》只有短短十二页，却被认为是射术进阶的隐形门槛。作者没有教任何拉弓技巧，而是把呼吸拆成四个阶段：吸气、屏息、微吐、释放。书中指出，大多数新手在瞄准时会无意识地憋气，导致肌肉颤抖；正确的做法是在呼气末端扣弦，让身体进入自然的稳定状态。作者设计了一套每日练习：站定、闭眼、只感受呼吸，直到能在三十秒内不刻意控制而让呼吸自动平稳。后半本讲解了移动中的呼吸节奏，要求射手在奔跑后五秒内恢复可射击状态。书的扉页写着：弓手的气息比箭飞得更远。许多资深游侠认为，这本书真正的价值不在于立竿见影的准度提升，而在于它让射手学会把身体当作一张更稳定的弓，在每一次拉弦前都能找到属于自己的节奏。训练场上最常见的错误是急于拉弓，而那些先学会呼吸的人往往能在数月后射出更稳定的一箭。

## 设计意图

将呼吸控制确立为弓手稳定输出的前置条件，为后续所有精准射击技能提供底层支撑。
