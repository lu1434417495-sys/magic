# 《跪姿稳定射击》

## 基础信息

- **书籍 ID**：`book_弓手射术_0063`
- **关联技能**：`archer_kneeling_shot`、`archer_aimed_shot`
- **使用效果**：阅读后解锁 `archer_kneeling_shot`；若已学会，提升 `current_mastery +110`，并在跪姿下首次射击获得 +10% 命中率。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；基础 `敏捷 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：军团弓手训练场、战场遗迹、标准战术教材。

## 书籍内容

《跪姿稳定射击》是许多正规军弓手的第二本教材，内容枯燥但实用。作者用大量图示讲解单膝跪地时如何将重心压在脚跟上，如何用另一侧手肘支撑弓身，以及如何在起身时避免箭矢晃动。书中指出，跪姿牺牲了移动能力，但换取了堪比站姿两倍的稳定性，尤其适合在城墙上或狭窄通道中作战。作者还讨论了几种地面状况下的调整：泥泞地面需要垫膝盖，碎石地面需要找平坦处，雪地则要防止单膝下沉。一个常被忽视的细节是呼吸方式：跪姿时膈肌受压，必须改用腹式呼吸才能维持满弦。书的空白处写满了前任读者的批注，其中一条说：“跪姿让你成为靶子之前，先让你成为死神。”在正规军考核中，跪姿射击成绩不合格的弓手会被调去担任辅兵或后勤。跪姿射击是城防弓手的必修课，也是许多战役的胜负手。

## 设计意图

补充弓手的姿态技能树，为定点输出和掩体射击提供战术选择。
