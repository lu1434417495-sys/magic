# 《姿态转换：站跪趴》

## 基础信息

- **书籍 ID**：`book_弓手射术_0049`
- **关联技能**：`archer_stance_transition`、`archer_kneeling_shot`
- **使用效果**：阅读后解锁 `archer_stance_transition`；若已学会，提升 `current_mastery +100`，并减少战斗中切换射击姿态的时间。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；已学会 `archer_kneeling_shot`；基础 `敏捷 ≥ 9`。
- **稀有度**：精良（Uncommon）
- **建议投放**：战术射击教官、边境机动营地、游侠进阶课程。

## 书籍内容

《姿态转换：站跪趴》把弓手的姿态看作流动的状态，而非固定姿势。作者讲解了如何根据掩体高度、敌我距离和体力状况在站姿、跪姿和卧姿之间快速切换，并保证每次切换后都能迅速恢复瞄准。书中强调，姿态转换的关键不是速度，而是转换后的第一箭质量。作者设计了一套练习：听到指令后三秒内完成姿态切换并命中目标。后半本讨论了不同地形对姿态选择的限制。最末页有一句话：弓手不是一棵树，而是一只随时准备改变形状的动物。战术射击教官会让学员在泥地里反复转换姿势，直到他们能无视污秽完成射击，因为战场上没有干净的位置，只有还活着的射手，而活着的射手懂得随机应变。学会它，意味着你已经开始用弓手的眼睛重新审视世界。在弓手的小圈子里，能背出这本书最后一句话的人总会赢得额外的尊重。

## 设计意图

提升弓手在复杂地形中的适应能力，为掩体战和动态射击提供支持。
