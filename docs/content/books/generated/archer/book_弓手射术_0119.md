# 《扇形散射术》

## 书籍内容

扇形散射术的作者是一位竞技场射手，专门在混战中同时压制多个敌人。书中提出"扇面"概念：以目标群为中心，将箭矢像扇子一样散开，不求每一箭都致命，但求每一箭都制造威胁。前半本讲手法：如何在极短时间内连续取箭、调整角度、不完全拉满就发射。中章分析最佳使用距离：太近会让箭束重叠浪费，太远会让散射过度稀疏。书中还提到，扇形散射最适合对付横向展开的敌人队列，而不是前后排列的纵队。后半本则用竞技场战例说明如何在移动中完成扇形射击，以及如何利用队友的控制技能制造静止目标群。最后一章警告："扇形散射是赌博，赌的是敌人不会同时躲向同一个方向。"

扇形散射的扇面角度被精确标注为十五度、三十度和四十五度三种。作者认为角度过大或过小都会让散射效果大打折扣，必须根据敌群密度灵活选择。

## 设计意图

为弓手提供群体打击与混战能力，强化其在多人战斗中的存在感。
