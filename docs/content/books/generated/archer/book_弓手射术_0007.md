# 《移动射击步法》

## 基础信息

- **书籍 ID**：`book_弓手射术_0007`
- **关联技能**：`archer_mobile_shot`、`archer_feather_step`
- **使用效果**：阅读后解锁 `archer_mobile_shot`；若已学会，提升 `current_mastery +100`，并使移动中首次射击的命中率惩罚减半。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；基础 `敏捷 ≥ 9`。
- **稀有度**：普通（Common）
- **建议投放**：游侠机动训练场、边境斥候营地、风息哨塔进阶课程。

## 书籍内容

《移动射击步法》的核心理念是：弓手不是炮台。作者把移动射击分为稳定步、跨步射和急停射三种基础模式，分别对应不同的敌我距离。书中强调，射击的最佳时机是双脚即将交替落地的瞬间，此时上半身的晃动最小。作者还设计了一套木桩练习：在九个木桩之间跑动，每到指定木桩必须完成一次射击并命中。后半本讨论了地形的影响，提醒读者在斜坡、碎石和泥泞中如何调整步幅。最末一页有一幅简笔画，画中弓手正以奇怪的姿势单脚点地放箭，配文：姿势难看不要紧，关键是重心别飞出去。许多教官会把这幅画贴在训练场门口，提醒学生不要迷信漂亮的站姿，因为战场上能命中的姿势才是好姿势。战场上最危险的弓手不是站得最稳的，而是那个能在奔跑、转身和跌倒边缘仍然放出致命一箭的人。

## 设计意图

打破弓手必须站定输出的刻板印象，为风筝战术和战场机动提供技能基础。
