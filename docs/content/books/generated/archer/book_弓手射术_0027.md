# 《鸣镝示警录》

## 基础信息

- **书籍 ID**：`book_弓手射术_0027`
- **关联技能**：`archer_signal_arrow`、`archer_sound_shot`
- **使用效果**：阅读后解锁 `archer_signal_arrow`；若已学会，提升 `current_mastery +80`，并使鸣镝响声的警戒范围扩大 20%。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；基础 `感知 ≥ 8`。

## 书籍内容

《鸣镝示警录》是一本关于不杀之箭的书。作者详细介绍了不同响声的箭矢如何传递不同信息：短促两声代表敌袭，长鸣一声代表集合，急促三声代表撤退。书中还讲解了如何利用空腔箭头在飞行时产生更尖锐的声音，以及如何在不同风向中让声音传得更远。作者提醒，示警箭的位置本身也在传递信息，射得太近会让队友误判距离。后半本收录了一套简化信号表，方便小队快速记忆。最末页有一句话：有时候，一支响箭比十支毒箭更能救下整个队伍。边境哨兵会在箭囊最外层专门留出一支鸣镝，以备不时之需，因为他们知道在荒野中，声音有时候比箭矢本身更能决定一群人的生死。在无声的边境夜晚，一声鸣镝可能就是生与死的分界线。它不是通往巅峰的捷径，而是让你在漫长旅途中少摔几个跟头的拐杖。

## 设计意图

为弓手提供非战斗功能性技能，强化团队沟通与战术预警能力。
