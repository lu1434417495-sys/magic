# 《伪装等待术》

## 基础信息

- **书籍 ID**：`book_弓手射术_0138`
- **关联技能**：`archer_camouflage`（待新增）
- **使用效果**：阅读后解锁 `archer_camouflage`；若已学会，提升该技能 `current_mastery +110`，并提升静止隐蔽时的先手暴击率。
- **阅读要求**：职业标签含 `archer` 或 `ranger`；基础 `感知 ≥ 11` 且 `智力 ≥ 9`。
- **稀有度**：精良（Uncommon）
- **建议投放**：猎人行会、荒野潜行任务、游侠密林据点。

## 书籍内容

伪装等待术教弓手如何成为环境的一部分。作者强调，最好的伪装不是把自己藏进灌木丛，而是让敌人的眼睛滑过你。前半本讲解色彩匹配、轮廓破坏和光影利用。中章讲等待的艺术：如何在同一位置保持数小时不动，如何在肌肉酸痛时调整呼吸而不被发现。后半本讨论心理伪装：如何在敌人靠近时控制自己的恐惧和杀意，避免被对方直觉察觉。作者还提供了一套利用自然材料快速制作伪装网的方法。作者在后记中写道，最危险的等待是"以为自己藏好了"。他建议伪装者每隔一段时间就让自己换一个观察角度，因为敌人的视线习惯会不断变化。最后一页写着："等待不是什么都不做，是把所有动作都藏进风里。"

自然材料伪装网的效果只有近距离才明显，作者建议在敌人可能经过的路径上预先布置，而不是临时寻找掩护。这需要对战场的提前熟悉。

## 设计意图

为弓手提供伏击与先手能力，与盗贼潜行形成差异化隐蔽玩法。
