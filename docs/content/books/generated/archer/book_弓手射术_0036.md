# 《沙漠热风射击》

## 基础信息

- **书籍 ID**：`book_弓手射术_0036`
- **关联技能**：`archer_heat_shimmer`、`archer_wind_compensate`
- **使用效果**：阅读后解锁 `archer_heat_shimmer`；若已学会，提升 `current_mastery +100`，并在沙漠地形降低热浪造成的瞄准偏差。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；基础 `感知 ≥ 9`。
- **稀有度**：普通（Common）
- **建议投放**：沙漠游侠营地、绿洲哨塔、商队护卫任务奖励。

## 书籍内容

《沙漠热风射击》专门研究海市蜃楼与热浪对远程射击的影响。作者指出，沙漠中的热气流会让目标看起来上下晃动，甚至产生虚影，直接瞄准往往射偏。书中建议射手观察目标脚下的阴影而非目标本身，因为阴影受热浪影响较小。作者还讲解了如何在高温下保护弓弦和箭羽，避免它们因干燥而变脆。后半本提供了沙漠行军中的水分管理与射击节奏建议。最末页有一句话：沙漠里的箭，要先穿过一层滚烫的空气才能到达目标。商队护卫常说，在绿洲学会这本书的人，才能在沙海中活到下一个绿洲，因为沙漠不会原谅任何轻视它的射手，也不会给第二次机会。沙漠中的弓手学会的第一件事，就是怀疑自己的眼睛。每一位走出训练营的新手，都会从导师手中收到这样一本赠书。读过它的人，会更懂得敬畏沙漠那看似平静却暗藏杀机的力量。

## 设计意图

将沙漠环境纳入弓手战术体系，提供地域特色的技能与挑战。
