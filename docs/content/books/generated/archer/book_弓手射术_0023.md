# 《射落飞行物》

## 基础信息

- **书籍 ID**：`book_弓手射术_0023`
- **关联技能**：`archer_clay_pigeon`、`archer_rapid_fire`
- **使用效果**：阅读后解锁 `archer_clay_pigeon`；若已学会，提升 `current_mastery +100`，并使对飞行单位的下一次射击命中 +10%。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；基础 `敏捷 ≥ 10`。
- **稀有度**：普通（Common）
- **建议投放**：风息哨塔靶场、飞行生物狩猎任务、竞技射鸟奖励。

## 书籍内容

《射落飞行物》是一本充满动态感的训练手册。作者认为，射击移动目标的核心不是追，而是预判。书中把飞行目标分为直线飞行、弧线飞行和不规则飞行三类，分别给出了瞄准提前量的估算方法。作者还提醒，射鸟时不要盯着鸟本身，而要看鸟将要飞到的位置。后半本收录了一套抛掷物练习：由同伴向上抛掷陶片，射手必须在落地前射中。随着熟练度提高，陶片越来越小，抛掷速度越来越快。最末页有一幅插图，一支箭正穿过一只飞鸟的翅膀，旁边写着：飞翔是自由的，但天空也有代价。许多年轻弓手把这本书当作炫耀技巧的入门，直到他们发现真正飞行中的敌人比陶片快十倍，预判才是唯一的胜算。射中飞鸟的那一刻，你并不会觉得自己战胜了天空，只会感激自己提前学会了预判风的轨迹。

## 设计意图

训练玩家对移动目标的预判能力，为后续对抗飞行敌人做铺垫。
