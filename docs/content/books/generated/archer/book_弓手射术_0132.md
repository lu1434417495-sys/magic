# 《迎击射术：正面收割》

## 基础信息

- **书籍 ID**：`book_弓手射术_0132`
- **关联技能**：`archer_counter_shot`（待新增）
- **使用效果**：阅读后解锁 `archer_counter_shot`；若已学会，提升该技能 `current_mastery +130`，并提升对突进敌人的反击伤害。
- **阅读要求**：职业标签含 `archer` 或 `ranger`；基础 `感知 ≥ 12` 且 `敏捷 ≥ 11`。

- **建议投放**：竞技场冠军奖励、前线军械库、游侠大师传承。

## 书籍内容

迎击射术：正面收割的作者是一位曾在竞技场连胜三十场的老射手。他认为弓手不应只会后退，还应学会在敌人冲过来的瞬间完成致命一击。前半本讲时机判断：如何读出敌人突进的前兆，如何在对方最无法闪避的时刻放箭。中章讨论不同敌人的突进模式：直线冲刺、Z 字走位、跳跃扑击，每一种都有最佳的迎击窗口。后半本则是心态训练：迎击需要射手主动放弃部分安全距离，把恐惧转化为专注。作者在最后提醒，迎击射术最忌讳贪心：一旦成功反制突进，应立即后撤重新拉开距离，而不是趁机追击。最后一页写着："当敌人冲向你时，他也在赌你不敢射。你要让他赌输。"

作者连胜三十场的秘诀不是技术，而是他总能在敌人以为他会后退时迎上去。这种反直觉的选择让他在竞技场上屡试不爽，但也受过多次重伤。

## 设计意图

为弓手提供反突进手段，让远程职业在正面交锋中也有高光时刻。
