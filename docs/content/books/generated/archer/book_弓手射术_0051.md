# 《风语者的拉弦姿势》

## 基础信息

- **书籍 ID**：`book_弓手射术_0051`
- **关联技能**：`archer_stance_foundation`、`archer_aimed_shot`
- **使用效果**：阅读后解锁 `archer_stance_foundation`；若已学会，提升该技能 `current_mastery +80`，并在下一次战斗中降低首次拉弓体力消耗 1 点。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；基础 `敏捷 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：风息哨塔入门书架、弓手训练场基础教材、新手游侠导师。

## 书籍内容

《风语者的拉弦姿势》开篇便警告读者：姿势不是美观问题，而是力量传导问题。作者风语者埃拉将拉弦动作拆成七个节点，从脚掌踩地到食指扣弦，每个节点都标注了常见错误。书中反复强调，弓手的小臂不应参与发力，真正牵引弓弦的是背部肌群。为了纠正陋习，埃拉设计了一套每日五十次的空手练习：假装拉弦，感受肩胛骨的靠拢。后半本收录了不同身高弓手的站姿微调，指出矮个射手需要更宽的步距来弥补拉距不足。最末页有一张被汗水浸黄的插图，画中弓手站在悬崖边缘，弓弦已拉至耳旁，配文写道：“站稳了，箭才有归处。”许多老练游侠仍会定期翻阅这本小册子，因为基础歪斜的人，射得越多偏得越远。后世游侠公会把这本书列为必读基础教材，任何站姿考试不合格者不得参加进阶训练。

## 设计意图

作为弓手系最底层姿势教材，降低新射手入门门槛，将“稳定站姿”确立为后续所有射术的前提。
