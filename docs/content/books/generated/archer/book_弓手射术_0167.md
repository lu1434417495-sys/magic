# 《元素附魔箭》

- **关联技能**：`archer_elemental_enchant_arrow`（待新增）

- **阅读要求**：职业标签含 `archer` 或 `ranger`；基础 `智力 ≥ 12` 且 `感知 ≥ 11`。

## 书籍内容

《元素附魔箭》讲解如何将火焰、冰霜、雷电等元素力量封存于箭镞之中。前半本介绍元素亲和测试，帮助射手找到最适合自己的元素属性。中章详述附魔步骤：以特殊矿石粉末绘制符文、注入元素精华、在箭镞固化前完成封装。后半本讨论不同元素在战场上的应用：火可点燃油料，冰可冻结水面，雷可传导金属护甲。书中还提醒，元素附魔对弓身有腐蚀，需使用抗魔材料或在射后及时清洁。作者认为，元素箭不只是增加伤害，更是改变地形与战术的钥匙。末页警告，同时附魔两种元素极易失控，初学者切勿尝试。

书中附有一张元素反应表，标注了不同元素命中同一目标时可能产生的复合效果。例如雷箭命中湿润敌人时会扩散麻痹，火箭命中油脂则会引发持续燃烧。元素附魔箭是弓手与法师合作的结晶。

## 设计意图

为弓手引入元素战术维度，让玩家根据环境与敌人类型选择元素，增强战场互动性。
