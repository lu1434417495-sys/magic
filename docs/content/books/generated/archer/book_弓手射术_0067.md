# 《弓弦保养秘录》

## 基础信息

- **书籍 ID**：`book_弓手射术_0067`
- **关联技能**：`archer_bow_maintenance`、`archer_stance_foundation`
- **使用效果**：阅读后解锁 `archer_bow_maintenance`；若已学会，提升 `current_mastery +90`，并永久降低所有弓类武器耐久损耗 5%。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；基础 `智力 ≥ 7`。
- **稀有度**：普通（Common）
- **建议投放**：工匠行会、游侠补给站、武器商人货架。

## 书籍内容

许多弓手愿意花大价钱买一把好弓，却不愿意花十分钟保养它。《弓弦保养秘录》的作者是一位活了九十岁的老弓匠，他认为弓是活的，需要像对待猎犬一样对待它。书中按季节列出保养重点：春季防潮，夏季防晒，秋季防虫蛀，冬季防干裂。作者特别反对用动物油脂涂抹弓弦，因为油脂会吸附灰尘，反而加速磨损；他推荐使用蜂蜡与松节油的混合物，既能润滑又不粘灰。关于弓身，他强调绝对不能用火烤干潮湿的木料，必须阴干。最令读者动容的是书中夹着的几张黑白画，画的是作者一生中用过的七把弓，每把弓下都写着名字和结局：“碎于龙焰”、“失于洪水中”、“传给了孙子”。老弓匠在书末写道，毁掉一把弓最快的方法不是战斗，而是连续一个月不擦拭它。作者强调，弓弦的寿命往往比弓身更短，却最容易被忽视。

## 设计意图

提供生活技能型弓手加成，将装备维护转化为长期养成收益。
