# 《灵木弓共鸣术》

## 基础信息

- **书籍 ID**：`book_弓手射术_0070`
- **关联技能**：`archer_spirit_bow`、`meditation_tidal_breath`
- **使用效果**：阅读后解锁 `archer_spirit_bow`；若已学会，提升 `current_mastery +180`，并使灵木弓在冥想后首次射击额外回复 5 点 MP。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；已学会任意 `meditation` 技能；基础 `意志 ≥ 12`，`感知 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：古树精灵居所、德鲁伊遗迹、冥想弓手圣地。

## 书籍内容

《灵木弓共鸣术》认为，一把好弓不仅仅是工具，更是施术者意志的延伸。作者是一群隐居的古树精灵，他们教导读者如何通过冥想与弓身中的木纹建立联系，让弓在拉满时发出类似琴弦的低鸣。书中强调，共鸣不是强迫，而是倾听：每把弓都有自己的“脾气”，有的喜欢清晨的湿气，有的则在满月时最稳定。初学者需要先用空弦练习感受震动，再逐步加入箭矢。作者还提到，灵木弓会对使用者的心境产生反应，愤怒会让箭矢变得沉重，恐惧会让弓弦发涩，唯有平静才能引出最大威力。书页由某种树叶制成，翻阅时会有淡淡的树脂香气。古树精灵只允许通过了“听树”试炼的外族人阅读此书，违者会被森林永远排斥。古树精灵相信，每把灵木弓都在等待一个能听懂它的主人。后人常在书页空白处批注心得。
