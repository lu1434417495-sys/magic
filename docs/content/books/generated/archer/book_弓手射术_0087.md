# 《幻光分影箭》

## 基础信息

- **书籍 ID**：`book_弓手射术_0087`
- **关联技能**：`archer_mirror_arrow`、`archer_shadow_shot`
- **使用效果**：阅读后解锁 `archer_mirror_arrow`；若已学会，提升 `current_mastery +210`，并使分影箭有 25% 几率产生额外一支幻影箭。
- **阅读要求**：角色职业标签含 `archer` 或 `mage`；已学会 `archer_shadow_shot`；基础 `感知 ≥ 14`，`智力 ≥ 12`。
- **稀有度**：史诗（Epic）
- **建议投放**：镜之迷宫、幻术师塔楼、异界光影遗迹宝箱。

## 书籍内容

《幻光分影箭》的作者可能不是人类，因为书中对光影的描述过于精确而冷漠。它教授一种利用棱镜和魔力碎片在箭矢飞行中制造幻影的技巧，让敌人难以判断真正的攻击来自何方。作者详细讲解了不同角度阳光或月光下幻影的生成规律，并指出最致命的幻箭往往在黎明或黄昏出现，因为斜射的光线最容易产生误导性阴影。书中还警告，过度依赖幻影会让射手失去对真实弹道的判断，因此初学时必须先用普通箭练习，直到能凭本能分辨哪一支是“真箭”。最神秘的章节提到，古代有一位弓手能将一支箭分成七道幻影，每一道都能杀人，但他最终死于无法分辨自己的箭。镜之迷宫的看守者会主动猎杀掌握此书的外人，因为他们认为幻光箭影会扰乱迷宫的平衡。幻光分影对心智坚定的敌人效果有限，因为意志能看穿幻象。

## 设计意图

为高阶弓手提供幻术型输出技能，扩展智力弓手的Build空间。
