# 《燎火箭矢调配》

## 基础信息

- **书籍 ID**：`book_弓手射术_0060`
- **关联技能**：`archer_flame_arrow`、`archer_arrow_balance`
- **使用效果**：阅读后解锁 `archer_flame_arrow`；若已学会，提升 `current_mastery +130`，并解锁火油配方 `alchemical_fire_oil`。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；基础 `智力 ≥ 8`。
- **稀有度**：精良（Uncommon）
- **建议投放**：炼金游侠商店、火山边缘据点、焚烧者委托奖励。

## 书籍内容

这本书散发着淡淡的焦油味，前几页已经被燎黑，显然作者有过几次不愉快的实验经历。燎火箭的核心问题不是如何点燃箭头，而是如何让火焰在飞行中不熄灭、落地后又能迅速蔓延。作者推荐的配方是在箭杆前段裹一层麻布，浸入由松脂、蜂蜡和少量火药粉调成的混合物中，点燃后必须在三秒内射出。书中还讨论了风向对火焰箭的影响，警告射手绝不可在逆风时使用，否则火星会扑向自己的脸。后半本收录了几场著名战役中火箭的使用案例，其中最惨烈的一次是某座木堡的陷落，作者用冷静的笔触描述了火如何比箭更快地瓦解守军意志。最后一页只有一句话：“火箭点燃的不只是木头，还有恐惧。”有经验的弓手会在箭囊中为火箭单独留出一层防火隔间，防止意外引燃其他箭矢。
