# 《顺风箭要诀》

## 书籍内容

《顺风箭要诀》只有三十页，但每一页都在讲同一件事：顺风不是礼物，是双刃剑。作者指出，顺风能让箭飞得更远更稳，但也容易让射手低估距离，导致射高。书中建议顺风射击时降低瞄准点半个身位，并在箭羽上选择更硬的羽片以抵抗风压。作者还提醒，顺风时箭矢落地角度更陡，适合射击掩体后的目标。后半本收录了不同风速下的距离修正表，但作者在每个数字旁都写着仅供参考，因为真实战场的风永远比表格复杂。扉页有一句话说：顺风放箭的人，最容易忘记风也会转弯。经验丰富的沿海哨兵往往会在箭囊里放一本被海风吹得卷边的小册子，就是它，因为顺风时的失误往往比逆风更让人猝不及防。真正老练的沿海哨兵会在顺风时故意降低射速，因为他们知道风带来的优势里也藏着骄傲的诱惑。

## 设计意图

引入环境风向对远程攻击的影响，让玩家开始学习动态修正射击。
