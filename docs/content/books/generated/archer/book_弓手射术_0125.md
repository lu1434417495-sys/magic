# 《涉水箭道》

## 书籍内容

涉水箭道讲如何在浅水中保持射击姿态。作者是一位以沼泽为家的游侠，他认为水面反射会严重干扰射手对距离的判断。前半本讲解如何用脚感知水底地形，在不稳定的地面上找到三点支撑。中章讨论湿度对弓弦和羽毛的影响，以及如何用动物脂肪临时防水。后半本记录了在芦苇丛中伏击敌人的技巧：如何利用水禽的叫声掩盖自己的动作，如何在敌人涉水时抓住其移动受限的瞬间。书中另有一节讲述如何用芦苇杆制作临时呼吸管，让射手能在水下潜伏时保持呼吸。作者承认这更像是猎人的技巧，但在沼泽伏击战中曾多次救他性命。最后一页是一幅简笔画：一双脚踩在浅水中，弓弦已经拉满。

临时呼吸管的制作材料被详细列出：中空芦苇、蜂蜡密封、皮革固定带。作者还建议在管口涂上薄荷油，以便在水下也能判断呼吸是否通畅。

## 设计意图

为弓手提供水域作战专长，扩展远程职业的环境适应性。
