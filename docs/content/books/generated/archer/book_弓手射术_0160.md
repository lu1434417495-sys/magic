# 《静默猎杀》

## 基础信息

- **书籍 ID**：`book_弓手射术_0160`
- **关联技能**：`archer_silent_hunting`（待新增）
- **使用效果**：阅读后解锁 `archer_silent_hunting`；若已学会，提升该技能 `current_mastery +100`，并使静默击杀延迟敌人发现尸体一回合。
- **阅读要求**：职业标签含 `archer` 或 `ranger`；基础 `感知 ≥ 12` 且 `敏捷 ≥ 11`。
- **稀有度**：稀有（Rare）
- **建议投放**：暗影猎手营地、遗迹密林、游侠大师委托。

## 书籍内容

《静默猎杀》记录如何在不被察觉的情况下逐一清除敌人。作者认为，弓手的最大优势不是射程，而是选择何时暴露自己。前半本讲解移动技巧：避开落叶、枯枝与积水，利用风向掩盖脚步声。中章介绍消音箭的制作，包括软木箭镞、羽毛消音处理与弓弦消音蜡。后半本讨论射击后的处理：立刻转移位置、观察同伴反应、判断是否需要补箭。书中还提到，最致命的猎杀往往在敌人发现尸体之前完成。作者强调，静默猎杀需要耐心，急躁会让数小时的潜伏前功尽弃。最后一页只有一句话：先隐藏，再射击，最后才呼吸。

许多读者在这句话下方留下了自己的签名，表示已经接受了这种孤独的战斗方式。作者认为，能够忍受漫长孤独的猎手，才配在最关键时刻射出最致命的那一箭。静默猎手往往也是最好的追踪者。

## 设计意图

强化弓手的潜行暗杀流派，通过延迟发现创造更多单点击杀机会，适合高感知高敏捷角色。
