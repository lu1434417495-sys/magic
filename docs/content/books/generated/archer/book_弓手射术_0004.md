# 《拉弦发力源流》

## 基础信息

- **书籍 ID**：`book_弓手射术_0004`
- **关联技能**：`archer_draw_power`、`archer_stance_foundation`
- **使用效果**：阅读后解锁 `archer_draw_power`；若已学会，提升该技能 `current_mastery +80`，并小幅提升拉满弓时的稳定时长。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；基础 `力量 ≥ 7`。
- **稀有度**：普通（Common）
- **建议投放**：武馆弓术分馆、力量型游侠教练、山麓训练场。

## 书籍内容

《拉弦发力源流》开篇便纠正了一个流传甚广的错误：拉弓靠的不是手臂，而是背部。作者把拉弦动作比喻成打开一扇沉重的门，肩胛骨的靠拢才是发力的核心。书中详细描述了背阔肌、斜方肌与手臂的协作顺序，并提供了空手模拟练习，让读者在没弓时也能体会正确的发力路径。作者还提醒，过早上高磅数弓会导致动作变形，建议新手在能连续稳定拉满三十次后再考虑换弓。后半本收录了不同体型射手的调整方法：肩宽者需缩短拉距，体弱者应降低磅数。最末页是一张背部肌肉图，几个关键部位被红笔圈出，旁边写着：箭的力量从这里来。老弓手常说，看懂这张图的人，射箭时肩膀不会再酸痛，而且能在连续射击中保持稳定输出。训练有素的射手能在连续射击中保持背部发力不变形，这是他们从新手走向成熟的第一个标志。

## 设计意图

将正确的发力方式转化为游戏内属性与技能成长，避免玩家过早追求高力量而忽视技术。
