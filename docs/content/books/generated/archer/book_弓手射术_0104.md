# 《半满弓与全满弓》

## 基础信息

- **书籍 ID**：`book_弓手射术_0104`
- **关联技能**：`archer_power_draw`（待新增）
- **使用效果**：阅读后解锁 `archer_power_draw`；若已学会，提升该技能 `current_mastery +90`，并减少下次战斗首次拉满弓的 `stamina` 消耗 1 点（一次性战斗增益，最多累计 3 次）。
- **阅读要求**：职业标签含 `archer` 或 `ranger`；基础 `力量 ≥ 9`。
- **稀有度**：普通（Common）
- **建议投放**：弓手训练场、老兵口传、基础军械库。

## 书籍内容

这本书专门讨论一个被新手忽视的问题：并非每一箭都需要拉满。作者用前半本分析半满弓的优势：射速快、噪音小、体力消耗低，适合中近距离压制与连续射击。后半本讲全满弓的禁忌：拉满后若停顿过久，肌肉会进入僵硬状态，精准度反而下降。书中提出"三段呼吸"法则：吸气时引弦，屏息时瞄准，呼气前释放。最有趣的章节是"假满"，讲述如何欺骗敌人——故意做出拉满的姿态，让对方做出防御重箭的准备，却在半满时突然发箭，打其措手不及。书中还记录了"借半力"技法：快速连射时第一箭用七成力，第二箭用九成力，第三箭视情况选择半满或全满。书末附有作者亲手画的肌肉负荷图，标注不同年龄与体型射手适合的拉弓强度。

肌肉负荷图旁边有一行小字："少年射手的肩膀是未来的宝库，不要现在就掏空它。"这句话被许多教官用红笔圈出，作为告诫学生的标准用语。

## 设计意图

区分弓手的力量控制层次，让玩家在伤害与频率之间做出有意识的选择。
