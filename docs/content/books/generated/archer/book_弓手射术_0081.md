# 《高空抛射学》

## 基础信息

- **书籍 ID**：`book_弓手射术_0081`
- **关联技能**：`archer_high_arc`、`archer_range_estimation`
- **使用效果**：阅读后解锁 `archer_high_arc`；若已学会，提升 `current_mastery +120`，并使从高处射击时射程 +15%。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；已学会 `archer_range_estimation`；基础 `感知 ≥ 10`。
- **稀有度**：普通（Common）
- **建议投放**：城楼守卫训练场、高地游侠据点、攻城战术藏书。

## 书籍内容

占据高处是弓手的天赐优势，但高处的弹道与地面截然不同。《高空抛射学》系统讲解了重力、风速和高度差对箭矢轨迹的影响。作者用一座假想的塔楼作为例子，展示了从十丈、二十丈和五十丈高度射击同一目标时需要的不同仰角。书中特别指出，高处射击的最大危险是过度自信：很多弓手因为射程变远而浪费箭矢，却忽略了返回地面后的近战危险。作者还建议在出发前估算需要携带的箭数，因为爬下塔楼补箭往往意味着失去最佳射击窗口。最实用的附录是一份“高度-距离修正表”，但被前任主人用咖啡渍污损了一半。攻城战中，占据塔楼的弓手往往能决定一场战斗的走向，因此他们也成为敌方投石机的首要目标。抛射箭的致命之处在于敌人往往看不到箭从何来。其价值在实践中愈发明显。

## 设计意图

将地形高度纳入弓手战斗计算，奖励占据制高点的战术选择。
