# 《猎场标记法则》

## 基础信息

- **书籍 ID**：`book_弓手射术_0066`
- **关联技能**：`archer_tracking_shot`、`archer_eagle_eye`
- **使用效果**：阅读后解锁 `archer_tracking_shot`；若已学会，提升 `current_mastery +120`，并使标记箭持续时间内全队对该目标伤害 +5%。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；基础 `感知 ≥ 10`。
- **稀有度**：普通（Common）
- **建议投放**：猎人行会、荒野向导营地、团队狩猎委托奖励。

## 书籍内容

《猎场标记法则》源自北方猎人行会的内部教材，核心思想是：一支箭不必致命，只要让猎物无法逃脱。书中介绍了多种标记方式，包括在箭杆上涂抹荧光苔藓、系上细小铃铛、或者在命中后释放气味浓烈的粉末。作者强调，标记箭最重要的是落点选择：肩膀会让目标速度下降，大腿会让其转向受限，而命中背部则最容易在逃跑时脱落。后半本转向战术层面，讲解如何让队伍成员根据标记调整站位，以及如何避免多人同时追逐同一目标而导致阵型崩溃。书中还记录了不同生物对标记的反应：狼群会试图咬掉标记，巨魔会无视标记继续冲锋，而某些精灵野兽则会反过来追踪射手。大型狩猎团队会把这本书当作指挥手册，标记手的地位和队长几乎相当。标记箭的颜色在不同地区有不同约定，误读可能导致误伤同伴。

## 设计意图

为弓手增加团队辅助定位，将“标记”机制引入战斗协作循环。
