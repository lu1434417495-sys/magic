# 《穿甲箭镞图谱》

## 书籍内容

这本图谱的每一页都画着不同形状的箭镞，旁边标注了它们穿透各类护甲的实测数据。作者是一位曾在矿山工作的半矮人弓手，他坚持认为穿甲箭的关键不是更重的箭头，而是更窄的锋角和更长的棱线。书中用整整二十页比较“三棱”与“四棱”箭镞在板甲、锁甲和皮甲上的表现，结论是没有任何一种箭头能通吃所有护甲。后半本讲解了拉弓力量与穿透力的关系，指出如果拉不开足够磅数的弓，再好的箭镞也只是浪费材料。图谱夹带着一张烧焦的订单，要求定制一百支“能射穿黑铁骑士胸甲”的箭，定金已经付讫，但交货日期永远停在三年前。最末页的批注写道：“穿甲是箭与弓的合谋，缺一不可。”图谱后半部有几页被撕毁，传言那些页面记载着能穿透龙鳞的禁制箭镞。矮人铁匠对书中某些数据嗤之以鼻，却偷偷按图仿制。

## 设计意图

为弓手提供反制重甲单位的手段，将力量属性与破甲流派联系起来。
