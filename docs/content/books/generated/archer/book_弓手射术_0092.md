# 《瞄准镜符文刻印》

## 基础信息

- **书籍 ID**：`book_弓手射术_0092`
- **关联技能**：`archer_rune_sight`、`archer_eagle_eye`
- **使用效果**：阅读后解锁 `archer_rune_sight`；若已学会，提升 `current_mastery +180`，并使符文瞄准对魔法生物弱点高亮显示 2 秒。
- **阅读要求**：角色职业标签含 `archer` 或 `mage`；已学会 `archer_eagle_eye`；基础 `智力 ≥ 12`，`感知 ≥ 11`。
- **稀有度**：稀有（Rare）
- **建议投放**：符文工匠塔、奥术射手据点、魔法遗迹宝箱。

## 书籍内容

肉眼有极限，但符文可以延伸视线。《瞄准镜符文刻印》教授如何在弓身、护指或特制的单片眼镜上刻印微量符文，帮助射手识别目标的魔力流动和结构弱点。作者是一位半退休的奥术射手，他强调符文瞄准不是替代训练，而是让训练成果更有效地落地。书中介绍了三种基础符文：“透魔”用于看穿低阶幻象，“热感”用于追踪体温，“弱点”则能在短时间内高亮显示敌人护甲缝隙。作者警告，符文的持续激活需要消耗微量魔力或精神力，长时间使用会导致偏头痛。最末页有一幅复杂的复合符文图，作者标注为“未完成的第四眼”，并留言说任何完善它的人都应该去沉钟书库找他。奥术射手之间流传着一个警告：不要在同一副眼镜上刻印超过三种符文，否则你会看见不该看见的东西。符文瞄准镜的维护费用惊人，普通弓手难以长期负担。

## 设计意图

为魔弓混合Build提供科技/魔法辅助，强化目标识别与弱点打击。
