# 《弦线张力与老化辨识》

## 基础信息

- **书籍 ID**：`book_弓手射术_0015`
- **关联技能**：`archer_string_tune`、`archer_bow_maintenance`
- **使用效果**：阅读后解锁 `archer_string_tune`；若已学会，提升 `current_mastery +70`，并提升弓弦类耗材的耐久上限 10%。
- **阅读要求**：无职业限制；基础 `智力 ≥ 6`。
- **稀有度**：普通（Common）
- **建议投放**：工匠行会书架、弓匠作坊、游侠补给商人。

## 书籍内容

《弦线张力与老化辨识》是弓弦匠人写给射手的实用手册。作者指出，弦线不像弓身那样显而易见，却决定了每一次拉弓的手感和箭矢的初速。书中详细讲解了如何判断弦线是否老化：看色泽是否发灰、听弹拨声是否沉闷、摸表面是否有起毛或硬化。作者还强调，不同材质的弦线需要不同的张力维护，过紧会损伤弓臂，过松则会让箭矢失去稳定性。后半本提供了一套简易的测张方法，只需要一枚小重物和一把直尺。最末页有一张被油渍浸黄的记录表，供读者记录每次上弦后的手感变化。作者写道：弦线的状态不会骗你，前提是你要学会问它问题，而这些问题最好在它断裂之前提出，而不是在战场上追悔莫及。老弓匠常说，弦线无声，却在每一次拉弓时诉说着自己的状态。读完之后，你会发现射术不只是拉弓放箭，而是一种与世界对话的方式。

## 设计意图

强化装备维护维度，为弓手引入耗材耐久与 crafting 资源的循环。
