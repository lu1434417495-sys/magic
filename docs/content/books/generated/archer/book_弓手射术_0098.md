# 《天鹰俯冲射》

- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；已学会 `archer_high_arc`；基础 `敏捷 ≥ 14`，`感知 ≥ 12`。

## 书籍内容

天鹰不会从平地攻击，它总是从太阳的方向俯冲而下。《天鹰俯冲射》的作者观察了二十年天鹰的捕猎方式，将其中精髓融入弓术。书中要求射手先从高处跳下或滑降，在坠落过程中完成拉弦、瞄准和放箭，落地前的一瞬间必须已经射出致命一箭。作者强调，这种射法的危险不在于落地，而在于心理上的失重恐惧；许多练习者因为不敢在坠落时松手而错失良机。书中还讲解了如何利用披风或滑翔装置控制下落角度，以及如何在落地时通过翻滚卸力。最壮观的插图描绘了一位弓手从悬崖跃下，身后是展开的双翅，身前是三支呈品字形飞向猎物的箭。天鹰部落的年轻弓手把第一次成功俯冲射当作成人礼，失败者通常会被送到地面部队。天鹰部落的弓手从小在悬崖边长大，常人难以复制他们的勇气。

## 设计意图

将高度优势转化为爆发伤害，为机动型弓手提供高风险高回报的空中打击手段。
