# 《断后箭诀》

## 基础信息

- **书籍 ID**：`book_弓手射术_0075`
- **关联技能**：`archer_parting_shot`、`archer_backflip_shot`
- **使用效果**：阅读后解锁 `archer_parting_shot`；若已学会，提升 `current_mastery +130`，并使撤退时射出的断后箭有 20% 几率触发定身。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；已学会 `archer_backflip_shot` 或 `archer_feather_step`；基础 `敏捷 ≥ 11`。
- **稀有度**：精良（Uncommon）
- **建议投放**：边境撤退专家、游侠幸存者营地、断后战术教官。

## 书籍内容

撤退不是逃跑，而是有组织的离开。《断后箭诀》专门研究如何在后撤时给追击者制造麻烦。作者将断后箭分为“迟滞型”、“惊吓型”和“杀伤型”，分别对应不同的撤退距离和敌人类型。迟滞型射向脚前地面，迫使敌人减速；惊吓型射向耳边，利用破空声争取时间；杀伤型则只在有把握命中时出手，因为停下瞄准会让自己也陷入危险。书中还讲解了如何边跑边上弦，如何在转身瞬间完成射击，以及如何让队友交替掩护。作者用冷静的语气写道：“最好的断后箭不需要命中，它只需要让追敌怀疑前方是否有埋伏。”书的扉页有一行潦草的字：“献给所有成功撤退的人。”撤退专家的墓碑上通常刻着同一句话：“我射出的最后一箭，是为了让同伴不必射出他们的最后一箭。”断后箭的高手往往在撤退时比进攻时更令人畏惧。

## 设计意图

补充弓手在劣势情境下的生存技能，将“放风筝”战术体系化。
