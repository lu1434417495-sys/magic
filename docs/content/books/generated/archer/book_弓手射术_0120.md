# 《高抛箭曲谱》

## 书籍内容

高抛箭曲谱把射箭比作音乐。作者认为，高抛箭的关键在于找到正确的"音符"——引弦力度、仰角、风速修正。前半本用大量抛物线图示讲解不同距离下的最佳仰角。中章讨论如何利用高抛箭越过城墙、树梢和盾墙，打击后方目标。后半本则是一本实战曲谱，每一页对应一种典型场景：攻城、守城、山谷伏击、密林仰攻。作者还记录了如何根据敌人盾牌的排列判断其后方薄弱点。作者在后半本加入了对"落点预判"的训练：让新手先向空中射一箭，然后在箭落地前判断其落点，反复练习直到能在箭离弦瞬间就预知轨迹。最后一页只有一句话："直线是箭的本能，曲线是射手的智慧。"

曲谱的最后一页不是乐谱，而是一幅靶场俯视图。图中用不同颜色的线条标注了各种高抛箭的落点分布，被称为"彩虹靶"。作者在后记中强调，这些技巧需要反复练习才能内化为本能，急于求成只会事倍功半。

## 设计意图

为弓手提供曲射与掩体后打击能力，丰富远程职业的战术空间。
