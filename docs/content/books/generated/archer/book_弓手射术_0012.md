# 《血痕追踪箭》

## 基础信息

- **书籍 ID**：`book_弓手射术_0012`

## 书籍内容

《血痕追踪箭》的作者是一位不愿透露姓名的猎手，书中满是血迹斑斑的野外笔记。核心技巧很简单：先造成伤口，再追击伤口。作者详细讲解了如何识别不同动物和敌人的出血模式，以及如何通过血迹判断目标的移动速度和方向。书中还介绍了追踪箭的改装方法：在箭头上刻出浅槽，使伤口更难愈合，从而延长可被追踪的时间。后半本有一章警告读者不要过度追击受伤的猛兽，因为濒死的野兽往往最危险。最末页是一幅手绘地图，上面用红叉标记着一次持续三天的追猎路线，旁边只有一句话：血不会说谎，但会让你追得太远。老练的猎手都说，这本书教会的不是追踪，而是何时该停下脚步，把猎物交给时间和耐心。这本书的真正读者不是那些追求一箭毙命的杀手，而是愿意花时间读懂猎物、读懂土地的猎手。

## 设计意图

将弓手与状态效果（流血）联动，培养玩家先伤后追的猎手节奏。
