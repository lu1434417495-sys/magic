# 《拉距测量法》

## 基础信息

- **书籍 ID**：`book_弓手射术_0043`
- **关联技能**：`archer_draw_length`、`archer_stance_foundation`
- **使用效果**：阅读后解锁 `archer_draw_length`；若已学会，提升 `current_mastery +80`，并为角色记录最佳拉距值以优化后续装备选择。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；基础 `敏捷 ≥ 7`。
- **稀有度**：普通（Common）
- **建议投放**：游侠装备商、制弓师导师、新手训练场。

## 书籍内容

《拉距测量法》帮助射手找到属于自己的最佳拉距。作者指出，拉距过短会浪费弓的储能，拉距过长则会导致动作变形和肩部受伤。书中提供了一种简易测量方法：双臂侧平举，测量指尖距离，再按比例换算出近似拉距。作者还讲解了不同弓种对拉距的要求差异，以及如何在购买或制作弓时参考自己的拉距。后半本讨论了成长中的射手如何随着身高和力量变化调整拉距。最末页有一句话：弓为你量身定做，前提是你知道自己的尺寸。许多父母会把这本书送给刚开始学弓的孩子，因为一开始就建立正确拉距能避免很多年的坏习惯和不必要的伤痛，让成长与技艺同步前进。真正掌握它的人，往往会对自己的弓产生全新的理解。有人说，这本书真正的价值不在于技巧，而在于它塑造的思维方式。
