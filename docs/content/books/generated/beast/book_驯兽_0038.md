# 《皮毛护甲利用》

## 基础信息

- **书籍 ID**：`book_驯兽_0038`
- **关联技能**：`beast_hide_armor`
- **使用效果**：阅读后解锁 `beast_hide_armor`；若已学会，提升该技能 `current_mastery +80`，并使野兽皮毛制作的护甲额外提供 5% 物理减伤。
- **阅读要求**：角色职业标签含 `warrior`、`rogue` 或 `ranger`；基础 `体质 ≥ 8`。
- **稀有度**：精良（Uncommon）
- **建议投放**：皮匠铺、猎人营地、护甲匠工作台。

## 书籍内容

《皮毛护甲利用》讲解了如何将猎获野兽的毛皮转化为高品质护甲的工艺要点。作者指出，剥皮与鞣制同样是驯兽师知识体系的一部分，因为了解野兽的皮肤结构有助于在战斗中保护它们。书中先讲解不同毛皮的特性：狼皮耐磨但较重，鹿皮柔软适合内衬，熊皮厚重能抗钝击。中间章节介绍鞣制过程中的关键步骤：去脂、软化、浸油与定型，每一步都会影响最终护甲的耐久度。后半本记录了如何在保留毛皮天然抗性的同时增强防护：拼接不同部位、嵌入金属片或浸泡防火药剂。作者在最后写道："穿兽皮不是对野兽的亵渎，而是让它们以另一种方式继续与你并肩作战。"书末附有一张不同野兽毛皮的最佳保存季节表，帮助猎人在正确的时间获取最优质的材料。书中还附有一张鞣制失败案例分析。

## 设计意图

将驯兽系统与装备制作连接，让玩家从野兽身上获得的收益不仅限于战斗伙伴，还包括可持续的装备来源。
