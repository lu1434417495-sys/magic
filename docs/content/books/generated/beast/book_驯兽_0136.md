# 《神圣兽庇护》

## 基础信息

- **书籍 ID**：`book_驯兽_0136`
- **关联技能**：`beast_holy_warden`（待新增，标签 `beast`、`holy`）
- **使用效果**：阅读后解锁 `beast_holy_warden`；若已学会，提升该技能 `current_mastery +180`，并使神圣属性野兽的光环为盟友提供小幅治疗。
- **阅读要求**：角色职业标签含 `cleric`、`paladin` 或 `beastmaster`；基础 `信仰 ≥ 13`。
- **稀有度**：稀有（Rare）
- **建议投放**：神殿、圣所、光明祭坛。

## 书籍内容

神圣属性的野兽通常与光明神殿或古老契约有关，它们对邪恶与混乱气息尤为敏感。这本书讲解如何通过纯净的意念、祈祷与洁净的生活方式赢得神圣兽的认可。作者强调，神圣兽不是宠物，而是共同守护某种信念的伙伴；一旦驯兽师背离誓言，神圣兽会自行离去。后半部分介绍神圣光环的维护方法，以及如何在战斗中让神圣兽为盟友提供治疗与净化。作者还建议每日清晨用清水清洗双手与护甲，并在兽栏入口悬挂圣徽，以维持神圣兽喜爱的纯净环境。书中指出，神圣兽对谎言有天然的排斥，驯兽师在与其交流时应保持内心诚实。最末页附有一段简短的晨祷，建议在每日喂食前诵读。神殿与圣所把它作为圣骑士与牧师驯兽的入门指南。作者认为，神圣兽是誓言的活体见证，而非工具。

## 设计意图

为牧师/圣骑士系提供辅助型野兽选择，扩展治疗与净化战术。
