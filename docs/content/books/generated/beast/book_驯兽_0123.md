# 《野性直觉训练》

## 基础信息

- **书籍 ID**：`book_驯兽_0123`
- **关联技能**：`beast_wild_intuition`（待新增，标签 `beast`）
- **使用效果**：阅读后解锁 `beast_wild_intuition`；若已学会，提升该技能 `current_mastery +120`，并使野外场景中感知与闪避提高 5%。
- **阅读要求**：无职业限制；基础 `感知 ≥ 9`。

## 书籍内容

长期在野外生活的人往往会发展出一种难以言喻的直觉，这本书试图把它系统化。作者设计了一系列感官训练：闭眼辨别风向、凭气味判断野兽种类、通过地面震动感知距离。书中指出，野性直觉不是玄学，而是大量观察经验在大脑中形成的快速判断。后半部分讨论如何在战斗中运用这种直觉，例如当背后的野兽突然安静时，往往意味着它正准备扑击。作者还提醒，直觉需要与理性验证结合，否则会陷入过度紧张的误判。书中建议每次依赖直觉做出决策后，回头检查判断依据，把正确与错误都记录下来，逐渐校准自己的感觉。最末页是一份为期一个月的野外独居训练计划。荒野试炼场与原住民营地把它当作勇士成长的一部分。作者相信，荒野从不会欺骗认真倾听它的人。作者提醒，直觉是经验的回声，而不是天赋的礼物。

## 设计意图

为驯兽师提供环境感知增益，强化野外探索时的代入感与生存优势。
