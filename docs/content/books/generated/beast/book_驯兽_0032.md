# 《野兽嗅觉强化》

- **关联技能**：`beast_sense_enhance`

## 书籍内容

《野兽嗅觉强化》教导驯兽师如何通过训练与草药辅助，放大野兽伙伴的感知能力。作者指出，大多数野兽的感官本来就远胜人类，只是缺乏针对性的引导。书中先讲解嗅觉训练：用沾有目标气味的布条进行追踪游戏，逐步增加距离与干扰气味。中间章节介绍听觉训练：在夜间让野兽闭眼，仅通过声音判断目标方位。后半本则记录了几种增强感知的天然药剂配方，包括薄荷、龙血草与某种稀有真菌的混合物。作者在最后强调，感知强化会让野兽更容易疲劳，因此每次任务后都需要额外休息。卷末写道："它们的鼻子能闻到谎言，耳朵能听到恐惧。你要做的，是学会相信它们。"书末附有一套为期两周的感知强化训练计划，从简单气味追踪逐步过渡到复杂环境下的多目标分辨。书中提醒训练必须循序渐进。

## 设计意图

为侦察与反隐玩法提供基础能力，让野兽伙伴在探索与警戒中发挥不可替代的作用。
