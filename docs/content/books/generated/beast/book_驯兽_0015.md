# 《冰霜巨狼契约》

## 基础信息

- **书籍 ID**：`book_驯兽_0015`
- **关联技能**：`beast_ice_wolf`
- **使用效果**：阅读后解锁 `beast_ice_wolf`；若已学会，提升该技能 `current_mastery +90`，并使冰霜巨狼的撕咬附加 1 层寒冷减速。
- **阅读要求**：角色职业标签含 `warrior`、`ranger` 或 `barbarian`；基础 `力量 ≥ 9` 或 `体质 ≥ 9`。
- **稀有度**：精良（Uncommon）
- **建议投放**：永冬森林狼穴、霜巨人营地、冰原祭坛传承任务。

## 书籍内容

《冰霜巨狼契约》讲述了与极地霜狼建立灵魂契约的严寒仪式。作者强调，冰霜巨狼只会尊重能在暴风雪中站立不动的人，因此契约前的考验往往是在雪地中静坐一夜。书中前半部分讲解如何解读霜狼的沉默语言：它们不像普通狼那样频繁嚎叫，而是通过耳朵角度、尾巴高度与呼吸节奏表达情绪。中间章节介绍战斗协同：冰霜巨狼的吐息可以冻结小片地面，限制敌人的移动路径。后半本记录了如何为霜狼维持低温环境：在营地中准备雪坑、避免长时间暴露在炎热气候中。作者在最后写道："霜狼的忠诚像冰一样坚固，也像冰一样容易碎裂。背叛它一次，你的血会比雪更冷。"书中还附有一张霜狼足部护理图，说明如何在长途行军后清理冰碴与检查肉垫裂伤。书中附有一张霜狼换毛期护理要点表，帮助骑手在换毛季节减少毛发打结。

## 设计意图

为近战与游侠职业提供控场型伙伴，用寒冷效果强化战棋中的地形控制与追击能力。
