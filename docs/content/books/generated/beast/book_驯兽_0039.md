# 《兽骨武器强化》

## 基础信息

- **书籍 ID**：`book_驯兽_0039`
- **关联技能**：`beast_bone_weapon`
- **使用效果**：阅读后解锁 `beast_bone_weapon`；若已学会，提升该技能 `current_mastery +80`，并使兽骨制作的武器伤害提高 5%。
- **阅读要求**：角色职业标签含 `warrior`、`barbarian` 或 `rogue`；基础 `力量 ≥ 9`。
- **稀有度**：精良（Uncommon）
- **建议投放**：武器匠、野蛮人营地、骨雕师工作台。

## 书籍内容

《兽骨武器强化》记录了利用野兽骨骼打造与强化武器的独特技艺。作者认为，兽骨武器不仅轻便锋利，还保留了原主的部分野性，因此特别适合敏捷与力量并重的战士。书中先讲解选材：腿骨适合做柄，肋骨适合制作弯刀，獠牙与角则是天然矛头。中间章节介绍强化工艺：通过油脂浸泡防止脆裂，用特定草药熏蒸增加韧性，或在骨刃上刻下激发兽魂的符文。后半本记录了使用兽骨武器的心理准备：许多战士会在战斗前轻抚骨刃，向原主野兽致意。作者在最后提醒："兽骨会记住最后一次战斗的愤怒。如果你没有资格驾驭这份愤怒，它会在最关键的时刻折断。"书末附有一张兽骨武器净化仪式说明，建议在每次重大战斗后用清水与草药 smoke 清洁骨刃。作者还提醒，兽骨武器忌讳暴晒，干燥过度会让骨刃变脆。

## 设计意图

为近战职业提供与驯兽系统联动的武器强化路径，让野兽素材成为装备体系的重要组成部分。
