# 《暗影兽潜行》

## 基础信息

- **书籍 ID**：`book_驯兽_0135`
- **关联技能**：`beast_shadow_stalker`（待新增，标签 `beast`、`shadow`）
- **使用效果**：阅读后解锁 `beast_shadow_stalker`；若已学会，提升该技能 `current_mastery +180`，并使夜间与暗影属性野兽共享隐匿效果。
- **阅读要求**：角色职业标签含 `rogue`、`ranger` 或 `beastmaster`；基础 `感知 ≥ 13`。

- **建议投放**：暗影公会、盗贼据点、夜行森林。

## 书籍内容

暗影属性的野兽只在夜晚完全展现力量，它们对光线、声音与气息极为敏感。这本书教授如何在黑暗中与这些野兽同行而不被它们视为入侵者。作者强调，潜行不只是不被敌人发现，也包括不让自己的伙伴因误判而受惊。书中详细说明夜行步伐、气味抑制与阴影利用，并给出在月光下与暗影兽沟通的特殊手势。后半部分讨论暗影兽攻击前的征兆：耳尖颤动、瞳孔扩张与尾巴低垂。作者还特别警告，暗影兽对背叛的记忆极为长久，任何一次出卖都会让它们永远消失在夜色中。书中建议在建立信任阶段避免任何形式的欺骗，哪怕是善意的误导也可能留下裂痕。最末页警告：暗影兽的信任一旦建立，它们会主动保护驯兽师；但若被背叛，追杀将无休无止。暗影公会与夜行森林常藏有此书。
