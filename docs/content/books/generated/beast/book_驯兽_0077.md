# 《兽群包围圈》

## 基础信息

- **书籍 ID**：`book_驯兽_0077`

## 书籍内容

狼群最强大的地方不是单只狼的牙齿，而是它们懂得如何一起制造一个无法逃脱的圆。本书用几何图形讲解了兽群包围的基本原则：每只野兽占据目标周围约一百二十度的扇面，始终保持移动，让敌人无法锁定单一方向。作者强调，包围不是为了立刻杀死，而是为了消耗敌人的意志和体力。书中还记录了“收紧节奏”：当目标试图突围时，该方向的野兽后撤，两侧的野兽收紧，把突围变成自投罗网。后半部讨论了不同数量野兽的阵型变化：三只呈三角，五只呈梅花，七只以上则开始利用轮换休息。作者还提醒，包围圈最怕的是驯兽师自己慌乱移动，因为野兽会误把主人的焦虑当作撤退信号。最末页写着一位老狼王驯兽师的笔记：“包围圈的真正杀手不在圈内，而在圈外——那是留给最后一口的位置。”

## 设计意图

为以多野兽为核心的构建提供终极群攻战术，突出数量优势与空间控制。
