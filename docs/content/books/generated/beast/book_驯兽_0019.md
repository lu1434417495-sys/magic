# 《蛛网陷阱配合》

## 书籍内容

《蛛网陷阱配合》是一本关于如何利用巨型蜘蛛设置战场地形的进阶手册。作者强调，蜘蛛不是冲锋单位，而是完美的区域控制专家。书中先讲解如何挑选合适的蜘蛛：太大的难以隐藏，太小的网不够结实，最佳体型约等于一只大型犬。中间章节介绍布网战术：提前在高处、拐角与必经之路上布置蛛网，然后用诱饵将敌人引入。后半本记录了如何应对蛛网被火攻破解的问题：可以使用特殊黏液增加火焰抗性，或选择对火焰免疫的灰烬蜘蛛。作者在最后提醒，永远不要站在蜘蛛与猎物之间，因为它的本能会优先攻击移动目标，不管那个目标是不是你。卷末附有一张常见蛛网类型图鉴。作者特别强调，布置蛛网后要定期更换位置，否则敌人会学会绕开固定陷阱。书中还建议在不同地形中测试蛛网强度，从岩石到树枝的承重点各有不同。

## 设计意图

为游侠与盗贼提供地形控制能力，让玩家通过布网改变战棋地形，制造分割与伏击机会。
