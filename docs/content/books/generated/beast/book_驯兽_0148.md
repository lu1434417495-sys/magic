# 《驯兽之王气势》

## 基础信息

- **书籍 ID**：`book_驯兽_0148`
- **关联技能**：`beast_king_presence`（待新增，标签 `beast`）
- **使用效果**：阅读后解锁 `beast_king_presence`；若已学会，提升该技能 `current_mastery +250`，并使对高阶野兽的初始敌意判定成功率提高。

- **稀有度**：史诗（Epic）

## 书籍内容

驯兽师到达一定境界后，会自然散发出让野兽敬畏的气场。这本书从意志、阅历、战绩与对生命的尊重四个维度，讲解如何培养这种王者气势。作者指出，真正的王者气势不是霸凌，而是让野兽感到跟随你比独自生存更安全、更有尊严。后半部分讨论如何利用气势在初次见面时压制高阶野兽的敌意，以及如何在群体中快速确立领导秩序。作者还强调，气势与责任相伴，拥有王者气势的驯兽师必须承担保护弱小与维护秩序的重任，否则气势会转为暴虐。书中建议在每日训练前进行短暂的自省，确认自己的内心是否配得上这份力量。最末页提醒：气势一旦用于欺凌弱小，就会变质为恐惧，反而会引来最强者的挑战。万兽之巅与兽王竞技场把它当作冠军驯兽师的毕业典礼。书中写道，真正的王者让每一只野兽都愿意追随。

## 设计意图

为高阶驯兽师提供社交/威慑层面的被动能力，强化角色扮演的王者气质。
