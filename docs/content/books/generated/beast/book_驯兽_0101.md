# 《野兽驯养基础》

## 基础信息

- **书籍 ID**：`book_驯兽_0101`
- **关联技能**：`beast_taming_basic`（待新增，标签 `beast`）
- **使用效果**：阅读后解锁 `beast_taming_basic`；若已学会，提升该技能 `current_mastery +60`，并使首次驯服低阶野兽时成功率提高 10%。
- **阅读要求**：无职业限制；基础 `感知 ≥ 6`。
- **稀有度**：普通（Common）
- **建议投放**：新手村猎户、兽栏训练师、初级探险营地书架。

## 书籍内容

这本手册把驯兽拆解为观察、喂食与建立边界三个环节。作者强调，野兽不是等待被征服的对手，而是拥有记忆与情绪的独立生命。书中先用一匹被遗弃的战马为例，说明稳定作息如何让受惊动物重新信任人类；接着又列举新手常犯的错误，例如直视掠食者眼睛会被视为挑衅。每章结尾附有“今日不可做”清单，提醒读者不要急于靠近、不要空腹接触、不要在野兽进食时打扰。作者反复写道，驯兽师最先要驯服的是自己的呼吸与情绪，因为紧张会通过气味和动作传递。书中还建议每日固定三次短时间接触，让野兽把驯兽师与安全感而非压力联系起来。最后一页是一张常见低阶野兽的食性表，并附有初学者三十天记录模板，被无数营地奉为入门必读。书中还强调，失败的驯养往往始于人类急于证明自己是主人。

## 设计意图

作为驯兽系最底层的认知书，把装备养护与长期成长绑定，让玩家从第一次接触野兽就建立尊重与耐心。
