# 《群体安抚咆哮》

## 基础信息

- **书籍 ID**：`book_驯兽_0048`
- **关联技能**：`beast_calm_roar`
- **使用效果**：阅读后解锁 `beast_calm_roar`；若已学会，提升该技能 `current_mastery +85`，并使你的咆哮有 25% 几率让半径 3 格内的敌对野兽停止攻击 1 回合。
- **阅读要求**：角色职业标签含 `ranger`、`barbarian` 或 `druid`；基础 `魅力 ≥ 10` 或 `意志 ≥ 10`。
- **稀有度**：史诗（Epic）
- **建议投放**：兽王祭坛、和平林地、世界树祭坛奖励。

## 书籍内容

《群体安抚咆哮》传授了一种古老而危险的技术：用声音模仿顶级掠食者的镇定信号，让暴怒的野兽重新评估局势。作者强调，这种咆哮不是威胁，而是一种"这里没有猎物值得拼命"的宣告。书中先讲解发声技巧：低沉、稳定、从腹部发力，避免尖锐或颤抖的音调。中间章节介绍不同野兽对咆哮的反应：狼群会后退评估，熊会站立观察，猫科动物则会犹豫是否继续潜行。后半本记录了失败案例：当咆哮者自身恐惧或受伤过重时，咆哮会被识破并引发更猛烈的攻击。作者在最后写道："真正的兽王咆哮，是让你和野兽都活下去的声音。"书末附有一张咆哮使用后的撤退路线规划图，提醒驯兽师安抚成功后果断离开，避免再次激怒兽群。书中还强调，咆哮只能争取时间，真正的安全来自撤退路线的预先规划。

## 设计意图

为控场型驯兽师提供非致命解决方案，让玩家在面对野兽敌人时可以选择安抚而非杀戮，丰富战术选择。
