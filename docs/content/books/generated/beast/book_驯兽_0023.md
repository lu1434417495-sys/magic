# 《灵魂兽链接》

## 基础信息

- **书籍 ID**：`book_驯兽_0023`
- **关联技能**：`beast_soul_link`
- **使用效果**：阅读后解锁 `beast_soul_link`；若已学会，提升该技能 `current_mastery +85`，并使野兽伙伴承担主人受到的单次伤害的 5%。
- **阅读要求**：无职业限制；基础 `意志 ≥ 9`。
- **稀有度**：稀有（Rare）
- **建议投放**：灵魂行者营地、古老遗迹、精神导师传承。

## 书籍内容

《灵魂兽链接》探索了驯兽师与野兽之间最深层的精神连接。作者认为，当两者的灵魂频率足够接近时，痛苦与快乐都会在彼此之间流动。书中先讲解冥想前置：必须先在七天七夜内与野兽同吃同住，让彼此的梦境开始交融。中间章节介绍链接建立后的效果：驯兽师能感受到野兽的疼痛方向，野兽也能在主人遇险时突破距离限制赶回。后半本记录了链接的副作用：如果野兽死亡，驯兽师会经历剧烈的精神创伤；如果链接被强行切断，双方都可能永久失去部分感知。作者在最后提醒："灵魂链接不是锁链，而是一座桥。桥的两端都必须是自由的。"卷末附有一张灵魂链接维护仪式表，建议在每月满月时进行简短冥想以稳固链接。作者强调，链接双方必须定期进行单独训练，避免过度依赖彼此的能力。

## 设计意图

为高投入驯兽玩法提供深度绑定机制，让伙伴真正成为角色的一部分，强化情感与战略双重价值。
