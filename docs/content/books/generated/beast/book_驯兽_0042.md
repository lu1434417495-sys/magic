# 《跨位面兽栏》

## 基础信息

- **书籍 ID**：`book_驯兽_0042`
- **关联技能**：`beast_planar_stable`
- **使用效果**：阅读后解锁 `beast_planar_stable`；若已学会，提升该技能 `current_mastery +85`，并使你可以在任意地点从跨位面兽栏中召唤已绑定的野兽。
- **阅读要求**：角色职业标签含 `mage` 或 `warlock`；基础 `智力 ≥ 12`。
- **稀有度**：史诗（Epic）
- **建议投放**：次元枢纽、位面行者藏身处、虚空图书馆密室。

## 书籍内容

《跨位面兽栏》记录了如何在异次元空间中为野兽建立稳定栖息地的尖端技艺。作者指出，随着驯兽师收集的野兽越来越多，普通兽栏已无法满足需求，而跨位面兽栏可以为每种野兽提供最适合它们原生的环境。书中先讲解兽栏的次元锚定：需要一个稳定的能量源与精确的坐标，否则野兽可能会在传送中迷失。中间章节介绍兽栏内部生态：火焰区、水域区、森林区、虚空区各自独立运行。后半本记录了紧急召唤技巧：在战斗中打开临时裂隙，让特定野兽加入战局。作者在最后警告："次元裂缝是野兽的庇护所，也是混乱的入口。不要让太多不同世界的法则在同一处碰撞。"书末附有一张跨位面兽栏维护周期表，包括能量源检查、环境参数校准与野兽健康巡视频率。作者强调维护不可懈怠。书中还提到。

## 设计意图

为高端法师型驯兽师解决多野兽携带与即时召唤的问题，让"野兽军团"概念在战棋中真正可行。
