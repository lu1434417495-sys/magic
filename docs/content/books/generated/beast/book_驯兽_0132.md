# 《灰烬兽驯化》

## 基础信息

- **书籍 ID**：`book_驯兽_0132`
- **关联技能**：`beast_ashen_taming`（待新增，标签 `beast`、`ashen`）
- **使用效果**：阅读后解锁 `beast_ashen_taming`；若已学会，提升该技能 `current_mastery +160`，并使灰烬交界变异野兽的疯狂触发率降低。

- **稀有度**：稀有（Rare）

## 书籍内容

灰烬交界的能量会扭曲野兽的心智，使它们时而狂暴、时而沉寂。这本书传授如何在保持自身清醒的同时，帮助这些变异野兽找回稳定的情绪节律。作者提出“余烬安抚法”：用低沉的声音、熟悉的节奏与少量含有异界尘埃的草药，让野兽在疯狂边缘找到锚点。书中记录了大量失败案例，提醒读者灰烬兽的信任极为脆弱，一次背叛足以让它彻底失控。后半部分讨论灰烬兽常见变异特征的识别与应对，例如发光的瞳孔、不规则的心跳与对普通食物的排斥。作者还建议为每只灰烬兽建立单独档案，记录其情绪周期与触发因素，因为个体差异远大于普通野兽。最末页附有一张危险等级表，余烬祭所与变异兽收容站的员工人手一本。作者强调，灰烬兽需要的不是拯救，而是一个愿意理解它们的人。

## 设计意图

把灰烬交界的环境风险融入驯兽玩法，为探索该区域提供专属能力。
