# 《战象调驯录》

## 基础信息

- **书籍 ID**：`book_驯兽_0010`
- **关联技能**：`beast_elephant_war`
- **使用效果**：阅读后解锁 `beast_elephant_war`；若已学会，提升该技能 `current_mastery +75`，并降低战象冲锋的 AP 消耗 1 点。
- **阅读要求**：角色职业标签含 `warrior` 或 `paladin`；基础 `体质 ≥ 11`。
- **稀有度**：普通（Common）
- **建议投放**：南方帝国军营、象夫训练营、沙漠商队首领奖励。

## 书籍内容

《战象调驯录》是一部关于如何把巨象转化为战场攻城锤的厚重手册。作者强调，象的记忆远超人类想象，一次虐待会让它记恨十年，而一次救命之恩会让它终生追随。书中首先讲解象的日常护理：脚底清理、耳朵防晒与长牙保养。中间部分重点描述战象的冲锋控制：骑手通过膝盖压力与脚踵敲击传递转向信号，鼻钩只在极端情况下使用。后半本记录了三种战象阵型：单列突破、双象锁阵与象墙防御。作者在最后提醒，象对火焰与高分贝噪音极度敏感，因此使用前必须确认敌方没有火油壶或爆鸣法术。卷末附有一张象语口令表，以及一句训象师的格言："你坐在山一样的动物背上， Remember 它记得你的一切。"录末还附有一张象夫专用的手势图，包含冲锋、转向、停止与安抚等十八个指令，必须在安静环境中反复练习。

## 设计意图

为前排重甲职业提供高冲击、高控制的坐骑选择，突出战象在战棋中打破阵线的战略价值。
