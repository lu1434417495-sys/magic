# 《火焰蜥蜴驯养》

## 基础信息

- **书籍 ID**：`book_驯兽_0014`
- **关联技能**：`beast_fire_lizard`
- **使用效果**：阅读后解锁 `beast_fire_lizard`；若已学会，提升该技能 `current_mastery +80`，并使火焰蜥蜴伙伴获得 10% 火焰抗性。
- **阅读要求**：角色职业标签含 `mage` 或 `ranger`；基础 `智力 ≥ 8`。
- **稀有度**：精良（Uncommon）
- **建议投放**：火山研究所、元素法师塔藏书、熔岩洞窟探索奖励。

## 书籍内容

《火焰蜥蜴驯养》记录了如何在高温环境中驯养这种小型元素野兽。作者提醒，火焰蜥蜴不是普通爬行动物，它们的体温会随情绪升高，因此愤怒时绝对不能用手直接抓取。书中先讲解栖息环境：一个持续温暖的石穴、足够的硫磺气味与定期的火山岩沐浴。中间章节介绍喂食要点：它们以熔岩虫与高温矿石碎屑为食，普通肉类只会让它们萎靡。后半本详细描述了战斗配合：火焰蜥蜴可以喷吐短距离火焰点燃地面，为法师的范围法术创造持续伤害区。作者在最后警告，不要让它们在木质建筑中释放火焰，否则你会先失去房子再失去伙伴。卷末附有一张"火焰蜥蜴情绪温度表"，帮助驯兽师判断何时该退后。作者还建议，每次与火焰蜥蜴互动后都要检查它的尾尖颜色，颜色变暗往往预示着健康或情绪问题。

## 设计意图

为法师与游侠提供元素型伙伴，增强火焰战术的协同性，让玩家体验元素野兽与普通野兽的差异。
