# 《驯鹰手札：天空之眼》

## 基础信息

- **书籍 ID**：`book_驯兽_0003`
- **关联技能**：`beast_hawk_eye`
- **使用效果**：阅读后解锁 `beast_hawk_eye`；若已学会，提升该技能 `current_mastery +85`，并使鹰类伙伴的侦察范围扩大 10%。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；基础 `感知 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：风息哨塔、猎鹰人帐篷、高空据点训练场。

## 书籍内容

《驯鹰手札：天空之眼》是一本关于如何让鹰隼成为战场侦察兵的实用手册。作者从选鹰开始讲起：幼鹰易驯但战力弱，成鹰凶猛却难以信任，最佳对象是刚过第一个冬天的亚成体。书中详细描述了戴 hood、放飞与召回的手势，强调每个动作都要与食物奖励绑定，让鹰把人类与"稳定猎物来源"联系在一起。中间章节讲解如何利用鹰的视野为地面部队标记敌人：一种特殊的短哨代表"发现目标"，连续两声代表"危险接近"。后半本还记录了在战棋地形中让鹰俯冲干扰敌阵的战术。作者在最后写道："鹰从不属于你，它只是同意在你需要时，借给你它的眼睛。"手札末尾附有十二种常见鹰病的简易诊断法，从羽毛黯淡到粪便异常，帮助驯鹰人在早期发现问题。作者特别强调，幼鹰换羽期间不宜过度放飞，否则会影响新羽的生长方向。

## 设计意图

为弓箭手与游侠提供侦察与信息优势，将"高空视野"转化为战棋中的先机机制，鼓励玩家在开战前部署天空之眼。
