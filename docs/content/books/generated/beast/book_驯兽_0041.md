# 《共生契约：高级》

## 基础信息

- **书籍 ID**：`book_驯兽_0041`
- **关联技能**：`beast_symbiosis_advanced`
- **使用效果**：阅读后解锁 `beast_symbiosis_advanced`；若已学会，提升该技能 `current_mastery +90`，并使主人与野兽伙伴之间的增益效果可以互相共享。
- **阅读要求**：无职业限制；基础 `意志 ≥ 11`。
- **稀有度**：史诗（Epic）
- **建议投放**：远古遗迹深处、传奇驯兽师传承、世界树根系密室。

## 书籍内容

《共生契约：高级》探讨了驯兽师与野兽之间超越命令与服从的深层共生关系。作者认为，真正的共生不是一方依赖另一方，而是两者在战斗中互相成为对方的延伸。书中先讲解契约的重新书写：必须放弃传统的主从条款，改为互相保护的誓言。中间章节介绍共生效果：当主人受到加速法术时，野兽也会获得同等的速度加成；当野兽进入狂暴状态时，主人的攻击也会附带野性伤害。后半本记录了维持共生的代价：双方距离不能超过一定范围，否则共生链接会断裂并造成反噬。作者在最后写道："共生意味着你们共享生命，但不共享死亡。记住这个区别，因为它会救你一命。"书末附有一份共生契约重新书写模板，要求双方明确列出愿意为对方承担的风险边界。书中还附有一张共生破裂预警表。

## 设计意图

作为高级驯兽build的核心羁绊技能，让 buff 管理从单人优化扩展到双人协同，提升策略深度。
