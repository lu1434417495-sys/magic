# 《熊骑入门：负重与平衡》

## 基础信息

- **书籍 ID**：`book_驯兽_0004`
- **关联技能**：`beast_bear_mount`
- **使用效果**：阅读后解锁 `beast_bear_mount`；若已学会，提升该技能 `current_mastery +70`，并提高骑乘状态下负重上限 12%。
- **阅读要求**：角色职业标签含 `warrior` 或 `barbarian`；基础 `力量 ≥ 10` 或 `体质 ≥ 10`。
- **稀有度**：普通（Common）
- **建议投放**：北境蛮族营地、熊皮旅店藏书、山岳聚落传承任务。

## 书籍内容

《熊骑入门：负重与平衡》讲述了如何与一头成年棕熊建立骑乘合作关系。作者直言，熊永远不可能像马那样温顺，因此骑手要学会读懂它的情绪边界。书中用三章篇幅讲解上熊动作：必须从侧面靠近，避免站在熊的正面直线；上马时要借助熊肩胛骨的隆起，把重心压在它最稳定的部位。中间部分讨论如何在战斗中保持平衡，包括膝夹、腰转与随熊呼吸起伏。后半本记录了几种熊类坐骑的冲锋战术：短距突袭、震地威慑与背靠防御。作者在附录中警告：熊会在饥饿时把命令排在食物之后，所以骑手必须永远随身携带比熊嘴里更香的饵料。书中还提到，棕熊在秋季会进入暴食期，此时不宜进行战斗训练，否则它会将骑手与食物产生危险联想。书中还附有一张冬季熊骑保暖装备清单，从毛垫到防风面罩一应俱全。

## 设计意图

为前排战士职业提供高负重、高冲击的骑乘方案，让熊坐骑兼具机动与威慑，突出蛮荒战斗风格。
