# 《野兽安抚手法》

## 基础信息

- **书籍 ID**：`book_驯兽_0105`
- **关联技能**：`beast_soothing_touch`（待新增，标签 `beast`）
- **使用效果**：阅读后解锁 `beast_soothing_touch`；若已学会，提升该技能 `current_mastery +60`，并降低野兽因紧张进入敌对状态的概率。
- **阅读要求**：无职业限制；基础 `感知 ≥ 6`。
- **稀有度**：普通（Common）
- **建议投放**：兽医帐篷、动物收容所、修道院偏院。

## 书籍内容

这本薄薄的小册子专门讲解如何通过触碰来缓解野兽的紧张。作者从肩膀、耳根、腹部三个安全区域入手，用图文说明按压的力度与节奏，提醒读者避开腹部以下与爪子正面等敏感部位。书中反复告诫：安抚之前必须先让野兽闻到你的手背，动作要像风拂过草叶一样缓慢，而不是突然拍击。后半部分收录了多种常见野兽的偏好，例如猫科喜欢耳后轻挠，犬科偏好胸侧抚摸，而蹄类动物则对背部轻敲反应良好。作者进一步指出，安抚的最佳时机是在野兽刚出现紧张信号但尚未进入防御状态时，一旦错过窗口，应立即后退重新建立距离。最末页有一段手写备注，强调安抚不是奖励，而是在危险情绪出现前 preemptively 浇灭火星。兽医帐篷里，这本书常被放在绷带旁边。书中总结，安抚的本质是让对方感到安全，而非被控制。

## 设计意图

给玩家提供非暴力的情绪管理手段，丰富驯兽师在探索与战斗外的互动选项。
