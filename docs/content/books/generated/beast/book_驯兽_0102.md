# 《野兽行为观察》

## 基础信息

- **书籍 ID**：`book_驯兽_0102`
- **关联技能**：`beast_behavior_watch`（待新增，标签 `beast`）
- **使用效果**：阅读后解锁 `beast_behavior_watch`；若已学会，提升该技能 `current_mastery +60`，并使观察野兽时更易发现攻击前兆。
- **阅读要求**：无职业限制；基础 `感知 ≥ 6`。
- **稀有度**：普通（Common）
- **建议投放**：猎人小屋、野外营地、低级图书馆。

## 书籍内容

书中主张驯兽始于观察而非接触。作者用三十六个简笔图示分解野兽的耳朵、尾巴、瞳孔与肩颈姿态，教读者判断它们是放松、警惕还是即将攻击。一个核心案例记录了一头棕熊在发起冲锋前会刻意压低耳朵并左右晃动头部，能识别这一征兆的猎户往往能全身而退。后半本收录了不同季节、不同天气下野兽行为的变化，强调饥饿与繁殖期会大幅改变判断标准。作者提醒，观察时应保持下风口并利用掩体，因为野兽的嗅觉与视觉同样敏锐。他还建议随身携带一本小型观察日志，用符号快速记录每次遭遇的细节，时间久了就能建立属于自己的行为数据库。最末页是一张空白观察表，供读者记录自己遇到的目标，许多资深驯兽师把它当作传承给学徒的第一份作业。作者认为，耐心是观察者的第一武器。
