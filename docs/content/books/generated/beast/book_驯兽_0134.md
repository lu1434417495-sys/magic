# 《驯兽：斗气震慑》

- **书籍 ID**：`book_驯兽_0134`

## 书籍内容

修炼者的斗气不仅能强化自身，也能在驯服猛兽时发挥作用。作者介绍如何在不伤害野兽的前提下，用斗气释放压迫感，让猛兽在力量层面承认驯兽师的领导地位。书中强调，斗气震慑必须与稳定的眼神和自信的站姿配合，否则会被野兽识破为虚张声势。后半部分讲解不同属性斗气对野兽的影响，例如火属性容易激怒耐寒生物，而土属性更容易让地行兽屈服。作者还建议初学者先以低强度斗气试探野兽反应，逐步提升压迫等级，突然释放全部气势往往会引发死斗。书中提醒，斗气震慑后必须给予野兽明确的撤退或服从通道，否则被逼入绝境的猛兽只会拼死反击。最末页警告：斗气震慑只是打开对话的大门，真正的服从仍需通过耐心与奖励建立。武馆与斗气修炼场把它当作修炼者跨界驯兽的桥梁。

## 设计意图

打通 AURA 修炼与驯兽，让非法系职业也能通过斗气参与高阶驯服。
