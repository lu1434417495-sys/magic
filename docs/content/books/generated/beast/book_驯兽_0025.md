# 《斗气与野兽共鸣》

## 基础信息

- **书籍 ID**：`book_驯兽_0025`
- **关联技能**：`beast_cultivation_resonance`
- **使用效果**：阅读后解锁 `beast_cultivation_resonance`；若已学会，提升该技能 `current_mastery +85`，并使野兽伙伴获得主人 AURA 上限 5% 的加成。
- **阅读要求**：角色职业标签含 `warrior` 或 `barbarian`；基础 `力量 ≥ 10` 或 `体质 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：武馆传承、斗气修炼场、山岳聚落兽栏。

## 书籍内容

《斗气与野兽共鸣》研究了修炼者如何将 AURA 能量分享给野兽伙伴。作者认为，斗气本质上是生命能量的高强度聚合，野兽对这种能量比人类更敏感。书中先讲解共鸣前提：修炼者必须能稳定控制自身 AURA 输出，否则过量的斗气会灼伤野兽。中间章节介绍三种共鸣方式：保护型共鸣增强野兽防御、爆发型共鸣提升野兽攻击、治疗型共鸣加速野兽恢复。后半本记录了与不同野兽共鸣的适配性：熊适合保护型，狼适合爆发型，而马适合耐力型。作者在最后强调："斗气共鸣不是施舍，而是共同呼吸。你的 AURA 流向它时，它的生命也在回应你。"卷末附有一张不同野兽最适合的共鸣类型对照表，帮助修炼者根据伙伴特性选择最佳强化方向。书中还警告，强行让不适合的野兽承受某种共鸣可能导致长期伤害。书中还提到。

作为修炼与驯兽的交叉技能书，让非法系职业也能通过 AURA 强化伙伴，拓宽 build 可能性。
