# 《桩功蓄势：蓄力桩》

## 基础信息

- **书籍 ID**：`book_cultivation_0026`
- **关联技能**：`cultivation_power_storing_stance`（待新增，标签 `cultivation`）

## 书籍内容

蓄力桩教人如何在静止中积蓄力量，像拉满的弓弦一样在需要时瞬间释放。书中第一章讲解基本姿势：双脚前后开立，重心略低，双手如握重物置于腰间，全身肌肉保持适度紧张。第二章强调「蓄而不僵」：紧张要有弹性，像弹簧被压缩，而不是像石头被压死。作者指出，蓄力桩练的是势能，越是能长时间保持蓄力状态，爆发时威力越大。中段讨论呼吸配合：吸气时蓄力，呼气时保持，直到需要爆发的瞬间再一次性呼出。后半本给出安全警示：初学者不要一次蓄力太久，否则可能导致肌肉痉挛或血压升高。末页写着：「站桩不是休息，是把身体拧成一把未出鞘的刀。」角斗场后台常见选手在出场前站蓄力桩，让观众的喧嚣逐渐退成背景，只剩下自己与下一轮爆发的那个瞬间。此书适合狂战士、战士等依赖爆发的职业。

## 设计意图

把桩功与爆发伤害机制结合，让玩家体验「蓄势待发」的战斗节奏，为后续高阶爆发功法提供前置。
