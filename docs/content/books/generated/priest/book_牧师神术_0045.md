# 《锁链束缚祷》

## 基础信息

- **书籍 ID**：`book_牧师神术_0045`
- **关联技能**：`priest_binding_chains`（待新增）
- **使用效果**：阅读后解锁 `priest_binding_chains`；若已学会，提升 `current_mastery +90` 并束缚一名敌人一回合，限制其移动与攻击范围。
- **阅读要求**：角色职业标签含 `priest` 或 `support`；基础 `意志 ≥ 9`。
- **稀有度**：普通（Common）
- **建议投放**：监狱、封印任务、中级控制支线。

## 书籍内容

锁链不是由金属打造，而是由一句接一句的祷词编织而成。作者认为束缚敌人的最高境界不是让他们无法动弹，而是让他们意识到继续挣扎已经没有意义。每一节锁链对应一个事实：你伤害了他人、你的力量被滥用、此刻你不能再前进。念完三节，锁链才算完整。书中强调，如果施术者自己心中也充满攻击欲，锁链会变得脆弱，因为链子的两端必须同时系在秩序上。练习时要在风中念出三节祷词，直到能让一片落叶在空中悬停三秒。最后一页画着一副锁链的草图，每一环上都写着一个被束缚者的名字，最下面一行小字是作者的提醒：记住这些名字，锁链不是为了忘记他们，是为了让他们有机会重新选择。这本书在城市守卫与教会执法者之间很受欢迎，因为它比镣铐更人道，也比说服更有效。

## 设计意图

为牧师系提供基础单体控制技能，通过秩序与选择主题包装，让控制效果具备叙事合理性，适合战棋中的集火准备。
