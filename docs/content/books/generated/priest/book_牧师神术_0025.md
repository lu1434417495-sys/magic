# 《衰弱诅咒解除》

## 基础信息

- **书籍 ID**：`book_牧师神术_0025`
- **关联技能**：`priest_lift_weakness`（待新增）
- **使用效果**：阅读后解锁 `priest_lift_weakness`；若已学会，提升 `current_mastery +80` 并移除一名友方身上的力量削弱或防御削弱效果。
- **阅读要求**：角色职业标签含 `priest` 或 `support`；基础 `意志 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：被诅咒遗迹、解毒支线、中级牧师导师。

## 书籍内容

这本书的每一页都画着一个人形的轮廓，不同页上标注着诅咒盘踞的位置：肩膀、膝盖、手腕、喉咙。作者认为衰弱诅咒就像一层看不见的湿布，裹在受术者身上，让他们每一次动作都比平常沉重。解除的方法不是用力撕开，而是找到湿布的边缘，轻轻卷起。书中列出了几种常见的解除顺序，警告说如果顺序错误，诅咒可能会从一个部位移到另一个部位。最复杂的一章讲述如何同时处理两层诅咒：先让受术者承认自己的无力，再帮助他们记起自己有力量的时刻。最后一页贴着一小撮黑色的粉末，附注说这是从第一个成功解除的诅咒上收集的残留物，放在阳光下会自己散开，提醒着读者：诅咒最怕的不是神力，是被看见。这本书在冒险者公会中被当作入门解咒手册，因为削弱型诅咒是废墟探索中最常见的麻烦。

## 设计意图

为牧师系提供基础属性恢复类解控技能，针对常见的Debuff设计，强化牧师作为状态管理者的战术价值。
