# 《默哀仪式》

## 基础信息

- **书籍 ID**：`book_牧师神术_0036`
- **关联技能**：`priest_ritual_of_silence`（待新增）
- **使用效果**：阅读后解锁 `priest_ritual_of_silence`；若已学会，提升 `current_mastery +90` 并在一回合内让自身周围一格范围内的敌人无法发出声音，打断需要吟唱的敌方技能。
- **阅读要求**：角色职业标签含 `priest` 或 `support`；基础 `意志 ≥ 9`。
- **稀有度**：普通（Common）
- **建议投放**：审判庭、反法师训练、中级打断支线。

## 书籍内容

仪式不需要语言，只需要一段特定长度的沉默。这本书把沉默分成三种：空白的沉默、压抑的沉默、有力的沉默，只有第三种才能完成仪式。作者认为声音是意志向外扩散的形式，而默哀仪式则制造出一个反向的场，让所有意图通过声音表达的东西暂时失效。练习时要在喧闹的市场中央保持三分钟不说话，同时用目光与每一个看向你的人对视，让他们感受到你的沉默是有重量的。书中还提醒，仪式结束后必须说一句话，否则沉默会继续留在施术者身上，影响自己的咒语。最后一页贴着一片黑色的羽毛，附注说这是从一只哑鸟身上落下的，那片羽毛周围三指范围内，任何乐器都会走音。这本书在对抗吟游诗人与亡灵巫师的战斗中价值极高，因为它让最优雅的声音变成了最无力的挣扎。

## 设计意图

为牧师系提供基础打断与控制技能，以沉默仪式包装，针对吟唱型敌人设计，增加战棋中的战术反制选项。
