# 《自审明镜》

- **书籍 ID**：`book_牧师神术_0037`

## 书籍内容

书中教的不是照普通镜子，而是在心中凝聚一面镜子，用它来照见自己此刻的状态。作者认为许多负面状态之所以难以摆脱，是因为人们不愿意承认自己身上有这些东西。镜子的作用不是批判，而是让施术者看见：这个恐惧、这个愤怒、这个怨恨，此刻确实在这里。看见之后，再以一句简短的祷词请它们离开。书中警告说，镜子不能照别人，也不能照未来，只能照此刻的自己。最让学徒害怕的是练习时会先看见自己不想看见的部分，比如嫉妒或懦弱。书的最后一页贴着一小块破碎的镜片，边缘被布仔细包着，附注说：这是我第一次成功自审时用的镜子，它碎了，因为我终于不用它了。这本书常与《惩戒印记》一起发放，因为审判他人之前，牧师必须先学会审判自己。镜子碎了，不是因为失败，而是因为不再需要逃避自己。

## 设计意图

为牧师系提供基础自我净化技能，把解控机制与自省主题结合，强化牧师作为精神自律者的职业特色。
