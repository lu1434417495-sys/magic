# 《勇气颂歌》

## 基础信息

- **书籍 ID**：`book_牧师神术_0024`
- **关联技能**：`priest_canticle_of_courage`（待新增）
- **使用效果**：阅读后解锁 `priest_canticle_of_courage`；若已学会，提升 `current_mastery +80` 并为相邻友军解除恐惧状态并提升少量士气。
- **阅读要求**：角色职业标签含 `priest` 或 `support`；基础 `意志 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：战地鼓舞任务、军营礼拜、中级团队副本。

## 书籍内容

颂歌的旋律已经失传，但歌词保留了下来，每一句都短促有力，像鼓点一样。书中把演唱分为独唱与合唱两种形式：独唱适合在绝望时刻让一个人重新站起，合唱则适合在冲锋前统一整支队伍的心跳。作者认为勇气不是消灭恐惧，而是让恐惧退到身后一步，自己则向前迈出一步。歌词中没有提到胜利，只提到坚持：再站一回合、再挡一次、再看一眼。这让一些将军不满，他们希望颂歌能承诺胜利，但作者坚持说，承诺胜利是骗子的工作，牧师只说真话。最末页有一段用血写成的备注，来自某位战地牧师：我唱了这首歌七次，有三次我们活了下来，这已经足够让我继续唱第八次。这本书在低级军官中偷偷流传，因为正规战歌太华丽，而这首颂歌说的是他们真正经历的东西。它让普通士兵在最黑暗的时刻，仍然能迈出下一步。

## 设计意图

为牧师系提供基础士气激励技能，把解控与增益结合，强调持续作战中的心理韧性，适合战棋中的撤退/崩溃机制。
