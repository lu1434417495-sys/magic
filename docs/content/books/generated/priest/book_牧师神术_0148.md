# 《治愈辉光手抄》

## 基础信息

- **书籍 ID**：`book_牧师神术_0148`
- **关联技能**：`priest_healing_light`
- **使用效果**：阅读后解锁 `priest_healing_light`；若已学会，提升 `current_mastery +100` 并恢复全队每人少量 `current_hp`。
- **阅读要求**：角色职业标签含 `priest` 或 `support`；基础 `意志 ≥ 9`。
- **稀有度**：普通（Common）
- **建议投放**：大教堂训练室、初级救护任务、通用技能商人。

## 书籍内容

手抄把治疗之光比喻成一种可以被握在手心的温暖，而不是从天而降的闪电。作者说，辉光之所以治愈，是因为它不会强迫身体改变，而是提醒身体自己还记得如何完整。书中详细描述了手势：左手托住右手腕，右手掌心向下，手指微微张开，像是在接住从高处落下的沙子。手抄警告，施术时不能想着"我要治好你"，而要想着"我愿意和你多待一会儿"。最后一页贴着一小片烧过的纱布，旁边写着："这光治不好所有的伤，但它能让伤口不再孤单。"手抄封底贴着一小片被烧过的纱布，纱布上有一个干净的圆形，像是曾经覆盖在某个伤口上；附注说这个圆圈里的伤是唯一一处没有留下疤痕的，连当事人也记不起它曾经存在。纱布的边缘还留着一丝体温，摸起来比周围的书页更暖。大教堂训练室的新手总在这本手抄旁放一杯温水，模拟手的温度。

## 设计意图

作为牧师系标准治疗技能入口，提供稳定、低门槛的续航能力。
