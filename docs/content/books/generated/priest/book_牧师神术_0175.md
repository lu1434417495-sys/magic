# 《束缚祈祷残卷》

## 书籍内容

残卷的纸面布满折痕，像是被反复卷起又展开过无数次。它记载的是一种以祈祷限制敌人行动的神术：施术者双手合十，低声念出目标的名字，目标周围会出现一圈淡淡的光绳，阻止其离开特定范围。书中指出，这个神术对没有名字或名字已被遗忘的生物效果会大打折扣，因为束缚的力量锚定在名字上。作者还附有一份如何正确收集敌人名字的建议：从俘虏口中、从文书记录中、从他们的同伴呼唤中。残卷最后一页有一小块被剪掉的痕迹，附注说原本印着一段完整的真名辨识术，但已被教会高层以"过于危险"为由移除。被剪掉的位置边缘有几滴褐色的污渍，像是眼泪，也像是血迹，旁边有人用极细的笔迹补了一句："他们害怕的不是我们学会真名，而是真名学会我们。"滴落污渍的纸面微微凸起，触摸时能感觉到下面似乎还压着另一层被撕去的文字。

## 设计意图

为牧师提供基础控场技能，通过"名字"这一独特机制，让控制技能与探索、情报收集玩法产生联动。
