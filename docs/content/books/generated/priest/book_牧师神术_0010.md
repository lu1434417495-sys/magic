# 《临终安慰经》

## 基础信息

- **书籍 ID**：`book_牧师神术_0010`
- **关联技能**：`priest_last_comfort`（待新增）
- **使用效果**：阅读后解锁 `priest_last_comfort`；若已学会，提升 `current_mastery +60` 并对一名濒死友方提供一次性士气稳定，防止逃跑判定。
- **阅读要求**：角色职业标签含 `priest` 或 `support`；基础 `意志 ≥ 6`。
- **稀有度**：普通（Common）
- **建议投放**：战地医院、护送任务、新手牧师伦理支线。

## 书籍内容

这本书的封面比内页旧得多，说明它经常被随身携带，却很少被完整读完。书中不讲如何起死回生，只讲如何在最后一刻陪伴一个人。作者把临终者可能说的话分为三类：后悔、告别、提问，并为每一类准备了简短的回应。最重要的原则是不要急于给答案，也不要假装知道死后会发生什么，只需要让对方感到自己不是独自面对。书中有一段被反复抄写的句子：你可以害怕，可以愤怒，可以什么都不信，但此刻你值得被握住手。后半部分记录着各地不同的临终习俗，从北方的冰葬祷词到南方的灰烬撒放仪式，作者提醒读者：仪式属于家属，牧师的职责是握住那只逐渐变冷的手。最后一页只写着一句话：送别不是失败，是治疗的最后一步。这本书在战场上的价值无法量化，因为它决定的不是生死，而是死亡的形状。

## 设计意图

为牧师系提供基础士气稳定与濒死支援技能，强化神职者作为陪伴者与伦理角色的定位，契合战棋撤退机制。
