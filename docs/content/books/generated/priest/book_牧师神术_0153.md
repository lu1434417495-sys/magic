# 《神圣印记拓片集》

## 基础信息

- **书籍 ID**：`book_牧师神术_0153`
- **关联技能**：`priest_holy_sigil`（待新增）
- **使用效果**：阅读后解锁 `priest_holy_sigil`；若已学会，提升 `current_mastery +120` 并在地面留下持续治疗印记。
- **阅读要求**：角色职业标签含 `priest` 或 `support`；基础 `意志 ≥ 11`。

## 书籍内容

拓片集收集了十二种曾出现在古老祭坛上的神圣符号，每个符号旁边都附有使用说明和一段被涂抹的姓名。作者认为，神圣印记的力量不来自符号本身，而来自它曾被多少双手触摸、多少双膝盖跪过；一个从未被使用过的完美符号，反而不如一个被磨旧的粗糙印记有效。书中详细讲解如何在战场地面上快速绘制印记：用靴跟划圆、用杖尖点中、用掌心按地。作者特别提醒，绘制时必须默念受印者的名字，否则印记只会散发微光，无法传递治疗。拓片集最后一页贴着一枚真正的青铜祭坛残片，残片上的符号已经磨损得只剩轮廓，但摸起来依然温热。附注还提到，这枚残片来自一座被火山灰掩埋的村庄祭坛，当年全村人轮流跪在上面祈祷，直到青铜被体温焐出了永不消散的暖意。阴天时，残片上的符号会泛起一层薄薄的青绿色铜锈，只有在晴日才会重新露出温暖的金属光泽。

## 设计意图

为牧师提供地面持续治疗技能，增强阵地战中的续航能力，同时用"磨损即神圣"的概念深化信仰主题。
