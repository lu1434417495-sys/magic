# 《虔诚步伐》

## 基础信息

- **书籍 ID**：`book_牧师神术_0029`
- **关联技能**：`priest_pious_stride`（待新增）
- **使用效果**：阅读后解锁 `priest_pious_stride`；若已学会，提升 `current_mastery +80` 并在移动时不触发低级陷阱与地刺。

## 书籍内容

这本册子很薄，却被装在一个沉重的铁盒里，因为前主人认为它需要被认真对待。书中教的步伐不是快跑，也不是潜行，而是一种稳定的、有节奏的移动方式，每一步落地前都先在心中念完一个音节。作者认为陷阱感应的不是重量，而是仓促，走得越急，越容易触发机关；走得越稳，地面越愿意让你通过。练习时要在碎石路上来回走，直到能听见自己脚步里的节奏。书中还提醒，虔诚步伐不能让你飞过深渊，也不能让你穿过火焰，它只能让那些本可避免的麻烦暂时退开。最后一页贴着一片朝圣者之路的泥土，旁边写着：我走这条路七年，没有一次因为匆忙而受伤，却有无数次因为停留太久而错过日出。这本书在考古学者与探险牧师之间口碑极佳，因为他们最清楚古墓里有多少机关只惩罚急躁的人。

## 设计意图

为牧师系提供基础陷阱规避与移动辅助技能，把移动节奏与信仰状态结合，适合探索型战棋地图与机关关卡。
