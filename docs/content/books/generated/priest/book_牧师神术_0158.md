# 《光耀结界残册》

## 书籍内容

残册的封面曾经镀过金，如今只剩边角还在反光，像是被某种力量从中央灼烧过。它记载的是一种主动型防御神术：施术者用拇指在空中划出一个闭合的四边形，然后把它像贴符一样拍在同伴胸前。书中强调，结界的强度取决于施术者是否相信受保护者值得存活，而非施术者自身的能力；对敌人的怜悯、对同伴的怀疑，都会让结界出现肉眼不可见的裂缝。作者设计了一套每日冥想练习：面对一面镜子，先为自己施放结界，再为镜中的自己解除，以此训练"无差别守护"的心境。残册最后几页被虫蛀出规律的圆孔，远看竟像是一排排小小的盾形。书页夹层里还藏着半张破损的名单，上面列着十二位曾在战场上被此结界救下的人名，其中有三个名字被墨水划掉了。夜间，被虫蛀出的圆孔会透出微弱的星光，远看像是盾牌上镶嵌着一串小小的眼睛。

## 设计意图

为牧师提供护盾型防御技能，将防御效果与施术者信念绑定，增加角色扮演与战斗决策的关联性。
