# 《低阶净化仪式》

## 基础信息

- **书籍 ID**：`book_牧师神术_0017`
- **关联技能**：`priest_lesser_purification`（待新增）
- **使用效果**：阅读后解锁 `priest_lesser_purification`；若已学会，提升 `current_mastery +70` 并移除一名友方身上的一个低级减益状态。
- **阅读要求**：角色职业标签含 `priest` 或 `support`；基础 `意志 ≥ 7`。
- **稀有度**：普通（Common）
- **建议投放**：被污染教堂、净化任务、低级疫病支线。

## 书籍内容

书的纸张边缘有被阳光暴晒过的痕迹，说明它经常被带到户外进行仪式。仪式分为四步：点燃熏香、洒落净水、念诵祷词、用手掌抚过受术者额头。作者对每个步骤都做了严格的时间规定，比如熏香必须燃烧到刚好能画出一个完整的圆，不能多也不能少。书中解释，净化不是把污秽赶走，而是让受术者重新记起自己原本的状态，就像把一面蒙尘的镜子擦干净。最让学徒困惑的是第三步，祷词的内容竟是向污秽道歉：对不起，你本不该出现在这里。作者批注道，敌意会让污秽更顽固，唯有承认它的存在，才能请它离开。最后一页贴着一小撮被净化的灰烬，旁边的字已经褪色：这是仪式成功后留下的，它曾经是一个人身上的诅咒。许多老牧师会警告学生：仪式结束后要把灰烬埋进土里，否则它会记得回家的路。

## 设计意图

为牧师系提供基础状态净化技能，把解控流程仪式化，强调牧师处理减益状态时的从容与秩序感。
