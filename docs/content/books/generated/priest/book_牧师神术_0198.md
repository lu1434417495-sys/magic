# 《哀悼香炉仪式书》

## 基础信息

- **书籍 ID**：`book_牧师神术_0198`
- **关联技能**：`priest_mourning_censer`（待新增）
- **使用效果**：阅读后解锁 `priest_mourning_censer`；若已学会，提升 `current_mastery +120` 并释放烟雾，降低范围内敌人的命中率。
- **阅读要求**：角色职业标签含 `priest` 或 `support`；基础 `意志 ≥ 12`。
- **稀有度**：精良（Uncommon）
- **建议投放**：哀悼堂、葬礼任务奖励、高级技能商人。

## 书籍内容

仪式书的封面用黑色的细绳缠绕，像是某种尚未完成的包扎。它记载的是一种以哀悼烟雾干扰敌人的辅助神术：施术者摇动一只虚幻的香炉，释放出的灰白色烟雾会笼罩一片区域，处于其中的敌人会感到沉重的悲伤，攻击精准度下降。书中说，烟雾的成分是无数未被哀悼的亡者的叹息，因此施术者在使用前必须先默念一个亡者的名字，否则烟雾会无差别影响友方。作者附有不同香料配方的替代方案，但强调最正宗的哀悼香炉不需要真正的香，只需要真实的悲伤。仪式书最后一页压着一小撮灰白色的灰烬，附注说这是从一场持续了三天的葬礼火堆中取出的，灰烬闻起来像雨后的泥土。灰烬中混着一小片烧焦的乐谱，附注说那是葬礼上唯一被唱完的挽歌，其余的歌词都被哭声淹没了。香炉烟雾最浓时，施术者会听见许多声音同时叹息，那是所有未被哀悼的亡者在短暂地被人想起。

## 设计意图

为牧师提供范围减益技能，通过"哀悼"主题与命名前提，将控场技能与游戏的生死叙事紧密结合。
