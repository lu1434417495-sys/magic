# 《苦行僧笔记》

## 基础信息

- **书籍 ID**：`book_牧师神术_0038`
- **关联技能**：`priest_ascetic_notes`（待新增）
- **使用效果**：阅读后解锁 `priest_ascetic_notes`；若已学会，提升 `current_mastery +90` 并在低物资状态下提升自身少量意志与抗性。
- **阅读要求**：角色职业标签含 `priest` 或 `support`；基础 `意志 ≥ 9`。
- **稀有度**：普通（Common）
- **建议投放**：荒野苦行、物资匮乏区域、中级生存支线。

## 书籍内容

笔记的字迹潦草，很多页被雨水泡过，但仍然能读出作者对简朴生活的痴迷。作者认为人拥有的越少，注意力越集中，因此苦行不是剥夺，而是清理。书中记录了如何在寒冷中入睡、如何在饥饿时保持祈祷、如何在长途跋涉中让脚步不因为疲惫而变形。最常被引用的一句话是：匮乏不是敌人，对匮乏的恐惧才是。笔记中间有一章专门讲灰烬交界中的苦行，那里的空气本身就像一种考验，作者建议每次呼吸只吸一半，把另一半留给内心的祷词。最后一页画着一个简单的碗，里面只有几粒米，旁边写着：我吃过最饱的一顿，是只有这一碗的时候，因为我知道自己不需要更多。这本书在长途朝圣者与边境巡礼者之间流传最广，因为他们常常要在没有补给的情况下穿越危险地带。它让他们在最匮乏的时刻，仍然能听见内心的祷词。

## 设计意图

为牧师系提供基于物资匮乏状态的增益技能，鼓励玩家在资源受限时发挥牧师潜力，契合生存与探索玩法。
