# 《灰烬挽歌断章》

## 基础信息

- **书籍 ID**：`book_牧师神术_0160`
- **关联技能**：`priest_elegy_of_ashes`（待新增）
- **使用效果**：阅读后解锁 `priest_elegy_of_ashes`；若已学会，提升 `current_mastery +140` 并在灰烬交界场景下复活濒死友方。
- **阅读要求**：角色职业标签含 `priest` 或 `support`；基础 `意志 ≥ 15`，已抵达灰烬交界。
- **稀有度**：稀有（Rare）
- **建议投放**：灰烬交界祭坛、灰烬巡礼终极任务奖励、灰烬高阶商人。

## 书籍内容

断章的每一页都轻得像烧过的纸灰，翻动时必须屏住呼吸。它记载的是灰烬交界特有的挽歌神术：当同伴在灰烬覆盖的战场上倒下时，牧师跪地吟唱一段没有歌词的旋律，把逝者的余温从灰烬中重新聚拢。书中警告，这并非真正的复活，而是让倒下者多战斗几个回合；挽歌结束后，他们依然会化为灰烬。作者详细描述了声音的走向：先低后高，像风穿过废墟，最后在一个不确定的音上停止。断章中央有一枚手掌印，按上去会留下淡淡的炭痕，附注说这是最后一位成功施展挽歌的牧师留下的，她后来也随着挽歌的对象一起消散了。断章末尾还有一段被烧去半边的建议："不要在同一个地方唱两次挽歌，灰烬会记住你的声音，并在下一次提前来取走它。"手掌印的温度会随着季节变化，冬日滚烫，夏日冰凉，附注说那是逝者对生者最后的提醒。

## 设计意图

为牧师提供灰烬交界特色的濒死救援技能，通过有限制的复活机制增强区域战斗的策略性与悲壮感。
