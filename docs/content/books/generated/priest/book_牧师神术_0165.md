# 《忏悔光环铭文》

- **书籍 ID**：`book_牧师神术_0165`

- **使用效果**：阅读后解锁 `priest_halo_of_penitence`；若已学会，提升 `current_mastery +120` 并对周围敌人造成持续神圣伤害。

## 书籍内容

铭文刻在一张薄铜片上，字迹因反复拓印而变得模糊，但每一道笔画都比普通文字更深，像是被烫进去的。它教授的是一种以自身罪孽为燃料的光环神术：施术者先默念自己犯过的错，把愧疚聚合成头顶的一圈暗金色光环，光环会向周围散发灼热，越是心怀恶意的敌人受到的伤害越深。书中警告，如果施术者自认为无罪，光环会立刻熄灭；反过来，过度沉溺于忏悔的人会被自己的光环烧伤。铭文边缘有一圈细小的裂痕，附注说这是某位圣徒长期佩戴后自然形成的，裂痕的形状像是一张正在说话的嘴。铜片背面还刻着一行更小的反文："忏悔若只为自己取暖，便与罪孽无异。"光环在雨天会变得暗淡，但在血月下会异常明亮，附注说那是因为月亮也在看着人间的罪。曾有审判官试图用此光环照明夜路，结果只照亮了自己内心最不愿承认的角落。

## 设计意图

为牧师提供近战范围持续伤害技能，通过"罪孽-忏悔"机制将防御型职业的神圣主题转化为攻击资源。
