# 《守护者誓约卷》

## 基础信息

- **书籍 ID**：`book_牧师神术_0186`
- **关联技能**：`priest_vow_of_the_keeper`（待新增）
- **使用效果**：阅读后解锁 `priest_vow_of_the_keeper`；若已学会，提升 `current_mastery +120` 并指定一名友方，在其受伤时为守护对象承受部分伤害。
- **阅读要求**：角色职业标签含 `priest` 或 `support`；基础 `意志 ≥ 12`。
- **稀有度**：精良（Uncommon）
- **建议投放**：守护者修道院、护卫任务奖励、高级技能商人。

## 书籍内容

誓约卷是用某种坚韧的动物皮制成的，上面布满了层层叠叠的签名，有些已经褪色到无法辨认。它记载的是一种长期守护誓约：施术者选定一名同伴，发誓在其面临危险时分担伤害，誓约持续数场战斗。书中强调，守护者不能同时守护多人，因为一份完整的注意力只能投向一个方向。作者还记录了如何正确结束誓约：当被守护者安全抵达目标地点或主动解除时，施术者需要把卷轴的一小段烧掉，否则会遭受反噬。誓约卷最后一页有一枚新鲜的空白签名栏，附注说每一位使用者都会在这里签下自己的真名，而真名一旦被写入，在誓约结束之前会从其他所有文书中暂时消失。签名栏的边缘有几处烧焦的痕迹，那是前任守护者未能等到解约便战死后，真名自动燃烧留下的印记。新的誓约建立时，烧焦处会发出极轻的噼啪声，像是在提醒现任守护者不要忘记前人的重量。

## 设计意图

为牧师提供持续伤害分担技能，通过"单一守护对象"与"真名绑定"强化牧师的忠诚守护者与牺牲精神主题。
