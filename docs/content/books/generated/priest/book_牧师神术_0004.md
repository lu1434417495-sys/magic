# 《伤口清洗术》

## 基础信息

- **书籍 ID**：`book_牧师神术_0004`
- **关联技能**：`priest_wound_cleansing`（待新增）

## 书籍内容

册子散发着淡淡的皂角气味，因为每一页都曾被前主人用稀释过的圣水擦拭过。书中不讲高深的治愈神术，只讲如何在施术前把伤口处理干净。作者花了整整十页讨论水源的选择：山泉水太冷，会让伤口收缩；河水太杂，可能带来新的污秽；最理想的是晨露与井水各半，加上一小撮盐。清洗时必须用布从伤口中心向外擦，不能来回，因为那样会把脏物推回深处。书中还警告说，有些伤口看起来已经结痂，其实内部仍在溃烂，施术者要学会用指尖感受温度来判断。最末页贴着一张老旧的清单，列着哪些草药可以用于清洗后的敷料，旁边有人补了一句：清洗干净不是为了好看，是为了让光能够真正照进去。这本书在战地医院中被奉为 silently 重要的手册，因为太多牧师的失败不是来自神力不足，而是来自第一步的疏忽。

## 设计意图

提供牧师系基础净化与状态移除技能，把治疗流程拆分为清洁与治疗两个层次，增加策略深度。
