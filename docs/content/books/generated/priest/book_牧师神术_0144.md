# 《圣礼油秘录》

## 书籍内容

秘录记录了一种可以在战斗中快速涂抹的圣油配方，原料包括橄榄渣、没药碎屑和一小滴阅读者的唾液。作者认为，圣油之所以有效，是因为它与人体接触后会记住涂抹者的意图。书中详细说明了涂抹顺序：先额头，再手腕，最后心脏——顺序不能颠倒，因为身体有它自己的记忆方向。附页警告，不要用这油润滑武器，"油会分不清敌我"。最后一页有一行被涂改多次的字："最好的油是用眼泪调和的，但我从没成功过。"秘录封底夹着一小片橄榄叶，叶片已经干枯发黑，叶脉却依然清晰，附注说这是从第一棵被祝圣的橄榄树上摘下的叶子；用它煎出的油曾经让一个死去三天的人睁开了眼睛。橄榄叶的背面有一排细小的牙印，像是某个饥饿的人曾经咬过它。圣油作坊的师父们会把干枯的橄榄叶贴在坛口，作为祝圣的标记。

## 设计意图

提供增益/抗性型牧师技能，把"涂抹圣油"仪式转化为战斗准备。
