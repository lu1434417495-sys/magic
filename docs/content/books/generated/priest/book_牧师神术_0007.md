# 《信徒的第一步》

## 基础信息

- **书籍 ID**：`book_牧师神术_0007`
- **关联技能**：`priest_first_step_of_faith`（待新增）
- **使用效果**：阅读后解锁 `priest_first_step_of_faith`；若已学会，提升 `current_mastery +60` 并在下次战斗中使首次移动额外增加一格。
- **阅读要求**：角色职业标签含 `priest` 或 `support`；基础 `意志 ≥ 6`。
- **稀有度**：普通（Common）
- **建议投放**：教会入门试炼、牧师新手任务、朝圣者之路。

## 书籍内容

这是一本给刚决定成为牧师的人看的册子，第一句话就是：信仰不是答案，是你愿意继续走下去的那条路。书中没有复杂的祷文，只有一连串关于如何迈出第一步的练习：在泥泞中保持平衡，在斜坡上不回头，在人群中不迷失方向。作者认为，牧师在战场上的第一步最重要，因为它决定了后续救援能否及时到达。每一页底部都有一行填空，要求读者写下自己最近一次为了帮助他人而走出的第一步，无论大小。书的后半部分被某位前辈涂改过，原本的句子是你必须相信神会托住你，被改成了你必须先学会自己站稳，否则神也帮不了你。最后一页贴着一片朝圣之路的泥土，已经干硬成块。在漫长的传承中，这本书的每一页都被无数手掌磨薄，但第一句话始终清晰，因为每个读者都会把它默念一遍。
