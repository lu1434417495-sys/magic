# 《惩戒印记》

## 基础信息

- **书籍 ID**：`book_牧师神术_0022`
- **关联技能**：`priest_mark_of_rebuke`（待新增）
- **使用效果**：阅读后解锁 `priest_mark_of_rebuke`；若已学会，提升 `current_mastery +80` 并标记一名敌人，使其下次攻击时受到反伤。
- **阅读要求**：角色职业标签含 `priest` 或 `support`；基础 `意志 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：审判庭训练、低级惩恶支线、教会执法任务。

## 书籍内容

这本书的封面印着一只睁开的眼睛，眼睛里有一团小小的火焰。书中教的是一种低阶审判术：在敌人身上留下一个只有施术者能看见的印记，当对方再次行凶时，印记会引动神圣之力进行反击。作者强调，这个术不是用来惩罚过去，而是用来阻止下一次伤害，所以施术者必须亲眼看见或明确知道对方即将攻击时才能使用。书中用大量篇幅讨论 Intent：如果只是为了报复，印记会黯淡无光；如果是为了保护，它会像烧红的铁一样发亮。最被折角的一页记录了一个案例：一名牧师在强盗即将挥刀时留下印记，强盗的刀最终砍向了自己。页边批注道：印记没有杀死他，是他自己的恶意反弹了回来。审判官们常常把这本书与《自审明镜》一起发放，因为他们知道，能使用惩戒印记的人，首先要能审判自己。

## 设计意图

为牧师系提供早期反击/控制技能，让神职者在保护队友的同时也具备威慑敌人的手段，丰富战术选择。
