# 《祈祷念珠使用法》

## 基础信息

- **书籍 ID**：`book_牧师神术_0018`
- **关联技能**：`priest_prayer_beads`（待新增）
- **使用效果**：阅读后解锁 `priest_prayer_beads`；若已学会，提升 `current_mastery +70` 并在连续施法时降低少量MP消耗。
- **阅读要求**：角色职业标签含 `priest` 或 `support`；基础 `意志 ≥ 7`。
- **稀有度**：普通（Common）
- **建议投放**：修道院工坊、念珠制作任务、低级祈祷训练。

## 书籍内容

这本册子的一半内容是念珠的编法，另一半则是如何使用念珠来辅助祈祷。作者详细比较了不同材质珠子的手感：木珠适合初学者，因为它会吸收手汗，越用越温润；骨珠适合战地牧师，因为它在寒冷中不会冻手；石珠则适合静修，因为它沉重，能让手指慢下来。使用法的核心是数珠，但不是机械地数，而是每拨动一颗珠子就完成一次完整的呼吸，这样三十三颗珠子就是三十三次完整的祈祷。书中还警告，念珠断掉不是坏事，它意味着某一段祈祷已经完成，不需要勉强续上。最后一页画着一串只剩十七颗珠子的念珠，附注说它的主人在一场战斗中把它扔向敌人，珠子散落一地，每一颗落地时都发出了一声轻微的祝福。在后来的传说中，那十七颗珠子被不同的人捡到，每一颗都成了一件小型护身符。

## 设计意图

为牧师系提供基础资源管理类被动技能，通过念珠把施法节奏与MP效率联系起来，增强战斗中的连招规划感。
