# 《光辉路径手札》

## 基础信息

- **书籍 ID**：`book_牧师神术_0189`
- **关联技能**：`priest_radiant_pathway`（待新增）
- **使用效果**：阅读后解锁 `priest_radiant_pathway`；若已学会，提升 `current_mastery +110` 并创建一条光辉路径，友方在其上移动时不触发借机攻击。
- **阅读要求**：角色职业标签含 `priest` 或 `support`；基础 `意志 ≥ 11`。
- **稀有度**：普通（Common）
- **建议投放**：大教堂走廊、突围任务奖励、普通技能商人。

## 书籍内容

手札的每一页都画着不同形状的发光道路，有的是直线，有的是折线，有的是螺旋，共同点是从不交叉。它记载的是一种战术移动辅助神术：施术者在地面上铺设一条短暂存在的光辉路径，走在上面的友方不会被敌人的借机攻击命中。书中说，路径必须一次性画完，中断会让光辉熄灭；同时，路径只能容纳有限的人数通过，超载会让光变得暗淡。作者还提醒，敌人在路径上不会受到伤害，只是会被光暂时致盲，无法准确判断时机。手札最后一页画着一条从战场中央通向远方的金色细线，线旁写着："光不负责打赢战争，只负责让你回家。"细线的尽头画着一扇半开的门，门后没有房间，只有一片更亮的光，附注说那是路径设计者自己也未曾到达过的地方。有传说称，曾有人在光辉路径上走着走着就消失了，只在原地留下一双还冒着热气的靴子。

## 设计意图

为牧师提供战术撤退与机动辅助技能，通过"安全路径"机制丰富战棋中的走位选择，强化牧师的战场指挥角色。
