# 《缄默誓约石板》

## 基础信息

- **书籍 ID**：`book_牧师神术_0157`
- **关联技能**：`priest_vow_of_stillness`（待新增）

## 书籍内容

石板沉重且冰凉，上面只刻着三行字和一道从中央裂开的缝隙。第一行是誓约词，第二行是违约后果，第三行被苔藓覆盖，据说只有真正沉默过三十天的人才能看清。它要求施术者在战斗中主动封住自己的言语，把本该说出口的话压缩成神术的燃料；沉默越久，下一次释放的神术就越强烈。石板边缘有一圈细小的牙印，附注说这是某位修行者在最后关头咬住石板以阻止自己尖叫留下的。作者警告，缄默誓约不是沉默寡言，而是把所有想说的话都转化成一种等待；一旦习惯了等待，许多人会忘记自己原本想说什么。石板底部还有一道用指甲刻出的补充："如果你开始享受沉默，请立刻打破它，因为那已经不是修炼，而是逃避。"夜深人静时，石板中央的裂缝会传出极轻的呜咽，像是有人的话语被卡在里面太久了。

## 设计意图

为牧师设计蓄力型机制技能，通过"沉默换爆发"的代价感，增强高阶牧师的战略深度与角色张力。
