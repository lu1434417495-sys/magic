# 《虚空行走的脚印管理》

## 基础信息

- **书籍 ID**：`book_法师咒术_0121`
- **关联技能**：`mage_void_walk`
- **使用效果**：阅读后解锁 `mage_void_walk`；若已学会，提升 `current_mastery +170` 并在下一次战斗中使虚空行走的首次移动不触发借机攻击。
- **阅读要求**：角色职业标签含 `mage` 或 `warlock`；基础 `智力 ≥ 17` 且 `意志 ≥ 14`。
- **稀有度**：史诗（Epic）
- **建议投放**：虚空观测站、禁忌裂隙、星界旅者任务奖励。

## 书籍内容

虚空行走不是隐身，而是让双脚短暂踏入一个与现实重叠的薄弱层。本书从脚印管理开始，因为虚空层会记住每一次踩踏，留下可被追踪的黑色灼痕。作者要求练习者在沙地上行走，观察脚印的深浅与消散速度：太深说明进入虚空过多，容易被虚空生物注意；太浅则步伐不稳，可能在中途被弹回现实。第二章讲解如何控制停留时间，超过两秒的行走会让施法者听见低语。书中警告，绝对不要在情绪激动时进行虚空行走，因为意识会吸引那些以情绪为食的存在。作者还建议在鞋底刻画微型稳定符文，以减少脚印残留。最末一页画着一串逐渐变淡的脚印，批注写道：走得越远，回来时要记得的越多。长时间在虚空中行走会让现实感变得稀薄，因此每次训练后都要用冷水洗脸，帮助意识重新锚定身体。

## 设计意图

为暗影与虚空法师提供高机动与风险并存的位移手段，增强战棋中的走位张力。
