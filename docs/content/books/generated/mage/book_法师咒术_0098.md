# 《永恒光明的副作用》

## 基础信息

- **书籍 ID**：`book_法师咒术_0098`
- **关联技能**：`mage_continual_light`
- **使用效果**：阅读后解锁 `mage_continual_light`；若已学会，提升 `current_mastery +90` 并延长光明持续 2 回合。
- **阅读要求**：角色职业标签含 `mage` 或 `cleric`；基础 `智力 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：普通法术商店、冒险者营地、地下城入口宝箱。

## 书籍内容

永恒光明是法师最先学会的实用法术之一，也是最容易被滥用的。前半本讲解法术结构：一个被压缩的光点会持续释放柔和的光芒，直到魔力耗尽或被驱散。作者强调，这个法术的难点不是让它亮，而是让它'不刺眼'——太亮的光在黑暗环境中会让使用者的瞳孔来不及适应。

中段收录了副作用清单：长期被永恒光明照耀的物体会轻微褪色，某些夜行生物会被吸引，施术者本人也可能在睡前难以入睡。后半部讨论战术：永恒光明最适合标记位置、吓退惧光生物，或者在黑暗中为队友提供稳定光源，但最好不要直接照向敌人眼睛，那只会让他们更快找到你。

普通法术商店的老板会把这本书放在柜台最显眼的位置，因为每个冒险者都会在进入地下城前想起买一本。永恒光明的书店从不需要点灯。无需点灯处是新手最爱。
## 设计意图

普通级功能法术书籍，解锁永恒光明并提供基础照明与位置标记，强调副作用管理与实用性。
