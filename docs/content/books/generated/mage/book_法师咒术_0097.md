# 《相位光束的穿透时刻》

## 基础信息

- **书籍 ID**：`book_法师咒术_0097`
- **关联技能**：`mage_phase_beam`
- **使用效果**：阅读后解锁 `mage_phase_beam`；若已学会，提升 `current_mastery +120` 并在下一次战斗中使相位光束首次命中后无视护盾。
- **阅读要求**：角色职业标签含 `mage` 或 `astromancer`；基础 `智力 ≥ 12` 且 `感知 ≥ 10`。
- **稀有度**：精良（Uncommon）
- **建议投放**：相位实验室、星界碎片遗迹、高阶法师私人藏书。

## 书籍内容

相位光束的穿透不是因为它硬，而是因为它在击中目标的那一刻'不在'这里。前半本讲解相位原理：施术者要让光束在物质世界与相位世界之间快速振荡，从而在物理障碍中找到一个'不存在'的缝隙。作者用钟摆比喻这种振荡：太快会散失能量，太慢会被物质捕捉。

书中警告，相位光束对施术者的视觉有要求，必须在微光环境下才能准确瞄准。中段收录了'穿透时刻'：真正有效的相位光束会在目标身上留下一道短暂的透明残影，那是光束穿过时留下的相位伤痕。后半部讨论限制：相位光束对纯粹的魔法护盾效果最好，对厚实的物理护甲反而一般。

相位实验室的观察窗采用多层相位玻璃，可以让研究员看到光束在物质世界与相位世界之间穿梭的瞬间。相位光束的玻璃窗需要定期更换相位。相位玻璃窗是最贵耗材。
## 设计意图

精良级相位穿透书籍，解锁相位光束并提供破盾能力，强调相位振荡与视觉条件。
