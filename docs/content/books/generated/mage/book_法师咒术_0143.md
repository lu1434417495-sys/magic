# 《末日绘本的最后一页》

## 基础信息

- **书籍 ID**：`book_法师咒术_0143`
- **关联技能**：`mage_doom_sketch`
- **使用效果**：阅读后解锁 `mage_doom_sketch`；若已学会，提升 `current_mastery +180` 并在下一次战斗中使末日绘本首次完成时额外施加一个随机减益。
- **阅读要求**：角色职业标签含 `mage` 或 `warlock`；基础 `智力 ≥ 18` 且 `感知 ≥ 14`。
- **稀有度**：传说（Legendary）
- **建议投放**：末日神殿禁书区、预言家密室、终局裂隙奖励。

## 书籍内容

末日绘本不是被阅读的书，而是被绘制的诅咒。本书每一页都留白，要求施法者用魔力在纸上勾勒出目标的轮廓，并在空白处写下三种可能的结局。作者指出，绘本的力量来自完成度：勾勒越细致，预言越难抗拒。书中收录了十二种笔触对应的命运类型，从折断武器到失去声音，每一种都需要特定的情绪作为墨水。作者警告，最后一页绝不能提前翻看，因为看到结局的人会立刻成为绘本的一部分。第二章讨论如何在战斗中快速完成简笔素描：不需要完美，只需要抓住目标的本质特征。最末一页是一张空白的纸，边缘焦黑，批注写道：当你画完最后一笔，纸上的东西就会抬头看你。作者建议把末日绘本存放在铅盒中，并定期更换盒内的干燥草药，因为潮湿的纸页会让未完成的作品提前苏醒。一旦绘本开始自己翻动，就再也没有回头路了。

## 设计意图

为暗法师与术士提供蓄力型减益叠加机制，强化末日预言与诅咒艺术的叙事表现。
