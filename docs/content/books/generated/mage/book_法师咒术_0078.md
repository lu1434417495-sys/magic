# 《熔岩爆裂的温度控制》

## 基础信息

- **书籍 ID**：`book_法师咒术_0078`
- **关联技能**：`mage_molten_burst`
- **使用效果**：阅读后解锁 `mage_molten_burst`；若已学会，提升 `current_mastery +140` 并在下一次战斗中使首次熔岩爆裂溅射范围增加一格。
- **阅读要求**：已学会 `mage_fireball` 或 `mage_burning_hands`；角色职业标签含 `mage`；基础 `智力 ≥ 12`。
- **稀有度**：史诗（Epic）
- **建议投放**：火山熔炉图书馆、龙息峡谷宝箱、炎魔学者密室。

## 书籍内容

熔岩爆裂的危险在于它不只有温度，还有重量。前半本讲解温度分层：外层是炽热的熔渣，内层是半液态的岩核，最中心则是一个被压缩的气泡。作者要求施术者先学会用普通石块练习'内部加压'，直到能在石头落地前让它从内部裂开。

书中警告，熔岩爆裂对施术者最隐蔽的伤害是吸入高温尘埃，因此实战时必须背风站立。中段是一份地形影响表：草地会让熔岩蔓延，石地会让它弹跳，水面则会产生大量蒸汽遮挡视线。后半部讨论'余烬管理'：好的熔岩爆裂应该留下持续燃烧的区域，而不是一次性把所有能量挥霍掉。

火山熔炉图书馆的书架是用冷却的熔岩砖砌成的，学徒们相信这些砖块会在附近有熔岩爆裂时微微发热。熔岩爆裂的实验室常备一桶火山灰。火山灰桶降低火灾率。灰烬是新火的肥料。
## 设计意图

史诗级火焰地形大招书籍，前置要求火系技能，解锁熔岩系范围伤害与持续燃烧区域，强调温度管理与环境互动。
