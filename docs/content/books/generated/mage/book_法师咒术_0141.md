# 《虚空凝视的眨眼练习》

## 基础信息

- **书籍 ID**：`book_法师咒术_0141`
- **关联技能**：`mage_void_gaze`
- **使用效果**：阅读后解锁 `mage_void_gaze`；若已学会，提升 `current_mastery +170` 并在下一次战斗中使虚空凝视首次命中时附加 1 回合的恐惧标记。
- **阅读要求**：角色职业标签含 `mage` 或 `warlock`；基础 `智力 ≥ 17` 且 `意志 ≥ 15`。
- **稀有度**：史诗（Epic）
- **建议投放**：虚空裂隙观测站、禁忌眼神训练室、深渊学者密室。

## 书籍内容

虚空凝视不是用眼睛看，而是用意识打开一道通向虚无的缝隙。本书从眨眼练习开始，因为施法者必须学会在极短时间内让意识进出虚空，避免被虚空反向注视。作者要求练习者对着镜子反复眨眼，每次闭眼时想象自己正把视线投向一个漆黑的深渊，睁眼时则立刻切断联系。书中警告，眨眼间隔过长会让深渊中的存在也看过来，而那是一种无法用语言描述的对视。第二章讲解如何在战斗中利用凝视打断敌人的施法专注：当对方开始吟唱时，一次精准的虚空凝视能让其咒语在喉咙里结冰。作者还提醒，使用后眼睛会暂时失去颜色，需要数小时才能恢复。最末一页是一双没有瞳孔的眼睛，批注写道：凝视虚空的人，也在被虚空计数。

长期使用虚空凝视的法师，眼角会浮现细小的黑色裂纹，同行称之为凝视者的年轮。

## 设计意图

为虚空法师提供精神干扰手段，强调高风险凝视与敌人施法压制，强化暗系控制风格。
