# 《风切：气流断刃》

## 基础信息

- **书籍 ID**：`book_法师咒术_0228`
- **关联技能**：`mage_gale_cutter`
- **使用效果**：阅读后解锁 `mage_gale_cutter`；若已学会，提升 `current_mastery +140` 并在下一次战斗中使首道风切可打断敌方正在咏唱的法术。
- **阅读要求**：角色职业标签含 `mage` 或 `elementalist`；基础 `智力 ≥ 12` 且 `敏捷 ≥ 11`。
- **稀有度**：稀有（Rare）
- **建议投放**：风元素祭坛、云中之城废墟、游侠法师营地。

## 书籍内容

风切是将高速气流压缩成无形利刃后释放的法术，能切断细绳、羽毛，甚至敌人的咒语。书中第一节要求练习者先站在风中张开手掌，感受气流从指缝穿过时的阻力。作者认为，风切的精髓在于时机的把握，必须在敌人吸气准备咏唱的瞬间出手。后半部讲解了如何让风切形成连续的气刃墙，以及如何利用上升气流让风切绕过障碍物。最末页是一段被风蚀得模糊的文字，勉强能辨认：切断空气，比切断喉咙更难。许多风法师会把练习风切当作日常冥想，因为连续失败的呼啸声听起来像远方的笑声。书中还提到，在密闭室内风切威力会减弱，而在峡谷或高塔上则能借助自然风延伸射程。风法师在练习时常把树叶当作靶子，久而久之能在空中切出复杂图案。这些图案被风法师们视为签名，每个人切出的弧度都不相同。

## 设计意图

提供快速打断与直线输出，让法师能有效反制敌方施法者，增强战斗中的反应维度。
