# 《石肤术：从脆弱到承重》

## 基础信息

- **书籍 ID**：`book_法师咒术_0055`
- **关联技能**：`mage_rock_armor`
- **使用效果**：阅读后解锁 `mage_rock_armor`；若已学会，提升 `current_mastery +100` 并增加该技能首次生效时的物理减伤 `+3%`。
- **阅读要求**：无职业限制；基础 `体质 ≥ 9` 或 `智力 ≥ 10`。
- **稀有度**：精良（Uncommon）
- **建议投放**：山岳聚落石匠工坊、战士与法师混血训练场、矿洞深处藏书。

## 书籍内容

石肤术不是让皮肤变硬，而是让皮肤学会'承认压力'。作者要求练习者先用手指按住一块鹅卵石，想象自己的皮肤正在向石头学习如何分散力道。前半本讲解三层岩石结构：外层承受冲击，中层吸收震动，内层把剩余力量导向地面。

书中警告说，很多法师把石肤术当成无敌技能，结果在受到重击时因不会'卸力'而骨折。中段收录了一套奇怪的体操：练习者要在石肤状态下被同伴用木棒轻敲全身，学习哪里该硬、哪里该软。最后一章讨论'石肤与移动'——真正的石肤术不会让人变成雕像，而是让每一步都像山一样沉稳。

山岳聚落的石匠们说，掌握石肤术的法师在劳作时会不自觉地用肩膀承重，像一座小山那样沉默而可靠。石肤术的初学者会在手臂上画满小石子图案，作为心理暗示。石子图案是最早的护甲图。
## 设计意图

为法师系提供基础物理防御选项，强调'承认与分散'而非'硬抗'，让非法师职业也能通过属性门槛获取有限防御能力。
