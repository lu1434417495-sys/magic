# 《雷霆织锦的经纬》

## 基础信息

- **书籍 ID**：`book_法师咒术_0195`
- **关联技能**：`mage_thunder_weave`
- **使用效果**：阅读后解锁 `mage_thunder_weave`；若已学会，提升 `current_mastery +190` 并在下一次战斗中使雷霆织锦完成时召唤一片持续 2 回合的雷云覆盖战场。
- **阅读要求**：角色职业标签含 `mage` 或 `stormweaver`；基础 `智力 ≥ 19` 且 `感知 ≥ 15`。
- **稀有度**：传说（Legendary）
- **建议投放**：风暴织坊、天空之城、雷神祭坛。

## 书籍内容

雷霆织锦是一种将闪电编织成覆盖战场的雷云图案的艺术。本书从经纬概念开始，讲解如何用垂直的引雷丝和水平的蓄电丝构成基本网格，再通过对节点充能激活整个织锦。作者强调，织锦的稳定性取决于经纬之间的张力平衡，任何一根丝线过紧或过松都会导致雷云提前消散。书中记录了不同图案对应的天气效果：网格型均匀落雷，螺旋型集中打击，而放射型则能随机触发电磁脉冲。最末一章讨论如何在织锦激活期间保护自己，作者建议穿着绝缘内衬并远离金属武器。批注写道：你织的不是云，是一片愤怒的天空。练习者需要在安全环境中先编织手掌大小的雷云，再逐步扩大规模。这门技艺在战棋中能够持续压制敌方行动。

雷霆织锦持续期间，所有金属装备都会发出轻微嗡鸣，提醒友军保持距离。

## 设计意图

为雷系法师提供持续性战场天气技能，将纺织艺术与风暴魔法结合。
