# 《冰花绽放的逆向工程》

## 基础信息

- **书籍 ID**：`book_法师咒术_0187`
- **关联技能**：`mage_frost_bloom`
- **使用效果**：阅读后解锁 `mage_frost_bloom`；若已学会，提升 `current_mastery +180` 并在下一次战斗中使冰花绽放逆向吸收时恢复施法者相当于伤害量 30% 的生命。
- **阅读要求**：角色职业标签含 `mage` 或 `cryomancer`；基础 `智力 ≥ 18` 且 `感知 ≥ 15`。
- **稀有度**：传说（Legendary）
- **建议投放**：永冻实验室、冰花谷、古代气象站。

## 书籍内容

冰花绽放通常是向外释放寒冷的过程，但逆向工程可以让它从周围热量中汲取生命力。本书从冻结循环开始，讲解如何让冰晶在绽放的同时吸收环境热量，并将这种能量转化为治愈施法者的生命力。作者强调，逆向过程必须严格控制速率，过快会导致周围生物瞬间冻僵，过慢则无法产生治疗效果。书中记录了在不同温度环境下的效率差异：温暖地区吸收更快，但冰花也更难维持；极寒地区冰花稳定，却缺少可吸收的热量。最末一章讨论道德边界，批注写道：从敌人身上取走热量，和从朋友身上取走一样需要谨慎。练习者需要先对无生命物体练习逆向吸收，确认不会失控后再用于战斗。这门技艺让冰系法师兼具输出与生存。

逆向吸收冰花时施法者体温会略微下降，过度使用可能导致手指发紫。

## 设计意图

为冰系法师提供伤害转化治疗机制，强化冰魔法的能量循环主题。
