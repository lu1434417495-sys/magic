# 《星辰陨落门的坐标学》

## 基础信息

- **书籍 ID**：`book_法师咒术_0076`
- **关联技能**：`mage_starfall_gate`
- **使用效果**：阅读后解锁 `mage_starfall_gate`；若已学会，提升 `current_mastery +160` 并减少该技能 `mp` 消耗 5%。
- **阅读要求**：角色职业标签含 `mage` 或 `astromancer`；基础 `智力 ≥ 16` 且 `感知 ≥ 12`。
- **稀有度**：传说（Legendary）
- **建议投放**：观星台顶层、星界裂隙中心、古代天文台遗迹。

## 书籍内容

星辰陨落门不是打开一扇门，而是让天空某个位置的星光'漏'到地面上来。前半本几乎全是坐标公式与星图，作者用三十页证明：要召唤陨落，必须同时计算目标地点、当前季节与三颗以上亮星的相对位置。书中警告，坐标误差超过半度，陨落物就可能落在施术者自己的阵营里。

中段记录了一次成功的召唤：某位法师在沙漠中心画下坐标阵，让一颗流星精准地砸穿了敌军的攻城塔。后半部转向哲学：星光本是无数年前的残像，召唤陨落等于让过去与未来在同一瞬间相撞。最后一页只有一行坐标，没有注释，旁边画着一个问号。

观星台的地板下埋着一块来自过去召唤的陨铁，任何站在上面施展星辰陨落门的法师都会觉得坐标格外清晰。星辰陨落门的坐标纸必须用陨铁墨水书写。陨铁墨水配方严密保管。
## 设计意图

传说级天体系大招书籍，提供高门槛高爆发的终极技能，强调精密计算与资源投入，服务于后期法师构筑。
