# 《焰鞭残卷：余烬之舌》

## 基础信息

- **书籍 ID**：`book_法师咒术_0201`
- **关联技能**：`mage_flame_whip`
- **使用效果**：阅读后解锁 `mage_flame_whip`；若已学会，提升 `current_mastery +150` 并在下一次战斗中使首记焰鞭附带灼烧效果。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 12` 且 `感知 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：灰烬交界焦炭营地、火焰元素裂隙、黑市魔法师摊位。

## 书籍内容

焰鞭并非真正的火焰长鞭，而是将火元素压缩成束后甩出的灼热残影。书中第一页画着一只焦黑的手掌，注解称初学者常因握点过高而被自己的法术烫伤。作者把焰鞭分成三段练习：先凝火为线，再甩出弧线，最后在鞭梢加入爆裂符文。每一阶段都需要在熄灭的炭盆上反复比划，直到手腕能在不烧衣袖的情况下完成三圈缠绕。后半部记录了几种变招，例如让焰鞭在击中地面后反弹，或将鞭身拆成数段短刃散射。最末页是一张烧焦的羊皮纸，只写了一句：舌头能说谎，但焰舌只会说实话。许多法师在学会此术后，会先用焰鞭点燃自己的烟斗，作为对恐惧的告别仪式。老手们则喜欢在鞭梢系一枚冷铁环，让火焰在撞击时迸出更刺耳的呼啸。书中最后一页还贴着一张烧焦的绷带使用说明，显然是前任主人留下的贴心提醒。

## 设计意图

为中距离法师提供火焰物理混合输出，丰富近战反制手段，让施法者在被贴身后仍有体面反击能力。
