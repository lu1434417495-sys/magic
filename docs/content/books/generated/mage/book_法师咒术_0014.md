# 《闪光钩：短暂但精准的牵引》

## 基础信息

- **书籍 ID**：`book_法师咒术_0014`
- **关联技能**：`mage_glimmer_hook`
- **使用效果**：阅读后解锁 `mage_glimmer_hook`；若已学会，提升 `current_mastery +90`，并在下一次战斗中使闪光钩的射程增加 1 格。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：高塔奥术训练场、边境巡逻队仓库、竞技场奖品柜。

## 书籍内容

闪光钩是一束高度凝聚的光魔力细线，可以瞬间延伸并钩住远处的物体或敌人，然后把它向施术者方向拉近。这本书的封面用烫金印着一只张开的手，指尖延伸出几道弯曲的光线。作者认为，这个咒语的魅力在于它不是攻击，而是重新排列战场上的位置关系。

前半部分教授如何控制钩索的"咬合"力度，太轻会滑脱，太重则可能把敌人直接甩到自己身上。后半部分列举了各种创造性用法：把远处的药瓶拉到手里、把敌人从高台拉下、在坠落前钩住岩壁边缘。书中特别提醒，闪光钩对活物的牵引效果取决于目标的体重，试图用它拉动一头熊只会把自己拽过去。最后一页是一句潦草的批注：光不会伤害你，但突然改变位置会。

附录中展示了几种特殊手势，可以让闪光钩在命中后缠绕目标更久，甚至短暂限制对方的移动。

## 设计意图

为法师系提供早期位移操控技能，强化战棋中的位置战术与地形互动，同时为后续力场、引力类高级法术建立"远程牵引"的基础熟练度概念。
