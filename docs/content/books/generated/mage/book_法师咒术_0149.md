# 《异界文字的舌头发音》

- **书籍 ID**：`book_法师咒术_0149`

## 书籍内容

异界文字不是用眼睛读，而是用舌头说。本书从舌头发音开始，因为许多异界符号对应的振动频率超出了人类耳朵的接收范围，只能通过口腔与喉咙的共鸣来产生。作者要求练习者先用温水漱口，放松舌根，再尝试发出介于嘶嘶声与哼鸣声之间的音调。书中收录了三十七个基础音节，每个音节都附带着对口腔肌肉的精确指示。作者警告，某些音节连续发音会让施法者的舌头短暂失去知觉，因此书中推荐每次练习不超过十五分钟。第二章讨论如何将异界文字与普通咒语结合，让召唤或传送更加稳定。最末一页是一排无法辨认的符号，批注写着：文字是声音的尸体，而你在让它复活。异界文字的发音会随着使用者的情绪产生细微变化，愤怒时音节会变得尖锐，悲伤时则会下沉。作者认为，正是这种不确定性让异界咒语充满了生命力。

## 设计意图

为召唤与异界主题法师提供语言类增幅，丰富设定中的异界文字系统与施法细节。
