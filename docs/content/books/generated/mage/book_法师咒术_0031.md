# 《猩红符印：用血液激活的咒文》

## 基础信息

- **书籍 ID**：`book_法师咒术_0031`
- **关联技能**：`mage_scarlet_sigil`
- **使用效果**：阅读后解锁 `mage_scarlet_sigil`；若已学会，提升 `current_mastery +90`，并在下一次战斗中使猩红符印激活时额外吸取目标 5 点生命。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：血法师隐居处、禁忌书籍黑市、地下竞技场奖品。

## 书籍内容

猩红符印是一种用少量自身血液作为媒介绘制的攻击符文，它能让敌人在触发时受到爆发性的伤害。这本书的作者不避讳这种咒术的危险性，开篇就列出三条禁忌：不要用心血，不要在虚弱时使用，不要在符印未完成时中断。前半部分讲解如何用指尖的伤口挤出刚好够用的血量，并在地面或武器上快速画出符印。

后半部分讨论战术布置：把符印画在敌人可能经过的位置，或者伪装成普通的血迹。书中警告，猩红符印对使用者本人也有轻微的反噬，频繁使用会让伤口愈合变慢。最后附有一张被血浸透的笔记，记录了一位法师如何在绝境中用猩红符印反杀追兵，代价是昏迷了整整两天。

书中特别强调了血量控制的重要性，挤出的血液太多会让符印过于活跃而提前引爆，太少则无法完成回路的闭合。

## 设计意图

为法师系提供早期血祭主题输出技能，引入"代价与回报"的咒语哲学，丰富法师的爆发手段，同时为后续血魔法、生命转换类法术建立叙事与熟练度铺垫。
