# 《反制咒术的拆招表》

## 基础信息

- **书籍 ID**：`book_法师咒术_0155`
- **关联技能**：`mage_counter_spell`
- **使用效果**：阅读后解锁 `mage_counter_spell`；若已学会，提升 `current_mastery +170` 并在下一次战斗中使首次成功反制后返还 25% 消耗 MP。
- **阅读要求**：角色职业标签含 `mage` 或 `spellbreaker`；基础 `智力 ≥ 18` 且 `感知 ≥ 15`。
- **稀有度**：史诗（Epic）
- **建议投放**：法师决斗场、战术学院、黑市武斗馆。

## 书籍内容

反制咒术不是正面碰撞，而是在对方咒语完成前的瞬间切断其魔力供给。本书将常见法术按照咒文结构分类，列出对应的拆招节点。火球术需要在压缩阶段打断，传送术则要在坐标锁定前扰动，而召唤术最脆弱的瞬间是契约签名完成的刹那。作者强调，拆招者必须比对手更熟悉对手的咒语，因此书中收录了大量常见敌法的起手动作。第二章讨论风险：反制失败会让自身魔力回路短暂震荡。最末一页是一张折叠的拆招表，边缘写着：最好的反制是让敌人以为你还在准备防御。练习者需要与同伴反复对练，直到能在半秒内识别咒语类型。真正的高手甚至能借用对方反噬的魔力。

书中附带一套手势暗号，让队友在你准备反制时调整站位避免误伤。

优秀的拆招者往往沉默寡言，因为过多的言语会让自己内心的节奏暴露给对手。

## 设计意图

为控制与对抗型法师提供战术反制手段，强调预判与咒文结构知识。
