# 《风羽术：坠落前的最后一秒》

## 基础信息

- **书籍 ID**：`book_法师咒术_0012`
- **关联技能**：`mage_wind_feather`
- **使用效果**：阅读后解锁 `mage_wind_feather`；若已学会，提升 `current_mastery +80`，并在下一次战斗中使风羽术的触发高度阈值降低 1 格。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 6`。
- **稀有度**：普通（Common）
- **建议投放**：高塔窗边书架、悬崖边哨站、风元素游荡者营地。

## 书籍内容

这本书的每一页都像被风吹打过一样微微卷曲。风羽术是一个被动触发的保命咒语，当施术者从高处坠落时，会在身下生成一股向上的气流，把致命的下落变成轻柔的飘降。作者用调侃的语气写道：学会这个咒语之前，请先改掉站在悬崖边思考问题的习惯。

前半部分解释如何在日常行走中保持对风压的微弱感知，这样咒语才能在正确的时机自动启动。后半部分展示了几种进阶用法，比如主动从高处跳下绕过敌人的防线，或者借助风羽术调整落点完成侧翼包抄。书中提到，最糟糕的用法是从两米高的地方跳下来炫耀，因为那会消耗一次宝贵的触发机会。最后一页是一幅简笔画，画着一个法师张开双臂，从塔顶缓缓飘落。

书中还提到，风羽术在暴风天气里会变得难以预测，强风可能把飘降的法师吹离预定落点很远。

## 设计意图

为法师系提供早期环境生存能力，强化战棋中地形高差的战术价值，同时为后续飞行、漂浮与风系机动法术奠定叙事基础与熟练度连接。
