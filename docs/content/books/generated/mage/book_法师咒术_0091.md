# 《记忆尖刺的编码方式》

## 基础信息

- **书籍 ID**：`book_法师咒术_0091`
- **关联技能**：`mage_memory_spike`
- **使用效果**：阅读后解锁 `mage_memory_spike`；若已学会，提升 `current_mastery +130` 并在下一次战斗中使首次记忆尖刺命中后使目标下回合技能 `mp` 消耗 `+20%`。
- **阅读要求**：角色职业标签含 `mage` 或 `psion`；基础 `智力 ≥ 13` 且 `意志 ≥ 11`。
- **稀有度**：稀有（Rare）
- **建议投放**：记忆神殿、灵能学者密室、梦境边界藏书。

## 书籍内容

记忆尖刺不是读取记忆，而是把一段混乱的信息强行塞进目标的短期记忆里，让他短时间内无法处理新的咒语。前半本讲解编码方式：最有效的尖刺不是痛苦的画面，而是'未完成的旋律'或'数不尽的楼梯'，这些内容会占用大脑的处理资源。

作者要求施术者先在动物身上练习，观察它们是否会突然停止正在做的事。书中警告，记忆尖刺对意志坚强的敌人效果会反弹，施术者自己可能会短暂忘记刚才的战术安排。后半部讨论伦理：用记忆尖刺审讯被认为是非法的，因为它会在目标脑中留下无法消除的杂音。

记忆神殿的档案员会用记忆尖刺来封存最机密的文件，因为被尖刺接触过的人会在一个月内无法回忆起任何细节。记忆尖刺的档案室被称为"健忘者的图书馆"。图书馆书脊标签印得大。
## 设计意图

稀有级精神干扰书籍，解锁记忆尖刺并提供施法干扰能力，强调信息编码与精神对抗。
