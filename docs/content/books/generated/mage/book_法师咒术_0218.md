# 《暴雪心：极寒核心》

## 基础信息

- **书籍 ID**：`book_法师咒术_0218`
- **关联技能**：`mage_blizzard_heart`
- **使用效果**：阅读后解锁 `mage_blizzard_heart`；若已学会，提升 `current_mastery +170` 并在下一次战斗中使暴雪心持续期间自身冰系法术冷却减少一回合。
- **阅读要求**：角色职业标签含 `mage` 或 `cryomancer`；基础 `智力 ≥ 16` 且 `意志 ≥ 13`。
- **稀有度**：史诗（Epic）
- **建议投放**：永恒冰川圣殿、冬之女皇陵墓、世界尽头的冰封图书馆。

## 书籍内容

暴雪心是在施法者胸腔内凝聚的一颗极寒核心，能持续向四周散发霜冻气息。书中强调，这颗核心不是器官，而是情绪的外化：只有真正冷静的人才能驾驭它。作者详细记录了核心的培育过程，包括如何在体温与极寒之间找到平衡点。练习者需要在暴风雪中赤身静坐，直到雪花落在身上不再融化。后半部讲解如何利用暴雪心强化其他冰系法术，让霜环、冰镜等技能的威力和频率都大幅提升。最末页是一颗被冰封的心脏标本，标签写着：它还在跳，只是很慢。许多冰法师在战斗结束后需要很长时间才能重新感到温暖。书中还提醒，暴雪心与火焰法术同时存在会互相抵消，甚至引发魔力紊乱。暴雪心成熟后，施法者的呼吸会带有细小冰晶，在阳光下闪烁如钻。这种美丽却危险的征兆，常让队友既惊叹又不敢靠得太近。

## 设计意图

作为冰系核心增益技能，强化法师的持续作战与流派协同，让冰法在长线战斗中越战越强。
