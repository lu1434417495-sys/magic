# 《霜火双生：元素悖论笔记》

## 基础信息

- **书籍 ID**：`book_法师咒术_0102`
- **关联技能**：`mage_frostfire_fusion`
- **使用效果**：阅读后解锁 `mage_frostfire_fusion`；若已学会，提升 `current_mastery +170` 并在下一次战斗中使首个霜火弹同时附带灼烧与缓速。
- **阅读要求**：角色职业标签含 `mage` 或 `elementalist`；已学会 `mage_fireball` 或 `mage_frost_bolt`；基础 `智力 ≥ 17`。
- **稀有度**：史诗（Epic）
- **建议投放**：元素裂隙交汇点、双头龙巢穴宝箱、禁术学者私藏。

## 书籍内容

霜与火在常识中互相排斥，本书却主张它们本是一枚硬币的两面。作者通过大量实验记录，证明低温火焰能在不熄灭的前提下冻结目标表面，而高温冰霜则可从内部撕裂护甲。书中详细拆解了三种失败的融合比例：火多霜少会导致蒸汽爆炸，霜多火少则只留一层薄冰。正确的方法是在施法瞬间让两种元素在指尖分离半拍，再借一次短促的呼吸让它们相撞。作者还警告，霜火双生会对施法者的手部神经造成轻微灼伤与冻伤交替的副作用，因此书中附带了七味药膏的配方。最末一页画着一个被冰晶与火苗同时包裹的螺旋符号，旁边只有一句话：悖论不是错误，是世界尚未习惯的答案。为了掌握这门技艺，练习者需要先分别精通火球术与霜箭术，再在寂静的实验室里反复寻找那个平衡点。

## 设计意图

鼓励玩家跨元素组合技能，制造复合异常状态，丰富后期战棋的战术维度。
