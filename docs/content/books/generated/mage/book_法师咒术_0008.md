# 《棘刺思维：疼痛即专注》

## 基础信息

- **书籍 ID**：`book_法师咒术_0008`
- **关联技能**：`mage_thorn_mind`
- **使用效果**：阅读后解锁 `mage_thorn_mind`；若已学会，提升 `current_mastery +90`，并在下一次战斗中使棘刺思维的反伤效果额外触发一次。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 8` 且 `意志 ≥ 6`。
- **稀有度**：普通（Common）
- **建议投放**：苦修院禁书区、战地法师背包、沉钟书库疼痛研究架。

## 书籍内容

这本书的边角布满细小的刺痕，翻阅时需要格外小心。作者提出一个反直觉的观点：法师的专注不是通过平静获得的，而是通过控制疼痛。棘刺思维的原理是在自己的精神周围布下细小的魔力荆棘，当敌人试图用心灵攻击侵入时，会先被刺伤。

前半部分讲述如何在冥想时刻意引入轻微不适，比如坐在不平整的石块上，让意识学会与疼痛共存。后半部分转入实战：当敌方施法者对你施放精神类法术时，棘刺思维会把一部分伤害反弹回去。书中警告，过度追求刺痛会让自己陷入偏执，反而更容易被真正的心灵大师利用。最后一页画着一个被荆棘环绕的大脑，旁边写着：让你的敌人记住，攻击你是有代价的。

书中列举了几种适合初学者的心理训练，比如在嘈杂的酒馆里尝试完成一道复杂的算题，以此锻炼在干扰中保持专注的能力。

## 设计意图

为法师系提供早期反制心灵攻击的能力，增强对抗控制型敌人的手段，同时引入"以痛换力"的咒语哲学，为后续精神系与诅咒系法术提供叙事连接。
