# 《星种的埋设与催芽》

## 基础信息

- **书籍 ID**：`book_法师咒术_0165`
- **关联技能**：`mage_star_seed`
- **使用效果**：阅读后解锁 `mage_star_seed`；若已学会，提升 `current_mastery +170` 并在下一次战斗中使星种成熟时对周围敌人造成基于施法者智力的星辉伤害。
- **阅读要求**：角色职业标签含 `mage` 或 `astromancer`；基础 `智力 ≥ 18` 且 `感知 ≥ 14`。
- **稀有度**：史诗（Epic）
- **建议投放**：观星台、陨石坑、星象学者营地。

## 书籍内容

星种是从陨石中提取的微小结晶，蕴含着来自遥远星辰的魔力。本书讲述如何将星种埋入战场，用法力和月光催使其在短时间内发芽爆发。作者强调，埋设深度和土壤成分都会影响成长速度：沙地中的星种发芽快但威力弱，岩石缝中的星种成长慢却更加持久。书中记录了不同星座对应的星种特性，有些偏向冰冻，有些偏向电击，还有一些会释放出治疗光辉。最末一章讨论催芽的风险，过度灌注魔力会让星种在手中提前爆裂。批注写道：星辰从不着急，它们的耐心是力量的一部分。练习者需要在每个满月夜埋设一枚星种并记录生长数据。这门技艺适合预先布置战场，让敌人在不知不觉中踏入星辉陷阱。

星种发芽时会发出微弱的星光脉冲，细心的施法者能凭此判断爆发时机。

星种埋入土壤后会微微发烫，那是遥远星辰的魔力正在与大地交换问候。

## 设计意图

为星象法师提供延时爆发陷阱，强化埋伏战术与天文学世界观。
