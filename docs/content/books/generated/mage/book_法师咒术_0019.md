# 《银丝线：精密到可缝补伤口》

## 基础信息

- **书籍 ID**：`book_法师咒术_0019`
- **关联技能**：`mage_silver_thread`
- **使用效果**：阅读后解锁 `mage_silver_thread`；若已学会，提升 `current_mastery +90`，并在下一次战斗中使银丝线缝合伤口时额外回复 5 点生命。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：战地医疗营、法师裁缝店、遗迹救援队仓库。

## 书籍内容

银丝线是由高度凝聚的魔力拉成的细长线条，肉眼几乎看不见，但坚韧程度足以缝合皮革。这本书的作者是一位前战地法师，他把银丝线从战斗陷阱改造成了紧急医疗工具。书中详细记录了如何在伤口两侧准确地穿出魔力细线，并用温和的魔力波动促进愈合。

前半部分讲解丝的粗细控制，太粗会刺激组织，太细则容易断裂。后半部分展示战术用法：除了治疗，银丝线还可以用来绊倒敌人、绑住物品、或者作为触发陷阱的引线。作者特别提醒，不要把银丝线长期留在活人体内，它会缓慢吸收血液中的魔力，最终造成虚弱。最后一页是一幅插图，画着一只被银线缝合的断臂正在重新活动。

书中特别强调银丝线与不同材质的反应，比如对丝绸和皮革几乎没有排斥，但遇到铁器会迅速发热甚至熔断。

## 设计意图

为法师系提供早期治疗与多功能辅助技能，拓展法师在团队中的支援角色，同时为后续丝线系、傀儡系与精密魔力操控类法术建立熟练度基础。
