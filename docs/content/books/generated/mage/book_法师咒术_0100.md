# 《天启真言的读法禁忌》

## 基础信息

- **书籍 ID**：`book_法师咒术_0100`
- **关联技能**：`mage_apocalypse_word`
- **使用效果**：阅读后解锁 `mage_apocalypse_word`；若已学会，提升 `current_mastery +180` 并在下一次战斗中使天启真言的伤害上限提高 5%。
- **阅读要求**：角色职业标签含 `mage` 或 `archmage`；基础 `智力 ≥ 18` 且 `意志 ≥ 14`。
- **稀有度**：传说（Legendary）
- **建议投放**：世界树根部禁书区、末日预言神殿、最终boss战利品。

## 书籍内容

天启真言不是被念诵的，而是被'允许说出'的。前半本列举了读法禁忌：不能在日出前读，不能在听到哭声后读，不能在心中怀有怜悯时读。作者认为，每一个音节都是一种请求，请求世界在局部范围内承认终结。

书中夹着一张空白页，批注说这一页记载着最后一个音节，但任何试图写下它的人都会立刻忘记自己为什么要写。中段警告：天启真言对施术者的伤害是渐进的，第一次使用会损失声音三天，第二次会损失一段记忆，第三次则可能永远失去某种情感。

后半部讨论战术：天启真言不应作为开场，而应作为收束——当所有其他手段都失败后，用一个词结束一切。末日预言神殿的壁画上画着无数个张开嘴的人物，但他们的嘴唇都被涂抹掉了，因为最后一个音节不允许被看见。天启真言的壁画嘴唇被涂掉后，有人声称夜里会听见低语。壁画低语是梦中继续念诵。
## 设计意图

传说级终极法术书籍，提供最高门槛的毁灭能力，作为法师成长循环的终点目标之一，强调禁忌、代价与终结感。
