# 《热源感知：看见温度的人》

## 基础信息

- **书籍 ID**：`book_法师咒术_0009`
- **关联技能**：`mage_heat_sense`
- **使用效果**：阅读后解锁 `mage_heat_sense`；若已学会，提升 `current_mastery +80`，并在下一次战斗中使热源感知的范围扩大 2 格。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 6`。
- **稀有度**：普通（Common）
- **建议投放**：矿洞入口守卫室、沙漠旅团营地、猎人公会藏书架。

## 书籍内容

真正老练的法师不靠眼睛判断敌人位置，而是靠温度。本书教授一种名为"热源感知"的低阶咒术，让施术者能够透过墙壁、烟雾甚至黑暗，感知到附近生物散发出的热量。前半部分是大量枯燥的温度记录表，作者坚持认为只有先记住正常体温的数值，才能识别异常。

后半部分讲解实战应用：如何在完全黑暗的房间中定位敌人，如何区分活人和被死灵法术驱动的尸体，以及如何通过热源判断敌人是否正在蓄力施法。书中还提到，过度使用热源感知会让人对冷热失去正常判断，曾有法师在冬天误把结冰的湖面当成温暖的道路。最后一章建议每次使用不要超过一盏茶时间。

作者还设计了一套进阶练习，要求学徒蒙上眼睛，仅凭温度判断房间里有多少人、他们分别站在哪个方向，以及是否持有火把。

## 设计意图

作为法师系早期侦察类技能解锁书籍，拓展战棋中的信息获取维度，强调感知类法术在探索与埋伏战中的价值，为后续预言系与元素感知法术奠定基础。
