# 《霜环绽放：极寒涟漪》

## 基础信息

- **书籍 ID**：`book_法师咒术_0208`
- **关联技能**：`mage_frost_pulse`
- **使用效果**：阅读后解锁 `mage_frost_pulse`；若已学会，提升 `current_mastery +150` 并在下一次战斗中使首次霜环释放时范围向外扩展半格。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 12`。
- **稀有度**：稀有（Rare）
- **建议投放**：冰霜巨龙巢穴、冬幕学院、冰封陵墓。

## 书籍内容

霜环绽放是以施法者为中心向外爆发的一圈极寒冲击，能把近身的敌人冻结在原地。书中第一页是一幅被冰晶覆盖的插画，描绘了一位法师被七名刺客包围后安然脱身的场景。作者把施法要点总结为收缩再释放：先让魔力在体内形成一个寒冷的核，然后像呼吸一样把它推出体外。初学者常犯的错误是急于求成，结果霜环只覆盖了身前半圈。后半部讲解如何配合脚步移动，让霜环的边界恰好卡在自己与敌人之间，制造安全的施法距离。最末页写着：最冷的不是霜，是你决定反击的那一刻。许多北方法师在学会此术后，会把第一次成功冻结的水面刻上自己的名字。高阶篇还提到，在霜环边缘撒上碎冰晶可让寒潮持续多滞留意刹那，足以让敌人脚步打滑。书的扉页夹着一片来自北境的雪花标本，至今仍未融化。

## 设计意图

提供近距离控场手段，让法师在被包围时拥有翻盘可能，强化冰系自保能力。
