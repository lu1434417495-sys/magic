# 《藤蔓鞭：把植物变成手臂》

## 基础信息

- **书籍 ID**：`book_法师咒术_0034`
- **关联技能**：`mage_vine_whip`
- **使用效果**：阅读后解锁 `mage_vine_whip`；若已学会，提升 `current_mastery +90`，并在下一次战斗中使藤蔓鞭首次命中时束缚目标 1 回合。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：森林德鲁伊营地、草药师协会、废弃植物园。

## 书籍内容

藤蔓鞭允许施术者从掌心或附近的地面召唤出一条灵活的藤蔓，像鞭子一样抽打或缠绕敌人。这本书的作者声称，这个咒语之所以适合初学者，是因为它不需要制造新的生命，只是唤醒沉睡在植物纤维里的本能。前半部分教读者如何与周围的植物建立短暂的"借用手臂"关系，并感受它们的生长方向。

后半部分讲解战斗中的灵活运用：可以把藤蔓鞭当作中距离武器，也可以用它缠住敌人的武器或脚踝。书中警告，藤蔓鞭在干燥环境中会变脆，在极寒环境中则会僵硬。最后附有一张被藤蔓勒出痕迹的练习木桩照片，木桩上还留着几十道深浅不一的鞭痕，记录着某位学徒漫长的练习过程。

书中还对比了几种常见藤蔓的特性，比如常春藤柔韧但缺乏杀伤力，荆棘藤锋利却难以控制，初学者应根据自己的战斗风格选择。

## 设计意图

为法师系提供早期自然主题中程武器技能，拓展攻击距离与控场手段，同时为后续植物召唤、自然盟友与德鲁伊式法术建立熟练度与叙事连接。
