# 《雷霆法典的装填术》

## 基础信息

- **书籍 ID**：`book_法师咒术_0126`
- **关联技能**：`mage_thunder_cannon`
- **使用效果**：阅读后解锁 `mage_thunder_cannon`；若已学会，提升 `current_mastery +180` 并在下一次战斗中使雷霆法典首次充能伤害提高 12%。
- **阅读要求**：角色职业标签含 `mage` 或 `elementalist`；基础 `智力 ≥ 18` 且 `体质 ≥ 12`。
- **稀有度**：史诗（Epic）
- **建议投放**：风暴要塞、魔导炮兵工坊、雷霆领主试炼奖励。

## 书籍内容

雷霆法典不是真正的火炮，而是一本被改造成魔力容器的厚重书卷。本书教授如何安全地往法典中装填雷电，以及如何判断当前容电量。作者强调，装填时必须将书页按特定顺序翻动，任何跳页都会引发电弧泄漏。书中记录了五种装填等级，从低声的静电到震耳的雷鸣，每一级都需要更长的蓄力时间。作者警告，不要将法典充能超过八成，因为雷电会开始反向吞噬书页上的文字。第二章讲解发射姿势：双手握持书脊，让法典开口朝向目标，同时用咒语引导释放方向。最末一页有一段被烧焦的警告：法典是借来的闪电，别把它当成自己的声音。战场上，雷霆法典需要队友掩护才能充分发挥威力。熟练的炮兵法师往往会在法典旁放置避雷针，以分散 accidental 的反噬。

雷霆法典的封面用绝缘龙皮装订，这是无数炮兵法师用灼伤换来的传统。

## 设计意图

为雷系法师提供蓄力型重炮输出，强调资源积蓄与释放时机，增强战棋中的位置压制。
