# 《白骨寒气的来源考》

## 基础信息

- **书籍 ID**：`book_法师咒术_0074`
- **关联技能**：`mage_bone_chill`
- **使用效果**：阅读后解锁 `mage_bone_chill`；若已学会，提升 `current_mastery +110` 并在下一次战斗中使首次白骨寒气降低目标 `敏捷` 1 点，持续 2 回合。
- **阅读要求**：角色职业标签含 `mage` 或 `necromancer`；基础 `智力 ≥ 10`。
- **稀有度**：精良（Uncommon）
- **建议投放**：古墓书库、亡灵法师遗迹、停尸房密室。

## 书籍内容

白骨寒气不是普通的冷，而是'曾经活过的东西最后呼出的温度'。前半本考据了这种寒气的来源：它通常出现在战场遗址、废弃医院与古老墓穴，是普通冰霜魔法的反面——不冻结水，只冻结生命力。作者要求施术者先在黎明前收集一捧带霜的枯叶，感受其中残留的'未完成的温暖'。

中段讲解了白骨寒气与普通冰霜的区别：普通冰霜伤害皮肤，白骨寒气则让关节发僵、反应变慢。后半部是道德警告：长期接触白骨寒气会让施术者的指尖失去正常温度，甚至影响握笔与进食。古墓书库的看守者会在每年的忌日点燃一种特殊的香，据说是为了让白骨寒气不要误判活人为同类。

白骨寒气会让附近的蜡烛火焰变成蓝色。蓝烛火判断是否有入侵。寒气会寻找生者身上的缝隙。寒气识生死。
白骨寒气会让蜡烛变蓝。
## 设计意图

精良级死灵/冰霜混合 debuff 书籍，解锁白骨寒气并提供属性削弱能力，强调来源考据与代价感。
