# 《风涌术的借力技巧》

## 基础信息

- **书籍 ID**：`book_法师咒术_0090`
- **关联技能**：`mage_gust_of_wind`
- **使用效果**：阅读后解锁 `mage_gust_of_wind`；若已学会，提升 `current_mastery +90` 并在下一次战斗中使首次风涌术吹散地面效果范围增加一格。
- **阅读要求**：角色职业标签含 `mage` 或 `elementalist`；基础 `智力 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：风息哨塔、游侠训练场、海边村庄藏书。

## 书籍内容

风涌术不是制造风，而是借用已有的空气流动。前半本讲解借力技巧：施术者要先感受环境中的微小气流，再用魔力把它们放大，而不是凭空挤压空气。作者建议在海边或高处练习，因为那里的风更愿意合作。

书中警告，在室内施放风涌术时要小心，反弹的气流可能会把盟友的文件和火把一起吹灭。中段收录了'风的方向感'：施术者必须记住风是三维的，地面上的旗帜只显示水平方向，真正的力量可能来自头顶。后半部讨论战术：风涌术可以吹散毒气、熄灭火焰，也可以把轻敌人推下高处。

风息哨塔的水手们说，懂得风涌术的法师在甲板上从不会晕船，因为他们已经学会了与风讨价还价。风涌术的法师说话声音通常很轻。风涌法师习惯轻声说话。风会记住。风会记住每一次承诺。风会回应。
## 设计意图

普通级元素实用书籍，解锁风涌术并为法师提供环境互动能力，强调借力而非强行创造。
