# 《水晶哨卫的篆刻手册》

## 基础信息

- **书籍 ID**：`book_法师咒术_0087`
- **关联技能**：`mage_crystal_sentinel`
- **使用效果**：阅读后解锁 `mage_crystal_sentinel`；若已学会，提升 `current_mastery +120` 并提升水晶哨卫生命 `+15%`。
- **阅读要求**：角色职业标签含 `mage` 或 `geomancer`；基础 `智力 ≥ 11` 且 `体质 ≥ 8`。
- **稀有度**：精良（Uncommon）
- **建议投放**：水晶矿洞图书馆、守护者祭坛、土元素工匠行会。

## 书籍内容

水晶哨卫不是被雕刻出来的，而是被'唤醒'出来的。前半本是一份篆刻手册，展示了如何在普通水晶上刻下三层符文：底层负责站立，中层负责感知，顶层负责攻击。作者强调，刻错一划符文不会让哨卫爆炸，但会让它变得非常固执，比如只攻击某一种颜色衣服的敌人。

中段收录了维护日志：水晶哨卫需要定期用魔力擦拭，否则会积聚静电，在雷雨天气主动引雷。后半部讨论指挥：哨卫只接受简单的指令，比如'守这里'或'打那个'，试图让它执行复杂战术通常会导致它原地发呆。水晶矿洞的深处有一座由失控哨卫组成的石堆，矿工们称之为"守卫者的沉默议会"。

水晶哨卫的核心符文必须逆时针描边。新学徒每年重排石堆。石堆需要定期整理。石堆也有秩序。核心需敬畏。哨卫守密。核心符文会记住每一次描边的手势。
## 设计意图

精良级召唤/防御书籍，解锁水晶哨卫并为法师提供固定炮台型召唤物，强调符文工艺与简单指挥。
