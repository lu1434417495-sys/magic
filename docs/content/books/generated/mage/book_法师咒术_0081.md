# 《虹光喷射的色谱笔记》

## 基础信息

- **书籍 ID**：`book_法师咒术_0081`
- **关联技能**：`mage_color_spray`
- **使用效果**：阅读后解锁 `mage_color_spray`；若已学会，提升 `current_mastery +90` 并在下一次战斗中使首次虹光喷射随机附加一种额外效果。
- **阅读要求**：角色职业标签含 `mage` 或 `illusionist`；基础 `智力 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：街头魔术师摊位、马戏团后台、彩光节庆奖励。

## 书籍内容

虹光喷射是幻术师最不受尊重却最实用的法术之一。前半本是一本色谱笔记，作者用七种颜色对应七种效果：红致盲、橙震慑、黄混乱、绿沉睡、蓝减速、靛沉默、紫魅惑。书中警告，实际施术时颜色会因为施术者情绪而偏色，愤怒的法师更容易喷出红色，悲伤的法师则偏向蓝色。

中段收录了'混色事故'：两名幻术师同时对同一目标喷射不同颜色，结果目标陷入了一种无法描述的眩晕状态。后半部讲解实战用法：虹光喷射最适合在敌人靠近前的一瞬间使用，因为距离太近时施术者自己也会被反射光影响。

彩光节庆的评委能根据一道虹光喷射的颜色组合判断施术者当天的情绪，准确率据说高达七成。虹光喷射的评委都戴着眼罩打分。眼罩打分消除颜色偏见。颜色比语言更诚实。评委也需要训练。
## 设计意图

普通级幻术范围控制书籍，解锁虹光喷射并提供随机 debuff 能力，用色彩机制增加趣味性与不可预测性。
