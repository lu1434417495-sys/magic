# 《骨算盘的概率演算》

## 基础信息

- **书籍 ID**：`book_法师咒术_0169`
- **关联技能**：`mage_bone_abacus`
- **使用效果**：阅读后解锁 `mage_bone_abacus`；若已学会，提升 `current_mastery +160` 并在下一次战斗中使概率演算首次成功时提高下次暴击率 20%。
- **阅读要求**：角色职业标签含 `mage` 或 `necromancer`；基础 `智力 ≥ 18` 且 `感知 ≥ 14`。

## 书籍内容

骨算盘是一种用亡者指骨制成的计算工具，据说能感知命运缝隙中的概率。本书从基础算术开始，教导如何用骨珠推演战场上的可能性。作者强调，骨算盘不会告诉你必然发生的事，只会显示哪一种选择更有利。书中记录了如何解读骨珠摩擦时发出的细微声响：清脆代表高概率，沉闷代表低概率，而完全无声则意味着命运尚未决定。第二章讨论反噬：过度依赖算盘会让施法者失去直觉，变成只会计算的空壳。最末一页写着：概率是风的语言，你只能顺风，不能造风。练习者需要每天用骨算盘预测一件小事，再验证结果。这门技艺在战棋中能帮助法师选择最优施法目标与时机。

经验丰富的使用者能在算盘声响变化前零点几秒内预感危险并调整策略。

骨算盘最忌讳在计算时被人打断，因为那一刻算珠记录的不只是概率，还有施法者的命运。

## 设计意图

为亡灵法师提供概率辅助机制，将命运计算与战术决策结合。
