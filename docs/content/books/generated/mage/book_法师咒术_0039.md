# 《重力轻触：让敌人踉跄一下》

## 基础信息

- **书籍 ID**：`book_法师咒术_0039`
- **关联技能**：`mage_gravity_tap`
- **使用效果**：阅读后解锁 `mage_gravity_tap`；若已学会，提升 `current_mastery +90`，并在下一次战斗中使重力轻触首次命中时使敌人下回合行动力减 1。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：高塔重力实验室、天体观测站、遗迹升降机旁。

## 书籍内容

重力轻触是一种极其精细的力场咒术，它不能把人压垮，但能在关键时刻让敌人的脚步突然变重，从而打乱对方的移动节奏。这本书的作者是一位研究重力的老学者，他坚持认为初学者应该从"让羽毛变重一点点"开始，而不是妄想移动整座山。

前半部分是大量枯燥的基础练习，包括让一枚硬币在掌心短暂增重、让一根羽毛垂直下落等。后半部分转入实战：在敌人准备冲锋时施放重力轻触，可以让对方的前冲变成踉跄；在敌人攀爬高台时施放，则可能导致对方失足。书中警告，这个咒语对体重极大的目标效果有限，试图用它阻止一头巨魔只会让自己魔力耗尽。最后一页画着一个被无形力量压住脚踝的士兵。

书中还讨论了重力轻触的施法时机，最好是在敌人单脚着地或重心前倾的瞬间释放，这样即使是微小的增重也足以让对方失去平衡。

## 设计意图

为法师系提供早期力场控制技能，强化战棋中的节奏干扰与走位限制，同时为后续重力系高级法术建立"精确微调"的基础熟练度概念。
