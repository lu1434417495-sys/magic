# 《暗影帷幕的经纬》

## 基础信息

- **书籍 ID**：`book_法师咒术_0111`
- **关联技能**：`mage_shadow_veil`
- **使用效果**：阅读后解锁 `mage_shadow_veil`；若已学会，提升 `current_mastery +160` 并在下一次战斗中使帷幕首次展开时附带 1 回合的隐身效果。
- **阅读要求**：角色职业标签含 `mage` 或 `warlock`；基础 `智力 ≥ 16` 且 `敏捷 ≥ 12`。
- **稀有度**：史诗（Epic）
- **建议投放**：影塔顶层、暗影议会密室、黑市幻术书商。

## 书籍内容

暗影帷幕不是一块简单的黑布，而是由无数细长影子交织成的防护层。本书从经纬结构讲起，要求施法者先在意识中画出横竖各九根主线，再让副线以特定角度穿插。作者指出，帷幕的密度决定了它能吸收多少光线与魔法，过密则无法透气，施法者会在数秒后窒息，过疏则形同虚设。第二章讨论如何在帷幕内保持方向感：黑暗中的定位依赖于对地脉磁场的微弱感知。书中还收录了三种暗影生物常用来窥视帷幕的缝隙，并给出修补方法。作者警告，不要长时间躲在自己编织的帷幕里，因为影子会逐渐忘记主人，开始模仿你的动作。最后一页是一幅被涂黑的肖像，下面写着：当你凝视帷幕时，帷幕也在凝视你。真正熟练后，甚至可以在移动中维持帷幕，让暗影成为第二层皮肤。

暗影议会的刺客常在帷幕中默念目标的名字，以此提醒自己影子只是工具，而非归宿。

## 设计意图

为暗影法师提供高阶防御与隐蔽手段，强化刺客型法师的战场生存与伏击选择。
