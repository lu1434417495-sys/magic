# 《念刃残章：思维的锋口》

## 基础信息

- **书籍 ID**：`book_法师咒术_0003`
- **关联技能**：`mage_dagger_of_mind`
- **使用效果**：阅读后解锁 `mage_dagger_of_mind`；若已学会，提升 `current_mastery +90`，并在下一次战斗中使首枚念刃无视目标 2 点护甲。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：沉钟书库心理学区、老兵法师遗物、边境哨塔储物柜。

## 书籍内容

念刃不是幻觉，而是把精神力压缩到足够锋利时产生的真实切割。作者开篇就提醒读者：如果你的注意力不能连续盯住同一个点超过十次呼吸，请不要继续往下读。书中详细描述了一种"凝视练习"，要求施术者盯着墙上的小孔，直到感觉自己的视线能穿透墙壁。

中段开始讲解如何把凝视转化为攻击。关键不在于想象一把刀，而在于把想法本身变得锋利。作者列举了几种常见的失败形态：有人念出了棉花糖般的钝刃，有人则因为杂念太多让念刃在中途散开。书末附有一页被撕掉一半的笔记，似乎前任主人用它成功切开了一把铁锁，代价是头疼了三天。最后一句写道：最危险的不是念刃，是施术者自己的执念。

作者在附录中记录了几种增强专注力的辅助手段，包括凝视烛火、默数呼吸以及想象脑海中有一面不断被敲击的铜锣。

## 设计意图

为法师系补充不依赖元素的早期精神伤害手段，丰富输出维度，同时引出"精神力可实体化"的设定，为后期心灵系法术提供叙事与熟练度铺垫。
