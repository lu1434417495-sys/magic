# 《微风足印：移动中的咒语》

## 基础信息

- **书籍 ID**：`book_法师咒术_0002`
- **关联技能**：`mage_zephyr_step`
- **使用效果**：阅读后解锁 `mage_zephyr_step`；若已学会，提升 `current_mastery +80`，并在下一次战斗中使首次微风步不触发借机攻击。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 6`。
- **稀有度**：普通（Common）
- **建议投放**：风元素祭坛边缘、游方法师背包、战棋训练场书架。

## 书籍内容

这本书的纸张极薄，翻页时会发出类似树叶摩擦的声响。作者认为法师最大的弱点不是血量，而是移动时像棵老树。微风步不是让你跑得更快，而是让风替你完成迈步的动作，你的身体只需要决定方向。书中用大量图示展示如何在抬脚的瞬间把魔力集中在脚踝，而不是膝盖。

前半部分练习要求学徒在原地单脚站立一炷香时间，直到能感知到脚下气流的方向。后半部分转入实战：如何在闪避箭矢时保持咒语吟唱的连续性。作者警告说，很多初学者会忍不住在风中跳得太高，结果落地时正好踩进敌人的攻击范围。真正成熟的微风步应该是贴着地面滑行，像一片被吹动的纸。

书中特别收录了一段老法师的笔记，讲述他如何在一次遭遇战中凭借微风步连续躲过三支弩箭，最终把反击距离缩短到恰到好处的位置。

## 设计意图

为法师系提供早期机动性选择，强调战棋中"走位即防御"的思路，使法师在施法距离与生存能力之间取得平衡，同时与后续高阶传送类技能形成进阶链条。
