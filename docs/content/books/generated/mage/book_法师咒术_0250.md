# 《黑曜尖刺：火山獠牙》

## 基础信息

- **书籍 ID**：`book_法师咒术_0250`
- **关联技能**：`mage_obsidian_spike`
- **使用效果**：阅读后解锁 `mage_obsidian_spike`；若已学会，提升 `current_mastery +170` 并在下一次战斗中使首次黑曜尖刺命中时附带破甲效果。
- **阅读要求**：角色职业标签含 `mage` 或 `pyromancer`；基础 `智力 ≥ 15` 且 `体质 ≥ 12`。
- **稀有度**：史诗（Epic）
- **建议投放**：火山深层矿脉、黑曜石神殿、地火锻炉。

## 书籍内容

黑曜尖刺是从地下召唤出尖锐黑曜石柱刺穿敌人的法术，兼具岩石硬度与火焰余热。书中把尖刺比作火山的牙齿，平时藏在地下，只在愤怒时露出。作者强调，召唤尖刺时必须感知地下岩层的走向，否则石柱可能在错误位置断裂。练习者需要先在沙盘上用熔蜡模拟岩浆通道，观察不同压力下尖刺的形成角度。后半部讲解了如何让黑曜尖刺在命中后碎裂成高温碎片，对周围敌人造成溅射伤害。最末页是一块真正的黑曜石碎片，边缘仍保留着熔岩流动的纹路。许多火山法师会把这块碎片当作法器，他们相信其中还封印着一次远古喷发。书中还提醒，黑曜尖刺在冷却后会变得脆弱，因此最好在召唤后立即命中目标，以保留最大的穿透力。黑曜尖刺碎片常被收集起来打磨成箭头，是火山法师喜爱的副业产物。

## 设计意图

提供高伤害破甲地刺，让火土双属性法师拥有强力的单点突破手段，丰富元素组合玩法。
