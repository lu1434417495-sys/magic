# 《灵魂契约的解约条款》

## 基础信息

- **书籍 ID**：`book_法师咒术_0148`
- **关联技能**：`mage_soul_release`
- **使用效果**：阅读后解锁 `mage_soul_release`；若已学会，提升 `current_mastery +170` 并在下一次战斗中使解约首次成功时为目标恢复 10% 最大生命。
- **阅读要求**：角色职业标签含 `mage` 或 `warlock`；基础 `智力 ≥ 17` 且 `意志 ≥ 15`。
- **稀有度**：史诗（Epic）
- **建议投放**：灵魂仲裁所、黑市契约商人、禁忌法学院。

## 书籍内容

签订灵魂契约很容易，解约却需要更高的智慧。本书从解约条款入手，教导施法者如何在契约文本中提前埋下终止条件、代偿方式与违约后果。作者指出，大多数灵魂契约的陷阱不在于绑定，而在于没有清晰的退出路径。书中收录了十二种常见契约的解约话术，每一种都需要在特定月相或地点说出才能生效。作者警告，强行撕毁契约会让双方灵魂都受到撕裂伤，因此和解约条款的谈判往往比战斗更危险。第二章讨论如何为队友解除被敌方施加的灵魂束缚，以及如何在解约后安抚受损的灵魂。最末一页是一份空白解约书，批注写着：自由不是取消契约，而是让契约双方都同意结束。解约成功后，原本被契约占据的灵魂会留下一个空洞。作者建议在解约后避免立即签订新契约，以免空洞被不怀好意的力量趁虚而入。

## 设计意图

为暗法师与辅助型法师提供状态解除与救赎机制，深化灵魂契约系统的策略与叙事。
