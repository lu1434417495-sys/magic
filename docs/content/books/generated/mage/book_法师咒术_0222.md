# 《焰门：烈焰通道》

## 基础信息

- **书籍 ID**：`book_法师咒术_0222`
- **关联技能**：`mage_flame_portal`
- **使用效果**：阅读后解锁 `mage_flame_portal`；若已学会，提升 `current_mastery +160` 并在下一次战斗中使首次通过焰门时附带一次火焰冲击。
- **阅读要求**：角色职业标签含 `mage` 或 `pyromancer`；基础 `智力 ≥ 15` 且 `感知 ≥ 12`。
- **稀有度**：史诗（Epic）
- **建议投放**：火焰维度裂隙、古代传送门遗址、炎魔领主宝库。

## 书籍内容

焰门是在两个地点之间打开火焰通道的法术，能让施法者或投射物瞬间移动。书中警告，焰门不是安全的传送门，穿越时会被火焰灼烧，体质不足者可能化为灰烬。作者把施法要点总结为稳定两端的锚点：入口太冷会关闭，出口太热会失控。练习者需要先在短距离内反复开门，直到能维持三秒不崩塌。后半部讲解了如何把焰门用作武器，例如让火球穿过门后从敌人背后出现，或者把敌人推入门中送到危险位置。最末页只有一句话：门的另一边永远比这边热。许多火法师的眉毛都在练习此术时消失过至少一次。书中还提醒，焰门在暴雨中极不稳定，最好随身携带干燥的火绒以快速重燃熄灭的入口。焰门关闭后空气中会留下硫磺味，久久不散，是火法师独有的气息。经验丰富的火法师能通过硫磺味的浓淡判断上一次焰门的大小。

## 设计意图

提供短程传送与战术位移，让法师能在战棋中快速调整位置或制造突袭角度。
