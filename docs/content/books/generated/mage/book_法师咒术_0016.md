# 《尘步：借地隐形的土系窍门》

## 基础信息

- **书籍 ID**：`book_法师咒术_0016`
- **关联技能**：`mage_dust_step`
- **使用效果**：阅读后解锁 `mage_dust_step`；若已学会，提升 `current_mastery +80`，并在下一次战斗中使尘步首次触发时必定使敌人失去目标锁定。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 6`。
- **稀有度**：普通（Common）
- **建议投放**：沙漠商队营地、盗墓者藏匿点、土元素祭坛外围。

## 书籍内容

尘步的原理很简单：在移动时掀起一小片尘土，并把自己的身影与尘土的轨迹重叠，从而让追击者在一瞬间失去目标。这本书的作者声称，最优秀的尘步使用者不是跑得最快的人，而是最懂得利用地面材质的人。

前半部分详细比较了沙地、泥地、落叶地和石板路的起尘效果，指出干燥松软的地面最适合这个咒语。后半部分转入实战节奏：如何在敌人攻击前的一刻启动尘步，让攻击落向自己留下的残影。书中警告，尘步不能让你真正隐身，只是制造瞬间的视线混乱，如果敌人已经记住了你的气味或魔力特征，这个咒语就会失效。最后一页画着一个模糊的人形正在沙雾中消散。

书中还附有一套称为"迷尘步"的练习步法，要求学徒在沙尘中走出一条之字形路线而不被旁观者看清身形。熟练者甚至能在沙尘中突然转身，让追击者的武器劈向自己留下的残影。

## 设计意图

为法师系提供早期闪避与干扰技能，强调移动与环境材质的结合，强化战棋中的走位欺骗战术，同时为后续土系隐身与沙暴类法术奠定熟练度基础。
