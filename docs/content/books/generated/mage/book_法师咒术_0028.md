# 《苔肤术：向植物借一层护甲》

## 基础信息

- **书籍 ID**：`book_法师咒术_0028`
- **关联技能**：`mage_moss_skin`
- **使用效果**：阅读后解锁 `mage_moss_skin`；若已学会，提升 `current_mastery +80`，并在下一次战斗中使苔肤术提供的护甲值额外增加 2 点。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 6`。
- **稀有度**：普通（Common）
- **建议投放**：古老森林、苔藓洞穴、自然法师隐居处。

## 书籍内容

苔肤术让施术者的皮肤表面覆盖一层柔软的绿色苔藓，这层苔藓能够吸收冲击、减缓流血，并让施术者在森林环境中更难被发现。这本书的作者是一个在森林里住了四十年的老法师，他声称最好的护甲不是金属，而是会呼吸的东西。

前半部分讲解如何让魔力模拟苔藓的生长节奏，太快了会痒得无法忍受，太慢了又起不到防护作用。后半部分讨论环境加成：在潮湿或有植被的地方，苔肤术的恢复速度会显著提升。书中还提到，这个咒语有一个副作用：使用者的皮肤会在几天内保持淡淡的绿色，洗澡也无法完全去除。最后一页画着一个浑身覆盖苔藓的法师，正安静地蹲在树根旁。

作者提到，苔肤术会让使用者身上散发出淡淡的泥土与青草气息，这在森林中是绝佳的伪装，但在城市里却很容易引起注意。

## 设计意图

为法师系提供早期自然主题防御技能，拓展护甲来源与环境互动，同时为后续植物系、自然系与生态相关法术建立熟练度基础与叙事铺垫。
