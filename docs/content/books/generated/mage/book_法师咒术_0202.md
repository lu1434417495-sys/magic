# 《冰镜摹本：寒霜自照》

## 基础信息

- **书籍 ID**：`book_法师咒术_0202`
- **关联技能**：`mage_ice_mirror`
- **使用效果**：阅读后解锁 `mage_ice_mirror`；若已学会，提升 `current_mastery +140` 并在下一次战斗中使首面冰镜可额外反射一次指向性法术。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 13` 且 `意志 ≥ 11`。
- **稀有度**：稀有（Rare）
- **建议投放**：北境霜塔藏书房、冰封湖底密室、高阶法师私人书架。

## 书籍内容

冰镜摹本的第一页是一面真正的薄冰，读者必须对着它凝视自己的倒影，直到镜面不再因呼吸而融化。作者认为，冰镜的本质不是防御，而是让施法者看清攻击的来路。书中详细记录了七种凝结角度，每一种对应一类常见法术的反射路径。初学者最容易犯的错误是把镜面磨得太厚，结果法术没被弹开，反而把镜子击碎。后半部分讲解如何在战斗中快速召唤多面小镜，将敌人的火球像打弹珠一样在镜阵间弹射。最末章是一页空白，批注写着：当你能在镜中看见敌人背后的弱点，冰镜才算真正学会。许多北境法师会把这本书压在枕头下，据说能梦见自己未曾犯过的错。进阶章节还提到，把冰镜碎片混入雪暴可制造出真假难辨的反射迷宫。书脊内侧藏着一小块永不融化的冰，据说是作者为了防止书籍在夏日变质而设。

## 设计意图

强化法师防御反击体系，让冰系法术兼具生存与策略深度，为高阶对局提供反制空间。
