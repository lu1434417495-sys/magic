# 《重力摇篮曲的哼唱》

## 基础信息

- **书籍 ID**：`book_法师咒术_0185`
- **关联技能**：`mage_gravity_lullaby`
- **使用效果**：阅读后解锁 `mage_gravity_lullaby`；若已学会，提升 `current_mastery +180` 并在下一次战斗中使重力摇篮曲首次唱完时使范围内敌人陷入 1 回合昏睡。
- **阅读要求**：角色职业标签含 `mage` 或 `gravitist`；基础 `智力 ≥ 18` 且 `冥想 ≥ 5`。
- **稀有度**：传说（Legendary）
- **建议投放**：浮空城遗迹、星界育儿所、重力研究塔。

## 书籍内容

重力摇篮曲是一种通过哼唱改变局部重力频率，让目标陷入昏睡的技艺。本书从呼吸节奏开始，教导如何用低音引导重力下沉，用高音让重力松弛，最终形成一种让生物本能感到安全的波动。作者强调，摇篮曲不能被任何攻击性法术打断情绪，施法者必须 genuinely 希望目标入睡。书中记录了不同种族对摇篮曲的敏感度，体型越大的生物反而越容易受影响。第二章讨论如何在团队战中保护正在哼唱的法师，因为一旦被打断，反噬会让周围重力瞬间紊乱。最末一页写着：让敌人入睡不是仁慈，而是给战场一个喘息。练习者需要先在动物身上练习，确保不会导致永久昏迷。这门技艺在控场和争取时间方面极为强大。

重力摇篮曲对施法者自己也有轻微镇静效果，因此唱完后不宜立刻投入剧烈运动。

## 设计意图

为重力系法师提供范围控制技能，将音乐、重力与情绪主题融合。
