# 《辉光球笔记：照亮与误导》

## 基础信息

- **书籍 ID**：`book_法师咒术_0004`
- **关联技能**：`mage_luminous_orb`
- **使用效果**：阅读后解锁 `mage_luminous_orb`；若已学会，提升 `current_mastery +80`，并使下一次战斗中的辉光球持续时间延长 2 回合。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 6`。
- **稀有度**：普通（Common）
- **建议投放**：地下墓穴入口、照明公会任务奖励、旧货市场摊位。

## 书籍内容

发光是法师最容易掌握的咒语之一，也是最容易被低估的咒语。本书作者用了整整一章来论证：一个会移动的光源，在战棋地形中远比一支火把更有价值。它不仅能照亮黑暗，还能制造虚假的施法者位置，让敌人的远程攻击落空。前半部分教读者如何把魔力凝聚成稳定的球体，而不是一闪烁就灭的火星。

后半部分讲的是颜色和亮度控制。不同波长的光对某些异界生物有驱散效果，而突然的强光可以在近战中打断敌人的视线锁定。书中警告说，辉光球最忌讳"贪婪"，把亮度拉到最高只会让它变成一个昂贵的火把，还很容易暴露自己的位置。真正的高手会让光球保持一种"刚好能被看见"的微弱状态。

附录里还记录了几种特殊配方，比如加入微量萤火虫粉末可以让光球在夜间更难被察觉，而掺入一点盐晶则能让光芒变得刺眼。

## 设计意图

作为功能性辅助技能的解锁书籍，强调环境互动与战术欺骗在战棋中的价值，为探索玩法和团队配合提供工具，同时为光明系法术建立基础熟练度。
