# 《冰霜精灵的驯养日志》

## 基础信息

- **书籍 ID**：`book_法师咒术_0083`
- **关联技能**：`mage_frost_sprite`
- **使用效果**：阅读后解锁 `mage_frost_sprite`；若已学会，提升 `current_mastery +120` 并使冰霜精灵在场时提升施术者 `mp` 恢复速度。
- **阅读要求**：角色职业标签含 `mage` 或 `elementalist`；基础 `智力 ≥ 10` 且 `魅力 ≥ 8`。
- **稀有度**：稀有（Rare）
- **建议投放**：元素精灵庇护所、北境精灵村落、霜语者任务奖励。

## 书籍内容

冰霜精灵不是被召唤来的，而是被'请'来的。前半本是一份驯养日志，记录了作者与一只冰霜精灵从互相警惕到建立信任的全过程。书中指出，冰霜精灵最讨厌热的东西，包括施术者手心的汗水，所以施术前必须让双手冷却。

中段讲解沟通方式：冰霜精灵没有语言，但会对特定的旋律和节奏做出反应，作者在书中附了几段用符号表示的'霜语'。后半部警告：冰霜精灵很记仇，如果施术者曾经用火法术伤害过它，它会故意在关键时刻让法术偏斜。最后一页画着一只小小的冰晶生物，旁边写着'它帮你是礼物，不是义务。'

元素精灵庇护所的雪屋里常年放着一把为空精灵准备的小椅子，霜精灵偶尔会坐在上面，把椅背冻出一层薄冰。冰霜精灵喜欢停在施术者的左肩。左肩停驻让斗篷常湿。精灵有自己的喜好。
## 设计意图

稀有级召唤/辅助书籍，解锁冰霜精灵并为法师提供资源恢复与元素协同，强调精灵关系与元素协调。
