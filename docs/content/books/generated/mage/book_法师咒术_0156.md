# 《镜面记忆的拓印术》

## 基础信息

- **书籍 ID**：`book_法师咒术_0156`
- **关联技能**：`mage_mirror_memory`
- **使用效果**：阅读后解锁 `mage_mirror_memory`；若已学会，提升 `current_mastery +160` 并在下一次战斗中使首次复制的技能熟练度临时视为满级。
- **阅读要求**：角色职业标签含 `mage` 或 `mirrorsage`；基础 `智力 ≥ 17` 且 `意志 ≥ 14`。
- **稀有度**：史诗（Epic）
- **建议投放**：镜之迷宫、幻术师工坊、记忆商人货摊。

## 书籍内容

镜面记忆是一种将见过的法术临时封存于镜中的技艺。本书从选择镜面开始，讲解如何用月光净化银镜，再将自己的一段记忆作为粘合剂，把目标咒语拓印上去。作者指出，拓印的关键在于观察：必须在法术释放的完整过程中保持注视，任何一个眨眼都会导致记忆残缺。第二章介绍如何在不损伤原主的情况下复制法术，并警告某些被诅咒的咒语会在镜中留下痕迹。最末一页是一幅镜面维护图，批注写道：镜子记住的越多，就越不像你。练习者需要定期用盐水清洗镜面，否则镜中记忆会反过来影响施法者。这门技艺在战场上能让法师临时掌握敌人的拿手好戏，但也要求极高的精神控制力。

拓印完成后镜面需避光静置十二个时辰，让记忆与玻璃彻底融合。

最危险的拓印对象是那些会自我遗忘的法术，它们会在镜中留下空白，却悄悄改变施法者的记忆。

## 设计意图

为法师提供临时复制敌方或队友技能的灵活性，强化镜像与记忆主题。
