# 《咒术双股绳的编织》

## 基础信息

- **书籍 ID**：`book_法师咒术_0159`
- **关联技能**：`mage_spell_twine`
- **使用效果**：阅读后解锁 `mage_spell_twine`；若已学会，提升 `current_mastery +170` 并在下一次战斗中使首次双咒齐发时第二道法术消耗降低 30%。
- **阅读要求**：角色职业标签含 `mage` 或 `duelist`；基础 `智力 ≥ 18` 且 `意志 ≥ 14`。
- **稀有度**：史诗（Epic）
- **建议投放**：双塔学院、咒语编织工会、魔法竞技场。

## 书籍内容

咒术双股绳是一种将两道法术同时编织并释放的高阶技艺。本书从最简单的左手画圆右手画方开始，训练施法者的分念能力。作者将双咒分为互补型与对冲型：互补型如火与风可以互相增强，对冲型如冰与火则需要精确控制比例，否则会在施法者手中爆炸。书中详细记录了九种常见的双咒组合及其失败后果，其中雷与水组合最容易导致施法者自伤。最末一章讨论如何在战斗中维持两道咒语的节奏，就像同时拨动两根琴弦。批注写道：双股绳不是两只手各做一件事，而是一个意识同时看到两个方向。练习者需要先用低阶法术对练数百次，才能尝试将正式咒语编织成双股绳。

双咒齐发时两道咒语尾音会互相缠绕，形成独特的魔力共鸣声。

双咒编织到深处时，两道咒语会短暂地互相观察，许多法师正是在这种对视中领悟了更高的施法境界。

## 设计意图

为高阶法师提供双法术连携机制，强化资源转换与施法复杂度。
