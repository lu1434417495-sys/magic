# 《涡流门：乱序通道》

## 基础信息

- **书籍 ID**：`book_法师咒术_0235`
- **关联技能**：`mage_vortex_gate`
- **使用效果**：阅读后解锁 `mage_vortex_gate`；若已学会，提升 `current_mastery +160` 并在下一次战斗中使首次涡流门传送后周围敌人向门中心拉近一格。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 15` 且 `感知 ≥ 13`。
- **稀有度**：史诗（Epic）
- **建议投放**：位面交汇点、迷宫核心、虚空商人货舱。

## 书籍内容

涡流门是在两个位置之间打开的临时通道，但与普通传送不同，它会在开启时产生强烈吸力。书中警告，涡流门的另一端可能不是你想去的地方，因为空间褶皱会让坐标产生微小偏移。作者把施法要点总结为稳住门框：门框越稳定，吸力越可控。练习者需要先在短距离内反复开门，记录每次落点的偏差并修正。后半部讲解了如何把涡流门当作控制技能，将敌人吸入门中再丢到危险地形。最末页是一张画满漩涡的地图，上面所有地标都被标注为好玩的。许多法师在使用涡流门后会晕上好一阵，他们称之为空间的报复。书中还提醒，不要让体积过大的敌人一半在门内一半在门外，那会导致门框崩塌并产生危险的空间碎片。涡流门关闭后，被吸入的小物件有时会从数里外掉落，成为路人的惊喜。

## 设计意图

提供位移与控制的结合，让法师能主动调整敌我位置，增强战棋中的空间操控感。
