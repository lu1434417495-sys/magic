# 《风暴眼：雷云之心》

## 基础信息

- **书籍 ID**：`book_法师咒术_0219`
- **关联技能**：`mage_storm_eye`
- **使用效果**：阅读后解锁 `mage_storm_eye`；若已学会，提升 `current_mastery +170` 并在下一次战斗中使风暴眼持续期间自身雷系法术射程增加一格。
- **阅读要求**：角色职业标签含 `mage` 或 `stormcaller`；基础 `智力 ≥ 16` 且 `感知 ≥ 12`。
- **稀有度**：史诗（Epic）
- **建议投放**：风暴之眼祭坛、云海古龙巢穴、雷霆议会密室。

## 书籍内容

风暴眼是在施法者头顶形成的一小片旋转雷云，能持续引动天地间的电荷。书中第一页警告：不要试图控制风暴，你只能成为风暴愿意借力的那个人。作者把修炼过程分为听雷、引雷、化雷三步，每一步都需要在真实雷暴中完成。练习者最先学会的是如何让雷电绕过自己劈中敌人，然后才尝试主动召唤落雷。后半部讲解如何把风暴眼与连锁闪电、闪电罗网等技能组合，形成覆盖全场的电网。最末页只有一道被雷劈穿的痕迹，旁边写着：眼中无风，心中有雷。许多风暴法师的头发会因此术而永久竖起。书中还提到，风暴眼在干燥沙漠中威力会下降，而在水域附近则容易过度充盈，需要额外控制。风暴眼持续期间，法师的指尖会不断跃出细小电弧，点烟颇为方便。但这也导致风暴法师在精密操作时容易误触金属物品。

## 设计意图

作为雷系核心增益技能，提升法师的射程与压制范围，鼓励玩家构建纯电击流派。
