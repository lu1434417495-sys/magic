# 《烈焰符文：把愤怒刻进地面》

## 基础信息

- **书籍 ID**：`book_法师咒术_0042`
- **关联技能**：`mage_blaze_rune`
- **使用效果**：阅读后解锁 `mage_blaze_rune`；若已学会，提升 `current_mastery +100`，并在下一次战斗中使烈焰符文触发时额外点燃周围 1 格区域。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 10`。
- **稀有度**：普通（Common）
- **建议投放**：火焰祭坛、古代符文工坊、战争法师训练营。

## 书籍内容

烈焰符文是一种预先在地上绘制火焰符文，等待敌人踏入后触发爆炸的陷阱咒术。这本书的作者是一位曾经参与过城墙防御战的法师，他认为最优雅的战斗不是面对面的厮杀，而是让敌人自己走进你的布置。前半部分讲解符文的绘制方法，包括三个必须封闭的火焰回路和一个作为触发点的开放纹路。

后半部分讨论实战布置：把烈焰符文画在敌人冲刺的直线上，或者伪装成地面上的焦痕。书中提到，这个咒语对木质地形有额外加成，有可能引发连锁火灾；但在潮湿环境中则需要更长的充能时间。最后附有一张城墙防御战的草图，显示某段通道被十几道烈焰符文覆盖，形成了一条死亡走廊。

作者特别提到，烈焰符文的触发敏感度可以调节，设置得太灵敏会被小动物或风吹草动浪费，太迟钝则可能错过最佳引爆时机。

## 设计意图

为法师系提供早期火焰陷阱技能，强化战棋中的区域控制与预判战术，同时为后续符文系、火焰场地类法术建立熟练度与叙事基础。
