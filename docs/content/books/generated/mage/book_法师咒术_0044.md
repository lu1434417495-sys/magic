# 《水晶种：种下一颗会生长的弹药》

## 基础信息

- **书籍 ID**：`book_法师咒术_0044`
- **关联技能**：`mage_crystal_seed`
- **使用效果**：阅读后解锁 `mage_crystal_seed`；若已学会，提升 `current_mastery +100`，并在下一次战斗中使水晶种成熟后的首次射击额外穿透 1 个目标。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 10`。
- **稀有度**：普通（Common）
- **建议投放**：水晶矿洞、宝石工匠作坊、元素富集区遗迹。

## 书籍内容

水晶种是一种把魔力结晶化成种子形态，植入地面或物体后等待它吸收周围魔力生长成熟的咒术。成熟后的水晶可以被施术者引爆或当作投射物使用。这本书的作者把它比作钓鱼：你需要先选一个有魔力流动的地方下种，然后耐心等待。

前半部分讲解如何判断一个地点的魔力浓度是否足够支持水晶生长，以及如何避免水晶因为过度生长而提前碎裂。后半部分讨论战术应用：在防守战中提前布置水晶种，形成交叉火力；在进攻战中则可以把水晶种当作延迟触发的地雷。书中警告，水晶种对附近的其他魔力源会产生反应，如果种在己方法师身边，可能会干扰队友施法。最后一页是一幅水晶生长周期的插画，从一粒沙子到一根尖锐的水晶柱。

书中强调收割水晶种的时机至关重要，太早则水晶脆弱易碎，太晚则魔力过度饱和可能引发不必要的爆裂。

## 设计意图

为法师系提供早期延迟部署与资源管理技能，强化战棋中的预设战术与地形利用，同时为后续晶体系、召唤造物类法术建立熟练度基础。
