# 《霜息：从呼吸开始结冰》

## 基础信息

- **书籍 ID**：`book_法师咒术_0023`
- **关联技能**：`mage_rime_breath`
- **使用效果**：阅读后解锁 `mage_rime_breath`；若已学会，提升 `current_mastery +80`，并在下一次战斗中使霜息的锥形范围扩大 1 格。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 6`。
- **稀有度**：普通（Common）
- **建议投放**：雪山训练场、冰元素祭坛、北方边境哨站。

## 书籍内容

霜息是冰系魔法最原始的形态之一：施术者深吸一口气，让魔力在喉咙里冷却到接近冰点，然后呼出一片覆盖前方区域的冰冷雾气。这本书的作者是一个说话带着浓重鼻音的老法师，他坚持认为霜息的威力取决于施术者能否忍受那种从内部传来的寒意。

前半部分教授呼吸节奏，要求吸气时让魔力流经舌底，呼气时把它压缩成扇形。后半部分讲解实战中的距离控制：太近会冻伤自己的嘴唇，太远则会变成无害的白雾。书中还记录了霜息在不同湿度环境下的表现，干燥空气中它更像一阵冷风，潮湿空气中则能迅速结出霜花。最后一页画着一只被冻住的蜘蛛，八条腿都保持着奔跑的姿态。

作者提醒，频繁使用霜息会让喉咙长期感到冰凉，有经验的法师会在练习后喝一杯温热的草药茶来保护声带。

## 设计意图

为法师系提供早期冰霜范围技能，强化战棋中的群体控制与元素伤害能力，同时作为冰系法术入门，为后续霜冻、冰锥与暴风雪类法术建立熟练度链条。
