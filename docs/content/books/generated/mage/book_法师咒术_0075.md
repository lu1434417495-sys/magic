# 《魔法护盾的边界感》

## 基础信息

- **书籍 ID**：`book_法师咒术_0075`
- **关联技能**：`mage_magic_shield`
- **使用效果**：阅读后解锁 `mage_magic_shield`；若已学会，提升 `current_mastery +100` 并提升护盾吸收量 `+10%`。
- **阅读要求**：角色职业标签含 `mage` 或 `abjurer`；基础 `智力 ≥ 9`。
- **稀有度**：普通（Common）
- **建议投放**：魔法学院防护课堂、冒险者公会基础教材、遗迹宝箱。

## 书籍内容

魔法护盾不是把自己包在蛋壳里，而是画一条清晰的边界。前半本讲解护盾的几何形状：球形最省魔力但遮挡视线，平面形最稳定但只能防御一个方向，不规则形最灵活但消耗最大。作者建议新手从'半圆顶'开始练习，因为它在保护头部和躯干的同时不影响观察。

书中强调，护盾最重要的不是硬度，而是'边界感'——施术者必须时刻知道护盾在哪里结束，否则会在自以为受保护的位置被击中。后半部收录了常见错误：把护盾贴得太近会限制移动，贴得太远则会让敌人走进护盾内部。

魔法学院的防护课堂有一个传统，第一节课的内容不是如何张开护盾，而是如何在被护盾困住时平静地等待救援。魔法护盾的考试失败者常被调侃为"蛋壳法师"。蛋壳法师绰号令人尴尬。蛋壳并不总是脆弱。蛋壳里也有世界。
## 设计意图

普通级防护书籍，解锁魔法护盾并为法师提供基础生存手段，强调边界意识与形状选择。
