# 《夜绽：只在黑暗中开放的花》

## 基础信息

- **书籍 ID**：`book_法师咒术_0038`
- **关联技能**：`mage_night_bloom`
- **使用效果**：阅读后解锁 `mage_night_bloom`；若已学会，提升 `current_mastery +90`，并在下一次战斗中使夜绽在夜间释放时额外恢复 5 点魔力。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：夜花园温室、月见草研究站、暗夜精灵遗迹。

## 书籍内容

夜绽是一种在黑暗中召唤出临时魔力花朵的咒术，这些花朵会散发出微弱的治愈能量，缓慢恢复周围友方的生命和魔力。这本书的作者用诗意的笔调写道：最美的花不需要阳光，只需要有人愿意在夜里守护它。前半部分讲解如何让魔力按照花瓣的层次一层层展开，而不是一次性炸开。

后半部分讨论战术布置：在防守战中提前种下夜绽，可以为队伍提供持续的恢复支援；在移动战中则需要把花朵种在敌人难以触及的角落。书中警告，夜绽的光芒虽然微弱，但在完全黑暗的环境中仍然足以暴露位置。最后一页是一幅手绘的夜绽图，花瓣是半透明的紫色，花蕊里似乎藏着一小片星空。

作者提到，夜绽在开放时会释放一种淡淡的甜香，这种香气能够安抚紧张情绪，但也会吸引某些以花蜜为食的异界昆虫。

## 设计意图

为法师系提供早期持续恢复与阵地支援技能，强化团队在持久战中的续航能力，同时为后续自然系、星光系与场地恢复类法术建立熟练度连接。
