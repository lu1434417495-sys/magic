# 《镜尘：把敌人照进碎片里》

## 基础信息

- **书籍 ID**：`book_法师咒术_0037`
- **关联技能**：`mage_mirror_dust`
- **使用效果**：阅读后解锁 `mage_mirror_dust`；若已学会，提升 `current_mastery +90`，并在下一次战斗中使镜尘复制的幻象额外承受一次攻击。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：镜子工匠作坊、幻术师协会、古堡废墟化妆间。

## 书籍内容

镜尘是一种把破碎镜片的反光凝聚成魔力粉尘后撒向敌人的幻术咒术，它能在原地制造出一个施术者的短暂幻象。这本书的作者是一位曾经靠卖镜子为生的法师，他认为每一块镜子都记得曾经照过的人。前半部分教读者如何收集镜片碎屑，并把自己的一小段影像"借"给它们。

后半部分讲解战斗中的欺骗用法：在敌人锁定你的瞬间释放镜尘，让攻击落向幻象，自己则趁机转移位置。书中警告，镜尘制造的幻象不能移动，也不能攻击，只能站在那里迷惑敌人。最后附有一张破碎的镜子照片，镜子里隐约能看见一个不属于拍摄者的人影。

作者强调，制造镜尘的镜片必须来自被月光照射过的镜子，普通橱窗玻璃的碎片无法承载足够清晰的影像，幻象会一闪即逝。熟练的幻术师会在镜尘中加入自己的一丝气息，让幻象闻起来也像是真实存在的人。

## 设计意图

为法师系提供早期幻术防御技能，强化战棋中的目标欺骗与生存能力，同时为后续镜像分身、幻影大军类高级幻术建立熟练度与叙事基础。
