# 《回声密室的建筑学》

## 基础信息

- **书籍 ID**：`book_法师咒术_0164`
- **关联技能**：`mage_echo_chamber`
- **使用效果**：阅读后解锁 `mage_echo_chamber`；若已学会，提升 `current_mastery +160` 并在下一次战斗中使回声密室内首个法术额外触发一次 50% 效果。
- **阅读要求**：角色职业标签含 `mage` 或 `acoustimancer`；基础 `智力 ≥ 17` 且 `感知 ≥ 15`。
- **稀有度**：史诗（Epic）
- **建议投放**：地下音乐厅、古老剧院、声波实验室。

## 书籍内容

回声密室不是普通的房间，而是用特定角度和材料构建的魔力共鸣空间。本书从建筑学角度讲解如何设计墙面弧度、地面材质与天花板高度，使得咒语在其中产生多重回声。作者强调，密室的大小决定了回声的延迟：太小的空间会让咒语互相抵消，太大的空间则会让回声散失。书中记录了七种经典密室布局，每种都对应不同的战术用途。第二章讨论如何携带便携式密室组件，包括可折叠的吸音板和微型共鸣水晶。最末一页写着：回声不是重复，而是让你的咒语多活一次。练习者需要在密室中反复念咒，直到能凭声音判断回声的强度。这门技艺在固定阵地战中能让单个法术发挥出数倍效果。

熟练的筑室者能在数息间用折叠组件搭起临时密室，适应突发遭遇战。

某些古老剧院的地基中天然存在回声密室，先辈法师认为那是建筑者无意中拨动了世界的琴弦。

## 设计意图

为法师提供阵地强化技能，通过建筑与声学概念扩展魔法战斗场景。
