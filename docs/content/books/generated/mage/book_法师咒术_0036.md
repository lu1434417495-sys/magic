# 《雷种：把闪电埋进地面》

## 基础信息

- **书籍 ID**：`book_法师咒术_0036`
- **关联技能**：`mage_thunder_seed`
- **使用效果**：阅读后解锁 `mage_thunder_seed`；若已学会，提升 `current_mastery +90`，并在下一次战斗中使雷种引爆时的范围扩大 1 格。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：雷暴高原、电工法师工坊、战场布雷兵营房。

## 书籍内容

雷种是一种把微弱电芒凝聚成种子形状，然后埋入地面的延迟性陷阱咒术。当敌人踩中触发点时，埋下的雷种会瞬间爆裂，释放出足以麻痹腿部的电流。这本书的作者喜欢把雷种比作脾气的积累：平时看不见，一旦被踩到就会发作。

前半部分讲解如何把狂暴的电流压缩成稳定的种子形态，以及如何选择不会提前放电的地面材质。后半部分讨论布雷战术：把雷种布置在草丛、水洼或金属门把手上，可以显著提升触发概率。书中警告，雷种在干燥沙地上的效果会大打折扣，而在积水中则容易误伤友军。最后一页是一张手绘的布雷图，显示某位法师如何在一条小路上间隔埋设了九颗雷种。

书中还介绍了如何隐藏雷种的魔力波动，让敌人即使踩上去也感觉不到异常，直到电流窜入他们的小腿。

## 设计意图

为法师系提供早期雷电陷阱技能，强化战棋中的预判与区域控制玩法，同时为后续连锁闪电、雷电场地类法术建立"电荷积累"的基础熟练度概念。
