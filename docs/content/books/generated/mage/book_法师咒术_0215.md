# 《月刃轮：银弧裁决》

## 基础信息

- **书籍 ID**：`book_法师咒术_0215`
- **关联技能**：`mage_moon_blade`
- **使用效果**：阅读后解锁 `mage_moon_blade`；若已学会，提升 `current_mastery +150` 并在下一次战斗中使首道月刃轮在命中后分裂为两道较小弧光。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 13` 且 `感知 ≥ 11`。
- **稀有度**：稀有（Rare）
- **建议投放**：月影神庙、夜行生物巢穴、观星台藏书阁。

## 书籍内容

月刃轮是把月光凝聚成锋利弧线后投掷出去的法术，在满月之夜会自动追踪目标。书中记载，最早的月刃轮是月神祭司用来修剪圣树的工具，后来被战斗法师改良为武器。作者强调，月刃的威力取决于施法者内心的平静，愤怒会让弧光变得不稳定。练习者需要在月光下反复投掷银盘，直到能在盘飞出后仍感知其轨迹。后半部讲解了如何在月刃中藏入第二段咒语，让它在命中后分裂散射。最末页是一段用银粉写的批注：月亮从不主动伤人，但它照亮的刀锋会。许多夜行法师只在满月时研习此书，因为他们相信缺月的月刃会反噬自己。书中还警告，月刃在穿过水体时会折射偏转，因此雨天或湿地使用时需要预留更复杂的弹道。月刃轮的弧线之美让许多法师在战斗结束后仍会凝视夜空良久。

## 设计意图

提供中距离穿透与分裂输出，让法师在夜间或特定环境中拥有独特优势，丰富战斗节奏。
