# 《星账本的借贷规则》

## 基础信息

- **书籍 ID**：`book_法师咒术_0191`
- **关联技能**：`mage_star_ledger`
- **使用效果**：阅读后解锁 `mage_star_ledger`；若已学会，提升 `current_mastery +180` 并在下一次战斗中使星账借贷首次生效时提前支取下回合 50% MP 供本回合使用。
- **阅读要求**：角色职业标签含 `mage` 或 `astromancer`；基础 `智力 ≥ 19` 且 `感知 ≥ 15`。
- **稀有度**：传说（Legendary）
- **建议投放**：星界银行、观星阁金库、古代占星术士遗产。

## 书籍内容

星账本是一种向未来星辰魔力借贷的契约系统，允许施法者在当下获得额外的法力，但必须在未来偿还。本书从借贷规则开始，讲解如何计算利率、期限以及违约后果。作者强调，借贷不是免费的力量，每一笔透支都会在下个周期的某个时刻被收回。书中记录了不同星象下的借贷条件：满月时利率最低，流星雨期间额度最高，而日食则是严格禁止借贷的时段。第二章讨论如何在战斗中合理使用预支魔力，作者建议在决定胜负的关键一击时使用，而不是用于普通攻击。最末一页写着：星辰借给你的，从来不是免费礼物。练习者需要先签署一份小额契约，体验偿还过程。这门技艺让法师能在绝境中爆发出额外一轮的施法能力。

违约者的魔力账户会被标记，在一段时间内无法向任何星辰借贷。

## 设计意图

为星象法师提供资源预支机制，将经济概念与魔力管理结合。
