# 《灵体之手：第三只腕》

## 基础信息

- **书籍 ID**：`book_法师咒术_0206`
- **关联技能**：`mage_spectral_hand`
- **使用效果**：阅读后解锁 `mage_spectral_hand`；若已学会，提升 `current_mastery +140` 并在下一次战斗中使灵体之手首回合射程增加一格。
- **阅读要求**：角色职业标签含 `mage` 或 `necromancer`；基础 `智力 ≥ 11` 且 `感知 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：亡灵法师塔、古墓藏书室、灵魂集市。

## 书籍内容

灵体之手是一只由施法者意志塑形的半透明手掌，能穿过实体障碍取物或触碰敌人。书中第一节要求练习者先用这只无形之手翻动书页，直到能像自己的真手一样感知纸张的纹理。作者指出，灵体之手的力量取决于专注度，分心时它会像烟雾一样散开。后半部分列举了多种战术用法：从敌人腰包里偷取卷轴、在战斗中按动远处的机关、或者穿过盾牌直接扼住敌人的喉咙。最末章警告，灵体之手若长时间离开身体，可能会带回一些不属于自己的记忆。书页边缘有一位前任读者的批注：千万别用它挠自己的背，你会忘记背在哪里。许多亡灵法师把它当作最贴心的实验助手。进阶技巧提到，将灵体之手浸入圣水中可短暂凝实，使其能握住普通武器参与近战。一些亡灵法师会让灵体之手代替自己翻书，从而腾出真手来品尝下午茶。

## 设计意图

让法师获得中距离交互与控制能力，扩展战棋场景中的操作维度，丰富非直接伤害玩法。
