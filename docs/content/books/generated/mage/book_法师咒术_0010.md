# 《回声低语：听见的不是声音》

## 基础信息

- **书籍 ID**：`book_法师咒术_0010`
- **关联技能**：`mage_echo_whisper`
- **使用效果**：阅读后解锁 `mage_echo_whisper`；若已学会，提升 `current_mastery +90`，并在下一次战斗中使回声低语传递的信息不会被敌方侦测。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：间谍据点密档、法师塔传讯室、地下情报商人处。

## 书籍内容

这本书没有普通纸张，全部写在一种会轻微震动的皮膜上。回声低语允许施术者把一句话送入特定目标的耳中，而周围的人什么都听不到。作者强调，这不是声音的传播，而是直接把震动图案印在对方的鼓膜上，因此不会被风声、噪音或隔音墙阻挡。

前半部分教读者如何"听见"自己的声音在空房间里的回声，然后把回声抓回来重新发送。后半部分涉及保密与反侦察：如何在 whisper 中加入只有接收者能解开的魔力指纹，以及如何识别伪造的回声信息。书末警告说，长时间用回声低语窃听他人会让自己开始分不清哪些想法是自己的，哪些是被别人 whisper 进来的。

书中收录了多个历史上著名的情报失误案例，说明即使是再精巧的传讯法术，一旦接收者被替换或催眠，整条信息链都会变成致命的陷阱。

## 设计意图

为法师系提供早期通讯与情报技能，强化团队配合与战术信息传递，同时为后续心灵链接、魅惑、沉默破解等高级精神法术提供叙事与技术铺垫。
