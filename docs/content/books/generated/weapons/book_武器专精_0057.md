# 《剑柄敲颚：非致命终结》

## 基础信息

- **书籍 ID**：`book_武器专精_0057`
- **关联技能**：`warrior_pommel_strike`
- **使用效果**：阅读后解锁 `warrior_pommel_strike`（待新增，标签 `sword`）；若已学会，提升该技能 `current_mastery +110`。
- **阅读要求**：已装备剑类武器；基础 `感知 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：治安队据点、佣兵诊所、地下拳场。

## 书籍内容

不是每场战斗都需要见血。这本书专门讲如何用剑柄末端解决敌人：在敌人贴身、剑刃没有挥动空间时，反手一转，用剑柄敲击下颌、太阳穴或鼻梁。作者指出，这个动作成功的关键在于握法转换：必须在零点几秒内从正握变为反握，同时用另一只手推压剑身稳定方向。书中列举了三种不适合用刃的场合：狭窄走廊、被抱住腰、敌人戴着过厚的头盔。每一种情况都配有简笔画，小人用剑柄敲向敌人面甲的缝隙。作者在最后写道：剑客总以为锋利才是答案，但有时候，钝的那一端更懂分寸。

作者提醒，剑柄敲颚最忌用力过猛：下颌骨碎裂后碎片可能刺入舌头，那会让一个本想活捉的目标变成尸体。书中列有三种不同盔型的敲击角度，专门供治安队在夜间巡逻使用。

书角有人用针刺了几个小孔，排列成一张人脸的轮廓。

## 设计意图

为剑士提供近距离控制与制服手段，扩展武器在不同空间下的战术选择。
