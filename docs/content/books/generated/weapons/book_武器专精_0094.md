# 《寸拳：短距爆发》

## 基础信息

- **书籍 ID**：`book_武器专精_0094`
- **关联技能**：`warrior_one_inch_advantage`
- **使用效果**：阅读后解锁 `warrior_one_inch_advantage`；若已学会，提升该技能 `current_mastery +120`。
- **阅读要求**：未装备武器或装备拳套；基础 `力量 ≥ 8`、`敏捷 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：东方拳馆、地牢拳手、秘密比武会。

## 书籍内容

寸拳的威力来自极短距离内的爆发。这本书的核心观点是：拳头不需要拉回再打出，只要肘部还有一寸空间，就能发出足以击倒人的力量。作者把发力分解为三个阶段：脚跟蹬地、腰胯旋转、肩臂前送，三个阶段必须在同一瞬间完成。书中要求练习者把拳头贴在木板上，然后不用后退直接发力，直到木板出现凹痕。后半本讨论实战应用：寸拳最适合在敌人抓住你或贴近你时使用，因为它不需要空间，只需要结构正确。作者提醒，错误的寸拳会伤到自己的手腕和肩膀。末页写着：最短的距离不是零，而是那一寸里藏着的整座山。

东方拳馆的墙上贴着一张旧规则：凡学寸拳者，须先能在一寸距离内打断一块薄木板，且手腕不红不肿。红肿者，说明力量散在了自己身上。馆主在规则下加了一句：木板会原谅你，敌人不会。

## 设计意图

为徒手战士提供贴身爆发技，把距离劣势转化为在极近范围内依然有效的打击手段。
