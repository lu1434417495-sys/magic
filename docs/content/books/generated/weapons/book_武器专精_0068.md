# 《战斧下劈：劈山势》

## 基础信息

- **书籍 ID**：`book_武器专精_0068`
- **关联技能**：`warrior_axe_chop`
- **使用效果**：阅读后解锁 `warrior_axe_chop`（待新增，标签 `axe`）；若已学会，提升该技能 `current_mastery +110`。
- **阅读要求**：已装备斧类武器；基础 `力量 ≥ 9`。
- **稀有度**：普通（Common）
- **建议投放**：狂战士训练场、矿山深处、强盗巢穴。

## 书籍内容

战斧下劈的力量来源不是手臂，而是身体像斧头一样整体落下。作者要求练习者先在木桩上练习不握斧：双手虚握，让身体前倾带动手臂落下，感受重力如何把力量聚到指尖。真正握斧时，斧头只是这个重力的放大器。书中警告，下劈最危险的是劈中后斧头被卡住，所以必须学会在接触瞬间松一点握力，让斧头的惯性自己完成切割。后半本讨论如何选择落点：盾牌的上沿、头盔的顶部、肩膀与脖子的交接处都是容易让敌人失衡的位置。末页画着一座被劈开的山，山下站着一个小小的人影，配文：山不是被劈倒的，是被自己的重量分开的。

作者警告，劈山势不可在松软地面上使用，因为斧头入土太深会拔不出来。最理想的落点是石板与泥土交界处，既能砸裂石板，又不会卡住斧刃。他还画了一个打叉的沼泽图案。

## 设计意图

为斧类武器提供高爆发单体伤害技，强调重力利用与破盾/破甲的垂直打击。
