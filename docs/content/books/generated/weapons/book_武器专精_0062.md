# 《枪出如龙：突刺线》

## 书籍内容

突刺线是一条虚构的直线，从枪尖出发，穿过敌人的防御重心，直达身后的某一点。这本书的核心论点是：枪兵不该瞄准敌人，而该瞄准敌人身后的位置。前半本讲解如何利用腰部推进代替手臂前伸，这样刺击的距离会突然增加半臂，常常超出敌人的预判。书中还强调收枪要快，因为枪在刺出后是最脆弱的，必须借助回拉的力量立刻回到中平架势。后半本讨论如何在密集阵型中使用突刺线而不误伤同伴：每一枪的落点都必须略高于前一枪的落点，形成错落有致的穿刺节奏。末页有一句话被老兵们反复引用：龙不是飞过去的，龙是从你胸口穿过去的。

作者画了一条贯穿全页的直线，线上标着七个点，代表突刺时身体重心应该经过的位置。线尾写着：龙之所以像龙，是因为它没有多余的动作。多余的动作会告诉敌人你的枪往哪去。

## 设计意图

为长柄武器提供标准突刺技能，强调直线穿透与收枪节奏，区别于剑的弧线斩击。
