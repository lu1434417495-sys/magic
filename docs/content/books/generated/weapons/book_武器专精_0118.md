# 《链枷乱舞控距法》

## 基础信息

- **书籍 ID**：`book_武器专精_0118`
- **关联技能**：`weapon_flail_distance`
- **使用效果**：阅读后解锁 `weapon_flail_distance`；若已学会，提升 `current_mastery +130`，并扩大链枷有效攻击半径约 5%（一次性战斗增益）。
- **阅读要求**：职业标签含 `warrior` 或 `berserker`；基础 `力量 ≥ 10`。
- **稀有度**：精良（Uncommon）
- **建议投放**：边境乱军营地、强盗王藏宝库、竞技场连胜奖励。

## 书籍内容

链枷是武器中最难预测的那个，连使用者自己也不例外。这本书的核心建议是：不要试图控制链枷的落点，要控制链枷的距离。通过改变挥动的半径和速度，你可以让链枷在敌人认为安全的距离上突然伸长。作者把链枷的轨迹分为三个阶段：蓄转、外摆、回弹，并指出真正致命的往往是回弹阶段，因为大多数人只防外摆。书中还提醒：在狭窄空间使用链枷等同于自杀，链头会反弹到自己或队友身上。附录是一页治疗记录，列着作者练习时被自己打伤的七次经历，最后总结："链枷不尊重距离，但尊重练习距离的人。"狂战士喜欢用链枷配合怒吼，因为敌人后退时最容易被链头追上。但作者提醒：怒吼会暴露位置，真正的链枷高手更擅长在沉默中挥出致命一击。沉默中的链枷更难被预判，这才是它最可怕的地方。

## 设计意图

把链枷的魅力建立在不可预测的距离控制上，半径奖励强化其独特手感。
