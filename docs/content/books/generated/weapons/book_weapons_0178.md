# 《钉头锤尖刺控制：钝器中的针》

## 基础信息

- **书籍 ID**：`book_weapons_0178`
- **关联技能**：`warrior_morning_star_puncture`, `warrior_spiked_mace`
- **使用效果**：阅读后解锁 `warrior_morning_star_puncture`；若已学会，提升该技能 `current_mastery +110`，并令钉头锤攻击有 `15%` 概率附加流血。
- **阅读要求**：角色职业标签含 `warrior`、`cleric` 或 `berserker`；基础 `力量 ≥ 11`。
- **稀有度**：精良（Uncommon）
- **建议投放**：教会武备库、审判所地下牢、山贼头目宝箱。

## 书籍内容

钉头锤是钝器与锐器的混血儿，它的尖刺能在撞击甲片时找到缝隙钻进去。作者认为，使用钉头锤不能只追求砸中，而要追求"刺入后还带着重量拖拽"——这需要让锤头在触甲时有足够的旋转。书中详细讲解了三种挥法：直落、斜劈与反手撩，每一种都会让尖刺以不同角度咬住甲面。后半部分讨论连锁甲克星：钉头锤对付锁子甲的效果优于板甲，因为尖刺会卡在环扣之间，把整片甲扯变形。作者提醒读者，尖刺一旦卡住就很难快速收回，因此每一次挥击都要想好下一击的位置。书末附有一份教会审判记录，记载着被钉头锤处决的异端名单，数量多到让纸张发脆。作者建议用不同材质的人偶反复练习，直到尖刺能准确穿过甲缝而不被卡住。 末页提醒读者，钝器真正的杀伤力不仅来自落点，更来自命中后的震荡传递。

## 设计意图

为钝器战士提供流血型分支，强化对轻甲/锁甲敌人的针对性与持续伤害。
