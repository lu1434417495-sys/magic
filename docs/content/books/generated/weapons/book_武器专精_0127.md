# 《太刀拔刀式》

## 基础信息

- **书籍 ID**：`book_武器专精_0127`
- **关联技能**：`weapon_katana_draw`
- **使用效果**：阅读后解锁 `weapon_katana_draw`（待新增）；若已学会，提升 `current_mastery +150`，并提升首次拔刀攻击的出手速度 5%（一次性战斗增益）。
- **阅读要求**：职业标签含 `warrior` 或 `rogue`；基础 `敏捷 ≥ 11`、感知 `≥ 9`。

- **建议投放**：东方使节船舱、剑圣遗迹、异界裂隙宝箱。

## 书籍内容

拔刀术的核心不是快，而是让敌人看不见你拔刀。这本书从坐姿、站姿、步法讲起，每一种姿态都对应不同的出刀弧线。作者强调：刀在鞘中时是最安全的，也是最危险的，因为没有人知道它什么时候会出现。拔刀的一瞬间，左手的推鞘和右手的拉刀必须同时完成，任何不同步都会把拔刀变成拔木。书中还讨论了呼吸：吸气时蓄意，呼气时出刀，刀刃离开鞘口的刹那恰好是呼气最平稳的那段。最后几页是一组连续动作图，被裁成狭长的纸条，翻页时会产生刀光一闪的错觉。末页写道："最快的刀，是在敌人眨眼之间已经完成。"太刀拔刀式在灰烬交界被改良为适合狭窄空间的半身拔刀，许多东洋流亡者靠这一招在裂隙中求生。书的附录中有几页是用异界文字写成的。那些异界文字无人能译，却被认为蕴含着更高深的拔刀真意。

## 设计意图

作为高稀有度武器书，提供爆发性拔刀体验，出手速度奖励强化先制打击。
