# 《断刃第一课：握柄如握手》

## 基础信息

- **书籍 ID**：`book_武器专精_0101`
- **关联技能**：`weapon_sword_grip_basic`
- **使用效果**：阅读后解锁 `weapon_sword_grip_basic`；若已学会，提升该技能 `current_mastery +100`，并在下一次战斗中使首次直剑攻击的耐力消耗降低 1 点。
- **阅读要求**：无职业限制；基础 `力量 ≥ 6` 或 `敏捷 ≥ 6`。
- **稀有度**：普通（Common）
- **建议投放**：断刃营地铁匠铺、新兵训练任务、通用战技商人。

## 书籍内容

这本书的扉页被刀剑割破，作者用一句话开场："握柄不是握住敌人，而是握住自己的重心。"正文把剑柄分为三段：近镡为控、中段为稳、尾端为放。多数人握得太紧，导致挥砍后半段僵硬，反而失去变招空间。书中要求练习者空手模拟三百次抓握，直到手掌能在不捏死柄的情况下传递全部力量。第二章讲腕角：剑尖指向决定了出招角度，而腕角只应微调，不应代替肩腰发力。最后几页夹着手绘的人体简图，标注了五种最常被新手忽略的破绽，每张图下都写着同一句话："先活下来，再谈招式。"许多新兵在练习到第三日掌心起泡时便放弃，而作者留下的批注是：水泡是手与柄正在互相承认。在灰烬交界，握不住武器的人通常也握不住自己的命。在灰烬交界，这种握力训练常被当作新人能否继续前行的第一道门槛。

## 设计意图

作为武器专精系列的开篇，用最低门槛建立"武器是身体的延伸"这一核心体感。
