# 《骑枪冲刺笔记》

## 基础信息

- **书籍 ID**：`book_武器专精_0014`
- **关联技能**：`weapon_lance_charge`、`mounted_combat`
- **使用效果**：阅读后获得 `weapon_lance_charge` 解锁机会；若已学会，提升 `current_mastery +140`，并在骑乘状态下首次冲锋时获得 `+15%` 伤害加成。
- **阅读要求**：具备骑乘能力或职业标签含 `knight`；基础 `力量 ≥ 12`、`体质 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：骑士团军械库、马场传承任务、贵族坐骑商店。

## 书籍内容

骑枪是人与坐骑共同完成的一次攻击。作者指出，骑枪冲刺最大的误区在于骑手试图用双臂发力；真正决定冲击力的是马的速度、枪杆与马背的夹角，以及骑手能否在马背上保持稳定。书中把夹角分为「高角刺盔」与「低角破胸」两种，并详细说明不同对手应选择的切入角度。作者还强调，骑枪一旦刺中目标就必须立刻松开或回抽，否则枪杆会被巨大的反作用力折断，连人带马失去平衡。后半本记录了数种常见坐骑在冲刺时的节奏差异：重型战马需要更长的加速距离，而轻型坐骑虽然冲击弱但转向灵活。最后一页被泥土弄脏，只能看清一行字：「枪尖触敌之前，先让马相信你。笔记里夹着一根断裂的木制枪尖，旁边注明「第一次冲锋练习用」，木尖上残留的凹痕显示它至少击中过三十个目标。

## 设计意图

服务于骑士/骑乘战斗体系，把骑枪设计成高爆发、高风险、需要坐骑配合的专属武器技能。
