# 《投石索隐藏杀机》

## 基础信息

- **书籍 ID**：`book_武器专精_0036`
- **关联技能**：`weapon_sling_trick`、`ranged_sling_shot`
- **使用效果**：阅读后解锁 `weapon_sling_trick`；若已学会，提升 `current_mastery +90`，并提高投石索对头部命中时的眩晕触发率 `+10%。
- **阅读要求**：无职业限制；基础 `敏捷 ≥ 7`。
- **稀有度**：普通（Common）
- **建议投放**：乡村集市、牧羊人任务、普通商人货架。

## 书籍内容

投石索是被贵族嘲笑的武器，却曾在无数次起义中证明过自己。作者用朴素的语言讲解了投石索的构造：两根皮绳、一块皮囊、一颗合适的石子，组合起来就能产生惊人的速度。书中最重要的技巧是「旋放」：不是用力把石子甩出去，而是通过稳定的旋转积累速度，在最高点或前点自然释放。作者还提醒，石子的形状与重量比大小更重要——光滑圆润的石子飞行稳定，不规则的石子则会在空中翻滚，难以预测。后半本收录了多种隐蔽携带投石索的方法：缠在腰间、藏在袖中、伪装成腰带。最后一页是一句带有乡土气息的忠告：「别小看石头，贵族的脑袋不比羊头硬多少。一位牧羊女在页边补充，她曾在叛军攻城时用投石索击中敌方旗手的面甲，那块石头是她最心爱的一只羊蹄形状。 末尾以表格列出不同重量投掷物的最佳出手角度与距离换算，供读者反复揣摩。

## 设计意图

为平民出身或非传统战斗职业提供低成本远程手段，强化「以弱胜强」的叙事与早期探索乐趣。
