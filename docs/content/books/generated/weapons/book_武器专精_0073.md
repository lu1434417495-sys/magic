# 《战锤举顶：迎头一击》

## 基础信息

- **书籍 ID**：`book_武器专精_0073`
- **关联技能**：`warrior_hammer_overhead`
- **使用效果**：阅读后解锁 `warrior_hammer_overhead`（待新增，标签 `hammer`）；若已学会，提升该技能 `current_mastery +110`。

## 书籍内容

把战锤举过头顶是一种宣告：我要用全身的力量砸向你。这个动作的威慑力本身就能让敌人迟疑半拍。作者详细讲解举顶姿势：双脚分开超过肩宽，锤柄贴近后脑，眼睛从锤柄上方盯住目标的头顶或肩膀。下砸时不是用手臂拉，而是让背部和臀部同时发力，像关门一样把锤头甩下去。书中警告，举顶最大的风险是被敌人贴近，所以必须配合队友控制距离，或者先用盾或脚踢逼退对方。后半本讨论头盔对迎头一击的影响：大多数头盔能分散锋刃，却无法分散垂直下砸的冲击力，所以这一击常常让敌人头晕目眩。末页写着：举高不是为了吓人，是为了让重力也站在你这边。

神殿的武装修士在每次使用这招前会低声诵念一句经文，不是为了祈福，而是为了提醒举锤者：头顶上方如果有横梁，会先撞到你自己。

## 设计意图

为锤类武器提供高威胁起手技，利用举顶姿态制造心理压制与垂直重击。
