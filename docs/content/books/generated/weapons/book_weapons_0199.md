# 《拐子格斗：把手臂延长一截》

## 基础信息

- **书籍 ID**：`book_weapons_0199`
- **关联技能**：`monk_tonfa_strike`, `monk_tonfa_block`
- **使用效果**：阅读后解锁 `monk_tonfa_strike`；若已学会，提升该技能 `current_mastery +90`，并令拐子格挡成功后的下一次反击伤害提升 `10%`。
- **阅读要求**：角色职业标签含 `monk`、`rogue` 或 `warrior`；基础 `敏捷 ≥ 10`。
- **稀有度**：普通（Common）
- **建议投放**：武馆基础教材、村庄护卫训练、东方商船货物。

## 书籍内容

拐子是最不起眼的武器之一：一根短棍带一个侧枝，却能同时用于攻击、格挡、锁扣与缴械。作者认为，拐子的真正价值在于它延长了前臂，因此使用者可以像空手格斗一样移动，却多了金属的保护。书中详细讲解了三种握法：正握用于突刺与格挡，反握用于砸击与锁技，以及旋转握法用于迷惑对手。后半部分讨论反击：拐子格挡后应该立刻利用侧枝扣住敌人武器，同时用主棍攻击持械手或面门。作者提醒读者，拐子不是长武器，不要试图与刀剑比距离；它的主场是贴身缠斗。作者附有一张关节图，标注着拐子最适合击打的人体脆弱点与对应的持法。拐子的真正威力在于它能让使用者用短兵器打出长兵器的控制范围。书中最后写道，拐子不会主动伤人，它只会放大使用者手臂里本来就有的每一分技巧。

## 设计意图

为武僧与近战职业提供攻防一体的短兵器，强调格挡反击与贴身控制。
