# 《狂战斧舞：血与重量的螺旋》

## 基础信息

- **书籍 ID**：`book_weapons_0175`
- **关联技能**：`berserker_axe_frenzy`, `warrior_cleave_spin`
- **使用效果**：阅读后解锁 `berserker_axe_frenzy`；若已学会，提升该技能 `current_mastery +140`，并令生命值低于 `30%` 时斧舞伤害提升 `10%`。
- **阅读要求**：角色职业标签含 `berserker`；基础 `力量 ≥ 13`、基础 `体质 ≥ 10`。
- **稀有度**：史诗（Epic）
- **建议投放**：北方狂战士祭坛、血战战场中心、狂战士导师传承。

## 书籍内容

狂战士的斧舞不是技术，而是一种让重量跟着血液一起旋转的状态。作者用大量篇幅警告读者：不要在没有学会"停"之前学会"旋"。书中把斧舞分为三圈：第一圈打开空间，第二圈建立节奏，第三圈才是真正收割的时刻。每一圈都需要比以前更快的脚步和更坚决的转身。后半部分讨论如何安全地结束斧舞：不是突然站定，而是利用最后一斧的惯性完成一次翻滚或后撤。作者写道，狂战士最强大的武器不是斧头，而是敌人看到他开始旋转时眼中闪过的恐惧；但真正的狂战士知道，那恐惧必须被控制，否则它会反噬自己。作者最后用血写着："斧舞停下来的那一刻，要么周围没有敌人，要么周围没有活着的敌人。"真正的狂战士不是失去理智，而是把理智压缩到只剩一个念头：转下去，直到敌人全部倒下。

## 设计意图

为狂战士提供高风险高回报的旋转AOE技能，强调低血量增伤与自我控制机制。
