# 《双手巨锤：地裂冲击》

- **书籍 ID**：`book_武器专精_0075`
- **关联技能**：`warrior_great_hammer_slam`
- **使用效果**：阅读后解锁 `warrior_great_hammer_slam`（待新增，标签 `hammer`、`aoe`）；若已学会，提升该技能 `current_mastery +150`。

## 书籍内容

双手巨锤的终极用法不是砸中人，而是砸中地面。当锤头与地面接触的瞬间，力量会以扇形向四周扩散，让近距离的敌人同时失去平衡。作者用了整整一章解释如何选择落点：必须是结实的地面，太软的泥土会吸收冲击，太薄的石板会让力量分散不均。书中还要求使用者掌握跃起下砸的时机：从空中落下的锤头会叠加体重与速度，但落地后的硬直也会更长。后半本收录了多种地裂冲击的变体：横向扫砸、纵向震地、以及用锤头侧面拍击地面制造碎石飞溅。末页画着一个被震裂的战场，裂缝从锤下向外延伸，配文：大地是你的第二把锤。

传说这一招最早是一位巨人用来砸开冰面的，后来人类武者花了三百年才学会如何用双腿吸收落地的反震。书末的脚印图示深深地印在纸上，像是从高处跳下的人留下的真实痕迹。

## 设计意图

为双手锤使用者提供范围控制终结技，把单体重武器扩展为战场扰乱工具。
