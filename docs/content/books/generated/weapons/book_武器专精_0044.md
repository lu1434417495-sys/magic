# 《异界武器适应性训练》

## 基础信息

- **书籍 ID**：`book_武器专精_0044`
- **关联技能**：`ashen_weapon_adapt`、`weapon_ash_touched`
- **使用效果**：阅读后解锁 `ashen_weapon_adapt`；若已学会，提升 `current_mastery +110`，并减少灰烬环境下武器技能的精神反噬 `10%`。
- **阅读要求**：无职业限制；基础 `体质 ≥ 9`、`意志 ≥ 9`；已抵达灰烬交界。
- **稀有度**：精良（Uncommon）
- **建议投放**：灰烬交界入口营地、异界训练场、边境据点任务奖励。

## 书籍内容

普通武器在灰烬交界会变得「不听话」，而适应性训练就是学会与这种不听话共处。作者把适应过程分为三个阶段：第一阶段是接受武器的异常重量变化，第二阶段是学会在武器发出异界振动时保持稳定握持，第三阶段则是在不依赖视觉的情况下判断武器的攻击范围。书中强调，不要试图用蛮力压制异界影响，那只会让反噬更强；正确做法是把异界能量当作一种额外的反馈来源，像感受风向一样感受它。后半本提供了数种针对不同武器类型的适应练习：长柄武器要练习在振动中保持尖端稳定，双持武器要学会两只手分别处理不同的异界反馈，远程武器则要重新校准因异界干扰而改变的弹道。最后一页写着：「在异界，武器不是你的工具，是你的同伴。 书末附有一段冥想引导词，提醒读者与武器建立精神共鸣前需先放空杂念与恐惧。

## 设计意图

降低玩家在灰烬交界使用普通武器的不适感，为异界战斗提供渐进式适应机制。
