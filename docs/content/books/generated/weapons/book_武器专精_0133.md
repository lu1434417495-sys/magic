# 《雷电长柄传导》

## 基础信息

- **书籍 ID**：`book_武器专精_0133`
- **关联技能**：`weapon_lightning_glaive`
- **使用效果**：阅读后解锁 `weapon_lightning_glaive`（待新增）；若已学会，提升 `current_mastery +150`，并提升下一次战斗中雷电链跃传导距离半个身位（一次性）。
- **阅读要求**：职业标签含 `warrior` 或 `mage`；基础 `力量 ≥ 10` 或 `智力 ≥ 11`。
- **稀有度**：史诗（Epic）
- **建议投放**：风暴祭坛顶层、雷霆巨人遗物、天空城宝箱。

## 书籍内容

雷电喜欢尖锐的东西和长的东西，因此长柄武器是天然的引雷器。《雷电长柄传导》教导如何把魔力注入戟杆，让电流沿金属一路奔涌到刃尖，再在击中时跳跃到附近的敌人身上。作者警告：传导时必须戴绝缘护手，否则第一道闪电就会顺着手臂爬进心脏。书中还详细记录了天气对雷电传导的影响：雨天传导距离增加但方向难控，干燥天气方向稳定但威力下降。最危险的是雷暴天，此时长柄武器会成为天然的避雷针，作者建议在室外战斗时避免高举武器。末页有一幅被劈裂的盔甲图，配文："先学会不被雷劈，再学会用雷劈人。"雷电长柄传导不仅依赖武器材质，还依赖使用者的AURA是否足够活跃。修炼铁山桩的战士往往更容易让电流沿戟杆稳定奔涌。稳定的AURA流能让雷电不再只是破坏，而是一种精确的语言。

## 设计意图

把雷电元素与长柄武器结合，链跃距离奖励增强AOE爆发与战场控制感。
