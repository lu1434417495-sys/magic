# 《飞斧旋风投掷》

## 基础信息

- **书籍 ID**：`book_武器专精_0035`
- **关联技能**：`weapon_throwing_axe`、`ranged_axe_throw`
- **使用效果**：阅读后解锁 `weapon_throwing_axe`；若已学会，提升 `current_mastery +110`，并在首次命中后提高下一次近战斧击伤害 `+8%。
- **阅读要求**：已装备飞斧或单手斧；基础 `力量 ≥ 9`、`敏捷 ≥ 8`。
- **稀有度**：精良（Uncommon）
- **建议投放**：蛮荒部落训练场、竞技场投掷奖励、佣兵营地宝箱。

## 书籍内容

飞斧与战斧的衔接，是力量型战士最狂野的舞蹈。作者把这套战术称为「旋风投掷」：先用飞斧在远距离制造威胁或削弱敌人，在敌人逼近时切换为近战斧正面迎战。书中指出，飞斧出手后不要急着收手，而是要保持手臂轨迹，方便立刻从腰间拔出第二把斧。作者还强调，飞斧的落点要比目标稍高一点，因为斧头在空中会自然下坠；瞄得太低只会砸在敌人脚前。后半本收录了数种快速拔斧手法，以及如何在腰间、背后和小腿绑缚斧套而不影响移动。最后一页画着一个战士连续动作的简图：投掷、拔斧、劈砍，配文：「斧头离开手不是结束，是下一击的开始。作者记录了蛮族战士的口头禅：「第一把斧是问候，第二把斧是礼物，手里的斧才是谈判。」蛮族战士会在战前把斧柄浸在水中，让木材略微膨胀，这样飞斧出手时不会在掌心打滑。

## 设计意图

为力量型职业提供远近结合的战斗风格，让飞斧成为近战斧系的前奏与节奏转换器。
