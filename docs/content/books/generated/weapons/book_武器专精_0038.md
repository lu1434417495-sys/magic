# 《战场快速修刃》

## 基础信息

- **书籍 ID**：`book_武器专精_0038`
- **关联技能**：`weapon_field_repair`、`weapon_maintenance_basic`
- **使用效果**：阅读后解锁 `weapon_field_repair`；若已学会，提升 `current_mastery +100`，并允许在战斗间隙临时恢复武器 `15%` 耐久。
- **阅读要求**：无职业限制；基础 `感知 ≥ 8`。
- **稀有度**：精良（Uncommon）
- **建议投放**：佣兵营地、战场遗迹、游侠导师任务奖励。

## 书籍内容

战场上没有铁匠铺，但战场上到处都是可以救急的石头与皮革。作者教授了几种快速修刃技巧：用河床的平整石块临时磨利刃口，用硬化皮革包裹卷刃防止进一步崩裂，用动物油脂暂时防锈。书中最重要的原则不是「修得多好」，而是「修得够快」——在敌人下一波攻势到来前恢复武器的可用状态。作者还提醒，临时修复后的武器不宜再次进行高强度格挡，应尽快在据点的铁砧上彻底处理。后半本收录了数种常见战场材料的替代用法：断裂的弓弦可以用兽筋临时接续，松动的斧柄可以用布条与树脂加固。最后一页画着一个蹲在盾牌后用石块磨剑的战士，配文：「修的不是完美，是活下去的下一次挥砍。书中有一张用血画成的简图，展示如何在盾牌背面固定石块进行临时打磨，作者警告这会缩短盾牌寿命但值得一试。

## 设计意图

为长时间探索与连续战斗提供武器耐久管理手段，强化资源规划与生存能力。
