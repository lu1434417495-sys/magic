# 《主手与副手分工》

## 基础信息

- **书籍 ID**：`book_武器专精_0028`
- **关联技能**：`weapon_main_off_hand`、`warrior_dual_wield_stance`
- **使用效果**：阅读后提升 `weapon_main_off_hand` 的 `current_mastery +90`（若未学会则解锁），并解锁副手可触发的基础反击动作。
- **阅读要求**：已装备两把单手武器；基础 `感知 ≥ 9`。
- **稀有度**：普通（Common）
- **建议投放**：武馆入门教材、佣兵营地藏书、普通商人货架。

## 书籍内容

双持新手最常犯的错误，是要求副手和主手做一样的事。作者用厨房比喻：主手像切菜的刀，副手像按住食材的叉，两者共同完成一次完整的切割。书中把主手职责定为「制造威胁与完成击杀」，副手职责定为「控制距离、创造破绽与防御补充」。作者还提醒，副手武器通常较短较轻，因此更适合贴身快速戳刺或格挡，而不是与主手一起参与大开大合的挥砍。后半本用图解展示了数种经典组合：剑与匕首、斧与锤、弯刀与短剑，每种组合都标注了推荐的主副手分工。最后一页是一段被圈住的文字：「不要让你的副手羡慕主手，要让敌人害怕你的副手。一位老佣兵在页边写道：「我的副手匕首救过我十七次命，而我的主手剑只负责让别人记住我的脸。」作者建议初学双持的人先戴上不同颜色的护腕，用视觉提醒大脑两只手肩负着不同的任务。

## 设计意图

为双持初学者厘清主副手概念，降低学习曲线，为后续高级双持技能奠定认知基础。
