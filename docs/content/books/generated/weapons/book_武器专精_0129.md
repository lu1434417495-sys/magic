# 《刺剑点穴入门》

## 基础信息

- **书籍 ID**：`book_武器专精_0129`
- **关联技能**：`weapon_rapier_thrust`
- **使用效果**：阅读后解锁 `weapon_rapier_thrust`（待新增）；若已学会，提升 `current_mastery +120`，并提升下一次战斗中对无甲敌人的弱点伤害 5%。
- **阅读要求**：职业标签含 `rogue` 或 `warrior`；基础 `敏捷 ≥ 10`。
- **稀有度**：精良（Uncommon）
- **建议投放**：贵族决斗俱乐部、宫廷剑术导师遗物、城市地下竞技场。

## 书籍内容

刺剑是武器中的外科医生，而《点穴入门》就是它的手术笔记。作者把人体分为几十个薄弱点，从颈侧动脉到膝盖后窝，每个点都对应不同的刺入角度和深度。书中强调：刺剑不是劈砍武器，它的伤害来自"到位"，而不是"用力"。到位的关键是手腕在最后关头的微调，让剑尖滑进盔甲缝隙或肌肉间隙。作者还警告了一个坏习惯：刺中后立刻拔剑后撤。正确做法是保持剑身在伤口里多停留一瞬，扩大创口后再脱离。最后一页是一张贵族决斗的速写，失败者捂着肩膀，胜者已经把剑收回鞘中。贵族决斗中禁用刺剑点穴中的某些杀招，但地下竞技场从不设限。作者在书后列出了十二处贵族禁用点，并淡淡批注：战场上没有裁判。地下竞技场的观众最爱看到贵族禁用点被一一重现。刺剑使用者认为，精准本身就是一种冷酷的仁慈。

## 设计意图

把刺剑定位为高精准反无甲武器，弱点伤害加成体现其专业对口优势。
