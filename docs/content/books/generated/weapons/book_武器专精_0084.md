# 《破甲箭：缝间寻隙》

## 书籍内容

破甲箭不是更硬的箭头，而是更准的落点。这本书的前半本用 armor 示意图标注了所有甲胄的薄弱缝隙：腋下、腰肋、膝盖后侧、颈窝、肘弯。作者强调，射中这些位置需要的不是蛮力，而是耐心——你必须等到敌人在某个动作中把这些缝隙暴露出来。后半本讲解箭头的选择：窄三棱箭头适合穿透链甲，细长锥形箭头适合板甲缝隙，而重箭头能在近距离砸开轻甲。书中还提醒，破甲箭飞行时更容易受风偏影响，所以射手必须在放箭前把风速预算多加一成。末页贴着一块被射穿的护心镜，裂纹从箭孔向四周蔓延，配文：盔甲保护的是害怕缝隙的人，而缝隙永远存在。

一位矮人弩匠在空白处画了一组甲胄接缝的放大图，并在每个缝隙旁标注了最佳入射角度。最后一幅图是一把断箭，配文：缝隙也会磨损箭头。所以破甲箭的箭头要特别硬，心要特别软。

## 设计意图

为弓箭手提供反重甲能力，把破甲箭从单纯高伤转化为对敌人动态弱点的捕捉。
