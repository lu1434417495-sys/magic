# 《六合大枪：压与锁》

## 基础信息

- **书籍 ID**：`book_武器专精_0065`
- **关联技能**：`warrior_spear_forest_press`
- **使用效果**：阅读后解锁 `warrior_spear_forest_press`；若已学会，提升该技能 `current_mastery +130`。
- **阅读要求**：已装备长柄武器；基础 `力量 ≥ 10`、`感知 ≥ 8`。
- **稀有度**：精良（Uncommon）
- **建议投放**：东方武馆、宗门演武堂、山贼大头目宝箱。

## 书籍内容

六合大枪不讲刺得多快，而讲究把敌人的空间一点点压没。作者把枪法分成六个方向：上下左右前后，每一方向都有对应的压制招式。练习时，对手不是被刺中，而是被逼到无处可退。书中详细解释压字诀：枪身像一扇不断合拢的门，不给敌人留出挥刀的角度。锁字诀则是在敌人退无可退时，用枪杆别住其兵器或关节。作者认为，真正的大枪高手会让对手在接战三招后就发现自己已经输了，只是身体还没倒下。后半本记录了一场著名比武，胜利者从头到尾只刺出一枪，却让对手退了十七步。末页批注：大枪的杀意在枪尖之外。

作者在最后坦白，六合大枪最凶的一招不是压，也不是锁，而是让敌人以为自己还有退路，直到发现身后已是墙角。他说这话时，书页上正好有一滴茶渍，形状像一个人被逼到角落。

## 设计意图

为长柄武器高手提供控制型战技，把枪矛从爆发输出重新定义为空间压迫工具。
