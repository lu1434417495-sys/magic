# 《直刺的艺术：剑尖先行》

## 基础信息

- **书籍 ID**：`book_武器专精_0052`
- **关联技能**：`warrior_piercing_thrust`
- **使用效果**：阅读后解锁 `warrior_piercing_thrust`；若已学会，提升该技能 `current_mastery +100`。
- **阅读要求**：已装备剑类武器；基础 `敏捷 ≥ 7`。
- **稀有度**：普通（Common）
- **建议投放**：剑士训练营、老兵传授、遗迹书架。

## 书籍内容

刺击是剑最古老的用法，也是最容易被低估的用法。这本书的前半本都在讲一个动作：让剑尖先动。作者认为大多数人的刺击失败不是因为不够快，而是因为他们让肩膀先动，于是敌人提前半拍看见了杀意。书中要求练习者面对悬空的细绳，在不触碰到其他部分的前提下让剑尖穿过绳环。第二章讨论距离控制：刺击的有效范围往往比劈砍短一掌，但致命窗口却大一倍。后半本收录了不同护甲接缝的刺入角度，特别是腋下与腰肋两处最容易被忽视的位置。末页有一句话被反复描粗：剑尖是你的眼睛，让它先看清楚，再让它决定方向。

作者在最后附了一页自己的训练日志，记载他连续三个月每天只练一剑直刺，直到能在蜡烛火焰前一寸停住剑尖而不熄灭烛火。他说：停得住的剑，才刺得准；收得回的剑，才刺得远。

## 设计意图

强化剑类武器精准穿透的定位，将直刺从简单伤害动作提升为距离与时机判断。
