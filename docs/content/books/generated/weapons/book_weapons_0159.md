# 《鞭影缚敌：软兵器的预谋》

## 基础信息

- **书籍 ID**：`book_weapons_0159`
- **关联技能**：`rogue_whip_trip`, `rogue_whip_disarm`
- **使用效果**：阅读后解锁 `rogue_whip_trip`；若已学会，提升该技能 `current_mastery +100`，并令下一次成功绊倒敌人时附加 `1` 层减速。
- **阅读要求**：角色职业标签含 `rogue` 或 `bard`；基础 `敏捷 ≥ 12`。
- **稀有度**：稀有（Rare）
- **建议投放**：马戏团逃亡者行李、奴隶主藏室、沙漠黑市。

## 书籍内容

鞭子是最难被新手驾驭的武器，因为挥出去之后它有自己的意志。作者用前半本书讲解如何让鞭身听话：不是用手腕猛甩，而是让力量像水波一样从肩膀传到鞭梢。书中把基本鞭法分为抽、缠、拖、绊四类，每一种都需要提前计算鞭身在空中的延迟。中段有一章专门讲"声东击西"——用鞭梢的破空声吸引敌人注意，真正的攻击来自第二波回弹。后半部分讨论地形：狭窄空间里鞭子容易弹回伤己，开阔地带才能发挥最大控制范围。作者警告读者，鞭子最美的时刻不是击中，而是缠住敌人脚踝后你轻轻一拉的那半拍。书中警告，鞭子挥出后若被敌人抓住，必须立刻弃鞭换短刀，迟疑半拍便会丧命。他建议在鞭梢系上不同颜色布条，通过观察布条飘动判断出手时机。 书后追加了一段软兵收纳与绳索缠绕的心得，强调出手速度始于整理方式。

## 设计意图

为盗贼与吟游诗人系提供软兵器控制选项，强调预判、延迟与地形利用的战术深度。
