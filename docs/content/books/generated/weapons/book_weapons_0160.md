# 《戟刃钩拽：长兵器的诡计》

## 基础信息

- **书籍 ID**：`book_weapons_0160`
- **关联技能**：`warrior_halberd_hook`, `warrior_halberd_thrust`
- **使用效果**：阅读后解锁 `warrior_halberd_hook`；若已学会，提升该技能 `current_mastery +110`，并令钩拽命中后下一次刺击必定暴击。
- **阅读要求**：角色职业标签含 `warrior` 或 `spearman`；基础 `力量 ≥ 11`、基础 `敏捷 ≥ 9`。
- **稀有度**：精良（Uncommon）
- **建议投放**：王国军械库、古战场戟阵遗址、精英长柄教官。

## 书籍内容

戟是长矛与斧头的私生子，因此它既有矛的距离，也有斧的狡诈。作者把戟的使用分为"正面"与"侧面"两种思路：正面像矛一样刺击与格挡，侧面则用钩刃拽倒、勾开盾牌或扯下马背上的敌人。书中详细讲解了三种钩拽时机：敌人抬脚时、举盾时、侧身挥砍时。每一次成功的钩拽都会让敌人进入短暂的失衡窗口，而戟手必须在这窗口内完成刺击或后撤。后半部分讨论戟尾砸击，这种被许多使用者忽略的动作在近身时能有效阻止敌人扑入怀中。末页有一段被血浸透的文字："戟不是君子兵器，它最喜欢敌人失去平衡的那一刻。"作者附上一份戟阵训练日程，要求练习者每日重复三百次钩拽空挥，直到动作成为本能。戟手必须在钩拽后立刻决定是追击还是后撤，犹豫会让长兵器的距离优势瞬间消失。

## 设计意图

为长柄武器增加复合动作与连携机制，通过钩拽创造暴击窗口，强化戟的多功能性。
