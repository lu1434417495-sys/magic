# 《长柄武器距离控制》

## 基础信息

- **书籍 ID**：`book_武器专精_0015`
- **关联技能**：`weapon_range_control`、`warrior_polearm`
- **使用效果**：阅读后解锁 `weapon_range_control`；若已学会，提升 `current_mastery +100`，并增加长柄武器有效攻击距离半格（一次性永久增益，最多累计 2 次）。
- **阅读要求**：已装备任意长柄武器；基础 `感知 ≥ 10`。
- **稀有度**：精良（Uncommon）
- **建议投放**：枪兵教官、边境哨塔、游侠导师藏书。

## 书籍内容

长柄武器的精髓不是刺得远，而是让敌人永远处在你够得着、他够不着的位置。作者把战斗距离分为内圈、中圈与外圈，指出新手最常见的错误是放任敌人进入内圈——一旦对手贴近到枪杆中间，长柄反而成为累赘。书中介绍了「滑杆」技术：当敌人试图沿枪杆逼近时，迅速松开一只手，用另一只手把枪尾抽出，用枪尾敲击或戳击对方面部与胸口。作者还强调脚步要配合枪尖移动，每次突刺后都要后撤或侧移，重新拉开距离。后半本用大量示意图展示如何在狭窄空间中利用墙壁限制敌人走位。最后一页是一幅对阵图，长枪兵始终把剑士挡在两步之外，配文：「一步是生，一步是死，你要替敌人决定他站在哪一步。作者用一根长绳在训练场上标出不同距离的界限，要求学生在三天内只练习一件事：让敌人始终站在绳子的另一侧。

## 设计意图

把长柄武器的核心机制从「攻击范围大」深化为「主动控制距离」，提升操作上限与策略深度。
