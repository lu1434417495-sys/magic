# 《破甲锤法：骨与铁的对话》

## 基础信息

- **书籍 ID**：`book_weapons_0155`
- **关联技能**：`warrior_armor_breaker`, `warrior_mace_smash`
- **使用效果**：阅读后解锁 `warrior_armor_breaker`；若已学会，提升该技能 `current_mastery +130`，并令下一次战斗中对重甲敌人的首次破甲锤命中附加 `1` 层易伤。
- **阅读要求**：角色职业标签含 `warrior` 或 `cleric`；基础 `力量 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：古老铁匠铺密室、教会武备库、重甲骑士遗产。

## 书籍内容

作者自称是锻甲师转行，对每一块甲片的受力点了如指掌。书中把破甲锤的攻击分为"传震"与"陷甲"两类：传震是要把冲击力透过甲片送进关节和内脏，陷甲则是要在板甲表面制造凹陷以限制活动。作者强调，破甲锤使用者必须学会"听"——听锤头落甲时的回声，判断下面是骨头、空腔还是另一层甲。书中详细记录了七种常见甲型的弱点，包括肩甲缝、膝甲铰链、背甲脊梁。后半部分讲呼吸：挥锤时要在锤头触甲的瞬间吐气，这样力量才能完整传递，而不是被自己的腹肌抵消。作者特别强调，破甲锤最忌讳连续敲击同一位置，那会让敌人适应震动，反而降低效果。作者附有一张甲片受力图，用不同颜色标注出最容易被一击变形的薄弱点。据传，北地军团的破甲锤手会在战前用唾液涂抹锤柄，不是为了防滑，而是提醒自己：锤下之人也曾穿着同样甲胄。

## 设计意图

针对重甲敌人设计专精型武器书，为高力量近战职业提供清晰的反坦克战术与护甲互动机制。
