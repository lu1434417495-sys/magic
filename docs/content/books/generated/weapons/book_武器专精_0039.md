# 《血污与锈蚀处理》

## 基础信息

- **书籍 ID**：`book_武器专精_0039`
- **关联技能**：`weapon_blood_rust_care`、`weapon_maintenance_basic`
- **使用效果**：阅读后提升 `weapon_blood_rust_care` 的 `current_mastery +80`（若未学会则解锁），并减少血污/锈蚀类环境对武器耐久的影响 `10%`（一次性永久增益）。
- **阅读要求**：无职业限制；基础 `感知 ≥ 6`。
- **稀有度**：普通（Common）
- **建议投放**：战地医疗队、边境哨塔、普通商人货架。

## 书籍内容

血会让金属变钝，锈会让金属变脆，而许多人直到武器折断才明白这个道理。作者详细讲解了战斗后清理血污的步骤：先用清水冲洗，再用细布擦干，最后用少量油脂涂抹刃面。对于已经生锈的武器，作者建议先用软刷去除浮锈，再用酸性弱的草药汁或醋液处理深层锈点，切忌用力刮擦导致刃面受损。书中还讨论了不同环境对武器的侵蚀：海边盐雾会加速锈蚀，沼泽湿气会让皮柄腐烂，火山灰则会在高温下烧结血污。后半本附了一张简易配方表，列出了几种可以临时制作防锈油的植物与矿物。最后一页是一句老兵的叹息：「最快的刀，往往是被主人忘了擦干的那一把。作者提到自己曾见过一把被主人精心保养了四十年的短剑，剑身上几乎没有划痕，因为真正的保养让每一次出手都足够致命。

## 设计意图

用环境互动与耐久管理增强真实感，让武器保养成为探索与战斗之间的必要仪式。
