# 《伐木斧与战斧的区别》

- **书籍 ID**：`book_武器专精_0009`

## 书籍内容

作者是一名退役佣兵，如今靠教村民用斧头养活自己。他开宗明义地指出，伐木斧与战斧最大的区别不在刃形，而在「目标会不会移动」。书中前半部分比较了两种斧头的重心：伐木斧头部更重，适合垂直下劈；战斧则把重量向手柄中部移动，方便横向挥砍与快速变向。后半部分讲如何把伐木技巧转化为战斗意识，例如「找木纹」在战场上对应「找关节与接缝」，「顺茬劈」对应「顺着敌人的动作落斧」。作者还记录了一个实用小技巧：用斧头背面敲击盾牌上方，可以震松对手的握盾手臂，为下一记劈砍创造机会。最后一页是一张粗糙的示意图，展示如何把普通伐木斧临时磨出战斧刃角，旁边注明「不要让你原来的铁匠知道」。作者在书的结尾提到，他曾在某个冬夜用一把伐木斧砍翻了三名强盗，第二天又把同一把斧磨回去继续劈柴。

## 设计意图

连接生活技能与战斗技能，为平民出身或非战士职业提供一条平易近人的斧类武器入门路径。
