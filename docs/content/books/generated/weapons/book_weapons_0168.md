# 《细剑穿刺：缝隙中的优雅》

## 基础信息

- **书籍 ID**：`book_weapons_0168`
- **关联技能**：`duelist_rapier_thrust`, `warrior_precise_pierce`
- **使用效果**：阅读后解锁 `duelist_rapier_thrust`；若已学会，提升该技能 `current_mastery +130`，并令下一次成功穿刺弱点的攻击回复 `5` 点体力。
- **阅读要求**：角色职业标签含 `duelist`、`rogue` 或 `warrior`；基础 `敏捷 ≥ 12`。
- **稀有度**：稀有（Rare）
- **建议投放**：贵族决斗馆、旧帝国竞技场、刺客行会密室。

## 书籍内容

细剑不是装饰品，而是专门寻找缝隙的工具。作者用前半本书讲解如何在敌人移动时识别甲缝、衣领、腋下与膝盖后侧这些永恒的弱点。书中强调，细剑使用者不能和重甲敌人硬碰硬，必须像水一样绕开正面，从敌人不得不暴露的角度进入。中段有一章专门讲"穿刺后的回收"：许多人刺中后急着拔剑，结果把剑卡在骨头或甲环里；正确的做法是利用剑身的弹性顺势滑出，而不是蛮力回抽。后半部分讨论步法：细剑的突刺距离很短，因此脚步必须比剑尖更先到达合适的位置。末页有一行优雅的字迹："剑尖之前，先让脚尖抵达。"书末附有一张贵族盔甲接缝图，作者用红笔圈出了每一处足以致命的狭窄缝隙。真正的细剑手懂得，每一次刺击都是一次赌博，赌的是自己对缝隙的判断比敌人的反应更快。

## 设计意图

为高敏捷决斗者提供弱点穿刺专精，强调走位、缝隙利用与体力循环管理。
