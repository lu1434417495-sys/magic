# 《飞斧投掷：旋转与重心》

## 基础信息

- **书籍 ID**：`book_武器专精_0069`
- **关联技能**：`warrior_axe_throw`
- **使用效果**：阅读后解锁 `warrior_axe_throw`（待新增，标签 `axe`、`ranged`）；若已学会，提升该技能 `current_mastery +120`。

## 书籍内容

飞斧飞行的秘密在于旋转。斧头不像匕首那样直飞，而是要在空中翻一个或两个跟头，让斧刃在命中时正对目标。这本书用前半本讲解如何根据距离选择旋转圈数：太近时几乎不转，太远时则需要一圈半。作者设计了一套练习方法：在地面插一排木桩，从近到远依次投掷，直到每个距离都能让斧刃先触桩。后半本讨论风速与投掷角度的补偿：侧风会让斧头翻转不均，必须让斧头的平面稍微迎着风向。书中还提醒，飞斧出手后不要立即前冲，先观察是否命中再决定下一步。末页贴着一张磨损的靶纸，靶心处嵌着半片斧刃，旁边批注：旋转是为了让斧头在最后一刻变成直线。

书中记载，最出色的飞斧手能在斧头离手的瞬间用手指拨动斧柄，让旋转圈数在半空中改变。 书末夹着一张旧靶图，圈出劈砍时应优先瞄准的肩线与膝弯位置。

## 设计意图

为斧类武器提供中距离远程选项，把投掷从杂技转化为需要计算旋转与风速的战术技能。
