# 《缴械与反缴械》

## 基础信息

- **书籍 ID**：`book_武器专精_0048`
- **关联技能**：`weapon_disarm_counter`、`warrior_disarm`
- **使用效果**：阅读后解锁 `weapon_disarm_counter`；若已学会，提升 `current_mastery +130`，并在成功反缴械后立刻获得一次反击机会。
- **阅读要求**：已装备任意近战武器；基础 `敏捷 ≥ 11`、`感知 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：武馆高级课程、竞技场冠军奖励、贵族决斗场藏书。

## 书籍内容

缴械与被缴械之间，只隔着一次正确的手腕转动。作者详细讲解了反缴械的核心原则：当敌人试图锁腕或旋夺武器时，不要与敌人角力，而是顺着对方的力道移动武器，同时用身体的重量改变受力点。书中把反缴械分为「卸、转、还」三步：卸是让敌人的力量落空，转是把武器带到安全位置，还则是在对方因落空而失衡时发起反击。作者还提醒，最有效的反缴械往往发生在敌人以为自己即将成功的那一刻——那时候他们的注意力全在夺武器上，防御最薄弱。后半本收录了数种针对空手夺刃、棍棒锁腕与链枷缠绕的反制方法。最后一页是一幅对练图，配文：「缴械者最怕的，不是对手握紧武器，而是对手假装握紧。一位宫廷剑术大师在页边留下心得：「最好的反缴械不是技术，是让对手从一开始就不敢尝试缴你的武器。」

## 设计意图

为高阶近战职业提供控制与反制技能，增加正面交锋中的心理博弈与技术上限。
