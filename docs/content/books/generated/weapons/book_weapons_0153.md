# 《战斧劈砍 timing：重刃落点手册》

## 基础信息

- **书籍 ID**：`book_weapons_0153`
- **关联技能**：`warrior_axe_cleave`, `warrior_hew`
- **使用效果**：阅读后解锁 `warrior_axe_cleave`；若已学会，提升该技能 `current_mastery +100`，并在下一次战斗中令首次战斧劈砍无视目标 `5%` 护甲。
- **阅读要求**：角色职业标签含 `warrior` 或 `berserker`；基础 `力量 ≥ 11`。
- **稀有度**：普通（Common）
- **建议投放**：北方部族营地、伐木工工会藏室、野兽猎人任务奖励。

## 书籍内容

手册的装订用的是野兽筋腱，翻页时会发出干涩的摩擦声。作者没有过多描述招式，而是把全部精力放在"落点"上：斧刃应该落在敌人的肩膀、锁骨、膝盖外侧，还是盾牌上沿？每一击的选择直接决定下一击还有没有空间。书中强调战斧不是剑，不能靠速度取胜，必须靠每一斧都落在让敌人最难受的位置。作者还画了一张"节奏表"，标注了对手举盾、侧身、后撤三种状态下最佳的劈砍时机。后半部分警告读者：不要因为斧头砍得深就急着拔斧，那会把你自己固定在原地。正确做法是顺劈方向扭身，让斧刃借着体重滑出。手册末尾附有一张磨损的靶图，上面标注着不同落点对应的敌人僵直时间，供读者反复揣摩。他还提醒，斧头嵌入盾牌时不必强行拔出，顺势扭身用斧刃划开盾面才是上策。 书末夹着一张旧靶图，圈出劈砍时应优先瞄准的肩线与膝弯位置。

## 设计意图

将战斧定位为高破甲、重落点的职业武器，鼓励玩家通过时机与位置选择来放大单次劈砍收益。
