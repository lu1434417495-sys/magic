# 《戟的钩拉与劈砍》

## 基础信息

- **书籍 ID**：`book_武器专精_0013`
- **关联技能**：`weapon_halberd_hook`、`warrior_polearm`
- **使用效果**：阅读后解锁 `weapon_halberd_hook`；若已学会，提升 `current_mastery +130`，并在下一次战斗中首次钩拉成功后附加一次免费劈砍。
- **阅读要求**：已装备戟或长柄混合武器；基础 `力量 ≥ 11`。
- **稀有度**：稀有（Rare）
- **建议投放**：王国军械库、贵族骑士训练场、精英副本宝箱。

## 书籍内容

戟是长柄武器中的异类，它同时拥有矛的尖端、斧的刃部和钩的弯曲。作者把戟法总结为「一拉二劈三压」：先用钩部勾住敌人盾牌或肢体，把它扯离防线；趁着敌人失衡，用斧刃劈向暴露的部位；最后用矛尖抵住对方咽喉或胸口，阻止其重新组织防御。书中详细分析了钩拉时的力学：不是往回硬拽，而是顺着敌人用力的方向突然加力，让它自己的惯性帮助自己摔倒。作者还提醒，戟由于头部复杂，挥舞速度比纯矛慢，因此每一次出手都必须同时完成两个目标——比如钩拉敌人的同时破坏其架势。最后一页是一张残破的战场速写，画中人正用戟把一名重甲骑士从马上拽下，配文：「戟不讲礼貌，它只问你要不要下来。书中记载了一位无名戟将的故事，他能在钩住敌人盾牌的同时用斧刃削断对方坐骑的前蹄，整套动作被称为「落马风」。

## 设计意图

丰富长柄武器的技能树，让戟成为兼具控制与爆发的多面手武器，强化「先控再打」的战术节奏。
