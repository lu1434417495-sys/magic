# 《钉头锤碎骨谱》

## 基础信息

- **书籍 ID**：`book_武器专精_0108`
- **关联技能**：`weapon_mace_shatter`
- **使用效果**：阅读后解锁 `weapon_mace_shatter`（待新增）；若已学会，提升 `current_mastery +140`，并提高对骷髅/构装体敌人的伤害加成 5%（持续至下一场战斗结束）。
- **阅读要求**：职业标签含 `warrior` 或 `cleric`；基础 `力量 ≥ 9`。
- **稀有度**：精良（Uncommon）
- **建议投放**：墓地守陵人遗物、圣骑士军械库、亡灵讨伐任务奖励。

## 书籍内容

《碎骨谱》的纸张又脆又黄，翻开时发出干骨头摩擦般的声响。作者声称钉头锤是对不死生物最友好的武器——不是因为它仁慈，而是因为它直接。书中把敌人分为"有骨"与"无骨"两类：有骨敌人怕震裂，无骨敌人怕压溃。每一页都画着不同骨骼的受力点，从头盖骨到胫骨，再到盆骨，旁边标注着需要多少角度才能让裂纹沿骨髓扩散。作者还提醒：对付骷髅时不要追求一锤粉碎，先打断支撑腿，再处理持武器的手臂。附录是一页祷文，被反复修改了多次，最后只剩一行："愿你的骨头比我先疲惫。"大教堂地下档案馆保存着一份抄本，上面记录了用圣水浸泡锤头后对亡灵的伤害增幅。抄本的最后一页被撕去，据说记载着某种不可触碰的仪式。那份缺失的最后一页，至今仍是亡灵猎手们争论的话题。亡灵在这份精确面前，往往比活人更显脆弱。

## 设计意图

为钉头锤建立反亡灵/构装特化定位，配合一次性场景伤害加成强化感知。
