# 《奉献光环》

## 基础信息

- **书籍 ID**：`book_信仰_0077`
- **关联技能**：`faith_aura_devotion`
- **使用效果**：阅读后解锁 `faith_aura_devotion`；若已学会，提升该技能 `current_mastery +80`，并使光环范围内友方每回合恢复少量生命。
- **阅读要求**：角色职业标签含 `priest`、`cleric` 或 `paladin`；基础 `信仰 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：团队牧师训练场、防御战奖励、圣骑士营地。

## 书籍内容

《奉献光环》教导牧师如何让自己成为一座移动的灯塔，持续为周围友方提供微弱但稳定的神圣滋养。书中把光环比作呼吸——它不需要刻意维持，但必须保持节律。第一章讲解光环的开启与收敛，指出过度扩张会导致效果稀释，过度收缩则无法覆盖需要保护的队友。第二章讨论光环与情绪的关系，愤怒会让光环带有攻击性，悲伤会让光环变得沉重，唯有平静才能让它真正治愈他人。作者警告，长期开启光环会缓慢消耗施术者的体力与信仰，因此需要学会在战斗间隙关闭恢复。后半部收录了多种光环应用方式，包括围绕阵地旋转、随冲锋推进、以及在撤退时断后掩护。最末页的插图是一名牧师站在队伍中央，柔和的光芒以他为中心笼罩着所有人，箭矢射入光芒后纷纷偏斜。奉献光环是信仰系持续团队支援的经典技能。

## 设计意图

为信仰系设计持续型团队光环技能，强化牧师作为团队核心的存在感与续航能力。
