# 《移念重心的祈祷》

## 基础信息

- **书籍 ID**：`book_faith_0027`
- **关联技能**：`faith_shift_prayer`
- **使用效果**：阅读后解锁 `faith_shift_prayer`；若已学会，提升该技能 `current_mastery +80`，并在冥想时额外回复 10% 当前缺失 MP。
- **阅读要求**：无职业限制；已解锁 `meditation` 系统或基础 `意志 ≥ 8`。
- **稀有度**：稀有（Rare）
- **建议投放**：冥想导师书架、修道院静修室、MP 修炼支线。

## 书籍内容

移念重心的祈祷教导修行者如何把焦虑从胸口移到掌心里。书中指出，大多数人在祈祷时把全部注意力集中在"请求"上，结果越祈求越紧张。正确的做法是把念头想象成一块石头，先承认它的重量，然后缓缓把它从咽喉移到胸口，再移到腹部，最后让它沉到脚底的大地。作者设计了一组简单的身体扫描练习，配合三句不同重心的祷词，帮助读者在几分钟内完成这一过程。中级章节讨论如何在战斗中快速使用这种技巧：不是完全放松，而是把恐惧从决策中心转移到身体的边缘。最深刻的章节认为，移念不是逃避，而是让意念站在更合适的位置上继续工作。书的附录里有一张人体轮廓图，标注了"请求"、"接受"、"交托"三个位置。冥想导师常让学生在感到烦躁时练习这个技巧，而不是强行压制情绪。他们发现，当焦虑被移到脚底后，人反而能更清醒地决定下一步行动。
