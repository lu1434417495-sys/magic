# 《圣殿晨星颂唱法》

## 基础信息

- **书籍 ID**：`book_faith_0002`
- **关联技能**：`faith_dawn_hymn`
- **使用效果**：阅读后解锁 `faith_dawn_hymn`；若已学会，提升该技能 `current_mastery +90`，并在清晨战斗前为全队提供一层短暂 `morale` 加成。
- **阅读要求**：角色拥有 `holy`、`support` 或 `bard` 标签职业；基础 `意志 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：晨祷礼拜堂、吟游诗人营地、圣骑士新兵训练营。

## 书籍内容

圣殿晨星颂唱法记录的是一种在黎明前最后黑暗里唱响的短歌。书中把音高分为三段：低沉的认罪、中平的祈愿、高亢的托付，每一段对应一次深呼吸。作者写道，歌声不是为了让神听见，而是为了让同伴在混乱中找到一个可依靠的节奏。后半本详细列举了适合不同人数的声部安排，从独行朝圣者到三十人唱诗班都能套用。最特别的一章提到，当颂唱者与晨星同时升起时，歌词中的某些音节会自行改变，仿佛星光本身在纠正人的走调。书中还警告：若颂唱者心怀炫耀，歌声会化作尖锐噪音，反而降低同伴的命中率。许多页边有旧年的音符批注，记录着历代修士微小的变奏。在北方的边境堡垒，守夜人把这本书当成交接班的暗号手册，因为晨星颂唱能在不暴露位置的情况下确认彼此身份。久而久之，某些旋律甚至成为了特定小队独有的身份证明。

## 设计意图

将信仰与团队士气绑定，让"清晨"成为具有仪式感的战略窗口，强化牧师与辅助职业的战场节奏控制能力。
