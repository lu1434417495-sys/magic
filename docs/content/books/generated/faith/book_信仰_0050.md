# 《终焉信仰的核心》

## 基础信息

- **书籍 ID**：`book_faith_0050`
- **关联技能**：`faith_apotheosis_creed`
- **使用效果**：阅读后解锁 `faith_apotheosis_creed`；若已学会，提升该技能 `current_mastery +150`，并解锁信仰系终极被动：当 MP 耗尽时自动将 AURA 转化为等额护盾，每场战斗限一次。
- **阅读要求**：角色拥有 `holy` 或 `zealot` 标签职业；已解锁 `meditation` 与 `cultivation` 系统；基础 `意志 ≥ 12`。
- **稀有度**：传说（Legendary）
- **建议投放**：终章信仰试炼、隐藏神殿、多重系统毕业奖励。

## 书籍内容

终焉信仰的核心是信仰系列中最薄却最难读完的一本书。它没有章节，只有一页纸，上面写着三句话："你无法拥有信仰，你只能成为它的通道；你无法证明信仰，你只能活成它的证据；你无法保存信仰，你只能把它交出去。"书的其余部分全是空白，但每一任持有者都会在空白处写下自己读完后的感受。这些批注跨越数百年，有的狂喜，有的绝望，有的只是简单的一句"我明白了"或"我还是不懂"。作者无名无姓，只在封面内侧留下一枚指印。据说这本书无法被带走，只能被传下去；当一个人真正读完时，它会自己出现在下一个需要它的人面前。大教堂的禁书目录把它列为"不可收藏"，因为任何试图独占它的人都会发现书页在第二天变成空白。这种特性反而让它成为信仰传承最纯粹的载体。也正因为如此，它从未出现在任何拍卖行的名录上。

## 设计意图

作为信仰系列的终极收尾，解锁跨系统的毕业级被动，用极简文本与历代批注营造信仰的传承与不可言说之美。
