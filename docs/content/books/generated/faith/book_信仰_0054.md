# 《庇护之光》

## 基础信息

- **书籍 ID**：`book_信仰_0054`
- **关联技能**：`faith_sanctuary_light`
- **使用效果**：阅读后解锁 `faith_sanctuary_light`；若已学会，提升该技能 `current_mastery +80`，并使庇护区域持续回合数增加 1。
- **阅读要求**：角色职业标签含 `priest` 或 `cleric`；基础 `信仰 ≥ 8` 或 `体质 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：前线战地教堂、守城战奖励、团队副本宝箱。

## 书籍内容

当战场的硝烟遮蔽天空，牧师举起法器，低声念出庇护祷词，一片柔和的光便会以他为中心缓缓扩散。《庇护之光》教导的并非攻击，而是如何用信仰划定一片安全的边界。书中把庇护分为三个层次：第一层是"拒敌"，令邪恶生物不愿踏入；第二层是"止血"，使范围内友方持续恢复轻微生命；第三层是"定心"，驱散恐惧与混乱状态。作者用一整章讨论站位问题，指出牧师必须位于区域中心，但又要避免成为敌人集火的目标。第二章列举了七种常见的庇护失效情况，包括施术者主动离开、范围内发生血祭、以及友方携带诅咒物品进入。后半部附带十二幅战场示意图，展示如何在不同地形中最大化庇护效果。最后一页的插图是一名牧师跪坐在倒下的战友之间，光幕如同破碎的蛋壳一般保护着所有人。

## 设计意图

为信仰系提供核心团队防御技能，强化牧师在战棋中的阵地控制与保护职责。
