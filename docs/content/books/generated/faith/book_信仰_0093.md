# 《信仰锁链》

## 基础信息

- **书籍 ID**：`book_信仰_0093`
- **关联技能**：`faith_chains`
- **使用效果**：阅读后解锁 `faith_chains`；若已学会，提升该技能 `current_mastery +85`，并使被锁链束缚的敌人在 2 回合内无法使用位移技能。
- **阅读要求**：角色职业标签含 `priest`、`cleric` 或 `inquisitor`；基础 `信仰 ≥ 9`。
- **稀有度**：稀有（Rare）
- **建议投放**：审判庭囚室、异端抓捕任务、控制型牧师训练场。

## 书籍内容

《信仰锁链》教导牧师如何用信仰凝聚成发光的锁链，束缚敌人的行动。书中指出，这些锁链不是实体金属，而是信念的延伸，因此对意志薄弱者效果更强，对信仰坚定者则可能被挣脱。第一章讲解锁链的投射与缠绕技巧，要求施术者在抛出锁链的同时默念目标所犯的罪行。第二章讨论锁链的弱点，包括极端高温、暗影腐蚀以及目标以纯物理力量强行崩断。作者警告，信仰锁链不应被用来囚禁无辜者，否则锁链会逐渐变黑并最终反噬施术者。后半部收录了多种战术应用，例如限制敌方刺客切入、阻止敌方治疗者后撤、以及在审讯中固定嫌疑人。最末页的插图是一名审判官手持发光的锁链，锁链另一端缠绕着一名挣扎的恶魔，光芒正缓缓渗入其身体。信仰锁链是信仰系重要的单体控制技能。

## 设计意图

为信仰系提供物理/魔法混合型控制技能，增强牧师对高机动敌人的反制能力。
