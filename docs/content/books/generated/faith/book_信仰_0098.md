# 《信仰护盾阵列》

## 基础信息

- **书籍 ID**：`book_信仰_0098`
- **关联技能**：`faith_aegis_array`
- **使用效果**：阅读后解锁 `faith_aegis_array`；若已学会，提升该技能 `current_mastery +95`，并使阵列中每个护盾被击破时对其他护盾产生小幅强化。
- **阅读要求**：角色职业标签含 `priest` 或 `cleric`；基础 `信仰 ≥ 10` 且 `智力 ≥ 8`。
- **稀有度**：史诗（Epic）
- **建议投放**：大型团队副本、信仰阵营终极防御任务、教会最高机密藏室。

## 书籍内容

当单个护盾不足以保护团队时，信仰系牧师可以构建覆盖多人的护盾阵列。《信仰护盾阵列》教导如何在多名队友身上同时维持相互连接的护盾，使伤害在阵列中分散。书中把阵列比作一张由光织成的网，每个节点都是一个人，每条线都是彼此的信任。第一章讲解阵列的构建方法，要求施术者先与每个目标建立短暂的信仰连接。第二章讨论阵列的优化，包括前排强化、后排链接以及关键节点保护。作者警告，阵列的维持消耗极大，若施术者被控制，整个阵列会瞬间崩溃。后半部收录了多个经典阵列案例，包括抵御龙息、抵挡攻城器械、以及在混乱战场中保护重要目标。最末页的插图是一名牧师站在阵中，无数光点从队友身上飞出，在空中交织成复杂的防御网络。信仰护盾阵列是信仰系最高级的团队防御技能之一。

## 设计意图

为信仰系提供终极团队防御技能，将单人护盾升级为网络化防御体系，强化牧师在大型战斗中的核心地位。
