# 《圣光裁决》

## 基础信息

- **书籍 ID**：`book_信仰_0097`
- **关联技能**：`faith_light_verdict`
- **使用效果**：阅读后解锁 `faith_light_verdict`；若已学会，提升该技能 `current_mastery +90`，并使裁决命中后目标 2 回合内无法获得增益效果。
- **阅读要求**：角色职业标签含 `priest`、`cleric` 或 `inquisitor`；基础 `信仰 ≥ 10` 且 `智力 ≥ 8`。

- **建议投放**：最高审判庭、信仰阵营终极任务、史诗副本奖励。

## 书籍内容

《圣光裁决》是信仰系最具仪式感的攻击技能之一。它不是普通的打击，而是对目标进行一场短暂的"审判"，并以圣光执行结果。书中指出，裁决的威力取决于施术者对正义的理解是否纯粹，任何私欲都会让裁决之光黯淡。第一章讲解裁决的前置步骤：先以神术标记目标，宣读其罪行，然后召唤光柱落下。第二章讨论如何应对不同类型的敌人：对亡灵会直接造成巨大伤害，对恶魔会灼烧其本质，而对被魅惑或胁迫的无辜者则会以净化代替伤害。作者警告，若目标确实有罪但施术者证据不足，裁决会部分失效。后半部收录了历史上几位大审判官使用圣光裁决的案例，每次都伴随着庄严的宣告与冲天光柱。最末页的插图是一名审判官将法典高举过头，一道光柱从天而降，将一名黑袍法师笼罩其中。圣光裁决是信仰系在剧情高潮中的标志性技能。

## 设计意图

为信仰系提供兼具仪式感与控制效果的强力攻击技能，作为审判主题的终极表达。
