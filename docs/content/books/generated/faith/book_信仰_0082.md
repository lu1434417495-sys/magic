# 《圣歌咏唱》

## 基础信息

- **书籍 ID**：`book_信仰_0082`
- **关联技能**：`faith_holy_chant`
- **使用效果**：阅读后解锁 `faith_holy_chant`；若已学会，提升该技能 `current_mastery +80`，并使咏唱期间范围内友方攻击力提升 10%。
- **阅读要求**：角色职业标签含 `priest`、`cleric` 或 `bard`；基础 `信仰 ≥ 8` 或 `魅力 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：教堂唱诗班、战地牧师训练营、团队增益任务奖励。

## 书籍内容

《圣歌咏唱》教导牧师如何通过歌声传递信仰，使听到歌声的友方获得勇气与力量。书中指出，圣歌不是表演，而是一种集体的祈祷，每个音符都应当承载真诚的祝愿。第一章讲解发声技巧，包括如何用腹腔共鸣代替喉部挤压，以及如何在移动中保持音准。第二章讨论不同战况下应选择的圣歌类型：进攻时选择节奏明快的战歌，防守时选择沉稳的守护曲，撤退时选择安抚人心的挽歌。作者警告，若咏唱者心怀恐惧，歌声会传播不安，反而削弱队友。后半部收录了十二首完整的圣歌乐谱与歌词，每首都对应特定的战场情境。书中还提到，圣歌可以与信仰共鸣叠加，多名牧师合唱时效果会呈几何级增长。最末页的插图是一群士兵在战壕中合唱，前方的牧师高举法器，音符化作光芒飞向每个人的胸口。圣歌咏唱让信仰系拥有了独特的团队增益与氛围塑造能力。

## 设计意图

为信仰系设计持续吟唱型团队增益技能，丰富牧师的战斗节奏与团队协作方式。
