# 《信仰之壁的砌筑》

## 基础信息

- **书籍 ID**：`book_faith_0021`
- **关联技能**：`faith_faith_wall`
- **使用效果**：阅读后解锁 `faith_faith_wall`；若已学会，提升该技能 `current_mastery +100`，并提高护盾对物理冲击的吸收量 15%。
- **阅读要求**：角色拥有 `holy`、`warrior` 或 `paladin` 标签职业；基础 `体质 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：要塞礼拜堂、城墙守卫任务、圣骑士盾墙训练。

## 书籍内容

信仰之壁的砌筑把抽象的信仰比喻成可以一层层垒起来的墙。书中把墙的构成分为基座、承重层、透气层与顶冠，每一层对应一种心灵状态：谦卑、承担、希望与交托。作者详细讲解了砌墙时的手势，要求每放一块石头都说出一句让它留下的理由，而不是默念咒语。最实用的章节是"紧急修补"：当护盾出现裂缝时，如何用最短的时间重新念诵三句核心信念来阻止崩溃。书中还附有一张古老的要塞图纸，显示信仰之壁曾经真的被用来加固过一段城墙，虽然现代学者怀疑那只是象征性的仪式。封面上的题词写道："墙的意义不在于永远不倒，而在于倒下之前为人们争取到转身的时间。"在实战训练中，圣骑士会用木槌敲击砌好的墙，若声音清脆，便说明信念没有空洞。这种检验方法让许多初学者意识到，信仰之壁首先是对自己内心的考验。

## 设计意图

为信仰系前排提供强力物理护盾，通过"砌筑"概念把防御行为仪式化，强化战棋中的阵地守护体验。
