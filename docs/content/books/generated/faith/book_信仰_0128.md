# 《异端辨析录》

## 基础信息

- **书籍 ID**：`book_信仰_0128`
- **关联技能**：`faith_heresy_lore_128`
- **使用效果**：阅读后解锁知识 `lore_faith_heresy_128` 并提升 `faith_heresy_lore_128` 的 `current_mastery +100`；若已学会，对 `heretic` 标签敌人造成的伤害提高 10%。
- **阅读要求**：角色职业标签含 `priest` 或 `inquisitor`；基础 `智力 ≥ 8` 或 `意志 ≥ 8`。
- **稀有度**：精良（Uncommon）
- **建议投放**：审判庭图书馆、教会暗室、异端调查任务。

## 书籍内容

辨析录并非猎杀手册，而是一部教人识别“信仰变形”的指南。作者把异端分为三类：因恐惧而极端、因权力而篡改、因孤独而自造神明。书中强调，真正的敌人不是怀疑，而是“把怀疑包装成绝对答案”。后半部分列出历史上几次著名异端运动的共同特征：排斥忏悔、神化领袖、把苦难当作功绩。最末页有一段被反复涂改的话：“你能辨出异端，不等于你有权焚烧它；火可以净化，也可以把所有真相都变成灰烬。”作者在结语处提醒：异端辨析录本身也可能被误用为排除异己的工具，因此每位读者在合上它之前，必须先用其中一条标准审视自己。书中还建议读者在辨析他人之前，先写下自己最近一次把不确定当作确定的经历，以防同样的变形正在自己身上发生。辨析录的最后一页贴着一张纸条，写着：如果你读完此书后只想找出一个敌人，请把它放回书架最高处。

## 设计意图

以知识解锁形式扩展信仰系对特定敌人的克制，同时避免异端题材流于简单化反派塑造。
