# 《神恩分配律》

## 基础信息

- **书籍 ID**：`book_信仰_0124`
- **关联技能**：`faith_divine_distribution_124`
- **使用效果**：阅读后解锁 `faith_divine_distribution_124`；若已学会，提升该技能 `current_mastery +100`，并使对单一友方治疗时 20% 的治疗溢出会传递给最近的其他友方。
- **阅读要求**：角色拥有 `holy` 或 `support` 标签职业；基础 `意志 ≥ 9`。
- **稀有度**：稀有（Rare）
- **建议投放**：教会大学、战地医院、大主教书房。

## 书籍内容

分配律挑战了“治疗越多越好”的直觉。作者指出，过量的光会对脆弱身体造成灼烧，因此真正的神恩必须被分配、转接、稀释。书中提出“治疗网格”概念：施术者不再是单向输出，而是把光拆成多股细流，让最需要的人得到最多，让已经饱和的人得到刚好足够维持的量。后半部分用战场案例说明错误分配的后果：一名牧师把过多光芒注入重伤员，导致其短暂失明。最末页写着：“神恩不是瀑布，而是灌溉渠；你的职责不是倾泻，而是让每一滴水抵达该去的地方。”作者在案例后附有一张表格，列出不同体质的人能承受的光量上限，并强调超过上限的治疗不是恩赐，而是另一种形式的烧伤。书中还提醒，分配时必须告诉受术者自己正在得到多少，否则光会在对方不知情时灼伤其骄傲。作者在最后提醒：治疗网格最难分配的对象，往往不是最需要的人，而是那个最不愿意承认自己需要的人。

## 设计意图

为治疗技能增加溢出分配机制，鼓励牧师在治疗时考虑团队整体资源分布。
