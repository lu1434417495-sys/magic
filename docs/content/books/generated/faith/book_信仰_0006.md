# 《圣餐杯的清洁仪式》

## 书籍内容

圣餐杯的清洁仪式听起来琐碎，却是许多年轻祭司真正的第一课。书中把清洁分为七步：清空残液、温水冲洗、盐搓内壁、亚麻布擦拭、日光晾晒、反向检查、最后以一句短祷封存。作者不厌其烦地解释，残留的水渍会变成下一任饮用者的杂念，而一丝指纹油垢可能让祝福在杯壁打滑。中间章节收录了十二种不同材质杯具的养护法，从陶土到纯银再到水晶，每一种都需要不同的耐心。最有趣的是一则轶事：某位老祭司坚持在清洁时唱歌，因为他发现某些旋律能让水面张力改变，从而带走肉眼看不见的污垢。书的附录列出了一周清洁轮值表，提醒读者：神圣不在杯子里，而在愿意反复清洗杯子的那只手中。书中还提醒，清洁后的第一滴水应当倒掉，因为它承载的是上一场的余韵，而不是新一场的祝福。这种看似多余的步骤，却被历代祭司视为最不可省略的敬意。

## 设计意图

通过日常仪式强化治疗职业的沉浸感，把道具效果增益包装成"认真准备圣餐"的行为奖励。
