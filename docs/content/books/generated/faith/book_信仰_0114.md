# 《庇护所布设法》

## 基础信息

- **书籍 ID**：`book_信仰_0114`
- **关联技能**：`faith_sanctuary_114`
- **使用效果**：阅读后解锁 `faith_sanctuary_114`；若已学会，提升该技能 `current_mastery +100`，并可在战斗中布设一片持续 3 回合的 3×3 庇护区域，阻挡敌方移动并治疗区域内友方。
- **阅读要求**：角色拥有 `holy` 或 `support` 标签职业；基础 `意志 ≥ 9`。
- **稀有度**：稀有（Rare）
- **建议投放**：城市防御战、神殿地下密室、高地牧师传承。

## 书籍内容

庇护所布设法是阵地战中的核心神术，能在混乱战场上划定一片短暂的安全区域。书中将庇护所比作“把祈祷折叠成墙壁”，施术者需要在地面上用圣盐或灰烬画出一个闭合图形，然后将自己的意志注入边界。作者提醒，庇护所的真正边界不在图形内，而在所有相信它的人心中；一旦有人开始怀疑，墙壁就会出现裂缝。后半部分记录了一次经典防御战：三十名平民在牧师布下的庇护所中等待援军，最终靠集体信念维持了远超时限的防御。作者在章节末尾附有一张避难者签名页，显示所有曾在庇护所中存活的人都在战后回函确认：他们之所以能安静等待，是因为边界外有人相信它存在。书中还说明，庇护所无法阻挡物理破坏，但能阻止带有敌意的生物穿越。最末页写着：“庇护所不是拒绝危险，而是让危险不得不绕路。”

## 设计意图

为战棋地形玩法增加信仰系控制/治疗区域，强调阵地固守与团队协作。
