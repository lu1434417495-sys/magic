# 《圣所结界的维护》

## 基础信息

- **书籍 ID**：`book_faith_0044`
- **关联技能**：`faith_sanctuary_ward`
- **使用效果**：阅读后解锁 `faith_sanctuary_ward`；若已学会，提升该技能 `current_mastery +90`，并延长营地或据点防护结界的持续时间 50%。
- **阅读要求**：角色拥有 `holy`、`cleric` 或 `leader` 标签职业；基础 `智力 ≥ 8`。
- **稀有度**：稀有（Rare）
- **建议投放**：据点建设任务、修道院维护支线、防御战役奖励。

## 书籍内容

圣所结界的维护把据点防御变成一场持续的信仰劳动。书中首先指出，结界不是一次性的咒语，而是需要每天修补的网状结构，任何一处松懈都会成为敌人的突破口。作者详细介绍了日常维护清单：清晨检查边界石是否移动、正午补充盐线、黄昏更换烛火、午夜静默巡视。最实用的章节是"应急修补"：当结界被攻破时，如何用最快的方式用身体与祷词暂时堵住缺口。书中还强调，结界的力量来自居住者对它的信任，如果据点内部充满猜忌，再完美的仪式也无法维持。附录里有一份居民心理评估表，帮助管理者识别哪些人的不安正在削弱结界。在一些边境要塞，结界维护被纳入军功考核，因为历史证明，内部崩溃比外部强攻更致命。这种制度虽然严苛，却也让居民学会了把集体安全放在个人情绪之上。

## 设计意图

为信仰系提供据点/营地防御增益，把资源管理与居民心理状态联系起来，扩展信仰玩法到基地建设层面。
