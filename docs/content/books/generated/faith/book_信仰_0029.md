# 《圣油淬炼之法》

## 基础信息

- **书籍 ID**：`book_faith_0029`
- **关联技能**：`faith_holy_oil`
- **使用效果**：阅读后解锁 `faith_holy_oil`；若已学会，提升该技能 `current_mastery +90`，并提高对武器与护甲进行神圣附魔的成功率 8%。
- **阅读要求**：角色拥有 `holy`、`blacksmith` 或 `alchemist` 标签职业；基础 `感知 ≥ 8`。
- **稀有度**：稀有（Rare）
- **建议投放**：大教堂工坊、锻造师行会、圣骑士后勤营。

## 书籍内容

圣油淬炼之法把信仰注入金属与皮革的工艺。书中首先讲解了基础油料的制作：橄榄油、蜂蜡、没药与一小撮教堂香灰，在低温下搅拌七七四十九次。作者指出，淬炼的关键在于搅拌者的心态，任何一次敷衍都会让圣油在第二天分层。接下来的章节讨论如何将圣油涂抹在武器上：不是越多越好，而是要在刃口形成一层几乎看不见的薄膜，这样挥砍时才会带出一道短暂的光。护甲附魔则需要把圣油滴入接缝，让神圣从内部支撑结构。书中还收录了如何判断圣油是否失效：滴在铁上若发出轻微嘶鸣，则仍有效；若只是铺开，则已成普通油脂。封底写着："金属会疲劳，但意志如果足够纯净，油就能重新唤醒它。"圣骑士团的锻造室里，学徒第一件独立完成的作品往往不是武器，而是一瓶合格的圣油。这种传统强调，战士首先应当成为信仰的容器。

## 设计意图

为信仰系提供装备附魔辅助，连接锻造与炼金系统，让玩家体验到信仰不仅是战斗技能，也是日常生活技艺。
