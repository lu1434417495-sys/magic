# 《灵魂牧养手札》

## 基础信息

- **书籍 ID**：`book_信仰_0132`
- **关联技能**：`faith_soul_shepherd_132`
- **使用效果**：阅读后解锁 `faith_soul_shepherd_132`；若已学会，提升该技能 `current_mastery +100`，并在战斗中当一名友方倒下时，周围 2 格内其他友方获得持续 2 回合的意志 +10% 增益。
- **阅读要求**：角色拥有 `holy` 或 `support` 标签职业；基础 `意志 ≥ 9`。
- **稀有度**：稀有（Rare）
- **建议投放**：灵魂牧场、临终牧者小屋、军团抚恤官。

## 书籍内容

手札把牧师的工作定义为“灵魂的牧者”，而不仅仅是伤口的处理者。作者认为，人在濒死时会经历三种恐惧：被遗忘、无意义、孤独。灵魂牧养的任务不是消除死亡，而是让临终者相信自己被看见、被记得、被允许离开。书中详细记录了陪伴临终者的手势与话语，提醒牧师不要急于祈祷，而要先握住对方的手。后半部分讨论了战后队伍的心理修复：如何为没有遗体的死者立碑，如何允许生者愤怒。最末页写着：“你不是在送他们上路，你是在确保路的那一端，也有人叫得出他们的名字。”作者在手札边缘写道：牧者不是答案的供应者，而是陪伴者；你能给的最后礼物，是让对方在离开时不觉得自己是个失败者。书中还附有一段简短的“归来礼”，帮助生者在战斗后与死者的记忆重新建立连接。手札的最后一章讨论了“未亡人的愤怒”，作者认为允许生者恨，是让他们最终能够原谅的前提。

## 设计意图

为支援角色赋予阵亡响应增益，用临终关怀主题强化情感冲击与团队韧性。
