# 《殉道者遗言的解读》

## 基础信息

- **书籍 ID**：`book_faith_0016`
- **关联技能**：`faith_martyr_words`
- **使用效果**：阅读后解锁 `faith_martyr_words`；若已学会，提升该技能 `current_mastery +110`，并在阵亡时为相邻队友回复生命与 MP。
- **阅读要求**：角色拥有 `holy` 或 `zealot` 标签职业；基础 `意志 ≥ 11`。
- **稀有度**：史诗（Epic）
- **建议投放**：殉道者陵墓深处、悲壮战役战利品、信仰试炼最终奖励。

## 书籍内容

殉道者遗言的解读是一本教人如何倾听死亡之言的书，而不是教人如何去死。书中收集了三十七位殉道者的最后话语，按主题分为"警告"、"托付"、"宽恕"与"未见之梦"。作者指出，这些遗言的真正价值在于它们被说出时的上下文：周围有谁、敌人从哪个方向来、天空是什么颜色。最珍贵的章节是一位无名修士用血写下的注解，他认为殉道者的话语之所以仍有力量，是因为死亡替他们完成了最后的筛选——只有最真实的念头能留在最后。书中提醒施术者，解读遗言时不要急于给出意义，而应先把话语原样转述给听众。附录里有一页被撕去，只剩下一句："我留下的不是答案，是让你们继续问下去的勇气。"在战地教堂，年轻祭司会被要求背诵其中至少十段遗言，以便在最混乱的时刻仍能传达逝者的声音。这种训练被视为信仰者最基本的责任之一。

## 设计意图

用"牺牲后的团队增益"机制强化信仰系的高风险奉献精神，同时让死亡在战棋中拥有情感与战术重量。
