# 《信仰护盾》

## 基础信息

- **书籍 ID**：`book_信仰_0058`
- **关联技能**：`faith_aegis`
- **使用效果**：阅读后解锁 `faith_aegis`；若已学会，提升该技能 `current_mastery +80`，并使护盾被击破时对周围 1 格敌人造成轻微神圣反伤。
- **阅读要求**：角色职业标签含 `priest`、`cleric` 或 `paladin`；基础 `信仰 ≥ 8`。

- **建议投放**：防御型牧师训练场、圣骑士营地、中低级副本宝箱。

## 书籍内容

护盾不是墙，而是一份信念的实体化。《信仰护盾》从最简单的护心镜开始教起，要求练习者将手掌按在胸口，想象自己相信的一切正在皮肤之外凝聚成一层薄膜。书中指出，护盾的强度与施术者的信仰稳定度直接相关，恐惧、怀疑或愤怒都会让护盾出现裂纹。第一章详细讲解三种起手式：单手施放适合快速应急，双手合十适合强化自身，高举法器则适合保护队友。第二章分析不同伤害类型对护盾的侵蚀速度，其中暗影与诅咒伤害最为危险。后半部提供了一套修复护盾的训练方法，即在护盾未完全破碎前主动补充信仰，使其恢复完整。最后一页的插图展示了一面半透明圆盾，盾面上浮现出施术者默念的祷词。许多前线牧师将信仰护盾视为生命线，它虽不能直接杀敌，却能让队友敢于冲锋。

## 设计意图

为信仰系提供基础个人/单体防御技能，作为庇护之光之外的轻量保护选项。
