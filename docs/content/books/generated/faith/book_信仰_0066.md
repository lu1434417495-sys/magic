# 《信仰跃迁》

## 基础信息

- **书籍 ID**：`book_信仰_0066`
- **关联技能**：`faith_leap`
- **使用效果**：阅读后解锁 `faith_leap`；若已学会，提升该技能 `current_mastery +80`，并使落点周围 1 格友方获得短暂移动力加成。
- **阅读要求**：角色职业标签含 `priest`、`cleric` 或 `paladin`；基础 `敏捷 ≥ 8` 或 `信仰 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：机动牧师训练营、跳跃竞技任务、前线突袭战奖励。

## 书籍内容

信仰不仅能让人站稳，也能让人飞跃。《信仰跃迁》是一种将神力灌注双腿，使施术者在短时间内跨越远距离的战技。书中把跃迁分为"起跳"、"悬空"、"着陆"三个阶段，每个阶段都需要精准的信仰控制。第一章讲解如何在起跳瞬间将神力向下爆发，借助反作用力升空。第二章讨论悬空中的方向调整，指出恐惧是跃迁失败的最大原因，因为慌乱会让神力提前消散。后半部提供了一系列训练方法，包括从矮墙到悬崖的渐进式练习，以及如何在着陆时保护膝盖与脚踝。书中还警告，跃迁落地后的短暂僵直是最危险的时刻，必须提前规划落点周围的安全。最末页的插图是一名牧师身披光芒跃过断裂的桥梁，下方是深渊与敌军的箭矢。作者写道："当你信任脚下的不是土地，而是信仰时，你就学会了飞翔。"信仰跃迁为牧师提供了宝贵的机动性，弥补了传统布甲职业移动不足的短板。

## 设计意图

为信仰系提供位移技能，打破牧师"站桩治疗"的刻板印象，增加战术机动空间。
