# 《神圣附体浅说》

## 书籍内容

浅说用冷静的笔调描述一种危险的神术：让神圣存在短暂借用施术者的身体。作者警告，附体不是获得力量，而是“被力量借用”。书中要求施术者在附体前写下三句话：自己为何需要、愿意付出什么、以及必须保留的底线。附体期间，施术者的声音、动作、甚至瞳孔都会改变，但意识仍有一部分保持清醒。后半部分记录了历代成功与失败的附体案例，失败者多为贪恋那份超越感而拒绝退出。最末页写着：“圣人离开你的身体时，你要还能认得镜子里的自己。”作者在警告栏里用粗体字写道：神圣附体最危险的不是失去身体控制权，而是你发现“被借用”的自己比平时更强大、更受尊敬，于是开始渴望再次被借用。书中还附有一份退出后的恢复食谱，强调附体后七天内必须避免再次施放高强度神术。
