# 《初阶圣光祷言》

## 基础信息

- **书籍 ID**：`book_信仰_0101`
- **关联技能**：`faith_holy_light_101`、`priest_holy_tag`
- **使用效果**：阅读后解锁 `faith_holy_light_101`；若已学会，提升该技能 `current_mastery +60`，并为最近一名友方恢复少量 `current_hp`。
- **阅读要求**：无职业限制；基础 `意志 ≥ 6`。
- **稀有度**：普通（Common）
- **建议投放**：新手村教堂、牧师引导任务、初级圣物箱。

## 书籍内容

这本书的扉页印着一行小字：“光不会挑选 worthy 的人，只挑选愿意伸出手的人。”正文用极短的句子列出圣光祷言的节奏：吸气、抬手、念出音节、让光从掌心漏出。作者强调圣光不是攻击的延伸，而是意志的倒影；若施术者心怀炫耀，光芒会变得刺眼却空洞。书中还记录了一位老牧师在暴风雨中维持烛火的故事，说明稳定意图比宏大咒语更重要。后半部分是每日晨祷的固定词，作者建议读者不要背诵，而是用自己的话重新组织，因为信仰的语言只有在属于个人时才会被光承认。作者特意在每一章结尾留出空白，要求读者写下自己最近一次感到不配被帮助的时刻，因为他认为承认脆弱比掌握手势更能召唤光。附录里画着九种手势，从完全张开到轻握，每一种对应不同的光量。最后一页被撕去一半，只剩一句话：“当你不再证明自己值得被救，光就来了。”

## 设计意图

作为信仰系最基础的技能入口，让玩家在解锁圣光攻击/治疗双用技能的同时，建立“意志即光源”的叙事基调。
