# 《圣徽投掷要旨》

## 基础信息

- **书籍 ID**：`book_信仰_0126`
- **关联技能**：`faith_symbol_throw_126`
- **使用效果**：阅读后解锁 `faith_symbol_throw_126`；若已学会，提升该技能 `current_mastery +80`，并使投掷圣徽造成远程神圣伤害，对亡灵标签敌人有 25% 概率眩晕 1 回合。
- **阅读要求**：角色职业标签含 `priest` 或 `inquisitor`；基础 `敏捷 ≥ 7` 或 `意志 ≥ 8`。
- **稀有度**：精良（Uncommon）
- **建议投放**：异端审判官营地、遗迹探险队、圣物回收任务。

## 书籍内容

要旨教读者如何把沉重的圣徽当作远程武器掷出。作者认为投掷圣徽不是亵渎，而是“让信仰到达手够不到的地方”。书中讲解了三种投掷手法：直飞用于精准打击，回旋用于绕过掩体，落地用于布设临时净化区。后半部分讨论圣徽材质：银制容易偏转但净化力强，铁制稳定但沉重，木制适合非致命惩戒。最末页警告：若投掷者心中没有具体要保护的对象，圣徽会在空中熄灭。旁边画着一只手甩出圣徽的分解动作，批注：“光离开你的瞬间，必须知道它要去哪里。”作者在章节之间插入了几页练习靶纸，提醒读者圣徽的飞行轨迹会暴露投掷者的真实意图，愤怒会让它下坠，怜悯会让它偏高。书中还提到，投掷圣徽后必须行一个短暂的回收礼，否则下次投掷时光会迟疑。要旨的末尾还有一段回收礼的口诀，强调圣徽落地后必须先向它道歉，因为它替你走完了手够不到的路。

## 设计意图

为审判官/牧师提供远程控制手段，把圣物从装饰扩展为战术道具。
