# 《赎罪鞭笞》

## 基础信息

- **书籍 ID**：`book_信仰_0053`
- **关联技能**：`faith_penance_lash`
- **使用效果**：阅读后解锁 `faith_penance_lash`；若已学会，提升该技能 `current_mastery +85`，并使下一次以自身伤害为代价的神术伤害提升 15%。
- **阅读要求**：角色职业标签含 `priest`、`cleric` 或 `flagellant`；基础 `信仰 ≥ 9`。
- **稀有度**：稀有（Rare）
- **建议投放**：苦修院密室、赎罪者据点、高阶牧师转职任务。

## 书籍内容

《赎罪鞭笞》是一本被封存在苦修院禁书区的薄册，封面用未鞣制的皮革包裹，翻阅时会散发淡淡的血腥味。书中主张，疼痛是信仰最诚实的语言，只有透过肉体的代价，灵魂才能与神明真正对话。开篇详细记载了一种特殊的鞭笞节奏：九下轻、一下重，对应十诫。第二章解释如何将自我伤害转化为神圣能量，使下一次攻击或治疗附带净化效果。作者反复强调，此术绝非自残表演，动机不纯者会陷入失血与疯狂的恶性循环。后半部收录了多位殉道者的手记，他们描述在极限疼痛中看见的白色光晕，以及随之而来的平静。书中还特别强调，练习者必须在每次鞭笞后默数呼吸，避免因肾上腺素淹没理智。最末页只有一枚干涸的血指印，旁边写着："愿你打出的每一鞭，都是为了背负他人的罪。"赎罪鞭笞在信仰系中属于高风险高回报的技能，常被用于绝境中的爆发，也是苦修者证明自身虔诚的最直接方式。

## 设计意图

为信仰系引入以自身健康换取神力的极端玩法，丰富牧师职业的战术深度与角色扮演空间。
