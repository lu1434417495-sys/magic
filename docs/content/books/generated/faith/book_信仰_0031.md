# 《神恩标记的赐予》

## 基础信息

- **书籍 ID**：`book_faith_0031`
- **关联技能**：`faith_blessing_mark`
- **使用效果**：阅读后解锁 `faith_blessing_mark`；若已学会，提升该技能 `current_mastery +80`，并使被标记队友在下次受击时获得一次伤害减免。
- **阅读要求**：角色拥有 `holy` 或 `support` 标签职业；基础 `意志 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：军营随军牧师、冒险者公会、新手祝福仪式。

## 书籍内容

神恩标记的赐予是一本关于如何把祝福画在他人身上的小册子。书中介绍了三种最常见的标记：额前横线代表洞察，肩胛圆环代表守护，手心短竖代表行动。作者强调，赐予标记时必须明确说出祝福的具体内容，模糊的"愿神保佑你"会让标记的力量散失。操作章节详细描述了手指蘸取圣水的顺序、画线的方向、以及念完最后一词后必须把手掌按在标记上停留多久。最有趣的章节讨论被赐予者的反应：有人会觉得温暖，有人会觉得刺痛，还有人什么感觉都没有，但这并不代表标记无效。书末附有一张常见问题解答，第一条就写着："神恩标记不是保险，它是一次被记住的选择。"许多老牧师把它当作给新手冒险者的临别礼物。在动荡的边境，父母常在子女离家前亲手画上守护圆环，哪怕他们自己并不精通神术。这种家庭仪式让神恩标记超越了战斗，成为亲情与告别的一部分。

## 设计意图

为信仰系提供低阶预防性保护，把"祝福"从抽象叙事转化为具体的减伤触发，降低新玩家的学习门槛。
