# 《灰喉圣咏的抑扬》

## 基础信息

- **书籍 ID**：`book_faith_0034`
- **关联技能**：`faith_ashen_chant`
- **使用效果**：阅读后解锁 `faith_ashen_chant`；若已学会，提升该技能 `current_mastery +110`，并在灰烬交界环境中提高全队抗性 8%。
- **阅读要求**：角色拥有 `holy` 或 `cleric` 标签职业；基础 `意志 ≥ 9`。
- **稀有度**：史诗（Epic）
- **建议投放**：灰烬交界据点、炭化大教堂残部、异界入侵事件。

## 书籍内容

灰喉圣咏是灰烬交界幸存者们发明的一种特殊唱法，它的音节被设计得能在充满灰烬的空气中传播而不被吞噬。书中首先训练读者压低喉头，让声音从胸腔而不是鼻腔发出，因为高频会被灰烬迅速吸收。接着讲解抑扬的变化：在灰雾浓厚时降低音调，在敌人靠近时加快节奏，在同伴倒下时延长尾音，让悲伤成为可传递的信号。作者特别提到，灰喉圣咏的歌词往往不完整，因为完整的句子在异界会被扭曲；碎片化的词语反而更安全。最珍贵的一章是一位老神父在失明后凭记忆写下的乐谱，旁边批注："不要唱得太美，灰烬会记住好听的声音。"书页上沾着洗不净的灰色污渍。灰烬交界的前哨站把灰喉圣咏当作通讯手段，不同小队拥有不同的碎片组合，用来在能见度为零时确认身份。敌对的灰烬生物有时也会模仿这些音节，所以应答时必须包含只有战友知道的错拍。

## 设计意图

为信仰系提供灰烬交界专属的环境抗性，通过"灰喉圣咏"把异界威胁与信仰表达的独特变体结合起来。
