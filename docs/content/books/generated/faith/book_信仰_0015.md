# 《信标光的聚敛》

## 基础信息

- **书籍 ID**：`book_faith_0015`
- **关联技能**：`faith_beacon_focus`
- **使用效果**：阅读后解锁 `faith_beacon_focus`；若已学会，提升该技能 `current_mastery +100`，并提高对隐身或暗处敌人的侦测范围 1 格。
- **阅读要求**：角色拥有 `holy`、`ranger` 或 `cleric` 标签职业；基础 `感知 ≥ 9`。
- **稀有度**：稀有（Rare）
- **建议投放**：边境瞭望塔、迷雾森林祭坛、斥候营地书架。

## 书籍内容

信标光的聚敛教导信仰者如何把分散的祈祷压缩成一束可辨识的光。书中先用棱镜做比喻：白光之所以软弱，是因为它包含太多意图；只有让意志像狭缝一样过滤，才能得到锐利的指向。练习者需要在日出时盯着远处的地平线，把自己的一声默念送向一个具体目标，比如某棵树或某块石头。作者警告，初学者最常见的错误是把光"散播"出去，结果谁也没照亮。中级章节讲解如何让光在命中目标后折返，带来关于目标状态的信息：颜色变淡说明对方虚弱，颜色发紫说明对方怀有恶意。书末有一张炭化大教堂的修复草图，标注了原址上曾有七道光束交汇的位置，被称为"七眼井"。边境哨站的瞭望员常借信标光确认远处商队是否平安，因为普通火光在灰雾中无法传递状态信息。这种应用让聚敛技巧从教堂走向了更广阔的荒野。

## 设计意图

为信仰系提供侦查与反隐能力，拓展信仰在战棋中的战术维度，同时用"聚敛"概念呼应冥想与专注力训练。
