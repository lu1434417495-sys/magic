# 《遗物修复笔记》

## 书籍内容

笔记记录了修复破损圣物的方法。作者认为遗物不是工具，而是“被时间磨损过的见证”，因此修复它们需要耐心而非强力法术。书中把修复分为清洁、补裂、重注祝福三步，每一步都要求施术者先了解遗物的历史。后半部分讨论了“修复伦理”：有些裂痕应该保留，因为它们记录了某场战役或某位圣人。最末页是一张残破圣杯的修复示意图，批注：“你不一定要把它恢复原状，你只需要让它还能继续承载祝福。”作者在笔记最后写道：遗物修复师的工作不是让过去看起来不曾发生，而是让过去继续以有限但真实的方式存在下去。书中还提到，修复时必须使用与原作相同来源的材料，否则重注的祝福会排斥异物。遗物修复笔记的封底写着：真正的修复不是让遗物焕然一新，而是让它继续以伤痕的形式陪伴下一位主人。
