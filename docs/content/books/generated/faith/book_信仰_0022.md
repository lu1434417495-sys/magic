# 《唱诗班和声训练》

## 基础信息

- **书籍 ID**：`book_faith_0022`
- **关联技能**：`faith_choir_harmony`
- **使用效果**：阅读后解锁 `faith_choir_harmony`；若已学会，提升该技能 `current_mastery +90`，并提高相邻队友的技能命中率 6%。
- **阅读要求**：角色拥有 `holy`、`support` 或 `bard` 标签职业；基础 `感知 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：大教堂唱诗班、吟游诗人学院、军营士气官。

## 书籍内容

唱诗班和声训练把信仰表达拆分成可协作的声音工程。书中先让读者单独练习母音的延长，确保每个人都能在不颤抖的前提下保持稳定气息。接着进入二声部练习，要求低音声部像地基一样托住高音声部，而高音声部则要像光一样不被重量压弯。作者反复提醒，和声的目的不是突出某个人，而是让多个不完美声音共同构成一个更完整的形状。书中收录了七首适合战前与战后的短曲，每一首都有明确的节拍与换气点。最有趣的章节讨论"错误之美"：当某个声部短暂走音时，其他声部应当轻轻抬高自己以填补空洞，而不是指责。书的封面画着五张并列的嘴，每一张都吐出不同颜色的音符，在空中交汇成一枚光环。军营里的唱诗班通常由伤兵组成，因为他们沙哑的声音被认为最接近大地的共鸣。这种传统让和声训练从教堂走向了战场。

## 设计意图

强化信仰系辅助的团队增益定位，把"合唱"机制转化为相邻命中率加成，鼓励阵型集中与协作。
