# 《信徒行军令》

## 基础信息

- **书籍 ID**：`book_信仰_0131`
- **关联技能**：`faith_march_order_131`
- **使用效果**：阅读后解锁 `faith_march_order_131`；若已学会，提升该技能 `current_mastery +80`，并使队伍在世界地图上接下来 3 次移动获得移动力 +1。

- **建议投放**：军队随军牧师、行军营地、远征任务。

## 书籍内容

行军令是供随军牧师在长途行军前诵读的短文集。它不是魔法咒语，而是一套让队伍在疲惫中保持节奏的心理仪式。书中要求牧师在行军中不断复述同一组短句，让士兵的脚步、呼吸与祷文同步。作者指出，最危险的时刻不是遭遇战，而是行军第三天后的沉默，那时人会开始怀疑战斗的意义。后半部分收录了不同地形下的行军变体：山地强调省力的呼吸，沼泽强调脚步的稳定，沙漠强调对水的感恩。最末页写着：“你带他们走的不是路，是信念；只要脚步还在响，他们就还没有被绝望追上。”作者在开篇指出，真正让队伍溃散的往往不是敌人，而是连续行军时每个人心里反复出现的同一个问题：这一切到底值不值得。书中还提醒，行军令不得在夜晚高声诵读，以免暴露位置。行军令的附录里有一套口令表，供指挥官在不能出声时使用，据说这些手势最早来自一支被围困的修道院守军。

## 设计意图

把信仰叙事延伸至大世界移动，为远征/探索玩法提供轻度增益。
