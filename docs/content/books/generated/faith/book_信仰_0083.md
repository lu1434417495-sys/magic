# 《信仰印记》

## 书籍内容

《信仰印记》教导牧师如何在目标身上留下神圣标记，使其在特定条件下触发预先设定的效果。书中把印记比作一封写给未来的祈祷：施术者在当下写下，神明在未来某刻回应。第一章讲解印记的绘制方法，可以用手指、法器尖端或圣水在物体或生物表面留下痕迹。第二章讨论常见的印记类型：守护印记在受到伤害时触发护盾，审判印记在目标作恶时造成伤害，引导印记则能帮助施术者追踪目标位置。作者警告，印记的持续时间与施术者的信仰稳定度相关，若施术者后来背叛信仰，自己留下的印记会反噬自身。后半部收录了多种印记组合技巧，例如将守护印记与审判印记叠加形成复杂的触发条件。最末页的插图是一只手在空气中留下发光的符文，符文缓缓沉入目标的胸口。信仰印记是信仰系灵活的战术预设技能。

## 设计意图

为信仰系提供陷阱/预设类技能，使牧师能够提前布局，增强战术准备深度。
