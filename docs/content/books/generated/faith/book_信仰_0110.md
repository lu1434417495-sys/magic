# 《神圣联结仪式》

## 基础信息

- **书籍 ID**：`book_信仰_0110`
- **关联技能**：`faith_divine_link_110`
- **使用效果**：阅读后解锁 `faith_divine_link_110`；若已学会，提升该技能 `current_mastery +100`，并允许在战斗中与一名友方分担 20% 所受伤害。
- **阅读要求**：角色拥有 `holy` 或 `support` 标签职业；基础 `意志 ≥ 9`。
- **稀有度**：稀有（Rare）
- **建议投放**：高阶牧师传承任务、圣所密室、联军指挥所。

## 书籍内容

神圣联结仪式是圣职系高阶辅助技能，允许施术者将一名队友的命运暂时与自己绑定。书中强调联结不是控制，而是一种“被允许的负重”。仪式开始前，双方必须各自说出自己最害怕失去的东西，以确保联结建立在真实之上。作者警告，单方面维持联结会迅速耗尽施术者的心神，因此必须约定解除手势。后半部分记录了几场著名战役中的联结使用：一名老牧师与年轻战士联结，替她承受了致命一箭。作者在倒数第二章列出了三种解除联结的紧急情况，并强调最危险的解除不是外力打断，而是其中一方在心里已经悄悄松手。书中还提醒，联结期间双方会共享梦境与疼痛，因此不适合与不信任的人缔结。最末页写着：“联结的终点不是牺牲，而是让两个人都相信，他们不会再独自面对结局。”

## 设计意图

为信仰系提供高阶伤害转移机制，强化团队协作与情感叙事，同时通过代价约束避免滥用。
