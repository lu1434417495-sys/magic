# 《圣徽铸印术》

## 基础信息

- **书籍 ID**：`book_信仰_0052`
- **关联技能**：`faith_seal_engraving`
- **使用效果**：阅读后解锁 `faith_seal_engraving`；若已学会，提升该技能 `current_mastery +80`，并允许在战斗中临时为一件武器铭刻持续 3 回合的圣徽。
- **阅读要求**：角色职业标签含 `priest` 或 `paladin`；基础 `智力 ≥ 7` 或 `信仰 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：教会工坊、圣骑士训练营、铁匠与牧师联合任务奖励。

## 书籍内容

圣徽并非只是挂在胸前的装饰品，它是信仰的物质锚点。《圣徽铸印术》详细记录了如何将祷言以特定纹路刻入金属、木材甚至石料之中。作者认为，铸印的关键不在于雕刻技艺，而在于每一下凿击都必须伴随默念。书中把圣徽分为三类：守护型、惩戒型与净化型，每类的符文走向截然不同。第一章用大量插图展示握锤与执笔的姿势，强调手腕必须放松，否则纹路会携带铸印者的焦躁，导致圣徽在关键时刻碎裂。第二章讲解材料选择，指出银对净化型最友好，而黑铁更适合承载惩戒之力。后半部是一份失败案例集，记载了七枚因心念不纯而爆裂的圣徽。最后一页附有一张空白拓片，批注写道："先在心里刻好，再动锤子。"许多前线圣骑士依靠此术在远征途中维护装备，使其始终保持神圣锋芒。

## 设计意图

为信仰系提供装备互动向的辅助技能，将信仰从施法延伸到战前准备与物品强化。
