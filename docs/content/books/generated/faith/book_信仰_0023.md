# 《荆棘冠冕的佩戴》

## 基础信息

- **书籍 ID**：`book_faith_0023`
- **关联技能**：`faith_crown_of_thorns`
- **使用效果**：阅读后解锁 `faith_crown_of_thorns`；若已学会，提升该技能 `current_mastery +100`，并在受到伤害时反弹 8% 神圣伤害给攻击者。
- **阅读要求**：角色拥有 `holy`、`zealot` 或 `paladin` 标签职业；基础 `体质 ≥ 9` 且 `意志 ≥ 9`。
- **稀有度**：史诗（Epic）
- **建议投放**：荆棘修道院、苦修者圣地、信仰试炼第二阶段奖励。

## 书籍内容

荆棘冠冕的佩戴不是装饰品，而是一种主动承受伤害的修行。书中详细介绍了如何挑选合适的荆棘：太细会刺不穿表皮，无法产生足够痛感；太粗则会造成不可控的伤口。作者建议先用草药浸泡一夜，让尖刺保持柔韧但仍有存在感。佩戴时需要一段专注的仪式：先承认过去一天的所有过失，然后把冠冕轻轻按在额头上，直到血液开始缓慢渗出。书中最为严苛的章节要求佩戴者在疼痛中保持微笑，理由是"面容是信仰最先暴露破绽的地方"。附录里有一份疼痛日记模板，记录每一次刺痛出现的时间与伴随的念头。书末警告：荆棘冠冕的反噬会在佩戴者心怀怨恨时加倍，所以佩戴前必须先宽恕最近一个伤害过自己的人。苦修圣殿的墙壁上挂满了历代佩戴者留下的冠冕，每一顶都因荆棘品种不同而呈现独特的形状。参观者往往会被要求先读十分钟日记，再决定是否尝试。

## 设计意图

为狂信与圣骑士设计反伤机制，把"承受痛苦"从负面体验转化为威慑敌人的武器，强化信仰的牺牲美学。
