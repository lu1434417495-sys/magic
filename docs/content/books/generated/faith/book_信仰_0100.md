# 《永恒信仰》

## 基础信息

- **书籍 ID**：`book_信仰_0100`
- **关联技能**：`faith_eternal`
- **使用效果**：阅读后解锁 `faith_eternal`；若已学会，提升该技能 `current_mastery +100`，并使角色死亡后保留 1 点信仰技能熟练度传承给下一位同阵营角色。
- **阅读要求**：角色职业标签含 `priest`、`cleric` 或 `paladin`；基础 `信仰 ≥ 10` 且 `意志 ≥ 10`。
- **稀有度**：传说（Legendary）
- **建议投放**：多周目传承系统、信仰阵营最终剧情、传说级隐藏任务。

## 书籍内容

《永恒信仰》是本系列最后一册，也是最为神秘的一本。它不讲具体的神术，而是探讨信仰如何超越个体的死亡，在代际之间传递。书中认为，真正的永恒不在于肉体的延续，而在于信念的传承。第一章讲解如何将自己的核心信仰凝结成一种可以被后人感知的"信仰种子"，这颗种子会在合适的继承者心中重新发芽。第二章讨论传承的条件：继承者不必是血亲，但必须拥有相似的理想与足够的虔诚。作者警告，若传承被用于个人野心或权力争夺，信仰种子会枯萎甚至腐化。后半部收录了历代信仰传承者的名字，以及他们留下的简短箴言。最末页是一段用金色墨水写成的文字："当你合上这本书时，你不是结束了一段旅程，而是把火把递给了下一个人。愿信仰如星光，一代一代，永不熄灭。"永恒信仰是信仰系传承机制的象征性技能。

## 设计意图

为信仰系设计跨角色/跨周目的传承型终极技能，作为本系列的压轴，强化信仰主题的延续性与史诗感。
