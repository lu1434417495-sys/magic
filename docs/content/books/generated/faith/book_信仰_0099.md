# 《神迹显现》

## 基础信息

- **书籍 ID**：`book_信仰_0099`
- **关联技能**：`faith_miracle`
- **使用效果**：阅读后解锁 `faith_miracle`；若已学会，提升该技能 `current_mastery +95`，并使神迹触发后全队 morale 提升，接下来 3 回合内幸运值小幅增加。
- **阅读要求**：角色职业标签含 `priest` 或 `cleric`；基础 `信仰 ≥ 10` 且 `意志 ≥ 9`。
- **稀有度**：史诗（Epic）
- **建议投放**：神明直接干预剧情、世界 boss 战利品、信仰阵营传说任务。

## 书籍内容

神迹是无法被规则完全解释的现象，它只会在最虔诚的祈祷与最绝望的时刻出现。《神迹显现》教导牧师如何成为神明施展奇迹的通道，而不是奇迹的主人。书中指出，神迹不能被强求，施术者能做的只是清空自己，让神恩自然流动。第一章讲解神迹出现前的征兆，包括空气中的香气、突然的寂静、以及周围人共同产生的敬畏感。第二章讨论神迹可能的形式：起死回生、疾病痊愈、天灾平息、敌人突然放下武器等。作者警告，试图记录或复制神迹是徒劳的，因为每次神迹都是针对特定情境的回应。后半部收录了历史上被教会确认的三次神迹，每次都伴随着大量目击者的一致描述。最末页的插图是一名牧师在废墟中祈祷，一名被认为已死的儿童缓缓睁开眼睛，周围所有人都跪了下来。神迹显现是信仰系最具传奇色彩的不确定技能。

## 设计意图

为信仰系提供高稀有度的随机奇迹技能，创造戏剧性转折，强化信仰主题的神秘感与敬畏感。
