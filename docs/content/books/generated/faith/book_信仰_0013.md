# 《神恩归来的步法》

## 基础信息

- **书籍 ID**：`book_faith_0013`
- **关联技能**：`faith_grace_step`
- **使用效果**：阅读后解锁 `faith_grace_step`；若已学会，提升该技能 `current_mastery +80`，并在撤退或向后移动时减少 25% 借机攻击命中率。
- **阅读要求**：无职业限制；基础 `敏捷 ≥ 8`。
- **稀有度**：稀有（Rare）
- **建议投放**：朝圣商队护卫、撤退战教学、边境驿站书架。

## 书籍内容

神恩归来的步法教人如何在败退中保持尊严。书中指出，逃跑与撤退的区别不在于方向，而在于脚心是否还踩着信念。步法分为四拍：确认同伴位置、降低重心、后撤时目光不离开敌人、落地时无声。作者用大量图示展示如何在沙地、石板、落叶和积水四种地形上做到最后一项。最反直觉的建议是：撤退时不要祈求胜利，而要祈求"下一次站起来的力气"，因为祈求胜利会让脚步变得急躁。书中还收录了一首老兵口头流传的短歌，歌词只有两句："我转身，不是因为我怕死；我转身，是因为还有人需要我活着。"许多经历过溃败的士兵把这句话抄在绑腿内侧。在圣骑士的战术训练中，这套步法常与盾墙配合使用，让前排能在承受重创后有序重组战线。教官会故意模拟溃败场景，只为让学生明白撤退也可以是下一次冲锋的准备。

## 设计意图

为所有职业提供信仰主题的防御机动选择，把"撤退"从失败重新定义为"守护剩余希望"的战略动作。
