# 《殉道者之愿》

## 书籍内容

真正的牺牲从不喧哗，它在沉默中完成交换。《殉道者之愿》记录的是一种古老誓言，允许虔诚的信徒在濒死之际将自身剩余的生命力、法力或斗气转移给指定队友。书中强调，殉道者的意愿必须完全自愿，任何形式的胁迫都会让誓言沦为诅咒。第一章讲解如何在意识清醒时预先立下誓言对象，这一对象可以是某个人、某个信念，甚至某座城市。第二章分析转移比例，指出过度转移会导致施术者立即死亡，而适度转移则能留下一线生机。后半部收录了多位殉道者的最后遗言，它们大多简短到只有几个字："替我走完。"最末页的插图是一名跪地的牧师，双手交叠在胸前，光芒从他的身体流向周围的战友。作者在最后写道："殉道不是结束，而是把未完成的祈祷交给下一个人。"这个技能让牧师在绝境中拥有扭转战局的能力。
