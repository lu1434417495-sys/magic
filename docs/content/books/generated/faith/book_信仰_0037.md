# 《天球倒影的观测》

## 基础信息

- **书籍 ID**：`book_faith_0037`
- **关联技能**：`faith_celestial_mirror`
- **使用效果**：阅读后解锁 `faith_celestial_mirror`；若已学会，提升该技能 `current_mastery +90`，并在夜间战斗时提高全队命中 5。
- **阅读要求**：角色拥有 `holy`、`mage` 或 `scholar` 标签职业；基础 `智力 ≥ 9`。
- **稀有度**：稀有（Rare）
- **建议投放**：天文台礼拜堂、星象师塔楼、夜间战役奖励。

## 书籍内容

天球倒影的观测把星象与祈祷结合成一种时间艺术。书中认为，夜空中的星体位置不是命运本身，而是命运在水面上的倒影；祈祷的作用是让观测者的心情足够平静，从而看清倒影而非涟漪。作者教授如何用一碗静止的水来校准视线：先把水面放到与胸口同高，再调整呼吸直到倒影不再晃动，最后把目标星体与水中影像连成一条想象中的线。最实用的章节是"战斗星历"，标注了哪些夜晚适合进攻、哪些夜晚适合防守、哪些夜晚应该避免重大决策。书中还警告，观测时不要许愿，因为愿望会让水面起伏。封底画着一只碗，碗里不是水，而是一片缩小的星空。占星师公会常与教会合作出版战斗星历，但双方对同一夜的解读往往不同，导致指挥官需要同时参考两版。这种分歧本身也被书中视为天球倒影的一部分，因为人心不同，倒影自然各异。

## 设计意图

为信仰系提供夜间战术增益，把星象观测机制与祈祷结合，丰富环境时间对战斗的影响维度。
