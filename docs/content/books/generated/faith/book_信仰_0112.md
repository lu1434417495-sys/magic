# 《忏悔录：罪与净化》

## 基础信息

- **书籍 ID**：`book_信仰_0112`
- **关联技能**：`faith_confession_112`
- **使用效果**：阅读后解锁 `faith_confession_112`；若已学会，提升该技能 `current_mastery +80`，并在战斗内可消耗一回合移除自身一个随机减益状态。
- **阅读要求**：角色职业标签含 `priest` 或 `paladin`；基础 `意志 ≥ 8`。
- **稀有度**：精良（Uncommon）
- **建议投放**：忏悔室、审判庭、心理修复支线。

## 书籍内容

这本书的每一页都分成左右两栏：左边写一种常见的罪，右边写对应的净化祷文。作者认为罪与净化的关系不是抵消，而是“把暗处的东西拿到光下，让它失去藏匿的形状”。书中特别指出，最危险的罪不是杀戮或欺骗，而是“把自己的罪变得看不见”。后半部分收录了多位圣职者的匿名忏悔，他们承认自己在治疗时偏袒、在审判时傲慢、在祈祷时走神。最末一章写道：“净化不会洗掉记忆，只会让你下次面对同样选择时，多一秒钟犹豫。”书中反复强调，忏悔的力量不在于说得多彻底，而在于说完之后是否愿意在下次面对同样处境时多停留一秒。作者还附上一份“每日三省”清单，要求读者在入睡前回答：今天我是否借神的名义抬高了自己？书中还提到，净化祷文在念出后的第七个呼吸最为关键，那时施术者必须同时放下对罪人的判断与对自己的辩解。

## 设计意图

为圣职系提供自我净化手段，将宗教忏悔机制转化为战斗中的减益解除技能。
