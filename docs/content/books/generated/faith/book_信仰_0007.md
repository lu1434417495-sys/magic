# 《审判之锤的握持》

## 基础信息

- **书籍 ID**：`book_faith_0007`
- **关联技能**：`faith_judgment_hammer`
- **使用效果**：阅读后解锁 `faith_judgment_hammer`；若已学会，提升该技能 `current_mastery +110`，并对 `sin` 标记敌人提高 12% 暴击率。
- **阅读要求**：角色拥有 `holy` 或 `paladin` 标签职业；基础 `力量 ≥ 10` 且 `意志 ≥ 8`。
- **稀有度**：稀有（Rare）
- **建议投放**：审判庭武器库、堕天使讨伐战、大教堂地下角斗场。

## 书籍内容

审判之锤不是普通战锤，它的重心被刻意设计得偏高，迫使握持者必须以信仰为支点而非蛮力。书中第一章比较了三种握法：惩罚式、平衡式、怜悯式，作者只推崇最后一种，理由是"审判者若被仇恨压弯手腕，锤头便会偏离真相"。随后的章节讲解锤面符文的充能节奏，每一次命中罪人都会让符文亮起一格，满格时可释放一次无视部分护甲的神圣震荡。书中还夹着一张泛黄的训练表，记录了某位见习审判官连续三十天击打木桩的数据，旁边批注："第三天后，手腕不再疼痛，因为我终于不再想砸碎什么。"最末页警告：审判之锤对无罪者会自动变重，仿佛手中握着一块拒绝落下的石头。大教堂的军械库至今仍保存着三把原型审判之锤，每把都因前任主人的不同信念而呈现出微妙的重量差异。新兵常被要求闭目挑选，因为锤会在诚实者手中变得均衡。

## 设计意图

为信仰系输出构建一条"克制而精准"的暴击路线，用"对罪标记"机制把审判主题转化为战术选择。
