# 《静默祈祷》

## 基础信息

- **书籍 ID**：`book_信仰_0065`
- **关联技能**：`faith_silent_prayer`
- **使用效果**：阅读后解锁 `faith_silent_prayer`；若已学会，提升该技能 `current_mastery +75`，并使静默状态下每回合恢复少量 MP 且神术不被打断。
- **阅读要求**：角色职业标签含 `priest` 或 `cleric`；基础 `意志 ≥ 9` 或 `智力 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：修道院静修室、潜行牧师训练场、情报型任务奖励。

## 书籍内容

并非所有祈祷都需要声音，有些最深刻的交流发生在沉默之中。《静默祈祷》教导牧师如何在不发出任何声响的情况下维持与神明的联系，从而在潜行、囚禁或禁魔环境中依然获得力量。书中指出，静默不是停止祈祷，而是把祈祷从语言层面下沉到呼吸与心跳层面。第一章训练读者用特定的呼吸节奏替代祷词，使神力循环不受出声限制。第二章讲解如何在战斗中保持静默施法，避免因吟唱暴露位置。作者特别强调，静默祈祷更容易被内心杂念干扰，因为失去了声音作为锚点。后半部收录了多名牧师在牢狱、战场废墟与敌对领土中使用静默祈祷的真实记录。书中还附有一套手指计数法，帮助练习者在不发声的情况下记录祈祷次数。最末页只有一句话："当世界不允许你发声时，你的心跳就是祷词。"这个技能让信仰系在特殊环境下依然具备作战能力。

## 设计意图

为信仰系提供静音/隐蔽场景下的续航能力，拓展牧师的适用场景与潜行玩法可能性。
