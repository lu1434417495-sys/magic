# 《圣餐仪式》

## 书籍内容

《圣餐仪式》将日常饮食转化为信仰行为。书中认为，一顿饭若是怀着感恩之心分享，便能成为神恩的载体。仪式分为四个步骤：洁净双手、祝谢食物、分食、默念感恩。第一章详细讲解每种食材对应的祷词变体，面包代表土地的馈赠，清水代表洁净，盐代表契约，酒代表牺牲。第二章讨论仪式规模，从一个人的简餐到整支军队的战前聚餐，规模越大，主持者需要越强的信仰控制力。作者指出，圣餐不是魔法药水，它的效果来自参与者共同建立的心理与精神状态。后半部收录了多篇行军食谱与紧急情况下的简化仪式，例如没有酒时可以用清水三次祝圣代替。最末页写着："不要轻视一块面包，它可能是一个士兵在决战前最后的平静。"圣餐仪式为信仰系提供了独特的战前 buff 机制，也经常在剧情中作为团队凝聚情感的重要场景。

## 设计意图

为信仰系设计非战斗场景的团队增益技能，强化牧师的仪式感与日常陪伴价值。
