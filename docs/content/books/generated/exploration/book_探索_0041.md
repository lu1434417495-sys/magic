# 《风暴眼：极端天气行进》

- **书籍 ID**：`book_探索_0041`

## 书籍内容

这本书的封面用防风油布包裹，内页画满了气旋、雷云与沙墙的示意图。作者认为，极端天气中的探索者不应对抗自然，而应学会在其缝隙中穿行。书中教导读者如何读取云层变化预测风暴路径，如何利用地形遮挡避开最强风区，以及如何在雷暴中降低被击中的概率。中段详细讲解了沙漠沙尘暴与雪原暴风雪中的行进策略，包括如何判断风眼位置与安全撤离时机。后半部分涉及战斗应用，比如借助风沙掩护接近敌人。书末写着："风暴不会因为你害怕而停止，但你可以学会在它呼吸的间隙前进。"

书末附有一张风暴路径预测图，作者提醒：天气会欺骗所有仪器，但不会欺骗一个愿意停下来观察的人，急躁是航海者最大的敌人；他还画了几种云型，标注哪些意味着必须立即寻找掩体。

他提醒，风暴中心的平静，是天空给勇敢者的礼物。

## 设计意图

整合沙漠、雪原与雷暴等多种极端天气挑战，提供通用应对技能，服务于后期开放世界远征玩法。
