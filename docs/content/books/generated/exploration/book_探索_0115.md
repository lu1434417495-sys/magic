# 《苔藓罗盘：自然界的指北针》

- **书籍 ID**：`book_探索_0115`
- **关联技能**：`exploration_natural_compass`（待新增，标签 `exploration`）

## 书籍内容

《苔藓罗盘》的书名来自一句老话："找不到北，就去找树阴面的青苔。"作者在书中系统整理了自然界提供的方向线索：树干苔藓的分布、年轮较密的一侧、单株树木枝条的向阳生长、蚂蚁筑巢的坡向偏好。中间章节提醒读者，这些规律只在特定气候区有效，把北半球的规律搬到灰烬交界可能会直接指向错误的方向。后半本用大量插图展示了不同树种在不同环境下的形态差异，并附有一位迷路旅者的日记："我那天没有罗盘，没有星星，但我记得书上说过橡树的西南侧枝条会更茂盛。它救了我。"最末页用绿色墨水写着："自然从不会主动告诉你答案，但它会在你学会提问之后，悄悄把答案放在你手边。"书的后半部分警告读者，苔藓也会被骗：某些矿脉区或异界影响下，植物生长方向会违背常识，因此必须结合两种以上线索确认方向。

## 设计意图

作为探索系列的自然导航技能，为无装备或装备失效的情况提供方向判断手段，增加野外生存的沉浸感。
