# 《滑翔翼制作与操控》

## 基础信息

- **书籍 ID**：`book_探索_0025`
- **关联技能**：`exploration_glide_kit`（待新增，标签 `exploration`）
- **使用效果**：阅读后解锁探索技能 `exploration_glide_kit`；若已学会，提升 `current_mastery +65`，可从高处滑翔跨越三格距离，战斗中可用于快速转移。
- **阅读要求**：无职业限制；基础 `敏捷 ≥ 9`。
- **稀有度**：稀有（Rare）
- **建议投放**：风之谷、工匠大师、高塔遗迹。

## 书籍内容

这本手册充满了飞行器骨架与翼面张角的草图，边角还粘着几根羽毛。作者从最简单的风筝式滑翔翼讲起，逐步介绍如何利用轻质木材、坚韧帆布与绳索制作可携带的滑翔装置。书中强调，滑翔不是飞行，而是利用高度差与气流进行受控下落，操控的核心在于重心转移与翼面姿态。中段讲解了如何判断上升气流、如何避免乱流区，以及起飞前必须检查的三个要点。后半部分涉及在战斗中使用滑翔翼进行快速转移与高地抢占。书的最后写道："一旦离开地面，你唯一能信任的就是风和自己的判断。"

书中夹着一根折断的滑翔翼骨架，旁边写着：“这不是失败，而是风告诉我该降落了。”作者用这种幽默让读者敬畏天空的力量；他还强调，滑翔翼的每一次起飞都要做好无法再次起飞的准备。

他写道，风从不为任何人停留，但聪明的人会借它的力。

## 设计意图

扩展战棋地图的立体机动能力，使高地地形成为可主动利用的战术节点，服务于快速部署与脱离玩法。
