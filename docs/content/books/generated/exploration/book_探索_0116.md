# 《灰烬踏勘：交界地表行走》

## 书籍内容

这本书的每一页都蒙着一层细细的灰，仿佛刚从灰烬交界带出来。作者把交界地表分成五类：硬壳灰、浮灰、烧结地、热裂石和假结壳。每种类型的承重、温度和声音都不相同，而真正的踏勘高手能在落地前的一刹那通过鞋底触感判断自己踩中的是哪一类。中间章节详细讲解了如何借力求行：从一块烧结地跳到另一块烧结地，用浮灰的缓冲减少落地冲击，但绝不可以在同一块硬壳灰上停留超过两次心跳的时间。后半本是一位资深踏勘者的笔记，他画出了自己穿越一片不稳定灰原的路线，那条线弯弯曲曲，旁边写着："直线属于活人，也属于死人，区别在于走的人是谁。"最末页只有一句话："在灰烬里，站稳比走得快更重要。"附录里有一份作者手绘的"交界地表声音对照表"，不同地面被踩踏时发出的声响用拟声词标注，老兵们称这张表比任何地图都值钱。

## 设计意图

作为探索系列的异界地表专精，把灰烬交界特有的危险地形转化为可学习的移动技能，强化异界探索的差异化体验。
