# 《灵兽亲和：寻路伙伴》

## 基础信息

- **书籍 ID**：`book_探索_0038`
- **关联技能**：`exploration_beast_kinship`（待新增，标签 `exploration`）
- **使用效果**：阅读后解锁探索技能 `exploration_beast_kinship`；若已学会，提升 `current_mastery +70`，野外遭遇野兽时可选择安抚而非战斗，并有几率获得野兽带路。
- **阅读要求**：无职业限制；基础 `意志 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：德鲁伊营地、驯兽师、森林圣地。

## 书籍内容

这本书的封面用某种柔软的兽皮制成，翻开时会闻到阳光与青草的气息。作者认为，野外最强大的向导不是罗盘，而是当地的野兽。书中教导读者如何通过姿态、气味与声音向野兽传递善意，并识别它们的领地标记与警告信号。中段详细介绍了不同生态系统中可作为向导的物种，从森林中的鹿群到沙漠中的狐獴。后半部分涉及如何在遭遇野兽时选择安抚而非战斗，以及如何让野兽带领队伍找到水源或隐藏路径。书末写着："动物从不说谎，它们的耳朵和鼻子比任何地图都更接近真实。"

作者提醒，野兽愿意带路不是因为喜欢你，而是因为你们暂时的利益一致，永远不要背对一匹刚认识不久的狼，哪怕它今天救了你；他还教读者如何在分别时用特定动作表示“债务已清”。

他提醒，野兽的眼睛里没有善恶，只有信任与警惕。

## 设计意图

将探索与生态交互结合，提供非战斗方式处理野外遭遇，为玩家开辟隐藏路径与特殊事件提供新途径。
