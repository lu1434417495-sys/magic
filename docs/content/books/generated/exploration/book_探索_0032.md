# 《危险预感》

## 基础信息

- **书籍 ID**：`book_探索_0032`
- **关联技能**：`exploration_danger_sense`（待新增，标签 `exploration`）
- **使用效果**：阅读后解锁探索技能 `exploration_danger_sense`；若已学会，提升 `current_mastery +70`，进入新区域时若存在陷阱或埋伏，角色获得一回合预警 buff。
- **阅读要求**：无职业限制；基础 `感知 ≥ 11`。
- **稀有度**：稀有（Rare）
- **建议投放**：老兵教官、战场遗迹、感知试炼奖励。

## 书籍内容

这本书没有作者署名，每一页的边角都画着一只半睁的眼睛。作者提出，危险预感不是魔法，而是长期训练后潜意识对异常信号的整合。书中教导读者如何在进入新环境时快速扫描出入口、阴影与制高点，并注意那些"太安静"或"太吵闹"的区域。中段用大量战例说明，许多埋伏的迹象其实很明显，只是人心不愿相信。后半部分讲解了如何在团队中建立预警系统，让预感转化为全队可执行的战术动作。书的最后写道："预感救不了你，但它能给你争取一次选择的机会。"

作者强调，预感如同肌肉，越使用越敏锐，但越依赖也越容易被精心设计的假象欺骗，所以预感应当被验证，而不是被盲从；他建议每次预感来袭时，先找出三个支持它和三个反驳它的证据。

他写道，危险预感不会替你战斗，但会让你先拔剑。

## 设计意图

作为全职业通用的感知类防御技能，提升探索容错率与遭遇战准备度，与陷阱拆解、潜行侦察形成信息优势组合。
