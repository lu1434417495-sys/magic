# 《听风：气流中的方位术》

## 基础信息

- **书籍 ID**：`book_探索_0112`
- **关联技能**：`exploration_wind_listen`（待新增，标签 `exploration`）
- **使用效果**：阅读后解锁探索技能 `exploration_wind_listen`；若已学会，提升 `current_mastery +90`，并在有风环境中提升对隐藏敌人方位的感知检定。
- **阅读要求**：无职业限制；基础 `感知 ≥ 8`。
- **稀有度**：稀有（Rare）
- **建议投放**：高地瞭望塔、风语者营地、游商稀有货物。

## 书籍内容

这本书的纸页极薄，似乎生怕厚一点的纸张会挡住风的声音。作者认为风是战场上最诚实的信使，它会把人的呼吸、金属的碰撞和脚步的摩擦带到下风口。书中教读者如何判断自己处于上风口还是下风口，并据此决定是埋伏还是绕行。中间章节详细讲解了不同地形对风的影响：山谷会把风压缩成哨声，树林会让风碎成无数细语，而灰烬交界的风则会携带细小的余烬，把接近者的轮廓提前描出来。后半本是一位盲眼巡林客的口述记录，他声称自己能在三十步外凭风声判断来者是否负重、是否紧张。最末页只有一句话："眼睛会骗人，因为你可以决定看哪里；风不会，因为它只决定你被谁听见。"书的后记讲述了一位弓手如何利用上风口的优势，让箭矢在敌人闻到他之前先到达目标，这或许是对"听风"最残酷的注解。

## 设计意图

作为探索系列的感知增强技能，把风向与气流转化为战术信息，强化埋伏、侦查与远程职业的协同空间。
