# 《风向读图手册》

## 基础信息

- **书籍 ID**：`book_探索_0073`
- **关联技能**：`exploration_wind_reading`（待新增，标签 `exploration`）
- **使用效果**：阅读后解锁 `exploration_wind_reading`；若已学会，提升 `current_mastery +80`，在野外地图中可预判天气变化与远程弹道偏移，并在风属性环境中提高移动效率。
- **阅读要求**：无职业限制；基础 `感知 ≥ 9`、智力 `≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：水手公会、港口集市、平原营地宝箱。

## 书籍内容

《风向读图手册》原本是为海员编写的，却被陆地探险家发现同样适用。书中指出，风不是随机吹拂的，它受地形、温度、湿度共同塑造，因此可以被阅读。作者介绍了如何通过云层移动方向判断高空风，通过树叶翻动程度判断地面风，通过山谷两侧温差预测峡谷风的变化。书中还讲解了如何利用风向进行隐蔽移动：从下风处接近猎物或敌人，可以避免气味和声音提前暴露位置。后半本附有多种地形下风力的换算表，以及弓箭手在不同侧风条件下的提前量修正。作者最后总结，读懂风向的人能在战棋地图上提前选择有利射击位置与行军路线，让风成为沉默的盟友。书中还附有一张常见地形的风玫瑰图，用不同方向的箭头标注各季节主导风向。最后一页被人用铅笔补了一句话："风会记住每座山的形状，你只需要学会读它的回忆。"

## 设计意图

为远程职业和野外探索提供环境互动能力，让风从背景装饰变为可读取、可利用的战术信息，增强战棋地图的动态感。
