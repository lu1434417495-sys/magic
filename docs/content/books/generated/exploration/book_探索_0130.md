# 《渡河要诀：水流与落点》

## 书籍内容

这本书的纸页有些发胀，仿佛曾经被河水打湿又晾干。作者把渡河分为三个阶段：选点、入水和上岸。选点要看水面的颜色变化——深色通常代表深潭，浅色可能是浅滩，但最危险的是颜色突然变化的地方，那是暗流与落差的交界。入水时要斜向切入，让身体与水流形成夹角而非正面对抗。上岸则要提前选择下游方向有缓坡或植被稳固的地点，避免被水流冲到无法攀爬的岸壁。后半本是一位老兵的笔记，他记录了一次率领部队渡河的失败：因为选择了看似平静的弯道，结果部队被卷入水下暗礁。最末页只有一句话："河流从不主动杀人，它只惩罚那些以为水面就是全部的人。"附录里有一份不同季节河流水位变化的参考表，作者强调同一条河在旱季和雨季可能是完全不同的敌人，不能用旧经验判断。

## 设计意图

作为探索系列的水域通过技能，把渡河从简单属性检定转化为需要观察与判断的过程，增强河流关卡的策略性。
