# 《地标绑定：记忆中的锚点》

## 基础信息

- **书籍 ID**：`book_探索_0138`
- **关联技能**：`exploration_landmark_bind`（待新增，标签 `exploration`）
- **使用效果**：阅读后解锁探索技能 `exploration_landmark_bind`；若已学会，提升 `current_mastery +80`，并可在当前区域额外标记 1 个自定义地标。
- **阅读要求**：无职业限制；基础 `智力 ≥ 7` 或 `感知 ≥ 7`。
- **稀有度**：普通（Common）
- **建议投放**：探险家协会、制图师摊位、基础导航任务奖励。

## 书籍内容

这本书的每一页都留有大片空白，显然是供读者自己填写地标用的。作者认为，好的地标不是最显眼的物体，而是最不容易被混淆的物体：形状独特、位置固定、从多个角度可见。书中把地标分为三类：近地标用于确认当前位置，远地标用于校正方向，序列地标则用来在没有道路的地方铺设一条 mental route。中间章节教读者如何为地标赋予个人记忆：把一棵歪脖树与某次成功狩猎绑定，把一块红石与一条安全退路绑定。后半本是一位探险家的笔记，他在一片看起来完全相同的草原上靠三座地标找到了回家的路。最末页只有一句话："世界很大，但你的记忆只需要几根钉子就能把它挂住。"书中还建议每位探索者拥有属于自己的"秘密地标"——一种只有自己和队友知道的微小记号，用来在复杂地形中确认是否回到了正确的路线。

## 设计意图

作为探索系列的地图标记技能，把地标记忆转化为可自定义的导航工具，增强玩家对大型区域的掌控感。
