# 《伪装与营地隐蔽》

## 基础信息

- **书籍 ID**：`book_探索_0013`
- **关联技能**：`exploration_camp_concealment`（待新增，标签 `exploration`）
- **使用效果**：阅读后解锁探索技能 `exploration_camp_concealment`；若已学会，提升 `current_mastery +45`，野外休息时不被低级怪物发现并提升营地恢复效率。
- **阅读要求**：盗贼或弓箭手优先；基础 `敏捷 ≥ 7`。
- **稀有度**：普通（Common）
- **建议投放**：游侠营地、边境旅者、佣兵公会。

## 书籍内容

这本手册的封面用迷彩布料包裹，内页详细记录了如何在野外让一个小队彻底消失。作者指出，营地隐蔽的关键不在于遮遮掩掩，而在于融入环境：利用天然凹陷、倒木与灌木丛搭建遮蔽所，避免砍伐新鲜植物留下痕迹。书中还讲解了如何控制炊烟、如何掩埋排泄物与食物残渣，以及如何选择远离兽道的位置。中段介绍了多种因地制宜的伪装方法，从雪地白色披风到沙漠散影网。后半部分开始讨论心理层面的隐蔽，即如何让营地看起来"从未有人来过"。最后几页是一位老兵的批注："最好的营地，是连你自己第二天都找不到的那种。"

书中特别警告，营火不仅照亮黑夜，也会照亮人心底的孤独，许多人因为忍不住聊天而暴露了整支队伍，沉默是营地最好的伪装；作者建议用简单的手势代替语言，直到天亮。

## 设计意图

为探索系列增加营地管理与生存隐蔽维度，强化盗贼、弓箭手在野外的战略纵深，与休息恢复系统形成联动。
