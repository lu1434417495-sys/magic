# 《危险直觉：第六感的训练》

## 基础信息

- **书籍 ID**：`book_探索_0128`
- **关联技能**：`exploration_danger_intuition`（待新增，标签 `exploration`）
- **使用效果**：阅读后解锁探索技能 `exploration_danger_intuition`；若已学会，提升 `current_mastery +100`，并在进入高危险区域时获得一次额外警觉检定。

## 书籍内容

这本书没有系统的章节，全是一位又一位幸存者的只言片语拼接而成。第一位写道："我不知道为什么，但我就是知道不能走那条路。"第二位写道："我的后颈发凉，然后箭就来了。"第三位写道："安静得太正常了，所以我知道有问题。"作者把这些零散经验归纳为"危险直觉"——它不是魔法，而是身体对环境异常的无意识汇总：空气温度的突然变化、昆虫声音的消失、皮肤上莫名的刺痛感。书中建议读者在感到不安时停下来，问自己五个问题：我看到了什么？没听到什么？闻到什么？皮肤感觉到什么？心跳为什么变快？最末页只有一句话："直觉不会替你做决定，但它值得你先停下，再决定走不走。"书的最后是一份空白表格，作者要求每位读者记录自己三次"没来由的不安"以及后续发生的事情，他相信直觉是可以被训练出来的。

## 设计意图

作为探索系列的直觉预警技能，把"第六感"包装为经验积累的结果，为高难度区域提供一次额外的安全缓冲。
