# 《足迹辨识入门》

## 基础信息

- **书籍 ID**：`book_探索_0002`
- **关联技能**：`exploration_track_reading`（待新增，标签 `exploration`）
- **使用效果**：阅读后解锁探索技能 `exploration_track_reading`；若已学会，提升 `current_mastery +50`，可在世界地图上识别近期经过的敌人轨迹。
- **阅读要求**：无职业限制；基础 `感知 ≥ 7`。
- **稀有度**：普通（Common）
- **建议投放**：猎人营地、兽道据点、探索者行会。

## 书籍内容

这本书的每一页都印着不同兽爪的拓印，从常见的山狼到罕见的石化蜥蜴。作者用红墨水标注出足印深浅与动物体重、速度的关系，并指出前爪与后爪间距往往暴露其是否在追击猎物。书中还教导读者如何区分新鲜足迹与雨水冲刷后的痕迹，以及如何通过折断的草茎判断经过时间。中段的案例集记载了一位追踪者因为误判足迹方向，带着整队人走进了沼泽。后半部分开始涉及类人怪物的足迹，包括兽人、哥布林与灰烬奴仆的步态差异。作者提醒，最危险的足迹是那些突然中断的，因为那意味着猎物学会了反追踪，或者它已经不再需要走路。

书的最后一页是空白表格，标题为“我的足迹档案”，作者希望每位读者都能记录自己遇到的独特痕迹，最终形成一本只属于自己的追踪笔记，因为最好的追踪者不是记住别人足迹的人，而是能发现自己足迹的人。

## 设计意图

为探索系列提供情报收集类技能入口，强化战棋地图中的信息优势，服务于伏击规避与目标追踪玩法。
