# 《世界边缘游记》

## 基础信息

- **书籍 ID**：`book_探索_0100`
- **关联技能**：`exploration_world_edge_travel`（待新增，标签 `exploration`）
- **使用效果**：阅读后解锁 `exploration_world_edge_travel`；若已学会，提升 `current_mastery +150`，角色可安全前往世界边缘区域，并在边界地带获得全属性小幅加成与异界事件触发优先权。
- **阅读要求**：无职业限制；基础 `智力 ≥ 12`、感知 `≥ 12`、意志 `≥ 11`。
- **稀有度**：传说（Legendary）
- **建议投放**：世界尽头遗迹、终极探索任务奖励、传说宝箱。

## 书籍内容

《世界边缘游记》的作者无人知晓，因为据说写下它的人从未真正返回。书中描述的不是某个具体地点，而是一种状态：当你走到地图不再标注的地方，空气会变得稀薄而明亮，时间的流逝开始显得可疑，远处的地平线会呈现出不该存在的颜色。作者用诗化的语言记录了在世界边缘的所见所闻：会倒流的小溪、长出金属叶片的树木、以及站在悬崖边却能听见身后脚步声的古怪回声。书中还提供了为数不多的实用建议：不要追逐那些向你招手的熟悉面孔，不要吃边界地带的果实，不要回头看自己走过的路超过三次。许多试图模仿作者的人都在边界失踪，书页间偶尔能发现他们遗留的笔记。后半本大部分页面空白，只在角落有一些无法辨认的符号。最后一页用流动的墨迹写着："世界的尽头不是终点，而是世界开始不习惯你的地方。"

## 设计意图

作为探索系的传说级收官书籍，承载项目世界边缘与异界拓展的核心叙事，为玩家提供进入终极探索区域的资格与收益。
