# 《岩壁抓握：攀爬中的力学》

## 书籍内容

这本书的边角布满细小的划痕，仿佛经常被带在岩壁上翻阅。作者把攀爬分解为四个力：向上的推力、向下的拉力、侧向的平衡力和核心的稳定力。书中强调，手臂在攀爬中主要用来定位，真正承担体重的是腿部和躯干。中间章节详细讲解了如何识别可抓握的岩点：颜色稍深可能代表潮湿，有白色盐霜可能代表风化严重，而看似坚固却发出空响的岩石必须避开。后半本是一位登山者的笔记，他记录了自己如何在一场突如其来的岩崩中靠三个支点撑到救援到来。最末页画着一只手，手指微微弯曲，配文："抓得太紧，手臂会僵；抓得太松，人会掉。攀爬的艺术，是找到刚刚好的不信任。"书的后记是一位独臂攀岩者的自述，他失去手臂不是因为滑落，而是因为错误判断了一块"看起来没问题"的岩石，这个故事被作者放在全书最后。

## 设计意图

作为探索系列的攀爬专精技能，把岩壁移动从单纯属性检定转化为可训练的力学知识，为山地关卡增加策略深度。
