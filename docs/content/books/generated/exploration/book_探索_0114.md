# 《星象引路：夜空导航术》

## 书籍内容

这本书的封面上镶嵌着一小块磨光的黑曜石，用来在野外反射星光以确定方位。作者从最基础的开始：找到北极星，然后以它为轴心辨认周围星座的季节位置变化。书中强调，星象导航不是背诵星图，而是理解"天空在旋转，而你需要找到那个不动的点"。中间章节介绍了如何利用月亮的位置和盈亏判断大致时间与方向，并警告在灰烬交界观星时要小心那些"假装成星星的眼睛"。后半本是一位航海士的手稿，他在一次风暴中失去了所有罗盘，却靠星象把船带回了航线。最末页画着一个简化的星盘，旁边写着："当你在地面上找不到答案时，抬头看看，答案可能一直挂在那里。"书的附录有一页专门讲述如何在阴天利用星辰的稀疏微光判断方向，作者认为真正的导航者从不因为看不见太阳就停下脚步。

## 设计意图

作为探索系列的星空导航技能，为夜间或无地标区域提供方向判断能力，与昼夜循环和天气系统形成联动。
