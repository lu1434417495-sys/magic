# 《洞穴气息：地下空气的阅读》

## 基础信息

## 书籍内容

这本书的纸页带着淡淡的霉味，仿佛作者长期生活在地下。书中教读者如何通过空气判断洞穴前方的状况：温暖的微风意味着开阔空间或地下热源，湿冷停滞的空气可能通向深水潭，而完全没有气流则预示前方可能是死胡同或密闭毒气区。中间章节详细讲解了不同气味的含义：硫磺味警告地热与毒气，腐殖质味代表有水与生物，而灰烬交界洞穴中偶尔出现的金属甜腥味则被作者标记为"不要前进"。后半本是一位老矿工的口述记录，他多次靠嗅觉提前避开塌方与暗河。最末页只有一句话："在地下，空气比火把更诚实；火把会灭，空气会告诉你为什么要灭。"书的后半部分记录了如何在不同季节通过洞穴入口的空气温度判断内部是否适合进入，作者称这是"用鼻子和脸颊做的第一步侦察"。

## 设计意图

作为探索系列的洞穴环境感知技能，把空气流动与气味转化为地下空间的信息源，增强洞穴探索的真实感与危险性。
