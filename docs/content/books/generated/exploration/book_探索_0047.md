# 《无尽阶梯：垂直探索》

## 基础信息

- **书籍 ID**：`book_探索_0047`
- **关联技能**：`exploration_endless_climb`（待新增，标签 `exploration`）
- **使用效果**：阅读后解锁探索技能 `exploration_endless_climb`；若已学会，提升 `current_mastery +85`，可攀爬任何非光滑垂直面，并在攀爬时保持战斗姿态。
- **阅读要求**：战士或盗贼；基础 `敏捷 ≥ 12` 或 `体质 ≥ 12`。
- **稀有度**：史诗（Epic）
- **建议投放**：高山神殿、攀登者之巅、云端遗迹。

## 书籍内容

这本书的封面用某种粗糙的岩石粉末压制，触感像真实的岩壁。作者将垂直探索定义为对重力的谈判，认为优秀的攀登者不是战胜高度，而是与它达成和解。书中教导读者如何在无装备状态下利用岩缝、冰棱与植物根系攀爬，并强调手指力量与核心稳定同样重要。中段详细讲解了垂直洞穴、钟楼废墟与异界浮空地形中的特殊技巧。后半部分涉及战斗中的垂直机动，包括从上方发动突袭与在岩壁上保持射击姿态。书末的批注写道："当你觉得阶梯没有尽头时，回头看看，你其实已经走了很远。"

作者在最后写道，攀登者最终会发现，真正需要征服的不是山峰，而是自己往下看时产生的那一阵眩晕，克服它，才算真正站在高处；他提醒，返回时比上升时更危险，因为骄傲会让人忘记检查绳索。

## 设计意图

作为绳索与岩壁的高阶版本，彻底解锁垂直地形限制，为高塔、浮空岛等立体副本提供核心机动能力。
