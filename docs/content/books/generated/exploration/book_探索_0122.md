# 《云相判势：大气中的战场》

## 基础信息

- **书籍 ID**：`book_探索_0122`
- **关联技能**：`exploration_cloud_reading`（待新增，标签 `exploration`）
- **使用效果**：阅读后解锁探索技能 `exploration_cloud_reading`；若已学会，提升 `current_mastery +80`，并在户外战斗前获得一次天气趋势预判。
- **阅读要求**：无职业限制；基础 `智力 ≥ 7` 或 `感知 ≥ 7`。
- **稀有度**：普通（Common）
- **建议投放**：气象台站、军事营地、战术任务奖励。

## 书籍内容

这本书的每一页上方都印着当天的云形素描，看起来像是一本天空日记。作者把云视为大气的肌肉纹理：积云的隆起代表上升气流，层云的铺展代表稳定天气，卷云的稀薄丝线则常常预示着远方的风暴。书中强调，读云不是为了预测精确到分钟，而是为了判断"接下来几个时辰里，天气是朋友还是敌人"。中间章节专门讨论战术应用：顺风时箭矢更远，逆风时火焰蔓延更慢，而暴雨会让火药与某些法术失效。后半本是一位将军幕僚的随笔，他记录了多场战役如何因对云相的误判而胜负逆转。最末页用粗体字写着："天空从不直接参战，但它决定了你手里的牌有多少张能打得出去。"附录中收录了各地渔民和农民对云的天气谚语，作者认为最准确的预报往往来自那些必须靠天吃饭的人，而不是象牙塔里的学者。

## 设计意图

作为探索系列的战术气象技能，把云相阅读与战斗系统挂钩，为户外遭遇战增加环境预判层次。
