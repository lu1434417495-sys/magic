# 《回声定位：盲探技巧》

## 基础信息

- **书籍 ID**：`book_探索_0016`
- **关联技能**：`exploration_echo_location`（待新增，标签 `exploration`）
- **使用效果**：阅读后解锁探索技能 `exploration_echo_location`；若已学会，提升 `current_mastery +60`，在完全黑暗区域可感知三格内敌人轮廓。
- **阅读要求**：无职业限制；基础 `感知 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：地下城、盲人先知、暗影洞穴。

## 书籍内容

这本奇特的书没有插图，只有密密麻麻的文字与节奏符号。作者是一位失明的洞穴探险家，他提出即使在完全黑暗中，人也能通过声音构建周围环境。书中教导读者如何发出短促而有控制的弹舌声，并分辨回声中的距离、材质与障碍物信息。中段讲解了在不同空间中声音传播的差异，以及如何利用水滴声、风声与脚下碎石声辅助定位。后半部分开始涉及战斗应用，比如在黑暗中判断敌人方位与距离。作者在最后写道："眼睛会让人只看见想看见的东西，而耳朵在黑暗中更诚实。"

作者还提醒，回声定位最大的敌人不是寂静，而是自己的心跳声，恐惧会让每一次弹舌都变得杂乱无章，所以先学会平静才能听见真实；他建议初学者先在安全的洞穴中闭眼行走十步。

他写道，失明不是失去世界，而是换了一种方式拥抱它。

## 设计意图

为黑暗环境探索提供不依赖光源的感知方式，与冥想感知体系形成互补，服务于洞穴、地牢与异界无光区域。
