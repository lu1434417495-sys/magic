# 《绳越技巧：垂直与横向移动》

## 基础信息

- **书籍 ID**：`book_探索_0124`
- **关联技能**：`exploration_rope_traverse`（待新增，标签 `exploration`）
- **使用效果**：阅读后解锁探索技能 `exploration_rope_traverse`；若已学会，提升 `current_mastery +90`，并可在特定地形使用绳索通过沟壑或高处。

## 书籍内容

《绳越技巧》的扉页上粘着一根磨损的麻绳纤维，作者说那是他从一次失败的峡谷穿越中抢救出来的。书中系统讲解了三种基本绳结：承重结、防滑结和速解结，并强调在任何垂直行动前必须先做"三点固定"。中间章节用大量图示展示如何借助绳索横渡峡谷、攀上断崖和从高处缓降，同时提醒读者绳子的敌人不是重量，而是摩擦与潮湿。后半本是一位探险家的回忆录，他详细记录了自己如何用一根绳索带着整支商队越过崩塌的桥梁。最末页用红墨水写着："绳子是你在空中延伸的意志，但前提是你要先学会信任它，然后怀疑它，最后再信任它。"附录里有作者手绘的绳索磨损检查图，他强调任何绳索在使用前都必须仔细检查，因为峡谷上方的信任一旦断裂，就再也没有第二次机会。书中还提到，雨后或霜冻的绳索会失去部分摩擦力，必须改用双绳保护，不能仅凭经验信任潮湿的绳子。

## 设计意图

作为探索系列的垂直机动技能，把绳索使用转化为可解锁的地形通过能力，为关卡设计增加立体移动可能性。
