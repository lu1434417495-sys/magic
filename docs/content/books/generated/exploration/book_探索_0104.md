# 《幽径指南：寻找隐蔽路径》

## 基础信息

- **书籍 ID**：`book_探索_0104`
- **关联技能**：`exploration_hidden_path`（待新增，标签 `exploration`）
- **使用效果**：阅读后解锁探索技能 `exploration_hidden_path`；若已学会，提升 `current_mastery +90`，并在当前区域揭示 1 条未标记的近道或暗门。

## 书籍内容

《幽径指南》的每一页边角都画着一只指向不同方向的手，仿佛作者随时准备把读者拉进一条看不见的岔路。书中指出，隐蔽路径往往藏在"过度合理"的地方：一丛特别密的藤蔓、一块过分干净的岩石、一段与周围风向不符的气流。作者教读者用四种感官交叉验证：眼看光影缺口、耳听回声差异、手触墙面温度、鼻嗅空气流向。中间章节收录了数十条古代商旅留下的暗号，比如三道横线代表"上方可攀"，螺旋纹代表"下方有洞"。后半本则用寓言体讲述一位旅人如何因为发现一条幽径而救下整支商队，又如何因为炫耀这条幽径而永远失去了它。最末页的插图是一扇被树根半掩的石门，配文："门一直都在，缺的是愿意停下来找门的人。"书的勒口处写着一行小字："所有幽径都是双向的，你能用它接近秘密，秘密也能用它接近你。"

## 设计意图

作为探索系列的奖励发现技能，把"隐藏路径"设计为可培养的主动侦查能力，为地图设计增加纵深与复访价值。
