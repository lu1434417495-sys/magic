# 《影步：无光移动》

## 基础信息

- **书籍 ID**：`book_探索_0039`
- **关联技能**：`exploration_shadow_step`（待新增，标签 `exploration`）
- **使用效果**：阅读后解锁探索技能 `exploration_shadow_step`；若已学会，提升 `current_mastery +85`，在阴影中移动不触发敌人视线检查并提升夜间闪避。
- **阅读要求**：盗贼或法师；基础 `敏捷 ≥ 11`。
- **稀有度**：史诗（Epic）
- **建议投放**：暗影神殿、夜之导师、幽暗城。

## 书籍内容

这本书的封面漆黑如墨，几乎不反射任何光线。作者提出，阴影不仅是光明的缺失，更是一种可以被借用的介质。书中教导读者如何在移动时让身体始终处于至少两个光源的交界阴影中，从而大幅降低被发现的概率。中段详细讲解了如何控制脚步速度以避免影子抖动、如何利用墙壁与物体的遮挡形成连续阴影路径。后半部分涉及战斗中的高级应用，包括从阴影中发动突袭后再次隐入黑暗。书末的警告只有一行字："不要在完全没有光的地方使用影步，因为那里可能没有阴影，只有它。"

书中最后一段被刻意模糊处理，只有反复在阳光下暴晒才能显现：“影子的尽头不是黑暗，而是另一种光。”这句话至今无人真正理解；有人猜测它指向某个隐藏的暗影神殿入口。

他写道，最深沉的阴影，往往诞生在最明亮的光下。

## 设计意图

作为盗贼与法师的高级潜行机动技能，将环境光照转化为战术资源，服务于夜间副本、潜入任务与暗影流派构筑。
