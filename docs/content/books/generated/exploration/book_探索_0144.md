# 《掩体搜寻：战场中的临时庇护》

## 基础信息

- **书籍 ID**：`book_探索_0144`
- **关联技能**：`exploration_shelter_find`（待新增，标签 `exploration`）
- **使用效果**：阅读后解锁探索技能 `exploration_shelter_find`；若已学会，提升 `current_mastery +90`，并在遭遇突袭时更快找到可用掩体。
- **阅读要求**：无职业限制；基础 `感知 ≥ 7` 或 `敏捷 ≥ 7`。
- **稀有度**：普通（Common）
- **建议投放**：雇佣兵营地、军事训练营、战术任务奖励。

## 书籍内容

这本书的封面上有一道明显的划痕，像是被箭矢擦过。作者把掩体分为两类：硬质掩体与视觉掩体。前者能挡住攻击，后者能让你不被发现；最好的位置是同时具备两者。书中教读者如何在进入陌生区域时快速扫描掩体：石块、断墙、凹陷、粗大树干，以及任何能改变弹道的地形。中间章节强调，掩体的价值不仅在于防御，还在于它能否提供反击角度和撤退路线。后半本是一位老兵的战场笔记，他记录了 dozens of 次靠一个预先看好的掩体活下来的经历。最末页用粗体字写着："战斗中最重要的不是枪法，而是在被打之前就已经知道要往哪里躲。"书的后记是一位老军医的笔记，他指出战场上最多的伤亡不是因为敌人太强，而是因为士兵在交火前没有先找到能趴下的地方。附录中还列出了几种常见陷阱：看似坚固的矮墙可能已被炮火震裂，茂密灌木后或许正藏着敌人的开阔射界。

## 设计意图

作为探索系列的战斗环境互动技能，把掩体识别转化为可训练的本能，增强遭遇战中的位置选择与战术移动。
