# 《武器缴械：空手夺白刃》

## 基础信息

- **书籍 ID**：`book_战士战技_0036`
- **关联技能**：`warrior_disarm`
- **使用效果**：阅读后解锁 `warrior_disarm`（待新增，标签 `battle_art`）；若已学会，提升该技能 `current_mastery +110`。
- **阅读要求**：基础 `敏捷 ≥ 8`、 `感知 ≥ 7`；已学会 `warrior_unarmed_grapple` 或 `warrior_precision_strike`。
- **稀有度**：精良（Uncommon）
- **建议投放**：决斗者公会、王室卫队训练、黑市格斗教练。

## 书籍内容

缴械不是炫耀技巧，而是在最短时间内让敌人失去最重要的优势。这本书详细讲解了针对不同武器的缴械方法：对剑要控制手腕和剑格，对斧要利用其重心偏移，对长柄武器要切入内圈后推压柄部。作者强调，缴械最危险的时刻不是接触武器，而是敌人意识到你要缴械后会本能地反击。因此书中花了大量篇幅讲解如何用假动作和身体压迫创造缴械机会。后半部分讨论了缴械后的处理：是把武器踢开、捡起来，还是立刻压制失去武器的敌人。作者最后写道：“缴械成功后不要欣赏你的战果，敌人的拳头还在。”

封底内侧写着："成功者学会缴械，失败者学会后悔。"另一行后来添上的字迹反驳道："最成功的缴械是让对方自己把武器放下，因为他知道打不过你。"

缴械只是开始，真正决定胜负的是你能否在敌人错愕的那半秒内完成从防御到反击的转换。

## 设计意图

为战士提供功能性控制技能，对付依赖武器的敌人时具有战略价值。
