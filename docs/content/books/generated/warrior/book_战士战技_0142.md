# 《压倒之力：力量碾压》

## 基础信息

- **书籍 ID**：`book_战士战技_0142`
- **关联技能**：`warrior_overwhelming_force`
- **使用效果**：阅读后解锁 `warrior_overwhelming_force`；若已学会，提升该技能 `current_mastery +140`。
- **阅读要求**：职业标签含 `warrior`；基础 `力量 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：巨人营地、精英敌人掉落、高级战技商人。

## 书籍内容

压倒之力是一种以绝对力量正面击溃敌人防御的战技。作者主张，当力量差距足够大时，技巧反而成为多余。书中教导战士如何在每次攻击中把体重完全压上，让敌人的盾牌或武器无法承受而崩开。后半部分讲解了如何选择最重的武器、如何利用战场地形获得高度优势，以及如何在连续重击中保持呼吸节奏。作者还指出，压倒之力的使用者必须有足够的体力储备，因为每一击都消耗巨大。书中建议通过搬运重物与长距离负重跑增强基础力量。作者提醒，面对同样以力量见长的敌人时，硬碰硬并不明智，此时应改用卸力或闪避。末尾附有一张断裂的盾牌照片。他还提到，压倒之力的真正代价是手腕与肩膀的暗伤，日积月累终会找上来。书的最后一页还夹着一张泛黄的纸条，上面写着：“真正的战技，只在生死之间学会。”

## 设计意图

为高力量战士提供正面破防机制，让属性优势直接转化为战场压制。
