# 《断头台：低血裁决》

## 基础信息

- **书籍 ID**：`book_战士战技_0006`
- **关联技能**：`warrior_execution_cleave`
- **使用效果**：阅读后解锁 `warrior_execution_cleave`；若已学会，提升该技能 `current_mastery +130`，并标记为可核心化候选。
- **阅读要求**：已学会 `warrior_heavy_strike`；基础 `力量 ≥ 9`、 `意志 ≥ 6`。
- **稀有度**：稀有（Rare）
- **建议投放**：角斗场冠军奖励、处刑人密室、高阶战士导师传承。

## 书籍内容

这本书没有前言，第一页就是一幅刽子手的侧影和他手中的宽刃斧。作者认为，处刑斩不是残忍，而是对战斗节奏的尊重——当敌人已经摇摇欲坠时，用一记确定性的重击结束交换，比任何花哨连招都更有效。书中详细讲解了如何判断“斩杀线”：不仅看敌人的血量，还要看他的站姿、呼吸和武器角度。一个撑着膝盖喘气的敌人，比一个站着但血量更低的敌人更容易被处刑。作者还提醒读者，发动处刑斩时自己的身体也会暴露巨大破绽，因此必须确认周围没有其他威胁。书的末尾有一行被反复描粗的字：“不要对还能反击的人使用处刑。”

书中夹着一枚生锈的竞技场铜牌，背面刻着"第十七场，一击"。铜牌的边缘已经被磨得发亮，说明原主人经常在口袋里摩挲它，作为某种沉默的提醒。

作者还提醒，处刑斩最重的是决心，犹豫会让剑慢上半拍，而那半拍往往就是生死之差。

## 设计意图

将处刑斩打造为战士收割残血的核心爆发技能，支持核心化成长路线。
