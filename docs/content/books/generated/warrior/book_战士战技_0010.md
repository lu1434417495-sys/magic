# 《战场喘息：伤痛管理学》

## 基础信息

- **书籍 ID**：`book_战士战技_0010`
- **关联技能**：`warrior_battle_recovery`
- **使用效果**：阅读后解锁 `warrior_battle_recovery`；若已学会，提升该技能 `current_mastery +100`，并恢复阅读者少量 `current_hp`。
- **阅读要求**：角色职业标签含 `warrior` 或 `berserker`；基础 `体质 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：战地医疗营、佣兵酒馆任务、残破军营宝箱。

## 书籍内容

不是每个人都能在战斗中包扎伤口，但每个活下来的战士都学会了在刀光剑影中调整自己的呼吸。这本书不讲医术，只讲“战场喘息”——如何在两波攻击的间隙里让心率下降、肌肉松弛、视野重新聚焦。作者把恢复分成四步：找掩体、压伤口、慢呼吸、扫视野。他警告说，最常见的死亡不是在冲锋时，而是在你以为安全了、低头看伤口的那一刻。书中还收录了几种简易止血手法，以及如何用盾牌或短刀临时制作夹板。最后一页只有一句话：“喘气的权利不是敌人给的，是你自己抢出来的。”

最后一章的页边写满了不同人的名字，每个名字后面都跟着一个数字，像是某种无声的清单。作者在前言里坦白："这些是我没能救回来的人，这本书是为了让他们的数字不再增加。"

书中还附有几行急救口诀，作者要求读者背到能在梦中念出来，因为战场上没有人会给你翻书的时间。

## 设计意图

为战士提供续航与自救能力，强化前排职业在持久战斗中的生存循环。
