# 《堡垒架势：一人成军》

## 书籍内容

堡垒架势要求战士把武器与盾牌组成一道移动的城墙。书中把架势拆成“锚点”与“拱顶”：锚点是双脚的站位，拱顶是盾牌上沿与武器交叉形成的防御三角。作者指出，这个架势不是为了美观，而是为了把敌人的攻击引导向盾牌最坚固的区域，同时让武器随时准备从盾沿下方刺出。后半部分讲解了如何在持盾时呼吸，以及被重击后如何用小碎步恢复平衡。为了掌握这个架势，作者要求练习者每天面对木人桩连续格挡三百次，并在每次格挡后立刻尝试一次盾沿刺击。他强调，堡垒架势最危险的时刻不是被重击，而是自己急躁地想主动攻击。书的封底印着一座小城堡，下面写着：“城堡从不需要进攻，它只需要存在。”书的装订用的是双股皮绳，因为单股线根本撑不过反复翻阅。书的最后一页还夹着一张泛黄的纸条，上面写着：“真正的战技，只在生死之间学会。”

## 设计意图

为持盾战士提供一个攻防一体的架势，强化前排的生存与反击能力。
