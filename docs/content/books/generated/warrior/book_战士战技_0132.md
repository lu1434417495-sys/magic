# 《龙尾横扫：席卷八方》

- **关联技能**：`warrior_dragon_sweep`

## 书籍内容

龙尾横扫模仿巨龙摆尾的动作，要求战士在低姿态下用武器扫出一圈大范围的攻击。书中教导如何把身体重心降到接近跪姿，用后腿蹬地带动上半身旋转，让武器像龙尾一样扫过四周。作者指出，这个姿势虽然威力巨大，但起身较慢，所以必须在敌人包围自己时使用，或在有队友掩护侧翼时使用。作者还提醒，龙尾横扫的发力顺序至关重要，必须从后腿到腰胯再到肩背，任何一环脱节都会让扫击失去速度。书中附有一张龙尾摆动的草图，标注着力量传导的方向。练习者可以先手持木棍蹲姿旋转，直到能在不失去平衡的情况下连续完成两次横扫，再换真刀。末尾有一句古老的战场谚语：“龙尾一扫，寸草不生。”他还提醒，龙尾横扫结束后要低姿翻滚，避免起身时被侧翼偷袭。书的最后一页还夹着一张泛黄的纸条，上面写着：“真正的战技，只在生死之间学会。”

## 设计意图

为战士提供低姿态大范围的解围战技，强化被包围时的反制能力。
