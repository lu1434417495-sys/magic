# 《持盾守则：格挡不是终点》

- **书籍 ID**：`book_战士战技_0009`
- **关联技能**：`warrior_guard`
- **使用效果**：阅读后解锁 `warrior_guard`；若已学会，提升该技能 `current_mastery +90`，并提升该技能生效期间 `guarding` 减伤效果 2%（一次性持续增益，最多累计 3 次）。

## 书籍内容

这本书来自一名退役盾卫，他用三十年的经验告诉读者：格挡不是把攻击挡下来，而是把攻击导向对你无害的地方。书中详细讲解了三种基本盾位：高位挡劈砍、低位挡突刺、侧位挡横扫。每一种都配有小图和常见错误示范。作者最强调的误区是“用盾推人”——在敌人攻击尚未结束时就急着把盾顶出去，结果往往是盾被推开、人露出胸膛。正确的做法是“先吃后送”：先让盾面承受冲击，再顺着来力方向滑动一小段，把攻击卸到身侧。书的后半部分讨论了如何在格挡后立即转入反击或撤退，而不是站在原地等下一轮攻击。

书的夹层里藏着半块碎裂的木盾碎片，据说是作者第一次成功格挡时留下的纪念品。碎片边缘光滑，说明它被无数次抚摸，成了某种护身符般的存在。

作者最后写道："格挡成功时不要笑，敌人会从你的表情里读出你的节奏。"

## 设计意图

作为战士防御姿态的正式入口，承担前排坦克的基础减伤教学。
