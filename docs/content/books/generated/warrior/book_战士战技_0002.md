# 《横扫队列：弧线控制》

## 基础信息

- **书籍 ID**：`book_战士战技_0002`
- **关联技能**：`warrior_sweeping_slash`
- **使用效果**：阅读后解锁 `warrior_sweeping_slash`；若已学会，提升该技能 `current_mastery +90`。
- **阅读要求**：已学会任意近战攻击技能；基础 `力量 ≥ 7`、 `敏捷 ≥ 5`。
- **稀有度**：普通（Common）
- **建议投放**：边境哨塔军械库、巡逻队战利品、通用战技书架。

## 书籍内容

弧线的可怕之处不在于它砍中多少人，而在于它让多少人不敢靠近。这本书用稻草人阵列作为教学模型，要求练习者在六个不同间距的靶位中保持同一套挥剑轨迹。作者反复强调，横扫不是把剑抡圆，而是用前手控制高度、后手决定收势；一旦后手失控，剑会带着身体一起偏离中线。书中夹了一张发霉的靶场示意图，上面标着“危险区”“压制区”和“浪费区”。作者还提出一个反直觉的观点：横扫最忌讳正面接敌，最佳发动时机是敌人侧向移动、彼此站位成一条斜线时。末尾有一章讲如何在横扫后立刻转入防御姿态，避免被反击穿透空档。

书脊内侧夹着一张泛黄的演习记录，显示作者曾因一次过度横扫被教官罚站了整整一下午。他在记录背面写道："那次我学会了，剑挥出去之后，身体必须比剑先停下来。"

## 设计意图

服务战士对多目标压制的入门需求，把横扫从AOE按钮提升为站位与时机判断。
