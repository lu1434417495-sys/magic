# 《盾牌冲锋：移动城墙》

- **关联技能**：`warrior_shield_charge`

## 书籍内容

盾牌冲锋是把防御姿态转化为进攻动量的技艺。这本书讲解了如何用盾牌作为前沿，整个人像一堵移动的墙一样压向敌人。作者强调，冲锋时视线必须越过盾牌上缘，而不是埋头猛冲；否则很容易在撞上敌人的一瞬间失去平衡。书中还讨论了如何应对敌人的闪避：如果敌人向侧面躲开，要立即停下脚步转为横扫或盾击；如果敌人试图硬抗，要用全身重量把他向后推。后半部分提供了一套力量训练方案，包括负重深蹲、推车和盾面撞击木桩。作者最后提醒：盾牌冲锋对长枪阵和拒马效果极差，使用前要确认敌人类型。

书中夹着一张军团合影，照片里所有人都举着盾牌，只有作者露出了半张脸。他在照片背面写道："冲锋时最前排的人通常照不到全脸，但队伍记得住他的背影。"

盾牌冲锋最忌讳孤军深入，一个好的冲锋应该让队友能够顺着打开的缺口跟进，而不是把你留在敌阵中央。

## 设计意图

为盾战战士提供机动型控制技能，把防御装备转化为进攻手段。
