# 《盾击：铁门的回响》

## 基础信息

- **书籍 ID**：`book_战士战技_0011`
- **关联技能**：`warrior_shield_bash`
- **使用效果**：阅读后解锁 `warrior_shield_bash`；若已学会，提升该技能 `current_mastery +120`。
- **阅读要求**：已装备盾牌；基础 `力量 ≥ 7`、 `体质 ≥ 6`。
- **稀有度**：精良（Uncommon）
- **建议投放**：断桥营寨军械库、盾卫训练任务奖励、老兵遗物。

## 书籍内容

盾击不是用盾打人，而是用盾改变战斗的节奏。这本书的作者——一位只剩三根手指的老兵——把盾击比作敲门：你敲的不是敌人的脸，而是他的平衡感。书中详细拆解了盾击的发力链条：从后脚蹬地到髋部前顶，再到盾面最后几寸的加速。作者特别强调，盾击最忌讳的是“推”而不是“撞”；推会让敌人后退但保持平衡，撞才会让他在原地僵住。后半部分记录了盾击与格挡的连招：先用盾面迎接攻击，在对方武器被弹开的瞬间踏步上前，用盾缘砸向敌人的锁骨或面门。书页间夹着一块变形的铁片，据说是某次盾击后从敌人头盔上剥下来的。

书中有一页被撕去大半，只剩下半句话："……盾面贴脸的瞬间，要记得闭气，否则牙齿会飞进自己的喉咙。"剩余的字迹潦草，仿佛写作者当时正在战场的喧嚣中记录。

练习者被反复提醒：盾击之后要立即收盾护住中线，否则下一次攻击会直接从你敞开的胸怀穿过。

## 设计意图

为盾战战士提供控制型近战手段，与盾反形成“主动压制vs被动反制”的互补。
