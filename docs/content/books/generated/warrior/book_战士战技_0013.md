# 《战吼：声音即武器》

## 基础信息

- **书籍 ID**：`book_战士战技_0013`
- **关联技能**：`warrior_war_cry`
- **使用效果**：阅读后解锁 `warrior_war_cry`；若已学会，提升该技能 `current_mastery +110`，并提升该技能下一次使用时队友增益幅度 5%（一次性战斗增益）。
- **阅读要求**：角色职业标签含 `warrior` 或 `berserker`；基础 `力量 ≥ 8`、 `意志 ≥ 7`。
- **稀有度**：精良（Uncommon）
- **建议投放**：战歌氏族祭坛、军团指挥官奖励、高地战鼓仪式。

## 书籍内容

战吼不是喊叫，而是一种把全身气力从丹田推出来的振动。作者从呼吸法开始教起：吸气到腹部而非胸口，发声时舌头抵住上颚，让声音从头腔共鸣而不是喉咙撕裂。书中列出了七种战场常用的吼声，每一种对应不同的意图：提振友军、震慑敌胆、标记集火、宣告冲锋。作者还提醒，战吼最忌讳在错误的时机使用——在敌人已经冲到脸上时才吼，只会让自己喘不上气。后半部分记录了如何把战吼与特定动作绑定，比如在举起武器的同时发出特定的音节，让队友即使没有看到手势也能判断你的下一步。

某页夹着一小段干枯的声带状物体，旁边批注"不是龙的，但足够吓人"。作者声称这是从某只沼泽巨兽身上取得的样本，用来展示共鸣腔的结构。

书的后半部分还讲到如何在连续战吼后保护喉咙，因为哑掉的指挥官比死去的指挥官更让队伍绝望。

## 设计意图

把战吼从氛围装饰转化为正式团队增益技能，强化战士的领导力与团队价值。
