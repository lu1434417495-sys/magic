# 《精准猛击：打到该打的地方》

- **书籍 ID**：`book_战士战技_0033`
- **关联技能**：`warrior_precision_strike`

## 书籍内容

力量决定你能打多重，精准决定你能打多对。这本书教战士如何像刺客一样寻找弱点，同时保留战士的正面压迫能力。作者提出“三层弱点”理论：第一层是护甲缝隙，第二层是姿势失衡，第三层是心理破绽。书中强调，真正的精准打击不是慢慢瞄准，而是在高速交换中仍然能把攻击送到正确位置。后半部分收录了针对不同敌人的优先打击目标：对法师是持咒的手，对弓手是拉弦的肩，对重装战士是膝盖后侧和脚踝。作者最后写道：“不要和敌人的优势比，去找他不得不保护的地方。”

书中夹着一张人体解剖图，每个要害都被人用针尖刺出了小孔。原主人留下说明："白天看图，晚上闭眼回忆孔的位置。三个月后，你会在黑暗中也能找到破绽。"

精准不是天生的，是无数次重复同一个动作直到肌肉比意识更快找到正确位置的结果。

## 设计意图

为战士提供精准打击分支，与力量型技能形成差异化构筑选择。
