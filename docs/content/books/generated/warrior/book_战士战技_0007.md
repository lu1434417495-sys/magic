# 《跃斩：从天而降的破绽》

## 基础信息

- **书籍 ID**：`book_战士战技_0007`
- **关联技能**：`warrior_jump_slash`
- **使用效果**：阅读后解锁 `warrior_jump_slash`；若已学会，提升该技能 `current_mastery +110`。
- **阅读要求**：已学会 `warrior_heavy_strike` 或 `warrior_execution_cleave`；基础 `力量 ≥ 8`、 `敏捷 ≥ 6`。
- **稀有度**：精良（Uncommon）
- **建议投放**：高地训练营、狮鹫骑士委托、山岳据点战技传授。

## 书籍内容

跃斩的魅力在于它把高度变成了伤害。作者先从落地讲起：如果双脚不同时着地，所有从空中积累的力量都会在膝盖里散掉。然后是起跳——跃斩不是垂直跳高，而是斜向跃进，利用敌人视野的盲区缩短距离。书中画了很多简笔示意图，展示如何从掩体、矮墙甚至队友肩头起跳。作者还强调，跃斩最危险的时刻不是空中，而是落地后那半秒；如果那一击没有让敌人失衡，练习者就会陷入包围。后半部分记录了一种被称为“鹰落”的变体：在空中改变握剑姿势，把劈砍变成突刺，专门对付披重甲的敌人。

扉页有一行颤抖的字迹："我徒弟死在落地后的半秒，请记住我的话。"字迹下方画了一个简单的箭头，指向关于"落地后立即收剑护胸"的那一段。

书末附有一张落地姿势的分解图，作者要求练习者每天从矮墙上跳下五十次，直到膝盖不再发出抗议。

## 设计意图

为战士提供机动型进场手段，把空间利用与伤害爆发结合起来。
