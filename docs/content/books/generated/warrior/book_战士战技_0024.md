# 《不屈：最后的站立》

## 基础信息

- **书籍 ID**：`book_战士战技_0024`
- **关联技能**：`warrior_last_stand`
- **使用效果**：阅读后解锁 `warrior_last_stand`；若已学会，提升该技能 `current_mastery +130`，并提升该技能触发时生命值阈值 2%（一次性永久调整）。
- **阅读要求**：角色职业标签含 `warrior` 或 `knight`；基础 `体质 ≥ 10`、 `意志 ≥ 9`。
- **稀有度**：史诗（Epic）
- **建议投放**：绝境突围任务奖励、堡垒守军传承、濒死老兵遗物。

## 书籍内容

真正的战士不是不会倒下，而是在倒下之前拒绝倒下。这本书不讲如何赢，只讲如何“站到最后”。作者把不屈分成身体和心理两个层面：身体上，要学会在重伤时保持肌肉紧张，不让伤口过度失血；心理上，要学会把恐惧压到意识的最底层，让它成为一种背景噪音而不是命令。书中记录了多名战士在绝境中站起来的案例，他们中的大多数最终仍然死去，但他们的站立为队友争取了关键的时间。作者最后写道：“不屈不是奇迹，是一种选择。你选择继续呼吸，选择继续握住武器，选择让敌人多看你一眼。”

书的最后一页只有一滴干涸的泪痕形状，没有任何文字。前任读者中有人在这滴痕迹旁写道："这不是悲伤，是选择站立时身体唯一允许流出的东西。"

作者认为，不屈的真正考验不是在万众瞩目时站起来，而是在无人看见时仍然选择不趴下。

## 设计意图

为战士提供濒死反击/韧性机制，强化前排职业在极限压力下的战略价值。
