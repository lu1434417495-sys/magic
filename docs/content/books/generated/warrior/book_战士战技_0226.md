# 《大地擒握：让敌人扎根》

## 基础信息

- **书籍 ID**：`book_战士战技_0226`
- **关联技能**：`warrior_earth_grasp`
- **使用效果**：阅读后解锁 `warrior_earth_grasp`；若已学会，提升 `current_mastery +160`。

## 书籍内容

大地擒握是一种让战士通过击打地面制造震动，使敌人双脚暂时陷入土中的控制技。作者原本是矿工，他把凿岩时“找到裂缝再用力”的经验写进了书里。书中教人如何通过听地面的回响判断土质：松土需要更大的震动范围，硬土则需要更集中的冲击点。最实用的章节是如何在擒握成功后立刻接上致命一击，因为敌人只会在原地被困很短时间。书页里夹着几块不同质地的土块，每块旁边都有使用者的笔记。某位批注者写道：“大地不会帮你抓住任何人，除非你先向它道歉。”另一人反问：“如果道歉有用，还要锤子做什么？”大地擒握在雨天效果减半，因为雨水会提前释放震动。大地擒握对飞行单位无效，但可以让试图起跳的敌人重重摔回地面。大地擒握对穿着铁靴的敌人效果最佳，因为铁会放大震动。

## 设计意图

为控制型战士提供地面束缚技能，丰富控场手段。
