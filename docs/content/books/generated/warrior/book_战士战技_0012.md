# 《挑衅的艺术：让敌人看你》

## 书籍内容

真正的挑衅不是骂人，而是让敌人相信他如果不先打你，就会后悔。这本书收集了来自不同军团和氏族的挑衅方式：从矮人战团的低沉喉音到草原部落的尖利口哨。作者指出，最有效的挑衅往往不是语言，而是动作——比如用武器敲一下自己的盾牌，或者在敌人面前故意转过身去。书中还警告说，挑衅必须建立在“你能承受后果”的基础上；一个脆皮角色的大声嘲讽只会让自己死得更快。后半部分讨论了如何在团队中为远程和施法者制造安全窗口，以及当多个敌人同时被嘲讽时如何调整站位。

封底印有一句被划掉的旧口号："最强的嘲讽是无声的藐视。"下面补充了新的一句话："但战场上，你需要让敌人和队友都听得见。"

作者用一章篇幅分析了不同种族和文化对挑衅的反应，提醒读者不要用兽人听不懂的贵族俚语去羞辱对方。

## 设计意图

确立战士作为团队仇恨控制者的基础身份，服务于前排保护后排的战术循环。
