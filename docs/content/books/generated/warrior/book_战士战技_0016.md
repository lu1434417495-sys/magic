# 《连段骨架：从一招到一套》

## 基础信息

- **书籍 ID**：`book_战士战技_0016`
- **关联技能**：`warrior_combo_strike`
- **使用效果**：阅读后解锁 `warrior_combo_strike`；若已学会，提升该技能 `current_mastery +120`，并提升该技能下一次完整连段最后一击伤害 5%（一次性战斗增益）。
- **阅读要求**：已学会至少两个战士近战技能；基础 `敏捷 ≥ 8`、 `力量 ≥ 7`。
- **稀有度**：精良（Uncommon）
- **建议投放**：武馆进阶课程、竞技场积分兑换、流浪剑豪委托。

## 书籍内容

连招不是把多个技能按顺序放出来，而是让每一招都为下一招创造更好的条件。这本书用“骨架”作比喻：重击是脊椎，突刺是肋骨，横扫是肩胛，后撤是关节。作者列举了五种基础连招骨架，从“重击—突刺—后撤”到“横扫—跃斩—断头台”。每一种都标注了适用场景和常见反制。书中强调，连招的最大敌人是贪婪——看到敌人血量下降就硬要把连段打完，往往会被反击打断。后半部分讲“断招”：在连招进行到一半时发现情况不对，如何用最小幅度的动作转入防御或撤退。

书末附有一张复杂的连招图，但所有箭头都指向同一个终点："根据实际情况调整。"作者用整整一页解释："骨架是死的，战斗是活的，死记连招的人会被会应变的人杀死。"

连招的骨架就像乐谱，真正让它动听的不是音符本身，而是演奏者决定在哪里停顿、在哪里加速。

## 设计意图

为战士构筑提供连招骨架与组合思维，支撑中阶玩家从按技能到打连段。
