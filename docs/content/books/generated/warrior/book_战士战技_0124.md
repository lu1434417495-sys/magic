# 《烟灰疾步：迷踪之影》

## 基础信息

- **书籍 ID**：`book_战士战技_0124`
- **关联技能**：`ashen_soot_dash`
- **使用效果**：阅读后解锁 `ashen_soot_dash`；若已学会，提升该技能 `current_mastery +100`。
- **阅读要求**：无职业限制；基础 `敏捷 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：灰烬交界入口营地、通用战技商人、低级任务奖励。

## 书籍内容

烟灰疾步是灰烬战士用来脱离视线的冲刺技巧。书中教导战士在奔跑时扬起一片烟灰或尘土，让敌人在一瞬间失去自己的确切位置。作者强调，这一技巧的关键不在跑得快，而在时机——必须在敌人即将出招的前一刻启动，让那一击落在空处，而自己则从烟幕的另一侧出现。作者还在书中比较了烟灰与尘土的区别：灰烬更轻、更容易悬浮，但也更容易被风吹散；尘土则相反。练习者要根据战场环境选择扬起的材料，并注意风向。末尾附有一张手绘的烟幕图，中心留出一个模糊的人形轮廓，旁边写着：“看见我的时候，已经太晚了。”他总结道：“烟灰疾步不是隐身，而是让敌人在该看见你的时候，正好眨了一下眼。”书的最后一页还夹着一张泛黄的纸条，上面写着：“真正的战技，只在生死之间学会。”许多练习者会把这句话抄在自己的护腕内侧。

## 设计意图

提供灰烬主题的闪避位移战技，让战士在近战中制造视觉混乱。
