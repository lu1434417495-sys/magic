# 《步法铁律：站稳才能打准》

## 基础信息

- **书籍 ID**：`book_战士战技_0048`
- **关联技能**：`warrior_footwork_foundation`
- **使用效果**：阅读后解锁 `warrior_footwork_foundation`（待新增，标签 `passive`）；若已学会，提升该技能 `current_mastery +90`，并提升 `敏捷` 属性 1 点（一次性永久调整）。
- **阅读要求**：无职业限制；基础 `敏捷 ≥ 6`。
- **稀有度**：普通（Common）
- **建议投放**：武馆入门课程、佣兵基础训练、街头格斗教练。

## 书籍内容

所有战技都建立在步法之上，这本书就是那座地基。作者从最基础的站立姿势开始：双脚分开与肩同宽，重心落在前脚掌，膝盖微屈像弹簧。书中详细讲解了前进、后退、侧移和转身的基本步法，每一种都强调身体中轴的稳定。作者指出，最常见的步法错误是“交叉步”——当双脚交叉时，身体最容易被推倒。后半部分讨论了如何把步法和攻击结合：攻击时踏入、防御时退后、闪避时侧移。作者最后写道：“如果你的步法对了，你甚至不需要看敌人的眼睛，你的身体会自己找到正确位置。”

书的底部比顶部厚，因为读者反复翻阅前半部分导致纸张变形。作者在再版前言里幽默地说："这本书站不稳，正说明它的内容被认真站过。"

步法练到最后，你会忘记自己在移动，身体会自动找到最稳定的位置，就像水找到杯子的形状。

## 设计意图

作为战士基础被动技能书，用属性成长强化角色的整体机动底子。
