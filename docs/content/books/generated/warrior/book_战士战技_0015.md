# 《斗气斩：第一缕锋芒》

## 基础信息

- **书籍 ID**：`book_战士战技_0015`
- **关联技能**：`warrior_aura_slash`
- **使用效果**：阅读后解锁 `warrior_aura_slash`；若已学会，提升该技能 `current_mastery +130`，并按技能评级微量提升 `aura_max` 上限。
- **阅读要求**：已解锁 `AURA` 资源链或完成任意 `cultivation` 基础功法；基础 `力量 ≥ 9`。
- **稀有度**：稀有（Rare）
- **建议投放**：斗气武馆、荒野修行洞窟、狂战士导师传授。

## 书籍内容

斗气斩是战士把内在能量外放到武器上的第一步。这本书没有讲复杂的咒语，只讲如何让斗气顺着持剑的手流到锋刃。作者把练习分成三个阶段：感气、蓄气、放气。感气是静坐时感知体内那股温热流动的位置；蓄气是在挥剑前把斗气聚集到手臂；放气则是在剑锋接触敌人前的一瞬间让斗气迸发。书中反复警告，蓄气过久会导致经脉酸痛，放气过早则会浪费斗气。后半部分介绍了三种常见的斗气斩偏误：斩线弯曲、威力外泄、反震自身。每一页都配有一幅简单的经脉图，标注了斗气应该从哪些穴位经过。

最后一页被烧掉一角，残留的字迹写着："当你的斗气第一次斩断风时，你会听见自己的心跳像战鼓。"烧焦的边缘形状像是一道剑痕，不知是意外还是刻意的装饰。

作者建议初学者在黎明和黄昏练习，因为这两个时刻的光线最容易让人看见斗气外放的微弱轨迹。

## 设计意图

把斗气系统与战士战技正式连接，为非法系战士提供资源驱动的远程/强化攻击手段。
