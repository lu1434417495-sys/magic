# 《韧性训练：先学会挨打》

## 基础信息

- **书籍 ID**：`book_战士战技_0034`
- **关联技能**：`warrior_pain_tolerance`
- **使用效果**：阅读后解锁 `warrior_pain_tolerance`（待新增，标签 `passive`）；若已学会，提升该技能 `current_mastery +90`，并提升阅读者 `current_hp` 上限微量。
- **阅读要求**：基础 `体质 ≥ 8`；职业标签含 `warrior` 或 `berserker`。
- **稀有度**：普通（Common）
- **建议投放**：战地医疗营、老兵传授、苦修训练任务。

## 书籍内容

每个战士都想学会打人，但活下来的战士都学会了挨打。这本书不讲进攻，只讲身体如何承受冲击。作者从“绷紧与放松”开始教起：在攻击即将命中时绷紧肌肉可以分散伤害，但一直绷紧会快速消耗体力。书中还讨论了跌倒的艺术——被击倒时不要用手掌硬撑，而是用肩膀或背部翻滚卸力。后半部分进入心理层面：如何把疼痛从“我要死了”的恐慌中分离出来，变成“这里受伤了”的客观信息。作者建议练习者每天用木棍轻击身体不同部位，不是为了练硬功，而是为了熟悉各种疼痛的质地。

书的边角磨损严重，仿佛曾被无数次从地上捡起又丢下。作者在前言中写道："如果你读这本书时没摔过几次，那你读得太小心了；韧性是摔出来的，不是看出来的。"

作者建议练习者从低强度冲击开始，逐渐提高承受力；妄图一步登天的人只会提前结束自己的战士生涯。

## 设计意图

为战士提供被动减伤/韧性入口，支撑前排坦克的成长曲线。
