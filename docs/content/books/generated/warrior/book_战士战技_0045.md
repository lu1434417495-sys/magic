# 《破釜沉舟：无路可退》

## 基础信息

- **书籍 ID**：`book_战士战技_0045`
- **关联技能**：`warrior_desperate_gambit`
- **使用效果**：阅读后解锁 `warrior_desperate_gambit`（待新增，标签 `battle_art`）；若已学会，提升该技能 `current_mastery +120`，并提升该技能下一次触发时伤害加成 5%（一次性战斗增益）。
- **阅读要求**：基础 `意志 ≥ 9`；已学会 `warrior_last_stand` 或 `warrior_blood_rage`。
- **稀有度**：史诗（Epic）
- **建议投放**：绝境突围传说任务、濒死老兵遗物、战场英灵传承。

## 书籍内容

当你没有退路时，唯一的选择就是把一切都押在下一击上。这本书讲述的是那些在绝境中反败为胜的战士所共有的心理状态：不是绝望，而是一种冷静的疯狂。作者认为，破釜沉舟不是赌博，而是精确计算后的全力一击。书中要求练习者在日常训练中模拟绝境：被包围、受伤、武器受损、队友倒下，然后练习在这种状态下做出最正确的选择。后半部分收录了几位传奇战士的案例，他们都在看似必死的局面中找到了唯一的胜机。作者最后提醒：这种心态一旦成瘾，会让人主动把自己逼入绝境，而那往往才是真正的绝境。

书的封底印着一艘正在燃烧的船，火焰用了真正的红色颜料。作者写道："破釜沉舟不是勇敢，是计算后的绝望。只有当你真的无路可退时，这艘船才会载你过去。"

破釜沉舟一旦发动，就没有中间状态；你要么冲过去，要么倒在自己的灰烬里。

## 设计意图

作为战士高阶绝境反击技能，把低血量转化为高爆发，强化戏剧性翻盘可能。
