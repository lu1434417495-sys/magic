# 《收割横扫：麦田之刃》

## 基础信息

- **书籍 ID**：`book_战士战技_0112`
- **关联技能**：`warrior_harvest_slash`
- **使用效果**：阅读后解锁 `warrior_harvest_slash`；若已学会，提升该技能 `current_mastery +100`。
- **阅读要求**：职业标签含 `warrior`；基础 `力量 ≥ 7`。
- **稀有度**：普通（Common）
- **建议投放**：民兵训练场、战技商人、低级野外遭遇。

## 书籍内容

收割横扫是专为成群敌人设计的横斩。作者把战场比成熟透的麦田，把敌人比成麦秆，要求战士在挥剑时想象自己正在收割。书中强调横扫的高度应控制在敌人胸腹之间，太高会漏掉矮个子，太低则容易被武器架住。发力要从后腿蹬地开始，带动腰腹旋转，最后让剑尖在弧线末端达到最高速度，这样一次横扫可以同时威胁多个目标。作者还提醒，横扫时不要追求武器回到原位，而要让惯性自然完成收势，否则下一次攻击会慢半拍。书中记录了不同武器的最佳横扫距离：长剑适合三人宽，大刀适合五人宽，而斧头则更适合两人宽但威力更大。末尾画着一片金色麦田，配文：“收割者从不看麦穗，只看弧线。”作者最后总结：横扫不是看你能砍到几个，而是看你能逼退几个。书的最后一页还夹着一张泛黄的纸条，上面写着：“真正的战技，只在生死之间学会。”

## 设计意图

作为战士的基础范围战技，让单体职业在面对密集敌人时有清场能力。
