# 《重甲行者：穿着堡垒战斗》

## 基础信息

- **书籍 ID**：`book_战士战技_0031`
- **关联技能**：`warrior_armored_advance`
- **使用效果**：阅读后解锁 `warrior_armored_advance`（待新增，标签 `battle_art`）；若已学会，提升该技能 `current_mastery +100`。
- **阅读要求**：已装备重甲；基础 `体质 ≥ 8`；职业标签含 `warrior` 或 `knight`。
- **稀有度**：普通（Common）
- **建议投放**：重甲工坊、堡垒守军训练、骑士侍从任务。

## 书籍内容

重甲不是让你站着不动的借口，而是让你能够无视某些攻击的资本。这本书详细讲解了如何在重甲中保持机动：步伐要小，重心要低，转身要用脚而不是用腰。作者指出，重甲战士最大的敌人是疲劳——不是敌人打累了你，而是你自己在盔甲里把自己累垮了。书中提供了一套呼吸和节奏训练，帮助练习者在战斗中把体力消耗降到最低。后半部分讨论了如何利用重甲进行“碾压式推进”：不是奔跑，而是稳步向前，用身体和盾牌把敌人挤开位置。作者写道：“当你成为一堵会走路的墙时，敌人就会开始怀疑自己为什么要挡在你面前。”

书的封面用一块真正的薄铁片加固，拿在手里有一种不合常理的沉重感。作者解释："先习惯书的重量，再习惯甲的重量，战场上你就少分一次心。"

重甲战士的移动不是慢，而是有节奏地慢；学会用敌人的急躁来换取自己的稳定，是穿着堡垒战斗的艺术。

## 设计意图

强化重甲战士的前排推进能力，把装备优势转化为战术移动优势。
