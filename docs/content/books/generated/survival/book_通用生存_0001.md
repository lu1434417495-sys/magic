# 《灰烬路口篝火手记》

## 书籍内容

在灰烬交界的寒夜里，篝火不只是取暖工具，更是人与世界谈判的筹码。这本书由一名不愿透露姓名的巡路者整理，开篇列出九种当地可燃残渣：树皮纤维、干燥苔藓、某些怪物背脊上的角质碎屑。作者反复强调，点火前必须先清理地面三掌宽，因为交界地的灰烬会突然复燃。书中夹有一张焦黑的示意图，标注了风向、背风坡与排烟角度。最珍贵的章节是“湿木燃烧法”：用剥下的树皮做内芯，把半湿的枝干架成金字塔，让火焰从中心向外烘干外层。最后几页记录了作者某夜的经历：他靠着一小团火撑过了三次灰烬巡游者的经过，因为他知道敌人也会忌惮光亮。篝火在这里不是信号，是界线。 书的封底被火燎去一角，留下焦黑的指印，仿佛前主人最后才舍得放下它。焦痕旁还写着一行小字：火灭之前，先别熄灭警惕。

## 设计意图

作为生存系入门书籍，降低荒野夜宿风险并把篝火转化为战略资源。
