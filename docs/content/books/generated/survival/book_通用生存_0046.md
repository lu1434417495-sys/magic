# 《战场搜尸伦理与技巧》

## 基础信息

- **书籍 ID**：`book_通用生存_0046`
- **关联技能**：`survival_loot_triage`
- **使用效果**：阅读后解锁 `survival_loot_triage`；若已学会，提升 `current_mastery +95`，并提升搜刮时获得稀有物资概率 10%（一次性）。
- **阅读要求**：无职业限制；基础 `感知 ≥ 7`。
- **稀有度**：普通（Common）
- **建议投放**：战场后勤营、战地搜尸伦理任务、军需官宝箱。

## 书籍内容

从死人身上拿东西，是战争的一部分，但如何拿决定你还是不是人。这本手册由战地后勤官编写，教人快速、安全地搜刮阵亡者物资。书中列出“搜尸四步”：确认死亡、检查陷阱、分类取物、记录身份。最实用的章节是“陷阱识别”：敌人有时会在尸体下压入手雷或毒针，翻动前要先从脚部轻拉测试。作者还强调，搜尸不是洗劫，要留下身份证明与遗物，方便后续辨认与家属认领。书中附有一张物资优先级表，标注了哪些东西值得带走，哪些只会增加负重。最后一页写着：“死者不需要尊严，但活人需要。” 后勤官在最后一页写：从死者手中拿走的，要替他还给活人。 拿走物资时，最好也带走死者的名字。 每个名字都值得被记住。后勤官在扉页贴了一张阵亡者名单的残片，注明：记住他们，比带走他们的刀更重要。

## 设计意图

把战场搜刮从自动拾取变为有伦理与风险考量的选择，强化叙事与资源取舍。
