# 《饥饿行军口粮分配律》

## 书籍内容

粮食有限时，吃掉最后一口的人就是凶手。这本小册子来自一支长途商队，作者用算式与案例说明如何在未知路程中分配口粮。核心原则是“前紧后松”：出发第一天只吃七分饱，把最完整的口粮留到意志最薄弱的返程阶段。书中有一张按体重与气温计算每日消耗的表格，边角被多次涂改。最珍贵的章节是“心理口粮”：把一块干粮分成三份，每次只吃一份，欺骗胃以为自己还有剩余。作者也警告不要依赖野味补充计划，因为猎物的出现从不可预测。最后几页记录了商队某次覆灭的原因：领队在第三天为庆祝找到水源而消耗了半数存粮。书的结论冷酷而实用：“饥饿不会杀死有计划的人，但骄傲会。” 小册子最后一页被撕去一半，只剩一句话：不要把明天的粮，当作今天的庆功酒。商队里有个不成文规矩：谁多吃一口，就要把明天的路多背一程。

## 设计意图

把口粮从固定消耗变为可由规划降低的变量，强化长途资源管理。
