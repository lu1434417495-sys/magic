# 《古战场上的急救手册》

## 基础信息

- **关联技能**：`knowledge_field_medicine`

## 书籍内容

这本手册的作者是一名在古战场上服务了二十年的军医，书中没有任何华丽的医术术语，只有如何在泥巴和血泊中让人多活一个小时的方法。前半本讲解止血、固定骨折、处理烧伤和辨认常见中毒症状，每一项都配有一句短小的战场格言，例如「先止血，再讲道理」。中间一章专门讨论如何在战斗中判断伤势优先级：谁还能走、谁还能打、谁已经只是时间问题。

手册后半部分记录了作者在无数次失败中总结出的规律：最能救人的不是药，是冷静；最容易死的人往往不是伤最重的，而是喊最大声的。最末一页用炭笔写着：「如果你只能救一个人，先救那个还能拿得起武器的人。不是因为他更重要，是因为他还想活。」

这本手册曾被一支雇佣兵队伍当作标准配发，直到他们发现按手册救活的人往往欠军医一条命。于是队伍里多了条不成文规定：军医救人后可要求被救者听自己讲一小时战场故事。

## 设计意图

为战斗支援与生存提供实用知识，通过药剂使用速度增益连接知识与战斗节奏。
