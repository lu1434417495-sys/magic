# 《战场地形学》

## 基础信息

- **书籍 ID**：`book_knowledge_0134`
- **关联技能**：`knowledge_tactics`
- **使用效果**：阅读后解锁技能 `knowledge_tactics`；记录 `known_knowledge_id: battlefield_terrain_study`。若已学会，提升 `current_mastery +120`，并在战斗开始时根据地形为全队提供 1 点临时先手优势。
- **阅读要求**：无职业限制；基础 `智力 ≥ 9`。
- **稀有度**：普通（Common）
- **建议投放**：军事学院、佣兵营地、老兵遗物。

## 书籍内容

地形学不是教你如何在平地上列阵，而是教你如何让敌人以为他在平地上列阵。作者用三十场经典战役说明地形如何决定胜负：高地、湿地、树林与废墟各自 favor 不同类型的部队。书中特别讨论"视觉欺骗"——如何利用烟尘、阴影与地势起伏隐藏真实兵力。最实用的一章是快速评估战场：用三十秒判断哪里是陷阱、哪里是退路、哪里适合伏击。最末一页只有一句话，被无数军校学员抄在笔记本上："地形不会偏袒任何人，但它会奖励先读懂它的人。"笔记本最后一页是一份空白表格，标题是"你下一场战斗的地形"。作者写道："填完它之前，不要拔剑。"

空白表格的第一行被人填了三个字："先活着。"字体稚嫩，像出自新兵之手。

封面有一道斜向的切口，恰好把书名分成两半，但没有伤及内文。

地形学的封底内侧贴着一张染血的绷带，绷带的包扎方式来自某个已解散的军团。

## 设计意图

把战术知识转化为战斗初始优势，鼓励玩家在战前观察环境而非只关注敌人。
