# 《符文辨识入门：防御刻印》

## 基础信息

- **书籍 ID**：`book_knowledge_0035`
- **关联技能**：`knowledge_runecraft`
- **使用效果**：阅读后解锁技能 `knowledge_runecraft`；记录 `known_knowledge_id: rune_defensive_glyphs`。若已学会，提升 `current_mastery +140`，并允许在装备上铭刻基础防御符文（一次性解锁制作配方）。

## 书籍内容

入门书从最常见的五种防御符文讲起，教读者辨认符文线条中的"起点"与"终点"——方向错误的解读可能触发反噬。作者用木板与炭笔演示如何在盾牌或门板上布置基础刻印，强调符文的力量来自刻写时的意图稳定，而非墨水珍贵。中间一章列出七种已失效的古符文，并解释它们为何会在现代魔力环境下熄灭。后半本则是一份符文字母表，标注了与安全相关的常用组合。最末一句提醒："符文不是图画，是凝固的言语。"


书的最后一页是一份空白符文纸，边缘有灼烧痕迹。作者写道：“如果你在上面画出的第一个符文没有发光，说明你的心还不够安静。”许多学徒在空白页上反复尝试，直到纸张被自己的指尖磨出毛边，才真正读懂这句话。

符文工坊的学徒只有在完成基础训练后，才被允许触摸这张空白符文纸。

为装备强化与法师系提供符文制作入口，把符文知识转化为可制作的防御配方。
