# 《边境要塞补给清单》

## 书籍内容

清单由一座废弃边境要塞的后勤官遗留，记录了要塞在陷落前三个月的物资流动。书中列出粮食、箭矢、油料、绷带、火把与药品的每日消耗，并用红笔标出了越来越大的缺口。中间一章分析补给线被切断后士兵的心理变化，从配给制到赌博再到沉默。后半本夹着几封未寄出的家书，信纸上还沾着粮袋的霉味。最末一行写道：“要塞不是被攻陷的，是被算错的数字饿死的。”

清单背面是后勤官草草写下的遗嘱，他把积蓄留给了一只他喂养的猫，并请求把这本清单与他一同安葬。

要塞陷落后的许多年里，这本清单仍被后勤学院引用，作为补给计划失败的经典案例。

后勤学院的新生常被要求根据清单数据重新推演一次围困战，并写出失败原因。后勤学院的教官喜欢在案例课后补上一句：数字不会杀人，但相信错误数字的人会。

## 设计意图

通过历史遗物揭示后勤的重要性，并在据点补给时给予一次资源反馈。
