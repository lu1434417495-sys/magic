# 《影界行者的警告》

## 基础信息

- **书籍 ID**：`book_knowledge_0126`
- **关联技能**：`knowledge_shadow`
- **使用效果**：阅读后解锁技能 `knowledge_shadow`；记录 `known_knowledge_id: shadow_plane_traveler_warning`。若已学会，提升 `current_mastery +140`，并在影界相关区域提升潜行检定成功率。
- **阅读要求**：角色职业标签含 `rogue` 或 `warlock`；基础 `敏捷 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：影界裂隙、黑市商人、暗杀者密室。

## 书籍内容

警告来自一名自称"去过又回来"的影界行者，他的真实姓名已被涂抹。书中把影界描述成物质世界的"暗面倒影"：同样的地形，但所有光源都被反转，所有声音都被拉长。作者强调，影界中最危险的不是怪物，而是自己的影子——在影界待太久，影子会开始有自己的想法。第一章讲解如何进入与离开；第二章讲解如何识别"影界本地人"，它们会模仿你的样子但走路方式总是慢半拍。最末一页是一幅自画像，画中人的影子正转过头来看着画家，旁边只有三个字："不要回头。"自画像的背面还有一幅更小的画：画家的影子正在画画。题词："它在学我。它学得很快。"

自画像背面的小画正在慢慢变淡，仿佛影子也在随着时间褪去。

书的扉页写着"禁止外传"四个字，但字迹与作者不同，像是后人添上的警告。

书的某一页背面透出一行反写的字，像是有人从纸张背面用力写下，又擦去了正面。

## 设计意图

为盗贼与术士系提供影界知识，把潜行玩法拓展到跨位面层面，增加神秘与风险感。
