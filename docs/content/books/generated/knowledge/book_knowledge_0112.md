# 《森林精魂契约录》

## 书籍内容

契约录并非法术书，而是一本关于"如何不被欺骗"的指南。作者是一位曾与十七个精魂签订过契约的德鲁伊，他在书中反复强调：精魂从不使用人类语言，它们通过风向、树叶摩擦与动物行为表达意愿。第一章教读者识别不同精魂的"签名"——有的精魂会让整片区域安静下来，有的则会引来大量昆虫。第二章列出历史上最危险的七种契约陷阱，包括"永远不走某条路""每季献上记忆"等。最末一页是一片压干的橡树叶，叶脉上有一行几乎看不清的字："契约一旦成立，违约的从不是精魂。"橡树叶背面有一行更小的字："我把这片叶子给你，不是作为证明，是作为问候。请还一片你的。"

橡树叶已经碎裂成三片，但每片的形状都恰好能拼成一只闭着的眼睛。

书的最后一页比前面薄了一半，显然被很多人反复翻阅过。

## 设计意图

为自然系职业提供超自然交涉知识，把森林从背景变成有意志、可互动的存在。
