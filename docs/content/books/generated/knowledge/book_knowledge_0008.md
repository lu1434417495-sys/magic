# 《药剂师学徒的错题簿》

## 基础信息

- **书籍 ID**：`book_knowledge_0008`
- **关联技能**：`knowledge_alchemy`
- **使用效果**：阅读后解锁技能 `knowledge_alchemy`；记录 `known_knowledge_id: potion_fume_hazards`。若已学会，提升 `current_mastery +100`，并提高下一次炼金成功率 `10%`（一次性制作增益）。
- **阅读要求**：无职业限制；基础 `智力 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：药剂店、炼金任务奖励、学徒宿舍。

## 书籍内容

错题簿封面沾满褐色药渍，内页全是被红笔划掉的配方。作者按错误类型分类：把"先加热"写成"先冷却"会导致药剂固化；把"龙血"误作"蜥蜴血"会让饮用者短暂自燃。中间一章记录了一次险些炸掉半间屋的蒸馏事故，结论是"锅底的沉淀物比锅里的液体更诚实"。后半本则是作者晚年补注，指出多数配方缺的不是珍贵材料，而是对火候的耐心。最末一页写着："药剂学最大的危险，是以为自己已经记住了一个配方。"


错题簿的扉页有一行前任主人留下的警告：“如果你觉得自己不会再犯错，就把这本书送给下一个学徒。”这行字被反复描粗，墨迹已经透到第三页。药剂师行会把这种错题簿当作一种传承，谁最后的批注最多，谁就有资格开新炉。

药剂师行会每年都会重印一批，但原版的药渍无法复制。

## 设计意图

作为炼金知识轨道的入门书，用失败案例降低学习门槛，同时为炼金制作循环提供一次性成功率奖励。
