# 《深渊裂隙目击档案》

## 书籍内容

档案由十二位匿名观察者的报告拼凑而成，统一特征是他们都在目睹深渊裂隙后活了下来。第一篇记录裂隙不是黑色的，而是「颜色被删除后的空洞」，盯着看太久会让人忘记自己名字的发音。第三篇详细描述了一种从裂隙边缘渗出的低语，它不说任何具体语言，却能让听者确信自己正在被呼唤。中间几页是手绘的裂隙形态图，每一张都被不同作者标注为「活的」「在呼吸」「像伤口」。

档案末尾附有一份简易精神自测表，共十个问题，用于判断观察者是否已被深渊轻度污染。最后一题写道：「你是否开始觉得裂隙比城市更安全？」若答案为是，作者建议立即远离所有深渊相关任务，并向最近的圣职人员报告。

档案的装订绳是用某种深色纤维搓成的，触感微凉。据一位收藏家说，接触过这份档案的人在接下来的一周内都会做同样的梦：站在裂隙边缘，听见有人用他们的名字呼喊，却不知道该答应还是该逃跑。

## 设计意图

为深渊相关内容提供 lore 入口，通过污染与意志检定强化世界观的压迫感，奖励偏向探索容错。
