# 《暗影议会的会议记录残页》

- **书籍 ID**：`book_knowledge_0066`
- **关联技能**：`knowledge_shadow_council`
- **使用效果**：阅读后解锁技能 `knowledge_shadow_council`；记录 `known_knowledge_id: shadow_council_minutes`。若已学会，提升 `current_mastery +130`，并解锁一条暗影议会相关的支线任务链。

## 书籍内容

这叠残页来自某个地下组织的会议记录，页边有大量被涂黑的名字。记录显示，暗影议会讨论的不是阴谋，而是如何在不被发现的情况下维持城市运转：疏通下水道、调节粮价、处理那些光明教会不方便处理的麻烦。前半本的议题看似琐碎，却透露出一张庞大的隐形权力网络。中间一章记录了一场关于「是否暗杀某位商人」的辩论，反对者提出的理由不是道德，而是「他的死会让鱼市涨价」。

残页最后几页被火烧毁，只剩一些零散的句子：「……第七席不同意……」「……不能让她知道计划……」「……下次会议地点：老地方。」这些碎片足以让读者意识到，自己所在城市的地下有一张从未见过的棋盘。

暗影议会的会议记录残页在市场上出现过多份不同版本，学者们至今无法确定哪一份是原版。有趣的是，每一份残页的最后都被烧毁，仿佛有人刻意不想让读者看到议会的最终决议。
