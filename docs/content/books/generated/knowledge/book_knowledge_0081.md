# 《预言师的自我怀疑》

## 基础信息

- **书籍 ID**：`book_knowledge_0081`
- **关联技能**：`knowledge_prophecy`
- **使用效果**：阅读后解锁技能 `knowledge_prophecy`；记录 `known_knowledge_id: seer_self_doubt`。若已学会，提升 `current_mastery +130`，并解锁一次命运相关事件的额外选择支。

## 书籍内容

这本书不是预言集，而是一位预言师对自己职业的批判性反思。前半本记录了预言的运作机制：未来的碎片会以图像、声音或情绪的形式闯入预言师的意识，但这些碎片没有顺序，也没有上下文。中间一章列举了二十个自己说中了的预言和十五个没说中的，作者坦诚地分析了每次失败的原因，包括自己的恐惧、雇主的期望和过度解读。

书的后半部分转向伦理问题：如果看见一个人即将死去，是否应该告诉他？如果改变一个预言，是否会让未来变得更糟？最末一页只有一句话：「真正的预言师不是看见未来的人，是看见未来后还能正常生活的人。」这本书在预言师同行中引发巨大争议，因为它暴露了太多行业秘密。

预言师的自我怀疑出版后，许多年轻预言师把它当作职业圣经，但老预言师们警告说，读太多怀疑会让自己看见的东西变少。作者在后记中回应：「看见的少，但看见的更真，这未尝不是进步。」
