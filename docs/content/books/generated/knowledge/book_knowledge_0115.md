# 《深渊裂隙观测》

## 基础信息

- **书籍 ID**：`book_knowledge_0115`
- **关联技能**：`knowledge_abyss`
- **使用效果**：阅读后解锁技能 `knowledge_abyss`；记录 `known_knowledge_id: abyss_rift_observations`。若已学会，提升 `current_mastery +150`，并在深渊环境中降低理智流失速度。

## 书籍内容

观测记录来自十二名深入深渊裂隙的学者，其中十一个人的笔迹在最后几页变成了同一种歪斜字体。书中把深渊描述为一种"反向山脉"：它不是向上隆起，而是向下无限延伸，并且会吸收靠近者的认知。作者提出了"凝视规则"——看深渊时不能超过特定时长，否则视野边缘会出现不存在的阶梯。最恐怖的一章是不同深度听到的"声音分类"，从低语到音乐再到完全的寂静，作者认为寂静才是最危险的状态。最后一页只有一句话，被反复涂改："它不是在下面，它是在我们理解不了的那个方向。"观测本的最后几页全是同一个词重复书写，越往后越潦草。那个词不是"深渊"，是"回头"。

观测本的封皮内侧有一道抓痕，从痕迹判断，留下它的东西有七根手指。

某些段落被人用墨水涂黑，又在涂黑处扎出小孔，透过后面的光才能读到原字。
