# 《亡灵马的驯养笔记》

## 基础信息

- **关联技能**：`knowledge_necro`

## 书籍内容

笔记由一名被通缉的死灵骑士遗留，记录驯养亡灵马的经验。书中指出，亡灵马不吃草料，而是需要定期补充“死亡气息”，通常来自战场、墓园或特定的灰烬植物。中间一章讲解如何通过缰绳上的符文与马匹建立契约，并警告不要用活人的血喂马，那会让马记住活人的味道。后半本记录了常见的马匹异常行为，比如无风时鬃毛飘动、在十字路口踌躇不前。最末的提示写道：“亡灵马不是坐骑，是你向死亡借来的腿。记得按时付租金。”

笔记封底画着一匹马的简笔画，眼眶处被戳了两个洞。旁边批注：如果它开始盯着你看，说明它饿了，而你正在名单上。

死灵骑士的同行们对这本笔记评价不一，有人奉为圣经，有人则认为作者太过溺爱坐骑。有些死灵骑士会在马鞍下塞一片生者的旧手帕，让马匹在战场上仍能闻到曾经主人的气息，以免契约松动。

为亡灵相关知识提供骑乘维度，让知识书籍对特殊坐骑系统产生增益。
