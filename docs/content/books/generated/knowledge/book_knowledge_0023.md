# 《尸鬼弱点汇编》

## 书籍内容

汇编来自守夜人公会多年的实战经验，每一页都对应一种尸鬼变体。作者指出尸鬼的弱点并不总在头部，某些深海尸鬼的心脏位于腹腔，而某些沙漠尸鬼则必须把全身水分蒸干才能停止行动。中间一章讲解如何在战斗中快速判断尸鬼类型：看指甲颜色、闻腐败气味、观察关节弯曲方向。后半本是一份"应急焚烧指南"，列出不同环境下最有效的助燃剂与风向要求。最后一页用粗体字写着："尸鬼曾经是某人。记住这一点不是为了怜悯，是为了判断它生前的职业习惯。"


汇编的最后一页不是文字，而是一幅尸鬼牙齿的放大图。牙齿缝隙里卡着一小片布料，守夜人用这条线索追踪到了一具失踪商人的遗体。那位商人的家属后来认领了书，却在第一页发现一行不属于自己的字迹：“他也快变成其中一员了。”

## 设计意图

在怪物图鉴中提供具体敌对生物的弱点情报，强化知识在战斗准备阶段的价值。
