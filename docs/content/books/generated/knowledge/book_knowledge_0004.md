# 《腐沼生物图鉴·甲虫卷》

## 基础信息

- **书籍 ID**：`book_knowledge_0004`
- **关联技能**：`knowledge_bestiary`
- **使用效果**：阅读后解锁技能 `knowledge_bestiary`；记录 `known_knowledge_id: swamp_beetle_ecology`。若已学会，提升 `current_mastery +100`，并在首次遭遇腐沼甲虫时提供 `弱点暴露` 一次性战斗增益。
- **阅读要求**：无职业限制；基础 `感知 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：猎人营地、药剂师、腐沼据点宝箱。

## 书籍内容

图鉴以铜版插画为主，每一只甲虫下方都写着可食用部位与危险等级。作者提醒腐沼甲虫的外壳会在死后继续释放致幻粉尘，因此采集时必须逆着风向。书中用半章篇幅描述甲虫群落的"假死仪式"：它们会集体沉入泥底，等待猎物踩上看似坚实的地面。后半本则是药剂师备注，指出某种甲虫肠液可与冥想药剂混合，暂时放大魔力感知，但会伴随剧烈头痛。最后一页粘着一片风干的甲壳，背面刻着："别相信任何会反光的水面。"


图鉴最后一章是空白页，只有一行小字：“当你看到不在这本书里的甲虫时，请把它的样子画在这里，然后烧掉。”这是腐沼采集者之间不成文的规矩。据说空白页上已经残留着焦痕，说明曾有不少人认真地执行过这条规定。

采集者协会把它列为入门必读，却要求读完即焚毁最后一页。
