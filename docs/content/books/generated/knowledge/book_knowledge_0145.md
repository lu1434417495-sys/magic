# 《审判庭异端名录》

## 基础信息

- **书籍 ID**：`book_knowledge_0145`
- **关联技能**：`knowledge_inquisition`
- **使用效果**：阅读后解锁技能 `knowledge_inquisition`；记录 `known_knowledge_id: inquisition_heretic_register`。若已学会，提升 `current_mastery +140`，并在对战异端敌人时提升伤害 5%。
- **阅读要求**：角色职业标签含 `holy` 或 `paladin`；基础 `意志 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：审判庭档案室、教会密室、异端审判任务奖励。

## 书籍内容

名录记录了审判庭成立以来定性的异端类型，但越往后翻阅，越难区分"异端"与"不同意见者"。作者是一名退休审判官，他在注释中流露出越来越深的怀疑。书中把异端分为"信仰异端""仪式异端""政治异端"与"接触异端"，并指出最后一类增长最快——仅仅因为与某个可疑人物说过话就会被定罪。最沉重的一章是关于误判：那些被平反的案例，以及审判庭如何以"维护信仰稳定"为由拒绝公开道歉。最末一页只有一句话："我们审判的不是神敌，是我们自己的恐惧。"最后一页是作者退休后加上的："今天我烧毁了自己的审判袍。如果这本书还在被使用，那么我也是异端之一。"

最后一页的加注意味着作者最终也被列入名录，只是这一版尚未出版。

书的最后一页背面有一幅潦草的地图，没有标注方向，只有一个红点。

## 设计意图

为教会势力提供灰色地带叙事，让圣职者在正义与狂热之间拥有选择空间。
