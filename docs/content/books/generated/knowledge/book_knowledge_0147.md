# 《兽人战吼词典》

## 基础信息

- **书籍 ID**：`book_knowledge_0147`
- **关联技能**：`knowledge_orcish`
- **使用效果**：阅读后解锁技能 `knowledge_orcish`；记录 `known_knowledge_id: orcish_battle_cry_lexicon`。若已学会，提升 `current_mastery +120`，并在与兽人敌人交战时小幅降低其先手概率。
- **阅读要求**：无职业限制；基础 `力量 ≥ 9` 或 `智力 ≥ 9`。
- **稀有度**：普通（Common）
- **建议投放**：佣兵营地、边境要塞、兽人战俘交易处。

## 书籍内容

词典作者是一名曾被兽人俘虏三年的佣兵，他在书中坚称兽人语比人类语言更直接。每个战吼都不是简单的怒吼，而是包含着挑战者身份、被挑战者罪行与战斗预期的完整信息。书中收录了四十八个常见战吼及其精确含义，包括几个听起来像侮辱、其实是尊敬的表达。最末一章警告读者不要模仿某些战吼，除非准备好接受挑战。最末一页是一页兽人文字的音标对照表，旁边有作者的血指纹，注释写道："我学会的第一个词是‘站起来’，第二个是‘去死’，第三个是‘回家’。"血指纹旁边多了一行后来者的注释："他说了三个词，但其实他想说的是‘对不起’。兽人不说这个词。"

血指纹旁后来多了一枚清晰的指纹，旁边写着："我也学会了。对不起。"

书的扉页有半枚唇印，颜色暗红，不知是胭脂还是血迹。

词典的某一页被撕下一小条，撕口整齐，像是被某种仪式性的动作取走的。

## 设计意图

为兽人敌人增加文化深度，让语言知识在战斗中产生实际的信息优势。
