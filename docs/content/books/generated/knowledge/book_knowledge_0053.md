# 《矮人熔炉的余热》

## 书籍内容

这本小册子是一名人类铁匠在矮人熔炉做学徒时的听课笔记，封皮被炉灰烫出几个焦斑。前半本记录了矮人锻造的核心信条：「金属记得每一次锤打的方向。」作者强调，矮人不是用更大的力气打造更好的武器，而是用更稳定的节奏让金属内部的应力自然释放。中间一章列举了七种地心矿石的熔点差异，以及为什么「黑曜铁矿石」必须在日落时分淬火。

笔记最后几页画满了奇怪的符号，作者注明这是矮人老师傅用来判断炉温的歌声简谱。人类声带无法完全复现，但接近的音调仍能提高成品率。最末一行字被眼泪晕开：「他们打造的从来不是武器，是承诺。」

笔记边缘留着前任主人用炭笔写下的疑问：「金属真的会记得吗？」没有人能回答这个问题，但每一位成功打造出矮人风格装备的工匠都承认，按照这些节奏敲打时，金属的回应确实不同。

## 设计意图

扩展锻造与装备成长的知识链，为战士/工匠型玩家提供装备图纸解锁路径。
