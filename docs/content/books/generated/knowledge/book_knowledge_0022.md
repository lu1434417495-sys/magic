# 《炼金计量单位考》

## 基础信息

- **书籍 ID**：`book_knowledge_0022`
- **关联技能**：`knowledge_alchemy`
- **使用效果**：阅读后提升 `knowledge_alchemy` 技能 `current_mastery +140`（若未学会则先解锁）；记录 `known_knowledge_id: alchemical_measure_system`。此后炼金产物稳定性 `+5%`（永久被动）。
- **阅读要求**：无职业限制；基础 `智力 ≥ 9`。
- **稀有度**：精良（Uncommon）
- **建议投放**：炼金学院、实验室、古书商。

## 书籍内容

作者是一位被同行嘲笑为"秤匠"的炼金术士，他坚持认为单位混乱是爆炸的主要原因。书中追溯了七种古代度量衡的来源，指出"一滴"在不同城邦可能相差三倍，"一握"则取决于施术者的手大小。中间一章给出换算表，并建议所有实验室统一使用"标准星砂杯"。后半本收录了十二起因单位错误引发的事故，其中最严重的一次让半座钟楼消失。最末一页贴着一张烧焦的标签："在炼金术里，一不是一，除非你能证明它是一。"


书的附录收录了一份“标准星砂杯”的铸造图纸，但图纸最后一行写着“此杯亦不准”。作者在晚年似乎陷入了对绝对精确的怀疑，这也成为他最被争议的观点。他的学生们分成两派，一派继续使用星砂杯，另一派则回归最古老的“手掌丈量法”。

现代炼金协会把它和星砂杯一起放在纪念馆里。

## 设计意图

作为炼金知识的中级读物，强调精度与规范，把计量从细节升华为长期制作收益。
