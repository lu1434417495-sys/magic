# 《魔像伦理评议报告》

## 基础信息

- **书籍 ID**：`book_knowledge_0165`
- **关联技能**：`knowledge_craft`
- **使用效果**：阅读后解锁技能 `knowledge_craft`；记录 `known_knowledge_id: golem_ethics_report`。若已学会，提升 `current_mastery +150`，并解锁“魔像情感抑制器”辅助材料配方，可降低魔像暴走概率。

- **建议投放**：炼金评议会档案、工匠行会、魔像工坊。

## 书籍内容

报告来自炼金评议会的内部档案，讨论赋予魔像有限智能后引发的伦理问题。书中记录了三个案例：一台魔像拒绝继续破坏它认定的“家”，一台魔像在主人死后继续守护空屋三百年，还有一台开始模仿人类的祈祷。中间一章提出“疼痛模拟”是否有必要的争论，以及关闭一台会痛的魔像是否等同于杀戮。后半本列出了一份魔像权利草案，但最后一页被墨水涂黑。最末的批注写道：“我们造出了能问‘为什么’的工具，却还没准备好回答。”

报告的最后一页被黑色墨水完全涂黑，只有右下角露出半个词：苏醒。评议会后来禁止任何人继续破译该页内容。

炼金评议会曾试图回收所有副本，但总有年轻工匠偷偷复印其中的案例作为辩论素材。

工匠行会把它列为高级技师晋升考核的必读书目，尽管争议不断。

## 设计意图

为工匠与炼金系统注入伦理维度，并通过配方奖励把抽象讨论转化为实际产出。
