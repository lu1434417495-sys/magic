# 《战场急救：止血与包扎》

## 基础信息

- **书籍 ID**：`book_knowledge_0159`
- **关联技能**：`knowledge_medicine`
- **使用效果**：阅读后解锁技能 `knowledge_medicine`；记录 `known_knowledge_id: battlefield_first_aid`。若已学会，提升 `current_mastery +100`，并在营地阅读后恢复全队每人少量 `current_hp`。
- **阅读要求**：无职业限制；基础 `智力 ≥ 8` 或 `体质 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：战地医院、佣兵营地、救护支线奖励。

## 书籍内容

这本手册由退伍战地医师编写，专供没有圣职者在场的雇佣兵使用。开篇不讲草药，而是讲如何判断伤口是否被魔法污染：看血的颜色、闻焦糊味、感受周围温度是否骤降。中间章节介绍三种最实用的止血手法，包括“指压点”“绞棒止血带”和“灰烬棉填充法”。后半本则是对常见错误的警告，比如把止血带绑太久导致肢体坏死，或用火直接灼烧伤口。最末一页有一句话：“急救不是治愈，是买时间。真正的治疗发生在有人愿意停下来之后。”

手册封底印着一行粗体字：先止血，再争论。旁边还有战地医师的手写补充：如果伤员还能大声抱怨，说明他暂时死不了。

手册的发行量不大，因为战地医师们普遍认为急救知识最好由老兵亲口传授。

许多退伍伤兵把它缝在绑腿里随身携带，说是比任何护身符都更灵验。

## 设计意图

为非圣职队伍提供基础医疗知识入口，让知识书籍在营地产生续航仪式感。
