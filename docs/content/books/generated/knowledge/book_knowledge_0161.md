# 《星辰碎片坠落记录》

## 书籍内容

记录由观星塔学徒整理，记载了十二次有明确目击的星辰碎片坠落事件。书中不只记录地点与光芒颜色，还追踪坠落点后续出现的异常：植物逆向生长、水源获得微弱魔力、当地居民出现共梦现象。中间一章提出假设，星辰碎片可能是某种世界之外的记忆载体，接触者会在梦中看到不属于自己的人生。后半本列出了安全采集碎片的步骤，强调必须戴铅衬手套并在日出前完成封装。最末一行写道：“碎片从天上落下，知识从地上长出来，两者都不问人类准备好了没有。”

记录册的封皮内衬夹着一小片银色箔纸，据说能阻挡碎片残余的辐射。观星塔学徒们轮流保管它，每人最多持有三天。

观星塔将坠落记录列为学徒必修，但要求学生在读完后必须接受一周的心理观察。观星塔的守夜人会在每次记录后加画一道银线，据说线条变长意味着下一片碎片正在靠近。

为天文知识线提供可采集资源的里程碑，把星象事件转化为材料获取机会。
