# 《断章：高地城邦的纹章学》

## 书籍内容

断章只有十七页，却记录了高地十二城邦的盾纹变迁。作者认为纹章不是身份炫耀，而是血盟契约的图形化摘要：每一道斜线代表一次债务，每一颗星代表一位被承认的守护者。书中用三幅插图演示如何从盾纹推断领主当前能调动的兵力，以及哪些家族已被除名但纹章尚未焚毁。最末一页是一张未完成的纹章，旁边批注："当新纹章覆盖旧纹章时，旧纹章的颜色会在三年内重新浮现。"它教会读者用眼睛读取权力，而不是只听传令官的宣读。


断章背面被人用炭笔补画了一枚第十三城邦的纹章，但纹章中央的野兽没有眼睛。老贵族们相信，这枚纹章代表一个尚未被承认的流亡家族。几位近代学者试图考证这个家族的下落，却发现所有相关档案都在一场“意外”火灾中消失。

学者们至今仍在争论那枚纹章是否真实存在。
