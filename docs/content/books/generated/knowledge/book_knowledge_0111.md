# 《炼金毒物百科》

## 基础信息

- **书籍 ID**：`book_knowledge_0111`
- **关联技能**：`knowledge_alchemy`
- **使用效果**：阅读后解锁技能 `knowledge_alchemy`；记录 `known_knowledge_id: alchemical_poisons`。若已学会，提升 `current_mastery +120`，并解锁三种基础毒药的调制配方。
- **阅读要求**：角色职业标签含 `rogue` 或 `alchemist`；基础 `智力 ≥ 9`。
- **稀有度**：普通（Common）
- **建议投放**：炼金术士商店、毒师小屋、下水道实验室。

## 书籍内容

百科以冷峻的笔记体记录了四十二种常见毒物的来源、症状与解毒方法。作者在开篇声明，本书的目的不是教人杀人，而是教人识别死亡。每种毒物都配有一幅简笔植物或动物素描，以及一个"误判案例"——很多人并非死于中毒，而是死于对自己症状的恐惧。中间一章专门讨论剂量：同一种毒物在不同体重与体质下可能产生完全不同的效果。最末一页是一份手写附录，记载了一种名为"灰舌"的罕见症状，患者会暂时失去味觉并说出反话。旁注只有一句："先确认病人不是在开玩笑。"百科封底贴着一张便条："书中所有解药都需要一种共同的成分——承认自己中毒的勇气。"

便条背面有一行更小的字："解毒的第一步是承认中毒。很多人死在这第一步。"

内页夹着一根细长的羽毛，不知道是书签还是某种警告。

## 设计意图

为炼金与盗贼系提供毒理知识入口，让毒药玩法有据可依，同时强调知识的双刃剑属性。
