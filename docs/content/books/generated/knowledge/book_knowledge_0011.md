# 《战场草药速认手册》

## 基础信息

- **书籍 ID**：`book_knowledge_0011`
- **关联技能**：`knowledge_medicine`
- **使用效果**：阅读后解锁技能 `knowledge_medicine`；记录 `known_knowledge_id: field_herbal_antiseptic`。若已学会，提升 `current_mastery +100`，并在战斗外使用草药时恢复量 `+10%`（一次性增益）。
- **阅读要求**：无职业限制；基础 `感知 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：医疗营地、传教士、游侠营地。

## 书籍内容

手册按季节与地形分类，每种草药配有一幅速描和一段简短口诀。作者强调战地救治首先不是找最好的药，而是先识别"看起来像药其实是毒"的伪装者。中间一章专门讲止血草的用法：捣烂后必须静置十息，否则汁液会刺激伤口反而流血更多。后半本记录了几种常见野菜与草药的混用禁忌，例如蓝铃花与活血根同服会让人陷入幻觉。最后一页被血浸透，勉强能读："如果只能带一种草上路，带那个闻起来像烂泥的。"


手册的塑料封套里夹着一片晒干的止血草标本，标本下方写着采集日期与地点。每一名使用者都会在痊愈后补上一行自己的经历，使这本书越来越厚。军医们相信，书的厚度本身就是战场经验最诚实的证明。

手册的边角被无数双手翻到发毛，证明了它比大多数军医更受信任。

为辅助与生存向角色提供医疗知识入口，让野外采集与治疗决策有据可依。
