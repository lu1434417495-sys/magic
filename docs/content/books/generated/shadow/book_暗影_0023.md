# 《暗影回响：让影子再演一次》

## 基础信息

- **书籍 ID**：`book_shadow_0023`
- **关联技能**：`shadow_echo`（待新增，标签 `shadow`）
- **使用效果**：阅读后解锁复制技能 `shadow_echo`；释放后复制上一次使用的暗影技能，且不消耗该技能冷却。
- **阅读要求**：角色职业标签含 `mage` 或 `rogue`；基础 `智力 ≥ 13` 或 `敏捷 ≥ 13`。
- **稀有度**：史诗（Epic）
- **建议投放**：黑市商人、影法师传承、史诗级宝箱。

## 书籍内容

暗影回响能让施术者短暂复制自己上一次释放的暗影技能。书中解释，影子本身具有记忆，只要用正确的方式呼唤，就能让过去的动作在黑暗中重演。作者强调回响的威力和时机都取决于原版技能，因此最适合搭配高消耗的关键招式。中段有一组练习，要求修习者在一天内重复同一个简单暗影箭，直到能在不施法的情况下让影子自动射出一发。书中还提到，暗影回响对同一场战斗中首次使用的技能记忆最清晰，重复使用同一技能会让回响效果逐渐减弱。回响只能复制最近一个完整释放的技能，任何被打断或取消的法术都不会被记录。书末记载了一项禁忌：若在短时间内多次呼唤回响，影子会开始重复施术者不愿回忆的动作，包括失误与死亡瞬间。书末附有一段训练口诀，要求每日早晚各诵念三遍。

## 设计意图

作为暗影系高阶连招放大器，鼓励玩家构建"关键技能+回响"的爆发组合，同时用精神副作用限制滥用。
