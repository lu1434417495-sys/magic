# 《暗视：穿透黑障》

## 基础信息

- **书籍 ID**：`book_暗影_0137`
- **关联技能**：`shadow_vision_dark`
- **使用效果**：阅读后解锁 `shadow_vision_dark`；可看穿普通黑暗、迷雾与低级幻象。
- **阅读要求**：角色职业标签含 `rogue` 或 `ranger`；基础 `感知 ≥ 12`。
- **稀有度**：稀有（Rare）
- **建议投放**：地下城探险者行会、夜行侦察任务奖励、遗迹斥候传承。

## 书籍内容

暗视是夜瞳的进阶版本，不再满足于"看得更清楚"，而是要学会区分真实与暗影制造的虚假轮廓。作者在书中写道，黑暗会欺骗所有人，因为它把没有光的地方和有很多影子的地方画得一样黑。暗视的训练从辨认物体的"阴影边缘"开始：真实物体在极低光下仍然有柔和的轮廓过渡，而幻象或迷雾则会呈现不自然的锐利切边。书中还教授如何利用暗视发现隐藏敌人：观察地面影子的微小抖动，注意墙壁上不应该存在的暗斑，聆听黑暗本身似乎被"占据"的沉默。后半部分是一份常见幻象生物的特征表，帮助读者避免在关键时刻被虚假影子误导。作者建议配合影听一起修炼，以获得更全面的夜间感知。暗视还能帮助发现隐藏在迷雾中的陷阱触发线。阴影并非虚无，而是光的缺席；修习者要学会在缺席中行动，让自身成为那道被忽略的暗角。

## 设计意图

探索向信息优势技能，服务于地下城与异界探索，把感知属性转化为战术情报。
