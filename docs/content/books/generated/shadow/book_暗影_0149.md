# 《噬影：吞噬光芒》

## 基础信息

- **书籍 ID**：`book_暗影_0149`
- **关联技能**：`shadow_consuming_dark`
- **使用效果**：阅读后解锁 `shadow_consuming_dark`；熄灭范围内光源，并根据熄灭光源数量回复 MP 或 AURA。
- **阅读要求**：角色职业标签含 `mage` 或 `warlock`；基础 `智力 ≥ 15`。
- **稀有度**：史诗（Epic）
- **建议投放**：深渊核心、古代暗影王座、终极资源管理任务奖励。

## 书籍内容

噬影是暗影系高阶资源管理技艺，它把熄灭光源从战术行为转化为自我补给。作者在书中解释，每一盏被熄灭的光都会释放出 residual——残留的光能，而掌握了噬影的人可以像喝水一样把这些残留能量吸入体内，转化为 MP 或 AURA。书中详细描述了施术过程：先以自身影子为嘴，向周围光源张开，然后依次咬灭它们，同时用意念把溢出的能量导入自己的资源池。初学者常犯的错误是同时熄灭太多光源，导致能量涌入过快而造成反噬。后半部分讨论了与暗影闪耀的区别：暗影闪耀是减法控制，噬影则是带有资源回收的减法，更适合持久战。附录里有一页被烧焦，只留下四个字：莫贪光明。作者补充，越是强大的光源，回收时越需要谨慎。古代暗影王座下的长明灯一旦被噬影者熄灭，便再也不能被普通火焰点燃，那些黑暗区域至今仍是探险者的禁地。

## 设计意图

资源管理与环境互动的高阶技能，把光照控制与 MP/AURA 恢复结合，服务持久战构筑。
