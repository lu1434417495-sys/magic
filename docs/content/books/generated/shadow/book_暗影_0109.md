# 《暮影行：黄昏边界移动》

## 基础信息

- **书籍 ID**：`book_暗影_0109`
- **关联技能**：`shadow_walk_twilight`
- **使用效果**：阅读后解锁 `shadow_walk_twilight`；在黄昏或黎明场景中移动速度提升 20%。
- **阅读要求**：角色职业标签含 `rogue`；基础 `敏捷 ≥ 12`。
- **稀有度**：稀有（Rare）
- **建议投放**：边境哨站藏书、黄昏林地世界事件、游侠隐士。

## 书籍内容

暮影行把一天中最短暂的时刻当作一种可以借用的力量。作者认为，黄昏与黎明是世界最"宽容"的边界，光与影在此互相谦让，让人有机会同时属于两个阵营。书中要求练习者在每天日落前后各练习一刻钟，感受脚下地面温度变化带来的脚步声差异，并学会利用斜长影子隐藏自己的真实移动方向。后半部分列举了不同气候下的黄昏特征：干燥地区的暮影短暂而锋利，湿润地区的暮影绵长而模糊，灰烬交界的暮影则会伴随细微的灰烬沉降。作者在最后警告：不要在暮影中停留太久，否则你会忘记自己究竟属于白昼还是黑夜，再也无法在正午阳光下稳定行走，甚至开始厌恶一切明亮的东西。许多修习者会在黎明前独自前往边界地带，寻找最适合自己的过渡节奏。阴影并非虚无，而是光的缺席；修习者要学会在缺席中行动，让自身成为那道被忽略的暗角。

## 设计意图

引入环境时间对暗影技能的影响，鼓励玩家关注游戏内时段与天气系统。
