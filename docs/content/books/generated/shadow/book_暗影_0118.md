# 《影护：阴影庇护》

## 基础信息

- **书籍 ID**：`book_暗影_0118`
- **关联技能**：`shadow_ward_shade`
- **使用效果**：阅读后解锁 `shadow_ward_shade`；站立于阴影中时受到的所有伤害降低 10%。
- **阅读要求**：无职业限制；基础 `意志 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：隐居暗影牧师、废墟祭坛、低阶防御向任务奖励。

## 书籍内容

影护是一本少见的防御向暗影书籍，作者自称曾在灰烬交界边缘的某个废弃神殿中居住多年。书中提出，阴影不是逃避现实的角落，而是世界自身的褶皱，只要学会谦卑地待在其中，褶皱就会替你分担伤害。练习方法并不复杂：找一处稳定的阴影，闭眼感受身体边缘与黑暗交接处的温度差异，然后想象自己正在缓慢沉入那层温差之中。书中警告，影护无法抵挡阳光直射或圣光类攻击，因为那些力量会直接把阴影连同庇护一起撕碎。后半部分收录了如何在移动中维持庇护的技巧，关键在于不要离开前一个阴影太远，否则新的阴影还来不及"认识"你。作者建议配合夜瞳使用，以便在黑暗中精准找到下一片阴影。配合缓慢深呼吸，庇护效果可以延长数秒，但无法无限维持。阴影并非虚无，而是光的缺席；修习者要学会在缺席中行动，让自身成为那道被忽略的暗角。

## 设计意图

提供防御向暗影选择，让非敏捷职业也能从阴影机制中获得生存收益。
