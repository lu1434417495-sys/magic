# 《暗影洪流：退潮与涨潮》

## 基础信息

- **书籍 ID**：`book_shadow_0020`
- **关联技能**：`shadow_torrent`（待新增，标签 `shadow`）
- **使用效果**：阅读后解锁击退技能 `shadow_torrent`；被击退的敌人若撞至障碍物，额外眩晕一回合。
- **阅读要求**：角色职业标签含 `mage` 或 `warlock`；基础 `智力 ≥ 12`。
- **稀有度**：稀有（Rare）
- **建议投放**：黑市商人、阴影法师塔、战场控制任务奖励。

## 书籍内容

暗影洪流以施术者为中心向四周爆发一股黑暗浪潮，将靠近的敌人推开并短暂致盲。书中强调这股浪潮不分敌我，因此需要精准的站位与释放时机。作者建议在浪潮成型前深吸一口气，因为释放时身体会短暂失去对周围空气的感知，容易误判距离。中段用图示说明洪流的衰减规律：距离施术者越近推力越大，但致盲时间越短；远处推力减弱，黑暗却停留更久。修习者常被要求在水池中练习，观察黑暗与水波的交界。书中还提到，暗影洪流可以扑灭火焰陷阱与小型火源，因此在布满火元素的战场中，它既是武器也是救场手段。洪流释放后的数秒内，施术者周围的阴影会异常浓重，这正是追击敌人的最佳时机。书末写着：洪流不是终点，是把所有人推入你预设战场的开始。作者最后提醒，暗影技艺的精进不在一日之间。

## 设计意图

为暗影法师提供以自身为中心的范围控制技能，结合地形碰撞机制，鼓励玩家利用障碍物制造额外控制效果。
