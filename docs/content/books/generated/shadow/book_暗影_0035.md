# 《暗影迷雾：寒冷的沉默》

## 基础信息

- **书籍 ID**：`book_shadow_0035`
- **关联技能**：`shadow_haze`（待新增，标签 `shadow`）
- **使用效果**：阅读后解锁范围减速技能 `shadow_haze`；迷雾中的敌人移动速度降低，命中率下降。
- **阅读要求**：角色职业标签含 `mage` 或 `rogue`；基础 `智力 ≥ 11`。
- **稀有度**：稀有（Rare）
- **建议投放**：黑市商人、战场控制任务、阴影遗迹宝箱。

## 书籍内容

暗影迷雾释放出一团寒冷的黑色雾气，降低区域内敌人的视野与移动速度。书中说明迷雾不会影响施术者自身的视线，但会让所有进入其中的光源变得昏黄微弱。作者建议在撤退或保护施法者时使用，因为迷雾能有效打断敌方的集火节奏。中段有一章比较迷雾与领域的区别：迷雾更轻、更易被风吹散，但对进入者的方向感干扰更强。修习者需要训练在迷雾中保持队形，否则自己人也会走散。书中还提到，暗影迷雾可以掩盖脚步声与呼吸声，因此常被暗杀者用来接近戒备森严的目标。迷雾中的声音会被吸收，因此暗杀者可以借此接近目标而不被发现脚步声。书末附有一名指挥官的笔记：在迷雾里，最怕的不是敌人，是你自己的脚步听起来像两个人。作者认为，理解影子的本质比单纯模仿招式更重要。

## 设计意图

为暗影系提供轻量级的范围控场，通过减速与命中 debuff 干扰敌方节奏，适合掩护、撤退与阵地战。
