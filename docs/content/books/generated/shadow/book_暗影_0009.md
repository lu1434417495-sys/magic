# 《暗影触须：深渊的腕足》

## 基础信息

- **书籍 ID**：`book_shadow_0009`
- **关联技能**：`shadow_tendril`（待新增，标签 `shadow`）
- **使用效果**：阅读后解锁召唤技能 `shadow_tendril`；触须击中敌人时有几率将其向施术者方向拖动一格。
- **阅读要求**：角色职业标签含 `mage` 或 `rogue`；基础 `智力 ≥ 11` 或 `意志 ≥ 11`。
- **稀有度**：稀有（Rare）
- **建议投放**：黑市商人、深渊遗迹、阴影召唤师任务奖励。

## 书籍内容

暗影触须从施术者的影子中延伸而出，像某种深海生物的腕足般探入战场。书中强调触须的力量来自施术者对恐惧的克制，越害怕失去控制，触须越容易反卷自身。作者详细描述了触须的感官特性：它们没有眼睛，却能通过黑暗浓度的变化感知周围移动的物体，因此在完全无光的环境中反而最为敏锐。中段有一组训练方法，要求修习者在黑暗中用触须分拣不同材质的球体，以培养精细操控。书中还警告，触须会在施术者睡眠时继续活动，因此初学者必须在床头放置一盏长明灯，防止影子在梦中做出不受控的举动。书中还提到，触须在施术者睡着后仍可能继续探索，因此床边必须点亮守护烛。书末附有一名前辈的笔记：当你觉得触须在替你思考时，立刻切断它们，因为黑暗从不免费出借力量。

## 设计意图

为暗影系提供兼具控制与感知的召唤物机制，强调精神状态对暗影召唤物稳定性的影响，拓展战棋中的位移与牵引玩法。
