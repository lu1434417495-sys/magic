# 《灰烬斗篷：余烬隐匿》

## 书籍内容

灰烬斗篷是专为灰烬交界环境设计的隐匿技艺。作者指出，异界灰烬与主物质界的灰尘不同，它们会主动吸附光线，让覆盖其中的物体轮廓变得模糊。掌握余烬隐匿的人不需要刻意躲藏，只需要让自己静止片刻，让灰烬在斗篷与皮肤上落满一层，就能与周围环境融为一体。书中详细描述了三种静止姿势：跪姿适合低矮地形，伏姿适合碎石坡，倚姿适合靠在残垣断壁上。后半部分讨论了灰烬斗篷的维护：灰烬层太薄会暴露轮廓，太厚则会影响行动，最佳厚度是刚好让最熟悉你的人也需要多看一眼。作者还警告，强风或雨水会迅速破坏灰烬层，需要重新静止积累，急躁的人永远无法掌握此术。有经验的灰烬游侠能在短短三次呼吸内让身体被灰烬完全覆盖。阴影并非虚无，而是光的缺席；修习者要学会在缺席中行动，让自身成为那道被忽略的暗角。

## 设计意图

与灰烬交界异界设定强绑定，把环境特产转化为隐身资源，强化异界探索的代入感。
