# 《影网：铺设在明暗交界》

## 基础信息

- **书籍 ID**：`book_shadow_0034`
- **关联技能**：`shadow_net`（待新增，标签 `shadow`）
- **使用效果**：阅读后解锁陷阱技能 `shadow_net`；敌人触发后受到束缚，且触发点周围暗影技能伤害提升。
- **阅读要求**：角色职业标签含 `rogue` 或 `ranger`；基础 `敏捷 ≥ 11`。
- **稀有度**：普通（Common）
- **建议投放**：黑市商人、低级宝箱、盗贼公会训练奖励。

## 书籍内容

影网将黑暗编织成一张隐形的网，铺设在地面上等待触发。书中指出影网最适合布置在光线交界地带，因为猎物往往会在明暗转换时放松警惕。作者详细介绍了网的几种触发方式：触碰式、压力式与魔力感应式，分别对付不同警觉程度的敌人。中段有一章讨论网的自我修复，影网在黑暗中会慢慢愈合破损处，但在强光下会迅速消融。修习者需要学会预判猎物的逃跑路线，把网布置在看似安全的阴影深处。书中还提到，影网可以与环境中的藤蔓、铁丝等实体结合，形成更难挣脱的复合陷阱。影网在布置后需要数秒才能完全隐形，这段时间内任何剧烈动作都会暴露其位置。书末用血画着一张简图，标注了七种常见地形中的最佳布网点，图注只有三个字：等他们。书中还记载，真正的暗影大师从不依赖单一技能取胜。

## 设计意图

为暗影系提供预判型陷阱，强调环境光线与布点选择，增强战棋中的区域控制与伏击杀敌玩法。
