# 《幻影短刃握法》

## 基础信息

- **书籍 ID**：`book_暗影_0103`
- **关联技能**：`shadow_blade_phantom`
- **使用效果**：阅读后解锁 `shadow_blade_phantom`；若已学会，短刃类武器基础伤害提升 5%。
- **阅读要求**：角色职业标签含 `rogue`；基础 `敏捷 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：刺客据点武器架、黑市武器商人、初级暗杀任务奖励。

## 书籍内容

幻影短刃握法并非教人如何握紧刀柄，而是教人如何在敌人眼中"看不住"你的刀。作者从手指位置讲起：食指与中指应当像钳子一样固定，无名指与小指则像弹簧一样缓冲，这样刀刃才能在极短距离内二次加速。书中花了整整一章讨论刀刃反光，建议在刀身涂抹烟灰或使用哑光处理，因为一道不该出现的光会出卖你所有的脚步。后半部分记录了几种常见握法的切换：正握适合突刺，反握适合割喉，而介于两者之间的"幻影握"则能在对手判断距离时制造误差。附录里有一幅被血污浸透的手掌图，旁边写着：握刀的手要松到像握着一团影子，太紧会让整只手发抖，太松则刀会先于意识出鞘。作者还附了一份每日挥空刀三百次的练习表。旧刺客公会规定，握法不合格者不得领取淬毒刃，以免手抖误伤自己。

## 设计意图

绑定匕首与短刃类武器，把暗杀爆发建立在可感知的握持与距离欺骗之上，而非单纯提高数值。
