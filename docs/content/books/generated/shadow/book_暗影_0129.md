# 《半影诱捕：光影圈套》

## 基础信息

- **书籍 ID**：`book_暗影_0129`
- **关联技能**：`shadow_snare_penumbra`
- **使用效果**：阅读后解锁 `shadow_snare_penumbra`；在明暗交界处布置陷阱，触发时束缚敌人。
- **阅读要求**：角色职业标签含 `rogue` 或 `mage`；基础 `敏捷 ≥ 11` 或 `智力 ≥ 11`。
- **稀有度**：稀有（Rare）
- **建议投放**：光影神殿侧殿、幻术师工坊、高阶控制任务奖励。

## 书籍内容

半影诱捕是对《影缚术：初级缠绕》的战术升级，把主动施法转化为预先布置。作者认为，最好的控制是让敌人以为那是自然现象。书中教授如何在明暗交界的地面上编织一层几乎看不见的影线，当目标踩入半影区域时，其影子会被临时固定在地面上，导致双腿无法移动。布置时需要精确计算光源角度与移动路径，太靠近光明处会让影线过早蒸发，太靠近黑暗处则难以触发。后半部分提供了几种经典布局：门廊内侧、转角后方、火把照射范围的边缘。附录里有一段警告：不要在自己撤退路线上布置半影诱捕，因为慌不择路时你可能会忘记它们的位置，反而绊倒自己，把后背留给敌人。熟练后可以在同一区域布置多层影线，让敌人越挣扎越被困紧。阴影并非虚无，而是光的缺席；修习者要学会在缺席中行动，让自身成为那道被忽略的暗角。

## 设计意图

利用环境光制造控制区域，把陷阱与光照系统深度绑定，提升战场预设的复杂度。
