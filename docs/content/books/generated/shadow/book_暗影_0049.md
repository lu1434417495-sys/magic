# 《暗影漩涡：把敌人拉出舒适区》

## 基础信息

- **书籍 ID**：`book_shadow_0049`
- **关联技能**：`shadow_vortex`（待新增，标签 `shadow`）
- **使用效果**：阅读后解锁场地控制技能 `shadow_vortex`；漩涡持续牵引敌人，被拉入中心的敌人下回合无法行动。
- **阅读要求**：角色职业标签含 `mage` 或 `warlock`；基础 `智力 ≥ 13`。
- **稀有度**：史诗（Epic）
- **建议投放**：黑市商人、战术家任务、史诗级宝箱。

## 书籍内容

暗影漩涡在指定位置制造一个缓慢旋转的黑暗漩涡，持续吸入附近的物体与敌人。书中说明漩涡的吸力会随时间增强，中心区域伤害最高但范围最小。作者建议在团战开场或敌人撤退路径上布置，以打乱其阵型。中段有一章讨论如何利用漩涡限制远程单位，把他们从安全位置拉到近战范围。修习者需要维持与漩涡的精神连接，一旦连接中断，漩涡会提前崩溃。书中还提到，暗影漩涡可以与暗影烈焰或暗影尖刺联动，将敌人吸入后立即触发陷阱或火焰，形成高伤害连招。漩涡在消失时会将吸入的物体抛出，聪明的施术者会利用这一点进行二次伤害布局。书末附有一名战术家的批注：漩涡的价值不在于杀伤，而在于让敌人无法待在他们想待的地方。书末还列有一份禁忌清单，提醒修习者哪些情况下绝不可使用此技。

## 设计意图

为暗影系提供强力的位置控制技能，通过牵引与中心定身改变战场空间结构，强化对远程单位与阵型的压制。
