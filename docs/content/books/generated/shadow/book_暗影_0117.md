# 《灰烬回身：余影撤离》

## 基础信息

- **书籍 ID**：`book_暗影_0117`
- **关联技能**：`shadow_recall_ashen`
- **使用效果**：阅读后解锁 `shadow_recall_ashen`；使用后可退回 3 秒前所在位置。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `敏捷 ≥ 12`。
- **稀有度**：稀有（Rare）
- **建议投放**：灰烬交界遗迹、高阶潜行任务奖励、异界游商。

## 书籍内容

灰烬回身与灰烬交界的世界观紧密相连。作者声称，异界灰烬不仅会覆盖地面，也会短暂地"记住"每一个经过者的足迹，而掌握了余影撤离的人可以在危急时刻顺着这些记忆退回原点。书中要求练习者在进入任何空间时先用鞋底轻蹭地面三次，留下可被召回的"锚点"。施术时，身体会被一层细灰包裹，视野倒退，三秒内的动作以反转顺序快速回放。初学者常犯的错误是试图在召回过程中改变方向，结果导致身体部分错位，造成严重内伤。最后几页用红笔标注：此术只能用于撤离，不能用于进攻，因为进攻者的杀意会污染灰烬的记忆，让召回指向错误的时间点，有时会把人送回更危险的位置。经验丰富的使用者会在进入陌生空间时每隔一段时间就留下新的锚点。阴影并非虚无，而是光的缺席；修习者要学会在缺席中行动，让自身成为那道被忽略的暗角。

## 设计意图

与灰烬交界异界设定联动，提供高机动性撤离手段，同时用代价限制滥用。
