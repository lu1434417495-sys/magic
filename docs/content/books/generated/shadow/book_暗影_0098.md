# 《影中审讯》

## 基础信息

- **书籍 ID**：`book_shadow_0098`
- **关联技能**：`shadow_interrogation`（待新增，标签 `shadow`）
- **使用效果**：阅读后学会技能 `shadow_interrogation`；若已学会，则提升 `current_mastery +130`，并提高从俘虏身上获取情报的成功率 `10%`。
- **阅读要求**：无职业限制；基础 `智力 ≥ 10` 或 `魅力 ≥ 10`。
- **稀有度**：普通（Common）
- **建议投放**：侦探事务所、间谍学校、地下执法者据点。

## 书籍内容

黑暗本身就是压力。《影中审讯》教授如何利用光影变化、孤立感与未知威胁，从俘虏或嫌疑人那里获取信息，而不必造成永久性伤害。书中把审讯分为三个阶段：剥夺光让人产生不安，制造影子移动让人产生被监视的错觉，最后用一道突然出现的光亮打破心理防线。作者强调，影中审讯的核心不是恐惧，而是让被审讯者的大脑自己填补空白；一旦使用真实暴力，审讯就会降级为普通的逼供。后半本记录了多个失败案例，提醒审讯者不要被自己的影子吓到。最后一页写着：最有价值的情报，往往来自你以为他已经说完之后的那一轮沉默。书末还附有一张审讯记录表，所有栏位都空着，只盖着一个褪色的印章。印章图案是一只闭着的眼睛，看久了会让人产生一种被注视的错觉。阴影并非虚无，而是光的缺席；修习者要学会在缺席中行动，让自身成为那道被忽略的暗角。

## 设计意图

为阴影主题补充非暴力情报获取手段，让玩家在交涉与任务推进中获得更多选择，减少对战斗的单一依赖。
