# 《暗影步入门：边缘行走》

## 基础信息

- **书籍 ID**：`book_shadow_0001`
- **关联技能**：`shadow_step`（待新增，标签 `shadow`）
- **使用效果**：阅读后解锁暗影移动技能 `shadow_step`（`practice_tier = basic`），首次释放时获得 1 次无消耗的短距离阴影位移。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `敏捷 ≥ 10`。
- **稀有度**：普通（Common）
- **建议投放**：盗贼公会入门奖励、黑市商人低级货物、阴影洞穴宝箱。

## 书籍内容

暗影步并非单纯的快速移动，而是一种将自身轮廓融入边缘光线的技艺。书中开篇便警告，初学者最常犯的错误是盯着目标奔跑；真正的暗影步要求你注视地面与自己的影子，让对手的目光自然滑过。作者详细记录了碎石地、草地与石板路三种地形的步法，强调要在敌人眨眼或转头的瞬间跨步。中段有一章专门讨论余影——快速移动后留在原地的视觉残留，高阶修习者能在敌人攻击余影时完成反击。书中还提到呼吸与心跳的配合，要求在跨步前屏息半拍，让身体的节奏与环境阴影的晃动同步。作者特别警告，不要在强光下练习，因为失去影子的参照会让修习者迷失方向。修习者常被要求在黄昏与黎明之间反复练习，因为这段时光的阴影最长也最容易操控。最后几页被烧去大半，只剩一行字：当你看不见自己的影子时，说明你已变成了影子。

## 设计意图

作为暗影系移动技能的入门书，承担解锁基础阴影位移的职责。内容与项目战斗系统中"机动即防御"的定位一致，同时为后续高阶暗影步法留出升级空间。
