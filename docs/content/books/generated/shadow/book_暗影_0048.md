# 《暗影冲击：包裹黑暗的突进》

## 基础信息

- **书籍 ID**：`book_shadow_0048`
- **关联技能**：`shadow_blast`（待新增，标签 `shadow`）
- **使用效果**：阅读后解锁突进技能 `shadow_blast`；对路径上敌人造成伤害，突进终点造成小范围黑暗爆发。
- **阅读要求**：角色职业标签含 `rogue`、`warrior` 或 `assassin`；基础 `敏捷 ≥ 12`。
- **稀有度**：稀有（Rare）
- **建议投放**：黑市商人、战士训练任务、阴影遗迹宝箱。

## 书籍内容

暗影冲击将施术者包裹在黑暗能量中向前突进，对路径上的敌人造成撞击伤害。书中指出冲击的末端会有一小片黑暗爆发，是最危险的输出时机，也是最脆弱的收招瞬间。作者建议在确认能命中多名敌人或关键目标时使用，单独追击高机动敌人容易落空。中段有一章分析冲击与其他技能的衔接，例如冲击结束后立即接影缚或暗影斩。修习者需要训练在突进过程中调整方向，虽然角度有限，但足以避开正面迎来的重击。书中还提到，暗影冲击在突进期间可以穿越较薄的墙壁与栅栏，因为施术者会短暂处于半暗影状态。冲击在突进过程中可以被远程攻击打断，因此施术者需要队友掩护或选择合适时机。书末用红笔写着：冲进去是勇气，停下来是技术。作者建议，每次练习后都要在光明中静坐片刻，以确认自己仍是血肉之躯。

## 设计意图

为近战暗影职业提供突进+小爆发组合，强化进场能力与技能衔接，体现"高风险高回报"的暗影突击风格。
