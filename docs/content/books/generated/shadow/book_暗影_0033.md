# 《暗影涟漪：探测黑暗的回波》

## 基础信息

- **书籍 ID**：`book_shadow_0033`
- **关联技能**：`shadow_ripple`（待新增，标签 `shadow`）
- **使用效果**：阅读后解锁侦测技能 `shadow_ripple`；释放后显示周围隐形单位、陷阱与阴影格分布，持续数秒。
- **阅读要求**：角色职业标签含 `rogue`、`ranger` 或 `mage`；基础 `智力 ≥ 10` 或 `敏捷 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：黑市商人、斥候任务奖励、阴影遗迹宝箱。

## 书籍内容

暗影涟漪以自身影子为中心向四周扩散微弱的波动，用于探测隐形单位或陷阱。书中解释涟漪本身没有伤害，但它会让所有与阴影接触的事物显露出轮廓。作者建议在进入陌生区域前先释放涟漪，并仔细观察地面影子的颤动方式，因为不同物体引发的涟漪形态各不相同。中段有一组练习图，要求修习者闭眼分辨活物与死物的涟漪差异。修习者常被要求在布满陷阱的古迹中训练，失败意味着受伤。书中还提到，暗影涟漪会被大面积强光源削弱，因此在正午或圣光法阵中使用效果极差。涟漪在接触水系魔法时会产生异常波动，有经验的修习者能借此发现隐藏的水元素陷阱。书末附有一名斥候的批注：涟漪能发现别人，也能暴露自己，释放后三秒内不要移动。书末附有一段训练口诀，要求每日早晚各诵念三遍。

## 设计意图

为暗影系提供环境侦察与反隐手段，丰富探索与战斗中的情报维度，同时通过"释放后自身短暂静止"平衡其泛用性。
