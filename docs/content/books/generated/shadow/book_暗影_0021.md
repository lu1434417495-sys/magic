# 《暗影锁链：把敌人串成一条线》

## 基础信息

- **书籍 ID**：`book_shadow_0021`
- **关联技能**：`shadow_chain`（待新增，标签 `shadow`）
- **使用效果**：阅读后解锁范围控制技能 `shadow_chain`；被连接的敌人中任意一人移动受限时，其他人同步受到部分效果。
- **阅读要求**：角色职业标签含 `mage` 或 `warlock`；基础 `智力 ≥ 13`。
- **稀有度**：史诗（Epic）
- **建议投放**：黑市商人、阴影法师塔高层、史诗级宝箱。

## 书籍内容

暗影锁链将多名敌人的影子串联在一起，使他们共享移动限制与部分伤害。书中解释，锁链的坚韧程度取决于被连接者之间的心理距离，彼此仇恨的目标反而更容易被锁住。作者详细记录了连接顺序：先连接影子最长的敌人作为锚点，再依次延伸；若中途有目标走出黑暗，锁链会从该节点崩断。中段有一章讨论战术价值，强调锁链最适合限制高机动敌人，把分散的战场强行压缩成一条线。书中还提到，暗影锁链可以传导某些暗影 debuff，例如当其中一人被诅咒时，连接者会分担少量伤害。锁链连接的目标越多，施术者需要维持的精神负担越重，因此三人以上连接极为危险。书末附有一名老兵的批注：当你把敌人锁在一起时，别忘了他们也能互相掩护。书中还强调，修习者必须学会在光明与黑暗之间找到平衡。

## 设计意图

为暗影系提供多人联动控制，通过"连接共享"机制改变战场空间结构，强化团队协作下的集火与分割战术。
