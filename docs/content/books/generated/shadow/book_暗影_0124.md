# 《幽影攫取：暗影之手》

## 基础信息

- **书籍 ID**：`book_暗影_0124`
- **关联技能**：`shadow_grasp_specter`
- **使用效果**：阅读后解锁 `shadow_grasp_specter`；可将 2 格外的小型物体拉至身边。
- **阅读要求**：角色职业标签含 `mage` 或 `rogue`；基础 `智力 ≥ 10` 或 `敏捷 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：幽灵船残骸、闹鬼宅邸书房、异界遗物收藏家。

## 书籍内容

幽影攫取把影子变成了一只可以伸长的手。作者在书中描述了施术时的微妙感觉：不是用手指去够，而是让脚下影子延伸出去，像舌头尝到东西一样把它卷回来。书中强调，能被攫取的物体必须满足两个条件——重量不超过施术者能单手举起，并且表面不能太光滑，否则影子会"打滑"。后半部分充满了实用小技巧：用暗影之手拉动门闩、取回掉落的钥匙、把远处药瓶勾到身边，甚至在战斗中把敌人的头盔拉歪。最后几页是一组警告，红笔圈出了几种危险物品：火把、圣水瓶、以及任何刻有光明符文的东西，因为攫取它们会让延伸出去的影子瞬间燃烧，并把灼烧感传回施术者，造成难以愈合的灼伤。施术者可以通过练习让暗影之手伸出更远，但越远控制越不稳定。阴影并非虚无，而是光的缺席；修习者要学会在缺席中行动，让自身成为那道被忽略的暗角。

## 设计意图

扩展环境互动与解谜维度，让暗影技能在战斗之外拥有丰富的应用场景。
