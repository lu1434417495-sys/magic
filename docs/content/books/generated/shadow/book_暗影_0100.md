# 《影逝录：附录零》

## 基础信息

- **书籍 ID**：`book_shadow_0100`
- **关联技能**：`shadow_obituary`（待新增，标签 `shadow`）
- **使用效果**：阅读后学会技能 `shadow_obituary`；若已学会，则提升 `current_mastery +150`，并延长预知濒死反击的判定窗口 `1` 回合。
- **阅读要求**：角色职业标签含 `shadowmancer`、`rogue` 或 `assassin`；基础 `智力 ≥ 11` 或 `感知 ≥ 11`。
- **稀有度**：史诗（Epic）
- **建议投放**：古墓密室、亡灵法师藏书、暗影档案馆。

## 书籍内容

这本书没有作者署名，每一页都记载着一位阴影中死去的人的名字、死因与最后一句话。《影逝录：附录零》不是战斗手册，而是对暗影道路终点的提醒。阅读它的人会获得一种特殊的能力：在敌人濒死时，通过阅读对方影子里的残留记忆，预知其最后的反击或遗言。书中把这种现象称为影葬——不是在埋葬敌人，而是在埋葬敌人与你的那段关系。作者告诫：不要为名单上的人流泪，因为他们中的大多数也曾在某个夜晚翻开过这本书。最后一页是空白的，只有一行极淡的字：当你在这里写下自己的名字时，请确保那是一笔漂亮的字。空白页的左下角有一个几乎看不见的指印，似乎是上一个读者留下的警告。指印的纹路很浅，却异常清晰，仿佛刚刚印上去不久。阴影并非虚无，而是光的缺席；修习者要学会在缺席中行动，让自身成为那道被忽略的暗角。

## 设计意图

为暗影系列收尾提供富有叙事重量的能力，把死亡与记忆融入战斗预测，让玩家在终结敌人时感受到阴影道路的代价。
