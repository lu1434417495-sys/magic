# 《暗影守护：暗膜之术》

## 书籍内容

暗影守护并非正面屏障，而是一层会主动吞噬攻击余波的暗膜。书中解释，这层暗膜不能挡住长矛直刺，却能削弱附魔箭矢、火焰溅射与诅咒余波等能量伤害。修习者需在冥想状态下将意识沉入自己的影子，让暗膜与影子的轮廓同步扩张与收缩。作者记录了一个反直觉的技巧：受到攻击时略微侧身的守护效果最好，因为正面迎击会让暗膜变薄，而斜向则能让攻击沿暗膜表面滑开。书中还提醒，暗膜在受到光明攻击时会被快速消耗，因此在面对圣骑士或光明法师时，应优先寻找阴影躲避。书中最后附有一份训练日程，要求修习者每日在三种不同光线下各承受十次攻击。书末提醒，长时间维持暗影守护会消耗精神，最危险的不是敌人打破它，而是修习者忘记自己还开着它。书中最后写道：影子是你的镜子，也是你最忠实的敌人。

## 设计意图

为前排战士与盗贼提供针对能量伤害的另类防御，结合冥想与 AURA 系统，鼓励玩家根据敌人类型切换防御手段。
