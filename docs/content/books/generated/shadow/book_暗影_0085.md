# 《幽影墨水与伪造》

## 书籍内容

普通的墨水在黑暗中会反光，而幽影墨水则吸收光线，只在特定角度下才能被看见。《幽影墨水与伪造》教授如何调配这种墨水，并用它来伪造文书、修改地图或在自己的皮肤上写下临时暗号。书中把配方分为底墨、稳定剂与显影液三部分，其中底墨必须用夜间采集的露水与炭粉混合，稳定剂则需要少量施术者自己的影子——也就是在无光环境中静坐一夜后凝结在皮肤上的凉意。后半本讲解伪造技巧：最好的伪造不是完美复制，而是在真品上做出一个微小的、只有接收者才看得懂的改动。最后一页画着一只握笔的手，笔尖滴下的不是墨，而是一滴黑色的光。黑色的光在纸上凝固成一个小点，细看会发现它在极其缓慢地移动。移动的方向始终朝向书本的封底，仿佛那里有什么东西在吸引它。

## 设计意图

把阴影能量转化为非战斗 crafting 与情报玩法，让玩家在任务准备阶段通过伪造与暗号获得多样化解决方案。
