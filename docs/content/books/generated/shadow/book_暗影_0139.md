# 《深渊束缚：暗影牢笼》

## 基础信息

- **书籍 ID**：`book_暗影_0139`
- **关联技能**：`shadow_restraint_abyss`
- **使用效果**：阅读后解锁 `shadow_restraint_abyss`；范围内敌人无法使用位移技能，持续 3 秒。
- **阅读要求**：角色职业标签含 `mage` 或 `warlock`；基础 `智力 ≥ 15`。
- **稀有度**：史诗（Epic）
- **建议投放**：深渊神殿核心、禁咒图书馆禁室、高阶控制任务终极奖励。

## 书籍内容

深渊束缚是《深渊锁链：暗影禁锢》的战略级扩展，从单体控制升级为范围反机动场域。作者在书中将其比作"把一片阴影浇筑成牢笼"，所有踏入其中的敌人都会感到双脚被无数只无形的手掌按住，无法冲刺、跳跃或传送。书中详细描述了施法代价：施术者需要持续引导，期间自身也无法移动，并且每多维持一秒，精神负担就会成倍增加。后半部分讨论了释放位置的选择：狭窄通道可以最大化覆盖效果，开阔地带则需要预判敌人移动路线。附录里有一段用古文字写成的警告，翻译成通用语只有六个字：笼门一开难收。作者提醒，不要在队友尚未撤离时释放深渊束缚，否则会把他们也困在阴影中。深渊束缚解除时，被困者的影子会剧烈抖动数秒才恢复正常。阴影并非虚无，而是光的缺席；修习者要学会在缺席中行动，让自身成为那道被忽略的暗角。

## 设计意图

战略级反机动控制，服务法师型暗影构筑的团队控场与阵地战需求。
