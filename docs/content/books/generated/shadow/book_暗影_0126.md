# 《黄昏标记：猎杀烙印》

## 书籍内容

黄昏标记是一种古老的猎杀契约技艺。作者认为，每一次成功的追杀都始于一次清晰的"看见"，而标记就是把那种看见固定下来的仪式。施术时，施术者需要先凝视目标超过一次完整呼吸的时间，然后在心中默念目标身上最显眼的阴影位置——眉骨下方、腋下、脚跟——那处阴影就会变成一个只有施术者能感知的烙印。书中强调，标记不是魔法飞弹，它不会造成伤害，也不会被目标察觉，但它会让后续所有暗影攻击精准地朝烙印处汇聚。后半部分讨论了标记的伦理：不要给未曾伤害过你的人打下烙印，因为烙印会在你自己心中留下对称的痕迹，时间久了会改变你看待世界的方式，让一切事物都像猎物。被标记的目标即使躲入人群，施术者也能凭借烙印感知其大致方向。阴影并非虚无，而是光的缺席；修习者要学会在缺席中行动，让自身成为那道被忽略的暗角。

## 设计意图

建立暗影猎杀循环，用前置标记放大后续输出，强化目标选择与集火策略。
