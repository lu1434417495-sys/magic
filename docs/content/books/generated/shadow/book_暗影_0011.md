# 《暗影长枪：无光之锋》

## 基础信息

- **书籍 ID**：`book_shadow_0011`
- **关联技能**：`shadow_lance`（待新增，标签 `shadow`）
- **使用效果**：阅读后解锁中距离突刺技能 `shadow_lance`；贯穿多名敌人时，每多一名伤害提升 `10%`。
- **阅读要求**：角色职业标签含 `rogue`、`warrior` 或 `mage`；基础 `敏捷 ≥ 11` 或 `智力 ≥ 11`。
- **稀有度**：稀有（Rare）
- **建议投放**：黑市商人、阴影战士训练所、稀有宝箱。

## 书籍内容

暗影长枪以手臂为柄、以凝聚的黑暗为锋，能在中距离发起贯穿突击。书中提到长枪的长度取决于施术者的意志集中程度，初学者往往只能形成短矛，而熟练者可在转瞬之间将其延伸至数米之外。作者强调突刺时机比准度更重要，因为暗影长枪在成型瞬间会扰动周围光线，过早暴露会被对手闪避。中段用图示说明三种握法：正握用于正面穿透，反握用于近身格挡，斜握则能借助枪身的弹性进行横扫。书中还提到，暗影长枪在击中目标后会从伤口处释放出细小影刺，对周围敌人造成二次伤害，但这对施术者的控制精度要求极高。暗影长枪在穿刺重甲时会产生剧烈震动，施术者必须握紧枪柄否则会被反噬。书末附有一段用暗语写成的口诀，译出后大意是：枪尖所指，皆为无光之地。书中还强调，修习者必须学会在光明与黑暗之间找到平衡。

## 设计意图

为暗影系提供直线贯穿型中距离攻击，鼓励玩家利用敌人排布制造连穿收益，强化战棋中的站位博弈。
