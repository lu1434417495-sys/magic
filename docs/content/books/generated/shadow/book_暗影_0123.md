# 《影听：回声定位》

## 基础信息

- **书籍 ID**：`book_暗影_0123`
- **关联技能**：`shadow_listen_echo`
- **使用效果**：阅读后解锁 `shadow_listen_echo`；在闭眼或失明状态下感知范围提升 2 格。

- **建议投放**：盲眼修道院、地下回音廊、感知训练任务奖励。

## 书籍内容

影听教人在无光环境中用声音代替眼睛。作者认为，阴影不仅是视觉现象，也是声学现象——黑暗会吸收一部分高频声波，同时放大低频回声，这正是盲眼修行者能在地下回廊中行走的原因。书中首先训练读者闭眼辨位：让同伴在不同方向轻声击掌，练习者需要在不转头的情况下判断距离与高度。进阶部分则要求读者学会"发出"自己的探测音，比如轻敲武器、跺脚或低声哼鸣，然后根据回声判断周围障碍与敌人的大致轮廓。后半本讨论了常见干扰：流水声会覆盖脚步，风声会让方向失真，而灰烬交界某些区域则会"吃掉"回声，让最熟练的影听者也感到不安，甚至产生被注视的错觉，仿佛黑暗中有什么在倾听你。长期修炼影听的人，即使在完全失明后也能在熟悉地形中自由行动。阴影并非虚无，而是光的缺席；修习者要学会在缺席中行动，让自身成为那道被忽略的暗角。

## 设计意图

为异常状态提供正向反馈，把失明从纯粹减益转化为信息获取方式的切换。
