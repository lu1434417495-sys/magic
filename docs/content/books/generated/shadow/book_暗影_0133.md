# 《亡影突袭：灵体穿刺》

## 基础信息

- **书籍 ID**：`book_暗影_0133`
- **关联技能**：`shadow_strike_wraith`
- **使用效果**：阅读后解锁 `shadow_strike_wraith`；对灵体、虚体敌人伤害提升 25%。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `敏捷 ≥ 13`。
- **稀有度**：史诗（Epic）
- **建议投放**：亡灵国度深处、幽影裂隙核心、高阶猎灵任务奖励。

## 书籍内容

亡影突袭解决了一个刺客们长期回避的问题：当敌人没有实体时，刀刃该刺向哪里。作者认为，灵体虽然无形，却仍然拥有"存在的轮廓"，而暗影正是轮廓最浓的部分。此术要求攻击者先观察灵体在地面或墙壁上投下的微弱阴影，然后把刀刃对准阴影最密集的那一点刺入。书中警告，亡影突袭对施术者精神要求极高，因为长时间凝视灵体影子会让普通人产生幻觉与恶寒。后半部分列举了几种常见灵体的阴影特征：幽灵的影子细长而摇摆，怨灵的影子浓重且带有尖刺，而灰烬交界某些异界残影则根本没有固定形状。作者还提醒，使用此术前最好服用少量安定心神的药剂，否则可能会在战斗中看见不该看的东西。长期凝视灵体影子的人，有时会梦见自己也被某种巨大阴影注视。阴影并非虚无，而是光的缺席；修习者要学会在缺席中行动，让自身成为那道被忽略的暗角。

## 设计意图

针对特定敌人类型的对策技能，让暗影构筑在特定副本与事件中拥有不可替代的价值。
