# 《暗影箭雨：压制的黑芒》

## 基础信息

- **书籍 ID**：`book_shadow_0018`
- **关联技能**：`shadow_rain`（待新增，标签 `shadow`）
- **使用效果**：阅读后解锁范围技能 `shadow_rain`；箭雨覆盖区域内的敌人下回合命中率下降。
- **阅读要求**：角色职业标签含 `mage` 或 `archer`；基础 `智力 ≥ 12` 或 `敏捷 ≥ 12`。
- **稀有度**：稀有（Rare）
- **建议投放**：黑市商人、战场法师任务、阴影遗迹宝箱。

## 书籍内容

暗影箭雨将大量细小黑芒射向天空，随后如雨点般覆盖一片区域。书中提醒，这一招对单体伤害有限，真正的价值在于制造压制与视野遮蔽。作者建议在释放前先计算风向与落点阴影，因为黑芒会自然飘向更暗的区域。修习者需要训练同时操控数十枚暗影箭的飞行姿态，过多的精神分散会让箭雨变得稀疏，过少则覆盖范围不足。中段记载了一次战役：三名暗影法师用箭雨覆盖峡谷入口，使敌军在数分钟内既无法前进也无法准确还击。书中还提到，若在箭雨中混入几枚实体暗器，可以制造真假难辨的攻击，让敌人无法判断哪一次需要举盾。修习者需要在释放箭雨后迅速转移位置，因为黑芒落下的轨迹会暴露施术者大致方位。书末用红笔标注：箭雨之后，务必亲自走入黑暗中确认战果。

## 设计意图

为暗影法师与暗影弓箭手提供范围压制技能，通过命中率 debuff 与阴影偏向机制，强化控场与团队协作价值。
