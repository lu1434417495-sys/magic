# 《暗影镜像：来自影子的复制品》

## 基础信息

- **书籍 ID**：`book_shadow_0031`
- **关联技能**：`shadow_mirror`（待新增，标签 `shadow`）
- **使用效果**：阅读后解锁召唤/干扰技能 `shadow_mirror`；复制一名敌人造成精神干扰，使其下回合攻击目标随机。
- **阅读要求**：角色职业标签含 `mage` 或 `warlock`；基础 `智力 ≥ 13`。
- **稀有度**：史诗（Epic）
- **建议投放**：黑市商人、影法师传承、史诗级宝箱。

## 书籍内容

暗影镜像从目标的影子中复制出一个由黑暗构成的复制品，短期内模仿目标的行动。书中解释复制品没有实体，只能造成精神干扰与视觉欺骗，但足以让敌人分神或误判距离。作者建议在面对多人时优先复制团队领袖或最强战士，因为心理压力会成倍放大。中段有一章讨论镜像的崩溃征兆：当复制品开始主动微笑或说出目标没说过的话时，必须立即解除，否则镜像可能获得独立意识。书中还提到，暗影镜像在目标死亡后仍可能短暂存活，并试图寻找新的宿主，因此施术者必须随时准备将其销毁。镜像在被解除时会发出碎裂声，这声音有时会被敌人误认为是实体破碎的线索。书末附有一名死囚的供词：我杀了我的镜像，但它死前说我才是复制品。书中还强调，修习者必须学会在光明与黑暗之间找到平衡。

## 设计意图

为暗影系提供精神干扰与敌我混乱手段，通过"镜像失控"风险强化技能的主题张力与使用门槛。
