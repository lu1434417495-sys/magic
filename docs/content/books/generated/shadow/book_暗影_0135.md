# 《虚空箭：暗影投射》

## 基础信息

- **书籍 ID**：`book_暗影_0135`
- **关联技能**：`shadow_bolt_void`
- **使用效果**：阅读后解锁 `shadow_bolt_void`；发射一支可穿透目标的暗影箭。
- **阅读要求**：角色职业标签含 `mage` 或 `archer`；基础 `智力 ≥ 12` 或 `敏捷 ≥ 12`。
- **稀有度**：稀有（Rare）
- **建议投放**：暗影射手营地、魔法靶场、远程战术任务奖励。

## 书籍内容

虚空箭把弓箭手的射术与暗影魔法结合，创造出一种没有实体却能贯穿敌人的投射物。作者在书中解释道，虚空箭的本质不是箭，而是一道被拉长的影子，因此它不受风力影响，却会被强光削弱。施术者需要先以手指或弓弦为引导，将自身影子的一小部分剥离出去，再赋予它方向与速度。初学者常犯的错误是拉出太粗的影子，导致飞行速度过慢；真正的虚空箭应当细如发丝，快如眨眼。后半部分比较了法师手势释放与弓箭手弓弦释放的差异：前者更容易控制方向，后者则能在移动中快速连发。书中提醒，连续发射虚空箭会让施术者的影子变薄，影响潜行效果，战斗间隙必须躲入阴影恢复。虚空箭在穿过第一个目标后会略微变暗，威力随之衰减。阴影并非虚无，而是光的缺席；修习者要学会在缺席中行动，让自身成为那道被忽略的暗角。

## 设计意图

让远程职业获得暗影输出手段，把穿透特性与光照系统结合，拓展远程构筑可能性。
