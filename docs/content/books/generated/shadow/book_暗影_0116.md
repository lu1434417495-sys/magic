# 《暗影闪耀：反制照明》

## 基础信息

- **书籍 ID**：`book_暗影_0116`
- **关联技能**：`shadow_flare_dark`
- **使用效果**：阅读后解锁 `shadow_flare_dark`；释放后可熄灭半径 3 格内光源 2 秒。
- **阅读要求**：角色职业标签含 `mage` 或 `rogue`；基础 `智力 ≥ 10` 或 `敏捷 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：影法师工坊、战术物资箱、黑市魔法道具商。

## 书籍内容

暗影闪耀是一种罕见的"减法"魔法：它不制造黑暗，而是暂时剥夺光源的发光能力。作者把光比作水，把暗影闪耀比作在灯火上盖上一层不可见的薄膜。书中详细讲解了三种常见光源的熄灭技巧：火把需要攻击火焰根部，魔法灯需要扰乱其能量回路，而生物荧光则需要切断其与生命体的联系。初学者最难掌握的是时机——熄得太早，敌人会重新点燃；熄得太晚，你已经暴露。后半本列举了几种战术组合：先熄灯再背刺、先熄灯再影缚、在多人混战中只熄灭特定方向的光源以制造混乱。作者还提醒，暗影闪耀对某些神圣光源无效，强行施放会造成反噬，甚至让自己的影子燃烧起来。此术对持续发光魔法阵的效果较弱，需要配合其他控制手段使用。阴影并非虚无，而是光的缺席；修习者要学会在缺席中行动，让自身成为那道被忽略的暗角。

## 设计意图

创造环境优势的战略技能，让玩家主动改写战场光照条件以服务团队或自身。
