# 《影镖投掷指南》

## 基础信息

- **书籍 ID**：`book_shadow_0006`
- **关联技能**：`shadow_dart`（待新增，标签 `shadow`）
- **使用效果**：阅读后解锁远程技能 `shadow_dart`；命中敌人影子时，额外附加一层暗影印记。

## 书籍内容

影镖是将黑暗压缩成飞镖形状的远程技艺，飞行时几乎无声，只在命中瞬间才会释放一小片墨色。书中强调准度比力度重要，因为影镖本身重量极轻，稍有偏斜就会被气流带偏。作者建议使用目标的影子作为瞄准参照，而非目标身体——影子不会晃动，也不会因恐惧而颤抖。中段有一整页列举了不同距离下影镖的衰减规律，超过十五步后影镖会重新散成烟雾。书中还提到一种进阶用法，将数枚影镖同时掷出，让它们在目标影子周围形成微型陷阱，逼迫对方不敢随意移动。最老练的影镖手能在投掷时让飞镖与烛火同步闪烁，使敌人无法分辨光源与暗器。最后几页是一组练习图，要求修习者在熄灯后的房间里，把飞镖掷向自己影子的眉心、咽喉与心口，直到能在闭眼时仍命中为止。修习者需要反复观摩自己的影子，直到能预判它的下一步动作。

## 设计意图

为盗贼与暗影弓箭手提供低消耗的远程起手技能，强化"瞄准影子而非实体"的暗影主题玩法，并为后续印记联动埋下机制接口。
