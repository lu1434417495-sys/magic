# 《暗影印记：追猎者的标记》

## 基础信息

- **书籍 ID**：`book_shadow_0019`
- **关联技能**：`shadow_sigil`（待新增，标签 `shadow`）
- **使用效果**：阅读后解锁追踪技能 `shadow_sigil`；被标记者每回合受到少量暗影伤害，且无法进入隐匿状态。
- **阅读要求**：角色职业标签含 `rogue`、`assassin` 或 `ranger`；基础 `敏捷 ≥ 10`、智力 `≥ 9`。
- **稀有度**：稀有（Rare）
- **建议投放**：黑市商人、追猎任务奖励、阴影斥候训练所。

## 书籍内容

暗影印记是施加在目标身上的追踪标记，施术者可通过标记感知目标的位置与大致状态。书中说明，印记必须印在目标的影子或直接皮肤上，印在衣物上会在清洗后消失。作者将印记分为明暗两种：明印记会散发出微弱的暗影波动，容易被察觉却能干扰对方的感知；暗印记几乎无法被发现，但传递的信息也较为模糊。中段有一章讲授如何在被标记者进入强光区域时维持连接，关键是在印记中预留一丝施术者自己的影子作为纽带。书中还提到，当目标试图用光明魔法清除印记时，施术者可以反向感知到清除者的位置与大致魔力水平。印记在传送或远距离移动时可能出现延迟，但这反而能帮助施术者判断目标的行进方向。书末附有一名猎手的笔记：最好的猎物，是以为自己已经逃脱的猎物。

## 设计意图

为暗影系提供追踪与反隐匿手段，构建"标记—收割"的技能联动链，同时丰富任务与探索中的情报获取方式。
