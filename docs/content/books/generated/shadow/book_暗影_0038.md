# 《暗影脉冲：规律的心跳》

## 基础信息

- **书籍 ID**：`book_shadow_0038`
- **关联技能**：`shadow_pulse`（待新增，标签 `shadow`）
- **使用效果**：阅读后解锁持续范围技能 `shadow_pulse`；每回合对周围敌人造成小额暗影伤害并打断吟唱。
- **阅读要求**：角色职业标签含 `mage` 或 `warlock`；基础 `智力 ≥ 12`。
- **稀有度**：稀有（Rare）
- **建议投放**：黑市商人、阵地战任务、阴影遗迹宝箱。

## 书籍内容

暗影脉冲以规律节奏向周围释放暗影波动，对靠近的敌人造成持续伤害并打断施法。书中指出脉冲的优势在于持续性，适合防守据点或保护固定目标。作者建议调整脉冲频率，过快会迅速消耗魔力，过慢则会给敌人留下可乘之机。中段有一章分析脉冲与环境的互动：在狭窄空间中回声会增强效果，在开阔地带则会被稀释。修习者需要训练在释放脉冲的同时进行移动和闪避。书中还提到，暗影脉冲可以暴露隐形的敌人，因为任何进入波动范围的物体都会引起暗影的轻微扭曲。脉冲的频率与施术者心跳相关，情绪激动时脉冲会自动加快，却也更容易耗尽魔力。书末写着：脉冲就像心跳，稳定时最可怕，慌乱时最致命。作者建议，每次练习后都要在光明中静坐片刻，以确认自己仍是血肉之躯。

## 设计意图

为暗影系提供持续性的近身压制技能，通过节奏控制与资源消耗平衡其输出效率，适合防守与阵地战场景。
