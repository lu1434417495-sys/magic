# 《影舞：连续残像》

## 基础信息

- **书籍 ID**：`book_暗影_0136`
- **关联技能**：`shadow_dance_umbra`
- **使用效果**：阅读后解锁 `shadow_dance_umbra`；成功闪避后下一次攻击连击数加 1。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `敏捷 ≥ 15`。
- **稀有度**：史诗（Epic）
- **建议投放**：影舞者秘传卷轴、竞技场冠军奖励、宗师级刺客试炼。

## 书籍内容

影舞是影舞者一脉的终极机动技艺，要求修习者把闪避不再视为被动反应，而是进攻的前奏。作者在书中描述，真正的影舞者在战斗中会留下多个短暂残像，每个残像都对应一次可能的攻击路线，而敌人无法判断哪一个是真实。书中把影舞拆成三步：引敌出招、借势滑入盲区、从盲区发动连击。每一步都需要极高的身体协调与空间判断。后半部分是一份高阶训练方案，要求练习者面对三名以上的对手，在不主动攻击的情况下连续闪避二十次，直到能本能地找到每次闪避后的最佳反击位置。附录里用血写着：舞不是表演，是生存，每一次闪避都是下一次攻击的借据，借太多会还不起。影舞达到最高境界时，残像会短暂地具有实体般的压迫感。阴影并非虚无，而是光的缺席；修习者要学会在缺席中行动，让自身成为那道被忽略的暗角。

## 设计意图

高阶连击与机动结合，把闪避收益转化为进攻资源，服务极限操作型玩家。
