# 《幽跃：阴影纵身》

## 基础信息

- **书籍 ID**：`book_暗影_0128`
- **关联技能**：`shadow_leap_gloom`
- **使用效果**：阅读后解锁 `shadow_leap_gloom`；从阴影中跃出时首次攻击伤害提升 15%。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `敏捷 ≥ 12`。
- **稀有度**：稀有（Rare）
- **建议投放**：城市屋顶密道、影贼训练场、高阶刺客试炼奖励。

## 书籍内容

幽跃解决了一个古老问题：如何从藏身处发起攻击而不让敌人提前察觉你的出现。作者指出，大多数伏击失败是因为攻击者在离开阴影的瞬间制造了"新阴影"，而敏锐的敌人会注意到那片突然变暗的区域。幽跃的技巧在于让身体在跃出时尽量贴近已有的阴影边缘，利用影子本身的形状作为掩护，直到最后一刻才完全现身。书中提供了起跳点的选择原则：高处优于低处，侧面优于正后，有遮挡物优于空旷地。后半部分是一组城市环境的实战案例，包括从屋檐跃下、从货堆后跃出、以及利用两名敌人之间的影子完成双目标切换。作者还强调，幽跃前要与队友约定信号，否则正面吸引火力的人可能会因误判而暴露，导致整个伏击失败。最精湛的幽跃大师能在跃出瞬间让敌人的影子承受第一眼注视，这一技巧被称为影替，只有极少数刺客掌握。

## 设计意图

强化立体机动与伏击爆发，把跳劈/跃击与环境阴影绑定，提升暗杀的空间维度。
