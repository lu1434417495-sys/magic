# 《无声落步：影行者足记》

## 基础信息

- **书籍 ID**：`book_暗影_0102`
- **关联技能**：`shadow_step_silent`
- **使用效果**：阅读后解锁 `shadow_step_silent`；若已学会，提升该技能 `current_mastery +80`。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `敏捷 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：盗贼公会训练场书架、下水道密道宝箱、潜行教官。

## 书籍内容

这本书的封面上印着一只猫踏过瓦片的剪影，暗示全书主题：落地不是结束，而是下一次发力的开始。作者把脚步声拆成三个部分——鞋底接触、重心转移、离开地面——并针对每一步给出肌肉控制要点。书中特别反对"踮脚走路"的刻板印象，认为那会让小腿过快疲劳，真正的无声来自髋部的稳定与脚掌的滚动。中段收录了七种常见地面的测试方法，包括木地板、碎石、积水石板和灰烬交界特有的脆化地面。每种地面都配有一套预踩节奏与错误示范，比如在碎石上要学会"碾"而不是"踩"。最后几页是一份为期十四天的训练计划，要求读者在白天练习、夜晚实战，并用砂纸磨掉鞋底花纹以放大错误，直到能在烛光下走过碎玻璃而不发出声响。传说最早的影行者能在暴雨中踏过铁皮屋顶而不惊动守夜人，后世学徒多以此作为成年礼。

## 设计意图

将"无声移动"从简单数值加成还原为操作与地形判断，为后续高级影步和突袭技能奠定节奏感。
