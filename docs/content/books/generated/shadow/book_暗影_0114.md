# 《剪影佯攻：分身骗术》

## 基础信息

- **书籍 ID**：`book_暗影_0114`
- **关联技能**：`shadow_feint_silhouette`
- **使用效果**：阅读后解锁 `shadow_feint_silhouette`；若已学会，成功佯攻后下一次攻击必中。
- **阅读要求**：角色职业标签含 `rogue`；基础 `敏捷 ≥ 12`。
- **稀有度**：稀有（Rare）
- **建议投放**：戏法师营地、竞技场暗盘商人、幻影盗贼传承。

## 书籍内容

剪影佯攻不是真正的分身术，而是让敌人的眼睛替你"画"出一个不存在的你。作者在书中分析人类视觉的预测机制：大脑会根据物体的运动轨迹提前补出下一帧画面，而一名熟练的影行者可以故意给出错误轨迹，让敌人的防御动作朝向一个虚幻的剪影。书中详细拆解了肩、肘、膝三处的微小动作如何被误判为进攻方向，并提供了三种基础佯攻套路：上挑转侧闪、前冲转后撤、低姿突进转高跃。每种套路都配有对手视角的简笔画。最后章节警告：最高级的佯攻不是在动作上作假，而是在眼神上作假——看向左，斩向右。初学者要花数周练习控制视线，因为眼睛往往比身体更诚实，这也是最难克服的本能。训练到最后，练习者要能在对手紧盯自己双眼时完成反向斩击。阴影并非虚无，而是光的缺席；修习者要学会在缺席中行动，让自身成为那道被忽略的暗角。

## 设计意图

强化战术欺骗与连击启动，把闪避与命中机制从数值对抗升级为预判博弈。
