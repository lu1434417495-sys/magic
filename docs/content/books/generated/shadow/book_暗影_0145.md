# 《黄昏徽记：黄昏契约》

## 基础信息

- **书籍 ID**：`book_暗影_0145`
- **关联技能**：`shadow_sigil_dusk`
- **使用效果**：阅读后解锁 `shadow_sigil_dusk`；在地面绘制徽记，踏入者受到持续暗影诅咒。
- **阅读要求**：角色职业标签含 `mage` 或 `warlock`；基础 `智力 ≥ 14`。
- **稀有度**：史诗（Epic）
- **建议投放**：黄昏神殿密室、古代契约室、高阶阵地任务奖励。

## 书籍内容

黄昏徽记是一种持久场地诅咒技艺，施术者用自己的血或影子在地面绘制一个复杂的符号，任何踏入符号范围的生物都会持续受到暗影侵蚀。作者在书中强调，黄昏徽记的力量来自"边界"——白昼与黑夜、生与死、主动与被动——因此最适合在黄昏时分布置，效果会持续到下一次日出。书中详细记录了徽记的基本结构：外圈代表界限，内圈代表侵蚀源，中心的三道斜线象征被束缚的阳光。初学者常犯的错误是把徽记画得太小，导致敌人容易一步跨过；正确的做法是画足够大，并把多个徽记连成阵势。后半部分讨论了契约代价：每维持一个徽记，施术者的一部分影子会被消耗，过度使用会让自己的影子变淡，甚至消失，再也无法使用其他暗影技能。阴影并非虚无，而是光的缺席；修习者要学会在缺席中行动，让自身成为那道被忽略的暗角。

## 设计意图

持久场地诅咒，服务阵地战与区域控制，通过代价机制限制无限布阵。
