# 《影下苗圃》

## 基础信息

- **书籍 ID**：`book_shadow_0084`
- **关联技能**：`shadow_garden`（待新增，标签 `shadow`）
- **使用效果**：阅读后学会技能 `shadow_garden`；若已学会，则提升 `current_mastery +130`，并减少植物培育时间 `20%`。

## 书籍内容

有些植物只在阴影中生长，并且以生物的恐惧为养分。《影下苗圃》是一本关于培育暗影植物的手册，教授如何在无光土壤中种下夜茄、影藤与噬光菌。这些植物不能用于正面战斗，却能在战场边缘布置成缓慢生效的障碍：夜茄释放的粉末会让人嗜睡，影藤会缠住踏入者的脚踝，噬光菌则会吞噬附近光源让区域变暗。书中强调培育者必须每天与自己的植物对话，因为暗影植物能感知培育者的情绪；焦虑会让它们长得更快，但也会更难控制。最后一页贴着一片干枯的叶子，叶脉上写着：你种下的不是植物，是你愿意留在黑暗里的那部分自己。叶子的形状与书中描述的夜茄叶片并不相同，仿佛来自某种未命名的暗影植物。叶背还有一排细小的齿痕，像是被某种夜行昆虫啃食过。阴影并非虚无，而是光的缺席；修习者要学会在缺席中行动，让自身成为那道被忽略的暗角。

## 设计意图

为阴影主题引入环境与资源养成玩法，让玩家通过预布置植物改变战场光照与通行条件，增强战前策略层次。
