# 《影之王座：终极统御》

## 基础信息

- **书籍 ID**：`book_暗影_0150`
- **关联技能**：`shadow_throne_umbra`
- **使用效果**：阅读后解锁 `shadow_throne_umbra`；处于阴影中时所有暗影技能效果提升 20%。
- **阅读要求**：角色职业标签含 `rogue`、`mage` 或 `warlock`；基础 `智力 ≥ 16` 或 `敏捷 ≥ 16`。
- **稀有度**：传说（Legendary）
- **建议投放**：最终暗影副本通关奖励、传说级世界事件、暗影宗师传承。

## 书籍内容

影之王座是暗影系列的最高典籍，据传由一位曾在灰烬交界深处称王的暗影法师所著。书中没有教学步骤，只有一段又一段关于"统治阴影"的箴言。作者认为，所有暗影技能的本质都是借债——向影子借力量、向黑暗借掩护、向黄昏借时间——而登上影之王座的人不再是借债者，而是债主。阅读此书的人会感到自己的影子变得格外浓重，仿佛有了独立的意志。书中最后几页是一幅巨大的王座图，王座由无数扭曲的影子交织而成，坐在上面的人没有脸，只有一片纯粹的黑暗。图下方写着：当你能命令自己的影子跪下时，整个世界的阴影都会向你低头。然而，王座之下最深的阴影里，似乎还藏着一双不属于你的眼睛，正静静地注视着你。传说中，那位暗影法师最终并未死去，而是整座王座化作了他的影子，在灰烬交界的黄昏继续寻找下一位候选人。

## 设计意图

系列终极技能，统领所有暗影构筑，提供全局加成作为对深度投入暗影体系的终极回报。
