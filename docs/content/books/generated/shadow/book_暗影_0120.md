# 《影锚：定身于暗》

## 基础信息

- **书籍 ID**：`book_暗影_0120`
- **关联技能**：`shadow_anchor_umbra`
- **使用效果**：阅读后解锁 `shadow_anchor_umbra`；免疫下一次强制位移效果。
- **阅读要求**：角色职业标签含 `warrior` 或 `rogue`；基础 `体质 ≥ 11`。
- **稀有度**：稀有（Rare）
- **建议投放**：地下角斗场冠军奖励、影卫训练营、抗推抗拉任务。

## 书籍内容

影锚是一种反制位移的暗影技巧，其核心是把自己的身体与脚下大片阴影临时钉在一起。作者在书中用船锚作比喻：船锚不是对抗海浪，而是让自己沉入海底，让海浪无可奈何。练习时，施术者需要在被冲击前的瞬间把意识下沉到脚底，想象双腿正在变长、变重，像两根黑色的钉子穿过地面。书中特别强调了呼吸节奏，因为大多数人在受到推力时会本能地屏息，反而让肌肉僵硬、更容易被推动。后半部分列举了影锚的局限：它不能抵抗垂直方向的抛投，也无法在完全没有阴影的强光区域生效。作者还提醒，影锚生效时会暂时冻结自己的移动能力，因此要在站稳或靠墙时使用，否则锚住后反而无法追击。建议练习者先从正面推力开始适应，再尝试侧面撞击。阴影并非虚无，而是光的缺席；修习者要学会在缺席中行动，让自身成为那道被忽略的暗角。

## 设计意图

对抗推拉机制的针对性技能，为前排与盗贼提供站位稳定性，丰富控制与反控制博弈。
