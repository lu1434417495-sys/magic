# 《暗影紧握：无数小手》

## 基础信息

- **书籍 ID**：`book_shadow_0044`
- **关联技能**：`shadow_grip`（待新增，标签 `shadow`）
- **使用效果**：阅读后解锁范围控制技能 `shadow_grip`；范围内敌人本回合移动速度降低，并有概率被定身。
- **阅读要求**：角色职业标签含 `mage` 或 `warlock`；基础 `智力 ≥ 11`。
- **稀有度**：稀有（Rare）
- **建议投放**：黑市商人、控制者任务奖励、阴影遗迹宝箱。

## 书籍内容

暗影紧握从四面八方的影子中伸出无数小手，抓住敌人的四肢与衣物，限制其行动。书中说明紧握的个体力量很小，但数量众多，最适合配合其他控制技能使用。作者建议在敌人被眩晕或绊倒后释放，因为动态中的目标更难被小手稳定抓住。中段有一章分析不同体型敌人的应对：大型敌人能轻易挣脱，但会因此被分散注意力；小型敌人则可能被完全固定。修习者需要学会让这些小手避开友军，否则会造成误伤。书中还提到，暗影紧握在目标挣扎越剧烈时抓得越紧，因此有时故意示弱反而能触发更强的控制效果。紧握在敌人试图抱团时会效果倍增，因为小手的数量会随范围内影子的总面积增加。书末用黑墨水画着一只被无数小手拖入地面的靴子，图注是：先让他们迈不开步。书中还记载，真正的暗影大师从不依赖单一技能取胜。

## 设计意图

为暗影系提供范围减速与概率定身，强调配合其他控制使用，强化团队协作中的连控链条与体型差异策略。
