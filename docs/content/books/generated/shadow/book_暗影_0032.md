# 《暗影爆裂：吞噬光芒的爆炸》

## 基础信息

- **书籍 ID**：`book_shadow_0032`
- **关联技能**：`shadow_burst`（待新增，标签 `shadow`）
- **使用效果**：阅读后解锁爆发技能 `shadow_burst`；命中敌人后在其周围造成小范围暗影伤害并短暂致盲。
- **阅读要求**：角色职业标签含 `mage` 或 `rogue`；基础 `智力 ≥ 12` 或 `敏捷 ≥ 12`。
- **稀有度**：稀有（Rare）
- **建议投放**：黑市商人、爆破任务奖励、阴影遗迹宝箱。

## 书籍内容

暗影爆裂将一团压缩的黑暗投向目标，命中后爆发出吞噬光芒的冲击波。书中强调爆裂的核心伤害来自瞬间的暗影压力，而非火焰或冲击。作者建议在密闭空间使用，因为墙壁反射会增强爆裂的致盲效果；在开阔地带则应瞄准敌人之间的空隙，以最大化覆盖。中段有一章分析不同职业的反应：战士会举盾前冲，盗贼会试图翻滚离开视野，法师则可能反向利用黑暗施法。修习者需要训练在爆裂后立即进入黑暗追击。书中还提到，暗影爆裂在命中已有暗影印记的目标时会触发连锁反应，使印记提前爆发造成额外伤害。爆裂后的黑暗区域会短暂干扰友军视线，因此团队作战时必须提前沟通释放时机。书末写着：爆裂制造的不是伤口，是机会。阴影并非虚无，而是光的缺席；修习者要学会在缺席中行动，让自身成为那道被忽略的暗角。

## 设计意图

为暗影系提供单体+小范围爆发技能，结合致盲效果创造追击窗口，强化"先控后打"的暗影战斗节奏。
