# 《暗影领域：无光之地》

## 基础信息

- **书籍 ID**：`book_shadow_0027`
- **关联技能**：`shadow_zone`（待新增，标签 `shadow`）
- **使用效果**：阅读后解锁场地技能 `shadow_zone`；领域内所有暗影技能伤害提升，非暗影单位命中率下降。
- **阅读要求**：角色职业标签含 `mage` 或 `warlock`；基础 `智力 ≥ 14`、意志 `≥ 12`。
- **稀有度**：史诗（Epic）
- **建议投放**：黑市商人、阴影神庙、史诗级宝箱。

## 书籍内容

暗影领域以施术者为中心展开一片持续性的黑暗区域，在其中所有光源都会被压制。书中强调领域的范围与维持时间成反比，越大越暗的领域崩塌得越快。作者建议把领域当作战术工具而非攻击手段，用来掩护队友、分割战场或掩护撤退。中段有一章讨论领域内的感知训练，要求修习者在绝对黑暗中仅凭空气流动判断敌人位置。书中还提到，领域边缘的光暗交界是最危险的地带，许多修习者因为误判边界而在领域崩溃时被强光灼伤眼睛。领域的边缘是双刃剑，敌人进入时会短暂失明，但离开时会因强光而恢复得更快。书末记载了一位大师临终前的经验：领域最强的时刻不是展开瞬间，而是崩溃前那一秒，因为所有人的眼睛都还没适应回来的光。书中最后写道：影子是你的镜子，也是你最忠实的敌人。

## 设计意图

作为暗影系核心场地技能，改变局部战斗环境，放大己方暗影技能收益并削弱敌方常规攻击，体现主题化的战场掌控。
