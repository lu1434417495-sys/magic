# 《暗影契约：血与影的交易》

## 基础信息

- **书籍 ID**：`book_shadow_0024`
- **关联技能**：`shadow_pact`（待新增，标签 `shadow`）
- **使用效果**：阅读后解锁增益技能 `shadow_pact`；消耗少量当前生命值，换取攻击力、速度或防御中的一项临时提升。
- **阅读要求**：角色职业标签含 `warlock` 或 `mage`；基础 `意志 ≥ 12`。

## 书籍内容

暗影契约是与某种黑暗存在签订的临时协议，用自身血液换取短暂的力量增幅。书中详细列出了三种常见契约：影兽契约提升速度与爪击能力，影铠契约强化防御，影瞳契约则增强感知。作者警告契约必须在心中明确交换内容，任何模糊的条款都会被黑暗存在利用。中段有一章讲授如何终止契约，最常见的方法是在日出前把签订时使用的媒介埋入流动的河水。书中还提到，长期重复使用同一种契约会逐渐改变使用者的气质，例如影兽契约者会开始厌恶阳光，影瞳契约者则会在黑暗中看见不该看的东西。契约的效力会随着日出而减弱，因此在清晨签订的契约往往比午夜时更加脆弱。书末附有一名违约者的遗书，字迹混乱：它给了我力量，却要走了我影子里属于人的那一部分。

## 设计意图

为暗影系提供高风险增益选择，通过生命值代价与契约类型分支，强化资源管理与战术决策的紧张感。
