# 《暗影信标》

## 基础信息

- **书籍 ID**：`book_shadow_0088`
- **关联技能**：`shadow_beacon`（待新增，标签 `shadow`）
- **使用效果**：阅读后学会技能 `shadow_beacon`；若已学会，则提升 `current_mastery +120`，并允许同时维持的信标数量 `+1`。
- **阅读要求**：无职业限制；基础 `智力 ≥ 9` 或 `感知 ≥ 10`。
- **稀有度**：普通（Common）
- **建议投放**：军队侦察兵、盗贼公会信使、地下抵抗组织。

## 书籍内容

在黑暗中，信息比刀剑更重要。《暗影信标》教授如何在自己或队友的影子里留下一个隐蔽的能量标记，标记可以在短距离内被同阵营的暗影使用者感知，用来传递位置、状态或简单的战术信号。书中把信标分为静标与动标：静标固定在某处，适合埋伏与接应；动标跟随目标移动，适合追踪与保护。最精妙的一章讲解假信标：故意留下错误的标记，让敌人以为你的主力在另一个方向。作者提醒：信标会被强光暂时压制，布置前必须确认战场光源分布。最后一页贴着一张密码表，每个图案对应一句话，正中最上方写着：不要让信标比你更亮。密码表的最下方有一个从未在任何章节出现过的符号，旁边写着：紧急自毁。符号旁边的空白处有一圈焦痕，似乎曾有人真的尝试激活过它。阴影并非虚无，而是光的缺席；修习者要学会在缺席中行动，让自身成为那道被忽略的暗角。

## 设计意图

为团队协作提供阴影主题的信息传递技能，让战场沟通融入世界观设定，并通过光源机制创造反制空间。
