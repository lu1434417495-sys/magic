# 《暗影使魔：影中仆从》

## 基础信息

- **书籍 ID**：`book_shadow_0043`
- **关联技能**：`shadow_familiar`（待新增，标签 `shadow`）
- **使用效果**：阅读后解锁召唤技能 `shadow_familiar`；召唤一只小型暗影生物，可执行侦察、干扰或自杀式攻击。
- **阅读要求**：角色职业标签含 `mage` 或 `warlock`；基础 `智力 ≥ 11`、意志 `≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：黑市商人、召唤师任务奖励、阴影遗迹宝箱。

## 书籍内容

暗影使魔是从施术者影子中召唤出的小型黑暗生物，能执行侦察、干扰与简单攻击。书中强调使魔与主人之间存在精神链接，使魔受伤时主人会感到头痛。作者详细介绍了三种常见使魔：影猫擅长潜行侦察，影鸦负责高空警戒，影虫则能钻进缝隙触发陷阱。中段有一章讨论使魔的喂养，它们不需要食物，但需要定期回到主人的影子中补充暗影能量。修习者需要训练同时控制多个使魔，否则它们会按本能行动。书中还提到，使魔在主人失去意识时可能接管影子继续行动，有些甚至会在主人濒死时试图将其拖入阴影维度。使魔在主人情绪剧烈波动时会变得狂躁，因此召唤师需要学会在战斗中保持冷静。书末附有一名召唤师的警告：不要给使魔起名字，它们会记得。书末附有一段训练口诀，要求每日早晚各诵念三遍。

## 设计意图

为暗影系提供可定制的召唤物体系，通过侦察、干扰与自杀攻击的分支选择，拓展战术多样性与信息战维度。
