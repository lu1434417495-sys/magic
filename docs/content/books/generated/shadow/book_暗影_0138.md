# 《夜刃：短刀淬毒暗影》

## 基础信息

- **书籍 ID**：`book_暗影_0138`
- **关联技能**：`shadow_dagger_night`
- **使用效果**：阅读后解锁 `shadow_dagger_night`；匕首攻击附加持续暗影流血效果。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `敏捷 ≥ 12`。
- **稀有度**：稀有（Rare）
- **建议投放**：毒师工坊密室、暗夜集市、高阶刺客毒药任务奖励。

## 书籍内容

夜刃把毒素学与暗影魔法结合，创造出一种不会留下可见血迹的持续伤害手段。作者在书中解释，暗影流血不是真正的失血，而是伤口处的影子不断向内侵蚀，让目标在数秒内持续衰弱。这种伤害无法被普通解毒剂治愈，但强光照射可以大幅缩短持续时间。书中详细描述了淬毒过程：把匕首浸泡在混合了暗影残渣与夜行草药的溶液中，然后在月光下晾干，反复三次。后半部分讨论了战术使用：夜刃适合对付高生命值目标与擅长治疗的敌人，因为它能制造持续压力，迫使对方消耗资源。附录里有一张被烧毁一半的配方表，最后一种材料的名字已经无法辨认，据说那是让夜刃真正致命的秘方，也可能只是作者的恐吓。夜刃造成的伤口在黑暗中会微微冒烟，这是其最显著的识别特征。

## 设计意图

强化持续伤害与资源消耗，把毒素主题与暗影机制融合，丰富刺客输出节奏。
