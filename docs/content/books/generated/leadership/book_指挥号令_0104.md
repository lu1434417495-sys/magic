# 《鼓舞士气要诀》

## 基础信息

- **书籍 ID**：`book_指挥号令_0104`
- **关联技能**：`leadership_inspire_morale`
- **使用效果**：阅读后解锁 `leadership_inspire_morale`；若已学会，提升该技能 `current_mastery +90`，并使士气低落时触发鼓舞的成功率提升 10%。
- **阅读要求**：无职业限制；基础 `魅力 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：吟游诗人营地、军官学堂、战场救援队。

## 书籍内容

这本书专门讨论如何在战斗中维持和提升队伍士气。作者认为，士气不是虚无缥缈的情绪，而是可以通过具体行为管理的状态。书中列举了十二种常见士气低落原因：饥饿、恐惧、同伴阵亡、命令矛盾、疲劳、谣言、寒冷、黑暗、孤立、背叛、失败记忆、长官怯懦。针对每一种原因，作者都给出了一句可以在战场上立刻使用的话。比如面对同伴阵亡，不要说他会光荣，而要说他留给我们机会。手册还提醒指挥官，鼓舞士气时自己的位置很关键，站在队伍前方中央效果最好，躲在后方则会被迅速识破。同时，指挥官必须以身作则，如果自己面露惧色，任何口号都会变成讽刺。此外，作者还提醒指挥官注意自己的声音状态，沙哑或颤抖的嗓音会让最鼓舞人心的话语大打折扣。最末一章讲述如何用歌声、口号、旗帜和共同回忆来构建队伍认同。许多老兵在退役后仍能背诵书中某句话。

## 设计意图

把士气系统具象化为可操作的指挥技能，让玩家在持久战中通过语言与行动扭转劣势局面。
