# 《集结呐喊：第一声号令》

## 基础信息

- **书籍 ID**：`book_指挥号令_0001`
- **关联技能**：`leadership_rallying_cry`
- **使用效果**：阅读后解锁 `leadership_rallying_cry`；若已学会，提升该技能 `current_mastery +90`，并延长下次呐喊的士气持续时间 1 回合（一次性）。
- **阅读要求**：无职业限制；基础 `魅力 ≥ 6` 或 `意志 ≥ 6`。
- **稀有度**：普通（Common）
- **建议投放**：新兵营训导官、民兵队长、基础战术商人。

## 书籍内容

这本薄册的封面印着一枚裂开的铜哨，书脊处用麻线重新装订过三次。开篇第一句写着："号令不是让你喊得大声，是让你的同伴知道该往哪边看。"作者把集结呐喊分成三种音量：第一种只让身边三人听见，用于小队的紧急收缩；第二种覆盖半个战场，用于重新组织散开的阵线；第三种只发出一个短促音节，却让所有人同时转向同一目标。书中花了整整十页纠正一个错误——不要在队友背对敌人时喊他们的名字，那会让他们本能回头，把要害暴露给追击者。后半部分是七个战场口令的列表，每个口令都配有一幅简笔画，显示队伍应如何移动。最末页被血浸透，只能辨认出最后一句："声音会散，但方向不会。"许多指挥官会把铜哨挂在胸前，不是为了吹响，而是为了提醒自己：号令一旦出口，就要为听令者的生命负责。

## 设计意图

作为指挥号令系列的基础入口，将"呐喊"从单纯增益重新定义为团队空间重组工具，降低新手指挥官的学习门槛。
