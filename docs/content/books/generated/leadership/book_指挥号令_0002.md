# 《阵线如铁：坚守指令》

## 基础信息

- **书籍 ID**：`book_指挥号令_0002`
- **关联技能**：`leadership_hold_the_line`
- **使用效果**：阅读后解锁 `leadership_hold_the_line`；若已学会，提升该技能 `current_mastery +85`，并减少下次发动时的 `aura` 消耗 2 点（一次性）。

- **建议投放**：盾卫训练营、城防工事书架、重装商人。

## 书籍内容

书皮是一块被反复折叠的旧帆布，上面还能看出当年某面军旗的残色。作者用木匠打榫的思路讲解阵线：每个人都在给左右两人提供支撑，任何一个缺口都会让整个结构在压力下断裂。书中强调"坚守"不等于"不动"，真正稳固的阵线会在敌人冲击时像柳枝一样微微后撤半步，卸力后再弹回原位。第二章列出了三种必须后撤的信号：脚步离地、盾牌错位、呼吸紊乱。作者警告说，如果指挥官自己忘了这些信号，阵线就会从"保存实力"变成"溃败"。后半本收录了十几张手绘盾阵图，每张边角都有不同队长的批注，最旧的一条写着："守住的不是土地，是彼此之间的信任。"书中还夹着一张被箭射穿的木片，上面刻着某位阵亡队长的临终笔迹："阵线可以后退，人心不能后退。"帆布夹层里还藏着半块被盾牌压变形的铁片，据说来自某位用身体补住缺口的新兵。

## 设计意图

服务于前排职业的团队守护定位，把"坚守"从被动挨揍转化为需要节奏判断的主动技能，为后续进阶阵法留出升级接口。
