# 《破阵号令》

## 基础信息

- **书籍 ID**：`book_leadership_0075`
- **关联技能**：`leadership_break_formation`（待新增，标签 `leadership`）
- **使用效果**：阅读后学会指挥技能 `leadership_break_formation`，可命令一名强力友方对敌方阵型发动冲击，若目标处于阵型中，则对其周围敌人造成溅射伤害并降低其阵型加成。
- **阅读要求**：角色职业标签含 `warrior`、`barbarian` 或 `berserker`；基础 `力量 ≥ 12`。

- **建议投放**：狂战士训练场、破阵者传承、史诗级攻城战奖励。

## 书籍内容

《破阵号令》是一本关于如何用暴力拆解秩序的书。作者认为，任何阵型都有其心理基础：士兵相信站在一起会更安全。破阵者的任务就是粉碎这种信念。书中将破阵分为"物理破阵"与"心理破阵"：前者靠重击、冲撞与范围伤害撕开缺口，后者则靠率先击杀阵型中的关键人物让其余人动摇。作者强调，破阵者必须是最勇猛或最疯狂的人，因为冲进密集敌阵意味着承受来自多个方向的攻击。书中还讨论了破阵后的跟进：一次成功的破阵如果没有队友迅速扩大缺口，就会退化成一次鲁莽的自杀。最后一章警告，破阵不是越多越好——在错误的地方撕开阵型，反而会让敌人从两翼包抄。作者建议破阵前先用小股佯攻试探敌方阵型中心与边缘的强度差异，找到真正的薄弱环节再全力出击。书末附有一幅重甲战士冲入敌阵的插画，周围是四散飞溅的泥土与盾牌。

## 设计意图

为重甲与狂战士职业提供反阵型能力，专门克制依赖密集站位的敌人。溅射伤害与阵型加成降低，让破阵成为改变战场格局的关键动作。
