# 《后卫掩护指令》

## 基础信息

- **书籍 ID**：`book_指挥号令_0109`
- **关联技能**：`leadership_rear_guard`
- **使用效果**：阅读后解锁 `leadership_rear_guard`；若已学会，提升该技能 `current_mastery +90`，并使后卫单位在掩护撤退时受到的伤害降低 8%。
- **阅读要求**：无职业限制；基础 `体质 ≥ 8` 或 `意志 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：重装营地、守备任务奖励、防御教官书架。

## 书籍内容

《后卫掩护指令》教导指挥官如何组织最后一条防线。作者指出，后卫不是被遗弃者，而是被信任的牺牲者。书中详细说明了后卫部队的选拔原则：必须拥有足够的防御能力、冷静的头脑和对全局的理解，否则一旦后卫溃散，整支队伍都会陷入灾难。手册用多个战例展示如何布置后卫阵地、如何利用狭窄地形迟滞敌人、如何在撤退中分批交接。后半部分还讨论了后卫部队的心理建设，建议指挥官在任务前与后卫成员单独谈话，明确他们的牺牲是有上限的，而不是无限拖延。书中还提醒，成功完成断后任务的部队应获得优先休整与荣誉，否则下次将无人愿意承担此任。手册还提醒，后卫部队成员应被告知具体的撤退时间和会合点，让他们知道牺牲是有明确期限的。最末一页写着：后卫的荣耀不在于杀敌多少，而在于让更多人活着离开战场。

## 设计意图

为防守与断后玩法提供技能支撑，让撤退与阵地战中的牺牲决策更具仪式感和策略意义。
