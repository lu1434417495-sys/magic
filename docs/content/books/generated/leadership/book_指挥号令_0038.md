# 《挑衅广播：让敌人只看你》

## 基础信息

- **书籍 ID**：`book_指挥号令_0038`
- **关联技能**：`leadership_taunt_broadcast`
- **使用效果**：阅读后解锁 `leadership_taunt_broadcast`；若已学会，提升该技能 `current_mastery +90`，并提高下次挑衅的强制目标数 1 名（一次性）。
- **阅读要求**：角色职业标签含 `warrior`、`knight` 或 `berserker`；基础 `体质 ≥ 9` 或 `魅力 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：角斗场看台、军团挑衅训练场、近战商人。

## 书籍内容

书的封面是一张被撕破的嘴，嘴角上扬，露出过于整齐的牙齿。作者把挑衅定义为"用语言或行动把敌人的注意力从脆弱目标转移到自己身上"。书中指出，有效的挑衅不是侮辱，而是让敌人觉得"不打你就是承认失败"。第二章讲解了"范围挑衅"与"精准挑衅"的区别：前者用于吸引一群杂兵的仇恨，适合保护后排；后者用于锁定某个关键敌人，适合配合集火。作者警告说，挑衅者必须具备承受后续攻击的能力，否则就是把队友从另一个危险转移到一个更大的危险。后半本收集了各地战士常用的挑衅语，从粗俗咒骂到贵族式嘲讽应有尽有。最末页只有一行被血指印加粗的话："如果我能让三个人转向我，后排就多出三秒。"旁边还粘着半片被打碎的盾牌，是某位挑衅者引以为傲的纪念品。盾牌碎片上刻着一行小字："挑衅者的脊梁，要比他的嘴更硬。"

## 设计意图

为坦克型职业提供团队仇恨管理工具，将体质/魅力转化为保护后排能力，强化前排指挥官的控场价值。
