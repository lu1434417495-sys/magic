# 《进攻姿态》

## 书籍内容

《进攻姿态》与《防御姿态》常被放在一起讨论，但作者坚称两者本质相反：防御是收缩，进攻则是把全部重量压向前方。书中将进攻姿态描述为一种主动的失衡——你故意让自己更容易被击中，以换取每一次挥击都带着终结的意味。作者强调，进攻姿态必须在合适的时机启动，最好在敌人刚刚失手、阵型出现松动或己方已取得局部优势时。书中还讨论了进攻姿态中的移动：向前、 always 向前，哪怕是侧向移动也会削弱那股一往无前的气势。最后一章警告，进攻姿态不能变成无头苍蝇式的乱冲，每一次突进都应该有明确的目标与撤退计划。作者还指出，进攻姿态下的单位最怕的是被控制或包围，因此指挥官应预先安排援军跟进以扩大突破口。书末附有一幅插图，画着一名战士浑身浴血却越战越勇，周围的敌人正下意识后退。

## 设计意图

提供高风险高回报的集体增益，让进攻型角色能够在关键时刻全力一搏。防御下降与攻击暴击提升的组合，要求指挥官精准把握启动窗口。
