# 《两翼指挥》

## 书籍内容

《两翼指挥》认为，最强大的攻击往往来自敌人的余光之外。作者将两翼作战比作张开双臂：中央是躯干，两翼是拳头，只有双臂同时挥出，才能让敌人无处可躲。书中强调，两翼指挥的最大挑战是同步——如果一侧提前发动，敌人会把全部注意力转向那边，另一侧就会失去突然性。作者详细讲解了如何用简单信号保持沟通：旗帜、号角或预先约定的法术闪光。书中还讨论了两翼的构成：高机动单位最适合承担两翼任务，因为他们需要在不被发现的情况下绕到指定位置。最后一章警告，两翼包抄成功的代价是中央薄弱，如果敌人识破意图并集中突破中央，两翼就会变成孤军。作者建议在两翼出动前，中央应故意示弱以诱使敌人分神。书末附有一张双臂合围的战术图，展示左右两翼如何同时压向中央目标。

## 设计意图

提供双单位协同夹击机制，让高机动角色在战场两侧创造爆发点。额外伤害与破甲效果鼓励玩家规划多角度进攻路线。
