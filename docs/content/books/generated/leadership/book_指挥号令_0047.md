# 《元素专注：让队伍只相信一种力量》

## 基础信息

- **书籍 ID**：`book_指挥号令_0047`
- **关联技能**：`leadership_elemental_focus`
- **使用效果**：阅读后解锁 `leadership_elemental_focus`；若已学会，提升该技能 `current_mastery +95`，并提高下次专注时同元素伤害叠加效率 12%（一次性）。
- **阅读要求**：角色职业标签含 `mage`、`sorcerer` 或 `druid`；基础 `智力 ≥ 9` 或 `感知 ≥ 9`。
- **稀有度**：稀有（Rare）
- **建议投放**：元素圣殿、法师塔专精室、灵能商人。

## 书籍内容

书的封面由四片不同颜色的薄石片拼成，分别代表火、水、风、土。作者把元素专注定义为"让团队在同一时间段内只强化一种元素属性，以获得最大化的环境共鸣"。书中指出，混合元素虽然灵活，但会导致场地效果相互抵消；而专注于单一元素时，战场会缓慢向该元素倾斜，例如连续使用火系法术会让地面出现焦痕，提高后续火系伤害。第二章讲解了"元素切换"：指挥官必须在战斗前或战斗间隙明确宣布本阶段的主元素，避免施术者因习惯而使用其他属性法术。作者警告说，专注最大风险是被敌人针对抗性，因此需要准备一次快速切换的预案。最末页贴着一张被烧黑的元素周期表，其中一个元素被红笔圈出，批注："一种力量用到极致，比十种力量各用一成更可怕。"石片缝隙中还嵌着一小块被熔化的法杖残片，是某次元素过度专注后留下的唯一痕迹。

## 设计意图

为法师队伍提供元素主题协同，将智力/感知转化为环境共鸣收益，强化同元素阵容的战略价值与战场塑造感。
