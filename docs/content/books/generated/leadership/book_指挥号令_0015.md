# 《防御据点：把地形变成队友》

## 书籍内容

这是一本被石粉和木屑浸透的厚册，封面上印着一台被简化成线条的投石机。作者把地形看作沉默的队友，好的指挥官能让墙壁、壕沟、高地都成为防御体系的一部分。书中提出"据点三要素"：入口要窄，让敌人无法一次性涌入；视野要宽，让守军能提前发现威胁；退路要留，避免被围困后全军覆没。第二章详细讲解如何在战棋格子上快速评估一个位置的价值，包括与己方远程单位的距离、与侧翼通道的夹角、以及敌人冲锋路线的交汇点。作者特别提醒：不要把所有精锐都塞进最坚固的位置，因为那会让其他区域变成诱饵。最末页贴着一张破损的城防图，某个塔楼被红圈圈出，旁边写着："这里死了三十七个人，但让三百人活到了黎明。"城防图背面还画着一条被涂抹的撤退路线，批注："最好的据点不是让人死在里面，而是让人能活着离开。"

## 设计意图

引入地形改造与据点驻守机制，将环境要素纳入指挥号令体系，为防守型战术提供资源转化出口。
