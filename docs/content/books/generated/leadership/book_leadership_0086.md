# 《反冲锋》

## 书籍内容

《反冲锋》是一本关于以动制动的书。作者认为，面对冲锋最糟糕的反应是原地硬抗，因为那会承受敌人积累的全部动能；最好的反应是在对方势头将尽未尽时迎面撞上去。书中将反冲锋的时机精确到"三步"：当敌人进入最后冲刺阶段、当己方阵型尚完整、当指挥官的号令能够被所有人听见。作者强调，反冲锋不是鲁莽对撞，而是利用敌人无法转向的瞬间切入其侧翼或打断其节奏。书中还讨论了反冲锋的代价：即使成功，参与单位也会承受严重冲击，因此不能频繁使用。最后一章警告，反冲锋最怕的是指挥官误判敌人冲锋方向——如果你的反冲锋扑空，身后就会留下巨大空当。作者建议预留一支小型机动单位作为纠错力量，在反冲锋偏离时及时补位。书末附有一幅两股箭头相撞的示意图，标注了正确与错误的接触角度。

## 设计意图

为战棋提供克制冲锋类技能的反制手段，让重装与骑兵单位能够以攻代守。打断冲锋加成的效果专门惩罚那些依赖直线突进的敌人。
