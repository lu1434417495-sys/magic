# 《牧师守护圈：以信仰为界》

## 基础信息

- **书籍 ID**：`book_指挥号令_0027`
- **关联技能**：`leadership_clerics_ward`
- **使用效果**：阅读后解锁 `leadership_clerics_ward`；若已学会，提升该技能 `current_mastery +95`，并扩大下次守护圈的范围 1 格（一次性）。
- **阅读要求**：角色职业标签含 `priest`、`paladin` 或 `cleric`；基础 `意志 ≥ 9` 或 `智力 ≥ 8`。
- **稀有度**：稀有（Rare）
- **建议投放**：神庙圣所、战地礼拜堂、神圣商人。

## 书籍内容

这本书的封面用银线绣着一个不完整的圆，断口处像是一扇尚未关闭的门。作者把牧师守护圈定义为"用共同信念画出的临时边界"。书中指出，守护圈真正的力量不在于阻挡物理攻击，而在于让圈内的人在受伤时仍能保持清醒。指挥官在下达守护指令时必须明确圈的持续时间，因为信仰集中过久会让施术者透支。第二章讲解了"接力守护"：当一位牧师的 AURA 或 MP 不足时，应由另一位提前在相邻位置预备新的守护圈，旧圈消失与新圈升起之间不应有超过一拍的间隙。最末页是一张被烛泪凝固的祈祷文，某些句子被反复描粗，旁边写着："圈外的人看着我们，圈内的人看着彼此。"祈祷文背面有一行被泪水晕开的字迹："我无法阻止刀剑，但我可以让你在刀剑下仍记得自己为何而战。"银线圆圈的断口处还系着一段被血染白的绷带，来自某位在守护圈消失前最后一刻仍握着队友手的牧师。

## 设计意图

为神职职业提供团队保护区域技能，将信仰资源转化为可共享的防御边界，与牧师治疗体系形成互补。
