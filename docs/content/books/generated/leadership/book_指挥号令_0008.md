# 《行军方阵：移动中的秩序》

## 基础信息

- **书籍 ID**：`book_指挥号令_0008`
- **关联技能**：`leadership_march_formation`
- **使用效果**：阅读后解锁 `leadership_march_formation`；若已学会，提升该技能 `current_mastery +85`，并提高下次行军时全队的移动力加成 1 格（一次性）。
- **阅读要求**：无职业限制；基础 `敏捷 ≥ 7` 或 `体质 ≥ 7`。
- **稀有度**：普通（Common）
- **建议投放**：行军营地、商队护卫任务、通用战术商人。

## 书籍内容

这是一本被马蹄泥点浸透的行军手册，扉页上写着"快不是目的，不散才是"。作者把队伍移动分为三种阵型：雁行适合开阔地，便于观察侧翼；纵队适合狭窄地形，减少被伏击的面积；菱形适合保护中心目标，但会牺牲整体速度。书中强调，指挥官在下达移动命令时必须同时说明"队形"和"步速"，缺少任何一项都会导致队伍在移动中自然解体。中间章节记录了如何在移动中保持间距一致——作者建议在心中默念一首短诗，每句对应一次落脚。最末页是一幅被水渍模糊的地图，上面用红笔标着一条曲折路线，旁边只有一句话："最快的路不一定是直的，但一定是所有人都能走完的。"地图背面还画着一只断掉的马蹄铁，旁边批注："行军中最昂贵的不是时间，是把一个人落在敌人手里。"手册封底内侧还贴着一张被雨水泡软的口粮条，某位老兵在上面写着："能一起到达，比先到更重要。"

## 设计意图

为指挥号令系列补充移动协同维度，把队伍走位从个体决策提升为受阵型增益影响的集体行为，强化战棋地图利用。
