# 《战俘处置原则》

## 基础信息

- **书籍 ID**：`book_指挥号令_0128`
- **关联技能**：`leadership_prisoner_protocol`
- **使用效果**：阅读后解锁 `leadership_prisoner_protocol`；若已学会，提升该技能 `current_mastery +100`，并使俘虏敌方单位后获得情报或招募的概率提升 10%。
- **阅读要求**：无职业限制；基础 `魅力 ≥ 8` 或 `意志 ≥ 8`。
- **稀有度**：精良（Uncommon）
- **建议投放**：骑士团藏书、审讯任务奖励、外交官书架。

## 书籍内容

《战俘处置原则》讨论了战场上的伦理与实用问题。作者认为，如何对待投降者不仅关乎道德，也关乎未来战斗的烈度。书中提出三条原则：确保安全、获取情报、决定去向。确保安全是指防止俘虏反扑或同伙救援；获取情报需要技巧，不能仅靠威胁；决定去向则涉及释放、交换、监禁或招募等多种选择。手册强调，虐待俘虏可能在短期内获得恐惧，但长期来看会激发更顽强的抵抗。后半部分讨论了不同文化背景俘虏的特殊处理方式，以及如何在队伍中建立对此类任务的轮换制度。作者还提醒，处置俘虏的人必须受到监督，因为战场上的仇恨容易让人越过底线。书中还建议为俘虏提供基本的饮食与医疗，这不仅是道德要求，也能提高他们配合审讯的意愿。最末一页写着：今天你对俘虏的态度，就是明天敌人对你的态度。

## 设计意图

为游戏增加俘虏与外交维度的指挥选择，让战斗结果影响后续剧情与资源获取。
