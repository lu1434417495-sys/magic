# 《盗贼协同：阴影里的接力》

## 基础信息

- **书籍 ID**：`book_指挥号令_0029`
- **关联技能**：`leadership_rogue_coordination`
- **使用效果**：阅读后解锁 `leadership_rogue_coordination`；若已学会，提升该技能 `current_mastery +90`，并提高下次协同中背刺伤害的连携加成 12%（一次性）。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `敏捷 ≥ 9` 或 `感知 ≥ 8`。
- **稀有度**：稀有（Rare）
- **建议投放**：盗贼公会暗室、黑市情报商、阴影商人。

## 书籍内容

书的封面是一层会随光线变色的黑布，正面看是纯色，侧面看能隐约看见一只手递出另一把刀的图案。作者把盗贼协同定义为"让阴影里的人彼此知道下一个动作会落在哪里"。书中强调，盗贼之间的配合不靠喊叫，而靠预先约定的节奏：第一击由最敏捷者发动吸引注意，第二击从相反方向切向要害，第三击负责补刀或撤离。第二章讲解了"错位现身"技巧：两名盗贼不能在同一侧连续暴露，否则敌人会下意识守住那一侧。作者还记录了一种被称为"影子握手"的确认方式：在黑暗中用武器轻触地面三下，表示"我已就位，可以动手"。最末页是一幅被墨水晕染的简笔画，两个模糊人影从左右同时逼近一个中心点，配文："一个人是刺客，两个人是判决。"黑布夹层里还藏着一枚被折断的淬毒匕首，据说属于一对从未失手的双子刺客。

## 设计意图

为盗贼/暗杀者职业提供团队连携入口，将高爆发背刺扩展为需要空间配合的战术技能，强化阴影职业的协同玩法。
