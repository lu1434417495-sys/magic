# 《拦截命令：切断敌人的脚步》

## 基础信息

- **书籍 ID**：`book_指挥号令_0033`
- **关联技能**：`leadership_intercept_order`
- **使用效果**：阅读后解锁 `leadership_intercept_order`；若已学会，提升该技能 `current_mastery +90`，并提高下次拦截成功时的控制持续时间 0.5 秒（一次性）。
- **阅读要求**：角色职业标签含 `warrior`、`knight` 或 `rogue`；基础 `敏捷 ≥ 8` 或 `力量 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：边境哨站、巡逻队营地、通用商人。

## 书籍内容

书的封面是一把横亘道路中央的短矛，矛杆上缠着表示警告的红布条。作者把拦截定义为"在敌人到达目标之前，先把自己的身体放进那条路径里"。书中强调，拦截者不需要打赢敌人，只需要让敌人的进攻节奏断一拍。第二章讲解了"预判拦截"：通过观察敌人的朝向、速度和前一次攻击目标，提前移动到其必经之路上。作者警告说，拦截最忌正面硬挡高速冲锋，正确做法是斜向切入敌人的侧前方，迫使其转向或减速。后半本记录了多种常见敌人的拦截弱点：骑兵怕绊索，野兽怕突入其视野盲区，施法者怕被打断引导。最末页是一张被踩脏的巡逻路线图，几个关键路口被红叉标出，批注："好的拦截不是追上敌人，而是让敌人不得不先撞上你。"路线图边缘还插着一根被折断的绊索，据说是某位拦截者用生命验证过的最后陷阱。

## 设计意图

为机动/前排职业提供敌人路径控制技能，将拦截从个人反应提升为可预判部署的战术指令，强化保护后排的能力。
