# 《先锋推进：撕开第一道口子》

## 基础信息

- **书籍 ID**：`book_指挥号令_0011`
- **关联技能**：`leadership_vanguard_push`
- **使用效果**：阅读后解锁 `leadership_vanguard_push`；若已学会，提升该技能 `current_mastery +90`，并提高下次先锋推进首击的破障伤害 15%（一次性）。
- **阅读要求**：角色职业标签含 `warrior`、`berserker` 或 `paladin`；基础 `力量 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：先锋营训练场、攻城器械旁书架、近战商人。

## 书籍内容

书的封面被一道斜向裂痕贯穿，像是被剑劈过但又被精心粘合。作者把先锋比作楔子：目的不是杀死所有敌人，而是在敌阵最厚的地方制造一个可供后续力量涌入的缺口。书中详细描述了"三步突进"：第一步用盾牌或肩甲撞击敌人重心，第二步踏住对方后退的脚，第三步把武器送入因失衡而暴露的空当。作者警告先锋最忌贪功，一旦突入过深失去侧翼保护，就会变成被包围的孤点。后半本记录了多种常见阵型的突破点：方阵的角、圆阵的切线、长蛇阵的腰。最末页是一幅被火烧掉一半的插图，只能看见一只向前伸出的手臂和一行字："先锋的职责是为后来的人挡住第一把刀。"裂痕处夹着一片已经发黑的绷带，据说是某位先锋在缺口打开后回头交给传令兵的遗物。绷带旁边还写着一行小字："先锋可以死，但缺口必须留给后面的人。"

## 设计意图

为力量型指挥官提供团队突进技能，将个人冲锋扩展为可制造缺口的战术行动，丰富战棋中的阵型破坏手段。
