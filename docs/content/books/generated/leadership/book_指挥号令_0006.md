# 《集火：让伤口出现在同一个地方》

## 基础信息

- **书籍 ID**：`book_指挥号令_0006`
- **关联技能**：`leadership_focus_fire`
- **使用效果**：阅读后解锁 `leadership_focus_fire`；若已学会，提升该技能 `current_mastery +95`，并提高下次集火对标记目标的破甲效率 10%（一次性）。
- **阅读要求**：无职业限制；基础 `感知 ≥ 8` 或 `智力 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：射手营靶场、战术教官背包、通用商人。

## 书籍内容

书的尺寸很小，刚好能塞进胸甲内侧的口袋里，页角都被磨损得发毛。作者用猎狼的经验讲解集火：狼群不会同时攻击熊的全身，它们只盯着一处咬，直到那处流血、僵硬、最终站不住。书中提出"伤口堆叠"概念——当一个目标在短时间内被多次命中同一区域，护甲会出现"疲劳裂纹"，后续攻击会获得额外穿透。第二章给出了三个简单的集火口令："点"表示标记目标，"压"表示持续输出，"透"表示切换已破防部位。作者警告说，集火最危险的时刻不是打不中，而是目标死后没人给出下一个"点"。书末附有一张被血染红的靶纸，中心只有一个孔洞，旁边批注："一百支箭的威慑，不如一支箭的位置被重复九十九次。"书的最后一页贴着一枚变形的箭头，注明来自某次著名的猎龙战役，那场胜利的关键就在于七名射手连续命中同一枚鳞片。

## 设计意图

为高感知/智力型指挥官提供团队伤害放大手段，把分散火力转化为破防机制，强化战棋中的目标优先级决策。
