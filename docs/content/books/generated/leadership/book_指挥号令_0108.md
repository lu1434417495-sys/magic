# 《先锋号令》

## 基础信息

- **书籍 ID**：`book_指挥号令_0108`
- **关联技能**：`leadership_vanguard_order`
- **使用效果**：阅读后解锁 `leadership_vanguard_order`；若已学会，提升该技能 `current_mastery +90`，并使先锋单位首次冲锋伤害提升 8%。
- **阅读要求**：无职业限制；基础 `力量 ≥ 8` 或 `敏捷 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：前锋营地、突击任务奖励、骑兵教官书架。

## 书籍内容

《先锋号令》是一本关于如何派遣与指挥先头部队的手册。作者认为，先锋的任务不是胜利，而是试探、压迫与制造混乱。书中把先锋分为斥候型、突击型和牵制型三种，并分别给出了选拔标准与使用禁忌。斥候型先锋需要高感知与隐蔽能力，突击型需要爆发伤害与承受首轮反击的硬度，牵制型则需要足够的机动力与脱战能力。后半部分讲述了指挥官如何在中军判断先锋传回的信息，哪些信号意味着可以跟进，哪些信号意味着必须立刻召回。书中还提到，先锋的装备必须轻便可靠，过于沉重的护甲会拖慢节奏，而不足的防护则可能让他们在接敌瞬间全灭。最末一章强调，先锋部队最容易被牺牲，但也最忌讳被无意义地牺牲。一名好的指挥官会让先锋知道，他们的风险是被计算过的，而不是被漠视的。

## 设计意图

为进攻型队伍提供开战斗指令，强化先手和突进职业的价值，让先锋不再是孤立送死的角色。
