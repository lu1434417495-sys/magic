# 《激励一击：让剑刃开口说话》

## 基础信息

- **书籍 ID**：`book_指挥号令_0003`
- **关联技能**：`leadership_inspired_strike`
- **使用效果**：阅读后解锁 `leadership_inspired_strike`；若已学会，提升该技能 `current_mastery +95`，并使下一次激励附加的伤害加成提高 8%（一次性）。
- **阅读要求**：无职业限制；基础 `力量 ≥ 7` 或 `魅力 ≥ 7`。
- **稀有度**：普通（Common）
- **建议投放**：佣兵公会任务奖励、竞技场教官、近战战术商人。

## 书籍内容

这是一本被剑油浸透的册子，页边布满指甲掐出的月牙痕。作者认为激励不是战前演说，而是在队友挥出关键一击前零点几秒内给出的精确信号。书中提出"三拍理论"：第一拍观察敌人姿态，第二拍喊出队友名字，第三拍指出敌人最脆弱的接缝。作者坚决反对空泛的"加油"，因为那会打断战斗中的本能节奏。中间章节记录了七种不同武器的激励语：对重剑手喊"沉下去"，对双持者喊"连起来"，对长枪兵喊"送到底"。每种指令都对应一种身体记忆的唤醒方式。书的最后夹着一片干枯的花瓣，旁边是一句褪色批注："最好的激励，是让对方相信自己本来就能做到。"书末空白处还有一行新添的字迹："激励者必须先看见队友的极限，而不是只看见自己的期待。"册子封底还贴着一张被剑油晕染的旧纸条，上面写着某位老教官的忠告："激励的话要短，因为战斗不会给你长篇大论的时间。"

## 设计意图

为指挥者提供即时战斗增益接口，将语言资源转化为伤害窗口，鼓励玩家关注队友的攻击节奏而非只盯着自己的技能冷却。
