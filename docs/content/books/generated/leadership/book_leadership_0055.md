# 《撤退信号》

## 基础信息

- **书籍 ID**：`book_leadership_0055`
- **关联技能**：`leadership_retreat_signal`（待新增，标签 `leadership`）
- **使用效果**：阅读后学会指挥技能 `leadership_retreat_signal`，可发出撤退号令，使范围内友方获得一次免费后撤移动并不引发借机攻击。
- **阅读要求**：无职业限制；基础 `敏捷 ≥ 8` 或 `感知 ≥ 8`。
- **稀有度**：稀有（Rare）
- **建议投放**：斥候营地、残兵收容所、战略撤退剧情奖励。

## 书籍内容

撤退是一门被污名化的艺术。《撤退信号》的第一句话是：会进攻的指挥官很多，会撤退的指挥官很少，而能带着大部分人活着撤退的指挥官才是真正的稀有品。书中将撤退信号设计成三段式：第一段是连续的短音，让士兵意识到"停止进攻"；第二段是拉长的低音，表示"向后移动"；第三段是急促的断音，提醒"不要恋战"。作者强调，撤退信号必须在局势尚可挽回时发出，等到全线崩溃再喊撤退，只会变成自相践踏。书中还分析了撤退路径的选择：优先利用掩体与烟雾，避免直线后撤，并且始终保留一支后卫部队。作者建议每次撤退前都预先演练两条备选路线，因为原计划往往会在第一支箭落下时失效。最后一章讨论士气管理——士兵需要知道撤退不是逃跑，而是为了下一次进攻。书末有一幅插图，画着一支队伍沿着山脊有序后撤，最后一名弓箭手正回身射出一支掩护箭。

## 设计意图

为战棋增加主动撤退的战术选项，避免战斗变成单纯的死磕。免费后撤与免疫借机攻击的组合，让指挥官能在劣势时保存有生力量并重新布阵。
