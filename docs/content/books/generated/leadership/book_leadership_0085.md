# 《联合突击》

## 基础信息

- **书籍 ID**：`book_leadership_0085`
- **关联技能**：`leadership_joint_assault`（待新增，标签 `leadership`）
- **使用效果**：阅读后学会指挥技能 `leadership_joint_assault`，可让近战与远程友方同时攻击同一目标，若该目标本回合同时受到近战与远程伤害，第二次伤害大幅提升。

## 书籍内容

《联合突击》认为，不同兵种的真正价值不在于各自多强，而在于能否在同一瞬间打出无法单独完成的伤害。作者将联合突击拆解为"牵引"与"收割"：近战单位先缠住目标，限制其移动与闪避；远程单位则在安全距离外瞄准被固定的弱点。书中强调，联合突击的关键是节奏——远程攻击不能过早，否则目标还有余力躲避；也不能过晚，否则近战单位可能已经倒下。作者还讨论了沟通方式：简单的手势或预设的法术标记，都比口头号令更可靠。最后一章警告，联合突击要求参与单位互相信任，如果远程担心误伤而不敢全力射击，整个配合就会失效。作者建议在训练中使用钝箭与包布武器反复演练，直到双方都能在不伤人的情况下完成配合。书末附有一幅配合图，画着一名战士架住敌人的武器，而远处的弓箭手正松开弓弦。

## 设计意图

促进近战与远程职业的跨类型配合，让不同职业在协同中获得超越单体输出的收益。第二次伤害大幅提升奖励精确的时机配合。
