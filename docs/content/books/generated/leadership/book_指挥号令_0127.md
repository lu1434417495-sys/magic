# 《战利品分配协议》

- **书籍 ID**：`book_指挥号令_0127`

## 书籍内容

《战利品分配协议》是一本关于如何避免胜利后内部分裂的书。作者认为，很多队伍不是死在敌人手中，而是死在分赃不均上。书中提供了一套透明的分配原则：按贡献、按需求、按事先约定，三者结合。手册强调，协议必须在战斗前达成共识，而不是战后才临时商量。后半部分讨论了不同成员类型的期望管理：战士渴望武器、法师渴望材料、牧师渴望圣物、盗贼渴望金币。最末一章附有一份常见战利品分类表和争议解决流程。作者提醒指挥官，公平的分配不是让每个人都满意，而是让每个人都觉得过程是可预期的。书中还建议设置一个中立的记录员，负责登记每一件战利品的归属，减少事后扯皮。此外，对于特别珍贵的物品，作者建议采用公开抽签或轮流优先权制度。许多老佣兵会把这本书放在行囊最深处，每次签合同前都翻一翻。

## 设计意图

把队伍管理与战利品系统结合，增加角色满意度与忠诚度维度，让领导力影响长期队伍建设。
