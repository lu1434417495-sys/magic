# 《指挥官凝视：看见就是控制》

## 基础信息

- **书籍 ID**：`book_指挥号令_0037`
- **关联技能**：`leadership_commanders_gaze`
- **使用效果**：阅读后解锁 `leadership_commanders_gaze`；若已学会，提升该技能 `current_mastery +95`，并延长下次凝视的标记持续时间 1 回合（一次性）。
- **阅读要求**：无职业限制；基础 `感知 ≥ 10` 或 `智力 ≥ 9`。
- **稀有度**：稀有（Rare）
- **建议投放**：鹰眼瞭望塔、战术观测站、高级商人。

## 书籍内容

书的封面是一只被刻进金属板的大眼睛，瞳孔位置嵌着一片透明水晶。作者把指挥官凝视定义为"用观察代替呼喊的指挥方式"。书中认为，最高效的指挥官往往不是话最多的人，而是能在混乱中持续看清关键目标的人。凝视一旦锁定某个敌人，全队对该目标的伤害和命中率都会获得加成，因为每个人都知道"这是此刻最重要的事物"。第二章讲解了如何对抗敌人的"反凝视"技巧——有些高阶敌人会通过幻象或快速移动让指挥官的目光无法停留，这时需要借助队友的视野接力。最末页是一张被反复折叠的战场速绘图，几个关键单位被圈出又划掉，旁边写着："指挥官的眼睛，是战场上最贵的资源。"金属板背面还有一行被摩挲得发亮的刻痕："看见敌人之前，先看见自己的队友。"水晶边缘有一道细小的裂纹，据说是某位指挥官过度凝视而被反噬时留下的痕迹。

## 设计意图

为高感知/智力型指挥官提供目标标记与团队增益结合的技能，将视野控制转化为战斗效率，强化信息优势主题。
