# 《士气提振》

## 基础信息

- **书籍 ID**：`book_leadership_0061`
- **关联技能**：`leadership_morale_boost`（待新增，标签 `leadership`）

- **阅读要求**：角色职业标签含 `paladin`、`bard` 或 `commander`；基础 `魅力 ≥ 10`。

## 书籍内容

《士气提振》认为，士兵的肉体可以训练，但精神的裂缝往往更难修补。作者把士气比作水壶里的水：平时慢慢积累，战时快速消耗，而指挥官就是那个在关键时刻拧紧壶盖的人。书中列举了五种常见的士气崩塌信号：过度沉默、反复查看后方、武器握姿变形、对号令反应迟缓、以及最危险的——突然过度兴奋。作者强调，提振士气不是靠喊口号，而是靠具体行动：出现在正确位置、说出敌人下一步会做什么、让每个人知道自己不是孤军奋战。书中还提供了一组简短演说模板，作者建议指挥官根据自己的性格改写，因为 borrowed 的台词听起来比沉默更糟。作者同时提醒，提振士气后应尽快给出具体任务，空洞的热情若没有行动承接，会迅速冷却为怀疑。最后一章讲述"虚假士气"的危害：用谎言维持的勇气会在真相揭露时加倍反噬。书末附有一幅插图，画着一名指挥官跪在重伤士兵身旁，声音低沉却清晰。

## 设计意图

引入士气与心理层面的指挥技能，让魅力型角色在控场与输出之外承担团队稳定职责。解除恐惧并提升攻击，形成攻防一体的支援节奏。
