# 《守城物资统筹》

## 书籍内容

《守城物资统筹》是一本关于如何在围城期间维持城防资源的书。作者指出，城墙再高也挡不住物资耗尽。书中从库存盘点讲起，详细介绍了箭矢、滚木、热油、石块、粮食、饮水和药品的储备标准与轮换方法。手册强调，守城物资必须分散存放，避免一次火灾或一次投石攻击就毁掉全部储备。后半部分讨论了物资配给的优先级：战斗人员优先、伤员其次、平民最后，但也要防止平民因绝望而引发动乱。最末一章附有一份围城物资消耗估算表，帮助指挥官预判还能坚持多久。作者还建议提前储备修理城墙的材料和工具，因为破损的城墙会让所有物资储备失去意义。书中还提醒，水源储备是守城中最容易被忽视却最关键的部分，一旦断水再多粮食也无济于事。作者提醒，守城战的胜利往往属于更能坚持的一方，而坚持的前提是有人一直在计算。

## 设计意图

为防守玩法提供资源管理维度，让守城战成为考验长期规划而非单纯即时战斗的内容。
