# 《狂战引导：让愤怒有方向》

## 基础信息

- **书籍 ID**：`book_指挥号令_0044`
- **关联技能**：`leadership_berserk_channel`
- **使用效果**：阅读后解锁 `leadership_berserk_channel`；若已学会，提升该技能 `current_mastery +95`，并提高下次引导时狂战士的伤害转化率 10%（一次性）。
- **阅读要求**：角色职业标签含 `berserker` 或 `warrior`；基础 `力量 ≥ 10` 或 `意志 ≥ 9`。
- **稀有度**：稀有（Rare）
- **建议投放**：狂战士祭坛、血腥竞技场、部落商人。

## 书籍内容

书的封面是一块被指甲抓出痕迹的厚皮，仿佛之前的读者在阅读时也曾陷入狂躁。作者把狂战引导定义为"给愤怒画一条通往敌人的渠"。书中指出，狂战士最强大的时刻也是最危险的时刻，因为他们会失去对友军位置的感知。指挥官的任务不是压抑这种愤怒，而是用一个简单、重复、声音足够大的指令把愤怒引向正确目标。第二章讲解了"狂战锚点"：在狂战士冲入敌阵前，由一名可靠的队友用绳索或约定手势与其建立联系，确保他在迷失方向时能循着锚点返回。作者警告说，引导狂战士最忌命令复杂，他们的大脑在狂怒中只能处理一个词或一个方向。最末页是一幅被血涂抹的简笔画，一个巨大人影追着一只被标红的小人，配文："让他追对人，比让他停下更重要。"厚皮封底还粘着一缕被扯断的绳索，是某位锚点队友留下的最后联系。

## 设计意图

为狂战士职业提供团队控制入口，将力量/意志转化为愤怒导向能力，强化高风险高回报职业的可用性。
