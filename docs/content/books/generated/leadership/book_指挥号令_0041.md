# 《法术同步：让咒语在同一拍落下》

- **书籍 ID**：`book_指挥号令_0041`
- **关联技能**：`leadership_spell_sync`
- **使用效果**：阅读后解锁 `leadership_spell_sync`；若已学会，提升该技能 `current_mastery +95`，并提高下次同步施法时的元素共鸣伤害 10%（一次性）。

- **建议投放**：魔法学院合奏厅、元素圣殿、灵能商人。

## 书籍内容

书的封面是一张被烧得卷曲的乐谱，音符位置被替换成了法术符文。作者把法术同步定义为"让多名施术者的咒语像合唱一样在同一瞬间完成"。书中指出，同步的关键不在于每个人的法术有多强，而在于所有人能否在同一拍释放，因为同时命中的法术会在目标身上产生元素共鸣，造成额外效果。第二章讲解了"同步咒语"：指挥官或主法师会先吟唱一个长音节作为节拍器，其他法师根据这个音节调整自己的施法速度。作者警告说，同步最忌有人临时改变法术，因为不同法术的引导时间会破坏整个节奏。后半本记录了常见的元素共鸣组合：火加风形成爆燃，冰加雷形成麻痹，土加水形成泥沼。最末页贴着一张被魔力灼穿的排练表，上面有几个名字被划掉，批注："同步不是为了华丽，是为了让敌人在同一秒里面对所有灾难。"乐谱背面还留着一片被烧毁的袍角，据说是某次同步失败时唯一的遗物。

## 设计意图

为法师队伍提供协同施法机制，将智力同步转化为元素共鸣收益，强化多法系阵容的组合技深度。
