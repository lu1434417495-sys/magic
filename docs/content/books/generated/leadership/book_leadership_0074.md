# 《压制火力》

## 基础信息

- **书籍 ID**：`book_leadership_0074`
- **关联技能**：`leadership_suppression_fire`（待新增，标签 `leadership`）
- **使用效果**：阅读后学会指挥技能 `leadership_suppression_fire`，可命令远程友方向指定区域倾泻火力，区域内敌人下回合命中率下降并可能被打断施法。
- **阅读要求**：角色职业标签含 `archer`、`ranger` 或 `gunslinger`；基础 `敏捷 ≥ 10`。

- **建议投放**：射手阵地、军械库、攻城战任务奖励。

## 书籍内容

《压制火力》主张，弓箭手的价值不只在击杀，更在于让敌人抬不起头。作者将压制定义为"用持续威胁换取敌人行动质量下降"，而非单纯的伤害输出。书中详细讲解了压制区域的划分：对施法者密集区压制以打断吟唱，对冲锋路径压制以降低命中率，对阵地制高点压制则纯粹为了争夺视野。作者强调，压制需要弹药或法力的持续投入，指挥官必须权衡压制的成本与收益。书中还讨论了压制与杀伤的平衡：过度追求击杀会分散火力，反而失去压制效果；过度压制而不杀伤则会让敌人适应节奏。最后一章警告，压制火力的射手位置一旦暴露，就会立刻成为敌方优先清除目标。作者建议压制组应准备多个备用射击点，并在每次齐射后主动转移，让敌人无法精确定位。书末附有一张火力分配图，用不同颜色标出压制区、杀伤区与机动通道。

## 设计意图

为远程职业提供区域 debuff 能力，让火力控制成为战术选择。降低命中率与打断施法的效果，专门克制依赖精确打击的敌人。
