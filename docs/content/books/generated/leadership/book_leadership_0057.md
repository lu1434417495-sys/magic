# 《冲锋号令》

## 书籍内容

《冲锋号令》对"冲锋"二字怀有近乎宗教般的敬意。作者认为，一次成功的冲锋取决于节奏而非蛮勇：起步要慢，让队伍保持密集；中段加速，积累势能；最后三十步全力冲刺，把动能转化为冲击力。书中详细规定了号令的音色与间隔，低音鼓点对应起步，急促铜管对应加速，号角长鸣则是最后冲刺的信号。作者警告，冲锋最忌讳的是队列散掉——一旦士兵开始各自为战，冲锋就会退化成一群人的奔跑。书中还分析了地形影响：下坡可以放大冲击，但也会增加失控风险；上坡则几乎不适合任何形式的冲锋。作者在脚注中补充，雨天或泥泞地面会让冲锋效果大打折扣，甚至让队伍在抵达敌阵前就已经耗尽体力。最后一章讨论收势，因为真正决定胜负的往往不是撞上去的那一刻，而是撞穿敌阵后能否迅速重整。书末画着一道楔形队形切开敌方战线的瞬间，尘土与呐喊仿佛要从纸面喷出。

## 设计意图

为进攻型职业提供爆发性的集体突进手段。冲锋的攻击力与撞击加成鼓励玩家在合适的时机放弃保守站位，主动撕裂敌方阵型。
