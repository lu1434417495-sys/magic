# 《冲锋信号：一拥而上的默契》

## 基础信息

- **书籍 ID**：`book_指挥号令_0018`
- **关联技能**：`leadership_charge_signal`
- **使用效果**：阅读后解锁 `leadership_charge_signal`；若已学会，提升该技能 `current_mastery +90`，并提高下次冲锋的首轮命中加成 10%（一次性）。
- **阅读要求**：角色职业标签含 `warrior`、`berserker`、`paladin` 或 `knight`；基础 `力量 ≥ 8` 或 `敏捷 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：骑兵营地、冲锋训练场、近战商人。

## 书籍内容

书的封面画着一排向前倾斜的长矛，矛尖指向同一处虚空。作者认为冲锋不是跑得快，而是"在同一时间把重量压到同一条线上"。书中提出"启动三判"：判距离，确保敌人在两回合内无法重新布阵；判体力，确认至少能完成一次完整攻击；判信号，保证所有人对启动音或旗语的理解一致。第二章讲解了冲锋中的"呼吸锁"——在接触敌人的前一秒屏住呼吸，能让身体在撞击瞬间保持刚性。作者警告说，最有害的冲锋是"半速冲锋"，那会让前排独自承受反击而后排还落在后面。最末页是一张被马蹄踏裂的羊皮纸，上面只画着一条向前延伸的粗线和三个并排的箭头，批注："犹豫的冲锋比撤退更致命。"羊皮纸边缘还沾着一片干涸的草浆，仿佛某匹战马在冲锋前最后一次踏足青草地时留下的痕迹。草浆旁边有一行小字："冲锋的尽头不是荣耀，是所有人同时到达的位置。"

## 设计意图

为近战职业提供团队同步爆发入口，将个体冲锋扩展为需要时机把控的集体技能，强化先手压制战术。
