# 《护卫轮换》

## 书籍内容

《护卫轮换》的核心观点是：没有人能永远站在最前面，但总有人应该站在最前面。作者将轮换视为一门精确的舞蹈，两名护卫需要在不暴露背后空当的情况下完成位置交换。书中详细规定了动作顺序：先由接替者上前半步并用盾牌制造屏障，再由原护卫借势后撤，整个过程不应超过一次呼吸的时间。作者警告，轮换最忌犹豫——半退不退的姿势会让两个人同时成为靶子。书中还分析了不同体型与武器的轮换难度：重甲长枪兵最难快速换位，因此需要更早启动轮换；双持轻甲战士则可以在更极限的时刻完成。最后一章讨论心理层面：被轮换下来的护卫不应感到羞耻，轮换是战术需要，不是能力否定。作者建议指挥官在每次成功轮换后简短肯定两人的配合，以维持护卫之间的信任。书末附有一张两人轮换的连续动作图。

## 设计意图

为战棋提供灵活的前排调度能力，让指挥官能够动态保护关键目标。位置交换与伤害减免的组合，适用于紧急救援与战术重组。
