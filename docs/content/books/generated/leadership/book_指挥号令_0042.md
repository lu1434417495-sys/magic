# 《急行军：在敌人喘气时到达》

## 基础信息

- **书籍 ID**：`book_指挥号令_0042`
- **关联技能**：`leadership_quick_march`
- **使用效果**：阅读后解锁 `leadership_quick_march`；若已学会，提升该技能 `current_mastery +85`，并减少下次急行军后的疲劳惩罚 20%（一次性）。
- **阅读要求**：无职业限制；基础 `敏捷 ≥ 8` 或 `体质 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：传令兵驿站、快速反应部队营地、通用商人。

## 书籍内容

书的封面是一双被磨穿鞋底又重新钉上铁掌的靴子。作者把急行军定义为"用纪律换取时间"。书中指出，急行军不是跑得最快，而是保持队形的前提下跑得比敌人预期的快。第二章讲解了"行军的呼吸"：指挥官必须让队伍在加速与恢复之间找到节奏，否则到达目的地时所有人都无法立即投入战斗。作者提出了一种被称为"三段速"的方法：第一段用正常步速热身，第二段用快步逼近目标，第三段在接敌前五十步恢复呼吸并整理武器。书中还警告说，急行军最忌被小股敌人拖住，哪怕只是耽误几分钟，也会让整个计划失去意义。最末页是一张被汗水浸透的行军时刻表，某个时间点被重重圈出，旁边写着："我们不是在赶路，我们是在偷时间。"靴子图案的靴底还刻着一句小字："每一步都要落在队友能跟上的地方。"

## 设计意图

为指挥号令系列提供战术机动技能，将敏捷/体质转化为战场位置优势，强化战棋中的时间压力与地图控制。
