# 《优先救援：先救谁，后救谁》

## 基础信息

- **书籍 ID**：`book_指挥号令_0021`
- **关联技能**：`leadership_aid_priority`
- **使用效果**：阅读后解锁 `leadership_aid_priority`；若已学会，提升该技能 `current_mastery +90`，并提高下次救援指令的治疗效果 10%（一次性）。
- **阅读要求**：无职业限制；基础 `智力 ≥ 8` 或 `感知 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：战地医护营、救援任务奖励、通用商人。

## 书籍内容

这本书的封面是一把折断后被布条缠紧的短剑，象征着在废墟中把人拉出来。作者认为救援不是道德本能，而是需要排序的战术动作。书中提出了"救援三角"：先救能恢复战斗力的人，再救能维持阵型的人，最后救无法立即回归战线的人。第二章讲解如何识别"假死"——有些伤员看似还有一口气，实际上已经透支了所有反击能力，救援他们会消耗宝贵资源。作者还警告指挥官不要被哭声或熟悉的面孔影响判断，因为情绪会制造虚假的优先级。后半本是一系列战场急救手势，每个手势都能在无法出声时传递伤员状态。最末页贴着一张被泪水泡花的纸条，上面只有三个字："谢谢你。"没有人知道是谁写的。纸条下方还压着一枚被掰弯的铜纽扣，据说是某位被救者在临终前从衣襟上扯下来，塞进救援者手心的。

## 设计意图

为指挥者提供治疗资源调度技能，将智力/感知转化为救援优先级判断能力，强化战棋中的资源分配深度。
