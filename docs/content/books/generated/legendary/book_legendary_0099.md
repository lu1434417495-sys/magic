# 《禁术：终焉咏叹调》

## 基础信息

- **书籍 ID**：`book_legendary_0099`
- **关联技能**：`legendary_final_aria`
- **使用效果**：阅读后解锁 `legendary_final_aria`；若已学会，提升 `current_mastery +170`，并允许咏唱终焉之曲，对生命值低于 15% 的敌人造成即死判定。
- **阅读要求**：角色职业标签含 `bard` 或 `mage`；基础 `智力 ≥ 16`、意志 `≥ 15`。
- **稀有度**：传说（Legendary）
- **建议投放**：终焉歌剧院、吟游诗人商人、谢幕任务奖励、传说级宝箱。

## 书籍内容

终焉咏叹调是一首为濒死者写的歌。书中说，每个生命在结束前都会有一小段空白的旋律，而修习者要学会用声音填满那段空白，让它变成真正的休止符。当咏唱达到最高音时，生命值岌岌可危的敌人会听见自己生命的伴奏戛然而止。古籍警告，这首歌也会吸引冥界的听众，有时它们会顺着歌声来到现世。书页上有一行被泪水晕开的乐谱，旁边写着：「不要为强者唱，他们听不见；要为将倒者唱，他们才会接。」

终焉咏叹调的最后一个音符会让空气变得安静，连风声都会停止。那两秒的寂静里，濒死者往往会看见自己一生的画面，而旁观者只能看见施术者嘴唇微微张开。

终焉咏叹调的最后一声会让周围所有光源短暂熄灭。那黑暗持续的时间越长，说明濒死者的生命曾经越为沉重。

有经验的施术者会通过这短暂的黑暗，判断敌人是否值得被这首咏叹调终结。

## 设计意图

提供斩杀型技能，对低血量敌人构成威慑，强化吟游诗人/法师的终结能力。
