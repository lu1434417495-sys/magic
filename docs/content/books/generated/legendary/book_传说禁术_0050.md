# 《末日启示录》

## 基础信息

- **书籍 ID**：`book_传说禁术_0050`
- **关联技能**：`legendary_apocalypse_revelation`
- **使用效果**：阅读后解锁 `legendary_apocalypse_revelation`；若已学会，提升 `current_mastery +150`，并一次性解锁 5 条新的 `known_knowledge_ids`（末日学相关），同时允许组合释放部分传说禁术。
- **阅读要求**：无职业限制；基础 `感知 ≥ 16`、意志 `≥ 16`；角色 `known_knowledge_ids` 数量 ≥ 10。
- **稀有度**：传说（Legendary）
- **建议投放**：末日图书馆、世界残骸密室、隐藏主线终极奖励、全知者宝箱。

## 书籍内容

记录世界终焉知识的禁书。书中没有直接技能，而是记载如何解读末日征兆。阅读后会解锁大量 known_knowledge_ids，并允许玩家在特定条件下发动组合禁术。作者声称，这本书的每一页都来自不同世界的残骸。读完最后一页时，读者会听见远方传来的号角声。作者用颤抖的笔迹写道："知道末日的人，无法阻止末日，只能决定自己站在哪一边。"

末日启示录的每一页材质各不相同，有的像树皮，有的像金属，有的像干涸的血。据说集齐所有碎片的人，能在终焉来临时选择自己的姿态。

末日启示录的最后一张碎片至今下落不明，有人说它藏在某个尚未毁灭的世界的黎明之中。

末日启示录的材质碎片会在世界发生灾难时发热，持有者能通过温度判断下一场末日将从哪个方向降临。

温度渐升，意味着下一场末日正在某处悄然孕育。

## 设计意图

作为知识型传说禁术的集大成者，解锁机制与组合技，服务于终局构筑。
