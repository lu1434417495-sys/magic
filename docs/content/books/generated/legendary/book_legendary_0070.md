# 《禁术：百兵冢》

## 基础信息

- **书籍 ID**：`book_legendary_0070`
- **关联技能**：`legendary_hundred_weapon_tomb`

- **阅读要求**：角色职业标签含 `warrior` 或 `weapon_master`；基础 `力量 ≥ 15`、敏捷 `≥ 14`。

## 书籍内容

百兵冢是一本关于如何让死去的武器继续战斗的书。书中记载，每一件被折断的兵器都残留着主人的一部分战意，只要施术者能以血为引，便能唤醒它们。战场上会浮现出无数半透明的刀、剑、枪、戟，它们不会完全受控，却会自动攻击任何靠近施术者的敌人。古籍中间有一幅战场全景图，图上每个光点都代表一柄被唤醒的残兵。作者警告：唤醒的兵器越多，施术者越容易被它们的战意吞噬，最终变成一具只知道挥舞双臂的空壳。

百兵冢唤醒的兵器无法分辨现代盔甲与古代战甲，它们只认血的味道。一位穿着博物馆复制品参加宴会的贵族曾因此丧命，引发了对古战意研究长达十年的禁令。

百兵冢唤醒的兵器在战斗结束后会互相撞击，发出类似送葬队伍的哀鸣。那声音会持续到天亮，让附近村庄的居民彻夜难眠。

## 设计意图

为近战职业提供范围反击与控场能力，增强被围困时的生存能力。
