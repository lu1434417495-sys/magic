# 《灰烬禁咒：焚世余烬》

- **书籍 ID**：`book_传说禁术_0012`
- **关联技能**：`legendary_ashen_world_incineration`
- **使用效果**：阅读后解锁 `legendary_ashen_world_incineration`；若已学会，提升 `current_mastery +200`，并在下一次战斗中使该技能对自身的友伤降低 30%。
- **阅读要求**：角色职业标签含 `mage` 或 `pyromancer`；已学会 `ashen_step` 或任意灰烬交界技能。

- **建议投放**：灰烬交界核心、余烬祭所禁室、焚毁大圣堂、传说级灰烬宝箱。

## 书籍内容

来自灰烬交界的终极火咒。书中描述，交界处的灰烬并非燃烧后的残渣，而是尚未燃尽的世界碎片。施术者将这些碎片收集进胸腔，再用咒术释放出去，形成一片持续焚烧的领域。该咒会同时伤害敌我，只有熟悉灰烬步的施术者才能安全穿行。书页被烧出无数小孔，光线穿过时像星空。末页警告：当你觉得灰烬温暖，它就已经在烧你了。

灰烬禁咒原典由焦黑金属页装订，翻页时指节会被余温灼痛。传说每一页都来自一个已被焚毁的世界，灰烬中偶尔能读出未燃尽的地名。

焚世余烬的灰烬样本被保存在封底的夹层中，靠近时会感到皮肤轻微灼痛。

焚世余烬的灰烬样本在月圆时会发出暗红色微光，靠近者会梦见自己被火舌追逐。

靠近者常被噩梦惊醒，梦见自己化作尚未燃尽的世界碎片。

## 设计意图

深化灰烬交界的高阶魔法威胁，为火法提供标志性的敌我不分领域技。
