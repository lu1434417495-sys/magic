# 《禁术：枯萎圣印》

- **书籍 ID**：`book_legendary_0071`
- **关联技能**：`legendary_withered_seal`

- **阅读要求**：角色职业标签含 `priest` 或 `dark_cleric`；基础 `意志 ≥ 15`、智力 `≥ 13`。

## 书籍内容

枯萎圣印是一本让圣光腐烂的书。书中说，光本身没有善恶，但当它照射到不愿被照亮的事物上时，便会变成一种灼烧。修习者需将圣印倒转，让光芒从内部开始枯萎，变成一团团灰黑色的斑点。被这种枯萎圣印击中的人不会感到灼痛，只会感到生命力像被霉菌慢慢覆盖一样流逝。古籍的纸张出奇地干燥，翻动时会发出枯叶碎裂的声音。最后一页有一行被反复涂抹的字：「我曾治愈千人，如今只想让一人永远沉睡。」

枯萎圣印的斑点在击中活人后会缓慢蔓延，但只要受害者诚心忏悔，斑点便会停止。教会内部因此争论不休：这究竟是仁慈，还是一种更为残酷的审判。

枯萎圣印的斑点在圣徒身上会呈现金色而非灰黑，教会对此的解释至今未统一，有人视为神恩，有人视为最严厉的警告。

教会内部的争论至今未休，每隔几十年便会爆发一次针对枯萎圣印修习者的审判。
