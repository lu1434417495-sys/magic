# 《禁术：腐化龙息》

- **书籍 ID**：`book_legendary_0078`
- **关联技能**：`legendary_corrupt_dragon_breath`

- **阅读要求**：角色职业标签含 `warrior` 或 `berserker`；基础 `体质 ≥ 16`、力量 `≥ 14`。

- **建议投放**：腐龙巢穴、龙裔商人、屠龙任务奖励、传说级宝箱。

## 书籍内容

腐化龙息是一本让凡人学会像龙一样吐息的书。书中记载，龙息不是火焰，而是龙体内某种古老物质的呕吐。修习者需吞下一小块腐化龙晶，让那种物质在胃中扎根，然后在战斗中将它逆涌而出。喷出的气息不会立刻烧死敌人，而是像酸液一样附着在他们身上，缓慢溶解护甲与血肉。古籍警告，龙晶会在体内继续生长，许多修习者最终从喉咙里长出了鳞片。书页上有一股淡淡的硫磺味，翻动时会让人咳嗽。

腐化龙息修习者的呼吸会永久带有硫磺味，靠近时花草会迅速枯萎。 dragonborn 视这种气息为一种耻辱，认为它玷污了龙族的高贵血统。

腐化龙息修习者死后，其遗体无法被普通火焰火化，必须从龙墓取来一种特殊的灰才能让其安息。 dragonborn 视此为最后的耻辱。

龙族的长老议会曾多次派出猎杀队，追捕那些胆敢修习腐化龙息的人类。

为近战职业提供范围持续伤害，拓展物理职业的 AoE 能力。
