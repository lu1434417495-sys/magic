# 《禁术：万魂朝宗》

## 书籍内容

万魂朝宗是一本关于如何向死者借兵的书。书中记载，战场上残留的亡魂并非无家可归，而是被死亡本身的秩序钉在原地。施术者需以自身为祭坛，用血液在地上画出一个倒置的往生阵，然后念诵阵亡者的名字——不是全部，只要足够多。那些名字会化作苍白的火线，从四面八方汇聚到施术者身上，再被一次性释放出去。古籍提醒，借来的魂魄只认声音不认人，若念错名字，火线会反噬自身。书末附有一张密密麻麻的名录，许多名字被划掉，旁边写着「已还」。

万魂朝宗念诵的名字若与施术者同姓，火线会格外明亮。许多家族因此将这本书列为禁物，担心祖先的亡魂会被不肖子孙当作燃料烧尽。

每年的阵亡纪念日，万魂朝宗的书页会自动渗出水珠，像书本身在哭泣。那些水珠收集后可以当作微弱的灵魂燃料使用。
