# 《影缚术》

## 基础信息

- **书籍 ID**：`book_传说禁术_0022`
- **关联技能**：`legendary_shadow_binding`
- **使用效果**：阅读后解锁 `legendary_shadow_binding`；若已学会，提升 `current_mastery +160`，并在下一次战斗中让影缚持续时间延长 1 回合。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `敏捷 ≥ 14`、感知 `≥ 12`。
- **稀有度**：传说（Legendary）
- **建议投放**：影之集市、缚影师密室、地下竞技场奖励、盗贼公会高阶任务。

## 书籍内容

用影子编织锁链束缚敌人的盗贼禁术。书中解释，每个人都有影子，而影子是身体最诚实的部分。施术者可以把自己的影子伸长，缠住敌人的脚踝或手腕，使其无法行动。束缚时间越长，自己的影子越稀薄。若影子完全消失，施术者会陷入失明状态。书中夹着几缕黑色丝线，摸上去像冷却的沥青。末页警告：别在正午使用，你的影子会不够长。

影缚术的影子丝线只能在无光处抽出，月光下会融化成黑色露水。被束缚者通常不会立刻察觉，直到试图迈步才发现脚踝已与黑暗连在一起。

影缚术的黑色丝线若存放过久，会自行缠绕成某个熟悉却叫不出名字的形状。

影缚术的丝线无法被利器割断，只能用施术者自己的一滴眼泪溶解，因此使用者往往越用越沉默。

眼泪越来越珍贵，因为每次使用都需要献祭真实的悲伤。

## 设计意图

为盗贼系补充强控手段，用自身视觉风险限制连续控制。
