# 《禁术：谎言之种》

## 书籍内容

谎言之种是一本教人如何在别人心里种假话的书。书中说，每个人的意识都是一片土壤，只要找到最柔软的一处，把一粒谎言埋进去，它就会自己生长。施术者需在敌人分心的一瞬间，将一段虚假的认知射入对方脑海——比如「你的盟友是敌人」或「敌人已经逃跑」。古籍警告，说谎者也会被谎言反噬，许多修习者最终分不清哪些记忆是自己的，哪些是别人种下的。书页上有一幅脑部剖面图，某个区域被画成了一棵小树的形状。

谎言之种发芽后，宿主的眼球会出现细小的根须状血丝。经验丰富的猎巫人会随身携带镜子，不是为了检查妆容，而是为了确认自己是否已被种下。

谎言之种在宿主体内生长时，会不断吸收其真实的记忆作为养分。待到成熟时，宿主会变成一颗行走的种子，只懂得传播谎言。
