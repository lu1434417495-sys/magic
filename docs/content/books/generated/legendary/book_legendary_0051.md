# 《禁术：轮回裂隙》

## 基础信息

- **书籍 ID**：`book_legendary_0051`
- **关联技能**：`legendary_reincarnation_rift`
- **使用效果**：阅读后解锁 `legendary_reincarnation_rift`；若已学会，提升 `current_mastery +160`，并在下一次战斗中可让一名已阵亡友方单位以残影形态发动一次攻击。
- **阅读要求**：无职业限制；基础 `智力 ≥ 15`、意志 `≥ 15`；角色 `known_knowledge_ids` 数量 ≥ 3。
- **稀有度**：传说（Legendary）
- **建议投放**：轮回神殿密室、世界裂缝奖励、全知商人、隐藏主线任务。

## 书籍内容

轮回裂隙是一门向死者借力的禁术。书中记载，施术者需在战场中找到生与死的夹缝，以自身记忆为诱饵，将某位逝去者的战斗本能短暂拉回现世。那一瞬，逝者不会真正复活，只会化作一道半透明的残影，顺着施术者指引的方向挥出最后一击。古籍警告，裂隙打开的时间越长，施术者越容易被轮回的潮汐带走——许多修习者最终消失在自言自语中，声称看见了前世的自己。书页边缘画满不规则的螺旋，像是有人曾用指甲一遍遍刻下同一个名字。最后一行用褪色墨水写着：「借来的刀，终究要还。」

古籍的装订线是用某种银色发丝捻成，每当有人读到此处，发丝便会微微收紧。有收藏者声称，午夜独读时能听见纸页间传来刀剑出鞘的回响，仿佛那些借来的战魂仍在寻找归还的方向。

修习者若在同一个月内三次阅读此书，发丝会开始缠绕手指，形成一圈圈螺旋状的勒痕。

## 设计意图

为后期构筑提供一次性的战术复活/补刀机会，强化记忆与知识的叙事权重。
