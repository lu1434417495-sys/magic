# 《禁术：贪婪金库》

## 基础信息

- **书籍 ID**：`book_legendary_0082`
- **关联技能**：`legendary_greedy_vault`
- **使用效果**：阅读后解锁 `legendary_greedy_vault`；若已学会，提升 `current_mastery +150`，并允许消耗金币发动财宝轰击，金币越多伤害越高。
- **阅读要求**：无职业限制；基础 `幸运 ≥ 12`、智力 `≥ 12`；角色持有金币 ≥ 1000。
- **稀有度**：传说（Legendary）
- **建议投放**：黄金深渊、贪婪商人、富翁任务奖励、传说级宝箱。

## 书籍内容

贪婪金库是一本教人把钱变成武器的书。书中记载，金币本身没有力量，但人们对金币的渴望却有。施术者需将一把金币抛向空中，然后念出一段让渴望具现化的咒语。那些金币会在空中熔化成金色的雨滴，每一滴都携带着观看者的贪欲，落在敌人身上时比箭矢更锋利。古籍警告，使用这门技艺会让周围所有人对你产生莫名的敌意——毕竟没有人喜欢看见别人烧钱。书页边缘贴着几枚已经发黑的硬币，似乎曾被反复熔化又凝固。

贪婪金库消耗的金币不会真正消失，而是会出现在某个深渊生物的胃袋里。这些生物偶尔会把金币反吐回人间，形成所谓的「血钱」，拥有者往往会在一年内破产。

贪婪金库消耗的金币会在施术者身上留下细小的金色纹路，纹路越多，施术者越容易被深渊生物当作同类或猎物。
