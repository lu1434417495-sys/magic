# 《焚心咒》

## 基础信息

- **书籍 ID**：`book_传说禁术_0002`
- **关联技能**：`legendary_heart_incineration_curse`
- **使用效果**：阅读后解锁 `legendary_heart_incineration_curse`；若已学会，提升 `current_mastery +170`，并将该技能首次施放时的法力消耗减半。
- **阅读要求**：角色职业标签含 `mage` 或 `warlock`；基础 `智力 ≥ 15`、意志 `≥ 12`。
- **稀有度**：传说（Legendary）
- **建议投放**：焚毁书库、黑市禁咒商人、火山遗迹密室、高阶法师委托。

## 书籍内容

禁术火焰从心脏点燃。内容讲述如何在胸腔内构建一座微型熔炉，将情绪作为柴薪。咒语不需要吟咏，而是需要愤怒。书中列出的第一个练习对象竟是一面镜子，要求施术者凝视自己直到眼底出现火光。警告：焚心咒一旦失控，会先从记忆开始燃烧，许多高阶法师因此忘记了为何而战。封底有一张烧焦的肖像，面容已无法辨认。末尾写道："烧尽敌人之前，先确认自己还剩多少。"

焚心咒的抄本总是带着焦味，翻页时能看到纸页边缘卷曲发黑。许多法师在练习时被自己的记忆烧伤，最终选择在熔炉旁自我了结。

焚心咒最早被发现于一座被焚毁的法师塔残骸中，塔主的焦尸仍紧握着最后一页。

如今焚心咒原典被封印在熔岩井底，只有戴上防火手套才能翻阅前三章。

翻开时书脊微微发热，仿佛余烬仍在纸张下呼吸。

## 设计意图

作为法师系情绪驱动型禁咒的基石，强化法术代价与角色扮演之间的张力。
