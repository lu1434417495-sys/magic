# 《魔纹锻体》

## 基础信息

- **书籍 ID**：`book_传说禁术_0018`
- **关联技能**：`legendary_demon_rune_body`
- **使用效果**：阅读后学会修炼技能 `legendary_demon_rune_body`（`practice_tier = legendary`），AURA 上限提升 25%，并获得基于 AURA 的物理减伤光环。
- **阅读要求**：无职业限制；基础 `力量 ≥ 14` 或 `体质 ≥ 14`；已学会任意中级炼体。
- **稀有度**：传说（Legendary）
- **建议投放**：恶魔遗迹熔炉、烙印师巢穴、深渊锻体圣地、禁忌纹身商人。

## 书籍内容

以恶魔符文烙印肉身的炼体禁术。书中主张，AURA 可以像纹身一样被刻进皮肤，成为永久的防护层。修习者需在满月下用烧红的烙铁将符文印入肌肉，成功者刀枪不入，但夜间会被符文灼痛惊醒。作者提醒，符文会自己选择位置，不能强行指定。书中附有多幅人体图，每幅图上的符文位置都不同。末页用血写着："皮肤记得一切。"

魔纹锻体的烙印模板由恶魔铁匠打造，每次烙印都会改变模板形状。因此无人能复制完全相同的符文，每个人的身体都成为独一无二的禁术容器。

魔纹锻体的烙印模板在每次使用后都会轻微变形，留下无法复制的独特齿痕。

魔纹锻体的符文会在使用者死后继续生长，将尸体变成一具布满发光纹路的禁忌标本。

标本仍保持睁眼，眼中的符文微光百年不灭。

纹路永不褪色。

## 设计意图

为近战/坦克职业提供 AURA 驱动的防御向功法，强化生存与代价主题。
