# 《禁术：星陨契约》

- **书籍 ID**：`book_legendary_0062`
- **关联技能**：`legendary_meteor_pact`

## 书籍内容

星陨契约是一本向星空借钱的书。书中记载，每一颗流星都是某个世界燃烧殆尽前的最后一声叹息，而施术者可以用自己的全部魔力作为代价，召唤那声叹息落在敌人头顶。契约的仪式很简单：在晴朗的夜空下伸出手掌，念出目标的名字，然后等待。流星会回应你，但它不会替你选择落点——若你念错名字，或者目标在流星到达前移动，毁灭会落在你自己身上。古籍封皮烧焦了一半，露出里面密密麻麻的星图，每一张图上都用红叉标着「失败」。

星陨契约的星图最后一角缺失，许多人相信那正是施术者自己所在的世界。每一笔契约的完成，都意味着某个世界少了一颗流星，而这边夜空多了一道无法解释的暗斑。

每完成一次星陨契约，施术者会在梦中收到一封来自星空的回信。回信内容通常只有一个词，比如「收到」「再见」或者「谢谢」。
