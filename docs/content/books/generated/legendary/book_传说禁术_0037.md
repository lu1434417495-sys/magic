# 《禁术：记忆剥离》

## 基础信息

- **书籍 ID**：`book_传说禁术_0037`
- **关联技能**：`legendary_memory_stripping`
- **使用效果**：阅读后解锁 `legendary_memory_stripping`；若已学会，提升 `current_mastery +170`，并在下一次战斗中让被剥离敌人 1 回合内无法使用最高熟练度技能。
- **阅读要求**：角色职业标签含 `mage` 或 `warlock`；基础 `智力 ≥ 16`、感知 `≥ 12`。
- **稀有度**：传说（Legendary）
- **建议投放**：记忆图书馆、疯狂学者密室、遗忘之城遗迹、知识猎人任务。

## 书籍内容

从敌人脑中剥夺知识的禁术。书中说，知识是有形的，可以被手指勾出。施术者需在敌人意识薄弱时探入其记忆，窃取特定技能或信息。被剥离者会短暂失忆，而剥离者会承受对方记忆的碎片。作者警告，不要窃取疯狂者的记忆，否则那些碎片会污染你自己。书中夹着几块颜色各异的记忆碎片状玻璃。

记忆剥离后，被取走的知识会以玻璃碎片形式悬浮在施术者掌心，颜色越鲜艳，记忆越危险。长期收集者最终会被这些碎片割伤思维。

记忆剥离的玻璃碎片在暗处会彼此碰撞，发出类似窃窃私语的清脆声响。

记忆剥离的玻璃碎片若被镶嵌在武器上，武器会偶尔自主挥动，仿佛某个被遗忘的记忆仍在寻找归处。

记忆在武器中寻找宿主，偶尔会在午夜发出低语。

碎片渴望归主。

切记。

慎之。

遗忘之城的档案员会用特制的铅盒收藏这些玻璃碎片，因为阳光会让它们重新想起被剥离者的尖叫。

## 设计意图

为法师系提供软控制/知识窃取，拓展技能封锁玩法。
