# 《禁术：深渊祈愿》

## 基础信息

- **书籍 ID**：`book_legendary_0067`
- **关联技能**：`legendary_abyss_wish`
- **使用效果**：阅读后解锁 `legendary_abyss_wish`；若已学会，提升 `current_mastery +160`，并允许在战斗中向深渊祈愿，随机获得强力增益但附带随机减益。
- **阅读要求**：无职业限制；基础 `意志 ≥ 14`、感知 `≥ 14`；角色 `known_knowledge_ids` 含 `abyss_lore`。

- **建议投放**：深渊祭坛、深渊商人、疯狂学者任务、传说级宝箱。

## 书籍内容

深渊祈愿是一本关于如何许愿的书。书中记载，深渊不是神明，却比神明更愿意回应祈求——因为它从不拒绝，只是总是以你意想不到的方式满足你。施术者需在心中默念愿望，然后将一件珍贵之物抛入黑暗。深渊会回赠力量：有时是自愈，有时是狂暴，有时是预知，但有时回赠的是失明、耳聋或失去一段记忆。作者在最后写道：「深渊听不见语言，它只听见渴望。越深的渴望，越深的代价。」书脊上刻着一串不断变化的数字，据说那就是深渊的「利息表」。

深渊祈愿的回赠往往以梦境形式提前显现，但梦中所见总是颠倒的。一位老练的使用者会在醒来后立刻把愿望反写，以期获得接近预期的结果。

深渊的回赠有时会延迟数日才到达，期间施术者会不断做同一个梦：站在悬崖边，手里握着一件看不清形状的东西。
