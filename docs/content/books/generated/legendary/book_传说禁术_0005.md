# 《贯魂箭》

## 基础信息

- **书籍 ID**：`book_传说禁术_0005`
- **关联技能**：`legendary_soul_piercing_arrow`
- **使用效果**：阅读后解锁 `legendary_soul_piercing_arrow`；若已学会，提升 `current_mastery +160`，并在下一次战斗中首次命中时忽略目标 20% 全抗性。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；基础 `感知 ≥ 15`、敏捷 `≥ 12`。
- **稀有度**：传说（Legendary）
- **建议投放**：古战场箭塔、游侠长老传承、龙骨荒原宝箱、传说猎人委托。

## 书籍内容

弓手禁术，箭矢穿过肉体直击灵魂。书中描述，箭杆需用亡者肋骨磨制，箭羽来自夜枭的翅膀。射击时不必瞄准心脏，而要瞄准敌人身后那道淡淡的轮廓——那是灵魂离开身体前的投影。命中后，肉体可能只受轻伤，灵魂却被钉在原地无法回归。书页间夹着几根灰白羽毛，羽毛根部缠着细小的黑发。附注警告：若射中自己的影子，灵魂会先一步离体。

此箭术世代由夜枭猎人传承，每代只能教授一名弟子。传说的最后一名猎手在射出贯魂箭后，发现自己的影子已被永远钉在靶心。

贯魂箭的最后传承者死于自己的倒影，他的灵魂至今仍被困在箭靶之上。

贯魂箭的箭靶至今立在荒原深处，靶心处插满灰白羽毛，无人敢靠近拔取。

无人敢触碰那些羽毛，因为曾有冒险者因此陷入三日不醒的梦魇。

据说那些羽毛会在无风之日微微颤动，仿佛仍在等待下一支贯穿灵魂的箭矢。

## 设计意图

为弓箭手提供跨抗性单体爆发，强调精准与诡异的世界观质感。
