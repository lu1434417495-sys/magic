# 《禁术：瘟疫使徒》

## 基础信息

- **书籍 ID**：`book_legendary_0080`
- **关联技能**：`legendary_plague_apostle`
- **使用效果**：阅读后解锁 `legendary_plague_apostle`；若已学会，提升 `current_mastery +160`，并在击败敌人后使其尸体爆发瘟疫，感染周围敌人。
- **阅读要求**：角色职业标签含 `warlock` 或 `necromancer`；基础 `智力 ≥ 15`、体质 `≥ 13`。
- **稀有度**：传说（Legendary）
- **建议投放**：瘟疫实验室、疫病商人、死亡传播任务奖励、传说级宝箱。

## 书籍内容

瘟疫使徒是一本关于如何让死亡继续传染的书。书中记载，死亡不是终点，而是一种可以被携带、被播种的信息。施术者需在敌人濒死时将一枚「疫种」送入其体内，当敌人倒下时，尸体不会安静，而是会肿胀、破裂，释放出肉眼看不见的孢子。周围的敌人会开始咳嗽、发热、视野模糊。古籍警告，施术者自身也活在瘟疫的阴影下，许多使徒最终死于自己播下的种子。书页上有一幅城市地图，许多街区被黑色墨水涂满，旁边写着「已完成」。

瘟疫使徒释放的孢子在干燥环境中会休眠数十年，一旦遇到雨水便会复苏。因此古籍的最后一章专门讲述如何在自己死后处理遗体，以免成为下一场瘟疫的起点。

瘟疫使徒散播的孢子会在风雨中传播得更远，但也更容易反噬施术者。因此有经验的使徒总是选择在干燥晴朗的日子发动。

## 设计意图

提供击败传染机制，强化亡灵术士的持续消耗与战场污染能力。
