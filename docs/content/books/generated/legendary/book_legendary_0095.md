# 《禁术：圣骸布》

## 书籍内容

圣骸布是一本教人如何被死人保护的书。书中记载，某些圣者的遗体不会腐烂，而是会化作一块苍白的布，那块布上残留着圣者生前的祝福与执念。施术者需在危急时刻将骸布裹在身上，那层布会替你承受一次本该致命的攻击——不是反弹，也不是治愈，只是让死亡在那块布上留下一个洞。古籍警告，每一块圣骸布只能用一次，而世界上圣者的遗体远比人们想象的少。书页上缝着一小块已经发黄的布片，布片上有焦黑的痕迹。

圣骸布使用后会留下一个与致命伤形状相同的破洞，但不会流血。收藏者可以通过破洞的形状辨认出这件布曾抵挡过何种攻击，从剑刺到诅咒不一而足。

圣骸布使用后的破洞若被缝补，会在下一次使用时再次出现在相同位置。教会因此认为，那块破布记录的是一种无法被修补的宿命。
