# 《禁术：旧神低语》

## 基础信息

- **书籍 ID**：`book_legendary_0088`
- **关联技能**：`legendary_old_god_whisper`
- **使用效果**：阅读后解锁 `legendary_old_god_whisper`；若已学会，提升 `current_mastery +160`，并允许低语一段旧神之名，使范围内敌人陷入恐惧 3 秒。
- **阅读要求**：无职业限制；基础 `意志 ≥ 16`、感知 `≥ 14`；角色 `known_knowledge_ids` 含 `old_god_lore`。

- **建议投放**：深海遗迹、疯狂学者、禁忌知识任务奖励、传说级宝箱。

## 书籍内容

旧神低语是一本只有疯子才敢读完的书。书中没有完整的句子，只有一连串破碎的音节，据说那是沉睡在世界边缘的古老存在梦中的呓语。施术者需在脑海中复刻其中一个音节，然后轻声念出。那声音人类几乎听不见，但敌人的理智会瞬间被撕开一个口子，看见不该看见的东西。古籍警告，每念出一个音节，施术者自己的理智也会被借走一部分。许多页面的空白处写满了读者留下的胡言乱语，有些字迹已经开始扭曲成非人的形状。

旧神低语念出的音节无法被文字记录，每次尝试誊写，墨水都会自行扭曲成触手状的图案。因此这本书只能口口相传，而每位传授者都会在最后一字时停顿三秒。

旧神低语的音节会在施术者耳边停留数日，像蚊子一样嗡嗡作响。只有用更高声的人类音乐才能暂时盖住这些声音。

## 设计意图

提供范围恐惧控制，以理智/知识为门槛，服务于旧神主题构筑。
