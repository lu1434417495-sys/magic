# 《无息刺杀》

## 基础信息

- **书籍 ID**：`book_传说禁术_0015`
- **关联技能**：`legendary_breathless_assassination`
- **使用效果**：阅读后解锁 `legendary_breathless_assassination`；若已学会，提升 `current_mastery +180`，并在下一次战斗中让屏息时间上限延长 1 秒。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `敏捷 ≥ 16`、体质 `≥ 10`。
- **稀有度**：传说（Legendary）
- **建议投放**：影之公会密室、无声墓穴、刺客传承任务、深渊宝箱。

## 书籍内容

盗贼的呼吸禁术，能在行动中完全停止呼吸。书中说，真正完美的暗杀不是看不见，而是让时间忘记你。修习者要学会在出击前屏息三秒，使自身存在感降到最低。成功后，第一击必定暴击，但如果在三秒内未命中，肺部会受到撕裂伤害。作者记录了无数次失败案例，死因多为窒息而非战斗。书末附有一张肺部解剖图，标注着"此处不可超过三秒"。

无息刺杀的入门考试要求在深水下闭气并击中移动的鱼影。失败者的肺部会留下永远无法愈合的细小裂痕，呼吸时发出类似漏气的嘶嘶声。

无息刺杀的肺部图注解来自一位因练习过度而咳血的宗师，笔迹越来越淡。

无息刺杀的宗师晚年选择自我封喉，因为他再也无法相信自己的呼吸不会暴露行踪。

封喉是他最后的气音，也是无息刺杀最沉默的毕业礼。

## 设计意图

强化暗杀者的极限首击爆发，用呼吸机制增加操作窗口与风险。
