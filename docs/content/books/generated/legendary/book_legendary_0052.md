# 《禁术：因果锚定》

## 基础信息

- **书籍 ID**：`book_legendary_0052`
- **关联技能**：`legendary_causality_anchor`
- **使用效果**：阅读后解锁 `legendary_causality_anchor`；若已学会，提升 `current_mastery +170`，并允许将一次受到的伤害延迟至 3 秒后结算。
- **阅读要求**：角色职业标签含 `mage` 或 `priest`；基础 `智力 ≥ 16`、感知 `≥ 14`。
- **稀有度**：传说（Legendary）
- **建议投放**：时计塔顶层、因果律研究者、传说级宝箱、世界线任务奖励。

## 书籍内容

因果锚定不是防御术，而是一种对债务的重新安排。书中教导施术者将即将落在自己身上的伤害写成一枚借据，钉入时间的缝隙，让它在三息之后才兑现。那三息之内，伤口不存在、疼痛不存在、死亡也不存在，唯有借据上的利息在静静增长。作者用整整一章讲述「锚点」的选择：钉在敌人身上，会让敌人分担；钉在环境上，会让地形崩裂；若钉在自己未来的某一刻，则下一战开始时便会自动受伤。古籍中间夹着一张破碎的契约残片，上面的签名已经模糊，只有手印鲜红如初。

书的后半部被虫蛀出细小的孔洞，孔洞连成的图案竟是一幅不断变化的债务关系图。曾有一位学者试图用这笔账计算整个王国的兴衰，结果在三日后失踪，只留下写满数字的墙壁。

古籍末尾有一页被反复涂改过，最新的墨迹下仍能看见更古老的版本，像是不同时代的读者在争夺同一条因果线的解释权。

## 设计意图

为高智职业提供风险转移型防御，鼓励玩家用时间差换取治疗或反击窗口。
