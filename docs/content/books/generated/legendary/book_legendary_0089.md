# 《禁术：烬世之舞》

## 基础信息

- **书籍 ID**：`book_legendary_0089`
- **关联技能**：`legendary_ash_world_dance`
- **使用效果**：阅读后解锁 `legendary_ash_world_dance`；若已学会，提升 `current_mastery +170`，并允许在灰烬中起舞，持续对周围敌人造成燃烧与减速。
- **阅读要求**：角色职业标签含 `dancer` 或 `rogue`；基础 `敏捷 ≥ 16`、感知 `≥ 13`；角色曾进入灰烬交界。
- **稀有度**：传说（Legendary）
- **建议投放**：灰烬交界祭坛、烬舞者商人、火焰节任务奖励、传说级宝箱。

## 书籍内容

烬世之舞是一本把毁灭变成舞蹈的书。书中记载，灰烬交界曾有一位舞者，她的舞步能让火焰跟随裙摆旋转，让整个世界在她身边缓慢燃烧。修习者需学会在移动中保持绝对的平衡，每一步都要踩在灰烬最轻的那一层上。舞动起来时，周围的空气会变得灼热，敌人会迷失在旋转的火光中，动作越来越慢，直到被火焰吞没。古籍警告，这支舞没有终点，许多舞者跳到最后一刻，自己也变成了灰烬的一部分。书页上有一幅舞者剪影，剪影周围是无数飘落的火星。

烬世之舞的舞步在地面上留下的焦痕会组成古老的文字，翻译过来大多是舞者的名字与遗言。有考古学家通过这些痕迹复原了一场发生在千年前的完整战役。

烬世之舞的舞者若在火焰中死去，其灰烬会保持舞动的姿态。收藏家用玻璃罩保存这些灰烬，当作最珍贵的战利品。

## 设计意图

为敏捷职业提供持续移动输出，强化灰烬交界主题与机动战斗风格。
