# 《禁术：虚空嫁衣》

## 基础信息

- **书籍 ID**：`book_legendary_0056`
- **关联技能**：`legendary_void_bride`
- **使用效果**：阅读后解锁 `legendary_void_bride`；若已学会，提升 `current_mastery +160`，并在下一次战斗中首次受到致命伤害时免疫该次伤害并瞬移三格。
- **阅读要求**：角色职业标签含 `mage` 或 `rogue`；基础 `智力 ≥ 15`、敏捷 `≥ 15`。
- **稀有度**：传说（Legendary）
- **建议投放**：虚空裂隙密室、星界商人、隐藏盗贼任务、传说级宝箱。

## 书籍内容

虚空嫁衣是一门把自己嫁给虚空的禁术。书中说，虚空并非空无一物，而是一个永远饥饿、永远等待的「亲族」。施术者需在无月之夜穿上一件由黑曜石粉末染成的长袍，对着镜子念出一段婚誓，从此虚空会把你当作它的新嫁娘——在你真正死亡之前，它会替你挡下一次致命的攻击，并将你拉入它的怀中三息。那三息里，你会看见无数 previous brides 悬浮在黑暗中，她们有的已经只剩骨架，有的还在微笑。作者在最后写道：「婚礼只举行一次，但虚空永远记得。」

虚空嫁衣的长袍没有重量，却会在穿戴者身后拖出一道淡淡的黑色尾迹。那尾迹会持续数日不散，追踪者称之为「寡妇的婚纱」，因为它总是通向一场未完成的婚礼。

穿上嫁衣的人会做一个相同的梦：在一个没有星辰的礼堂里，无数黑影站在红毯两侧，向自己抛洒冰冷的碎石。

## 设计意图

提供一次性的致命伤害规避，适合脆皮高输出职业作为最后的保险。
