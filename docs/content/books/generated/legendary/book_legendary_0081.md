# 《禁术：魂钉七桩》

- **书籍 ID**：`book_legendary_0081`
- **关联技能**：`legendary_soul_nails_seven`

## 书籍内容

魂钉七桩是一本教人如何把灵魂钉在原地的书。书中说，灵魂本可以自由流动，但人有七处「门」——双眼、双耳、双鼻与心口。只要用魔力凝成的钉子封住这七处门，灵魂便无法从外界汲取力量。施术者需在极近距离内将七枚魂钉依次刺入敌人的对应位置，任何一枚偏离都会让前功尽弃。古籍警告，钉魂者也会被魂钉反钉，许多修习者最终在自己的梦中被封住了七门，再也醒不过来。书末附有一幅人体穴位图，七个红点被黑线连成北斗形状。

魂钉七桩的七枚钉子需用七种不同金属锻造，分别对应人体内的七处「门」。收集齐这些金属的代价往往比学会钉魂术本身更高，因为最后一种金属只在梦中矿脉出现。

七枚魂钉若全部命中同一敌人，敌人的影子会被钉在地上，久久不散。那影子有时会自己移动，模仿生前的习惯动作。
