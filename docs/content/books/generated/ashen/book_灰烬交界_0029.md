# 《灰烬审判宣言》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0029`
- **关联技能**：`ashen_judgment`
- **使用效果**：阅读后解锁 `ashen_judgment`；若已学会，提升 `current_mastery +150`，并对被审判目标提升 5% 最终伤害。
- **阅读要求**：角色职业标签含 `paladin` 或 `holy_warrior`；基础 `意志 ≥ 12` 或 `力量 ≥ 11`。
- **稀有度**：稀有（Rare）
- **建议投放**：审判所、圣骑士团据点、正义任务奖励。

## 书籍内容

《灰烬审判宣言》记录的不是法庭审判，而是圣职者在战场上对邪恶目标宣告终结的仪式。审判需要先以圣火点燃一份写有目标罪行的灰烬卷轴，然后在战斗中把燃烧的卷轴掷向目标。作者强调，审判之力不来自愤怒，而来自不可动摇的信念。书中详细讲解了审判宣言的发音技巧：必须一字一顿，任何颤抖都会让圣火熄灭。第二章讨论了审判的限制：不能对无辜者使用，否则反噬会直接烧伤施术者的灵魂。书的后半部分收录了历史上七位著名审判者的完整宣言，其中一位的宣言只有四个字："灰烬归尘。" 审判宣言的力量来源被作者解释为"信念的纯度"。他写道，一个对自己行为有丝毫怀疑的人，审判宣言只会变成普通的燃烧卷轴。只有真正相信自己代表正义的人，才能让宣言在空中燃烧成不可躲避的光矛。

## 设计意图

为圣战型职业提供单体爆发与制裁技能，强化信念主题。
