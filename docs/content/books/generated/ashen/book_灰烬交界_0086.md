# 《灰烬盗贼：灰袋术》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0086`
- **关联技能**：`ashen_pouch`
- **使用效果**：阅读后解锁 `ashen_pouch`；若已学会，提升 `current_mastery +120`，并扩大可隐藏偷窃物品的临时灰袋容量。
- **阅读要求**：角色职业标签含 `rogue` 或 `thief`；基础 `敏捷 ≥ 10`。
- **稀有度**：普通（Common）
- **建议投放**：盗贼公会藏书、黑市商人、灰烬交界市集。

## 书籍内容

灰袋术教盗贼如何用浸透水的灰袋临时藏匿赃物或危险品。作者认为，灰烬的吸味和隔热特性让它成为理想的临时包裹材料。书中详细说明灰袋的制作：用三层细灰夹着一层湿布，捏成拳头大小的袋子，可以短时间隔绝金属声响和魔法波动。核心章节讲解如何把灰袋藏在身上而不被发现：最好放在腰部或小腿外侧，因为这些位置在搜身时最容易被忽略。作者警告，灰袋只能维持几个时辰，时间过长里面的物品会被腐蚀。练习者需成功藏匿一件金属物品并通过检查。尾页题词：“最好的赃物，是连你自己都闻不到味道的赃物。”书页边缘留有被炭火熏黑的空白，供读者记录自己的灰烬坐标。作者在跋文中提醒：灰烬交界的技法没有标准答案，只有烧剩下的答案。许多抄本的末页都沾着不同颜色的灰烬，那是前人练习时留下的印记。

## 设计意图

为盗贼系提供生活与探索辅助技能，把灰烬特性转化为盗窃与潜行工具。
