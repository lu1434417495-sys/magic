# 《灵魂箭飞行稳定论》

- **建议投放**：沉钟书库研究桌、法师公会任务、咒术飞靶挑战奖励。

## 书籍内容

这本书不讲凝聚，只讲飞行。作者认为灵魂箭离开指尖后的每一毫秒都在衰减，施术者的任务是把衰减降到最低。书中详细讨论了湿度、温度和周围魔晶矿脉对箭矢稳定性的影响，并给出了一套环境补偿口诀。中间部分收录了三十七次靶场测试数据，每一箭的偏差都被精确记录。最有趣的章节是"风与灵魂箭"：作者发现微弱的气流反而能帮助箭矢保持稳定，前提是施术者能在射出前感知到气流方向。最后一页是一张被箭头戳穿无数次的靶纸，靶心写着：干净比 loud 重要。封底贴着一张法师公会的罚款单，理由是"在书库内擅自进行飞行实验"。罚款单上的金额被墨水涂改过多次，最后一次修改旁边写着"值得"。罚款单的边缘被一位不知名的法师画上了小小的靶心，似乎在表达某种无声的抗议。

## 设计意图

为灵魂箭提供精通向的熟练度与资源优化，鼓励环境感知玩法。
