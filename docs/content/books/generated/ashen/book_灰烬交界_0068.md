# 《烬矢制作与瞄准》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0068`
- **关联技能**：`ashen_arrow`
- **使用效果**：阅读后解锁 `ashen_arrow` 制作配方；若已学会，提升 `current_mastery +120`，并提高烬矢命中后的灼烧概率。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；基础 `感知 ≥ 10`。
- **稀有度**：普通（Common）
- **建议投放**：灰烬交界商人、游侠营地、余烬祭所基础传授。

## 书籍内容

这本手册专讲如何在缺乏金属箭头时用灰烬和硬木制作临时箭矢。作者认为，烬矢的威力来自命中时四散的余烬，而非穿透力。书中把箭杆选材、羽毛粘合、箭头裹灰每一步都配以图示。核心技巧是“裹灰”：在箭头上缠一层浸透油脂的布，再蘸取细灰，飞行时灰不会散落，命中后布破灰扬。作者警告，烬矢不能用于远程精准射击，因为灰的重量会让箭速下降。练习者需在二十步内命中稻草人，并观察灰扩散范围。尾页写着：“一支烬矢杀不死龙，但能让龙睁不开眼。”书页边缘留有被炭火熏黑的空白，供读者记录自己的灰烬坐标。作者在跋文中提醒：灰烬交界的技法没有标准答案，只有烧剩下的答案。许多抄本的末页都沾着不同颜色的灰烬，那是前人练习时留下的印记。此抄本曾被余烬烫穿数页，缺失处反而逼迫读者用自己的经验补全。

为弓箭手提供灰烬环境弹药选择，强化近战射程内的控场与持续伤害。
