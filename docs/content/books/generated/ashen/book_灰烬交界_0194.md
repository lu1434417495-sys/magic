# 《灰烬魔像拆解手册》

## 书籍内容

作者是一名曾在灰烬交界研究魔像的工程师，他把魔像称为"会走路的建筑"。书中指出灰烬魔像由魔晶、金属和大量压缩灰烬构成，常规攻击很难造成有效伤害。作者建议攻击关节连接处和胸口的魔晶核心，前者能让魔像失去平衡，后者则能直接瘫痪其行动。中间章节还讨论了不同类型魔像的弱点：重型魔像惧怕雷电，敏捷魔像惧怕冲击，施法型魔像则最怕被近身打断。最后几页是一份紧急维修指南，但作者备注：这本指南是给魔像自己看的，不是给你看的。书的封皮上嵌着一小块魔像外壳碎片，敲击时会发出空洞的回响。作者说这碎片来自他拆解的第一具魔像，每当他怀疑自己时就会敲一下。那块外壳碎片在靠近魔像残骸时会发出低沉的共鸣声，像是还在试图执行某个未完成的指令。
