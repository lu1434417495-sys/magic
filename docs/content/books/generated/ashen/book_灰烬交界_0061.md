# 《灰壳陷阱制作》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0061`
- **关联技能**：`ashen_pit_trap`
- **使用效果**：阅读后解锁 `ashen_pit_trap`；若已学会，提升 `current_mastery +110`，并降低布置灰壳陷阱所需的材料消耗。
- **阅读要求**：无职业限制；基础 `智力 ≥ 9`。
- **稀有度**：普通（Common）
- **建议投放**：猎户村落、灰烬交界营地、游荡商人。

## 书籍内容

这本笔记教人利用灰烬交界特有的灰壳地形制造陷阱。作者认为，灰壳看似坚硬，实则只需破坏下方支撑就能塌陷。书中详细说明如何找到灰壳下方的空洞，用薄木板或硬枝搭建伪装桥面，再在表面撒上与周围颜色一致的细灰。陷阱触发机关可以是绳索、压力板，甚至一只被训练过的老鼠。作者警告，制作陷阱时必须先测试自己的体重能否安全通过，否则设陷阱的人会成为第一个受害者。后半部分讨论如何让陷阱看起来更像自然塌陷。尾页批注：“最好的陷阱，是连你自己都差点忘了的陷阱。”书页边缘留有被炭火熏黑的空白，供读者记录自己的灰烬坐标。作者在跋文中提醒：灰烬交界的技法没有标准答案，只有烧剩下的答案。许多抄本的末页都沾着不同颜色的灰烬，那是前人练习时留下的印记。

## 设计意图

为野外生存与游击战术提供灰烬环境陷阱技能，丰富探索互动选项。
