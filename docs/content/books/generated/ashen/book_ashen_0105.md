# 《焚心祷言：灰烬牧师的圣典残页》

## 基础信息

- **书籍 ID**：`book_ashen_0105`
- **关联技能**：`ashen_ember_prayer`
- **使用效果**：阅读后解锁 `ashen_ember_prayer`；若已学会，提升 `current_mastery +120`，并为全队恢复少量 `current_hp` 与 `current_mp`。
- **阅读要求**：职业标签含 `priest` 或 `support`；基础 `意志 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：炭化大教堂密室、圣职传承任务、高阶牧师遗物。

## 书籍内容

这些残页来自一座在灰烬中仍保持热量的祭坛，纸张上的字迹不是墨水，而是某种冷却后凝结的圣灰。祷言的核心不是祈求熄灭，而是祈求在燃烧中保持清醒。它要求施术者先承认痛苦是神圣的一部分，然后才能把余烬般的温暖传递给他人。书中反复警告：灰烬牧师的力量来自"被烧过但仍完整"的心，若施术者自身尚未经历磨难，祷言只会变成空洞的暖风。残页中间有一首被烧掉一半的圣诗，只剩反复出现的句子："我以灰烬为冠，不以火焰为衣。"很多信徒认为，这首诗本身就是一道需要被完整吟诵的封印。这些残页在传递力量时会微微发热，据说是被圣灰字迹共鸣的结果。但如果有施术者心怀怨恨，残页会迅速冷却并冒烟，成为一种无声的警告和考验。据说在极为罕见的时刻，当多位灰烬牧师同时吟诵这段祷言时，残页会发出类似心跳的温热脉动。

## 设计意图

灰烬主题牧师治疗/辅助技能入口，把"燃烧后的宁静"作为圣职系在异界战场的叙事核心。
