# 《灰烬交界的冥想改良》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0179`
- **关联技能**：`meditation_ashen_breath`
- **使用效果**：阅读后学会冥想技能 `meditation_ashen_breath`（`practice_tier = basic`），解锁 MP 资源链并按首日成长公式注入起始值。
- **阅读要求**：无职业限制；基础 `智力 ≥ 9` 或 `意志 ≥ 9`。
- **稀有度**：稀有（Rare）
- **建议投放**：沉钟书库冥想室、灰烬交界隐士据点、冥想导师奖励。

## 书籍内容

作者发现普通冥想功法在灰烬交界效果大打折扣，因为这里的魔力流动带着燃烧后的残渣。书中提出了一套改良呼吸法：吸气时要想象把灰烬过滤出去，屏息时让纯净魔力在胸腔沉淀，呼气时把无法消化的杂质排出体外。前几章讲如何判断自己是否吸入了"灰毒"：舌尖发麻、眼前出现金色碎屑、耳鸣如钟。中间部分收录了多位冥想者的失败案例，他们因为急于求成而把灰毒也一起压缩，结果反而损伤了经脉。最后一页只有一句话：在这里冥想，不是清空自己，是筛选自己。封底粘着一小片灰色的结晶，据说是灰毒的实体残留。作者警告读者不要把它当作收藏品，因为每一块灰毒结晶都曾是一个冥想者失控的瞬间。灰毒结晶在不同光线下会折射出不同的灰色层次，像是一枚被冻结的小型风暴。

## 设计意图

作为灰烬交界限定冥想功法，为非法系职业或法师提供 MP 成长路径。
