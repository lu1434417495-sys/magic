# 《燃尽式：斗气爆发残卷》

## 基础信息

- **书籍 ID**：`book_ashen_0109`
- **关联技能**：`cultivation_burnout_strike`
- **使用效果**：阅读后学会修炼技能 `cultivation_burnout_strike`（`practice_tier = advanced`），立即解锁 `AURA` 资源链高级分支，并提升 10% 暴击率（持续三场战斗）。
- **阅读要求**：无职业限制；已学会任意基础修炼功法；基础 `力量 ≥ 12` 或 `体质 ≥ 12`。
- **稀有度**：史诗（Epic）
- **建议投放**：灰烬竞技场冠军奖励、狂战士传承任务、异界裂隙宝箱。

## 书籍内容

燃尽式是一门被大多数正统修炼门派禁止的技法。它要求修炼者在短时间内把斗气像泼油一样点燃，换取超越常态的爆发力。书的纸张边缘有明显的焦痕，仿佛作者写到最后时自己的功法也反噬了。正文只有薄薄十几页，却花了大量篇幅警告练习者：燃尽式不是拼命，而是精确计算自己还能燃烧多久。书中提出"三息原则"：第一息点燃，第二息挥击，第三息必须开始熄灭，否则就会真的燃尽。后半本收录了九位前辈的结局，七死二残。最后活着的两位都在同一句话上做了批注："火能杀敌，也能替你写遗书。"残卷的作者在最后几页写满了自己的计算：不同年龄、体质和功法基础的人，最长能维持燃尽式多久。他试图找出一条安全线，却发现这条线几乎不存在，只有\"更少\"和\"更久\"之间的赌博。残卷的装订线是用某种耐火兽筋制成，即便书页被烧毁，装订线仍能完整保留，仿佛在等待下一个读者。

## 设计意图

高阶斗气爆发技能，定位为高风险高回报的修炼分支，强化 AURA 资源链的战斗释放端。
