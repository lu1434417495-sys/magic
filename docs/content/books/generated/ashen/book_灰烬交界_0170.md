# 《火焰壶的引线学问》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0170`
- **关联技能**：`ashen_firebomb`
- **使用效果**：阅读后提升 `ashen_firebomb` `current_mastery +110`，并使引信时间缩短 0.5 TU，落地即爆概率提升。
- **阅读要求**：已学会 `ashen_firebomb`；基础 `敏捷 ≥ 10` 或 `智力 ≥ 9`。
- **稀有度**：精良（Uncommon）
- **建议投放**：坠墓镇炼金铺、灰烬交界游荡者商人、遗迹工具台。

## 书籍内容

这本书只讲一件事：引线。作者认为火焰壶九成失败都源于引线问题：太长会被敌人踢开，太短会在自己手里爆炸，太湿会哑火，太干会提前爆。书中详细列举了不同气候下的引线调整方案，并附有一张手写配方表。中间部分讲投掷时机：引线在手中燃烧到第几拍时脱手，才能让壶体在目标头顶正上方爆裂。后半本还收录了用火焰壶制造"火墙"封堵通道的战术。最后一页是一幅烧焦的插画，一个盗贼正把火焰壶丢进敌人堆里，旁边写着：引线即命运。书的扉页上粘着半根没燃尽的引线，散发着淡淡的硫磺味。引线的长度正好对应书中"最佳脱手时机"的示例，读者可以把它当作实物教具。那根没燃尽的引线至今 still 散发着硫磺味，读者翻开扉页时总会不自觉地屏住呼吸。封皮的边角已经卷曲发黑，像是曾经被丢进火堆里又被人抢救出来。

## 设计意图

作为火焰壶的精通书籍，强化道具投掷的时机与战术深度。
