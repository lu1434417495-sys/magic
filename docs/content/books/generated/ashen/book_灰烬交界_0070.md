# 《烬土种植笔记》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0070`
- **关联技能**：`ashen_growth`
- **使用效果**：阅读后解锁 `ashen_growth`；若已学会，提升 `current_mastery +110`，并令灰烬催生的植物额外存活 2 回合。
- **阅读要求**：无职业限制；基础 `智力 ≥ 9`。
- **稀有度**：普通（Common）
- **建议投放**：草药师营地、德鲁伊林地任务、灰烬交界生态据点。

## 书籍内容

笔记记录了一位草药师如何在灰烬中发现并培育耐火植物的尝试。作者指出，灰烬并非死土，某些植物的种子只有在高温余烬中才会发芽。书中列出七种可在烬土中生长的草药，以及它们对光照、温度和灰层厚度的要求。核心章节讲解“余温播种”：把种子埋入尚有余温的灰中，不深不浅，让热度唤醒胚芽而不烧伤它。作者还提醒，灰烬植物生长极快但寿命短暂，采集时机至关重要。练习者需在营地里培育出第一株灰芽草。尾页写着：“灰烬不是坟墓，是某些生命才懂的语言。”书页边缘留有被炭火熏黑的空白，供读者记录自己的灰烬坐标。作者在跋文中提醒：灰烬交界的技法没有标准答案，只有烧剩下的答案。许多抄本的末页都沾着不同颜色的灰烬，那是前人练习时留下的印记。此抄本曾被余烬烫穿数页，缺失处反而逼迫读者用自己的经验补全。

## 设计意图

为生活与探索型玩家提供灰烬环境资源生产技能，拓展异界生态系统。
