# 《燃烬斩击要义》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0057`
- **关联技能**：`ashen_slash`
- **使用效果**：阅读后解锁 `ashen_slash`；若已学会，提升 `current_mastery +140`，并令下一次战斗中首次斩击命中时附加灼烧。
- **阅读要求**：角色职业标签含 `warrior`；基础 `力量 ≥ 11`。
- **稀有度**：精良（Uncommon）
- **建议投放**：余烬祭所、战士训练场、灰烬遗迹宝箱。

## 书籍内容

要义把灰烬斩击分为“引灰、蓄热、释放”三个阶段。作者指出，真正有效的燃烬斩击不是让剑燃起明火，而是让灰烬在高速挥动中与空气摩擦发热。书中强调蓄热阶段的姿势：剑身略微后收，肘部下沉，像一张拉满的弓。释放时则要在挥至中点时突然加速，让灰粒在刃口前形成一道热线。作者用大量炭笔图示展示正确与错误的挥剑弧线，并反复警告不要追求过大的动作幅度。练习者需在稻草人前连续斩击，直到稻草内部出现焦痕而非外伤。尾页写着：“灰烬之刃，烧的是耐心。”书页边缘留有被炭火熏黑的空白，供读者记录自己的灰烬坐标。作者在跋文中提醒：灰烬交界的技法没有标准答案，只有烧剩下的答案。许多抄本的末页都沾着不同颜色的灰烬，那是前人练习时留下的印记。此抄本曾被余烬烫穿数页，缺失处反而逼迫读者用自己的经验补全。

## 设计意图

为战士系提供灰烬属性斩击技能，强化近战输出与异常状态叠加。
