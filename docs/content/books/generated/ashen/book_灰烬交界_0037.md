# 《灰烬咆哮战吼》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0037`
- **关联技能**：`ashen_roar`
- **使用效果**：阅读后解锁 `ashen_roar`；若已学会，提升 `current_mastery +110`，并延长恐惧效果 0.5 秒。

## 书籍内容

《灰烬咆哮战吼》认为，战吼不是简单的喊叫，而是一种用声音在敌人心中制造恐惧的艺术。作者要求练习者在咆哮时想象自己把肺里的空气全部变成灰烬，然后一次性喷向敌人。这种咆哮会带有交界特有的低频震动，能让听到的敌人产生短暂的逃跑冲动。书中详细讲解了发音部位：不是用嗓子喊，而是用气从腹部推出，经过胸腔共鸣后从口腔释放。第二章讨论了战吼的时机：最好在敌人刚要发起攻击前使用，因为犹豫中的敌人最容易被恐惧影响。书的后半部分收录了多种战吼的实际应用，包括吓退野兽、打断施法、以及提振己方士气。" 咆哮战吼的音量不是关键，频率才是。作者发现，交界余火会放大某些低频音波，让听到的人产生本能的恐惧。书中提供了几种不同的咆哮方式，每种对应不同的恐惧效果：混乱、僵直、或逃跑冲动。

## 设计意图

为战士系提供控制与士气技能，强化团队辅助与控场能力。
