# 《灰烬弓箭手的连射心得》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0198`
- **关联技能**：`archer_aimed_shot`
- **使用效果**：阅读后提升 `archer_aimed_shot` `current_mastery +130`，并在灰烬交界首次命中敌人时附加 `标记` 状态持续 60 TU。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；基础 `敏捷 ≥ 11` 且 `感知 ≥ 10`。
- **稀有度**：精良（Uncommon）
- **建议投放**：风息哨塔高阶训练、游侠导师奖励、灰烬交界狩猎任务。

## 书籍内容

作者认为在灰烬交界射箭，最重要的是节奏而非速度。书中把连射分为"定射""追射""断射"三种：定射用于击杀关键目标，追射用于扩大优势，断射用于打断施法或冲锋。作者特别强调呼吸：每次拉弓时吸气，瞄准时屏息，松弦时呼气，节奏不能乱。中间章节收录了多位游侠的实战笔记，每个人都提到灰雾会让目标看起来在移动，因此要学会相信肌肉记忆而非眼睛。最后一页是一句被反复描粗的格言：连射不是射得快，是每次松弦都比上一次更稳。书的夹页里有一根断裂的弓弦，旁边标注着"它在我最稳的那一次断了"。作者说这是提醒射手：即使最稳定的箭术也有极限，学会接受意外比追求完美更重要。那根弓弦虽然已经断裂，但在拉紧时仍会发出轻微的颤音，像是在怀念最后一次被绷紧的瞬间。

## 设计意图

作为弓箭手通用技能与灰烬主题的结合，强化标记与连射玩法。
