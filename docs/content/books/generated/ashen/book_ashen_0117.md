# 《灰烬商人的估价密录》

## 基础信息

- **书籍 ID**：`book_ashen_0117`
- **关联技能**：`ashen_appraisal`
- **使用效果**：阅读后解锁 `ashen_appraisal`；若已学会，提升 `current_mastery +100`，并在下一次出售物品时获得 15% 额外收益（一次性）。
- **阅读要求**：无职业限制；基础 `智力 ≥ 8` 或 `魅力 ≥ 9`。
- **稀有度**：普通（Common）
- **建议投放**：灰烬集市商人、行会任务奖励、普通宝箱。

## 书籍内容

灰烬商人是一群在毁灭边缘讨生活的人，他们的核心能力不是战斗，而是判断一件烧焦的东西还有没有价值。这本密录把灰烬交界的物品分成四类：能卖的、能修的、能吃的、会爆炸的。作者用大量篇幅讲解如何从灰烬的颜色和气味判断原材料：植物灰偏白、布料灰偏灰、金属灰有金属味、魔晶灰会在夜里微弱发光。书中还记录了各地商人的信誉等级和常用的骗术，比如把冷灰重新加热冒充余烬、把普通石头包在炭壳里冒充魔晶。最实用的章节是"紧急易物"，教你身上只有一瓶水时如何换到一把刀。最后一页被撕掉了一半，只剩一句话："在灰烬里，最贵的东西永远不是武器，是信息。"密录中有一章专门讲述如何与灰烬原住民交易。他们不用金币，而是接受余烬、净水和故事作为货币。一个足够离奇的故事有时能换到一件价值连城的遗物。

## 设计意图

经济/交易向技能，为玩家在灰烬环境的资源循环中提供收益放大与物品识别能力。
