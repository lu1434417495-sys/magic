# 《灰烬祭司的挽歌》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0087`
- **关联技能**：`ashen_dirge`
- **使用效果**：阅读后解锁 `ashen_dirge`；若已学会，提升 `current_mastery +140`，并令挽歌对亡灵敌人附加安抚或削弱效果。
- **阅读要求**：角色职业标签含 `priest` 或 `holy`；基础 `意志 ≥ 12`。
- **稀有度**：稀有（Rare）
- **建议投放**：炭化大教堂禁书区、亡灵净化任务、异界裂隙祭坛。

## 书籍内容

挽歌是一首专门安抚灰烬中未逝之魂的古老曲调。作者认为，许多在交界中游荡的亡灵并非恶意，只是无法相信自己已经燃烧殆尽。书中把挽歌分为“唤名、叙生、送行”三段，每一段都有特定的音高与节奏。核心章节讲解如何在歌唱时用灰烬画出引导符文，帮助亡灵找到离开的方向。作者警告，唱挽歌时必须心怀慈悲而非恐惧，否则亡灵会把施术者当作新的执念对象。练习者需在一位老祭司的指导下完成第一次完整演唱。尾页经文：“歌声不能复活灰烬，但能让灰烬愿意安息。”书页边缘留有被炭火熏黑的空白，供读者记录自己的灰烬坐标。作者在跋文中提醒：灰烬交界的技法没有标准答案，只有烧剩下的答案。许多抄本的末页都沾着不同颜色的灰烬，那是前人练习时留下的印记。此抄本曾被余烬烫穿数页，缺失处反而逼迫读者用自己的经验补全。

为圣职系提供亡灵控制与剧情仪式技能，深化灰烬交界的生死主题。
