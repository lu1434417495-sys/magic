# 《余烬之盾：守护者的灰烬防御》

## 基础信息

- **书籍 ID**：`book_ashen_0134`
- **关联技能**：`ashen_ember_shield`
- **使用效果**：阅读后解锁 `ashen_ember_shield`；若已学会，提升 `current_mastery +130`，并在下一次战斗中为自身提供 1 次灰烬护盾（吸收火焰伤害）。
- **阅读要求**：职业标签含 `knight`、`paladin` 或 `warrior`；基础 `体质 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：守护者要塞、盾卫传承任务、灰烬遗迹防御宝箱。

## 书籍内容

余烬之盾不是金属盾牌，而是一面由凝聚的余烬和斗气构成的能量屏障。书中描述了如何在手臂上构建这面盾：先感受周围余烬的温度，再用斗气把它们拉拢、压缩，最后在盾面上形成一层不断缓慢燃烧的薄膜。作者警告，余烬之盾最忌讳的是"完美密封"——盾必须留有小缝隙让热量逸出，否则会在使用者手臂上积聚过高温度。后半本讲如何在移动中维持盾形，以及如何用盾面的余烬反伤近战敌人。书的末尾附有一张盾面温度监测图，标注了不同颜色代表的危险等级，最后一种颜色旁边只有一个字："逃。"当余烬之盾吸收过多火焰伤害时，盾面会由暗红转为刺眼的白亮。这时使用者必须主动散去盾上的热量，否则盾会反噬，把积蓄的能量一次性释放到手臂上。盾面上的余烬纹路会随着使用者的情绪微微变化，愤怒时燃烧更旺，恐惧时则黯淡无光，成为一面诚实的镜子。

## 设计意图

守护型防御技能，为前排职业提供火焰特化护盾，强化灰烬环境下的生存能力。
