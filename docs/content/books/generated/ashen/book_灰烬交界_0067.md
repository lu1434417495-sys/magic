# 《灰烬潜行：熄影步》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0067`
- **关联技能**：`ashen_stealth`
- **使用效果**：阅读后解锁 `ashen_stealth`；若已学会，提升 `current_mastery +130`，并令在灰烬中潜行时更难被听觉察觉。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `敏捷 ≥ 11`。
- **稀有度**：精良（Uncommon）
- **建议投放**：黑市商人、盗贼公会声望奖励、暗杀任务密室。

## 书籍内容

熄影步教盗贼如何在松软的灰烬中移动而不发出脚步声。作者指出，灰烬会放大脚步的摩擦声，但也会吸收高频震动，因此关键是控制落地的“第二声”——脚底完全压实时发出的挤压音。书中把潜行步法分为“落灰、沉灰、离灰”三拍，要求每一步都在下一次抬脚前让灰烬完全落定。作者还建议在衣物外撒一层细灰，让自己闻起来与周围环境一致。练习者需在一名蒙眼监听者背后绕行三圈而不被发现。尾页题词：“影子在火里会消失，在灰里会醒来。”书页边缘留有被炭火熏黑的空白，供读者记录自己的灰烬坐标。作者在跋文中提醒：灰烬交界的技法没有标准答案，只有烧剩下的答案。许多抄本的末页都沾着不同颜色的灰烬，那是前人练习时留下的印记。此抄本曾被余烬烫穿数页，缺失处反而逼迫读者用自己的经验补全。

## 设计意图

为盗贼系提供灰烬环境潜行强化，把异界微粒转化为隐蔽优势。
