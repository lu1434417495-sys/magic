# 《灰烬交界战士守则》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0183`
- **关联技能**：`ashen_shield_parry`
- **使用效果**：阅读后提升 `ashen_shield_parry` `current_mastery +100`，并解锁战士专属对话选项`ashen_warrior_code`。
- **阅读要求**：角色职业标签含 `warrior`；基础 `体质 ≥ 10`。
- **稀有度**：普通（Common）
- **建议投放**：断桥营寨军械库、战士导师任务、灰烬交界军营奖励。

## 书籍内容

这本书是灰烬交界前线士兵的行为手册，内容包括：不要单独进入静止区域、听到钟声就趴下、看到会动的灰烬先开枪再问、永远留一把短刀在触手可及处。作者用粗俗但有效的语言反复强调团队合作的重要性，称独自行动的战士不是英雄，是"会走路的补给箱"。书中还记录了多种战场信号：不同颜色的烟火代表撤退、集结、求援和"别过来"。最后几页是一份阵亡名单，名字后面都写着同一句话：他忘了第一条。名单旁边有一行新墨水的批注："第一条不是给新人看的，是给活人记住的。"这句话的墨迹比周围都新，说明最近还有人在使用这本守则。那行新墨水的字迹与作者本人的笔法略有不同，暗示有一位后来的老兵接过了续写的责任。整本书的纸张都带着灰烬交界特有的粗粝触感，翻阅时仿佛能听见远处裂隙的低语。

## 设计意图

作为战士职业在灰烬交界的背景书籍，提供熟练度与叙事选项。
