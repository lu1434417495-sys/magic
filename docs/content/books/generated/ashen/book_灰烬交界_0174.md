# 《黑暗斩痕的代价》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0174`
- **关联技能**：`ashen_dark_edge`
- **使用效果**：阅读后提升 `ashen_dark_edge` `current_mastery +150`，并使 `life_drain` 效果提升 25%。
- **阅读要求**：已学会 `ashen_dark_edge`；基础 `智力 ≥ 14` 且 `意志 ≥ 10`。
- **稀有度**：史诗（Epic）
- **建议投放**：沉钟书库封印室、黑暗法师临终遗赠、异界裂缝宝箱。

## 书籍内容

作者以第一人称记录了修炼黑暗斩痕的全过程。他提到每一次施法都会从自己身上带走一小段记忆：先是童年的一次生日，然后是一位朋友的名字，最后是自己为何开始修炼。书中没有给出避免代价的方法，反而反复强调"愿意支付代价"才是掌握黑暗斩痕的前提。中间章节用血画出了十二种斩痕轨迹，每一种都对应不同的生命吸取效率。最后几页字迹越来越潦草，最后一句话几乎无法辨认：我忘了为什么要写这本书，但还记得它很有用。书的封皮由某种黑色皮革制成，触感像是在抚摸一段被遗忘的噩梦。皮革上有一道浅浅的划痕，据说每当有人读完这本书，划痕就会变长一点点。那道划痕的长度每次测量都不完全相同，几位学者曾因此争论这是否只是幻觉。书脊处的烫金文字早已剥落，只剩下一层淡淡的金色粉末。

## 设计意图

作为黑暗斩痕的史诗级精通书，深化代价与收益的成长张力。
