# 《炭化大教堂治愈祷文》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0159`
- **关联技能**：`ashen_heal_prayer`
- **使用效果**：阅读后解锁 `ashen_heal_prayer`；若已学会，提升 `current_mastery +100` 并恢复全队每人少量 `current_hp`。
- **阅读要求**：角色拥有 `holy` 或 `support` 标签职业；基础 `意志 ≥ 9`。
- **稀有度**：普通（Common）
- **建议投放**：炭化大教堂祭坛、牧师新手任务、伤员救护支线。

## 书籍内容

这卷祷文被发现时正在铜炉里缓慢燃烧，抢救下来只剩中段和末尾。它没有祈求神迹，而是要求施术者先承认伤口属于身体的一部分，而非需要驱逐的敌人。祷文反复强调"稳"字：稳定的手势、稳定的呼吸、稳定的意图。治疗之力不是从天上砸下来的光，而是被施术者用意志一点点托住的生命节奏。中间还记录了一个被大教堂删去的细节：施术者必须先让自己的心跳慢下来，否则治疗之力会带上施术者自身的焦虑，反而加速伤者失血。残卷末尾附注：如果你在治疗时想着下一场战斗，光会穿过伤口，什么也不留下。卷轴背面用更淡的墨迹写着："我救过很多人，但第一个没救回来的人，我一直记得。"祷文卷轴的边缘有轻微卷曲，那是长期被潮湿手掌握住的痕迹。大教堂的修女们说这卷轴曾被七代牧师使用过，每一位都在背面留下了一句自己的祷告，层层叠叠像是一种无声的传承。祷文卷轴展开时会沙沙作响。

圣职系标准续航技能入口，保留朴素可靠的治疗气质。
