# 《灰烬爆发术》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0011`
- **关联技能**：`ashen_burst`
- **使用效果**：阅读后解锁 `ashen_burst`；若已学会，提升 `current_mastery +140`，并缩短下一次战斗中该技能的蓄力时间 10%。
- **阅读要求**：角色职业标签含 `mage` 或 `sorcerer`；基础 `智力 ≥ 11`。
- **稀有度**：稀有（Rare）
- **建议投放**：灰烬术士塔顶层、遗迹魔晶箱、黑市拍卖。

## 书籍内容

《灰烬爆发术》教授的法术原理简单得近乎粗暴：将大量灰烬压缩到极限，然后瞬间释放。难点不在于释放，而在于压缩过程中保持自己的魔力稳定。作者把这一过程比作握住一把正在燃烧的沙子：握得太松会散，握得太紧会烫伤自己。书中详细记录了爆发点的选择技巧，最佳位置通常是在敌人脚下或身后半步，这样冲击波会把敌人推向队友的攻击范围。练习者还需要学会控制释放后的反冲，因为灰烬爆发会把自己也向后推开。书末附有一张失败案例表，排名第一的死因是"在狭窄空间使用并把自己埋在塌方的灰烬中"。" 作者把灰烬爆发比作一次被精确控制的叹息：所有的力量都在一瞬间释放，但释放之前必须屏住呼吸。书中警告，蓄力时最容易犯的错误是提前绷紧肩膀，这会让魔力无法顺利流向手掌。正确的做法是想象肩膀是两扇门，蓄力时门要打开，释放时才猛然关闭。

## 设计意图

为法师系提供范围爆发与控制兼具的招牌技能。
