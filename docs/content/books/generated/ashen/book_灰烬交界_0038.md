# 《余烬指挥术》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0038`
- **关联技能**：`ashen_command`
- **使用效果**：阅读后解锁 `ashen_command`；若已学会，提升 `current_mastery +120`，并提高指令生效范围 1 格。
- **阅读要求**：角色职业标签含 `leader` 或 `tactician`；基础 `智力 ≥ 10` 或 `魅力 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：军团指挥部、战术学院、大型战役奖励。

## 书籍内容

《余烬指挥术》教导指挥官如何在灰烬交界的混乱战场上维持有效的指挥。作者指出，传统的旗帜和号角在这里效果有限，因为烟雾会遮蔽视线，余火会干扰声音。最有效的指挥方式是通过短促的灰烬信号：不同颜色的灰烬燃烧时会发出不同颜色的光，可以传递简单的命令。书中详细记录了十二种标准信号的含义，包括"集结""撤退""包围""固守"等。第二章讲解了指挥者自身的位置选择：不能太靠前，否则无法观察全局；也不能太靠后，否则信号传递会延迟。书的后半部分收录了多场著名战役的指挥复盘，总结了"三秒原则"：任何命令都必须在三秒内被下属理解。" 指挥术的高级章节讲"沉默指挥"：在不能发出声音的情况下，通过改变余火信号的颜色和闪烁频率传递复杂命令。这种技巧需要团队成员事先经过长期训练，但一旦掌握，就能在完全静音的情况下完成战术配合。

## 设计意图

为指挥型职业提供团队指令技能，强化多人协同与战术调度。
