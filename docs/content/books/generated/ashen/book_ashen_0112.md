# 《灰喉吟诵：异界战吼技法》

## 基础信息

- **书籍 ID**：`book_ashen_0112`
- **关联技能**：`ashen_war_cry`
- **使用效果**：阅读后解锁 `ashen_war_cry`；若已学会，提升 `current_mastery +130`，并在下一次战斗中令战吼附加恐惧效果（对普通敌人有效）。
- **阅读要求**：职业标签含 `warrior` 或 `barbarian`；基础 `体质 ≥ 9`。
- **稀有度**：精良（Uncommon）
- **建议投放**：狂战士训练场、战歌氏族营地、战场战利品箱。

## 书籍内容

灰喉吟诵不是用嗓子喊，而是用腹腔把声音压成一束，穿过灰烬弥漫的空气。书中指出，普通战吼在灰烬里会很快被细尘吸收，而灰喉吟诵利用的是低频震动，能让敌人在听到之前先感到胸口发麻。技法分为三段：吸气时想象把灰吸进腹部，发声时让声带保持松弛，收尾时把尾音故意截断制造不安。作者警告，灰喉吟诵最忌讳"漂亮"，尾音拖得越长，恐惧感反而越弱。书中还记录了不同敌人对吟诵的反应差异：野兽会僵直，亡灵会停顿，而某些灰烬原生生物会因此兴奋。最后几页是一些无法发出正常声音的战吼符号，供喉部受伤的老兵使用。灰喉吟诵的修习者通常会在清晨的灰雾中对着山谷练习，因为那里的回声能帮助他们判断声音是否真正凝聚成束。一个合格的吟诵者能让回音比自己原始的喊声更具压迫感。

## 设计意图

为狂战士/战士提供灰烬主题控场战吼，强化近战职业在异界战场的群体压制能力。
