# 《烬法师的火花笔记》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0062`
- **关联技能**：`ashen_spark`
- **使用效果**：阅读后解锁 `ashen_spark`；若已学会，提升 `current_mastery +130`，并令火花弹射次数 +1。
- **阅读要求**：角色职业标签含 `mage` 或 `sorcerer`；基础 `智力 ≥ 11`。

## 书籍内容

笔记来自一名在灰烬交界研究火花的年轻法师。作者发现，交界中的火星具有异常的弹跳性，会在物体表面之间连续传递。书中把“烬火花”定义为“尚未熄灭但已不再燃烧的光点”，并给出捕捉与引导它的手势。核心章节讲解如何让火花在敌人之间弹射：第一目标必须选择金属或湿润表面，第二目标则需处于同一视线内。作者警告，火花对施术者自己的饰品同样敏感，施法前应摘下金属戒指。练习者需在悬挂的铁片间让火花连续跳跃三次。尾页写着：“追逐火花的人，要先学会不被火花追上。”书页边缘留有被炭火熏黑的空白，供读者记录自己的灰烬坐标。作者在跋文中提醒：灰烬交界的技法没有标准答案，只有烧剩下的答案。许多抄本的末页都沾着不同颜色的灰烬，那是前人练习时留下的印记。

## 设计意图

为法师系提供灰烬系基础法术，用弹射机制体现异界火焰的独特物理。
