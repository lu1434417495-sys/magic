# 《灰烬冥想：余火坐》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0059`
- **关联技能**：`ashen_meditation`
- **使用效果**：阅读后解锁 `ashen_meditation`（`practice_tier = basic`，标签 `meditation`）；若已学会，提升 `current_mastery +150`，并在冥想时额外恢复少量 MP。
- **阅读要求**：无职业限制；基础 `意志 ≥ 9`。
- **稀有度**：稀有（Rare）
- **建议投放**：余烬祭所密室、冥想导师、灰烬交界静心据点。

## 书籍内容

余火坐是专为灰烬交界环境改编的冥想法门。作者认为，交界中的余烬是魔力循环的天然催化剂，但前提是不能抗拒那种微弱的灼烧感。书中要求练习者坐在尚有余温的硬地上，双腿盘结如柴堆，想象自己的呼吸是一缕即将熄灭却仍向上的烟。第一章讲解如何与肺部的轻微刺痛共处，而不是立刻撤退。第二章讨论“灰烬共鸣”：当呼吸节奏与周围余烬的闪烁同步时，MP 恢复效率会显著提升。作者警告，此法不可在明火旁练习，否则会从冥想变成自焚。尾页题词：“坐进灰烬里，才能听见火在说什么。”书页边缘留有被炭火熏黑的空白，供读者记录自己的灰烬坐标。作者在跋文中提醒：灰烬交界的技法没有标准答案，只有烧剩下的答案。许多抄本的末页都沾着不同颜色的灰烬，那是前人练习时留下的印记。

## 设计意图

把冥想系统延伸至灰烬异界，让环境危险转化为资源恢复条件。
