# 《灰烬箭术要略》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0008`
- **关联技能**：`ashen_arrow_shot`
- **使用效果**：阅读后解锁 `ashen_arrow_shot`；若已学会，提升 `current_mastery +120`，并提升对灰烬目标的首次命中暴击率 3%。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；基础 `感知 ≥ 10`。
- **稀有度**：精良（Uncommon）
- **建议投放**：风息哨塔废墟、游侠遗物、灰烬交界高处宝箱。

## 书籍内容

《灰烬箭术要略》指出，在灰烬交界射箭最大的敌人不是风，而是漂浮的炭粒。这些微粒会附着在箭羽上改变飞行轨迹，也会让瞄准镜变得模糊。作者发明了一种特殊的箭羽涂抹法：用冷却后的灰烬油涂抹羽毛，让它们变得更重、更稳定。书中最重要的章节是"延迟瞄准"——在完全拉满弓之后不要立刻放箭，而是等待一个心跳的时间，让呼吸与周围的灰烬沉降同步。后半部分收录了十二种交界生物的弱点位置，其中大部分都在关节或散热孔。末尾有一幅插画：一支箭穿过烟幕，钉入目标背后发光的裂缝，配文："看见烟，更要看见烟后面的东西。" 书中还收录了作者发明的"灰烬风向仪"：一根细长的铜针，顶端系着一小片炭化的羽毛。射手可以通过观察羽毛的摆动判断当前高度的风速与方向。作者提醒，不要只依赖眼睛，手指也要感受箭杆的微微震动，因为风的变化往往比视觉更早被触觉捕捉。

## 设计意图

为弓箭手提供适应灰烬环境的远程战技，突出精准与环境适应。
