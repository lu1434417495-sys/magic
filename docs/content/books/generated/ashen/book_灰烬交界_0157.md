# 《黑火球原理解析》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0157`
- **关联技能**：`ashen_black_fire_orb`

- **阅读要求**：角色职业标签含 `mage` 或 `rogue` 副修法系；基础 `智力 ≥ 11`。

- **建议投放**：坠墓镇黑咒学者、黑暗遗迹、灰烬交界地底宝箱。

## 书籍内容

黑火球不是普通火焰的放大版，而是一种更沉、更狠的爆压现象。作者把它描述为"把光吞掉的火焰"，并警告施术者不要盯着火球中心看，否则会短暂失明。书中详细讲解了压缩黑火的特殊呼吸法：吸气要比普通火焰短促，呼气却要拉得很长，让黑暗咒术在肺叶深处先形成稳定涡流。中间部分收录了三位因急于求成而被黑火反噬的学徒案例。最后几页是手绘的施法手势图，每个指尖位置都用红墨标出，旁边写着：黑火不听从渴望，只听从控制。书的封皮上有一块永远冰凉的焦痕，触摸时会让人做同一个噩梦。封皮内侧有一小块始终冰凉的焦痕，触摸时会让人短暂看到一团黑色火焰的幻象。作者警告读者不要频繁触摸这块痕迹，因为已经有三位学徒在触摸后连续做了三天同样的噩梦。焦痕周围的纸页比其他地方更脆，翻阅时必须格外小心，否则碎片会落进衣袖里。

## 设计意图

作为黑暗咒术爆发入口，与法师/盗贼副修形成差异化玩法。
