# 《焚书人的笔记：如何烧毁一本书》

## 基础信息

- **书籍 ID**：`book_ashen_0116`
- **关联技能**：`ashen_fire_control`
- **使用效果**：阅读后解锁 `ashen_fire_control`；若已学会，提升 `current_mastery +120`，并在下一次战斗中令所有火焰伤害提高 8%（一次性增益）。

## 书籍内容

这本笔记的作者自称焚书人，他的工作是在旧帝国崩溃前烧毁那些不该流传的知识。书的讽刺之处在于，它本身就是一本关于燃烧的书。焚书人把火分成两种：吃饭的火和杀人的火。前者需要被尊重，后者需要被控制。他详细描述了如何通过调整呼吸和手势让火焰"听话"：太急它会反扑，太缓它会熄灭，真正的控火者必须让火觉得自己还有选择。书中夹着几张被烧掉一半的旧书页，据说都是他曾经烧毁的书籍残留。最后一页没有字，只有一个烧焦的手印，旁边有一行小字："我烧掉了很多书，但这本我留了下来，因为火也需要被理解。"焚书人在笔记中承认，他曾烧毁过自己母亲的日记，因为其中记载了某种不该流传的火焰真名。他写道，有些知识之所以必须消失，不是因为它们邪恶，而是因为世界还没准备好承受它们。

## 设计意图

火焰法师/术士的灰烬主题控火技能，把"理解毁灭"作为力量来源的叙事。
