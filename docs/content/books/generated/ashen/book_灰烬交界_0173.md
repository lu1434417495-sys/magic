# 《雷枪的蓄电术》

- **书籍 ID**：`book_灰烬交界_0173`

## 书籍内容

这本书讲如何把雷枪"养"得更久。作者指出，普通雷枪是即时释放的奇迹，但高阶使用者可以让雷光在手中多停留一段时间，让它吸收空气中的电荷。书中警告：蓄电时不能移动，否则雷电会寻找最近的大地出口，可能是你自己的脚。中间章节详细记录了不同天气下的蓄电效率：雷雨天最佳，雪天最差，沙漠正午会让雷枪变得不稳定。后半本还讲到了"伪蓄电"战术：假装蓄力逼迫敌人提前闪避，再瞬间释放。最后一页是一段被闪电烧黑的字迹：雷枪是借来的光，别握太久。夹页里有一片始终带着静电的金属箔。夹页里有一片始终带着静电的金属箔，翻阅时会让书页发出轻微的噼啪声。作者提醒读者不要把金属箔靠近易燃物，已经有两位学徒因此烧掉了自己的眉毛。金属箔在干燥的天气里会让相邻书页粘在一起，翻阅时经常发出细小的撕裂声。

## 设计意图

为雷枪提供环境联动与战术欺骗空间，强化高阶奇迹玩法。
