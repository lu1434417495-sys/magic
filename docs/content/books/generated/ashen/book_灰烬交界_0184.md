# 《牧师的灰烬救赎》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0184`
- **关联技能**：`ashen_heal_prayer`
- **使用效果**：阅读后提升 `ashen_heal_prayer` `current_mastery +110`，并使在灰烬交界施放治愈祷告时额外清除一个随机减益。
- **阅读要求**：角色职业标签含 `priest` 或 `paladin`；基础 `意志 ≥ 11`。
- **稀有度**：精良（Uncommon）
- **建议投放**：炭化大教堂祭坛、圣职进阶任务、灰烬交界救援支线。

## 书籍内容

作者是一位随军牧师，她发现在灰烬交界施放治疗 miracle 时，光芒会带上淡淡的灰色。起初她以为这是污染，后来意识到这是灰烬本身在回应祷告：它把伤口周围的残留魔力一起带走。书中要求施术者在治疗时保持特殊心态：不要驱逐灰烬，而是请求它离开。中间章节讨论了如何在治疗烧伤、灰毒和灵魂侵蚀时调整祷文节奏。后半本是一份护理手册，记录了她救治过的士兵类型与对应祷文。最后一页写着：在灰烬里，救赎不是把黑暗推开，是把伤者从黑暗里拉出来。书的封底内侧有一枚小小的银质圣徽，已经被灰染成了暗色。作者在每完成一次艰难的救赎后都会抚摸这枚圣徽，她说这是她与自己的怀疑对话的方式。那枚圣徽在祈祷时会变得比平时更沉，像是吸收了太多未能说出口的愿望。

## 设计意图

强化牧师/圣骑士在灰烬交界的专属治疗价值。
