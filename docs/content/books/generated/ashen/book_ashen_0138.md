# 《烬眼：灰烬交界洞察术》

## 基础信息

- **书籍 ID**：`book_ashen_0138`
- **关联技能**：`ashen_vision`
- **使用效果**：阅读后解锁 `ashen_vision`；若已学会，提升 `current_mastery +120`，并在下一次战斗中令全体敌方弱点暴露 2 回合（一次性）。
- **阅读要求**：职业标签含 `ranger`、`mage` 或 `scholar`；基础 `感知 ≥ 10` 或 `智力 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：洞察者塔、学者任务、高阶侦察奖励。

## 书籍内容

烬眼不是真的长出一只燃烧的眼睛，而是一种让施术者能在灰烬中看清魔力流动和生命痕迹的感知技法。书中要求练习者先学会"闭眼"——不是物理上闭上眼睛，而是停止用视觉主导判断。然后感受周围温度的细微差异：生命体会产生不规则的热纹，魔力源则有稳定的脉动，而死物只会缓慢均匀地冷却。作者指出，烬眼最大的敌人是施术者自己的预期：当你预设会看到什么，灰雾就会配合你的想象制造假象。训练的最后阶段是在一场真正的灰雨中分辨敌我，很多学习者在这一步失败。书的末尾写着："看见真相的人，往往先承认自己什么都看不见。"烬眼的训练有一个危险的副作用：长期使用会让练习者在正常光线下也偶尔看到\"烬痕\"——人或物周围残留的温度轮廓。大多数使用者学会与之共处，少数人会因此失眠。

## 设计意图

侦察/辅助技能，为法系/游侠提供团队情报增益，强化灰烬环境下的感知机制。
