# 《灰烬幻象录》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0025`
- **关联技能**：`ashen_illusion`
- **使用效果**：阅读后解锁 `ashen_illusion`；若已学会，提升 `current_mastery +140`，并增加幻象存在数量 1 个。
- **阅读要求**：角色职业标签含 `mage` 或 `trickster`；基础 `智力 ≥ 12` 或 `魅力 ≥ 11`。
- **稀有度**：稀有（Rare）
- **建议投放**：幻术师塔、迷宫遗迹、欺诈商人。

## 书籍内容

《灰烬幻象录》教导如何用灰烬和魔力制造短暂的幻象。与普通幻象不同，灰烬幻象具有轻微的实体感，能够承受一次攻击才会消散。作者强调，制造幻象的关键不在于让它看起来像真人，而在于让它看起来像"一个会威胁到敌人的存在"。书中最重要的章节是"姿态欺骗"：一个静止的幻象远不如一个做出攻击前摇动作的幻象有威胁。第二章讲解了如何利用灰烬环境增强幻象：在烟雾中，幻象会变得更加逼真，因为敌人的视线本身就不清晰。书末警告，过度依赖幻象会让施术者自己的存在感减弱，最终连自己都分不清真假。" 幻象录的高级章节讨论"自我幻象"：制造一个自己的幻象，同时让真实身体隐藏起来。这种技巧的难点在于，幻象必须模仿施术者真实的呼吸节奏和微小动作，否则老练的敌人会通过"太完美"而识破。真正的幻象要有瑕疵。

## 设计意图

为幻术与诡计型职业提供分身与欺骗技能，强化战术多样性。
