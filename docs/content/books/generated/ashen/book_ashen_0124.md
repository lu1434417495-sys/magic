# 《烬刃铭刻：灰烬武器附魔入门》

## 基础信息

- **书籍 ID**：`book_ashen_0124`
- **关联技能**：`ashen_weapon_imbue`
- **使用效果**：阅读后解锁 `ashen_weapon_imbue`；若已学会，提升 `current_mastery +130`，并在下一次战斗中令主武器获得 3 回合火焰附魔（一次性）。
- **阅读要求**：职业标签含 `warrior`、`rogue` 或 `mage`；基础 `智力 ≥ 9` 或 `敏捷 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：灰烬铁匠密室、附魔师委托、高阶宝箱。

## 书籍内容

烬刃铭刻不是简单的把武器烧红，而是把余烬中的魔力以特定纹路导入金属。书中展示了十余种基础铭刻图案，每种图案对应不同的效果：螺旋纹增加持续燃烧，锯齿纹提升破甲，波浪纹则让火焰更容易蔓延。作者警告，铭刻必须在武器温度刚好降到临界线时进行，太早会毁掉图案，太晚则魔力无法附着。最危险的一步是"引燃"：用施术者自己的体温或一小团魔力点燃铭刻，让它真正活过来。书的中间夹有一张失败的铭刻图，整把刀从中间裂开，旁边批注："它醒了，但我没压住。"铭刻完成后，武器会在接下来的几个小时内持续散发微弱的热量。这段时间被称为\"蜜月期\"，附魔效果最稳定；之后效力逐渐衰减，需要重新激活或维护。铭刻师通常会在作品完成后低声说一句话，既是对武器的告别，也是对自己失误的预先道歉。

## 设计意图

武器附魔技能入口，为近战与混合职业提供临时元素强化玩法。
