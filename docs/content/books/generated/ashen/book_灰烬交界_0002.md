# 《余烬剑术入门》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0002`
- **关联技能**：`ashen_blade_strike`
- **使用效果**：阅读后解锁 `ashen_blade_strike`；若已学会，提升 `current_mastery +130`，并使该技能在接下来三场战斗中对余烬目标额外造成 5% 伤害。
- **阅读要求**：角色职业标签含 `warrior` 或 `rogue`；基础 `力量 ≥ 9` 或 `敏捷 ≥ 9`。
- **稀有度**：普通（Common）
- **建议投放**：灰烬熔炉训练场、废弃兵营、剑士导师委托。

## 书籍内容

《余烬剑术入门》的封皮用烧焦的皮革包裹，摸起来仍然温热。书中拒绝讨论华丽的剑招，只讲三件事情：角度、节奏、余烬。作者认为剑锋划过空气时带起的灰烬本身就是一种武器，因为它会迷乱敌人的眼睛。入门篇反复练习的是一个斜向斩击，要求练习者在剑刃到达最低点的瞬间松开握力，让惯性完成最后的切割。书中警告，握紧剑柄直到最后一刻是许多新手受伤的原因。后半部分收录了十五位战死剑士的最后一击，每人只有一句话的批注。其中一句被反复圈出："剑停的时候，余烬还在飞。" 作者特别画了一幅失败者的手部特写：因为紧握剑柄，虎口被震裂，血顺着剑格滴到地上，把灰烬黏成暗红色的泥。他写道，受伤不是因为敌人太强，而是因为你舍不得放手。真正的余烬剑士会在斩击完成后的瞬间把手指张开，让剑自己找回落点，再用下一次握力接住它。

## 设计意图

为近战职业提供灰烬交界的标志性斩击技能，强调节奏而非蛮力。
