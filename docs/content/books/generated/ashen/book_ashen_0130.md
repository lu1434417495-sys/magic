# 《灰雾中的回声定位》

## 基础信息

- **书籍 ID**：`book_ashen_0130`
- **关联技能**：`ashen_echo_sense`
- **使用效果**：阅读后解锁 `ashen_echo_sense`；若已学会，提升 `current_mastery +120`，并在下一次战斗中每回合自动揭示一个隐藏敌人的大致位置（持续 3 回合）。
- **阅读要求**：职业标签含 `ranger`、`rogue` 或 `monk`；基础 `感知 ≥ 11`。
- **稀有度**：稀有（Rare）
- **建议投放**：盲眼僧侣隐居处、回声洞穴任务、感知训练奖励。

## 书籍内容

在能见度极低的灰烬环境中，有些人学会用声音来"看"世界。这本书教授一种古老的回声定位技法：通过短促的拍手、脚步声或杖击地面，根据回声判断周围物体的形状和距离。作者是一名双目失明的武僧，他认为视觉在灰烬中反而是负担，因为眼睛会被灰雾中的光影欺骗。书中详细描述了如何训练耳朵分辨不同材质的回声：灰壳是沉闷的、金属是尖锐的、生物体则是带有轻微颤动的。训练过程非常枯燥，要求练习者蒙眼在灰堆中行走数周。书的末尾写着："当你不再依赖眼睛，灰烬就不再是迷雾，而是无数层声音。"高级练习者能通过回声判断目标的情绪：紧张的生物呼吸急促，会在回声中加入细微的颤抖；而冷静的埋伏者几乎不产生额外的声波，这反而会成为他们被发现的线索。练习到一定境界后，使用者甚至能通过回声感知到墙壁或障碍物背后的空洞，提前发现隐藏的通道。

## 设计意图

感知型侦察技能，强化灰烬环境下的信息获取，为高风险区域探索提供克制隐身敌人的手段。
