# 《灰烬忍法：灰替身》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0090`
- **关联技能**：`ashen_decoy`
- **使用效果**：阅读后解锁 `ashen_decoy`；若已学会，提升 `current_mastery +130`，并令灰烬替身存在期间吸引一次敌方单体攻击。
- **阅读要求**：角色职业标签含 `rogue`、`ninja` 或 `assassin`；基础 `敏捷 ≥ 12`。
- **稀有度**：稀有（Rare）
- **建议投放**：影行会、盗贼公会密室、暗杀任务奖励。

## 书籍内容

灰替身教刺客用灰烬和旧衣物制造一个短暂迷惑敌人的替身。作者认为，灰烬的飘动特性会让静态假人在远处看起来像真正移动的目标。书中把制作过程分为“塑型、赋温、引动”三步：先用灰和布捏出人形，再在内部放入一小块余烬让它有温度，最后用细线或微风让它轻微晃动。核心章节讲解放置位置：必须处于敌人最可能射击的直线方向上，同时让自己躲到侧翼。作者警告，灰替身只能欺骗一次，一旦被击中就会散架。练习者需在训练场让同伴向替身射出一箭。尾页写着：“死一次是悲剧，让别人以为你死了是艺术。”书页边缘留有被炭火熏黑的空白，供读者记录自己的灰烬坐标。作者在跋文中提醒：灰烬交界的技法没有标准答案，只有烧剩下的答案。许多抄本的末页都沾着不同颜色的灰烬，那是前人练习时留下的印记。

## 设计意图

为刺客系提供灰烬主题脱身与欺骗技能，强化机动与生存能力。
