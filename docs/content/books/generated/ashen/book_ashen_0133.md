# 《灰烬炼金：爆炸与药剂之间》

## 基础信息

- **书籍 ID**：`book_ashen_0133`
- **关联技能**：`ashen_alchemy`
- **使用效果**：阅读后解锁 `ashen_alchemy`；若已学会，提升 `current_mastery +120`，并立即获得 2 瓶灰烬药剂（随机效果：攻击/防御/恢复）。
- **阅读要求**：职业标签含 `alchemist` 或 `mage`；基础 `智力 ≥ 10`。
- **稀有度**：精良（Uncommon）
- **建议投放**：炼金术士塔、灰烬集市商人、实验任务奖励。

## 书籍内容

灰烬炼金术是把灰烬交界的残余物转化为有用药剂的技艺，介于科学与赌博之间。这本书介绍了十几种基础配方，每一种都强调"不稳定"是这个学科的核心美学。作者把药剂分成三类：温药、热药和烬药。温药安全但效果弱，热药效果显著但有副作用，烬药则可能在瓶中继续反应，变得更强或彻底失效。书中最好的一章是"如何逃跑"：当一瓶药剂开始冒烟、变色或发出尖锐声音时，你应该做什么、不该做什么。书的空白处有大量烧焦的痕迹，显示作者自己也曾多次失败。最后一页写着："在灰烬炼金里，最大的成就不是成功，是失败后还能数清自己的手指。"炼金师之间有一句谚语：\"第一次爆炸是老师，第二次爆炸是朋友，第三次爆炸是镜子。\"它提醒从业者，每一次失败都在反映操作者内心的急躁或贪婪。

## 设计意图

炼金 crafting 技能，为法系/炼金职业提供药剂制作与随机效果玩法，契合灰烬主题。
