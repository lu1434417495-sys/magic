# 《余烬标记术》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0020`
- **关联技能**：`ashen_mark`
- **使用效果**：阅读后解锁 `ashen_mark`；若已学会，提升 `current_mastery +110`，并提高标记后首次攻击的暴击率 4%。
- **阅读要求**：角色职业标签含 `ranger` 或 `assassin`；基础 `感知 ≥ 10`。
- **稀有度**：精良（Uncommon）
- **建议投放**：猎人营地、游侠导师、追踪任务奖励。

## 书籍内容

余烬标记术教导射手和猎手如何用特殊的灰烬混合物在目标身上留下难以察觉的印记。这种印记在常温下 invisible，但在灰烬交界的特殊光线下会微微发亮。作者强调，标记最重要的是隐蔽性：如果目标发现自己被标记，就会立刻改变行动模式。书中介绍了三种标记方式：涂抹式用于近战偷袭，投掷式用于远程追踪，陷阱式用于预设埋伏。第二章讲解了如何根据目标的皮肤或护甲材质调整灰烬混合物的配方：鳞片类需要更强的附着力，毛皮类则需要更细的颗粒。书的后半部分收录了多个著名猎人的追踪笔记。最后一页写着："标记不是结束，是开始的开始。" 标记术的高级应用是"连锁标记"：在多个目标身上留下同类型的印记，当其中一个目标受到伤害时，其他被标记目标也会感受到微弱的灼痛。这种技巧在狩猎群体目标时极为有效，但需要极高的专注力来维持印记之间的联系。

## 设计意图

为远程与刺杀职业提供集火与追踪工具，强化团队协作。
