# 《灰烬中的阴影契约》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0190`
- **关联技能**：`ashen_dark_edge`
- **使用效果**：阅读后提升 `ashen_dark_edge` `current_mastery +100`，并解锁盗贼/法师副修的暗影知识对话。
- **阅读要求**：角色职业标签含 `rogue` 或 `mage`；基础 `智力 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：坠墓镇地下密室、黑市拍卖、暗影导师任务奖励。

## 书籍内容

这本书没有明确作者，每一章的笔迹都不同，仿佛是被多人接力写成的。它讨论了如何在灰烬交界与"阴影"达成临时契约：施术者付出一段记忆或一个秘密，换取短时间内更稳定的黑暗咒术控制。书中警告这种契约不是魔法，而是交易，每次交易的代价都会累加。中间章节收录了七份契约模板，每份都被不同程度地涂改过。最后几页是一份名单，上面列着历史上几位著名暗影使用者的名字，每个名字后面都跟着同一个词：遗忘。名单下方有一行更淡的字："如果你看到自己的名字出现在这里，说明你已经忘了这件事。"这句话让许多读者在阅读后不由自主地检查了一遍名单。名单下方的字比上方更淡，作者似乎越写到后面越不确定自己是否还应该继续。整本书的纸张都带着灰烬交界特有的粗粝触感，翻阅时仿佛能听见远处裂隙的低语。

## 设计意图

作为黑暗向知识与技能结合的书籍，深化盗贼/法师副修路线。
