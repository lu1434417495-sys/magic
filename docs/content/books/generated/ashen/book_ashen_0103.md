# 《炭壳拳：交界近身短打》

## 基础信息

- **书籍 ID**：`book_ashen_0103`
- **关联技能**：`ashen_cinder_fist`
- **使用效果**：阅读后解锁 `ashen_cinder_fist`；若已学会，提升 `current_mastery +130`，并在下一次战斗中令首次命中附带 1 层余烬灼烧。
- **阅读要求**：职业标签含 `warrior` 或 `monk`；基础 `力量 ≥ 9`。
- **稀有度**：精良（Uncommon）
- **建议投放**：断桥营寨拳师、炭壳矿洞宝箱、近战训练场奖励。

## 书籍内容

炭壳拳没有花哨的招式，它的核心是把拳面想象成一层即将碎裂的炭壳：外面冷硬，里面藏着最后一丝高温。书中要求练习者先在冷水里握拳三分钟，感受皮肤发白、关节僵硬，然后再出拳击打热灰堆。这样做的目的不是锻炼力量，而是让身体记住"冷包热"的触感。正式技法只有四式：崩壳、裂灰、回烬、散烟。崩壳是直线短打，裂灰针对护甲接缝，回烬是受挫后的二次发力，散烟则是在连击中制造视线干扰。作者在每个招式后都加了一句"别贪恋热度"，因为炭壳拳最危险的时刻不是击中，而是击中后想追加一拳、结果自己先被烫伤。为了掌握这门拳法，许多练习者会在拳面上裹一层薄灰，以测试自己出拳时是否能让灰壳刚好碎裂而不飞散。这种训练看似原始，却能有效纠正手腕僵硬和发力过猛的问题。

## 设计意图

为战士/武僧提供灰烬风格的近战输出技能，突出"冷热交替"与"灼烧层数"的节奏感。
