# 《灰烬预见录》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0043`
- **关联技能**：`ashen_foresee`
- **使用效果**：阅读后解锁 `ashen_foresee`；若已学会，提升 `current_mastery +140`，并延长预见窗口 0.5 秒。
- **阅读要求**：角色职业标签含 `monk` 或 `seer`；基础 `感知 ≥ 12` 或 `智力 ≥ 12`。
- **稀有度**：稀有（Rare）
- **建议投放**：先知神殿、占卜师营地、预言任务奖励。

## 书籍内容

《灰烬预见录》教导练习者通过观察灰烬飘落的方向和速度来预测短时间内即将发生的事情。作者认为，灰烬交界的空气中充满了信息，只是大多数人的感知太慢。书中第一章让练习者盯着一个燃烧的余烬，试图在火焰闪烁的瞬间看到下一刻的形状。第二章进阶到战斗应用：通过观察敌人动作带起的灰烬流动，预判对方的攻击轨迹。作者强调，预见不是看见未来，而是看见未来最有可能的路径。书的后半部分记录了多位先知的笔记，其中一人写道："最准确的预见往往是最不愿意相信的。" 预见录警告，预见到的未来只是概率最高的一种，不是命中注定。作者讲述了一位先知因为坚持相信自己预见到的灾难，反而通过行动促成了那场灾难的故事。他写道："预见最大的危险，是让你成为自己预言的同谋。"

## 设计意图

为感知型职业提供预判与闪避增益技能，强化高技巧战斗。
