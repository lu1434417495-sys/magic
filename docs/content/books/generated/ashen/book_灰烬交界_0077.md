# 《灰烬壁垒构筑法》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0077`
- **关联技能**：`ashen_wall`
- **使用效果**：阅读后解锁 `ashen_wall`；若已学会，提升 `current_mastery +130`，并令壁垒存在期间阻挡远程攻击的概率提高。
- **阅读要求**：无职业限制；基础 `体质 ≥ 11`。
- **稀有度**：稀有（Rare）
- **建议投放**：战士训练场、要塞据点、灰烬遗迹宝箱。

## 书籍内容

构筑法教人如何用灰烬和碎石快速筑起一道临时壁垒。作者指出，灰烬壁垒的强度不在于材料，而在于密度：压得越实的灰墙越能吸收冲击。书中把构筑过程分为“奠基、堆叠、压实”三步，每一步都有对应的工具和手法。核心技巧是“热压”：在灰层尚有余温时压实，冷却后外壳会变得坚硬。作者还讨论如何在壁垒上留出射击孔，以及如何设置易崩塌段作为陷阱。练习者需在规定时间内筑起能抵挡一次投掷的矮墙。尾页题词：“墙不是让人躲在后面，是让人有时间重新站起来。”书页边缘留有被炭火熏黑的空白，供读者记录自己的灰烬坐标。作者在跋文中提醒：灰烬交界的技法没有标准答案，只有烧剩下的答案。许多抄本的末页都沾着不同颜色的灰烬，那是前人练习时留下的印记。此抄本曾被余烬烫穿数页，缺失处反而逼迫读者用自己的经验补全。
