# 《烬灭剑诀：灰烬剑士的奥义》

## 基础信息

- **书籍 ID**：`book_ashen_0132`
- **关联技能**：`ashen_extinction_blade`
- **使用效果**：阅读后解锁 `ashen_extinction_blade`；若已学会，提升 `current_mastery +160`，并在下一次战斗中令终极一击无视目标 20% 火焰抗性（一次性）。
- **阅读要求**：职业标签含 `warrior`、`swordmaster` 或 `knight`；基础 `力量 ≥ 12` 且 `敏捷 ≥ 10`。
- **稀有度**：史诗（Epic）
- **建议投放**：灰烬剑冢、剑圣传承任务、异界裂隙核心宝箱。

## 书籍内容

烬灭剑诀被认为是灰烬剑士一脉的最高奥义，据说创立者在挥出最后一剑后自己也化为了灰烬。书中没有繁复的招式，只有一式：把全身的力量、意志和斗气压缩进一剑，在击中目标的瞬间让剑身燃烧、熄灭、再燃烧。作者反复强调，烬灭不是毁灭，而是让一切回归灰烬的仪式；使用者必须怀抱"同归于尽"的觉悟，才能真正挥出这一剑。后半本全是前辈的失败记录，他们要么力量不够导致剑身提前碎裂，要么意志动摇让火焰反噬自身。书的最后一页只有一行字："当你愿意成为灰烬时，灰烬也会为你让路。"据说完整的烬灭剑诀共有九重境界，但流传下来的只有前三重。后六重没有文字，只有一句话作为提示：\"当你不再需要这本剑诀时，第四重自然会出现。\修习烬灭剑诀的人常在剑柄上缠绕一圈自己的头发，作为必要时献给火焰的祭品，也提醒自己已无可后退。

## 设计意图

高阶战士剑技，作为灰烬剑士体系的顶点技能，提供高爆发与主题叙事的高潮体验。
