# 《灰烬炼金：火药与灰》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0075`
- **关联技能**：`ashen_alchemy`
- **使用效果**：阅读后解锁 `ashen_alchemy` 配方树；若已学会，提升 `current_mastery +120`，并降低灰烬炼金制品的制作失败率。
- **阅读要求**：无职业限制；基础 `智力 ≥ 11`。
- **稀有度**：精良（Uncommon）
- **建议投放**：炼金术士摊位、工匠行会、灰烬遗迹实验室。

## 书籍内容

这本笔记把灰烬交界的余烬当作炼金材料，记录了几种稳定且可用的配方。作者指出，异界灰烬含有微量魔力残留，可以作为催化剂或燃料。书中给出三种入门配方：灰火药、余烬膏、冷却粉尘。每种配方都强调比例与研磨顺序，因为灰烬活性会随时间衰减。核心章节讲如何避免爆炸：研磨时必须加入稳定剂，混合时不能产生静电。作者警告，新手最容易犯的错误是认为“更多灰烬等于更强效果”。练习者需成功制作一份稳定燃烧的余烬膏。尾页批注：“炼金不是让东西烧起来，是让东西按你想的方式烧完。”书页边缘留有被炭火熏黑的空白，供读者记录自己的灰烬坐标。作者在跋文中提醒：灰烬交界的技法没有标准答案，只有烧剩下的答案。许多抄本的末页都沾着不同颜色的灰烬，那是前人练习时留下的印记。

## 设计意图

为生活职业与探索者提供灰烬炼金入口，把环境资源转化为消耗品经济。
