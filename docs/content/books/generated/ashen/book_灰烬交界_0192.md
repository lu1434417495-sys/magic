# 《灰烬裂隙行者指南》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0192`
- **关联技能**：`ashen_roll`
- **使用效果**：阅读后提升 `ashen_roll` `current_mastery +100`，并解锁快速穿越小型裂隙的能力，在灰烬交界移动时有几率跳过普通战斗。
- **阅读要求**：已学会 `ashen_roll`；基础 `敏捷 ≥ 11`。
- **稀有度**：稀有（Rare）
- **建议投放**：余烬祭所高级导师、裂隙探索任务、异界宝箱。

## 书籍内容

裂隙是灰烬交界最危险也最便利的通道。作者是一名专门研究裂隙的行者，他把穿越裂隙称为"在世界皮肤上滑动"。书中指出裂隙不稳定，进入前必须确认另一端的位置，否则可能被传送到断层中央或敌人堆里。作者提供了"探针法"：先丢一块小石头或一根火把进裂隙，观察另一端是否安全。中间章节还讲到了如何在裂隙中保持方向感：闭上眼睛、屏住呼吸、想象自己的身体像箭一样直飞。最后几页是一份警告清单，第一条就是：不要背着队友进裂隙，除非你想一个人出来。清单下方有人用血写着："我曾经出来了，但他们没有。"这行字的笔迹与上方不同，像是另一位裂隙行者后来补充的警告，让指南带上了一丝沉重的真实感。那行血字已经渗入了纸张纤维，无论如何都无法完全擦除，像是一个永远无法撤销的誓言。

## 设计意图

为机动型角色提供探索增益，深化灰烬交界裂隙机制。
