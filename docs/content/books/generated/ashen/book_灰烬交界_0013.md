# 《灰烬召唤残篇》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0013`
- **关联技能**：`ashen_summon_ember`
- **使用效果**：阅读后解锁 `ashen_summon_ember`；若已学会，提升 `current_mastery +130`，并延长召唤物存在时间 1 回合。
- **阅读要求**：角色职业标签含 `warlock` 或 `necromancer`；基础 `智力 ≥ 11` 或 `意志 ≥ 11`。
- **稀有度**：稀有（Rare）
- **建议投放**：灰烬召唤祭坛、禁忌书库、深渊商人。

## 书籍内容

这本残篇被发现时只剩前半部分，后半似乎被某种力量烧掉了。书中教授的召唤术不是召唤生物，而是召唤"余烬意识"——一团有简单智能的灰烬聚合体。这种召唤物没有固定形态，会根据周围环境的温度改变自己的形状。作者强调，与余烬意识沟通不是靠命令，而是靠提供燃料：一小块木炭、一滴血、或者一段记忆。书中警告，余烬意识会模仿召唤者的情绪，如果召唤者心怀恐惧，召唤物也会变得畏缩。残篇末尾被撕毁，只留下一个未完成的召唤阵和一句警告："不要问它们从哪里来。" 召唤残篇中有一段关于"喂养"的讨论。作者认为余烬意识不会真正吃饱，它们只是渴望被记住。如果召唤者能在提供燃料的同时讲述一段自己的记忆，召唤物会变得更稳定、更愿意执行复杂命令。书中警告，不要讲述太过痛苦的记忆，否则召唤物会吸收那种痛苦并反过来影响召唤者。

## 设计意图

为召唤系职业引入灰烬交界的特色召唤物，强调情绪共鸣与资源维持。
