# 《原力震荡讲义》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0160`
- **关联技能**：`ashen_force_burst`
- **使用效果**：阅读后解锁 `ashen_force_burst`；若已学会，提升 `current_mastery +140` 并减少该技能首次使用 MP 消耗 1 点。
- **阅读要求**：角色职业标签含 `priest` 或 `paladin`；基础 `意志 ≥ 10`。
- **稀有度**：精良（Uncommon）
- **建议投放**：炭化大教堂密室、圣骑士训练场、奇迹导师奖励。

## 书籍内容

原力震荡被作者称为"贴脸时的最后一次礼貌"。它的核心不是伤害，而是把敌人从法师或牧师身边掀开。书中把施法动作分为三段：收束、外放、收束。外放那一瞬要像把胸腔里的空气一次性推出去，而不是用手势去推敌人。作者特别提醒：不要在敌人已经贴到背后时使用，因为推退方向会不可控。中间章节收录了七位牧师的实战笔记，每个人都提到自己曾把敌人推到队友脸上。最后几页是一幅被撕坏的图示，只剩大字标题：震荡之后的第一秒，决定你是活着还是只是被推了一下。讲义夹页里有一片碎裂的护符，上面刻着"先护身后伤人"。讲义中间夹着一片碎裂的护符，上面刻着"先护身后伤人"。据说这是作者第一次成功用原力震荡救下队友时佩戴的护符，碎裂是因为替他挡下了一次偷袭。护符碎片在靠近圣职人员时会微微发热，仿佛在辨认与它共鸣过的那种善意。

## 设计意图

圣职近身解围技入口，强化牧师/圣骑士的保护与控场定位。
