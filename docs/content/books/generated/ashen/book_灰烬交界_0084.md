# 《灰烬牧师：余烬圣礼》

## 书籍内容

余烬圣礼是一种把灰烬重新定义为神圣物质的仪式。作者认为，灰烬是事物燃烧后最接近本质的状态，因此可以作为向神圣存在献祭的媒介。书中要求施术者收集七把来自不同燃烧物的余烬，在祭坛上排成螺旋形，再带领参与者共同默念感恩词。仪式完成后，灰烬会被祝福，参与者可在短时间内获得对火焰的抵抗。作者警告，圣礼不能被用于复仇或炫耀，否则余烬会拒绝被祝福。练习者需先学会正确收集和保存不同来源的余烬。尾页经文：“灰烬之下，万物平等；被祝福的灰，是平等的证明。”书页边缘留有被炭火熏黑的空白，供读者记录自己的灰烬坐标。作者在跋文中提醒：灰烬交界的技法没有标准答案，只有烧剩下的答案。许多抄本的末页都沾着不同颜色的灰烬，那是前人练习时留下的印记。
