# 《踢击破防入门》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0153`
- **关联技能**：`ashen_guard_kick`
- **使用效果**：阅读后解锁 `ashen_guard_kick`；若已学会，提升 `current_mastery +130` 并使下一次使用该技能时必定移除目标 `guard`。
- **阅读要求**：角色职业标签含 `warrior` 或 `berserker`；基础 `力量 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：断桥营寨训练场、狂战士聚落、龟缩敌人掉落。

## 书籍内容

这本书专门对付举着盾不肯动的敌人。作者认为踢击的精髓不是伤害，而是羞辱对方的防御姿态。第一章讲重心：起脚时身体要略侧，让脚跟对准盾面中心偏下的位置，这样能把对方重心向上挑。第二章讲时机：必须在对方刚进入防御姿态、肌肉最紧张的那一刻踢出，早了会被架开，晚了则失去意义。书中还列举了七种常见盾牌的接缝弱点，并提醒练习者不要被反震伤到脚踝。最后一页是一幅简笔插画，一个战士正把敌人连同盾牌一起踹得双脚离地。封皮内侧写着一行小字："最好的踢击不是让盾飞出去，是让拿盾的人后悔举起来。"夹页中掉出一枚生锈的营寨徽章。封底印着一行小字："本教材由断桥营寨第七步兵队赞助出版"。旁边还有一行更小的批注："他们赞助的原因是他们受够了举着盾的敌人"。这让整本书带上了一丝前线士兵特有的黑色幽默。封皮内侧还留着几处浅浅的鞋印。

## 设计意图

为战士/狂战士提供破防入口，强调功能型战技的战术价值。
