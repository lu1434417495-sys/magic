# 《炭化大教堂治愈祷文残卷》

## 基础信息

- **书籍 ID**：`book_heal_prayer_fragment`
- **关联技能**：`priest_healing_light`、`ashen_heal_prayer`
- **使用效果**：阅读后解锁 `priest_healing_light`；若已学会，提升 `current_mastery +100` 并恢复全队每人少量 `current_hp`。
- **阅读要求**：角色拥有 `holy` 或 `support` 标签职业；基础 `意志 ≥ 9`。
- **稀有度**：普通（Common）
- **建议投放**：炭化大教堂祭坛、牧师新手任务、伤员救护支线。

## 书籍内容

这卷祷文被发现时正在一只铜炉里缓慢燃烧，抢救下来时只剩中段和末尾。炭化的大教堂神父们把它重新装裱，但谁也不敢补全缺失的开头——据说每一次补写尝试都会在当夜引发高烧与耳鸣。可阅读的部分内容朴素得近乎固执：它没有祈求神迹，而是要求施术者先承认伤口属于身体的一部分，而不是需要驱逐的敌人。祷文反复强调"稳"字：稳定的手势、稳定的呼吸、稳定的意图；治疗之力不是从天上砸下来的光，而是被施术者用意志一点点托住的生命节奏。残卷中间还记录了一个被大教堂后来删去的细节：施术者必须先让自己的心跳慢下来，否则治疗之力会带上施术者自身的焦虑，反而加速伤者的失血。残卷末尾有一段被烟熏黑的附注，依稀可辨："如果你在治疗时想着下一场战斗，光会穿过伤口，什么也不留下。"

## 设计意图

治愈祷文残卷是圣职系的标准续航技能入口，设计气质偏向"朴素可靠"，与灰烬交界 Heal 的稳住节奏感一致。全队少量回血的效果让这本书在营地/据点阅读时有额外仪式感。
