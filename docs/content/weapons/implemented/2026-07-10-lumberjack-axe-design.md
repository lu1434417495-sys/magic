# 伐木工之斧武器重设计

日期：2026-07-10
状态：已实现并通过聚焦回归
来源：`docs/content/weapons/by_family/axes_02.md:59`

## 设计目标

伐木工之斧原设计只有面对植物生物时才提供直接战斗收益，快速砍伐依赖当前不存在的常规砍树行动，树的愤怒还会在使用核心能力后强化敌人。新版改为一把通用的持续伐倒战斧：先在目标身上留下劈痕，随后顺着劈痕提高命中并追加伤害；砍倒已经留下劈痕的目标时返还本次行动消耗的一部分 AP。

新版不使用三层爆发。当前已经有碎骨、霜咬、蛇发女妖弩、寒霜锤和岩石戟采用同目标第三次命中触发，永恒之刃和月蚀战斧也使用叠满三层后由下一击结算的近似结构。伐木工之斧改用单层持续状态与无次数限制的击杀回势，避免继续复用同一节奏。

## 武器来源

- 名称：伐木工之斧
- 内部物品 id：`weapon_unique_battleaxe_lumberjack_383`
- 武器族：斧
- 基础物品：`weapon_type_battleaxe_base`
- 训练组：军用
- 射程：近战 1 格
- 单手伤害：`1D8+2`
- 双手伤害：`1D10+2`
- 属性：多用
- 原始价格：22000
- 重设计价格：38000
- 原始特殊性质：快速砍伐、植物杀手、树的愤怒

价格提高到 38000。新版对普通目标有稳定的命中与伤害收益，并能在多目标战斗中通过击杀返还 AP；其单体持续收益略低于 40000 档的霜咬，但清杂行动经济明显更强。

## 重设计总览

新版包含三条能力：

1. 顺纹连斩：真实武器命中存活目标后留下单层劈痕；攻击自己留下劈痕的目标时命中 `+1`，命中后追加 `1D4 physical_slash`。
2. 植物杀手：真实武器命中 `plant` 目标时追加 `2D6 physical_slash`。
3. 倒木回势：使用本斧的真实武器攻击击杀命中前已有自身劈痕的目标时恢复 `1 AP`，不限制每回合触发次数，但不能超过正常回合 AP 上限。

原快速砍伐与树的愤怒不保留。两者都依赖当前没有正式 owner 的世界砍树事件；倒木回势承担通用战斗中的伐倒主题。

## 特性设计

### 顺纹连斩

伐木工之斧的真实武器攻击命中一个仍然存活的目标后，目标获得或刷新一层劈痕：

- 状态 id：`lumberjack_chop_notch`
- 持续时间：`60TU`
- 层数上限：1
- 叠层方式：刷新
- 来源：记录施加劈痕的战斗单位 id
- 类型：可见、不可驱散的物理负面状态

攻击命中前已经带有该持有者劈痕的目标时：

- 本次真实武器攻击检定获得 `+1`。
- 命中后追加 `1D4 physical_slash`。
- 目标仍存活时，将劈痕刷新为 `60TU`。

标准节奏为：

```text
第一击：基础伤害，目标存活则留下 1 层劈痕
后续击：命中 +1，基础伤害 +1D4，目标存活则刷新劈痕
```

未命中不会施加或刷新劈痕。第一击直接击杀目标时不施加劈痕，因此不能触发倒木回势。命中但最终 HP 伤害为 0 时，只要目标仍存活，仍视为斧刃命中并施加或刷新劈痕。

同一目标同一时刻只保留一个 `lumberjack_chop_notch`。另一名持有者第一次命中该目标时不能读取旧来源的加值；若目标存活，本次命中把劈痕来源改为新持有者。不同目标可以各自保留一层劈痕。

### 植物杀手

伐木工之斧真实武器攻击命中生物分类包含 `plant` 的目标时，额外造成 `2D6 physical_slash` 伤害。

- 使用战斗单位正式 `creature_type_tags`，不回查敌人模板。
- 走通用 `add_damage_dice`，沿用现有暴击、减伤与伤害事件语义。
- 可与顺纹连斩的 `1D4` 同时生效。
- 不对缺少 `plant` 标签的目标生效。

### 倒木回势

使用伐木工之斧参与结算的真实武器攻击击杀目标时，同时满足以下条件才恢复 AP：

1. 击杀来源是包含真实武器伤害的攻击。
2. 击杀来源装备实例就是当前伐木工之斧。
3. 目标在本次攻击命中前已经带有该持有者留下的 `lumberjack_chop_notch`。

满足条件时恢复 `1 AP`：

- 每回合触发次数不设上限。
- 当前 AP 不得超过该单位属性快照中的正常回合 AP 上限。
- 不恢复基础攻击消耗的 8 点体力，也不恢复技能的 MP、体力、灵光或冷却。
- 一次多目标攻击击杀多个符合条件的目标时，每个目标分别结算一次，但每次结算后仍执行 AP 上限裁剪。
- 法术、持续伤害、环境伤害、其他武器和第一击直接击杀均不触发。

因此它可以连续处理此前已经砍出劈痕的低生命目标，但不能把 AP 堆到正常上限以上，也仍受体力和可用目标数量限制。

## 强度基准

对普通单体目标，第一击没有额外伤害，后续命中平均增加 2.5 点伤害并获得 `+1` 命中。它的纯单体伤害低于每击追加 `1D6` 且带控制的霜咬，但基础平加值高 1。

对植物目标，每次命中再追加平均 7 点伤害；已有劈痕时 `1D4+2D6` 同时结算。

倒木回势主要提高多目标战斗的行动效率。每个可返 AP 的目标都必须先承受至少一次未致死的真实武器命中，而且基础攻击仍消耗 8 点体力，因此它是强力连续收割而不是无成本无限行动。

## 机制分类

- 物品基础伤害、射程、价格和多用属性：当前 `ItemDef` 支持。
- 植物杀手与顺纹追加伤害：当前 `creature_type_tags`、`add_damage_dice` 支持。
- 劈痕状态与 `60TU` 生命周期：当前 `apply_status` 支持。
- 劈痕目标上的 `+1` 命中：当前 `attack_roll_bonus` 支持，并以 `require_weapon_damage = true` 限定真实武器攻击。
- 来源隔离：给通用 `status_stacks` fact query 增加 `require_source_unit_match`。开启后，状态 `source_unit_id` 不等于当前装备能力来源单位时返回 0。
- AP 返还：扩展通用 `modify_action_points`，增加 `restore_current_action_points_capped` 模式，并允许该动作在 `on_kill / after_kill` 阶段执行。
- AP 上限：读取目标单位 `attribute_snapshot[action_points]`；当前 AP 已达到或超过该值时不增加，也不反向降低现有 AP。
- 不新增主动 `SkillDef`，不新增武器专用 C# 分支，不通过 item id、trait id 或 binding id 推导运行时行为。

## 内容模型

实现内容包括：

- 物品：`data/configs/items/weapon_unique_battleaxe_lumberjack.tres`
- Trait：
  - `weapon.axe.lumberjack.chopping_rhythm`
  - `weapon.axe.lumberjack.plant_slayer`
  - `weapon.axe.lumberjack.felling_momentum`
- 装备能力包：`data/configs/equipment_abilities/lumberjack_axe_pack.tres`
- 回归：`tests/battle_runtime/runtime/run_lumberjack_axe_weapon_ability_regression.cs`

Trait 只负责身份与装备能力来源；触发、条件、伤害、状态和 AP 返还全部由装备能力包配置。

## 生命周期与边界情况

- 劈痕持续 `60TU`，再次命中存活目标时刷新，超时后自然清除。
- 目标死亡时，`on_kill` 先读取仍存在的劈痕，随后目标状态随死亡清理。
- 战斗结束时所有劈痕清理，不写入角色、装备或世界存档。
- 卸下或摧毁伐木工之斧后，binding 立即失效；未到期劈痕可以暂时显示，但不能继续提供命中、伤害或 AP 返还。
- 重新装备后，只有来源单位匹配且仍在 `60TU` 内的劈痕可再次被读取。
- 未命中不施加、不刷新，也不返 AP。
- 其他持有者不能借用旧来源劈痕；其首次命中只负责接管来源。
- AP 恢复只做封顶增加，不创建 per-turn charge、cooldown 或 once state。

## 用例与测试

回归必须通过真实内容注册、装备投影和攻击/击杀结算路径覆盖：

- 加载物品、三个 trait 和三个 binding；价格为 38000。
- 装备后投影 `1D8+2` 单手、`1D10+2` 双手、射程 1、多用属性；卸装后全部清理。
- 第一击只造成基础伤害并留下 1 层 `60TU` 劈痕。
- 对自身劈痕目标攻击检定 `+1`，命中追加 `1D4` 并刷新 `60TU`。
- 非来源持有者不能读取 `+1` 或 `1D4`，其命中后接管劈痕来源。
- 普通目标不触发植物杀手；`plant` 目标每击追加 `2D6`，已有劈痕时同时追加 `1D4`。
- 未命中与第一击直接击杀都不留下劈痕。
- 击杀自身劈痕目标恢复 `1 AP`；同回合多个合格击杀可连续恢复。
- AP 达到正常上限时不继续增加；体力不返还。
- 错误来源劈痕、其他装备实例、非攻击击杀都不返 AP。
- 卸装后残留劈痕不再提供任何收益。
- 脚本中不存在伐木工之斧 item id、trait id 或 binding id 的硬编码分支。
