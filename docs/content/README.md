# 内容策划与制作资料

本目录保存剧情、任务、信仰、装备套装、武器、书籍和物品目录等内容资料。

这些文档可以指导 `.tres` 制作，但不定义 C# 运行时 owner、save schema、战斗结算或 AI 合同。发生冲突时，以 [`../design/project_context_units.md`](../design/project_context_units.md)、对应当前实现文档、源码和测试为准。

内容状态通过子目录表达：已实现的单项武器设计记录放入 [`weapons/implemented/`](weapons/implemented/README.md)；尚未制作的任务内容放入 [`quests/planned/`](quests/planned/README.md)。内容文档即使标记“已实现”，也不是项目架构真相源。
