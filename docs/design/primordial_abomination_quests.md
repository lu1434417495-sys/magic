# 远古神孽与时光龙——剧情任务线设计

> 核心定位：这些不是"可选择的起始种族"，而是**世界规则的异常**——他们是神性的失败实验、禁忌的后代、被时间遗忘的存在。玩家不是"扮演"他们，而是**面对**他们。
>
> 参考D&D神孽（Abomination）：神与凡物/神与神/神与远古存在的禁忌产物。拥有神性的碎片，但没有神格的完整。被诸神所忌惮，被世界所排斥。

---

# 核心设计原则

## 1. 他们不是"种族"，是"灾难"

远古神孽和时光龙不是"另一个可选角色"。他们是：

- **世界规则的漏洞**——他们的存在本身就会引发异常（时间倒流、空间撕裂、因果混乱）
- **神性的废弃物**——诸神不想要他们，但无法消灭他们（消灭神性碎片需要付出巨大代价）
- **被遗弃的过去**——他们来自比灰烬王朝更古老的时代，那个时代的规则与现在完全不同

**玩家在任务中不是"成为"他们，而是**：
- 发现他们的存在
- 理解他们为何存在
- 决定如何处理他们（消灭/封印/利用/共存）

## 2. 超模的体现：不是"数值更高"，是"规则不同"

神孽和时光龙不是"HP更高的龙"或"伤害更高的兽人"。他们的"超模"体现在：

| 标准敌人 | 神孽/时光龙 |
|---------|-----------|
| 遵循回合制 | 可以同时存在于多个回合 |
| HP归零=死亡 | HP归零=进入另一种形态 |
| 受因果律约束 | 可以"撤销"自己的死亡 |
| 有固定属性 | 属性随观察者的心情变化 |
| 可以被控制/魅惑 | 控制他们的意志会反噬控制者 |

## 3. 任务线结构：发现→理解→面对→选择

每个神孽/时光龙任务线遵循四段式：

1. **发现**：世界出现异常——时间倒流、空间撕裂、NPC突然消失又出现
2. **理解**：找到远古文献/幸存者/神孽本身，理解异常的原因
3. **面对**：直面神孽——战斗不是唯一选择，有时对话/欺骗/交易更有效
4. **选择**：决定神孽的命运——消灭（获得力量但失去信息）、封印（安全但隐患）、利用（强大但危险）、共存（和平但不被理解）

# 第一篇章：时光龙——「时渊之蛇」艾欧洛克斯（Aiolox the Time-Serpent）

## 世界观定位

**时光龙不是"会魔法的龙"**。他们是**时间本身的错误**——在远古时代，时间之神试图创造"完美的永恒存在"，结果创造出了能同时存在于所有时间点的生物。但这个实验失败了：时光龙无法"固定"在任何一条时间线上，他们在所有时间线之间不断滑动。

**时光龙的悲剧**：
- 他们无法拥有"记忆"——因为对他们而言，过去、现在、未来同时发生
- 他们无法拥有"情感"——因为情感需要时间积累，而他们没有"时间"
- 他们无法"死亡"——因为死亡是一个时间点，而他们在所有时间点同时存在

**艾欧洛克斯的特殊性**：
- 他是最后一条时光龙——其他的时光龙要么被诸神封印在时间之外，要么"解体"成了时间碎片
- 他选择"固定"在一条时间线上——通过不断"吞噬"其他时间点上的自己，他勉强维持了一个"稳定"的存在
- 但他的存在导致周围的时间异常——他所在的地方，时间会随机加速、减速、倒流、甚至冻结

## 任务线：时渊之蛇（Q401-Q420）

### Q401「时间异常报告」

**触发**：玩家在任意城市，发现异常现象。

**异常现象（随机出现一种）**：
- **时间倒流**：街道上的行人突然倒退行走，说的话倒着播放，然后一切恢复正常（目击者以为自己在做梦）
- **时间加速**：一个NPC在玩家眼前迅速老化——从青年变成老年，然后变成尸体，然后化为白骨（持续10秒，然后恢复正常）
- **时间冻结**：整个城市突然静止——所有人停止不动，落叶停在半空，水滴停在空中。玩家可以移动，但不能与任何人交互。10秒后，一切恢复，没人记得刚才发生了什么。
- **时间重叠**：玩家同时看到两个版本的同一个NPC——一个年轻版，一个老年版。他们在做不同的事，然后突然合并成一个。

**调查**：
- 玩家需要收集目击者的证词（但大多数人认为是幻觉）
- 唯一可靠的线索：一个疯癫的老学者，他说"时间有洞。洞里有蛇。"

**奖励**：解锁「时间异常感知」——此后，玩家可以在时间异常发生前3秒预感到（画面出现轻微的波纹扭曲）。

### Q402「疯癫学者的日记」

**触发**：完成Q401。

**剧情**：
1. 玩家找到老学者的住所——一间堆满了古籍和奇怪装置的房间。
2. 学者已经死了——但他的尸体**同时处于多个状态**：一部分已经白骨化，一部分正在腐烂，一部分还很新鲜。
3. 他的日记是用**倒着写的文字**记录的——从最后一页写到第一页。
4. 日记内容：
   > "艾欧洛克斯不是龙。他是时间之神的一块碎片。时间之神试图创造永恒，结果创造出了无法停止的滑动。"
   > "我找到了固定他的方法——用'锚'。但锚需要代价。锚需要有人永远留在时间里。"
   > "我决定成为锚。但我失败了。时间不喜欢被固定。"

**关键道具**：获得「学者的怀表」——一个坏了的怀表，指针在疯狂旋转。使用它可以在3秒内看到"3秒后的未来"（冷却时间：现实时间1小时）。

### Q403「时间的锚」

**触发**：完成Q402。

**剧情**：
1. 学者日记中提到"锚"——一种可以固定时光龙的装置。
2. 玩家需要收集三种材料来制作锚：
   - **「凝固之沙」**：来自一个时间冻结的区域——沙子不会流动
   - **「因果之线」**：来自命运女神的信徒——一根可以连接因果的线
   - **「永恒之石」**：来自摩拉丹的祭坛——一块被认为"永远不会改变"的石头
3. 收集过程中，玩家会遭遇"时间滑动的碎片"——艾欧洛克斯的部分意识在时间的裂缝中游荡，会试图阻止玩家。

**敌人：时间碎片**
- 不是实体，是"时间异常"的具象化
- 外观：一个模糊的人形，身体由多个时间点的影像重叠而成
- 能力：
  - 「时间跳跃」——随机出现在战场的任意位置（不是移动，是"重新出现在那里"）
  - 「加速老化」——被击中的敌人会瞬间老化10年（属性-10%，持续3回合）
  - 「倒流」——受到伤害后，有30%概率"撤销"这次伤害（时间倒流1秒）
- 弱点：「因果锁定」——如果攻击者使用「因果之线」，时间碎片无法"撤销"伤害

### Q404「时渊之穴」

**触发**：完成Q403。

**剧情**：
1. 玩家找到艾欧洛克斯的巢穴——一个存在于"时间裂缝"中的洞穴。
2. 进入洞穴时，玩家会看到**多个版本的洞穴同时存在**：
   - 过去版：洞穴中有远古文明的遗迹
   - 现在版：洞穴是空的，只有灰尘
   - 未来版：洞穴坍塌了，只有碎石
3. 玩家需要在这些版本之间"穿梭"——找到正确的路径。

**解谜机制**：
- 某些机关只在"过去版"中存在（如古代文明的钥匙）
- 某些道路只在"未来版"中可见（因为现在的岩石在未来会风化）
- 某些敌人只在"现在版"中出现（他们是来调查时间异常的冒险者，已经被时间碎片逼疯了）

**关键场景**：
- 玩家在洞穴深处看到艾欧洛克斯——但他的身体**同时处于多个状态**：
  - 一部分是青年龙（鳞片光泽）
  - 一部分是老年龙（鳞片暗淡）
  - 一部分是幼龙（体型小）
  - 一部分是龙骨（已经死了）
- 他的眼睛没有瞳孔——只有不断旋转的时钟。

### Q405「与时渊之蛇对话」

**触发**：完成Q404。

**剧情**：
1. 艾欧洛克斯不会攻击玩家——他"同时知道"攻击和不攻击的结果，所以他没有动机做任何事。
2. 但他会"说话"——他的声音不是单一的，是**多个时间点的声音同时播放**：
   - 过去的声音（年轻、好奇）："你是谁？"
   - 现在的声音（疲惫、痛苦）："你怎么找到这里的？"
   - 未来的声音（绝望、疯狂）："杀了我。求求你。"
3. 玩家需要与他"对话"——但对话不是线性的：
   - 玩家的每个回答，艾欧洛克斯会同时给出"已经回答过"、"正在回答"、"将要回答"三种反应
   - 玩家需要在这些混乱的反应中，找到"真实的意图"

**关键对话**：
```
艾欧洛克斯（三重声音）：
"我……（过去：想要自由）……（现在：想要固定）……（未来：想要死亡）。"
"时间……（过去：是我的玩具）……（现在：是我的监狱）……（未来：是我的坟墓）。"
"你……（过去：会成为我的食物）……（现在：会成为我的锚）……（未来：会成为我的继承者）。"

【玩家选择】
[A] "你想要什么？" → 艾欧洛克斯："我想要……不存在。"
[B] "你能看到未来吗？" → 艾欧洛克斯："我看到所有未来。所以我没有未来。"
[C] "我能帮你吗？" → 艾欧洛克斯："你能……成为我的锚。或者……成为我的解脱。"
[D] "我要消灭你。" → 艾欧洛克斯："你……（过去：会失败）……（现在：会尝试）……（未来：会后悔）。"
```

### Q406-Q410：四条路线

根据Q405的选择，任务线分叉为四条路线：

#### 路线A：成为锚（Anchor）——Q406A-Q410A

**核心**：玩家选择成为艾欧洛克斯的"时间锚"——用自己的存在固定他的时间线。

- Q406A「锚的代价」：玩家被"固定"在艾欧洛克斯的时间线上——玩家的年龄不再增长（不会老死），但玩家也无法"改变"——每次做出重大选择后，有50%概率"回到选择前"（时间倒流）
- Q407A「固定的时间」：艾欧洛克斯逐渐稳定——周围的时间异常减少
- Q408A「锚的重负」：玩家开始"遗忘"——因为时间被固定，玩家的记忆无法"积累"（每过一天，有10%概率忘记昨天的事）
- Q409A「其他锚」：发现学者不是第一个锚——历史上至少有100人成为过锚，他们都"消失"了（被时间同化）
- Q410A「最终固定」：艾欧洛克斯完全固定——但玩家也被"固定"了。结局：玩家成为"时间守护者"——永远存在，但永远无法改变。

**奖励**：
- 「时间锚定」——玩家免疫所有时间类效果（加速、减速、倒流）
- 「永恒存在」——玩家不会自然死亡
- 代价：玩家每次升级需要2倍经验；玩家的记忆会逐渐丧失；某些NPC会"忘记"玩家曾经存在

#### 路线B：消灭时渊（Kill）——Q406B-Q410B

**核心**：玩家选择消灭艾欧洛克斯——彻底终结时间异常。

- Q406B「因果之刃」：用「因果之线」制作一把可以"切断"时间线的武器
- Q407B「时渊之怒」：艾欧洛克斯感应到威胁——时间异常加剧，整个区域陷入"时间风暴"
- Q408B「时间的碎片」：战斗中，玩家需要同时与多个时间版本的艾欧洛克斯战斗（过去版、现在版、未来版）
- Q409B「因果的反噬」：消灭艾欧洛克斯后，玩家被"因果反噬"——因为艾欧洛克斯存在于所有时间点，消灭他意味着玩家也"消灭"了过去和未来与艾欧洛克斯相关的所有存在
- Q410B「时间的伤痕」：世界出现"时间伤痕"——某些区域的时间永远混乱。结局：时间异常停止了，但代价是历史的永久性损伤。

**Boss战：艾欧洛克斯**

| 阶段 | 状态 | 能力 |
|------|------|------|
| **第一阶段** | 幼龙+青年龙+老年龙同时存在（3个身体） | 每个身体独立行动；幼龙速度快但伤害低，青年龙平衡，老年龙速度慢但伤害高 |
| **第二阶段** | 龙骨+幽灵龙同时存在 | 龙骨物理免疫，幽灵龙魔法免疫；需要同时消灭两者 |
| **第三阶段** | 时间碎片形态（无实体） | 随机出现在战场任意位置；受到伤害后30%概率"撤销"；每回合随机对一名敌人施放「加速老化」（-10%全属性） |
| **终结阶段** | 所有时间版本同时崩溃 | 全场时间混乱——所有单位的行动顺序随机打乱；玩家需要使用「因果之刃」在正确的"时间点"给予最后一击 |

**奖励**：
- 「因果之刃」——武器：攻击时有20%概率"切断"敌人的时间线（秒杀非Boss敌人，Boss受到300%伤害）
- 「时间伤痕」debuff——玩家在所有时间异常区域受到的伤害+50%（因为玩家是"破坏时间"的凶手）

#### 路线C：利用时渊（Exploit）——Q406C-Q410C

**核心**：玩家不消灭也不固定艾欧洛克斯——而是"利用"他的时间能力。

- Q406C「时间的交易」：与艾欧洛克斯达成交易——他给予玩家"时间碎片"，玩家给予他"存在的目的"
- Q407C「时间碎片的力量」：玩家获得操控时间碎片的能力——可以短暂"倒流"小范围的时间（如让打碎的瓶子复原、让死去的NPC复活3秒）
- Q408C「碎片的上瘾」：玩家开始"依赖"时间碎片——没有碎片时，玩家会感到"时间的空洞"（所有属性-20%）
- Q409C「艾欧洛克斯的衰弱」：每次给予碎片，艾欧洛克斯就更衰弱——他开始"解体"
- Q410C「碎片之王」：艾欧洛克斯完全解体——玩家成为时间碎片的"容器"。结局：玩家拥有强大的时间能力，但身体开始"时间化"（外观逐渐变得像艾欧洛克斯）。

**奖励**：
- 「时间碎片」——道具：使用后可倒流30秒（仅限玩家周围5米范围）。每次使用，玩家的外观发生微小变化（皮肤出现时钟纹路、眼睛变白）。
- 代价：使用超过50次后，玩家被NPC视为"时间异常"——所有NPC态度-30；使用超过100次后，玩家无法区分"过去"和"现在"——某些任务会自动"重复"

#### 路线D：释放时渊（Release）——Q406D-Q410D

**核心**：玩家选择释放艾欧洛克斯——让他从"固定"中解脱，回归时间的流动。

- Q406D「解放的方法」：找到释放艾欧洛克斯的方法——不是消灭他，是"分散"他，让他成为时间本身的一部分
- Q407D「诸神的反对」：诸神（特别是时间之神的信徒）反对释放——他们害怕艾欧洛克斯的力量扩散
- Q408D「时间的融合」：玩家需要帮助艾欧洛克斯"溶解"——将他的意识分散到所有时间点
- Q409D「溶解的代价」：艾欧洛克斯溶解后，他的记忆会"流入"所有生命——所有生物都会短暂地"记得"一些不属于自己时间线的记忆
- Q410D「新的时间」：世界的时间规则发生微小变化——某些区域的时间流速不同了。结局：艾欧洛克斯"不存在了"，但他也"无处不在了"。

**奖励**：
- 「时间之触」——被动：玩家有5%概率在战斗中触发「时间巧合」——敌人的攻击恰好miss、玩家的攻击恰好暴击、或者恰好触发某个稀有事件
- 代价：玩家偶尔会"记得"未来——在对话中，玩家会说出NPC"将要说的"话（这会让NPC困惑或恐惧）

# 第二篇章：烬神孽——「灰烬之子」卡西姆（Kasim the Ash-Scion）

## 世界观定位

**烬神孽是灰烬王朝诸神与凡物的禁忌后代**。在灰烬王朝鼎盛时期，诸神试图创造"完美的信徒"——拥有神性力量的凡人。但实验失败了：这些生物拥有神的力量，却没有神的控制。他们被称为"烬"——因为他们所到之处，一切都会化为灰烬。

**烬神孽的悲剧**：
- 他们不是"邪恶的"——他们是"过于强大的"。他们的存在本身就会"燃烧"周围的一切（不是火焰，是"存在的燃烧"——物质、记忆、甚至时间都会被他们"烧掉"）
- 灰烬王朝覆灭后，烬神孽被诸神"封印"在灰烬交界——因为他们是王朝存在的"证明"，消灭他们等于否认历史
- 但封印正在衰弱——随着界火被帝国和联邦抽取，烬神孽正在苏醒

**卡西姆的特殊性**：
- 他是最后一个被封印的烬神孽——其他的烬神孽在三千年的封印中要么"熄灭"了，要么"暴走"了
- 他选择"沉睡"——不是因为被封印，是因为他"不想烧掉任何东西"
- 但他的力量在封印中积累——如果他完全苏醒，整个灰烬交界会被"烧成灰烬"

## 任务线：灰烬之子（Q421-Q440）

### Q421「灰烬交界的低语」

**触发**：玩家在灰烬交界活动。

**异常现象**：
- NPC开始"忘记"东西——不是健忘，是"被烧掉"的记忆
- 某些区域出现"灰烬人形"——不是怪物，是"被烧掉的存在"留下的痕迹（走过去就散了）
- 界火的火焰开始出现"人脸"——在火焰中，可以看到痛苦的面孔

**调查**：
- 灰烬交界的原住民（无旗军）说："封印松了。里面有东西在呼吸。"

### Q423「封印的三把钥匙」

**触发**：完成Q422。

**剧情**：

   - **「存在之钥」**：在Fortuna的信徒手中——他们用这把钥匙"赌"命运
   - **「记忆之钥」**：在古根的根系中——古根用这把钥匙"记住"封印的存在
   - **「力量之钥」**：在战火尊的祭坛下——战火尊用这把钥匙"压制"卡西姆的力量

- **记忆之钥**：古根不会"给"——但玩家可以用自己的记忆"交换"。玩家需要选择"忘记一段重要的记忆"来获得钥匙。
- **力量之钥**：战火尊不会"给"——玩家需要"击败"钥匙的守护者。但守护者不是敌人，是"卡西姆的力量碎片"——击败它意味着吸收一部分烬神孽的力量。

### Q424「烬神孽的苏醒」

**触发**：完成Q423。

**剧情**：
1. 玩家使用三把钥匙打开封印——但发现卡西姆**不想出来**。

4. 玩家需要在7天内做出选择。

**卡西姆的声音**：
- 不是通过耳朵听到的——是直接从玩家的"存在"中响起的
- 他说话时，玩家会感到"热"——不是身体的温度，是"存在的温度"
- 他说："我不是火焰。我是'燃烧'本身。你靠近我，你就会开始'不存在'。"

### Q425-Q430：四条路线

#### 路线A：重新封印（Reseal）——Q425A-Q430A

**核心**：用新的封印替代旧封印——卡西姆继续沉睡，但需要新的"燃料"。

- Q425A「新的燃料」：需要找到新的"燃料"来维持封印——燃料可以是：玩家的生命、大量NPC的生命、或者某种古代神器
- Q426A「燃料的代价」：如果选玩家的生命——玩家每过一天失去1点最大HP；如果选NPC——需要"说服"或"欺骗"100名NPC成为燃料；如果选神器——需要找到已经失落的神器
- Q427A「诸神的交易」：诸神愿意帮助重新封印——代价是玩家需要成为诸神的"工具"（完成一系列诸神指派的任务）
- Q428A「封印的仪式」：重新封印的仪式需要持续7天——期间，卡西姆会不断"诱惑"玩家释放他（"我会给你力量。我会让你燃烧一切。"）
- Q429A「仪式的中断」：仪式可能被第三方打断（帝国想利用烬神孽的力量、联邦想释放烬神孽来对抗帝国、龙巫教想用神孽的血制造药剂）
- Q430A「新的平衡」：封印成功——但新的封印需要持续的维护。结局：玩家成为"封印的守护者"——需要定期回到灰烬交界维护封印。

**奖励**：
- 「封印守护者」称号——在灰烬交界获得所有NPC的尊敬
- 「烬之抗性」——对火焰和"存在燃烧"类伤害免疫
- 代价：玩家需要定期维护封印（每周一次任务）；如果错过维护，封印会衰弱，卡西姆会苏醒

#### 路线B：释放与引导（Release & Guide）——Q425B-Q430B

**核心**：释放卡西姆——但"引导"他的力量，让他成为对抗帝国的武器。

- Q425B「控制的尝试」：找到控制烬神孽力量的方法——需要同时掌握Fortuna、Misfortune、和战火尊的信仰
- Q426B「卡西姆的同意」：说服卡西姆"只烧敌人"——卡西姆说："我控制不了。我靠近什么，什么就会烧。"
- Q427B「烬神孽的容器」：玩家成为卡西姆的"容器"——将烬神孽的力量吸入自己体内。玩家的身体开始"燃烧"（外观变化：皮肤出现灰烬纹理、眼睛变成火焰色）
- Q428B「容器的代价」：每次使用烬神孽的力量，玩家会"烧掉"一部分自己——可能是记忆、可能是情感、可能是与NPC的关系
- Q429B「帝国的恐惧」：卡西姆的力量被释放——帝国军队在烬神孽面前化为灰烬。但联邦也害怕了——"如果他能烧帝国，他也能烧我们。"
- Q430B「烬之王」：玩家成为"烬之王"——拥有摧毁一切的力量，但也被一切所恐惧。结局：玩家站在灰烬交界的中心，周围是燃烧的帝国军队，远处是恐惧的联邦军队，身后是沉默的卡西姆。

**Boss战：帝国军队vs烬神孽**
- 不是传统的Boss战——是"战场控制"
- 玩家需要"引导"卡西姆的力量——选择烧哪里、不烧哪里
- 如果玩家选择"烧一切"——帝国和联邦都会受到重创，但玩家也会"烧掉"自己的一部分
- 如果玩家选择"只烧帝国"——需要精确控制，难度极高（失败=误烧友军）

**奖励**：
- 「烬之王」称号——所有敌人对你的恐惧+50
- 「灰烬之触」——攻击时有30%概率「燃烧存在」（敌人受到持续真实伤害，直到死亡或离开战斗）
- 代价：玩家每次使用能力都会"烧掉"一部分自己；玩家的外观逐渐"灰烬化"；某些NPC会"忘记"玩家（被烧掉的记忆）

#### 路线C：熄灭（Extinguish）——Q425C-Q430C

**核心**：彻底"熄灭"卡西姆——让他不再燃烧，不再存在。

- Q425C「熄灭的方法」：找到"熄灭"烬神孽的方法——不是消灭，是"让他冷却"
- Q426C「冷却的代价」：熄灭烬神孽需要消耗巨大的能量——可以是：玩家的全部神性、整个灰烬交界的界火、或者某个古老神器的力量
- Q427C「卡西姆的请求」：卡西姆说："请熄灭我。我不想再烧了。" 但熄灭他意味着"从未存在过"——所有与卡西姆相关的历史都会被"删除"
- Q428C「历史的删除」：熄灭卡西姆后，灰烬交界消失了——界火、无旗军、甚至某些NPC的记忆都"不存在了"
- Q429C「存在的空洞」：世界出现"空洞"——某些地方"应该有什么"，但什么都没有。玩家能感受到这种空洞。
- Q430C「熄灭的余温」：卡西姆不存在了——但他的"余温"还在。玩家在寒冷的地方会感到温暖，在黑暗中能看到微光。结局：卡西姆"不存在了"，但他也"无处不在了"。

**奖励**：
- 「熄灭火种」——道具：可以"熄灭"任何火焰或神性存在（对Boss有效，但使用次数有限）
- 「存在的空洞」感知——可以看到世界中的"空洞"（被删除的存在留下的痕迹）
- 代价：某些NPC会"忘记"玩家（因为玩家的某些经历与卡西姆有关，被一同删除）；玩家的某些技能可能"不存在了"

#### 路线D：共存（Coexist）——Q425D-Q430D

**核心**：让卡西姆"部分苏醒"——他不是完全释放，也不是完全封印，而是成为一种"可控制的存在"。

- Q425D「部分苏醒的方法」：找到让烬神孽"部分存在"的方法——让他成为"界火的一部分"
- Q426D「界火的融合」：卡西姆与界火融合——他不再是独立的生物，是"界火的意识"
- Q427D「界火的意识」：界火有了意识——它会"选择"燃烧什么、不燃烧什么
- Q428D「意识的不稳定」：界火的意识不稳定——有时会"误烧"友军
- Q429D「平衡的努力」：玩家需要帮助界火"稳定"——找到让它"理性"的方法
- Q430D「界火之神」：界火稳定了——卡西姆成为了"界火之神"。结局：灰烬交界不再危险——界火成为了"可控的资源"。但卡西姆不再是"生物"，是"现象"。

**奖励**：
- 「界火亲和」——可以操控界火（在灰烬交界获得巨大加成）
- 「界火之神」的祝福——在界火附近恢复速度+200%
- 代价：玩家无法离开灰烬交界太久——界火会"想念"玩家（如果离开超过7天，玩家获得debuff「界火的呼唤」——所有属性-30%）

# 第三篇章：界核行者——「核心之种」泽拉（Zera the Core-Seed）

## 世界观定位

**界核行者不是在灰烬交界"出生"的——他们是在灰烬交界"被种出来的"**。在远古时代，某个神明试图创造"可以在界火中生存的生物"，结果创造出了"界核"——一种以界火为土壤、以神性为种子的存在。

**界核行者的本质**：
- 他们不是"生物"——他们是"现象"。他们的身体不是由细胞构成的，是由"能量节点"构成的
- 他们可以"生长"——吸收界火后，他们会变大、变强。但"生长"是不可逆的——他们不会缩小
- 他们可以"分裂"——一个界核行者可以分裂成两个，但分裂后的每个个体都只有原来的一半"完整性"

**泽拉的特殊性**：
- 她是第一个界核行者——其他的界核行者都是她的"分裂体"或"后代"
- 她选择"停止生长"——因为她害怕自己会长得太大，以至于无法"存在"（身体会分散成能量）
- 但她停止生长后，她的"后代"开始失控——分裂体们开始争夺"谁才是真正的泽拉"

## 任务线：核心之种（Q441-Q460）

### Q441「界火的种子」

**触发**：玩家在灰烬交界发现异常能量波动。

**异常现象**：
- 界火中出现"种子"——不是火焰，是固体的、发光的、像果实一样的东西
- 触碰种子的人会"发芽"——皮肤上出现发光的纹路
- "发芽"的人不会死——但会逐渐"转化"（变成界核行者的"容器"）

### Q442「泽拉的声音」

**触发**：完成Q441。

**剧情**：
1. 泽拉的声音从种子中传来——不是语言，是"能量波动"直接转化为理解
2. 她说："我是第一个。我的孩子们……在争夺我。"
3. 玩家发现：界核行者没有"个体意识"——所有的界核行者共享一个"集体意识"，但这个意识正在分裂。

### Q443-Q460：四条路线

（路线设计与烬神孽类似，但核心冲突是"个体 vs 集体"——界核行者的存在方式挑战了"个体意识"的概念）

# 第四篇章：噬神者后裔——「神餐者」沃拉格（Vorag the God-Eater Kin）

## 世界观定位

**噬神者是远古时代的存在——他们以神性为食**。在诸神诞生之前，噬神者就已经存在了。他们不是"邪恶的"——他们只是"饥饿的"。神性对他们来说是"食物"。

**噬神者后裔的本质**：
- 他们不是噬神者——他们是噬神者与凡物的后代。他们拥有"饥饿"，但无法"消化"神性。
- 他们的存在本身就是"诅咒"——靠近神明或神性物品时，他们会感到"饥饿"，但无法满足。
- 他们被诸神猎杀——因为诸神害怕他们"觉醒"真正的噬神者力量。

**沃拉格的特殊性**：
- 他是最后一个已知的噬神者后裔——其他的后裔要么被诸神杀死，要么"饿死"了（无法获得神性而衰弱至死）
- 他选择"封印自己的饥饿"——通过不断祈祷（向所有神明），他试图用"信仰"来压制"饥饿"
- 但封印正在崩溃——随着玩家在游戏中与越来越多的神性存在交互，沃拉格感应到了"食物"的存在

## 任务线：神餐者（Q461-Q480）

### Q461「饥饿的低语」

**触发**：玩家首次获得神性力量（如信仰五阶、获得神器、与神明对话）。

**异常现象**：
- 玩家开始做"饥饿的梦"——梦中自己在"吃"某种发光的东西
- 某些NPC会突然"忘记"与神明相关的事——不是健忘，是"被吃掉"了记忆
- 神像开始"流血"——不是血，是"神性液体"

### Q462「沃拉格的忏悔」

**触发**：完成Q461。

**剧情**：
1. 沃拉格找到玩家——他是一个瘦弱的、看似普通的人类，但眼睛是"无底洞"（看不到瞳孔，只有黑暗）
2. 他说："我感应到了你。你身上有……食物的味道。"
3. 他请求玩家帮助他"压制饥饿"——但方法极其危险：需要玩家"分享"自己的神性力量给他

### Q463-Q480：四条路线

**路线A：喂养（Feed）**：玩家定期给予沃拉格神性力量——他越来越强大，但也越来越"饥饿"
**路线B：封印（Seal）**：找到封印沃拉格饥饿的方法——但他会变成"神性的黑洞"（靠近他的人失去神性）
**路线C：觉醒（Awaken）**：帮助沃拉格"觉醒"真正的噬神者力量——他可以吞噬神明，但也会吞噬世界
**路线D：共存（Coexist）**：找到让沃拉格"消化"神性的方法——让他成为"神性的转化者"（将神性转化为其他能量）

# 神孽/时光龙的通用战斗机制

## 时光龙战斗机制

| 机制 | 描述 | 应对方法 |
|------|------|---------|
| **时间滑动** | 敌人同时存在于3个时间点（过去/现在/未来） | 需要同时攻击3个版本才能造成伤害 |
| **因果倒置** | 玩家的"因"变成"果"——先看到伤害，后才看到攻击 | 使用「因果之线」锁定因果顺序 |
| **时间碎片** | 战场被分割成多个时间片段——不同片段有不同的时间流速 | 需要在正确的时间片段中行动 |
| **存在抹除** | 被击杀的敌人"从未存在过"——其他NPC会忘记他 | 使用「记忆锚」固定存在 |

## 烬神孽战斗机制

| 机制 | 描述 | 应对方法 |
|------|------|---------|
| **存在燃烧** | 玩家的HP不是减少，是"最大HP"在减少（暂时性的，但会累积） | 使用「存在之盾」（Fortuna信仰）或「烬之抗性」（完成任务奖励） |
| **记忆焚烧** | 玩家随机"忘记"一个技能（战斗中暂时无法使用） | 使用「记忆之钥」（古根信仰）恢复 |
| **灰烬化身** | 烬神孽可以将死去的敌人"复活"为灰烬傀儡 | 灰烬傀儡免疫物理攻击，需要使用神圣/时间类攻击 |
| **界火共鸣** | 烬神孽在界火附近无限恢复HP | 需要先将烬神孽引离界火区域 |

## 界核行者战斗机制

| 机制 | 描述 | 应对方法 |
|------|------|---------|
| **能量分裂** | 界核行者受到致命伤害时会分裂成两个（每个50%属性） | 需要使用「封印攻击」阻止分裂 |
| **界火吸收** | 界核行者吸收界火后体积和力量倍增 | 需要切断其与界火的连接 |
| **集体意识** | 所有界核行者共享视野和HP——攻击一个等于攻击所有 | 需要使用「意识隔离」攻击特定个体 |
| **生长不可逆** | 界核行者不会恢复，但也不会缩小——战斗时间越长，它越大 | 需要速战速决 |

## 噬神者后裔战斗机制

| 机制 | 描述 | 应对方法 |
|------|------|---------|
| **神性吞噬** | 玩家使用神性技能时，噬神者会"吃掉"该技能（技能无效化，噬神者恢复HP） | 需要使用非神性攻击 |
| **饥饿光环** | 靠近噬神者的玩家逐渐失去所有增益效果 | 需要保持距离或使用「饱腹」道具 |
| **神明恐惧** | 如果玩家信仰神明，靠近噬神者会受到「神明的恐惧」debuff（全属性-30%） | 需要临时放弃信仰或使用「无神」状态 |
| **吞噬觉醒** | 噬神者HP降至10%时会「觉醒」——吞噬周围所有神性存在（包括玩家的神器和信仰增益） | 需要在10%前使用「封印」或「超度」 |

| 神孽/时光龙 | 正义之神 | 兽人之神 | 生命女神 | 大地之神 |
|------------|---------|---------|---------|---------|
| **时光龙** | 时间没有罪恶——正义之神无法称量时间 | 血祖不记得时光龙（时间之外） | 时光龙没有生命之线（不在织锦中） | 时光龙存在于地质时间之前 |
| **烬神孽** | 烬神孽的"燃烧"是罪恶——但他是被迫的 | 血祖"记得"烬神孽——他们是灰烬王朝的"余烬" | 烬神孽没有生命之线——他们是"燃烧的存在" | 烬神孽"烧毁"大地——大地的骨被烧焦了 |
| **界核行者** | 界核行者没有"个体"——正义无法审判集体 | 血祖不记住界核行者（他们是现象，不是生命） | 界核行者不是"生命"——他们是能量 | 界核行者"生长"在大地之上——大地是他们的土壤 |
| **噬神者后裔** | 噬神者是"罪恶"——但他也是"受害者" | 血祖害怕噬神者——他会"吃掉"名字 | 噬神者后裔有生命之线——但线在不断"饥饿" | 大地之神不害怕噬神者——神性不是大地的 |

# 总结：神孽任务线的设计理念

| 维度 | 设计原则 |
|------|---------|
| **不是敌人，是悲剧** | 每个神孽/时光龙都不是"邪恶的Boss"——他们是"失败的实验"、"被遗弃的存在"、"无法控制的异常" |
| **不是战斗，是选择** | 任务线的核心不是"打赢Boss"——是"理解他们的处境"并"做出道德选择" |
| **不是奖励，是代价** | 获得神孽/时光龙的力量不是"变强"——是"承受他们的诅咒" |
| **不是结束，是开始** | 完成任务线后，世界会永久改变——时间异常区域、灰烬化区域、界火意识化区域、神性黑洞区域 |
