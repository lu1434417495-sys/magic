## 核心设计理念

本次扩展的四神信仰，不是独立的"新DLC"，而是**嵌入现有世界观的深层脉络**：

- **正义之神**是秩序之神的**分裂面**——当秩序变成暴政，正义就会觉醒
- **兽人之神**是战火尊的**另一面**——战火尊问"你战了吗"，兽人之神问"你为何而战"
- **生命女神**是Fortuna与Misfortune的**仲裁者**——她不在乎运气，只在乎生死之间的平衡
- **大地之神**是古根的**兄弟**——古根记得过去，大地承载现在

四神信仰的设计遵循现有框架：
- 5阶信仰体系，统一 `FaithDeityDef`/`FaithRankDef` schema
- 每神50个任务（主线20 + 支线20 + 隐藏10），共200个
- 编号 Q201-Q400
- 与现有 Q101-Q200、十轮战役、种族战争深度交织

# 第一神：正义之神「衡世者」艾奎斯（Aequus the Scale-Bearer）

## 一、神格定位

### 1.1 世界观嵌入

正义之神不是「善良」。它不保护弱者，不惩罚邪恶，它只做一件事：**称量**。

> "我不审判。我只称量。左边是你的罪，右边是你的功。如果左边沉了，你就坠下去。如果右边沉了，你就升上去。如果两边平衡——那你就是人。"

**正义之神与秩序之神的关系**（核心设定）：
- 秩序之神是霜烬帝国的国教，代表"规则、法律、服从"
- 正义之神是秩序之神在三百年前「分裂」出的另一面
- 分裂原因：灰烬王朝覆灭时，秩序之神选择了"维持规则"，哪怕规则会导致千万人死亡；正义之神选择了"打破规则"，哪怕打破规则意味着混乱
- 从此，秩序与正义成为对立的两极：秩序说"服从即正义"，正义说"正义即秩序之敌"

**关键叙事**：
- 在霜烬帝国，信仰正义之神是**死罪**
- 在星陨联邦，正义之神被容忍，但不受欢迎——因为联邦的"七族平等"也是一种规则，而正义之神会质疑任何规则
- 在玩家的祖国（多元种族帝国），正义之神是**合法信仰**，但信徒很少——因为"正义"太沉重了

### 1.2 与其他信仰的关系

| 信仰 | 与正义之神的关系 |
|------|----------------|
| **秩序之神** | **死敌**。秩序说"服从规则"，正义说"规则必须被称量" |
| **战火尊** | **复杂**。战火尊不问对错，正义之神只问对错。但正义之神承认：有些罪恶只能用战斗来称量 |
| **古根** | **尊重**。古根记录一切，正义之神称量一切。两者都相信"真相不会消失" |
| **Fortuna** | **蔑视**。正义之神说"运气是弱者的借口，强者的伪装" |
| **Misfortune** | **警惕**。碎镜女神说"厄运即真理"，正义之神说"厄运只是称量的一部分" |
| **生命女神** | **盟友**。两者都关注"个体价值"，但生命女神关注"存在"，正义之神关注"价值" |

### 1.3 正义之神在国家战争中的位置

**帝国的视角**：
- 正义之神信徒是"秩序的破坏者"、"法律的叛徒"
- 帝国有一个秘密组织"衡世猎手"，专门追杀正义之神信徒
- 但讽刺的是：帝国的某些高层也秘密信仰正义之神——因为他们知道帝国的"净化"是不义的

**联邦的视角**：
- 联邦欢迎正义之神信徒对抗帝国
- 但联邦也害怕正义之神——因为联邦的"七族平等"也是一种规则，正义之神会问："如果平等导致更多的死亡，它还正义吗？"

**玩家的位置**：
- 玩家不是正义之神的信徒（除非选择信仰）
- 玩家是"被正义之神注视的人"——因为玩家在Q101中做出了阵营选择，这个选择会被正义之神"称量"

## 二、信仰体系：五阶「称量」

正义之神不称量金银，称量**灵魂**。

| 阶位 | 称号 | 核心含义 | 所需条件 | 供奉 |
|:---:|------|---------|---------|------:|
| 一阶 | **观秤者** | 第一次见证"不正义"而不移开目光 | — | 500 |
| 二阶 | **执秤者** | 亲手做出一个"正义但痛苦"的选择 | 完成任意正义之神任务 | 2000 |
| 三阶 | **断罪者** | 有能力分辨"合法但邪恶"与"违法但正义" | 等级≥14 | 4500 |
| 四阶 | **衡世者** | 成为他人眼中的"正义化身" | 完成Q240 | 8000 |
| 五阶 | **天平之眼** | 可"称量"任何人的灵魂，看到其善恶比重 | 完成Q250 | 14000 |

### 各阶能力

**一阶·观秤者**：
- 「善恶感知」：可看到NPC的"罪孽值"（隐藏属性，范围-100到+100）
- 限制：只能看到"重大罪恶"（杀人、背叛、酷刑），看不到"小恶"（撒谎、贪婪）

**二阶·执秤者**：
- 「正义之誓」：接受任务时，可选择"以正义之名"完成——任务奖励翻倍，但失败惩罚也翻倍
- 「痛苦抉择」：某些任务会出现"正义但痛苦"的选项（如：杀死一个无辜者以拯救十个人）

**三阶·断罪者**：
- 「断罪之眼」：战斗中可看穿敌人的"罪恶"——罪恶越高的敌人，受到你的伤害越高（最高+30%）
- 「法外正义」：对"合法但邪恶"的敌人（如帝国的净化军官），伤害额外+20%

**四阶·衡世者**：
- 「天平衡量」：战斗中可选择"称量"一个敌人——如果其罪恶值>50，直接秒杀（对Boss无效，改为伤害×3）
- 「正义光环」：友方单位对"罪恶敌人"伤害+10%

**五阶·天平之眼**：
- 「灵魂称量」：与任何NPC对话时，可要求其"接受称量"——如果拒绝，说明其心中有鬼；如果接受，你会看到其一生的重大善恶事件
- 「最终审判」：战斗中可释放"天平之眼"——所有敌人显示其罪恶值，并根据罪恶值受到相应伤害（每点罪恶=1点真实伤害）

## 三、正义之神任务链（Q201-Q250）

### 3.1 任务链总览

| 篇章 | 任务编号 | 主题 | 核心冲突 |
|------|---------|------|---------|
| **觉醒篇** | Q201-Q210 | 玩家发现正义之神的存在，第一次称量 | 目睹帝国暴行，选择是否介入 |
| **衡世篇** | Q211-Q230 | 玩家成为正义之神的工具，执行"法外正义" | 合法但邪恶的目标，违法但正义的手段 |
| **分裂篇** | Q231-Q240 | 正义之神与秩序之神的正面冲突 | 帝国的"衡世猎手"追杀玩家 |
| **终章** | Q241-Q250 | 最终的称量——玩家自己接受审判 | 玩家一生的选择被称量 |

### 3.2 关键任务详细设计

#### Q201「秤的第一边」

**触发**：玩家在任意帝国占领区，目睹一次"净化"行动。

**剧情**：
1. 玩家看到帝国士兵将一群混血家庭赶出家园，理由是"血统不纯"
2. 一个帝国军官（不是索伦，是更低级的军官）在旁记录，他的记录本上写着："今日净化：12人。功绩+1。"
3. 玩家可以选择：
   - **不介入**：离开。当晚做梦，梦见一个手持天平的人看着你，天平左边是"12人的生命"，右边是"你的安全"。天平左边沉了下去。
   - **介入**：阻止士兵。会触发战斗（vs 6名帝国士兵）。战斗后，被帝国通缉。
4. 无论选择什么，当晚都会做梦。梦中，手持天平的人说："你看到了。你没有移开眼睛。这就是第一边。"

**奖励**：
- 选择不介入：获得debuff「观秤者的凝视」——48小时内，所有帝国NPC对你态度-10（因为他们感觉到你"看到了"）
- 选择介入：获得buff「观秤者的勇气」——48小时内，对帝国士兵伤害+10%
- 正义之神信仰解锁（可在信仰系统界面选择加入）

#### Q205「合法的邪恶」

**触发**：完成Q201，等级≥10。

**剧情**：
1. 玩家得知一个帝国法官——他从未亲手杀过人，但他签署的"净化令"导致了超过三千人死亡
2. 法官住在帝国城市「霜铠堡」中，受到重重保护
3. 玩家需要选择如何"审判"他：
   - **法庭路线**：收集证据，在帝国法庭起诉他。几乎不可能胜诉（法官就是法律），但如果成功，会引发帝国司法系统的地震
   - **暗杀路线**：潜入法官府邸，杀死他。简单直接，但会让你变成"恐怖分子"
   - **羞辱路线**：公开他的罪证，让他在社会性上死亡。最安全，但法官可能会自杀
4. 正义之神信徒特殊选项：「天平衡量」——直面法官，告诉他"你的罪恶值是87。你签署的文件，每一笔都是血。"

**奖励**：
- 法庭路线胜诉：解锁成就「法内正义」，获得称号「律令之刃」（对合法邪恶敌人伤害+15%）
- 暗杀路线：解锁成就「法外正义」，获得称号「夜衡者」（暗杀成功率+20%，但所有帝国NPC态度-30）
- 羞辱路线：法官自杀，解锁成就「无血之刃」，获得称号「言罪者」（说服力+10，但道德值-5）

#### Q210「秩序的分裂」

**触发**：完成Q205。

**剧情**：
1. 玩家发现一个秘密：秩序之神和正义之神在三百年前的分裂，不是因为"理念不同"，而是因为一个**人**
2. 那个人是灰烬王朝的最后一位公主。秩序之神选择了"保护王朝的规则"，即使这意味着公主必须死；正义之神选择了"保护公主的生命"，即使这意味着王朝会覆灭
3. 公主最终还是死了。秩序之神和正义之神从此分裂
4. 但传说中，公主的灵魂没有消散——她变成了"天平"本身
5. 玩家需要在灰烬交界找到公主的墓。墓中有一把古老的秤

**奖励**：
- 获得「公主之秤」——一个可在战斗中使用一次的道具：称量一个敌人的灵魂，如果其罪恶值>50，直接秒杀（Boss无效）
- 解锁二阶「执秤者」

#### Q220「衡世猎手」

**触发**：完成Q210，玩家在帝国区域活动。

**剧情**：
1. 帝国秘密组织"衡世猎手"开始追杀玩家。他们不是普通的士兵，是**信仰秩序之神的高阶审判官**
2. 衡世猎手的领袖叫「裁决者·瓦伦丁」（Valentine the Arbiter），一个70岁的老妇人， blind in one eye，但另一只眼睛能看到"规则的光芒"
3. 瓦伦丁不恨玩家。她说："你不是邪恶。你是**错误**。秩序不需要敌人，秩序需要**纠正错误**。"
4. 玩家可以选择：
   - **战斗**：杀死瓦伦丁。她是高阶Boss，战斗极其困难
   - **说服**：向她证明"秩序本身也需要被称量"。需要完成一系列前置任务
   - **转化**：让她看到帝国的"净化"是不义的。如果成功，她会成为玩家最强大的盟友——一个从秩序之神转向正义之神的审判官

**Boss机制**：
- 瓦伦丁使用「秩序锁链」——每回合召唤一条锁链束缚一个友方单位，被束缚单位无法行动，但受到的伤害转移到瓦伦丁身上（她在"承受规则的代价"）
- 正义之神信徒≥三阶可「断罪」——指出瓦伦丁的"罪恶"（她杀过无辜者以维持秩序），她会短暂失神，锁链松动

#### Q230「七族审判」

**触发**：完成Q220。

**剧情**：
1. 联邦邀请玩家参与"七族审判"——审判一名被指控"战争罪"的帝国战俘
2. 但问题在于：这名战俘是一个**被迫参战的农民**，他从未杀过人，只是在军队中做饭
3. 联邦的某些代表（特别是精灵代表）要求处死他，因为"帝国的人都该死"
4. 玩家作为"正义之神的代表"，需要做出裁决：
   - **释放他**：联邦内部的复仇派会愤怒，但玩家维护了"个体正义"
   - **处死他**：联邦满意，但玩家违背了正义之神的原则
   - **折中**：让他"赎罪"——在联邦的难民营中服务十年。但帝国会认为这是"奴隶制"
5. 正义之神信徒≥四阶可「天平衡量」——直接称量战俘的灵魂，证明其无辜。但代价是：你会看到所有人的灵魂，包括联邦代表的——他们中也有罪恶

**核心冲突**：
- 这不是"善恶对决"，是"正义vs正义"——联邦的"集体正义"（惩罚帝国）vs 正义之神的"个体正义"（保护无辜者）

#### Q240「天平的两端」

**触发**：完成Q230。

**剧情**：
1. 玩家得知一个终极秘密：正义之神和秩序之神的分裂，其实是**故意的**
2. 三百年前的分裂，是两位神共同的决定——因为只有分裂，才能"称量"人类在"秩序"和"正义"之间的选择
3. 换句话说：正义之神和秩序之神是**同一个存在的两面**，它们的"战争"是一场持续了三百年的实验
4. 玩家需要做出选择：
   - **支持秩序**：告诉世界"秩序即正义"，秩序之神和正义之神重新合并为"秩序-正义之神"
   - **支持正义**：让世界知道"正义高于秩序"，两位神继续分裂，但正义之神获得更高的地位
   - **拒绝选择**：说"我不选"。这是隐藏路线——玩家会发现，公主的灵魂（天平本身）一直在等待一个说"我不选"的人。因为"不选"也是一种选择

**奖励**：
- 支持秩序：获得「秩序之链」——可束缚任何敌人3回合，但自己也无法行动（"维持规则的代价"）
- 支持正义：获得「正义之秤」——战斗中可称量任意敌人，根据罪恶值造成伤害
- 拒绝选择：获得「公主之眼」——可看到所有NPC的隐藏罪恶值，且可选择"不称量"（尊重他人的隐私）

#### Q250「最终的称量」

**触发**：完成Q240，等级≥28。

**剧情**：
1. 玩家被召唤到"天平之间"——一个存在于现实与梦境之间的空间
2. 正义之神和秩序之神同时出现——它们不是人形，是两团光芒（金色=秩序，银色=正义）
3. 它们说："三百年来，你是第一个走到这里的人。现在，称量你自己。"
4. 玩家的所有选择被「称量」：
   - 杀过多少人？（每个无辜者-10分，每个罪恶者+5分）
   - 救过多少人？（每个无辜者+10分）
   - 说过多少次谎？（每次-1分）
   - 背叛过多少次？（每次-5分）
   - 帮助过多少次？（每次+2分）
5. 根据总分，玩家获得不同的结局：
   - **总分>100**：「正义化身」——获得五阶「天平之眼」，且所有正义之神技能永久增强50%
   - **总分0-100**：「凡人」——获得五阶，但技能无增强。正义之神说："你不是圣人，也不是恶魔。你是人。这是最难得的。"
   - **总分<0**：「罪人」——无法获得五阶。正义之神说："你的秤，左边沉了。但我不会杀你。因为杀人，会让我的秤也沉下去。"（玩家需要完成赎罪任务才能重新获得五阶）

# 第二神：兽人之神「血祖」古鲁什（Gurush the Blood Ancestor）

## 一、神格定位

### 1.1 世界观嵌入

兽人之神不是"战神"。战火尊问"你战了吗"，兽人之神问"你为何而战"。

> "战斗不是为了杀人。战斗是为了让敌人记住你的名字。当你的名字被遗忘时，你才真正死了。"

**兽人之神的本质**：
- 它是兽人种族的**集体记忆**——不是某个具体的神，是所有死去的兽人英雄的"名字"的集合
- 兽人相信：当一个人死去，他的名字会回归"血祖"；当血祖被呼唤时，所有名字会同时回应
- 因此，兽人之神的声音不是单一的，是**千万个声音的合唱**

**与战火尊的区别**（核心设定）：
- 战火尊："战斗证明存在。" → 存在主义，不问原因
- 兽人之神："战斗证明你是谁。" → 身份主义，只问原因
- 兽人可以同时信仰两者——在战斗前向战火尊祈祷"让我战斗"，战斗后向兽人之神祈祷"记住我的名字"

**与兽人帝国的关系**：
- 战争派（格罗姆）主要信仰**战火尊**——他们更关心"战斗本身"
- 和平派（萨娜）主要信仰**兽人之神**——他们更关心"为什么战斗"
- 但两者都会说："血祖记得一切。"

### 1.2 与其他信仰的关系

| 信仰 | 与兽人之神的关系 |
|------|----------------|
| **战火尊** | **盟友但不同**。可以共存，但核心理念不同 |
| **古根** | **尊重**。古根记住世界，血祖记住兽人。两者都相信"记忆即存在" |
| **正义之神** | **复杂**。血祖不问对错，只问"你是否忠于自己的名字" |
| **生命女神** | **盟友**。两者都关注"传承"——生命女神关注血脉，血祖关注名字 |
| **秩序之神** | **敌对**。秩序说"服从规则"，血祖说"忠于你的名字，即使它违背规则" |

### 1.3 兽人之神在国家战争中的位置

**战争派的视角**：
- 格罗姆会说："血祖记得每一个为人类而战的兽人叛徒。"
- 但格罗姆自己也在血祖的注视下——他杀过自己的挚友铁爪，血祖"记得"这件事

**和平派的视角**：
- 萨娜会说："血祖记得每一个选择不战斗的兽人。不战斗，也是一种名字。"
- 萨娜的"磨平角"传统，实际上是兽人之神的仪式——"放下武器，但不忘名字"

**玩家的位置**：
- 如果玩家是兽人：血祖是你的祖先，你的名字已经被血祖记住了（从你出生的那一刻起）
- 如果玩家不是兽人：血祖不会拒绝你，但会问"你为什么要记住兽人的名字？"

## 二、信仰体系：五阶「铭名」

兽人之神不称量灵魂，**铭记名字**。

| 阶位 | 称号 | 核心含义 | 所需条件 | 供奉 |
|:---:|------|---------|---------|------:|
| 一阶 | **闻血者** | 第一次听到血祖的合唱（千万兽人名字同时回响） | — | 500 |
| 二阶 | **颂名者** | 学会颂唱一个兽人英雄的名字，并获得其力量 | 完成任意兽人之神任务 | 2000 |
| 三阶 | **铭名者** | 你的名字被血祖记录，死后不会消失 | 等级≥14 | 4500 |
| 四阶 | **血祖之喉** | 可以呼唤血祖，召唤死去的兽人英雄作战 | 完成Q290 | 8000 |
| 五阶 | **万血归一** | 你的名字成为血祖的一部分，活着时就能呼唤千万名字 | 完成Q300 | 14000 |

### 各阶能力

**一阶·闻血者**：
- 「血祖低语」：在战斗中，偶尔会听到血祖的声音提示（如"左边有敌人"、"那个敌人很弱"）
- 「兽人亲和」：所有兽人NPC对你的态度+10

**二阶·颂名者**：
- 「英雄颂歌」：可选择一名兽人英雄的名字颂唱，获得其一项能力（持续1场战斗）
  - 颂唱「铁爪·老静语」：获得「铁爪之握」——近战攻击时附加流血效果
  - 颂唱「血喉·格罗姆（年轻时期）」：获得「格罗姆之怒」——生命值低于30%时伤害+50%
  - 颂唱「萨娜·静语」：获得「静语之智」——说服成功率+20%
- 限制：每场战斗只能颂唱一个名字，每天只能颂唱三次

**三阶·铭名者**：
- 「血誓」：可与任意NPC签订「血誓」——如果NPC背叛血誓，你在对其战斗时伤害+30%
- 「名字之重」：死亡时，不会丢失装备和金币（血祖"记住"了你的名字，所以你的存在不会被遗忘）

**四阶·血祖之喉**：
- 「唤名」：战斗中可呼唤一名死去的兽人英雄的灵魂，协助作战（持续3回合）
  - 召唤「铁爪」：高防御坦克，可嘲讽敌人
  - 召唤「格罗姆（青年）」：高攻击狂战士，但会攻击友方
  - 召唤「萨娜的父亲」：辅助型，可为友方恢复HP
- 限制：每次战斗只能召唤一次，且召唤的英雄有自己的意志（不会完全听从玩家）

**五阶·万血归一**：
- 「血祖合唱」：释放血祖的千万名字，所有友方单位属性+20%，所有敌方单位陷入恐惧1回合
- 「永铭」：你的名字被永远记录在血祖中。即使游戏结束（角色死亡），你也可以在"血祖殿堂"中看到自己的名字

## 三、兽人之神任务链（Q251-Q300）

### 3.1 任务链总览

| 篇章 | 任务编号 | 主题 | 核心冲突 |
|------|---------|------|---------|
| **闻血篇** | Q251-Q260 | 玩家接触兽人文化，听到血祖的合唱 | 在战争与和平之间寻找兽人的真实身份 |
| **颂名篇** | Q261-Q280 | 玩家颂唱兽人英雄的名字，理解他们的选择 | 每个英雄都有黑暗面，没有纯粹的英雄 |
| **铭名篇** | Q281-Q290 | 玩家的名字被血祖记录，面对自己的死亡 | 如果名字被记住，死亡是否还有意义？ |
| **终章** | Q291-Q300 | 血祖的终极秘密——所有名字都是谎言 | 兽人之神不是记忆，是"被需要的记忆" |

### 3.2 关键任务详细设计

#### Q251「第一次合唱」

**触发**：玩家进入兽人帝国领土（西方草原），或在与兽人相关的任务中（如Q136大迁徙）。

**剧情**：
1. 玩家在草原上过夜时，听到风中传来声音——不是一个人，是**千万个人**同时说话
2. 声音在说名字："格罗姆……铁爪……萨娜……瓦拉……赫鲁……"（所有死去的兽人英雄）
3. 玩家可以选择：
   - **恐惧**：逃跑。获得debuff「血惧」——48小时内，所有兽人敌人对你伤害+20%
   - **倾听**：静坐聆听。声音会逐渐清晰，你会听到一个特定的名字——那是"属于你的名字"（根据玩家的种族和行为决定）
   - **回应**：大声说出自己的名字。血祖会"回应"你——所有声音会同时重复你的名字，持续三秒
4. 兽人之神信仰解锁

**奖励**：
- 倾听路线：获得「血祖低语」能力（一阶）
- 回应路线：额外获得「名字之印」——一个被动buff，所有兽人NPC初次见到你时态度+5（"血祖知道你"）

#### Q255「英雄的另一面」

**触发**：完成Q251，等级≥10。

**剧情**：
1. 玩家选择颂唱一名兽人英雄的名字。但血祖有一个规则："要颂唱英雄的光，必须先知道他的暗。"
2. 玩家需要调查这名英雄的"黑暗面"：
   - 如果选择「铁爪·老静语」：你会发现他年轻时杀过人类俘虏——不是为了仇恨，是为了"让敌人记住他的名字"
   - 如果选择「格罗姆·血喉（青年）」：你会发现他曾经是和平主义者，直到他的父亲被人类毒杀
   - 如果选择「萨娜·静语」：你会发现她的"和平"是有代价的——她每年要向格罗姆上缴30%的产出，这导致静语草原每年都有人饿死
3. 玩家需要决定：知道黑暗面后，是否还要颂唱这个名字？

**核心冲突**：
- 兽人之神的教义："没有纯粹的英雄。只有被记住的人。"
- 玩家的选择：接受英雄的黑暗面（颂唱名字），还是拒绝（寻找另一个英雄）？

#### Q260「磨平的角」

**触发**：完成Q255，玩家访问静语村。

**剧情**：
1. 萨娜邀请玩家参加"磨角仪式"——静语氏族的传统，幼年时磨平角表示"不设防"
2. 但仪式中，一个静语氏族的年轻人拒绝磨角："我不想忘记如何战斗。"
3. 萨娜说："磨角不是忘记战斗。是选择什么时候战斗。"
4. 年轻人说："但格罗姆不会给我们选择的机会。他会杀了所有磨平角的人。"
5. 玩家需要做出裁决：
   - **支持磨角**：年轻人会服从，但眼中失去光芒
   - **支持不磨角**：年轻人会拿起武器，但他可能死于下一场战争
   - **提出第三条路**："磨平一只角，留下一只。" 这是隐藏选项，需要≥12智力。年轻人会成为"既和平又准备战斗"的象征

**奖励**：
- 支持磨角：获得「静语之印」——说服成功率+15%，但战斗伤害-10%
- 支持不磨角：获得「战角之印」——战斗伤害+15%，但说服成功率-10%
- 第三条路：获得「双角之印」——同时获得两个效果，但每个只有+7%/-7%

#### Q270「格罗姆之死」

**触发**：完成Q260，玩家在兽人帝国活动。

**剧情**：
1. 格罗姆的「灰鳞病」恶化，他预计还有不到一年寿命
2. 格罗姆决定发动「最终劫掠」——不是边境骚扰，是全面入侵人类领土
3. 萨娜向玩家求援："他不是想赢。他想在死前，让血祖记住他的名字。"
4. 玩家需要选择：
   - **阻止格罗姆**：与萨娜联合，在战场上对抗格罗姆。但格罗姆是兽人英雄，杀死他会让血祖"记住"你是一个"杀英雄的人"
   - **帮助格罗姆**：加入他的最终劫掠。你会获得巨大的战斗奖励，但会杀死无数无辜者
   - **说服格罗姆**：告诉他"血祖已经记住你了。你不需要再杀人"。需要完成一系列前置任务，且格罗姆只会听「铁爪的后裔」或「萨娜的盟友」的话

**Boss机制**：
- 格罗姆有三阶段：
  - 第一阶段（100%-70%）：正常使用战斧「吞城者」，高攻击低防御
  - 第二阶段（70%-30%）：灰鳞病发作，身体部分石化，AC+5但移动力-2。他会说"我……快……记不住……自己的名字了……"
  - 第三阶段（30%-0%）：放弃防御，全力攻击。每回合自损10%HP，但伤害×2。他会说"血祖……记住我……格罗姆……血喉……"
- 兽人之神信徒≥三阶可「唤名」——在第三阶段呼唤格罗姆的名字，他会短暂停手，露出迷茫的表情。这是唯一说服他的机会

#### Q280「铁爪的后裔」

**触发**：完成Q270。

**剧情**：
1. 玩家发现铁爪·老静语有一个**私生子**——一个半兽人，被人类母亲抚养长大，不知道自己的父亲是谁
2. 这个半兽人现在是一名人类城市的铁匠，名叫「汤姆」
3. 玩家需要决定是否告诉汤姆真相：
   - **告诉他**：汤姆会崩溃，然后愤怒，然后……选择。他可能去找格罗姆复仇，也可能去静语草原寻找自己的根
   - **不告诉他**：汤姆继续过普通人的生活。但血祖"记得"铁爪的名字，而铁爪的后裔不知道自己的父亲——这是一种"被遗忘"
   - **间接引导**：不直接告诉，但让汤姆"发现"真相。这是最困难但最人道的选择

**核心主题**：
- "名字"不仅是自己的，也是祖先的。如果不知道祖先的名字，你是否还是"完整"的？

#### Q290「血祖的真相」

**触发**：完成Q280。

**剧情**：
1. 玩家发现血祖的终极秘密：**血祖不是真实的**
2. 血祖是兽人在"大崩塌"（三百年前）后创造的——因为兽人失去了帝国、失去了盟友、失去了希望，他们需要"血祖"来让自己相信"我们的名字不会被遗忘"
3. 换句话说：血祖是兽人的**集体幻觉**——但因为千万兽人同时相信，它变成了"真实"
4. 玩家需要做出选择：
   - **揭露真相**：告诉世界"血祖不存在"。这会导致兽人社会的崩溃，但也会让兽人"面对现实"
   - **维护幻觉**：保护真相，让兽人继续相信血祖。这维持了兽人的团结，但也是欺骗
   - **重新定义**：说"血祖不存在，但我们的名字确实存在——在彼此的记忆中"。这是隐藏路线，需要≥16智慧

**奖励**：
- 揭露真相：获得「真相之眼」——可看穿任何集体幻觉，但所有兽人NPC态度-50
- 维护幻觉：获得「守护之誓」——所有兽人NPC态度+30，但你必须永远保守秘密
- 重新定义：获得「新血祖」——你成为"活着的血祖"，你的名字被千万兽人记住

#### Q300「万血归一」

**触发**：完成Q290，等级≥28。

**剧情**：
1. 玩家被召唤到"血祖殿堂"——一个存在于所有兽人梦中的空间
2. 殿堂中，千万个名字在墙壁上发光。玩家会看到：
   - 格罗姆的名字（如果他在Q270中死亡）
   - 铁爪的名字
   - 萨娜的名字（她还活着，但名字已经"预备"了）
   - 如果你完成了Q255，你颂唱过的英雄的名字会特别亮
   - **最亮的名字**：是你自己的名字
3. 血祖会问（千万个声音同时）："你愿意让你的名字，成为千万名字中的一个吗？"
4. 玩家的选择：
   - **愿意**：获得五阶「万血归一」。你的名字永远留在血祖中。但代价是：你的一部分"自我"会消散——你会开始听到其他名字的声音，有时会分不清"我是谁"
   - **不愿意**：保持独立。获得四阶「血祖之喉」，但无法达到五阶。血祖说："你的名字很亮。但孤独。"
