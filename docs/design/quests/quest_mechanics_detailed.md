# 任务机制详细设计

> 为200个剧情任务补充实际可玩的机制骨骼。在现有系统约束下（3种目标类型，无对话树），通过多阶段目标、特殊战棋规则、AI行为差异和 settlement_action 抉择节点来实现深度。

---

## 任务设计模式库

### 模式A：多阶段遭遇链
```
objective_1: defeat_enemy(前锋, 3)  →  开门/触发事件
objective_2: defeat_enemy(精英, 1)   →  获取关键物品
objective_3: settlement_action(报告) →  选择分支奖励
```

### 模式B：阵地防御战
```
objective_1: defeat_enemy(波次1, N)  →  保护目标物存活
objective_2: defeat_enemy(波次2, N)  →  保护目标物存活
objective_3: defeat_enemy(波次3, N)  →  目标物HP>0则完成
```
> 注："目标物存活"通过 quest_progress_events 中的 context 记录，由 BattleRuntime 在结算时判断目标物HP。

### 模式C：收集-触发-战斗
```
objective_1: submit_item(材料A, 3)   →  制造开门道具/解除封印
objective_2: defeat_enemy(守护者, 1) →  进入核心区域
objective_3: submit_item(任务物品, 1) →  带回报酬
```

### 模式D：潜入或正面
```
objective_1: settlement_action(选择潜入) 或 defeat_enemy(正面清剿)
objective_2: 根据选择1解锁不同的objective_2
```
> 注：可通过两条并行的 quest_id 实现（如 `quest_sneak` 和 `quest_assault`），接取时由玩家选择。

### 模式E：环境机制战
```
objective_1: defeat_enemy(Boss, 1)
特殊规则：场地每N回合塌陷/起火/重力反转
```
> 注：通过 battle_sim profiles 或特定 encounter 配置实现场地效果。

### 模式F：护送/伴随
```
objective_1: settlement_action(开始护送)
objective_2: defeat_enemy(伏击者, N) → NPC必须存活
objective_3: settlement_action(送达)
```

### 模式G：限时生存
```
objective_1: defeat_enemy(无限波次, N只) → 坚持X回合
特殊规则：不以全灭为目标，以存活回合数为完成条件
```

## 主世界任务详细机制

### Q001 初阵 【教学模式】

**目标结构**：
1. `defeat_enemy(wolf_pack, 3)` — 击败3只荒狼
2. `settlement_action(service_contract_board, 1)` — 回委托板报告

**战棋设计**：
- 场地：6×6 农田网格，中央有草垛（1格掩体，+2AC）
- 敌人：`wolf_pack` ×3，AI为 `melee_aggressor`（近战侵略型）
- 特殊机制：
  - 第一回合玩家AP+2（教程提示："移动到这里，然后攻击"）
  - 敌人HP降至30%时会尝试逃跑（向地图边缘移动）
  - 击败第一只后，剩余两只进入"包抄"模式，试图绕到玩家侧翼

**奖励**：50金 + `skill_unlock: charge`

### Q003 狼群首领 【首个精英战】

**目标结构**：
1. `defeat_enemy(wolf_alpha, 1)` — 击败狼群首领
2. `settlement_action(service_contract_board, 1)` — 报告

**战棋设计**：
- 场地：8×8 山丘网格，中央高地（占据后射程+1，命中+1）
- 敌人：`wolf_alpha` ×1 + `wolf_pack` ×2（杂兵）
- **wolf_alpha 特殊AI**：
  - 第一回合必定使用"嚎叫"：召唤2格内所有友方单位AP+1
  - HP>50%时：积极进攻，优先攻击最低HP目标
  - HP<50%时：撤退到高地，命令杂兵挡在前方（杂兵获得"护卫"标记，主动为主首领承受攻击）
  - HP<25%时：狂暴，伤害+3，但AC-2
- 地形互动：山丘边缘有"滑坡"格，站在上面的单位被冲撞命中时可能滑落（强制位移2格）

**奖励**：150金 + `skill_unlock: warrior_guard`

### Q006 边境巡逻 【标准遭遇+探索】

**目标结构**：
1. `defeat_enemy(wolf_raider, 5)` — 清剿狼骑兵
2. `settlement_action(service_contract_board, 1)` — 报告异常发现

**战棋设计**：
- 场地：10×8 商道网格，中间2格宽为"道路"（移动-1AP），两侧为"荒地"
- 敌人：`wolf_raider` ×5，AI为 `ranged_archer`（远程弓箭手型），但骑乘状态移动力+2
- 特殊机制：
  - 敌人优先攻击"商队NPC"（如果任务携带NPC）
  - 商道两侧高地有"废弃弩台"，玩家角色可用2AP操作，造成2d6穿刺伤害（冷却3回合）
  - 第3回合，地图边缘刷新2只 `wolf_pack` 增援（从后方包抄）
- 收集元素：最后一只狼骑兵死亡时掉落"灰色鳞片"（context记录，用于后续任务）

**奖励**：200金 + `iron_ore` ×3

### Q008 裂隙封印 【首个Boss战】

**目标结构**：
1. `defeat_enemy(mist_beast, 2)` — 清除前锋
2. `defeat_enemy(mist_weaver, 1)` — 击败编织者
3. `settlement_action(service_contract_board, 1)` — 报告

**战棋设计**：
- 场地：10×10 裂隙边缘网格，中央有"裂隙"（3×3不可进入区域，每回合随机向相邻1格喷射"迷雾"）
- **迷雾效果**：进入迷雾格的单位命中率-2，移动力-1
- 敌人阶段：
  - 阶段1：`mist_beast` ×2，前排坦克AI，有"迷雾光环"（相邻友方+1AC，-1接触AC）
  - 阶段2：`mist_weaver` ×1 在 mist_beast 全灭后从裂隙侧出现
- **mist_weaver 特殊机制**：
  - 法师控制AI，优先使用法术而非普攻
  - "现实编织"：每2回合选择1个玩家角色，该角色下回合最高AP消耗技能封印1回合
  - "迷雾步"：可消耗2AP瞬移到任意迷雾格（无视借机攻击）
  - 弱点：火焰伤害使其下回合法术失败率50%
- 环境目标：玩家可以破坏裂隙边缘的"稳定水晶"（AC12，15HP），破坏后本场战斗不再产生新迷雾

**奖励**：500金 + `calamity_shard` ×1 + 智力成长+20

### Q010 村庄保卫战 【阵地防御战】

**目标结构**：
1. `defeat_enemy(wolf_raider, 10)` — 抵御3波袭击（波次在context中区分）

**战棋设计**：
- 场地：12×8 村庄外围，北侧为"栅栏防线"（占据3格，20HP，AC15，友方站在相邻格获得+2AC）
- 友方NPC：
  - 村长（弓箭手）：每2回合自动射击最近敌人，伤害1d8，只有6支箭，射完后转为近战（1d4）
  - 民兵×2：前排步兵，HP低（8HP），但会主动挡在村民前面
- 敌人波次：
  - 波次1（第1回合）：`wolf_raider` ×3 从东侧出现
  - 波次2（第4回合）：`wolf_raider` ×4 从南侧出现 + `wolf_pack` ×2 从西侧包抄
  - 波次3（第7回合）：`wolf_alpha` ×1 + `wolf_raider` ×3 从北侧主攻栅栏
- 失败条件：栅栏HP降至0，或村长死亡
- 特殊机制：玩家可用2AP修复栅栏（恢复5HP），或操作屋顶弩台（每3回合1次，3格范围，2d8伤害）

**奖励**：300金 + `travel_ration` ×5

### Q012 失踪的巡逻队 【调查探索】

**目标结构**：
1. `submit_item(bandit_insignia, 2)` — 收集现场证据
2. `defeat_enemy(wolf_shaman, 2)` — 击退占据营地的邪教徒
3. `settlement_action(service_contract_board, 1)` — 报告

**战棋设计**：
- 场地：10×10 营地网格，有帐篷（可进入，内部1格，提供掩体）、篝火（相邻格每回合受1火焰伤害）
- 阶段1（调查）：无战斗，在营地搜索3个交互点：
  - 帐篷内：找到 `sealed_dispatch`（可拾取）
  - 篝火旁： footprints 走向裂隙（触发任务更新）
  - 武器堆：发现武器被整齐堆放（非战斗撤离的迹象）
- 阶段2（触发战斗）：当玩家接近 footprints 终点时，埋伏的 `wolf_shaman` ×2 + `wolf_pack` ×4 出现
- **wolf_shaman 特殊机制**：
  - 每3回合施放"血怒"：所有友方兽人伤害+2，但受到的伤害+1
  - 会主动复活阵亡的 `wolf_pack`（每2回合1次，复活1只，HP为最大值50%）
  - 优先击杀规则：若玩家有治疗技能，shaman会优先攻击治疗者

**奖励**：400金 + `healing_herb` ×5

### Q015 匪徒伏击 【潜入或正面】

**双路径设计**：
- 任务接取时，通过 settlement_action 选择路径：
  - **路径A（正面）**：`quest_bandit_assault`
  - **路径B（潜入）**：`quest_bandit_infiltrate`

**路径A — 正面清剿**：
- 目标：`defeat_enemy(wolf_raider, 6)` + `defeat_enemy(bandit_captain, 1)`
- 场地：峡谷营地，敌人分散在3个区域
- 敌人AI：`wolf_raider` 为 ranged_archer，`bandit_captain` 为 melee_aggressor 精英版（每回合可命令1个友方单位额外移动2格）
- 特殊：敌人会敲警钟召唤增援（若玩家在3回合内未击杀敲钟者，额外出现4个敌人）

**路径B — 潜入破坏**：
- 目标：`submit_item(forge_coal, 3)`（在营地内收集并点燃炸药）+ `settlement_action(escape)`
- 场地：同峡谷，但敌人初始为"未警觉"状态
- 机制：
  - 玩家移动力+2（潜行模式），但进入敌人视野格（3格锥形）会触发警报
  - 可绕行背后，用1AP"暗杀"单个敌人（秒杀，但每回合只能1次）
  - 收集3份炸药材料后，在指定地点 settlement_action 引爆，任务完成（无需全灭敌人）

**奖励差异**：
- 路径A：350金 + `iron_ore` ×5（战斗奖励更高）
- 路径B：250金 + `bandit_insignia` ×3 + 知识解锁"匪徒网络"（信息奖励）

### Q022 鼠患之巢 【地下城探索】

**目标结构**：
1. `defeat_enemy(wolf_pack, 8)` — 清剿矿坑深处的变异兽群
2. `submit_item(iron_ore, 5)` — 收集特殊矿石样本
3. `settlement_action(service_contract_board, 1)` — 报告

**战棋设计**：
- 场地：多层地下网格（上层8×8，下层6×6，通过楼梯连接）
- 上层：普通 `wolf_pack` ×4，矿车轨道（站在轨道上的单位每3回合可能被矿车撞击，强制位移+1d6伤害）
- 下层：`wolf_pack` ×4（变异体，HP+30%，但火焰伤害翻倍）+ 环境 hazard："酸性水坑"（进入后每回合受1d4酸蚀，离开后持续2回合）
- 隐藏区域：下层东南角有隐藏通道（需要感知相关技能或 `dead_road_lantern` 照亮），内有 `calamity_shard` ×1
- 收集目标：5份 `iron_ore` 散布在各层，需移动采集

**奖励**：200金 + `iron_ore` ×5 + 可能有 `calamity_shard`

### Q029 深渊之门 【环境机制Boss战】

**目标结构**：
1. `defeat_enemy(mist_weaver, 2)` — 封印次级裂隙的守护者
2. `submit_item(moonfern_sample, 3)` — 用月蕨稳定封印
3. `settlement_action(service_contract_board, 1)` — 报告

**战棋设计**：
- 场地：10×10 森林网格，中央为"次级裂隙"（2×2不可进入，每回合向四周扩散1格"腐蚀区"）
- 腐蚀区效果：进入后每回合受1d6力场伤害，离开后下回合仍受一半伤害
- 封印机制：
  - 玩家可携带 `moonfern_sample`（任务物品）到裂隙四角的"封印柱"（每柱需1份样本， settlement_action 封印）
  - 4根封印柱全部激活后，裂隙关闭，所有腐蚀区消失
  - 但封印柱激活时会召唤2只 `mist_harrier` 守卫
- 敌人：`mist_weaver` ×2 初始在裂隙两侧，AI为 `mage_controller`
  - 编织者会优先攻击正在封印的玩家角色
  - 每3回合，编织者从裂隙召唤1只 `mist_beast` 增援
- 战术选择：可先击杀编织者再封印（安全但敌人多），或边封印边防守（压力大但快）

**奖励**：600金 + `calamity_shard` ×2

### Q036 盗贼的暗影契约 【潜入抉择】

**目标结构**：
1. `submit_item(bandit_insignia, 10)` — 从金库中取得目标纹章

**战棋设计**：
- 场地：双层建筑网格（上层守卫区12×8，下层金库区6×6）
- 潜入机制（模拟）：
  - 上层有6名守卫（`wolf_vanguard` ×6），按固定巡逻路线移动
  - 玩家有3名角色，需同时控制，避开守卫视野（4格锥形，每回合旋转90度）
  - 若被发现：触发警报，下层额外出现4名守卫，任务变为正面战斗
  - "暗杀"机制：从背后接近守卫可用1AP使其"昏迷"1回合（不击杀，不会触发警报）
- 金库机关：
  - 正门：需要 `bandit_insignia` ×1 打开（但会引起注意）
  - 通风口：需要敏捷相关技能，通过狭窄通道（移动-2AP）
  - 密道：在厨房地窖，需要感知检定发现
- 隐藏发现：金库内有笼子，关着暗红眼睛的小孩（剧情线索，context记录，触发隐藏任务 `hidden_demonic_child`）

**奖励**：500金 + `scout_charm` ×1 + 解锁隐藏任务

### Q046 灰烬觉醒 【异界首战】

**目标结构**：
1. `defeat_enemy(mist_beast, 1)` — 在余烬祭所外围击败迷雾兽

**战棋设计**：
- 场地：8×8 灰烬荒原网格，无天然掩体，但散落"灰烬堆"（消耗1AP可踢起，制造1格烟雾，持续2回合）
- 迷雾：`mist_beast` ×1
- **灰烬地形规则**：
  - 移动消耗+0.5AP（向下取整为+1AP）
  - 火焰技能范围+1（灰烬助燃），但持续伤害+1回合
  - 站在"灰烬堆"上的单位被击杀时，会爆发出"灰烬云"（2格范围，命中率-1，持续1回合）
- **mist_beast 异界版AI**：
  - "迷雾光环"：相邻2格内友方单位+1AC（本次战斗中无友方，但机制存在）
  - "吞噬灰烬"：若站在灰烬堆上，每回合恢复2HP
  - 弱点：火焰伤害使其"灰烬外壳"剥落，AC-2（持续至战斗结束）

**奖励**：100金 + `skill_unlock: warrior_backstep`

### Q052 异端之骸 【大教堂区域首战】

**目标结构**：
1. `defeat_enemy(mist_beast, 3)` — 清剿中央过道
2. `defeat_enemy(mist_harrier, 2)` — 清除彩窗残骸中的突袭者
3. `settlement_action(service_contract_board, 1)` — 报告

**战棋设计**：
- 场地：12×10 大教堂废墟网格，有"长椅排"（每排提供1格掩体，+1AC）、"倒塌石柱"（占据2格，不可通过，但可攀爬，消耗3AP到达顶部，射程+2）
- 阶段1：`mist_beast` ×3 分布在中央过道，其中1只在"做礼拜"（前2回合不主动攻击，除非被攻击）
- 阶段2：当第一只 mist_beast 被攻击时，`mist_harrier` ×2 从彩窗高处跳下（落地时造成1d6钝击范围伤害）
- **mist_harrier 特殊机制**：

- 环境互动：敲碎"彩窗残骸"（1AP）可制造"玻璃碎片区"（进入受1d4切割，持续2回合）

**奖励**：600金 + `blood_debt_shawl`

### Q055 灰烬祭司 【精英Boss战】

**目标结构**：
1. `defeat_enemy(mist_beast, 4)` — 灰烬侍僧（精英小怪）
2. `defeat_enemy(mist_weaver, 1)` — 灰烬祭司（Boss）
3. `settlement_action(service_contract_board, 1)` — 报告

**战棋设计**：
- 场地：10×10 地下祭坛网格，中央祭坛（2×2，占据后每回合恢复1HP），四角有"灰烬火炬"（可点燃/熄灭，点燃时全场光明，熄灭时迷雾兽获得+1命中）
- 阶段1：`mist_beast` ×4（灰烬侍僧），前排坦克AI，特殊行为：
  - "挡枪"：若灰烬祭司在2格内，侍僧会主动移动至祭司与玩家之间，承受本回合下一次攻击
  - "殉道"：侍僧死亡时对相邻1格造成2d6火焰伤害（自爆）
- 阶段2：侍僧全灭后，灰烬祭司激活
- **灰烬祭司 Boss机制**：
  - 占据2×2格，触及范围2格
  - "灰烬圣唱"（每3回合）：全场不死/异界生物恢复1d8+2HP，玩家可通过造成15+单体伤害或施加控制效果（眩晕/沉默/定身）打断

## 附录：如何在现有系统下扩展任务深度

### 1. 通过 `context` 传递战斗状态

`QuestProgressService.record_progress()` 支持传入 `context` Dictionary。BattleRuntime 可以在 `BattleResolutionResult.quest_progress_events` 中附加 context：

```csharp
// 示例：村庄保卫战中判断栅栏是否存活
quest_progress_events.Add(new Dictionary {
    ["event_type"] = "progress",
    ["quest_id"] = "main_village_siege",
    ["objective_id"] = "defeat_raiders",
    ["progress_delta"] = defeatedCount,
    ["context"] = new Dictionary {
        ["fence_hp"] = fenceUnit.CurrentHp,
        ["village_chief_alive"] = chiefUnit.IsAlive,
    }
});
```

### 2. 通过多条 quest_id 实现分支

不要试图在一个 QuestDef 内实现复杂分支。使用多个 quest_id：

```
quest_bandit_assault     → 正面战斗路线
quest_bandit_infiltrate  → 潜入路线
quest_bandit_negotiate   → 谈判路线
```

接取时由 settlement_action 或前置条件控制玩家能获得哪一个。

### 3. 通过 `tags` 实现动态任务板

```csharp
// 任务板根据玩家状态显示不同任务
if (player_has_tag("empire_soldier"))
    show_quests_with_tag("empire");
else if (player_has_tag("federation_hero"))
    show_quests_with_tag("federation");
```

### 4. 通过 `auto_accept` 实现连锁触发

```csharp
// 完成 Q008 后自动触发 Q009
quest_progress_events.Add(new Dictionary {
    ["event_type"] = "progress",
    ["quest_id"] = "main_ashlands_scout",
    ["objective_id"] = "auto_accept_trigger",
    ["auto_accept"] = true,
});
```
