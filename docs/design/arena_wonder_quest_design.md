## 零、世界观前提

### 0.1 大陆上的"决斗"传统

大陆上每个种族都有各自的"一对一"战斗哲学，但形态各异：

| 种族/势力 | 决斗名称 | 核心精神 | 与竞技场的关系 |
|-----------|----------|----------|----------------|
| **兽人（血喉帝国）** | 荣耀决斗（Q137） | "选择自己的死法" | 战争派视竞技场为"人类把戏"，和平派则认为这是另一种形式的荣耀 |
| **龙族/龙裔** | 龙骑士誓言（Q166） | "狱卒与囚犯共享锁链" | 竞技场是少数能让龙骑士"公平"战斗的地方——龙的体型被界火压制为人类形态 |
| **霜烬帝国** | 无正式决斗传统 | 帝国不承认个体间的公平战斗，只承认军团秩序 | 帝国军官私下会来竞技场"解决私人恩怨"，但从不公开承认 |
| **星陨联邦** | 七族仲裁决斗 | 联邦法律规定，七族成员间的不可调和矛盾可通过"仲裁决斗"解决 | 竞技场是联邦官方认可的仲裁场所之一 |
| **灰烬王朝遗民** | 守门人试炼 | 已失传，据说是筛选"第七守门人"的仪式 | **竞技场的真正起源** |

### 0.2 万战圆环的真相

万战圆环不是任何现代国家建造的。它是一座**灰烬王朝遗迹**，直径约三百步的 perfect circle，材质不明——不是石、不是金属、不是界火结晶，而是某种"凝固的寂静"。

**关键事实**：
- 圆环内部，所有**外部力量**被压制：装备附魔失效、信仰神力无法降临、种族天赋（如矮人毒素抗性、精灵黑暗视觉）被暂时剥离
- 圆环内部，**内在力量**被放大：技巧、经验、肌肉记忆、战斗直觉——这些"属于战士本人的东西"会变得异常清晰
- 圆环边缘有**十万道刻痕**，不是装饰，是计数。每一道刻痕代表一场被圆环认可的"公平决斗"
- 圆环中央有一座无面雕像，手持双剑交叉于胸前。没有人见过雕像的脸——不是被毁，而是"尚未被决定"

**传说**：当第十万道刻痕出现时，雕像会裂开，露出其中沉睡的"**第一决斗者**"——灰烬王朝时期最强的战士，也是守门人试炼的创造者。他会向胜利者提出一个问题，这个问题的答案将决定圆环是继续沉睡，还是成为某种更危险的东西。

### 0.3 谁控制着竞技场

没有人。也没有任何势力能控制它。

圆环坐落在灰烬交界与主世界的交汇点上——物理上它位于主世界某处荒原，但界火裂隙的能量使其同时存在于灰烬交界的某个对应坐标。这意味着：
- 帝国和联邦的军队都无法长期占领它（圆环会在大军逼近时"消失"，只在少数人靠近时显现）
- 只有**七人以下**的团体能接近圆环——这是某种古老的封印机制
- 圆环有自己的"规则"：进入者必须同意"公平决斗"的契约，否则会被逐出

**实际管理者**：一群自称为"**计数人**"（Tally-Keepers）的流浪者。他们不是任何种族，或者说，他们是太多种族的混血，已经无法被归类。他们在圆环外围搭建帐篷，记录每一场决斗的结果，为决斗者提供基本的医疗和仲裁服务。他们不偏袒任何一方，因为"圆环不偏袒，我们只是圆环的舌头"。

## 一、场景设定

### 1.1 万战圆环外部：计数人营地

- **位置**：荒原中心，四周没有明显的地标。第一次来访的玩家会感觉"这里不应该有建筑"，但圆环就在那里。
- **天气**：永远是黄昏。不是某个特定的黄昏，而是"黄昏本身"——太阳既不升起也不落下，天空是一种固定的琥珀色。
- **声音**：没有鸟鸣，没有风声。只有铁器碰撞的 echo，以及计数人低声的计数："九万七千四百二十一……九万七千四百二十二……"
- **气味**：铁锈、灰烬、以及某种奇怪的"干净"——像刚磨过的刀刃。

**无法忽视的事实**：
1. 计数人的帐篷里没有床，只有镜子——他们说"我们不需要睡觉，我们需要记住自己是谁"
2. 营地边缘有一圈倒插的武器，来自历代在圆环中战死的决斗者。它们不是墓碑，是"还在等待主人回来取走它们"
3. 如果你带着强烈的"杀人意图"接近圆环，你会在五十步外突然忘记为什么要来这里。只有"战斗意图"能通过

### 1.2 万战圆环内部：决斗场

- **尺寸**：直径30格的正圆形（战棋尺度），中央5格为"心域"，外围10格为"环域"，再外围15格为"界域"
- **地面**：凝固的寂静材质， footsteps 不会产生声音，但会产生微小的涟漪（像踩在水面上）
- **光源**：无明确光源，但能见度永远清晰。没有影子——或者说，每个人的影子都指向圆心

**无法忽视的事实**：
1. 圆环内不能说话。不是物理上的禁音，而是"话语在这里变得无意义"——你可以开口，但你会意识到说的话不重要
2. 每一场决斗结束后，地面会短暂显示两位决斗者的"真名"——不是他们自称的名字，而是某种更深层的身份标识。计数人会记录下来，但从不解释
3. 圆环内死亡不是真正的死亡——失败者会被"逐出"到圆环边缘，身上带着一道无法愈合的疤痕。但如果有人在圆环内**拒绝承认失败**（即被击败后仍攻击对手），界火会真正烧死他

### 1.3 场景状态总览

```
[主世界荒原] ——approach——> [计数人营地] ——consent——> [万战圆环]
                                      |
                                      v
                               [武器之圈：倒插的遗物]
                                      |
                                      v
                               [圆环入口：契约石碑]
                                      |
                      +---------------+---------------+
                      |               |               |
                   [界域]          [环域]          [心域]
                 (外围15格)      (中间10格)       (中央5格)
                      |               |               |
                  移动速度-1      无特殊效果      暴击+10%
                  远程射程-1                      但承伤+10%
```

## 二、NPC角色档案

### 2.1 计数人·零（Null the Tally-Keeper）

| 属性 | 描述 |
|------|------|
| 种族 | 不可归类（自称"第零代混血"） |
| 年龄 | 不可判断（外观约60岁人类，但计数人说他已计数三百年） |
| 外貌 | 没有瞳孔，眼白是纯粹的灰白色；皮肤上有数字状的天然斑纹；左手有六根手指，据说"为了更快地计数" |
| 穿着 | 无数层叠的灰白色布条，每层上都写着数字；腰间挂着一个空荡的算盘——珠子是透明的，只有在计数时才会显现 |
| 声音 | 没有音调变化，像机器在朗读 |

**对话特征**：
- 从不使用代词（"我"、"你"、"他"），只用数字或描述："第九万七千四百二十二号来访者"
- 回答问题时总是先报一个数字，然后才是答案："七。是的，圆环接受非致命决斗。"
- 当被问及"为什么计数"时，他会说："因为圆环在等一个数字。数字到了，门就会开。"

## 四、详细任务设计

### SQ-ARENA-01 圆环的邀请函

#### 4.1 触发方式

玩家在以下任一条件满足后，会在世界地图移动时触发"黄昏异常"事件：
- 完成 Q008「裂隙封印」
- 任一角色达到 Lv.10
- 携带 Q137 的兽人狂战士盟友（若饶恕了血嚎）

#### 4.2 叙事流程

**接近圆环（世界地图事件）**

天空突然变成固定的琥珀色。你的指南针开始旋转，然后停在一个不存在的方向上。前方本来是一片荒原，但现在有一座圆形的……东西在那里。它不是建筑，是"一个被空出来的空间"。

计数人·零站在圆环边缘，背对着你，正在地面上刻什么。

【接近】

零没有转身："九万七千四百二十二号。你来得比预计早。预计是九万八千号之后。"

【你是谁？】
"零。计数人。不是第一个，但可能是最后一个。"

【这是什么地方？】
"万战圆环。十万场决斗的容器。还差两千五百七十八场。"

【什么十万场？】
零终于转身。他的眼睛让你感到一阵眩晕——不是恐惧，是"被计算"的感觉。
"当第十万场公平的决斗完成时，雕像会裂开。第一决斗者会问胜利者一个问题。答案决定圆环是继续沉睡，还是醒来。"

【第一决斗者是谁？】
"我们不知道。我们只知道他很强。强到连灰烬王朝都害怕他。所以王朝把他封进了圆环，让他永远战斗——不是惩罚，是保护。保护王朝，也保护他。"

【为什么要告诉我这些？】
"因为你身上有刻痕的潜质。不是所有人都有。大多数人只是来送死，或者来杀人。但你……你在寻找某种公平。"

#### 4.3 战棋设计

本任务无战斗，纯叙事+教学。

**解锁内容**：
- 万战圆环作为可访问据点解锁
- 获得知识：`knowledge_arena_rules`（圆环法则：圆环内外部力量压制机制说明）
- 获得计数人营地的基本服务：决斗登记、医疗（ scars only，不能恢复HP）、武器修复

**抉择节点**：
- 【接受契约】：正式进入圆环任务链，获得"圆环挑战者"身份标记
- 【拒绝契约】：可以离开，圆环据点保持解锁但无任务推进。随时可返回接受
- 【询问代价】：零会说："代价是你必须公平。不公平的人会被烧死。"

### SQ-ARENA-02 初阵之试

#### 4.4 叙事前提

接受契约后，零要求玩家进行"第一场被圆环认可的决斗"。对手不是强敌，而是圆环从玩家"过去的战斗记忆中抽取的影像"——具体来说，是玩家在游戏中击败的第一个有意义的敌人（根据存档数据动态选择，若无法读取则默认使用 `wolf_alpha` 的强化版本）。

> **叙事meta层**：圆环能读取玩家的战斗历史，这暗示圆环与灰烬交界的某种"记忆"属性相关——呼应灰烬王朝"被遗忘而非被毁灭"的核心主题。

#### 4.5 战棋设计

**场地**：16×16 万战圆环（完整圆形）

**特殊规则——圆环法则**：
1. **力量剥离**：所有角色进入时，以下效果暂时失效：
   - 装备附魔效果
   - 信仰神力效果（福图娜的运气加成、摩拉丹的神触时刻等）
   - 种族被动特性（矮人毒素抗性、精灵黑暗视觉、兽人狂暴等）
   - 药水/食物buff
2. **技艺放大**：以下效果获得+20%加成：
   - 技能熟练度提供的命中/伤害加成
   - 职业特性（如战士的斗气获取）
   - 玩家手动操作的战术收益（侧背击、高地优势等）
3. **心域机制**：中央5格范围内，暴击率+10%，但受到伤害+10%
4. **无声领域**：圆环内无法使用任何需要"语言"的技能（如战吼、命令、祈祷类技能被封印）
5. **公平誓约**：决斗开始前，双方HP被调整至各自最大HP的100%（恢复满状态），但**战后不会恢复**——连续挑战时HP继承

**敌方**：`arena_memory_wolf` ×1（玩家首个击败敌人的强化影像）
- HP为原版的150%
- AI为 `arena_honor`（荣誉AI：不会逃跑，不会召唤援军，HP<25%时伤害+20%但不再使用防御技能）
- 特殊：击败后不会死亡，而是化为灰烬被圆环吸收

**胜利条件**：击败 arena_memory_wolf
**失败条件**：玩家全部角色倒地（但圆环的"公平誓约"会保护玩家：失败后角色被逐出圆环，HP降至1但不会被真正击杀）

#### 4.6 战后叙事

零在圆环边缘等待："九万七千四百二十二号。第一场。记录完成。"

他指向地面——一道新的刻痕出现了，旁边隐约浮现玩家的角色名。

【我看到了我的名字】
"那是你的战斗之名。不是真名。真名需要更多场决斗才能显现。"

【什么真名？】
"每个人在圆环中都有一个真名。不是父母给的，是你自己挣的。第一决斗者也有真名。他的真名被封印在雕像里。"

### SQ-ARENA-03 兽人的第七道疤

#### 4.7 叙事前提

**前置**：完成 SQ-ARENA-02，且 Q137 状态为"已完成"（无论饶恕或击杀血嚎）。

血嚎站在圆环边缘，身上的七道疤痕在琥珀色光线下显得异常清晰。他看到你，咧嘴一笑——不是挑衅，是某种解脱。

"人类。我在这个圆环里打了七场。七场全胜。七道疤。"

他解开腰间的兽皮，露出更多疤痕——有些来自圆环，有些来自其他战斗。

"但这里（指心口）没有疤。你知道为什么吗？因为没有人值得我在那里留下印记。"

【你是来复仇的？】（若Q137击杀了他）
"不。血嚎死了。我是……他还没完成的部分。"

【你是来再比一次的？】（若Q137饶恕了他）
"我是来确认一件事。在灰炉镇，你饶了我。那不是荣耀决斗的规则。我想知道，在这里——在公平的地方——你会怎么选。"

#### 4.8 战棋设计

**场地**：16×16 万战圆环

**圆环法则**：同 SQ-ARENA-02（力量剥离、技艺放大、心域、无声、公平誓约）

**敌方**：`arena_bloodhowl` ×1（血嚎·格罗姆之子）

| 阶段 | HP条件 | 行为模式 |
|------|--------|----------|
| **试探期** | HP>75% | 标准近战AI，优先使用「星刃决斗」流派技能（星点试探、月弧侧斩），保持距离试探玩家风格 |
| **狂暴期** | HP 50%-75% | 放弃防御，全力进攻，每回合使用「断光截手」封印玩家技能；伤害+15%，AC-2 |
| **不屈期** | HP 25%-50% | 兽人种族狂暴被圆环压制，但触发替代机制「内在狂暴」：放弃所有技能，只用普通攻击，但普通攻击伤害+50%、连击两次 |
| **终局期** | HP<25% | 免疫死亡一次（圆环特殊规则：HP降至0时不倒地，保留1HP一回合）；下回合必定暴击；若仍未被击败，则真正倒地 |

**特殊机制——兽人的选择**：
- 血嚎HP降至10%时，会停止攻击，进入`settlement_action`抉择：
  - 【给予致命一击】：血嚎死亡（在圆环中真正死亡，无法复活），玩家获得战利品「血嚎的兽皮」（饰品：HP<25%时伤害+3，但每场战斗失去1HP）
  - 【饶恕】：血嚎愣住，然后缓缓跪下——不是投降，是"承认"。他成为圆环中的"常驻决斗者"，玩家可随时找他再战。获得称号「值得兽人承认的对手」
  - 【问他为什么战斗】：触发隐藏对话，血嚎会说："因为我不知道其他活法。父亲没有教过我。" 此选项不影响战斗结果，但会在后续兽人帝国任务线中产生蝴蝶效应

#### 4.9 战后世界变化

| 选择 | 立即效果 | 长期影响 |
|------|----------|----------|
| 致命一击 | 获得饰品，血嚎从后续任务中移除 | 兽人帝国任务线中，格罗姆获得"为子复仇"加成，更难说服 |
| 饶恕 | 获得称号，血嚎成为可重复挑战的对手 | 兽人帝国任务线中，若后续与和平派合作，血嚎可能作为第三方介入 |
| 隐藏对话 | 无物品奖励，但获得知识 | 血喉帝国内战任务线中，血嚎可能有额外的叛逃/觉醒剧情 |

### SQ-ARENA-04 龙骑士的解脱

#### 4.10 叙事前提

**前置**：完成 SQ-ARENA-02，且 Q166 状态为"已完成"。

凯尔多兰坐在圆环边缘，龙鳞在琥珀光下呈现病态的金色。他的龙——如果还能称之为龙的话——不在他身边。在圆环中，龙被压制为人类形态的一个"影子"，附着在他的背上。

"你拿了锁链，"他说，"现在你知道那意味着什么。"

【你想要什么？】
"我想死。但不是普通的死。龙骑士不能自杀——锁链会阻止。我也不能被弱小的敌人杀死——锁链会保护。我需要一个**公平的死亡**。在圆环里，锁链变薄了。"

【为什么是我？】
"因为你在Q166中赢了。你是唯一一个'值得杀死龙骑士'的人。"

#### 4.11 战棋设计

**场地**：16×16 万战圆环

**圆环法则**：同前

**敌方**：`arena_dragon_knight` ×1（凯尔多兰）

| 机制 | 描述 |
|------|------|
| **双生HP** | 凯尔多兰有独立的"骑士HP"和"龙HP"。圆环将龙压制为人类形态，但龙仍独立承受伤害。龙HP归零时，骑士HP也受到等同伤害 |
| **共享攻击** | 每回合，凯尔多兰进行两次攻击：一次来自骑士（物理），一次来自龙（火焰/魔法）。圆环压制后，龙的攻击变为"残余火焰"（伤害-30%，但仍无视部分护甲） |
| **锁链反噬** | 每3回合，锁链试图"修复"自身——凯尔多兰恢复10%HP（优先恢复龙HP），但下回合无法行动 |
| **求死意志** | 凯尔多兰的AI不是最优化的。他会故意暴露破绽（侧背对玩家），但不会完全放弃防御——"我要死，但要死得有尊严" |

**特殊机制——解脱的选择**：
- 击败凯尔多兰后，他不倒地，而是单膝跪地。`settlement_action`：
  - 【给予死亡】：凯尔多兰微笑，第一次也是最后一次。龙鳞脱落，露出下面苍老的人类皮肤。他化为灰烬，锁链断裂。玩家获得「断链之印」（知识：龙骑士解脱的方式）
  - 【打破锁链】：需要玩家携带 Q166 获得的「龙骑士之锁」饰品。用锁对抗锁，凯尔多兰存活，但失去龙的力量，变回普通老人。他感谢玩家，然后离开圆环，去向不明。后续可能在联邦某处作为普通NPC出现
  - 【成为新的锁链】：玩家选择继承龙骑士之位（仅限角色职业为战士/骑士时）。凯尔多兰的龙转移到玩家身上，玩家获得永久性debuff「龙骑士之锁」（与龙战斗时龙伤害-3，但每场战斗失去2HP）+ 永久性buff「残余龙火」（普通攻击附加少量火焰伤害）。凯尔多兰作为普通人类存活，但失去所有战斗能力

#### 4.12 战后世界变化

| 选择 | 立即效果 | 长期影响 |
|------|----------|----------|
| 给予死亡 | 获得知识，凯尔多兰死亡 | 灰烬交界某处出现一座无名墓碑；后续龙族任务线中，某条龙会提及"一个终于解脱的同类" |
| 打破锁链 | 获得感谢，凯尔多兰变回老人 | 联邦某城镇后续出现NPC"老凯尔"，出售稀有的龙类知识 |
| 成为新锁链 | 获得debuff+buff组合 | 龙族任务线中，玩家被部分龙视为"同类"，部分龙视为"窃贼" |

### SQ-ARENA-05 百战之影

#### 4.13 叙事前提

**前置**：完成 SQ-ARENA-03 或 SQ-ARENA-04 之一。

零第一次露出某种类似"期待"的表情（虽然他的脸没有变化，但数字斑纹短暂地变亮了）：

"连续战斗。三名对手。不恢复。这是圆环的古老试炼。通过者，真名显现。"

#### 4.14 战棋设计

**场地**：16×16 万战圆环

**圆环法则**：同前，但增加：
- **连续战斗**：三场决斗之间不恢复HP、不恢复技能CD、不恢复斗气/体力。状态效果（中毒、流血等）继承到下一场
- **对手轮换**：每场对手风格完全不同，测试玩家适应性

**对手1：「铁壁」加尔丹**（盾环护卫流派）
- AI：`turtle_defender`（龟缩防守型）
- 特性：极高的AC和格挡率，低伤害但会反击
- 胜利关键：不能硬拼，需要用破防技能、侧背击、或耗尽他的体力

**对手2：「流火」希尔薇**（苍焰斗气流派）
- AI：`aggressive_caster`（激进施法型）
- 特性：远程斗气攻击，蓄力后高爆发，但自身脆弱
- 胜利关键：快速接近，打断蓄力，不给她远程输出的空间

**对手3：「镜刃」无名**（双刃逐影流派）
- AI：`mirror_assassin`（镜像刺客型）
- 特性：复制玩家上一场使用最多的三个技能（伤害-20%），高机动性
- 胜利关键：改变自己的战斗风格，让对手"复制错误的东西"

**特殊机制——真名显现**：
- 若玩家三场全胜，圆环地面会显示玩家的"真名"——一个由玩家角色名+战斗风格关键词组成的独特称号（如"影侧之刃"、"不动的铁壁"等）。这个真名在后续圆环战斗中被计数人使用，且可能触发某些NPC的特殊对话。
- 若玩家在任何一场失败，可以重新挑战，但对手组合会随机变化。

### SQ-ARENA-06 真名之战

#### 4.15 叙事前提

**前置**：完成 SQ-ARENA-05，且在圆环内累计胜利≥10场（包括重复挑战）。

圆环的黄昏第一次出现了变化——天空变暗了，但不是夜晚，是"某种东西遮住了光"。

零的声音第一次出现了颤抖："它醒了。不是第一决斗者。是它的影子。"

从圆环中央的雕像脚下，一道黑影缓缓站起。它没有脸，但拿着两把剑——姿势和雕像一模一样。

"每一个在圆环中战斗过的人，都留下了碎片。碎片聚成了它。它知道你的所有弱点。"

#### 4.16 战棋设计

**场地**：16×16 万战圆环，但心域扩大为中央9格，且心域内每回合随机出现"记忆残片"（地面效果，站立其上会被强制回忆某场过去的战斗，眩晕1回合）

**敌方**：`arena_ring_shadow` ×1（竞技场的影子）

| 机制 | 描述 |
|------|------|
| **风格模仿** | 影子每2回合切换一次战斗风格，随机从以下选择：铁潮战法/枪林封域/裂岩重兵/星刃决斗/盾环护卫/双刃逐影/雷砧锤术/苍焰斗气/龙血战纹/军势统御 |
| **弱点记忆** | 影子会优先使用"玩家最不擅长应对"的攻击类型（根据玩家过去的承伤数据统计） |
| **真名反噬** | 若玩家在圆环中有"真名"，影子会使用一个基于该真名的特殊技能。例如真名含"影"则影子获得高闪避，真名含"铁"则影子获得高护甲 |
| **界火汲取** | HP<30%时，影子开始汲取圆环力量，每回合恢复5%HP，但玩家对其伤害+20%（"它变强了，但也变脆弱了"） |

**胜利条件**：击败影子
**特殊奖励**：「影之心」（任务物品），用于触发 SQ-ARENA-07

### SQ-ARENA-07 第十万道刻痕

#### 4.17 叙事前提

**前置**：完成 SQ-ARENA-06，且全服/全局进度（或玩家个人通过重复挑战累计推进）使圆环刻痕达到十万。

> **注**：若采用全服累计机制，第十万场可能由其他玩家的决斗完成，玩家的SQ-ARENA-07是"见证者"视角；若采用个人累计机制，需要设计额外的可重复决斗任务让玩家刷满刻痕。本设计假设为**个人剧情触发**，刻痕通过玩家完成的所有圆环决斗累计。

零站在雕像前，所有的计数人都出来了——不止一个，是几百个，他们一直躲在圆环的"褶皱"里。

"十万。数字到了。"

雕像裂开。不是破碎，是"打开"——像一扇门。

里面没有人。只有一面镜子。

镜子中映出的不是玩家，而是**玩家在所有圆环决斗中的对手的脸**——血嚎、凯尔多兰、影子、无数无名决斗者——他们的脸叠加在一起，形成了一张"所有人的脸"。

一个声音响起。不是来自镜子，是来自圆环本身：

"我等了十万场公平的决斗。不是为了醒来。是为了确认一件事——你们还在追求公平吗？"

#### 4.18 抉择——圆环的命运

**第一决斗者的问题**：

"圆环是继续作为'公平的容器'存在，还是成为'力量的熔炉'？前者意味着它永远中立，任何人都可以来此寻求公平的决斗。后者意味着它可以被操控——我可以将圆环的力量赋予某一方，让它成为武器。"

| 选择 | 结果 | 世界变化 |
|------|------|----------|
| **继续作为公平的容器** | 圆环保持中立，但计数人消失——零说"我们的任务完成了"，然后化为灰烬。圆环自动运转，不再需要见证者 | 所有势力都可以继续使用圆环进行仲裁决斗；圆环内不再有任何NPC服务，只有纯粹的决斗机制 |
| **成为力量的熔炉** | 玩家可以选择将圆环的力量赋予：帝国（帝国获得"净化军团训练场"buff，军团战伤害+5%）、联邦（联邦获得"七族仲裁庭"buff，外交成功率+10%）、或自己（玩家角色获得永久性"圆环之子"buff：在圆环内全属性+10%，但离开圆环后-5%） | 被赋予势力与另一方关系永久恶化；未被选中的势力会试图摧毁圆环 |
| **让圆环沉睡** | 雕像闭合，圆环从主世界消失，只在灰烬交界的对应坐标保留入口 | 主世界失去圆环，但灰烬交界多了一个"安全的决斗场"——在充满危险的灰烬交界中，圆环成为少数的中立区 |
| **你为什么不自己决定？** | 需要极高的说服/战斗混合能力。第一决斗者（镜子中的叠加脸）会反问玩家一系列关于"公平"的哲学问题。若全部回答令其满意，他会说："那么，你就是下一个守门人。" 玩家获得知识「守门人之试」——这不是直接的力量，而是一个通往更深层剧情的钥匙 | 圆环继续存在，但玩家成为"荣誉计数人"——可以自由出入圆环的隐藏区域，接触其他守门人相关剧情 |

## 六、与现有任务线的整合

### 6.1 Q137「荣耀决斗」的回响

- 若玩家在Q137中饶恕血嚎，SQ-ARENA-03中血嚎会带着"被人类饶恕过的兽人"的复杂心态战斗。他的AI会故意留手（伤害-10%），但防御更积极——"我不想再欠你一次"。
- 若玩家在Q137中击杀血嚎，SQ-ARENA-03由「裂骨·格罗姆之侄」替代。裂骨会提及血嚎的死："他死在了外面。我应该嫉妒他。死在圆环里才是荣耀。"

### 6.2 Q166「龙骑士誓言」的回响

- Q166的龙骑士是匿名的，SQ-ARENA-04将其实体化为凯尔多兰。若玩家已完成Q166，凯尔多兰会提及Q166的龙骑士："他选择了诅咒。我选择了求死。我们都是囚徒。"
- 「龙骑士之锁」饰品在Q166和SQ-ARENA-04中都有关键作用，形成道具跨任务关联。

### 6.3 Q032「血之仪式」与Q033「战士试炼场」

- Q032和Q033已使用"竞技场式荒原"和"观众呐喊"机制。万战圆环可视为这些场景的"终极版本"——Q032/Q033是普通竞技场，万战圆环是"世界奇观级"竞技场。
- 完成Q033的玩家在首次进入万战圆环时，零会说："你曾在小竞技场中连胜。那只是练习。这是真正的试炼。"

### 6.4 战火尊信仰线

- 战火尊（`war_deity_faith_design.md`）的核心教义是"不参与战斗者不存在"。万战圆环的纯粹战斗环境是战火尊信徒理想的祈祷场所。
- 设计建议：战火尊信仰等级≥3的角色在圆环内获得额外斗气获取+10%（作为"公平战斗的奖励"）。
- 战火尊高阶任务（如"百战胜者"）可直接要求在圆环中完成指定场次。

### 6.5 星刃决斗流派

- 战士的「星刃决斗」流派（`warrior_tactical_skill_system_new_200.md`）在圆环中获得最大收益——该流派的核心是"单挑、侧背击、精准打击"，而圆环的"技艺放大"规则直接强化这些依赖玩家操作而非外部buff的机制。
- 建议设计：在圆环中使用「决斗宣名」技能时，效果持续时间从2回合延长至3回合（圆环认可"公平决斗的宣告"）。

## 七、关键设计决策

### 7.1 为什么圆环要"剥离外部力量"

这不是为了"平衡游戏性"的粗暴设计，而是为了叙事主题：**圆环是一场关于"你是谁"的试炼**。装备、信仰、种族——这些都是"你被赋予的"或"你选择的"。但在圆环里，只有"你自己锻造的"东西才能留下。

这呼应了矮人剧情线中的"灵魂锻造仪式"（Q133）：矮人成年时要打造一把武器并用它击败自己的影子。圆环是全大陆所有种族的"成年礼"——只不过大多数人一辈子都通不过。

### 7.2 为什么第一决斗者没有实体

雕像裂开后的"镜子"设计，是为了避免把圆环变成一个"打败某个强大NPC"的俗套任务。第一决斗者不是一个敌人，是一个**问题**。他的脸是所有对手的脸的叠加，意味着"最强的人不是某个个体，是所有追求公平者的 collective 意志"。

玩家面对的不是Boss，是**自己的战斗历史**。

### 7.3 为什么计数人是"混血"

计数人的不可归类性，是对大陆种族政治的一种隐喻。在圆环里，种族不重要——矮人和卓尔同源（Q135）、兽人和人类可以互相理解（Q137饶恕路线）、龙骑士的锁链不分种族。计数人是"超越了种族"的存在，因为他们只关注一件事：战斗是否公平。

零的六根手指中"有一根属于击败他的人"，暗示计数人是一种"传承"——每一代计数人都继承前代的一部分。他们不是种族，是"职能的进化"。

### 7.4 成就系统的设计哲学

圆环的成就不是为了"刷数值"，而是为了"定义战斗风格"。

- 「慈悲之刃」成就奖励魅力，因为饶恕对手需要说服对方接受失败——这是另一种形式的战斗
- 「纯粹者」成就要求用同一流派击败不同对手，鼓励玩家精通而非杂学
- 「逆境反击」成就奖励体质，因为它考验的是"承受伤害的意志"而非"输出伤害的能力"

这些成就与圆环的核心主题一致：**战斗的意义不在于赢，而在于你如何赢**。

### 9.5 Boss 4：双生残响·影与烬（Umbra and Cinder the Twin Echoes）

影与烬是一对在圆环中同归于尽的决斗者。他们的意识没有消散，而是被圆环融合成了一对「共生残响」。影是刺客的残余，烬是法师的残余。它们共享同一个HP池——但只攻击其中一个时，另一个会疯狂恢复。

#### 9.5.3 核心机制：共生法则

### 9.7 Boss 6：时烬术士·萨洛拉丝（Saloras the Ash-Time Weaver）

> **解锁**：350胜，且击败弗拉德
> **主题**：「她不是在攻击你。她是在编辑你的行动。」

#### 9.7.1 背景

萨洛拉丝是灰烬王朝末期的「时法师」——不是真正操控时间，而是操控「行动预判」。她能读取对手的行动意图，并在对方行动前做出反制。王朝覆灭时，她试图用最后一次时间法术把自己送到未来，但法术被界火干扰，她被困在了「行动与反应之间的缝隙」里。

圆环是她唯一能以实体形态存在的地方——因为圆环的「公平法则」强制将一切压缩到「可交互」的框架中。

#### 9.7.2 基础属性

| 属性 | 数值 | 备注 |
|------|------|------|
| HP | 260 | 偏低 |
| AC | 15 | 中等 |
| 移动力 | 5 | 标准 |
| 时烬 | 80上限 | 替代斗气 |
| 体力恢复 | 7/回合 | 偏低 |

#### 9.7.3 核心机制：行动预判与反制

- 萨洛拉丝每回合开始时，会「标记」玩家下一回合最可能使用的技能类型（近战/远程/位移/治疗/buff）
- 若玩家下一回合使用了被标记的类型，该技能效果-30%，且萨洛拉丝恢复10点时烬
- 若玩家使用了未被标记的类型，萨洛拉丝受到额外15%伤害（「预判失误」惩罚）
- 玩家可以通过故意「骗预判」来触发惩罚——但需要承担使用非最优技能的风险

- 「时烬终焉」的额外回合极其危险，尽量在她HP降至30%前保留爆发技能速杀

### 9.8 Boss 7：界火傀儡·灰烬之核（Ashcore the Boundary Fire Golem）

> **解锁**：400胜，且击败萨洛拉丝
> **主题**：「场地本身在攻击你。你能打的地方，到处都是陷阱。」

#### 9.8.1 背景

灰烬之核是圆环与灰烬交界之间的「能量溢出体」。它没有意识，只有「燃烧」的本能。圆环的公平法则将其压制为人形大小，但它的本质仍是界火——一种会改变规则的原始能量。

计数人·零警告："它不是活着的。所以你不能用对付活人的方法对付它。"

#### 9.8.2 基础属性

| 属性 | 数值 | 备注 |
|------|------|------|
| HP | 360 | 高 |
| AC | 18 | 高（但元素弱点明显） |
| 移动力 | 4 | 偏低 |
| 界火核心 | 100上限 | 替代斗气，驱动场地转换 |
| 元素抗性 | 火焰免疫，冰霜-30% | 冰霜伤害额外有效 |

#### 9.8.3 核心机制：场地相位转换

灰烬之核每3回合强制转换一次圆环的「相位」，改变全场地形效果：

| 相位 | 效果 |
|------|------|
| **炽相**（默认） | 心域变为「界火池」，站在心域内每回合受到8%最大HP的火焰伤害；但火焰技能伤害+20% |
| **烬相** | 全场地面变为「灰烬层」，移动力-1，但闪避+10%；灰烬之核的AC-3 |
| **裂相** | 随机出现3个「裂隙格」，站在上面下回合会被随机传送到另一裂隙格；裂隙格上的单位受到伤害-15% |
| **凝相** | 全场冻结1回合，所有单位不能移动，只能使用射程≥2的技能；灰烬之核每回合恢复8%HP |

相位转换顺序固定：炽→烬→裂→凝→炽……

|---:|---|---|---|---|---|---:|---|---|
| 1 | 灰烬拳 | 输出 | 1 | 单体 | 体力12 | 0 | 造成100%火焰伤害；当前相位为「炽相」时额外附加点燃（每回合失去6HP，2回合） | 近身时优先使用 |
| 2 | 界火喷发 | 输出/地形 | 3 | 圆形2格 | 界火20 | 2 | 造成90%火焰伤害，区域变为「燃烧地面」2回合：站立其上每回合失去5%HP | 玩家聚集或固定站位时使用 |
| 3 | 相位同步 | 状态 | 自身 | 自身 | 界火25 | 3 | 强制提前转换至下一相位，并根据新相位获得增益：炽相（伤害+20%）、烬相（闪避+20%）、裂相（下次攻击无视距离瞬移至目标旁）、凝相（恢复15%HP） | CD到了就用，但会预判相位选择时机 |

- 冰霜伤害是核心克制——携带冰霜武器/技能可以在「凝相」和「重生后」造成毁灭性伤害
- 相位转换是固定的，提前规划走位——例如「裂相」时主动站上裂隙格进行战术传送
- 「核心过载」的范围提示很明显，看到它蓄力立刻散开
- 重生后的3回合是窗口期，它伤害高但冰霜弱点暴露，全力爆发

### 9.9 Boss 8：守门人残响·奥拉克（Orac the Gatekeeper Resonance）

> **解锁**：450胜，且击败灰烬之核
> **主题**：「他拥有之前所有人的力量。你不是在打第八个Boss。你是在打前七个，同时。」

#### 9.9.1 背景

奥拉克不是第一决斗者。他是圆环在吸收了前七位守护者的战斗数据后，自动生成的一个「终极测试」。他的存在意义只有一个：确认是否有资格面对第一决斗者的问题。

他的脸是七位守护者面容的快速切换——万相的千面、艾欧莉丝的裂隙之眼、莫德雷德的铁棺纹路、影与烬的双色瞳孔、弗拉德的獠牙、萨洛拉丝的时间刻痕、灰烬之核的火焰核心。

计数人·零说："如果你赢了他，第十万道刻痕会在你眼前完成。"

#### 9.9.2 基础属性

| 属性 | 数值 | 备注 |
|------|------|------|
| HP | 500 | 极高 |
| AC | 19 | 高 |
| 移动力 | 5 | 标准 |
| 全能资源 | 120上限 | 替代斗气/法力/界火/血池/时烬 |
| 体力恢复 | 10/回合 | 高 |

#### 9.9.3 核心机制：七相轮转

奥拉克拥有七个「相位槽」，每个槽对应一位前守护者的核心能力。战斗开始时，随机激活2个槽。每受到相当于最大HP15%的伤害，强制切换一次激活槽组合。

| 2 裂隙之步 | 可使用「界火跃迁」和「虚空坍缩」 | 受到近战攻击时有40%概率自动后撤2格 |
| 3 铁棺之壁 | 可使用「棺钉反击」和「铁壁沉降」 | 开场拥有3层铁棺护盾（同莫德雷德机制，但不反弹） |
| 4 双生之协 | 可使用「影袭背刺」和「烬火弹」 | 每3回合召唤一个「残影分身」（HP=50，AC=14，存活1回合），分身会同步使用当前激活技能 |
| 5 血宴之渴 | 可使用「血爪撕裂」和「血核引爆」 | 造成伤害的20%恢复HP；火焰伤害削减其5点全能资源 |
| 6 时烬之预 | 可使用「时滞锁链」和「灰烬预见」 | 每回合预判玩家行动类型，命中则玩家该类型技能效果-20% |
| 7 灰烬之核 | 可使用「界火喷发」和「核心过载」 | 每4回合强制转换一次场地相位（同灰烬之核） |

| 压制期 | HP 40%-75% | HP每降15%强制切换槽位；开始使用「守门人审判」施压；激活槽逐渐增至3-4个 |
| 终局期 | HP<40% | 激活槽维持4-5个；频繁使用「七重奏鸣」；HP<25%时强制使用「终焉守门」——这是最大窗口也是最大危险 |

#### 9.9.6 应对策略提示

- 奥拉克的难点在于「不可预测」——每次切换槽位都需要立刻调整应对策略
- 「残响袭」在3槽以上时极其危险，因为它会同时触发多个被动；优先控制他的激活槽数量（通过削减HP节奏来控制切换时机）
- 「终焉守门」的1回合爆发可以秒杀满血角色，但该回合后他有1回合硬直——预留保命技能撑过爆发，然后全力输出
- 冰霜伤害仍然有效（削减血宴槽的资源，同时可能影响灰烬槽的场地转换）

## 十、Boss 战后叙事与圆环终局

### 10.1 击败奥拉克后的剧情

零缓缓走到裂开的雕像前。所有的计数人都跪下了——不是向玩家，是向圆环。

"第十万道刻痕。由第九万九千九百九十九号的胜利者完成。"

他指向地面。最后一道刻痕正在缓缓浮现，旁边是玩家的真名——不是战斗之名，是在五百场决斗中被圆环确认的、属于玩家自己的「真名」。

雕像完全裂开。里面不是第一决斗者。

是一面镜子。镜子里是玩家自己——但穿着灰烬王朝的铠甲，手持双剑，眼神中没有疲惫，只有无尽的战斗渴望。

"第一决斗者，"零说，"不是某个人。是'第一个通过试炼的人'。现在你通过了。镜子里的你，是圆环为你铸造的'可能性'。"

【触碰镜子】

镜子的表面像水一样波动。你的手穿了过去——然后你看到了圆环的起源：灰烬王朝不是毁灭了，是被「分散」到了每一个通过试炼的人身上。

"守门人不是守护某个门，"镜中的你说，"是守护'可能性'本身。你可以留下，成为圆环的一部分。或者离开，把可能性带出去。"

### 10.2 最终抉择（500胜后触发）

| 选择 | 结果 | 全局影响 |
|------|------|----------|
| **成为圆环** | 玩家角色获得「守门人」称号，可自由进出圆环隐藏区域，但再也不能离开圆环超过7天（超过则失去守门人身份） | 圆环增加一个新的「计数人」NPC，外观为玩家角色；其他玩家可以与该NPC进行特殊对话 |
| **带走可能性** | 玩家角色获得永久性被动「灰烬遗志」：每场战斗开始时，若HP满值，首次受到致命伤害时保留1HP（每场战斗1次） | 圆环继续运转，但雕像重新闭合，等待下一个十万场 |
| **打破圆环** | 玩家用真名之力摧毁圆环的核心机制；圆环从主世界消失，只在灰烬交界留下一个弱化版本（无Boss，无真名机制，只有基础决斗） | 所有依赖圆环的任务线改变路径；帝国和联邦失去仲裁场所，边境冲突小幅增加 |
| **让圆环选择** | 将决定权交给圆环本身；圆环随机选择上述三种结果之一（玩家事先不知道会是哪个） | 高风险高回报的随机结局，适合多周目玩家 |
