# 《阴影行者的绕后手册》

## 基础信息

- **书籍 ID**：`book_shadow_flank_manual`
- **关联技能**：`rogue_flank_attack`（待新增）、`assassin_backstab`（待新增）
- **使用效果**：阅读后随机解锁 `rogue_flank_attack` 或 `assassin_backstab` 中的一项；若两项均已学会，则提升其中等级较低者 `current_mastery +130`。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `敏捷 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：黑市商人、盗贼公会声望奖励、暗杀任务密室。

## 书籍内容

手册没有署名，封皮用人造革包了一层又一层，摸起来像某种不肯死去的动物。正文通篇使用第二人称，仿佛在对你说话："你首先要学会的不是潜行，是 patience——耐心这个词在你母语里没有对应的狠劲，所以书里保留了原文。"作者把绕后拆成两种：一种是让敌人看不见你，另一种是让敌人看得见你、但误判你的位置。前者靠阴影和脚步，后者靠假动作和队友的声势。手册中段详细记录了七种常见护甲的接缝位置，每种都配有一句冷笑话，比如"板甲的腋下永远忠诚于死亡"。手册花了整整一章贬低"独行侠绕后"：真正可靠的绕后需要正面有人制造声音和视线压力，否则敌人会无意识地转动身体，把你的最佳角度越压越小。最后几页被血黏在一起，只能读到大字标题："不要在绕后成功后回头看。回头会把你重新拉回正面。"

## 设计意图

服务于盗贼/暗杀者的机动与爆发定位，把"绕后"从简单位移提升为空间欺骗与时机判断。熟练度分配机制避免重复奖励已饱和技能，鼓励多样化构筑。
