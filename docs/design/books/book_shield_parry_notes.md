# 《断桥营寨盾反笔记》

## 基础信息

- **书籍 ID**：`book_shield_parry_notes`
- **关联技能**：`warrior_shield_bash`、`ashen_shield_parry`
- **使用效果**：阅读后获得 `warrior_shield_bash` 技能解锁机会（若未学会），并立即提升该技能 `current_mastery +120`。
- **阅读要求**：已装备盾牌；角色基础 `体质 ≥ 8`。
- **稀有度**：精良（Uncommon）
- **建议投放**：断桥营寨军械库、老兵遗物、盾卫训练任务奖励。

## 书籍内容

这本笔记出自断桥营寨一名匿名盾卫之手，羊皮纸边角已经被汗水和铁锈浸成褐色。开篇只有一句话："盾不是墙，是一扇只开一次的门。"笔记将盾反拆成三步：读势、沉肩、开门。读势不是看敌人的刀，而是看敌人的肩和胯——真正发力的地方永远比武器先动半拍。沉肩是为了把盾重心压低，让反震力沿着小腿灌进地面，而不是撞回自己的胸口。开门则是赌那一瞬：盾面先迎上攻击弧线，再顺着来劲的方向滑开一寸，把敌人的重心扯到空处。笔记后半画满了简笔小人，每个小人都在摔倒，旁边标注着"早了""晚了""对了"。笔记还专门讨论了盾反之后的"半步"：大多数人反制成功后急着追击，结果踩进敌人失衡时胡乱挥出的攻击范围。正确的做法是先踏出小半步确认对方真的失去重心，再决定是补刀、换位还是继续压制。最后一页被撕去大半，只剩半行字："……真正危险的，是你爱上那一下反震的快感。"

## 设计意图

这本书把盾反从"高伤反击"重新框定为"读招与反制"，与灰烬交界破势盾反的战技气质一致。熟练度投放直接命中战士前排的招牌技能，避免泛化到所有近战职业。
