# 《风息射手瞄准术》

- **书籍 ID**：`book_wind_archer_aim`

## 书籍内容

《风息射手瞄准术》不是一本教你拉弓的书，而是一本教你等待的书。作者用前半本篇幅描述风：如何在箭羽上感受它的方向，如何判断它会在箭杆中段变强还是变弱，如何在拉满弓的十秒钟里重新校准三次呼吸。书中最著名的章节是"静止的移动"——它要求射手在扣弦时想象自己正在随风移动，而目标才是静止的那个点。这个反直觉的意象让许多新手射偏，却让老手在远距离上获得惊人的稳定。后半本收录了二十七种目标的"弱点节奏"：心脏不是总在同一个位置跳动，盔甲接缝会因为呼吸而轻微开合。书中还列有一张简易距离换算表，标注了不同风速下箭矢下坠的提前量，但作者在每个数字旁边都加了一句"仅供参考"，因为真正的射手要靠肌肉记忆而非背诵表格。末尾有一页被反复翻阅到起毛，上面只有一句话："弓弦松开前的最后一秒，你不是在瞄准，你是在和空气谈判。"

## 设计意图

强化弓箭手"精准、稳定、远程收割"的职业画像。"下一次战斗首次射击加成"是一种轻量、可感知但不过度破坏平衡的书籍奖励，符合成长优先于一次性刺激的总纲。
