# 《雪山攀登者日志》

## 基础信息

- **书籍 ID**：`book_knowledge_0125`
- **关联技能**：`knowledge_mountain`
- **使用效果**：阅读后解锁技能 `knowledge_mountain`；记录 `known_knowledge_id: snow_mountain_climbing_log`。若已学会，提升 `current_mastery +120`，并在雪山区域减少严寒造成的行动力损失。
- **阅读要求**：无职业限制；基础 `力量 ≥ 9` 且 `体质 ≥ 9`。

- **建议投放**：登山者营地、高山驿站、冻死者遗体。

## 书籍内容

日志记录了一支七人登山队的最后攀登，只有一人生还。作者在字里行间展现出一种克制的恐惧：他没有渲染雪怪的可怕，而是详细记录了每一步踩雪的声音变化。书中提出"雪山在呼吸"的观点——积雪会在特定时刻释放积存的气体，形成看似平静的死亡陷阱。最实用的一章是如何识别冰裂缝：不要看表面，要看雪粒的反光方式。最末几页笔迹越来越潦草，最后一段只有几个字："不要救已经放弃自己的人。他们会把你也拉下去。"日志封皮里缝着一张小照片，已经褪色。照片背面："这是队伍登顶前的合影。后来只有我一个人下山。"

照片的一角被折起，折痕处露出半张脸，是那位没能下山的人最后的微笑。

书的最后一章缺了一页，缺页处留着整齐的切痕，不像自然脱落。

日志的封皮被雪水浸透后变硬，内侧浮现出一幅从未被画上去的山峰轮廓。

## 设计意图

为雪山区域建立危险认知与生存知识，强调环境本身作为敌人的设计理念。
