# 《猎魔人的怪物分类法》

## 书籍内容

这本分类法不按体型或元素属性给怪物分类，而是按「它们为什么杀人」分类。前半本列出七个类别：饥饿型、领地型、仪式型、复仇型、误会型、娱乐型和「不知道原因型」。作者强调，判断类别比判断弱点更重要，因为一种怪物的弱点可能随动机改变。中间一章详细描述了如何通过对现场痕迹的解读来推断怪物类别，例如爪痕的深度、尸体的摆放方向和是否有被拖拽的痕迹。

书的后半部分是一本案例集，每个案例都记录了一次失败的猎杀和从中吸取的教训。最末一页写着：「最危险的怪物不是最大的，是你把它当成另一种怪物来打的那只。」这本书的封皮由某种鳞片制成，摸起来冰凉而粗糙。

猎魔人的怪物分类法在印刷后被大量猎人使用，但作者本人后来补充了一个第八类：「看起来像某类但其实完全不同的那种」。他承认这个分类破坏了整本书的体系，但坚称这是最实用的一类。
