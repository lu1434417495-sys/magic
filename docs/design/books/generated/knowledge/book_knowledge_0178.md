# 《盗贼公会晋升仪式》

## 基础信息

- **书籍 ID**：`book_knowledge_0178`
- **关联技能**：`knowledge_lore`
- **使用效果**：阅读后解锁技能 `knowledge_lore`；记录 `known_knowledge_id: thieves_guild_promotion_rituals`。若已学会，提升 `current_mastery +100`，并潜行类技能熟练度获取速度 +5%，持续至角色下次升级。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `敏捷 ≥ 10`。
- **稀有度**：普通（Common）
- **建议投放**：盗贼公会密室、黑市商人、暗杀任务奖励。

## 书籍内容

这本手抄本记录了某盗贼公会内部流传的晋升仪式，从“影子学徒”到“无名之主”共分七级。每一级都需完成一项试炼：偷取一件没有价值的东西、在目标面前消失、让守卫主动打开门等等。中间一章警告，仪式真正的考验不是技巧，而是对规则的信任——因为高级别任务往往要求成员把命交给同伴。后半本附有多种暗号与接头手势，但最后一页被撕去。最末的批注写道：“公会不需要最强的贼，只需要最懂闭嘴的人。”

手抄本的封皮用多张通缉令糊成，最上面一张已经被划掉，只剩半张脸。公会老人说，那就是最后一页被撕去的原因。

盗贼公会否认存在这样一本手册，但新成员入会时总会被暗示去找来读一读。

城市守卫也把它当作了解地下组织的秘密教材，尽管没人承认来源。

服务于盗贼/暗杀者的背景成长，让知识书籍与职业熟练度循环产生关联。
