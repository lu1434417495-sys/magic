# 《吸血鬼血系与盟约》

## 书籍内容

本书以学者视角记录吸血鬼社会的内部结构，拒绝浪漫化。作者把吸血鬼按血源分为十三支系，每一支系都有独特的禁忌与盟约形式。中间一章详解"初拥"背后的契约本质：被转化者并非获得永生，而是继承了一份不可撤销的债务。后半本则记录了几份血族盟约的文本，展示它们如何用优雅辞藻包装绝对服从。最末一段警告："想了解吸血鬼的人，往往最先成为它们的史料。"


书的末尾附有一封被退回的血族邀请函，信纸上的火漆印仍然鲜红。作者建议把这张纸夹在书中，作为提醒自己“有些门永远不该回应”的实物教材。然而许多读者在深夜会不自觉地把手指伸向那枚火漆，仿佛它有自己的温度。

吸血鬼血族对这本书的态度复杂：有人想销毁它，有人则把它当作族谱的讽刺注脚。

这让血族内部也充满了争议。

## 设计意图

为恶魔学与黑暗阵营内容提供知识入口，让血族交互拥有可读取的社会规则。
