# 《佣兵公会评级标准》

## 基础信息

- **书籍 ID**：`book_knowledge_0172`
- **关联技能**：`knowledge_lore`
- **使用效果**：阅读后解锁技能 `knowledge_lore`；记录 `known_knowledge_id: mercenary_guild_rating`。若已学会，提升 `current_mastery +100`，并雇佣佣兵时佣金降低 5%（一次性交易增益）。
- **阅读要求**：无职业限制；基础 `智力 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：佣兵公会大厅、酒馆传闻、任务发布板。

## 书籍内容

这本内部手册详细说明了佣兵公会如何从战斗力、信誉、团队协作与任务完成率四个维度给佣兵定级。书中列出每个等级对应的佣金分成与可接任务类型，并用大量案例解释“信誉”如何因为一次违约而断崖式下跌。中间一章讨论临时组队的风险，建议雇主优先选择有固定搭档的佣兵。后半本附有公会黑名单的摘录，上面某些名字旁边画着骷髅。最末写道：“评级不是荣誉，是公会用来算账的借条。”

手册内页夹着一张公会徽章，背面刻着一行小字：评级可以被买，但黑名单上的名字必须自己挣。

公会高层否认这份手册的真实性，但几乎每个分会都能找到手抄副本。

雇主们在签订契约前往往会偷偷翻看这本书，用评级标准来压低佣金或挑剔履历。

## 设计意图

把佣兵系统的背景规则书籍化，让雇主玩家获得一次经济优势。
