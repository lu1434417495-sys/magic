# 《亡灵仪式的七种误读》

## 基础信息

- **书籍 ID**：`book_knowledge_0055`
- **关联技能**：`knowledge_necromancy`
- **使用效果**：阅读后解锁技能 `knowledge_necromancy`；记录 `known_knowledge_id: undead_ritual_misconceptions`。若已学会，提升 `current_mastery +120`，并解锁与亡灵 NPC 的中立对话选项。
- **阅读要求**：无职业限制；基础 `智力 ≥ 9` 或 `意志 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：亡灵法师塔、禁忌书库、地下墓穴宝箱。

## 书籍内容

作者在开篇就声明自己不是亡灵法师，而是一名研究死亡文化的学者。他列举了七种关于亡灵仪式最常见的误解：第一，亡灵不需要被命令，它们需要被提醒；第二，骨骼复活的阻力比肉体更小，但记忆流失更快；第三，大多数仪式失败不是因为法力不足，而是因为施术者无法直面自己的死亡。书中详细分析了一个被误传为「奴役死者」的仪式，作者认为其原意其实是「让未完成者完成告别」。

后半本收录了几位亡灵的书面访谈，它们的字迹歪歪扭扭，却出奇地冷静。一位亡灵写道：「我不恨生者，我只是讨厌你们总是假设我想回来。」作者在最后提醒读者：理解亡灵不等于赞同亡灵，但误解会让你在面对它们时犯下致命错误。

书的封底有一道焦痕，形状像是一只张开的手。据说这是某位亡灵法师在读到「让未完成者完成告别」时失控焚毁的痕迹，也有人说那是亡灵自己留下的记号，提醒后来人不要忘记书中的提醒。

## 设计意图

为亡灵相关内容提供中性 lore 视角，拓展知识系统的叙事深度，并解锁特殊对话分支。
