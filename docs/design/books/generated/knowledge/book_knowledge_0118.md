# 《怪物弱点图鉴：人形篇》

## 基础信息

- **书籍 ID**：`book_knowledge_0118`
- **关联技能**：`knowledge_beastiary`
- **使用效果**：阅读后解锁技能 `knowledge_beastiary`；记录 `known_knowledge_id: monster_weakness_humanoid`。若已学会，提升 `current_mastery +120`，并在对战人形怪物时提升 5% 暴击率。
- **阅读要求**：无职业限制；基础 `感知 ≥ 9`。
- **稀有度**：普通（Common）
- **建议投放**：猎人公会、佣兵营地、怪物讨伐任务奖励。

## 书籍内容

图鉴摒弃了夸张的插画，只保留尸体解剖图与实战观察笔记。作者是一位退休的怪物猎人，他坚持认为人形怪物之所以危险，不是因为它们像人，而是因为它们"不够像人"。书中按护甲类型、关节结构与攻击习惯分类了二十一种常见人形敌人，并标注了最有效的打击点。最实用的一章是"习惯陷阱"——某些怪物会假装受伤或逃跑，引诱猎物进入伏击。最末一页只有一行加粗的字："如果你开始觉得它们可怜，就离死不远了。"图鉴最后是一张空白页，标题是"留给你的下一个敌人"。作者写道："不要填满它，留点空白给恐惧。"

空白页的边缘有一行血迹指纹按下的字："第22种是我。请把我也画上去。"

封面内侧写着一串数字，没人知道是页码、日期还是某种密码。

图鉴的某一页被咬掉了一个角，牙印与人类不符，却与图鉴中的某种怪物高度相似。

## 设计意图

为战斗系统提供知识驱动的弱点机制，让玩家在战前准备中获得可量化的战斗优势。
