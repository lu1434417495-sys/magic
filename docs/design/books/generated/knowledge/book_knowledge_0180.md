# 《飞行魔兽骑乘入门》

## 基础信息

- **书籍 ID**：`book_knowledge_0180`
- **关联技能**：`knowledge_beasts`
- **使用效果**：阅读后解锁技能 `knowledge_beasts`；记录 `known_knowledge_id: flying_mount_riding_basics`。若已学会，提升 `current_mastery +120`，并骑乘飞行魔兽时，耐力消耗降低 5%（一次性探索增益）。
- **阅读要求**：无职业限制；基础 `体质 ≥ 9` 或 `感知 ≥ 9`。
- **稀有度**：精良（Uncommon）
- **建议投放**：空骑军营地、翼兽巢穴、游侠委托奖励。

## 书籍内容

手册由空骑军退役教官编写，面向有志于骑乘狮鹫、翼蛇等飞行魔兽的新手。书中先讲解如何判断一只魔兽是否适合被骑乘：观察它的眼神是否还能保留野性，以及它对地面接触的反应。中间一章详述了鞍具、缰绳与平衡要点，特别警告不要在高空使用刺激性气味物品。后半本收录了紧急迫降与失控应对的步骤，以及若干教官亲身经历的险境。最末的忠告写道：“飞行不是征服天空，是说服一只比你更骄傲的生物暂时带上你。”

手册封底印着一行褪色的字：记住，你从天上掉下来时，地面不会因为你交了学费就变软。

空骑军把它列为预备役必读，但真正毕业的骑手都说最好的老师是从马背上摔下来的经验。

驯兽师公会把它当作新学员的第一课教材，但常被故意缺页。

## 设计意图

把野兽知识拓展到空中骑乘，为开放世界移动系统提供一次性续航奖励。
