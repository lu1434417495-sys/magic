# 《亡灵低语转译手册》

## 基础信息

- **书籍 ID**：`book_knowledge_0105`
- **关联技能**：`knowledge_necromancy`
- **使用效果**：阅读后解锁技能 `knowledge_necromancy`；记录 `known_knowledge_id: undead_whispers_translation`。若已学会，提升 `current_mastery +140`，并在与亡灵对话时解锁额外选项。
- **阅读要求**：角色职业标签含 `mage` 或 `warlock`；基础 `智力 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：死灵学者密室、黑市商人、古代墓穴宝箱。

## 书籍内容

手册的编纂者自称"翻译过三百个亡灵的遗言"，但他也承认其中大部分是诅咒与重复的执念。书中把亡灵低语分为"记忆回声""情绪残片""伪意识"三类，并提供了一套以节奏而非语义为核心的转译方法。作者强调，与亡灵交流时最重要的不是听懂每个词，而是判断它是否还在"时间"里——有些亡灵以为自己仍在生前最后一刻，任何超出该时刻的信息都会让它们崩溃。最末一页是一页空白，只有页眉写着："有些问题，即使听懂了也不该问。"手册封面内侧写着一行警告："读完本书后，若你在深夜听到有人叫你的名字，请数到三再回答。"

书的装订线里缠着一根灰白头发，不知道是读者的还是译者的。

某些页面的空白处写满了后来者的批注，字迹越来越潦草，像是在与时间赛跑。

封面内页有一幅手绘的耳朵，旁边标注着"听之前，先确认声音是从哪个方向来的"。

## 设计意图

为亡灵相关知识线提供进阶入口，让"与死者交谈"成为可设计的剧情分支与情报来源。
