# 《符文工匠的负面教材》

## 基础信息

- **关联技能**：`knowledge_runes`

## 书籍内容

这本教材收集了九十九个符文雕刻失败的案例，作者认为学习符文的最好方式是看别人怎么出错。前半本按错误类型分类：笔画顺序颠倒导致魔力倒灌、刻痕深浅不一导致符文早逝、材料与符文属性冲突导致自燃。每一个案例都配有失败成品的拓片和后果描述。中间一章特别讲解了「好看但不稳定」的符文，作者警告初学者不要被装饰性纹样迷惑。

书的后半部分逐渐从技术分析转向哲学思考，作者提出符文的本质不是图案，而是「意图的物质形态」。最末一页只有一句话：「如果你不知道这个符文为什么有效，就不要刻它。因为有效的符文会记住你的无知。」

符文工匠的负面教材最后一页印有作者自己的墓碑拓片，碑文是他生前刻下的：「这里躺着的是一个终于把所有错误都犯完的人。」学生们会在考试前触摸这块拓片，祈求不要重蹈覆辙。

## 设计意图

为符文系统提供以错误为基础的学习路径，通过配方解锁把知识转化为装备附魔能力。
