# 《古神祭祀遗址调查报告》

## 书籍内容

报告由一支秘密考古队撰写，记录了对七处古神祭祀遗址的勘察。书中详细描述了遗址的共同点：非欧几里得几何结构、刻有未知语言的祭坛、以及大量被刻意破坏的参与者遗骸。中间一章分析了祭祀仪式可能的步骤，并推测古神并不需要信仰，而是需要某种“注意力”作为食粮。后半本附有多幅现场素描，其中几幅会让人长时间注视后感到眩晕。最末的警告只有一行：“不要尝试复原任何仪式，即使只是为了验证。”

报告的封皮内侧夹着一片遗址碎石，任何长时间注视它的人都会感到轻微的坠落感，仿佛地板正在缓慢倾斜。

报告发表后，原本计划前往遗址的考古队纷纷取消行程，导致相关资助也迅速枯竭。

教会的审查官曾多次试图焚毁它，却始终找不到全部副本。某位匿名学者在空白处补充：遗址碎石在梦中会重新拼成祭坛，醒来时却发现它们仍在铅盒里。
