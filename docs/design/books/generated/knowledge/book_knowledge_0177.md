# 《魔法瘟疫传播模型》

## 基础信息

## 书籍内容

本书由一名被隔离的疫病学法师写成，用数学模型解释魔法瘟疫如何在人群中扩散。书中把传染源分为“实体媒介”“咒语残留”和“情绪共振”三类，并给出每种的基本再生数。中间一章通过历史案例说明，最危险的瘟疫不是致死率最高的，而是会让人失去判断力的那种。后半本收录了若干失败的隔离方案，每次失败都因为有人低估了恐惧的传播速度。最末的警告写道：“瘟疫会过去，但人们对瘟疫的记忆会成为下一次瘟疫的温床。”

书的扉页盖着隔离区的火漆印，旁边用炭笔写着：如果你正在发烧，请把书放下并敲响房门，门外有人比你更怕这本书。

隔离区解除后，这本书被重新出版，但所有涉及具体地名的章节都被删除。

疫病过后的城镇会把它刻在石碑上，提醒后人不要重蹈覆辙。

## 设计意图

为医疗知识线增加灾难题材，通过抗性奖励让玩家敢于进入疫区。
