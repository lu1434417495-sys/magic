# 《龙语发音臆测集》

## 基础信息

- **书籍 ID**：`book_knowledge_0018`
- **关联技能**：`knowledge_draconic`
- **使用效果**：阅读后解锁技能 `knowledge_draconic`；记录 `known_knowledge_id: draconic_phonetics`。若已学会，提升 `current_mastery +160`，并在面对龙类敌人时首次龙语相关检定 `+10`（一次性战斗/事件增益）。

## 书籍内容

这本书大胆地把龙语从"不可学习的神圣语言"降格为一种可分析的声学现象。作者用三百多页推测龙语中爆破音与魔力振动的对应关系，并声称真正危险的龙语不是含义，而是它携带的频率。中间一章记录了十七次失败的"低声模仿"，每一次失败都以实验者耳鼻出血告终。后半本附有一张声带结构图，标注了人类无法发出的三个音域。最末一段警告：即便发音正确，没有足够魔力支撑的龙语也只会招来龙的厌烦，而不是服从。


书的最后夹着一片龙鳞碎片，碎片在有人朗读某些音节时会微微发热。前任主人警告：如果龙鳞开始震动，立刻合上书，因为你可能已经被某个存在听见。据说那片龙鳞来自一头被龙语学者误杀的幼龙，它的体温至今未散。

龙语学者把这片龙鳞称为“最后一个音节”。
