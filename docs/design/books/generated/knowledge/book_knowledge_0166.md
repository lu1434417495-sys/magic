# 《荒野中的可食用根茎》

## 基础信息

- **关联技能**：`knowledge_survival`

## 书籍内容

这本植物图鉴由流浪德鲁伊编纂，介绍了十二种在荒野中可安全食用的根茎。每种植物都配有手绘图、生长环境、采摘季节以及最常见的相似毒草对比。中间一章特别强调“灰烬交界变种”与常见品种的区别，某些可食用根茎在灰烬土壤中会变成温和的麻醉剂。后半本收录了简单的烹饪建议，警告不要把多种根茎混煮，因为它们的药性会互相叠加。最末一行写道：“荒野不会为你准备菜单，但它确实在地下藏了许多面包。”

图鉴最后一页粘着一片干枯的灰褐色根茎，旁边警告：如果你闻到杏仁味，请把它埋回土里并道歉。

这本书的封面用防水树皮包裹，据说是第一位德鲁伊读者亲手缝制的。

游侠们会把关键页面用油纸封好，藏在腰带夹层里，过河时也不愿取出。
