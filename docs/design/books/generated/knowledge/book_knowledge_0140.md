# 《死灵法师实验日志》

## 基础信息

- **书籍 ID**：`book_knowledge_0140`
- **关联技能**：`knowledge_necromancy`
- **使用效果**：阅读后解锁技能 `knowledge_necromancy`；记录 `known_knowledge_id: necromancer_lab_journal`。若已学会，提升 `current_mastery +150`，并解锁对亡灵敌人的操控抗性。
- **阅读要求**：角色职业标签含 `mage` 或 `warlock`；基础 `智力 ≥ 11`。
- **稀有度**：史诗（Epic）
- **建议投放**：死灵法师实验室、禁忌图书馆、黑市高价拍卖。

## 书籍内容

日志的主人在最后一页还活着，但他已经不再是人了。书中前半部分冷静地记录实验步骤：如何保存灵魂碎片、如何让尸体重新站立、如何让多个意识共存于一具躯壳。后半部分笔迹逐渐紊乱，作者开始质疑"死亡"与"生命"的边界，并在某页写下："如果意识可以转移，那么自我究竟在哪里？"最 disturbing 的一章是关于失败品的处理——那些被唤醒却无法控制的亡灵，作者称它们为"未完成的问题"。最末一页只有一行字，字迹与前面截然不同："我终于听到了它们的回答。"日志封面内页写着："若你发现这本日志时我还活着，请把它烧掉。若我已死去，请把它读完。两者没有区别。"

封面内页的留言下方有一行后来者的批注："我烧掉了它。它又出现在我的书架上。第三次了。"

封面内侧贴着一小块镜子碎片，碎片中照不出读者的脸。

## 设计意图

作为亡灵知识线的高阶读物，深化死亡伦理主题，为禁忌魔法提供沉重的叙事代价。
