# 《斥候的伪装与观察术》

## 基础信息

## 书籍内容

这本书的作者是军方斥候学校的退休教官，他强调伪装不是让自己消失，而是让自己变成环境中「不值得注意」的那部分。前半本讲解如何利用光影、纹理和运动模式来降低被发现的概率，作者认为最失败的伪装往往是伪装者自己太紧张，反而吸引了注意力。中间一章是观察训练：如何在静止状态下记住一个场景的所有细节，并在闭上眼睛后复述出来。

书的后半部分讨论斥候的心理素质：长时间独处、面对无法分享的恐惧、在报告坏消息时不被情绪左右。最末一页有一段被无数新手抄下来的话：「最好的斥候不是最会躲的人，是最能在被发现前一秒做出正确决定的人。」

斥候的伪装与观察术在军队中被广泛使用，但最优秀的斥候都会在水源页加上自己的笔记。有人说真正保命的技巧永远不会写在书里，只会在某个老兵喝醉后透露给听得懂的人。

## 设计意图

为斥候与潜行职业提供专业化知识，通过观察范围增益强化其情报收集定位。
