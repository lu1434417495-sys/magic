# 《异界寄生虫标本说明》

## 基础信息

- **书籍 ID**：`book_knowledge_0190`
- **关联技能**：`knowledge_occult`
- **使用效果**：阅读后解锁技能 `knowledge_occult`；记录 `known_knowledge_id: otherworld_parasite_specimens`。若已学会，提升 `current_mastery +180`，并对认知寄生或精神控制类敌人的抵抗成功率 +5%（一次性战斗增益）。
- **阅读要求**：无职业限制；基础 `智力 ≥ 11` 或 `意志 ≥ 11`。

- **建议投放**：异界生物实验室、封印研究所、禁忌标本室。

## 书籍内容

说明手册由一名异界生物学者整理，收录了七种来自不同位面的寄生虫标本。书中描述了它们的宿主、生命周期、传播方式，以及最令人不安的“认知寄生”类型——会缓慢替换宿主的部分记忆。中间一章讲解了安全观察与保存方法，强调必须让标本始终处于“以为自己还活着”的状态。后半本记录了几起因标本泄漏导致的小规模事故。最末的警告写道：“寄生不是谋杀，是搬进来。最可怕的房客是你慢慢觉得它一直在这里。”

说明手册的封皮用特殊的铅箔包裹，警告标签上写着：阅读时间超过一小时后，请检查自己是否还记得为什么要翻开它。

异界生物学者警告，即使只是阅读标本说明，也应定期检查自己的近期记忆是否完整。

封印研究所要求所有接触标本的人员先签字确认已读完本书。
