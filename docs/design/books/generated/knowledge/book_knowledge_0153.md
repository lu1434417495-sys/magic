# 《失传的炼金墨水配方》

## 基础信息

- **书籍 ID**：`book_knowledge_0153`
- **关联技能**：`knowledge_alchemy`
- **使用效果**：阅读后解锁技能 `knowledge_alchemy`；记录 `known_knowledge_id: lost_alchemical_ink_recipe`。若已学会，提升 `current_mastery +120`，并解锁“炼金墨水”辅助材料配方，可用于附魔与古籍修复。
- **阅读要求**：无职业限制；基础 `智力 ≥ 9`。
- **稀有度**：精良（Uncommon）
- **建议投放**：炼金术士工作室、遗迹宝箱、黑市拍卖。

## 书籍内容

配方残页来自一名被开除的炼金学徒笔记，记载一种能在普通羊皮纸上永久保留魔力的墨水。开篇列出七种原料，其中三种已因植物灭绝而无法取得，但作者贴心地附上了替代品与对应的褪色年限。中间部分讲解“情绪稳定剂”的重要性：若调配者心怀怨恨，墨水会在书写时自燃。后半本收录了若干失败样品，有的会缓慢吞噬文字，有的会让读者产生幻觉。最末一行用褪色笔迹警告：“真正失传的不是配方，而是写它时那种不敢骗人的诚实。”

残页边缘有几处焦黑的指纹，似乎是某位后来的调配者在成功前最后一刻被火焰灼伤。附魔师们相信，这些指纹本身就是配方的一部分。

这本书因此在黑市上价格不菲，但买家们更关心的是焦黑指纹是否还能被辨认出来。

## 设计意图

为炼金与附魔系统提供可落地的配方知识，让知识见闻与工匠循环产生交集。
