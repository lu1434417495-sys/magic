# 《猎魔人笔记：吸血鬼》

## 书籍内容

笔记的每一页都散发着大蒜与陈旧圣水的气味，纸边有烧灼痕迹。作者没有名字，只有代号"第七根木桩"。书中把吸血鬼分为"墓生者""血裔""返魂者"三类，并指出民间传说中有多少是错误的：十字架只对信仰坚定者有效，大蒜对高等血族几乎无用，而真正致命的往往是不起眼的阳光反射。最触目惊心的一章记录了作者被迫处决自己导师的过程，因为那位导师在被咬后隐瞒了伤口。最末一页只有一句话："不要爱上任何一个你觉得可以拯救的怪物。"笔记最后一页贴着一根银色的头发，不是作者的。旁边写着："有些怪物留下纪念品，是为了让你记得你还没赢。"

银发在黑暗中会发出极弱的荧光，提示吸血鬼的视力或许能追踪这种光泽。

书脊处裂开一道缝，缝里露出一张折叠的纸条，只露出一个角。

## 设计意图

为特定敌人类型提供针对性知识，构建吸血鬼作为高威胁特殊敌人的狩猎玩法。
