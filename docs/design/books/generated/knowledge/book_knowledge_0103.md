# 《古代战场旌旗考》

## 基础信息

- **书籍 ID**：`book_knowledge_0103`
- **关联技能**：`knowledge_heraldry`
- **使用效果**：阅读后解锁技能 `knowledge_heraldry`；记录 `known_knowledge_id: ancient_battlefield_banners`。若已学会，提升 `current_mastery +120`，并在面对古代亡灵军队时可提前识别敌方指挥官类型。
- **阅读要求**：无职业限制；基础 `智力 ≥ 9`。
- **稀有度**：普通（Common）
- **建议投放**：废墟图书馆、老兵遗物、历史学者委托奖励。

## 书籍内容

此书整理了三十二面曾在灰烬交界前哨战中出现的战旗，每一面都对应不同的军阵与指挥官特长。作者并非将军，而是一名战地收尸人，他从尸体的盔甲纹样与旗帜残片中反推每支部队的编制。书中将旌旗分为"血旗""骨旗""烟旗"三类：血旗主冲锋，骨旗主围困，烟旗主扰敌。最有趣的一章讨论"假旗"——某些亡灵军团会故意悬挂敌方旗帜引诱援军。末尾附有六面破损战旗的彩绘复原图，以及一句警告："旗帜从不杀人，但看错旗帜会。"收尸人在最后一页画了一个简单的手势图，标注着"看到烟旗右转，看到血旗趴下，看到骨旗——祈祷你已经跑远了"。

彩绘复原图的背面有一枚旧印章，已经模糊，只能辨认出"不归"两个字。

封面内侧有一道烧焦的指痕，似乎有人曾带着它穿越火场。

书的某一页被火药熏黑了一半，剩下的一半字迹反而比平时更清晰。

## 设计意图

为战场遭遇战提供前置信息层，让玩家通过知识而非试错来预判敌群构成，增强策略感。
