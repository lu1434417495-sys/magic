# 《禁忌之书名册索引》

## 基础信息

- **书籍 ID**：`book_knowledge_0181`
- **关联技能**：`knowledge_occult`
- **使用效果**：阅读后解锁技能 `knowledge_occult`；记录 `known_knowledge_id: forbidden_book_index`。若已学会，提升 `current_mastery +180`，并阅读其他禁书或高危险知识书籍时，理智值惩罚降低 10%（一次性交互增益）。
- **阅读要求**：无职业限制；基础 `智力 ≥ 11` 或 `意志 ≥ 11`。
- **稀有度**：史诗（Epic）
- **建议投放**：禁书区、深渊图书馆、禁忌收藏家书房。

## 书籍内容

这本索引本身也是一本禁忌之书，记录了分散在世界各地的三十九本危险典籍的书名、存放地点与已知的诅咒效果。书中警告，有些书不能被阅读，只能被“瞻仰”或“偿还”。中间一章按危险等级把禁书分为“看封皮就会受影响”“读目录就会受影响”和“想名字就会受影响”三类。后半本收录了数名索引编纂者的离奇死亡记录，说明这本书本身也在缓慢吞噬他们。最末一行写道：“知识有重量，这本索引只是帮你决定哪块石头值得压在自己身上。”

索引的最后一页是一张空白页，但用手指轻抚时能感受到极浅的凹凸，像是有人用隐形墨水写下了第四十本书的名字。

索引的历任保管者都活不过四十岁，这个统计数字本身也被后来者记录在空白页上。

图书馆管理员会把它藏在假墙后面，只向最信任的学者展示。

## 设计意图

作为禁书知识的“元书籍”，降低后续危险阅读成本，服务于深度探索型玩家。
