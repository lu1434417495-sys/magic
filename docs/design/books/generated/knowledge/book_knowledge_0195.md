# 《传奇武器命名学》

## 基础信息

- **书籍 ID**：`book_knowledge_0195`
- **关联技能**：`knowledge_lore`
- **使用效果**：阅读后解锁技能 `knowledge_lore`；记录 `known_knowledge_id: legendary_weapon_naming`。若已学会，提升 `current_mastery +150`，并为武器命名或重命名时，额外解锁一个候选名字与潜在加成方向。
- **阅读要求**：无职业限制；基础 `智力 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：吟游诗人学院、武器收藏馆、传奇铁匠委托奖励。

## 书籍内容

本书研究著名武器名字的来源与力量之间的关系。作者认为，一把武器的名字不只是标识，更是持有者、锻造者与历史共同施加的咒语。中间一章列举了数把传奇武器的原名与后世误传，指出某些武器在改名后力量大减，而另一些则在改名后觉醒。后半本提供了为武器命名的基本原则，警告不要使用过于宏大的名字，因为名字会在使用中逐渐“要求”持有者兑现它。最末写道：“武器的名字是它的债，也是它的梦想。”

书末附有一张空白表格，标题是：为你的武器写下三个名字，然后划掉两个。表格下方只有一行小字：剩下的那个会记住你。

武器锻造大师会把这本书送给即将出师的学生，作为命名前必须完成的最后一课。

吟游诗人会把这本书当作讲述英雄传说前的备课材料，以免记错武器真名。

## 设计意图

把通识知识转化为装备命名与角色扮演深度，为武器个性化系统提供选项。
