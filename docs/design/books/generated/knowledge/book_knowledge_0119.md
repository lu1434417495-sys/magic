# 《古代机关拆解术》

## 基础信息

- **书籍 ID**：`book_knowledge_0119`
- **关联技能**：`knowledge_engineering`
- **使用效果**：阅读后解锁技能 `knowledge_engineering`；记录 `known_knowledge_id: ancient_mechanism_dismantling`。若已学会，提升 `current_mastery +130`，并提高古代宝箱与机关锁的开启成功率。
- **阅读要求**：无职业限制；基础 `智力 ≥ 9` 或 `敏捷 ≥ 9`。
- **稀有度**：精良（Uncommon）
- **建议投放**：工程师行会、遗迹工坊、矮人据点。

## 书籍内容

这本书的每一页边缘都留有空白，显然是为了让读者在实操时做笔记。作者用五十个拆解案例讲解古代机关的核心逻辑：不是破坏，而是理解力量的流向。第一章介绍如何通过磨损痕迹判断机关的年龄与使用频率；第二章讲解七种常见的触发机制，包括压力、光线、声音与温度；第三章则是失败案例集，其中大部分事故源于拆解者过于自信。最末一页是一份自检清单，最后一项写着："在动手前，先找到它的退路。"自检清单背面是一幅潦草的涂鸦，画着一个微笑的机关核心，配文："最好的机关拆解，是让机关以为你还喜欢它。"

涂鸦旁边有一枚古代齿轮，刚好能嵌入书中某一页的凹槽，但没人敢转它。

书的边缘被人用蜡反复封过，又被反复拆开，留下层层叠叠的封口痕迹。

书的最后夹着一个空信封，信封上写着"寄给第一个活着读完本书的人"。

## 设计意图

把机关解谜从试错玩法转化为可学习的系统，为盗贼与工程师角色提供成长路径。
