# 《吟游谎言与真相》

## 基础信息

- **书籍 ID**：`book_knowledge_0144`
- **关联技能**：`knowledge_bardic`
- **使用效果**：阅读后解锁技能 `knowledge_bardic`；记录 `known_knowledge_id: bard_lies_and_truth`。若已学会，提升 `current_mastery +120`，并提升谎言识别与说服成功率。
- **阅读要求**：角色职业标签含 `bard` 或 `rogue`；基础 `魅力 ≥ 9`。

## 书籍内容

作者自称"说谎说了五十年才开始说真话"，他在书中把谎言分为保护性谎言、操控性谎言与仪式性谎言三类。最精彩的部分是大量真实案例：一个吟游诗人如何通过改一个词让整场战争看起来正义，一个乞丐如何通过编故事让贵族自愿掏钱。作者也讨论了"真相的暴力"——在某些时候，说出真相比说谎更残忍。最末一页是一篇未完成的歌谣，歌词在赞美与讽刺之间摇摆，最后一句被划掉多次，依稀可辨："听众只相信他们愿意相信的，而诗人只负责把它唱出来。"未完成歌谣的背面贴着一张剧院的票根，来自一场从未发生过的演出。配文："最好的谎言，是连说谎者都想去听的那场戏。"

票根的座位在火灾中消失，但有人声称每年同一天仍能听见那个座位上传来掌声。

内页有几行字被用刀尖划掉，划得极深，几乎穿透纸张。
