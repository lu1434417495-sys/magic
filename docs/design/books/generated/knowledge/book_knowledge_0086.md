# 《边境法庭的判例集》

## 基础信息

- **书籍 ID**：`book_knowledge_0086`
- **关联技能**：`knowledge_law`
- **使用效果**：阅读后解锁技能 `knowledge_law`；记录 `known_knowledge_id: border_court_precedents`。若已学会，提升 `current_mastery +100`，并解锁与部分城镇守卫的特殊对话与减刑选项。

- **建议投放**：城镇法庭、律师行会任务、治安官办公室。

## 书籍内容

这本判例集记录了边境地区五十年来的重要判决，作者是一名巡回法官。前半本的案件多与资源争夺有关：水源、牧场、矿脉和过境税。作者展示了在缺乏中央权威的地区，法律如何依靠先例、人情和暴力威慑共同维持。中间一章专门讨论「异界生物是否拥有权利」的争议，不同边境城镇给出了完全不同的答案。

书的后半部分逐渐从法律技术转向法官的个人反思：每一个判决都是在不完美信息下的权衡，而法官必须学会与错误共存。最末一页写着：「法律不是正义，法律是正义的草稿。好的法官知道何时修改它。」

边境法庭的判例集被几位法学院学生改编成了戏剧，在城市广场上演。最受欢迎的台词是：「法律是正义的草稿。」演出结束后，一位老法官在台下鼓掌，但拒绝上台合影。据说他回到办公室后，在最新一份判决书旁写下了同样的话。
