# 《殉道者之盾笔记》

## 基础信息

- **书籍 ID**：`book_牧师神术_0109`
- **关联技能**：`priest_martyr_shield`（待新增）
- **使用效果**：阅读后解锁 `priest_martyr_shield`；若已学会，提升 `current_mastery +130` 并在下一次战斗中为相邻队友承担首次伤害的 25%。
- **阅读要求**：角色职业标签含 `priest`；基础 `体质 ≥ 9`，基础 `意志 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：烈士陵墓、前线救护任务、圣骑士传承宝箱。

## 书籍内容

笔记的封面被一块烧穿的布包裹着，布料的经纬间还嵌着细小的铁屑。作者没有歌颂牺牲，而是把它拆解成一道算术题："你能替别人承受多少，取决于你愿不愿意先承认自己的极限。"书中描述殉道者之盾不是一种法术，而是一种姿态——膝盖微屈、重心下沉、双臂像门框一样张开。作者警告，最危险的时刻不是替人挡下攻击，而是挡完之后还站在那里，因为敌人的第二次攻击会本能地落向同一个点。最后一页画着一个简笔小人，胸口有一个洞，旁边写着："这个洞不是荣耀，是提醒。"笔记封底粘着一块碎裂的盾漆，漆面上还能看出半枚徽记，附注说这是一面被击碎的盾唯一剩下的部分，它在碎裂前替持盾者挡住了三次致命的攻击。

## 设计意图

强化牧师前排保护者定位，用"替伤"机制鼓励站位与团队配合。
