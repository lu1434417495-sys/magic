# 《亡灵退散令》

## 基础信息

- **书籍 ID**：`book_牧师神术_0042`
- **关联技能**：`priest_turn_undead`（待新增）
- **使用效果**：阅读后解锁 `priest_turn_undead`；若已学会，提升 `current_mastery +90` 并尝试让周围低阶亡灵后退两格，无法发动借机攻击。
- **阅读要求**：角色职业标签含 `priest` 或 `support`；基础 `意志 ≥ 9`。
- **稀有度**：普通（Common）
- **建议投放**：墓地、亡灵入侵区域、中级驱邪支线。

## 书籍内容

退散令的核心是一句被无数次修改的命令：你们不属于此地，回去。作者解释，这句话必须念得既坚定又悲伤，因为坚定的语气让亡灵无法忽视，悲伤的语气让它们知道这不是驱逐，而是送别。书中还记录了不同地区对这句话的变体，北方的版本更短，南方的版本会加上亡灵生前的名字。最让学徒惊讶的是，有时候命令无效不是因为意志不够，而是因为施术者自己害怕亡灵真的离开，那种犹豫会通过声音传出去。练习时要在墓地边缘对一群飞蛾念诵，直到它们因为你声音里的界限感而散开。最后一页有一段用木炭写的话：我赶走了它们三次，第四次它们自己转身了，我想那是因为我终于不再害怕看见它们的脸。这本书是墓园守卫的标准配发读物，因为它比任何武器都更有效地阻止亡灵靠近活人居住区。

## 设计意图

为牧师系提供基础范围控场技能，把亡灵驱散与站位控制结合，适合战棋中打开通道或保护后排的场景。
