# 《缓痛低语》

## 基础信息

- **书籍 ID**：`book_牧师神术_0005`
- **关联技能**：`priest_soothing_whisper`（待新增）
- **使用效果**：阅读后解锁 `priest_soothing_whisper`；若已学会，提升 `current_mastery +60` 并降低一个友方下一次受击时的痛感判定。
- **阅读要求**：角色职业标签含 `priest` 或 `support`；基础 `意志 ≥ 6`。
- **稀有度**：普通（Common）
- **建议投放**：战地医院、新手牧师德鲁伊任务、安抚支线。

## 书籍内容

这本书没有封面，第一张纸直接写着书名，字迹纤细得像怕惊扰什么。内容全是短句，最长的句子也不超过十二个字，因为作者相信疼痛中的人听不进复杂的道理。书中教的并不是让伤口消失，而是让伤者把注意力从伤口转移到自己的呼吸上：吸气时默念一个音节，呼气时默念另一个，以此切断疼痛与恐惧之间的联系。作者特别强调声音要轻，近于耳语，因为大声的命令会让已经紧张的人更加警觉。中间几页记录了几位伤员的反应，有人哭泣，有人沉睡，也有人突然开始讲述家乡的事。书的最后一行字被泪水晕开：不要急着让疼痛停止，先让它不再决定伤者是谁。在多次战地救援中，这本书被证明比任何镇痛草药都更持久，因为它安抚的不是神经，而是意义。

## 设计意图

为牧师系提供基础减伤与状态抗性技能，强调心理安抚在治疗体系中的作用，契合战棋中的士气机制。
