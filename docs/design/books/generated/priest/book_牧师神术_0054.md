# 《圣水瓶封印法》

## 基础信息

- **书籍 ID**：`book_牧师神术_0054`
- **关联技能**：`priest_holy_water_seal`（待新增）

## 书籍内容

圣水瓶封印法是一本关于如何给普通水瓶赋予临时神圣属性的实用手册。作者坚持认为，圣水的效果取决于封印时施术者是否真正相信水能承载祝福，而非瓶子的材质或圣水的来源。书中详细描述了封口蜡的配方、祈祷词的长短以及摇晃瓶身的禁忌次数，强调封印完成后瓶身应微微发热，否则需要重新来过。后半部是一些战场记录，记载士兵如何在灰烬交界的废墟中用此法临时封印门窗，阻止低等亡灵进入，也记载有人因封印时心存怀疑而被亡灵从内部攻破。某一页的污渍被人用指甲划成一句话："水不会审判，只是反射光。"另一处画着一个被倒置的圣水瓶，附注："倒置即失效，别在夜里犯这个错。"最后一页贴着一小片发黄的蜡纸，上面还残留着一个不完整的封印符文。蜡纸的边缘已经发脆，像某个未完成誓言的残骸。

## 设计意图

提供牧师系基础亡灵针对技能入口，强化"神圣封印"的低阶战斗价值。
