# 《荆棘冠冕观想法》

## 基础信息

- **书籍 ID**：`book_牧师神术_0032`
- **关联技能**：`priest_meditation_of_thorns`（待新增）
- **使用效果**：阅读后解锁 `priest_meditation_of_thorns`；若已学会，提升 `current_mastery +90` 并在冥想时提升少量意志恢复速度。
- **阅读要求**：角色职业标签含 `priest` 或 `support`；基础 `意志 ≥ 9`，已解锁冥想机制。
- **稀有度**：普通（Common）
- **建议投放**：苦修院静室、冥想训练任务、中级精神修炼支线。

## 书籍内容

观想不是让人舒适，而是让人在不适中保持清醒。这本书要求读者在冥想时想象一顶由荆棘编成的冠冕，每一根刺都代表一个未解的烦恼。关键不在于让刺消失，而是让它们保持在意识边缘，既不忽视，也不被刺伤。作者认为这种训练能让牧师在战场上保持专注，因为真正的干扰从来不是疼痛，而是对疼痛的反应。书中提供了从一刻钟到一整夜的渐进练习，最短的一种只需在心中默念三句话：刺在这里，我在这里，光也在这里。许多页边有使用者的涂鸦，画着被荆棘缠绕的头颅，表情却很平静。最后一页贴着一小段干枯的荆棘，附注说这是从苦修院后山采来的，戴在手上不会流血，但会一直提醒你不要忘记自己为什么坐下。这本书是冥想导师最常推荐的辅助读物，因为它把抽象的专注力训练变成了可以触摸的意象。

## 设计意图

为牧师系提供冥想相关的意志恢复技能，连接项目的冥想机制，强化牧师作为精神修炼者的成长路径。
