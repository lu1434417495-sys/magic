# 《圣餐仪式简编》

## 基础信息

- **书籍 ID**：`book_牧师神术_0027`
- **关联技能**：`priest_eucharist_rite`（待新增）
- **使用效果**：阅读后解锁 `priest_eucharist_rite`；若已学会，提升 `current_mastery +80` 并在营地休息时提升全队少量最大HP上限，持续到下次战斗结束。
- **阅读要求**：角色职业标签含 `priest` 或 `support`；基础 `意志 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：营地、教会食堂、中级团队休整支线。

## 书籍内容

这本简编没有讲复杂的神学，只讲如何把一顿简单的饭变成一次圣餐。作者认为分享食物是最古老的祈祷，因为它同时承认了身体的需要与共同体的存在。仪式要求主持者亲手分发食物，并在递出时说一句简短的祝福，不能省略，也不能说得太过华丽。书中还详细规定了食物的种类：面包代表土地，清水代表旅程，盐代表经历过的艰辛。最特别的是关于剩余食物的处理：不能浪费，必须保存到下一顿，因为祝福已经附着在上面。简编末尾有一段某位军营牧师的记录：在战壕里，我们用硬饼干和雨水完成了圣餐，没有人笑，但所有人的手都没有抖。那一刻我知道，仪式可以在任何地方发生。这本书在长途远征队伍中极受欢迎，因为它让枯燥的休整时间变成了一种值得期待的力量来源。

## 设计意图

为牧师系提供营地增益类技能，把休息与仪式结合，增强队伍续航与战前准备阶段的策略深度。
