# 《安息圣所图录》

## 基础信息

- **书籍 ID**：`book_牧师神术_0185`
- **关联技能**：`priest_sanctum_of_rest`（待新增）
- **使用效果**：阅读后解锁 `priest_sanctum_of_rest`；若已学会，提升 `current_mastery +120` 并创建一片区域，友方在其中每回合恢复少量生命与 MP。
- **阅读要求**：角色职业标签含 `priest` 或 `support`；基础 `意志 ≥ 12`。
- **稀有度**：精良（Uncommon）
- **建议投放**：休养修道院、驻守任务奖励、高级技能商人。

## 书籍内容

图录的每一页都是一座小圣所的平面图，从简陋的石屋到宏伟的殿堂，共同点是中央都有一口未被封盖的井。它记载的是一种创建临时安全区域的神术：施术者用杖尖或手指在地上画出一个四方形，方框内会升起柔和的光壁，站在其中的友方缓慢恢复生命与法力。书中说，圣所的边界必须被完整画出，中断的线条会让恢复效果漏出，甚至吸引外界敌人。作者还提醒，圣所不是堡垒，光壁无法阻挡恶意进入，只能让恶意在进入时变得迟缓。图录最后一页是一幅空白平面，附注写着："你自己才是最后一面墙。"空白平面的四角有四枚浅浅的指印，像是某位牧师在临终前用自己的血按下的，试图把自身也变成圣所的一部分。每逢有人在此圣所中入睡，总会梦见一位没有面孔的牧师长跪在角落，默默地守护着边界。

## 设计意图

为牧师提供场地型持续恢复技能，通过有限防御与完整边界的要求，增强战棋中的阵地经营与团队协作。
