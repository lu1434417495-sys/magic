# 《神恩救助手册》

## 基础信息

- **书籍 ID**：`book_牧师神术_0149`
- **关联技能**：`priest_aid`
- **使用效果**：阅读后若已学会 `priest_aid`，提升 `current_mastery +90` 并在下一次战斗中令急救类技能冷却减少 1 回合；未学会时解锁该技能。
- **阅读要求**：角色职业标签含 `priest` 或 `support`；基础 `意志 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：急救站、民兵训练任务、普通商人。

## 书籍内容

手册的内容非常实际：如何判断一个人是昏迷还是死亡，如何用布条止住动脉出血，如何在搬运伤者时不让骨头错位。作者认为，神恩救助不是等待奇迹，而是先把能做的事做完。书中反复强调，救助的第一步不是念诵祷文，而是确认自己的手是干净的。每一章后面都有一道检查清单，最后一项永远是："你有没有问过伤者想不想被救？"最后一页画着两只手交握的图案，一只戴着护甲，一只没有。手册封底画着一个简单的十字架，十字架上缠着一条布条，布条上写着："先止血，再祈祷。"这条布条是从某件被血浸透的衬衫上裁下来的，主人后来成了最好的战地医师。布条末端打了一个死结，附注说解开它的人会同时解开一段记忆。急救站的墙上挂着那条写着先止血再祈祷的布条，作为入站誓言。边境的流浪牧师最珍惜此书。

## 设计意图

强化牧师基础急救技能，用务实的叙事平衡神术与医疗常识。
