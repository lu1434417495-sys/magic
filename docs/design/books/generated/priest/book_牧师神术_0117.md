# 《慈悲王座讲章》

## 书籍内容

讲章记录了一位老主教在临终前三个月的布道。他没有谈论天堂或地狱，而是反复描述一张空椅子的摆放角度："王座不应该让人仰望，而应该让人敢于坐下。"作者认为，慈悲的力量在于让受苦的人感到自己被授权，而不是被拯救。讲章中有一段关于倾听的技术：不要打断，不要提前说"我懂"，不要在对方停顿超过三秒时递上答案。书的最后几页被泪水泡得发胀，只能辨认出一句："我无法治愈你，但我可以坐在你身边。"讲章的封底印着一把空椅子的剪影，椅背上搭着一块被洗得发白的布，布角绣着一个已经看不清名字的徽章；有人把这块布当作绷带用过一次，伤者的疼痛在第二天减轻了。徽章上残留着一点药草的气味，闻起来像苦艾与蜂蜜的混合物。

## 设计意图

提供高阶急救/稳定类牧师技能，用叙事深化"陪伴式救赎"主题。
