# 《终极祈祷残典》

- **书籍 ID**：`book_牧师神术_0200`
- **关联技能**：`priest_final_orison`（待新增）

## 书籍内容

残典没有封面，只有一堆被金线穿在一起的散页，每一页上都写着"最后一页"四个字。它记载的是牧师系最为终极的神术：当所有希望耗尽时，施术者跪下，把自己的全部精神力、生命力与修炼成果一次性燃烧，化为笼罩全队的救赎之光。书中说，终极祈祷不是胜利的手段，而是拒绝让同伴孤独死去的意志；施展后施术者会陷入长时间的虚弱，甚至永远失去一部分神术能力。作者在前言中写道："不要学习这本书，除非你已经在某个深夜确认过，自己愿意为某个人献出一切。"残典最后一页是一面空白的镜子，据说只有在真正需要时，镜中才会映出你愿意为之祈祷的那张脸。镜框上刻着一行小字，提醒每一位翻阅者："当你看见镜中是自己的脸时，说明你已经找到了那个值得的人。"施展终极祈祷后，镜子会碎裂成无数片，每一片都映出一位被拯救者未来的笑容。

## 设计意图

作为牧师 151-200 编号的压轴史诗技能，提供全资源消耗的全队救赎效果，象征牧师职业最核心的牺牲与守护精神。
