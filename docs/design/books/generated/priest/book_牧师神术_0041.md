# 《神圣震击》

## 书籍内容

这本书的封面有一道焦痕，像被闪电擦过。神圣震击不是攻击，而是让过量的秩序瞬间涌入混乱之体，所以它对违背自然法则的亡灵特别有效。作者把施法过程比作握拳：先张开五指凝聚光，再猛然合拢，让光在敌人身上炸开。书中警告，这个术不能带着仇恨施放，因为仇恨会让光变得浑浊，反而削弱对亡灵的效果。练习时要在铜盘上凝聚光点，直到能让盘子发出清脆的鸣响而不留下焦痕。最严厉的批评来自一位老审判官：神圣震击是用来阻止邪恶继续扩散，不是用来发泄你的愤怒，如果你分不清两者，就先去告解室。最后一页贴着一片被震碎的亡灵甲片，附注说它只是被光擦过边缘，就已经碎成了十二块。这本书标志着牧师从纯粹的治疗者开始向具备战斗能力的守护者转变，因此被许多导师谨慎地发放给学生。

## 设计意图

为牧师系提供早期直接伤害技能，强化神圣伤害对亡灵的克制关系，让牧师在需要时也能承担输出角色。
