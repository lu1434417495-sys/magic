# 《光辉收获手札》

## 基础信息

- **书籍 ID**：`book_牧师神术_0176`
- **关联技能**：`priest_luminous_harvest`（待新增）
- **使用效果**：阅读后解锁 `priest_luminous_harvest`；若已学会，提升 `current_mastery +120` 并将战场上阵亡敌人的余烬转化为全队治疗。
- **阅读要求**：角色职业标签含 `priest` 或 `support`；基础 `意志 ≥ 12`。
- **稀有度**：精良（Uncommon）
- **建议投放**：战后清扫任务、墓园教堂、高级技能商人。

## 书籍内容

手札的封面画着一个弯腰的人形，双手捧着一团光，脚下是倒伏的麦穗与武器。它记载的是一种战斗结束后的恢复神术：施术者在战场上行走，把刚刚逝去的生命残留的光点收集起来，像收割麦子一样归拢，然后分发给幸存的同伴。书中强调，这个神术必须在战斗结束后短时间内施展，因为死亡的光芒消散得很快；同时，施术者不能收集自己亲手杀死的敌人的余烬，否则光辉会变成灼烧。作者建议每次收获后默念一句："你不再是敌人，你是被归还的土地。"手札最后一页贴着一片干枯的麦穗，附注说这是从一位老牧师的葬礼上取得的，那位牧师一生都在替别人收拾战场。麦穗的根部缠着一根细细的头发，附注说那是老牧师最后一次收获时，从一位年轻敌人身上拾起的，他把它和自己的头发埋在了一起。

## 设计意图

为牧师提供战后恢复型技能，通过"收割余烬"的概念将战斗结果转化为续航资源，强化牧师的仪式收尾角色。
