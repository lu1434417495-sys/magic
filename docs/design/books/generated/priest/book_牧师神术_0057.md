# 《静心默想录》

- **书籍 ID**：`book_牧师神术_0057`
- **关联技能**：`priest_quiet_meditation`（待新增）

## 书籍内容

静心默想录是一本薄册，主张牧师的力量不只来自祈祷，也来自沉默。作者将冥想比作给精神磨刀：刀不磨会钝，心不静则神术涣散。书中提供了九种坐姿、三种呼吸法和一套逐层放下杂念的步骤，从数息开始，到观想烛火，最后进入无对象的静默。后半部是一些练习者的笔记，记录他们在灰烬交界的嘈杂战场中如何用短短几次呼吸恢复专注，有人在投石机的轰鸣中完成了完整的冥想周期。某页边角写着："不要追逐安静，让它来找你。"另一处有人用铅笔淡淡写着："我曾以为冥想是逃避，后来发现它是让我能重新站起来的地方。"封底夹着一片干枯的薄荷，似乎是某位读者用来保持清醒的遗物，轻轻一捻仍有淡淡的凉意。
