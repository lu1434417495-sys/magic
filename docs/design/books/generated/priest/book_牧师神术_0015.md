# 《止血祷言》

## 基础信息

- **书籍 ID**：`book_牧师神术_0015`
- **关联技能**：`priest_staunch_prayer`（待新增）
- **使用效果**：阅读后解锁 `priest_staunch_prayer`；若已学会，提升 `current_mastery +70` 并在下次战斗中对一名友方立即止血。
- **阅读要求**：角色职业标签含 `priest` 或 `support`；基础 `意志 ≥ 7`。
- **稀有度**：普通（Common）
- **建议投放**：战地医院、止血训练任务、低级牧师导师。

## 书籍内容

这是一本几乎每一页都有褐色污渍的册子，污渍来自前任主人练习时沾上的草药汁与血迹。祷言的核心只有三句话，分别对应按住伤口、调整呼吸、请求身体自己闭合。作者反复强调手的位置比祷词更重要，因为话可以被耳朵听见，但按压必须被伤口感受到。书中详细描述了不同部位出血的处理顺序：四肢先于躯干，远端先于近端，不要一次松开查看。最常被折角的一页写着：祈祷不会代替按压，但按压时若心中有祷词，血会停得更快，因为伤者的身体知道有人在替它争取时间。最后一页是一段手写的失败记录：某次我念完了整篇祷文却忘了继续按，结果血流得更多，从那以后我只念前三句。这本书在紧急救护训练中被要求背诵到本能反应的程度，因为战场上没有时间翻页。

## 设计意图

为牧师系提供即时止血类治疗技能，强调急救的时效性与操作顺序，适合战棋中处理持续伤害与紧急救援场景。
