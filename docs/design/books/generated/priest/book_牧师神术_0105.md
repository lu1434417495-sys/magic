# 《异端审判笔录》

- **书籍 ID**：`book_牧师神术_0105`
- **关联技能**：`priest_heretic_judgment`（待新增）

## 书籍内容

这本笔录的每一页都经过编号和火漆封存，但最后一页的封漆被人抠掉了半块。内容不是判决书，而是审问者自问的记录："我如何判断自己所见的是异端，而不是我自己无法理解的虔诚？"作者反复警告，神罚之权最容易腐化为个人愤怒，因此施术前必须念一段抑制咒语，把声音压低到只有自己能听见。笔录中间夹着一张炭化的画像，背面写着："她曾经也是执灯人。"读完此书的人常常梦见自己在被告席上。笔录封底夹着一张被撕掉的判决书草稿，上面只写了被告的名字和一句"也许不是"；墨迹被雨水晕开，像是一滴很久以前的泪。那张草稿被夹在最显眼的位置，仿佛前任审问者希望下一个翻开它的人能看见。判决书草稿的背面画着一个没有五官的人形，标注为"可能的自己"。

## 设计意图

引入牧师系的惩击输出技能，同时用叙事强调"审判"背后的道德张力。
