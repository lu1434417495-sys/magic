# 《悼词吟诵术》

## 基础信息

- **书籍 ID**：`book_牧师神术_0087`
- **关联技能**：`priest_elegy`（待新增）
- **使用效果**：阅读后解锁 `priest_elegy`；若已学会，提升 `current_mastery +50` 并在下一次战斗中令首次为亡灵敌人吟诵时令其短暂迟疑，降低 1 点命中。
- **阅读要求**：角色职业标签含 `priest` 或 `support`；基础 `意志 ≥ 7`。
- **稀有度**：普通（Common）
- **建议投放**：墓园礼拜堂、悼亡任务奖励、低级亡灵宝箱。

## 书籍内容

悼词吟诵术是一本关于如何在战斗中用悼词影响亡灵行动的小册。作者认为，许多亡灵之所以滞留，是因为它们从未被正式地告别过，所以一句真诚的悼词比一记重击更能动摇它们。书中收录了数种简短而庄重的悼词格式，每一种都可以根据死者的身份进行调整，从士兵到孩童都有对应的变体。后半部是一些牧师的实战经验，他们如何在灰烬交界的战场上用此法让低阶亡灵短暂停止攻击，为队伍争取调整阵线的时间。某一页写着："不要假装悲伤，亡灵能听出真假。"另一处有人画了一个低头的人形，旁边写着："先念名字，再念悼词，顺序不能乱。"

## 设计意图

提供牧师系基础亡灵控制技能入口，强化"悼词安抚"的低阶亡灵应对主题。
