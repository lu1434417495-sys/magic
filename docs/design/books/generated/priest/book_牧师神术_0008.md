# 《祈祷姿态图解》

## 基础信息

- **书籍 ID**：`book_牧师神术_0008`
- **关联技能**：`priest_prayer_posture`（待新增）
- **使用效果**：阅读后解锁 `priest_prayer_posture`；若已学会，提升 `current_mastery +60` 并在跪姿施法时降低少量MP消耗。
- **阅读要求**：角色职业标签含 `priest` 或 `support`；基础 `意志 ≥ 6`。
- **稀有度**：普通（Common）
- **建议投放**：修道院图书馆、祈祷训练支线、低级牧师导师。

## 书籍内容

全书几乎都是图画，只有极少数文字说明，据说是为了让不识字的人也能学习。作者用三十六个姿势分解了一次完整的祈祷：如何站、如何跪、如何俯身、如何在受到攻击时保持身体的稳定。每个姿势旁边都标注了对应的呼吸次数与意念集中点，书中称之为让身体先于嘴巴祈祷。最受争议的是第十五图，图中人物单膝跪地，一只手按在地面，另一只手护住胸口，注释说这是为濒死者祈祷时的姿态，因为它能让施术者的重心低到不会被打倒。书页背面有使用者的笔记：姿态不是为了好看，是为了在混乱中仍然记得自己为何而战。最后一页画着一个空白的圆圈，下面写着：最后的姿态由你自己完成。这本图解在战地牧师中尤其流行，因为他们在炮火中无法高声祈祷，只能用身体完成全部仪式。

## 设计意图

提供牧师系基础姿态类被动或资源优化技能，通过身体语言加深神职者职业的仪式感与战斗中的专注主题。
