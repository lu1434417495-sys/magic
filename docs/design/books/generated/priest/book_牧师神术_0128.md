# 《复活颂歌残页》

## 书籍内容

残页只有半张，上面的音符几乎被岁月磨平。它记载的复活不是让死者重新站起来，而是让死亡暂时"没有发生"。作者警告，施术者必须同时承受被复活者临终前最后三秒的感受，包括痛苦、恐惧和未说完的话。如果施术者在这三秒内闭上眼睛，复活会成功，但自己会永远记得那三秒；如果睁开眼睛，复活会失败，但施术者会忘记一切。残页的边缘有一行更古老的字迹，像是后来被添上去的："没有人能真正复活别人，我们只能替他们多活一会儿。"残页的背面粘着一小片干枯的皮肤，附注说这是第一位成功施术者的右手背，她在复活别人后失去了那三天的记忆；皮肤的纹理与残页上的某个音符完全吻合。皮肤碎片的边缘有一圈细密的针孔，像是曾经被缝在某件袍子上。

## 设计意图

作为牧师系终极技能入口，复活机制提供高风险高回报的战术核心。
