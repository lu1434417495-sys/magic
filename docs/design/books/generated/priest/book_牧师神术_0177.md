# 《慰藉之钟铭文》

## 书籍内容

铭文刻在一块弯曲的铜钟碎片上，文字必须沿着弧度阅读，否则会断句错误。它记载的是一种借助钟声稳定心智的神术：施术者敲击一面由祈祷凝结的虚幻大钟，钟声所及之处，恐惧、混乱与魅惑效果会被打断。书中说，钟声的有效性取决于施术者是否真正相信声音能够穿透黑暗，而不是仅仅把它当作一种武器。作者还记录了不同金属音色对应的效果：铜钟驱恐惧，银钟破魅惑，铁钟打断狂怒。铭文边缘有一行小字："如果你自己也在害怕，钟会先替你哭出来。"碎片背面刻着钟楼的平面图，但某个关键房间被刻意磨平。磨平处残留着几道凿痕，附注说那是后来人试图恢复房间位置时留下的，但每次恢复都会在当夜引发附近所有钟声的异常共鸣。钟声异常时，镇上的狗会集体沉默，直到黎明才敢重新吠叫。

## 设计意图

为牧师提供群体驱散异常状态技能，通过钟声意象与材质差异，丰富牧师在控制应对方面的战术选择。
