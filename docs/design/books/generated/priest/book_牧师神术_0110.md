# 《驱邪封灵简仪》

## 基础信息

- **书籍 ID**：`book_牧师神术_0110`
- **关联技能**：`priest_exorcism_seal`（待新增）
- **使用效果**：阅读后解锁 `priest_exorcism_seal`；若已学会，提升 `current_mastery +120` 并为下一场战斗开始时提供对亡灵敌人的首轮命中 +2。
- **阅读要求**：角色职业标签含 `priest`；基础 `意志 ≥ 10`，基础 `智力 ≥ 8`。
- **稀有度**：稀有（Rare）
- **建议投放**：驱魔修道院密室、亡灵巢穴任务奖励、古书商摊。

## 书籍内容

简仪的每一页都只有三步图解：第一步是"识"，辨认附身灵与宿主的分界；第二步是"定"，用四枚钉子把灵钉在宿主的影子里；第三步是"请"，问它是否愿意离开，而不是直接驱逐。作者强调，"封"比"杀"更需要技巧，因为被封的灵会记住你，并在未来以别的方式回来。书中夹着一张泛黄的便条，上面是一串住址："如果封灵后梦见敲门声，请于黎明前把这些地址逐一走访。"简仪的末尾画了一只被钉住的手，手指指向阅读者。简仪的最后一页是空白的，只压着一枚生锈的钉子，钉头上刻着一行小字："第七枚留给你想留的人。"钉身发黑，像是曾经被什么东西的血泡过很久，久到已经忘了名字。空白页的背面有一个用指甲划出的圆圈，圆心点着一点暗红色的漆。

## 设计意图

提供针对亡灵/灵的牧师控制技能，用仪式感流程区别于直接伤害法术。
