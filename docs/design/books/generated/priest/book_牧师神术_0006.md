# 《微光祝福》

## 基础信息

- **书籍 ID**：`book_牧师神术_0006`
- **关联技能**：`priest_glimmer_blessing`（待新增）
- **使用效果**：阅读后解锁 `priest_glimmer_blessing`；若已学会，提升 `current_mastery +60` 并为一名友方附加微量命中加成，持续三回合。
- **阅读要求**：角色职业标签含 `priest` 或 `support`；基础 `意志 ≥ 6`。
- **稀有度**：普通（Common）
- **建议投放**：黎明祭坛、新手牧师祝福任务、营地祈祷点。

## 书籍内容

这本书小巧得可以放进护腕的暗袋里，专门写给那些在战场上来不及完成完整祷文的牧师。书中教的是一种简化的祝福术：用食指在对方额头点三下，同时低声念出一句不超过七个字的祷词。作者警告说，简化不等于敷衍，三下的节奏必须均匀，念词时要把注意力完全放在受术者身上，而不是想着下一场战斗。为了训练专注力，作者建议学徒在嘈杂的集市里练习，如果能让人在人群中感到片刻宁静，就算入门。书页间夹着几片压制过的花瓣，附注说这些花只在神庙后山开放，摘下后三天内必须用完。末尾有一行小字：祝福不是借给别人的力量，而是提醒他们本来就有的光。这本小册子在历代牧师之间传递时，总会附带一句口头叮嘱：最短的祝福，往往最需要最完整的心。它提醒每一个牧师，最短的帮助也可以是最深的。

## 设计意图

提供牧师系基础命中加成类祝福技能，设计为低消耗、短持续的战略辅助，适合新手资源管理练习。
