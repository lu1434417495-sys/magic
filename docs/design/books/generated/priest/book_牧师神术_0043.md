# 《审判之锤》

## 基础信息

- **书籍 ID**：`book_牧师神术_0043`
- **关联技能**：`priest_hammer_of_judgment`（待新增）
- **使用效果**：阅读后解锁 `priest_hammer_of_judgment`；若已学会，提升 `current_mastery +90` 并对一名敌人造成神圣伤害，若目标带有负面状态则伤害提升。
- **阅读要求**：角色职业标签含 `priest` 或 `support`；基础 `意志 ≥ 9`。
- **稀有度**：精良（Uncommon）
- **建议投放**：审判庭、讨伐邪恶任务、中级惩恶支线。

## 书籍内容

审判之锤不是实体武器，而是由祷词与意志凝聚成的沉重一击。作者把它比作法官的木槌：落下时不是为了残忍，而是为了结束一段已经持续太久的罪恶。施术者需要在心中先确认目标的罪行，这种确认不是情绪化的判断，而是基于事实的承认。书中提醒，审判之锤对无辜者几乎没有伤害，但如果施术者心中充满偏见，它会变得很轻，轻到连恶人都打不痛。练习的方法是在水中凝聚锤形，然后一击打碎漂浮的木板，要求是木屑向四周均匀散开，而不是只飞向一个方向。最后一页贴着一张被烧焦的通缉令残片，附注写道：这个人最后是被审判之锤击倒的，不是因为我想惩罚他，而是因为他已经停不下来。这本书在审判庭内部被视为权力与责任的平衡象征，每一位新审判官都要在封面上按下手印。

## 设计意图

为牧师系提供基于敌方状态的爆发伤害技能，鼓励玩家先施加Debuff再使用审判，形成控制与输出的连招。
