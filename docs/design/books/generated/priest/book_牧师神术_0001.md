# 《初阶治愈祷文》

## 基础信息

- **书籍 ID**：`book_牧师神术_0001`
- **关联技能**：`priest_lesser_heal`（待新增）

- **建议投放**：新手村教堂、牧师训练任务、低级治疗支线。

## 书籍内容

这是一本被翻得发黄的薄册，封面上只有一行手写标题，墨迹已经渗进纸背。内容从最简单的呼吸法开始，要求诵读者在念出祷词前先完成三次深长的呼气，理由是急促的呼吸会让治疗之光变成刺眼的光斑，不仅无法止血，还会让伤者感到眩晕。书中把伤口分为三类：开口伤、瘀伤和惊惧伤，每一类都配有一句不同的结语。最常被圈点的是惊惧伤的句子：请先让自己相信，你不是被战斗抛弃的人，然后再去握住别人的手。册子后半部分贴着几片干枯的草药标本，旁边标注着这些植物与祷文配合时能让伤口愈合得更平整，但必须在日落前采摘。最后一页有一段见习牧师的批注：不要在伤员面前皱眉，他们会以为你在判断他们是否值得被救，而真正的祷文从不先做判断。许多年之后，这本册子仍被新手牧师随身携带，因为它的每一页都提醒人们，治疗从看见开始。

## 设计意图

提供牧师系最基础的治疗技能入口，强调治疗不仅是恢复生命值，更是稳定情绪与建立信任的过程。
