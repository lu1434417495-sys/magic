# 《小型驱邪符》

## 基础信息

- **书籍 ID**：`book_牧师神术_0013`
- **关联技能**：`priest_minor_exorcism`（待新增）
- **使用效果**：阅读后解锁 `priest_minor_exorcism`；若已学会，提升 `current_mastery +70` 并对低阶亡灵造成一次小范围圣光伤害。
- **阅读要求**：角色职业标签含 `priest` 或 `support`；基础 `意志 ≥ 7`。
- **稀有度**：普通（Common）
- **建议投放**：墓地巡逻任务、亡灵出没区域、教会驱邪训练。

## 书籍内容

这本小册子原本只是几张折叠起来的羊皮纸，外面用麻绳捆了三圈。内容从如何折符纸开始，每一步都配有小图：先对折，再折出三角，最后用拇指按住中心点默念一句短祷。作者强调驱邪符的力量不在于纸本身，而在于折叠时心中是否真的有边界感，即你清楚地知道哪里是神圣空间，哪里是污秽所在。书中警告说，不要把符纸折得太复杂，复杂的形状会分散意念，反而让邪气找到缝隙。后半部分列出了几种常见低级亡灵的反应：骷髅会后退，幽灵会停顿，被附身的动物则会剧烈颤抖。最末页贴着一张使用过的驱邪符残片，旁边写着：它曾经挡住过一次攻击，然后化成了灰，这就是符纸最好的结局。在低阶牧师中，这本书是最常被翻烂的手册之一，因为每个人都想确认自己的符是否折得足够虔诚。

## 设计意图

为牧师系提供早期对亡灵伤害技能，以符纸与仪式感包装，让驱邪机制在战棋中具备明确的范围与目标类型区分。
