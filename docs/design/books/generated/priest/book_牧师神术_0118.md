# 《亡者连祷》

## 基础信息

- **书籍 ID**：`book_牧师神术_0118`
- **关联技能**：`priest_ghost_litany`（待新增）
- **使用效果**：阅读后解锁 `priest_ghost_litany`；若已学会，提升 `current_mastery +140` 并在下一次战斗中降低亡灵敌人的首轮命中。
- **阅读要求**：角色职业标签含 `priest`；基础 `意志 ≥ 11`，已学会 `priest_requiem` 或 `priest_exorcism_seal`。
- **稀有度**：稀有（Rare）
- **建议投放**：亡灵墓地深处、驱灵仪式任务奖励、古墓宝箱。

## 书籍内容

连祷由九十九个死者的名字组成，每个名字后面都跟着一句"愿你被记得"。作者提醒，念诵时不能加快语速，因为亡灵对急躁极其敏感；也不能放慢，因为拖延会被视为怜悯，而怜悯有时比蔑视更让亡灵愤怒。书中记载了一次失败案例：一名年轻牧师把九十九个名字缩成了三十个，结果当晚所有被省略名字的亡灵同时出现在他的房间里。连祷的最后一页是空白的，只有一行脚注："第一百个名字由阅读者亲自填写。"连祷的最后一页不是空白，而是布满了无数细小的指印，附注说每一个指印都属于一个曾被记起过的亡灵；如果你在午夜把手指按在空白处，会感觉到一种比室温更低的凉意从纸背透过来。指印的排列没有规律，但把所有指印连起来会形成一个不规则的门形。亡灵墓地的守墓人会在午夜轻声念出第一百个名字，以免名单中断。

## 设计意图

提供亡灵特化控制/削弱技能，强化牧师对抗不死生物的专业性。
