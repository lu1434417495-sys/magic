# 《圣水调制笔记》

## 基础信息

- **书籍 ID**：`book_牧师神术_0009`
- **关联技能**：`priest_holy_water_brew`（待新增）
- **使用效果**：阅读后解锁 `priest_holy_water_brew`；若已学会，提升 `current_mastery +60` 并立即获得一瓶可用于下次战斗的低阶圣水。
- **阅读要求**：角色职业标签含 `priest` 或 `support`；基础 `意志 ≥ 6`。
- **稀有度**：普通（Common）
- **建议投放**：教会厨房、草药商人、圣泉采集支线。

## 书籍内容

笔记的纸张已经被各种水渍染出不同深浅的颜色，证明它曾无数次被带进调制现场。前半部分记录的是配方：三份井水、一份晨露、一小撮盐，以及一句必须在搅拌时低声念出的祷词。后半部分全是失败案例，作者诚实地写下了每一次调制失败的原因：水太急会让祝福散掉、容器不洁净会让圣水发臭、搅拌方向错误会让光沉入底部。最有趣的一条备注是：如果你在调制时想着要打败某个敌人，圣水会变得浑浊；如果你想着要保护某个人，它会自己发亮。笔记最后一页贴着一张旧标签，上面写着第一批圣水的保存期限只有七天，七天后它会变回普通的水，但作者补了一句：即便如此，那七天里它确实曾经是圣水。许多见习牧师会把这页撕下贴在工作台上，提醒自己每一次调制都是一次完整的祈祷。

## 设计意图

为牧师系提供基础圣水制作与道具类技能入口，把物资准备与信仰状态挂钩，增强沉浸感与资源规划乐趣。
