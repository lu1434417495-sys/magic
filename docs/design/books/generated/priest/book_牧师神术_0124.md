# 《清贫誓约书》

## 基础信息

- **书籍 ID**：`book_牧师神术_0124`
- **关联技能**：`priest_vow_of_poverty`（待新增）
- **使用效果**：阅读后解锁 `priest_vow_of_poverty`；若已学会，提升 `current_mastery +130` 并在下一次战斗中令自身每拥有一件以下品质的物品时，治疗量获得小幅加成。
- **阅读要求**：角色职业标签含 `priest`；基础 `意志 ≥ 11`，背包中金币 ≤ 500。
- **稀有度**：稀有（Rare）
- **建议投放**：苦修院院长室、清贫试炼任务奖励、隐修商人。

## 书籍内容

誓约书的正文只有一句话："我放弃的不是财富，而是财富能替我做的决定。"其余篇幅全是签名栏，每一栏都空着，等待阅读者自己填写日期和放弃的财物清单。作者认为，清贫不是贫穷，而是把选择重新收回到自己手中。书中警告，签这份誓约时不要流泪，也不要微笑，"情绪会让誓言变成表演"。最后一页有一行被反复擦拭的字迹，勉强可读："我已经签了三次，每一次都发现，我以为放弃的并不是我真正在意的。"誓约书的封底夹着一枚生锈的铜币，铜币被钻了孔，用线穿在书里，附注说这是作者最后一次拥有的钱；她在签下誓约的第二天把这枚铜币捐给了第一个向她乞讨的人。铜币背面有一个被凿掉的图案，只剩下边缘一圈难以辨认的花纹。清贫试炼的失败者常说，誓约书比任何锁链都更难挣脱。边境的流浪牧师最珍惜此书。

## 设计意图

提供基于携带物品数量/金币的治疗加成技能，引入"清贫构筑"玩法。
