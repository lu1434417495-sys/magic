# 《牺牲契约》

## 基础信息

- **书籍 ID**：`book_牧师神术_0033`
- **关联技能**：`priest_sacrifice_bond`（待新增）
- **使用效果**：阅读后解锁 `priest_sacrifice_bond`；若已学会，提升 `current_mastery +90` 并与一名友方建立链接，使其所受部分伤害转移至牧师自身。
- **阅读要求**：角色职业标签含 `priest` 或 `support`；基础 `意志 ≥ 9`。

- **建议投放**：高级护送任务、骑士团契约仪式、中级牺牲支线。

## 书籍内容

这本书被装在一个铁盒里，盒盖上刻着两只手相握的图案，其中一只手明显更瘦弱。契约的核心不是咒语，而是同意：双方必须清楚知道伤害会转移，较弱的一方不会因此失去选择。书中反复强调，真正的牺牲契约不能让受保护者感到亏欠，否则它会变成另一种债务。仪式要求在月光下进行，双方各念一句承诺，然后把血滴在同一枚铜币的两面。最让后来的读者不安的是第七章：如何解除契约。作者说，当其中一方不再需要保护时，契约会自然松动，但如果一方强行维系，它会反噬双方。最后一页有一段被泪水泡过的字迹：我替他挡下了那一剑，但我没有告诉他，因为我知道他不会同意。这本书在骑士团与高级牧师之间流传，常被当作最沉重的礼物赠予即将分别的同伴。

## 设计意图

为牧师系提供伤害转移类保护技能，通过契约仪式包装，增加团队保护策略的风险与情感深度。
