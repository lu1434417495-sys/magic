# 《黎明颂歌抄本》

- **书籍 ID**：`book_牧师神术_0180`
- **关联技能**：`priest_canticle_of_dawn`（待新增）

## 书籍内容

抄本的装订线里缠着几根公鸡羽毛，翻开时会有轻微的啼鸣错觉。它记载的是一种与黎明绑定的团队增益神术：施术者在太阳升起前后的短暂时间内唱诵特定的颂歌，全队会获得全属性的临时提升。书中指出，颂歌必须在第一缕阳光出现之前开始，否则效果会减半；因此许多牧师会提前守候在高处。作者警告，黎明颂歌不能连续两天对同一支队伍使用，因为人体无法承受两次被"重新擦亮"。抄本最后一页贴着一小片朝霞染过的云絮，附注说这是从一座极高钟楼顶部收集的，云絮在离开原地的第三天化作了一滴水。水滴落下的位置长出了一小片金色的苔藓，附注说那是颂歌效力尚未完全消散的痕迹，踩上去会听见极微弱的合唱。连续使用颂歌的队伍成员，头发会在第七天泛起一缕极淡的金色，数日后才会消退。

## 设计意图

为牧师提供时间窗口型团队增益技能，通过黎明时机的限制与连续使用的惩罚，增强战略规划与角色扮演感。
