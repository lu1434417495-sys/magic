# 《忏悔室手记》

## 书籍内容

忏悔室手记是一位老牧师在多年倾听告解后写下的笔记。作者认为，倾听本身是一种神圣行为，它能让被倾听者从内部开始松动，而不需要施术者急于提供解决方案。书中记录了如何保持沉默、何时该说一句话、以及如何不让自己被他人的重负压垮，强调牧师不是法官也不是治疗师，而是见证者。后半部是一些牧师的实践心得，他们如何在灰烬交界的营地中用类似的方法帮助战友释放战斗带来的恐惧，让队伍在下次战斗前恢复专注。某一页写着："不要急着给答案，先让问题有地方放。"另一处有人画了一只耳朵，旁边写着："听的时候，记得呼吸。"

## 设计意图

提供牧师系基础驱散回蓝技能入口，强化"倾听忏悔"的低阶支援主题。
