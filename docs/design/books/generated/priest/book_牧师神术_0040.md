# 《殉道者遗言》

## 基础信息

- **书籍 ID**：`book_牧师神术_0040`
- **关联技能**：`priest_martyrs_testament`（待新增）
- **使用效果**：阅读后解锁 `priest_martyrs_testament`；若已学会，提升 `current_mastery +90` 并在牧师HP归零时触发一次范围治疗，随后进入濒死状态。
- **阅读要求**：角色职业标签含 `priest` 或 `support`；基础 `意志 ≥ 9`。
- **稀有度**：普通（Common）

## 书籍内容

这本书收集了十二位殉道者在最后时刻说出的话，每一句话都不长，却都被后来的牧师当作最高形式的祈祷。作者指出，殉道者遗言的力量不在于死亡本身，而在于他们选择把最后一口气用在保护他人上。阅读者需要反复诵读这些话，直到能在危急时刻不假思索地念出。书中还提醒，这个技能不能被当作主动求死的借口，因为真正的殉道者从未期待死亡，只是不逃避它。最年轻的一位殉道者只有十七岁，他的遗言是：请替我看看明天的太阳。许多读者在这句话下面留下了自己的批注，有的写着我会的，有的只有一滴已经干涸的水渍。最后一页是一片空白，只写着：这里的空白留给你，当你准备好时，再写下自己的那一句。这本书在神学院里不被鼓励阅读，因为导师们担心年轻学生会把它误解为一种浪漫化的死亡邀请。

## 设计意图

为牧师系提供濒死爆发治疗技能，以殉道者叙事包装，强调牺牲与希望的交替，适合高风险战局的最后救援。
