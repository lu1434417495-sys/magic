# 《叹息之墙》

## 基础信息

- **书籍 ID**：`book_牧师神术_0028`
- **关联技能**：`priest_wall_of_sighs`（待新增）
- **使用效果**：阅读后解锁 `priest_wall_of_sighs`；若已学会，提升 `current_mastery +80` 并在指定方向生成一道低阶光墙，阻挡一次近战冲锋。
- **阅读要求**：角色职业标签含 `priest` 或 `support`；基础 `意志 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：城防训练、撤退掩护任务、中级防御支线。

## 书籍内容

这本书的标题听起来悲伤，内容却很实用。作者把防御墙命名为叹息，是因为墙本身不攻击，只是默默承受，像一声没有喊出口的叹息。墙由无数低声的祷词叠加而成，每一句都是上一个受伤者的名字，所以它的强度取决于施术者记得多少需要保护的人。书中强调墙不能太高太宽，否则会在第一击就崩塌；最好是窄而深的墙，像一把竖起的剑，专门挡在最关键的路径上。最有趣的练习是让学生想象一堵只挡住一扇门的墙，而不是围住整座房子，因为学会放弃才是守护的开始。最后一页有一段烧焦的字迹：我曾用这堵墙挡住了一名骑兵，墙碎的时候我也倒下了，但门后面的人都还活着。这本书在城市守卫牧师中几乎是必修课，因为他们最理解何谓守住一扇门。

## 设计意图

为牧师系提供基础地形/阻挡技能，把防御与记忆主题结合，适合战棋中控制敌人路径与保护后排的战术需求。
