# 《审判之光仪典》

## 基础信息

- **书籍 ID**：`book_牧师神术_0184`
- **关联技能**：`priest_light_of_judgment`（待新增）
- **使用效果**：阅读后解锁 `priest_light_of_judgment`；若已学会，提升 `current_mastery +130` 并对高罪恶值敌人造成额外伤害。
- **阅读要求**：角色职业标签含 `priest` 或 `support`；基础 `意志 ≥ 13`。
- **稀有度**：稀有（Rare）
- **建议投放**：审判庭藏书室、讨伐任务奖励、稀有技能商人。

## 书籍内容

仪典的封面是一本被铁链锁住的书，但锁链已经锈死，无法打开也无法取下。它记载的是一种针对"有罪者"的攻击神术：施术者高举右手，召唤一束垂直落下的强光，目标身上的罪孽越重，受到的伤害越深。书中警告，审判之光对无辜者几乎无效，因此施术者必须先判断目标的罪恶；误判会让光芒在落地前散开，反而暴露施术者的位置。作者附有一份简短的罪恶辨识指南，从眼神、手势到步态，但每一页都被红笔批注"不可尽信"。仪典最后一页贴着一小片被烧焦的法官袍角，附注说这是从一位误判者身上取下的，他的审判之光最终落回了自己头上。袍角背面还留着半枚焦黑的印章，那是他曾经引以为傲的审判官印记，如今只剩轮廓。印章残留的轮廓会在雷雨夜微微发热，仿佛仍在等待一次再也不会到来的开庭。

## 设计意图

为牧师提供条件型单体爆发技能，通过"罪恶判定"机制鼓励玩家识别敌人属性，增强战斗中的目标选择深度。
