# 《启示印记解码》

## 基础信息

- **书籍 ID**：`book_牧师神术_0116`
- **关联技能**：`priest_sigil_of_revelation`（待新增）
- **使用效果**：阅读后解锁 `priest_sigil_of_revelation`；若已学会，提升 `current_mastery +120` 并在下一次战斗中为首回合提供全队侦测隐形能力。
- **阅读要求**：角色职业标签含 `priest`；基础 `智力 ≥ 10`，基础 `意志 ≥ 9`。
- **稀有度**：精良（Uncommon）
- **建议投放**：预言者密室、解谜任务奖励、学者商人。

## 书籍内容

解码书把启示分成三类：来自光的、来自阴影的、来自光的缺席。每一类都对应一组印记，书中要求阅读者先在墙上画出这些印记，再关掉灯，等待眼睛适应黑暗后重新看。作者声称，很多启示只有在看不见的时候才会显现。书中有一段被反复涂改的定义："真相不是被找到的，是被允许进入的。"最后一页贴着一张半透明的薄片，对着光看时能看到一个从未在正文中出现过的复杂符号，旁边写着："如果你现在能看见它，说明它已经看见你很久了。"解码书最后一页是一片被涂黑的方框，附注说只有当你不再寻找答案时，黑色方块里才会出现最后一个印记；很多人把这一页撕掉，结果在三天内失去了夜视能力。方框的边缘有一圈用银粉画的细线，据说是唯一能框住那个印记的东西。

## 设计意图

提供侦察/反隐向牧师技能，扩展牧师在探索和战斗中的信息优势。
