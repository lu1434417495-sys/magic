# 《坚固心灵章》

## 基础信息

- **书籍 ID**：`book_牧师神术_0012`
- **关联技能**：`priest_fortified_mind`（待新增）
- **使用效果**：阅读后解锁 `priest_fortified_mind`；若已学会，提升 `current_mastery +70` 并为自身提供一次低阶精神抵抗。
- **阅读要求**：角色职业标签含 `priest` 或 `support`；基础 `意志 ≥ 7`。
- **稀有度**：普通（Common）
- **建议投放**：修道院静修室、抵抗恐惧训练、低级心灵防御支线。

## 书籍内容

这本书的装订用的是铁环，翻页时会发出清脆的声响，据说是为了让读者在分心时立刻被拉回注意力。内容不讲如何攻击敌人，只讲如何在混乱中守住自己的意志。作者把心灵比作一座城，恐惧是从城门缝隙钻进来的风，而祷文就是关上城门的手。书中提供了七种守城方法，最简单的一种是在心中反复默念一句固定祷词，直到它形成一堵墙。最复杂的一种则需要想象自己站在城墙上，看着恐惧像潮水一样涌来又退去，既不迎战也不逃跑。许多页边有前辈的批注：恐惧本身不伤人，伤人的是你以为恐惧必须消失才能行动。最后一页只有一行加粗的字：城门可以暂时关闭，但不要忘记城墙上还开着一扇小窗。这本书在亡灵出没的地区被大量抄录，因为那里最危险的不是骨爪，而是会让人放弃抵抗的绝望。

## 设计意图

为牧师系提供基础精神抗性技能，帮助神职者在面对亡灵、诅咒与恐惧效果时保持施法能力，强化职业韧性。
