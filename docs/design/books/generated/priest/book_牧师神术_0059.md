# 《苦行绑带用法》

## 书籍内容

苦行绑带用法是一本争议不小的小册，教授如何在衣物内侧缝制粗麻绑带以提醒自己保持警觉。作者坦承，这种方法并非适合所有人，只有真正愿意承受不适的人才能从中获得精神上的锐利，而不是用来表演苦修。书中详细说明了绑带的位置、松紧度以及每日穿戴时间，并警告不可影响行动或造成真正的伤口。后半部是一些修士的体验记录，他们发现这种轻微的持续不适反而帮助自己在灰烬交界的长时间战斗中保持清醒，让疼痛成为专注的锚点。某页边缘写着："痛苦不是目的，清醒才是。"另一处被划掉的句子依稀可辨："如果有人以受苦为荣，他就该脱下绑带，因为他已经迷失了。"书的夹层里还藏着一小段磨旧的麻绳，绳结处留有汗渍与血痕。最后一页贴着一小块粗麻布碎片，纤维里还缠着一根灰色的头发。

## 设计意图

提供牧师系基础自我减伤技能入口，强化"苦行自律"的低阶生存主题。
