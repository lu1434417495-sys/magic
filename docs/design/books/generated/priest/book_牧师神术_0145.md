# 《缚灵咏唱》

## 基础信息

- **书籍 ID**：`book_牧师神术_0145`
- **关联技能**：`priest_chant_of_binding`（待新增）
- **使用效果**：阅读后解锁 `priest_chant_of_binding`；若已学会，提升 `current_mastery +140` 并在下一次战斗中有概率束缚一个灵体/召唤物 1 回合。
- **阅读要求**：角色职业标签含 `priest`；基础 `意志 ≥ 11`，基础 `智力 ≥ 9`。
- **稀有度**：稀有（Rare）
- **建议投放**：缚灵塔、召唤物抑制任务奖励、神秘商人。

## 书籍内容

缚灵咏唱用重复的音节制造一种"声音的笼子"。作者说，灵体不怕刀剑，但害怕被固定在某个节奏里，因为节奏会让它们想起自己曾经拥有过的身体。书中列出了七种缚灵音节，每一种对应一种情绪：愤怒、悲伤、眷恋、悔恨、惊讶、羞耻、疲惫。选择错误的音节会让灵体更强。附页有一段用血写的警告："缚灵之后必须放灵，否则笼子会变成你自己的一部分。"最后一页画着一个被音波包围的影子，影子的轮廓越来越清晰，像是要重新变成人。缚灵咏唱的封底画着一只被音波缠住的小鸟，附注说这是作者第一次缚灵时误伤的生灵；她把它画在这里，提醒自己笼子不是用来装饰天空的，小鸟的眼睛是用墨水点的，却总在夜里反光。

## 设计意图

提供对灵体/召唤物的控制型牧师技能，丰富牧师的反召唤能力。
