# 《庇护微光》

## 基础信息

- **书籍 ID**：`book_牧师神术_0016`
- **关联技能**：`priest_shelter_gleam`（待新增）
- **使用效果**：阅读后解锁 `priest_shelter_gleam`；若已学会，提升 `current_mastery +70` 并为相邻友方提供一次低阶伤害格挡。
- **阅读要求**：角色职业标签含 `priest` 或 `support`；基础 `意志 ≥ 7`。
- **稀有度**：普通（Common）
- **建议投放**：防御训练场、护送任务、低级护卫支线。

## 书籍内容

这本书的封面镶着一圈已经失去光泽的铜片，据说是过去用来反射光线的。书中教的不是实体盾牌，而是一层由意念与祷词共同维持的光膜。作者把庇护术分为三个阶段：凝聚、展开、承受。凝聚时要把注意力收回到胸口，展开时要像展开一块布一样把光覆盖到需要保护的人身上，承受时则必须学会不闭上眼睛。书中警告说，这层光很薄，只能挡下一次攻击，施术者不能因为它存在就放松警惕。最精彩的部分是作者画下的失败案例：一名牧师把光膜铺得太大，结果薄得像纸，被箭矢一穿而过。书页末尾有一段被火燎过的文字：庇护的本质不是替你挡下所有伤害，而是让第一次伤害来得轻一点，让你有时间做出下一步选择。这本书是年轻护卫牧师的入门必读，因为它清楚地告诉他们保护的边界在哪里。

## 设计意图

提供牧师系基础保护/格挡技能，把防御机制与近距离站位结合，鼓励牧师主动贴近前线队友进行战术支援。
