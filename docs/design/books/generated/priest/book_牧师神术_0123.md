# 《坚稳诗篇》

## 基础信息

- **书籍 ID**：`book_牧师神术_0123`
- **关联技能**：`priest_psalm_of_steadfastness`（待新增）
- **使用效果**：阅读后解锁 `priest_psalm_of_steadfastness`；若已学会，提升 `current_mastery +120` 并在下一次战斗中令自身无法被击退一次。
- **阅读要求**：角色职业标签含 `priest`；基础 `体质 ≥ 9`，基础 `意志 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：要塞礼拜堂、守城任务奖励、前线商人。

## 书籍内容

诗篇的每一句都以"我站在这里"开头，但后面的内容各不相同：我站在这里，因为背后有人；我站在这里，因为离开会让伤口更痛；我站在这里，因为逃跑的代价比站立更大。作者说，坚稳不是勇敢，而是把所有不站在这里的理由暂时放在一边。书中要求阅读者用右脚重重踩地三次，同时默念自己最想逃离的一次经历。附页有一段军官的批注："在战场上，这首诗比盾牌更有用，因为盾牌会碎，诗不会。"诗篇的封底用粗线钉着一块从旧盾牌上裁下的铁皮，铁皮上凹痕交错，像是曾被许多把刀同时砍中；附注说这面盾没有挡住任何一击，但持盾者因此多活了七秒，足够队伍撤退。铁皮背面刻着一行小字，记录了持盾者撤退后活到的具体天数。
