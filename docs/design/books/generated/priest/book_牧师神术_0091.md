# 《信标光耀术》

## 基础信息

- **书籍 ID**：`book_牧师神术_0091`
- **关联技能**：`priest_beacon_of_faith`（待新增）

## 书籍内容

信标光耀术教授如何让自己成为战场上可供同伴辨识与凝聚的光点。作者认为，成为信标不是让自己最亮，而是让自己最稳定，让疲惫的人知道该往哪里靠拢，因此稳定的节奏比耀眼的光芒更重要。书中详细描述了调整呼吸以稳定光芒、控制站位以避免吸引过多敌意，以及在被攻击时如何不熄灭光芒，比如把光芒收敛到最小但保持不灭的核。后半部是一些指挥官牧师的记录，他们如何在灰烬交界的混战中用此法重新聚拢被打散的队形，也记录了信标过于显眼而成为敌方弓箭手目标的教训。某一页写着："你不是灯塔，你是火把；火把的任务是让人看见彼此。"另一处有人画了一圈光晕，旁边写着："别跑太快，后面的人跟不上。"书的封面有一道被烧灼后留下的浅色圆环，仿佛曾真的被当作信标使用过。

## 设计意图

提供牧师系中阶团队凝聚技能入口，强化"信标光耀"的士气与集结主题。
