# 《圣光指引手稿》

## 基础信息

- **书籍 ID**：`book_牧师神术_0002`
- **关联技能**：`priest_guiding_light`（待新增）
- **使用效果**：阅读后解锁 `priest_guiding_light`；若已学会，提升 `current_mastery +60` 并在迷雾地图中扩大视野一格。
- **阅读要求**：角色职业标签含 `priest` 或 `support`；基础 `意志 ≥ 6`。

- **建议投放**：新手村礼拜堂、迷雾森林入口、牧师学徒任务。

## 书籍内容

手稿原本是一整卷，因为经常被带进潮湿的洞穴而霉坏，只剩下前半部分还能辨认。作者用大量图示说明如何让指尖凝聚一团不散的光，不是用来照明，而是作为队伍在混乱战场中的方向标记。书中反复强调：这团光必须比周围环境稍暗一点，太亮会吸引敌人，太暗则会被队友忽略。为了训练稳定性，作者建议学徒每天清晨在钟楼阴影里练习，直到能在风声最大的时刻让光点保持静止。手稿中间夹着一张泛黄的地图，上面用光点标注了三个失踪朝圣者的最后位置，备注写着：光会指引愿意跟随的人，但不会代替他们迈步。最后一页被水渍泡得模糊，只能读出一句：当你找不到路时，先成为别人的路标。这本书后来被许多边境哨所的牧师抄录，他们相信即使在最浓重的迷雾里，一束稳定的光也足以让迷途者找到归队的方向，而这点微光往往比任何地图都更可靠。

## 设计意图

为牧师系提供基础团队辅助技能，突出光作为战术标记与方向指引的功能，适合战棋中的视野机制。
