# 《圣物之光图录》

## 基础信息

- **书籍 ID**：`book_牧师神术_0197`
- **关联技能**：`priest_reliquary_light`（待新增）
- **使用效果**：阅读后解锁 `priest_reliquary_light`；若已学会，提升 `current_mastery +120` 并激活一件圣物，临时提升全队对应属性。
- **阅读要求**：角色职业标签含 `priest` 或 `support`；基础 `意志 ≥ 12`。
- **稀有度**：精良（Uncommon）
- **建议投放**：圣物陈列室、考古任务奖励、高级技能商人。

## 书籍内容

图录的每一页都展示着一件破损圣物的素描，旁边标注着它曾被谁佩戴、因何碎裂、以及激活它需要念诵的词语。它记载的是一种以圣物为媒介的团队增益神术：施术者携带或接触一件圣物碎片，通过祈祷短暂唤醒其中的力量，为全队提供与该圣物相关的属性提升。书中说，圣物之光的效果取决于施术者是否尊重圣物的历史，把它当作工具随意使用会导致力量衰退。作者还提醒，同一件圣物每天只能被激活一次，过度唤醒会让碎片彻底化为粉末。图录最后一页贴着一片小小的骨屑，附注说它的来源已不可考，但曾在一次激活时让全队听见了远处传来的钟声。骨屑被装在一个小布袋里，袋子上绣着一个已经被磨得看不清的徽章，附注说这是圣物原主人的家族纹章，如今连名字都已失传。激活圣物时，若念错纹章上的任何一个线条，增益效果会反转为随机减益。

## 设计意图

为牧师提供与装备系统联动的团队增益技能，通过圣物激活机制鼓励玩家收集与尊重背景物品，增强叙事沉浸感。
