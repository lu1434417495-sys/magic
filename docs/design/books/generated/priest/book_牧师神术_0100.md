# 《初光仪式概要》

## 基础信息

- **书籍 ID**：`book_牧师神术_0100`
- **关联技能**：`priest_rite_of_first_light`（待新增）
- **使用效果**：阅读后解锁 `priest_rite_of_first_light`；若已学会，提升 `current_mastery +100` 并在下一次黎明战斗中令全队首次神术效果额外 +1。
- **阅读要求**：角色职业标签含 `priest` 或 `support`；基础 `意志 ≥ 9`，基础 `智力 ≥ 8`。
- **稀有度**：稀有（Rare）
- **建议投放**：黎明大教堂、晨光任务奖励、高级圣所宝箱。

## 书籍内容

初光仪式概要是一本总结如何在黎明时分举行简短祝圣仪式的手册。作者认为，初光是昼夜交替中最脆弱也最纯净的时刻，最适合重新校准队伍与神圣之间的联系，因此仪式必须在日出前开始、日出后结束。书中详细规定了仪式所需的物品、站立方位、祷文顺序以及如何应对灰烬遮挡日出的情况，比如当太阳被灰云遮住时，要以烛火作为初光的替代。后半部是一些高阶牧师的实践记录，他们如何在灰烬交界用这套仪式为整支队伍注入一日的信心，也记录了仪式中断后整日神术不稳的教训。某一页写着："第一缕光不是最强的，但它是最诚实的。"另一处有人画了一个上升的太阳，旁边写着："别急着开始仪式，先让光触到你的额头。"书的封面有一圈被阳光晒褪的颜色，仿佛曾常年被放在窗台迎接黎明。

## 设计意图

提供牧师系高阶环境仪式技能入口，承接后续黎明主题高阶神术，强化"初光仪式"的团队增益主题。
