# 《病患看护录》

## 书籍内容

这本书的每一页都写着不同病人的姓名与症状，像是一本病历，又像是一本日记。作者认为看护的本质不是治愈，而是陪伴病人度过身体最脆弱的时期。书中详细记录了如何换药、如何调整姿势、如何在病人说胡话时保持冷静，以及如何在深夜判断一次高烧是否危险。最让作者费心的是关于喂食的章节：病人吃不下时不要强迫，但要保证他们醒来时第一口能喝到温水。书的中间部分有一段关于牧师自身防护的提醒：你若倒下，病人会失去最后的依靠，所以请先洗手，先休息，先吃饭。最后一页贴着一张褪色的便条，上面是一位病人写的：谢谢你没在我叫喊时走开。这句话下面被后来的读者重重地划了线。对于经常面对瘟疫与诅咒的牧师来说，这本书比许多高级祷文集都更珍贵，因为它教的是如何不让自己也变成需要被照顾的人。

## 设计意图

为牧师系提供基础异常状态护理技能，把治疗扩展到持续照护层面，适合处理中毒、疾病等时间型减益效果。
