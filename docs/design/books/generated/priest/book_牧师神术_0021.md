# 《护盾祷文》

## 基础信息

- **书籍 ID**：`book_牧师神术_0021`
- **关联技能**：`priest_shield_prayer`（待新增）
- **使用效果**：阅读后解锁 `priest_shield_prayer`；若已学会，提升 `current_mastery +80` 并为一名友方施加一个可吸收少量伤害的光盾，持续两回合。
- **阅读要求**：角色职业标签含 `priest` 或 `support`；基础 `意志 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：防御训练场、护送任务、中级牧师导师。

## 书籍内容

祷文被刻在一块薄薄的铜板上，边缘已经被无数次触摸磨得发亮。全文只有四十九个字，但作者用了十八页来解释每一个字的发音与停顿。最关键的字是承，作者说它既是承受的承，也是承认的承，施术者必须先承认伤害可能发生，盾才不会在接触攻击时碎裂。书中还要求施术者在结盾时想象一面圆形的小盾，不能太大，因为过大的盾会消耗过多意志，也不能有尖角，因为尖角会把攻击导向旁边的人。练习的方法很朴素：先替一只母鸡护盾，再替一个奔跑的孩子护盾，最后才能在战场上为战友护盾。铜板背面刻着一行小字：最好的盾不是让攻击消失，而是让被保护的人有时间低下头。这本祷文在防御型牧师中代代相传，因为它把护盾从一种消耗品变成了一种承诺。

## 设计意图

为牧师系提供基础护盾技能，把防护量与施术者意志挂钩，强调提前布防与目标选择，适合战棋中的前置保护策略。
