# 《日爆祈祷残页》

## 书籍内容

残页薄如蝉翼，对着光看能看见里面嵌着无数细小的金箔碎片，像是被压缩进纸里的阳光。它记载的是一种需要直面太阳完成准备的大范围攻击神术：施术者在日出时张开双臂，让阳光穿透自己的胸口，把那份灼热封存为祷词。书中警告，阴天无法施展，因为日爆祈祷借用的不是信仰之光，而是真正的恒星之力；若在夜晚强行使用，会从自身抽取生命力作为替代。作者附有一张手绘的日晷图，标注着一年中八个适合施术的日子。残页边缘有一处焦黑的指印，附注说这是抄写者最后一次验证祷文时留下的，他的右手自此失去了指纹。残页背面还用极淡的金粉画着一个太阳的轮廓，只有在完全黑暗处才能看见，像是某种只向失明者展示的秘密。据说曾在日全食时阅读此残页的人，会在接下来三天内梦见自己站在太阳表面，脚下是无数燃烧的面孔。

## 设计意图

为牧师提供环境依赖型范围输出技能，通过"晴天/夜晚"的差异效果，增强战棋中的时机选择与战术深度。
