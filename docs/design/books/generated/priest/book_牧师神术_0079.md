# 《静默进食仪》

## 基础信息

- **书籍 ID**：`book_牧师神术_0079`
- **关联技能**：`priest_silent_meal`（待新增）
- **使用效果**：阅读后解锁 `priest_silent_meal`；若已学会，提升 `current_mastery +80` 并在下一次进食休息时令全队额外恢复少量士气与 `current_hp`。
- **阅读要求**：角色职业标签含 `priest` 或 `support`；基础 `意志 ≥ 8`。
- **稀有度**：精良（Uncommon）
- **建议投放**：静食堂、后勤任务奖励、中级营地宝箱。

## 书籍内容

静默进食仪主张在用餐时保持安静，以此让食物与精神同时被消化。作者认为，边吃边说话会让身体与心灵都错过滋养的机会，因为言语会分散对味道的感知。书中规定了进食前的祝谢手势、咀嚼次数的建议以及餐后沉默的时长，并提醒不要在愤怒或焦虑中进食。后半部是一些随军牧师的记录，他们如何在灰烬交界的艰苦行军中用此法维持队伍的凝聚力，让一顿饭成为短暂的休战与修复。某一页写着："一起吃过面包的人，不容易互相背叛。"另一处有人画了一张长桌，旁边写着："让最饿的人先吃，而不是让地位最高的人先吃。"书的某一页还粘着一粒风干的黑麦，仿佛某位饥饿的读者在沉默中把它当作了书签。书的某一页角还沾着一点面包屑，像某位饥饿的读者在沉默中留下的唯一声音。

## 设计意图

提供牧师系中阶休息增益技能入口，强化"静默滋养"的团队恢复主题。
