# 《制裁之光》

## 书籍内容

制裁之光是一种后发制人的神术，它不主动寻找敌人，而是回应伤害。作者把它比作一面延迟反弹的镜子：敌人先动手，光才降临。施术者必须在心中保持清醒的记录，知道谁伤害了谁，不能因为愤怒而误判目标。书中强调，这个术对误伤无效，对自卫无效，只对主动的攻击意图有效，所以它要求牧师在混乱中仍然能分辨动机。练习时要在两名同伴模拟的对战中判断谁是真正的攻击者，准确率必须超过八成才能实战使用。最后一页贴着一张被箭矢射穿的布片，附注说：这块布来自一名盾卫的披风，他替队友挡下箭后，我立刻对他施加了制裁之光，那名射箭的强盗还没来得及放下弓就倒在了光里。这本书让牧师第一次拥有了明确的以牙还牙能力，但也让他们背负了判断对错的重量。这正是制裁之光与其他攻击神术最大的不同。

## 设计意图

为牧师系提供反击型神圣伤害技能，强化保护后的即时回报，鼓励玩家主动保护队友并抓住反击窗口。
