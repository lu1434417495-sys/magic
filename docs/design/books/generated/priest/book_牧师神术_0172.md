# 《归返印记拓本》

## 基础信息

- **书籍 ID**：`book_牧师神术_0172`
- **关联技能**：`priest_sigil_of_return`（待新增）
- **使用效果**：阅读后解锁 `priest_sigil_of_return`；若已学会，提升 `current_mastery +110` 并为单个友方标记归返点，濒死时自动传送回安全位置。
- **阅读要求**：角色职业标签含 `priest` 或 `support`；基础 `意志 ≥ 12`。
- **稀有度**：精良（Uncommon）
- **建议投放**：传送神殿、救援任务奖励、高级技能商人。

## 书籍内容

拓本的纸页上印着同一个符号的无数变体，从稚拙的草稿到精细的成品，像是某个人穷尽一生研究如何画出一个完美的归返印记。它教授的是一种预防性保护神术：施术者在同伴身上或某件随身物品上绘制一个小型印记，当携带者的生命降到危险线以下时，印记会自动激活，将其传送到预先设定的安全点。书中强调，安全点必须是施术者曾经跪下来祈祷过的地方，否则归返会变成迷失。作者还提醒，印记只能使用一次，之后需要从施术者的一段记忆中提取能量重新充能。拓本最后一页贴着一张褪色的地图，上面用红笔标出了三个坐标，却没有任何地名。地图背面有一行潦草的字迹，警告说第四个坐标绝对不能使用，因为那个安全点在一场大火后已经变成了一片只会接收、不会归还的黑暗。有人曾在第四个坐标处捡到一本相同的拓本，只是所有印记都已变成了 outbound 的方向。

## 设计意图

为牧师提供保命型传送技能，通过"预设安全点"与"记忆充能"机制增加策略准备感与情感投入。
