# 《行军祝福卷》

## 基础信息

- **书籍 ID**：`book_牧师神术_0014`
- **关联技能**：`priest_march_blessing`（待新增）
- **使用效果**：阅读后解锁 `priest_march_blessing`；若已学会，提升 `current_mastery +70` 并在队伍移动时降低疲劳累积速度。
- **阅读要求**：角色职业标签含 `priest` 或 `support`；基础 `意志 ≥ 7`。
- **稀有度**：普通（Common）
- **建议投放**：远征任务、商队护送、低级野外行军支线。

## 书籍内容

卷轴被设计成可以绑在脚踝或手腕上的细长形状，方便行军中随时展开阅读。书中教的祝福术不需要跪坐，甚至可以在走路时完成，秘诀是把祷词拆成四个短句，分别配合左右脚的步伐。作者认为行军中的祝福重点不是力量的大小，而是持续性，因为长途跋涉消磨的往往不是身体，而是愿意继续走的意志。书中有一段关于鞋底磨损的记录：如果祝福生效，鞋底会先磨平而不是开裂，因为走路的人步伐会变得均匀。卷轴末尾画着一支简单的歌谣，曲调已经失传，但歌词仍可念诵，内容是关于如何让沉重的腿记住自己曾经轻快过的感觉。最后有人用铅笔补了一句：祝福不能替你走完剩下的路，但能让你觉得每一步都还算值得。这本卷轴在商队中极为抢手，因为长途 traders 愿意为任何能让旅程轻松一点的文字支付额外费用。

## 设计意图

提供牧师系基础移动/耐力辅助技能，适合大世界探索与长距离战斗，强化牧师作为队伍续航核心的前期定位。
