# 《缄口令》

## 基础信息

- **书籍 ID**：`book_牧师神术_0095`
- **关联技能**：`priest_pledge_of_silence`（待新增）
- **使用效果**：阅读后解锁 `priest_pledge_of_silence`；若已学会，提升 `current_mastery +80` 并在下一次战斗中令首次进入缄默状态时，下一次神术效果额外 +1。
- **阅读要求**：角色职业标签含 `priest`；基础 `意志 ≥ 9`。
- **稀有度**：精良（Uncommon）
- **建议投放**：静默修道院、缄默任务奖励、中级禁欲商人。

## 书籍内容

缄口令是一本关于如何在战斗中主动保持沉默以增强下一次神术效果的小册。作者认为，言语是一种消耗，暂时收起言语可以让力量集中，但真正的难点在于沉默期间仍然保持对战局的参与。书中教授如何用手势和眼神与同伴沟通、如何在缄默期间维持对战局的判断，以及何时该打破沉默，避免因为固执于沉默而错过关键指令。后半部是一些苦修战士牧师的记录，他们如何在灰烬交界的伏击中用此法积攒力量，在关键时刻发出决定性的一击，也记录了有人因沉默太久而忘记如何开口的轶事。某一页写着："沉默不是空白，是把声音存进银行。"另一处有人画了一张闭着的嘴，旁边写着："说得越少，下一次说得越重。"

## 设计意图

提供牧师系中阶蓄力爆发技能入口，强化"缄默积蓄"的纪律与爆发主题。
