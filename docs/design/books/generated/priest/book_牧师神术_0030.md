# 《赦免初仪》

## 基础信息

- **书籍 ID**：`book_牧师神术_0030`
- **关联技能**：`priest_rite_of_absolution`（待新增）
- **使用效果**：阅读后解锁 `priest_rite_of_absolution`；若已学会，提升 `current_mastery +80` 并移除一名友方身上的罪咎标记，防止其被神圣伤害类敌人锁定。
- **阅读要求**：角色职业标签含 `priest` 或 `support`；基础 `意志 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：告解室、审判庭后续任务、中级伦理支线。

## 书籍内容

这本书的封面没有装饰，只有一道浅浅的折痕，像是被人反复合上又打开。内容围绕着一个简单的仪式：听对方说完、承认伤害的存在、说出一句赦免、让对方离开。作者强调赦免不是否认错误，而是不再让错误决定一个人未来的全部。书中警告施术者不要急于说出那句我原谅你，必须先听完，否则赦免会变成另一种压迫。最复杂的一章讨论如何赦免那些没有道歉的人：不是替他们开脱，而是决定自己不再背负他们的重量。最后一页贴着一张被撕碎的纸条，后来被人用胶带小心拼回，上面写着：谢谢你没问我值不值得，只是让我走了出去。旁边有作者的评语：这就是初仪的全部意义。在某些严格的教会分支中，这本书被列为禁书，因为它把赦免的权力交到了每一个凡人手中。但那些真正使用过它的人，都知道它的分量。

## 设计意图

为牧师系提供基础状态解除与叙事型技能，把赦免机制与神圣伤害敌人的目标逻辑结合，丰富牧师的社会与战斗角色。
