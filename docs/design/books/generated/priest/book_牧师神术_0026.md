# 《守望者之眼》

## 书籍内容

书中把守望者的眼睛比作一盏不会熄灭的灯，但作者立刻补充说，这盏灯照见的往往不是敌人，而是危险本身。技能的核心是在短时间内让视觉从看东西转为看关系：哪里不应该有影子却有影子，哪里不应该有风却在动，哪里的温度比周围低半度。书中提供了许多练习方法，比如在人群中找出那个最不自在的人，在树林里找出最先停止鸣叫的鸟。最难的是学会不眨眼，因为眨眼会让注意力重新开始凝聚。书的后半部分被某位边境牧师批注得密密麻麻，其中一条写道：真正的守望者不是最先发现敌人的人，而是最先发现同伴疲惫的人。最后一页画着一只睁开的眼睛，瞳孔里不是倒影，而是一小团稳定的光。在盗贼与刺客横行的地区，这本书是牧师唯一能提前发现威胁的手段。这正是守望者之眼最珍贵的价值。

## 设计意图

为牧师系提供基础侦察与反隐技能，通过视觉训练包装，让神职者在战棋中承担情报与预警角色。
