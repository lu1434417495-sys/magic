# 《光之路径》

## 基础信息

- **书籍 ID**：`book_牧师神术_0146`
- **关联技能**：`priest_luminous_path`（待新增）
- **使用效果**：阅读后解锁 `priest_luminous_path`；若已学会，提升 `current_mastery +120` 并在下一次战斗中令自身及相邻队友移动时不触发借机攻击一次。
- **阅读要求**：角色职业标签含 `priest`；基础 `意志 ≥ 10`，基础 `敏捷 ≥ 8`。
- **稀有度**：精良（Uncommon）
- **建议投放**：光之路祭坛、护送撤离任务奖励、游商货物。

## 书籍内容

光之路径不是地图，而是一种走路的方式。作者说，每个人脚下都有一条只有他自己能看见的光带，但那光带只有在不回头的情况下才会出现。书中要求阅读者先在黑暗房间里练习直线行走，用心感受脚尖前方那一点微弱的拉力。如果开始害怕，光会立刻消失；如果开始得意，光会变硬，把人绊倒。最后一页有一段前任读者的批注："我曾在战场上用这条路径救出三个人，但第四次我回头看了一眼，光就把我留在了原地。"光之路径的最后一页是一张只有起点的地图，终点处画着一个问号，附注写着："如果你知道终点，光就不会出现。"地图的纸很薄，背面能透出下一页的内容，但下一页是空白的。地图空白处有几滴墨水，形成了一个没有被命名的小岛。

## 设计意图

提供机动/撤离型牧师技能，用"光之路径"增强牧师在战场的位移价值。
