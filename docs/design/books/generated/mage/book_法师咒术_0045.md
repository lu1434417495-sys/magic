# 《风切：把空气磨成刀片》

## 基础信息

- **书籍 ID**：`book_法师咒术_0045`
- **关联技能**：`mage_air_blade`
- **使用效果**：阅读后解锁 `mage_air_blade`；若已学会，提升 `current_mastery +100`，并在下一次战斗中使风切对无护甲目标伤害提升 20%。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 10`。

- **建议投放**：风元素祭坛、悬崖训练场、游侠法师营地。

## 书籍内容

风切是一种把高速气流压缩成薄刃后释放的远程攻击咒术，它不像火球那样有华丽的爆炸，但胜在速度快、轨迹直、难以被普通盾牌完全挡住。这本书的作者是一个在海边长大的法师，他说风切的声音就像渔民收网时绳索划破空气的声音。

前半部分讲解如何在掌心制造两股方向相反的气流，并让它们在离开手掌的瞬间叠加成锋利的风刃。后半部分讨论目标选择：风切对轻甲和无甲敌人效果最佳，对重甲敌人则容易被弹开。书中还提到，在封闭空间使用风切时要小心反弹，因为风刃会在墙壁上折射。最后一页是一张被整齐切开的羊皮纸，切口薄得几乎看不见。

作者还提醒施术者注意风向，顺风释放时风切射程更远，逆风则可能需要额外魔力维持风刃的稳定形态。书中附录记录了几种专门用于训练风切准度的稻草人制作法，强调目标必须足够轻才能被风刃切开。

## 设计意图

为法师系提供早期风系远程输出技能，强化单体打击与护甲穿透维度，同时为后续龙卷风、空气切割类高级风系法术建立熟练度链条。
