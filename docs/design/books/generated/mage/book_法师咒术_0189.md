# 《虚空收割的镰刀保养》

## 基础信息

- **书籍 ID**：`book_法师咒术_0189`
- **关联技能**：`mage_void_harvest`
- **使用效果**：阅读后解锁 `mage_void_harvest`；若已学会，提升 `current_mastery +190` 并在下一次战斗中使虚空收割首次击杀时刷新施法者一个随机低阶法术冷却。
- **阅读要求**：角色职业标签含 `mage` 或 `reaper`；基础 `智力 ≥ 19` 且 `意志 ≥ 16`。
- **稀有度**：传说（Legendary）
- **建议投放**：虚空农场、星界收割站、死神学徒营地。

## 书籍内容

虚空收割是一种用虚空物质凝聚的镰刀进行攻击的技艺，能够切断目标与现实的联系。本书从镰刀保养开始，讲解如何用星尘擦拭刀刃，以及如何在每次收割后清理附着在刃上的情绪残渣。作者强调，虚空镰刀不需要磨利，反而会因为太锋利而伤及使用者，关键在于保持刀刃与现实之间的微妙距离。书中记录了不同收割对象产生的回响：收割植物会得到宁静，收割野兽会得到警惕，而收割智慧生物则会留下长久的低语。最末一章讨论如何抵御这些回响，避免被它们侵蚀意志。批注写道：收割不是杀戮，而是把存在从一端移到另一端。练习者需要先收割无生命的虚空碎片，熟悉镰刀的重量与弧度。这门技艺在连续作战中具有强大的滚雪球潜力。

虚空镰刀在月光下几乎不可见，只有在挥动时才会撕裂出一道比夜色更深的细线。

## 设计意图

为虚空法师提供击杀刷新机制，将收割意象与连续输出结合。
