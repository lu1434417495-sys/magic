# 《苦根咒：从植物里借来的痛》

## 基础信息

- **书籍 ID**：`book_法师咒术_0021`
- **关联技能**：`mage_bitter_root`
- **使用效果**：阅读后解锁 `mage_bitter_root`；若已学会，提升 `current_mastery +90`，并在下一次战斗中使苦根咒的减速效果延长 1 回合。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：草药师小屋、被诅咒的植物园、德鲁伊遗迹书架。

## 书籍内容

苦根咒是一种把植物的苦味转化为精神打击的低阶咒术。施术者不需要真的拥有一株苦草，只需要让目标感受到那种突如其来的、来自舌根深处的苦涩，就足以让对方在瞬间失神。这本书的作者显然尝过很多种苦味，书中对各种植物的苦涩程度进行了详尽评级。

前半部分教读者如何把自己的魔力"调频"到接近某种苦味植物的精神印记。后半部分讲解战术应用：在敌人即将发动强力攻击时释放苦根咒，可以让对方因为突如其来的恶心而动作变形。书中警告，这个咒语对味觉已经退化的亡灵效果很差，但对养尊处优的贵族法师往往有奇效。最后附有一张被苦汁染黄的清单，列出了三十七种可用的苦味来源。

作者在附录中列出了几种适合初学者培育的苦味植物，强调只有亲手种植过，才能真正理解苦根咒中那股令人皱眉的力量来源。

## 设计意图

为法师系提供早期非致命控制手段，拓展咒术与自然环境互动的维度，同时为后续毒素系、植物系与精神干扰类法术建立叙事与熟练度连接。
