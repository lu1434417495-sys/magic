# 《潮汐 surge：洪流冲击》

## 基础信息

- **书籍 ID**：`book_法师咒术_0244`
- **关联技能**：`mage_tidal_surge`
- **使用效果**：阅读后解锁 `mage_tidal_surge`；若已学会，提升 `current_mastery +160` 并在下一次战斗中使首次潮汐 surge 命中时击退目标两格。
- **阅读要求**：角色职业标签含 `mage` 或 `elementalist`；基础 `智力 ≥ 14` 且 `体质 ≥ 11`。
- **稀有度**：史诗（Epic）
- **建议投放**：深海神殿、潮汐祭坛、水元素领主宫殿。

## 书籍内容

潮汐 surge 是召唤一股巨浪向前冲击的法术，能把敌人冲倒并推向远处。书中强调，这股力量不是来自施法者，而是来自月亮与海洋之间古老的约定。作者把施法比作拉弓：施法者只是拉开潮汐的弦，真正的力量来自潮水的回弹。练习者需要先学会感受远处水域的起伏，才能在远离海洋的地方也召唤出有效的 surge。后半部讲解了如何让潮汐 surge 与地形互动，例如在狭窄通道中形成高压水刀，或在开阔地带制造大面积滑倒区域。最末页是一张被海水泡皱的海图，标注着几处据说能听见潮汐低语的地点。许多水法师在施法时会不自觉地跟随浪的节奏呼吸。书中还提醒，潮汐 surge 在退潮期威力减半，因此观潮表是水法师背包里的常备工具。

## 设计意图

提供强力直线击退与地形互动，让法师能破坏敌方阵型，增强水系法术的控制表现力。
