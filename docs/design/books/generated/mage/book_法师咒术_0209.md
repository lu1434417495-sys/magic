# 《闪电罗网：天罚细丝》

## 基础信息

- **书籍 ID**：`book_法师咒术_0209`
- **关联技能**：`mage_lightning_web`
- **使用效果**：阅读后解锁 `mage_lightning_web`；若已学会，提升 `current_mastery +160` 并在下一次战斗中使闪电罗网首次命中额外麻痹目标一回合。
- **阅读要求**：角色职业标签含 `mage` 或 `stormcaller`；基础 `智力 ≥ 14` 且 `敏捷 ≥ 11`。
- **稀有度**：史诗（Epic）
- **建议投放**：风暴祭坛、云端城废墟、雷霆王座。

## 书籍内容

闪电罗网是将数道电弧编织成细密的电网，从天而降罩住一片区域。书中强调，罗网的关键不是电压，而是如何让电弧在命中目标后仍保持连接。作者把编织过程比作纺纱，每一根电丝都要与相邻的电丝保持相同的节奏，否则整张网会提前消散。练习者需要在雷雨夜用铜针引出闪电，反复尝试把电弧弯成稳定的环。后半部讲解了如何在罗网中加入追踪符文，让电网能跟随移动目标漂移数秒。最末页只有一行被电击得焦黑的字迹：天罚不是审判，而是接线。许多风暴法师会在战斗前先把罗网预存在云层中，等敌人进入范围再瞬间落下。书中还提醒，编织罗网时若哼唱古老雷歌，可让电弧更听话，不易反噬施法者。最资深的雷法师能在罗网落下前，从空气中闻到臭氧的味道。雷雨季节里，闪电罗网的成功率几乎翻倍，因为天空本身就在帮忙。

## 设计意图

结合范围控制与输出，让雷系法术成为团队集火的发起者，提升战棋协同深度。
