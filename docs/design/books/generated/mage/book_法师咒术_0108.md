# 《灵魂碎片的契约语法》

## 基础信息

- **书籍 ID**：`book_法师咒术_0108`
- **关联技能**：`mage_soul_fragment`
- **使用效果**：阅读后解锁 `mage_soul_fragment`；若已学会，提升 `current_mastery +160` 并在下一次战斗中使首个灵魂碎片造成的伤害转化为 10% 生命恢复。
- **阅读要求**：角色职业标签含 `mage` 或 `warlock`；基础 `智力 ≥ 17` 且 `意志 ≥ 14`。
- **稀有度**：史诗（Epic）
- **建议投放**：灵魂商人黑市、亡灵学者密室、深渊裂隙奖励。

## 书籍内容

灵魂碎片不是完整的灵魂，而是强烈情绪留下的结晶。本书从契约语法入手，教导施法者如何用准确的代词、时态与条件句去约束这些碎片。作者指出，最常见的错误是使用祈使句，这会让碎片误以为自己是主人。正确的契约应该像一份精密的租赁合同，明确借用时间、用途与归还方式。书中列举了七种碎片类型：悔恨、执念、恐惧、狂喜、眷恋、愤怒、空洞，每种对应的语法结尾都不相同。作者还附上一份免责声明：与碎片交易会让施法者的记忆出现细小缺口，建议每月做一次记忆清点。最末一页用红墨水写着：当你能平静地写下自己的条款时，碎片才会认真听你说话。签订契约时，环境必须足够安静，任何突如其来的声响都可能被碎片理解为新的条件，从而改变整个契约的效力。

## 设计意图

为术士与暗法师提供资源循环与生命恢复机制，同时深化世界观中灵魂交易的危险性。
