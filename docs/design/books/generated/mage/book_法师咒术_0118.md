# 《冰封王座的铭刻学》

## 基础信息

- **书籍 ID**：`book_法师咒术_0118`
- **关联技能**：`mage_ice_throne`
- **使用效果**：阅读后解锁 `mage_ice_throne`；若已学会，提升 `current_mastery +180` 并在下一次战斗中使王座存在期间冰系法术伤害提高 10%。
- **阅读要求**：角色职业标签含 `mage` 或 `cryomancer`；基础 `智力 ≥ 18` 且 `体质 ≥ 13`。
- **稀有度**：史诗（Epic）
- **建议投放**：北境王座遗迹、冰霜龙穴、元素高塔冰狱区。

## 书籍内容

冰封王座不是宝座，而是一种以极寒为媒介的施法平台。本书教授如何在战场上快速铭刻王座符文，将一片区域改造成冰霜领域的核心。铭刻需要三种材料：干净的冰晶、施法者的血液以及一句不能中断的咒语。作者强调，王座的稳定性取决于铭刻者的意志，任何动摇都会让王座从内部崩裂。书中收录了五种王座造型，分别对应防护、增幅、控制、召唤与毁灭五种倾向。第二章讨论王座与周围环境的互动：在高温地形铭刻会消耗更多魔力，在雪地则能获得自然加成。最末一页的插图是一座由冰雕成的王座，座位上积满了雪，批注写道：坐上它的人不是国王，而是寒意的翻译者。铭刻王座时，施法者的体温会显著下降，因此需要提前服用驱寒药剂或让队友准备保暖咒文。王座崩塌时的碎片同样锋利，不可轻视。

## 设计意图

为冰系专精法师提供领域型增益与战术据点，强化阵地战中的控场与输出节奏。
