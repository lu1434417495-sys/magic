# 《灰烬纹章的绘制》

## 基础信息

- **书籍 ID**：`book_法师咒术_0171`
- **关联技能**：`mage_ash_sigil`
- **使用效果**：阅读后解锁 `mage_ash_sigil`；若已学会，提升 `current_mastery +170` 并在下一次战斗中使灰烬纹章首次触发时为全队提供 10% 火焰伤害加成 2 回合。
- **阅读要求**：角色职业标签含 `mage` 或 `ash_mage`；基础 `智力 ≥ 17` 且 `冥想 ≥ 4`。
- **稀有度**：史诗（Epic）
- **建议投放**：灰烬交界集市、燃烧教堂、余烬学者帐篷。

## 书籍内容

灰烬纹章是一种用冷却后的余烬绘制的临时符文，能在短时间内增强火焰相关法术。本书从收集灰烬开始，讲解如何辨别不同燃烧物留下的灰烬特性：木材灰稳定，骨灰持久，而魔法生物的灰烬则带有特殊效果。作者强调，绘制时手指必须保持干燥，任何汗水都会让纹章提前失效。书中记录了十二种基础纹章图案，每种对应不同的增益方向。第二章讨论纹章的激活方式，有的需要念咒，有的只需踩踏，还有的会在周围出现火焰时自动亮起。最末一页写着：灰烬是火焰的字迹，纹章是它的语法。练习者需要学会用手指感受灰烬的温度，在最合适的时刻完成最后一笔。这门技艺在团队火法配置中能提供显著增益。

灰烬纹章在雨天效果会减半，因此沙漠与废墟才是它真正的舞台。

## 设计意图

为灰烬交界法师提供团队增益符文，强化火焰协同与异界纹章文化。
