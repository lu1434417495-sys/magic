# 《水晶思维的切割法》

## 基础信息

- **书籍 ID**：`book_法师咒术_0112`
- **关联技能**：`mage_crystal_mind`
- **使用效果**：阅读后解锁 `mage_crystal_mind`；若已学会，提升 `current_mastery +170` 并在下一次战斗中使首个精神类减益持续时间缩短 1 回合。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 17` 且 `意志 ≥ 15`。
- **稀有度**：史诗（Epic）
- **建议投放**：水晶高塔、思维训练密室、古代灵能者遗迹。

## 书籍内容

法师的头脑常年被大量咒语与知识占据，水晶思维则教会施法者如何把意识切割成多个独立切面。本书第一章让练习者想象自己的思维是一块六角水晶，每个切面负责一种法术或一种感官。切割的关键在于切面之间不能互相渗漏，否则会造成记忆混淆。作者提供了十二种标准切法，从最简单的双切到复杂的多层嵌套。书中警告，过度切割会让施法者产生短暂的人格错位，因此每次训练后都需要进行一次完整的意识整合。第二章讲解如何在战斗中快速切换切面，以应对不同属性的敌人。最末一章附有一张自测表，用来判断当前思维是否出现裂纹。作者写道：锋利不是水晶的缺陷，而是它保护自己的方式。初学者常因切面过多而在训练后忘记自己的出生年月，因此书中建议从双切开始，逐步增加复杂度。

## 设计意图

为高智力法师提供精神抗性与多线程施法支持，拓展后期法师对控制与干扰的应对能力。
