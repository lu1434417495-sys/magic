# 《骨鸣：唤醒死亡遗骸的低语》

## 基础信息

- **书籍 ID**：`book_法师咒术_0046`
- **关联技能**：`mage_bone_rattle`
- **使用效果**：阅读后解锁 `mage_bone_rattle`；若已学会，提升 `current_mastery +100`，并在下一次战斗中使骨鸣首次命中时恐惧目标 1 回合。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 10`。
- **稀有度**：普通（Common）
- **建议投放**：墓地守夜人小屋、死灵法师学徒书架、战场收尸人营地。

## 书籍内容

骨鸣是一种让周围遗骸发出刺耳共鸣的精神咒术，这种声音活人听不到，但会对亡灵和意志薄弱者造成强烈的精神冲击。这本书的作者显然对死亡有着职业化的冷静，书中没有任何恐怖故事，只有大量关于骨骼共振频率的实验数据。前半部分教读者如何让魔力以正确的频率震动，从而引发骨骼的本能恐惧。

后半部分讨论战术应用：骨鸣对付低阶亡灵尤其有效，有时甚至能让它们短暂逃离战场；对活人则主要起到扰乱和威慑作用。书中警告，长期练习骨鸣会让施术者开始对死亡产生一种不自然的亲近感，因此作者建议每练习一周后都要去活人聚集的地方待上一整天。最后一页是一张画着指骨的图，旁边标注着最佳共振点。

书中提到，骨鸣对新鲜骨骼和古老化石的反应不同，新鲜骨骼共鸣更尖锐，古老骨骼则会产生低沉悠长的回响。

## 设计意图

为法师系提供早期亡灵特化控制技能，拓展对抗不死生物的手段，同时为后续死灵系、恐惧系与灵魂沟通类法术建立叙事与熟练度连接。
