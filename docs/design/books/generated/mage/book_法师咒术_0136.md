# 《血魔法导论的献血须知》

## 基础信息

- **书籍 ID**：`book_法师咒术_0136`
- **关联技能**：`mage_blood_magic`
- **使用效果**：阅读后解锁 `mage_blood_magic`；若已学会，提升 `current_mastery +180` 并在下一次战斗中使首个血魔法法术的伤害随当前生命比例额外提高 8%。
- **阅读要求**：角色职业标签含 `mage` 或 `warlock`；基础 `智力 ≥ 18` 且 `体质 ≥ 12`。
- **稀有度**：史诗（Epic）
- **建议投放**：血法师密室、禁忌医院、黑市血魔法商人。

## 书籍内容

血魔法不是邪恶，而是一种直接用生命换取力量的古老技艺。本书从献血须知开始，强调必须使用自己的血液，借用他人血液会让咒语带上原主人的记忆，最终反噬施法者。作者详细介绍了采血部位的选择：指尖适合快速小法术，手腕适合中等咒语，舌尖则是爆发性法术的首选。书中警告，失血过多会导致施法者进入虚假的亢奋状态，此时释放的血魔法往往失控。第二章讨论如何在战斗中安全采血，比如提前在手臂上刻画微型伤口，或在队友掩护下使用储血瓶。作者还附上一份禁忌清单，包括不得在月蚀时献祭、不得用血书写真名等。最末一页用暗红色写着：血会记得一切，包括你的贪心。书中还附有一份自我输血训练法，帮助施法者在不伤害自身的前提下控制出血量。作者强调，血魔法师最大的敌人不是敌人，而是自己对力量的渴望。

## 设计意图

为暗法师提供高风险高回报的生命转化机制，强化玻璃大炮与自残输出风格。
