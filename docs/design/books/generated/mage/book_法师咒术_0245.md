# 《彗星召唤：天外来客》

## 基础信息

- **书籍 ID**：`book_法师咒术_0245`
- **关联技能**：`mage_comet_call`
- **使用效果**：阅读后解锁 `mage_comet_call`；若已学会，提升 `current_mastery +170` 并在下一次战斗中使首次彗星召唤落地时产生范围眩晕。
- **阅读要求**：角色职业标签含 `mage` 或 `astromancer`；基础 `智力 ≥ 16` 且 `感知 ≥ 13`。
- **稀有度**：史诗（Epic）
- **建议投放**：观星台顶端、流星雨祭坛、星界法师塔。

## 书籍内容

彗星召唤是向天空发出呼唤，让一颗燃烧的流星坠向指定位置的法术。书中把彗星比作天空寄来的信，施法者需要准确说出收件地址。作者强调，召唤彗星不是创造，而是请求：你要让天空相信，坠落是值得的。练习者需要先在星图中找到自己信任的彗星，并记住它的运行周期，否则呼唤来的可能只是普通的陨石。后半部讲解了如何控制坠落角度，让彗星在落地后继续向前滚动，形成一条燃烧的轨迹。最末页是一段被烧焦的观星记录，旁边写着：我召唤了它，但它选择了落点。许多星术师认为彗星有自己的脾气。书中还提醒，彗星召唤需要开阔的天空，在室内或地底施展时只能召唤出较小的陨星，威力大打折扣。彗星坠落的轰鸣声能传到数里之外，因此也常用于宣告战役的开始。守军听到这声音时，往往意味着敌人的总攻已经到来。

## 设计意图

提供延迟高伤害范围控制，让法师能预判战场并制造关键回合的爆发点。
