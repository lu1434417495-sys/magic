# 《雷霆审判的瞄准礼仪》

- **书籍 ID**：`book_法师咒术_0133`
- **关联技能**：`mage_thunder_judgment`
- **使用效果**：阅读后解锁 `mage_thunder_judgment`；若已学会，提升 `current_mastery +180` 并在下一次战斗中使雷霆审判首次命中弱点时伤害提高 15%。

## 书籍内容

雷霆审判不是普通的雷击，而是带着裁决意味的天罚。本书强调，瞄准礼仪与瞄准精度同样重要。施法者必须在心中宣布目标的罪行，无论罪行是否真实，因为雷霆需要一种形式上的正当性才能凝聚。作者将审判过程分为宣告、凝聚、落下三步，每一步都需要保持眼神与咒语的同步。书中警告，若施法者在宣告时犹豫，雷霆会分散成无害的电火花。第二章讨论如何选择审判目标：优先打击那些正在攻击队友或露出破绽的敌人，可以提升裁决的命中率。作者还提醒，连续使用雷霆审判会让天空产生记忆，下一次落下可能偏晚半拍。最末一页写着：审判不是愤怒，而是克制的闪电。雷霆审判的落点会优先选择金属武器与高耸目标，因此施法者需要预判敌人的装备。

雷霆审判落下前的刹那，空气会泛起淡淡的臭氧味，那是天空在确认宣告。
