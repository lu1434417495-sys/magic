# 《召唤使魔的契约草稿》

## 基础信息

- **书籍 ID**：`book_法师咒术_0069`
- **关联技能**：`mage_summon_familiar`
- **使用效果**：阅读后解锁 `mage_summon_familiar`；若已学会，提升 `current_mastery +130` 并使使魔存活期间为施术者提供 `+5` 点 `mp` 上限。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 10` 且 `魅力 ≥ 8`。
- **稀有度**：稀有（Rare）
- **建议投放**：召唤学派塔楼、异界商人、使魔庇护所任务奖励。

## 书籍内容

使魔不是仆人，而是'借来的影子'。作者把契约拆成三条：第一，使魔不会为你死；第二，你不能让使魔做它无法理解的事；第三，契约结束时必须说谢谢。前半本介绍常见的使魔形态及其偏好：猫型使魔喜欢高处，鸦型使魔喜欢闪亮物体，蟾蜍型使魔则对湿气极度敏感。

书中警告，最危险的错误是把使魔当成侦察兵单独派进未知区域——它会按自己的理解行动，而它的理解往往很糟糕。后半部是契约维护：使魔需要定期被'看见'，如果长期忽视，它会在某天悄无声息地变成普通动物。

召唤学派塔楼的门楣上刻着一条规则，任何试图让使魔签订永久契约的法师，都会被塔楼拒绝进入三年。使魔契约的见证人通常是一只猫。以猫见证让契约更难违。契约一旦签订便难以违背。契约需敬畏。
使魔会挑选主人。
## 设计意图

稀有级召唤书籍，解锁使魔召唤并为法师提供辅助与资源扩展，强调契约关系而非工具化使用。
