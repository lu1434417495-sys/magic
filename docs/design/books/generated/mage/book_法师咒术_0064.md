# 《黑焰：吞噬自己的火》

## 基础信息

- **书籍 ID**：`book_法师咒术_0064`
- **关联技能**：`mage_black_flame`
- **使用效果**：阅读后解锁 `mage_black_flame`；若已学会，提升 `current_mastery +150` 并让下一次战斗中首次黑焰命中附加持续灼烧。
- **阅读要求**：角色职业标签含 `mage` 或 `warlock`；基础 `智力 ≥ 13` 且 `意志 ≥ 11`。
- **稀有度**：史诗（Epic）
- **建议投放**：深渊裂隙藏书、黑焰祭坛密室、禁忌知识商人。

## 书籍内容

黑焰的颜色不是黑色，而是'没有光愿意离开'。作者警告，学习黑焰前必须先学会让普通火焰在掌心熄灭而不烧伤自己，因为黑焰第一个吞噬的往往是施术者的影子。前半本讲解'负燃烧'：普通火焰向外释放能量，黑焰则向内塌陷，把热量锁在一个极小的漩涡里。

书中记录了多名学徒的失败：有人被自己的影子绊倒，有人在施术后发现周围的光线变暗了一整天。后半部是战术篇：黑焰最适合攻击已经受伤的目标，因为它会顺着伤口向体内钻。最后一页只有一句话被反复涂改：'它烧的不是血肉，是你认为安全的东西。'

黑焰祭坛的看守者每隔十年就要更换一次自己的影子，因为长期研究黑焰会让影子逐渐变薄，最终像烧穿的纸一样消失。黑焰研究者会在自己的影子里藏一把伞。影中藏伞是看守者标志。
## 设计意图

史诗级暗影火焰输出书籍，提供高风险高回报的进阶伤害技能，强调意志门槛与禁忌魔法的代价感。
