# 《星尘幕：陨屑迷踪》

## 基础信息

- **书籍 ID**：`book_法师咒术_0216`
- **关联技能**：`mage_star_dust`
- **使用效果**：阅读后解锁 `mage_star_dust`；若已学会，提升 `current_mastery +140` 并在下一次战斗中使首次星尘幕释放时自身获得一次闪避加成。
- **阅读要求**：角色职业标签含 `mage` 或 `astromancer`；基础 `智力 ≥ 14` 且 `敏捷 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：观星台密室、流星雨过后遗迹、星界旅人遗落物。

## 书籍内容

星尘幕是将细碎星光挥洒成一片闪烁雾气的法术，能干扰敌人的视线并掩盖施法者的位置。书中第一页是一颗真正的陨石碎屑，据说来自某位古代星术师的收藏。作者认为，星尘的关键在于颗粒大小的控制：太大容易落地，太小则无法折射光线。练习者需要在夜晚对着星空反复挥洒银粉，直到能让自己的身体在星尘中变得模糊。后半部讲解如何把星尘与幻术结合，制造出多个虚假身影。最末页是一段褪色的诗句：我们是尘埃，也是光的残渣。许多观星法师会在施放星尘幕后静静站立，享受那几秒钟被宇宙遗忘的感觉。书中还提到，流星雨中施放的星尘幕会带有微弱引力，能轻微偏转敌方飞行道具的轨迹。星尘幕散去后，施法者身上常会落下细小的银色尘埃，数日才会消失。

## 设计意图

提供防御性遮蔽与闪避增益，让法师在战棋中获得短暂生存空间，增强幻术与星象主题联动。
