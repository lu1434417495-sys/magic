# 《毒瘴云：腐败呼吸》

## 基础信息

- **书籍 ID**：`book_法师咒术_0212`
- **关联技能**：`mage_poison_cloud`
- **使用效果**：阅读后解锁 `mage_poison_cloud`；若已学会，提升 `current_mastery +150` 并在下一次战斗中使首片毒瘴云持续时间延长一回合。
- **阅读要求**：角色职业标签含 `mage` 或 `alchemist`；基础 `智力 ≥ 13` 且 `体质 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：沼泽巫婆小屋、炼金术士废弃实验室、毒龙巢穴。

## 书籍内容

毒瘴云是将腐化魔力与水汽混合后释放的持续性区域法术，能让踏入其中的敌人逐渐衰弱。书中详细记录了十七种常见毒草的配比，并提醒施法者必须在下风口施放，否则最先中毒的可能是自己。作者认为，毒云的艺术在于边界控制：太浓会被风吹散，太淡则无法造成有效压制。后半部介绍了如何让毒云附着在地表缓慢移动，以及如何与火系法术配合引发剧烈爆炸。最末页是一片干枯的叶片，叶脉上写着：腐败也是循环的一部分。许多炼金法师会把这本书当作园艺手册，因为里面关于植物枯萎的章节写得格外浪漫。书末附录还有一页解毒配方，作者自嘲说这是为了让你在被自己的云呛到时能自救。书页间偶尔能发现干枯的毒蘑菇碎片，显然是某位前辈的实验残留。

## 设计意图

提供持续区域压制与状态伤害，让法师在战棋中分割战场，限制敌方推进节奏。
