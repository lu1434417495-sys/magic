# 《极寒射线：霜白死线》

## 基础信息

- **书籍 ID**：`book_法师咒术_0233`
- **关联技能**：`mage_polar_ray`
- **使用效果**：阅读后解锁 `mage_polar_ray`；若已学会，提升 `current_mastery +160` 并在下一次战斗中使首道极寒射线命中时冻结目标移动一回合。
- **阅读要求**：角色职业标签含 `mage` 或 `cryomancer`；基础 `智力 ≥ 15` 且 `意志 ≥ 12`。
- **稀有度**：史诗（Epic）
- **建议投放**：极地科考站废墟、永恒冰核、霜巨人王座。

## 书籍内容

极寒射线是从指尖射出的一道纯白光束，所过之处空气都会凝结成细小冰晶。书中把这道射线描述为冬天的呼吸，它不会燃烧，只会让一切停止活动。作者强调，射线的温度越低，颜色就越白，当射线完全看不见时，才是杀伤力最大的时候。练习者需要先让自己的指尖温度降到冰点以下而不冻伤，这个过程通常伴随着手指发麻和幻痛。后半部讲解了如何让射线在击中目标后向周围蔓延，把单个敌人变成冰雕展览的中心。最末页是一颗被冰冻的泪滴，标签写着：寒冷到达极致时，连悲伤都会凝固。许多冰法师会在施展此术后用力搓手，仿佛这样就能确认自己还活着。书中还提醒，连续发射会迅速降低周围温度，可能误伤己方敏捷较低的同伴。

## 设计意图

提供高伤害单体控制，让冰系法师拥有锁定关键目标的终极手段，强化点杀能力。
