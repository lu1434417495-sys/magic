# 《影缚索：无光镣铐》

## 基础信息

- **书籍 ID**：`book_法师咒术_0210`
- **关联技能**：`mage_shadow_snare`
- **使用效果**：阅读后解锁 `mage_shadow_snare`；若已学会，提升 `current_mastery +140` 并在下一次战斗中使影缚索首次命中目标下回合无法使用位移技能。
- **阅读要求**：角色职业标签含 `mage` 或 `shadowmage`；基础 `智力 ≥ 13` 且 `感知 ≥ 12`。
- **稀有度**：稀有（Rare）
- **建议投放**：暗影巷陌、刺客公会藏书阁、月蚀之夜交易。

## 书籍内容

影缚索是从施法者脚下影子中射出的黑色触须，能牢牢缠住目标的脚踝。书中第一页警告，施术者必须先学会凝视自己的影子，否则影子会在施法时背叛你。作者把练习分为两步：先让影子在烛光下听从指挥，再在完全无光的环境中凭感知召唤缚索。后半部分讲解各种变体，包括让缚索爬上敌人手臂封印施法、或把多个敌人的影子连在一处以限制集体移动。最末页是一段用隐形墨水写成的文字，只有在月光下才能看见：锁住影子的同时，你也锁住了自己的一部分。许多暗影法师认为，影缚索最美妙的时刻是敌人发现自己明明没有被任何东西碰到，却动弹不得。高阶技巧提到，把缚索系在自己的影子上，可在被击倒时借助影子把自己拉回站立姿态。暗影学徒常在训练后找不到自己的影子，需要静坐片刻才能重新合而为一。

## 设计意图

针对高机动敌人设计，强化暗影系法师的限制能力，创造战术性击杀窗口。
