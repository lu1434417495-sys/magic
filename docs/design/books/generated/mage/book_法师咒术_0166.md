# 《霜悼：为火焰送行》

## 基础信息

- **书籍 ID**：`book_法师咒术_0166`
- **关联技能**：`mage_frost_mourning`
- **使用效果**：阅读后解锁 `mage_frost_mourning`；若已学会，提升 `current_mastery +170` 并在下一次战斗中使霜悼熄灭首个火焰效果时恢复施法者 10% 最大 MP。
- **阅读要求**：角色职业标签含 `mage` 或 `cryomancer`；基础 `智力 ≥ 17` 且 `意志 ≥ 15`。
- **稀有度**：史诗（Epic）
- **建议投放**：极北冰原、冰霜巨龙巢穴、元素冲突战场。

## 书籍内容

霜悼是一种为火焰举行的葬礼仪式，施法者用极寒之力包裹燃烧的目标，使其在寂静中熄灭。本书从哲学角度探讨火焰与冰霜的对立统一，认为两者并非敌人，而是同一枚硬币的两面。作者详细描述了仪式步骤：先要承认火焰的存在，再用寒气环绕而不压迫，最后在一声低语中让其自然消亡。书中警告，怀着仇恨施法会让霜悼变成攻击，失去其原本的净化意义。第二章收录了不同文化中为火焰送行的悼词，每种语言都会影响最终效果。最末一页写着：你熄灭的不是敌人，而是失控。练习者需要在营火旁反复练习，直到能用霜气包裹火焰而不让它爆裂。这门技艺在对抗火系敌人时能化解其持续伤害。

霜悼完成后空气中会漂浮细小冰晶，它们像雪花一样标记着仪式的边界。

## 设计意图

为冰系法师提供反制火焰的机制，同时融入仪式与文化元素。
