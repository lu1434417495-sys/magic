# 《心镜术：思维的倒影》

## 基础信息

- **书籍 ID**：`book_法师咒术_0227`
- **关联技能**：`mage_mirror_of_mind`
- **使用效果**：阅读后解锁 `mage_mirror_of_mind`；若已学会，提升 `current_mastery +150` 并在下一次战斗中使首次心镜术成功复制敌方一个非终极技能。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 16` 且 `感知 ≥ 13`。
- **稀有度**：史诗（Epic）
- **建议投放**：灵能修道院、镜像迷宫核心、心灵法师密室。

## 书籍内容

心镜术是在施法者意识中构建一面镜子，能反射敌人的法术或复制其战斗技巧的法术。书中警告，镜子只能映照你理解得了的东西，面对过于复杂的技能时，复制出来的版本会严重失真。作者把练习分为观心、映心、化心三步，每一步都需要与不同对手进行大量实战。后半部讲解了如何在复制技能时保留自己魔法的特性，让复制来的火球带有奥术穿透，或者让复制来的治疗附带净化效果。最末页只有一句话：最强的镜子照见的不是别人，是可能的自己。许多心灵法师会用这本书练习与自己下棋，因为他们说那面镜子下棋很阴。书中还提到，心镜术对机械或无心灵敌人无效，因此在面对魔像或亡灵时需谨慎使用。心镜术失败时，镜子会映出施法者最狼狈的样子，令人难堪。因此许多心灵法师在练习前会先整理仪容，这成了该流派出了名的怪癖。

## 设计意图

提供技能复制与反制能力，让法师在战棋中针对敌方关键技能进行灵活应对，增强策略深度。
