# 《睡眠粉尘的伦理争议》

## 基础信息

- **书籍 ID**：`book_法师咒术_0070`
- **关联技能**：`mage_sleep_dust`
- **使用效果**：阅读后解锁 `mage_sleep_dust`；若已学会，提升 `current_mastery +100` 并提升下一次战斗中首次命中后的入睡深度 1 级。
- **阅读要求**：角色职业标签含 `mage` 或 `illusionist`；基础 `智力 ≥ 8`。
- **稀有度**：精良（Uncommon）
- **建议投放**：炼金术士行会、睡眠诊所、梦境边界据点。

## 书籍内容

睡眠粉尘是少有的让作者感到不安的法术。前半本客观讲解配方：月光花晒干后研磨，混入少量缬草粉，再用魔力激活。中段突然转入伦理讨论：让一个人入睡等于暂时剥夺他的反抗能力，那么在他睡着后，施术者是否有权搜查他的身体？

书中引用了三起著名案件的法庭辩论记录，结论是多数王国把睡眠粉尘列为'可携带的非致命武器'。后半部回归技术：睡眠效果与目标的疲劳程度成正比，对刚睡醒的人几乎无效。最后一页被撕掉了一半，残留的批注写着'……但睡着的人也会做梦，梦里可能出现你。'

梦境边界的医师们发现，被睡眠粉尘影响的人所做的第一个梦，往往与施术者最近三天读过的书有关。睡眠粉尘的配方在潮湿季节会失效。医师会干燥保存配方。梦是粉尘的副产品。梦有回响。
## 设计意图

精良级控场书籍，解锁睡眠粉尘并为法师提供非致命控制手段，用伦理讨论丰富世界观并限制滥用。
