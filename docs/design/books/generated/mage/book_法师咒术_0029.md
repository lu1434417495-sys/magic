# 《钢铁意志：法师的第二次生命》

## 基础信息

- **书籍 ID**：`book_法师咒术_0029`
- **关联技能**：`mage_iron_will`
- **使用效果**：阅读后解锁 `mage_iron_will`；若已学会，提升 `current_mastery +90`，并在下一次战斗中使钢铁意志首次抵抗控制时额外反弹精神伤害。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 8` 且 `意志 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：苦修院训练室、战地法师营房、精神防御课程书架。

## 书籍内容

很多法师把全部精力用来强化攻击，却忘记了大脑本身也需要防御。这本书教导一种名为"钢铁意志"的精神强化技巧，让施术者在面对恐惧、魅惑和心灵冲击时，能够像握紧铁拳一样守住自己的意识。作者是一个少言寡语的教官，书中没有任何花哨的修辞。

前半部分是大量的意志训练记录，包括在长噪音环境中保持专注、在剧痛下完成简单计算等。后半部分讲解如何在战斗中把钢铁意志作为一种主动防御启动，抵挡一次即将到来的精神控制。书中警告，钢铁意志不能抵挡物理疼痛，把意志力浪费在抵挡刀伤上是最大的错误。最后一页只有一行字：意志是你的盾，不是你的血。

书中建议学徒找一个信得过的同伴进行对抗训练，由对方释放微弱的精神冲击，自己则尝试用钢铁意志将其反弹回去。

## 设计意图

为法师系提供早期精神防御技能，提升对抗控制型敌人的生存能力，同时强化"智力与意志并重"的法师成长路线，为后续心灵护盾类法术建立熟练度基础。
