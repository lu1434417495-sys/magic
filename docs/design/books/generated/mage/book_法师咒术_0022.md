# 《星点术：把星光握在手里》

## 基础信息

- **书籍 ID**：`book_法师咒术_0022`
- **关联技能**：`mage_star_point`
- **使用效果**：阅读后解锁 `mage_star_point`；若已学会，提升 `current_mastery +90`，并在下一次战斗中使星点术的暴击伤害提升 15%。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：观星台藏书室、夜间露天市场、流浪占星师摊位。

## 书籍内容

星点术是星象魔法中最基础的一招：把远处星辰的微弱光芒凝聚成一点，然后像投掷石子一样把它抛向敌人。这本书的封面用银粉画着猎户座的腰带，翻开第一页就能看到一句警告：不要盯着星点太久，因为它会把你一起拉走。

前半部分讲解如何在夜晚建立与特定星辰的"联系"，这种联系不需要真正的星光照射，只需要施术者在想象中准确地定位那颗星。后半部分讨论实战中的释放技巧：星点术的飞行速度不快，但穿透力惊人，尤其适合对付穿着重甲的敌人。书中还提到，阴天时这个咒语的效果会下降，因为云层会干扰施术者对星辰的感知。

书中还提到，星点术与特定星辰建立联系后，施术者会在梦中反复看见那颗星的影像，这是魔力建立稳定通道的标志，也是许多学徒放弃这个法术的原因。

## 设计意图

为法师系提供早期星辰主题输出技能，引入"星象魔法"分支概念，丰富法师的远程打击手段，同时为后续高阶星陨、星象预言类法术奠定熟练度基础。
