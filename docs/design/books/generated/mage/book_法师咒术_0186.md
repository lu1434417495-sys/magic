# 《以太巢穴的编织术》

## 基础信息

- **书籍 ID**：`book_法师咒术_0186`
- **关联技能**：`mage_ethereal_nest`
- **使用效果**：阅读后解锁 `mage_ethereal_nest`；若已学会，提升 `current_mastery +180` 并在下一次战斗中使以太巢穴首次激活时为进入的友军提供 1 回合无敌。
- **阅读要求**：角色职业标签含 `mage` 或 `ethereal_weaver`；基础 `智力 ≥ 19` 且 `感知 ≥ 15`。
- **稀有度**：传说（Legendary）
- **建议投放**：以太海岸、星界避难所、异界编织者营地。

## 书籍内容

以太巢穴是一种用星界物质编织的临时庇护所，能够短暂隔绝现实世界的伤害。本书从材料收集开始，讲解如何捕捉飘浮的以太丝并将其编织成稳定的半球结构。作者强调，编织时必须保持心情宁静，任何愤怒都会让以太丝断裂。书中记录了不同尺寸巢穴的用途：小型巢穴供一人躲避，大型巢穴可以容纳整支小队，但消耗也成倍增加。第二章讨论巢穴的入口管理，必须精确控制谁可以进入，否则敌人也会利用这个安全区。最末一页写着：巢穴不是堡垒，而是现实之间的缝隙。练习者需要先编织自己的袖口大小巢穴，再逐步扩大规模。这门技艺在关键时刻能为团队争取宝贵的喘息机会。

以太巢穴在解散时会像水泡破裂一样发出轻响，随后所有丝线消散无踪。

## 设计意图

为法师提供紧急庇护技能，将以太编织与战术撤退结合。
