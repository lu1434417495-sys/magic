# 《镜面法则的适用范围》

## 基础信息

- **书籍 ID**：`book_法师咒术_0194`
- **关联技能**：`mage_mirror_law`
- **使用效果**：阅读后解锁 `mage_mirror_law`；若已学会，提升 `current_mastery +180` 并在下一次战斗中使镜面法则首次适用时反弹一个敌方增益效果给施法者。
- **阅读要求**：角色职业标签含 `mage` 或 `mirrorsage`；基础 `智力 ≥ 19` 且 `感知 ≥ 16`。
- **稀有度**：传说（Legendary）
- **建议投放**：镜之法庭、幻象法学院、古老审判所。

## 书籍内容

镜面法则是一种将现实与镜像世界之间的法律应用于战斗的高深技艺。本书从法则条文开始，讲解哪些效果可以被反射，哪些效果会被镜面吸收，又有哪些会同时伤害双方。作者强调，镜面法则不是万能盾牌，它只适用于那些能被逻辑对称的行为。书中记录了常见法术的适用情况：直接伤害通常无法反射，增益效果可以被夺取，而诅咒则会根据施法者意图反弹。第二章讨论如何在战斗中快速判断适用性，作者建议观察敌人施法时的手势与目光方向。最末一页写着：镜子只回应它理解的东西。练习者需要先在静止的水面练习，学会让法则在眨眼间生效。这门技艺在面对大量增益型敌人时具有战略价值。

镜面法则生效时周围会出现短暂镜像倒影，这是判断法则是否启动的直观标志。

## 设计意图

为镜像主题法师提供增益反制机制，将法律与镜面概念融入战斗。
