# 《闪电链的拓扑优化》

## 基础信息

- **书籍 ID**：`book_法师咒术_0117`
- **关联技能**：`mage_lightning_topology`
- **使用效果**：阅读后解锁 `mage_lightning_topology`；若已学会，提升 `current_mastery +160` 并在下一次战斗中使闪电链首次跳跃次数增加 1 次。
- **阅读要求**：角色职业标签含 `mage` 或 `elementalist`；已学会 `mage_chain_lightning`；基础 `智力 ≥ 16`。
- **稀有度**：史诗（Epic）
- **建议投放**：风暴祭坛核心、高塔电气实验室、雷霆领主宝箱。

## 书籍内容

闪电链从来不是直线，它会在导体之间寻找最省力的路径。本书用拓扑学方法分析战场上的跳跃节点，教导施法者如何提前布置金属残片或湿润地面来引导电弧。作者指出，闪电链的伤害会随跳跃次数递减，因此优化路径比增加次数更重要。书中收录了七种常见阵型下的最佳释放角度，以及如何利用敌人的护甲缝隙作为跳点。作者警告，不要在雷雨天气 indoors 使用这门技巧，因为墙壁上的湿气会形成不可控的回响。第二章是预判训练：练习者需要在脑海中预先计算三到四个目标的相对距离与导电性。最末一页写着：闪电喜欢聪明人，但更喜欢谦卑的人。练习时可以在训练场悬挂多个金属铃铛，通过铃声判断电弧的实际路径是否与预期一致。当铃声连成一段旋律，说明你的拓扑感已经初步成型。

## 设计意图

为雷系法师提供进阶的路线规划能力，强化连锁闪电在战棋中的策略性与地图互动。
