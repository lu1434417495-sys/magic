# 《灰烬华尔兹的步法》

## 基础信息

- **书籍 ID**：`book_法师咒术_0154`
- **关联技能**：`mage_ashen_waltz`
- **使用效果**：阅读后解锁 `mage_ashen_waltz`；若已学会，提升 `current_mastery +180` 并在下一次战斗中使灰烬华尔兹首次位移后 1 回合内受到伤害降低 20%。
- **阅读要求**：角色职业标签含 `mage` 或 `ashen_dancer`；基础 `智力 ≥ 17` 且 `冥想 ≥ 4`。
- **稀有度**：史诗（Epic）
- **建议投放**：灰烬交界舞厅、余烬酒馆、异界裂隙边缘。

## 书籍内容

灰烬交界有一种特殊的战斗舞蹈，舞者必须在燃烧的余烬上保持优雅步伐。本书将这套步法拆解为六个基本位置，每一个位置都对应一种火焰元素的利用方式。第一步是接纳，让灰烬附着靴底；第二步是旋转，利用离心力甩出火花；第三步是下沉，将火焰压入地面形成短暂屏障。作者提醒，华尔兹的核心不是攻击，而是让敌人无法预测你的下一步。书中记录了多名法师因过于急躁而被自己的火焰烧伤脚踝的案例。最末一页是一首短诗：踩在灰烬上的人，不能害怕跌倒。练习者需要在铺满温热的木炭上完成整套步法，才能真正掌握与火焰共舞的节奏。这套技艺在战棋中尤其擅长穿越敌阵。

熟练后舞者可在灰烬上留下短暂火焰残影，迷惑追击者的判断。

## 设计意图

将灰烬交界设定与法师机动结合，提供兼具位移与防御的火焰系战技。
