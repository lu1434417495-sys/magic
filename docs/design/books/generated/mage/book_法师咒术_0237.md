# 《凤凰灰烬：不灭余火》

## 基础信息

- **书籍 ID**：`book_法师咒术_0237`
- **关联技能**：`mage_phoenix_ash`
- **使用效果**：阅读后解锁 `mage_phoenix_ash`；若已学会，提升 `current_mastery +170` 并在下一次战斗中使首次凤凰灰烬触发时额外清除自身一个负面状态。
- **阅读要求**：角色职业标签含 `mage` 或 `pyromancer`；基础 `智力 ≥ 16` 且 `意志 ≥ 14`。
- **稀有度**：史诗（Epic）
- **建议投放**：凤凰巢穴遗迹、不死鸟祭祀场、古代火法师陵墓。

## 书籍内容

凤凰灰烬是把自己化作一团火焰后重生的法术，能在濒死时恢复部分生命并清除负面状态。书中把这一过程描述为与凤凰之火的短暂契约：你燃烧自己，然后借用它的余烬重塑形体。作者警告，每次使用都会让施法者对火焰产生更深依赖，过度使用的人最终会变成只知道燃烧的怪物。练习者需要先在篝火中感受灼烧而不躲避，学会把疼痛当作重塑的信号。后半部讲解了如何控制重生的落点，避免从火中归来时直接落入敌人包围。最末页只有一片红色的羽毛，据说来自某位成功施展此术的法师的残影。许多火法师把它当作最后的底牌。书中还提醒，重生后的数秒内体温极高，触碰队友可能造成烫伤，因此需保持短暂距离。

## 设计意图

提供濒死复活与状态净化，让法师拥有高风险高回报的第二次机会，增强战斗戏剧性。
