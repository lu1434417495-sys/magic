# 《熔岩路径的脚印管理》

## 基础信息

- **书籍 ID**：`book_法师咒术_0163`
- **关联技能**：`mage_molten_path`
- **使用效果**：阅读后解锁 `mage_molten_path`；若已学会，提升 `current_mastery +170` 并在下一次战斗中使熔岩路径首次经过敌人时造成持续 2 回合的灼烧。
- **阅读要求**：角色职业标签含 `mage` 或 `pyromancer`；基础 `智力 ≥ 17` 且 `冥想 ≥ 3`。
- **稀有度**：史诗（Epic）
- **建议投放**：火山要塞、熔岩洞窟、火焰教派据点。

## 书籍内容

熔岩路径是一种让法师在移动时在地面上留下灼热足迹的技艺。本书从鞋底防护开始，讲解如何用耐火符文和一层薄薄的法力膜保护双脚。作者指出，脚印管理的重点在于节奏：太快会让熔岩四溅误伤队友，太慢则无法形成连续的路径。书中记录了如何利用地形扩大效果：在石质地面上熔岩会扩散，在草地上则会被迅速消耗。最末一章讨论如何在路径熄灭前完成战术走位，作者建议每次训练先画出理想的移动路线再开始奔跑。批注写道：你留下的不是脚印，而是一串燃烧的宣言。练习者需要学会在熔岩上行走而不被粘住靴底，同时控制每一步的温度。这门技艺在战棋中能切割战场，迫使敌人绕行或承受灼伤。

熔岩路径熄灭后会留下黑色玻璃状痕迹，可作为临时障碍阻挡追击。

## 设计意图

为火系法师提供地形控制型机动技能，强化走位与区域封锁的战术价值。
