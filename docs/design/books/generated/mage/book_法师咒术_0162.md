# 《符文侵蚀与修复手册》

## 基础信息

- **书籍 ID**：`book_法师咒术_0162`
- **关联技能**：`mage_rune_erosion`
- **使用效果**：阅读后解锁 `mage_rune_erosion`；若已学会，提升 `current_mastery +160` 并在下一次战斗中使首次侵蚀敌方符文时偷取其 15% 效果反弹给施法者。
- **阅读要求**：角色职业标签含 `mage` 或 `runesmith`；基础 `智力 ≥ 17` 且 `感知 ≥ 14`。
- **稀有度**：史诗（Epic）
- **建议投放**：符文工坊、古代遗迹、矮人矿坑图书馆。

## 书籍内容

符文不是永恒的文字，它们会随时间风化，也会被敌人的恶意力量侵蚀。本书前半部分教导如何识别符文的健康状态：完整符文光芒稳定，受损符文会闪烁，被侵蚀符文则会散发出不协调的热量。后半部分讲解修复技巧，包括如何用同源的魔力重新描边，以及如何在紧急情况下用临时墨水填补缺口。作者强调，修复符文时必须保持心情平静，愤怒会让修复后的符文带有攻击性。书中收录了三十六个常见符文的侵蚀案例与对应修复方案。最末一页写着：侵蚀不是破坏，而是另一种形式的对话。练习者需要先学会破坏自己的符文，再尝试修复它们。这门技艺在对抗依赖符文护身的敌人时尤其有效。

修复完成后需用同频率魔力轻敲符文三次，确认其重新进入稳定共鸣。

最资深的符文修复师能在不借助工具的情况下，仅凭指尖触感判断符文深处的裂痕走向。

## 设计意图

为法师提供针对符文系统的攻防手段，强化符文维护与战术剥夺。
