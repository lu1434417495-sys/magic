# 《地刺：岩笋审判》

## 基础信息

- **书籍 ID**：`book_法师咒术_0229`
- **关联技能**：`mage_earth_spike`
- **使用效果**：阅读后解锁 `mage_earth_spike`；若已学会，提升 `current_mastery +130` 并在下一次战斗中使首根地刺命中后使目标倒地一回合。
- **阅读要求**：角色职业标签含 `mage` 或 `elementalist`；基础 `智力 ≥ 11`。

- **建议投放**：土元素祭坛、矿洞深处、古老德鲁伊遗迹。

## 书籍内容

地刺是让地下岩石瞬间向上突刺的法术，常用于破坏敌人阵型或制造地形障碍。书中把地刺比作种蘑菇：你不知道它会在哪里冒出来，但你知道它一定会在你选好的菌丝网络里。作者强调，施法前必须感知地下的岩层结构，否则地刺可能从错误角度长出。练习者需要先在沙地上画出目标点，再尝试让沙柱准确从标记处升起。后半部讲解了如何让多根地刺同时爆发，形成一片石林封锁通道。最末页是一段矿工的涂鸦：地刺不会说谎，它指向哪里，哪里就有空隙。许多土法师喜欢用这招修理不平整的路面。书中还附有一张常见地层硬度表，提醒在松软泥土中地刺出得快但易折断，在岩石中则缓慢却锋利。地刺法术也是测量地下矿脉的便捷工具，许多勘探队会高价聘请土法师同行。地刺出现的角度和颜色，往往能直接指示地下矿藏的丰富程度。

## 设计意图

提供基础地形控制与单体打断，让法师拥有环境互动能力，丰富低级战术选择。
