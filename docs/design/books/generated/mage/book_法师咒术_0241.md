# 《灵体长枪：幽冥突刺》

## 基础信息

- **书籍 ID**：`book_法师咒术_0241`
- **关联技能**：`mage_spirit_lance`
- **使用效果**：阅读后解锁 `mage_spirit_lance`；若已学会，提升 `current_mastery +150` 并在下一次战斗中使首柄灵体长枪无视目标百分之二十护甲。
- **阅读要求**：角色职业标签含 `mage` 或 `necromancer`；基础 `智力 ≥ 14` 且 `感知 ≥ 12`。
- **稀有度**：稀有（Rare）
- **建议投放**：古墓深处、灵魂渡口、亡灵军团战利品。

## 书籍内容

灵体长枪是由死者残念凝聚而成的穿刺武器，能穿透金属铠甲直击肉体。书中第一节要求练习者先学会聆听战场上的低语，那些未被安息的魂灵才是长枪的材料。作者强调，灵体长枪不是召唤，而是借用：你必须对死者保持尊重，否则长枪会在飞行途中转向你自己。练习者需要在墓地静坐整夜，直到能分辨出哪些魂灵愿意被借用。后半部讲解了如何让长枪在命中后分散成数道幽魂继续攻击邻近敌人。最末页是一段用骨粉写的警告：借来的东西要还，利息是记忆。许多亡灵法师在使用此术后会忘记一些不重要的往事。书中还提到，在古老战场施放此术时，长枪会自动吸收更多残念，射程和威力都会显著提升。灵体长枪穿过铠甲时不会留下物理伤口，但目标醒来后会感到莫名疲惫。

## 设计意图

提供穿甲与精神伤害，让法师能有效对抗重甲敌人，丰富暗系输出维度。
