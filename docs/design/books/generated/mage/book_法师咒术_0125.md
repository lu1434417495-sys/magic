# 《幻境迷宫的入口设计》

## 基础信息

- **书籍 ID**：`book_法师咒术_0125`
- **关联技能**：`mage_illusion_labyrinth`
- **使用效果**：阅读后解锁 `mage_illusion_labyrinth`；若已学会，提升 `current_mastery +170` 并在下一次战斗中使迷宫首次展开时敌人困惑概率提高 10%。
- **阅读要求**：角色职业标签含 `mage` 或 `illusionist`；基础 `智力 ≥ 17` 且 `感知 ≥ 14`。
- **稀有度**：史诗（Epic）
- **建议投放**：幻术师公会密室、镜宫遗迹深层、梦境裂隙奖励。

## 书籍内容

幻境迷宫的威力不在于墙壁，而在于入口。本书从入口设计入手，教授如何利用目标的习惯与期待，让他们主动走进并不存在的走廊。作者指出，最好的入口往往看起来像是出口，而最致命的转弯则模仿了目标最熟悉的回家路线。书中收录了九种经典入口原型：重复门廊、无限楼梯、倒映广场、气味回廊等。第二章讨论迷宫内的循环逻辑，要求施法者为每个幻象设定一条不可见的回路，让敌人在愤怒中耗尽体力。作者警告，施法者自己也会偶尔迷失在幻境中，因此必须保留一个只有本人知道的秘密出口。最末一页画着一扇半开的门，门后是另一扇同样的门，批注写道：迷宫不是困住身体，而是困住选择。书中还提供了如何在被识破时迅速瓦解迷宫的技巧，因为被困住的敌人若意识到真相，反而可能利用迷宫反击施法者。

## 设计意图

为幻术法师提供区域性控场，强化心理战与敌人行动干扰，拓展幻术系后期玩法。
