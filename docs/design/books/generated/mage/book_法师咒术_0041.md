# 《冬之守护：以寒冷为盟友的护盾》

## 基础信息

- **书籍 ID**：`book_法师咒术_0041`
- **关联技能**：`mage_winter_ward`
- **使用效果**：阅读后解锁 `mage_winter_ward`；若已学会，提升 `current_mastery +100`，并在下一次战斗中使冬之守护首次被击破时对攻击者造成 10 点寒冰伤害。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 10`。
- **稀有度**：普通（Common）
- **建议投放**：冰封堡垒、北境法师塔、冬之祭坛。

## 书籍内容

冬之守护是一种把自己包裹在旋转冷风中的防御咒术，它不像火盾那样具有攻击性，但能让近战敌人在击中你的同时冻得手指僵硬。这本书的作者是一个在雪原生活了半辈子的老妇人，她写道：真正的冬天不是刺骨的，而是安静的、缓慢的、让人失去斗志的。

前半部分讲解如何在身体周围维持一层稳定的低温气流，重点是把热量从护盾内侧排到外侧，而不是让冷气直接吹到自己脸上。后半部分讨论战术细节：冬之守护对火焰攻击的抵抗力较弱，但对物理钝击和毒素有不错的缓释效果。书中警告，护盾持续时间结束后，施术者会因为体温骤降而短暂发抖，这段时间内施法速度会下降。最后一页画着一个被雪花环绕的法师，表情平静。

书中还介绍了护盾分层的技巧，把冬之守护拆成内外两层，外层负责承受冲击，内层则保留最后一丝防御，避免被一次性击穿。

## 设计意图

为法师系提供早期元素防御技能，强化生存能力与元素主题分支选择，同时为后续冰系护盾、绝对零度类高级法术建立熟练度与叙事连接。
