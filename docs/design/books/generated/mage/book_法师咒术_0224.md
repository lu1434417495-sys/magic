# 《时间裂隙：刹那狭缝》

## 基础信息

- **书籍 ID**：`book_法师咒术_0224`
- **关联技能**：`mage_time_rift`
- **使用效果**：阅读后解锁 `mage_time_rift`；若已学会，提升 `current_mastery +170` 并在下一次战斗中使首次时间裂隙额外延迟一个敌方单位一回合。
- **阅读要求**：角色职业标签含 `mage` 或 `chronomancer`；基础 `智力 ≥ 17` 且 `感知 ≥ 14`。
- **稀有度**：传说（Legendary）
- **建议投放**：时间尽头的钟楼、时之神殿遗迹、最终隐藏宝箱。

## 书籍内容

时间裂隙是在现实时间线上撕开的一道细小缺口，能让目标短暂停滞或回溯数秒。书中警告，这道裂隙只能容纳很小的改变，试图改变重大事件会导致裂隙反噬施法者。作者把时间操控比作在激流中捕鱼：你可以让一条鱼慢下来，但不能让整条河倒流。练习者需要先学会感知时间的纹理，才能在关键时刻撕开裂隙。后半部讲解了如何在团队战中用裂隙保护濒死队友、延迟敌方关键技能，或者让自己在危急时刻重获一回合行动机会。最末页只有一枚停摆的怀表，表盖刻着：刹那即永恒。许多时法师在研究此术后会开始对钟表产生恐惧。书中还提到，连续使用时间裂隙会让周围人产生似曾相识的眩晕感，因此不建议在密集人群中反复使用。时间裂隙闭合时会发出类似玻璃碎裂的轻响，只有施法者能听见。

## 设计意图

提供传说级时间操控能力，让法师拥有改变行动顺序的战略手段，增强高端战局深度。
