# 《力场长矛的贯穿原理》

## 基础信息

- **书籍 ID**：`book_法师咒术_0082`
- **关联技能**：`mage_force_lance`
- **使用效果**：阅读后解锁 `mage_force_lance`；若已学会，提升 `current_mastery +110` 并在下一次战斗中使首次力场长矛贯穿第一个目标后伤害衰减降低 20%。
- **阅读要求**：已学会 `mage_force_wall` 或 `mage_arcane_missile`；角色职业标签含 `mage`；基础 `智力 ≥ 10`。
- **稀有度**：精良（Uncommon）
- **建议投放**：防护与塑能联合学院、战场图书馆、古战场武器库。

## 书籍内容

力场长矛的本质是把'无形的墙'压缩成一条线，再让它以极高速度射出。前半本讲解贯穿原理：长矛在穿透第一个目标时会损失一部分'结构完整性'，导致后续贯穿能力下降。作者提供了三种补偿方法：增加初始密度、减少矛身长度、或者让长矛在命中后短暂旋转以重新稳定。

书中夹着一张被戳穿的钢板照片，背面写着'第二块钢板只裂了一半'。后半部讨论战术：力场长矛最适合攻击排成直线的敌人，但也容易误伤站在后面的友军。最后一页是一幅简笔画，一个法师正躲在盾牌后面发射长矛，旁边批注'先确认你身后没有人。'

古战场武器库里保存着一柄被力场长矛贯穿的塔盾，盾面上的孔洞边缘光滑得像被水切割过。力场长矛的贯穿痕迹常被误认为钻孔。光滑痕迹被误为工匠作。钻孔会留下永久证据。
## 设计意图

精良级力场穿透输出书籍，前置要求力场墙或奥术飞弹，为法师提供直线贯穿伤害能力，强调结构与误伤管理。
