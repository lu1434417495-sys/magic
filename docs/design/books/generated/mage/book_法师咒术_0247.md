# 《生命转换：血偿魔流》

## 基础信息

- **书籍 ID**：`book_法师咒术_0247`
- **关联技能**：`mage_life_tap`
- **使用效果**：阅读后解锁 `mage_life_tap`；若已学会，提升 `current_mastery +150` 并在下一次战斗中使首次生命转换获得的 MP 量提升百分之二十。
- **阅读要求**：角色职业标签含 `mage` 或 `warlock`；基础 `智力 ≥ 14` 且 `体质 ≥ 12`。
- **稀有度**：稀有（Rare）
- **建议投放**：血魔法师密室、禁忌契约所、黑暗集市。

## 书籍内容

生命转换是以自身生命力为代价换取魔力的法术，常用于紧急时刻补充 MP。书中把这一过程描述为与自己签订一份不平等契约：你现在借走生命，将来连本带利偿还。作者强调，转换的比例必须精确控制，一次性抽取太多会导致施法者当场昏迷。练习者需要先学会感受自己生命的流动，就像感受水壶里的水量。后半部讲解了如何在转换后快速用治疗或护盾弥补损失，以及如何让转换效率在濒死时达到最高。最末页是一张写满数字的表格，显示不同体质下安全转换的上限。许多血法师会把这本书藏在枕下，提醒自己永远留最后一滴血。书中还提到，连续使用生命转换会让血液变得稀薄，愈合速度变慢，因此需要合理规划使用频率。

## 设计意图

提供生命值与 MP 的转换机制，让法师在资源枯竭时有最后的搏命选择，增强风险决策。
