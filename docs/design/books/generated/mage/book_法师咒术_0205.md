# 《虚空茧壳：无光之室》

## 基础信息

- **书籍 ID**：`book_法师咒术_0205`
- **关联技能**：`mage_void_shell`
- **使用效果**：阅读后解锁 `mage_void_shell`；若已学会，提升 `current_mastery +170` 并在下一次战斗中使虚空茧壳持续期间首次受击完全吸收。
- **阅读要求**：角色职业标签含 `mage` 或 `voidwalker`；基础 `智力 ≥ 15` 且 `意志 ≥ 13`。
- **稀有度**：史诗（Epic）
- **建议投放**：虚空裂隙深处、古代禁书区、深渊观察者宝箱。

## 书籍内容

虚空茧壳不是护盾，而是一层暂时把施法者与正常空间剥离开来的薄膜。书中警告，这层薄膜会同时阻挡善意与恶意，因此施法期间无法接受治疗。作者详细讲解了如何控制薄膜的厚度：太薄会被锐利的剑气刺穿，太厚则会让自己的法术也穿透不出去。练习者需要先在绝对黑暗中冥想，直到能区分真正的虚无与单纯的黑。后半部记录了多位法师在虚空茧中看到的幻象，有人声称听见了世界的呼吸，有人说看见了自己未来的死状。最末页用银色墨水写着：无光之室里没有敌人，只有你自己。许多高阶法师只在万不得已时启用此术，因为每次使用都会让他们对现实产生一丝怀疑。资深使用者会在茧壳上留下一个单向窗口，以便观察外界而不被外界察觉。有记录显示，某些虚空行者能在茧壳内短暂思考平时无法触及的问题。

## 设计意图

为高阶法师提供战略性护盾，鼓励在危险位置大胆施法，同时以副作用换取绝对防御。
