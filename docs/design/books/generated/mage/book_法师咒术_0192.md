# 《魔力发酵的窖藏术》

## 基础信息

- **书籍 ID**：`book_法师咒术_0192`
- **关联技能**：`mage_mana_fermentation`
- **使用效果**：阅读后解锁 `mage_mana_fermentation`；若已学会，提升 `current_mastery +180` 并在下一次战斗中使发酵魔力首次释放时效果提高 25%。
- **阅读要求**：角色职业标签含 `mage` 或 `alchemist`；基础 `智力 ≥ 18` 且 `感知 ≥ 15`。
- **稀有度**：传说（Legendary）
- **建议投放**：地下酒窖、炼金术士庄园、古代发酵所。

## 书籍内容

魔力发酵是一种将法力像酒一样窖藏，使其随着时间推移变得更加醇厚的技艺。本书从容器选择开始，讲解不同材质对发酵效果的影响：橡木桶增加温暖感，水晶瓶保持纯净，而黑陶罐则会让魔力带上泥土气息。作者强调，发酵需要恒定的温度和湿度，任何剧烈波动都会导致魔力变酸甚至爆炸。书中记录了如何判断发酵是否完成：成熟的魔力会发出低沉的嗡鸣，瓶塞会轻微颤动。第二章讨论饮用时机，过早会浪费潜力，过晚则可能醉酒般失去控制。最末一页写着：窖藏不是等待，而是让时间成为配方的一部分。练习者需要先窖藏一小瓶低阶魔力，观察其变化过程。这门技艺适合需要提前准备的重要战斗，让关键法术获得显著增强。

## 设计意图

为炼金与法师结合角色提供蓄力增强机制，将酿酒文化与魔力储备结合。
