# 《熔核珠：地心低语》

## 基础信息

- **书籍 ID**：`book_法师咒术_0207`
- **关联技能**：`mage_magma_orb`
- **使用效果**：阅读后解锁 `mage_magma_orb`；若已学会，提升 `current_mastery +150` 并在下一次战斗中使首颗熔核珠命中后地面留下持续燃烧区域。
- **阅读要求**：角色职业标签含 `mage` 或 `elementalist`；基础 `智力 ≥ 14` 且 `体质 ≥ 10`。
- **稀有度**：史诗（Epic）
- **建议投放**：火山口熔岩图书馆、地脉枢纽、元素领主战利品。

## 书籍内容

熔核珠是把地底岩浆浓缩成拳头大小的炽热球体，表面浮动着黑曜石般的裂纹。书中记载，施法者必须在心中先听见地心的低沉轰鸣，才能让熔核稳定成型。作者详细描述了温度控制的关键：外壳太薄会提前爆裂，太厚则落地后无法铺开燃烧区域。练习者通常先从冷却的玄武岩珠开始，逐步增加内部热量，直到珠子能在掌心悬浮三秒而不烧穿手套。后半部收录了多种投掷轨迹，包括高抛落地、贴地滚动和弹跳引爆。最末页是一张被烧出洞的地图，标注着一处据说能直达地脉的裂口。许多元素法师认为，熔核珠是火系与土系交汇最完美的形态。书中还附带一页耐热手套的缝制图样，提醒读者保护好握珠的手。封面上有一圈焦黑的指印，提醒后人熔核珠从来不是温柔的法术。许多火法师把熔核珠当作护身符挂在胸前，尽管它偶尔会烧焦衣襟。

## 设计意图

强化地形控制与持续伤害，让火系法术在战棋中制造封锁区，限制敌方走位。
