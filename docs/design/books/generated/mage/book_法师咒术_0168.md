# 《闪电的丝绸化处理》

## 基础信息

- **书籍 ID**：`book_法师咒术_0168`
- **关联技能**：`mage_silken_lightning`
- **使用效果**：阅读后解锁 `mage_silken_lightning`；若已学会，提升 `current_mastery +170` 并在下一次战斗中使丝绸闪电首次命中时跳跃至相邻目标且伤害衰减降低 25%。
- **阅读要求**：角色职业标签含 `mage` 或 `stormweaver`；基础 `智力 ≥ 18` 且 `感知 ≥ 13`。
- **稀有度**：史诗（Epic）
- **建议投放**：风暴云宫、雷雨祭坛、织雷者工坊。

## 书籍内容

闪电通常狂暴而难以控制，但通过丝绸化处理，它可以变成柔软而连续的电流束。本书从材料选择开始，讲解如何用特殊金属丝和法力涂层包裹闪电，使其在释放时保持丝状。作者强调，丝绸闪电的关键在于张力控制：太紧会断裂，太松则会散开。书中记录了如何在丝线上设置节点，让电流在击中第一个目标后沿丝线跳跃到相邻敌人。第二章讨论颜色与温度的关系，金色丝线温度最高，蓝色丝线穿透力最强。最末一页是一张编织图，批注写道：闪电不是鞭子，是你意志的延伸。练习者需要先在绝缘池中将电流拉伸成线，再尝试编织简单的图案。这门技艺在密集敌群中能造成连锁伤害。

丝绸闪电击中目标时会留下丝线状焦痕，这是判断命中与否的明显标志。

## 设计意图

为雷系法师提供可控连锁攻击，扩展闪电魔法的形态与战术应用。
