# 《急冻闪：刹那冰封》

## 基础信息

- **书籍 ID**：`book_法师咒术_0238`
- **关联技能**：`mage_cold_snap`
- **使用效果**：阅读后解锁 `mage_cold_snap`；若已学会，提升 `current_mastery +140` 并在下一次战斗中使首次急冻闪对生命值低于百分之三十的目标造成双倍伤害。
- **阅读要求**：角色职业标签含 `mage` 或 `cryomancer`；基础 `智力 ≥ 13` 且 `感知 ≥ 11`。

- **建议投放**：冰川裂缝、霜狼巢穴、极夜集市。

## 书籍内容

急冻闪是瞬间释放一股极寒气息的瞬发法术，能在眨眼间把目标表面覆盖一层薄冰。书中强调，这个法术的威力不在于持续低温，而在于温度的急剧变化。作者把施法比作猛关一扇门：门缝里的风最冷。练习者需要先学会让手掌温度在瞬间骤降，这个过程常常让手指起满冻疮。后半部讲解了如何把急冻闪与其他冰系法术连招，例如先急冻再冰刺，能让碎冰伤害成倍增加。最末页是一段猎人笔记：猎物最怕的不是冷，是突然冷。许多冰法师会在夏天用这个法术冰镇饮料，顺便练习手感。书中还提到，急冻闪对已经处于冰冻状态的目标效果会减弱，因为温差不再剧烈，因此最好作为起手或斩杀使用。急冻闪练到极致时，法师能在水滴坠地前将其冻成冰珠串成项链。这种冰珠项链在北境集市上颇为抢手，因为永不融化。

## 设计意图

提供低冷却斩杀与连招启动，让冰系法师拥有灵活的收尾手段，强化连击节奏。
