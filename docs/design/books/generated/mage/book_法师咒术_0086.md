# 《次元互换的镜像学》

## 基础信息

- **书籍 ID**：`book_法师咒术_0086`
- **关联技能**：`mage_dimension_swap`
- **使用效果**：阅读后解锁 `mage_dimension_swap`；若已学会，提升 `current_mastery +130` 并在下一次战斗中使首次互换后双方各获得 1 回合 `haste` 缓冲。
- **阅读要求**：已学会 `mage_blink`；角色职业标签含 `mage`；基础 `智力 ≥ 12` 且 `敏捷 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：空间学派密室、镜次元遗迹、高阶传送任务奖励。

## 书籍内容

次元互换比闪现更难，因为它不是移动自己，而是让两个位置上的'存在'暂时交换。前半本讲解镜像学：施术者必须在脑海中同时维持两个点的精确图像，就像一手画圆一手画方。作者建议在练习时先与不重要的物体互换位置，比如一块石头或一杯水。

书中警告，互换活物时最危险的是'惯性冲突'——如果一方正在全力奔跑，另一方会在交换后感到严重的方向错乱。后半部讨论战术：次元互换最常用于把队友拉出危险，或者把敌人换进陷阱，但两次使用之间必须留给大脑足够的冷却时间。

镜次元遗迹的地板上画着无数成对的脚印，那是古代法师练习互换时留下的，每对脚印的朝向都相反。次元互换的脚印遗迹被称为"倒置舞池"。倒置舞池成拍照胜地。脚印记得每一次互换。互换会留下记忆。
## 设计意图

稀有级空间战术书籍，前置要求闪现，解锁与目标位置互换的能力，强调空间同步与团队配合。
