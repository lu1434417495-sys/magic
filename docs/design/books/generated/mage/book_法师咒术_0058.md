# 《时间膨胀的呼吸悖论》

## 基础信息

- **书籍 ID**：`book_法师咒术_0058`
- **关联技能**：`mage_time_dilate`
- **使用效果**：阅读后解锁 `mage_time_dilate`；若已学会，提升 `current_mastery +150` 并减少该技能首次冷却 1 回合。
- **阅读要求**：角色职业标签含 `mage` 或 `chronomancer`；基础 `智力 ≥ 14` 且 `意志 ≥ 10`。
- **稀有度**：史诗（Epic）
- **建议投放**：时之塔顶层、命运裂隙宝箱、时间旅者任务奖励。

## 书籍内容

时间膨胀不是让世界变慢，而是让自己的感知在极短区间内展开。作者把施术过程比作深吸一口气，然后把这口气切成无数小段，每次只呼出一小段。前半本用大量图示解释'呼吸悖论'：如果你在膨胀的时间里呼吸得太快，现实会把你拽回原速；如果呼吸得太慢，你会在效果结束前就先耗尽精神。

书中记录了一个著名实验：一位法师在膨胀时间内读完了一整页书，结果回到常速后发现那页书上的字全部倒流成了墨水。后半部讨论战术应用——最危险的不是延长自己的动作，而是学会在'别人的一瞬'里决定自己的下一步。

时之塔的钟摆室禁止佩戴任何计时器进入，因为时间膨胀会让机械钟表在数秒内走完一整天的发条。时间膨胀的研究者最终都学会了慢性子的走路方式。慢性子走路是毕业特征。
## 设计意图

史诗级时间魔法入门书籍，为法师系提供高门槛战略技能，强调感知管理而非简单加速，服务于高端构筑。
