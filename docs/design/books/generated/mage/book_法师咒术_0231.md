# 《奥术符印：魔纹地雷》

## 基础信息

- **书籍 ID**：`book_法师咒术_0231`
- **关联技能**：`mage_arcane_sigil`
- **使用效果**：阅读后解锁 `mage_arcane_sigil`；若已学会，提升 `current_mastery +150` 并在下一次战斗中使首枚奥术符印触发时额外弹射一次。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 13` 且 `感知 ≥ 11`。
- **稀有度**：稀有（Rare）
- **建议投放**：符文工坊、古代战场遗址、奥术猎人宝箱。

## 书籍内容

奥术符印是把魔力压缩成隐蔽印记埋设在地面的法术，敌人踩中后会触发爆炸或诅咒。书中强调，符印的核心是伪装：太显眼会被避开，太隐蔽则连自己都会忘记位置。作者详细记录了三十七种常见符印图案，每一种对应不同触发条件和效果。练习者需要先在羊皮纸上反复绘制，直到能在三秒内完成一枚标准符印。后半部讲解了如何把多枚符印连成阵列，让触发效果相互增幅。最末页是一段被烧焦的清单，列着某位法师忘记清理的旧符印位置。许多谨慎的法师会在自己的帐篷周围画满符印，然后第二天醒来时小心翼翼地绕出去。书中还提醒，雨水会冲刷露天符印，因此持久战前最好补画或改用防水颜料。

## 设计意图

提供陷阱与区域控制，让法师能在战棋中预设战场，增强战术布局与心理博弈。
