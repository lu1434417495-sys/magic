# 《法力潮汐的月相规律》

## 基础信息

- **书籍 ID**：`book_法师咒术_0114`
- **关联技能**：`mage_mana_tide`
- **使用效果**：阅读后解锁 `mage_mana_tide`；若已学会，提升 `current_mastery +150` 并在下一次战斗中使首个潮汐回复效果额外恢复 10% MP。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 15` 且 `感知 ≥ 14`。
- **稀有度**：稀有（Rare）
- **建议投放**：月神殿图书馆、潮汐观测站、夜间施法者集市。

## 书籍内容

法力潮汐并非恒定不变，它会随着月相涨落。本书整理了三百年的观测数据，证明新月时魔力最为内敛，适合精细咒语；满月时魔力汹涌，适合大范围法术。作者将潮汐分为海潮、地潮与血潮三种，分别对应环境中的水、矿物与生物节律。书中警告，在月蚀期间强行施放潮汐类法术，会导致魔力反方向流动，让施法者瞬间虚脱。练习部分要求读者在连续二十八天内记录自己的冥想效率，再与月相对照。作者认为，最优秀的法师不是储备最多魔力的人，而是懂得在正确时间借取潮汐的人。附录里有一页月历，每个日期旁都标注了适合练习的法术类型。作者还提到，潮汐不仅影响个人法力，也会影响法阵与魔像的运转效率，因此大型仪式前必须核对月相。初学者最好在新月与满月之间各做一次对照实验。

## 设计意图

将时间与环境机制引入法师资源管理，鼓励玩家根据月相规划战斗与修炼节奏。
