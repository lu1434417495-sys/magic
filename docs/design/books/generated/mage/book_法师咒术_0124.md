# 《寒冰墓碑的雕刻课》

## 基础信息

- **书籍 ID**：`book_法师咒术_0124`
- **关联技能**：`mage_ice_tomb`
- **使用效果**：阅读后解锁 `mage_ice_tomb`；若已学会，提升 `current_mastery +180` 并在下一次战斗中使寒冰墓碑首次封印持续时间延长 1 回合。
- **阅读要求**：角色职业标签含 `mage` 或 `cryomancer`；基础 `智力 ≥ 18` 且 `冥想 ≥ 4`。
- **稀有度**：史诗（Epic）
- **建议投放**：冰法师墓园、北境封印所、元素高塔深层冰库。

## 书籍内容

寒冰墓碑不是纪念死者，而是暂时冻结强敌的封印术。本书从雕刻冰碑的纹路开始，要求施法者在极寒环境中用指尖直接刻画，因为工具会传导体温，导致冰面开裂。作者强调，碑文必须用古语书写，现代语言无法承受封印的扭曲力。书中收录了七种碑顶造型，分别对应封印不同类型生物：尖锐顶适合灵体，圆顶适合野兽，平顶适合人类。第二章讨论封印后的维护：墓碑周围必须保持低温，任何热源都会削弱封印。作者警告，不要为活人雕刻墓碑，因为那会让施法者与目标之间建立一条冰冷的命运线。最末一页只有一行字：每一座冰碑里，都藏着雕刻者的一口呼吸。雕刻完成后，施法者需要退后三步并低声诵读封印咒，这一步骤被称为送别。任何多余的动作都可能让墓碑提前碎裂。

被封印者的梦境会透过冰碑渗出，雕刻者有时能在午夜听见陌生的低语。

## 设计意图

为冰系法师提供强力单体控制，强调封印主题与施法代价，丰富后期战术选择。
