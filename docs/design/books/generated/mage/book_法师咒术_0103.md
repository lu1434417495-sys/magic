# 《星界触须的伸展操》

- **书籍 ID**：`book_法师咒术_0103`
- **关联技能**：`mage_astral_tendril`
- **使用效果**：阅读后解锁 `mage_astral_tendril`；若已学会，提升 `current_mastery +150` 并在下一次战斗中使首次触须延伸距离增加 1 格。
- **阅读要求**：角色职业标签含 `mage` 或 `astromancer`；基础 `智力 ≥ 15` 且 `意志 ≥ 12`。

- **建议投放**：星界观测台、浮空城废墟、占星术士任务奖励。

## 书籍内容

星界触须不是召唤生物，而是施法者意识越过物质边界后留下的一道细长投影。本书从伸展操开始，要求练习者每日清晨闭眼想象头顶有一根看不见的线向天空生长。第一章讲解如何让这条线避开星界乱流，作者将乱流比作逆风的峡谷，强行穿过只会折断意识。第二章是距离控制：触须伸得越远，反馈越慢，施法者需要学会在延迟中预判目标位置。书中还记录了触须末端可做的三种动作：抓取、缠绕、轻叩。作者特别提醒，绝对不要用触须去触碰那些会回看的存在。附录里有一页密密麻麻的星图，标注了三十七个相对安全的投射角度，旁边的小字写着：天空比你想象的更近，也更危险。初学者常犯的错误是过度追求延伸距离，结果意识收不回来，导致整整一天头晕目眩。

许多星象学院把伸展操列为晨课，认为它能让法师在一天开始时便与更大的世界保持联系。

## 设计意图

为法师提供中远距离的灵活控制手段，同时借助星界意象拓展世界观中的异界层次。
