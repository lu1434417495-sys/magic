# 《凋零力场的生息循环》

## 基础信息

- **书籍 ID**：`book_法师咒术_0088`
- **关联技能**：`mage_wither_field`
- **使用效果**：阅读后解锁 `mage_wither_field`；若已学会，提升 `current_mastery +140` 并在下一次战斗中使凋零力场首次命中附加生命恢复抑制。
- **阅读要求**：角色职业标签含 `mage` 或 `necromancer`；基础 `智力 ≥ 12` 且 `意志 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：死灵花园、枯萎神殿、瘟疫学者密室。

## 书籍内容

凋零力场不是死亡，而是'生息循环被放慢到接近停止'。前半本讲解生态原理：所有生命都在不断生长与衰亡之间摆动，凋零力场只是把摆动的幅度压小。作者要求施术者先在一片落叶上练习，让叶子不枯死但也不继续腐烂。

书中警告，长期接触凋零力场会让施术者自己的伤口愈合变慢，因此实战时必须保持距离。中段收录了战术用法：凋零力场最克制依赖再生或治疗的敌人，对机械或亡灵则几乎无效。后半部讨论美学：一个成熟的凋零力场应该像秋天的黄昏，安静、缓慢、不可挽回。

死灵花园的园丁们相信，凋零力场最温和的状态可以让花朵保持盛开而不凋谢，只是再也没有蜜蜂愿意靠近。凋零力场花园里的蜜蜂最终学会了在亡灵花上采蜜。亡灵花蜜是珍贵药材。凋零中也藏着生机。
## 设计意图

稀有级死灵区域控制书籍，解锁凋零力场并提供治疗抑制能力，强调生命循环与代价意识。
