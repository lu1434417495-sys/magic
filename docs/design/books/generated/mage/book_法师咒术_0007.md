# 《烟形散记：有形与无形之间》

## 基础信息

- **书籍 ID**：`book_法师咒术_0007`
- **关联技能**：`mage_smoke_form`
- **使用效果**：阅读后解锁 `mage_smoke_form`；若已学会，提升 `current_mastery +90`，并在下一次战斗中使烟形术解除后的首次攻击获得优势。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：刺客 guild 藏书阁、灰雾沼泽密室、旅法师行李箱。

## 书籍内容

这本书散发着淡淡的焦味，仿佛刚从火堆里抢出来。烟形术不是隐身，而是让身体暂时呈现出半气态，从而穿过栅栏、缝隙，甚至避开普通的物理锁定。作者警告：这个咒语最大的危险在于使用者会爱上那种飘忽不定的感觉，最终忘记自己还有实体。

前半部分教授呼吸节奏，要求施术者在吸气时把魔力推入四肢，呼气时让身体"散开"。书中提到，第一次成功的人往往会惊慌失措，因为他们能感觉到自己透过地板下沉了半寸。后半部分讲解战术用途：如何在敌人包围时化作烟雾穿过缝隙，然后在另一侧重新凝聚并反击。书末附有一张被烟熏黑的纸条，上面写着：永远记得回家的路，也记得自己是什么形状。

作者建议练习时先在封闭的房间里进行，并备好一面大镜子，这样即使身体散成了烟雾，也能通过镜子确认自己大致的轮廓。

## 设计意图

为法师系提供早期生存与位移技能，强化战棋中的地形穿越与逃脱策略，同时为后续高阶变形、相位类法术建立"形态转换"的核心熟练度概念。
