# 《雷霆花园的修剪日》

## 基础信息

- **书籍 ID**：`book_法师咒术_0177`
- **关联技能**：`mage_thunder_garden`
- **使用效果**：阅读后解锁 `mage_thunder_garden`；若已学会，提升 `current_mastery +170` 并在下一次战斗中使雷霆花园首次绽放时对范围内随机敌人造成三次闪电伤害。
- **阅读要求**：角色职业标签含 `mage` 或 `storm_gardener`；基础 `智力 ≥ 17` 且 `感知 ≥ 14`。
- **稀有度**：史诗（Epic）
- **建议投放**：浮空花园、风暴温室、元素植物园。

## 书籍内容

雷霆花园是一种种植闪电植物的技艺，这些植物能在开花时释放出小型雷击。本书从土壤配方开始，讲解如何用带电金属粉末和雷云凝结水培育植株。作者强调，修剪是管理花园的核心：过早修剪会浪费花蕾，过晚则会让闪电失控伤到自己。书中记录了不同品种的开花特性，有的像蒲公英一样随风飘散，有的像藤蔓一样攀附敌人，还有的只在受到攻击时反击。最末一章讨论如何在战斗中快速移植花朵，作者建议随身携带小型花盆作为移动弹药。批注写道：花园不会为你而战，它只是恰好在敌人出现时开花。练习者需要学会在雷雨天气为花园接雷，补充植株所需的电能。这门技艺在阵地战中能形成持续的压力区域。

雷霆花园在干燥天气中生长缓慢，但在雷暴夜会一夜绽放数十朵雷花。

## 设计意图

为自然与雷电结合的法师提供种植型区域技能，扩展魔法植物世界观。
