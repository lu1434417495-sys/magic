# 《梦境锚点的下锚法》

## 基础信息

- **书籍 ID**：`book_法师咒术_0170`
- **关联技能**：`mage_dream_anchor`
- **使用效果**：阅读后解锁 `mage_dream_anchor`；若已学会，提升 `current_mastery +170` 并在下一次战斗中使梦境锚点首次触发时让目标陷入 1 回合沉睡。
- **阅读要求**：角色职业标签含 `mage` 或 `oneiromancer`；基础 `智力 ≥ 17` 且 `意志 ≥ 16`。
- **稀有度**：史诗（Epic）
- **建议投放**：梦境边界、睡神神庙、梦魇猎手营地。

## 书籍内容

梦境锚点是一种将现实中的物体与梦境世界相连的技艺，能让目标在接触锚点时短暂陷入施法者编织的梦境。本书从下锚材料开始，讲解如何选用与目标记忆相关的物件作为锚点核心。作者强调，锚点必须藏在意想不到的位置，太过明显会被目标的潜意识排斥。书中记录了梦境内容的设计原则：不能过于美好让人不愿醒来，也不能过于恐怖让人立刻惊醒。最末一章讨论脱身方案，因为目标在梦境中挣扎时，锚点可能会反噬施法者。批注写道：你种下的是一个念头，不是一座监狱。练习者需要先在自己的梦中下锚，观察自己何时会察觉异常。这门技艺在控制单个强敌时极为有效。

梦境锚点失败时最常见的反馈是施法者自己先陷入短暂幻觉，需立即咬舌清醒。

## 设计意图

为梦境主题法师提供控制技能，深化梦境与现实交织的设定。
