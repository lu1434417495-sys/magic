# 《放逐之环：异界边界》

## 基础信息

- **书籍 ID**：`book_法师咒术_0246`
- **关联技能**：`mage_banishment_circle`
- **使用效果**：阅读后解锁 `mage_banishment_circle`；若已学会，提升 `current_mastery +170` 并在下一次战斗中使首次放逐之环对召唤物与异界生物造成额外百分之五十伤害。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 16` 且 `意志 ≥ 14`。
- **稀有度**：史诗（Epic）
- **建议投放**：封印神殿、异界裂缝边缘、守门人传承密室。

## 书籍内容

放逐之环是在地面画出的圆形符文阵，能削弱甚至驱逐不属于这个世界的存在。书中强调，圆环的每一笔都代表一条边界规则，画错一笔可能把放逐变成邀请。作者详细记录了针对元素、恶魔、亡灵、星界生物等不同类别的圆环变体，每一种都有特定的符文组合。练习者需要先用粉笔在地上画上一千个完美的圆，直到手腕能自动画出闭合曲线。后半部讲解了如何在战斗中快速布设简化版放逐之环，以及如何配合队友把敌人逼入环中。最末页是一句被反复描粗的警告：圆圈之内是规则，圆圈之外才是世界。许多守门人会把这本书随身携带，仿佛它是某种护身符。书中还提醒，放逐之环对本土原生生物效果有限，不要浪费在普通强盗身上。放逐之环的光芒会让异界生物感到本能恐惧，犹如猎物遇见天敌。

## 设计意图

提供针对召唤物与异界生物的克制手段，让法师在特定遭遇战中成为关键对策角色。
