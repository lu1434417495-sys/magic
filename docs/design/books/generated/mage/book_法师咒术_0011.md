# 《宁神水滴：躁动魔力的镇定剂》

## 基础信息

- **书籍 ID**：`book_法师咒术_0011`
- **关联技能**：`mage_soothing_drop`
- **使用效果**：阅读后解锁 `mage_soothing_drop`；若已学会，提升 `current_mastery +80`，并在下一次战斗中使宁神水滴同时移除目标一个轻微负面状态。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 6`。
- **稀有度**：普通（Common）
- **建议投放**：溪边冥想点、草药师学徒书架、新手村治疗屋。

## 书籍内容

很多法师学徒在第一次成功施法后会兴奋得睡不着，魔力像野马一样在血管里乱跑。这本书教导一种简单的水系镇静技巧：在掌心凝聚一滴蕴含冷意的魔力水珠，然后让它在眉心慢慢融化。作者声称这个过程能把过度活跃的魔力循环拉回正常节奏。

前半部分详细记录了呼吸与凝水的配合时机，强调水滴必须小到能悬在指尖而不坠落。后半部分讲解战术用途：在队友受到轻微狂乱、灼热或恐惧影响时，宁神水滴可以快速稳定对方的精神状态。书中警告，这个咒语不能替代真正的治疗，它只能让混乱的人重新找回自己的节奏。最后附有一张被水渍泡糊的便签，似乎某位前任主人曾用它成功阻止了一场魔力暴走。

作者建议在清晨或雨后的溪边练习，因为水汽能够帮助魔力更快地凝聚成稳定的水滴形状。

## 设计意图

作为法师系早期辅助与状态管理技能解锁书籍，引入"魔力稳定性"概念，为团队成员提供基础支援手段，同时为水系与心灵镇静类法术建立熟练度链条。
