# 《法师挽歌的最后一个音节》

## 基础信息

- **书籍 ID**：`book_法师咒术_0150`
- **关联技能**：`mage_mage_requiem`
- **使用效果**：阅读后解锁 `mage_mage_requiem`；若已学会，提升 `current_mastery +200` 并在下一次战斗中使挽歌首次唱完时为全队恢复 8% 最大 MP。
- **阅读要求**：角色职业标签含 `mage` 或 `archmage`；基础 `智力 ≥ 19` 且 `意志 ≥ 16`。
- **稀有度**：传说（Legendary）
- **建议投放**：世界树根部禁书区、最终 boss 战利品、法师议会终极传承。

## 书籍内容

法师挽歌不是哀悼死者，而是为耗尽魔力的大地唱一首送别的歌。本书认为，每一个被施放的法术都会在世界某处留下细小的伤痕，而挽歌的作用是让这些伤痕暂时愈合。作者将挽歌分为九段，每一段对应一种元素或一种魔法学派，唱完最后一段时，施法者会与周围所有残余魔力共鸣。书中警告，挽歌不能被打断，一旦中断，愈合过程会反转为撕裂，对周围所有人造成伤害。第二章讨论如何在团队战中找到安全的咏唱位置，以及如何用防护咒语保护正在唱挽歌的法师。最末一页只有一个音节，旁边写着：最后一个音不是结束，而是让所有之前的咒语安心睡去。法师挽歌只能在魔力紊乱的战场上发挥全部效果，平静的练习场中唱出它只是普通的歌曲。许多年迈的法师在退休后仍会低声哼唱，作为对自己一生的告别。

## 设计意图

作为法师系的传说级团队回复与终局技能，强调牺牲、共鸣与魔法循环的闭合感。
