# 《火球术原典：第一朵焰心》

## 基础信息

- **书籍 ID**：`book_法师咒术_0051`
- **关联技能**：`mage_fireball`
- **使用效果**：阅读后解锁 `mage_fireball`；若已学会，提升 `current_mastery +120`，并在下一次战斗中使首枚火球爆炸范围向外扩展半格。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 8`。
- **稀有度**：稀有（Rare）
- **建议投放**：沉钟书库禁书区、法师塔入门试炼奖励、灰烬交界营地的老法师行囊。

## 书籍内容

原典第一页没有咒语，只有一句被烧穿的警告：'先学会熄灭，再学会点燃。'作者把火球术拆成'焰心'与'焰衣'两步，焰心负责稳定，焰衣负责伤害；新手常犯的错误是急着把魔力灌成焰衣，结果焰心太弱，火球离手三米就散成火星。

书中夹着半张焦黑的练习表，上面记录着同一法术在清晨、正午、雨天的不同表现，批注显示湿度每增加一成，起爆延迟约两个心跳。后半部是失败集锦：有人把火球捏成方形导致反弹，有人试图让火球悬停而烧掉了眉毛。最后一章只有一页，写着'火球不会问你准备好了没有，它只问你敢不敢放手。'

书末附有前任看守者的炭笔批注，称曾有一位法师在沉钟书库地下三层连续施放七百枚火球，最后整座塔的地砖都留下了焦黑的同心圆。许多法师在学会火球术后，会先拿这本书烧焦的边角练习熄灭。熄灭蜡烛后才能离开。
## 设计意图

作为法师系标志性入门输出技能的解锁书籍，强化'控制先于破坏'的咒术思维，同时为火焰系后续高阶法术奠定熟练度基础。
