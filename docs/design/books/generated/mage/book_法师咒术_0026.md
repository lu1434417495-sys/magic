# 《沙漏术：借用时间碎片的错觉》

## 基础信息

- **书籍 ID**：`book_法师咒术_0026`
- **关联技能**：`mage_sand_glass`
- **使用效果**：阅读后解锁 `mage_sand_glass`；若已学会，提升 `current_mastery +90`，并在下一次战斗中使沙漏术的效果持续时间延长 1 回合。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：沙漠神庙、时间研究者密室、考古学家营地。

## 书籍内容

沙漏术并不能真正控制时间，它只是让一小块区域内的时间感知变得模糊，从而让敌人的动作看起来比自己慢一拍。这本书的作者是一位痴迷于古代沙漏的学者，他认为时间不是河流，而是无数颗可以倒流的沙粒。前半部分教读者如何在眼前构建一个只有施术者自己能看见的魔力沙漏，并通过注视沙粒的流动来调整自己的节奏。

后半部分讲解实战应用：在敌人攻击即将命中时启动沙漏术，可以争取到宝贵的半拍反应时间。书中警告，这个咒语对施术者本人的精神负担极大，使用后会有一段时间感到周围的一切都在加速。最后一章记录了一位法师在沙漏术辅助下成功躲避了三十七支箭矢，代价是之后三天看任何东西都觉得在飞。

作者在书末附有一张他收藏的古代沙漏照片，声称真正优质的沙漏术需要配合特定比例的沙粒，普通河沙虽然可用，但效果会打折扣。

## 设计意图

为法师系提供早期时间感知类辅助技能，引入"时间"主题分支，强化战棋中的反应与节奏控制，同时为后续真正的时间系法术建立叙事铺垫与熟练度基础。
