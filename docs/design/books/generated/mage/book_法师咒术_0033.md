# 《寒冰新星：身边的冻结爆发》

## 基础信息

- **书籍 ID**：`book_法师咒术_0033`
- **关联技能**：`mage_ice_burst`
- **使用效果**：阅读后解锁 `mage_ice_burst`；若已学会，提升 `current_mastery +100`，并在下一次战斗中使寒冰新星首次命中时附加 1 回合定身。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 10`。
- **稀有度**：普通（Common）
- **建议投放**：冰元素祭坛、雪山法师塔、北方战场遗迹。

## 书籍内容

寒冰新星是冰系法师用来应对被近身包围时的经典反击：以自身为中心释放一圈急速扩散的寒气，把周围敌人推开并冻结他们的下肢。这本书的作者用亲身经历写道：学会这个咒语之前，请先学会判断敌人离你到底有多近，因为施放得太早会浪费，太晚则会施放不出来。

前半部分讲解如何在体内快速凝聚一个冰冷的魔力核心，并在受到威胁时瞬间释放。后半部分讨论战术细节：寒冰新星对被淋湿的敌人效果最佳，对穿着厚重毛皮的敌人则效果较差。书中还提到，这个咒语在室内施放时需要小心，因为飞溅的冰晶会让地面变得异常湿滑，连施术者自己也可能摔倒。最后一页是一幅插画，画着一个被冰霜包围的法师，四周是动作定格的敌人。

作者提醒，频繁使用寒冰新星会让手指末梢出现冻伤，因此施法后必须立即用体温回暖，不能立刻接触冰冷金属。

## 设计意图

为法师系提供早期近战防卫技能，强化被包围时的反击能力，同时作为冰系范围控制法术的入门，为后续更强大的冰霜新星与暴风雪类法术建立熟练度链条。
