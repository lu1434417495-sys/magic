# 《极寒领域的保温悖论》

## 书籍内容

极寒领域的秘密不是更冷，而是在极端寒冷中保留一丝温度。本书从保温悖论讲起，要求施法者在展开领域时，于自己心脏位置维持一个微小的热源。这个热源不是为了取暖，而是为了作为温度对比的核心，让周围的寒冷显得更刺骨。作者强调，若施法者自身完全失温，领域会失去控制，反而把自己也冻成雕像。书中收录了五种维持核心热度的呼吸法，以及在不同气候下的调整方式。作者警告，极寒领域对植物与水源的破坏是永久性的，因此不应在生态脆弱区使用。第二章讨论如何让敌人在不知不觉中踏入领域边界。最末一页写着：真正的寒冷，是让你忘记温暖曾经存在。极寒领域的边界往往不易察觉，施法者可以用细小的冰晶折射光线来标示范围。作者警告，领域内的友军同样需要保温措施，否则胜利将是惨胜。
