# 《咒文压缩的标点学》

## 基础信息

- **书籍 ID**：`book_法师咒术_0139`
- **关联技能**：`mage_glyph_compression`

## 书籍内容

冗长的咒文往往被标点拖累，而标点本身也可以是咒语的一部分。本书教授如何通过省略、合并与转写标点，将一段十秒的咒文压缩到三秒内。作者将咒文标点分为停顿符、强调符、转折符与终止符四类，并给出各自的压缩规则。书中警告，过度压缩会让咒文失去清晰度，导致法术目标偏移或威力减半。第二章提供了一系列练习：把常见咒语逐句拆解，再重新组合成最短有效版本。作者建议在镜子前练习，因为嘴唇的微小动作会影响压缩后的发音稳定性。最末一页是一行被极度压缩的咒语，正常人读起来像一声咳嗽，批注写着：标点不是休息，而是让咒语记住自己该去哪里。初学者在压缩咒文时最常犯的错误是把终止符也省略，结果法术无限回荡在自身周围。作者用整整一章列举了各种失控案例，供读者引以为戒。
