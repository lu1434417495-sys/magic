# 《等离子光束的聚焦课》

## 基础信息

- **书籍 ID**：`book_法师咒术_0085`
- **关联技能**：`mage_plasma_beam`
- **使用效果**：阅读后解锁 `mage_plasma_beam`；若已学会，提升 `current_mastery +150` 并在下一次战斗中使首次等离子光束命中后附加 2 回合导电标记。
- **阅读要求**：角色职业标签含 `mage` 或 `elementalist`；基础 `智力 ≥ 13` 且 `感知 ≥ 10`。
- **稀有度**：史诗（Epic）
- **建议投放**：高阶元素实验室、雷暴核心据点、古代能量塔遗迹。

## 书籍内容

等离子光束是火与电的边界产物，它要求施术者同时维持两种相互排斥的元素。前半本讲解聚焦原理：光束不是越粗越好，过粗的光束会在空气中散失能量，真正有效的是核心那一缕被极度压缩的等离子线。作者要求练习者先学会用普通火焰和静电分别画出直线，再尝试让两者重合。

书中警告，等离子光束会电离周围空气，施术者本人的毛发可能会因此竖起，甚至产生轻微电击感。后半部是战术运用：这种光束对金属护甲和潮湿目标有额外效果，但对绝缘良好的皮革效果较差。高阶元素实验室的墙壁采用导电涂层，因为失控的等离子光束会在墙面上留下永久的发光轨迹。

等离子光束的实验室禁止穿金属纽扣。金属纽扣禁令源于事故。等离子喜欢导体。光束偏爱直线。等离子危险。
## 设计意图

史诗级元素混合输出书籍，解锁等离子光束并提供高穿透与导电协同，强调元素边界与聚焦控制。
