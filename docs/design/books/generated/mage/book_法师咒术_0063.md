# 《力场墙的建筑学》

## 基础信息

- **书籍 ID**：`book_法师咒术_0063`
- **关联技能**：`mage_force_wall`
- **使用效果**：阅读后解锁 `mage_force_wall`；若已学会，提升 `current_mastery +120` 并提升力场墙耐久 `+10%`。
- **阅读要求**：角色职业标签含 `mage` 或 `abjurer`；基础 `智力 ≥ 11`。
- **稀有度**：稀有（Rare）
- **建议投放**：防护学派高塔、战场工程师营地、古战场遗迹宝箱。

## 书籍内容

力场墙不是一块板，而是一座微型建筑。作者把每面力场墙拆成基座、拱肋与锚点三部分，基座负责接地，拱肋负责分散冲击，锚点则把剩余力量导入地面。前半本要求读者用木棍和绳子搭建等比例模型，体验'墙在受力时的呼吸'。

书中强调，最稳固的力场墙不是垂直于敌人，而是与来袭方向呈六十度角，这样能让冲击力沿墙面滑走。后半部讨论了'墙的伦理'：一道保护正面却堵住退路的墙，比没有墙更危险。最后一页是一张开裂的图纸，上面画着力场墙与友军通道的配合方式，批注'墙是空间的语言，别忘了给同伴留门。'

防护学派高塔的地基里嵌着古代力场墙的碎片，据说这些碎片至今仍能在地震时吸收一部分震动。力场墙的建筑师们认为，最稳固的墙从不完全封闭。不完全封闭理念影响城防。
## 设计意图

稀有级防护地形书籍，解锁力场墙并为团队提供空间分割工具，强调防护法师的战场建筑师角色。
