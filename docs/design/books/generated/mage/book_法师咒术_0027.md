# 《鬼灯笼：引路的光与诱饵的光》

## 基础信息

- **书籍 ID**：`book_法师咒术_0027`
- **关联技能**：`mage_ghost_lantern`
- **使用效果**：阅读后解锁 `mage_ghost_lantern`；若已学会，提升 `current_mastery +90`，并在下一次战斗中使鬼灯笼的诱饵持续时间延长 1 回合。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：墓地守夜人处、鬼市摊贩、通灵师协会藏书阁。

## 书籍内容

鬼灯笼是一种看起来阴森却极其实用的咒术：施术者召唤出一盏漂浮的冷光灯笼，它可以缓慢移动，吸引某些敌人的注意力，也可以在黑暗中为队伍引路。这本书的作者声称，最早的鬼灯笼是用来安抚亡魂的，后来被战场法师改造成了一种廉价的诱饵。

前半部分讲解如何给灯笼注入"温和"的魔力，避免它变成吸引恶灵的信号灯。后半部分讨论战术用法：把鬼灯笼送到战场另一侧，让远程敌人把它当成施术者本人进行攻击。书中警告，鬼灯笼对高感知敌人效果有限，他们很快就能识破这种简单的伪装。最后一页附有一张古老的葬礼路线图，显示某盏鬼灯笼如何引导一支迷路的商队走出沼泽。

书中还介绍了鬼灯笼的移动路径设定方法，比如让它沿着墙壁缓慢飘行，模拟施术者贴边移动的样子，从而误导敌人的预判。

## 设计意图

为法师系提供早期召唤诱饵与照明技能，强化战棋中的目标引导与团队机动，同时为后续亡灵系、通灵系与幻影召唤类法术建立熟练度与叙事连接。
