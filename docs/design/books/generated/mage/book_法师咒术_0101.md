# 《灵火织网：奥术回路入门》

## 基础信息

- **书籍 ID**：`book_法师咒术_0101`
- **关联技能**：`mage_arcane_weave`
- **使用效果**：阅读后解锁 `mage_arcane_weave`；若已学会，提升 `current_mastery +160` 并在下一次战斗中使首张罗网额外束缚目标 1 回合。
- **阅读要求**：角色职业标签含 `mage` 或 `archmage`；基础 `智力 ≥ 16` 且 `感知 ≥ 12`。
- **稀有度**：史诗（Epic）
- **建议投放**：高塔奥术研究所、元素裂隙深层宝箱、传奇法师遗赠。

## 书籍内容

灵火并非单纯的火焰，而是意志在魔网中留下的纹路。本书从最基本的回路起手，教导施法者如何在指尖编织出三条彼此咬合的奥术丝线。作者强调，织网的关键不在于力量大小，而在于节奏：太早收紧会让丝线崩断，太晚则敌人已经脱身。书中记录了常见断点与呼吸法接续技巧。后半部分介绍如何将织网与火元素结合，使罗网在收缩时产生灼烧。最末一章是一页空白，批注写着：真正的网不是捕捉身体，而是困住对方的下一步。许多高阶法师会在空白页上留下自己的失败记录，作为后来者的警示。作者建议每次训练只增加一条丝线，急于求成的人往往会被自己的回路反噬。真正熟练的法师能在战斗中边移动边织网，把行走本身变成咒语的一部分。

## 设计意图

为后期法师提供控制与输出结合的进阶法术，强化战棋中的走位限制与先手压制感。
