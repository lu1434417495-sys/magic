# 《气泡壳：水中的呼吸法》

## 基础信息

- **书籍 ID**：`book_法师咒术_0015`
- **关联技能**：`mage_bubble_shell`
- **使用效果**：阅读后解锁 `mage_bubble_shell`；若已学会，提升 `current_mastery +80`，并在下一次战斗中使气泡壳的水下持续时间延长 2 回合。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 6`。
- **稀有度**：普通（Common）
- **建议投放**：水下遗迹入口、渔村老法师家、沉船货舱。

## 书籍内容

这本书的纸张经过特殊处理，即使被水浸泡也不会变形。气泡壳是一个简单却非常实用的水系法术：在头部周围制造一个充满空气的魔力薄膜，让施术者能够在水下自由呼吸。作者开篇就说，很多伟大的法师之所以英年早逝，仅仅是因为他们不会游泳。

前半部分讲解如何维持气泡壳的稳定形状，重点是把空气循环出口放在头顶，这样呼出的二氧化碳才不会在面部附近积聚。后半部分讨论战斗中的应用：除了潜水探索，气泡壳还可以在一定程度上抵挡有害气体、花粉或粉尘攻击。书中警告，气泡壳不能抵挡直接物理攻击，受到重击后它会像肥皂泡一样破裂。最后附有一张手绘地图，标注着某条河流下的隐藏洞穴入口。

对于深水探险，作者提醒气泡壳会随深度增加而承受压力，超过一定限度后需要持续注入魔力来维持形态。

## 设计意图

为法师系提供早期环境适应技能，拓展探索维度与特殊地形通过能力，同时作为水系法术的入门，为后续气泡类防御与水下战斗法术建立熟练度基础。
