# 《虚空花开的灌溉》

## 基础信息

- **书籍 ID**：`book_法师咒术_0199`
- **关联技能**：`mage_void_bloom`
- **使用效果**：阅读后解锁 `mage_void_bloom`；若已学会，提升 `current_mastery +200` 并在下一次战斗中使虚空花开绽放时随机驱散范围内敌人一个增益效果。
- **阅读要求**：角色职业标签含 `mage` 或 `void_gardener`；基础 `智力 ≥ 19` 且 `意志 ≥ 17`。
- **稀有度**：传说（Legendary）
- **建议投放**：虚空花园、星界温室、异界植物园核心。

## 书籍内容

虚空花是一种以不存在之物为养分的诡异植物，开花时会吞噬周围的光芒与增益。本书从灌溉开始，讲解如何用静默、遗忘和一小段真实的记忆喂养虚空花的根系。作者强调，虚空花不需要阳光和水，它需要被忽视。过度关注会让它枯萎，完全遗忘则会让它失控。书中记录了不同品种的开花形态：有的像黑洞般吸收一切，有的像银色花瓣般缓慢剥离现实，还有的会释放出让人失语的香气。第二章讨论如何在战场上种植虚空花，作者建议提前埋下种子，再用敌人的注意力浇灌它。最末一页写着：花开之处，存在的边界变薄。练习者需要学会在不看、不想、不期待的情况下培育虚空花。这门技艺在驱散敌方增益和制造混乱方面极具威胁。

虚空花开绽放时没有声音，被驱散的光芒仿佛从未存在过，只留下一片让人不安的寂静。

## 设计意图

为虚空主题法师提供范围驱散技能，将虚空植物与存在哲学结合。
