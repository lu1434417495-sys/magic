# 《水鞭：柔流抽击》

## 基础信息

- **书籍 ID**：`book_法师咒术_0230`
- **关联技能**：`mage_water_whip`
- **使用效果**：阅读后解锁 `mage_water_whip`；若已学会，提升 `current_mastery +140` 并在下一次战斗中使首记水鞭附带缴械效果。
- **阅读要求**：角色职业标签含 `mage` 或 `elementalist`；基础 `智力 ≥ 12` 且 `感知 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：水元素祭坛、沉没图书馆、河神神庙。

## 书籍内容

水鞭是将水流凝聚成可伸缩长鞭的法术，看似柔软，抽击时却能留下淤青甚至骨折。书中第一节要求练习者先学会让一碗水立起来，再尝试把它甩成鞭状。作者认为，水鞭的威力来自速度而非重量，甩得越快，水分子之间的张力就越强。后半部讲解了如何利用水鞭缠绕敌人武器并甩飞，以及如何在鞭梢加入冰晶增加切割力。最末页是一幅被水渍晕染的插画，描绘了一位法师用水鞭从敌人手中夺下长剑的场景。许多水元素法师会把这本书放在浴室里，因为练习水鞭时最好有水龙头在旁边。书中还提醒，水鞭在极寒环境中会自然结冰，失去柔韧性，需要额外加热才能维持液态鞭身。水鞭练习者在初学阶段常常把自己淋湿，因此附近总有晾衣绳。熟练之后，他们甚至能用水鞭在远处开关门窗，省去起床的麻烦。

## 设计意图

提供中距离控制与缴械能力，让法师能削弱敌方物理输出，增强水系法术的战术价值。
