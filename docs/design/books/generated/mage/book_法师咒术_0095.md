# 《符文魔像的核心语法》

## 基础信息

- **书籍 ID**：`book_法师咒术_0095`
- **关联技能**：`mage_runic_golem`
- **使用效果**：阅读后解锁 `mage_runic_golem`；若已学会，提升 `current_mastery +150` 并提升魔像攻击力 `+10%`。
- **阅读要求**：角色职业标签含 `mage` 或 `artificer`；基础 `智力 ≥ 14` 且 `体质 ≥ 9`。
- **稀有度**：史诗（Epic）
- **建议投放**：符文工坊、古代魔像墓地、工匠神殿密室。

## 书籍内容

符文魔像的核心不是石头，而是刻在石头里的'语法'。前半本是一份语法教材，作者把魔像的行为拆成主语、谓语和状语：主语决定它守护谁，谓语决定它如何攻击，状语决定它在什么条件下行动。书中强调，一个语法错误不会让魔像失控，但会让它变得非常礼貌，比如在攻击前先说一声'请'。

中段收录了核心维护：魔像的动力符文需要定期用施术者的血重新描边，但血量过多会让魔像变得暴躁。后半部讨论命令链：魔像可以理解最多三层嵌套命令，超过三层它会把命令倒过来执行。

符文工坊的学徒第一课是擦拭一块已经报废的魔像核心，老师要求他们读三遍核心上的符文，再决定如何修复。符文魔像的报废核心埋在工坊地板下。报废核心深夜微弱发光。核心沉默却从不真正死去。核心待唤醒。
## 设计意图

史诗级召唤/构装书籍，解锁符文魔像并为法师提供强力战斗召唤物，强调符文语法与维护成本。
