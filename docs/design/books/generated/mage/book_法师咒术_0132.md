# 《影缚术的挣脱与加固》

## 基础信息

- **书籍 ID**：`book_法师咒术_0132`
- **关联技能**：`mage_shadow_bind`
- **使用效果**：阅读后解锁 `mage_shadow_bind`；若已学会，提升 `current_mastery +160` 并在下一次战斗中使影缚首次命中时束缚回合数增加 1 回合。
- **阅读要求**：角色职业标签含 `mage` 或 `warlock`；基础 `智力 ≥ 16` 且 `敏捷 ≥ 12`。
- **稀有度**：史诗（Epic）
- **建议投放**：影塔藏书阁、刺客法师训练场、黑市束缚术商人。

## 书籍内容

影缚术的核心在于理解影子不是物体的附属，而是物体在另一个维度上的延伸。本书先教如何加固自己的影子，使其不易被敌人利用；再教如何用咒语刺入对方影子的关节处，让目标在现实中动弹不得。作者指出，挣脱影缚的关键不是用力，而是改变光源方向：一个突然的强光会让影子短暂缩小，从而制造逃脱窗口。书中收录了五种常见光源下的影缚强度变化，以及如何利用火把、镜子和云层来操控战场阴影。作者警告，不要在完全黑暗中施放影缚，因为没有影子的目标反而会让咒语反噬。最末一页画着一只被自己的影子缠住的手，批注写道：束缚别人之前，先确保自己不被影子绊倒。作者建议在战斗中随身携带一枚可调节亮度的光源戒指，以便在关键时刻改变自己的影子形态。影缚术高手往往也是光影布局的大师。

## 设计意图

为暗影控制型法师提供强力的单体控制，强调光影环境对战局的影响。
