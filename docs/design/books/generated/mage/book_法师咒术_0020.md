# 《空洞音符：用沉默制造声音》

## 基础信息

- **书籍 ID**：`book_法师咒术_0020`
- **关联技能**：`mage_hollow_note`
- **使用效果**：阅读后解锁 `mage_hollow_note`；若已学会，提升 `current_mastery +90`，并在下一次战斗中使空洞音符的迷惑效果额外影响一个目标。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：吟游诗人公会暗房、音乐厅地下室、声音研究者实验室。

## 书籍内容

空洞音符是一种奇怪的咒术，它不是发出声音，而是瞬间抽空一小块区域内的空气振动，制造出令人不安的绝对寂静。这本书的作者认为，真正的恐惧不是来自巨响，而是来自声音突然消失的那一刻。前半部分教读者如何精准定位需要沉默的空间，误差不能超过一个拳头大小。

后半部分讲解战术应用：在敌人吟唱咒语时释放空洞音符，可以打断对方的施法节奏；在己方移动时释放，则可以消除脚步声。书中还提到，过度使用这个咒语会让施术者自己的耳朵产生耳鸣，仿佛整个世界都在低语。最后一章记录了某位法师用空洞音符成功阻止了一场爆炸：他在爆炸发生的瞬间抽空了空气，让火焰无法传播。

作者还在附录中讨论了沉默区域的大小控制，太大容易误伤队友，太小则无法覆盖敌人的吟唱范围。

## 设计意图

为法师系提供早期控制与打断技能，强化战棋中的施法节奏对抗，同时引入"声音作为介质"的魔法概念，为后续音波系与沉默系法术建立熟练度连接。
