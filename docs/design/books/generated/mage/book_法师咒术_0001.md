# 《星火初触：施法者第一课》

## 基础信息

- **书籍 ID**：`book_法师咒术_0001`
- **关联技能**：`mage_spark_touch`
- **使用效果**：阅读后解锁 `mage_spark_touch`；若已学会，提升 `current_mastery +80`，并使下一次战斗中的首次火花触碰必定暴击。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 6`。
- **稀有度**：普通（Common）
- **建议投放**：新手法师训练室、沉钟书库入门架、杂货商人的旧书堆。

## 书籍内容

大多数学徒第一次把魔力逼出指尖时，只会得到一阵静电和一声咒骂。本书不厌其烦地重复一个事实：火花不是终点，而是起点。作者用三十页篇幅教人如何坐在原地，把情绪波动从掌心排出，直到指尖能感受到空气里飘浮的微尘。真正的难点在于控制放电的方向，而不是放电本身。

书中夹有一张烧焦的练习记录，显示某位学徒连续七天只能把火花射向左边。第八天，他突然学会了把目标换成蜡烛芯。作者在旁边批注：方向错了没关系，重要的是别烧到自己的眉毛。后半部记录了几种常见的错误手势，比如握拳会让魔力回流，食指单独伸出则会让火花跑偏。最后一页只有一句话：先让火花听你，再让它听话。

书末还附有一套每日练习清单，从清晨的指尖放电到睡前的方向控制，作者相信坚持三个月的人才能真正驾驭这枚最初的火花。

## 设计意图

作为法师系最基础的攻击技能解锁书籍，降低新手对咒术系统的畏惧感，同时建立"魔力控制优先于威力"的核心认知，为后续元素法术的学习奠定熟练度基础。
