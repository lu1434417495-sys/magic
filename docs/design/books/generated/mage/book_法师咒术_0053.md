# 《奥术飞弹的十六种偏差》

## 基础信息

- **书籍 ID**：`book_法师咒术_0053`

- **使用效果**：阅读后解锁 `mage_arcane_missile`；若已学会，提升 `current_mastery +110` 并让下一次战斗中首次施放多弹射一枚。

## 书籍内容

书名里的'偏差'不是错误，而是飞弹必须经历的轨道修正。作者用十六张示意图展示同一发奥术飞弹在七种情绪状态下的飞行姿态：愤怒时飞弹过直，容易被格挡；恐惧时飞弹会绕弯，命中率反而提高。书中核心观点是，奥术飞弹不是被'发射'出去，而是被'放开'；施术者越想把飞弹攥紧，它越会偏向。

第五章专门讲'同步呼吸'——三枚飞弹必须落在同一呼气节奏里，否则它们会在空中互相追逐，最后撞成光尘。后半部是一份事故记录：某学徒为追求完美同步，连续施放十七次后昏厥，醒来发现自己的魔力池形状变成了螺旋。

沉钟书库第三任看守者在讲义扉页写下备注，称真正的奥术飞弹大师能从偏差中读出目标的魔力流动方向。沉钟书库规定，读过这本书的人必须上交三页偏差记录。偏差记录与书一并上交。
## 设计意图

将奥术飞弹定位为法师'稳定多段输出'的基石技能，通过'偏差即修正'的理念塑造法师系咒术控制的美学。
