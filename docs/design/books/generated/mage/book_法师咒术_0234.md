# 《静电力场：电荷囚笼》

## 基础信息

- **书籍 ID**：`book_法师咒术_0234`
- **关联技能**：`mage_static_field`
- **使用效果**：阅读后解锁 `mage_static_field`；若已学会，提升 `current_mastery +150` 并在下一次战斗中使首次静电力场持续期间敌人每次移动都受到伤害。
- **阅读要求**：角色职业标签含 `mage` 或 `stormcaller`；基础 `智力 ≥ 14` 且 `感知 ≥ 11`。
- **稀有度**：稀有（Rare）
- **建议投放**：雷电实验室、风暴云层、古代雷兽巢穴。

## 书籍内容

静电力场是在一片区域内充满游离电荷的法术，任何移动都会引发小规模电击。书中把力场比作一张看不见的电网，敌人越是挣扎，受到的伤害就越多。作者详细讲解了如何平衡电荷密度：太高会提前消散，太低则无法形成有效威慑。练习者需要先在羊毛毯上摩擦双手，感受静电积累的微妙过程。后半部讲解了如何让静电力场与金属地形或敌人装备互动，放大伤害效果。最末页是一段被电得卷曲的纸条，上面写着：动得越快，死得越快。许多雷法师会在战斗前故意脱掉金属饰品，以免误伤自己。书中还附有一页绝缘鞋制法，提醒在自立场场中移动时接地是关键，否则自己也会成为闪电的靶子。静电力场中每个人的头发都会竖起，因此这法术不适合在正式宴会上使用。但它却是清理身上灰尘的意外好手，只需站进去再走出来即可。

## 设计意图

提供区域持续压制，限制敌方走位并惩罚移动，增强雷系控场的层次感。
