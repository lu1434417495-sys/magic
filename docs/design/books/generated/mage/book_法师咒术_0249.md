# 《元素庇护：万法之盾》

## 基础信息

- **书籍 ID**：`book_法师咒术_0249`
- **关联技能**：`mage_elemental_ward`
- **使用效果**：阅读后解锁 `mage_elemental_ward`；若已学会，提升 `current_mastery +160` 并在下一次战斗中使首次元素庇护同时抵抗两种元素伤害。
- **阅读要求**：角色职业标签含 `mage` 或 `elementalist`；基础 `智力 ≥ 15` 且 `感知 ≥ 12`。
- **稀有度**：史诗（Epic）
- **建议投放**：元素议会圣殿、四元素交汇祭坛、古代守护者陵墓。

## 书籍内容

元素庇护是在施法者周围形成一层由四种基础元素调和而成的护盾，能根据受到的攻击自动调整抗性。书中把庇护比作一支小型议会，火、水、土、风在受到伤害时轮流发言。作者强调，只有让四种元素保持平衡，庇护才能发挥最大效果，偏向任何一种都会留下明显弱点。练习者需要先在四种元素环境中各冥想一夜，感受它们各自的脾气。后半部讲解了如何主动指定庇护的主导元素，以应对已知的敌方攻击类型。最末页是一句被四种颜色墨水共同写成的格言：没有元素能单独保护你。许多元素法师会在施展此术后感到四种不同的温度同时拂过皮肤。书中还提醒，元素庇护对纯物理攻击效果有限，因此不要用它硬接战士的巨剑。

## 设计意图

提供元素抗性护盾，让法师能根据敌方属性灵活防御，增强元素流派的生存能力。
