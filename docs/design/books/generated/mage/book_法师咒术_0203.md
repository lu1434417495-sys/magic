# 《雷行步法：疾电无踪》

## 基础信息

- **书籍 ID**：`book_法师咒术_0203`
- **关联技能**：`mage_thunder_step`
- **使用效果**：阅读后解锁 `mage_thunder_step`；若已学会，提升 `current_mastery +160` 并在下一次战斗中使首次雷行不触发借机攻击。
- **阅读要求**：角色职业标签含 `mage` 或 `elementalist`；基础 `敏捷 ≥ 12` 且 `智力 ≥ 14`。
- **稀有度**：史诗（Epic）
- **建议投放**：风暴尖塔顶层、雷电祭坛遗迹、精英法师追猎者掉落。

## 书籍内容

雷行步法不是跑得更快，而是让身体短暂化作一道电弧，沿着空气中游离的静电抵达目标位置。书中要求练习者先在雷雨天赤脚站在铜盘上，感受电流从脚底涌入的感觉。作者强调，雷行的落点必须预先在脑中画好，否则容易卡在墙里或出现在敌人怀里。前半部分列举了三十七种常见地形对电弧路径的影响，包括水面会增强距离、金属栅栏会分散落点、潮湿泥土会让出口偏移半尺。后半部介绍如何利用雷行制造残影，让敌人在你消失的瞬间误判方向。最末页只有一道闪电形状的焦痕，旁边小字写着：电不会等你准备好，它只等通道。许多法师用这招逃离餐桌上的尴尬对话。精通者甚至能在雷行途中抛下一枚带电诱饵，让追击者误以为你仍停留在原地。老练的雷法师会把失败的落点记录在册，久而久之形成一本专属的雷电地图。

## 设计意图

为法师提供高机动性位移，打破战棋中施法者站桩输出的刻板印象，增强战场生存能力。
