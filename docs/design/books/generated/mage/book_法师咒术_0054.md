# 《连锁闪电的节点演算》

## 基础信息

- **书籍 ID**：`book_法师咒术_0054`
- **关联技能**：`mage_chain_lightning`
- **使用效果**：阅读后解锁 `mage_chain_lightning`；若已学会，提升 `current_mastery +140` 并提升下一次战斗中的首次跳跃伤害 `+8%`。
- **阅读要求**：角色职业标签含 `mage`；基础 `智力 ≥ 12` 且 `感知 ≥ 8`。
- **稀有度**：稀有（Rare）
- **建议投放**：风暴祭坛密室、高塔图书馆闪电区、元素使试炼奖励。

## 书籍内容

这本书要求读者先学会画'节点图'：把敌人、地面金属物、潮湿格子都标成点，再用线估算闪电最可能的路径。作者反复强调，连锁闪电不是瞄准目标，而是给自然电流一个'更好的理由'。

书中用一整章讲解'湿度税'——每道跳跃都会因空气干燥而损失一部分威力，精明的法师会提前在地面洒下一小片水渍作为导电桥。后半部是战场案例分析：一名法师在峡谷战中利用敌人盔甲上的铆钉制造额外节点，让一道闪电跳跃了五次。

最后一页被雷烧焦，只剩几个大字：'不要站在自己的传导路径上。'

风暴祭坛的祭司相信，每一次成功跳跃的闪电都是天空对施术者计算能力的认可，而失败则是云层在嘲笑。风暴祭坛的闪电从不重复同一轨迹，因此这本书每十年就要增补。云层嘲笑比成功更珍贵。云层自有记忆。
## 设计意图

稀有级雷电系进阶书籍，把连锁闪电从'随机弹跳'提升为'环境预判与节点布局'，鼓励法师在战斗前调整站位与地形。
