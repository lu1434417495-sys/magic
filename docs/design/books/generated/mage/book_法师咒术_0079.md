# 《沉默法球的咽喉记忆》

## 基础信息

- **书籍 ID**：`book_法师咒术_0079`
- **关联技能**：`mage_silence_orb`
- **使用效果**：阅读后解锁 `mage_silence_orb`；若已学会，提升 `current_mastery +130` 并扩大沉默区域半径半格。
- **阅读要求**：角色职业标签含 `mage` 或 `abjurer`；基础 `智力 ≥ 11` 且 `意志 ≥ 9`。
- **稀有度**：稀有（Rare）
- **建议投放**：反咒学院密室、法师猎手营地、寂静修道院藏书。

## 书籍内容

沉默法球剥夺的不是声音，而是'言语成形前的最后一瞬'。前半本讲解咽喉记忆：施术者必须先记住自己念诵咒语时喉咙的震动方式，再用相反的方式去压制它。作者指出，沉默法球对依赖咒语的法师最有效，对依靠血脉或斗气的敌人效果有限。

中段收录了一份'沉默礼仪'：施放沉默法球前应尽量避免说话，因为刚刚用过声带的人更容易被自己的法术反噬。后半部是战术讨论：最致命的沉默不是罩住敌人，而是罩住自己与敌人的交界，让敌人在冲过来时才发现已经念不出咒语。

寂静修道院的修女们用沉默法球进行冥想训练，她们认为能在一刻钟内完全不说话的人，才有资格学习真正的沉默。沉默法球的修女们在食堂用手势交流。食堂手势让用餐极安静。沉默是最难维持的法术。沉默最难守。
## 设计意图

稀有级反制法術书籍，解锁沉默法球并提供范围禁言能力，强调对施法机制的压制与战术区域控制。
