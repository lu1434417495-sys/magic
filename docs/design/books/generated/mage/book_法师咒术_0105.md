# 《咒术过载的呼吸阀》

## 基础信息

- **书籍 ID**：`book_法师咒术_0105`
- **关联技能**：`mage_spell_overload`
- **使用效果**：阅读后解锁 `mage_spell_overload`；若已学会，提升 `current_mastery +180` 并在下一次战斗中使首个过载法术伤害提高 15%，但额外消耗 10% MP。
- **阅读要求**：角色职业标签含 `mage` 或 `battlemage`；基础 `智力 ≥ 18` 且 `冥想 ≥ 3`。
- **稀有度**：史诗（Epic）
- **建议投放**：战场废墟、军事法师训练营、高阶冥想密室。

## 书籍内容

咒术过载的本质是在咒语完成前的最后一刻强行灌入更多魔力，如同在封闭的锅炉里追加燃料。本书第一章警告：没有呼吸阀的过载等于自杀。作者将呼吸阀定义为施法者意识中的一个微小出口，用于在魔力暴走时释放多余压力。第二章给出具体的节奏练习：吸气时蓄能，屏息时压缩，呼气时喷发。书中记录了九种常见的过载失控征兆，从指尖发麻到耳鸣，再到短暂的色盲。作者建议初学者先用低阶火球练习，直到能在过载后三秒内恢复正常呼吸。最后一页的批注写道：真正的强大不是烧得更多，而是知道什么时候让火焰退回去。战场上使用这门技艺时，队友的掩护与撤退路线同样重要，因为过载后的短暂虚弱会让法师变得异常脆弱。

## 设计意图

为输出型法师提供高风险高收益的爆发选项，强调资源管理与施法节奏的掌控。
