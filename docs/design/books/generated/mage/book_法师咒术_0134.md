# 《法力燃烧的灰烬利用》

## 基础信息

- **书籍 ID**：`book_法师咒术_0134`
- **关联技能**：`mage_mana_burn`
- **使用效果**：阅读后解锁 `mage_mana_burn`；若已学会，提升 `current_mastery +170` 并在下一次战斗中使法力燃烧首次命中时额外消耗目标 5% MP。
- **阅读要求**：角色职业标签含 `mage` 或 `battlemage`；基础 `智力 ≥ 17` 且 `冥想 ≥ 4`。
- **稀有度**：史诗（Epic）
- **建议投放**：魔导战争学院、灰烬交界战场、高阶冥想密室。

## 书籍内容

法力燃烧不是摧毁敌人的魔力，而是将其魔力强行转化为热量并释放。本书从灰烬利用入手，教授如何收集燃烧后的残渣，将其二次利用为临时护盾或引火材料。作者强调，燃烧越彻底，灰烬越少；而灰烬越少，回收价值越低，因此需要找到一个平衡点。书中记录了七种常见种族的魔力燃烧特征：精灵的灰烬带花香，矮人的灰烬含金属碎屑，恶魔的灰烬则会轻微腐蚀容器。作者警告，对同一目标连续燃烧会让其魔力产生抗性，效果迅速递减。第二章介绍如何在团队战中配合盗贼或弓箭手，让敌人在失去魔力后难以逃跑。最末一页写着：燃烧是最后的礼貌，灰烬是战后的收据。法力燃烧产生的灰烬若不及时处理，可能被敌方土系法师利用。作者建议在战斗结束后立刻用风吹散或用水浸透，避免留下可被追踪的魔力痕迹。

## 设计意图

为战斗法师提供法力消耗型控制，强化对施法敌人的压制与战后资源回收。
