# 《咒术交响的指挥棒》

- **书籍 ID**：`book_法师咒术_0190`
- **关联技能**：`mage_spell_symphony`

## 书籍内容

咒术交响是一种将多个法师的施法节奏统一起来，形成协同爆发的高级战术。本书从指挥棒的选择开始，讲解如何用特定材质的法杖引导团队咒语进入同一节拍。作者强调，指挥者的作用不是代替施法，而是让每个人的咒语在正确的时间点相互增强。书中记录了常见的乐章结构：前奏用于削弱敌人，主奏集中火力，尾声则负责清理残余。第二章讨论如何处理团队中的不和谐音，当某个法师节奏错误时，指挥者必须及时调整，否则整个交响会崩溃。最末一页写着：一个人的咒语是声音，一群人的咒语是浪潮。练习者需要先与至少两名同伴进行基础合奏，逐步增加复杂度。这门技艺在多人法师团队中能成为决定性力量。

指挥者必须熟悉每位队员的施法习惯，才能在他们出手的瞬间给出正确节拍。

## 设计意图

为团队法师提供协同增益指挥技能，强化多人配合与节奏主题。
