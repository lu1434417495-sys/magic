# 《活体纹身的墨水调配》

## 基础信息

- **书籍 ID**：`book_法师咒术_0172`
- **关联技能**：`mage_living_tattoo`
- **使用效果**：阅读后解锁 `mage_living_tattoo`；若已学会，提升 `current_mastery +160` 并在下一次战斗中使活体纹身首次激活时免疫一次控制效果。
- **阅读要求**：角色职业标签含 `mage` 或 `tattooist`；基础 `智力 ≥ 17` 且 `意志 ≥ 15`。
- **稀有度**：史诗（Epic）
- **建议投放**：纹身密室、部落祭坛、人体改造诊所。

## 书籍内容

活体纹身不是装饰，而是将法术以图案形式封印在皮肤下的技艺。本书从墨水调配开始，讲解如何用魔兽血液、魔力草药和少量施法者自身法力调制出能与皮肤共生的颜料。作者强调，纹身的部位决定了效果：胸口增强防御，手臂强化攻击，而脊椎则与机动性相关。书中记录了不同图案对应的咒语，以及如何在战斗中用意念激活它们。最末一章讨论失败后果，劣质墨水会导致纹身反噬，在皮肤上自行蠕动。批注写道：你的身体是一本正在书写的书，纹身只是其中一页。练习者需要先在动物皮革上练习，确认墨水稳定后再刺入自己皮肤。这门技艺让法师在无法持咒时仍能保留反击手段。

纹身颜料在皮肤下流动时会带来轻微痒感，那是法术正在与血肉建立连接。

活体纹身在施法者沉睡时会自行发出微光，部落中的长者认为那是皮肤下的法术在梦中继续练习。

## 设计意图

为法师提供被动防御与身体改造机制，扩展纹身魔法的世界观。
