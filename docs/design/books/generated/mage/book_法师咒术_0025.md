# 《余烬闪烁：短距离内的残像》

## 基础信息

- **书籍 ID**：`book_法师咒术_0025`
- **关联技能**：`mage_ember_blink`
- **使用效果**：阅读后解锁 `mage_ember_blink`；若已学会，提升 `current_mastery +90`，并在下一次战斗中使余烬闪烁的冷却缩短 1 回合。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：火元素祭坛外围、灰烬交界边缘、老兵法师遗物箱。

## 书籍内容

余烬闪烁是一种短距离传送技巧，施术者在原地留下一团逐渐熄灭的火星残像，同时出现在不远处。这本书的作者把它比作弹烟灰：你必须清楚自己要落在哪一片灰烬上，否则就会烫到自己的手。前半部分反复练习的是"落点预判"，要求读者在睁眼闭眼之间记住周围所有可燃物的位置。

后半部分讲解战斗中的欺骗用法：敌人会误以为残像是你本人，从而浪费一次攻击。书中提到，最高明的余烬闪烁不是消失在最远的地方，而是移动到敌人视线的死角里。作者警告，连续使用会让施术者的体温升高，严重时甚至会让头发自燃。最后一页被烧焦了一角，似乎是前任主人实践这个警告时留下的纪念。

作者特别指出，残像的颜色越接近真正的火焰，欺骗效果越好，因此初学者常被要求先学会观察不同材质燃烧时的火星色泽。

## 设计意图

为法师系提供早期短距离传送技能，强化战棋中的位置欺骗与机动性，同时为后续火焰闪现、相位移动类高级法术建立"残像"与"落点"的基础熟练度概念。
