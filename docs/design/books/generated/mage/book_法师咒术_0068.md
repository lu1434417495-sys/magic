# 《虚空尖刺的代价》

## 基础信息

- **书籍 ID**：`book_法师咒术_0068`
- **关联技能**：`mage_void_spike`
- **使用效果**：阅读后解锁 `mage_void_spike`；若已学会，提升 `current_mastery +140` 并在下一次战斗中使首次虚空尖刺无视目标 10% 护甲。
- **阅读要求**：角色职业标签含 `mage` 或 `warlock`；基础 `智力 ≥ 12` 且 `意志 ≥ 10`。
- **稀有度**：史诗（Epic）
- **建议投放**：虚空观测站、禁忌图书馆、星界裂隙宝箱。

## 书籍内容

虚空尖刺不是从这个世界生长出来的，而是从'此处没有东西'的缝隙里拔出来的。作者要求施术者先在脑海中制造一个'空'：不是黑暗，不是寂静，而是连'没有'这个概念都不存在的点。前半本警告，这个'空'会吸引周围的光线，让施术者的眼白出现暂时性的灰斑。

书中记录了一位法师在实战中的发现：虚空尖刺对魔抗高的敌人反而更有效，因为它不穿透护甲，而是让护甲以为自己不存在。后半部讨论代价：每次施术后，施术者都会在短时间内失去一种不重要的记忆，比如昨天早餐的味道。

虚空观测站的记录员必须在观测日志上注明自己的体重，因为长期施放虚空尖刺会让人在称重时轻那么一点点。虚空尖刺的残留物只能用特定频率的光照显现。残留尖刺痕迹令人着迷。虚空从不白白给予。
## 设计意图

史诗级虚空穿透输出书籍，提供无视护甲的高阶伤害手段，强调智力与意志门槛以及禁忌魔法的代价。
