# 《泥泞之手：地形即武器》

## 基础信息

- **书籍 ID**：`book_法师咒术_0005`
- **关联技能**：`mage_mud_grasp`
- **使用效果**：阅读后解锁 `mage_mud_grasp`；若已学会，提升 `current_mastery +80`，并在下一次战斗中使首次泥泞之手额外降低目标 1 点移动力。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 6`。
- **稀有度**：普通（Common）
- **建议投放**：沼泽边小屋、元素学徒宿舍、湿地遗迹宝箱。

## 书籍内容

本书的封面上有一块洗不掉的泥渍，据说是作者故意留下的。书中主张，初学咒术的人不必急着召唤火焰或冰霜，学会与脚下的地面合作才是更稳妥的起点。泥泞之手的本质不是制造泥浆，而是唤醒泥土中已经存在的水分，让它们抓住敌人的脚踝。

前半部分详细记录了不同土壤的起效速度：沙地最慢，黏土最快，石板路则几乎无效。后半部分转而讲解组合战术，比如在敌人踏入泥沼后再追加雷系法术，可以让电流传播得更远。作者反复强调，这个咒语的威力不在于伤害，而在于让敌人"不想继续往前走"。最后一页是一幅潦草的示意图，画着一只由泥巴构成的手正攥住一只靴子。

作者在书的最后提醒读者，泥泞之手最理想的战场是雨后初晴的田野，那时泥土既不会太干而失效，也不会太湿而难以定型。

## 设计意图

作为法师系早期地形控制技能解锁书籍，培养玩家对战棋地形的重视，为元素组合打法提供入门案例，同时连接后续土系与水系的进阶法术。
