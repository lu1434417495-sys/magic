# 《雷萤：一群会爆炸的小光点》

## 基础信息

- **书籍 ID**：`book_法师咒术_0047`
- **关联技能**：`mage_lightning_bug`
- **使用效果**：阅读后解锁 `mage_lightning_bug`；若已学会，提升 `current_mastery +100`，并在下一次战斗中使雷萤集群爆炸时额外麻痹目标 1 回合。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 10`。
- **稀有度**：普通（Common）
- **建议投放**：沼泽萤火湿地、雷电研究者营地、夏夜祭典摊位。

## 书籍内容

雷萤是一种召唤出数颗带电光点环绕自身的咒术，这些光点像夏夜的萤火虫一样漂浮移动，但接触敌人时会释放出足以让人肌肉痉挛的电流。这本书的作者声称，这个咒术的灵感来自某个雷雨夜被困在沼泽里的经历，当时他发现发光的飞虫最容易被闪电吸引。

前半部分讲解如何同时维持多个微弱的电荷核心，重点不是让每个核心都很强，而是让它们彼此之间保持稳定的排斥距离。后半部分讨论战术用法：雷萤可以自动攻击靠近的敌人，也可以被指挥飞向指定目标进行集中爆破。书中警告，雷萤对金属护甲的敌人效果特别好，但如果己方队友也穿着金属护甲，就需要保持距离。最后一页画着几点蓝光围绕着一个法师旋转。

作者建议同时维持的雷萤数量不要超过七颗，否则电荷核心之间的排斥会变得难以控制，反而容易误伤自己。

## 设计意图

为法师系提供早期召唤物型雷电技能，强化持续输出与近战威慑，同时为后续元素使魔、雷电领域类法术建立熟练度与叙事基础。
