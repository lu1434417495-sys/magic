# 《时间涟漪：让动作慢半拍》

## 基础信息

- **书籍 ID**：`book_法师咒术_0049`
- **关联技能**：`mage_time_ripple`
- **使用效果**：阅读后解锁 `mage_time_ripple`；若已学会，提升 `current_mastery +100`，并在下一次战斗中使时间涟漪影响的敌人在下回合无法使用反应技能。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 10`。
- **稀有度**：普通（Common）
- **建议投放**：古代钟楼、时间法师塔、钟表匠协会藏书室。

## 书籍内容

时间涟漪是一种向目标释放一圈微弱时间波动的咒术，被击中的敌人会感觉自己周围的时光慢了一瞬，导致动作和反应都出现延迟。这本书的作者是一个痴迷于钟表的法师，他认为时间并不是一条直线，而是由无数层涟漪组成的湖面。前半部分教读者如何感知自己周围的时间流速，并找到那一层可以拨动的涟漪。

后半部分讲解战术用途：在敌人准备反击或闪避时释放时间涟漪，可以让对方的反应技能失效一瞬；在团队配合下，这个短暂的延迟足以决定一场战斗的走向。书中警告，时间涟漪不能叠加，对同一个目标连续使用只会浪费魔力。最后一页画着一个巨大的钟表，指针被一圈圈波纹推得微微错位。

作者还提到，施展时间涟漪时最好配合怀表或钟楼钟声，固定的节奏能帮助施术者更准确地找到那一层可以拨动的时间涟漪。

## 设计意图

为法师系提供早期时间控制技能，强化战棋中的节奏压制与配合能力，同时为后续真正的时间停止、时间回溯类高级法术建立熟练度与叙事基础。
