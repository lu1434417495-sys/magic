# 《奥术短匕：指间流星》

## 基础信息

- **书籍 ID**：`book_法师咒术_0204`
- **关联技能**：`mage_arcane_dagger`
- **使用效果**：阅读后解锁 `mage_arcane_dagger`；若已学会，提升 `current_mastery +130` 并在下一次战斗中使首把奥术短匕可穿透一个额外目标。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 10`。
- **稀有度**：普通（Common）
- **建议投放**：法师公会初级训练室、旧书摊、学徒遗落的行囊。

## 书籍内容

奥术短匕是最经济的攻击法术之一，它把魔力压缩成刀刃大小的稳定能量体，从指尖射出。本书从握姿开始教起，作者认为短匕飞得直不直，取决于施法时小指是否放松。书中夹着大量练习表，记录不同距离下魔力注入量与穿透力的关系，批注显示二十步内只需三分力，超过五十步则需要七分力并牺牲精准。后半部收录了数十种花式投掷法，包括回旋、分裂和延时引爆，但作者提醒这些华而不实的技巧容易在实战中让同伴分心。最末页是一行被划掉的话，原句是短匕可以杀人，后面被改成了短匕可以切面包。许多老法师至今仍用这招来削苹果皮。书末还附有一张破损的靶纸，中心钉着七把由不同学生凝出的短匕，形状各异。封底印着一行小字：匕首飞向目标，也飞向施法者自己的傲慢。

## 设计意图

作为低耗蓝瞬发技能，帮助新手法师建立稳定的补刀与输出节奏，降低入门门槛。
