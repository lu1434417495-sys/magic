# 《灼痕符印：烙铁契约》

## 基础信息

- **书籍 ID**：`book_法师咒术_0243`
- **关联技能**：`mage_searing_sigil`
- **使用效果**：阅读后解锁 `mage_searing_sigil`；若已学会，提升 `current_mastery +150` 并在下一次战斗中使首个灼痕符印在目标受到火焰伤害时额外爆炸一次。
- **阅读要求**：角色职业标签含 `mage` 或 `pyromancer`；基础 `智力 ≥ 13` 且 `感知 ≥ 11`。
- **稀有度**：稀有（Rare）
- **建议投放**：火焰审判所、烙印师工坊、灰烬交界军营。

## 书籍内容

灼痕符印是把火焰咒语刻入目标身体的标记，之后每当目标受到火焰伤害，符印都会引发额外爆炸。书中把符印比作一份滚烫的契约，一旦烙下，所有火焰都会来讨债。作者详细讲解了如何在快速移动中准确把符印印在敌人身上，包括手掌、武器和投掷物三种施法方式。练习者需要先在木头人上练习，直到能在三秒内完成烙印而不烧伤自己的手指。后半部讲解了如何让多个灼痕符印相互叠加，形成连锁爆燃。最末页是一段审判官的记录：罪犯最怕的不是烙铁，是之后每次靠近壁炉。许多火法师会在自己的法杖上刻一个缩小版符印，作为对火焰的致敬。书中还提醒，灼痕符印会被强力的净化术提前解除，因此最好在敌方牧师反应过来前引爆。

## 设计意图

提供标记增伤机制，让火系法师能通过前置技能放大后续爆发，增强连招深度。
