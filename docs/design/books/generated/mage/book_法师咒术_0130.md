# 《以太铠甲的贴合度》

## 基础信息

- **书籍 ID**：`book_法师咒术_0130`
- **关联技能**：`mage_ether_armor`
- **使用效果**：阅读后解锁 `mage_ether_armor`；若已学会，提升 `current_mastery +170` 并在下一次战斗中使以太铠甲首次激活时额外吸收一次物理伤害。
- **阅读要求**：角色职业标签含 `mage` 或 `abjurer`；基础 `智力 ≥ 17` 且 `体质 ≥ 12`。
- **稀有度**：史诗（Epic）
- **建议投放**：以太工坊、防护学派高塔、浮空城防御学院。

## 书籍内容

以太铠甲不是穿戴的金属，而是紧贴皮肤的魔力薄膜。本书从贴合度开始，强调铠甲必须与施法者的身体轮廓完全吻合，任何褶皱都会成为攻击的突破口。作者要求练习者先在水池中静坐，感受以太在皮肤上的流动，再逐步调整到与心跳同步。书中讨论了不同体型与姿态下的贴合差异，比如举起法杖时肩部需要额外加厚，弯腰时后背则要放松。作者警告，贴合过紧会压迫血管，导致施法者头晕；过松则会在冲击下产生气泡状空洞。第二章介绍如何在战斗中快速修补破损部位。最末一页画着一副透明的人体甲胄，批注写道：最好的铠甲，是让你忘记自己穿着铠甲。作者建议在铠甲内侧刻上个人真名的一个音节，用以增强以太与施法者的亲和力。这一步骤需要绝对的独处，因为真名不可被他人听见。

## 设计意图

为防护型法师提供轻便的贴身防御，强调精细控制与持续维护，拓展防御流派玩法。
