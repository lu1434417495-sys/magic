# 《永恒冰封的保存期限》

## 基础信息

- **书籍 ID**：`book_法师咒术_0147`
- **关联技能**：`mage_eternal_frost`
- **使用效果**：阅读后解锁 `mage_eternal_frost`；若已学会，提升 `current_mastery +180` 并在下一次战斗中使永恒冰封首次命中时附加的减速效果提高 15%。
- **阅读要求**：角色职业标签含 `mage` 或 `cryomancer`；基础 `智力 ≥ 18` 且 `意志 ≥ 14`。
- **稀有度**：史诗（Epic）
- **建议投放**：北境永冻层、冰霜巨龙密室、时间停滞遗迹。

## 书籍内容

永恒冰封的目标不是杀死敌人，而是将他们保存起来。本书从保存期限讲起，指出即使是永恒也有其前提条件：温度不能波动、封印不能被阳光直射、施法者的意志不能动摇。作者详细介绍了冰封内部的时间流动：被封印者不会衰老，也不会恢复，意识被冻结在最后一刻。书中警告，长期保存智慧生物会让自己背负对方的记忆残片，许多冰法师因此逐渐变得冷漠。第二章讨论如何在战斗中快速施展临时冰封，让敌人失去行动能力而非永久封印。作者还附上一份解冻流程，强调解冻时必须缓慢升温，否则目标会碎裂。最末一页写着：永恒是冰冷的承诺，不是温暖的家。永恒冰封也常被用于保存珍贵的药材与古籍，北境的一些学派甚至把图书馆建在冰层之下。作者提醒，用这门技艺保存物品时，别忘了在封印上标注日期。

## 设计意图

为冰系法师提供长效控制与叙事上的时间停滞主题，强化封印与保存的玩法分支。
