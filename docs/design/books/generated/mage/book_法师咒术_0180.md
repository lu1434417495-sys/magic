# 《灵魂制图学基础》

## 基础信息

- **书籍 ID**：`book_法师咒术_0180`
- **关联技能**：`mage_soul_cartography`
- **使用效果**：阅读后解锁 `mage_soul_cartography`；若已学会，提升 `current_mastery +170` 并在下一次战斗中使灵魂地图首次完成时揭示敌方阵营全部单位的初始位置。
- **阅读要求**：角色职业标签含 `mage` 或 `soul_scribe`；基础 `智力 ≥ 18` 且 `感知 ≥ 16`。
- **稀有度**：史诗（Epic）
- **建议投放**：星象塔制图室、灵界档案馆、古代航海家遗藏。

## 书籍内容

灵魂制图学是一种将生命体的灵魂波动绘制成地图的技艺。本书从感知灵魂轮廓开始，教导如何辨别不同生物的灵魂形状：人类灵魂如摇曳火焰，野兽灵魂如尖锐闪电，而亡灵灵魂则是残缺的漩涡。作者强调，制图时必须保持距离，过度靠近会让自己的灵魂与对方产生共振。书中记录了如何在战场上快速扫描并标记所有灵魂位置，以及如何处理伪装成普通生物的强敌。最末一章讨论地图的保存：灵魂地图只能用特殊墨水绘制，普通纸笔无法承载这种信息。批注写道：每张地图都是一次短暂的窥视，不要试图记住所有细节。练习者需要先为自己绘制灵魂地图，确认自身稳定后才能扫描他人。这门技艺在开战前能提供宝贵的情报。

灵魂制图师常被误认为占卜师，但前者只记录当下，从不预测未来。

## 设计意图

为侦察型法师提供战前情报技能，将灵魂感知与地图绘制结合。
