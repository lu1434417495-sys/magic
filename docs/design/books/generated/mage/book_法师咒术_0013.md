# 《灰烬符印：交界残片的再利用》

## 基础信息

- **书籍 ID**：`book_法师咒术_0013`
- **关联技能**：`mage_ashen_mark`
- **使用效果**：阅读后解锁 `mage_ashen_mark`；若已学会，提升 `current_mastery +90`，并在下一次战斗中使灰烬符印爆炸时额外附加 1 回合失明。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：灰烬交界边缘营地、废墟法师遗物、异界战技教官处。

## 书籍内容

灰烬交界是一片被烧尽的世界，但灰烬本身仍然残留着魔力的痕迹。这本书教读者如何收集这些交界残片，并在上面刻下简易符印，使其成为一次性的小型爆炸陷阱。作者强调，这不是正规的法术，而是一种应急手艺，适合资源匮乏的前线法师。

前半部分介绍如何识别"有活力"的灰烬：颜色偏银、触感微凉、在月光下会缓慢漂移。后半部分讲解符印的绘制方法，包括三个必须闭合的回路和一个故意留出的缺口，缺口方向决定爆炸的覆盖范围。书中警告，把灰烬符印放在贴身口袋里是极其危险的行为，曾有法师在奔跑时把自己半边袍子炸成了灰。最后附有一张烧焦的实战照片，背景是一片扭曲的异界地形。

作者专门用一章讲解采集灰烬时的安全措施，包括必须佩戴的厚手套和绝不能使用金属容器的理由。

## 设计意图

作为连接法师咒术与灰烬交界异界战技的入门书籍，拓展法师的技能来源与战场工具体系，为后续异界能量相关法术提供叙事铺垫与熟练度积累。
