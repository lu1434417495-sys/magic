# 《裂解射线的边界效应》

## 基础信息

- **书籍 ID**：`book_法师咒术_0113`
- **关联技能**：`mage_disintegration_ray`
- **使用效果**：阅读后解锁 `mage_disintegration_ray`；若已学会，提升 `current_mastery +180` 并在下一次战斗中使首次裂解射线对护甲额外造成 15% 伤害。
- **阅读要求**：角色职业标签含 `mage` 或 `battlemage`；基础 `智力 ≥ 18` 且 `冥想 ≥ 4`。
- **稀有度**：史诗（Epic）
- **建议投放**：古代战场遗迹、魔导兵器工坊、高阶法师竞技场奖励。

## 书籍内容

裂解射线之所以危险，不仅在于它能瓦解物质，更在于边界效应不可预测。本书从射线与空气、护甲、血肉、石头四种介质的交界处入手，分析不同材质被击穿时的二次飞溅方向。作者强调，施法者必须精确控制射线的宽度：太细只能留下穿孔，太宽则会把施法者自己的防护也一起蒸发。书中记录了七个实验事故，其中三名法师因忽视边界反射而失去手臂。第二章介绍如何利用边界效应进行跳弹射击，让射线在墙壁间折返。作者建议初学者先在废弃矿洞练习，直到能在岩壁上打出直角痕迹。最末一页的警告用粗体写成：裂解射线没有朋友，只有还没被照到的敌人。训练用的废弃矿洞最好选在没有居民的偏远地区，因为裂解射线意外击穿岩壁后，常会惊醒沉睡的地下生物。耐心是这门技艺最昂贵的材料。

## 设计意图

为后期输出法师提供穿甲与地形利用能力，强调高风险、高伤害的精准打击风格。
