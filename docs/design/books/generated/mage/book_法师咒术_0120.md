# 《魔像集群控制协议》

## 基础信息

- **书籍 ID**：`book_法师咒术_0120`
- **关联技能**：`mage_golem_protocol`
- **使用效果**：阅读后解锁 `mage_golem_protocol`；若已学会，提升 `current_mastery +170` 并在下一次战斗中使魔像集群的协同攻击伤害提高 8%。
- **阅读要求**：角色职业标签含 `mage` 或 `artificer`；基础 `智力 ≥ 17` 且 `感知 ≥ 12`。
- **稀有度**：史诗（Epic）
- **建议投放**：魔像工坊核心、古代机械遗迹、工匠法师任务奖励。

## 书籍内容

单个魔像只是工具，一群魔像才需要协议。本书从集群控制的基本逻辑讲起，要求施法者为每个魔像分配一个独特的指令频率，避免信号互相干扰。作者将魔像分为前锋、侧翼、后卫三种角色，并给出编队示例。书中强调，控制魔像集群最重要的不是数量，而是优先级管理：当多个魔像同时请求同一目标时，施法者必须在半秒内做出裁决。第二章讨论魔像之间的物理协同，比如让石魔像搭成临时桥梁，或让铁魔像互相借力投掷。作者警告，不要在情绪激动时下达集群指令，因为魔像会忠实地执行每一个颤抖的词语。最末一页是一份简洁的协议模板，批注写着：集群服从的不是声音，而是清晰的意图。集群协议也可以用简单的鼓点或手势代替语言，在魔力干扰严重的区域尤其有效。

## 设计意图

为造物型法师提供多单位协同的指挥机制，拓展召唤/魔像流在战棋中的战术宽度。
