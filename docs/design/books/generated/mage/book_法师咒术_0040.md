# 《魂绕：把意识像线一样缠住目标》

## 基础信息

- **书籍 ID**：`book_法师咒术_0040`
- **关联技能**：`mage_soul_coil`
- **使用效果**：阅读后解锁 `mage_soul_coil`；若已学会，提升 `current_mastery +90`，并在下一次战斗中使魂绕的持续伤害提升 10 点。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：通灵师墓穴、魂术士隐居处、战地法师遗物箱。

## 书籍内容

魂绕是一种把自己的一缕意识抽成细丝，缠绕在敌人精神上的持续性咒术。被缠绕的目标会感受到一种无法摆脱的隐痛，就像有人一直在他耳边轻轻拉扯。这本书的作者警告读者，施放魂绕时必须保持心神稳定，否则缠绕的线可能会反过来勒住自己的意识。

前半部分讲解如何把意识拉伸成丝而不让它断裂，这需要在施术时反复默念一个固定音节。后半部分讨论战术应用：魂绕适合对付高护甲但精神薄弱的敌人，比如亡灵骑士或狂战士。书中提到，魂绕的伤害不会立刻致命，但它会让敌人无法安心施法或休息。最后附有一张被红线缠绕的玩偶照片，玩偶的眼睛被缝住了，看起来有些渗人。

书中提到，魂绕的丝线颜色会反映施术者的情绪，愤怒的丝线呈暗红色，冷静的丝线则近乎透明，情绪失控会让丝线变得脆弱易断。

## 设计意图

为法师系提供早期持续性精神伤害技能，拓展输出方式与目标选择策略，同时为后续诅咒系、灵魂系与精神折磨类法术建立熟练度与叙事基础。
