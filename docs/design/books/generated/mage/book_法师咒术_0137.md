# 《幻象分身的谢幕演出》

## 基础信息

- **书籍 ID**：`book_法师咒术_0137`
- **关联技能**：`mage_phantom_finale`
- **使用效果**：阅读后解锁 `mage_phantom_finale`；若已学会，提升 `current_mastery +170` 并在下一次战斗中使分身谢幕时造成的范围伤害提高 10%。
- **阅读要求**：角色职业标签含 `mage` 或 `illusionist`；基础 `智力 ≥ 17` 且 `敏捷 ≥ 14`。
- **稀有度**：史诗（Epic）
- **建议投放**：幻术大剧院、镜宫舞台、传奇幻术师遗物。

## 书籍内容

幻象分身的最高境界不是欺骗敌人，而是在消失时给他们留下深刻印象。本书从谢幕演出开始，要求施法者为每个分身设计一个优雅的退场：化作花瓣、碎成镜子、散作烟雾或融进阴影。作者指出，谢幕越华丽，敌人越容易愣住，从而为真身争取行动时间。书中收录了九种经典谢幕动作，每一种都附带相应的咒语尾音与手势。作者警告，不要让分身死得太过平凡，否则敌人会立刻识破真身。第二章讨论谢幕时的爆炸或迷惑效果，以及如何避免误伤队友。最末一页是一张舞台设计图，灯光、道具与分身位置都被精确标注，批注写道：最好的幻术，是连谢幕都被当作真实。一场完美的谢幕演出需要精确计算敌人的视线方向与情绪节奏。作者建议幻术师在谢幕前先让分身做出一个明显错误，以降低敌人的警惕。

## 设计意图

为幻术法师提供分身终结技，强化幻象系的欺骗与爆发结合玩法。
