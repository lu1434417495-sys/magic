# 《熵增护盾的裂缝美学》

## 基础信息

- **书籍 ID**：`book_法师咒术_0104`
- **关联技能**：`mage_entropy_shield`
- **使用效果**：阅读后解锁 `mage_entropy_shield`；若已学会，提升 `current_mastery +160` 并在下一次战斗中使护盾破碎时返还 10% 已吸收伤害。
- **阅读要求**：角色职业标签含 `mage` 或 `abjurer`；基础 `智力 ≥ 16` 且 `体质 ≥ 10`。
- **稀有度**：史诗（Epic）
- **建议投放**：废弃实验室、混沌裂隙边缘、古代防护学派密室。

## 书籍内容

传统护盾追求完整无缺，熵增护盾却主动在表面保留裂缝。作者认为，完美屏障会让 incoming 能量集中一点，而可控的裂缝能分散冲击力，并让部分能量在裂缝中自我抵消。书中先用三幅破裂瓷器的插画说明应力分布，再过渡到咒语的编织方法：先构筑一个密实的球体，再故意留下七条不对称的细缝。裂缝的宽度与角度都需要精确计算，太宽则防御崩解，太窄则失去卸力效果。作者还讨论了护盾破碎时的二次利用，建议将碎片化为反噬的乱流推向敌人。书末附录了一张裂缝模板，注释强调：美不是目的，让伤害迷路才是。掌握熵增护盾需要放弃对完美的执念，许多防护学派的学生在第一次故意留缝时都会本能地想要修补，这正是最大的障碍。

## 设计意图

为后期防御型法师提供反制空间，用破碎美学包装高风险的防御转化机制。
