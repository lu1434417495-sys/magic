# 《符文眼：刻在视线里的文字》

## 基础信息

- **书籍 ID**：`book_法师咒术_0018`
- **关联技能**：`mage_rune_eye`
- **使用效果**：阅读后解锁 `mage_rune_eye`；若已学会，提升 `current_mastery +90`，并在下一次战斗中使符文眼的解析速度缩短 1 回合。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：古代图书馆解密区、符文工匠工作台、遗迹拓印师营地。

## 书籍内容

符文眼是一个辅助性咒术，它让施术者能够在视野中直接看到隐藏符文、魔力残留和陷阱标记。这本书的前半部分是一系列视觉训练，要求读者盯着复杂的迷宫图案，直到能在三秒内找出所有交叉点。作者认为，眼睛需要被重新教育，才能识别出符文特有的"语法"。

后半部分讲解如何在战斗中快速解析敌人身上的增益或减益符文，从而判断对方的弱点。书中提到，符文眼对某些自然生成的异界文字也会产生反应，这些文字往往包含着关于灰烬交界的重要信息。最后警告说，长时间开启符文眼会让普通文字在视野里也开始"发光"，导致阅读普通书籍时产生轻微眩晕。

书末附有一份简易符文对照表，帮助初学者辨认最常见的二十种封印结构，避免在实战中浪费解析时间。作者建议初学者随身携带这本对照表，直到能够不假思索地辨认出最常见的危险符文。

## 设计意图

为法师系提供早期侦察与解密技能，强化探索玩法与信息获取能力，同时为后续符文系、封印系与古代知识相关法术建立熟练度与叙事铺垫。
