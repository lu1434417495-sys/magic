# 《法力菌丝的生长周期》

## 基础信息

- **书籍 ID**：`book_法师咒术_0181`
- **关联技能**：`mage_mana_mycelium`
- **使用效果**：阅读后解锁 `mage_mana_mycelium`；若已学会，提升 `current_mastery +180` 并在下一次战斗中使法力菌丝成熟时为施法者持续恢复 MP 3 回合。
- **阅读要求**：角色职业标签含 `mage` 或 `fungalmancer`；基础 `智力 ≥ 18` 且 `感知 ≥ 15`。
- **稀有度**：传说（Legendary）
- **建议投放**：地下菌菇王国、远古森林根系、禁忌生态园。

## 书籍内容

法力菌丝是一种以魔力为养分的真菌网络，能在地下悄然生长并反馈能量给培育者。本书从孢子选择开始，讲解不同颜色孢子对应的生长速度与效果差异。作者强调，菌丝对情绪极为敏感，焦虑会让它们枯萎，而平和则能促进蔓延。书中记录了如何在战场下播撒孢子网络，以及如何在不引起敌人注意的情况下等待成熟。第二章讨论采摘时机：太早会损失恢复量，太晚则菌丝可能开始侵蚀周围土壤。最末一页写着：你不是在种植菌丝，而是在种植一段耐心的关系。练习者需要学会倾听菌丝通过土壤传来的微弱震动，判断它们的生长阶段。这门技艺在持久战中能为法师提供稳定的魔力补给。

菌丝网络成熟后会与施法者的神经产生微弱连接，带来一种奇异的饱腹感。

## 设计意图

为法师提供延迟型持续回蓝机制，将真菌生态与魔力循环结合。
