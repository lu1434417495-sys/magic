# 《梦境束缚：睡魇罗网》

## 基础信息

- **书籍 ID**：`book_法师咒术_0236`
- **关联技能**：`mage_dream_binding`
- **使用效果**：阅读后解锁 `mage_dream_binding`；若已学会，提升 `current_mastery +150` 并在下一次战斗中使首次梦境束缚命中时目标沉睡两回合，受到伤害后苏醒。
- **阅读要求**：角色职业标签含 `mage` 或 `illusionist`；基础 `智力 ≥ 14` 且 `感知 ≥ 13`。
- **稀有度**：稀有（Rare）
- **建议投放**：梦境迷宫、梦魇栖息地、睡眠之神废弃神殿。

## 书籍内容

梦境束缚是把目标的意识拖入短暂梦境的法术，在梦中目标会看见自己最渴望或最恐惧的景象。书中强调，施法者不能进入目标梦境，否则会被对方的潜意识反噬。作者把施法过程比作轻轻扣响一扇门，门后的人自愿走进去。练习者需要先学会控制自己的梦境，才能安全地把他人送入梦境。后半部讲解了如何在目标沉睡期间布置陷阱或撤离战场，以及如何利用梦境内容判断敌人的弱点。最末页是一段梦话般的文字：不要叫醒他们，他们在梦里比较诚实。许多幻术师会用这个法术来审讯，因为醒来的人往往会把梦中秘密挂在嘴边。书中还提到，对意志坚定的敌人效果会缩短，因此配合削弱意志的技能使用效果更佳。梦境束缚常被用于治疗失眠，因为中招者往往会做一个漫长的美梦。

## 设计意图

提供长回合控制与信息获取手段，让法师能暂时移除威胁并创造战术窗口。
