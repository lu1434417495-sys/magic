# 《魔典舌：与书籍对话》

## 基础信息

- **书籍 ID**：`book_法师咒术_0152`
- **关联技能**：`mage_tome_tongue`
- **使用效果**：阅读后解锁 `mage_tome_tongue`；若已学会，提升 `current_mastery +160` 并在下一次战斗中使首个通过魔典施放的法术冷却减少 1 回合。
- **阅读要求**：角色职业标签含 `mage` 或 `lorekeeper`；基础 `智力 ≥ 17` 且 `感知 ≥ 14`。
- **稀有度**：史诗（Epic）
- **建议投放**：大图书馆禁书区、学者营地、古抄本商人。

## 书籍内容

有些书籍不愿意被阅读，它们只愿意与能理解其语言的人交谈。本书教授一种被称为魔典舌的技艺，让施法者能通过舌尖的轻微震动与魔法书籍建立联系。第一章介绍如何用唾液湿润指尖后轻抚书脊，以判断书籍的情绪状态。第二章讲解七种常见的书籍语气，从傲慢到疲惫，再到伪装成普通教科书的恶灵。作者警告，某些古书会试图反过来阅读读者，因此每次对话不得超过十分钟。最末一页记载了一段发音：不是读文字，而是让文字读你。练习者需要在一个月内与同一本书建立稳定关系，魔典舌熟练后，书中的知识会自动以梦境形式浮现。真正的学者能与任何语言的书籍交谈，包括那些尚未被破译的异界文字。

交谈时注意书籍翻页速度，那往往是它情绪变化的第一个信号。

## 设计意图

为知识型法师提供与魔法典籍互动的独特机制，强化探索和知识解锁的乐趣。
