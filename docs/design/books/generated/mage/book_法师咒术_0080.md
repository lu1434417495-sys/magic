# 《迷雾墓穴的呼吸术》

## 基础信息

- **书籍 ID**：`book_法师咒术_0080`
- **关联技能**：`mage_grave_mist`
- **使用效果**：阅读后解锁 `mage_grave_mist`；若已学会，提升 `current_mastery +110` 并延长迷雾持续 1 回合。
- **阅读要求**：角色职业标签含 `mage` 或 `necromancer`；基础 `智力 ≥ 10`。
- **稀有度**：精良（Uncommon）
- **建议投放**：古代墓地书库、亡灵学者据点、迷雾沼泽宝箱。

## 书籍内容

迷雾墓穴的雾气不是水，而是'被延缓的叹息'。前半本讲解呼吸术：施术者要用极慢的呼气把魔力释放到地面，让雾气贴着地表爬行而不是向上飘散。作者强调，这种雾气最怕风，三级以上的风就能让它在几秒内消散。

中段记录了迷雾中的移动技巧：把脚跟先着地，减少脚步声，因为雾气会把声音传得比平常更远。后半部转向生死观：墓穴雾气会让生者感到压抑，却会让亡灵感到舒适，因此有些法师用它来判断附近是否有不死生物。最后一页是一句潦草的警告：'不要在雾中呼喊自己的名字。'

古墓书库的烛火从不需要灯油，因为墓穴迷雾本身会让火焰呈现出幽蓝的冷光，足以照亮脚下的台阶。墓穴迷雾会吸附在施术者的睫毛上。睫毛雾气是成功小勋章。墓穴迷雾也会记得施术者。雾气会低语。
## 设计意图

精良级死灵/环境控制书籍，解锁墓穴迷雾并提供视野遮蔽与氛围控制能力，强调呼吸节奏与环境弱点。
