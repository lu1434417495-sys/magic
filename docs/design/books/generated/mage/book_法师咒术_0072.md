# 《火焰长矛的握持法》

## 基础信息

- **书籍 ID**：`book_法师咒术_0072`
- **关联技能**：`mage_flame_spear`
- **使用效果**：阅读后解锁 `mage_flame_spear`；若已学会，提升 `current_mastery +110` 并在下一次战斗中使首次火焰长矛命中后附加 1 层`burn`。
- **阅读要求**：已学会 `mage_burning_hands` 或 `mage_fireball`；角色职业标签含 `mage`；基础 `智力 ≥ 9`。
- **稀有度**：精良（Uncommon）
- **建议投放**：火焰斗技场、龙血后裔训练场、火山口藏书。

## 书籍内容

火焰长矛最难的不是让它燃烧，而是让它在手中稳定。前半本讲解'虚握'：手指不能真正捏紧火矛，而要像握住一条活鱼那样留有余地，让火焰在掌心与指缝间流动。作者警告，握得太实会导致火焰反噬手腕，握得太松则长矛会在命中前解体。

中段是一份材质测试表：不同木材、金属与骨制矛柄对火焰传导的影响。书中特别推荐未经处理的橡木，因为它会在燃烧时发出稳定的噼啪声，提醒施术者当前温度。后半部讨论投掷角度：火焰长矛最适合略微上扬的抛物线，这样落地时火焰会向前泼洒。

火焰斗技场的冠军们在胜利后会把熔化的矛尖铸成一枚戒指，提醒自己最危险的不是矛尖，而是握矛的手。火焰长矛的斗技场地面铺着防火沙。斗技场每年补三次沙。防火沙记得每一次胜利。长矛会记住握它的人。
## 设计意图

精良级火焰单体/直线输出书籍，前置要求火系基础技能，形成火焰系进阶链条，强调手感与控制。
