# 《星陨法杖的握持修正》

## 基础信息

- **书籍 ID**：`book_法师咒术_0145`
- **关联技能**：`mage_starfall_staff`
- **使用效果**：阅读后解锁 `mage_starfall_staff`；若已学会，提升 `current_mastery +170` 并在下一次战斗中使星陨法杖首次召唤的陨石数量增加 1 颗。
- **阅读要求**：角色职业标签含 `mage` 或 `astromancer`；基础 `智力 ≥ 17` 且 `感知 ≥ 14`。
- **稀有度**：史诗（Epic）
- **建议投放**：古代观星台、星象武器工坊、浮空城遗迹。

## 书籍内容

星陨法杖不是普通法杖，而是一根能与特定星辰共鸣的引导器。本书从握持姿势开始，指出常见的单手举杖姿势会让星辰之力在肩部淤塞。正确的方法是双手握住杖身中下段，让法杖成为身体的延伸，而非武器。作者强调，握持过紧会限制魔力流动，过松则会在星陨落下时被反冲力震脱手。书中收录了七种星辰对应的握持角度，每种角度都会影响陨石的落点分布。作者警告，不要在云层过厚的夜晚使用，因为星光无法穿透障碍，陨石可能偏离目标。第二章讲解如何在施法时与星辰建立短暂的对视。最末一页画着一只握住法杖的手，旁边写着：你不是在召唤星星，你是在请求它们坠落。星陨法杖通常由陨铁与星木制成，不同的材质会影响陨石落下的速度与温度。作者附有一份简单的材质对照表，帮助使用者根据自己法杖的特性微调握持姿势。

## 设计意图

为星象法师提供装备协同与召唤型输出，强化星辰主题与战棋范围打击。
