# 《雷霆震击的节奏课》

## 基础信息

- **书籍 ID**：`book_法师咒术_0065`
- **关联技能**：`mage_thunderclap`
- **使用效果**：阅读后解锁 `mage_thunderclap`；若已学会，提升 `current_mastery +100` 并在下一次战斗中使首次震击眩晕概率 `+5%`。
- **阅读要求**：角色职业标签含 `mage` 或 `elementalist`；基础 `智力 ≥ 9` 且 `敏捷 ≥ 8`。
- **稀有度**：精良（Uncommon）
- **建议投放**：风暴祭坛入门区、元素训练场、雷雨高地据点。

## 书籍内容

雷霆震击的精髓不是响亮，而是'骤停'。作者把施术过程比作拍手：手掌合拢前的最后一刻最安静，雷霆就在那一刻诞生。前半本要求练习者先用单手拍击不同材质的表面，感受'声在前还是痛在前'。书中指出，多数新手把魔力一次性倾泻，结果只有 noise 没有 shock；正确做法是先积蓄，再在一个极短窗口内释放。

中段收录了'三步雷音'：第一声让敌人听清方向，第二声让敌人捂住耳朵，第三声才是真正的震击。后半部警告：不要在封闭石室里练习，反射的雷音会让自己也陷入眩晕。风暴祭坛的台阶上刻满了小坑，那是数百年间学徒们在练习雷霆震击时，因节奏错误而把能量泄入地面的痕迹。

雷霆震击的节奏课考试要求闭眼拍对十下。闭眼拍对十下源自盲师。节奏错误会留下痕迹。雷霆只听从精确。节奏即一切。
## 设计意图

精良级雷电控制书籍，解锁雷霆震击并为法师提供范围打断能力，强调节奏与时机而非单纯伤害。
