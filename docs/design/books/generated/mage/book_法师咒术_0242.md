# 《噩梦迷雾：恐惧之纱》

## 基础信息

- **书籍 ID**：`book_法师咒术_0242`
- **关联技能**：`mage_nightmare_mist`
- **使用效果**：阅读后解锁 `mage_nightmare_mist`；若已学会，提升 `current_mastery +160` 并在下一次战斗中使首片噩梦迷雾范围内的敌人首次攻击有百分之五十概率落空。
- **阅读要求**：角色职业标签含 `mage` 或 `illusionist`；基础 `智力 ≥ 15` 且 `意志 ≥ 12`。
- **稀有度**：史诗（Epic）
- **建议投放**：梦魇沼泽、废弃精神病院、恐惧之神祭坛。

## 书籍内容

噩梦迷雾是把恐惧具象化成灰黑色雾气的法术，吸入者会看见自己最害怕的幻象。书中警告，施法者必须先直面自己的噩梦，否则雾气会反过来笼罩你。作者把施法过程比作打开一个装满他人梦境的盒子，你不需要知道每个梦的内容，只需要让它们的恐惧溢出来。练习者需要在镜子前反复讲述自己最羞耻的经历，直到能平静地面对。后半部讲解了如何让迷雾与睡眠法术配合，让敌人在恐惧中昏睡不醒。最末页只有一行用颤抖笔迹写的话：我看见它了，它也在看你。许多幻术师认为，这行字本身也是法术的一部分。书中还提醒，噩梦迷雾对同一目标多次使用效果会递减，因为人会逐渐习惯恐惧，需要变换幻象内容才能维持效果。

## 设计意图

提供范围 debuff 与闪避干扰，让法师能削弱敌方命中，增强幻术系的生存能力。
