# 《元素誓约：土之篇》

## 基础信息

- **书籍 ID**：`book_法师咒术_0131`
- **关联技能**：`mage_earth_pact`
- **使用效果**：阅读后解锁 `mage_earth_pact`；若已学会，提升 `current_mastery +170` 并在下一次战斗中使土之誓约首次触发时额外提高 10% 物理防御。
- **阅读要求**：角色职业标签含 `mage` 或 `geomancer`；基础 `智力 ≥ 17` 且 `体质 ≥ 14`。

- **建议投放**：土元素圣殿、山岳聚落传承地、元素高塔地脉区。

## 书籍内容

土之誓约不是向元素下跪，而是与大地达成一次平等的握手。本书从 barefoot 站立开始，要求施法者脱下鞋袜，让脚底直接感受土壤的温度与湿度。作者认为，大地只会回应那些愿意倾听的人，而倾听的方式就是保持静止。书中详细描述了三种握手礼仪：掌心向下表示请求，掌心向上表示奉献，双手合十表示同盟。错误的礼仪会让大地误以为你在索取或挑衅，从而引发局部地震。第二章讨论誓约的代价：每次借用大地的力量，都需要在施法后归还一部分魔力给土壤。作者警告，长期拖欠会让施法者脚下的大地变得松软无力。最末一页画着一只手掌按在泥土上，批注写道：土不会说话，但它会记住你有没有说谢谢。书中还提到，站在不同地质上会改变誓约的响应速度：花岗岩最快，沙地最慢。

违背土之誓约的法师会在行走时感到脚下传来轻微的抱怨，那是大地在提醒债务未清。

## 设计意图

为土系法师提供防御向的元素契约，强化坦克型法师的阵地与生存能力。
