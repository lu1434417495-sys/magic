# 《幻光尘与视觉欺骗》

## 基础信息

- **书籍 ID**：`book_法师咒术_0067`
- **关联技能**：`mage_glitter_dust`
- **使用效果**：阅读后解锁 `mage_glitter_dust`；若已学会，提升 `current_mastery +90` 并延长致盲效果 1 回合。
- **阅读要求**：角色职业标签含 `mage` 或 `illusionist`；基础 `智力 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：幻术街头表演者摊位、马戏团宝箱、新手幻术师任务奖励。

## 书籍内容

幻光尘是幻术师最诚实的法术——它从不假装真实，只让眼睛暂时背叛大脑。前半本讲解光尘的颗粒大小与致盲时间的关系：太粗的颗粒会被眨眼擦掉，太细的颗粒则无法反射足够的光。作者建议新手先在黑暗房间里撒一把普通面粉，观察它在微光下的漂浮方式。

书中夹着几张彩色玻璃碎片，批注说不同颜色对夜视生物效果不同。后半部是表演技巧：幻光尘最致命的用法不是遮住敌人眼睛，而是让敌人以为看到了不存在的东西，比如一把悬在头顶的剑。

马戏团的幻光尘表演者会在演出结束后收集掉落的尘埃，据说这些尘埃可以用来判断观众当晚最害怕的颜色。幻光尘的收集瓶必须用黑色天鹅绒包裹。黑绒瓶是幻术师标配。光尘偏爱黑暗舞台。每一粒尘埃都是光的记忆。尘埃亦有灵。
## 设计意图

普通级幻术控场书籍，解锁幻光尘并为法师提供低成本致盲手段，服务于幻术与欺诈战术。
