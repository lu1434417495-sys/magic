# 《魔力迸发：过载脉冲》

## 基础信息

- **书籍 ID**：`book_法师咒术_0248`
- **关联技能**：`mage_mana_flare`
- **使用效果**：阅读后解锁 `mage_mana_flare`；若已学会，提升 `current_mastery +160` 并在下一次战斗中使首次魔力迸发对周围敌人造成的伤害随自身当前 MP 增加。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 15` 且 `冥想 ≥ 3`。
- **稀有度**：史诗（Epic）
- **建议投放**：奥术反应堆、魔力涌泉、高阶法师实验室。

## 书籍内容

魔力迸发是把体内多余 MP 一次性释放成冲击波的法术，MP 越多，爆炸越猛烈。书中把这一法术比作打开泄洪闸：你需要蓄满水，然后在最合适的时刻放出去。作者警告，蓄力过程中施法者无法移动，因此必须依赖队友保护或地形掩护。练习者需要先学会在体内安全储存大量 MP，直到皮肤下能看见魔力的微光流动。后半部讲解了如何让魔力迸发与奥能电池、冥想等机制配合，形成蓄力爆发的战斗循环。最末页是一张被烤焦的实验记录，最后一行写着：百分之八十的爆炸来自太贪心，不是咒语。许多法师会在满 MP 时感到一种奇怪的冲动。书中还建议，在释放前高声喊出咒语最后一个音节，有助于把残余魔力彻底排空。

## 设计意图

提供资源转化为爆发的机制，让法师能根据 MP 管理决策制造关键输出，强化冥想体系联动。
