# 《元素化身：火焰篇》

## 基础信息

- **书籍 ID**：`book_法师咒术_0110`
- **关联技能**：`mage_fire_aspect`
- **使用效果**：阅读后解锁 `mage_fire_aspect`；若已学会，提升 `current_mastery +180` 并在下一次战斗中使火焰化身首回合伤害提高 12%。
- **阅读要求**：角色职业标签含 `mage` 或 `pyromancer`；基础 `智力 ≥ 17` 且 `体质 ≥ 12`。
- **稀有度**：史诗（Epic）
- **建议投放**：火山核心圣殿、炎元素王座、灰烬交界火焰区。

## 书籍内容

元素化身不是让法师变成元素，而是让元素暂时住进法师的身体里。火焰篇从控温开始，要求练习者在不灼伤自己的前提下，让血液温度缓慢升高三度。书中详细描述了三种火焰寄宿的位置：心脏负责爆发，胃负责持续，指尖负责精准。作者警告，心脏寄宿最危险，一旦情绪失控，火焰会反过来点燃施法者的理智。第二章是姿态训练：双臂略微张开，肩胛下沉，想象自己是一个正在呼吸的熔炉。书中附带了七段冥想的引导词，用于在化身结束后安抚火焰。最末一页只有一行被烧焦的字：当你感到温暖时，那是火焰在微笑；当你感到灼痛时，它已经在咬你了。化身结束后，法师的头发和皮肤会散发出淡淡的硫磺味，这是元素尚未完全退出的标志。

火焰化身持续期间，施法者的影子会被烧得极淡，仿佛连黑暗都暂时让位于这股 borrowed heat。

## 设计意图

为火焰专精法师提供限时变身机制，强化爆发节奏并拓展元素主题的角色扮演深度。
