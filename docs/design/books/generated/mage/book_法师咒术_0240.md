# 《符文囚牢：刻印牢笼》

## 基础信息

- **书籍 ID**：`book_法师咒术_0240`
- **关联技能**：`mage_rune_prison`
- **使用效果**：阅读后解锁 `mage_rune_prison`；若已学会，提升 `current_mastery +160` 并在下一次战斗中使首次符文囚牢持续时间增加一回合。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 15` 且 `感知 ≥ 12`。
- **稀有度**：史诗（Epic）
- **建议投放**：古代符文塔、禁魔监狱、封印师传承密室。

## 书籍内容

符文囚牢是在目标周围构建一圈发光符文的法术，被困者无法离开牢笼范围，外界攻击也会被符文削弱。书中把囚牢比作一篇写给空间的契约，只要符文完整，空间就会遵守约定。作者详细记录了十二种基础符文组合，每一种对应不同的囚禁对象，例如人类、元素、亡灵等。练习者需要先在纸上反复书写符文，直到闭上眼睛也能准确画出每一笔。后半部讲解了如何在囚牢中加入削弱效果，让被困者不仅出不去，还会逐渐流失 MP。最末页是一段狱卒的批注：最好的牢房不是墙厚，是让囚犯不想逃。许多封印师会把这本书当作建筑设计手册来读。书中还提醒，符文囚牢对纯能量体效果较差，因为它们可能直接穿过符文缝隙逃逸。

## 设计意图

提供强力单体禁锢，让法师能隔离关键敌人或保护脆弱队友，增强战场分割能力。
