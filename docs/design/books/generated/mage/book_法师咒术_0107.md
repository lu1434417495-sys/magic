# 《魔网共振与吟唱频率》

## 基础信息

- **书籍 ID**：`book_法师咒术_0107`
- **关联技能**：`mage_ley_resonance`
- **使用效果**：阅读后解锁 `mage_ley_resonance`；若已学会，提升 `current_mastery +150` 并在下一次战斗中使首个法术的吟唱时间缩短 0.5 回合。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 15` 且 `感知 ≥ 13`。
- **稀有度**：稀有（Rare）
- **建议投放**：魔网节点图书馆、地脉观测站、远古巫师塔。

## 书籍内容

魔网像一张埋在世界深处的琴，施法者的吟唱则是拨弦的手指。本书通过大量频谱图，解释如何让咒语频率与地脉节点产生共振。作者将魔网节点分为稳定节点、脉冲节点和噪音节点三类，并给出各自的匹配口诀。书中警告，强行在不稳定节点上施法会导致咒语反弹，轻者耳鸣，重者短暂失声。练习部分要求读者在不同时间段录下自己的吟唱，再用附录的算法寻找最接近节点频率的版本。作者认为，最好的施法者不是嗓门最大的，而是最能倾听世界脉搏的人。书末附有一张空白五线谱，批注写着：填满它之前，先学会留白。长期练习魔网共振的法师，会逐渐拥有一对内在的耳朵，即使在完全寂静的房间里，也能听见地脉的低沉轰鸣。

有经验的施法者能通过地脉轰鸣的细微变化预测天气，甚至提前察觉远方大型法术的波动。

## 设计意图

为法师提供吟唱节奏与地图机制联动的成长路径，鼓励玩家观察环境并调整施法策略。
