# 《炼狱火雨：苍穹熔炉》

## 基础信息

- **书籍 ID**：`book_法师咒术_0232`
- **关联技能**：`mage_hellfire_rain`
- **使用效果**：阅读后解锁 `mage_hellfire_rain`；若已学会，提升 `current_mastery +180` 并在下一次战斗中使首轮炼狱火雨覆盖范围增加半格。
- **阅读要求**：角色职业标签含 `mage` 或 `pyromancer`；基础 `智力 ≥ 17` 且 `意志 ≥ 14`。
- **稀有度**：传说（Legendary）
- **建议投放**：深渊裂隙、炼狱之门遗址、最终 boss 战利品。

## 书籍内容

炼狱火雨是召唤一片燃烧陨石从天而降的传说级法术，覆盖范围内的所有单位都会遭受毁灭性打击。书中第一页是一幅被烧穿的城市俯瞰图，据说是某位古代法师施放此术后的唯一记录。作者警告，火雨不仅会毁灭敌人，也会改变地形，把草地变成焦土，把河流蒸发成毒雾。练习者需要先在精神层面承受火焰的炙烤，才能与炼狱之火建立契约。后半部讲解了如何控制落点密度，让火雨集中在敌人密集区域而避开己方。最末页只有一行字：当你呼唤天空燃烧时，先确认自己也站在地上。许多火法师终生只敢在梦中施展此术。书中还提到，施展前必须清空头顶云层，否则陨石可能提前在半空引爆，反而削弱地面伤害。炼狱火雨降临时，天空会先出现异样的暗红色，像是世界在流血。有幸见过这一景象而存活的人，大多会在余生中回避红色的天空。

## 设计意图

作为传说级范围毁灭法术，提供极高的爆发伤害与地形改变，成为法师终局输出的代表。
