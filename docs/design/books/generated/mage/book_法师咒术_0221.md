# 《霜障壁：冰原城墙》

## 基础信息

- **书籍 ID**：`book_法师咒术_0221`
- **关联技能**：`mage_frost_barrier`
- **使用效果**：阅读后解锁 `mage_frost_barrier`；若已学会，提升 `current_mastery +140` 并在下一次战斗中使首面霜障壁被击破时对周围敌人造成减速。
- **阅读要求**：角色职业标签含 `mage` 或 `cryomancer`；基础 `智力 ≥ 12` 且 `体质 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：冰霜要塞军械库、冬幕学院防御课、雪原遗迹。

## 书籍内容

霜障壁是从地面升起的厚重冰墙，能阻挡远程攻击并分割战场。书中第一节要求练习者先学会在手掌上凝出一小块冰砖，直到冰砖能承受自己的体重不碎裂。作者认为，冰墙的价值不在于永久存在，而在于它存在的那几回合能改变敌人的决策。后半部讲解了如何在冰墙中预埋尖锐的冰刺，让试图翻越的敌人付出代价，以及如何让冰墙在融化时释放寒气减速周围单位。最末页是一段守城法师的留言：城墙会融化，但融化本身也是武器。许多北方领主会重金聘请能施展霜障壁的法师，因为他们的城堡因此少修了很多石墙。书中还附有一张冰砖配方便条，提醒加入少量海盐可让冰墙在承受火焰时多坚持片刻。霜障壁融化后的水常被收集起来，据说比寻常井水更适合泡茶。北境贵族甚至专门聘请霜法师，只为在宴会上表演凝冰取水的技艺。

## 设计意图

提供战场分割与防护手段，让法师能为团队创造掩体，强化阵地战中的战略地位。
