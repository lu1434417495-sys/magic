# 《私语书页：会自己找人的信》

## 基础信息

- **书籍 ID**：`book_法师咒术_0032`
- **关联技能**：`mage_whispering_page`
- **使用效果**：阅读后解锁 `mage_whispering_page`；若已学会，提升 `current_mastery +90`，并在下一次战斗中使私语书页的传递距离增加 3 格。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：信使公会密档、法师塔邮局、情报站书架。

## 书籍内容

私语书页是一种把信息封印在纸张中，让它自动飞向指定目标的咒术。这本书的封面就是一张曾经飞过半个大陆的羊皮纸，上面还留着几道焦黑的闪电痕迹。作者认为，真正的通信法术不应该只是传递文字，还应该传递一部分发送者当时的心情。

前半部分教读者如何把一段简短的信息压缩进一页纸，并设定接收者的魔力特征作为导航。后半部分讲解实战中的妙用：在战斗前把战术指令送给队友，或者在逃跑时丢下一张会尖叫的书页吸引敌人注意。书中警告，私语书页有可能被具备魔力感知能力的人中途截获，因此绝密信息还需要额外加密。最后一页是一张空白纸，但只要把它对折，就能听见一段模糊不清的耳语。

作者推荐使用一种名为"风语纸"的特殊材料，它比普通羊皮纸更轻，也更容易被魔力驱动，能在复杂气流中保持稳定飞行。

## 设计意图

为法师系提供早期通信与信息传递技能，强化团队配合与战术调度能力，同时为后续契约系、使魔系与远程精神链接类法术建立熟练度基础。
