# 《烈焰余烬的二次燃烧》

## 基础信息

- **书籍 ID**：`book_法师咒术_0084`
- **关联技能**：`mage_ember_wisp`
- **使用效果**：阅读后解锁 `mage_ember_wisp`；若已学会，提升 `current_mastery +110` 并在下一次战斗中使余烬精灵首次爆炸范围扩大。
- **阅读要求**：已学会 `mage_fireball` 或 `mage_burning_hands`；角色职业标签含 `mage`；基础 `智力 ≥ 9`。
- **稀有度**：精良（Uncommon）
- **建议投放**：火元素栖息地、灰烬交界营地、烈焰祭坛奖励。

## 书籍内容

烈焰余烬是火球术失败后的产物——一团没有足够燃料继续燃烧的火星，却仍然保持着燃烧的记忆。前半本讲解'二次燃烧'：施术者不是点燃余烬，而是提醒它还没有烧完。作者建议在练习时先制造一堆小火星，再尝试让它们依次复燃。

书中警告，余烬精灵很不稳定，如果周围有易燃物，它可能会提前引爆。中段收录了操控技巧：余烬精灵会被快速移动的目标吸引，因此可以用来追击逃跑的敌人；但它也容易被风引偏，所以室外使用时要格外小心。后半部讨论美学：一只优秀的余烬精灵应该在空中划出弧线，而不是直直地飞过去。

烈焰祭坛的祭司会把余烬精灵收集在陶罐里，作为仪式中的照明工具，但每个陶罐底部都留有小孔以防提前引爆。烈焰余烬需要在陶罐里摇晃才能唤醒。摇晃陶罐节奏编成圣歌。
## 设计意图

精良级火焰召唤/延迟伤害书籍，前置要求火系技能，为法师提供持续压力与区域控制，强调不稳定与二次利用。
