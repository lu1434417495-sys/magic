# 《骨牢与意图锁定》

## 基础信息

- **书籍 ID**：`book_法师咒术_0092`
- **关联技能**：`mage_phantom_cage`
- **使用效果**：阅读后解锁 `mage_phantom_cage`；若已学会，提升 `current_mastery +120` 并提升骨牢耐久 `+10%`。
- **阅读要求**：角色职业标签含 `mage` 或 `necromancer`；基础 `智力 ≥ 11`。
- **稀有度**：精良（Uncommon）
- **建议投放**：古墓囚室、死灵法师训练场、刑具博物馆藏书。

## 书籍内容

骨牢不是用骨头围成笼子，而是用目标的'被限制意图'来成形。前半本讲解意图锁定：施术者必须在敌人心中种下一个念头——'我逃不掉'——然后让这个念头具现为实体。作者强调，骨牢对完全不怕被困的敌人效果很差，比如狂战士或某些亡灵。

中段收录了构造细节：骨牢的每一根骨头都来自不同的死者，因此必须先用一句统一的悼词安抚它们，否则骨牢会在成形后互相争斗。后半部讨论解除方式：最干净的解除不是击碎，而是让被困者真心相信自己可以离开，但那时候往往已经太晚了。

古墓囚室的墙上刻满了抓痕，其中一些抓痕的间距与人类手指不符，那是骨牢在成形前试探空间的痕迹。骨牢的抓痕会被新来的学徒当作装饰临摹。抓痕被用在家具设计中。骨牢会挑选囚徒。骨牢有签名。
## 设计意图

精良级死灵控制书籍，解锁幻影骨牢并提供单体禁锢能力，强调意图与心理锁定。
