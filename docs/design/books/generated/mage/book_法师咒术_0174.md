# 《水晶回声的倾听术》

## 基础信息

- **书籍 ID**：`book_法师咒术_0174`
- **关联技能**：`mage_crystal_echo`
- **使用效果**：阅读后解锁 `mage_crystal_echo`；若已学会，提升 `current_mastery +160` 并在下一次战斗中使水晶回声首次成功倾听时复制敌方下一次施法的前置动作。
- **阅读要求**：角色职业标签含 `mage` 或 `crystal_seer`；基础 `智力 ≥ 17` 且 `感知 ≥ 15`。
- **稀有度**：史诗（Epic）
- **建议投放**：水晶洞窟、占卜师塔楼、矿物共振室。

## 书籍内容

水晶能够记录周围发生的魔法事件，并以回声形式保存一段时间。本书教导如何倾听这些回声，从而推断出附近发生过什么法术、由谁施放以及施法者的情绪状态。作者从选择水晶开始，讲解不同晶面切割方式对回声清晰度的影响。书中强调，倾听时必须保持绝对安静，连自己的心跳都可能干扰解读。第二章介绍回声的分层：最外层是最近的法术，越往深处越古老，也越模糊。最末一页是一份危险警示，批注写道：有些回声不想被听见，它们会顺着你的耳朵爬进记忆。练习者需要先用小水晶记录自己的法术再回放，逐步适应回声的节奏。这门技艺在追踪敌人、破解结界和预判战术方面都有重要价值。

某些古老水晶中的回声会自行组合成旋律，那是数个世纪前施法者留下的歌声。

## 设计意图

为水晶主题法师提供信息获取与预判技能，强化水晶作为记忆载体的设定。
