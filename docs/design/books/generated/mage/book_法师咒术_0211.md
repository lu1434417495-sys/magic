# 《力场推击：排斥之掌》

## 基础信息

- **书籍 ID**：`book_法师咒术_0211`
- **关联技能**：`mage_force_push`
- **使用效果**：阅读后解锁 `mage_force_push`；若已学会，提升 `current_mastery +130` 并在下一次战斗中使首次力场推击击退距离增加一格。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 11`。
- **稀有度**：普通（Common）
- **建议投放**：法师公会训练场、遗迹壁画拓本、冒险者公会奖励。

## 书籍内容

力场推击是将压缩空气与魔力混合后向前爆发的简单法术，能把敌人推开或撞倒障碍物。书中从鼓掌开始讲解原理，作者认为每一次推击都是一次被控制住的爆炸。练习者需要先对蜡烛火焰施放，直到能做到只让火焰倾斜而不熄灭，才算掌握力度。后半部列举了推击的各种战术价值：把敌人推下高台、打断冲锋、或者为自己争取宝贵的咏唱时间。最末页是一段前任法师的笔记：推击不是侮辱，是拒绝。许多法师在酒馆斗殴中偷偷使用这个法术，因为对手往往只会以为自己没站稳。书中还画有几种手势变体，比如双掌合推可增强正面冲击，单掌侧挥则能把敌人扫向两侧，让初学者能在不同战局中灵活运用这股排斥之力。许多老法师把力场推击当作开门的礼节，因为推门有时太费力气。

## 设计意图

提供低耗蓝位移控制技能，让法师拥有基础自保与地形互动能力，丰富初级战术选择。
