# 《奥术分类学导论》

## 基础信息

- **书籍 ID**：`book_法师咒术_0188`
- **关联技能**：`mage_arcane_taxonomy`
- **使用效果**：阅读后解锁 `mage_arcane_taxonomy`；若已学会，提升 `current_mastery +170` 并在下一次战斗中使分类判定成功时提高对目标类型敌人的伤害 25% 2 回合。
- **阅读要求**：角色职业标签含 `mage` 或 `loremaster`；基础 `智力 ≥ 19` 且 `感知 ≥ 15`。
- **稀有度**：传说（Legendary）
- **建议投放**：大图书馆核心、法师大学讲堂、博学者的密室。

## 书籍内容

奥术分类学是一门研究如何将世间万物按照其魔法属性归类的学问。本书从分类原则开始，教导读者如何快速判断一个生物、物体或法术所属的学派与弱点。作者强调，分类不是贴标签，而是发现事物之间隐藏的联系。书中收录了数百种常见对象的分类条目，以及如何应对跨学派混合体的策略。第二章讨论分类失败的代价：错误的归类会让后续法术事倍功半，甚至完全无效。最末一页写着：理解先于力量，命名先于掌控。练习者需要随身携带一本分类笔记，记录每一次遭遇的对象特征。这门技艺在战棋中能让法师针对敌人类型调整战术，发挥出超越常规的伤害。

奥术分类学的终极目标是编写一部包含所有存在分类的百科全书，目前最厚的一卷仍未完成。

为知识型法师提供针对性增益机制，奖励玩家对怪物与魔法体系的了解。
