# 《暴风雪的视界管理》

## 基础信息

- **书籍 ID**：`book_法师咒术_0073`
- **关联技能**：`mage_hail_storm`
- **使用效果**：阅读后解锁 `mage_hail_storm`；若已学会，提升 `current_mastery +140` 并扩大暴风雪半径一格。
- **阅读要求**：已学会 `mage_frost_bolt` 或 `mage_ice_lance`；角色职业标签含 `mage`；基础 `智力 ≥ 12`。
- **稀有度**：稀有（Rare）
- **建议投放**：北境高塔、冰霜巨龙巢穴藏书、极地远征队奖励。

## 书籍内容

暴风雪不只是攻击敌人，更是在战场上制造一片'自己更习惯'的环境。前半本讲解视界管理：施术者必须提前记住暴风雪区域内的地形轮廓，因为在法术生效期间，能见度会同时影响敌我双方。作者建议在施术前先在心中把战场分成'安全移动格'与'危险停留格'。

中段收录了'冰雹节奏'：大雪粒负责制造噪音掩护，小冰屑负责降低敌人命中，真正的伤害来自夹杂其中的尖锐冰锥。后半部警告：暴风雪对远程友军同样不友好，施术前必须与队友约定撤退信号。最后一页画着一个被雪糊住脸的法师，配文'先学会在暴风雪里找到自己，再让别人找不到你。'

北境高塔的窗户采用特殊的三层玻璃，因为普通玻璃会在暴风雪法术的余波中瞬间结霜并碎裂。暴风雪的施术者必须学会在风雪中睁眼。风雪中睁眼是基础考核。
## 设计意图

稀有级冰霜范围控制书籍，前置要求冰系基础技能，解锁大范围环境改造能力，强调敌我空间管理。
