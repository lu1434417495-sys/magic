# 《重力羽毛笔的握法》

## 基础信息

- **书籍 ID**：`book_法师咒术_0167`
- **关联技能**：`mage_gravity_quill`
- **使用效果**：阅读后解锁 `mage_gravity_quill`；若已学会，提升 `current_mastery +160` 并在下一次战斗中使重力书写首次命中时降低目标 25% 移动速度 1 回合。
- **阅读要求**：角色职业标签含 `mage` 或 `gravitist`；基础 `智力 ≥ 17` 且 `感知 ≥ 14`。
- **稀有度**：稀有（Rare）
- **建议投放**：浮空塔、重力实验室、天体质检站。

## 书籍内容

重力羽毛笔是一种用压缩重力作为笔尖的书写工具，它写下的每一笔都能改变物体的重量感。本书从握法开始，教导施法者如何用手指感知笔端的重力波动，而不是依靠视觉。作者强调，书写速度必须均匀：太快会让重力断流，太慢则会让墨迹过重压穿纸面。书中记录了七种基本笔画对应的重力效果，横画增加压力，竖画改变方向，而点画则能制造短暂的停滞。最末一章讨论如何在战斗中快速书写临时符文，作者建议先在沙盘上练习，因为沙子能承受失败的重力。批注写道：每一笔都是一次让步，让现实承认你的意志。练习者需要用重力笔在空中写下自己的名字而不颤抖，才算初步入门。

初学者常因重力笔过重而手腕酸痛，作者建议每日只练习三行字。

## 设计意图

为重力系法师提供远程削弱与控制技能，将书写艺术与重力魔法结合。
