# 《传送闪现的距离感训练》

## 基础信息

- **书籍 ID**：`book_法师咒术_0059`
- **关联技能**：`mage_blink`
- **使用效果**：阅读后解锁 `mage_blink`；若已学会，提升 `current_mastery +120` 并增加下一次战斗中首次闪现后 1 回合内的移动速度。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 10` 且 `敏捷 ≥ 8`。
- **稀有度**：稀有（Rare）
- **建议投放**：传送门研究所、沉钟书库空间学区、高塔移动课程奖励。

## 书籍内容

闪现不是消失再出现，而是把'这里'和'那里'之间的空间折叠成一步。作者认为最危险的不是落点有敌人，而是落点在心里不够清楚。前半本要求练习者在闭着眼睛的情况下，凭记忆画出自己所在房间每一寸地面的触感：哪块地板有裂缝，哪里有风，哪块木头会响。

书中强调，闪现依赖的不是视力，而是'身体地图'。中段收录了'三步训练'：先闪现到自己背后一步，再闪现到侧身一步，最后闪现到视线外的一步。后半部警告：不要在情绪剧烈波动时闪现，因为恐惧会让落点向'远离危险'的方向偏移，结果可能正好撞上另一个危险。

传送门研究所的走廊里贴满了告示，提醒研究员闪现落地时务必先确认脚下不是另一位同事刚刚打开的传送门。传送闪现的教材封底印着禁止传送的地点清单。禁传地点每年因事故更新。
## 设计意图

稀有级空间移动书籍，解锁法师核心位移技能，把闪现从简单逃生提升为空间感知与战术落点选择的艺术。
