# 《重力井：塌陷之眼》

## 基础信息

- **书籍 ID**：`book_法师咒术_0223`
- **关联技能**：`mage_gravity_well`
- **使用效果**：阅读后解锁 `mage_gravity_well`；若已学会，提升 `current_mastery +170` 并在下一次战斗中使首次重力井吸引范围增加一格。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 16` 且 `意志 ≥ 13`。
- **稀有度**：史诗（Epic）
- **建议投放**：星界观测站、坍塌浮空城、重力异常区域。

## 书籍内容

重力井是在指定区域制造局部强引力的法术，能把周围敌人拉向中心并压制其行动。书中第一页是一颗被压扁的铜球，展示了法术失控时的可怕后果。作者强调，重力井的维持需要持续消耗大量魔力，因此必须配合队友的爆发技能使用。练习者需要先在反重力环境中感受引力的变化，再尝试在正常空间中制造局部塌陷。后半部讲解了如何让重力井与陨石、熔核珠等落体法术配合，形成集中打击。最末页是一段被撕裂的公式，旁边批注：算错一步，井会变成陷阱。许多法师会在练习时先在地上画好安全线。高阶技巧提到，把重力井中心设在自己脚下可让近战敌人难以靠近，但同时也会让施法者自身承受额外负荷。重力井消失后，地面往往会出现一个完美的圆形凹陷，像被巨人按过。

## 设计意图

提供强力的范围聚拢控制，为团队集火创造机会，强化法师在协同战斗中的核心作用。
