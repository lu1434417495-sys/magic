# 《流沙术的地质笔记》

## 基础信息

- **书籍 ID**：`book_法师咒术_0066`
- **关联技能**：`mage_quicksand`
- **使用效果**：阅读后解锁 `mage_quicksand`；若已学会，提升 `current_mastery +120` 并扩大流沙区域一格。
- **阅读要求**：角色职业标签含 `mage` 或 `geomancer`；基础 `智力 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：沙漠遗迹图书馆、地质学者营地、土元素祭坛奖励。

## 书籍内容

流沙术不是制造沙子，而是让脚下的土地暂时忘记自己是固体。前半本是一份地质笔记，作者用不同颜色的墨水标注了黏土、砂岩与腐殖土在法术作用下的反应差异。书中强调，成功的流沙必须让目标在迈出第一步时才察觉，因此表层要保留足够的'欺骗性硬度'。

中段收录了'三步沉陷'：先让脚踝没入，再让膝盖受限，最后才完全固定。作者警告，流沙术对体重过大的敌人效果更好，但对会飞的敌人几乎无效。后半部讨论了'流沙的仁慈'——它造成的伤害很小，却能让最凶猛的战士变成瓮中之鳖。

沙漠遗迹的墙上留有古代法师的涂鸦，画着一个战士在流沙中只露出头盔，旁边写着"站得太直是罪"。流沙术的实践场地必须提前三个月申请。三个月申请让课程稀缺。流沙偏爱直立的猎物。沙粒是最好的老师。
## 设计意图

稀有级地形控制书籍，解锁流沙术并为法师提供区域限制能力，强调地质知识与战场预判的结合。
