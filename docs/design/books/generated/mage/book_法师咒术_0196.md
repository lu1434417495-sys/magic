# 《霜冻账簿的核对》

## 基础信息

- **书籍 ID**：`book_法师咒术_0196`
- **关联技能**：`mage_frost_ledger`
- **使用效果**：阅读后解锁 `mage_frost_ledger`；若已学会，提升 `current_mastery +180` 并在下一次战斗中使霜冻账簿首次核对时冻结敌方等同于已造成伤害 30% 的生命恢复。
- **阅读要求**：角色职业标签含 `mage` 或 `cryomancer`；基础 `智力 ≥ 18` 且 `感知 ≥ 16`。
- **稀有度**：传说（Legendary）
- **建议投放**：冰霜银行、雪原交易所、古代税务所。

## 书籍内容

霜冻账簿是一种记录伤害与寒冷债务的魔法账本，能够让敌人欠下的每一滴鲜血都以冰冻形式偿还。本书从记账规则开始，讲解如何在战斗中实时记录自己对敌人造成的伤害，并在合适的时机要求结算。作者强调，账簿必须保持清晰，任何模糊的记录都会导致结算失败。书中讨论了不同敌人的债务类型：再生型生物最怕冻结恢复，吸血型敌人则会对血液凝固感到恐惧。第二章介绍核对时机，通常在敌人即将大量回血前进行最为有效。最末一页写着：寒冷是最公正的收债人。练习者需要先学会在心中快速估算伤害，再用霜冻账簿验证自己的计算。这门技艺在对抗高恢复敌人时能够形成致命克制。

霜冻账簿的封面由永不融化的冰片装订而成，只有施法者本人能翻开它。

## 设计意图

为冰系法师提供反治疗机制，将经济账簿概念与冰霜主题结合。
