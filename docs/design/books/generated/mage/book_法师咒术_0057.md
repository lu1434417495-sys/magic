# 《暗影箭：光的背面》

## 基础信息

- **书籍 ID**：`book_法师咒术_0057`
- **关联技能**：`mage_shadow_bolt`
- **使用效果**：阅读后解锁 `mage_shadow_bolt`；若已学会，提升 `current_mastery +110` 并在下一次战斗中使首发射击附带 2 回合`dim`脆弱标记。
- **阅读要求**：角色职业标签含 `mage` 或 `warlock`；基础 `智力 ≥ 9`。
- **稀有度**：精良（Uncommon）
- **建议投放**：影塔藏书、遗迹暗影祭坛、流浪术士行囊。

## 书籍内容

暗影箭不是从黑暗里来，而是从'光不够亮的地方'来。作者要求施术者先凝视一盏灯，直到能在闭眼后仍看见灯丝的残像，再把这份残像反转成暗影。前半本讲解'负向聚焦'：不是凝聚魔力，而是让魔力围绕一个空无的点旋转。

书中警告，暗影箭对心怀愧疚的人特别危险——它会借用施术者不愿回忆的画面作为形状，有几名练习者因此被自己射出的箭吓退。后半部是战场运用：暗影箭最可怕的不是伤害，而是它落地后留下的'影渍'，会让区域内的人下意识地看向错误方向。

最后一页只有一行小字：'别在完全黑暗的地方施放它，它会在那里迷路。'

影塔的学者发现，暗影箭在穿过清晨或黄昏的光线时会产生极短的彩虹残影，那是光在填补被箭矢借走的空隙。暗影箭的轨迹常被误认为是眼角的疲劳残影。彩虹残影让研究者争论。
## 设计意图

精良级暗影/奥术混合输出书籍，解锁暗影箭并为恐惧与控场战术提供入口，强调暗影魔法对施术者心智的反馈。
