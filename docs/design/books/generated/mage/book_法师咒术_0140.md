# 《元素风暴的指挥手势》

## 基础信息

- **书籍 ID**：`book_法师咒术_0140`
- **关联技能**：`mage_elemental_storm`
- **使用效果**：阅读后解锁 `mage_elemental_storm`；若已学会，提升 `current_mastery +180` 并在下一次战斗中使元素风暴首次伤害范围向外扩展半格。
- **阅读要求**：角色职业标签含 `mage` 或 `elementalist`；基础 `智力 ≥ 18` 且 `体质 ≥ 12`。
- **稀有度**：史诗（Epic）
- **建议投放**：元素王座、风暴祭坛核心、高阶元素试炼最终奖励。

## 书籍内容

元素风暴不是单一法术，而是一场需要现场指挥的混战。本书从指挥手势开始，要求施法者用左手控制火、右手控制水、眼神引导风、脚步震动土。作者强调，四种元素同时出现时最容易互相冲突，因此指挥者必须像乐团指挥一样精确分配注意力。书中收录了十二种基础手势，每种手势的微小变化都会让元素偏向攻击或防御。作者警告，在元素风暴中失去控制的元素会攻击施法者自己，所以必须预留一个紧急平息动作。第二章讨论如何根据敌人属性临时调整元素比例。最末一页画着一只四只手同时挥动的剪影，批注写道：风暴不是被召唤的，是被说服的。元素风暴的持续时间取决于施法者的肺活量与专注力，中途换气必须用特定手势衔接，否则风暴会立刻解体。高阶元素使往往能在风暴中走出优雅的舞步。

## 设计意图

为元素法师提供高阶范围爆发，强调多资源协调与即时指挥，强化大规模战斗表现力。
