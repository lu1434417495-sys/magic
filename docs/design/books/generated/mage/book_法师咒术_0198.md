# 《奥术安魂的回响》

## 基础信息

- **书籍 ID**：`book_法师咒术_0198`
- **关联技能**：`mage_arcane_requiem`
- **使用效果**：阅读后解锁 `mage_arcane_requiem`；若已学会，提升 `current_mastery +200` 并在下一次战斗中使奥术安魂完成时为全队恢复 12% 最大 MP 并清除一个随机 debuff。
- **阅读要求**：角色职业标签含 `mage` 或 `archmage`；基础 `智力 ≥ 20` 且 `意志 ≥ 16`。
- **稀有度**：传说（Legendary）
- **建议投放**：世界树根部禁书区、法师议会终极传承、远古战场遗迹。

## 书籍内容

奥术安魂是一种为逝去的魔法能量举行的葬礼咏唱，能够让残余魔力回归施法者并治愈队伍。本书从安魂的旋律开始，讲解如何用低沉的咏唱引导战场上散失的魔力重新聚集。作者强调，安魂不是复活，而是让已经释放的法术得到安息，同时回收它们最后的馈赠。书中记录了不同学派法术死亡时的不同回响：火焰会发出最后的温暖，冰霜会留下清凉，而亡灵法术则需要额外的净化音节。第二章讨论如何在敌人攻击下完成咏唱，作者建议由队友构建防护圈。最末一页写着：每一道逝去的咒语都值得一场告别。练习者需要先为训练用的低阶法术举行小型安魂仪式，感受魔力回归的流动。这门技艺在持久战中能为团队提供宝贵的续航与净化。

## 设计意图

为高阶法师提供团队续航与净化技能，深化魔法循环与仪式感。
