# 《连锁霜冻：寒潮接力》

## 基础信息

- **书籍 ID**：`book_法师咒术_0239`
- **关联技能**：`mage_chain_frost`
- **使用效果**：阅读后解锁 `mage_chain_frost`；若已学会，提升 `current_mastery +150` 并在下一次战斗中使首次连锁霜冻额外弹跳两个目标。
- **阅读要求**：角色职业标签含 `mage` 或 `cryomancer`；基础 `智力 ≥ 14` 且 `感知 ≥ 12`。
- **稀有度**：稀有（Rare）
- **建议投放**：冰封古战场、霜精灵遗迹、极地魔法师营地。

## 书籍内容

连锁霜冻是发射一道能在敌人之间跳跃的寒冰能量，每次命中都会降低目标移动速度。书中把这道能量比作冬天里的窃窃私语，它会在人群中最怕冷的那个人身上停留最久。作者强调，跳跃的距离和角度取决于施法者对寒气的引导，仓促施放只会让霜冻在第一个目标身上消散。练习者需要先在冰面上滚动水珠，观察它们在低温下如何相互粘连。后半部讲解了如何利用连锁霜冻清理成群的小怪，以及如何让最后一跳命中关键目标完成收割。最末页是一句被冻在冰里的格言：寒冷喜欢聚会。许多霜法师会在施法时默数跳跃次数，仿佛那是一道寒冷的算术题。书中还提醒，若敌人体温 already 极低，连锁霜冻可能直接将其冻结在原地。

## 设计意图

提供多目标减速连锁，让冰系法师在面对群敌时拥有清场与控场兼备的手段。
