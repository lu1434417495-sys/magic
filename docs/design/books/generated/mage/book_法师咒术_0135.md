# 《次元锚点的稳定性》

## 基础信息

- **书籍 ID**：`book_法师咒术_0135`
- **关联技能**：`mage_dimensional_anchor`
- **使用效果**：阅读后解锁 `mage_dimensional_anchor`；若已学会，提升 `current_mastery +170` 并在下一次战斗中使次元锚点首次触发时额外阻止一次传送。
- **阅读要求**：角色职业标签含 `mage` 或 `abjurer`；基础 `智力 ≥ 17` 且 `感知 ≥ 13`。
- **稀有度**：史诗（Epic）
- **建议投放**：空间稳定局、异界裂隙营地、防护学派密室。

## 书籍内容

次元锚点不是钉子，而是一种让局部空间变得黏稠的咒语。本书从稳定性开始，要求施法者在锚点落下后持续用意识微调其频率，因为周围的空间会不断试图恢复原状。作者指出，锚点的有效范围与施法者的专注力成正比，一旦分心，锚点就会像沉入水中的石头一样消失。书中收录了三种锚点形态：钉型用于固定单个敌人，网型用于覆盖区域，塔型用于保护队友。作者警告，在已经不稳定的空间中使用锚点，可能会引发次元震荡，把周围所有人抛向随机方向。第二章介绍如何识别敌人的传送前兆，提前布下锚点。最末一页画着一个被钉住的漩涡，批注写道：稳定不是不动，而是拒绝被带走。次元锚点持续期间，施法者自身也无法传送，这是一种双向约束。作者认为，愿意承受同样限制的人，才能真正驾驭稳定的力量。

## 设计意图

为防护与控制法师提供反传送手段，克制高机动敌人并强化阵地控制能力。
