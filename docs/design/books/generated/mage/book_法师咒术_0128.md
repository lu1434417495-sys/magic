# 《魔力虹吸的伦理边界》

## 基础信息

- **书籍 ID**：`book_法师咒术_0128`
- **关联技能**：`mage_mana_siphon`
- **使用效果**：阅读后解锁 `mage_mana_siphon`；若已学会，提升 `current_mastery +160` 并在下一次战斗中使虹吸转化的 MP 效率提高 10%。
- **阅读要求**：角色职业标签含 `mage` 或 `warlock`；基础 `智力 ≥ 16` 且 `意志 ≥ 14`。
- **稀有度**：史诗（Epic）
- **建议投放**：黑市拍卖行、禁忌图书馆、魔法监狱密室。

## 书籍内容

魔力虹吸允许施法者从周围环境或敌人身上抽取能量，但每一次抽取都伴随着伦理问题。本书第一章将虹吸对象分为四类：无生命物体、野生动物、敌对法师与自愿盟友，并逐类讨论可接受程度。作者认为，从石头中抽取魔力最为安全，因为石头的反抗最小；从智慧生物抽取则会让施法者的梦境混入对方的记忆碎片。书中收录了多种过滤咒语，用来清除吸入魔力中的情绪残渣。作者警告，虹吸上瘾是许多暗法师堕落的起点，一旦开始把盟友当作电池，魔力本身也会变质。第二章提供了一套自我监察表格，建议每月填写一次。最末一页写着：虹吸不是偷窃，而是你与世界之间的一笔贷款。书中还指出，虹吸植物魔力的效率远低于矿物，但对生态的破坏最小。许多德鲁伊对这门技艺保持警惕，却也不得不承认其节制使用的价值。

## 设计意图

为暗法师提供资源续航手段，同时用伦理边界增加角色扮演的重量与选择后果。
