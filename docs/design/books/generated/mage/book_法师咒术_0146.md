# 《混沌魔方的稳定面》

## 基础信息

- **书籍 ID**：`book_法师咒术_0146`
- **关联技能**：`mage_chaos_cube`
- **使用效果**：阅读后解锁 `mage_chaos_cube`；若已学会，提升 `current_mastery +170` 并在下一次战斗中使混沌魔方首次稳定面触发时效果持续时间延长 1 回合。
- **阅读要求**：角色职业标签含 `mage` 或 `wildmage`；基础 `智力 ≥ 17` 且 `感知 ≥ 13`。
- **稀有度**：史诗（Epic）
- **建议投放**：混沌裂隙实验室、疯法师塔、随机事件奖励。

## 书籍内容

混沌魔方是一个不断旋转的微型次元体，每一面都对应一种随机效果。本书从寻找稳定面开始，因为在旋转中有一瞬间，魔方会呈现出一个相对静止的面，抓住这一瞬间才能控制它。作者将稳定面比作暴风雨中的眼，虽然短暂，却真实存在。书中记录了数十种效果与对应颜色的关系，但警告这些关系会随着使用者的心情而改变。作者强调，混沌魔方的持有者必须学会接受意外，因为即使是最熟练的使用者也无法每次都得到想要的结果。第二章讨论如何在团队战中将混沌魔方当作最后手段，用它的不可预测性打破僵局。最末一页画着一个不停转动的立方体，批注写道：稳定不是停止，而是知道自己在转。熟练的混沌法师会在魔方旋转时观察光晕的强弱，用直觉判断下一次稳定面可能出现的位置。

## 设计意图

为混沌法师提供随机收益型道具技能，强化不确定性与娱乐性，丰富战棋中的惊喜机制。
