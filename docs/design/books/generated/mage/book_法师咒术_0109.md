# 《时间褶皱的补丁学》

## 基础信息

- **书籍 ID**：`book_法师咒术_0109`
- **关联技能**：`mage_time_patch`
- **使用效果**：阅读后解锁 `mage_time_patch`；若已学会，提升 `current_mastery +170` 并在下一次战斗中首次修补褶皱时额外移除目标一个减益。
- **阅读要求**：角色职业标签含 `mage` 或 `chronomancer`；基础 `智力 ≥ 18` 且已学会 `mage_time_dilate`。
- **稀有度**：史诗（Epic）
- **建议投放**：时之塔密室、命运裂隙深处、时间旅者传承任务。

## 书籍内容

时间不是一条直线，而是一块容易被勾丝的织物。本书教授如何在局部褶皱上打补丁，让过去几秒内的失误得到修正。补丁学的第一步是定位勾丝点，作者建议使用一种特殊的呼吸法让意识退后半拍。第二步是用咒语编织覆盖层，覆盖层必须比原时间更薄，否则会造成新的鼓包。书中警告，同一条褶皱上不能连续打两次补丁，否则时间会在补丁边缘裂开。作者还记录了失败的典型案例：一名法师试图修补自己的死亡，结果制造出一段无限循环的临终三秒。书末夹着一张烧焦的便签：补丁只能补洞，不能补命。时间补丁对施法者的精神负担极大，频繁使用会让记忆出现不连贯的跳跃，使用者需要定期整理自己的记忆锚点，否则将在过去与未来之间迷路。

## 设计意图

为高阶时法师提供团队辅助与状态修正手段，强化时间操控的策略深度与代价感。
