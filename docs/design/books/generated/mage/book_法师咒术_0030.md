# 《月滴术：借用月光的治愈之力》

## 基础信息

- **书籍 ID**：`book_法师咒术_0030`
- **关联技能**：`mage_moon_drop`
- **使用效果**：阅读后解锁 `mage_moon_drop`；若已学会，提升 `current_mastery +90`，并在下一次战斗中使月滴术在夜间使用时治疗效果提升 20%。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：月神殿偏殿、夜间集市、天文台藏书室。

## 书籍内容

月滴术是一种温和的治疗咒术，施术者凝聚一滴含有月光精华的魔力水滴，让它落在伤口上，缓慢促进愈合。这本书的作者相信，月光不是火焰那样炽热的能量，而是一种冷静的、持续的修复力量。前半部分教读者如何在夜晚感受到月光的"重量"，并把那种重量导入水滴。

后半部分讨论月相的影响：满月时的月滴术效果最好，新月时则几乎无效。书中还提到，月滴术对由阳光或火焰造成的烧伤有额外的镇痛效果。作者警告，不要在正午尝试凝聚月滴，那会让魔力像找不到家的孩子一样在掌心乱撞。最后一页是一幅月相图，每个相位旁边都标注着对应的月滴强度。

作者强调，月滴术对水质有很高要求，含有杂质的水会削弱月光精华的纯度，因此野外施法时最好先用魔力过滤一遍水源。书中还提到，用月滴术治疗他人时，施术者会感受到对方伤口处传来的微弱凉意。

## 设计意图

为法师系提供早期治疗技能，引入"月相"与"天体能量"主题，强化时间与环境对治疗法术的影响，同时为后续光明系、自然系与天体魔法类法术建立熟练度连接。
