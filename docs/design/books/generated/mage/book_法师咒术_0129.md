# 《星辰排列与施法窗口》

## 基础信息

- **书籍 ID**：`book_法师咒术_0129`
- **关联技能**：`mage_star_alignment`
- **使用效果**：阅读后解锁 `mage_star_alignment`；若已学会，提升 `current_mastery +170` 并在下一次战斗中使星辰法术的暴击率提高 8%。
- **阅读要求**：角色职业标签含 `mage` 或 `astromancer`；基础 `智力 ≥ 17` 且 `感知 ≥ 15`。
- **稀有度**：史诗（Epic）
- **建议投放**：观星台顶层、星象学派密室、远古天文台。

## 书籍内容

星辰从不回应祈祷，它们只是在特定排列时愿意被借用。本书整理了二十八个主要星座的运行周期，帮助施法者预测最佳的施法窗口。作者指出，窗口通常只持续数秒，提前或延后都会导致法术威力减半。书中收录了七类星辰能量的属性：有的偏向燃烧，有的偏向冻结，有的则专门瓦解护盾。作者警告，不要在日食或彗星过境时强行施法，因为天体的异常状态会让咒语反向作用。第二章介绍如何在无法观测星空的地下环境中，借助星图与沙漏模拟窗口。最末一页是一张残缺星图，旁边写着：真正的窗口不在天上，而在你放下傲慢的那一刻。熟练后，施法者能在心中默算星辰位置，无需抬头即可抓住窗口。这种能力被称为内星图，是星象法师的骄傲。

## 设计意图

为星象法师提供时机型爆发机制，将天文设定与战斗节奏结合，强化策略深度。
