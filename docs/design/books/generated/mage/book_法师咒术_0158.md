# 《光阱的折射设置》

## 基础信息

- **书籍 ID**：`book_法师咒术_0158`
- **关联技能**：`mage_luminous_trap`
- **使用效果**：阅读后解锁 `mage_luminous_trap`；若已学会，提升 `current_mastery +160` 并在下一次战斗中使首个光阱触发时致盲目标 1 回合。
- **阅读要求**：角色职业标签含 `mage` 或 `lightweaver`；基础 `智力 ≥ 16` 且 `感知 ≥ 14`。
- **稀有度**：稀有（Rare）
- **建议投放**：光学实验室、圣殿地下、棱镜矿洞。

## 书籍内容

光阱是一种利用折射原理布置的隐形陷阱，敌人一旦踏入特定角度就会被强光刺入视网膜。本书从基础光学讲起，教导如何用三棱镜、水晶碎片和一小段咒语构建稳定的光路。作者提醒，布置光阱时必须考虑战场环境：阴天需要更强的光源，雪地会反射过量光芒，而雨天则会让光路变得不稳定。书中给出了七种常见地形下的折射方案，并附带手绘示意图。最末一页是一份检查清单，包括角度、亮度、触发范围与友军警示标记。批注写道：最好的光阱不是最亮的，而是最不会被人怀疑的。练习者需要先在不借助魔法的情况下用镜子点燃蜡烛，以此训练对光路的直觉。这门技艺在狭窄通道和室内战斗中尤为致命。

撤除光阱时记得按原路回收棱镜，否则残留光路可能灼伤后来者。

## 设计意图

为法师提供环境依赖型控制陷阱，结合光学知识与战场位置感。
