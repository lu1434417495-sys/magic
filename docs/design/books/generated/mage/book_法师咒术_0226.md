# 《元素刃：万象成锋》

## 基础信息

- **书籍 ID**：`book_法师咒术_0226`
- **关联技能**：`mage_elemental_blade`
- **使用效果**：阅读后解锁 `mage_elemental_blade`；若已学会，提升 `current_mastery +160` 并在下一次战斗中使首把元素刃根据战场环境自动切换元素属性。
- **阅读要求**：角色职业标签含 `mage` 或 `elementalist`；基础 `智力 ≥ 15` 且 `感知 ≥ 12`。
- **稀有度**：史诗（Epic）
- **建议投放**：元素议会武库、古代元素使遗迹、四元素交汇点。

## 书籍内容

元素刃是把周围环境中游离的元素凝聚成近战武器的法术，在火山中是火焰剑，在冰川中是冰晶刀。书中强调，施法者不是选择元素，而是倾听环境告诉你的答案。作者详细记录了在不同地形中凝聚元素刃的手感差异，并提醒靠近水源时容易凝出过重的冰刃。练习者需要先在四种基础环境中各完成一百次挥砍，直到能在切换地形时无缝调整武器形态。后半部讲解了如何让元素刃在击中时释放对应元素效果，例如雷刃麻痹、风刃击退。最末页是一幅被烧又被冻过的插画，旁边写着：剑随环境，人随剑。许多元素法师认为此术最能体现人与自然的妥协。书中还附有一页剑柄握法图，提醒不同元素形态下重心位置差异极大，需要相应调整架势。

## 设计意图

提供环境适应性近战法术，让法师能根据战场元素属性灵活切换输出方式，增强流派互通。
