# 《冰枪术的几何瞄准》

## 基础信息

- **书籍 ID**：`book_法师咒术_0062`
- **关联技能**：`mage_ice_lance`
- **使用效果**：阅读后解锁 `mage_ice_lance`；若已学会，提升 `current_mastery +110` 并在下一次战斗中使首发射击暴击率 `+5%`。
- **阅读要求**：已学会 `mage_frost_bolt`；角色职业标签含 `mage`；基础 `智力 ≥ 9`。
- **稀有度**：精良（Uncommon）
- **建议投放**：冰霜试炼场、北境游侠据点、冰法师导师奖励。

## 书籍内容

冰枪术把霜元素压缩成一条线，要求施术者像木匠用墨斗一样精确。前半本用几何图形讲解瞄准：目标不是敌人的胸口，而是敌人胸口与背景的交界处，只有那里能让冰枪的轮廓在视觉上'断开'，从而判断距离。作者要求练习者先在水面投掷石子，观察涟漪的长轴，再用同样的心境射出冰枪。

书中警告，冰枪术最忌讳'追目标'——一旦施术者在发射瞬间移动视线，冰枪会像断线的风筝一样偏离。后半部收录了'冰枪与移动靶'的训练：先在静止靶上打出一个孔，再要求孔与上一孔连成直线，以此训练手的稳定性。

冰法师导师常说，冰枪术最难的不是命中目标，而是在射出后立刻停止自己的呼吸，因为呼出的热气会让瞄准镜起雾。冰枪术的靶子通常画在普通玻璃背面，以便观察裂纹走向。裂纹走向反映呼吸节奏。
## 设计意图

精良级冰霜单体爆发书籍，前置要求霜箭术，形成'霜箭控制—冰枪爆发'的成长链条，强调精准与稳定。
