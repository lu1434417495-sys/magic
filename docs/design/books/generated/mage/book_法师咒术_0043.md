# 《影步：借阴影移动一瞬》

## 基础信息

- **书籍 ID**：`book_法师咒术_0043`
- **关联技能**：`mage_shadow_step`
- **使用效果**：阅读后解锁 `mage_shadow_step`；若已学会，提升 `current_mastery +100`，并在下一次战斗中使影步后的首次攻击伤害提升 15%。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 10`。
- **稀有度**：普通（Common）
- **建议投放**：影舞者公会、暗夜神殿、废弃剧院后台。

## 书籍内容

影步不是消失，而是把自己的身形压缩进 nearby 的阴影中，然后借助影子的连续性在另一处阴影中重新出现。这本书的作者强调，影步能否成功取决于施术者对光线的理解，而不是对黑暗的恐惧。前半部分教读者如何快速判断周围环境中的阴影是否足够"深"，浅到能看见底部的影子无法承载一个人。

后半部分讲解战斗中的用法：从敌人的影子中窜出发动背刺，或者在被包围时躲进自己的影子里等待时机。书中警告，影步不能穿越完全无影的区域，比如正午的广场中央；连续使用也会让施术者感到一种被黑暗挤压的窒息感。最后一页画着一个法师正从一面墙的阴影中探出半个身体。

作者建议初学者先观察自己的影子一整天，熟悉它在不同光线下的形状，因为对自己影子越熟悉，影步失败时越容易找回身体。

## 设计意图

为法师系提供早期暗影机动技能，强化战棋中的侧翼打击与位置欺骗，同时为后续暗影系、瞬移类高级法术建立熟练度与叙事连接。
