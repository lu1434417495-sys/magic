# 《火山种：地脉萌芽》

## 基础信息

- **书籍 ID**：`book_法师咒术_0217`
- **关联技能**：`mage_volcano_seed`
- **使用效果**：阅读后解锁 `mage_volcano_seed`；若已学会，提升 `current_mastery +160` 并在下一次战斗中使首颗火山种延迟爆发后额外召唤一座小型岩浆喷泉。
- **阅读要求**：角色职业标签含 `mage` 或 `elementalist`；基础 `智力 ≥ 15` 且 `体质 ≥ 11`。
- **稀有度**：史诗（Epic）
- **建议投放**：火山核心祭坛、地脉工程师密室、元素暴君宝藏。

## 书籍内容

火山种是把一小团压缩地火埋入地下的法术，经过数回合后会破土爆发。书中把整个过程比作播种：先在地表埋下火种，再用魔力浇灌，最后等待地脉自己回应。作者警告，种子埋得太深会延迟太久，太浅则可能被敌人提前踩灭。练习者需要先在沙盘中反复推演，直到能在指定回合数引发精确爆发。后半部讲解了如何让火山种相互连锁，形成一片延时燃烧区域。最末页是一张烫手的种植日历，标注着不同地层对爆发时间的影响。许多元素法师喜欢把火山种当作礼物送给不喜欢的人。高阶用法提到，把种子埋在自己脚下可在被近身时触发环形岩浆护城河，迫使敌人保持距离。火山种爆发后的土壤格外肥沃，因此农民有时会偷偷聘请火法师来改良田地。不过丰收的代价是，田里偶尔会冒出几年不散的硫磺味。

## 设计意图

提供延时地形爆破，让法师在战棋中设置陷阱与区域封锁，增强预判与布局玩法。
