# 《重力陷落的矢量分析》

## 基础信息

- **书籍 ID**：`book_法师咒术_0089`
- **关联技能**：`mage_gravity_sink`
- **使用效果**：阅读后解锁 `mage_gravity_sink`；若已学会，提升 `current_mastery +150` 并扩大重力异常区域半格。
- **阅读要求**：角色职业标签含 `mage` 或 `astromancer`；基础 `智力 ≥ 14` 且 `感知 ≥ 10`。
- **稀有度**：史诗（Epic）
- **建议投放**：浮空城核心图书馆、重力井观测站、星界学者密室。

## 书籍内容

重力陷落不是让敌人变重，而是让某个方向上的矢量突然倾斜。前半本几乎全是矢量图，作者用箭头表示重力、支撑力与摩擦力的相互作用，再展示如何在局部打破这种平衡。书中指出，最致命的重力陷落不是向下压，而是让敌人脚下的地面突然'认為'侧面才是下方。

中段记录了实验事故：一位法师在练习时让整间屋子的重力偏转九十度，所有家具都砸向墙壁，包括他自己。后半部讨论战术：重力陷落对飞行单位同样有效，因为它改变的不是重量，而是方向感。最后一页写着'学会让自己先适应异常重力，再让敌人适应。'

浮空城核心的走廊里，偶尔会有行人突然向侧面摔倒，那是古代重力实验留下的残余场域在作怪。重力陷落的走廊需要扶手，但扶手也是倾斜的。倾斜扶手减少摔倒伤害。
## 设计意图

史诗级空间/重力控制书籍，解锁重力陷落并提供大范围强制移动与压制能力，强调矢量计算与空间理解。
