# 《咒术马赛克的拼贴》

## 书籍内容

咒术马赛克是一种将多个小型法术碎片拼合成完整攻击的技艺。本书从材料准备开始，教导如何将不同元素的咒语压缩成规则的小块，再像拼贴画一样组合成更大的法术。作者强调，拼贴的关键在于缝隙处理：碎片之间不能留有空隙，否则法术会在释放前崩塌。书中记录了常见的拼贴模式，放射型适合范围攻击，螺旋型适合穿透，而层叠型则擅长防御。最末一章讨论色彩与元素的对应关系，以及如何让视觉效果与伤害类型一致。批注写道：每一块碎片都是一句未完成的咒语，拼贴让它们同时完成。练习者需要先在纸上设计图案，再用低阶法术模拟拼贴过程。这门技艺能让法师在一次施法中融合多种元素效果。

拼贴完成后作者建议在作品背面签名，这能让碎片之间的连接更加稳固。

## 设计意图

为法师提供多元素组合输出技能，将艺术创作与咒术构建结合。
