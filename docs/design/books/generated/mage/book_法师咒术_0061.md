# 《燃烧之手：掌心的契约》

## 基础信息

- **书籍 ID**：`book_法师咒术_0061`
- **关联技能**：`mage_burning_hands`
- **使用效果**：阅读后解锁 `mage_burning_hands`；若已学会，提升 `current_mastery +90` 并扩大扇形范围 15 度。
- **阅读要求**：角色职业标签含 `mage` 或 `pyromancer`；基础 `智力 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：炼金术士摊位、灰烬交界营地、火元素试炼奖励。

## 书籍内容

燃烧之手是法师学会的第一个'慷慨'的法术——它不要求精准，只要求施术者敢把手伸出去。前半本讲解手掌张开的角度与火焰扇面关系：手指并拢时火焰集中，张开时范围扩大但温度下降。作者建议新手在施术前先对着冷水练习手势，直到能在不烫伤自己的情况下完成整个动作。

书中夹着一张烧焦的契约纸，上面写着'我以掌心为炉，以呼吸为风，愿火只烧我想烧之物'。后半部是实战教训：燃烧之手最容易误伤的是自己的袖口和站在侧前方的队友，所以施术前要养成'先看左右再看前'的习惯。

炼金术士摊位的老顾客都知道，这本书的封皮边缘总是焦黑的，因为每个学会燃烧之手的人都会忍不住先烧一下自己的袖口。燃烧之手的毕业生会在手掌心留下淡淡的灼痕作为纪念。手心灼痕是熟练度证明。
## 设计意图

普通级火焰范围伤害书籍，作为火球术的低阶补充，强化法师近距离面控能力，适合新手法师建立范围意识。
