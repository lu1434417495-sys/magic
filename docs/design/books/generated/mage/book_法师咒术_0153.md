# 《法力晶胚的培育手记》

## 基础信息

- **书籍 ID**：`book_法师咒术_0153`
- **关联技能**：`mage_mana_geode`
- **使用效果**：阅读后解锁 `mage_mana_geode`；若已学会，提升 `current_mastery +160` 并在下一次战斗中使首个法力晶胚破碎时为周围友军恢复 10% 最大 MP。
- **阅读要求**：角色职业标签含 `mage` 或 `geomancer`；基础 `智力 ≥ 16` 且 `感知 ≥ 13`。
- **稀有度**：稀有（Rare）
- **建议投放**：水晶洞穴、元素矿坑、地脉研究室。

## 书籍内容

法力晶胚是一种在地脉附近缓慢生长的半透明矿石，内部封存着尚未定型的魔力。本书从选址开始，教导读者如何在富含魔力的岩层中寻找雏形晶胚，并用自身法力喂养它们。作者强调，晶胚对情绪极其敏感，焦虑会让它们变得浑浊，专注则使它们更加透亮。书中记录了不同元素的晶胚培育差异：火元素需要偶尔加温，水元素需要定时浸泡，而奥术晶胚则需在静默中生长。最末一章讨论晶胚的收割时机，太早会浪费潜力，太晚则晶胚可能产生自我意识。作者建议每个法师只同时培育三到五枚晶胚，过多会分散精神连接。成熟的晶胚可作为一次性法力电池，也可在战斗中投掷产生元素爆发。

每次收获后应留出一小部分晶胚继续生长，作为下一批培育的母本。

## 设计意图

为法师提供资源管理与团队回蓝机制，扩展地脉与元素矿石的世界观。
