# 《异界召唤的礼节手册》

## 基础信息

- **书籍 ID**：`book_法师咒术_0115`
- **关联技能**：`mage_otherworld_call`
- **使用效果**：阅读后解锁 `mage_otherworld_call`；若已学会，提升 `current_mastery +170` 并在下一次战斗中使首次异界召唤的生物忠诚度临时提高 20%。
- **阅读要求**：角色职业标签含 `mage` 或 `summoner`；基础 `智力 ≥ 17` 且 `意志 ≥ 13`。
- **稀有度**：史诗（Epic）
- **建议投放**：召唤学派密室、异界裂隙营地、禁忌召唤师传承任务。

## 书籍内容

召唤异界生物不是命令，而是一次跨越维度的外交。本书从礼节入手，列出与不同位面居民见面时的问候语、礼物禁忌与姿态要求。作者强调，最常见的召唤事故并非力量不足，而是礼仪错误：对火元素鞠躬会被视为挑衅，对风精灵直视则会被认为无礼。书中收录了十二种常见异界存在的脾气档案，以及它们最厌恶的称呼。第二章讨论契约的临时性与永久性的区别，建议初学者只签订限时契约。作者还警告，不要在召唤阵附近放置镜子，因为某些存在会借镜面反向召唤施法者。最末一页是一张空白请柬，批注写着：先学会做客人，再学会做主人。有些异界存在对时间的感知与人类不同，一份按人类小时计算的契约对它们可能毫无意义。召唤前，最好先确认对方使用哪一种时间单位。

## 设计意图

为召唤流法师提供稳定性与叙事深度，将异界设定融入召唤机制并降低召唤失控风险。
