# 《烈阳爆：白昼碎星》

## 基础信息

- **书籍 ID**：`book_法师咒术_0214`
- **关联技能**：`mage_sunburst`
- **使用效果**：阅读后解锁 `mage_sunburst`；若已学会，提升 `current_mastery +170` 并在下一次战斗中使首次烈阳爆对亡灵与暗影生物伤害提升百分之三十。
- **阅读要求**：角色职业标签含 `mage` 或 `lightbringer`；基础 `智力 ≥ 15` 且 `感知 ≥ 12`。
- **稀有度**：史诗（Epic）
- **建议投放**：日光圣殿、天空城遗迹、圣光法师传承宝箱。

## 书籍内容

烈阳爆是召唤一束聚焦日光轰击目标的法术，在正午时分威力最大。书中第一页警告：不要直视你召唤的光，即使它来自你自己。作者把施法过程描述为与太阳的短暂对话，施法者必须在心中默念三段赞词，才能让光芒回应召唤。练习者通常在黎明时面对东方练习，直到能在没有太阳的地底也召唤出微弱的闪光。后半部讲解如何利用镜子或水面增强烈阳爆的覆盖范围。最末页只有一句话被反复描粗：白昼不属于懦夫。许多光法师会在施展此术后短暂失明，他们认为这是太阳收取的小小代价。书中还提到，若在日食时强行施展，烈阳爆会转化为暗影爆裂，反噬施法者，因此需格外谨慎选择时机。烈阳爆的强光常被用作战场信号，召唤远方的友军前来汇合。

## 设计意图

提供针对亡灵与暗影生物的高伤害法术，扩展法师的克制维度，丰富环境相关玩法。
