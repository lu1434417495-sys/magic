# 《以太牵引与重心》

## 基础信息

- **书籍 ID**：`book_法师咒术_0077`
- **关联技能**：`mage_ether_pull`
- **使用效果**：阅读后解锁 `mage_ether_pull`；若已学会，提升 `current_mastery +120` 并在下一次战斗中使首次牵引距离增加一格。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 11` 且 `敏捷 ≥ 9`。
- **稀有度**：稀有（Rare）
- **建议投放**：以太实验室、浮空城遗迹、重力异常区据点。

## 书籍内容

以太牵引不是把目标拉过来，而是让目标周围的以太密度突然变低，使他自己'掉'向你。前半本讲解重心原理：被牵引者的平衡取决于他脚下是否还有可靠的支撑，因此施术前观察目标的站姿比估计他的体重更重要。作者建议在练习时先用空杯子做目标，体会'拉空'与'拉实'的区别。

中段收录了'牵引接招'的几种组合：把敌人拉进陷阱、把队友拉离危险、把物体拉到自己手中。后半部警告：对体重过大的目标强行牵引会导致施术者自己反被拽过去，所以书中反复强调'顺势而为'，不要与目标的质量硬碰硬。

以太实验室的安全手册第一条写着，牵引活物前必须先牵引自己的斗篷，以确认当天的以太密度是否正常。以太牵引的练习先从拉自己的影子开始。拉影子让人理解重力。影子比身体更诚实。
## 设计意图

稀有级空间位移控制书籍，解锁以太牵引并为法师提供强制移动能力，强调重心判断与战术配合。
