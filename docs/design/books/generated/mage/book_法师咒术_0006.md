# 《纸盾术讲义：最薄的防线》

## 基础信息

- **书籍 ID**：`book_法师咒术_0006`
- **关联技能**：`mage_paper_shield`
- **使用效果**：阅读后解锁 `mage_paper_shield`；若已学会，提升 `current_mastery +80`，并在下一次战斗中使纸盾首次被击破时反弹 5 点伤害。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 6`。
- **稀有度**：普通（Common）
- **建议投放**：旧军营训练室、防御法术入门课、废墟中的破书架。

## 书籍内容

很多年轻法师抱怨，自己总是队伍里最先倒下的那个。这本书的作者用实验回应：一块足够薄的魔力屏障，在正确角度下可以偏转绝大多数普通攻击。纸盾的关键不在于厚度，而在于让攻击"滑开"。书中展示了多种持盾角度，并配有一位老法师用 paper_shield 挡住飞斧的插画。

前半部分教读者如何把魔力塑造成一张平整的薄膜，中间厚、边缘薄，像真正的纸张一样具有韧性。后半部分讨论心理层面：纸盾施放后不能慌张后退，否则膜面会产生褶皱，防御力大幅下降。作者建议练习时让同伴用软木球投掷自己，直到能下意识保持膜面稳定。最后一章的标题是"纸破了就让它破"，提醒读者这是一个争取时间的技能，不是永恒堡垒。

书中还提到一个进阶小技巧：在纸盾表面刻上细密的纹路，可以让来袭的箭矢在接触时发生偏转，而不是正面穿透薄膜。

## 设计意图

为法师系提供早期防御手段，缓解新手生存压力，强调"角度与时机优于绝对硬度"的防御理念，为后续魔力护盾类技能提供叙事与熟练度衔接。
