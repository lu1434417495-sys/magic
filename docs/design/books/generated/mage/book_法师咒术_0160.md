# 《奥术灯笼的照明半径》

## 基础信息

- **书籍 ID**：`book_法师咒术_0160`
- **关联技能**：`mage_arcane_lantern`
- **使用效果**：阅读后解锁 `mage_arcane_lantern`；若已学会，提升 `current_mastery +150` 并在下一次战斗中使奥术灯笼照亮范围内友方命中率提高 12%。
- **阅读要求**：角色职业标签含 `mage` 或 `pathfinder`；基础 `智力 ≥ 15` 且 `感知 ≥ 13`。
- **稀有度**：稀有（Rare）
- **建议投放**：地下城入口、探险者公会、幽暗森林营地。

## 书籍内容

奥术灯笼不是普通照明工具，它发出的光线能够揭示隐藏在阴影中的魔力脉络。本书从灯芯材料开始，讲解如何用凝固的星尘和一小块法力结晶制作可持续燃烧数日的光源。作者强调，照明半径的选择至关重要：太大容易暴露队伍位置，太小则无法驱散某些依靠黑暗生存的异界生物。书中记录了不同颜色光芒的效果：白光适合常规探索，蓝光能显示幻象破绽，而红光会让某些亡灵感到不适。最末一章讨论如何在战斗中移动灯笼而不影响施法，作者建议用一根细链将灯笼系在腰间或法杖顶端。批注写道：光明不只是为了看见，也是为了让敌人知道你已经看见它了。练习者需要在完全黑暗的房间中凭灯笼辨认出三十种魔法符文。

长期携带灯笼的法师瞳孔会适应微光，在完全黑暗中也能辨物。

## 设计意图

为探索和辅助型法师提供团队增益照明技能，扩展奥术道具的应用场景。
