# 《灰烬吐息：从肺里喷出余烬》

## 基础信息

- **书籍 ID**：`book_法师咒术_0035`
- **关联技能**：`mage_ashen_breath`
- **使用效果**：阅读后解锁 `mage_ashen_breath`；若已学会，提升 `current_mastery +90`，并在下一次战斗中使灰烬吐息的致盲概率提升 20%。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：灰烬交界营地、火山口研究站、老兵法师遗物。

## 书籍内容

灰烬吐息是一种把肺里的空气与魔力混合成灼热灰烬后喷出的咒术，它不仅能造成伤害，还能让敌人暂时睁不开眼。这本书的作者显然在灰烬交界待过很长时间，书中充满了对那种世界被烧尽后的特殊空气质感的描述。前半部分讲解如何在不烫伤喉咙的前提下，让魔力在口腔里完成最后的加热。

后半部分讨论战术用途：在狭窄的走廊里喷出灰烬吐息，可以一次性影响多个敌人；在开阔地带则更适合用来遮挡视线和掩护撤退。书中警告，使用这个咒语前必须屏住呼吸，否则施术者自己会被呛得比敌人还严重。最后附有一张灰烬交界的风景素描，天空是暗红色的，地面上覆盖着厚厚的灰白色余烬。

作者提到，优质的灰烬吐息需要吸入少量真正的交界灰烬作为引子，这意味着施术者必须曾经踏足灰烬交界或拥有可靠的材料来源。

## 设计意图

作为连接法师咒术与灰烬交界异界能量的技能书籍，为法师系提供早期火焰范围控制手段，同时为后续异界火焰、灰烬操控类法术建立叙事与熟练度铺垫。
