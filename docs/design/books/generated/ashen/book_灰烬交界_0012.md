# 《炭化锁链技法》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0012`
- **关联技能**：`ashen_chain_bind`
- **使用效果**：阅读后解锁 `ashen_chain_bind`；若已学会，提升 `current_mastery +120`，并提高对中型敌人的束缚成功率 5%。
- **阅读要求**：角色职业标签含 `warrior` 或 `rogue`；基础 `敏捷 ≥ 10` 或 `力量 ≥ 10`。
- **稀有度**：精良（Uncommon）
- **建议投放**：链卫兵营、游侠猎场、交界巡逻任务奖励。

## 书籍内容

炭化锁链技法讲的是如何用一根被余火淬炼过的锁链限制敌人的行动。这种锁链平时柔软，遇热会变硬，因此使用者需要掌握投掷的时机——在锁链飞出后、变硬前，让它缠绕住目标。书中用大量图示展示三种基本投掷方式：套索式、绊脚式、回拉式。作者特别推崇回拉式，因为它能把敌人拽向灰烬区域，造成二次灼伤。第二章讲锁链的保养：每次使用后必须清除上面的灰烬残留，否则下一次变硬时会不均匀而断裂。书的后半部分记录了几位著名链卫的战斗日记，其中一人写道："我不需要打败你，我只需要让你知道你的脚不属于你。" 炭化锁链的打造秘方被作者藏在一段看似普通的保养说明里：锁链必须用三种不同温度的余火交替淬炼，才能同时具备柔软与硬度。这段说明被许多读者忽略，导致他们打造的锁链要么太脆、要么太软。真正读懂的人会在页边画一个小小的三角形作为记号。
