# 《跳劈重斩笔记》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0154`
- **关联技能**：`ashen_leaping_cleave`
- **使用效果**：阅读后解锁 `ashen_leaping_cleave`；若已学会，提升 `current_mastery +150`。
- **阅读要求**：角色职业标签含 `warrior` 或 `berserker`；基础 `力量 ≥ 10`。
- **稀有度**：精良（Uncommon）
- **建议投放**：断桥营寨高阶训练、遗迹武器架、战士导师任务。

## 书籍内容

跳劈被作者称为"从空中买下的一刀"。书中指出大多数新手的问题不在落地后的斩击，而在起跳前的助跑与落点选择。起跳前要确认落点半径内至少有两个敌人或一个高价值目标，否则这一刀的风险会盖过收益。落地瞬间要把全身重量像锤子一样砸进武器，膝盖弯曲吸收冲击，同时利用反作用力把刀刃横向甩出。书中还警告：不要在敌人密集区正中心起跳，因为起跳动作本身会让你暴露侧背。最后一页画了一位战士从矮墙跃下的剪影，旁边写着：跳劈是进场，不是炫耀。书页间夹着一根断裂的弓弦，据说是某位弓箭手用来测量最佳落点的遗物。书的中间掉出一张折叠的草图，画着一种被称为"跃骨"的异界生物。作者认为跳劈的姿势最早就是模仿这种生物的扑击，因此建议练习者观察它们的起跳角度。草图背面写着："它们落地时从不用手撑地，你也应该做到。"草图的边缘有被反复折叠的痕迹。

## 设计意图

作为高威胁进场技，服务战士/狂战士的爆发与位移需求。
