# 《余烬祭所的翻滚训令》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0151`
- **关联技能**：`ashen_roll`
- **使用效果**：阅读后解锁 `ashen_roll`；若已学会，提升 `current_mastery +120`，并在下次战斗中首次使用该技能时不消耗 stamina。
- **阅读要求**：无职业限制；基础 `敏捷 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：余烬祭所基础传授、灰烬交界入口营地、通用战技商人。

## 书籍内容

余烬祭所的地板被无数初学者的膝盖磨出浅坑，这本训令就是那些膝盖换来的经验。它不教花哨的转身，只教一件事：翻滚结束时双脚必须同时着地，目光始终锁住敌人。作者把战场画成一张灰格子图，标出"危险格"与"机会格"，并反复强调多数死者不是翻得不够远，而是翻进了另一片危险。书中夹着半张烧焦地图，几个炭笔点旁边写着"这里翻，别跑"。最后几页记录了一位老战士的批注：翻滚不是逃跑，是用一寸位移重新买一张位置票。姿态难看但活着，永远比死得漂亮有用。封底贴着一张褪色的学徒名单，其中大半名字被粗黑线划去，旁边写着"他们学会了翻滚，却没学会停下来"。老战士在最后一页补了一句：在灰烬交界，最危险的不是翻滚失败，而是翻滚成功后以为自己安全了。书中还夹着几张被汗水浸透的纸条，是历届学徒留下的实战笔记。

## 设计意图

作为灰烬交界最泛用的生存战技入口，降低翻滚学习门槛并强化其战场定位感。
