# 《游侠的灰烬追踪术》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0181`
- **关联技能**：`ashen_roll`
- **使用效果**：阅读后提升 `ashen_roll` `current_mastery +80`，并解锁：在灰烬交界地图中追踪敌人时不会触发随机遭遇。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；基础 `感知 ≥ 11`。
- **稀有度**：精良（Uncommon）
- **建议投放**：风息哨塔藏书、游侠导师任务、灰烬交界巡逻队奖励。

## 书籍内容

这本书教会游侠如何在灰烬中追踪而不被追踪。作者指出灰烬地面的最大特点是它会记录一切：脚印、拖拽痕迹、魔力灼烧的痕迹都会保留很长时间。但这也意味着追踪者自己的痕迹同样容易被发现。书中讲到了"反向行走"：利用风向让自己的脚印被新落下的灰烬快速覆盖；"断点跳跃"：每隔一段距离改变路线，让敌人无法判断你的目的地；"灰烬伪装"：在身上涂抹湿灰降低体温信号。中间章节收录了多个实战案例，每个都强调耐心比速度更重要。最后一页写着：在灰烬里，最好的猎人看起来像个失败者。封底粘着几根灰色的羽毛，据说是某种灰烬鸟类的尾羽。作者说这种鸟类能在灰烬风暴中飞行而不迷失方向，观察它们的飞行路线是追踪术的至高课程。那些尾羽在灰雾中会轻微颤动，有游侠声称它们仍在模仿原主飞行时的节奏。

## 设计意图

为弓箭手/游侠提供探索与机动增益，强化灰烬交界野外生存能力。
