# 《烟中潜行手册》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0005`
- **关联技能**：`ashen_smoke_walk`
- **使用效果**：阅读后解锁 `ashen_smoke_walk`；若已学会，提升 `current_mastery +120`，并使下一次进入烟雾时隐身持续时间延长 1 秒。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `敏捷 ≥ 10`。
- **稀有度**：精良（Uncommon）
- **建议投放**：盗贼公会藏身处、烟幕商人、暗杀任务密匣。

## 书籍内容

手册的纸张薄如蝉翼，每一页都能透光。作者认为，烟中潜行最大的敌人不是敌人的眼睛，而是自己的呼吸。书中要求练习者学会在烟雾中把呼吸降到每分钟四次以下，因为急促的呼吸会扰动烟雾，形成可见的涡流。第二章讲述了如何利用灰烬交界的特殊烟雾——这种烟雾比普通烟更重，会沉向地面，因此低矮移动反而比站立更隐蔽。手册中段有一个章节专门讲"故意露出破绽"：让敌人看到一缕烟的流动，引诱他们攻击错误的位置。书的最后几页被撕掉，只剩一句话："当你成为烟雾的一部分，连影子都会背叛你。" 手册中段有一张被汗水浸湿的烟中步法图，标注了七种不同的移动高度。作者强调，在烟中移动时，头部的高度每改变一寸，被发现的可能性就会改变。最低的姿态几乎是匍匐，但也是最安全的；站立移动只应在烟雾最浓或敌人最分心的瞬间使用。

## 设计意图

服务于盗贼与暗杀者的环境利用能力，将烟雾从障碍物转化为战术资源。
