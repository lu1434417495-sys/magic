# 《灰烬咒术：灰舌术》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0091`
- **关联技能**：`ashen_tongue`
- **使用效果**：阅读后解锁 `ashen_tongue`；若已学会，提升 `current_mastery +120`，并令与灰烬灵体或古代存在交涉时获得加值。
- **阅读要求**：角色职业标签含 `mage`、`warlock` 或 `sorcerer`；基础 `智力 ≥ 11`。
- **稀有度**：精良（Uncommon）
- **建议投放**：禁书商人、学者营地、灰烬遗迹书房。

## 书籍内容

灰舌术教施术者如何用灰烬交界的特殊语法与古老存在交流。作者认为，普通语言在灰烬中会失真，因为火焰烧掉了大部分修饰词，只剩下最本质的含义。书中列出灰烬语法的三个特点：没有过去时、没有客套话、每个词都必须附带一个燃烧意象。核心章节讲解如何避免冒犯：不能直说“我”，而要使用“这一缕余烬”；不能说“想要”，而要说“渴望重燃”。作者警告，说错一个词可能导致契约对象当场离去。练习者需背诵并正确使用十句灰烬常用语。尾页写着：“在灰烬里，语言也是火，说错了会烧到自己。”书页边缘留有被炭火熏黑的空白，供读者记录自己的灰烬坐标。作者在跋文中提醒：灰烬交界的技法没有标准答案，只有烧剩下的答案。许多抄本的末页都沾着不同颜色的灰烬，那是前人练习时留下的印记。

## 设计意图

为法师/术士提供异界交涉辅助技能，连接剧情对话与知识解锁机制。
