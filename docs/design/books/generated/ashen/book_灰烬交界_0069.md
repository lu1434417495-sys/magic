# 《灰烬风暴召唤残卷》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0069`
- **关联技能**：`ashen_storm`
- **使用效果**：阅读后解锁 `ashen_storm` 范围法术；若已学会，提升 `current_mastery +150`，并扩大风暴影响范围 1 格。
- **阅读要求**：角色职业标签含 `mage` 或 `sorcerer`；基础 `智力 ≥ 13`。
- **稀有度**：史诗（Epic）
- **建议投放**：灰烬邪教祭坛、异界裂隙宝箱、高阶法师传承任务。

## 书籍内容

残卷记载了一种召唤局部灰烬风暴的危险法术。作者认为，灰烬交界的风暴不是气象现象，而是世界接缝处溢出的能量。施术者需在风暴眼中保持静止，用自己的魔力引导灰烬旋转。书中详细列出施法材料：三把不同来源的余烬、一片烧焦的布料、以及施术者自己的一滴血。作者警告，风暴会无差别伤害范围内所有目标，包括盟友，因此必须在敌人密集且己方已撤离时使用。练习者需先学会在微风中控制一小团灰烬旋转。尾页被撕去大半，只剩：“当世界开始旋转，你只能是它的中心，不是它的主人。”书页边缘留有被炭火熏黑的空白，供读者记录自己的灰烬坐标。作者在跋文中提醒：灰烬交界的技法没有标准答案，只有烧剩下的答案。许多抄本的末页都沾着不同颜色的灰烬，那是前人练习时留下的印记。

## 设计意图

为法师系提供高阶范围控场法术，体现灰烬交界的灾难性环境力量。
