# 《灰铸仪式：灰烬构装体的唤醒》

## 基础信息

- **书籍 ID**：`book_ashen_0136`
- **关联技能**：`ashen_construct_awakening`
- **使用效果**：阅读后解锁 `ashen_construct_awakening`；若已学会，提升 `current_mastery +130`，并在下一次战斗中召唤一个低级灰烬构装体助战（一次性）。
- **阅读要求**：职业标签含 `mage`、`artificer` 或 `summoner`；基础 `智力 ≥ 11`。
- **稀有度**：史诗（Epic）
- **建议投放**：构装工坊密室、造物者传承任务、异界遗迹核心。

## 书籍内容

灰铸仪式教授如何唤醒那些沉睡在灰烬中的古老构装体。这些构装体原本是旧帝国的守卫，如今只剩下一具具被灰覆盖的空壳。唤醒它们需要找到核心的"烬种"，用特定的频率注入魔力，并念出一段被称为"燃名"的古老称号。书中警告，灰铸不是创造生命，而是重新点燃一个已经熄灭的意志；如果唤醒者没有足够的控制力，构装体可能会把最近的活物当作敌人。最危险的一步是"命名"——一旦你给构装体起了名字，它就会开始形成自己的意图。书的末尾附有一张未完成的名字列表，每个名字旁边都标注着"已焚"或"在逃"。被唤醒的构装体不会立刻服从命令，它们会先用空洞的眼眶凝视唤醒者数秒，仿佛在判断这个人是否值得被守护。这段沉默被炼金师称为\"灰烬的审视\"。成功唤醒构装体后，仪式师必须在二十四小时内为它命名，否则构装体会自行选择一个名字，而那往往意味着麻烦。

## 设计意图

召唤师/工匠的高阶召唤技能，把灰烬遗迹中的构装体转化为可控战力，强化召唤玩法线。
