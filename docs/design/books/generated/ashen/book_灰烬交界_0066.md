# 《余烬治疗祷文》

## 书籍内容

祷文是炭化大教堂为灰烬交界伤员专门编写的治疗法门。作者认为，灰烬造成的伤口不同于刀伤或烧伤，它带有“熄灭”性质，会让生命力像余烬一样逐渐冷却。祷文要求施术者先用手掌覆盖伤口，感受那股凉意，再用意志把温暖重新推入伤者体内。书中强调，治疗灰烬伤不能急于求成，因为过强的光芒会让伤口边缘焦化。最困难的部分是安抚伤者：恐惧会加速生命力的冷却。练习者需在模拟灰伤上反复尝试。尾页经文：“灰烬不是终点，是等待被重新点燃的休眠。”书页边缘留有被炭火熏黑的空白，供读者记录自己的灰烬坐标。作者在跋文中提醒：灰烬交界的技法没有标准答案，只有烧剩下的答案。许多抄本的末页都沾着不同颜色的灰烬，那是前人练习时留下的印记。此抄本曾被余烬烫穿数页，缺失处反而逼迫读者用自己的经验补全。

## 设计意图

为圣职系提供灰烬环境特化治疗技能，呼应交界灼伤机制。
