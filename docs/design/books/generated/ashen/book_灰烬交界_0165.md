# 《破盾者的呼吸》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0165`
- **关联技能**：`ashen_guard_kick`
- **使用效果**：阅读后提升 `ashen_guard_kick` `current_mastery +120`，并使该技能对处于 `guard` 状态目标的伤害提升 20%。
- **阅读要求**：已学会 `ashen_guard_kick`；基础 `力量 ≥ 10`。
- **稀有度**：精良（Uncommon）
- **建议投放**：断桥营寨高级训练室、攻破堡垒任务奖励、狂战士导师。

## 书籍内容

这本书专门研究如何在踢击破防时把全身力量压进那零点几秒。作者指出，踢击的呼吸节奏与普通攻击相反：要在起脚前吸气蓄力，在脚面接触盾面时猛然呼气，把横膈膜的下沉转化为腿部的冲击力。书中还讲到了视线：眼睛要盯着敌人的锁骨而不是盾牌，因为锁骨会提前暴露对方的重心变化。中间章节收录了针对不同种族敌人的踢击角度调整。最后几页被汗水浸得发黄，只剩下反复出现的一句话：破盾不是把盾踢碎，是把拿盾的人踢醒。书的扉页上有一个深深的脚印，旁边写着"我练了三千次才踢出这一下"。脚印的大小与普通人脚相仿，但鞋底纹路异常复杂，似乎是某种特制训练鞋的印记。那个脚印的深度在纸上形成了轻微的凹陷，触摸时能感受到作者当年用力踩踏的力度。

## 设计意图

深化破盾技能的熟练度收益，强化战士对防御型敌人的压制力。
