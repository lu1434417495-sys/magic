# 《灰烬渡鸦的信使训练》

## 基础信息

- **书籍 ID**：`book_ashen_0121`
- **关联技能**：`ashen_raven_dispatch`
- **使用效果**：阅读后解锁 `ashen_raven_dispatch`；若已学会，提升 `current_mastery +110`，并在下一次据点返回时额外带回一份情报或物资。
- **阅读要求**：职业标签含 `ranger` 或 `spy`；基础 `感知 ≥ 9` 且 `魅力 ≥ 8`。
- **稀有度**：精良（Uncommon）
- **建议投放**：渡鸦塔据点、情报商任务、灰烬游侠奖励。

## 书籍内容

灰烬渡鸦是一种能在灰云中辨别方向的黑色大鸟，在灰烬交界被用作信使和侦察兵。这本书教你如何与渡鸦建立信任关系：不是靠食物收买，而是靠稳定的行为模式。书中说，渡鸦会记住那些遵守承诺的人，也会记住那些试图欺骗它们的人。训练分为三步：喂食时保持同一姿势、放飞时用固定的哨音、返回时给固定的奖励。作者还详细描述了渡鸦的几种叫声含义，以及如何在灰雾中通过声音判断渡鸦的位置。最有趣的一章是"渡鸦的谎言"：这些聪明的鸟有时会故意带回错误信息以测试主人，只有识破并纠正它的人才会被长期信任。渡鸦对亮红色物体有天然的敌意，因此灰烬信使从不穿红色衣物。相反，深灰色和暗褐色最容易获得渡鸦的好感，因为它们让渡鸦觉得对方只是另一块会移动的大石头。

## 设计意图

探索/后勤向技能，为游侠/间谍提供情报与物资补充的非战斗成长路径。
