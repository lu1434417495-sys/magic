# 《灰烬审判：灼心言》

- **书籍 ID**：`book_灰烬交界_0074`

## 书籍内容

灼心言是灰烬法官用于审判背誓者的言灵。作者认为，背叛的代价应当由背叛者自己的誓言来收取，而灰烬正是誓言燃烧后的形态。书中要求施术者在宣判前先诵读被告曾经立下的誓言，再用灰烬在空中画出“焚”字符。言灵生效时，被告会感到自己曾经背弃的承诺化作灼烧从胸口蔓延。作者警告，灼心言对从未立誓者无效，因此施术者必须先确认目标的罪状。练习者需在模拟法庭上完整执行一次审判流程。尾页写着：“每一句背弃的誓言，都变成了烧你的灰。”书页边缘留有被炭火熏黑的空白，供读者记录自己的灰烬坐标。作者在跋文中提醒：灰烬交界的技法没有标准答案，只有烧剩下的答案。许多抄本的末页都沾着不同颜色的灰烬，那是前人练习时留下的印记。此抄本曾被余烬烫穿数页，缺失处反而逼迫读者用自己的经验补全。

## 设计意图

为圣职/审判者提供灰烬主题处决技能，强化信仰与誓言机制联动。
