# 《灰烬诗人：烬歌行》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0097`
- **关联技能**：`ashen_bard_song`
- **使用效果**：阅读后解锁 `ashen_bard_song`；若已学会，提升 `current_mastery +130`，并令烬歌对友方提供的士气增益延长 1 回合。
- **阅读要求**：角色职业标签含 `bard` 或 `performer`；基础 `魅力 ≥ 11`。
- **稀有度**：精良（Uncommon）
- **建议投放**：吟游诗人营地、市集表演区、灰烬交界酒馆。

## 书籍内容

烬歌行收集了灰烬交界中流传的古老歌谣，把它们改编成可在战场上吟唱的短歌。作者认为，灰烬世界夺走了人们的家园，但夺不走他们用歌声重新定义悲伤的能力。书中把烬歌分为“挽歌、战歌、归歌”三类，每类对应不同的节拍与效果。核心章节讲解如何在歌唱时让灰烬随声波轻微振动，从而放大歌声的影响范围。作者警告，烬歌不能被用来制造虚假希望，因为灰烬能辨别谎言。练习者需在听众面前完整演唱一首烬歌并获得认可。尾页题词：“在灰烬里，歌声不是娱乐，是证明自己还能呼吸。”书页边缘留有被炭火熏黑的空白，供读者记录自己的灰烬坐标。作者在跋文中提醒：灰烬交界的技法没有标准答案，只有烧剩下的答案。许多抄本的末页都沾着不同颜色的灰烬，那是前人练习时留下的印记。

## 设计意图

为吟游诗人系提供灰烬主题团队增益技能，丰富支援职业的氛围与机制。
