# 《黑暗斩痕禁书残页》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0162`
- **关联技能**：`ashen_dark_edge`
- **使用效果**：阅读后解锁 `ashen_dark_edge`；若已学会，提升 `current_mastery +170` 并附带少量 `life_drain`。
- **阅读要求**：角色职业标签含 `mage` 或 `rogue` 副修；基础 `智力 ≥ 12`。
- **稀有度**：史诗（Epic）
- **建议投放**：沉钟书库禁书区、坠墓镇地下墓穴、黑暗法师遗产。

## 书籍内容

残页的边缘像被某种生物啃噬过，墨迹在纸上缓慢蠕动。它把黑暗斩痕描述为"在目标身上切出一道通往虚无的口子"，并强调这类咒术的关键不是倍率，而是侵蚀感。书中要求施术者在释放前想象自己的指尖是一片正在剥落的影子，而不是一道光束。中间部分记录了一个被反复涂抹的警告：不要在虚弱时使用黑暗斩痕，因为它会从你身上也吸走一点什么。最后几页是一系列无法辨认的符号，但每个符号旁边都用不同笔迹写着"别碰"或"再来一次"。残页背面有一行更淡的字迹："我已经忘了为什么开始学这个，但它还记得我。"残页背面有一个不断变化的掌纹，像是某种认证机制。有人尝试用自己的手掌覆盖上去，结果掌纹变成了他的手的形状，但下一秒又恢复了原状，仿佛在说"还不够资格"。皮革上的划痕在满月时会变得更加清晰，像是某种周期性的警告。

## 设计意图

黑暗单体咒术入口，提供奥脆与生命吸取的成长延展空间。
