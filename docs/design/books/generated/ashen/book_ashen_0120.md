# 《烬丝编织：灰烬护甲修补术》

## 基础信息

- **书籍 ID**：`book_ashen_0120`
- **关联技能**：`ashen_thread_mending`
- **使用效果**：阅读后解锁 `ashen_thread_mending`；若已学会，提升 `current_mastery +100`，并立即修复当前护甲 25% 耐久度。
- **阅读要求**：无职业限制；基础 `敏捷 ≥ 8` 或 `智力 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：营地铁匠旁、裁缝据点任务、通用商人。

## 书籍内容

烬丝编织使用的是一种特殊的灰纤维，只有在余烬尚未完全冷却时才能从某些灰烬植物上抽取出足够长的丝。这本书手把手教人如何把烬丝搓成线、把线编成补丁、把补丁缝进护甲的破损处。作者指出，烬丝补丁不怕火烧但怕水浸，一旦沾水就会迅速脆化。书中记录了好几种编织花纹，每种花纹不仅美观，还能在一定程度上分散冲击力。最实用的章节是"应急补甲"：当护甲在战斗中裂开，如何用随身携带的灰粉和一根细枝临时堵住缺口。书的末尾夹着一小块烬丝样品，摸起来粗糙但坚韧，像某种早已死去的昆虫的翅膀。最顶级的烬丝编织师能在护甲表面织出细密的火焰纹路，这些纹路不仅美观，还能在受到火焰攻击时主动吸收部分热量。但作者坦言，自己最多只能织出三道完整纹路。

## 设计意图

通用护甲维护技能，拓展灰烬环境的生存 crafting 与资源管理维度。
