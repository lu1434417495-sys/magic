# 《原力的边界控制》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0172`
- **关联技能**：`ashen_force_burst`
- **使用效果**：阅读后提升 `ashen_force_burst` `current_mastery +120`，并使推退距离增加至 2 格。
- **阅读要求**：已学会 `ashen_force_burst`；基础 `意志 ≥ 12`。
- **稀有度**：稀有（Rare）
- **建议投放**：炭化大教堂静修室、高阶圣骑士试炼、奇迹守护者奖励。

## 书籍内容

作者认为原力震荡最难控制的不是释放，而是边界。推得太近无法解围，推得太远会让敌人脱离队友射程。书中介绍了一种"感知边界"的训练：闭上眼睛，让同伴从不同方向走近，在对方进入某一距离时释放原力，反复校准感觉。中间章节还讨论了地形影响：靠墙使用原力会造成额外碰撞伤害，但也会让敌人更难被推退。后半本讲到了多人配合：原力震荡最好由一名牧师负责制造空间，另一名队友负责在敌人失衡时补刀。最后一页写着：边界即慈悲。书脊上刻着一道浅浅的圣徽，据说是某位高阶圣骑士生前最后一本书。圣徽的纹路中填满了灰烬，怎么清理都清理不干净，像是某种神圣的污渍。圣徽上的灰烬无论怎么吹都吹不干净，仿佛它已经成为书本材质的一部分。每隔几页就有一处墨迹被泪水晕开的痕迹，不知道属于哪一位读者。

## 设计意图

作为原力震荡的精通书籍，强化控场精度与地形联动。
