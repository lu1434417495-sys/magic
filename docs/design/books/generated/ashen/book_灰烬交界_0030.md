# 《余烬守护契约》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0030`
- **关联技能**：`ashen_guard`
- **使用效果**：阅读后解锁 `ashen_guard`；若已学会，提升 `current_mastery +120`，并提高守护对象受到伤害时触发的反击概率 5%。
- **阅读要求**：角色职业标签含 `paladin` 或 `support`；基础 `体质 ≥ 10` 或 `意志 ≥ 10`。
- **稀有度**：精良（Uncommon）
- **建议投放**：守护骑士团营地、护送任务奖励、团队副本宝箱。

## 书籍内容

《余烬守护契约》教导圣职者如何与需要保护的目标建立一种基于灰烬的能量链接。一旦契约成立，当目标受到伤害时，部分伤害会转移到守护者身上，同时守护者也能感知目标的危险。作者强调，守护契约不是强制签订的，必须得到被守护者的同意，否则契约会在第一次伤害转移时崩溃。书中详细记录了契约的绘制方法：需要用双方的血混合交界灰烬，在地面画出一个双环图案。第二章讲解了如何分担伤害而不至于让自己先倒下：守护者必须不断调整自己的防御姿态，让转移来的伤害落在最坚固的部位。书末有一句被反复描粗的誓言："我身即盾，我灰即你。" 守护契约的反噬机制在书中有详细说明：当守护对象受到的伤害超过一定阈值时，守护者会感受到同样的痛苦，但比例减半。作者建议守护者在签订契约前评估自己的承受能力，因为一次过强的攻击可能导致守护者先于被守护者倒下。

## 设计意图

为保护型职业提供队友链接与伤害分摊机制，强化团队协作。
