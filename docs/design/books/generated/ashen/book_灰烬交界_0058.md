# 《余温感知法》

## 书籍内容

余温感知法教人用皮肤而非眼睛去观察交界中的生命。作者认为，灰烬世界能见度极低，但温度分布反而更清晰：活物会扰动余温，形成可感知的“冷洞”或“热丝”。书中要求练习者先闭眼站在余烬旁，感受热量从哪一侧飘来，再尝试判断三丈外是否有人。进阶章节讨论如何分辨生物体与岩浆裂缝的温度差异，以及风如何扭曲热流。作者提醒，过度依赖余温会让人忽视声音线索，因此必须配合听觉训练。练习者常需在灰烬中辨认同伴与木人的位置。尾页批注：“眼睛会被灰迷住，皮肤不会。”书页边缘留有被炭火熏黑的空白，供读者记录自己的灰烬坐标。作者在跋文中提醒：灰烬交界的技法没有标准答案，只有烧剩下的答案。许多抄本的末页都沾着不同颜色的灰烬，那是前人练习时留下的印记。
