# 《灰烬神射：红天瞄准》

## 书籍内容

红天瞄准是专门针对灰烬交界暗红色天空的射术修正法。作者认为，在红天下物体会显得比实际更近，因为红色光波长会压缩视觉深度。书中给出“红视修正”口诀：瞄准目标下缘、把参照物向外推半个身位、用灰白色物体而非红色物体判断距离。核心章节讲解如何利用漂浮灰烬判断风层：灰烬下沉说明空气稳定，灰烬打转说明有乱流。作者警告，红天下最容易误判的是移动目标的速度，因此必须提前量加倍。练习者需在模拟红天箱中连续命中移动靶。尾页写着：“在红天下，眼睛要学会说谎，手才说真话。”书页边缘留有被炭火熏黑的空白，供读者记录自己的灰烬坐标。作者在跋文中提醒：灰烬交界的技法没有标准答案，只有烧剩下的答案。许多抄本的末页都沾着不同颜色的灰烬，那是前人练习时留下的印记。

## 设计意图

为弓箭手提供灰烬环境特化瞄准技能，呼应异界视觉修正需求。
