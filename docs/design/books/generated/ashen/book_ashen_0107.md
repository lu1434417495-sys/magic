# 《断刃重铸：灰烬铁匠的笔记》

## 基础信息

- **书籍 ID**：`book_ashen_0107`
- **关联技能**：`ashen_weapon_repair`
- **使用效果**：阅读后解锁 `ashen_weapon_repair`；若已学会，提升 `current_mastery +100`，并立即恢复当前主武器 30% 耐久度。
- **阅读要求**：职业标签含 `warrior` 或 `blacksmith`；基础 `力量 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：断桥营寨铁匠铺、矿洞据点奖励、工匠委托。

## 书籍内容

这本笔记的每一页都沾着煤灰和金属碎屑，看起来像一本被反复翻阅多年的账本。作者是一名不愿透露姓名的灰烬铁匠，他认为真正的维修不是把缺口补平，而是让武器记住它断过的地方。书中详细记录了用余烬灰覆盖刀身进行"热补"的技巧：把断刃插入高温灰烬，让金属吸收炭粒，再迅速淬火。这样修好的武器会在断口处留下一道深色纹路，铁匠称之为"伤疤"。笔记的后半部分是三十七种常见武器的弱点清单，作者认为修武器之前必须先理解它最可能在哪里再次断裂。最后一页写着："最好的剑不是没断过的剑，是断过三次还能杀人的剑。"笔记的夹缝中还夹着几片不同金属在灰烬中淬火后的色泽样本，从银白到暗红再到死灰，每种颜色都对应一种特定的硬度。老练的铁匠仅凭颜色就能判断回火是否到位。

## 设计意图

为近战职业提供装备维护技能，把灰烬环境的资源稀缺转化为锻造与修复玩法。
