# 《灰烬铁匠的淬火法》

## 书籍内容

这本书讲如何用灰烬交界的特殊环境来淬火武器。作者发现灰烬本身是一种天然的隔热材料，用它包裹正在淬火的刀刃可以防止温度骤降导致的金属开裂。书中详细介绍了"灰淬"步骤：先加热、再裹灰、再入水、最后风干。每个步骤的时间和温度都被精确记录。中间章节讨论了不同金属对灰淬的反应：铁会变硬但变脆，钢会获得韧性，而某些异界合金会出现不可预测的变化。最后几页是一份失败记录，作者坦诚自己毁了十七把刀才摸清规律。书的封皮上有一块永远焦黑的污渍，据说是第十七把刀融化时溅上的。污渍在特定的光线下会呈现出刀的形状，让这本书成了一件半工艺品。那块污渍在不同角度下会呈现出刀身、锤头或人脸的模糊轮廓，让许多读者不敢久看。封底粘着一小块风干的泥渍，泥中嵌着一片细小的金属碎屑。
