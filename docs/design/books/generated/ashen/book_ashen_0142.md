# 《烬拳：武僧的灰烬打击》

## 基础信息

- **书籍 ID**：`book_ashen_0142`
- **关联技能**：`ashen_fist_strike`
- **使用效果**：阅读后解锁 `ashen_fist_strike`；若已学会，提升 `current_mastery +130`，并在下一次战斗中令徒手攻击附带 1 层脆弱（持续 3 回合）。
- **阅读要求**：职业标签含 `monk` 或 `martial_artist`；基础 `力量 ≥ 9` 且 `敏捷 ≥ 9`。
- **稀有度**：精良（Uncommon）
- **建议投放**：灰烬寺院、武僧训练场、体能修炼任务。

## 书籍内容

烬拳是灰烬寺院武僧们创造的徒手技法，核心在于把拳击出时想象成一块烧红的炭落入水中：先是炽热的冲击，然后是迅速的冷却收缩。书中强调，烬拳的威力来自"温度差"而不是蛮力：在击中前让拳头保持高温，在击中瞬间让热量迅速散去，造成肌肉和筋脉的急剧收缩。练习者需要先在热灰中练耐热，再浸入冷水练急停，最后才能把两种感觉合二为一。作者警告，烬拳不能连续使用，因为手掌需要时间来恢复温度平衡。书的末尾附有一套掌纹护理法，以及如何识别自己是否过度练习——当掌纹开始呈现灰黑色时，就该停下来了。烬拳的高手能在击中对手的瞬间感受到对方体内气血的温度变化。这种感知无法用语言传授，只能通过数千次对热灰堆的练习慢慢积累，被称为\"灰中的手感\"。

## 设计意图

武僧系近战技能，以温度变化为机制核心，提供 debuff 输出与主题叙事。
