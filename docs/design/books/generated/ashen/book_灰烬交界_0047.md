# 《灰烬圣约书》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0047`
- **关联技能**：`ashen_covenant`
- **使用效果**：阅读后解锁 `ashen_covenant`；若已学会，提升 `current_mastery +150`，并提高圣约共享效果的范围 1 格。
- **阅读要求**：角色职业标签含 `priest` 或 `paladin`；基础 `意志 ≥ 12`。
- **稀有度**：稀有（Rare）
- **建议投放**：大教堂核心密室、圣骑士团最高奖励、神圣任务。

## 书籍内容

《灰烬圣约书》记载的是圣职者与交界余火之间建立的契约。与其他契约不同，圣约不是索取力量，而是承诺用这份力量保护值得保护的人。书中详细记录了圣约的建立仪式：必须在余火前跪立一夜，期间不能入睡、不能进食，只能用圣火维持体温。第二章讨论了圣约的共享：建立圣约的施术者可以将自己的力量分享给周围的队友，但分享得越多，自己承受的负担越重。书的后半部分收录了历史上多位圣约者的最后记载，他们大多为了保护他人而燃尽自己。书末有一句话被金色墨水写成："圣约不是借条，是把自己烧成光的许可。" 圣约书的最后几页被撕去，只留下一个被金色封边的残角。学者们推测，缺失的部分记载了"终极圣约"——施术者把自己的生命完全分给队友，自己化为余火。这个推测从未被证实，因为见过终极圣约的人都没有回来。
