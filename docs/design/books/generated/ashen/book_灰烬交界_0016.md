# 《烟幕逃脱指南》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0016`
- **关联技能**：`ashen_smoke_escape`
- **使用效果**：阅读后解锁 `ashen_smoke_escape`；若已学会，提升 `current_mastery +100`，并提高逃脱后的隐身持续时间 1 秒。
- **阅读要求**：角色职业标签含 `rogue` 或 `ranger`；基础 `敏捷 ≥ 9`。
- **稀有度**：普通（Common）
- **建议投放**：盗贼公会、游侠营地、低级赏金任务奖励。

## 书籍内容

这本指南薄得只有十几页，但每一页都写满了求生智慧。作者认为，烟幕逃脱的关键不是制造多大的烟，而是让敌人相信你还在烟里。书中教授的第一个技巧是"留物诱敌"：在烟幕边缘丢下一件随身物品，让追击者以为那是你摔倒的痕迹。第二个技巧是"反向呼吸"：在烟雾中不要跑向新鲜空气，而是短暂屏息后向侧翼移动，因为大多数敌人会顺着烟雾流动的方向追击。指南还提醒，灰烬交界的烟雾有特殊性质，会黏附在衣服上很久，因此逃脱后必须拍打衣物，否则会留下可被追踪的气味。最后一页是一张简易地图，标注了几个适合制造烟幕的地形点。" 指南的后半部分是一系列手绘的逃脱路线图，每条路线都用虚线标出，并在关键节点画有小型的余火符号。作者解释，这些符号不是装饰，而是提醒使用者在那些位置必须做出选择：继续跑、改变方向、或者停下制造新的烟幕。

## 设计意图

为机动职业提供低阶生存与脱战技能，强化探索与任务容错。
