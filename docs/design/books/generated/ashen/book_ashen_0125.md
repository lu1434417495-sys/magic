# 《灰烬法院的审讯记录》

## 基础信息

- **书籍 ID**：`book_ashen_0125`
- **关联技能**：`ashen_interrogation`
- **使用效果**：阅读后解锁 `ashen_interrogation`；若已学会，提升 `current_mastery +110`，并在下一次与敌对 NPC 对话时获得一次额外信息判定。
- **阅读要求**：职业标签含 `rogue`、`inquisitor` 或 `commander`；基础 `魅力 ≥ 10` 或 `智力 ≥ 10`。
- **稀有度**：精良（Uncommon）
- **建议投放**：灰烬法院档案室、审判官任务、黑市情报交易。

## 书籍内容

这份记录来自灰烬法院，一个以残酷效率著称的异界审判机构。书中详细记录了多种审讯技巧，但最让后世读者惊讶的是，这些技巧很少涉及肉体折磨，更多的是利用灰烬环境的特殊性：寒冷、孤独、对未来的不确定性。审讯官会让囚犯面对一盆缓慢冷却的余烬，告诉他当火熄灭时，机会也会熄灭。书中还记录了不同种族和文化背景囚犯的脆弱点，以及如何避免让囚犯进入"完全放弃"状态——那会导致他们停止提供任何信息。最后一页是一份被涂黑的名单，只有一句话可见："他们说的不一定是真相，但足够我们决定下一步。"记录中提到了一种被称为\"冷灰室\"的审讯场所：四壁涂满冷却的细灰，没有任何光源，囚犯甚至无法判断自己是否还在呼吸。这种环境比任何刑具都更快地瓦解人的意志。

## 设计意图

社交/情报向技能，为特定职业提供对话中的信息获取能力，拓展非战斗玩法。
