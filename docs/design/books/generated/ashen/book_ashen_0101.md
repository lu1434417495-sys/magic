# 《灰烬步测：交界地形速读》

## 基础信息

- **书籍 ID**：`book_ashen_0101`
- **关联技能**：`ashen_terrain_read`
- **使用效果**：阅读后解锁 `ashen_terrain_read`；若已学会，提升 `current_mastery +100`，并在下一次灰烬交界探索中增加 1 格安全移动距离。
- **阅读要求**：无职业限制；基础 `感知 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：灰烬交界入口营地、游商杂货摊、新兵补给箱。

## 书籍内容

这本书的封面被烧出一只手的形状，据说是某位斥候最后的签名。它把灰烬交界的地面分成三类：会塌的灰壳、藏着余烬的硬地和可以借力的碎石。作者用极简的笔法画了一百多张地形剖面图，并在每一张旁边写了一个字：跳、绕、等、冲。书中反复强调，地形不是障碍，而是时间；读懂地面的斥候能比敌人多出一整轮出手。前半部分教你用靴底试探灰壳的厚度，后半部分教你听碎石下的余烬爆裂声判断温度。最末一页只有一行被熏黑的句子："在灰烬里跑直线的人，不是勇敢，是迷路。"很多老手把这页撕下来贴在护臂内侧。书中还附带了一份简易的灰壳承重表，标注了不同厚度灰壳能承受的大致重量，但作者在每个数字旁都写着"仅供参考"。他认为真正的步测高手不会依赖表格，而是依赖脚底传来的细微震动。

## 设计意图

作为灰烬交界探索系的基础入口，把"读地形"包装成可培养技能，降低新人在异界战场中的迷路与暴毙率。
