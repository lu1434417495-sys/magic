# 《灰烬斗气：燃尽式》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0180`
- **关联技能**：`cultivation_ashen_ember_stance`
- **使用效果**：阅读后学会修炼技能 `cultivation_ashen_ember_stance`（`practice_tier = basic`），解锁 AURA 资源链并按首日成长公式注入起始值。
- **阅读要求**：无职业限制；基础 `力量 ≥ 10` 或 `体质 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：武馆据点、狂战士训练场、灰烬交界战士传承任务。

## 书籍内容

燃尽式斗气与传统铁山桩完全相反：它不是静止承重，而是让身体在极限运动中找到能量的更高效路径。作者要求练习者先进行高强度冲刺、挥砍、翻滚，直到肌肉颤抖不止，然后立刻进入一种半蹲姿态，把暴动般的体力转化为斗气。书中警告这套功法极易透支，练习时必须有人在旁看护。中间章节详细描述了"燃尽点"的感觉：当身体告诉你已经到极限时，实际上还有最后一层能量可以被压榨出来。最后几页是一份训练日志，记录了一位战士从站不稳到能维持燃尽式整整三十息的蜕变。书的扉页上有一个烧焦的手印，五指张开，像是在燃烧中抓住了什么。手印旁边没有说明，但每位练习者都会被要求先把手按在上面三秒钟，感受燃尽式的温度。那个手印在练习者手掌按压上去时会短暂变得温热，仿佛原作者的斗气还残留在纸上。

## 设计意图

作为灰烬交界限定修炼功法，为近战职业提供 AURA 资源链入口。
