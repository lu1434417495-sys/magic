# 《灰烬诗人的挽歌集》

## 基础信息

- **书籍 ID**：`book_ashen_0135`
- **关联技能**：`ashen_dirge`
- **使用效果**：阅读后解锁 `ashen_dirge`；若已学会，提升 `current_mastery +110`，并在下一次战斗中令敌方全体士气 -1（对精英以下有效，一次性）。
- **阅读要求**：职业标签含 `bard`、`priest` 或 `mage`；基础 `魅力 ≥ 10` 或 `意志 ≥ 10`。

- **建议投放**：灰烬诗人隐居处、吟游诗人任务、战场悼念仪式奖励。

## 书籍内容

这本挽歌集收录了灰烬诗人们在漫长岁月中为死者谱写的安魂曲。与普通音乐不同，灰烬挽歌不追求优美，而是追求一种让听者感到生命无常的沉重。书中详细描述了演唱时的呼吸控制、音色调配和情感投入，并警告演唱者不要过度沉浸其中——有些诗人在唱了太多挽歌后，自己也渐渐失去了活下去的意愿。最著名的一首挽歌只有四个音符，反复吟唱，据说能让敌人想起自己失去的亲人而暂时丧失战意。书的扉页上写着："我们为灰烬歌唱，不是因为悲伤，而是因为有人需要被记得。"挽歌集的最后一页是空白的，只有一行小字说明：\"为下一个需要被歌唱的灵魂预留。\"灰烬诗人相信，只要还有空白页，死者就没有真正被遗忘。诗人相信，每一首挽歌都会残留一丝听者的悲伤在空气中，久而久之，灰烬交界某些地方的灰雾会特别沉重。

## 设计意图

吟游诗人/信仰职业的控场技能，用叙事与音乐机制影响敌我士气，深化灰烬情感主题。
