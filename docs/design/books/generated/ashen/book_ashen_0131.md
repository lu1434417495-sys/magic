# 《灰烬战马驯养指南》

## 基础信息

- **书籍 ID**：`book_ashen_0131`
- **关联技能**：`ashen_steed_bond`
- **使用效果**：阅读后解锁 `ashen_steed_bond`；若已学会，提升 `current_mastery +100`，并在下一次骑乘冲锋时伤害提高 15%（一次性）。
- **阅读要求**：职业标签含 `knight`、`cavalier` 或 `ranger`；基础 `魅力 ≥ 9` 且 `体质 ≥ 9`。
- **稀有度**：精良（Uncommon）
- **建议投放**：灰烬马厩、骑士团任务、骑兵训练场奖励。

## 书籍内容

灰烬战马不是普通马匹，它们的肺适应了含灰空气，蹄子能在松软的灰壳上保持平衡。这本书教你如何识别一匹好的灰烬战马：看它的眼睛是否能在灰雾中保持平静，听它的呼吸是否深沉而均匀。驯养的关键是建立信任而不是恐惧，因为灰烬战马一旦受惊，会不顾一切地冲进最深的灰堆。作者详细描述了战马饮食、蹄铁护理和冲锋训练的细节，并警告骑手不要在灰雾中过度依赖速度——一匹跑得太快的战马可能根本来不及发现脚下的陷阱。书的末尾附有一张马鞍内衬的缝线图，标注了如何在紧急情况下迅速割断鞍带逃生。灰烬战马对骑手体重极为敏感，过重的骑手会让它们在下坡时失去信心。书中提供了一张战马负重对照表，并建议骑士在长途奔袭前减少不必要的装备。战马对骑手的气味极为敏感，因此同一位骑士最好能长期固定使用同一款肥皂或香水，避免让马匹产生困惑。

## 设计意图

骑乘/伙伴技能，为骑士/游侠提供灰烬环境下的机动与冲锋增益，丰富伙伴养成线。
