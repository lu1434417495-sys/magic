# 《烬魂召唤仪式》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0076`
- **关联技能**：`ashen_spirit_call`
- **使用效果**：阅读后解锁 `ashen_spirit_call`；若已学会，提升 `current_mastery +140`，并延长召唤灰烬灵体的持续时间。
- **阅读要求**：角色职业标签含 `mage`、`warlock` 或 `necromancer`；基础 `智力 ≥ 12` 且 `意志 ≥ 10`。
- **稀有度**：史诗（Epic）
- **建议投放**：灰烬邪教密室、异界裂隙宝箱、禁书区。

## 书籍内容

仪式书记录了如何召唤在灰烬交界中游荡的残余灵体。作者认为，这些灵体并非完整的亡灵，而是强烈情绪燃烧后剩下的“烬魂”。召唤者需准备一个曾经属于逝者的物品，把它埋入余烬中，再用咒语呼唤其最深刻的记忆。书中详细列出三种可召唤的烬魂类型：守护型会替施术者承受一次攻击，引路型能指出隐藏道路，哀嚎型则会干扰敌人。作者警告，烬魂有自己的执念，召唤后必须完成它的心愿，否则它会反噬。练习者需先与最弱的灰影建立联系。尾页写着：“召唤灰烬中的人，要先承认自己也是灰烬的一部分。”书页边缘留有被炭火熏黑的空白，供读者记录自己的灰烬坐标。作者在跋文中提醒：灰烬交界的技法没有标准答案，只有烧剩下的答案。许多抄本的末页都沾着不同颜色的灰烬，那是前人练习时留下的印记。

## 设计意图

为黑暗法系提供召唤玩法入口，把灰烬交界的残魂设定转化为战斗辅助。
