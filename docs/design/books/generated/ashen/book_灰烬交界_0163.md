# 《灰烬骑士的步法》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0163`
- **关联技能**：`ashen_roll`

- **阅读要求**：已学会 `ashen_roll`；基础 `敏捷 ≥ 12`。

- **建议投放**：余烬祭所进阶导师、灰烬骑士遗骸、异界战场宝箱。

## 书籍内容

这本书不讲翻滚本身，而是讲翻滚之后怎么走。作者是一位曾在灰烬交界服役多年的骑士，他把步法分为"落地步""切角步""回辙步"三种。落地步要求翻滚结束后立即压低重心横向移动，避免被敌人预判落点。切角步用于绕过持盾敌人，永远以四十五度角逼近对方弱侧。回辙步则是进攻失败时的保命动作，用一次短后撤重新拉开距离。书中夹着一张手绘战场示意图，标注了数十个"死格"与"活格"。最后一页写道：在灰烬里，移动不是速度，是位置。封底贴着一张骑士团的退役许可，名字被烧掉，只剩一枚灰烬骑士的印章。书的最后一页贴着一张褪色的骑士团退役许可，名字被烧掉，只剩一枚灰烬骑士的印章。印章旁边有一行字："步法救了他三十七次，但第三十八次，他选择留下来。"退役许可的边缘已经被摩挲得起了毛边，说明曾有许多人试图读出那个被烧掉的名字。

## 设计意图

为已掌握翻滚的玩家提供进阶机动性，深化灰烬交界地图策略。
