# 《灰烬亡灵超度祷文》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0197`
- **关联技能**：`ashen_force_burst`
- **使用效果**：阅读后提升 `ashen_force_burst` `current_mastery +120`，并对灰烬交界亡灵类敌人使用该技能时伤害提升 30%。
- **阅读要求**：角色职业标签含 `priest` 或 `paladin`；基础 `意志 ≥ 12`。
- **稀有度**：稀有（Rare）
- **建议投放**：炭化大教堂禁书室、亡灵超度任务、圣职高阶奖励。

## 书籍内容

这本书收录了专门针对灰烬亡灵的 miracle 变体。作者认为灰烬亡灵不是普通的死者，而是被异界力量困住的记忆残片，因此超度它们需要的不是毁灭，而是"释放"。书中要求施术者在施放原力震荡时怀着慈悲之心，把亡灵身上的灰烬束缚震散。中间章节讨论了不同亡灵类型的超度难点：战士亡灵执着于战斗，法师亡灵执着于法术，而普通平民亡灵最难超度，因为他们往往不知道自己已经死去。最后几页是一份名单，作者每超度一个亡灵就写下它的名字。名单的最后一页只有半行字："还有一个，我不知道他的名字，但他一直在等我。"这句话让许多超度者相信，灰烬亡灵中有些并不渴望被释放，而是渴望被记住。名单最后半行字的墨迹在月光下会泛出淡淡的银色，像是被超度者留下的某种回应。

## 设计意图

为圣职系提供对灰烬亡灵的特化能力，深化职业特色。
