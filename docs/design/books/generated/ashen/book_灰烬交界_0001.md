# 《灰烬步基础讲义》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0001`
- **关联技能**：`ashen_step`
- **使用效果**：阅读后解锁 `ashen_step`；若已学会，提升 `current_mastery +120`，并延长下一次战斗中灰烬步的无敌帧 0.1 秒。
- **阅读要求**：无职业限制；基础 `敏捷 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：灰烬交界入口营地、游荡商人、新兵补给箱。

## 书籍内容

这本讲义被灰烬染成了浅灰色，翻页时会落下细小的炭屑。作者用大量简笔画解释灰烬步的原理：不是跑得快，而是在灰烬弥漫的空气中找到一条被灼烧过的缝隙。书中强调，灰烬步的关键在于呼气与落地的同步，每一次踏步都要在呼气结束的瞬间完成，这样身体才不会因为紧张而僵硬。讲义第一章列举了十二种最常见的错误，排名第一的是"把灰烬步当成冲刺"，作者警告这会很快耗尽体力。第二章讲述了如何在灰烬云中辨别方向，因为交界处的能见度常常不足三步。书中还夹着一张手绘地图，上面标注了安全落脚点，但大部分已经被烧焦无法辨认。最后几页是空白页，作者写道："灰烬步没有终点，每一步都是新的交界。"书中还提到，灰烬步练到深处后，练习者的脚印会短暂留在空气中，像一行逐渐消散的灰色足迹。老练的灰烬步使用者能通过这些脚印判断自己上一次踏步是否稳健。

## 设计意图

作为灰烬交界移动战技的基础入口，帮助玩家掌握该区域的节奏与空间感。
