# 《灰烬法官的末日判决录》

## 基础信息

- **书籍 ID**：`book_ashen_0150`
- **关联技能**：`ashen_judgment`
- **使用效果**：阅读后解锁 `ashen_judgment`；若已学会，提升 `current_mastery +150`，并在下一次战斗中对生命值低于 20% 的敌人造成额外 15% 伤害（一次性，限精英以下）。

## 书籍内容

末日判决录记载着灰烬法官对旧帝国末期叛乱者的最终裁决。这些法官不依靠证人，而是依靠一种被称为"烬证"的仪式：把被告的一件物品投入余烬，根据燃烧后的形状判断其灵魂的状态。书中详细描述了七种判决词，每一种都对应一种末日场景：焚城、灰雨、永昼、寂夜等。最著名的一句判决是"汝之火焰已尽，当归于灰"，据说被念出的同时，被告脚下的地面会轻微塌陷。作者在书的扉页郑重声明，这些判决录不应被当作复仇工具，因为每一位法官最终都会发现自己也 burning with the same ash。最后一页贴着一张泛黄的名单，上面所有人的名字都被划掉了，只剩一句话："没有人能审判灰烬而不被灰烬审判。"判决录的封底刻着一行小字："每一次宣判，法官都在燃烧自己的一部分。"因此灰烬法官的寿命普遍不长，但他们的骨灰会被混入法院的墙壁，永远守护他们曾捍卫的秩序。

## 设计意图

高阶圣职/审判者斩杀技能，结合异界法律叙事与处决机制，强调权力与自我审判的主题。
