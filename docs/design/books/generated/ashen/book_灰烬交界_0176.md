# 《余烬祭所编年史》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0176`
- **关联技能**：`known_knowledge_ashen_history`
- **使用效果**：阅读后解锁知识 `known_knowledge_ashen_history`，与灰烬交界 NPC 对话时额外获得一个选项。
- **阅读要求**：无职业限制；基础 `智力 ≥ 9`。
- **稀有度**：普通（Common）
- **建议投放**：沉钟书库历史区、余烬祭所档案室、学者任务奖励。

## 书籍内容

编年史记录了灰烬交界从一次灾难性魔法事故演变为永久异界战场的全过程。作者没有采用英雄叙事，而是收集了士兵、平民、咒术师和牧师的只言片语，拼凑出一幅模糊的图景。书中提到最早进入灰烬交界的人并不是战士，而是矿工，他们在地下挖到了某种"活着的灰烬"。此后才有教会、军政府和学院相继派人来研究和控制。编年史的最后几页是空白的，作者写道：历史在这里不会结束，只会被烧掉重写。这本书让读者意识到，灰烬交界不是背景，而是一个仍在呼吸的世界。书脊处有一道整齐的灼痕，正好烧掉了作者的名字。有人推测这是作者自己烧的，因为他认为在灰烬交界，个人的名字不如记录本身重要。灼痕周围的纸页呈现出一种特殊的脆化状态，触碰时会发出类似秋叶碎裂的声响。

## 设计意图

作为世界观知识书籍，解锁 NPC 对话选项，增强叙事沉浸感。
