# 《灰烬诅咒典籍》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0017`
- **关联技能**：`ashen_curse`
- **使用效果**：阅读后解锁 `ashen_curse`；若已学会，提升 `current_mastery +140`，并延长诅咒持续时间 1 回合。
- **阅读要求**：角色职业标签含 `warlock` 或 `dark_priest`；基础 `智力 ≥ 11` 或 `意志 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：诅咒神庙、禁忌图书馆、堕落商人。

## 书籍内容

《灰烬诅咒典籍》的封面用某种烧焦的皮革制成，上面布满了细小的裂纹。书中认为，诅咒的本质不是伤害，而是让目标与周围环境产生排斥。灰烬诅咒会让受术者体内的热量逐渐被周围的灰烬吸走，最终陷入寒冷与虚弱。作者详细记录了诅咒的施放步骤：首先需要接触目标的影子，然后低声念出被反转的治疗祷文，最后把一小撮交界灰烬撒向目标。书中警告，施术者自己也会感受到轻微的寒意，因为诅咒会反噬。最可怕的章节是"诅咒的延续"：如果目标在诅咒期间死亡，诅咒会转移到最近的一个活人身上。书末用红字写着："下诅咒前，先确定你能承受它的代价。" 诅咒典籍的最后一章被教会列为禁章，因为它记载了如何把诅咒附加在自己的影子上，让影子代替自己承受一部分伤害。这种技巧的代价是影子会逐渐拥有自己的意识，在满月之夜可能会不听使唤。作者用红笔写道："借影者，终被影借。"

## 设计意图

为暗法系职业提供持续削弱型技能，强化控场与持续输出。
