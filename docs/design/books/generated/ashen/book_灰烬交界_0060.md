# 《烬纹阅读术》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0060`
- **关联技能**：`ashen_rune_read`
- **使用效果**：阅读后解锁 `ashen_rune_read`；若已学会，提升 `current_mastery +120`，并解锁一种灰烬交界古代符文解析。
- **阅读要求**：无职业限制；基础 `智力 ≥ 10`。
- **稀有度**：精良（Uncommon）
- **建议投放**：沉钟书库、灰烬遗迹学者营地、考古委托奖励。

## 书籍内容

烬纹阅读术教人辨认灰烬交界墙壁上那些由灼烧留下的古代符号。作者指出，这些符文并非刻写，而是高温瞬间将信息烙入石面，因此必须用特定角度观察才能看清。书中把烬纹分为“指路纹、警告纹、封印纹”三类，每类都有独特的裂纹走向。核心章节讲解如何用余烬粉末涂抹石面，让隐藏符文因温差而显现。作者还记录了十二种常见误读，比如把“禁止入内”看成“此处有宝”。练习者需在遗迹墙壁上寻找并翻译三处真实符文。尾页写着：“灰烬烧掉了文字，却烧不掉文字想警告的事。”书页边缘留有被炭火熏黑的空白，供读者记录自己的灰烬坐标。作者在跋文中提醒：灰烬交界的技法没有标准答案，只有烧剩下的答案。许多抄本的末页都沾着不同颜色的灰烬，那是前人练习时留下的印记。此抄本曾被余烬烫穿数页，缺失处反而逼迫读者用自己的经验补全。
