# 《炭化护盾笔记》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0053`
- **关联技能**：`ashen_shield_bash`
- **使用效果**：阅读后解锁 `ashen_shield_bash`；若已学会，提升 `current_mastery +140`，并在下一次战斗中令盾击附带灰烬灼烧效果。
- **阅读要求**：已装备盾牌；基础 `体质 ≥ 9`。
- **稀有度**：精良（Uncommon）
- **建议投放**：断桥营寨军械库、老兵遗物、盾卫训练任务奖励。

## 书籍内容

笔记记录了一群在灰烬前线作战的盾卫如何用余烬加固防御。作者认为，盾不是被动挨打的工具，而是可以主动压向敌人的热墙。书中教授“炭化覆层”技巧：在战斗前让盾牌表面沾上薄层灰烬，受击时灰烬会飞溅，短暂模糊敌人视线。盾击时则需用盾缘而非盾面，像铲子一样把余烬拍向对手。作者警告，灰烬覆层不能过厚，否则会影响举盾速度。后半部分讨论如何在灰烬雨中保持盾面角度，让灰烬顺着弧线滑落而非堆积。尾页批注：“最好的盾，是敌人不敢碰的盾。”书页边缘留有被炭火熏黑的空白，供读者记录自己的灰烬坐标。作者在跋文中提醒：灰烬交界的技法没有标准答案，只有烧剩下的答案。许多抄本的末页都沾着不同颜色的灰烬，那是前人练习时留下的印记。此抄本曾被余烬烫穿数页，缺失处反而逼迫读者用自己的经验补全。

## 设计意图

为前排战士提供灰烬环境防御反击入口，把盾牌从减伤工具扩展为控场手段。
