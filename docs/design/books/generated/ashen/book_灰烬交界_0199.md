# 《灰烬交界传奇：无名骑士》

- **书籍 ID**：`book_灰烬交界_0199`
- **关联技能**：`ashen_shield_parry`
- **使用效果**：阅读后提升 `ashen_shield_parry` `current_mastery +200`，并解锁称号`灰烬无名者`，装备时盾牌格挡率 +5%。

## 书籍内容

这本书讲述了一位没有留下姓名的骑士如何在灰烬交界守护一座断桥整整三十年的故事。他不属于任何势力，也不接受任何供奉，只是站在那里，把每一个试图越过断桥的怪物挡回去。书中没有华丽的战斗描写，只有一次次的盾反、一次次的半步、一次次的沉默等待。作者收集了路过旅人的口述，拼凑出这位骑士的日常：他会修补桥面、掩埋尸体、在桥头发呆。最后几页是一份未署名的碑文，上面刻着：他不需要名字，因为桥还在。阅读这本书的人会在某个深夜梦见那座桥，和桥上的身影。醒来时枕边会落下一小片灰色的金属碎屑，像是某种无声的托付。许多读者试图保存这些碎屑，但它们总是在日出前化为普通的灰烬，只留下一个关于守护的梦。那些金属碎屑在离开书本后很快就会消失，让许多收藏家怀疑它们是否真的存在过。

## 设计意图

作为传奇级叙事书籍，提供高额熟练度与称号奖励，承载灰烬交界核心精神。
