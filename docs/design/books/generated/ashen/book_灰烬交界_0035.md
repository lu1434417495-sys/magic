# 《灰烬复苏法》

- **关联技能**：`ashen_revive`

- **阅读要求**：角色职业标签含 `priest` 或 `support`；基础 `意志 ≥ 13`。

## 书籍内容

《灰烬复苏法》记载的是一种极为罕见的复活仪式，它不是让死者完全复生，而是让其在短时间内以灰烬形态继续战斗。作者警告，这种仪式有严格的时间限制：必须在死亡后三分钟内开始，否则灵魂会彻底消散。仪式需要大量交界灰烬和一个自愿承担反噬的施术者。书中详细讲解了复苏过程：先把死者的身体覆盖在灰烬中，然后施术者把自己的生命力分出一部分注入灰烬，最后用圣火点燃。复苏者会保留大部分战斗能力，但在一段时间后必须再次沉睡。书末有一段禁忌注释："不要对同一个人使用两次，第二次复苏回来的东西，不一定还是他。" 复苏法的伦理困境在书中被多次提及。作者问道：如果复苏回来的人缺少了一部分记忆，他还是原来的那个人吗？书中没有给出答案，但建议施术者在施法前与被复苏者的亲友讨论，因为有些人宁愿死亡也不愿意以灰烬形态存在。

## 设计意图

为治疗系提供高风险复活技能，强化团队容错与史诗战斗。
