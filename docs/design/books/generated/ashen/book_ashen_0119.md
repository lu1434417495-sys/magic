# 《断旗续章：灰烬战团的指挥残卷》

## 基础信息

- **书籍 ID**：`book_ashen_0119`
- **关联技能**：`ashen_battle_command`
- **使用效果**：阅读后解锁 `ashen_battle_command`；若已学会，提升 `current_mastery +130`，并在下一次团队战斗中为所有召唤物/随从提供 +10% 攻击力（一次性）。
- **阅读要求**：职业标签含 `commander` 或 `tactician`；基础 `魅力 ≥ 10` 且 `智力 ≥ 9`。
- **稀有度**：稀有（Rare）
- **建议投放**：灰烬战团遗迹、指挥官传承任务、战场指挥所宝箱。

## 书籍内容

这本残卷记录了一支早已覆灭的灰烬战团的指挥口令和旗语。书的封面是一面被烧焦的旗帜，旗面上的纹章已经看不清，只能摸到凸起的刺绣轮廓。正文把指挥分成三个层次：令旗传意、鼓点传情、沉默传志。令旗是具体的指令，鼓点是整体的节奏，而沉默则是在最混乱的时刻让士兵知道指挥官仍在思考。作者特别强调，灰烬战场的能见度极差，声音和光比视觉信号更可靠。书中附有一套简化的灰烬鼓语，以及如何在火光和灰雾中保持旗帜可见的技巧。最后一章是写给继任者的："旗帜会断，口令会忘，但只要有人还在按照你的节奏移动，战团就没有灭。"残卷中有一段被反复涂改的撤退号令。最初的版本是\"全体撤退\"，后来改为\"有序撤离\"，最终版本只有两个字：\"归灰\"。据说最后那个版本让战团在覆灭前保留了最后的尊严。

## 设计意图

指挥官/战术家团队增益技能，把异界战场环境与指挥节奏机制结合。
