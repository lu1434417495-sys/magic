# 《烟灰遮蔽术》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0032`
- **关联技能**：`ashen_shroud`
- **使用效果**：阅读后解锁 `ashen_shroud`；若已学会，提升 `current_mastery +110`，并扩大遮蔽范围半格。
- **阅读要求**：角色职业标签含 `rogue` 或 `mage`；基础 `敏捷 ≥ 9` 或 `智力 ≥ 10`。
- **稀有度**：精良（Uncommon）
- **建议投放**：暗影商人、遗迹密室、潜入任务奖励。

## 书籍内容

《烟灰遮蔽术》教导如何瞬间释放大量灰烬形成遮蔽视野的烟幕。与普通烟幕不同，灰烬遮蔽术产生的烟幕会持续从施术者身上散发，跟随施术者移动。作者强调，这种遮蔽最大的用途不是逃跑，而是重新选择战斗位置。书中详细讲解了控制烟幕浓度的技巧：太浓会连自己也无法视物，太薄则无法有效遮蔽敌人。第二章讲解了如何在烟幕中保持方向感：要学会记住进入烟幕前最后一眼看到的地面特征，并在移动中用脚感受地形变化。书的后半部分记录了多种战术应用，包括掩护队友撤退、制造假撤退、以及配合刺客进行突袭。" 遮蔽术的高级使用者可以在移动中持续释放烟幕，形成一条"灰烬尾巴"。这种技巧的关键是控制释放量，让尾巴既不会暴露自己的精确位置，又能让追击者不敢贸然闯入。作者把这种移动方式称为"灰色蛇行"。

## 设计意图

为机动与法系职业提供视野控制技能，强化战术 repositioning。
