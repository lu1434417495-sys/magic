# 《灰烬狂战士的失控美学》

## 基础信息

- **书籍 ID**：`book_ashen_0147`
- **关联技能**：`ashen_berserker_trance`
- **使用效果**：阅读后解锁 `ashen_berserker_trance`；若已学会，提升 `current_mastery +140`，并在下一次战斗中进入灰烬狂暴状态（攻击 +15%，受到伤害 +10%，持续 4 回合）。
- **阅读要求**：职业标签含 `barbarian` 或 `berserker`；基础 `力量 ≥ 11` 且 `体质 ≥ 10`。
- **稀有度**：史诗（Epic）
- **建议投放**：狂战士祭坛、角斗场冠军奖励、血脉觉醒任务。

## 书籍内容

灰烬狂战士不相信控制，他们相信的是与失控共舞。这本书来自一位被称为"余烬咆哮者"的狂战士，他认为真正的狂暴不是失去理智，而是让理智退后一步，让身体的本能接管一切。书中描述了如何在战斗中点燃内心的"烬种"：回忆最痛苦的失去、最深刻的愤怒、最不甘的失败，然后把它们全部喂给那团火。作者警告，灰烬狂暴与普通狂暴不同，它不会让人完全失去判断力，但会让使用者对痛苦和恐惧变得麻木。最危险的是结束时刻——当火焰熄灭，疲惫和伤口会同时袭来。书的末尾只有一句话重复了几十遍："烧完之前，先想好怎么躺下。"余烬咆哮者留下了一段关于结束的忠告：灰烬狂暴最好的落幕不是胜利，而是倒下的地方刚好有一堆温热的灰。他说这样至少不会冷得太快，虽然这话听起来更像是自嘲。

## 设计意图

狂战士高阶爆发技能，以自伤换取输出，强化高风险战斗风格与灰烬主题叙事。
