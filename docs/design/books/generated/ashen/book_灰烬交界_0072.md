# 《灰烬法器保养术》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0072`
- **关联技能**：`ashen_focus_craft`
- **使用效果**：阅读后解锁 `ashen_focus_craft` 制作支线；若已学会，提升 `current_mastery +130`，并降低法器在灰烬环境中的损耗速度。
- **阅读要求**：角色职业标签含 `mage` 或 `sorcerer`；基础 `智力 ≥ 10`。
- **稀有度**：精良（Uncommon）
- **建议投放**：法师导师藏库、工匠行会、灰烬遗迹宝箱。

## 书籍内容

保养术专讲如何在灰烬交界的腐蚀环境中维护法器。作者指出，异界灰烬会渗入木质法杖的纹理、侵蚀金属戒指的光泽，甚至改变水晶的共鸣频率。书中给出清洁步骤：先用干刷去除浮灰，再用微温的油脂擦拭，最后用干净布包裹静置一夜。核心章节教授“灰封”技术：在法器表面涂一层薄薄的耐火漆，既能隔绝灰烬，又不影响魔力传导。作者还记录了十二种法器材质在灰烬中的耐受排名。练习者需亲自修复一件被轻微腐蚀的练习法杖。尾页批注：“法器是法师的第二个肺，别让它被灰烬堵塞。”书页边缘留有被炭火熏黑的空白，供读者记录自己的灰烬坐标。作者在跋文中提醒：灰烬交界的技法没有标准答案，只有烧剩下的答案。许多抄本的末页都沾着不同颜色的灰烬，那是前人练习时留下的印记。

## 设计意图

为法师系提供装备维护与制作入口，把环境危害转化为工匠玩法内容。
