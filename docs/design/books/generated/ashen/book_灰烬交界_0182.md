# 《盗贼的灰烬潜行》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0182`
- **关联技能**：`ashen_roll`
- **使用效果**：阅读后提升 `ashen_roll` `current_mastery +90`，并在灰烬交界地图中首次进入战斗时获得 `stealth` 状态持续 30 TU。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `敏捷 ≥ 12`。
- **稀有度**：精良（Uncommon）
- **建议投放**：黑市商人、盗贼公会声望奖励、暗杀任务密室。

## 书籍内容

作者是一位曾在灰烬交界生活多年的盗贼，他认为灰烬是最完美的潜行媒介：它会掩盖脚步声、吸收体味、模糊轮廓。但灰烬也有致命缺陷：它会记录你的脚印，而且一旦移动过快就会扬起可见的尘云。书中提供了"慢潜"技巧：每次移动后等待灰烬重新沉降，再迈出下一步。还讲到了"借势"：利用灰烬中的裂缝和突起作为视觉遮挡。中间章节讨论了不同盔甲在灰烬中移动时的噪音差异。最后几页是一份逃生路线图，标注了多个"一旦被发现就滚进去"的藏身点。书的夹页里有一片黑色的面罩碎片，边缘还残留着体温。前任主人留言说这块面罩陪他完成了七次不可能的任务，最后在一次脱身中被刀刃割破。面罩碎片在黑暗中几乎无法看见，只有用特殊灯光照射时才会显出原本的轮廓。夹在书页间的一根头发已经变成了灰白色，与灰烬交界的尘埃融为一体。

## 设计意图

强化盗贼/刺客在灰烬交界的先手与生存优势。
