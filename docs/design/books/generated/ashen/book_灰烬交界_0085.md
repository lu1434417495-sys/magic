# 《灰烬锻造：余火锤》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0085`
- **关联技能**：`ashen_forge`
- **使用效果**：阅读后解锁 `ashen_forge` 制作支线；若已学会，提升 `current_mastery +130`，并降低灰烬锻造武器时材料损耗。
- **阅读要求**：无职业限制；基础 `力量 ≥ 10` 且 `智力 ≥ 9`。
- **稀有度**：精良（Uncommon）
- **建议投放**：锻造据点、工匠行会、灰烬遗迹铁匠铺。

## 书籍内容

余火锤教人利用灰烬交界的低温余烬进行特殊锻造。作者指出，异界余烬的温度稳定且持久，适合进行需要精确控温的淬火。书中把锻造过程分为“预热、塑形、灰淬”三步，关键在于灰淬：把烧红的金属迅速埋入干燥的细灰中，让灰烬缓慢吸热，形成独特的纹理。核心章节讲解如何判断灰烬的活性：抓一把在手中握紧，若三秒后掌心感到温热，说明可用。作者还记录了几种适合灰淬的金属配方。练习者需亲自锻造一枚灰纹匕首。尾页写着：“火塑造了形状，灰塑造了灵魂。”书页边缘留有被炭火熏黑的空白，供读者记录自己的灰烬坐标。作者在跋文中提醒：灰烬交界的技法没有标准答案，只有烧剩下的答案。许多抄本的末页都沾着不同颜色的灰烬，那是前人练习时留下的印记。此抄本曾被余烬烫穿数页，缺失处反而逼迫读者用自己的经验补全。

## 设计意图

为生活职业提供灰烬主题锻造入口，把异界环境转化为装备制作资源。
