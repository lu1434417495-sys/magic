# 《灰烬领主：烬域令》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0099`
- **关联技能**：`ashen_domain`
- **使用效果**：阅读后解锁 `ashen_domain` 领域技；若已学会，提升 `current_mastery +200`，并令领域内所有灰烬系技能效果提升 10%。
- **阅读要求**：角色职业标签含 `warlord`、`commander` 或 `knight`；基础 `魅力 ≥ 12` 且 `意志 ≥ 12`。
- **稀有度**：传说（Legendary）
- **建议投放**：灰烬法院王座厅、世界Boss稀有掉落、高阶指挥官传承任务。

## 书籍内容

烬域令是灰烬交界中少数被承认的统治象征。作者认为，真正的灰烬领主不是征服者，而是能够与交界本身达成契约的人。书中要求领主在宣誓时用自己的血混合七把不同来源的余烬，在领地边界画出守护符文。领域一旦建立，范围内的灰烬会响应领主的意志，强化友方、削弱入侵者。核心章节警告，维持烬域需要持续消耗领主的意志与体力，过度扩张会让领主自身也化为灰烬。练习者需先在小范围内建立并维持烬域一整夜。尾页题词：“领主不是站在灰上的人，是愿意成为灰下基石的人。”书页边缘留有被炭火熏黑的空白，供读者记录自己的灰烬坐标。作者在跋文中提醒：灰烬交界的技法没有标准答案，只有烧剩下的答案。许多抄本的末页都沾着不同颜色的灰烬，那是前人练习时留下的印记。

## 设计意图

作为灰烬系列传奇级团队核心技能，为指挥官类职业提供领域控制与团队增幅。
