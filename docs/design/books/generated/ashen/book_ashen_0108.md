# 《烬法师的灰烬箭术》

## 基础信息

- **书籍 ID**：`book_ashen_0108`
- **关联技能**：`ashen_ash_arrow`
- **使用效果**：阅读后解锁 `ashen_ash_arrow`；若已学会，提升 `current_mastery +150`，并在下一次战斗中令前三次射击附带灰烬致盲效果。
- **阅读要求**：职业标签含 `archer` 或 `mage`；基础 `感知 ≥ 9` 或 `智力 ≥ 9`。
- **稀有度**：精良（Uncommon）
- **建议投放**：沉钟书库禁书区、灰烬法师塔、游侠-法师混合任务奖励。

## 书籍内容

灰烬箭不是实体箭矢，而是把凝聚的魔力压成灰粉的形态射出。书中强调，这种箭的飞行轨迹不像普通箭矢那样稳定，而是像被风吹散的烟一样轻微摆动。射手需要学会的不是瞄准，而是"领烟"——在箭离弦后用意念维持它的形状，直到命中目标。前半本讲凝聚：太紧会提前爆裂，太松会在半路散开。后半本讲命中：灰烬箭对金属护甲效果极差，但对眼睛、关节和暴露在外的皮肤有奇效。书的末尾附有一张实验记录表，某次射击在十五米外让一头灰烬兽失明整整八秒，旁边批注："烟没有锋，但烟能盖住光。"高级射手会在箭矢离弦前轻轻吹一口气，让灰烬箭表面附着一层口腔湿气。这样箭矢在飞行中会留下更明显的灰迹，便于修正下一箭的轨迹，但也更容易被敌人察觉。高级烬法师能在箭矢中封存一缕自己的意念，使箭在命中后短暂留存施术者的感知，用于侦察而非杀伤。

## 设计意图

为弓箭手/法师提供灰烬主题的远程控制技能，强调视觉干扰与精准落点。
