# 《烬刃初阶剑谱》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0054`
- **关联技能**：`ashen_blade`
- **使用效果**：阅读后解锁 `ashen_blade`；若已学会，提升 `current_mastery +130`，并令下一次灰烬刃攻击附加 1 层余烬标记。
- **阅读要求**：角色职业标签含 `warrior` 或 `rogue`；基础 `敏捷 ≥ 10`。
- **稀有度**：精良（Uncommon）
- **建议投放**：灰烬遗迹宝箱、余烬祭所基础传授、游荡武器商人。

## 书籍内容

剑谱教人把灰烬附着在剑刃上，让普通斩击带有灼烧与滞缓效果。作者强调，烬刃的关键不在火焰，而在“冷灰”——一种燃烧殆尽后仍保持高温的残渣。书中详细说明如何在挥剑前让剑身扫过地面的余烬，使灰粒均匀覆盖刃口。第一章是七种基础斩击，每种都配以灰烬飞扬的角度图示。第二章讨论灰烬消耗：一次附灰大约维持三到五击，之后必须重新蘸取。作者警告，烬刃对使用者同样危险，剑柄必须缠有隔热材料。尾页画着一柄布满裂纹的旧剑，配文：“灰烬让剑变钝，也让敌人变慢。”书页边缘留有被炭火熏黑的空白，供读者记录自己的灰烬坐标。作者在跋文中提醒：灰烬交界的技法没有标准答案，只有烧剩下的答案。许多抄本的末页都沾着不同颜色的灰烬，那是前人练习时留下的印记。此抄本曾被余烬烫穿数页，缺失处反而逼迫读者用自己的经验补全。

## 设计意图

作为灰烬系近战核心技能的入门书籍，把环境资源转化为武器增益。
