# 《灰雨步法：在落灰中移动》

## 基础信息

- **书籍 ID**：`book_ashen_0115`
- **关联技能**：`ashen_rain_step`
- **使用效果**：阅读后解锁 `ashen_rain_step`；若已学会，提升 `current_mastery +140`，并在下一次战斗中令移动不再触发借机攻击（限 3 次）。
- **阅读要求**：无职业限制；基础 `敏捷 ≥ 9`。
- **稀有度**：精良（Uncommon）
- **建议投放**：灰烬游侠营地、通用战技商人、余烬祭所基础传授。

## 书籍内容

灰雨步法的名字来自灰烬交界一种常见现象：空中会突然飘落大量细灰，像一场黑色的雨。作者观察到，大多数人在灰雨中会本能地低头、闭眼、放慢脚步，而训练有素的战士可以利用这段时间快速改变位置。灰雨步法的关键不是快，而是"轻"：脚掌先落外侧再滚向内侧，身体重心略向前倾，双臂保持放松以随时变向。书中有一段颇具诗意的描述："你要像一片灰本身那样落下，不要发出比灰更大的声音。"后半部分讲如何在灰雨中判断敌人的盲区：落灰会遮蔽视线，但也会让光源变得弥散，从敌人瞳孔的方向可以反推他能看到什么。书中还记载了\"灰雨停\"的诀窍：当落灰突然变密时，往往意味着附近有余烬爆裂或大型生物移动。优秀的步法使用者会把这种变化当作预警，而不是单纯的视觉障碍。

## 设计意图

通用机动技能，强化玩家在灰烬环境中的位置控制能力，与翻滚形成互补。
