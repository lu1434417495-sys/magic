# 《灰烬弓箭手的测距术》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0186`
- **关联技能**：`ashen_firebomb`
- **使用效果**：阅读后提升 `ashen_firebomb` `current_mastery +80`，并使弓箭手在灰烬交界的首次远程攻击射程 +1。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；基础 `感知 ≥ 12`。
- **稀有度**：精良（Uncommon）
- **建议投放**：风息哨塔训练场、游侠测距挑战、灰烬交界高处据点。

## 书籍内容

这本书教弓箭手如何在灰烬弥漫的环境中判断距离。作者指出，灰烬会让远处的目标看起来比实际更近，也会让近处的轮廓变得模糊。她建议射手用"双点法"：先找到目标旁边的参照物，再用参照物与目标的相对大小反推距离。书中还讲到了风对箭矢的影响：灰烬中的风往往没有规律，射手要学会观察地面灰烬的飘动方向。中间章节收录了不同距离下的提前量表格，但作者在每一页都写着"仅供参考"。最后一页是一段心得：在灰雾里，眼睛会骗你，但呼吸不会。书的扉页上有一道浅浅的划痕，像是被箭羽划过留下的纪念。划痕旁边写着"射中这一箭时，我闭着眼"，让这本书带上了一点传奇色彩。那道划痕与书中某张示意图上的箭矢轨迹完全重合，不知是巧合还是刻意的标记。书的最后一页背面画着一个小小的太阳，被无数道黑线划掉又重新画过。

## 设计意图

为弓箭手提供远程战斗增益，强调环境感知与距离判断。
