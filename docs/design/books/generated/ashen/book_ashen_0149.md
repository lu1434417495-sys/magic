# 《灰烬赌徒的骰子戏法》

## 基础信息

- **书籍 ID**：`book_ashen_0149`
- **关联技能**：`ashen_gamblers_favor`
- **使用效果**：阅读后解锁 `ashen_gamblers_favor`；若已学会，提升 `current_mastery +100`，并在下一次涉及随机判定的交互中获得一次重骰机会（一次性）。

## 书籍内容

灰烬赌徒是一群在毁灭边缘寻找刺激的人，他们相信灰烬交界残留着旧帝国最后的气运，而这些气运可以被特定的仪式借走片刻。这本书介绍了一种被称为"烬骰"的戏法：用灰烬覆盖普通的骰子，在掷出前低声念出一段祷词，然后接受结果——无论好坏。作者强调，烬骰真正的技巧不是作弊，而是知道什么时候停止借用运气。书中记录了十几种祷词变体，每一种据说能影响不同的运势方向：财运、桃花运、生死运。最危险的一种祷词被整页涂黑，只在边缘露出半句话："……代价会在你最高兴的时候收取。"很多赌徒把这一页撕掉，声称它"太不吉利"。烬骰的忠实使用者会在每次掷骰后把骰子浸入冷水再擦干，他们相信这样能\"洗去\"上一次借用运气留下的债务。但书里明确写道，真正的债务从来不在骰子上。

## 设计意图

为赌徒/吟游诗人/盗贼提供一次性运气干预技能，拓展社交与随机玩法，强调代价与节制。
