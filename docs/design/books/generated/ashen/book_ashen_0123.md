# 《灰中膳食：异界生存食谱》

## 基础信息

- **书籍 ID**：`book_ashen_0123`
- **关联技能**：`ashen_survival_cooking`
- **使用效果**：阅读后解锁 `ashen_survival_cooking`；若已学会，提升 `current_mastery +100`，并立即制作一份灰烬炖菜（恢复中量 HP）。
- **阅读要求**：无职业限制；基础 `体质 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：营地厨师、游商杂货、探索任务奖励。

## 书籍内容

这是一本被油烟和灰渍浸透的食谱，专门教人用灰烬交界的有限材料做出口味尚可的食物。作者把可食用材料分成三类：灰菇、烬根和余烬虫。灰菇需要泡水去涩，烬根必须烤透否则有毒，余烬虫则是高蛋白但心理门槛极高。书中每道菜都标注了恢复体力的效果和可能的副作用，比如"灰烬炖菜暖胃但会让口气变差三天"。最实用的一章是"无水烹饪"：利用余烬的余热把食物慢慢烘熟。书的空白处有很多手写批注，其中一条写着："不要相信颜色鲜艳的灰菇，它们在灰烬里越好看，越容易让你看见祖先。"作者在最后推荐了一道名为\"灰中灰\"的极简料理：把几种可食用灰菇和烬根磨粉，拌入余烬水调成糊状。它看起来令人作呕，但能提供长途行走所需的大部分热量。作者特别提醒，在灰烬交界不要浪费任何食物残渣，因为余烬可以反复加热同一批食材至少三次。

## 设计意图

生存 crafting 技能入口，把异界环境转化为可采集、可烹饪的资源循环。
