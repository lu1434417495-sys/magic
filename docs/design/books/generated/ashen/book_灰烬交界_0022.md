# 《炭化陷阱图鉴》

## 书籍内容

这本图鉴收集了三十七种用灰烬和余火制成的陷阱，从最简单的绊脚索到复杂的连锁爆破阵。作者认为，好的陷阱不应该追求一击必杀，而是要让敌人陷入困境，让布置者有足够的时间决定下一步。书中每一种陷阱都配有材料清单、布置时间和预计效果。最受欢迎的几种是"灰雾绊索""余烬坑"和"假撤退诱饵"。第二章讲解了如何伪装陷阱：在灰烬交界，最明显的陷阱往往是用最少的灰烬覆盖，因为过多的灰烬反而会引起警觉。书的后半部分记录了多个陷阱失败案例，排名第一的原因是"布置者自己忘记了位置"。" 图鉴中有一种被称为"灰烬摇篮"的陷阱：在地上挖一个浅坑，铺上灰烬和余火碎片，再覆盖一层薄薄的浮土。敌人踩上去时不会立刻受伤，但会陷入短暂的僵直，因为余火会通过鞋底灼烧脚部。这个陷阱最适合配合远程攻击使用。

## 设计意图

为游侠与盗贼提供阵地控制技能，强化埋伏与防御玩法。
