# 《余烬狂暴手册》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0044`
- **关联技能**：`ashen_berserk`
- **使用效果**：阅读后解锁 `ashen_berserk`；若已学会，提升 `current_mastery +130`，并降低狂暴结束后的虚弱持续时间 1 回合。
- **阅读要求**：角色职业标签含 `berserker` 或 `warrior`；基础 `力量 ≥ 12` 或 `体质 ≥ 11`。
- **稀有度**：稀有（Rare）
- **建议投放**：狂战士神殿、角斗场冠军奖励、rage 试炼。

## 书籍内容

《余烬狂暴手册》记录的狂暴不是失去理智，而是有意识地让交界余火点燃自己的斗气。作者强调，真正的余烬狂暴者能在狂暴中保持最低限度的判断，只攻击敌人而不伤害队友。书中详细讲解了进入狂暴的三个步骤：压制恐惧、点燃斗气、放开限制。最难的是第一步，因为恐惧是身体对死亡的本能保护。第二章讲解了如何在狂暴中控制呼吸：急促的呼吸会加速体力消耗，而深长的呼吸能延长狂暴时间。书的后半部分收录了多位狂暴者的战后反思，其中一人写道："我不记得我杀了多少人，但我记得我没有杀那个挡在我面前的战友。这就是余烬狂暴和野兽狂暴的区别。" 狂暴手册区分"余烬狂暴"与"野兽狂暴"的关键在于眼睛：前者眼中仍有焦点，后者眼中只有混乱。作者建议练习者在狂暴时始终盯着一个固定的点，这个点可以是敌人、战友、或自己武器上的某个标记，用来锚定理智。

## 设计意图

为狂战士提供高风险高收益的爆发状态技能。
