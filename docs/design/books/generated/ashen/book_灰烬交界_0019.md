# 《灰烬共鸣学》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0019`
- **关联技能**：`ashen_resonance`
- **使用效果**：阅读后解锁 `ashen_resonance`；若已学会，提升 `current_mastery +150`，并使队友的下一次灰烬系技能伤害提升 5%。
- **阅读要求**：角色职业标签含 `bard` 或 `support`；基础 `智力 ≥ 10` 或 `魅力 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：吟游诗人公会、战场指挥所、团队任务奖励。

## 书籍内容

《灰烬共鸣学》研究的是如何让多个灰烬系技能产生协同效应。作者发现，当两个以上的灰烬法术在相近时间释放时，它们之间的余波会相互放大，形成一种低频共鸣。这种共鸣对施术者也有反作用，如果频率不对，会导致魔力紊乱。书中教授的核心技巧是"节奏匹配"：不是同时施放，而是按照特定的时间间隔依次施放，让每一次技能都落在前一次共鸣的波峰上。第二章讲解了不同职业之间的共鸣组合，比如法师的灰烬爆发与战士的灰烬冲锋可以形成完美的前后夹击。书末有一段被烧毁的乐谱，据说是用灰烬共鸣原理创作的战歌。" 共鸣学中有一个被称为"灰潮"的现象：当足够多的灰烬系法术在战场上同时释放时，整个区域的魔力会被短暂地统一节律。作者认为，精通共鸣的人不是在施放自己的法术，而是在指挥一场由灰烬演奏的交响乐。每个法术都是一个音符，时机比音量更重要。
