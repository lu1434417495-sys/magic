# 《火焰壶投掷手册》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0158`
- **关联技能**：`ashen_firebomb`
- **使用效果**：阅读后解锁 `ashen_firebomb`；若已学会，提升 `current_mastery +120` 并在下次战斗中首次投掷时范围半径临时 +1。
- **阅读要求**：无职业限制；基础 `敏捷 ≥ 7` 或 `力量 ≥ 7`。
- **稀有度**：普通（Common）
- **建议投放**：坠墓镇商人、灰烬交界游荡者营地、通用道具箱。

## 书籍内容

这是一本教你把火装进陶罐再扔出去的书。作者没有讲火焰配方，而是讲投掷：弧线、落点、提前量。它指出火焰壶的真正价值不是伤害，而是逼迫敌人移动或把敌人逼出关键格。书中把投掷分为三种距离：近抛用于封路，中抛用于补刀，远抛用于打断施法。每个距离都配有简单的角度图示。后半本讲壶体封装：引线长度、封口松紧、陶罐壁厚都会影响引爆时间。最后一页是一张泛黄的清单，列着"好壶的三个标准"：不响、不漏、落地不碎。扉页上用焦黑墨水画着一只简笔壶，旁边写着："扔出去的是壶，收回来的是空间。"书的扉页上用红墨水写着"仅供灰烬交界使用"。下面有人用铅笔补了一句："主世界用也行，只是效果没那么好，而且可能违法。"这种随意的批注让手册多了几分生活气息。手册的装订线明显比同规格书籍更粗，因为原线曾被多次烧断后重新穿过。

## 设计意图

作为通用投掷物技能入口，让近战、弓手、盗贼都能享受魂味道具循环。
