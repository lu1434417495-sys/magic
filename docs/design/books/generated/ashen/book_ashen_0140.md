# 《燃灰步：火焰中的舞蹈》

## 基础信息

- **书籍 ID**：`book_ashen_0140`
- **关联技能**：`ashen_fire_dance`
- **使用效果**：阅读后解锁 `ashen_fire_dance`；若已学会，提升 `current_mastery +140`，并在下一次战斗中令闪避火焰攻击的成功率 +20%（持续 3 回合）。
- **阅读要求**：职业标签含 `monk`、`dancer` 或 `rogue`；基础 `敏捷 ≥ 11`。
- **稀有度**：稀有（Rare）
- **建议投放**：火焰舞者营地、武僧传承任务、表演者支线奖励。

## 书籍内容

燃灰步源自一群在灰烬交界流浪的舞者，他们把躲避火焰变成了一种艺术形式。书中描述的核心不是快，而是"顺"：顺着热浪的方向移动，顺着火焰的呼吸节奏变换重心，让攻击者感觉自己面对的不是一个目标，而是一片随风飘荡的灰。正式步法只有五个基本位，但组合起来可以应对大多数火焰攻击。作者警告，燃灰步要求练习者完全放松，任何紧张都会让身体变成火焰的靶子。书中还记录了如何在舞蹈中保持攻击能力，因为真正的燃灰步舞者从不只是躲避。最后一页是一张烧焦的舞谱，上面有几个模糊的脚印，旁边写着："火会追紧绷的人，不会追流动的灰。"燃灰步的练习者会在手腕和脚踝上系一小撮灰烬，移动时观察灰烬飘落的轨迹。如果灰烬被甩向身体后方，说明动作正确；如果绕身旋转，说明重心出了问题。

## 设计意图

高机动闪避技能，为武僧/舞者/盗贼提供火焰特化生存能力，突出节奏与流动的战斗美学。
