# 《灰烬死灵：烬骨召》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0098`
- **关联技能**：`ashen_necromancy`
- **使用效果**：阅读后解锁 `ashen_necromancy`；若已学会，提升 `current_mastery +150`，并令召唤的烬骨仆从额外继承一项灰烬特性。
- **阅读要求**：角色职业标签含 `necromancer` 或 `warlock`；基础 `智力 ≥ 12` 且 `意志 ≥ 11`。
- **稀有度**：史诗（Epic）
- **建议投放**：禁书区、亡灵法师密室、异界裂隙宝箱。

## 书籍内容

烬骨召教死灵法师如何利用灰烬交界的余烬唤醒被火焰重塑过的骸骨。作者认为，灰烬中的骨骼与普通亡灵不同，它们保留了燃烧时的痛苦与执念，因此更加顽强。书中要求施术者先在骸骨上涂抹一层活灰，再用咒语把余烬压入骨髓。核心章节讨论烬骨仆从的三种特性：耐火、灼烧反伤、灰雾光环。作者警告，烬骨仆从比普通亡灵更难控制，因为它们仍记得燃烧。练习者需先成功控制一具小型烬骨。尾页写着：“唤醒灰烬中的人，要先愿意分担它的燃烧。”书页边缘留有被炭火熏黑的空白，供读者记录自己的灰烬坐标。作者在跋文中提醒：灰烬交界的技法没有标准答案，只有烧剩下的答案。许多抄本的末页都沾着不同颜色的灰烬，那是前人练习时留下的印记。此抄本曾被余烬烫穿数页，缺失处反而逼迫读者用自己的经验补全。

## 设计意图

为死灵法师提供灰烬主题召唤技能，强化亡灵体系与异界环境的结合。
