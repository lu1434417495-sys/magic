# 《灰烬誓约书》

## 书籍内容

《灰烬誓约书》记录的宣誓仪式需要在交界余火前进行，宣誓者必须把手伸入余火中直到感受到疼痛，才能把誓约烙印在灵魂上。作者强调，真正的誓约不是对神的承诺，而是对自己选择的确认。书中详细记录了三种基本誓约：守护誓约提升防御，复仇誓约提升攻击，牺牲誓约提升治疗能力。每一种誓约都有特定的誓言词，念错一个字都会让誓约失效。第二章讲解了誓约的代价：获得加成的同时，宣誓者会受到某种限制，比如守护誓约期间不能主动撤退。书末有一幅被烧焦的插图，显示一名骑士跪在余火前，配文："誓约一旦立下，灰烬即为见证。" 誓约书强调，立下誓约时必须大声说出，否则余火无法识别。作者记录了一个失败案例：一位骑士在心中默念誓约，结果誓约生效了一半，加成来了，限制也来了，但他无法解除，因为余火没有"听到"解除的誓词。

## 设计意图

为战士与圣骑士提供有限制的高收益状态技能，强化角色扮演。
