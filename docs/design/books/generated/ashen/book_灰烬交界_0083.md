# 《灰烬术士的契约书》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0083`
- **关联技能**：`ashen_pact`
- **使用效果**：阅读后解锁 `ashen_pact`；若已学会，提升 `current_mastery +140`，并降低与灰烬灵体契约时的反噬伤害。
- **阅读要求**：角色职业标签含 `warlock` 或 `mage`；基础 `智力 ≥ 12` 且 `意志 ≥ 11`。
- **稀有度**：史诗（Epic）
- **建议投放**：禁书区、灰烬邪教密室、异界裂隙宝箱。

## 书籍内容

契约书记录了与灰烬交界中古老存在缔结契约的条款与仪式。作者强调，灰烬中的存在不在乎金币或鲜血，它们只愿意接受“记忆”或“情感”作为代价。书中列出三条基本法则：契约必须口头念出、必须写明期限、必须指定交付方式。核心章节教授如何辨认契约对象的真正名字，因为一个错误的音节会让契约转向施术者自己。作者警告，最危险的条款往往是“永远”这个词。练习者需先与一个弱小的灰烬存在签订一份只持续一日的临时契约。尾页写着：“在灰烬里，签名之前先想好自己还有什么可烧。”书页边缘留有被炭火熏黑的空白，供读者记录自己的灰烬坐标。作者在跋文中提醒：灰烬交界的技法没有标准答案，只有烧剩下的答案。许多抄本的末页都沾着不同颜色的灰烬，那是前人练习时留下的印记。

## 设计意图

为术士/法师提供异界契约机制入口，深化灰烬交界的神秘与危险氛围。
