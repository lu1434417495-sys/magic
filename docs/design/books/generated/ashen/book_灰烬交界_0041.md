# 《灰烬刻印术》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0041`
- **关联技能**：`ashen_seal`
- **使用效果**：阅读后解锁 `ashen_seal`；若已学会，提升 `current_mastery +130`，并提高刻印持续时间 1 回合。
- **阅读要求**：角色职业标签含 `mage` 或 `priest`；基础 `智力 ≥ 11` 或 `意志 ≥ 11`。
- **稀有度**：稀有（Rare）
- **建议投放**：符文工坊、大教堂地下、封印任务奖励。

## 书籍内容

《灰烬刻印术》教导如何用交界灰烬在地面、武器或生物身上绘制具有魔法效果的刻印。刻印可以强化、封印、或触发特定的法术效果。作者强调，刻印最重要的是稳定性：一个不稳定的刻印可能在绘制过程中反噬施术者。书中详细讲解了刻印的基本结构：核心符文决定效果，边界符文控制范围，连接符文维持能量流动。第二章讨论了不同材质对刻印的影响：金属表面传导性好但容易失控，石材稳定但启动慢，生物皮肤最灵活但风险最高。书的后半部分附有二十七个基础刻印图案，每个都标注了绘制顺序和常见错误。书末警告："刻印不是纹身，是把自己一部分意志留在世界上。" 刻印术强调，刻印必须在完成后的三个呼吸内激活，否则灰烬会干燥失效。这个限制使得刻印术无法在战前过早布置，必须掐准时机。书中提供了一种延长刻印有效期的方法：在刻印表面覆盖一层薄薄的余火油脂。

## 设计意图

为法师与圣职提供增益/封印/陷阱类技能，强化战术准备与阵地。
