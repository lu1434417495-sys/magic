# 《燃灰步虚经》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0040`
- **关联技能**：`ashen_void_step`
- **使用效果**：阅读后解锁 `ashen_void_step`；若已学会，提升 `current_mastery +160`，并减少步虚的冷却时间 1 回合。
- **阅读要求**：角色职业标签含 `monk` 或 `assassin`；基础 `敏捷 ≥ 13` 或 `感知 ≥ 12`。
- **稀有度**：史诗（Epic）
- **建议投放**：武僧隐修院、暗杀公会禁地、传说级宝箱。

## 书籍内容

《燃灰步虚经》记载的是一种高深的移动技巧，让使用者能在短时间内把身体化为灰烬般的微粒，穿过实体障碍或攻击。作者强调，步虚不是真正的消失，而是把身体分散到周围的灰烬中再重新凝聚。这种技巧极其危险：如果在步虚过程中被打断，使用者会永远失去一部分身体。书中详细讲解了步虚前的准备：必须先让自己进入一种极度平静的状态，情绪波动会直接影响重新凝聚的成功率。第二章讨论了步虚的距离限制：初学者只能移动三五步，大师可以穿过整道墙壁。书的后半部分记录了多位修行者的经验，其中一人写道："每次步虚后，我都会少记得一些事情。我不知道这是代价，还是提醒。" 步虚经的练习被作者称为"在生与死之间散步"。每一次步虚，练习者都会短暂地体验到身体不再完整的奇异感觉。作者警告，频繁步虚会让人对"拥有实体"产生淡漠，最终可能主动选择停留在灰烬状态中。

## 设计意图

为高机动职业提供高端位移/穿越技能，强调高风险高回报。
