# 《燃烬一击诀》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0034`
- **关联技能**：`ashen_finisher`
- **使用效果**：阅读后解锁 `ashen_finisher`；若已学会，提升 `current_mastery +160`，并对生命值低于 20% 的目标提升 8% 伤害。
- **阅读要求**：角色职业标签含 `warrior` 或 `assassin`；基础 `力量 ≥ 12` 或 `敏捷 ≥ 12`。
- **稀有度**：稀有（Rare）
- **建议投放**：竞技场冠军奖励、刺客公会最高机密、世界任务掉落。

## 书籍内容

《燃烬一击诀》是灰烬交界最冷酷的战技之一，专门用于结束已经奄奄一息的目标。作者认为，最后一击需要的不是最强的力量，而是最准确的判断。书中强调，燃烬一击必须在敌人露出"灰烬时刻"——即生命力最低、防御最松懈的瞬间——出手。过早会浪费机会，过晚会错失良机。第二章讲解了如何在连招中制造灰烬时刻：通过连续的压制让敌人无法恢复，然后在对方动作结束的刹那完成终结。书的后半部分收录了多位战士对"仁慈"的思考，因为燃烬一击一旦出手几乎不会留下活口。书末有一句话被血浸透："让敌人带着余温死去，是对战斗最后的尊重。" 燃烬一击诀建议练习者在平时训练中使用木桩，但要在木桩上标记出"灰烬时刻"的位置。只有当连续一百次都能在正确位置击中时，才可以在实战中使用这一击。作者警告，实战中的敌人不会站着不动，但这个训练能培养出手感。

## 设计意图

为爆发型近战职业提供斩杀技能，强化战斗收尾能力。
