# 《灰烬净化仪式》

- **关联技能**：`ashen_purify`

## 书籍内容

《灰烬净化仪式》记录的并不是消灭邪恶，而是将被灰烬污染的土地恢复到可以承受生命状态的过程。仪式需要一个圣职者跪在污染中心，用圣火点燃一小撮交界灰烬，然后让燃烧后的灰烬随风飘散。作者警告，净化不是瞬间完成的，被污染越严重，仪式需要的时间越长。书中详细记录了各种污染类型的特征：有的是魔物尸体腐烂形成的，有的是诅咒长期积累形成的，还有的是战败者怨念凝聚形成的。第二章讲解了如何在仪式过程中保护自己：必须保持呼吸平稳，任何恐惧都会让仪式失败。书末附有一张净化后的土地检测方法，以及一句圣骑士的誓言："我燃尽的是污秽，留下的是净土。"净化仪式需要准备的材料出乎意料地简单：一小撮交界灰烬、一滴施术者自己的血、和一段真诚的祷文。
