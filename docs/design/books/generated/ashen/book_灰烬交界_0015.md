# 《灰烬冲锋要诀》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0015`
- **关联技能**：`ashen_charge`
- **使用效果**：阅读后解锁 `ashen_charge`；若已学会，提升 `current_mastery +130`，并使冲锋路径上的敌人受到短暂灼烧效果。
- **阅读要求**：角色职业标签含 `warrior` 或 `knight`；基础 `力量 ≥ 10`。
- **稀有度**：精良（Uncommon）
- **建议投放**：骑士训练营、灰烬交界前哨、突破任务奖励。

## 书籍内容

灰烬冲锋不是直线奔跑，而是一次被余火推动的冲撞。书中要求练习者在冲锋前深吸一口气，然后在呼气的瞬间启动，让身体像一支被点燃的箭一样射出。作者把冲锋分成三段：起步要快，中段要稳，末段要狠。最危险的是中段，因为这时练习者速度最快但控制力最弱，容易被侧翼攻击打偏方向。书中建议在冲锋时双眼盯住目标的胸口而非脸部，因为胸口是最稳定的参照点。练习者还需要学会在冲锋结束后立刻转入防御姿态，因为惯性会让身体短暂失衡。书末有一幅失败的示意图：一名骑士冲进敌阵太深，被包围在灰烬中，配文："冲过去是勇气，停下来是愚蠢。"书中把灰烬冲锋的末段称为"落点审判"，因为选择落点决定了这次冲锋是成功还是自杀。作者建议练习者在冲锋前用余火标记临时落点，这个落点必须在敌人的侧翼或背后。

## 设计意图

为前排职业提供突进型战技，兼具位移与小范围持续伤害。
