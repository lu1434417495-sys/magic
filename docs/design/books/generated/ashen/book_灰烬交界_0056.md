# 《灰雾遮蔽手册》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0056`
- **关联技能**：`ashen_smoke_screen`
- **使用效果**：阅读后解锁 `ashen_smoke_screen`；若已学会，提升 `current_mastery +130`，并延长灰雾持续 1 回合。
- **阅读要求**：角色职业标签含 `rogue` 或 `ranger`；基础 `敏捷 ≥ 10`。
- **稀有度**：精良（Uncommon）
- **建议投放**：盗贼公会密室、灰烬交界斥候营地、黑市商人。

## 书籍内容

手册教授如何利用灰烬交界的浮灰制造临时遮蔽。作者认为，灰雾不是单纯的烟，而是带有异界性质的微粒，能在短时间内扭曲光线与声音。书中先讲如何收集“轻灰”——那种悬浮在空中、尚未落地的细灰，因为它比沉积灰更容易被扰动。然后讲投掷位置：必须在敌人视线高度偏下的位置引爆，让灰雾向上弥漫。作者警告，灰雾对敌我同样有效，因此使用者必须提前记住地形与出口方向。练习时需在灰雾中闭眼穿行十步而不偏离。尾页题词：“让别人在雾里找你，是撤退最好的礼仪。”书页边缘留有被炭火熏黑的空白，供读者记录自己的灰烬坐标。作者在跋文中提醒：灰烬交界的技法没有标准答案，只有烧剩下的答案。许多抄本的末页都沾着不同颜色的灰烬，那是前人练习时留下的印记。此抄本曾被余烬烫穿数页，缺失处反而逼迫读者用自己的经验补全。

## 设计意图

为机动职业提供灰烬环境控场工具，把异界微粒转化为战术烟雾。
