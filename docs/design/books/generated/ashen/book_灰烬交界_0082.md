# 《灰烬狂暴：燃血怒》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0082`
- **关联技能**：`ashen_berserk`
- **使用效果**：阅读后解锁 `ashen_berserk`；若已学会，提升 `current_mastery +150`，并令狂暴状态下对灼伤目标的伤害提高。
- **阅读要求**：角色职业标签含 `berserker` 或 `warrior`；基础 `力量 ≥ 12` 且 `体质 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：狂战士训练场、灰烬竞技场奖品、部落传承任务。

## 书籍内容

燃血怒教狂战士如何利用灰烬中的残余热量点燃自己的战斗本能。作者认为，真正的狂暴不是失去理智，而是把恐惧和犹豫全部烧成推动肌肉的燃料。书中把进入燃血怒分为“引火、升温、爆发”三阶段，每个阶段都有对应的呼吸节奏。核心章节警告，必须在战斗前划定“熄火线”——一个让自己停止杀戮的信号，否则燃血怒会把使用者也烧成灰烬。练习者需在低温余烬中感受热度如何影响肌肉紧张度。尾页题词：“怒火烧敌人，也烧自己；能熄灭的怒，才是真正的武器。”书页边缘留有被炭火熏黑的空白，供读者记录自己的灰烬坐标。作者在跋文中提醒：灰烬交界的技法没有标准答案，只有烧剩下的答案。许多抄本的末页都沾着不同颜色的灰烬，那是前人练习时留下的印记。此抄本曾被余烬烫穿数页，缺失处反而逼迫读者用自己的经验补全。

## 设计意图

为狂战士提供灰烬主题狂暴技能，用火焰意象强化职业高风险高回报定位。
