# 《跳劈落点学》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0166`
- **关联技能**：`ashen_leaping_cleave`
- **使用效果**：阅读后提升 `ashen_leaping_cleave` `current_mastery +130`，并解锁：使用该技能击杀敌人后立即刷新冷却。
- **阅读要求**：已学会 `ashen_leaping_cleave`；基础 `力量 ≥ 12`。
- **稀有度**：稀有（Rare）
- **建议投放**：断桥营寨精英训练场、远古战士传承、Boss 掉落。

## 书籍内容

作者把跳劈比喻为"从空中掷下一枚骰子"，落点决定了一切。书中用几何图示分析了战场上常见的敌人站位：密集阵型、分散阵型、护卫阵型、环形阵型，并为每种阵型提供了推荐落点。作者特别强调：跳劈的杀伤半径只有一格，但震慑范围要大得多，聪明的敌人会因为你起跳而主动散开，这时落点就要选在散开的中心。后半本讲武器选择：重剑适合中心砸击，长柄武器适合落地后横扫。最后一页只有一幅图，一个战士正好落在敌人阵型最脆弱的接缝处。书页间夹着一片碎裂的盾牌残片，据说是作者第一次成功跳劈时从敌人手中砸下来的。残片的边缘有烧灼痕迹，与书中描述的"中心砸击"完全吻合。盾牌残片的边缘与书页接触的地方留下了一道浅灰色的擦痕，像是不愿被忘记的战斗记忆。

## 设计意图

提升跳劈重斩的战略价值，奖励精准进场与击杀连携。
