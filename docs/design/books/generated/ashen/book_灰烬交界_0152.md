# 《断桥营寨盾反手札》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0152`
- **关联技能**：`ashen_shield_parry`
- **使用效果**：阅读后解锁 `ashen_shield_parry`；若已学会，提升 `current_mastery +140` 并减少该技能首次使用 stamina 消耗 1 点。
- **阅读要求**：已装备盾牌；基础 `体质 ≥ 9`。
- **稀有度**：普通（Common）
- **建议投放**：断桥营寨军械库、老兵遗物、盾卫训练任务奖励。

## 书籍内容

手札开篇只有一句话：盾不是墙，是一扇只开一次的门。作者 anonymous 盾卫把盾反拆成读势、沉肩、开门三步。读势不是看刀，而是看敌人的肩与胯；沉肩让反震力沿小腿灌进地面；开门则是在接触瞬间顺势滑开一寸，把敌人重心扯到空处。手札后半画满摔倒的小人，分别标注"早了""晚了""对了"。它还特别提醒：反制成功后不要急着追击，应先踏出小半步确认对方真的失衡。最后一页被撕去大半，只剩半行字：真正危险的，是你爱上那一下反震的快感。书脊处嵌着半片断裂的盾甲，表面有一道几乎穿透的斩痕，旁边用炭笔写着"它救过我一次"。手札的装订线是用皮绳重新穿过的，原线早已在无数次翻阅中磨断。皮绳的末端打着几个奇怪的结，作者注释说这是"盾卫结"，每个结代表一次成功的盾反。 readers 被告知不要解开这些结，因为它们记录了手札本身的历史。书脊处的皮绳在潮湿天气会散发出淡淡的皮革味。

## 设计意图

把盾反框定为读招与反制，服务战士/圣骑士前排定位。
