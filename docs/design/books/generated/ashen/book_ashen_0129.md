# 《灰烬祭司的祈火仪式》

## 书籍内容

祈火仪式是灰烬祭司用来与异界之火沟通的方式，不是为了召唤火焰，而是为了确认火仍然记得自己。仪式需要一堆特殊的灰烬、一段固定的祷词和一个愿意承认自己渺小的人。书中详细描述了仪式的十二个步骤，每一步都对应火焰的一种品质：点燃时的勇气、燃烧时的专注、熄灭时的接受。作者警告，最容易出错的步骤是"接受"——很多人无法真心接受火焰终将熄灭，结果让仪式变成一场失控的纵火。书的末尾附有几段不同方言的祷词变体，以及一句反复强调的话："我们不是火的主人，我们只是火的记忆。"仪式中使用的灰烬必须是自然熄灭的火焰所留，不能用人为扑灭的火灰。祭司们相信，被强行熄灭的火会在灰中留下怨恨，干扰仪式的纯净。仪式结束后，祭司会把剩余的灰烬装入一个小袋随身携带，直到下一次仪式才重新使用，称为"续火"。
