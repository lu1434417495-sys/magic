# 《余烬步法详解》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0052`
- **关联技能**：`ashen_step`
- **使用效果**：阅读后解锁 `ashen_step` 进阶模块；若已学会，提升 `current_mastery +130`，并减少在松软灰壳上移动的速度惩罚。
- **阅读要求**：无职业限制；基础 `敏捷 ≥ 9`。
- **稀有度**：普通（Common）
- **建议投放**：灰烬交界入口营地、通用战技商人、新兵补给箱。

## 书籍内容

详解从无数斥候的尸骨中总结出来，专门教人如何在会塌陷的灰壳上行走。作者把落脚点分为“实、虚、借”三类：实点是下方的硬地，虚点是空心的灰壳，借点则是可以短暂承重的碎石。书中要求练习者先用脚尖轻探，再让重心缓慢前移，整个过程不能超过半秒。作者用大量图示展示错误的重心轨迹，并指出最常见死因是第二步踩得太快。进阶章节讲如何在余烬未熄的地面上借热上升气流完成短距离跳跃。尾页只有一句话：“在灰烬里，走得慢不是怯懦，是还活着。”书页边缘留有被炭火熏黑的空白，供读者记录自己的灰烬坐标。作者在跋文中提醒：灰烬交界的技法没有标准答案，只有烧剩下的答案。许多抄本的末页都沾着不同颜色的灰烬，那是前人练习时留下的印记。此抄本曾被余烬烫穿数页，缺失处反而逼迫读者用自己的经验补全。

## 设计意图

强化灰烬交界移动战技，把地形从阻碍转化为可读取的战术信息。
