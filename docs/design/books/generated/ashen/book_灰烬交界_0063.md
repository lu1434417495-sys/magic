# 《灰烬护甲编织法》

## 基础信息

- **关联技能**：`ashen_armor`

## 书籍内容

编织法教人把湿灰与余烬混合后涂抹在身上，形成一层临时护甲。作者强调，灰烬护甲的关键是“湿度”：太干会散落，太湿则无法固化。书中给出配方三份灰配一份水，搅拌至糊状后从四肢末端向躯干涂抹。护甲在干燥后会形成脆硬外壳，能吸收一次或两次轻击。作者警告，灰烬护甲会影响关节灵活性，因此不适合需要精细动作的战斗。移除时不能用蛮力撕扯，而需用水浇软。尾页画着一个人形轮廓，关节处特意留空，配文：“保护躯壳，别锁住灵魂。”书页边缘留有被炭火熏黑的空白，供读者记录自己的灰烬坐标。作者在跋文中提醒：灰烬交界的技法没有标准答案，只有烧剩下的答案。许多抄本的末页都沾着不同颜色的灰烬，那是前人练习时留下的印记。此抄本曾被余烬烫穿数页，缺失处反而逼迫读者用自己的经验补全。
