# 《灰烬诅咒：蚀甲术》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0065`
- **关联技能**：`ashen_curse`
- **使用效果**：阅读后解锁 `ashen_curse`；若已学会，提升 `current_mastery +130`，并延长蚀甲效果持续时间 1 回合。
- **阅读要求**：角色职业标签含 `mage`、`warlock` 或 `sorcerer`；基础 `智力 ≥ 12`。
- **稀有度**：稀有（Rare）
- **建议投放**：黑市禁书商人、灰烬邪教据点、异界裂隙宝箱。

## 书籍内容

蚀甲术把灰烬交界的腐蚀特性凝聚成针对护甲的诅咒。作者指出，异界灰烬会缓慢啃噬金属与皮革，就像时间在灰烬中加速流逝。书中教授如何把一把余烬握在掌心，默念目标护甲的材质名称，再扬灰出手。诅咒生效后，敌护甲表面会出现细密的灰斑，防御力逐渐下降。作者警告，施术者自己的衣物也会受到轻微腐蚀，因此施法时应穿旧衣或专用法袍。练习者需在废弃盔甲上测试灰斑扩散速度。尾页写着：“让敌人的铠甲先老，比让他先死更有趣。”书页边缘留有被炭火熏黑的空白，供读者记录自己的灰烬坐标。作者在跋文中提醒：灰烬交界的技法没有标准答案，只有烧剩下的答案。许多抄本的末页都沾着不同颜色的灰烬，那是前人练习时留下的印记。此抄本曾被余烬烫穿数页，缺失处反而逼迫读者用自己的经验补全。

## 设计意图

为黑暗法系提供灰烬主题削弱技能，把环境腐蚀特性武器化。
