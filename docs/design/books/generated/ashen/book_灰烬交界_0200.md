# 《灰烬交界传奇：焚尽咒术师》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0200`
- **关联技能**：`ashen_black_fire_orb`
- **使用效果**：阅读后提升 `ashen_black_fire_orb` `current_mastery +200`，并解锁称号`焚尽者`，装备时黑火球 MP 消耗降低 1 点。
- **阅读要求**：已学会 `ashen_black_fire_orb`；基础 `智力 ≥ 15` 且 `意志 ≥ 12`。
- **稀有度**：传说（Legendary）
- **建议投放**：沉钟书库禁书最深处、传说级咒术任务链、隐藏 Boss 掉落。

## 书籍内容

这本书讲述了一位咒术师为了封印一道不断扩大的裂隙，把自己连同整座城镇一起烧成灰烬的故事。她没有使用传统的封印术，而是创造了一种能够"烧掉空间本身"的黑火，把裂隙周围的现实一起焚毁，从而阻止了异界力量的涌入。书中详细记录了这种禁术的代价：施术者会逐渐失去形体，最终变成一团永恒燃烧的黑火。最后几页是她在消失前写下的最后一句话：我不后悔点燃自己，我只后悔没有更早学会控制它。这本书会让读者的指尖在翻页时感到一阵灼热的刺痛。据说每个读完它的人，都会在梦中看到一座燃烧的城镇，和城镇中央一个越来越小的身影。有人试图靠近那个身影，但总是在触及之前醒来，手中多了一块温热的炭屑。那块炭屑在掌心会保持温热约十秒钟，然后化作普通的灰尘。

## 设计意图

作为传奇级咒术书籍，提供高额熟练度与称号奖励，承载黑暗咒术的终极代价。
