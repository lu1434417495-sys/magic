# 《灰烬先知：灰梦占》

## 书籍内容

灰梦占教人如何在灰烬交界的余温中入睡，并接收来自交界的模糊预兆。作者认为，灰烬是世界燃烧后的记忆，而梦境是读取这些记忆的通道。书中要求练习者在睡前用余烬在额头上画一个淡淡的灰印，然后躺在硬地上，让后背感受地面的温度。梦境通常以火、灰、裂缝、旧建筑的形象出现，需要练习者自己解读。作者警告，灰梦不能频繁使用，因为交界的信息会侵蚀做梦者的自我边界。练习者需记录连续七次梦境并找出共同符号。尾页题词：“梦是灰烬在夜里写的信，不要每一封都回。”书页边缘留有被炭火熏黑的空白，供读者记录自己的灰烬坐标。作者在跋文中提醒：灰烬交界的技法没有标准答案，只有烧剩下的答案。许多抄本的末页都沾着不同颜色的灰烬，那是前人练习时留下的印记。
