# 《灰烬制衡术》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0045`
- **关联技能**：`ashen_balance`
- **使用效果**：阅读后解锁 `ashen_balance`；若已学会，提升 `current_mastery +120`，并提高制衡反击的伤害 5%。
- **阅读要求**：角色职业标签含 `monk` 或 `warrior`；基础 `敏捷 ≥ 10` 或 `感知 ≥ 10`。
- **稀有度**：精良（Uncommon）
- **建议投放**：武僧寺院、平衡试炼、武道大会奖励。

## 书籍内容

《灰烬制衡术》教导练习者如何在敌人的力量与自己之间找到平衡点，然后用最小的力量造成最大的效果。作者用秤来比喻：敌人的攻击是重物，你的反击是秤砣，关键是找准支点。书中详细讲解了三种制衡方式：上挑卸力、侧引偏转、下沉反制。每一种都需要精确判断敌人发力的方向和时机。第二章讨论了心态：制衡时不能想着打败敌人，而要想着利用敌人的力量。书的后半部分附有多个对战图解，展示如何用小动作化解大攻击。书末有一句话："不以力抗力，而以灰借力。"制衡术的高级应用是"双点制衡"：同时接触敌人的两个发力点，让它们相互抵消。这种技巧需要极高的感知和反应速度，但一旦成功，可以让敌人的强力攻击完全失效，甚至让敌人自己摔倒。作者提醒，制衡不是示弱，而是用敌人的力量写下自己的节奏。

## 设计意图

为武僧与战士提供反击型防御技能，强化技巧型战斗。
