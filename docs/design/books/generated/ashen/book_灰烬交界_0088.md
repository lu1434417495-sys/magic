# 《灰烬骑士：焚誓斩》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0088`
- **关联技能**：`ashen_knight_oath`
- **使用效果**：阅读后解锁 `ashen_knight_oath`；若已学会，提升 `current_mastery +150`，并令对违背誓言的敌人伤害提高。
- **阅读要求**：角色职业标签含 `knight` 或 `paladin`；基础 `力量 ≥ 12` 且 `意志 ≥ 12`。
- **稀有度**：史诗（Epic）
- **建议投放**：灰烬法院核心档案、骑士团传承任务、高阶审判庭宝箱。

## 书籍内容

焚誓斩是一种把骑士誓言与灰烬火焰结合的高阶战技。作者认为，誓言是未被火焰烧尽的语言，而违背誓言者的血液则是最好的引火物。书中要求骑士在每次出战前向自己的信条立誓，并把誓言词刻入剑身。当剑命中背誓者时，刻字会短暂发光并引发灼烧。核心章节讲解如何保持誓言的纯净：任何一丝私欲都会让焚誓斩失效。作者警告，这把剑也会记录骑士自己的违背，因此使用者必须比敌人更诚实。练习者需在圣火前重新立誓并挥剑。尾页写着：“你的剑有多亮，取决于你的誓言有多真。”书页边缘留有被炭火熏黑的空白，供读者记录自己的灰烬坐标。作者在跋文中提醒：灰烬交界的技法没有标准答案，只有烧剩下的答案。许多抄本的末页都沾着不同颜色的灰烬，那是前人练习时留下的印记。

## 设计意图

为骑士/圣骑士提供灰烬主题誓言斩杀技能，强化道德约束与职业仪式感。
