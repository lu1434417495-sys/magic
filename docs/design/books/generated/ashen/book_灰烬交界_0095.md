# 《灰烬武僧：灰衣禅》

- **书籍 ID**：`book_灰烬交界_0095`
- **关联技能**：`ashen_monk_stance`

- **阅读要求**：角色职业标签含 `monk` 或 `martial_artist`；基础 `敏捷 ≥ 11` 且 `意志 ≥ 10`。

## 书籍内容

灰衣禅是一种把灰烬的“无执”理念融入武僧架势的法门。作者认为，灰烬曾是树、曾是屋、曾是人，现在什么都不是；武僧应学习这种放下。书中把架势分为“落灰、扬灰、定灰”三式，分别对应防御、闪避与反击。核心章节讲解如何在切换架势时让身体像灰烬一样不可捉摸：不是快，而是让敌人的预期落空。作者警告，灰衣禅不是逃避，而是在放下中保持警觉。练习者需在余烬旁连续完成一百次架势切换而不让灰烬扬起。尾页写着：“像灰一样轻，才能像灰一样不可抓住。”书页边缘留有被炭火熏黑的空白，供读者记录自己的灰烬坐标。作者在跋文中提醒：灰烬交界的技法没有标准答案，只有烧剩下的答案。许多抄本的末页都沾着不同颜色的灰烬，那是前人练习时留下的印记。此抄本曾被余烬烫穿数页，缺失处反而逼迫读者用自己的经验补全。

## 设计意图

为武僧系提供灰烬主题架势技能，强调闪避、转换与心性修炼。
