# 《灰烬裂变原理》

## 书籍内容

《灰烬裂变原理》研究的是如何让一个灰烬法术在命中后分裂成多个次级效果。作者用投石入水来类比：主法术是石头，次级效果是涟漪，而涟漪可以触发更远处的连锁反应。书中详细讲解了裂变点的控制：太早裂变会导致主效果太弱，太晚裂变则次级效果无法形成。第二章讨论了不同材质的敌人对裂变效果的影响：金属护甲会让裂变向四周均匀扩散，而软组织则会让裂变集中向深处穿透。书的后半部分附有复杂的数学公式和多个实验记录，记录了施术者如何在一次裂变中同时伤害到三个目标。书末警告："裂变是贪婪的艺术，贪多会让你什么都抓不住。" 裂变原理的数学部分被作者故意写得晦涩难懂，因为他认为裂变不适合心智不够稳定的人学习。书中有一页满是算式和符号，页边有一行小字："如果你只看懂数字，说明你还没准备好。"
