# 《烬焰双刀舞》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0073`
- **关联技能**：`ashen_twin_blades`
- **使用效果**：阅读后解锁 `ashen_twin_blades`；若已学会，提升 `current_mastery +140`，并令双刀连击命中时叠加余烬燃烧层数。
- **阅读要求**：角色职业标签含 `rogue` 或 `warrior`；基础 `敏捷 ≥ 12`。
- **稀有度**：稀有（Rare）
- **建议投放**：灰烬竞技场奖品、双刀流派传承、黑市商人。

## 书籍内容

双刀舞是一种把灰烬附着在两把短刃上交替攻击的战技。作者认为，双刀的优势不在单次伤害，而在让敌人始终处于“刚被灼伤、又迎来下一次灼伤”的节奏中。书中把连击分为“引、缠、爆”三段：引是第一次轻击附着灰粒，缠是第二次攻击把灰粒推入伤口，爆是在第三击时让余烬内燃。作者强调，双刀使用者必须左右手同样灵活，否则连击会在转换时露出破绽。练习者需用木刀在涂满灰的靶上完成连续十组三段击。尾页题词：“两把刀，一场不会熄灭的小火。”书页边缘留有被炭火熏黑的空白，供读者记录自己的灰烬坐标。作者在跋文中提醒：灰烬交界的技法没有标准答案，只有烧剩下的答案。许多抄本的末页都沾着不同颜色的灰烬，那是前人练习时留下的印记。此抄本曾被余烬烫穿数页，缺失处反而逼迫读者用自己的经验补全。

## 设计意图

为高机动近战职业提供灰烬主题连击技能，强调节奏与异常状态叠加。
