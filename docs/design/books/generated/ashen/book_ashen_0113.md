# 《余烬兽医：灰烬兽驯养手稿》

## 基础信息

- **书籍 ID**：`book_ashen_0113`
- **关联技能**：`ashen_beast_tending`
- **使用效果**：阅读后解锁 `ashen_beast_tending`；若已学会，提升 `current_mastery +100`，并令下一次遭遇灰烬兽时获得一次安抚判定机会。
- **阅读要求**：职业标签含 `ranger` 或 `beastmaster`；基础 `感知 ≥ 10` 且 `魅力 ≥ 8`。
- **稀有度**：稀有（Rare）
- **建议投放**：灰烬兽巢据点、驯兽师传承任务、边境游商稀有货物。

## 书籍内容

这份手稿来自一位在灰烬交界生活了二十年的驯兽师，她认为灰烬兽不是怪物，只是被迫适应了毁灭环境的普通生物。书中详细记录了十余种灰烬兽的体温节律、进食偏好和受惊信号。她指出，大多数灰烬兽的攻击性源于体温失衡，而不是饥饿；一碗温度适中的余烬水往往比一块生肉更能安抚它们。手稿中间画满了简笔动物图，每张图旁边都标注着"摸这里"、"不要碰这里"、"它这样做时是在求救"。最感人的一章是关于一只失去前爪的灰烬狼，作者花了三个月教它重新奔跑。书的末尾写着："在灰烬里，温柔不是弱点，是唯一不会被烧掉的工具。"手稿中强调，灰烬兽对声音的敏感远胜于视觉。作者建议驯兽师用低沉平稳的哼唱与兽类交流，而不是高亢的呼喊。一曲适当的摇篮调往往比一根肉干更能建立信任。

## 设计意图

为游侠/驯兽师提供异界生物互动技能，拓展非战斗解决路径与伙伴养成空间。
