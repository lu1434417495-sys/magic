# 《燃灰步法：逐火行》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0064`
- **关联技能**：`ashen_flame_walk`
- **使用效果**：阅读后解锁 `ashen_flame_walk`；若已学会，提升 `current_mastery +140`，并令穿越余烬区域时不再受到地面灼烧伤害。

- **建议投放**：余烬祭所高阶传授、灰烬交界核心营地、传说游商。

## 书籍内容

逐火行是一种在余烬未熄的地面上快速穿行的步法。作者认为，火焰不会灼伤那些懂得与它同频移动的人。书中把步法拆成“点、掠、跃”三式：点是在热区边缘短暂落脚，掠是用脚掌边缘滑过温度较低的区域，跃则是在热流上升最强处借力腾空。作者强调，逐火行不是无视火焰，而是把每次落脚都变成与地面的谈判。练习者需先赤脚踩过低温余烬，再逐步挑战更高温度。书中还记录了如何判断地面下是否有暗火：看灰烬颜色，偏白则安全，偏红则危险。尾页题词：“火追逐静止的东西。”书页边缘留有被炭火熏黑的空白，供读者记录自己的灰烬坐标。作者在跋文中提醒：灰烬交界的技法没有标准答案，只有烧剩下的答案。许多抄本的末页都沾着不同颜色的灰烬，那是前人练习时留下的印记。此抄本曾被余烬烫穿数页，缺失处反而逼迫读者用自己的经验补全。
