# 《灰烬流星投掷术》

## 基础信息

- **书籍 ID**：`book_灰烬交界_0055`
- **关联技能**：`ashen_meteor_throw`
- **使用效果**：阅读后解锁 `ashen_meteor_throw`；若已学会，提升 `current_mastery +120`，并提高余烬弹丸的爆炸半径。
- **阅读要求**：无职业限制；基础 `力量 ≥ 9`。
- **稀有度**：普通（Common）
- **建议投放**：灰烬交界入口营地、游荡商人、地城杂物箱。

## 书籍内容

这本小册子来自一名在灰烬中拾荒的流浪者，教人把余烬捏成临时弹丸投掷出去。作者指出，余烬弹丸的威力不在于重量，而在于内部未熄的火星。书中把捏制手法分为“三压一旋”：先轻压让灰成团，再重压排出空气，最后旋转封口。投掷时需在出手瞬间用拇指划破丸壁，让空气进入引发爆燃。作者列出三种常见错误：捏得太实无法引爆、封口不严提前散落、出手太慢烧穿手套。练习者需先对着岩石投掷，直到能稳定制造小型闪光。尾页写着：“捡起的每一把灰，都可能是最后的火焰。”书页边缘留有被炭火熏黑的空白，供读者记录自己的灰烬坐标。作者在跋文中提醒：灰烬交界的技法没有标准答案，只有烧剩下的答案。许多抄本的末页都沾着不同颜色的灰烬，那是前人练习时留下的印记。此抄本曾被余烬烫穿数页，缺失处反而逼迫读者用自己的经验补全。

为所有职业提供低门槛灰烬环境消耗品技能，丰富探索与战斗中的即兴选择。
