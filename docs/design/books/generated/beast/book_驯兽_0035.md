# 《远古龙裔驯化》

## 基础信息

- **书籍 ID**：`book_驯兽_0035`
- **关联技能**：`beast_ancient_drake`
- **使用效果**：阅读后解锁 `beast_ancient_drake`；若已学会，提升该技能 `current_mastery +90`，并使远古龙裔的吐息伤害提高 15%。
- **阅读要求**：角色职业标签含 `warrior`、`mage` 或 `ranger`；基础 `体质 ≥ 12` 或 `意志 ≥ 12`。
- **稀有度**：史诗（Epic）
- **建议投放**：古龙巢穴探索、龙裔遗迹传承、传说驯兽师遗产任务。

## 书籍内容

《远古龙裔驯化》记载着与拥有稀薄龙血的飞行蜥蜴建立契约的古老技艺。作者坦言，龙裔永远不会被真正驯服，它们只是暂时认可了某个个体的实力。书中先讲解龙裔的骄傲：喂食时不能弯腰，必须让它主动来取；命令时不能用吼叫，必须用低语。中间章节介绍飞行骑乘的注意事项：龙裔的翅膀对气流变化极为敏感，骑手要学会用重心而非缰绳引导方向。后半本记录了龙裔吐息的训练：先用小型火焰或酸液目标练习，再逐步增加射程与威力。作者在最后写道："你与龙裔的关系，是火焰与持火者的关系。它照亮你，也可能烧死你。"卷末附有一张龙裔饮食禁忌表，警告某些食物会让它们的吐息失控或性格暴躁。作者还提醒，龙裔对金属味极为敏感，因此喂食器具最好使用木制或石制。书中还提到。

## 设计意图

作为史诗级驯兽目标，为高端玩家提供飞行与毁灭性吐息的单位，成为 build 的核心支柱。
