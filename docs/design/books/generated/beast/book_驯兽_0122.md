# 《野兽情绪共鸣》

## 基础信息

- **书籍 ID**：`book_驯兽_0122`
- **关联技能**：`beast_emotion_resonance`（待新增，标签 `beast`）
- **使用效果**：阅读后解锁 `beast_emotion_resonance`；若已学会，提升该技能 `current_mastery +110`，并使预判野兽攻击的准确率提高 10%。
- **阅读要求**：无职业限制；基础 `感知 ≥ 9`。
- **稀有度**：精良（Uncommon）
- **建议投放**：心灵学者塔、兽语者部落、梦境林地。

## 书籍内容

这本书进一步探讨如何感知并回应野兽的情绪波动。作者认为，愤怒往往源于恐惧，逃跑多半因为不安，而突然的攻击性可能是疼痛的信号。书中给出一张情绪-行为对照表，帮助读者从细微动作中读出真实状态。后半部分教授“情绪镜像”技巧：驯兽师先模仿野兽的呼吸与姿态，再逐渐放缓，用自己的平静带动对方平静下来。作者提醒，共鸣是双向的，如果驯兽师自身情绪混乱，野兽只会更加焦躁。书中建议在每次练习前进行五分钟的深呼吸，把当天的烦恼暂时留在练习场外。最末页收录了几位兽语者的手记，描述他们在共鸣中看到的颜色与温度。心灵学者塔与梦境林地把它当作进阶读物。书中最后写道，只有先让自己的情绪澄澈，才能映照出野兽真实的颜色。情绪共鸣的终点，是彼此不再需要猜测。

## 设计意图

深化情绪互动，让玩家在战斗外也能通过“共情”影响野兽状态。
