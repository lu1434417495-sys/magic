# 《野兽威慑姿态》

## 基础信息

- **书籍 ID**：`book_驯兽_0119`
- **关联技能**：`beast_intimidation_posture`（待新增，标签 `beast`）
- **使用效果**：阅读后解锁 `beast_intimidation_posture`；若已学会，提升该技能 `current_mastery +100`，并使对野兽威慑成功时降低其攻击欲望 1 回合。

## 书籍内容

有时驯兽师需要的不是亲近，而是让对方明白谁才是这片领地的主人。作者从站姿、眼神、呼吸与声音四个要素拆解威慑姿态，强调真正的威慑源于自信而非愤怒，过度挑衅反而会引发野兽的拼死反击。书中用多次巡林经历说明，面对猛兽时缓慢张开双臂、保持侧身、发出低沉而稳定的吼声，往往能让对方选择退却。后半部分讨论不同种类野兽对威慑的反应差异，例如群居动物会评估你是否值得挑战，而独居猎手更看重逃跑成本。作者建议先用体型较大的家畜或驯服野兽练习威慑姿态，等身体记忆形成后再面对真正的猛兽。最末页警告：威慑只对尚未进入狂暴状态的野兽有效，一旦见血，唯有战斗。边境守卫与猎人公会把它列为必修。作者认为，威慑不是炫耀力量，而是让对方保留退路。

## 设计意图

提供非战斗化解野兽敌意的手段，丰富探索中的选择与策略。
