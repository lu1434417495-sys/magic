# 《诱捕陷阱改良》

## 基础信息

- **关联技能**：`beast_trap_improve`（待新增，标签 `beast`）

## 书籍内容

书中批评传统捕兽陷阱过于追求杀伤而忽略捕获后的驯化价值。作者提出一套“低伤高捕”改良方案：用弹性索套代替铁齿，用布袋缓冲坠落，并在陷阱旁放置带有驯兽师气味的布条。书中详细说明不同体型野兽对应的陷阱尺寸与触发力度，强调陷阱越贴合目标，野兽受惊程度越低。后半部分讨论如何在捕获后快速接近，包括用食物转移注意、用布蒙眼降低视觉刺激，以及第一时间检查是否有严重外伤。作者还建议在陷阱附近设置遮蔽物，让被困野兽有地方躲藏，避免长时间暴露在开阔环境中造成持续恐慌。书中特别强调，捕获后最初的十分钟决定了未来能否驯化，急躁靠近往往会让所有努力白费。最末页附有一张改良陷阱零件清单，猎人协会把它列为必备案头资料。书中认为，善待捕获的野兽，是驯化真正的第一步。

## 设计意图

把“捕获”与“驯化”衔接起来，给偏好陷阱流的玩家提供可持续发展的路径。
