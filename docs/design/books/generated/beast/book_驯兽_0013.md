# 《夜行生物亲和》

## 基础信息

- **书籍 ID**：`book_驯兽_0013`
- **关联技能**：`beast_nocturnal_bond`
- **使用效果**：阅读后解锁 `beast_nocturnal_bond`；若已学会，提升该技能 `current_mastery +85`，并使夜行野兽伙伴在夜间获得 +5% 暴击率。
- **阅读要求**：角色职业标签含 `rogue` 或 `ranger`；基础 `感知 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：暗夜据点、墓地守夜人小屋、月下祭坛藏书。

## 书籍内容

《夜行生物亲和》教导读者如何与猫头鹰、蝙蝠、夜行狼等黑暗中的猎手建立联系。作者指出，夜行生物对光线、温度与突然声响极度敏感，因此驯兽师必须学会在黑暗中行动如幽灵。书中前半部分讲解夜间接近技巧：不使用火把、避免直视它们的眼睛、让自己的体温先稳定下来。中间章节介绍了利用回声与超声波沟通的方法，特别是与蝙蝠群协同侦察的要点。后半本记录了如何在夜间战斗中保护夜行伙伴的视力：避免己方施法者释放强光，提前标记敌人位置而非临时指点。作者在最后一页写道："白天属于人类，夜晚属于它们。你想在夜晚借用它们的力量，就要先学会成为夜晚的一部分。"书末附有一张夜行生物活动时间表，帮助驯兽师根据目标习性选择最佳接触时机。书末还提醒，夜行生物对月光格外敏感，满月时的训练效率往往高于无月之夜。

## 设计意图

为潜行与夜战玩法提供环境加成，让玩家在夜间任务中感受到夜行伙伴的独特优势。
