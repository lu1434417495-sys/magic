# 《魔兽核心解析》

## 基础信息

- **书籍 ID**：`book_驯兽_0034`
- **关联技能**：`beast_core_analyze`
- **使用效果**：阅读后解锁 `beast_core_analyze`；若已学会，提升该技能 `current_mastery +80`，并使击败魔兽后获得稀有材料的几率提高 10%。
- **阅读要求**：角色职业标签含 `mage` 或 `alchemist`；基础 `智力 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：炼金术士公会、魔法学院藏书、魔兽研究所奖励。

## 书籍内容

《魔兽核心解析》是一本关于如何安全提取与利用野兽体内魔力核心的技术手册。作者指出，魔兽之所以强大，是因为它们体内形成了能量聚合点，类似于简化版的魔法器官。书中先讲解核心的分类：元素型、血肉型、精神型与异界型，每种核心的提取方式都不同。中间章节介绍提取工具与防护：必须使用绝缘镊子、防护手套与稳定药剂，否则核心会在离体瞬间爆炸或腐化。后半本记录了核心的用途：制作药水、镶嵌武器、喂养特定野兽或作为法术材料。作者在最后警告："每一块核心都曾是某个生命的心跳。尊重它，否则它会反过来侵蚀你。"书末附有一张核心保存容器对照表，指出不同属性核心需要不同材质与温度的容器。书中还附有一张核心稳定药剂配方，用于延长核心离体后的保存时间。

## 设计意图

为生活技能与战斗掉落系统提供驯兽向接口，让击败野兽不仅是经验来源，也是资源循环的一环。
