# 《堕落野兽净化》

## 基础信息

- **书籍 ID**：`book_驯兽_0043`
- **关联技能**：`beast_corruption_purify`
- **使用效果**：阅读后解锁 `beast_corruption_purify`；若已学会，提升该技能 `current_mastery +80`，并使被净化的堕落野兽有 20% 几率成为临时友方单位。
- **阅读要求**：角色职业标签含 `priest` 或 `paladin`；基础 `信仰 ≥ 11`。
- **稀有度**：史诗（Epic）
- **建议投放**：光明神殿深处、净化者要塞、腐化之地任务奖励。

## 书籍内容

《堕落野兽净化》是一本关于如何将被腐化野兽从邪恶控制中解救出来的神圣手册。作者强调，堕落野兽本身往往是受害者，净化它们不仅是战斗需要，也是慈悲的体现。书中先讲解腐化识别：被腐化的野兽通常眼睛浑浊、行为违背本能、伤口不会正常愈合。中间章节介绍净化仪式：圣水、祷言与温和但坚定的光芒，必须持续到野兽眼中的浑浊完全散去。后半本记录了净化后的安置：大多数被净化野兽需要时间重新学习信任，不能立即投入战斗。作者在最后写道："净化不是消灭黑暗，而是给曾经光明的生命第二次选择。选择离开，或者选择与你同行。"书末附有一张净化后野兽康复观察表，帮助驯兽师判断它们是否已准备好重新融入自然或加入队伍。书中还提醒，净化后的野兽需要新的名字。

## 设计意图

为神圣职业提供独特的驯兽转换机制，让玩家能够将敌人转化为临时盟友，拓展战棋中的动态兵力变化。
