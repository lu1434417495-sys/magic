# 《野兽急救包扎》

## 基础信息

- **书籍 ID**：`book_驯兽_0112`
- **关联技能**：`beast_first_aid`（待新增，标签 `beast`）
- **使用效果**：阅读后解锁 `beast_first_aid`；若已学会，提升该技能 `current_mastery +80`，并使对受伤野兽急救的成功率提高 15%。
- **阅读要求**：无职业限制；基础 `感知 ≥ 7`。
- **稀有度**：普通（Common）
- **建议投放**：战地医师、探险队、猎人行会。

## 书籍内容

驯兽师不可能永远避免伙伴受伤，这本书就是为此准备的。作者按出血、骨折、烧伤、中毒四类常见伤情给出处理流程，并配有简明的包扎图示。书中特别指出，野兽在疼痛时会本能地咬向靠近者，因此急救前必须先进行安抚或固定。后半本介绍了多种野外可得的草药与替代品，例如嚼碎的蒲公英根可以临时止血，冰凉的湿泥能缓解轻度烫伤。作者还强调包扎后必须持续观察野兽是否有发热、拒食或伤口红肿等感染迹象，并及时更换敷料。对于受伤后仍具攻击性的猛禽，作者建议用头罩或布巾遮蔽其视线后再靠近，以减少应激。最末页是一份紧急携带清单，包括绷带、止血粉、夹板与镇静药剂。战地医师与探险队里的驯兽师常常在背包里塞一本，希望永远用不上它。作者写道，急救的速度有时比技术更能挽救伙伴的生命。

## 设计意图

增加伙伴生存维度，让玩家在战斗与探索中更珍惜自己的野兽同伴。
