# 《季节迁徙感知》

## 基础信息

- **书籍 ID**：`book_驯兽_0044`
- **关联技能**：`beast_migration_sense`
- **使用效果**：阅读后解锁 `beast_migration_sense`；若已学会，提升该技能 `current_mastery +75`，并使你在季节更替时提前 3 天感知到珍稀野兽群落的位置。
- **阅读要求**：角色职业标签含 `ranger` 或 `druid`；基础 `感知 ≥ 10`。

## 书籍内容

《季节迁徙感知》是一本教导驯兽师如何读懂大地与野兽共同书写的季节语言的古籍。作者认为，迁徙不是混乱的逃窜，而是自然界最精确的时间表。书中先讲解气候信号：某种鸟类的提前南飞预示寒流，某类鱼群的聚集暗示洪水，狼群的大规模移动则往往与魔力潮汐有关。中间章节介绍如何利用这些信息：在迁徙路径上设置安全通道、提前储备食物、在特定地点等待稀有野兽经过。后半本记录了与迁徙群落建立临时同盟的方法：为它们清理道路、提供水源，它们会在需要时回馈情报。作者在最后写道："读懂迁徙，你就读懂了大地的心跳。而野兽，只是心跳的回声。"书末附有一张四季迁徙预警信号清单，教导驯兽师从风向、植物花期与云层变化中捕捉前兆。作者还建议建立自己的观察笔记。

## 设计意图

为世界探索与事件预测玩法提供驯兽向能力，让玩家通过观察自然获得战略先机与稀有遭遇机会。
