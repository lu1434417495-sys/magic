# 《百兽之心》

## 书籍内容

百兽之心不是技能，而是一种境界。当驯兽师与无数野兽建立过真诚关系后，它们会把自己的一部分信任与智慧赠予你。书中描述了这种境界下的体验：能同时感知多只野兽的情绪，能理解它们没有说出口的需求，能在混乱战场上用一瞬间的目光稳定伙伴的心神。作者强调，通往百兽之心没有捷径，每一次失败、每一次离别都是必经之路。后半部分收录了历代兽语者的临终手记，提醒后人不要试图独占这份天赋，因为它属于所有生命。作者还建议把这份感悟传授给下一代学徒，让百兽之心在传承中不断生长。书中写道，拥有百兽之心的人永远不会孤单，因为森林、草原与山脉都会为他低语。世界树心与兽魂本源相传藏有此书的完整抄本。作者提醒，百兽之心越大，肩负的责任也越重。

## 设计意图

作为驯兽流的质变节点，让玩家真正感受到“与百兽同行”的宏大体验。
