# 《驯兽口令集》

## 基础信息

- **书籍 ID**：`book_驯兽_0103`
- **关联技能**：`beast_command_code`（待新增，标签 `beast`）
- **使用效果**：阅读后解锁 `beast_command_code`；若已学会，提升该技能 `current_mastery +60`，并使已驯服野兽响应基础指令的成功率提高 10%。
- **阅读要求**：无职业限制；基础 `感知 ≥ 6`。
- **稀有度**：普通（Common）
- **建议投放**：驯兽师行会、军营犬舍、游牧部落。

## 书籍内容

这本书收集了来自七个部族与三座军营的常用驯兽口令，并按照急停、靠近、攻击、守护、撤退五类整理成表。作者指出，口令的关键不在声音大小，而在一致性与情绪稳定；同一口令在不同情绪下发出来，野兽会当作不同指令。书中详细说明每个音节的开合与节奏，建议训练者用固定的手势配合声音，让野兽形成条件反射。后半部分讨论口令失效的常见原因，包括环境噪音过大、野兽过度疲劳以及训练者自身焦虑。作者建议在训练初期选择安静的清晨，等基础反应稳定后再逐步加入风声、人群与其他动物干扰。最末页附有一套十日训练计划，从每日十次重复开始，到逐步加入干扰环境。军营犬舍把它列为驯犬员的标准教材。作者提醒，口令训练没有捷径，只有重复才能让声音成为信任的桥梁。

## 设计意图

为基础驯兽体系建立通用指令层，让玩家感受到“训练成果”而非单纯解锁技能。
