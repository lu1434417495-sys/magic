# 《守护姿态：挡在主人身前》

## 基础信息

- **书籍 ID**：`book_驯兽_0073`
- **关联技能**：`beast_guard_stance`（待新增，标签 `beast`）
- **使用效果**：阅读后解锁 `beast_guard_stance`；若已学会，提升 `current_mastery +90`，并使野兽伙伴在主人濒危时自动进入挡护状态。
- **阅读要求**：无职业限制；基础 `体质 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：护卫驯兽师营地、骑士团兽栏、守卫任务奖励。

## 书籍内容

最好的守护不是攻击敌人，而是把主人的位置变成敌人不愿靠近的代价。本书教导如何让野兽理解“守护”这一抽象命令：先用食物引导它站在你与假人之间，再逐渐引入模拟攻击，让野兽把主人背后的安全与自己的奖励绑定。作者强调，守护型野兽不应过度主动攻击，否则它会离开位置，让主人暴露。后半部按体型分类讨论了不同野兽的守护优势：大型犬科适合正面拦截，熊类适合吸收冲击，蛇类适合威慑接近者。书中还提到，守护训练必须从幼年开始，成年野兽很难把“保护”理解为优先于“追击”的命令。作者还建议为守护型野兽设置一个固定站位点，比如主人的左侧半步，这能让它在混乱中迅速找到正确位置。最末页记录了一位老驯兽师的话：“训练守护犬的秘诀，是让它相信你的后背比它的牙齿更重要。”

## 设计意图

为驯兽师增加防御向战术选项，让野兽伙伴在战棋中承担护卫角色。
