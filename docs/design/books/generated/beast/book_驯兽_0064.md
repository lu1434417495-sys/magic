# 《骑乘野猪入门》

## 基础信息

- **书籍 ID**：`book_驯兽_0064`
- **关联技能**：`beast_boar_riding`（待新增，标签 `beast`）
- **使用效果**：阅读后解锁 `beast_boar_riding`；若已学会，提升 `current_mastery +85`，并降低骑乘野猪时的首次冲锋体力消耗。
- **阅读要求**：角色职业标签含 `warrior` 或 `rider`；基础 `力量 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：野猪骑士营地、蛮荒部落交易点、重骑兵训练场。

## 书籍内容

野猪不是优雅的坐骑，但它们是山脉最可靠的 shock。作者用幽默的笔触描绘了第一次骑乘的狼狈：被甩下、被拱翻、被拖行在泥浆里。他指出，骑野猪的关键不是拉缰绳，而是夹紧膝盖并顺应它的节奏。书中详细说明了鞍具的特殊设计：前鞍桥必须加高，因为野猪低头冲锋时会把骑手向前抛；缰绳只能用于提示方向，不能用于制动。后半部收录了七种冲锋后的急转技巧，以及如何在野猪发怒时通过轻拍耳根让它冷静。作者还警告，骑乘野猪时绝不要从正前方落地，因为它们会把落地的动作理解为挑战。书中还提到，野猪对陌生气味极其敏感，新骑手应在骑乘前把自己的外套放在猪窝中三天。最末页有一幅被泥浆溅满的插画，画中战士骑在巨猪背上穿过敌阵，配文：“马背上是荣耀，猪背上是胜利。”

## 设计意图

为战士系提供重型冲击坐骑选项，用幽默感平衡野兽骑乘的硬核学习曲线。
