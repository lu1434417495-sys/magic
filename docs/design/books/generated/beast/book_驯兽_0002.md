# 《狼群契约术入门》

## 基础信息

- **书籍 ID**：`book_驯兽_0002`
- **关联技能**：`beast_wolf_pact`
- **使用效果**：阅读后解锁 `beast_wolf_pact`；若已学会，提升该技能 `current_mastery +90`，并使召唤出的灰狼伙伴基础生命值提高 8%。
- **阅读要求**：角色职业标签含 `ranger`、`rogue` 或 `barbarian`；基础 `敏捷 ≥ 7`。
- **稀有度**：普通（Common）
- **建议投放**：灰雾森林营地、狼嚎峡谷掉落、游侠导师传承。

## 书籍内容

《狼群契约术入门》详细介绍了如何与灰狼建立初步的灵魂链接。作者认为，狼不是被召唤出来的仆从，而是平等的猎手伙伴。书中首先教导读者辨认狼群中的等级语言：夹尾表示臣服、舔嘴表示请求、竖尾漫步则是自信的宣告。接着讲解契约仪式：在满月夜放置一块带血的生肉，自己后退七步，等待狼王主动靠近。作者提醒，仪式成功的关键是气味必须真实——狼能分辨恐惧与欺骗。后半本收录了十二种不同地域灰狼的习性差异，从苔原狼到丛林狼各有侧重。最后一页是一张手绘的狼爪印，旁边写着："契约一旦成立，你便不再是一个人在狩猎。"作者特别警告，契约仪式中的食物必须亲自猎取，不能使用市场购买的肉品，否则狼群会嗅出陌生人类的气息而拒绝接近。书中还提醒，契约后的第一个月最为关键，任何一次失信都会让契约倒退数周。

## 设计意图

为近战与游侠职业提供早期战斗伙伴，强调"狼作为协同单位"而非简单坦克，让玩家体验以多打少的战术乐趣。
