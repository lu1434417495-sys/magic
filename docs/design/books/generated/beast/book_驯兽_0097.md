# 《原始本能觉醒》

## 书籍内容

每只被驯服的野兽体内都沉睡着一个野性祖先。作者研究出一种方法，可以在不破坏伙伴关系的前提下，短暂唤醒这种原始本能。书中警告，这种觉醒是一把双刃剑：它会大幅提升野兽的力量、速度和恢复力，但也会让野兽暂时失去对复杂命令的理解能力。正确的使用时机是生死关头，而不是日常狩猎。后半部讲解了觉醒后的安抚流程：不能用平时的口令，而要用最原始的气味和声音——主人的心跳、熟悉的毛毯、幼年时吃过的食物。作者还提醒，频繁唤醒原始本能会缩短野兽的寿命，因此每一次使用都应像告别一样郑重。书中建议在觉醒结束后用大量清水和安静环境帮助野兽降温，防止虚脱。最末页画着一只眼睛发红的巨狼，但它的尾巴仍朝向主人，配文：“它不是疯了，它只是回到了还没学会信任你的时候。”

## 设计意图

为野兽伙伴设计高风险爆发状态，在绝境中提供翻盘可能但伴随失控代价。
