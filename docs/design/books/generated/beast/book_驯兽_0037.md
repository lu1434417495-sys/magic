# 《野兽驯养场管理》

## 基础信息

- **书籍 ID**：`book_驯兽_0037`
- **关联技能**：`beast_pen_management`
- **使用效果**：阅读后解锁 `beast_pen_management`；若已学会，提升该技能 `current_mastery +75`，并使驻扎在驯养场中的野兽恢复速度提高 10%。
- **阅读要求**：无职业限制；基础 `智力 ≥ 8`。
- **稀有度**：精良（Uncommon）
- **建议投放**：农场主、领地建设奖励、驯养场管理员。

## 书籍内容

《野兽驯养场管理》教导玩家如何建立一个让多种野兽安全共存的营地设施。作者认为，驯养场不是监狱，而是一个微型的生态系统。书中先讲解场地规划：肉食区与草食区必须隔离，水源要远离排泄区，每个区域都需要遮阴与通风。中间章节介绍日常管理：喂食时间表、清洁周期、疾病预防与隔离措施。后半本记录了如何处理野兽之间的紧张关系：通过气味交换、共同喂食与渐进式接触让它们熟悉彼此。作者在最后强调，驯养场的核心是规律，"野兽比人类更依赖可预测的环境。你今天少喂一次，它们下个月都会记得。"书末附有一张驯养场安全检查表，涵盖围栏稳固性、水源清洁度与野兽隔离状态。作者强调，驯养场的布局应该让野兽能够随时看到天空，封闭环境会加速它们的焦虑。书中还提到。

## 设计意图

为基地建设与长期养成玩法提供驯兽支撑，让野兽伙伴在非战斗时间也能持续成长与恢复。
