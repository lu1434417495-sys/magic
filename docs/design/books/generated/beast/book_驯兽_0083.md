# 《双兽同时驾驭》

## 基础信息

- **书籍 ID**：`book_驯兽_0083`
- **关联技能**：`beast_dual_handle`（待新增，标签 `beast`）

## 书籍内容

同时驾驭两只野兽不是把命令重复两次，而是让它们相信彼此的存在不会威胁到地位。作者从“分离喂食”开始讲起：两只野兽必须先在各自独立的空间中认可你的领导权，才能被允许同时出现在你面前。书中详细设计了“左右分工”训练：左手持饵给左侧野兽，右手持饵给右侧野兽，让它们把位置与奖励稳定关联。后半部扩展到战斗中的双兽调度：一只进攻时另一只警戒，一只疲劳时另一只顶上。最困难的环节是“冲突仲裁”：当两只野兽互相低吼时，驯兽师必须立刻介入，用身体站位明确谁在前谁在后。作者还提醒，双兽驾驭的瓶颈从来不是技巧，而是注意力分配——你必须让每一只野兽都觉得，当它看向你时，你正看着它。最末页写着：“你不是在命令两只野兽，你是在维护一个小型社会的秩序。”

## 设计意图

突破单野兽伙伴的上限，为深度驯兽构建提供多线操作与群体管理玩法。
