# 《雷电兽共鸣》

## 基础信息

- **书籍 ID**：`book_驯兽_0140`
- **关联技能**：`beast_thunder_resonance`（待新增，标签 `beast`、`thunder`）
- **使用效果**：阅读后解锁 `beast_thunder_resonance`；若已学会，提升该技能 `current_mastery +200`，并使雷电属性野兽协同攻击时有概率附加感电。
- **阅读要求**：无职业限制；基础 `感知 ≥ 14` 或 `敏捷 ≥ 14`。
- **稀有度**：稀有（Rare）
- **建议投放**：雷暴高原、天空神殿、风暴祭坛。

## 书籍内容

雷电属性的野兽速度极快、脾气暴烈，但它们对节奏与频率异常敏感。这本书讲解如何通过特定的金属器具与步伐节奏，与雷电兽建立“同频”关系。作者强调，驯兽师自身的神经反应必须足够快，否则会在共鸣中落后半拍，导致雷电兽失去兴趣或发起攻击。后半部分讨论雷暴天气对共鸣的加成，以及如何在战斗中引导雷电兽释放感电攻击。作者还详细比较了不同金属器具在共鸣中的音色差异，指出银器高频适合小型雷兽，而铜器低频更适合大型雷兽。书中建议在每次训练前用节拍器校准节奏，因为人类主观感觉的快慢并不可靠。最末页附有一张节拍训练表，建议每日用鼓点或金属敲击练习反应。雷暴高原与风暴祭坛的学徒把这本书翻得卷了边。书中强调，与雷电兽同行，必须学会比闪电更早一步思考。

## 设计意图

强化速度与节奏主题，为战斗中的连携与元素异常状态提供来源。
