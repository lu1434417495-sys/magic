# 《灵猫同步：阴影中的脚步》

## 基础信息

- **书籍 ID**：`book_驯兽_0009`
- **关联技能**：`beast_cat_sync`
- **使用效果**：阅读后解锁 `beast_cat_sync`；若已学会，提升该技能 `current_mastery +80`，并使猫科伙伴的暴击率提高 5%。
- **阅读要求**：角色职业标签含 `rogue` 或 `ranger`；基础 `敏捷 ≥ 9`。
- **稀有度**：普通（Common）
- **建议投放**：影巷盗贼公会、黑市珍奇书商、夜行生物学者收藏。

## 书籍内容

《灵猫同步：阴影中的脚步》讲述如何与猫科野兽建立隐秘行动的默契。作者认为，猫是天生的潜行大师，驯兽师要学的不是命令它安静，而是让自己的心跳与呼吸也慢下来。书中先讲解猫的身体语言：耳朵转动方向代表注意力的焦点，尾巴低垂表示准备扑击，尾尖轻摇则是不耐烦。中间章节教导读者如何训练猫科伙伴在阴影中等待信号，以及如何利用它的扑击吸引敌人注意，为自己创造背刺机会。后半本记录了几种适合协同作战的猫科野兽：山猫敏捷、猎豹爆发、黑豹夜视。作者在最后一页提醒："猫只会在它认为有利可图时出手，所以你必须让它相信，跟着你总能捕到最大的猎物。"书中还提到，猫科伙伴对重复训练极易厌倦，因此每次练习都要变换路线与目标，保持它们的好奇心与专注力。

## 设计意图

为盗贼与游侠提供高暴击、高隐蔽的伙伴选择，与灵猫的潜行节奏形成战术共振。
