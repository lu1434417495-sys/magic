# 《冰霜兽亲和》

## 基础信息

- **书籍 ID**：`book_驯兽_0138`
- **关联技能**：`beast_frost_affinity`（待新增，标签 `beast`、`frost`）
- **使用效果**：阅读后解锁 `beast_frost_affinity`；若已学会，提升该技能 `current_mastery +190`，并使寒冷环境中冰霜野兽的忠诚度不下降。
- **阅读要求**：无职业限制；基础 `感知 ≥ 13`。
- **稀有度**：稀有（Rare）
- **建议投放**：雪山圣殿、冰霜洞穴、极地驿站。

## 书籍内容

冰霜属性的野兽在寒冷中反而感到舒适，它们对高温与干燥极为厌恶。这本书从体温管理、食物温度与居住环境三个角度，讲解如何让冰霜野兽在非原生环境中保持忠诚。作者强调，与冰霜兽建立关系的关键在于尊重它们对寒冷的依赖，而不是强行让它们适应人类的温暖。后半部分介绍如何利用冰霜兽的体温与吐息进行辅助战斗，例如在炎热地区制造局部降温区域。作者还建议在炎热季节为冰霜兽准备冰雾浴或深埋地下的石床，帮助它们调节体温并维持情绪稳定。书中提醒，给冰霜兽饮用温水反而会让它们不适，应提供接近冰点的清水。最末页附有一份寒冷环境适应性训练表，帮助野兽逐步适应极端低温。雪山圣殿与冰霜洞穴的守卫者常把它放在枕边。书中写道，尊重寒冷，就是尊重冰霜兽本身。

## 设计意图

引入元素属性亲和，让环境成为驯兽养成与战斗策略的变量。
