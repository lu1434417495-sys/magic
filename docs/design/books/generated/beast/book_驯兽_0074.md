# 《野兽冲锋协同》

## 基础信息

- **书籍 ID**：`book_驯兽_0074`
- **关联技能**：`beast_charge_sync`（待新增，标签 `beast`）
- **使用效果**：阅读后解锁 `beast_charge_sync`；若已学会，提升 `current_mastery +95`，并提升与野兽伙伴同时冲锋时的破甲效果。
- **阅读要求**：角色职业标签含 `warrior` 或 `rider`；基础 `力量 ≥ 8`。
- **稀有度**：精良（Uncommon）
- **建议投放**：重骑兵营地、战兽军团训练场、边境要塞任务奖励。

## 书籍内容

真正的冲锋不是一个人骑着野兽跑，而是人与野兽变成同一个箭头。作者是一名退役的野猪骑士，他在书中详细拆解了冲锋的四个阶段：预备、启动、提速、撞击。每个阶段都需要骑手与野兽的节奏完全同步，任何一拍的错位都会让冲击力从尖端变成侧面。书中还讲解了“目标锁定”训练：在移动中保持目光与野兽视线一致，让它把人类的杀意转化为自己的方向感。后半部收录了不同坐骑的冲锋距离与转向惩罚，从野猪的短距爆发到巨蜥的直线碾压。作者特别提醒，冲锋结束后的减速同样关键，许多新手因为忘记控制坐骑的收势而被甩落。书中还建议在冲锋前先让坐骑围绕目标慢跑半圈，以确认彼此的默契。最末页画着一名骑士与坐骑同时低下头颅的剪影，配文：“当你感觉不到马鞍，就是冲得最好的时候。”

## 设计意图

把骑乘冲锋从简单的移动攻击升级为需要时机与同步的高收益战术。
