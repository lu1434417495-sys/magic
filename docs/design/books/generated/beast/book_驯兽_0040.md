# 《野性爆发激发》

## 基础信息

- **书籍 ID**：`book_驯兽_0040`
- **关联技能**：`beast_feral_surge`
- **使用效果**：阅读后解锁 `beast_feral_surge`；若已学会，提升该技能 `current_mastery +85`，并使野兽伙伴生命值低于 50% 时攻击速度提高 10%。
- **阅读要求**：角色职业标签含 `barbarian` 或 `ranger`；基础 `意志 ≥ 9`。
- **稀有度**：稀有（Rare）
- **建议投放**：狂战士祭坛、荒野神殿、兽魂仪式奖励。

## 书籍内容

《野性爆发激发》研究如何在战斗中短暂唤醒野兽最原始的杀戮本能。作者指出，真正的野性不是疯狂，而是一种抛弃犹豫后的绝对专注。书中先讲解触发条件：野兽必须处于生死压力之下，驯兽师必须同步释放自己的杀意，两者的心跳达到同一频率时，爆发才会发生。中间章节介绍爆发期间的效果：痛觉被抑制、反应速度提升、攻击不再保留余力。后半本记录了控制爆发的风险：过度激发会导致野兽战后陷入虚脱，甚至分不清敌我。作者在最后强调："野性是你的最后一张牌。只有在愿意承担失去它的代价时，才应该翻开这张牌。"书末附有一张野性爆发后恢复护理清单，包括补充营养、隔离静养与逐步降低刺激。作者警告，连续激发野性超过三次的野兽可能出现永久性的性格改变。书中还提到。

## 设计意图

为狂暴型 build 提供高风险高回报的爆发机制，让野兽在危急时刻成为扭转战局的关键力量。
