# 《撤退哨音》

## 基础信息

- **书籍 ID**：`book_驯兽_0075`
- **关联技能**：`beast_retreat_whistle`（待新增，标签 `beast`）
- **使用效果**：阅读后解锁 `beast_retreat_whistle`；若已学会，提升 `current_mastery +85`，并使野兽伙伴在听到撤退哨音时更快脱离战斗。

- **稀有度**：普通（Common）
- **建议投放**：游侠公会、猎人营地、战场医疗站。

## 书籍内容

让野兽进攻容易，让它们停下来很难。本书专注于一个被忽视的命令：撤退。作者指出，野兽一旦进入战斗状态，血液里的捕食本能会压过训练，因此撤退信号必须具有强烈的打断效果。哨音比人声更适宜，因为它尖锐、短促、与环境音截然不同。书中介绍了三种哨音模式：一声长音代表立刻停战，两声短音代表退回主人身边，三声急促代表寻找掩体。后半部讲解了如何让野兽把哨音与奖励建立强关联：每次吹哨后都给予高价值食物，直到哨音本身成为一种期待。作者还提醒，不要在战斗中首次使用撤退哨，因为那时的野兽很可能听不见。书中还建议在非战斗状态下反复练习撤退路径，让野兽对安全地点形成肌肉记忆。作者强调，撤退训练中的奖励必须高于进攻时的奖励，否则野兽会主动选择继续战斗。最末页写着：“能活着回来的野兽，才是训练有素的野兽。”

## 设计意图

为驯兽战斗加入风险控制手段，鼓励玩家在危急时刻保护伙伴而非牺牲它们。
