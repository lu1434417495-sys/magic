# 《驯兽师护甲选择》

- **书籍 ID**：`book_驯兽_0124`

## 书籍内容

驯兽师不需要最厚重的板甲，而需要能安静移动、不妨碍手势、不散发刺鼻气味的装备。作者比较了皮甲、链甲内衬与特殊织物在噪音、气味与灵活性上的差异，并建议根据常伴野兽的习性选择颜色与材质。书中强调，金属撞击声会让许多野兽误以为战斗开始，而过于鲜艳的涂装可能激怒以视觉锁定目标的捕食者。后半本讲解如何在护甲上固定工具与药剂，以及如何处理血迹以避免野兽把驯兽师与食物混淆。作者还建议在护甲内衬缝制可更换的香草袋，用熟悉气味帮助野兽在混乱战场上快速识别主人。最末页附有三套经典搭配方案，分别适合林地、沙漠与雪地。游侠行会与猎人装备店常把它推荐给进阶学员。作者强调，护甲是人与野兽之间的缓冲，而不是隔阂。合适的护甲，是驯兽师与野兽之间的沉默语言。

## 设计意图

把装备选择纳入驯兽体系，让玩家在防御与野兽互动之间做取舍。
