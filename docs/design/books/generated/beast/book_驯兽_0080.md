# 《疲劳管理：何时收手》

## 基础信息

- **书籍 ID**：`book_驯兽_0080`
- **关联技能**：`beast_fatigue_management`（待新增，标签 `beast`）

## 书籍内容

最残忍的驯兽师不是打骂野兽的人，而是看不出野兽已经累了的人。本书作者通过长期观察发现，野兽疲劳有四个阶段：耳朵后压、舌头外垂、步伐变沉、最后才是不听命令。很多驯兽师只在第四阶段才意识到问题，而那时伤害已经造成。书中建议每场战斗后让野兽休息至少一个时辰，并在长途行军中使用轮换制度。后半部讲解了“主动收手”的信号训练：当驯兽师发出特定哨音时，野兽应立刻降低攻击强度，转为游走或防御。作者还提醒，疲劳的野兽更容易受伤，也更容易在战后产生心理阴影。书中特别强调，战后的梳理和喂食比战前的激励更能建立长期信任。作者还建议在长途行军时每隔两个时辰让野兽自由活动片刻，哪怕只是嗅闻地面。最末页用红笔写着：“它们不会说累，所以你必须替它们决定什么时候停。”

## 设计意图

引入疲劳与长期健康管理概念，防止野兽伙伴成为可无限消耗的战斗资源。
