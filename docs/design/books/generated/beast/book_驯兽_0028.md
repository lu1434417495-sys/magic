# 《盗贼影豹伙伴》

## 基础信息

- **书籍 ID**：`book_驯兽_0028`
- **关联技能**：`beast_shadow_panther`
- **使用效果**：阅读后解锁 `beast_shadow_panther`；若已学会，提升该技能 `current_mastery +85`，并使影豹伙伴的潜行持续时间延长 1 回合。
- **阅读要求**：角色职业标签含 `rogue`；基础 `敏捷 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：影巷黑市、暗影森林深处、刺客公会密库。

## 书籍内容

《盗贼影豹伙伴》是暗影行者们口耳相传的驯豹秘典。作者认为，影豹与盗贼是天生的搭档：两者都信奉安静、耐心与一击必杀。书中先讲解如何获得影豹幼崽：必须在无月之夜进入暗影森林，不带武器，不带光源，只凭心跳声吸引它们。中间章节介绍协同战术：影豹负责吸引注意力或制造恐惧，盗贼则趁机完成背刺；也可以让影豹先行标记目标，让盗贼的伏击成功率大幅提升。后半本记录了影豹的弱点：强光会让它短暂失明， loud noise 会让它暴露位置。作者在最后写道："影豹不是宠物，它是你投在墙上的另一个影子。它服从你，因为它和你一样热爱黑暗。"书末附有一张影豹幼崽气味偏好表，建议使用特定苔藓与夜行鼠的气味来吸引它们的注意。作者还警告，影豹幼崽一旦认定信任对象，便会终生难忘。

## 设计意图

为盗贼职业提供高度契合潜行玩法的专属伙伴，强化偷袭、标记与逃脱的战术链条。
