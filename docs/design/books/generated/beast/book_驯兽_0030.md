# 《法师使魔契约》

## 书籍内容

《法师使魔契约》是法师们与小型魔法生物建立联系的入门典籍。作者指出，使魔与召唤兽不同：召唤兽是临时工具，使魔是长期研究助手与生活伴侣。书中先讲解契约生物的选择：猫头鹰适合侦察，蟾蜍适合药材处理，灵猫适合警戒，小型龙裔则能提供元素亲和。中间章节介绍如何将使魔与法术回路连接：使魔可以帮助稳定施法、分担魔力反噬，甚至在主人昏迷时自动触发护盾。后半本记录了使魔的智力培养：通过每日阅读与对话，使魔可以逐渐学会简单决策。作者在最后写道："一个法师可以有很多法术，但只有一个使魔。它是你魔法生命的见证者。"书末附有一份使魔日常养护清单，包括每周梳理、每月魔力浴与每季度智力测试。作者提醒，使魔的情绪会直接影响法师的施法稳定性，因此不可忽视日常陪伴。

## 设计意图

为法师职业提供符合学术设定的长期伙伴，将驯兽系统与法术强度、施法稳定性的成长绑定。
