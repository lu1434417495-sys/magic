# 《佯攻与真咬》

## 书籍内容

野兽的欺骗不是诡计，而是狩猎本能的一部分。作者观察到猫科动物在捕猎时常用假动作：先向一个方向压低身体，再突然从另一个方向扑出。本书把这一本能训练成可控战术，让野兽伙伴学会“佯攻咬击”：第一口不发力，只为逼迫敌人暴露防御空当。书中详细说明了训练步骤：先用厚布包裹手臂让野兽习惯咬而不撕，再引入移动目标练习时机判断。后半部讨论了不同野兽的佯攻风格：犬科偏向左右晃动头部，猫科偏向身体假伏，蛇类则利用静止后的突然弹射。最有趣的章节是“破绽读取”：训练师要学会观察敌人的重心偏移，在正确时机发出真咬指令。作者提醒，佯攻失败的最大代价是让野兽养成“假咬变成真咬”的坏习惯，因此必须严格区分两种命令。书末画着一张利齿在敌人眼前虚晃的草图。

## 设计意图

为野兽伙伴增加战术深度，让它们在战斗中不仅是输出单位，也是制造机会的控场者。
