# 《驯兽师的号令》

## 基础信息

- **书籍 ID**：`book_驯兽_0012`
- **关联技能**：`beast_trainer_command`
- **使用效果**：阅读后解锁 `beast_trainer_command`；若已学会，提升该技能 `current_mastery +75`，并使野兽指令的有效范围扩大 1 格。
- **阅读要求**：无职业限制；基础 `魅力 ≥ 7` 或 `意志 ≥ 7`。
- **稀有度**：普通（Common）
- **建议投放**：驯兽师公会、竞技场后台、佣兵营地训练官。

## 书籍内容

《驯兽师的号令》讲述如何通过声音、手势与气场同时指挥多只野兽。作者认为，真正的号令不在于音量，而在于清晰度与一致性。书中先讲解基础口令设计：每个指令必须只有一个音节或一个手势，避免野兽混淆。中间章节介绍了"主从链"概念：先让最强壮的野兽理解指令，其他野兽会模仿它的反应。后半本则记录了在嘈杂战场中保持号令清晰的技巧，包括使用哨子、旗帜与特定的跺脚节奏。作者还提醒，频繁改变口令会让野兽产生焦虑，因此一个团队应该统一命令体系。最后一页是一张常见口令对照表，涵盖了前进、停止、攻击、撤退、守护与追踪。卷末写道："野兽听见的不是你的词，而是你的确定。"作者在最后附上了一份训练日志模板，要求记录每次训练使用的口令、野兽反应与奖励类型，以便追踪进步。

## 设计意图

作为驯兽师的核心指挥技能书，为多野兽协同作战提供基础规则，降低同时控制多个单位的操作成本。
