# 《山地巨猿协作》

## 基础信息

- **书籍 ID**：`book_驯兽_0018`
- **关联技能**：`beast_mountain_ape`
- **使用效果**：阅读后解锁 `beast_mountain_ape`；若已学会，提升该技能 `current_mastery +85`，并使巨猿投掷岩石的伤害提高 15%。
- **阅读要求**：角色职业标签含 `warrior` 或 `barbarian`；基础 `力量 ≥ 11`。
- **稀有度**：精良（Uncommon）
- **建议投放**：高山部落祭坛、猿王洞窟、石拳氏族训练场。

## 书籍内容

《山地巨猿协作》讲述了如何与智力接近人类的巨猿建立战友关系。作者指出，巨猿不会屈服于暴力，它们只会与能赢得它们尊重的个体合作。书中前半部分讲解社交规则：先分享食物、再互相梳理毛发、最后共同完成一项任务。中间章节介绍战斗协同：巨猿可以举起巨石进行远程投掷，也可以将骑手抛向高处平台。后半本记录了如何处理巨猿的情绪波动：它们在受挫时会捶胸咆哮，此时应该给予空间而非命令。作者在最后写道："与巨猿并肩作战，你不是主人，而是兄弟。它会在你倒下时为你挡下致命一击，也会在你背叛它时把你扔下悬崖。"书末附有一张巨猿喜爱的果实清单，作为建立信任的初始礼物非常重要。作者还提醒，巨猿对欺骗极度敏感，一次食言可能需要数月才能修复关系。书中还提到。

## 设计意图

为力量型职业提供高智力伙伴，拓展远程投掷与地形互动玩法，强调平等协作而非主从关系。
