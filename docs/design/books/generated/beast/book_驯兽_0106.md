# 《兽栏布置指南》

## 基础信息

- **书籍 ID**：`book_驯兽_0106`
- **关联技能**：`beast_pen_layout`（待新增，标签 `beast`）
- **使用效果**：阅读后解锁 `beast_pen_layout`；若已学会，提升该技能 `current_mastery +60`，并使兽栏内野兽的压力下降、休息效率提升。
- **阅读要求**：无职业限制；基础 `感知 ≥ 6`。
- **稀有度**：普通（Common）
- **建议投放**：庄园兽栏、城堡马厩、兽栏建筑师。

## 书籍内容

书中认为，一个合适的兽栏不只是关押野兽的牢笼，而是帮助它们建立领地感与安全感的环境。作者从光线、通风、地面材质与遮蔽物四个维度给出建议，强调野兽需要既能观察四周又能躲藏的“半开放角落”。书中用多个案例说明，过于空旷的兽栏会让被捕野兽持续应激，而过于封闭的隔间又会让它们失去对外界的信任。后半本讨论不同气候下的调整方案：炎热地区需要浅水池与遮阴，寒冷地区需要干燥垫草与防风入口。作者还建议在栏内放置可供撕咬或攀爬的丰容物，帮助野兽释放压力并保持自然行为，并强调定期清理气味残留对维持领地认知至关重要。最末页附有三种标准兽栏的平面草图，被许多庄园管家和城堡马夫当作翻修依据。作者认为，一个让野兽愿意返回的兽栏，才算真正合格。

## 设计意图

把基地建设与驯兽成长挂钩，让玩家在战棋之外也关注后勤空间的规划。
