# 《猛兽口哨指令》

## 基础信息

- **书籍 ID**：`book_驯兽_0126`
- **关联技能**：`beast_whistle_command`（待新增，标签 `beast`）
- **使用效果**：阅读后解锁 `beast_whistle_command`；若已学会，提升该技能 `current_mastery +130`，并使口哨指挥已驯服野兽的有效范围提高 2 格。
- **阅读要求**：无职业限制；基础 `感知 ≥ 10`。
- **稀有度**：精良（Uncommon）
- **建议投放**：驯兽竞技场、军情哨所、猎团指挥所。

## 书籍内容

远距离指挥野兽，声音必须穿越风声与战场喧嚣。作者设计了一套高频口哨信号，每个信号由长短音组合构成，分别代表攻击、撤退、守护、分散与集结。书中详细说明吹奏口型、舌位与气流控制，强调同一信号在不同距离下需要重复次数不同。后半部分讨论口哨失效的补救方案，例如备用手势与气味标记点。作者还提醒，口哨指令必须配合日常训练，不能到了战场才临时使用。书中还特别提到口哨本身的保养：潮湿或灰尘都会影响音准，一名合格的驯兽师会在睡前检查哨口是否通畅。最末页是一张信号对照卡，许多驯兽师会把它挂在脖子上。军情哨所与猎团指挥所把它列为标准通讯教材。作者认为，一只训练有素的野兽能在噪音中分辨出口哨，是因为信任让声音变得清晰。战场上，一个清晰的信号能救下双方性命。

## 设计意图

扩展战场指挥距离，让野兽在战棋中成为可远程调度的战术单位。
