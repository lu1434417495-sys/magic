# 《野兽协同走位》

## 基础信息

- **书籍 ID**：`book_驯兽_0117`
- **关联技能**：`beast_positioning`（待新增，标签 `beast`）
- **使用效果**：阅读后解锁 `beast_positioning`；若已学会，提升该技能 `current_mastery +100`，并使与野兽相邻时双方闪避提高 5%。
- **阅读要求**：无职业限制；基础 `敏捷 ≥ 8`。
- **稀有度**：精良（Uncommon）
- **建议投放**：战术训练场、猎群营地、协同作战教室。

## 书籍内容

真正的驯兽战斗不是人与兽各自为战，而是共同编织一张移动的网。作者用战例说明，驯兽师应主动吸引敌人正面，而野兽则从侧翼或背后发起攻击；当敌人转向野兽时，驯兽师立刻补位。书中给出三种基础阵型：钳形、轮转与护卫，每一种都配有步法图示与切换信号。后半部分强调，协同走位的前提是驯兽师与野兽彼此熟悉移动节奏，因此平日训练要包含大量无武器跟随跑。作者还指出，切换阵型的口令或手势必须在训练时反复强化，否则战场噪音会让指挥失效。最末页有一段警告：不要让野兽独自承担主攻任务，因为再忠诚的伙伴也会疲劳与受伤。猎群营地与战术训练场的学员们把它背得滚瓜烂熟。作者强调，真正的协同不是命令与服从，而是彼此预判的默契。战场上，一个眼神往往比十句口令更可靠。

## 设计意图

把野兽从“独立单位”转化为战棋协同的一部分，强调站位与配合。
