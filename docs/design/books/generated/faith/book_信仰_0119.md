# 《信仰飞跃步法》

## 基础信息

- **书籍 ID**：`book_信仰_0119`
- **关联技能**：`faith_leap_of_faith_119`
- **使用效果**：阅读后解锁 `faith_leap_of_faith_119`；若已学会，提升该技能 `current_mastery +80`，并允许在每场战斗中有一次机会穿越敌方控制领域而不触发借机攻击。
- **阅读要求**：角色职业标签含 `holy`；基础 `敏捷 ≥ 8` 或 `意志 ≥ 8`。
- **稀有度**：精良（Uncommon）
- **建议投放**：朝圣者山道、战牧训练场、高空遗迹。

## 书籍内容

步法看起来不合常理：它要求练习者在心中默念一个比自己更重要的目标，然后向看似不可能到达的位置迈步。作者说信仰飞跃不是跳跃技巧，而是“把重量交给信念的瞬间”。书中记录了许多练习者从悬崖、屋顶、断桥上一跃而过的案例，但也警告若目标不够真实，施术者会在半空中失去支撑。后半部分是落地训练，强调飞跃之后必须立刻进入下一个动作，不能在原地发呆。最末页画着一只脚悬在悬崖外，旁边批注：“地心引力并没有消失，只是你暂时把一部分自己交给了光。”作者在附录里画了几条失败轨迹，显示那些把飞跃当作炫耀技巧的人，大多在落地时摔断了腿，因为他们把重量交给了骄傲，而不是信念。书中还提到，信仰飞跃不能用于逃离，只能用于接近，否则会直接坠落。步法书的末页还有一张示意图，显示信仰飞跃最理想的落点不是安全地面，而是下一个需要你出现的位置。

## 设计意图

为信仰系提供机动突破手段，让战棋中的走位也带有宗教叙事色彩。
