# 《复活仪式的准备》

## 基础信息

- **书籍 ID**：`book_faith_0028`
- **关联技能**：`faith_rite_of_returning`
- **使用效果**：阅读后解锁 `faith_rite_of_returning`；若已学会，提升该技能 `current_mastery +120`，并降低复活类技能的 MP 消耗 10%。
- **阅读要求**：角色拥有 `holy` 或 `cleric` 标签职业；基础 `智力 ≥ 11` 且 `意志 ≥ 10`。
- **稀有度**：传说（Legendary）
- **建议投放**：亡灵战役终章、古代祭坛、大教堂禁书区。

## 书籍内容

复活仪式的准备是一本被多数教会列为限制阅读的典籍。书中不教授任何起死回生的咒语，只讲准备：如何收集逝者生前最常触摸的三件物品、如何选择月亮不亮的那一夜、如何安排逝者的身体朝向、以及如何安抚围绕遗体不散的残念。作者反复强调，复活不是逆转死亡，而是为迷失的灵魂打开一扇回家的门；若门开得不对，回来的可能不是原来的那个人。最惊心动魄的章节记录了十二次失败案例，每一次都因为仪式准备中一个看似微小的疏忽：一杯水放错了位置、守夜者打了个盹、或者祈祷者口中提到了逝者的乳名。书末用金箔压着一句话："你能唤回的只有愿意回来的人。"禁书区的管理员会定期检查这本书是否完好，因为曾有失控的家族试图用不完整的信息复活战死的亲人。他们的悲剧被追加在最新附录中，成为最严厉的警示。

为信仰系提供高阶资源效率增益，用沉重的准备流程降低复活机制的商业化感，强调代价与尊重。
