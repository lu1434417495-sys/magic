# 《信仰试炼的记述》

## 基础信息

- **书籍 ID**：`book_faith_0046`
- **关联技能**：`faith_trial_lore`
- **使用效果**：阅读后解锁知识 `faith_trial_lore`；阅读完成后提升所有信仰系技能 `current_mastery +25`，并降低信仰试炼任务的失败惩罚 10%。
- **阅读要求**：无职业限制；基础 `意志 ≥ 7`。
- **稀有度**：普通（Common）
- **建议投放**：试炼接待处、导师书架、新手信仰引导任务。

## 书籍内容

信仰试炼的记述是一本朴素的记录集，收集了历代试炼者的自述。书中没有统一的答案，只有各种各样的人在面对怀疑、恐惧与诱惑时的真实反应。有的人在饥饿中坚持祈祷，有的人在绝境中放弃又找回信念，还有的人发现试炼本身只是一个让自己更诚实地面对内心的仪式。作者按照试炼类型分类：孤独、牺牲、诱惑、审判、侍奉，每一类都附有三到五个不同结局的故事。最常被翻阅的是一位失败者的记录，他写道："我没有通过试炼，但试炼让我看清了自己真正相信什么。"书页边有无数读者的批注，彼此争论着哪些故事才算真正的成功。导师们常把这本书放在试炼入口，让每个参与者先了解失败也是记录的一部分。这种安排降低了焦虑，也让试炼的结果变得更加人性化。许多新手正是读了这些批注，才第一次敢于面对自己的怯懦。

## 设计意图

作为知识型入门书，降低玩家对信仰试炼失败的恐惧，用多元故事强化"信仰不是唯一答案"的世界观主题。
