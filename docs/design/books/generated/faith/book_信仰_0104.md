# 《神罚之光残页》

## 基础信息

- **书籍 ID**：`book_信仰_0104`
- **关联技能**：`faith_smite_light_104`
- **使用效果**：阅读后解锁 `faith_smite_light_104`；若已学会，提升该技能 `current_mastery +100`，并对亡灵/恶魔标签敌人的首次命中附加眩晕 1 回合。
- **阅读要求**：角色职业标签含 `priest` 或 `paladin`；基础 `意志 ≥ 9`。
- **稀有度**：精良（Uncommon）
- **建议投放**：审判庭档案室、讨伐恶魔任务奖励、古老圣所废墟。

## 书籍内容

残页来自一部被焚毁的审判典籍，只剩下关于“神罚之光”的七章。书中主张光不仅有抚慰之力，也有称量罪孽的灼热。施术者必须在施放前默念三条罪状：自己的、敌人的，以及这场战斗无法避免的。作者称这种自我称量能避免审判沦为屠杀。残页还提到，神罚之光对内心坦荡的敌人伤害反而较低，因为光只灼烧虚伪。后半部分收录了几次著名审判的简短记录，包括一名圣骑士用神罚之光击碎伪装成村民的恶魔。残页边缘有许多读者的批注，其中出现最多的一句话是：我在审判别人时，总能找到自己不敢承认的嫉妒。这些批注的笔迹各不相同，却都越写越小，仿佛每个人都在纸上后退。最末页被血渍浸透，但仍可辨认：“当你高举光的时候，先确认自己的手没有阴影。”附录里还有一段被涂黑的祷文，只有标题《给将要审判自己的人》。

## 设计意图

为圣职系补充对邪恶特攻的输出手段，用“自我审判”机制平衡高伤害，避免正义主题滑向无差别暴力。
