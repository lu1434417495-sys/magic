# 《圣洗之泉考》

- **书籍 ID**：`book_信仰_0134`
- **关联技能**：`faith_baptismal_spring_134`

## 书籍内容

泉考追溯了各地圣洗之泉的水文、历史与神学意义。作者指出，圣洗的力量不来自泉水本身，而来自“一个人愿意在水中承认自己的过去”。书中描述了洗礼的标准流程：浸入、沉默、出水、祝福，每个步骤都对应一种心理上的放手。后半部分收录了被污染泉水的净化案例，说明若施术者急于展示奇迹，污染会反弹。最末页是一张手绘的泉眼剖面图，标注着“最深的杂质不在水里，在施术者想快点结束仪式的心里”。作者在附录里收录了几位受洗者的匿名信，他们描述圣洗后最常见的感受不是洁净，而是终于允许自己不再假装坚强。书中还警告，同一个人不能在一天内接受两次圣洗，否则身体会因过度释放记忆而虚弱。泉考的最后一页是一首短诗，描述受洗者从水中站起时的感受：不是重生，而是终于允许自己继续活着。
