# 《放逐低语的封口令》

## 基础信息

- **书籍 ID**：`book_faith_0011`
- **关联技能**：`faith_silence_command`
- **使用效果**：阅读后解锁 `faith_silence_command`；若已学会，提升该技能 `current_mastery +90`，并对低语类精神攻击增加 15% 抵抗率。
- **阅读要求**：角色拥有 `holy` 或 `cleric` 标签职业；基础 `意志 ≥ 9`。
- **稀有度**：稀有（Rare）
- **建议投放**：疯人院礼拜堂、深渊低语事件、精神污染区域宝箱。

## 书籍内容

放逐低语的封口令是一种反向祈祷：它不是向神诉说，而是学习如何让自己的名字不再被邪物正确念诵。书中要求读者先写下自己最常用的十个词汇，然后在静默中逐一"收起"它们，使这些词在心中不再激起回响。作者解释道，异界低语往往通过重复一个人内心的关键词来撬开裂缝，封口令的作用就是让那些关键词变得迟钝。训练过程极其枯燥：连续七天只使用最简单的名词回答别人的问话。书中记录了一位成功修行者的感受："第七天，我发现自己不再被过去困住，因为那些词语已经失去了刺。"最危险的章节警告说，如果封口令练得太过彻底，修行者可能会失去表达悲伤的能力，所以每月必须有一天彻底放开说话。教会疗养院收治过几位过度练习者，他们最终能听懂所有语言，却再也无法说出"再见"。这一条款因此被严格写入修行守则。

为信仰系提供精神抗性路线，把"沉默"从负面状态转化为可主动修炼的保护壳，呼应灰烬交界的精神污染威胁。
