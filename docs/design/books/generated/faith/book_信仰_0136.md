# 《神怒雷霆引》

## 书籍内容

雷霆引是一部记载神怒显化为天雷的古老经文。作者警告，召唤雷霆不是请求保护，而是请求天平倾斜，因此施术者必须同时承受一部分天雷的反噬。书中把雷霆引分为三段：聚云要求施术者集中所有愤怒却不让它失控，判罪要求明确指认敌人的具体罪行，降罚则要求施术者在闪电落下时不闭眼。后半部分记录了几次神怒雷霆改变战局的战役，也记录了因滥用神怒而被反噬致死的案例。最末页写着：“雷霆不会为你愤怒，它只会借走你的愤怒；如果你无法承受借出的代价，就别开口。”作者在正文旁用红色批注写道：愤怒是雷霆的燃料，但愤怒若失去了具体对象，就会反过来点燃施术者自己。书中还提醒，神怒雷霆不能在雨天施展，否则天雷会优先寻找召唤者本身。封底还写着：神怒从不错认目标。

## 设计意图

为信仰系提供高伤害群体输出大招，用代价与局势相关伤害防止其成为常规手段。
