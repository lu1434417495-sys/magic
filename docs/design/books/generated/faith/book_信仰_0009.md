# 《临终福音的七句话》

## 书籍内容

临终福音不是治愈术，而是一种帮助灵魂跨越边界的言语技艺。书中列出七句话，分别对应七种最常见的临终执念：未竟之责、未说之爱、未解之恨、未偿之债、未归之家、未竟之梦、未忘之我。每一句话都不是标准答案，而是引导听者自己说出遗言的楔子。作者强调，施术者必须抑制住安慰的冲动，因为临终者需要的不是被说服，而是被听见。书中最沉重的章节是"失败案例"：一位年轻祭司因为急于让病人安息，跳过了第二句话，结果病人死后化作怨灵回到教堂。附录里有空白页，标题是"第八句话"，注释说每一名长期施术者最终都会写下属于自己的那句。书的装订线里夹着几根灰白头发，来源不明。在大教堂的安宁病房，这本书从不被束之高阁，而是放在每位临终者触手可及的地方，供他们随时翻阅。有时病人会自己补充第九句、第十句，成为后来者的指南。

为信仰系提供高风险的濒死救援与叙事深度，把"拯救"从回血延伸到对死亡过程的尊重。
