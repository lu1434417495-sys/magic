# 《福音传令术》

## 基础信息

- **关联技能**：`faith_gospel_herald_141`

## 书籍内容

传令术教你如何把一个鼓舞人心的消息带到战场每个角落。作者指出，福音不是说服敌人，而是让己方在绝望中还能听见彼此。书中讲解了三种传令方式：高声宣告适合开阔地形，手势暗号适合潜行环境，信鸽/圣印适合被分割的队伍。后半部分强调传令者的危险：他们往往是敌方优先狙杀的目标，因此必须学会在移动中简短祈祷。最末页写着：“你传的不是胜利的消息，是‘我们还在’这四个字；只要这四个字还能被听见，队伍就还没输。”作者在扉页上强调，福音传令术最关键的修炼不是肺活量，而是让每一个字都发自对同伴的真实关心，否则声音再大也只能传得很远，却进不了人心。书中还提到，传令术不增加声音本身的音量，而是让信息在听者心中变得清晰，因此嘈杂环境中反而更有效。
