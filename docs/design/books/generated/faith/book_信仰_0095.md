# 《忏悔仪式》

## 基础信息

- **书籍 ID**：`book_信仰_0095`

- **使用效果**：阅读后解锁 `faith_confession`；若已学会，提升该技能 `current_mastery +80`，并使忏悔后清除的负面状态额外增加 1 个。
- **阅读要求**：角色职业标签含 `priest` 或 `cleric`；基础 `信仰 ≥ 8` 且 `智力 ≥ 7`。

- **建议投放**：忏悔室、教会心理治疗任务、团队休整剧情奖励。

## 书籍内容

《忏悔仪式》教导牧师如何通过引导他人坦白过错，达到净化心灵与解除负面状态的效果。书中认为，许多诅咒与疾病并非来自外部，而是源于内心的愧疚与压抑。第一章讲解如何营造安全的忏悔环境，包括隐私、光线、以及施术者不带评判的态度。第二章讨论忏悔的层次：从具体行为到深层动机，越深入的忏悔带来的净化效果越强。作者警告，牧师不能泄露忏悔内容，这是比生命更神圣的誓言。后半部收录了多种常见负面状态的忏悔对应法，例如被恐惧支配者需要承认自己的软弱，被魅惑者需要说出被利用的愿望，被诅咒者则需要面对自己曾经的恶意。最末页的插图是一名牧师隔着帘子倾听忏悔者的低语，帘子两侧各有一支蜡烛，火光同时照亮了两个人的轮廓。忏悔仪式是信仰系独特的剧情与状态恢复技能。

## 设计意图

为信仰系提供剧情驱动的状态恢复机制，将心理治疗与信仰仪式结合，丰富角色扮演维度。
