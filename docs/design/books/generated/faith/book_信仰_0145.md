# 《献身契约书》

## 基础信息

- **书籍 ID**：`book_信仰_0145`
- **关联技能**：`faith_selfless_pact_145`
- **使用效果**：阅读后解锁 `faith_selfless_pact_145`；若已学会，提升该技能 `current_mastery +100`，并允许每场战斗中一次牺牲自身 10% 当前 `hp`，为一名友方完全恢复 `current_mp`。
- **阅读要求**：角色拥有 `holy` 或 `support` 标签职业；基础 `意志 ≥ 9`。
- **稀有度**：稀有（Rare）
- **建议投放**：契约神殿、法师塔合作任务、联合作战指挥所。

## 书籍内容

契约书是一份空白的神圣协议，施术者用自己的生命力换取他人的魔力。作者强调这不是债务，而是“在被需要时选择给出自己多余的部分”。契约生效前，双方必须在书上按下手印，并说出各自愿意为对方放弃的东西。书中警告，若施术者把牺牲当作控制他人的手段，契约会变成吸血。后半部分收录了多位法师与牧师合作的案例，证明献身契约在长时间战斗中能扭转局势。最末页写着：“你给出的不是血，是你对‘我们一起走到最后’这句话的同意。”作者在契约模板下方用小字注明：若接收方在恢复魔力后没有向施术者道谢，契约不会失效，但双方的信任会在下一次战斗中受到考验。书中还说明，契约书在使用后会自燃一角，三次后需重新向教会申请新页。献身契约书的最后提醒：契约不会因为一方忘记而失效，但遗忘会让下一次牺牲变得加倍沉重。

## 设计意图

提供 HP 与 MP 资源转换技能，促进牧师与法师等高耗蓝职业的战术配合。
