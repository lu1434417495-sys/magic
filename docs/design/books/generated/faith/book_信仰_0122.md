# 《审判之锤锻造录》

## 基础信息

- **书籍 ID**：`book_信仰_0122`
- **关联技能**：`faith_judgment_hammer_122`
- **使用效果**：阅读后解锁 `faith_judgment_hammer_122`；若已学会，提升该技能 `current_mastery +100`，并使锤/链枷类攻击对生命值低于 30% 的敌人暴击率提高 15%。
- **阅读要求**：角色职业标签含 `paladin` 或 `holy_warrior`；基础 `力量 ≥ 8` 或 `意志 ≥ 8`。
- **稀有度**：精良（Uncommon）
- **建议投放**：圣骑士工坊、审判庭军械库、矮人铁匠铺。

## 书籍内容

锻造录从选矿开始，强调审判之锤的金属必须混入了“被誓言祝福过的灰烬”。作者详细讲解锤头的重心、柄长与握法，指出审判之锤不是用来炫耀力量，而是用来“让罪人听见自己的重量”。书中列出三种锤型：断罪型加重锤头以追求一击制敌，慈悲型在握柄处留空以控制伤害，警示型敲击地面产生震慑波纹。后半部分是维护仪式，要求使用者在每次战斗后用清水洗净锤身，并默念自己当日审判的动机。最末页写着：“锤子落下时，你要同时审判自己是否有资格举起它。”锻造录的附录里有一页专门讲解如何辨认金属中的灰烬是否经过祝福：真正的祝福灰烬在黑暗中会发出极微弱的蓝光，而普通灰烬只会发灰。书中还提到，审判之锤对从未伤害过无辜者的人会明显变轻。锻造录的最后记载了一个传说：某位圣骑士在临终前把审判之锤熔成农具，锤身上的祝福灰烬因此散入麦田。

## 设计意图

为圣骑士/信仰战士提供武器专精与处刑向被动，突出审判主题的重量感。
