# 《临终涂油的程序》

## 基础信息

- **书籍 ID**：`book_faith_0040`
- **关联技能**：`faith_last_anoint`
- **使用效果**：阅读后解锁 `faith_last_anoint`；若已学会，提升该技能 `current_mastery +90`，并在对濒死目标施放治疗时额外清除一个负面状态。
- **阅读要求**：角色拥有 `holy` 或 `support` 标签职业；基础 `感知 ≥ 8`。
- **稀有度**：稀有（Rare）
- **建议投放**：安宁病房、战场救护站、大教堂临终关怀所。

## 书籍内容

临终涂油的程序把最后的告别变成一套庄严的动作。书中规定需要涂抹五个部位：额头代表思想、眼睑代表视觉、嘴唇代表言语、手心代表行动、脚心代表旅程。每一个部位都对应一句简短的赦免语，涂油者必须一边说一边用手指把温热的油轻轻按进皮肤。作者提醒，涂油时最重要的不是技巧，而是不要避开临终者的目光，因为很多人在最后一程最需要的是被看见。最感人的章节是"家属指南"，教导亲人如何在涂油后握住逝者的手，而不去打扰信仰者完成仪式。书末用细线装订了一页空白，标题是"我的最后一句话"，供读者提前写下想留给世界的话。安宁病房的志愿者会反复练习这套程序，直到能在黑暗中凭触觉完成所有步骤。因为他们知道，临终者最后看见的可能是涂油者专注而温柔的脸。

## 设计意图

为信仰系治疗添加濒死驱散维度，用临终关怀叙事深化治疗的情感价值，适合剧情向支线设计。
