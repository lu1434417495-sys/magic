# 《信仰坚韧》

## 基础信息

- **书籍 ID**：`book_信仰_0074`
- **关联技能**：`faith_fortitude`
- **使用效果**：阅读后解锁 `faith_fortitude`；若已学会，提升该技能 `current_mastery +75`，并使受到控制效果的持续时间减少 1 回合。
- **阅读要求**：角色职业标签含 `priest`、`cleric` 或 `paladin`；基础 `体质 ≥ 8` 或 `意志 ≥ 9`。
- **稀有度**：普通（Common）
- **建议投放**：苦修训练场、前线牧师营地、意志试炼奖励。

## 书籍内容

身体可以被束缚，但信仰不能被折断。《信仰坚韧》教导牧师如何通过坚定的信念抵抗恐惧、魅惑、麻痹等精神控制效果。书中指出，坚韧不是天生的性格，而是可以通过训练获得的技能。第一章讲解"信念锚定法"，要求练习者在平静时选定一句核心信条，在受控时默念它以唤回意识。第二章讨论身体与精神的联动，说明放松肩膀与深呼吸能有效削弱控制效果的影响。作者警告，信仰坚韧不能替代警惕心，过度自信反而会让牧师陷入更危险的境地。后半部收录了多种常见控制效果的应对策略，包括恐惧时的侧身移动、魅惑时的自我伤害提醒、麻痹时的集中感官等。最末页的插图是一名牧师在敌人的恐惧光环中单膝跪地，双手合十，脸上的表情逐渐从惊恐转为平静。信仰坚韧是信仰系提升生存能力的基础技能。

## 设计意图

为信仰系提供抗控制能力，确保牧师在混乱战场上仍能稳定施法与治疗。
