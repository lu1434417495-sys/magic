# 《默观圣像技法》

## 基础信息

- **书籍 ID**：`book_信仰_0140`
- **关联技能**：`faith_icon_gaze_140`
- **使用效果**：阅读后解锁 `faith_icon_gaze_140`；若已学会，提升该技能 `current_mastery +80`，并使战斗前凝视圣像可在首回合获得 5% 全抗性增益。
- **阅读要求**：无职业限制；基础 `意志 ≥ 7`。
- **稀有度**：普通（Common）
- **建议投放**：修道院画室、圣像工坊、朝圣者摊位。

## 书籍内容

技法书教人如何观看圣像，而不是如何绘制圣像。作者说圣像不是艺术品，而是“凝视的锚点”，让观看者在混乱中找到稳定的中心。书中把观看分为三层：第一层看形象，第二层看象征，第三层看自己内心被形象唤起的部分。作者提醒不要长时间凝视愤怒或审判主题圣像，否则容易激发攻击性。后半部分附有十二幅经典圣像的简短解读，每幅都配有一句适合默念的短祷。最末页写着：“你不需要看懂圣像，你只需要允许自己被它看见。”作者在技法书的前言中写道：圣像不会主动医治任何人，它只是站在那里，等你自己决定要不要被看见。书中还建议，观看圣像前必须先安静呼吸七次，否则眼睛会只看见颜料而非光。技法书的附录里附有一幅圣像清洁图，说明灰尘不会减弱圣像的力量，但遮挡会，因为观看需要直接的相遇。
