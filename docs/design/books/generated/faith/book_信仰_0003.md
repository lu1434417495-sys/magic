# 《灰烬圣印的烙制法》

## 基础信息

- **书籍 ID**：`book_faith_0003`
- **关联技能**：`faith_ash_seal`
- **使用效果**：阅读后解锁 `faith_ash_seal`；若已学会，提升该技能 `current_mastery +100`，并使圣印对灰烬系敌人的驱散判定额外加 5。
- **阅读要求**：角色拥有 `holy` 或 `cleric` 标签职业；基础 `智力 ≥ 8`。
- **稀有度**：稀有（Rare）
- **建议投放**：炭化大教堂密室、灰烬交界前哨战利品、高阶审判官掉落。

## 书籍内容

灰烬圣印来自被焚毁的大教堂废墟，它的烙具不是铁，而是冷却后的教堂残砖。书中首先教导读者如何调配圣灰与清水，把灰浆制成可短暂附着于武器或地面的印泥。接着详细描述七种基础印纹：封锁、净化、引导、怜悯、审判、回归与沉默，每一种都有独特的闭合节点。作者反复强调，烙印时手腕不能抖动，因为颤抖会被圣印解读为"不确定"，从而降低其持续时间。最晦涩的一节讨论如何在灰烬交界的腐蚀气息中保持印纹清晰：需要在印泥里加入一滴诵读者自己的泪水。书的最后几页被烧去一半，只留下一句话："圣印不是权力的盖章，而是你愿意替谁承担痛苦的签名。"大教堂的修复者曾试图重制这些残砖，却发现新砖烧出的印纹缺乏韧性，仿佛废墟本身也记得那场大火。于是原初的残砖被小心翼翼地编号保存，每一块都对应一段不可复制的历史。

## 设计意图

为信仰系提供针对灰烬交界的专属控制与驱散手段，同时用"泪水"等细节强化牺牲与契约的主题。
