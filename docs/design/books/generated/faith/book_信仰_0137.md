# 《慈悲停战令》

## 基础信息

- **书籍 ID**：`book_信仰_0137`
- **关联技能**：`faith_mercy_truce_137`
- **使用效果**：阅读后解锁 `faith_mercy_truce_137`；若已学会，提升该技能 `current_mastery +100`，并允许每场战斗中一次令生命值低于 25% 的非首领敌人跳过下一回合。
- **阅读要求**：角色拥有 `holy` 或 `support` 标签职业；基础 `意志 ≥ 9`。
- **稀有度**：稀有（Rare）
- **建议投放**：和平使者营地、外交任务、战俘营。

## 书籍内容

停战令不是投降书，而是一份教圣职者如何“让战斗暂停”的手册。作者认为真正的慈悲不是治愈伤口，而是在伤口出现之前阻止下一次挥刀。书中列出停战令的三个条件：敌人必须还有理智、施术者必须没有复仇意图、双方都必须看到另一种结局的可能。后半部分收录了多场因停战令而避免的血战，也记录了失败案例：一名牧师因误判敌人本性而导致同伴被杀。最末页写着：“慈悲不是软弱，是你明明能杀，却选择给出一个不是杀的理由。”作者在总结时提醒，慈悲停战令的成功率与施术者是否真心相信敌人仍有选择密切相关，任何隐藏的轻视都会让停战令在念完前失效。书中还提到，停战令对野兽与亡灵无效，因为它们无法认知“另一种结局”。停战令的附录里列有失败的代价：施术者若被证明心怀怜悯但判断错误，将失去一个月的施法能力作为补偿。

## 设计意图

为信仰系提供非致命控制技能，让“慈悲”在战棋中有具体的战术表达。
