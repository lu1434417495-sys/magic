# 《神圣连结》

## 基础信息

- **书籍 ID**：`book_信仰_0088`

- **使用效果**：阅读后解锁 `faith_divine_link`；若已学会，提升该技能 `current_mastery +85`，并使连结期间分担伤害的比例提升 10%。
- **阅读要求**：角色职业标签含 `priest` 或 `cleric`；基础 `信仰 ≥ 9` 且 `意志 ≥ 8`。
- **稀有度**：稀有（Rare）
- **建议投放**：团队牧师高级训练、守护骑士任务、信仰阵营剧情奖励。

## 书籍内容

《神圣连结》教导牧师如何在两名角色之间建立一条神圣纽带，使他们共享部分伤害与治疗效果。书中把连结比作婚姻中的誓言：不是束缚，而是选择共同承担。第一章讲解连结的建立方法，通常需要双方同意并同时默念相同的祷词。第二章讨论连结的类型：生命连结分担伤害，法力连结共享 MP，感知连结则能让双方感知彼此的位置与状态。作者警告，连结一旦建立，任何一方的极端情绪都会影响另一方，因此不适合与精神状态不稳定者连结。后半部收录了多个战场案例，其中最著名的是一名牧师与重伤战士连结，用自己的生命为对方争取了反击的时间。最末页的插图是两条发光的细线从两人胸口延伸出来，在空中交织成一颗心形符文。神圣连结是信仰系保护关键队友的重要手段。

## 设计意图

为信仰系提供伤害分摊与治疗共享机制，强化牧师对关键目标的重点保护能力。
