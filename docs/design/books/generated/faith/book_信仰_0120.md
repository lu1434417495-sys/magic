# 《圣餐礼仪轨》

## 基础信息

- **书籍 ID**：`book_信仰_0120`
- **关联技能**：`faith_eucharist_120`
- **使用效果**：阅读后解锁 `faith_eucharist_120`；若已学会，提升该技能 `current_mastery +80`，并使营地处食物/饮水时额外获得下一场战斗最大 `hp +5%` 的增益。
- **阅读要求**：角色拥有 `holy` 或 `support` 标签职业；基础 `意志 ≥ 7`。
- **稀有度**：普通（Common）
- **建议投放**：修道院餐厅、教会厨房、营地后勤官。

## 书籍内容

礼轨详细记录了圣餐的每一步：洗手、分饼、举杯、祝谢、分发。作者指出圣餐的核心不是食物本身，而是“把日常进食变成共同记忆”。书中要求主持者必须在分食前说出这顿饭的来源与准备者的名字，以对抗战场上常见的麻木感。后半部分收录了战地圣餐的简化版本，用干粮和水代替面饼与酒，但保留“看彼此眼睛”的关键步骤。最末页写着：“在最坏的年月里，圣餐是让人们还记得自己属于彼此的仪式；只要这一点还在，队伍就不会散。”礼轨要求主持者在分饼时先掰开自己的那一块，因为作者相信只有先承认自己也会饿、也会害怕的人，才有资格把食物递给别人。书中还提醒，圣餐后的一个小时内，参与者对恐惧的抗性会略有提升，这是信仰共同体的余温。礼轨在附录里说明，圣餐的主持者若当日心中有未化解的怨恨，应当先把怨恨写在纸上焚烧，否则仪式会被污染。

## 设计意图

将营地吃饭行为仪式化，为队伍提供战前准备 buff，强化信仰系的团队凝聚力主题。
