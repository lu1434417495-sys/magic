# 《圣印刻画入门》

## 基础信息

- **书籍 ID**：`book_信仰_0113`
- **关联技能**：`faith_holy_seal_113`
- **使用效果**：阅读后解锁 `faith_holy_seal_113`；若已学会，提升该技能 `current_mastery +80`，并使祝福武器攻击有 15% 概率附加圣印标记，使来自神圣来源的伤害额外提高。
- **阅读要求**：角色职业标签含 `holy`；基础 `智力 ≥ 8` 或 `意志 ≥ 8`。
- **稀有度**：精良（Uncommon）
- **建议投放**：符文工坊、圣印师行会、古老图书馆。

## 书籍内容

入门手册从最简单的圆开始，讲解如何把信仰凝固成可携带的印记。作者说圣印不是装饰，而是“把一句誓言压缩成一个可以触摸的符号”。书中列出七种基础圣印：守护、审判、治愈、封印、引导、牺牲、警醒，每个圣印都有对应的手势与呼吸节奏。后半部分用大量图示说明刻印时常见的错误：线条断裂代表意图犹豫，角度歪斜代表心存杂念。最末页是一张练习用圣印，下面写着：“真正的圣印在你刻完之前就已经生效，因为它改变的是刻画者，而不是被刻之物。”作者建议初学者先用炭笔在纸上练习三百次，直到手腕能在不看的情况下也能画出完美圆形，因为真正生效的不是图案，而是刻画时不再犹豫的手。书中还警告，圣印一旦刻下，在誓言完成前无法擦除，因此刻画前必须确认自己的决心。作者在最后提醒：圣印的效果会在你违背誓言时自动消失，而消失的速度往往比你想象中更快。

## 设计意图

为祝福武器与神圣输出提供连携机制，通过圣印标记丰富 faith build 的战术深度。
