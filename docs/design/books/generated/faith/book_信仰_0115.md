# 《狂热誓言》

## 基础信息

- **书籍 ID**：`book_信仰_0115`
- **关联技能**：`faith_zealot_oath_115`
- **使用效果**：阅读后解锁 `faith_zealot_oath_115`；若已学会，提升该技能 `current_mastery +80`，并在接下来 5 场战斗中造成伤害提高 10%，但最大 `hp` 降低 5%。
- **阅读要求**：角色职业标签含 `paladin`、`crusader` 或 `holy_warrior`；基础 `意志 ≥ 8`。
- **稀有度**：精良（Uncommon）
- **建议投放**：狂热者营地、远征军先锋营、失序神殿。

## 书籍内容

狂热誓言书用烫金大字写着：“以全部换一瞬。”书中教导战士如何通过庄严誓言燃烧自己的生命力，换取短时间内惊人的神圣打击力。作者把狂热分为“清醒的狂热”与“盲目的狂热”，前者知道自己的代价，后者把代价当成荣耀。书中要求宣誓者必须说出自己愿意放弃的具体事物：一只手、十年寿命、或某个记忆，模糊的誓言无法生效。后半部分记录了多位宣誓者的结局，大多数在战斗后陷入长久的虚弱。最末页被火焰烧去一角，仅剩的话是：“如果你念完誓言后笑了，光会拒绝你；如果你哭了，它也不会因此偏爱你。”作者在附录里给出一组身体信号，教战士识别狂热即将失控的前兆：指尖发麻、视野边缘泛白、对同伴的声音产生轻微敌意。书中还提醒，同一誓言不能反复使用，否则身体会习惯燃烧，最终彻底枯竭。

## 设计意图

为信仰战士提供高风险增益技能，用代价机制避免“狂热”沦为无脑增伤。
