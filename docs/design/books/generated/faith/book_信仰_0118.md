# 《天使号角乐谱》

## 基础信息

- **书籍 ID**：`book_信仰_0118`
- **关联技能**：`faith_angelic_horn_118`
- **使用效果**：阅读后解锁 `faith_angelic_horn_118`；若已学会，提升该技能 `current_mastery +100`，并在战斗开始时为全体友方施加持续 3 回合的意志/士气提升 10% 的增益。

## 书籍内容

乐谱由一连串高亢而克制的音符组成，传说中能模仿天使宣告战况的号角声。作者提醒，吹奏者必须站定、深吸一口气，因为号角的声音会先扫过自己，再抵达他人；若吹奏者内心动摇，第一个被击溃的将是自己。书中把乐谱分为“集结号”“警戒号”“送行号”三段，分别对应开战、转折与结束。后半本讲述了历代号手的命运：许多人因吹响送行号而失声数日。最末页的空白处有一行小字：“天使从不亲自吹响号角，他们借人的嘴唇告诉世界——我们还在。”乐谱的夹页里有一段警告：送行号一旦吹响，吹奏者会在接下来三天内反复梦见自己告别的人，因此只有准备好接受梦境的人才能学习最后一段。书中还建议，每次吹奏前必须向听众说明这是号角还是普通乐曲，以免误判引发恐慌。乐谱的封底印着一句古老的号手格言：吹响送行号的人，必须先学会如何在不吹响时陪伴别人。

为信仰系提供开战群体 buff，用音乐与天使意象扩展辅助技能的演出空间。
