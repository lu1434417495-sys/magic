# 《微光祷言入门》

- **书籍 ID**：`book_faith_0001`
- **关联技能**：`faith_glimmer_prayer`
- **使用效果**：阅读后解锁 `faith_glimmer_prayer`；若已学会，提升该技能 `current_mastery +80`，并恢复施术者少量 `current_mp`。

## 书籍内容

这本书是信仰之路上的第一盏灯。它没有复杂的仪式，只要求读者在日出前低声重复三段祷词，直到声音与心跳逐渐同步。作者强调，微光祷言的力量不在于音量，而在于承认自己需要被照亮的那一瞬间。书中用大量插图展示手势：双手交叠于胸口，食指微微抬起，像承接一滴即将落下的露水。练习者常被要求在烛光将尽时念诵，因为黑暗会让意念更加集中。末尾附有一则警告：若有人在念诵时想着惩罚敌人，微光会立刻熄灭，因为它只回应软弱与恳求。整本书的纸张泛黄，边缘被无数拇指摩挲出毛边，可见多少初学者曾将它当作救命稻草。在一些偏远的村庄，这本书常被夹在婴儿的襁褓里，人们相信最早的光明祝福应当从生命之初便开始陪伴。而教会图书馆的记录显示，它的发行量远超任何一部华丽经文，因为平凡人更需要一盏不挑剔持有者的灯。
