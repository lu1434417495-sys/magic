# 《圣痕显现的预备》

## 基础信息

- **书籍 ID**：`book_faith_0012`
- **关联技能**：`faith_stigma_manifest`
- **使用效果**：阅读后解锁 `faith_stigma_manifest`；若已学会，提升该技能 `current_mastery +100`，并在生命值低于 30% 时提高神圣伤害 15%。
- **阅读要求**：角色拥有 `holy`、`zealot` 或 `paladin` 标签职业；基础 `体质 ≥ 10`。

- **建议投放**：殉道者陵墓、狂信徒试炼、圣痕事件任务。

## 书籍内容

圣痕显现不是主动追求的能力，而是身体在极端信仰压力下自然浮现的印记。书中首先告诫读者不要故意自伤，因为伪造的圣痕会反噬施术者的 MP。接着描述了三种常见圣痕：掌心灼痕、肩胛羽翼状淤血、胸口十字形低热，每一种对应不同的神圣共鸣频率。作者详细记录了显现前身体发出的信号：连续三晚做同一个梦、对金属味道异常敏感、听见远处钟声但周围并没有钟。书中最为珍贵的部分是一位匿名修女的日记，她在日记里承认，圣痕最痛的不是伤口，而是伤口带来的"被选中"的孤独。附录里有几页空白，标题为"你的圣痕"，鼓励读者只记录属于自己的体验，而不是模仿前人。圣骑士团内部有专门观察员负责记录每位显现者的征兆，试图找出规律，却不得不承认每个人的信仰质地都不相同。这份不可复制性，正是圣痕最令研究者着迷的地方。

为狂信者与圣骑士设计低血量爆发的神圣伤害机制，用"圣痕"叙事将痛苦与神恩绑定，强化高风险高回报风格。
