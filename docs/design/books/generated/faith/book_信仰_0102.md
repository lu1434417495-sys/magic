# 《信仰护盾讲义》

## 基础信息

- **书籍 ID**：`book_信仰_0102`
- **关联技能**：`faith_divine_shield_102`
- **使用效果**：阅读后解锁 `faith_divine_shield_102`；若已学会，提升该技能 `current_mastery +80`，并在接下来三场战斗中开场获得 1 层圣盾。
- **阅读要求**：角色拥有 `holy` 或 `support` 标签职业；基础 `意志 ≥ 7`。
- **稀有度**：普通（Common）
- **建议投放**：城镇神殿、前线救护站、圣骑士训练营。

## 书籍内容

护盾讲义从一面破碎的圆盾讲起。作者认为，信仰护盾并非坚硬的外壳，而是一层“被允许承担的重量”。书中将护盾拆解为意图、呼吸和焦点三步：先承认危险存在，再把恐惧压成一条直线，最后用信念将其推开。作者批评了许多新人把护盾当成拒绝世界的墙壁，结果墙壁倒塌时施术者会被碎片反噬。后半本列出常见失效场景：在护盾中蓄意欺骗、用护盾炫耀、为不值得的人强行维持护盾。最后一章附有一张手绘图解，展示护盾应像雨伞一样覆盖自己与他人，而不是把自己封在球里。讲义中间夹着一张旧盾碎片，边缘刻着一行小字，提醒读者护盾在破裂前往往会先变薄，那是它在替穿戴者争取最后几秒钟。书中还提醒，护盾的强度与施术者是否愿意移动有关，越想让护盾替自己挡住一切的人，越难让它真正成形。末尾写道：“最坚固的盾，来自你终于愿意保护某样东西的那一刻。”

## 设计意图

强化圣职系前排与辅助的守护定位，让护盾从数值防御转向“信念—责任”的情感机制。
