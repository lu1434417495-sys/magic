# 《治愈赞美诗抄本》

## 基础信息

- **书籍 ID**：`book_信仰_0105`
- **关联技能**：`faith_heal_hymn_105`
- **使用效果**：阅读后解锁 `faith_heal_hymn_105`；若已学会，提升该技能 `current_mastery +80`，并令队伍在战斗外聆听时恢复全队少量 `current_hp`。
- **阅读要求**：角色拥有 `holy` 或 `support` 标签职业；基础 `智力 ≥ 7` 或 `意志 ≥ 7`。
- **稀有度**：普通（Common）
- **建议投放**：教堂唱诗班、医院礼拜堂、流浪吟游诗人行囊。

## 书籍内容

抄本收录三首短赞美诗，专为战场救护而写。与寻常祷文不同，这些诗句刻意采用重复的旋律，让受伤的士兵能在半昏迷中跟随节奏呼吸。作者指出，治愈赞美诗的真正施术者是整个吟唱团体，领唱者只负责把光引入和弦。书中详细记录了不同伤口对应的节拍：外伤用舒缓的四拍，内伤用沉稳的二拍，精神创伤则用不规律的自由拍。后半本是音符与手势的对照表，提醒读者不要在歌词结束时立刻停止，而要等余音散尽才放手。抄本的装订线里夹着几根干枯的草药，据说是第一位编写者留下的，用来提醒读者赞美诗与草药一样，需要被反复使用才会生效。书中还提到，唱赞美诗时若有人哭泣，不应制止，因为眼泪是身体在跟随旋律排毒。最后一页写着：“歌声停止后，光还会多留三秒，那是给伤者学会再次相信自己还活着的时间。”

## 设计意图

用音乐性包装群体治疗，让牧师在营地与战场都有独特的“仪式恢复”体验。
