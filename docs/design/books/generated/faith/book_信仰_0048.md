# 《迷失灵魂的呼唤》

## 基础信息

- **书籍 ID**：`book_faith_0048`
- **关联技能**：`faith_lost_soul_call`
- **使用效果**：阅读后解锁 `faith_lost_soul_call`；若已学会，提升该技能 `current_mastery +100`，并提高对幽灵、怨灵类敌人的命中率 10%。
- **阅读要求**：角色拥有 `holy`、`mage` 或 `cleric` 标签职业；基础 `感知 ≥ 9`。
- **稀有度**：稀有（Rare）
- **建议投放**：墓园事件、幽灵森林、亡灵战役支线。

## 书籍内容

迷失灵魂的呼唤教导信仰者如何用声音接触那些不愿离去的灵魂。书中认为，大多数幽灵并非恶意，而是被困在一段没有说完的话里。呼唤者需要先安静下来，倾听环境中不协调的声响，然后用逝者的名字或生前最常用的小名轻声呼唤，而不是使用通用的祷词。作者提醒，呼唤时必须保持情感真实，因为灵魂能分辨出怜悯与恐惧的区别。最危险的章节描述如何为被强行束缚的灵魂打开出口：需要用言语替它们说出它们自己无法承认的遗憾，然后才能引导它们离开。书末附有一张名单，上面是作者一生中呼唤过的灵魂，有些名字后面画着对勾，有些则画着问号。墓园管理者会定期举办小型呼唤仪式，帮助逝者与家属完成最后的告别。这些仪式往往没有惊天动地的场面，只有一声轻唤和一阵突然变温柔的风。

## 设计意图

为信仰系提供对灵体敌人的针对性能力，同时用"未竟之言"概念深化与亡灵相关的剧情任务设计。
