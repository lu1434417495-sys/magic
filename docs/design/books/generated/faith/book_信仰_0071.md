# 《惩戒之光》

## 基础信息

- **书籍 ID**：`book_信仰_0071`
- **关联技能**：`faith_smite`
- **使用效果**：阅读后解锁 `faith_smite`；若已学会，提升该技能 `current_mastery +85`，并使对单一目标的伤害提升 12%，对标记邪恶目标必中。
- **阅读要求**：角色职业标签含 `priest`、`cleric` 或 `inquisitor`；基础 `信仰 ≥ 9`。
- **稀有度**：稀有（Rare）
- **建议投放**：审判庭基础教材、圣骑士营地、讨伐邪恶任务奖励。

## 书籍内容

《惩戒之光》是信仰系最经典的攻击神术教材之一，几乎每个战斗牧师都曾在某处读过它的简化版。书中教导如何从掌心或法器顶端射出一束凝聚的神圣光束，直接贯穿敌人的防御。第一章讲解光束的凝聚方法，要求施术者在心中明确审判的理由，因为模糊的信念会让光束散开。第二章讨论目标的判定，指出惩戒之光对 actively 伤害无辜者的敌人效果最强，对只是立场不同的对手则威力大减。作者反复强调，此术是"惩戒"而非"处刑"，其目的在于制止罪恶，而非满足施术者的愤怒。后半部收录了多种战术应用，包括打断敌方施法、引爆黑暗能量、以及作为信号弹使用。书中还提到，惩戒之光在狭窄空间中会产生反射，熟练者可以利用这一点攻击掩体后的敌人。最末页的插图是一道光柱从天而降，将一名持刀的强盗钉在原地。惩戒之光简单、直接、有效，是信仰系不可或缺的远程攻击手段。

## 设计意图

为信仰系提供标准远程神圣攻击技能，确立牧师在战斗中的基础输出定位。
