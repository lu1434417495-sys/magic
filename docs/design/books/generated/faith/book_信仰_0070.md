# 《信仰共鸣》

## 基础信息

- **书籍 ID**：`book_信仰_0070`
- **关联技能**：`faith_resonance`
- **使用效果**：阅读后解锁 `faith_resonance`；若已学会，提升该技能 `current_mastery +90`，并使共鸣范围内每多一名信仰系队友，所有神术效果提升 8%。
- **阅读要求**：角色职业标签含 `priest`、`cleric` 或 `paladin`；基础 `信仰 ≥ 9`。
- **稀有度**：稀有（Rare）
- **建议投放**：多人信仰副本、教会合唱堂、团队牧师训练场。

## 书籍内容

当多名信徒同时祈祷，他们的信仰会产生共鸣，形成比个体之和更强大的力量。《信仰共鸣》教导牧师如何感知并加入这种共鸣，使自己的神术与队友产生协同。书中把共鸣比作合唱：每个人的声音不必相同，但必须和谐。第一章讲解如何识别共鸣的"调性"，即当前团队中主导的信仰频率。第二章讨论不同神术在共鸣中的叠加规则，治疗术会扩大覆盖范围，攻击术会提升穿透力，防御术则会延长持续时间。作者警告，若团队中有人信仰不纯，共鸣会被污染，甚至反噬全体成员。后半部收录了多个经典共鸣阵型，包括三角守护阵、环形治疗阵与锋矢审判阵。最末页的插图是一群牧师围成圆圈，每个人的光芒通过地面相连，形成复杂的符文图案。信仰共鸣让多名牧师组队时发挥出超乎寻常的战斗力。

## 设计意图

为信仰系设计多人协同机制，鼓励团队中配置多名信仰职业，形成独特的战术体系。
