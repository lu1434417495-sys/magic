# 《驱邪祷文汇编》

## 基础信息

- **书籍 ID**：`book_信仰_0107`
- **关联技能**：`faith_exorcism_chant_107`
- **使用效果**：阅读后解锁 `faith_exorcism_chant_107`；若已学会，提升该技能 `current_mastery +100`，并对附身/诅咒状态敌人附加净化层数 +1。
- **阅读要求**：角色职业标签含 `priest` 或 `inquisitor`；基础 `意志 ≥ 9`。
- **稀有度**：精良（Uncommon）
- **建议投放**：驱魔师公会、被诅咒宅邸书房、边境修道院。

## 书籍内容

汇编收录各地驱魔师在实践中保留下来的有效祷文，其中不乏粗俗方言和错漏字母。作者提醒，驱邪的关键不在祷文是否优美，而在诵读者是否真正相信被附身者还有被拯救的价值。书中把驱邪分为三个阶段：隔离、对话、驱逐，每个阶段都需要不同的人性判断。后半部分记录了十几个失败案例，失败原因多为驱魔师把被附身者当成敌人。最末附有一张手绘符印，标注着“此符只在施术者愿意替对方承受一部分痛苦时生效”。汇编的封皮内侧写着一段警告：若你在驱邪后立刻回到人群中，你带回去的可能不是平安，而是黑暗还没来得及散尽的余温。书中还警告，驱魔后施术者必须独处一夜，因为被驱逐的黑暗往往会先尝试附在离它最近的人身上。最后一行字被划掉又重写：“恶魔最怕的不是光，是你不肯放弃那个人。”

## 设计意图

为圣职系提供净化/控制向技能，强化对特殊状态敌人的战术价值。
