# 《神圣化身》

## 基础信息

- **书籍 ID**：`book_信仰_0079`
- **关联技能**：`faith_divine_avatar`
- **使用效果**：阅读后解锁 `faith_divine_avatar`；若已学会，提升该技能 `current_mastery +95`，并使化身期间所有神术消耗降低 30%。
- **阅读要求**：角色职业标签含 `priest` 或 `cleric`；基础 `信仰 ≥ 10` 且 `意志 ≥ 9`。
- **稀有度**：史诗（Epic）
- **建议投放**：神明降临剧情、最高难度团队副本、信仰阵营终极奖励。

## 书籍内容

《神圣化身》是信仰系最高深的典籍之一，书中记载了一种让凡人短暂承载神性的危险神术。化身期间，施术者的双眼会发出金光，身体被神圣能量包裹，各项能力大幅提升。第一章讲解化身前的准备，要求施术者先进行长达数日的净化与禁食，以确保身体不会被神力烧毁。第二章讨论化身中的意识状态，指出施术者仍会保留自我意识，但会被放大到接近神明的视角，容易对凡人产生冷漠。作者警告，神圣化身结束后施术者会陷入极度虚弱，若频繁使用可能导致不可逆的灵魂损伤。后半部收录了历史上几次神圣化身的记录，每次出现都伴随着重大历史转折。最末页的插图是一名牧师悬浮于战场之上，光芒从他身上倾泻而下，敌人在光辉中溃散。神圣化身是信仰系最具威慑力的终极技能之一。

## 设计意图

为信仰系提供爆发型终极变身技能，在关键战斗中制造碾压性优势，同时以虚弱后果平衡强度。
