# 《预言残页的拼读》

## 基础信息

- **书籍 ID**：`book_faith_0030`
- **关联技能**：`faith_prophecy_read`
- **使用效果**：阅读后解锁知识 `faith_prophecy_read`；阅读完成后提升感知判定 3，并有几率在事件选择前获得一条模糊提示。
- **阅读要求**：角色拥有 `holy`、`mage` 或 `scholar` 标签职业；基础 `智力 ≥ 9`。
- **稀有度**：史诗（Epic）
- **建议投放**：古老图书馆、先知遗迹、大教堂密档室。

## 书籍内容

预言残页的拼读是一本教人如何从碎片中看出整体的技巧书。书中收集了大量烧焦、水渍、虫蛀的预言残页，要求读者不依赖上下文，而是通过字迹的倾斜、墨色的深浅、以及纸张破损的形状来推断原意。作者认为，真正的预言从不直接告诉未来，而是把未来的气味留在字里行间。最实用的章节是"拼读七问"：谁在说话、对谁说、在何种情绪下、被隐藏的词是什么、与已知历史是否冲突、是否服务于某个权力、以及最后一条——它是否让你更勇敢。书中还警告，有些残页是故意伪造以操纵决策，识别伪造的最佳方法是看它们是否每次都指向同一个受益者。封面上烫金的眼睛图案已经磨损，只剩一只瞳孔。古代图书馆的管理员把这本书当作入职测试，要求学徒在三个月内从十张残页中找出三张伪造品。通过率不足三成，因为伪造者越来越擅长模仿预言的口吻。

## 设计意图

作为知识型书籍，为信仰与学者职业提供事件提示能力，同时增加世界观的神秘与政治层次。
