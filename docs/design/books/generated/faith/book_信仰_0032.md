# 《断罪之眼的开启》

## 基础信息

- **书籍 ID**：`book_faith_0032`
- **关联技能**：`faith_eye_of_judgment`
- **使用效果**：阅读后解锁 `faith_eye_of_judgment`；若已学会，提升该技能 `current_mastery +100`，并提高对敌人的弱点侦测成功率 10%。
- **阅读要求**：角色拥有 `holy`、`paladin` 或 `inquisitor` 标签职业；基础 `感知 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：审判庭训练室、异端讨伐战、大教堂地下档案。

## 书籍内容

断罪之眼的开启不是字面意义上的眼睛变化，而是一种让施术者看穿伪装的凝视技艺。书中要求读者先练习盯着烛火看，直到能在火焰周围看见一圈稳定的轮廓，再把这种凝视转移到人身上。作者强调，断罪之眼不是为了寻找敌人的罪，而是为了确认自己没有被仇恨蒙蔽。最危险的章节描述了一种进阶用法：在战斗中短暂关闭自己的情感反应，只接收纯粹的行动信息，这种状态下能更准确地判断敌人的下一次攻击。书中也记录了失控案例：某位审判官过度使用断罪之眼，最终看谁都像罪人，连自己的影子都不放过。书末有一页被涂黑，旁边小字注明："真正需要被审判的，往往是那个举起审判之刃的人。"审判庭的新兵必须在封闭房间里连续三天使用断罪之眼观察同一个囚犯，以测试自己的稳定性。许多人在这项测试后选择放弃这条道路。

## 设计意图

为信仰系提供侦查与弱点定位能力，同时用"审判者反噬"叙事平衡强度，呼应战棋中的信息博弈。
