# 《神圣契约的缮写》

## 基础信息

- **书籍 ID**：`book_faith_0024`
- **关联技能**：`faith_holy_contract`
- **使用效果**：阅读后解锁 `faith_holy_contract`；若已学会，提升该技能 `current_mastery +90`，并延长与队友签订的增益契约持续时间 2 回合。
- **阅读要求**：角色拥有 `holy`、`cleric` 或 `leader` 标签职业；基础 `智力 ≥ 9`。
- **稀有度**：稀有（Rare）
- **建议投放**：公证人礼拜堂、佣兵契约所、大教堂文书室。

## 书籍内容

神圣契约的缮写把口头承诺变成可被信仰监督的文字。书中首先区分了三种契约：临时盟约、血誓与代赎契约，每一种需要不同的纸张、墨水与见证人。作者强调，缮写者本人必须相信契约的内容，否则墨水会在书写到一半时突然干涸。最实用的章节是违约条款的设计：不是用诅咒威胁，而是让违约者在未来祈祷时首先听见自己违背的承诺。书中还记录了古代圣骑士与农民签订的粮食保护契约，契约末尾写明："若我未能守护，则我亦无权接受下一餐的祝福。"附录里有一份空白模板，标题为"今日之约"，鼓励读者每天写下一件具体而微小的事并尽力完成。在大城市的契约所，神圣契约常被用于商业担保，但老缮写师会拒绝那些明显不义的条款。他们相信，一份连自己都不信的契约，即使签了名字，也不会被信仰承认。

## 设计意图

为信仰系提供团队增益契约机制，通过"缮写"概念把承诺与责任量化为战棋中的持续 buff。
