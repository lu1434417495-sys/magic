# 《信仰风暴》

## 基础信息

- **书籍 ID**：`book_信仰_0090`
- **关联技能**：`faith_storm`
- **使用效果**：阅读后解锁 `faith_storm`；若已学会，提升该技能 `current_mastery +90`，并使风暴范围内友方获得短暂加速，敌方移动力下降。
- **阅读要求**：角色职业标签含 `priest`、`cleric` 或 `paladin`；基础 `信仰 ≥ 9` 且 `智力 ≥ 8`。
- **稀有度**：稀有（Rare）
- **建议投放**：风暴神殿高级藏室、大规模战场任务、信仰阵营精英奖励。

## 书籍内容

当无数信徒同时祈祷，他们的信仰会汇聚成一场席卷战场的神圣风暴。《信仰风暴》教导牧师如何成为这场风暴的核心，引导信仰能量形成大范围的战场扰动。书中指出，风暴的力量来自集体，而非个人，因此施术者必须学会倾听与协调，而不是强行控制。第一章讲解风暴的召唤仪式，通常需要至少三名信仰者在不同方位同时起祷。第二章讨论风暴的效果：对友方是加速与净化，对敌方则是压制与致盲。作者警告，若信仰者之间存在分歧，风暴会分裂成互相冲突的气流，伤及所有人。后半部收录了历史上几次信仰风暴改变战局的记录，包括在围城战中瓦解敌军士气、在瘟疫中驱散邪气。最末页的插图是一场金色风暴席卷平原，友军在风中疾行，敌军则被狂风压制得寸步难行。信仰风暴是信仰系大规模战场控制技能。

## 设计意图

为信仰系提供多人协作型战场控制技能，强调团队协作与集体信仰的力量。
