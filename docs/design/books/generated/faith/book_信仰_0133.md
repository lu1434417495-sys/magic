# 《光辉披风裁制》

## 基础信息

- **书籍 ID**：`book_信仰_0133`
- **关联技能**：`faith_radiant_cloak_133`
- **使用效果**：阅读后解锁 `faith_radiant_cloak_133`；若已学会，提升该技能 `current_mastery +80`，并使披风位装备额外提供 5% 神圣抗性，同时略微提高仇恨生成。
- **阅读要求**：角色职业标签含 `holy`；基础 `体质 ≥ 7` 或 `意志 ≥ 8`。
- **稀有度**：精良（Uncommon）
- **建议投放**：神圣裁缝铺、圣殿骑士后勤、遗迹纺织工坊。

## 书籍内容

裁制书记录了如何为圣职者缝制披风，让布料成为光的载体。作者强调披风不是炫耀身份，而是“让身后的追随者能看见你站在哪里”。书中讲解三种披风款式：长摆型适合仪式与守护，短披风适合战斗机动，分层式可在不同光线下调整亮度。后半部分是染料与祝福配方：白色代表守护，金色代表审判，灰色代表灰烬中的坚持。最末页附有一张披风内衬的缝制图，批注：“把最珍贵的祷文缝在里层，光会从里面透出来，而不是从外面贴上去。”作者特别指出，披风的光泽不应来自染料，而应来自穿戴者长期暴露在危险中后留下的痕迹，那些痕迹才是真正的祝福。书中还提到，披风破损后必须亲手修补，委托他人修补会让披风逐渐失去对穿戴者意志的回应。裁制书的末页还警告：披风上的祷文若被外人看见，守护之力会减半，因为秘密本身就是信仰的一部分。
