# 《庇护圆环的绘制》

## 基础信息

- **书籍 ID**：`book_faith_0017`
- **关联技能**：`faith_shelter_circle`
- **使用效果**：阅读后解锁 `faith_shelter_circle`；若已学会，提升该技能 `current_mastery +90`，并扩大防御圆环的半径 1 格。
- **阅读要求**：角色拥有 `holy` 或 `support` 标签职业；基础 `智力 ≥ 8`。
- **稀有度**：稀有（Rare）
- **建议投放**：大教堂图书馆、防御战任务、难民庇护所。

## 书籍内容

庇护圆环的绘制是一本关于如何用信仰划定安全边界的教材。书中把圆环分为实线与虚线两种：实线用于物理防护，需要用盐、石灰或融化的烛蜡在地面上留下痕迹；虚线用于精神防护，仅靠行走与念诵即可完成。作者详细讲解绘制圆环时的呼吸节奏：吸气时落笔，呼气时抬笔，让圆环的每一小段都对应一次完整的祈愿。最实用的章节列举了七种常见错误，例如起点与终点没有重叠、在圆环内说出否定信念的话、以及绘制时回头张望。书中还提到，最强大的庇护圆环往往不是画在地上，而是画在施术者自己的心里。书的封面画着一个被圆环围住的小小人影，圆环外是风暴，圆环内是一盏灯。难民庇护所的夜晚，常能看到志愿者蹲在地上画圆环，为睡梦中的孩子圈出一片安心的区域。这些孩子长大后，很多也成为了画圆环的人。

## 设计意图

为信仰系提供范围防护技能，通过"绘制"机制把战棋地形互动与仪式准备结合起来。
