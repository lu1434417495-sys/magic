# 《亡灵超度指南》

## 基础信息

- **书籍 ID**：`book_信仰_0117`
- **关联技能**：`faith_undead_rites_117`
- **使用效果**：阅读后解锁 `faith_undead_rites_117`；若已学会，提升该技能 `current_mastery +100`，并使击败亡灵标签敌人时有 30% 概率额外掉落灵质残片。
- **阅读要求**：角色职业标签含 `priest` 或 `inquisitor`；基础 `意志 ≥ 9`。
- **稀有度**：精良（Uncommon）
- **建议投放**：墓园、亡灵战场、幽暗地穴。

## 书籍内容

指南开篇即警告：亡灵不是敌人，而是“被遗忘的未完成”。书中教导读者在战斗结束后为亡灵举行简短超度仪式，帮助他们脱离徘徊状态。仪式包括呼唤亡灵的真名、承认他们曾经的痛苦、最后念出放行祷文。作者强调，若施术者抱着刷取材料的功利心态，仪式会失败，甚至激怒亡灵。后半部分列出常见亡灵类型对应的超度变体：战士型需要武器归位，孩童型需要玩具陪葬，怨灵型则需要有人替他们说出未能说出口的话。最末页写着：“超度不是为了清净战场，是为了让你自己不会在夜里听见他们。”作者在每一章开头都写下同一句话：如果你把亡灵当作资源，它们会把你当作债务。这句话的墨水比其他文字更淡，仿佛被反复涂抹过许多次。书中还附有一张简谱，超度祷文可以用低吟或哼唱两种方式完成。

## 设计意图

将战斗后仪式与资源掉落结合，强化信仰系对亡灵敌人的主题优势与人文关怀。
