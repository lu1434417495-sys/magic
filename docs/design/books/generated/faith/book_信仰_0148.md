# 《唱诗班指挥术》

## 书籍内容

指挥术教人如何带领多名信仰者同时吟唱而不互相干扰。作者说合唱不是声音整齐，而是“每个人在集体中仍然听见自己的那部分”。书中讲解了起拍、呼吸统一、分声部、以及如何处理唱错时的补救。后半部分讨论了战斗合唱的特殊要求：指挥者必须用简单手势维持节奏，因为战场上无法依赖听觉。最末页写着：“当所有人的声音叠在一起时，光会把它当成一扇门；你的手势，就是那扇门的把手。”作者在指挥术的扉页上指出，战斗中的唱诗班最重要的不是音色，而是即使有人倒下，剩下的人也能在没有指挥的情况下继续完成最后一句。书中还提醒，合唱人数超过七人时需要两名指挥，否则声部会相互吞噬。唱诗班指挥术的附录里有一段关于“错音”的说明：合唱中第一个唱错的人，往往是最想证明自己的人。
