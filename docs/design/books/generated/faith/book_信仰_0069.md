# 《祝福武器》

## 基础信息

- **书籍 ID**：`book_信仰_0069`
- **关联技能**：`faith_blessed_weapon`
- **使用效果**：阅读后解锁 `faith_blessed_weapon`；若已学会，提升该技能 `current_mastery +80`，并使祝福武器对亡灵/恶魔额外造成 10% 伤害。
- **阅读要求**：角色职业标签含 `priest`、`cleric` 或 `paladin`；基础 `信仰 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：圣骑士营地、武器祝福所、讨伐任务奖励。

## 书籍内容

一把武器若被正确使用，也可以成为祈祷的延伸。《祝福武器》教导牧师如何在战前为武器注入神圣之力，使其在打击邪恶时更加锋利。书中强调，被祝福的武器不是自动向善的工具，它仍然取决于使用者的意图。第一章讲解不同武器的祝福方法：剑需要沿刃口引导神力，锤需要集中于打击面，弓则需要祝福箭矢而非弓身。第二章讨论祝福的持续时间与损耗，指出每次命中邪恶目标都会消耗一部分祝福，直至需要重新补充。后半部收录了武器与使用者不匹配的案例，例如邪恶者使用祝福武器会导致手心灼伤。书中还提到，祝福武器对拥有坚定信仰的战士效果最好，对心怀疑虑者则可能只是普通的附魔。最末页的插图是一柄普通长剑在祝福后发出柔和光芒，剑身上浮现出细小的祷文。祝福武器让信仰系能够直接提升团队的物理输出能力。

## 设计意图

为信仰系提供武器附魔类辅助技能，使牧师成为战前准备与装备强化的重要一环。
