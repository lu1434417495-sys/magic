# 《宿敌烙印的识别》

## 基础信息

- **书籍 ID**：`book_faith_0042`
- **关联技能**：`faith_foe_mark`
- **使用效果**：阅读后解锁 `faith_foe_mark`；若已学会，提升该技能 `current_mastery +90`，并提高对特定敌人类型的首次命中 10%。
- **阅读要求**：角色拥有 `holy`、`ranger` 或 `inquisitor` 标签职业；基础 `感知 ≥ 9`。
- **稀有度**：普通（Common）
- **建议投放**：怪物猎人公会、审判庭资料室、边境哨站。

## 书籍内容

宿敌烙印的识别是一本关于如何在敌人身上看见"签名"的猎手手册。书中认为，每种长期与信仰为敌的生物都会在行动、气味或痕迹上留下可被识别的烙印，这些烙印不是纹身，而是一种与邪恶共生的习惯。作者列举了亡灵留下的霜迹、恶魔灼烧空气的硫磺味、以及被腐蚀心智者反复出现的梦境符号。最实用的章节是"战场快速识别"：通过敌人武器上的磨损方式判断其杀戮偏好，从而预测下一次攻击目标。书中还提醒，识别烙印不是为了仇恨，而是为了在战斗中保持清醒——很多猎手失败是因为他们把敌人当成了抽象的恐惧。封面画着一只睁开的眼睛，瞳孔里嵌着一枚小小的十字架。怪物猎人公会把这本书当作必修教材，因为新手往往死于对敌人类型的误判。老猎手则会在每次任务后更新自己的烙印笔记，把个人经验传承给后辈。

## 设计意图

为信仰系提供针对特定敌人类型的命中增益，同时用"识别而非仇恨"的叙事引导玩家更理性地面对怪物。
