# 《祝福武器研习》

## 基础信息

- **书籍 ID**：`book_信仰_0116`
- **关联技能**：`faith_blessed_weapon_116`
- **使用效果**：阅读后解锁 `faith_blessed_weapon_116`；若已学会，提升该技能 `current_mastery +80`，并使接下来 10 次武器攻击附带 +8 神圣伤害。
- **阅读要求**：角色职业标签含 `holy`；基础 `力量 ≥ 7` 或 `意志 ≥ 7`。
- **稀有度**：普通（Common）
- **建议投放**：武器祝福祭坛、圣骑士军械库、讨伐任务奖励。

## 书籍内容

研习从一把普通长剑开始，教读者如何把光“擦”进金属。作者说祝福武器的关键不在念咒，而在让施术者相信这把剑接下来要做的事是公正的。书中详细列出不同材质武器的祝福差异：铁器容易承载，银器自带净化，木器适合非致命惩戒。后半部分是维护篇，提醒读者被祝福的武器若用于偷袭或滥杀，祝福会一层层剥落，直到剑变回普通铁块。最末页画着一只手握剑的示意图，掌心与剑柄之间留出一条缝隙，批注：“光要从这里流过，不要攥得太紧。”作者在书脊内侧贴了一张小纸条，提醒使用者祝福武器在第一次杀人后的三个小时内最容易脱落，因为那时施术者最常怀疑自己的行为是否公正。书中还提到，祝福会在月圆之夜自行减弱，需要在月光下重新默念誓言。研习的最后附有一则案例：一名骑士因用祝福剑斩杀投降的敌人，祝福在当夜化为灰烬，剑身冷却后布满锈斑。

## 设计意图

为近战信仰角色提供基础武器附魔，让“公正使用力量”成为维持 buff 的隐性条件。
