# 《神圣怒火》

## 基础信息

- **书籍 ID**：`book_信仰_0094`
- **关联技能**：`faith_holy_wrath`
- **使用效果**：阅读后解锁 `faith_holy_wrath`；若已学会，提升该技能 `current_mastery +90`，并使攻击附带神圣怒火的目标时伤害提升 15%。
- **阅读要求**：角色职业标签含 `priest`、`cleric`、`paladin` 或 `inquisitor`；基础 `信仰 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：审判庭终极藏室、信仰阵营高端任务、世界 boss 战利品。

## 书籍内容

《神圣怒火》是一本充满力量感的典籍，教导牧师如何将对邪恶的憎恶转化为纯粹的攻击力量。书中强调，神圣怒火不是失控的狂怒，而是经过信仰淬炼后的正义之火。第一章讲解如何在心中点燃这股怒火，要求施术者先默想邪恶所造成的伤害，再将情绪导向审判而非复仇。第二章讨论怒火的维持与控制，指出过度燃烧会吞噬施术者的理智，使其分不清敌友。作者警告，神圣怒火对无辜者无效，若强行对善良目标使用，怒火会立刻熄灭并灼伤自己。后半部收录了多位使用神圣怒火的圣骑士与审判官手记，他们描述那种力量充满全身的灼烧感，以及必须时刻保持清醒的艰难。最末页的插图是一名战士全身笼罩在金色火焰中，他的眼中没有疯狂，只有冰冷的决断。神圣怒火是信仰系最高伤害的输出技能之一。

## 设计意图

为信仰系提供高伤害输出技能，以"仅对邪恶有效"作为机制限制，强调正义与控制的平衡。
