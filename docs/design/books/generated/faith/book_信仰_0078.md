# 《信仰审判》

## 基础信息

- **书籍 ID**：`book_信仰_0078`
- **关联技能**：`faith_inquisition`
- **使用效果**：阅读后解锁 `faith_inquisition`；若已学会，提升该技能 `current_mastery +90`，并使审判成功时目标全属性下降 10%，持续 3 回合。
- **阅读要求**：角色职业标签含 `priest`、`cleric` 或 `inquisitor`；基础 `信仰 ≥ 10` 且 `智力 ≥ 8`。
- **稀有度**：稀有（Rare）
- **建议投放**：审判庭高级训练室、异端讨伐任务、信仰阵营特殊剧情。

## 书籍内容

审判不是为了毁灭，而是为了剥离伪装。《信仰审判》教导牧师如何以神圣之力质问目标的内心，使其谎言、伪装与隐藏的罪恶无所遁形。书中把审判过程分为"注视"、"发问"、"裁决"三个阶段，每个阶段都需要施术者保持绝对的冷静与公正。第一章讲解如何营造审判氛围，包括光线、距离与语气的控制。第二章讨论目标抵抗的方式，意志强大者可以暂时隐瞒，但无法长期维持。作者严厉警告，若审判者自身心怀偏见，审判会反噬其精神，造成短暂的疯狂。后半部收录了历史上几次著名审判的记录，既有成功揭露阴谋的案例，也有因误判导致的悲剧。书中特别收录了一篇忏悔书，作者曾因偏见造成冤案，余生都在阴影中度过。最末页的插图是一名审判官手持发光法典，被审问者跪在地上，阴影从其身上被迫剥离。信仰审判是信仰系在剧情与控制方面的强力技能。

## 设计意图

为信仰系提供剧情审讯与战斗 debuff 结合的技能，拓展牧师在情报与心理战中的作用。
