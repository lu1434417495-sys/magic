# 《祝福武器的擦拭》

## 基础信息

- **书籍 ID**：`book_faith_0033`
- **关联技能**：`faith_weapon_bless`
- **使用效果**：阅读后解锁 `faith_weapon_bless`；若已学会，提升该技能 `current_mastery +80`，并提高近战武器对亡灵敌人的伤害 8%。
- **阅读要求**：无职业限制；基础 `意志 ≥ 7`。
- **稀有度**：普通（Common）
- **建议投放**：军械库祈祷室、亡灵前线营地、民兵训练场。

## 书籍内容

祝福武器的擦拭是一本把武器维护变成祈祷的小册子。书中认为，武器在杀戮后会被"重量"污染，而擦拭不仅是清洁，也是把使用者的意图重新校准到守护而非毁灭。作者规定了擦拭顺序：先从护手向剑尖单向擦三次，象征把残余的敌意导出；再从剑尖向护手擦三次，象征把祝福引入。书中还提醒，擦拭时不能说话，因为言语会干扰金属对祝福的接收。最实用的章节列出了不同材质武器的擦拭禁忌：木柄忌水、银刃忌过度摩擦、骨制武器忌用圣水。书末附有一张简笔画，一把剑被分解成柄、格、刃、尖四个部分，每一部分都标注了对应的祈祷词。许多士兵在战斗前夜会照这本书做一遍，即使他们并不完全相信。新兵营里，士官会检查士兵的武器光泽，不是为了卫生，而是为了判断他们是否还认真对待守护这件事。被发现有锈迹或油污的士兵会被要求重新擦拭并默诵祈祷词。

## 设计意图

为任意近战职业提供信仰主题的对亡灵增伤，同时用"擦拭"仪式强化战斗前后的仪式感与世界观沉浸。
