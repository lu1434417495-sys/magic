# 《烛火不熄的守护》

## 书籍内容

烛火不熄的守护是一本关于如何照看一盏圣烛的小册子。书中开篇便否定了"火越旺越好"的常识，指出过大的火焰会耗尽蜡油并遮蔽周围细节。作者建议把烛芯修剪到恰好能舔舐空气的高度，然后在火焰周围留出半掌宽的黑暗，让眼睛适应低光。中间章节教授七种防风手势，每一种都能在行走或战斗中保护烛火不灭。最实用的部分是一份故障排查清单：火焰偏向一侧说明有未察觉的气流，火焰发蓝说明附近存在亡灵，火焰突然升高说明有善意灵体经过。书的最后一页写着："不要试图让烛火替你驱散所有黑暗，它的职责只是让你看清下一步该踩在哪里。"许多人把它放在行囊最深处，当作绝望时的路标。守墓人通常会在入冬前用这本书复习所有手势，因为漫长的夜晚里，火是他们与未知之间最脆弱的契约。一旦火灭，他们便不再继续巡逻，而是原地等待黎明。
