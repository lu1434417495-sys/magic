# 《锁链祝圣术》

## 基础信息

- **书籍 ID**：`book_faith_0008`
- **关联技能**：`faith_holy_chain`
- **使用效果**：阅读后解锁 `faith_holy_chain`；若已学会，提升该技能 `current_mastery +90`，并延长束缚类效果的持续时间 1 回合。
- **阅读要求**：角色拥有 `holy`、`rogue` 或 `cleric` 标签职业；基础 `敏捷 ≥ 8`。
- **稀有度**：稀有（Rare）
- **建议投放**：异端审判监狱、盗贼公会秘密礼拜堂、地下城镣铐室。

## 书籍内容

锁链祝圣术教授信仰者如何将普通镣铐转化为承载神圣的囚具。书中首先要求读者在铁链尚冷时诵读祝福，因为热铁会扭曲祷词的频率。接着介绍了三种结扣：颈环用于压制狂乱，手铐用于封印施法，脚镣用于阻止逃遁，每一种都需要在不同链节上刻写不同的短句。作者特别提醒，祝圣锁链的目的不是羞辱囚犯，而是让被束缚者仍能祈祷；因此锁链内侧通常刻有"仍有出路"四个字。最艰深的章节讨论如何让锁链在断裂瞬间释放最后一次净化冲击，这需要祝圣者在锻造时把自己的一句真心宽恕融入金属。书末附有一张设计图，图中锁链末端不是尖钩，而是一枚未封闭的圆环。在边境监狱，经验丰富的看守会用这本书训练新兵，要求他们在给犯人上锁前默诵对应的短句，以提醒自己权力的边界。这种传统让许多囚犯在获释后仍记得那段被尊重的时光。

## 设计意图

为信仰系补充控制与封印手段，同时用"束缚中仍有尊严"的叙事弱化传统监禁题材的阴暗感。
