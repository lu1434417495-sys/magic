# 《灵魂共鸣的调律》

## 基础信息

- **书籍 ID**：`book_faith_0025`
- **关联技能**：`faith_soul_resonance`
- **使用效果**：阅读后解锁 `faith_soul_resonance`；若已学会，提升该技能 `current_mastery +100`，并提高与绑定队友共享治疗与 buff 的范围 1 格。
- **阅读要求**：角色拥有 `holy` 或 `support` 标签职业；基础 `感知 ≥ 10`。
- **稀有度**：史诗（Epic）
- **建议投放**：灵魂医者密室、双人试炼奖励、大教堂地下圣堂。

## 书籍内容

灵魂共鸣的调律认为，真正的治愈发生在两个频率相近的灵魂之间。书中教导读者如何通过长时间并肩作战来"聆听"队友的灵魂音色：有人像低沉的钟声，有人像急促的鼓点，还有人像被风吹过的芦苇。调律的关键不是改变对方，而是找到自己的频率能为对方填补哪个空隙。作者设计了一套简单的共鸣测试：两人背靠背静坐，同时默念同一个词，如果能在三次呼吸后同时开口，就说明调律初步成功。书中最为珍贵的部分是一位老兵的回忆，他说自己在战场上从未学会任何高级神术，只因为与一位祭司形成了共鸣，便能隔着硝烟感受到对方是否需要帮助。书末写道："最高级的信仰不是拯救世界，而是让一个人不再感到孤单。"战地医院常把这本书发给需要长期配合的救护小组，作为团队建设的一部分。共鸣的建立往往比任何医疗训练都更能降低死亡率。

## 设计意图

为信仰系提供深度绑定队友的机制，强化治疗与支援的叙事厚度，鼓励玩家培养固定角色关系。
