# 《忏悔行军操典》

## 基础信息

- **书籍 ID**：`book_faith_0005`
- **关联技能**：`faith_penance_march`
- **使用效果**：阅读后解锁 `faith_penance_march`；若已学会，提升该技能 `current_mastery +100`，并在背负负面状态时提升移动速度 10%。
- **阅读要求**：角色拥有 `holy`、`warrior` 或 `zealot` 标签职业；基础 `体质 ≥ 9`。
- **稀有度**：稀有（Rare）
- **建议投放**：苦行僧营地、圣骑士远征军、忏悔之路支线。

## 书籍内容

忏悔行军操典源于一支在荒漠中行走的朝圣队伍，他们相信每一步沉重都是洗涤罪孽的磨石。书中规定了三种负重姿势：肩扛石块、背负十字架、手提灯盏，分别对应骄傲、逃避与冷漠三种原罪。作者详细计算了步幅与呼吸的比例，要求行者在踏出左脚时默念"我承受"，踏出右脚时默念"我放下"。最艰难的章节描述如何在脚底磨出血泡后继续前进：不是忍耐疼痛，而是把疼痛重新命名为"身体正在说话"，并倾听它。操典还附录了一份行军地图，标注了七处已被风沙掩埋的补给点，只有真正忏悔的人才能从地表痕迹中找到它们。书的扉页盖着一枚已经干涸的血指印。在忏悔之路上，丢弃负重是不被允许的，但允许把石块换小，因为操典认为承认极限本身也是一种诚实。这种温和让许多修行者反而坚持得更久。

## 设计意图

为信仰系前排提供一种"越痛苦越坚定"的机动与叙事机制，鼓励玩家主动承受负面状态以换取战场优势。
