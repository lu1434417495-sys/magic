# 《隐秘经文的破译》

## 基础信息

- **书籍 ID**：`book_faith_0038`
- **关联技能**：`faith_esoteric_decode`
- **使用效果**：阅读后解锁知识 `faith_esoteric_decode`；阅读完成后提升智力判定 3，并解锁阅读更高阶信仰典籍的能力。
- **阅读要求**：角色拥有 `holy`、`mage` 或 `scholar` 标签职业；基础 `智力 ≥ 10`。
- **稀有度**：史诗（Epic）
- **建议投放**：禁书区、古代遗迹、秘密结社藏书室。

## 书籍内容

隐秘经文的破译是一本关于如何阅读那些不愿被读懂的文字的书。书中收集了各种加密方法：镜像书写、音节置换、空缺字母、以及用香料水才能显现的隐形墨水。作者认为，最困难的加密不是技术，而是信仰本身——有些经文只在读者准备好理解时才会显义。破译章节从简单的替换密码开始，逐步过渡到需要根据经文出现地点、时间甚至天气来解读的"情境密码"。最神秘的章节没有文字，只有几页空白，旁边写着："当你能读出这里的内容时，你已不需要这本书。"许多学者为这几页争论不休，有人说那是最高级的考验，也有人说只是作者偷懒。秘密结社把这本书当作入门考验，要求新成员从一段伪造的经文中找出三处隐藏信息。通过者会被允许接触真正的教义，而失败者则继续在空白页前苦思。

## 设计意图

作为进阶知识钥匙，解锁更高阶信仰书籍的阅读门槛，同时用破译玩法增加信仰系的探索与成长层次。
