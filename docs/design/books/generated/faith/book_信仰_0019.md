# 《神罚雷的引导》

## 基础信息

- **书籍 ID**：`book_faith_0019`
- **关联技能**：`faith_holy_lightning`
- **使用效果**：阅读后解锁 `faith_holy_lightning`；若已学会，提升该技能 `current_mastery +120`，并提高对亡灵与恶魔敌人 10% 伤害。
- **阅读要求**：角色拥有 `holy`、`mage` 或 `paladin` 标签职业；基础 `智力 ≥ 10` 且 `意志 ≥ 9`。
- **稀有度**：史诗（Epic）
- **建议投放**：风暴大教堂、堕天使之战、天空裂隙事件。

## 书籍内容

神罚雷的引导是一本充满危险美感的典籍。书中把雷电比作神明的眨眼：它不会瞄准罪人，只会落在最清晰的那一个念头上。修行者需要先在平原上架设一根引雷针，然后站在针旁念诵三段越来越短的祷词，让天空误以为施术者是一个值得回应的问题。作者警告，最常见的失败不是被雷击中，而是雷电到达时施术者脑中一片空白，结果雷光只击碎了地面。中级章节讲解如何把落地的雷电暂时封存在金属容器中，作为一次性投掷武器使用。书中最华丽的一页描绘了一位圣骑士高举长剑，云层像旋涡一样向他汇聚。末尾用红字标注："神罚雷从不替人选择目标，它只放大你已经做出的选择。"平原上的游牧部落把这种技艺视为与天空对话的方式，每次引导前都会先向四方献上清水。他们认为，干燥的心灵无法承接雷电，正如干裂的土地留不住雨水。

## 设计意图

为信仰系提供高伤害范围打击，呼应"审判"主题，同时用引导机制强化站位与准备的战棋决策。
