# 《悲痛转化为圣能》

## 基础信息

- **书籍 ID**：`book_faith_0045`
- **关联技能**：`faith_grief_to_grace`
- **使用效果**：阅读后解锁 `faith_grief_to_grace`；若已学会，提升该技能 `current_mastery +100`，并在队友阵亡时获得一次性全属性加成，持续 3 回合。
- **阅读要求**：角色拥有 `holy`、`paladin` 或 `zealot` 标签职业；基础 `意志 ≥ 11`。
- **稀有度**：史诗（Epic）
- **建议投放**：悲壮战役奖励、悼亡礼拜堂、战争孤儿庇护所。

## 书籍内容

悲痛转化为圣能是一本关于如何把失去变成力量的危险典籍。书中不否认悲伤的重量，反而要求读者先完整地沉入悲伤，像沉入水底一样感受它的寒冷与压力。只有当一个人不再逃避悲伤时，才能开始把它向上引导，穿过胸口、喉咙，最后从双手释放为圣能。作者警告，转化的关键不是"为了谁而强大"，而是"承认失去已经改变了自己"。最触动人心的一章是匿名信：写信者在失去所有家人后发明了这种技艺，却发现每次使用都会让她重新经历一次离别。书末用红字写着："你可以把悲痛变成光，但请不要假装那束光不是用眼泪浇出来的。"圣骑士团把这本书列为高级读物，只有经历过实战损失的成员才被允许翻阅。教官们相信，没有真正悲痛的人强行练习，只会把圣能变成暴烈的火焰。因此，它始终被锁在高级阅览室的铁柜里。

## 设计意图

为信仰系设计基于队友阵亡的爆发机制，让悲伤在战棋中拥有战术意义，同时保持对死亡的情感尊重。
