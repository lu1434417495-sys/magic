# 《神恩审判阵》

## 基础信息

- **书籍 ID**：`book_信仰_0143`
- **关联技能**：`faith_judgment_circle_143`
- **使用效果**：阅读后解锁 `faith_judgment_circle_143`；若已学会，提升该技能 `current_mastery +100`，并可在战场上生成一道 5×1 的神圣光墙，对穿越的敌人造成伤害并治疗穿越的友方。

## 书籍内容

审判阵是一种高阶阵地神术，能在战场上划出一道同时具有审判与治愈功能的光之界线。作者把阵法比作“把天平具象化”：站在同一侧的生者得到治疗，越过边界的敌人受到灼烧。书中详细描述了维持审判阵的代价——施术者必须持续站在阵眼，任何移动都会导致阵法崩溃。后半部分记录了历史上几次著名审判阵的使用，最著名的一次是在城市广场划出界线，将平民与恶魔军团分开长达三个小时。最末页写着：“审判阵不是拒绝谁进来，而是让每个人自己决定站在哪一边。”作者在总结时警告，审判阵最危险的副作用不是敌人的冲击，而是施术者开始享受“决定谁该受伤”的权力感。书中还附有一张阵眼站立姿势图，标注着“双脚必须等重，否则天平会倾斜”。审判阵的尾页写着：阵法最可怕的不是敌人不敢越界，而是你发现自己开始享受划定界线这件事本身。

## 设计意图

为信仰系提供史诗级地形分割技能，强化审判与庇护的双重主题。
