# 《祈祷钟的敲击节奏》

## 基础信息

- **书籍 ID**：`book_faith_0014`
- **关联技能**：`faith_prayer_bell`
- **使用效果**：阅读后解锁 `faith_prayer_bell`；若已学会，提升该技能 `current_mastery +90`，并在战斗开始时为全队提供一次先攻判定加 3。
- **阅读要求**：角色拥有 `holy` 或 `support` 标签职业；基础 `感知 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：钟楼顶层、晨祷仪式奖励、村庄守夜人任务。

## 书籍内容

祈祷钟的敲击节奏是一本关于声音如何组织时间的小书。书中把钟声分为四类：召集、警告、哀悼与欢庆，每一类对应一种独特的敲击间隔。作者强调，真正让钟声产生力量的不是音量，而是敲击者是否在正确的时间放手。书中详细记录了标准祈祷钟的十六拍节奏，要求练习者先用木槌在桌面上模拟，直到手腕能在无意识中复现。最有趣的章节探讨了双人敲钟：一人负责高音，一人负责低音，两人的呼吸必须错开半拍，才能让钟声在空中形成完整的祈福。书末附有一张古老的钟谱，某些音符旁画着小小的火焰标记，注释称那是大教堂被焚毁前最后一次完整敲响的旋律。钟楼管理员通常会在暴风雨来临前敲出警告节奏，让远处村落能提前关闭门窗。这种习俗延续至今，即便许多人已经听不出钟声中的具体含义。

## 设计意图

通过节奏与先攻绑定，让辅助职业在战斗开场拥有存在感，同时为游戏世界补充"钟楼"这一信仰地标。
