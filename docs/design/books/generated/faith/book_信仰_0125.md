# 《苦难承袭书》

## 基础信息

- **书籍 ID**：`book_信仰_0125`
- **关联技能**：`faith_burden_inheritance_125`
- **使用效果**：阅读后解锁 `faith_burden_inheritance_125`；若已学会，提升该技能 `current_mastery +100`，并在战斗开始时可以选择一名友方的一个减益状态转移到自身，持续时间减半。
- **阅读要求**：角色拥有 `holy` 或 `support` 标签职业；基础 `体质 ≥ 8` 或 `意志 ≥ 9`。
- **稀有度**：稀有（Rare）
- **建议投放**：苦修院、临终关怀所、悲情支线终点。

## 书籍内容

承袭书记录了一种被教会谨慎使用的古老仪式：把他人身上的痛苦暂时转移到自己身上。作者强调这并非治疗，而是“替对方争取时间”。仪式要求施术者先聆听对方的完整经历，不能打断、不能评判，否则痛苦会在转移途中反噬。书中详细描述了转移后的身体反应：眩晕、恶心、情绪闪回，以及如何通过呼吸与祈祷维持意识。后半部分收录了多位承袭者的回忆，他们说最难承受的不是疼痛，而是“突然理解了别人为何会变成那样”。最末页写着：“承袭不是为了当英雄，是为了让对方不必独自证明痛苦是真的。”作者在扉页上用红笔写着：承袭不是替对方解决问题，而是替对方保留解决问题的力气。如果你抱着“我救了你”的想法伸出手，痛苦会立刻回头咬住你。书中还警告，承袭后的三天内不能再次施术，否则转移的痛苦会永久留下。

## 设计意图

为信仰系提供减益转移能力，用自我牺牲强化支援角色的情感张力与战术价值。
