# 《神恩灌注》

## 基础信息

- **书籍 ID**：`book_信仰_0063`
- **关联技能**：`faith_divine_grace`
- **使用效果**：阅读后解锁 `faith_divine_grace`；若已学会，提升该技能 `current_mastery +90`，并使目标下一次行动必定成功且伤害/治疗量提升 25%。
- **阅读要求**：角色职业标签含 `priest`、`cleric` 或 `paladin`；基础 `信仰 ≥ 9` 且 `智力 ≥ 7`。
- **稀有度**：稀有（Rare）
- **建议投放**：高阶教堂祭坛、信仰阵营精英任务、团队副本稀有掉落。

## 书籍内容

神恩不是奖励，而是一种被信任的重量。《神恩灌注》教导牧师如何将浓缩的信仰之力注入队友体内，使其在短时间内获得近乎完美的执行力。书中把灌注过程比作倒水：杯子若是关闭的，再纯净的水也会洒在外面。因此，施术者必须先在目标心中点燃"值得被帮助"的信念。第一章讲解三种灌注方式：额头注入强化意志，胸口注入强化防御，双手注入强化攻击。第二章讨论失败征兆，如目标出现颤抖、耳鸣或短暂的失明，说明其身体正在抗拒神力。后半部收录了历代战场上使用神恩灌注的经典配合，例如让濒死的战士完成最后一击，让慌乱的法师稳定施法。书中还提醒，灌注后目标会短暂产生依赖感，施术者需避免被这种情感反噬。最末页写着："当神恩降临，人不再是自己，而是借来的光。"这个技能是信仰系在团队配合中最具戏剧性的辅助手段之一。

## 设计意图

为信仰系提供高价值单体增益技能，强化牧师在关键回合改变战局的能力。
