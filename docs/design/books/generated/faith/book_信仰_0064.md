# 《信仰审判之锤》

## 基础信息

- **书籍 ID**：`book_信仰_0064`
- **关联技能**：`faith_hammer_of_judgment`
- **使用效果**：阅读后解锁 `faith_hammer_of_judgment`；若已学会，提升该技能 `current_mastery +85`，并使对邪恶阵营目标的伤害提升 15%。
- **阅读要求**：角色职业标签含 `priest`、`cleric`、`paladin` 或 `inquisitor`；基础 `力量 ≥ 8` 或 `信仰 ≥ 9`。
- **稀有度**：稀有（Rare）
- **建议投放**：审判庭武库、圣骑士训练场、异端讨伐战利品。

## 书籍内容

《信仰审判之锤》不是一本温和的祈祷书，而是一份战斗祷词的汇编。它的核心理念是：信仰可以柔软如光，也可以沉重如铁。书中教导如何将神力凝聚成实体化的锤形冲击，从空中砸向罪恶之躯。第一章分析持握姿势，即使施术者空手，也必须想象自己正握着一柄由信念铸成的战锤。第二章讨论审判的判定问题，指出此术对真正邪恶者会自动追踪，对无辜者则会偏斜或消散。作者严厉警告，若以审判之名行私刑之实，锤子会在落下前反砸施术者。后半部收录了历代著名审判官的战例，以及他们在使用此术前后的心理独白。书中还讨论了审判之锤与信仰审判的配合，先用质问剥离伪装，再以巨锤执行裁决。最末页的插图是一名身穿重甲的审判官，高举发光巨锤，脚下的阴影中传来尖叫。审判之锤让信仰系拥有了强大的物理型神圣攻击手段。

## 设计意图

为信仰系提供兼具物理打击与神圣属性的攻击技能，适配圣骑士与审判官等近战信仰职业。
