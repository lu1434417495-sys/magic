# 《赎罪券的辨伪》

- **关联技能**：`faith_indulgence_lore`
- **使用效果**：阅读后解锁知识 `faith_indulgence_lore`；阅读完成后提升所有信仰系技能 `current_mastery +30`，并提高对教会相关 NPC 的说服判定 5。

## 书籍内容

赎罪券的辨伪是一本让人既尴尬又清醒的入门读物。书中先讲述历史上赎罪券如何被伪造、贩卖与滥用，然后列出七项常见的伪造特征：印章边缘模糊、纸质过于洁白、拉丁文拼写错误、价格标注低于官方、承诺的赦免范围过宽、背面缺少当地主教的亲笔押记、以及油墨在阳光下不会变色。作者语气辛辣地指出，真正的赦免从不需要购买，而那些急于出售赦免的人往往最不相信赦免。最实用的章节是一份对谈脚本，帮助信徒礼貌地拒绝可疑贩子，同时不冒犯真正的教会人员。书末附有一张真假对比图，假券上的天使翅膀总是比真券多出一根羽毛。许多改革派牧师把它藏在讲经台抽屉里，只在信任的人面前拿出来。市井书摊上常能看到它的廉价抄本，书商把它包装成反诈骗指南出售。教会对此睁一只眼闭一只眼，因为普及辨伪知识反而减少了信徒上当的次数。

## 设计意图

作为信仰系列的知识型书籍，通过辨伪主题补充世界观的经济与权力结构，同时提供全局信仰技能熟练度奖励。
