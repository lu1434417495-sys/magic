# 《袖剑隐蔽原理》

## 基础信息

- **书籍 ID**：`book_武器专精_0020`
- **关联技能**：`assassin_hidden_blade`、`weapon_sleeve_blade`
- **使用效果**：阅读后解锁 `assassin_hidden_blade`；若已学会，提升 `current_mastery +150`，并提高首次隐蔽出手时的破甲无视率 `+10%。
- **阅读要求**：角色职业标签含 `assassin`；基础 `敏捷 ≥ 13`、`智力 ≥ 10`。
- **稀有度**：史诗（Epic）
- **建议投放**：暗杀任务密室、王室密库、黑市拍卖行稀有货物。

## 书籍内容

袖剑不是武器，而是一种承诺——一旦亮出，就必须有结果。作者没有署名，但字里行间透露出对机械结构的痴迷。书中详细讲解了袖剑的三种触发机构：弹簧式爆发最快但噪音大，滑轨式安静但需要精确安装，链条式最隐蔽但维护困难。作者认为比机构更重要的是「藏」：袖剑使用者必须让手臂自然下垂，肘部微屈，让旁观者误以为那只是一只放松的手。书中还讲到了出手角度：从下向上的袖刺最容易命中咽喉与下颌，但需要极近距离贴近；从侧面向内的横割相对安全，杀伤力却低得多。最后一页是一张被烧毁大半的设计图，只剩几个齿轮轮廓和一行字：「最危险的袖剑，是敌人到死都没看见的那一把。书的封皮内侧刻着一行小字：「此书记录了三十七位使用者的名字，其中三十一位死于自己的武器。」

## 设计意图

作为暗杀者的高级专属技能入口，强调隐蔽、精准与致命一击，服务于高风险高回报的职业 fantasy。
