# 《盾击后势：门板之后的刀锋》

## 基础信息

- **书籍 ID**：`book_weapons_0162`
- **关联技能**：`warrior_shield_bash`, `warrior_shield_slash`
- **使用效果**：阅读后提升 `warrior_shield_bash` 技能 `current_mastery +130`；若未学会，则解锁该技能。阅读后额外学会 `warrior_shield_slash`。
- **阅读要求**：角色已装备盾牌；基础 `体质 ≥ 10`。
- **稀有度**：精良（Uncommon）
- **建议投放**：军团盾卫营帐、要塞军械库、盾战教官任务。

## 书籍内容

《盾击后势》专门讨论盾击之后那几秒钟该做什么。作者指出，大多数人把盾击当成控制技能的终点，其实它应该是新连招的起点。盾击命中后敌人会短暂后仰，这时如果立刻收盾拔剑，反而会浪费最佳的追击窗口。书中推荐三种后势：盾沿割喉、盾角顶颚、以及利用盾面推开敌人制造距离。每种后势都取决于敌人的体型与站位。后半部分讨论盾牌的角度：盾击不是正面推，而是用一个斜面把敌人的攻击或重心导向一侧。作者还提醒读者，盾击最忌讳的是用力过猛导致自己重心前栽，那会让下一个瞬间的你比敌人更脆弱。笔记强调，盾击后不要急着看敌人倒没倒，要先确认自己的盾牌仍在最佳防御角度。笔记中用红笔圈出了三种最常见的盾击后失误，每一种都配有潦草的急救备注。 书后附有作者手绘的握腕与转肩示意图，提醒习练者注意刃筋与发力的配合。

## 设计意图

扩展盾战士的连招深度，把盾击从单点控制延伸为后续攻击的启动器，强化前排职业的持续压制。
