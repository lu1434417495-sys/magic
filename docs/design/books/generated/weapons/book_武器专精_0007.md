# 《战斧破甲指南》

## 基础信息

- **书籍 ID**：`book_武器专精_0007`
- **关联技能**：`warrior_axe_sunder`、`weapon_axe_armor_break`
- **使用效果**：阅读后获得 `warrior_axe_sunder` 解锁机会；若已学会，提升 `current_mastery +100`。
- **阅读要求**：已装备单手斧；基础 `力量 ≥ 9`。
- **稀有度**：普通（Common）
- **建议投放**：佣兵营地、铁匠铺学徒任务、低阶兽人据点宝箱。

## 书籍内容

这本书的封皮被油渍浸透，闻起来像铁锈与动物脂肪的混合物。作者开门见山：斧头对付的不是皮肉，是板甲与锁子甲之间的骄傲。书中用大量篇幅比较了斧刃不同落点的效果：砍在肩甲上会弹开，砍在关节处会让敌人动作变形，砍在盾牌上则是逼对方露出破绽。最关键的章节是「短斧的欺骗性」：因为斧柄短、头部重，新手总以为要大力抡圆，结果把自己重心甩出去；正确的做法是借助斧头的自重做短促下劈，让重力而不是肌肉完成主要工作。作者还附了一张简易护甲接缝图，标注了最容易被斧刃咬住的六个位置。最后一页是一句老兵口吻的总结：「剑刺心脏，斧毁希望。听见金属裂开的声音，你就赢了半。书中有一页被斧头劈成两半又重新粘合，作者戏称这是「最直观的破甲示范」，并提醒读者注意斧刃切入纸张的角度。

## 设计意图

为力量型近战职业提供针对重甲敌人的破甲入口，强化斧头「破防、压制」的职业画像。
