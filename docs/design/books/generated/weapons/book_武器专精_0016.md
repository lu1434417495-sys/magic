# 《匕首涂毒手册》

## 基础信息

- **书籍 ID**：`book_武器专精_0016`
- **关联技能**：`rogue_dagger_poison`、`weapon_dagger_venom`
- **使用效果**：阅读后解锁 `rogue_dagger_poison`；若已学会，提升 `current_mastery +120`，并赠送一份「基础麻痹毒」材料用于首次涂毒。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `敏捷 ≥ 10`。
- **稀有度**：精良（Uncommon）
- **建议投放**：黑市商人、盗贼公会声望奖励、毒药师密室。

## 书籍内容

涂毒不是把药水倒在刀刃上那么简单。作者详细讲解了毒液与金属的兼容性：酸性毒会腐蚀普通铁刃，油性毒则难以附着在光滑表面，必须先用细砂打磨刃口再涂抹。书中把毒药按作用分为三类：麻痹类适合控制高威胁目标，流血类用于持久战，神经类则能在短时间内造成剧烈疼痛但容易被意志抵抗。作者还提醒，涂毒时务必戴手套，并用布条包裹刀柄，否则一场战斗下来最先中毒的可能是自己。后半本收录了七种常见毒草的采集地与简易提炼方法，但大部分配方旁都标注了「慎用」。最后一页用红笔写着：「毒是匕首的延伸，不是匕首的借口。不要让毒替你完成本该属于技巧的部分。手册最后一页贴着一小块干涸的植物标本，叶片边缘发黑，作者警告这是「连蚂蚁都不敢碰的叶子」。 边角处写满刃口角度的批注，告诫读者出刃前务必确认手腕角度与回收路线。

## 设计意图

为盗贼与暗杀者提供持续伤害与控制手段，把涂毒与材料收集、技能熟练度成长绑定。
