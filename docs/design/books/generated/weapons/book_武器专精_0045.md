# 《武器契合度测试》

## 基础信息

- **书籍 ID**：`book_武器专精_0045`
- **关联技能**：`weapon_affinity_test`、`weapon_master_bond`
- **使用效果**：阅读后解锁 `weapon_affinity_test`；若已学会，提升 `current_mastery +100`，并允许检测当前武器与自身的契合等级。
- **阅读要求**：无职业限制；基础 `感知 ≥ 10`、`意志 ≥ 8`。
- **稀有度**：稀有（Rare）
- **建议投放**：武馆秘传、武器收藏家书房、精灵导师委托。

## 书籍内容

不是所有好武器都适合你，契合度比稀有度更重要。作者设计了一套简单的测试方法：握住武器闭目静立，感受它在你掌心的温度、重量分布，以及挥动时是否顺手。书中把契合度分为「抗拒」「可用」「顺手」「合一」四个等级，并指出大多数战士一辈子只停留在「可用」。作者认为，当武器与使用者高度契合时，挥砍会变得更省力、变招会更自然，甚至在危急时刻会出现本能般的反应。后半本收录了数种提升契合度的方法：长时间共同战斗、定期保养、在重要战斗中依赖它，以及——作者郑重警告——不要在情绪不稳定时更换主武器，那会打乱双方建立的默契。最后一页是一行被圈出的话：「最好的武器，是你忘了自己握着它的那一把。作者记录了一位剑痴用三十年寻找本命剑的故事，最终他发现最契合的剑竟是少年时用过的那把生锈练习剑。

## 设计意图

引入武器与角色的情感绑定机制，为长期Build提供深度，鼓励玩家忠于特定武器风格。
