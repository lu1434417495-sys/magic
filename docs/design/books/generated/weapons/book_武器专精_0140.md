# 《血咒长鞭噬命》

## 基础信息

- **书籍 ID**：`book_武器专精_0140`
- **关联技能**：`weapon_blood_whip_life_drain`
- **使用效果**：阅读后解锁 `weapon_blood_whip_life_drain`（待新增）；若已学会，提升 `current_mastery +160`，并提升下一次战斗中血鞭命中时生命偷取比例 2%（一次性战斗增益）。
- **阅读要求**：职业标签含 `warlock` 或 `berserker`；基础 `体质 ≥ 10`。
- **稀有度**：传说（Legendary）
- **建议投放**：血咒祭坛核心、吸血鬼领主宝库、禁忌仪式任务奖励。

## 书籍内容

血咒长鞭不是皮革也不是金属，而是使用者自己的血在魔咒中凝固成的鞭形。这本书的每一页都散发着淡淡的铁锈味，作者警告：每次使用都会消耗少量生命，因此必须学会"借敌人的血还自己的债"。鞭身的特点是越愤怒越锋利，但愤怒也会让鞭子失控反噬主人。书中教给读者一种特殊的呼吸法：在鞭子抽中敌人的瞬间深吸一口气，把敌人的生命波动通过鞭身引导回自己体内。作者还提醒：不要在贫血状态下连续挥鞭，否则鞭子会把你当成下一个目标。末页是一幅自画像，作者比实际年龄老了几十岁，旁边写着："它吃掉了我的青春，也吃掉了我的恐惧。"血咒长鞭的契约一旦建立，便无法通过常规手段解除。历代持有者都在寻找替代品，但大多数人最终选择继续挥舞，因为放弃意味着立即偿还代价。

## 设计意图

作为传说级武器书，提供生命偷取机制，强化以血换血的极端build。
