# 《长鞭诱击与回拉》

## 基础信息

- **书籍 ID**：`book_武器专精_0116`
- **关联技能**：`weapon_whip_lure`
- **使用效果**：阅读后解锁 `weapon_whip_lure`；若已学会，提升 `current_mastery +120`，并提升下一次战斗中将敌人拉近的成功判定 5%。
- **阅读要求**：无职业限制；基础 `敏捷 ≥ 9`。
- **稀有度**：精良（Uncommon）
- **建议投放**：马戏团驯兽师遗留、地下竞技场商人、荒野游侠宝箱。

## 书籍内容

长鞭是最容易让自己陷入尴尬境地的武器。这本书的第一章标题是"别让鞭子比你先害怕"。诱击不是直接抽向敌人，而是先让鞭梢落在敌人身侧，诱使对方朝反方向闪避，然后在他落脚处收紧鞭身。回拉则是把鞭子当作杠杆：鞭头缠住目标后，不是靠手臂硬拽，而是转身用腰背发力，把敌人甩向预定位置。书中警告：回拉时如果脚下站得太死，你会先摔倒。作者还建议在鞭柄末端绑一小块重物练习腕劲，因为鞭子的全部精确度都来自手腕最后那一下抖动。最后一页贴着一张马戏团海报，主角的鞭子正在半空画出一个完美的圈。马戏团覆灭后，原驯兽师把长鞭带入战场，发现诱击技巧对人类同样有效。她在书边补注：人的本能比野兽更容易预测，因为他们会思考。她对人类本能的观察，后来成为许多控制型武技的理论基础。

## 设计意图

把长鞭定义为控制与位移工具，拉近判定加成鼓励战术性位置调整。
