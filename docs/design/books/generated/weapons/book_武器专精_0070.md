# 《斧盾协同：破开缺口》

## 书籍内容

斧头与盾牌的配合不是一攻一守的简单轮换，而是用盾牌制造角度，再用斧头扩大角度。作者指出，盾牌应该先撞击敌人的盾牌或武器，让其偏离中线，然后斧头立刻从暴露出的缝隙劈入。书中把这套动作命名为开膛：盾是扒开伤口的手，斧是伸进去的刀。后半本讨论了不同盾牌的应对方式：小盾可以用盾牌边缘撞击对方持盾手的手腕，大盾则需要用肩膀顶住盾面再用斧刃沿盾沿滑入。作者特别提醒，斧盾协同最忌讳各自为战，一旦斧头挥出，盾牌必须立刻回到防守位置保护空档。末页写着：一个缺口不够，你要让敌人相信到处都是缺口。

一位攻城工兵在书末写道：真正的缺口不在盾牌上，而在持盾者的心里。当他开始害怕下一次撞击时，斧头就已经赢了。作者补注：但也不要因此爱上撞击，盾牌后面可能还有长矛。

## 设计意图

为斧战士提供破盾突进能力，强调与盾牌的攻防一体，强化前排突破定位。
