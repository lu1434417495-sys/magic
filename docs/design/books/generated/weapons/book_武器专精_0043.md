# 《灰烬之刃觉醒法》

## 基础信息

- **书籍 ID**：`book_武器专精_0043`
- **关联技能**：`ashen_blade_awakening`、`ashen_weapon_resonance`
- **使用效果**：阅读后获得 `ashen_blade_awakening` 解锁机会；若已学会，提升 `current_mastery +150`，并允许为一把武器附加临时灰烬附魔。
- **阅读要求**：已装备近战武器；基础 `意志 ≥ 12`；已抵达灰烬交界深处。
- **稀有度**：史诗（Epic）
- **建议投放**：余烬祭所深处、异界Boss宝箱、灰烬交界隐藏祭坛。

## 书籍内容

灰烬之刃不是打造出来的，是唤醒出来的。作者认为，每一把经历过无数次战斗的武器都在金属内部沉淀着某种记忆，而灰烬交界的能量可以作为催化剂，让这些记忆以火焰或暗影的形式重新浮现。书中详细记录了觉醒仪式：使用者必须在余烬祭所的灰烬池中浸泡武器，同时以自身血液或斗气为引，默念武器曾见证过的三次生死战斗。作者警告，觉醒过程极其危险，若武器与使用者之间没有足够的羁绊，异界能量会直接吞噬武器甚至持剑者。后半本收录了数种觉醒后的形态描述：有的刀刃会覆盖灰烬裂纹，有的会散发出低温黑焰，有的则会让周围的光线微微扭曲。最后一页是一幅残缺的仪式图，配文：「觉醒的不是刀，是你与刀之间那些杀与被杀的日子。仪式记录中提到，若觉醒时听见金属内部传来心跳声，应立即停止，因为那不是武器在回应，而是异界在邀请。

## 设计意图

作为灰烬武器系统的高级内容，提供武器个性化与临时附魔能力，强化玩家在异界探索中的成长感。
