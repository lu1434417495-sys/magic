# 《十字弩装填精要》

## 基础信息

- **书籍 ID**：`book_武器专精_0121`
- **关联技能**：`weapon_crossbow_load`
- **使用效果**：阅读后解锁 `weapon_crossbow_load`；若已学会，提升 `current_mastery +100`，并缩短下一次战斗中的首次装填时间 10%（一次性）。
- **阅读要求**：职业标签含 `archer` 或 `rogue`；基础 `敏捷 ≥ 7`。
- **稀有度**：普通（Common）
- **建议投放**：城防军械库、猎人营地、低级地城宝箱。

## 书籍内容

十字弩的威力人人知道，但装填时的脆弱却不是每个人都能活着学会。这本书把装填拆成四个动作：踩镫、拉杆、置矢、复位。作者指出大多数弩手把精力花在拉杆上，却忽略了置矢的角度——箭矢放进槽道时如果倾斜，射击时会偏出目标很远。书中建议在弩臂上贴一小块皮革，用手指感受正确角度。另一个要点是装填时的站姿：永远不要单膝跪地，那会让你在受袭时无法立刻翻滚或格挡。正确做法是半蹲，重心在两脚之间，眼睛始终看着敌人。最后几页是不同型号弩机的结构图，每幅图旁都标着"这玩意夹手"。有经验的弩手会在装填完成后立刻侧移一步，让敌人无法预判射击方向。这个习惯源自城市守卫对抗盗贼公会的实战经验。侧移装填的习惯如今已成为弩手考核中的标准动作。对弩手而言，装填的每一秒都是下一次击杀的伏笔。

## 设计意图

降低弩类武器使用门槛，用装填奖励让玩家在战斗开场更顺畅。
