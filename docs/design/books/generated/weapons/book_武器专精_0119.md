# 《魔杖引导手势》

## 基础信息

- **书籍 ID**：`book_武器专精_0119`
- **关联技能**：`weapon_wand_channel`
- **使用效果**：阅读后解锁 `weapon_wand_channel`；若已学会，提升 `current_mastery +100`，并减少下一次施法时 `MP` 消耗 2 点（一次性战斗增益）。
- **阅读要求**：职业标签含 `mage`；基础 `智力 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：法师塔入门书架、魔法学徒遗物、法术商人。

## 书籍内容

魔杖不只是法力的导体，更是施法意图的延伸。这本书从最基本的手指姿势讲起：拇指与食指形成的环决定法力的出口，中指提供稳定，无名指和小指负责切断余波。作者指出，许多法师施法浪费MP不是因为咒文背错，而是手势结束得太潦草，导致魔力在手指末端泄漏。书中列举了七种常见错误手势，每种都配有示意图，并用"漏"、"散"、"偏"、"炸"等单字标注后果。最后一章讲"引导中的移动"：魔杖法术通常要求施法者静止，但作者提出可以在引导时用脚尖轻转，把身体变成魔杖的一部分。末页有一行被火焰烧穿的字迹，只剩下："手势结束得越干净，法术开始得越锋利。"冥想解锁MP之后，许多法师发现手势精度直接决定了法力泄漏量。魔杖引导手势因此被法师塔列为入门必修，与潮汐呼吸并称双璧。法师塔的学生们常常争论：手势与呼吸，究竟哪个更决定施法效率。

## 设计意图

作为法师武器入门，把MP管理具象化为手势精度，与冥想系统形成资源呼应。
