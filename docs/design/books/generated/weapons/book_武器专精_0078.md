# 《双匕连刺：左右开花》

## 基础信息

- **书籍 ID**：`book_武器专精_0078`
- **关联技能**：`warrior_twin_blade_rotate`
- **使用效果**：阅读后解锁 `warrior_twin_blade_rotate`（待新增，标签 `dual_wield`、`dagger`）；若已学会，提升该技能 `current_mastery +130`。
- **阅读要求**：已双持匕首；基础 `敏捷 ≥ 11`。
- **稀有度**：精良（Uncommon）
- **建议投放**：影舞者训练营、地下竞技场、精英刺客宝箱。

## 书籍内容

双持匕首最难的不是让两只手都动，而是让两只手不同时动。这本书教导一种交替节奏：左手佯攻吸引防御，右手在敌人调整姿态的瞬间刺入暴露的空档，然后反过来再用右手逼迫，左手收割。作者强调，双匕连刺的威力在于连续制造二选一的威胁，让敌人永远无法同时护住两侧。书中用大量图示展示身体的旋转：双持时不能只用手臂进攻，必须用肩膀和腰胯把一只手的攻击送到另一只手制造出的空档里。后半本讨论防守：双持者没有盾牌，所以要用不断的进攻代替防守，让敌人始终处于应接不暇的状态。末页写着：两把刀不是两个人在战斗，是一个人有了两次呼吸。

书中记载，影舞者在训练时会蒙住一只眼睛，因为双眼容易被两只手同时吸引，而单眼更容易判断哪一只手才是真正的杀招。作者补充：蒙眼训练三天后，你会重新学会走路。

## 设计意图

为双持匕首流派提供连击核心，把左右手的协调转化为持续的多目标压迫。
