# 《断剑重铸录》

## 基础信息

- **书籍 ID**：`book_武器专精_0003`
- **关联技能**：`weapon_blade_repair`、`warrior_sword_slash`
- **使用效果**：阅读后解锁知识 `known_knowledge_ids: weapon_blade_repair`，并提升 `warrior_sword_slash` 的 `current_mastery +60`。
- **阅读要求**：无职业限制；基础 `智力 ≥ 6` 或 `感知 ≥ 6`。
- **稀有度**：精良（Uncommon）
- **建议投放**：断桥镇铁匠铺、废墟遗迹书架、矿工聚落任务奖励。

## 书籍内容

这本册子记录的不是铸新剑，而是救旧剑。作者坚信一把断过再续的剑比新剑更懂战场，因为每一次重铸都在金属内部留下「记忆」。书中详细介绍了三种常见的断刃情况：崩口、斜断与齐断，并对应给出打磨、夹钢与重新开刃的方案。最有趣的章节是「 temper 的谎言」：许多铁匠迷信回火次数越多越好，作者却指出过度回火会让剑身变软，反而在格挡时弯曲变形。书中还夹着一张泛黄的清单，列出了七种可以在野外临时修复刃口的矿石与草药，旁边用小字注明「应急用，回去后必须重铸」。最后一页是一柄断成两截的旧剑拓图，配文：「剑断了不是结束，是它终于愿意听你说一次话。册子最后一章夹着一片极薄的断刃碎片，作者没有说明来历，只说「这是某位无名者的第三十次重铸，足够再砍断一根骨头」。

## 设计意图

把武器维护与知识系统挂钩，让玩家在探索中建立起「收集材料—修复武器—延长装备寿命」的轻量循环。
