# 《镰刀横扫：弧线中的收割》

## 基础信息

- **书籍 ID**：`book_weapons_0169`
- **关联技能**：`warrior_scythe_sweep`, `warrior_reaping_arc`
- **使用效果**：阅读后解锁 `warrior_scythe_sweep`；若已学会，提升该技能 `current_mastery +110`，并令横扫命中多个目标时伤害递增 `5%`。
- **阅读要求**：角色职业标签含 `warrior`、`berserker` 或 `reaper`；基础 `力量 ≥ 11`、基础 `敏捷 ≥ 9`。
- **稀有度**：稀有（Rare）
- **建议投放**：死亡教团藏室、丰收祭坛暗格、收割者导师。

## 书籍内容

镰刀是一种被战场重新发明的农具，它的弧线天然适合同时威胁多个敌人。作者认为，镰刀真正的威力不在锋刃，而在柄长与弧度创造的"不可接近区"。书中详细讲解了横扫时的站位：使用者必须让自己处于敌人包围圈的边缘，而不是中心，这样每一挥都能扫过最大的扇面。后半部分讨论镰刀的"内弧"与"外弧"：外弧攻击范围广但速度慢，内弧速度快但容易让敌人近身。作者还提醒读者，镰刀收回时的钩刃同样危险，许多对手会在你以为攻击结束时被勾住脚踝或手臂。作者提醒，镰刀挥出后收回的路径同样危险，许多初学者在收镰时被自己的刃口割伤。作者附有一张麦田收割图，暗示镰刀的每一道弧线都源自最朴实的劳作记忆。

## 设计意图

为中力量型职业提供群体收割武器选择，通过弧线攻击与命中递增奖励反制密集敌人。
