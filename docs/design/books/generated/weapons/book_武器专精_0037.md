# 《武器保养与磨刀》

## 基础信息

- **书籍 ID**：`book_武器专精_0037`
- **关联技能**：`weapon_maintenance_basic`、`known_knowledge_ids: blade_sharpening`
- **使用效果**：阅读后解锁知识 `known_knowledge_ids: blade_sharpening`，并提升所有刃类武器 `+3%` 基础伤害（一次性永久增益）。
- **阅读要求**：无职业限制；基础 `智力 ≥ 5`。
- **稀有度**：普通（Common）
- **建议投放**：铁匠铺、新手村商人、民兵训练场。

## 书籍内容

一把钝刀不仅砍不动敌人，还会让使用者浪费更多体力。作者从最基础的磨刀讲起：粗石去缺口，细石修刃线，皮革荡刀口。书中强调，磨刀的角度比力度更重要，每种钢材都有其最佳刃角，太陡容易崩口，太平则锋利不持久。作者还提醒，保养不只是磨刀，还包括清理血污、擦干水分、给皮柄上油，以及在长期不用时涂抹防锈脂。后半本用图解展示了不同武器的检查清单：剑看刃与柄紧固，斧看头部松动，弓看弦的张力，弩看机括状态。最后一页是一张被油污弄脏的表格，记录着日常保养所需的最少工具，旁边写着：「武器不会背叛你，除非你先背叛它。作者固执地认为，真正爱武器的人会在磨刀时与它对视，因为金属表面的反光会映出使用者当时的表情。作者坚持认为，给武器上油的最佳时机是雨后的黄昏，因为那时空气中的湿度会让油脂渗得更均匀。

## 设计意图

把武器保养与知识系统结合，为所有物理职业提供轻量但持久的成长收益，增强沉浸感。
