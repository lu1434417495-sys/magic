# 《兵器重量与体力分配》

## 基础信息

- **书籍 ID**：`book_武器专精_0047`
- **关联技能**：`weapon_weight_stamina`、`weapon_efficiency`
- **使用效果**：阅读后解锁 `weapon_weight_stamina`；若已学会，提升 `current_mastery +100`，并减少所有重型武器的基础 `stamina` 消耗 `5%`（一次性永久增益）。
- **阅读要求**：已装备重型武器；基础 `体质 ≥ 10`。
- **稀有度**：普通（Common）
- **建议投放**：狂战士训练场、山岳聚落、铁匠铺进阶教材。

## 书籍内容

重武器的敌人从来不是敌人，而是你自己的体力。作者把体力分配比作呼吸：进攻是呼气，防守是吸气，而蓄力则是屏息。书中指出，许多战士在战斗前半段就把体力挥霍一空，因为他们每一击都用全力；正确的做法是根据敌人的状态调整出力，只有在确认命中或逼迫敌人硬接时才全力以赴。作者还讲解了如何利用武器自重节省体力：斧头与大剑的挥砍应借助下落惯性，而不是全程用肌肉对抗重力。后半本提供了数种恢复体力的微动作：在格挡后顺势后撤半步、在攻击间隙调整握距、在移动时把武器扛在肩上而非悬在身前。最后一页画着一个战士举剑喘息的简图，配文：「能打到最后的重武器使用者，不是最强壮的，是最会偷懒的。 书后附有一套负重分配与呼吸口诀，帮助战士在长途行军与高强度战斗中保存体力。

## 设计意图

为重型武器使用者提供体力管理基础，降低持续作战的疲劳惩罚，鼓励稳扎稳打的前排风格。
