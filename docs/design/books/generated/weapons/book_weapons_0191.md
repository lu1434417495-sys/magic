# 《战鼓锤：节奏比力量更重要》

## 基础信息

- **书籍 ID**：`book_weapons_0191`
- **关联技能**：`warrior_war_drum_mace`, `cleric_rhythm_strike`
- **使用效果**：阅读后解锁 `warrior_war_drum_mace`；若已学会，提升该技能 `current_mastery +110`，并令连续命中同一目标时每次伤害递增 `4%`，最多叠加 `3` 次。
- **阅读要求**：角色职业标签含 `warrior`、`cleric` 或 `bard`；基础 `力量 ≥ 10`。
- **稀有度**：精良（Uncommon）
- **建议投放**：战鼓营地、教会仪式武库、吟游诗人行会。

## 书籍内容

战鼓锤的用法源自军阵鼓点：一下、两下、三下，节奏稳定后第四下最致命。作者认为，这种钝器的真正威力不是单次打击，而是通过连续命中让敌人的防御节奏崩溃。书中详细讲解了三种基本鼓点式连击：慢-慢-快、快-快-慢、以及匀速三连，每一种都对应不同的敌人反应。后半部分讨论如何利用声音干扰对手：战鼓锤击中盾牌或甲片时会产生沉闷的撞击声，连续的声音会让敌人下意识地预判下一次落点，而这正是变招的机会。作者提醒读者，战鼓锤最忌讳的是乱了节奏——一旦快一下慢一下，它的威胁就会大打折扣。作者建议练习者对着战鼓挥锤，让锤击与鼓点重合，直到连击变成身体的节拍器。作者建议在锤柄上缠上不同颜色的布条，通过视觉提醒自己何时该变招。

## 设计意图

为战士与圣职系提供节奏型钝器，通过连续命中叠加奖励鼓励稳定输出循环。
