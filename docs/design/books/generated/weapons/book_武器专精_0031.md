# 《盾击武器衔接》

## 基础信息

- **书籍 ID**：`book_武器专精_0031`
- **关联技能**：`warrior_shield_bash_follow`、`weapon_shield_combo`
- **使用效果**：阅读后解锁 `warrior_shield_bash_follow`；若已学会，提升 `current_mastery +120`，并在盾击命中后立即触发一次无消耗的普攻追击。
- **阅读要求**：已装备盾牌与单手武器；基础 `力量 ≥ 10`。
- **稀有度**：精良（Uncommon）
- **建议投放**：军械库、盾卫进阶任务、老兵教官奖励。

## 书籍内容

盾击之后的那一瞬间，是战场最容易被浪费的黄金时间。作者指出，大多数战士用盾击把敌人推开后就停下来重新摆架势，实际上盾击的真正价值在于把敌人震到短暂僵直。书中教读者如何利用这短暂窗口：盾击后不要后撤，而是立刻踏前半步，用单手武器从盾牌上方或侧方刺入敌人暴露的空当。作者把这套动作称为「跟进」，并强调跟进的速度比力量更重要——盾击造成的僵直通常只有不到一秒，犹豫就会错失。后半本还讨论了不同盾型的跟进差异：小盾机动好但控制弱，需要更快的反应；大盾控制强但收招慢，需要提前规划路线。最后一页画着一个被盾牌撞歪身体的敌人，配文：「他还没恢复平衡，你的剑应该已经在等他了。作者在断桥营寨的城墙上观察了三年攻城战，总结出盾击后最有效的跟进距离：不多不少，正好一步半。

## 设计意图

把盾击从单纯的控制技能延伸为连招起手，提升盾卫的输出节奏与操作反馈。
