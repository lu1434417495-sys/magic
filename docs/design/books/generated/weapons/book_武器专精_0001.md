# 《铁匠学徒的握剑要诀》

## 基础信息

- **书籍 ID**：`book_武器专精_0001`
- **关联技能**：`warrior_sword_slash`、`weapon_sword_grip`
- **使用效果**：阅读后获得 `warrior_sword_slash` 技能解锁机会（若未学会）；若已学会，提升该技能 `current_mastery +80`。
- **阅读要求**：无职业限制；基础 `力量 ≥ 6` 或 `敏捷 ≥ 6`。
- **稀有度**：普通（Common）
- **建议投放**：新手村铁匠铺、战士训练场、通用武器商人。

## 书籍内容

这本书的扉页上沾着干涸的煤灰，显然曾被无数次放在铁砧旁翻阅。作者自称只是铁匠铺最不起眼的学徒，却用三十页篇幅论证了「握剑不是握手」的道理。书中把剑柄分成根、腹、尾三段，指出新手最常见的错误是五指均匀用力，导致挥砍时剑身摇晃；正确做法是让掌根压住剑柄根部，中指与无名指像钳子一样夹住腹部，小指与食指则负责微调方向。作者还画了一组手掌简图，分别标注「太松」「太紧」「对了」。后半本讲站姿：握剑时肩膀必须比日常低半寸，肘部微微外张，这样劈砍时力量才能从脚底一路传到剑尖，而不是卡在手腕。最后一页是一句被反复描粗的告诫：「剑会告诉你它想往哪走，你要先学会听懂。」作者还在书页边缘画下自己第一次握剑时磨出的血泡，旁边标注日期，仿佛那是一道比任何剑痕都重要的勋章。

## 设计意图

作为武器专精系列最基础的书籍，降低战士系入门门槛，把「挥砍」从按键动作还原为身体发力的连贯过程。
