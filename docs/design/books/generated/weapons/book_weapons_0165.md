# 《链枷弧光：不可预测的落点》

## 基础信息

- **书籍 ID**：`book_weapons_0165`
- **关联技能**：`warrior_flail_sweep`, `warrior_flail_overhead`
- **使用效果**：阅读后解锁 `warrior_flail_sweep`；若已学会，提升该技能 `current_mastery +110`，并令链枷攻击对格挡敌人的伤害穿透提升 `8%`。
- **阅读要求**：角色职业标签含 `warrior` 或 `berserker`；基础 `力量 ≥ 12`。
- **稀有度**：稀有（Rare）
- **建议投放**：异端审判所武库、北方狂战士营地、地下竞技场。

## 书籍内容

链枷是唯一一种使用者自己也无法完全预测落点的武器，而这正是它的可怕之处。作者认为，链枷的精髓在于利用敌人的防御惯性：当敌人举盾准备迎接直来直去的攻击时，链枷的锤头会绕过盾面砸向头盔或肩膀。书中详细讲解了握柄长度、链节数量与锤头重量对弧线的影响，并给出了三种常见配置的使用场景。后半部分讨论"甩鞭"技巧：通过改变挥动节奏让锤头在最后一刻加速或变向，从而打穿敌人的格挡预判。作者警告读者，链枷同样不可预测地反噬自己——初学者最常受的伤来自回弹的锤头。作者提醒，链枷使用者必须佩戴特制的护颈，因为回弹的锤头是新手最常见的死因。他还强调，链枷挥出后必须顺着惯性转身，强行停止只会让自己暴露空门。

## 设计意图

为重武器战士提供反格挡专精，通过不可预测的攻击弧线克制防御型敌人。
