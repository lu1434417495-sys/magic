# 《战锤落点学》

## 基础信息

- **书籍 ID**：`book_武器专精_0107`
- **关联技能**：`weapon_warhammer_strike`
- **使用效果**：阅读后解锁 `weapon_warhammer_strike`；若已学会，提升 `current_mastery +100`，并在下一次战斗中锤击眩晕判定 +5%。
- **阅读要求**：无职业限制；基础 `力量 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：石堡哨所军械库、矿洞巡逻兵掉落、城市守卫训练任务。

## 书籍内容

这本书的每一页都像被锤打过，边缘卷曲、字迹粗重。作者用一句话定义战锤："剑追求切口，锤追求震动。"落点学不讲如何挥锤，只讲锤头应该落在哪里。头盔正面最硬，但震动会传导至颈椎；胸甲中心会分散冲击力，而肩窝和髋骨连接处会把震动送进内脏。书中配有十二种常见敌人的骨骼简图，标注了作者建议的首选落点，并在旁边用小字写下"试过，有效"或"试过，差点死"。最后一章讨论追击：敌人被震退后，不要急着补上第二锤，而要先确认对方是真的失衡，还是只是假装失衡引你近身。有牧师把这本书送给新兵时，会在扉页写下祷言：让每一锤都落在该落之处。圣骑士团甚至发展出了专门配合锤击的神圣震击仪式。新锤兵在扉页祷言旁签名，意味着正式接受这份责任。战锤手相信，锤头落下的位置就是命运的回答。

## 设计意图

让战锤使用者理解控制与冲击机制，提供首次眩晕判定加成作为战斗甜头。
