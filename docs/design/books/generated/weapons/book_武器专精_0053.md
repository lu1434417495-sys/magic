# 《反手剑弧：腰胯带动》

## 基础信息

- **书籍 ID**：`book_武器专精_0053`
- **关联技能**：`warrior_spin_slash`
- **使用效果**：阅读后解锁 `warrior_spin_slash`；若已学会，提升该技能 `current_mastery +100`。
- **阅读要求**：已装备剑类武器；基础 `力量 ≥ 7`。
- **稀有度**：普通（Common）
- **建议投放**：佣兵公会、游荡剑客、废墟宝箱。

## 书籍内容

反手挥剑看起来潇洒，实际上最容易变成原地打转的破绽。作者开篇便指出，真正让反手剑成立的不是手臂力量，而是腰胯旋转时产生的离心力。书中用一根绑在腰上的长布条做示范：如果布条在转身时没有被甩成水平直线，说明发力还停留在肩膀。练习分为三步，先慢速转身保持平衡，再带剑出弧观察轨迹，最后在实际距离中控制落点。作者特别提醒，反手剑最忌讳贪大求全，弧度一旦超过一百八十度，身后和侧翼就会同时暴露。末页画了一个简笔小人，身体中轴笔直，剑锋却划出一道饱满的弧线，旁边批注：圆心是腰，不是肩。

书的扉页被某位前任主人撕去一半，只剩半句话：……真正的反手，是让敌人以为你要逃。后半页则用炭笔画了一个脚印，脚跟朝内，脚尖朝外，像一朵半开的花，暗示转身的发力。

## 设计意图

为剑士提供中距离范围打击选项，把旋转斩从炫技动作重构为以躯干为核心的发力训练。
