# 《西洋剑剑柄击：当剑尖不够用时》

## 基础信息

- **书籍 ID**：`book_weapons_0194`
- **关联技能**：`duelist_pommel_strike`, `warrior_sword_bash`
- **使用效果**：阅读后解锁 `duelist_pommel_strike`；若已学会，提升该技能 `current_mastery +90`，并令剑柄击命中后 `2` 秒内目标格挡效率下降 `15%`。
- **阅读要求**：角色职业标签含 `duelist`、`warrior` 或 `rogue`；基础 `敏捷 ≥ 10`。
- **稀有度**：普通（Common）
- **建议投放**：决斗学院、贵族武师私教、竞技场基础教材。

## 书籍内容

剑柄击是被许多剑客瞧不起的技巧，但在近身混战中它往往比刺击更救命。作者认为，剑柄击的价值在于突然与多功能：它可以砸晕敌人、打开距离、破坏对方架势，或者在剑身被格挡时创造二次攻击机会。书中详细讲解了三种剑柄击时机：敌人低头时砸向头盔、敌人举剑过顶时砸向手腕、以及双方剑刃交缠时推压对方护手。后半部分讨论力度控制：剑柄击不需要全力，太用力会让自己的剑失去控制；关键是让对手在一瞬间失去平衡。作者提醒读者，剑柄击不是终结技，而是为真正的终结创造空间的手段。书中提醒，剑柄击最常见的失败是击中头盔后自己的手指被震麻，因此必须握紧护手。作者附有一张剑柄击的力道分布图，标注了能造成眩晕而不至于碎骨的最佳接触点。

## 设计意图

为剑士提供近身控制小技能，丰富剑斗连招与反格挡手段。
