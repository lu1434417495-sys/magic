# 《手半剑：一手半的灵活》

## 基础信息

- **书籍 ID**：`book_weapons_0188`
- **关联技能**：`warrior_bastard_sword`, `warrior_hand_and_a_half`
- **使用效果**：阅读后解锁 `warrior_bastard_sword`；若已学会，提升该技能 `current_mastery +110`，并令单手与双手姿态切换后的首次攻击伤害提升 `8%`。
- **阅读要求**：角色职业标签含 `warrior`、`knight` 或 `duelist`；基础 `力量 ≥ 10`、基础 `敏捷 ≥ 9`。
- **稀有度**：精良（Uncommon）
- **建议投放**：骑士团武库、雇佣兵营地、王室卫队训练营。

## 书籍内容

手半剑介于单手剑与双手剑之间，因此它可以根据战场需要随时切换两种握法。作者认为，这种灵活性是优势也是陷阱——切换太频繁会让人失去节奏，切换太少又会浪费武器潜力。书中详细讲解了单手配盾时的刺击与格挡，以及双手握持时的劈砍与半剑术。后半部分讨论"切换时机"：当敌人近身时换单手争取速度，当敌人露出破绽时换双手追求伤害，切换本身也可以成为假动作的一部分。作者提醒读者，手半剑的使用者必须同时精通单手与双手两种思路，否则这把剑只会显得样样通、样样松。书中建议，切换握法时要用盾牌或脚步掩护，因为切换本身是最容易被敌人抓住的空隙。真正的高手能在一次格挡中完成握法切换，让敌人以为面对的仍是同一把剑。

## 设计意图

为全能剑士提供形态切换武器，通过姿态变化奖励鼓励玩家根据战况调整打法。
