# 《血滴子：抛出的断头圆环》

## 书籍内容

血滴子是暗杀技艺中最骇人听闻也最难以驾驭的一种：一个内侧装有利刃的金属圆环，抛出后能套住目标脖颈并旋转收紧。作者没有署名，但书中每一页都透露着对这种武器近乎宗教般的敬畏。书中强调，血滴子不是远程武器，而是"被扔出去的近身处决"——它要求使用者在抛出前准确判断目标的身高、姿态与移动方向。后半部分讨论回收与失败处理：一旦血滴子没有套中，使用者必须立刻准备近身战或撤退，因为敌人会瞬间意识到自己被刺客盯上。末页只有一句话，用朱砂写成："圆环飞出去后，不是他死，就是你亡。"书末用血写着警告："练习时先用稻草人，直到你能连续十次套中同一根脖子。"传说真正的血滴子大师一生只失手一次，而那一次，圆环飞向了镜子里的自己。

## 设计意图

作为刺客系传说级终结武器，提供高风险、高视觉冲击的处决技能，服务于顶级暗杀构筑。
