# 《宗师兵器心得：万法归一》

## 基础信息

- **书籍 ID**：`book_武器专精_0050`
- **关联技能**：`weapon_master_unity`、`weapon_affinity_test`
- **使用效果**：阅读后获得 `weapon_master_unity` 解锁机会；若已学会，提升 `current_mastery +200`，并提高所有武器类技能 `current_mastery +30`。
- **阅读要求**：已学会至少五种不同类型的武器技能；基础 `力量 ≥ 12` 或 `敏捷 ≥ 12`；基础 `感知 ≥ 12`。
- **稀有度**：传说（Legendary）
- **建议投放**：宗师试炼奖励、传说遗迹最深处、世界Boss宝箱。

## 书籍内容

这本书没有固定作者，历代兵器宗师都在末尾添上几行自己的心得，然后再传给下一位挑战成功者。开篇便是一句被无数手迹包围的话：「万法归一，不是把所有武器练成一样，而是让所有武器都成为你意志的延伸。」书中不教具体招式，只讲一种状态：当使用者不再需要思考「我现在拿的是什么」时，身体的记忆会自动选择最合适的角度、力度与距离。一位宗师写道，他在暮年甚至能用一根木棍施展出剑的精准、斧的暴烈、矛的压迫，因为他已经不再依赖武器的形状，而是依赖自己对战斗的理解。另一位宗师则在末尾警告：「万法归一是终点，也是陷阱——当你觉得自己什么都懂时，就是下一个徒弟打败你的时候。最新的一位宗师只添了八个字：「放下此书，去练。」这八个字被无数后来者用墨圈起，争论它到底是敷衍还是终极答案。

## 设计意图

作为武器专精系列的终极书籍，奖励多元化的武器修炼路线，为顶尖玩家提供显著的全身熟练度提升与职业认同感。
