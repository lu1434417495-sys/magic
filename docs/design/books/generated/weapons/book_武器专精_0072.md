# 《骨裂锤：震荡内脏》

## 基础信息

- **书籍 ID**：`book_武器专精_0072`
- **关联技能**：`warrior_bone_crush`
- **使用效果**：阅读后解锁 `warrior_bone_crush`；若已学会，提升该技能 `current_mastery +120`。
- **阅读要求**：已装备锤类武器；基础 `力量 ≥ 9`。
- **稀有度**：普通（Common）
- **建议投放**：地牢看守、骨匠工坊、废墟巨魔巢穴。

## 书籍内容

骨裂锤的可怕之处不在于它砸断了什么，而在于它砸不断的东西也会受伤。作者用解剖图说明钝力如何穿过皮肉，在骨骼表面造成微裂，并让内脏发生位移。书中教导练习者瞄准胸腹之间的区域：这里集中了肝脏、脾脏和胃，震荡会让敌人短时间内无法集中呼吸。练习方法是在装满沙子的皮袋上挥锤，要求沙子不从袋中洒出，但袋子后面的木板出现裂纹，这意味着力量传透了。后半本讨论节奏：骨裂锤不需要连续快攻，而是每一击之间给敌人留出颤抖的时间，让他们自己暴露下一次落点。末页写着：骨头会愈合，但愈合之前你什么也做不了。

一位地牢看守在空白处列了一张清单，记录哪种犯人在受震荡后最容易招供。清单被后来的读者用墨涂掉了，只留下一行字：此法伤人不伤骨，慎用。再下面有人画了一个骷髅。

## 设计意图

为锤类武器提供持续削弱型技能，通过钝击震荡降低敌人的战斗续航能力。
