# 《大剑蓄力入门》

## 基础信息

- **书籍 ID**：`book_武器专精_0103`
- **关联技能**：`weapon_greatsword_charge`
- **使用效果**：阅读后解锁 `weapon_greatsword_charge`；若已学会，提升 `current_mastery +100`，并缩短首次蓄力前摇 5%（一次性战斗增益）。
- **阅读要求**：职业标签含 `warrior`；基础 `力量 ≥ 10`。
- **稀有度**：普通（Common）
- **建议投放**：山岳聚落训练场、重甲巡逻兵掉落、铁匠学徒任务。

## 书籍内容

大剑玩家最常犯的错误是：把蓄力当成越久越好。这本书在第一页就用红字写道："蓄力不是憋气，是借钱。"借的是敌人的节奏，还的是自己的位置。作者建议初学者先练习半蓄：把剑举到肩高就出手，感受重心的前后转移，而不是追求满蓄那一下的破坏力。书中还指出，大剑的蓄力窗口应该选在敌人攻击后的硬直里，而不是自己主动创造的空隙里。第二章配有几张被血浸透的草图，显示如何在举剑时用护手护住面门。最后一页只有一句话："真正吓退敌人的不是剑落下的时候，而是剑举起来还没落下的时候。"作者建议将铁山桩的静态承重与蓄力结合，用斗气稳住下盘后再举剑，能显著减少反震带来的硬直。战士馆的新手往往因此少走半年弯路。战士们常说，能稳住大剑的人，才能稳住自己的命运。

## 设计意图

降低大剑上手门槛，把"高风险高回报"简化为可执行的蓄力节奏教学。
