# 《弩机齿轮学：静力与精准》

## 基础信息

- **书籍 ID**：`book_weapons_0157`
- **关联技能**：`archer_crossbow_mastery`, `archer_bolt_craft`
- **使用效果**：阅读后解锁 `archer_crossbow_mastery`；若已学会，提升该技能 `current_mastery +110`，并解锁 `archer_bolt_craft` 的配方知识。
- **阅读要求**：角色职业标签含 `archer`、`ranger` 或 `engineer`；基础 `感知 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：工匠行会图纸柜、城防器械库、遗迹机械宝箱。

## 书籍内容

这本书更像一本工程手册，里面充满了齿轮比、弦张力和弩臂弹性的计算。作者认为弩是"把力量存起来再一次性释放"的武器，因此使用者真正的技艺不在发射，而在维护与准备。书中详细讲解了三种上弦方式：足踏、腰带与绞盘，并指出不同方式对弩机寿命与精度的影响。中段有一章专门讨论弩矢配重，强调矢身过轻会导致翻滚，过重则会下坠过快。后半部分收录了几张残缺的设计图，画的是一种可以连发的小型弩机，但关键部件被刻意涂黑。作者在最后写道："弩不会原谅粗心的人，但它会忠实回报每一个认真对待它的人。"书中夹着一张采购清单，列着各种润滑油、清洁布与备用弦，旁注写着"细心者生，粗心者死"。

## 设计意图

为弓手系引入弩专精分支，强调准备、维护与资源制作，与速射弓形成鲜明对比。
