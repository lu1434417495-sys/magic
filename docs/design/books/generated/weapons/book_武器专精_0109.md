# 《长枪突刺基础》

## 基础信息

- **书籍 ID**：`book_武器专精_0109`
- **关联技能**：`weapon_spear_thrust`
- **使用效果**：阅读后解锁 `weapon_spear_thrust`；若已学会，提升 `current_mastery +100`，并增加首次突刺攻击距离半个身位（一次性战斗增益）。
- **阅读要求**：无职业限制；基础 `力量 ≥ 7` 或 `敏捷 ≥ 7`。
- **稀有度**：普通（Common）
- **建议投放**：边境哨所长枪兵营地、民兵训练任务、普通武器商人。

## 书籍内容

这本书被设计成可以塞进长枪兵的胸甲口袋里，尺寸很小但内容极扎实。开篇说："枪是线的艺术，不是点的艺术。"突刺不是把枪尖送到敌人身上，而是让整条枪身成为一条从肩膀延伸到枪尖的直线。作者用稻草人练习法讲解：先在稻草人胸口画一个铜钱大小的圈，然后后退三步，每次突刺都要让枪尖从圈中心穿过，而不是擦边。书中还警告了一个常见错误：刺中后立刻拔枪，结果枪头被肌肉或盔甲夹住。正确做法是在刺入后轻微拧动手腕，让枪刃沿原路退出。最后一页有一幅被刺穿的靶纸，旁边写着："刺中很容易，刺得准很难。"长枪兵常与灰烬翻滚配合使用：先翻滚拉近距离，再起枪突刺。书中夹着一张被烧焦的便条，上面写着：翻滚后不要急着站直，半蹲起枪更快。这种配合在灰烬交界入口营地被反复演练，已成为长枪兵的本能。

## 设计意图

作为长枪入门，突刺距离奖励让玩家立刻感受到长枪的攻击范围优势。
