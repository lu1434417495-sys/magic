# 《链锤甩击：借势弧线》

## 基础信息

- **书籍 ID**：`book_武器专精_0098`
- **关联技能**：`warrior_chain_hammer_swing`
- **使用效果**：阅读后解锁 `warrior_chain_hammer_swing`（待新增，标签 `whip`、`blunt`）；若已学会，提升该技能 `current_mastery +130`。
- **阅读要求**：已装备鞭/链锤类武器；基础 `力量 ≥ 10`、`敏捷 ≥ 8`。
- **稀有度**：精良（Uncommon）
- **建议投放**：角斗场、地下竞技场、狂信者营地。

## 书籍内容

链锤的攻击路径是一条不断加速的弧线。这本书教使用者如何利用这条弧线：先让锤头在身侧低速旋转积蓄动能，再在合适的角度释放，让锤头像被甩出去一样砸向目标。作者指出，链锤的威力在于它可以从意想不到的角度越过盾牌或格挡，击中头盔侧面或肩膀。书中警告，甩击时最容易犯的错误是贪大求全：弧线一旦拉得太大，敌人就有时间贴近，而链锤在近身时几乎无用。后半本讨论如何收势：击中后立刻借回弹之力把锤头拉回防守位置，而不是让它在身周乱飞。末页画着一条被砸凹的盾牌，配文：链锤不是砸穿防御，而是从防御旁边绕过去。

角斗场的冠军在空白处画了一个小人，正把链锤甩过头顶。他批注：不要把锤子举高，要让它自己飞高。你举得越高，敌人低头躲得越容易。冠军的下场是被自己的链锤缠住了脖子。

## 设计意图

为软兵器使用者提供高伤害弧线打击，把链锤的不可预测性转化为实战中的破防能力。
