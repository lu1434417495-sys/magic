# 《弱点打击兵器学》

## 基础信息

- **书籍 ID**：`book_武器专精_0046`
- **关联技能**：`weapon_weakpoint_strike`、`weapon_anatomy`
- **使用效果**：阅读后解锁 `weapon_weakpoint_strike`；若已学会，提升 `current_mastery +120`，并提高对类人敌人弱点部位的暴击伤害 `+8%。
- **阅读要求**：无职业限制；基础 `感知 ≥ 10`、`智力 ≥ 8`。
- **稀有度**：精良（Uncommon）
- **建议投放**：刺客公会藏书、游侠导师、战场军医室。

## 书籍内容

武器的真正目标不是盔甲，而是盔甲后面的肉体。作者用解剖图讲解了类人敌人的主要弱点：咽喉、腋下、腹股沟、膝盖后侧，以及肘关节内侧。书中指出，不同武器适合攻击不同弱点：长矛适合咽喉与关节，钝器适合头盔覆盖下的头部与肋骨，匕首则适合腋下与腹股沟的柔软缝隙。作者还强调，打击弱点需要的不是运气，而是耐心——大多数敌人会本能地保护这些位置，你必须用假动作或队友配合逼迫他们露出空当。后半本收录了数种常见护甲的薄弱点：板甲的腋下与肩颈连接处、锁子甲的腰部、皮甲的脊椎。最后一页是一张被反复翻阅的人体图，几个部位被红笔圈出，配文：「盔甲是谎言，身体是真相，你的武器要学会戳穿谎言。 附录以表格列出常见敌人护甲的薄弱接缝与关节位置，供读者临场对照。

## 设计意图

把「打弱点」从随机暴击提升为可学习、可针对的战术技能，增强战斗的策略性与真实感。
