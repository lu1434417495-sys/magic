# 《擒拿反关节：控制即伤害》

## 基础信息

- **书籍 ID**：`book_武器专精_0095`
- **关联技能**：`warrior_unarmed_grapple`
- **使用效果**：阅读后解锁 `warrior_unarmed_grapple`（待新增，标签 `unarmed`、`control`）；若已学会，提升该技能 `current_mastery +130`。

## 书籍内容

擒拿不是把敌人摔倒，而是让敌人的关节到达它不该去的方向。这本书前半本讲结构：人体哪些关节只能向一个方向弯曲，哪些方向弯曲会立刻失去战斗力。作者强调，擒拿的力量不是蛮力，而是利用敌人自己的力量：当敌人出拳时，顺着他的力道一拉一扭，就能让他的肘关节或手腕陷入被动。书中要求练习者先用慢速配合的伙伴反复练习，直到能在对方发力瞬间找到反关节的角度。后半本讨论地面控制：把敌人摔倒后，如何用膝盖和体重锁住对方的行动，而不是急于补拳。末页写着：让敌人动弹不得，比让他流血更安全。

书中强调，擒拿时最重要的是自己的重心要低，因为你在控制别人的关节时，自己的身体也处于一个容易失衡的姿势。低一寸，安全一分。作者建议初学者先在泥地里练，摔了不会太疼。

## 设计意图

为徒手战士提供控制型技能，把徒手战斗从单纯输出扩展为削弱与锁定的混合手段。
