# 《回旋剑舞：周身圆》

## 基础信息

- **书籍 ID**：`book_武器专精_0059`
- **关联技能**：`warrior_whirlwind_slash`
- **使用效果**：阅读后解锁 `warrior_whirlwind_slash`（待新增，标签 `sword`、`aoe`）；若已学会，提升该技能 `current_mastery +150`。
- **阅读要求**：已学会 `warrior_spin_slash`；基础 `敏捷 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：剑舞团营地、精灵遗迹、高级竞技场。

## 书籍内容

当敌人从四面八方围上来时，剑客需要一次让周身都成为危险的攻击。回旋剑舞不是简单的原地转圈，而是在旋转中通过脚步微调控制攻击半径，让每一圈剑锋覆盖不同的距离。作者把动作分为内旋和外旋：内旋时剑刃贴近身体，用于逼退贴身敌人；外旋时剑锋甩出，用于收割中距离目标。书中用大段的墨迹画出一圈又一圈的轨迹，像一朵绽开的黑色花。作者提醒，真正的剑舞者在旋转时不会头晕，因为他们始终盯着一个固定的视觉锚点。末页有一句话被雨水洇开了一半：当你成为圆心，所有靠近你的东西都在你的圆上。

书的最后一页是一首短诗：圆心不动，圆周皆刃；敌进我旋，敌退我进。诗下有一行小字：舞得再好，也不要在悬崖边用这招。再下面还有更小一行：我试过，没死，但很近。

 书后附有作者手绘的握腕与转肩示意图，提醒习练者注意刃筋与发力的配合。

## 设计意图

为剑士提供被包围时的清场手段，把个人武技升华为以自身为范围的战场控制。
