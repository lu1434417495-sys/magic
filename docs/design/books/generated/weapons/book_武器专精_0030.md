# 《剑盾配合要义》

## 基础信息

- **书籍 ID**：`book_武器专精_0030`
- **关联技能**：`warrior_sword_and_board`、`weapon_sword_shield_sync`
- **使用效果**：阅读后解锁 `warrior_sword_and_board`；若已学会，提升 `current_mastery +110`，并在格挡成功后 1 回合内提高反击伤害 `+10%。
- **阅读要求**：已装备单手剑与盾牌；基础 `力量 ≥ 9`、`体质 ≥ 8`。
- **稀有度**：精良（Uncommon）
- **建议投放**：断桥营寨军械库、盾卫训练任务、老兵遗物。

## 书籍内容

剑与盾不是两件武器，而是一个系统的两端。作者认为，盾的主要职责不是挡下所有攻击，而是为剑创造出手空间。书中把配合分为「盾引剑出」与「剑护盾回」两种模式：前者用盾牌吸引或偏转敌人攻击，在敌人失去平衡的瞬间出剑；后者则在剑击后收势较慢时，用盾牌补位防守。作者强调，举盾的高度与角度必须配合剑的位置，例如剑准备上段劈砍时，盾应略低以保护躯干；剑准备突刺时，盾应前置以掩护剑路。后半本用大量实战图示说明如何应对不同方向的同时攻击。最后一页是一句老兵的总结：「盾是剑的影子，剑是盾的回答。书中提到一位独臂盾卫的传奇，他把盾牌绑在残肢上，用剩下的那只手持剑，成为断桥营寨最坚固的防线。断桥营寨的老兵常说，一个好的盾卫能让队友忘记盾牌的存在，因为所有危险都在抵达队友之前被解决了。

## 设计意图

深化剑盾战士的战斗系统，把格挡与反击连接成连贯的节奏，强化前排坦克的进攻能力。
