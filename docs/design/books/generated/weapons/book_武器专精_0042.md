# 《灰烬武器共鸣论》

## 基础信息

- **书籍 ID**：`book_武器专精_0042`
- **关联技能**：`ashen_weapon_resonance`、`weapon_ash_touched`
- **使用效果**：阅读后解锁 `ashen_weapon_resonance`；若已学会，提升 `current_mastery +130`，并提高灰烬交界内武器技能的触发稳定性 `+8%。
- **阅读要求**：无职业限制；基础 `意志 ≥ 9`；已抵达灰烬交界。
- **稀有度**：稀有（Rare）
- **建议投放**：灰烬交界入口营地、余烬祭所、异界商人。

## 书籍内容

灰烬交界的武器会低语，只有愿意倾听的人才能与之共鸣。作者指出，异界能量会让金属内部产生微弱的振动，这种振动在普通环境中几乎无法察觉，但在灰烬浓度高的区域会显著增强。书中把共鸣分为「顺共鸣」与「逆共鸣」：顺共鸣能让武器更顺畅地引导异界能量，提高技能的稳定性；逆共鸣则会让武器反噬使用者，造成体力或精神上的损耗。作者建议初学者不要急于追求强大的共鸣，而是先用冥想或斗气稳定自身频率，再逐步与武器同步。后半本收录了数种常见武器在灰烬交界中的异常表现：长剑会发出低沉鸣响，战斧会不自主地震颤，匕首则会在黑暗中微微发亮。最后一页写道：「不要害怕武器的变化，那是它在学习你。作者声称自己在灰烬交界边缘曾听见武器发出类似哭泣的声音。

## 设计意图

作为灰烬交界武器系统的入门读物，为异界战斗提供独特的武器共鸣机制与世界观铺垫。
