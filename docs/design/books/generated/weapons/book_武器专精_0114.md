# 《拳套贴身战纪》

## 基础信息

- **书籍 ID**：`book_武器专精_0114`
- **关联技能**：`weapon_fist_strike`
- **使用效果**：阅读后解锁 `weapon_fist_strike`；若已学会，提升 `current_mastery +100`，并提升下一场战斗中近身攻击的命中率 3%。
- **阅读要求**：职业标签含 `monk` 或 `warrior`；基础 `敏捷 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：武馆入门书架、街头拳师遗物、市井格斗任务奖励。

## 书籍内容

拳套是距离最近的武器，因此也是最危险的书。作者开篇警告："戴拳套不是为了保护你的手，是为了让你敢于打中骨头。"贴身战纪不讲招式，只讲距离。它把战斗距离分为远距、中距、近距和贴距，而拳套只在贴距真正有效。进入贴距的关键不是冲过去，而是让敌人以为你还在中距时突然压进半步。书中还详细记录了如何在贴身时呼吸：许多人一近身就屏息，导致肌肉僵硬，真正应该做的是短促呼气，让核心保持弹性。附录里有一页揉皱的赌债欠条，作者在下面备注："赢得比赛还了债，但书里的债还在。"武馆的武僧常把贴身战纪与斗气修炼并修，因为斗气在静止中生成，而拳套在最短距离内释放。两者结合，便是最朴素的爆发。斗气与拳套的结合，让许多武僧在入门半年内战力翻倍。拳套使用者总说，最近的距离才是最真实的距离。

## 设计意图

为徒手/拳套build提供贴距概念，命中奖励让玩家在近身缠斗中更有信心。
