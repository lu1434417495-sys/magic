# 《巨剑挥砍的呼吸》

## 基础信息

- **书籍 ID**：`book_武器专精_0104`
- **关联技能**：`weapon_greatsword_cleave`
- **使用效果**：阅读后解锁 `weapon_greatsword_cleave`（待新增）；若已学会，提升 `current_mastery +140`，并解锁知识 `known_knowledge_greatsword_arc`。
- **阅读要求**：职业标签含 `warrior` 或 `berserker`；基础 `力量 ≥ 12`。
- **稀有度**：精良（Uncommon）
- **建议投放**：巨人骸骨遗迹、老兵遗物、高地战团军械库。

## 书籍内容

这本书没有教如何挥剑，而是教如何在挥剑时呼吸。作者认为巨剑的每一次挥砍都是一次完整的呼吸循环：吸气把剑带起，屏息决定方向，呼气释放斩击。错误的呼吸会让第二刀慢上半拍，而半拍在灰烬交界的战场上足够死三次。书中列有七种常见武器的斩击弧线对照图，指出巨剑的弧线最大，也意味着最需要提前规划落点。后半部分讲"挥空后的补救"：当一剑砍到空气时，如何用脚步和肩转动把惯性导向下一击，而不是变成一个转圈的靶子。书脊里夹着一片碎甲，据说是作者第一次成功打断重甲敌人时留下的纪念品。呼吸法与冥想中的潮汐呼吸相通，只是潮汐呼吸向内安抚心神，巨剑呼吸向外释放惯性。有修士读后声称自己的重剑斩击多了一份禅意。重剑修士会把这本书与铁山桩一起摆在床头，日夜参悟。

## 设计意图

把巨剑从"数值碾压"重新包装为呼吸与惯性的艺术，配合知识解锁鼓励深度练习。
