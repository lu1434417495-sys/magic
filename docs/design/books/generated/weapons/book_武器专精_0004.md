# 《双手大剑挥斩学》

## 基础信息

- **书籍 ID**：`book_武器专精_0004`
- **关联技能**：`warrior_greatsword_cleave`、`weapon_greatsword_stance`
- **使用效果**：阅读后获得 `warrior_greatsword_cleave` 解锁机会；若已学会，提升 `current_mastery +120`，并在下一次战斗中首次重击获得 `+8%` 伤害加成。
- **阅读要求**：已装备双手剑；基础 `力量 ≥ 10`。
- **稀有度**：精良（Uncommon）
- **建议投放**：狂战士训练场、山岳聚落传承任务、巨兽狩猎奖励。

## 书籍内容

双手大剑的恐怖不在于重量，而在于它能把全身重量变成一次单向承诺。作者把挥斩分为「蓄、放、跟」三个阶段，警告读者最危险的是「放」之后的那口气——许多人以为自己砍中了就放松肩膀，结果剑身卡在骨头或盾牌里拔不出来。书中花了整整两章讲如何利用惯性：大剑出手后不要立刻往回拉，而是顺着弧线让它自然下沉，利用这一小段下坠完成下一次起势。作者还提醒，双手剑最忌讳原地转圈挥砍，那是竞技场表演，战场上只会把自己的侧面卖给第二个人。最后一页是一张血迹斑斑的身高对照表，标注着不同身高战士的最佳握距，旁边潦草地写着：「大剑不是抡圆的，是推出去的。传闻这本书最早写在一头巨龙的腹皮上，作者是个独眼佣兵，他坚持大剑的真正重量不在手里，而在每次挥出前的心理准备。

## 设计意图

强化双手武器「高伤害、高风险、需要节奏控制」的定位，用一次性首击加成降低玩家尝试重武器的心理门槛。
