# 《双匕首连击节奏》

## 基础信息

- **书籍 ID**：`book_武器专精_0019`
- **关联技能**：`rogue_dual_dagger_flurry`、`weapon_dual_dagger`
- **使用效果**：阅读后解锁 `rogue_dual_dagger_flurry`；若已学会，提升 `current_mastery +130`，并减少该技能首次连击的 `stamina` 消耗 2 点。
- **阅读要求**：已装备两把匕首；基础 `敏捷 ≥ 12`。
- **稀有度**：精良（Uncommon）
- **建议投放**：盗贼公会高级教材、黑市商人、精英刺客任务奖励。

## 书籍内容

双匕首不是两只手各做一件事，而是一只手为另一只手创造机会。作者把连击节奏比喻成心跳：主手负责「重拍」，制造威胁与压制；副手负责「轻拍」，在敌人防守转换的间隙补刀。书中警告最常见的错误是追求对称——许多人以为双匕首就是左右交替快攻，结果两把刀互相干扰，反而不如单匕首流畅。正确做法是让主手先动，吸引敌人注意，副手从相反角度或更低位置切入。作者还强调，双匕首使用者必须学会「留一只手」：永远有一只手处于可防守或可变招的位置，而不是两只同时挥空。最后一页画着一组连续动作简图，配文：「节奏乱了，你就变成了两个拿匕首的新手。一位退休刺客在页边批注，他说自己用了二十年才明白，真正致命的连击不是左右交替，而是让敌人分不清哪只手才是主攻。 附有几幅呼吸节奏图，说明出招时腰腹收紧比四肢挥动更决定劲道。

## 设计意图

把双匕首从「攻速快」的简单印象提升为需要节奏配合的连击系统，增加盗贼职业的Build深度。
