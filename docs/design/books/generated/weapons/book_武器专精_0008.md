# 《双手斧回旋要诀》

## 基础信息

- **书籍 ID**：`book_武器专精_0008`
- **关联技能**：`warrior_axe_whirlwind`、`weapon_greataxe_spin`
- **使用效果**：阅读后解锁 `warrior_axe_whirlwind`；若已学会，提升 `current_mastery +140`，并减少下一次战斗中首次旋风斩的 `stamina` 消耗 3 点。
- **阅读要求**：已装备双手斧；基础 `力量 ≥ 12`。
- **稀有度**：精良（Uncommon）
- **建议投放**：狂战士训练场、蛮荒部落祭坛、巨兽巢穴宝箱。

## 书籍内容

回旋不是原地打转，而是用斧头画出一个死亡半径。作者把双手斧的回旋斩拆解成「起势、横扫、收势」三段，重点不在扫得快，而在扫完后还能站稳。书中警告，最常见的死法是旋到一半被侧面敌人打断，所以真正的高手会在起势前先踏出一步确认周围距离。作者还提出「两圈原则」：第一圈逼退敌人、制造空间，第二圈才是杀伤；试图在第一圈就结束战斗的人往往会因为惯性太大而成为靶子。后半本记录了数种地形对回旋的影响：狭窄巷道会让斧头提前撞墙，开阔平地则容易让敌人后退躲过。最后一页画着一个被划掉的「三圈」计划，旁边写着：「两圈之后必须停，否则斧头会比敌人先决定你的结局。一位蛮族首领在页边留下血指印，他声称自己用这本书中的两圈原则，在峡谷中独自击退了一支巡逻队。

## 设计意图

把双手斧塑造成高风险高回报的控场武器，用一次性 stamina 减免鼓励玩家在获得书籍后立即验证新技能。
