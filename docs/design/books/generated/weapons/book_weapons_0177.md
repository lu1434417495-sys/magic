# 《马刀冲锋：借来的速度与恐惧》

## 基础信息

- **书籍 ID**：`book_weapons_0177`
- **关联技能**：`cavalry_saber_charge`, `warrior_mount_slash`
- **使用效果**：阅读后解锁 `cavalry_saber_charge`；若已学会，提升该技能 `current_mastery +130`，并令冲锋首刀暴击率提升 `10%`。
- **阅读要求**：角色职业标签含 `cavalry`、`ranger` 或 `warrior`；基础 `敏捷 ≥ 12`。
- **稀有度**：稀有（Rare）
- **建议投放**：边境骑兵营、游牧民营地、马王任务奖励。

## 书籍内容

马刀冲锋的威力一半来自马的速度，一半来自敌人转身时的恐惧。作者认为，骑兵真正的训练不在刀法，而在控马与选择冲锋角度。书中详细讲解了三种冲锋路线：正面撕裂、侧翼横扫与背后追击，每一种都对应不同的敌阵形态。中段有一章专门讲"出刀时机"：太早会砍空，太晚会被敌人闪开或架住，必须在马身掠过敌人的那一瞬间完成挥砍。后半部分讨论收刀与脱离：冲锋不是冲入敌阵中央，而是像刀切黄油一样划过边缘，然后借助马力重新拉开距离。末页写着："马借给你速度，你借给马恐惧。"作者强调，骑兵真正的杀招不是第一刀，而是马蹄声让敌人士兵转头时露出的侧背。书中强调，骑兵最怕的不是长枪阵，而是自己坐骑在最后一刻因恐惧而减速。

## 设计意图

为骑兵/骑乘战斗提供爆发冲锋技能，强调角度、时机与一击脱离的机动战术。
