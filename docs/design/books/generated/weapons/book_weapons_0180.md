# 《投石索回旋：石头也能有弧线》

## 基础信息

- **书籍 ID**：`book_weapons_0180`
- **关联技能**：`ranger_sling_spin`, `ranger_sling_volley`
- **使用效果**：阅读后解锁 `ranger_sling_spin`；若已学会，提升该技能 `current_mastery +90`，并令下一次战斗中首次投石索命中附加 `1` 层眩晕。
- **阅读要求**：角色职业标签含 `ranger`、`shepherd` 或 `rogue`；基础 `感知 ≥ 9`。
- **稀有度**：普通（Common）
- **建议投放**：牧羊人营地、村庄民兵仓库、山民任务奖励。

## 书籍内容

投石索是最被低估的武器之一，它廉价、安静、弹药遍地都是。作者认为投石索的关键不在力量，而在释放时机的精确：必须在弹兜旋转到最高点的瞬间松手，让石头沿着切线飞出。书中详细讲解了三种弹兜材质——皮革、麻线与兽肠——对射程与精准度的影响。后半部分讨论"甩投"与"旋投"的区别：前者适合近距离快速出手，后者适合远距离精准打击。作者还提醒读者，投石索在雨天或潮湿环境中效果会明显下降，因为湿石头更重、弹兜也更涩。末页有一句农夫式的忠告："别小看石头，大卫用的也是石头。"书中还讲到如何在移动中发射，作者认为牧羊人之所以擅长此技，是因为他们一辈子都在边走边丢石头。作者还提到，最优秀的投石索手能根据石头重量在出手前瞬间调整旋转圈数。

## 设计意图

为游侠与平民职业提供低成本远程起手，强调弹药自由与精准释放时机。
