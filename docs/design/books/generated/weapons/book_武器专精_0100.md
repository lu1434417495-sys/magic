# 《双持的代价：协调两手》

## 书籍内容

双持武器的人常犯的错误是以为两只手各打各的就能造成两倍伤害。这本书开篇便指出，双持的代价是协调：如果你的左手和右手没有配合，它们会互相干扰，速度反而比单持更慢。作者把双持分为两种思路：对称双持，即两把相同武器以同样节奏进攻；非对称双持，即一把主攻、一把辅攻，主手制造破绽，副手收割。书中要求练习者先单手熟练每一把武器，再开始双手同时练习，否则只会把两个坏习惯叠加。后半本讨论防御：双持者没有盾牌，所以必须用不断的进攻或精确的步法来替代格挡。末页写着：两只手是两把刀，但只有一颗心能决定它们何时落下。

剑舞团的团长在扉页上写了一句话：观众看的是两只手，你自己要看的却是肚脐。肚脐稳，两只手才不会打架。有人在这句下面画了一个问号，团长批注：不信你对着镜子打一架试试。

## 设计意图

为双持武器流派提供基础被动入口，把双持从视觉风格转化为需要高度协调的战术选择。
