# 《长枪突阵谱》

## 基础信息

- **书籍 ID**：`book_武器专精_0011`
- **关联技能**：`warrior_spear_charge`、`weapon_spear_stance`
- **使用效果**：阅读后获得 `warrior_spear_charge` 解锁机会；若已学会，提升 `current_mastery +110`。
- **阅读要求**：已装备长枪或矛；基础 `力量 ≥ 9`、`敏捷 ≥ 7`。
- **稀有度**：普通（Common）
- **建议投放**：军械库、枪兵训练营、阵营前线任务奖励。

## 书籍内容

突阵谱的作者是一位老兵，他把长枪战术总结为「先扎稳，再扎人」。书中前半部分讲握法：长枪不能只靠双臂控制，必须让枪杆贴着腰侧，用整个上半身作为支点，否则一次格挡就会让枪尖偏离目标。后半部分讲冲锋的时机——不是越快越好，而是要在敌人刚刚完成一次攻击、身体还来不及回正的那一瞬间发起。作者画了很多简笔小人，每个都在展示错误的冲锋姿势：枪尖太高会被拨开，太低会扎进地面，身体前倾太多则收不住脚步。最耐人寻味的章节是「停枪」：真正致命的突刺不是刺出去，而是刺中后立刻稳住，利用前冲惯性把伤口扩大，然后迅速回抽准备下一次。最后一页写道：「枪比剑诚实，它只问一件事——你敢不敢一直站在最前面。突阵谱的末尾附有一张手绘阵图，枪兵们排成三层梯队，作者用不同颜色标注了「死区」与「活区」。

## 设计意图

确立长枪「中距离压制、冲锋突破」的核心定位，为前排战士提供稳定可靠的突阵技能入口。
