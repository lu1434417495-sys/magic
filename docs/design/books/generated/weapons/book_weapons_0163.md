# 《双持节奏：两手各唱一首歌》

## 基础信息

- **书籍 ID**：`book_weapons_0163`
- **关联技能**：`rogue_dual_wield`, `warrior_twin_blades`
- **使用效果**：阅读后解锁 `rogue_dual_wield`；若已学会，提升该技能 `current_mastery +140`，并令双持攻击的连击计数上限 `+1`。
- **阅读要求**：角色职业标签含 `rogue`、`ranger` 或 `berserker`；基础 `敏捷 ≥ 12`。
- **稀有度**：稀有（Rare）
- **建议投放**：影刃教派藏室、双刀流浪者行李、竞技场连击任务。

## 书籍内容

双持不是两只手各挥一次，而是让两只手轮流承担攻击与防御的角色。作者把双持的节奏比作两首歌同时播放：主旋律由主手承担，副手则负责填补空隙与制造佯攻。书中详细讲解了三种基础节奏：快-快-慢、慢-快-快、以及不规则节奏，每一种都对应不同的敌人类型。作者强调，双持者最大的敌人不是对手，而是自己的急躁——两只手同时出击会让身体失去保护，必须学会让一只手等待。后半部分讨论武器配重：主手略重、副手略轻是最稳妥的配置，两把同重武器容易让肩膀疲劳。末页有一段被划掉的文字，隐约可见："当你忘了哪只手是主手，你就入门了。"作者建议初学者先用木筷练习节奏，直到双手能各自独立完成不同旋律再握真刀。 书后附有作者手绘的握腕与转肩示意图，提醒习练者注意刃筋与发力的配合。

## 设计意图

为敏捷型近战职业提供双持专精，通过节奏与连击机制区分于单手盾战与巨武器流派。
