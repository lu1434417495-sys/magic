# 《古代机关弩连发》

## 基础信息

- **书籍 ID**：`book_武器专精_0145`

## 书籍内容

古代机关弩是工程学与杀戮欲结合的巅峰。这本书详细介绍了失传的上弦机构：不是一根弦，而是三根弦轮流蓄力，通过齿轮联动实现连续击发。作者警告：这种武器需要定期上油，否则齿轮会在关键时刻卡死，比没有弩更危险。书中还讨论了弹药管理：机关弩的箭矢比普通弩箭短，携带更多但穿透力较弱，因此要选择敌人最脆弱的位置连续射击。最精彩的部分是"三连射节奏"：第一箭逼走位，第二箭封方向，第三箭才是真正的杀招。末页有一幅古代战场的浮雕拓片，无数短箭从一台机械中喷涌而出，配文："他们以为它只能射一次。"古代机关弩的图纸失落已久，这本书是目前最完整的抄本之一。机关师公会把它当作圣物，只允许核心成员在密室中抄录部分内容。核心成员抄录时只能带走片段，完整版本永不离开密室。

## 设计意图

作为传说级远程武器书，用三连射爆发奖励凸显古代机关弩的独特输出模式。
