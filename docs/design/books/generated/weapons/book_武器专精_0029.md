# 《双短剑风车斩》

## 基础信息

- **书籍 ID**：`book_武器专精_0029`
- **关联技能**：`weapon_dual_windmill`、`warrior_dual_wield_stance`
- **使用效果**：阅读后解锁 `weapon_dual_windmill`；若已学会，提升 `current_mastery +120`，并在下一次战斗中首次风车斩命中时恢复少量 `stamina`。
- **阅读要求**：已装备两把短剑或匕首；基础 `敏捷 ≥ 11`。
- **稀有度**：精良（Uncommon）
- **建议投放**：竞技场技巧奖励、武馆高级课程、盗贼公会训练场。

## 书籍内容

风车斩不是原地乱挥，而是让身体成为两把短剑旋转的轴心。作者把动作分解为「起转、展臂、收势」三段，强调核心力量比手臂速度更重要——如果腰腹不稳，旋转只会把自己甩出去。书中指出，风车斩最适合被包围或需要快速压制多个轻甲目标时使用，面对重甲敌人则效果有限。作者还提醒，旋转时视野会受限，因此必须在起转前记住敌人的大致位置，靠听觉与余光判断距离。后半本收录了数种变体：低位风车斩专攻下肢，高位风车斩逼迫敌人仰头防守，反向风车斩则用于在旋转中改变移动方向。最后一页画着一个被划掉的大圈，旁边写着：「转得漂亮不如转得有用。作者提醒，风车斩在狭窄巷道中会变成自杀动作，但他也承认，正是这个限制让掌握它的人显得更加可怕。风车斩的最高境界被称为「静风」，即旋转时剑刃不带风声，让敌人直到中剑才意识到攻击已经到来。

## 设计意图

为双持敏捷职业提供范围压制技能，强化被包围时的生存能力，同时保留对使用场景的限制。
