# 《法杖近身格挡术》

## 基础信息

- **书籍 ID**：`book_武器专精_0120`
- **关联技能**：`weapon_staff_parry`
- **使用效果**：阅读后解锁 `weapon_staff_parry`（待新增）；若已学会，提升 `current_mastery +120`，并提升下一次被近身攻击时的格挡成功率 5%。
- **阅读要求**：职业标签含 `mage` 或 `priest`；基础 `智力 ≥ 8`、体质 `≥ 6`。
- **稀有度**：精良（Uncommon）
- **建议投放**：古老图书馆密室、法师塔守卫遗物、护送任务奖励。

## 书籍内容

这本书是写给那些"法力还没回满就被冲到脸上"的法师的。法杖近身格挡不是把杖横在身前等敌人撞，而是用杖身制造一个斜面，把来袭力量的方向偏转。作者强调：格挡时眼睛要盯着敌人的肩膀而不是武器，因为肩膀会比刀剑先泄露意图。书中还讨论了法杖两端的使用：握住杖尾三分之一处时，杖头可以作为短棍反击；握住杖中时，法杖更像一面窄盾。最实用的建议是在法杖上刻几道浅痕作为握位标记，避免紧急时握错位置。最后一页是一张被折断的法杖照片，下面写着："这根杖替我挡过一剑，然后我用断口刺穿了那个人的喉咙。"法杖格挡术常与灰烬翻滚互补：格挡失败时立刻翻滚脱离，而不是硬撑。一位大法师在书边批注：活着的法师才有MP，死去的法师只有传记。这种互补理念被写进法师生存手册的第一章，代代相传。

## 设计意图

提升法师生存能力，把法杖从纯施法工具扩展为应急防御武器。
