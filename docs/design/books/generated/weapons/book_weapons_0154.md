# 《飞刀轨迹十二则》

## 基础信息

- **书籍 ID**：`book_weapons_0154`
- **关联技能**：`rogue_thrown_dagger`, `rogue_fan_of_blades`
- **使用效果**：阅读后解锁 `rogue_thrown_dagger`；若已学会，提升该技能 `current_mastery +90`，并补充 `3` 柄普通飞刀至背包。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `敏捷 ≥ 11`。
- **稀有度**：精良（Uncommon）
- **建议投放**：盗贼公会暗室、黑市飞刀商人、暗杀目标书房。

## 书籍内容

这本薄册子只有十二页，每页对应一种投掷轨迹。作者没有写名字，只在最后一页画了一只缺指的手。书中指出，飞刀不是暗器，而是"被抛出去的刺击"，因此握法、腕力与出刀角度必须和近战匕首保持一致。第一则讲直线直射，用于打断施法；第二则讲上旋抛射，用于越过低矮掩体；第三则讲反弹投掷，利用墙面改变角度。每一则都配有一张墨迹未干的草图。作者特别提醒：飞刀最危险的时刻不是出手，而是敌人侧身闪避后你手中已无刀。册子末尾有一行潦草的字："留一把在左袖，这是规矩。"册子背面粘着一张泛黄的赌债单据，似乎是前任主人用飞刀赢来的，也可能是输掉的。每一则末尾都画着一个拇指印，仿佛前任主人曾用血或墨水确认过自己的掌握。 边角处写满刃口角度的批注，告诫读者出刃前务必确认手腕角度与回收路线。

## 设计意图

为盗贼系补充远程起手与打断手段，飞刀作为资源型消耗品强化潜行职业的预备策略。
