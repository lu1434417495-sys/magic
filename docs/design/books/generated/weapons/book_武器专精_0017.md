# 《反手匕首握法》

## 基础信息

- **书籍 ID**：`book_武器专精_0017`
- **关联技能**：`rogue_dagger_backhand`、`weapon_dagger_stance`
- **使用效果**：阅读后解锁 `rogue_dagger_backhand`；若已学会，提升 `current_mastery +90`。
- **阅读要求**：角色职业标签含 `rogue`、`assassin` 或 `duelist`；基础 `敏捷 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：盗贼公会入门教材、黑市地摊、新手刺客任务奖励。

## 书籍内容

正手握刀是切割世界，反手握刀是刺穿自己面前的障碍。作者用简洁的语言比较了两种握法的优劣：正手攻击距离远、变化多，但发力路径长，容易被格挡；反手攻击距离短、角度受限，却能贴着身体发力，在贴身混战中出其不意。书中最重要的练习是「贴墙刺」：练习者背靠墙壁，模拟被敌人逼近到无路可退时的反手突刺，要求肘部始终贴近肋骨，只用前臂和手腕完成刺击。作者还提醒，反手挥砍时刀尖朝向自己，一旦动作过大就会划伤手臂，因此必须严格控制挥动幅度。最后一页画着一只握紧匕首的手，掌心上写着：「反手不是炫技，是被逼到绝境时还能用的最后一条路。书中记载了一种古老的入门仪式：新手必须在黑暗中用反手匕首切下一根悬空的丝线，以此证明手腕能在极限空间里保持稳定。

## 设计意图

丰富匕首战斗的基础姿态选择，为近战敏捷职业提供贴身战斗的另一种技术路线。
