# 《巨剑惯性论：挥斩不止于手》

## 基础信息

- **书籍 ID**：`book_weapons_0151`
- **关联技能**：`warrior_greatsword_sweep`, `warrior_momentum_strike`
- **使用效果**：阅读后解锁 `warrior_greatsword_sweep`；若已学会，提升该技能 `current_mastery +110`，并在下一次战斗中令首次巨剑挥斩获得 `+8%` 范围伤害。
- **阅读要求**：角色职业标签含 `warrior` 或 `berserker`；基础 `力量 ≥ 12`。
- **稀有度**：精良（Uncommon）
- **建议投放**：重甲佣兵营地、古战场遗骸、武器商人高级货架。

## 书籍内容

这本书的扉页被一道旧剑痕贯穿，作者声称那是为了提醒读者：巨剑的力量不在手臂，而在惯性。书中用整整一章批评"举剑再劈"的新手动作，指出真正有效的巨剑斩击应当让剑自身的重量带动身体旋转。作者详细拆解了三种起势：高位落斩、低位横扫与转身反劈，每一种都配有重心移动的墨线图。后半部分讨论"斩后余势"——多数战士在命中后急于收剑，结果浪费了剑身继续前冲的势能。正确的做法是利用余势完成半步位移，把下一次斩击的准备时间压缩到最短。末页有一段被血染红的批注："握住巨剑的不是你，是你允许它下落的决心。"书中还提到，许多新手在挥空后会因惯性失去平衡，老练的巨剑手却能把这股力量转化成下一次旋转的起点。 书后附有作者手绘的握腕与转肩示意图，提醒习练者注意刃筋与发力的配合。

## 设计意图

把巨剑从笨重高伤武器重新定义为需要节奏管理的重型刃器，强化战士系"控势"而非"蛮力"的玩法深度。
