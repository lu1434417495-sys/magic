# 《冰晶短杖凝刺》

- **书籍 ID**：`book_武器专精_0132`
- **关联技能**：`weapon_ice_wand_spike`

## 书籍内容

冰晶短杖不是把冰发射出去，而是把空气中的水汽凝结成刺。这本书的第一章教读者如何感受湿度：在干燥的环境里，冰刺会又脆又短；在潮湿的地方，同样的魔力可以制造出三倍体积的寒冰。作者强调手势的收敛：火焰法杖需要张扬的弧线，冰晶短杖则需要像握针一样精准，任何多余的动作都会让冰刺在成形前碎裂。书中还讨论了瞄准：冰刺的飞行速度比火球慢，因此要提前判断敌人的移动方向，把冰刺放在敌人将要到达的位置。最后一页是一张被冻住的蜘蛛照片，八条腿都被冰刺钉在墙上，旁边写着："冷不是瞬间，是慢慢失去选择。"冰晶短杖在冥想者手中格外稳定，因为冥想训练出的专注力能让水汽凝结得更均匀。北方冰原的法师塔因此把这本书列为冥想进阶读物。法师塔的冥想导师会要求学生在凝结冰刺前先静坐一刻。

## 设计意图

强化冰法控制主题，减速效果奖励让玩家体会到冰系武器的战术价值。
