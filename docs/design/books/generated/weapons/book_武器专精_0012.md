# 《矛尖保持稳定法》

## 基础信息

- **书籍 ID**：`book_武器专精_0012`
- **关联技能**：`weapon_spear_stability`、`warrior_spear_charge`
- **使用效果**：阅读后解锁 `weapon_spear_stability`；若已学会，提升 `current_mastery +100`，并略微减少突刺被格挡时的后仰惩罚。
- **阅读要求**：已装备长柄武器；基础 `感知 ≥ 9`。
- **稀有度**：精良（Uncommon）
- **建议投放**：枪兵训练场、边境哨塔藏书、军械库密室。

## 书籍内容

矛尖的颤抖会泄露你的一切。作者认为，长柄武器的精髓在于「把尖端变成一只不动的眼睛」，无论你的身体如何移动，枪尖指向的威胁区域必须保持稳定。书中介绍了三种稳定训练：单手持杆悬停、移动中保持尖端对准固定点、以及在受到侧向力时用手腕而非手臂修正。作者特别强调呼吸节奏对稳定的影响，指出大多数人在出枪前会下意识屏息，导致肩膀僵硬、枪尖下坠。正确的做法是在呼气结束时出枪，让上半身处于自然放松的最低点。后半本还讨论了不同枪头配重对稳定性的影响，并给出一张根据臂长选择枪杆长度的对照表。最后一页只有一句话：「敌人不怕你刺得快，怕你刺出去之后不晃。作者自称曾在一艘摇晃的渔船上练习三年，最终做到无论船身如何颠簸，矛尖始终对准桅杆顶端的一只海鸥。

## 设计意图

为长枪战斗增加精细操作维度，把「稳定性」从隐性手感提升为可训练、可成长的战斗属性。
