# 《标枪投掷：把距离变成伤口》

## 基础信息

- **书籍 ID**：`book_weapons_0166`
- **关联技能**：`warrior_javelin_throw`, `warrior_skirmisher`
- **使用效果**：阅读后解锁 `warrior_javelin_throw`；若已学会，提升该技能 `current_mastery +100`，并补充 `2` 根标枪至背包。
- **阅读要求**：角色职业标签含 `warrior`、`ranger` 或 `spearman`；基础 `力量 ≥ 10`、基础 `敏捷 ≥ 9`。
- **稀有度**：普通（Common）
- **建议投放**：轻步兵营地、游牧民交易点、边境巡逻任务。

## 书籍内容

标枪是步兵与骑兵之间最古老的距离博弈工具。作者把标枪投掷分为"定点投"与"移动投"两种：前者强调站姿稳定与全身发力，后者则依赖助跑时的节奏与出手时机。书中详细讲解了持枪角度、助跑步数与出手高度对飞行轨迹的影响，并附有一张不同距离对应的瞄准点参考图。后半部分讨论标枪作为近战武器的用法：在敌人近身后，标枪可以反过来当作短矛使用，枪尾也能用于格挡与推搡。作者提醒读者，标枪最大的价值不是每一投都命中，而是让敌人在冲过来时不得不考虑自己会不会在半路上被扎穿。书中还讲到如何在奔跑中投掷，作者认为真正的标枪手在投出前就已经在规划撤退路线。书中记载，最好的标枪手能在助跑三步内完成取枪、瞄准与出手，不留多余动作。 末页补了几种枪头保养与枪杆直度检查的方法，强调刺击准度来自日常维护。

## 设计意图

为战士与游侠系提供中距离投掷选项，强调资源管理与远近切换的战术灵活性。
