# 《兵器谱残卷：凶器篇》

## 基础信息

- **书籍 ID**：`book_武器专精_0041`
- **关联技能**：`weapon_infamous_weapons`、`known_knowledge_ids: cursed_arms`
- **使用效果**：阅读后解锁知识 `known_knowledge_ids: cursed_arms`，并提高所有武器技能对人类的伤害 `+5%`（一次性永久增益，可被后续净化任务移除）。
- **阅读要求**：角色职业标签不含 `holy`；基础 `意志 ≥ 10`。
- **稀有度**：史诗（Epic）
- **建议投放**：黑市拍卖行、邪教据点密室、王室密库禁书区。

## 书籍内容

凶器篇从不记录锻造者的名字，只记录每一把武器带走的最后一个生命。作者以冷峻的笔触描述了九把被诅咒的兵器：一把会越砍越轻的斧头，据说是由死者的骨头减轻了重量；一枚戒指上的细剑，能让使用者出其不意地刺杀，却会在七年后反噬主人；一柄从不锈蚀的匕首，刀刃上永远残留着上一个受害者的体温。书中反复强调，凶器本身没有善恶，但它们会放大持器者内心已有的黑暗。最令人不安的章节是「选择」，作者记录了几位曾经拥有凶器的人如何在权力与良知之间撕裂。最后一页被烧焦大半，只剩一句话：「读到这里的人，你已经在找理由拿起它们了。有读者在页边用更细的笔迹补充了第十把凶器，但那个名字被后来的某只手用浓墨彻底涂黑，仿佛从未存在。有图书馆员在书脊上贴了三道封条，每一道都被神秘力量自行烧毁，仿佛书中的武器不愿被禁锢。

## 设计意图

作为高稀有度收集书籍，提供显著但带有道德代价的增益，服务于黑暗向Build与世界观叙事。
