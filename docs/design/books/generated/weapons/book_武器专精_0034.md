# 《投矛猎杀术》

## 基础信息

- **书籍 ID**：`book_武器专精_0034`
- **关联技能**：`weapon_javelin_hunt`、`ranged_javelin_throw`
- **使用效果**：阅读后解锁 `weapon_javelin_hunt`；若已学会，提升 `current_mastery +120`，并在对野兽或大型敌人时提高 `+10%` 伤害加成。
- **阅读要求**：已装备投矛；基础 `力量 ≥ 9`、`感知 ≥ 8`。
- **稀有度**：稀有（Rare）
- **建议投放**：猎人导师委托、蛮荒部落训练场、巨兽狩猎任务奖励。

## 书籍内容

投矛是连接人类与野兽之间最古老的距离。作者把投矛分为「追猎投」与「伏击投」两种：追猎投要求猎人在移动中出手，依靠臂力与腰力把矛送向奔跑的目标；伏击投则强调静止中的精准，通常配合地形埋伏使用。书中最重要的技巧是「让矛自己飞」——不要用手腕强行控制方向，而要让矛身的重量与前冲惯性决定轨迹，手只负责在正确的时间松开。作者还讨论了矛尾平衡的重要性：尾羽或配重不当会让矛在空中翻滚，损失穿透力与精度。后半本收录了针对不同体型野兽的瞄准点：四肢关节限制移动，腰腹造成持续出血，咽喉与眼睛则是终结一击。最后一页画着一只被投矛贯穿咽喉的巨兽剪影，配文：「矛出手后，猎人与猎物的身份就已经交换。书中夹着一根断裂的矛头，锈迹斑斑，旁边写着「第一头巨兽」，矛头弯曲的角度显示那次命中来自正面三十步的距离。

## 设计意图

为游侠与猎人风格职业提供中距离重投掷技能，强化对大型目标的猎杀主题。
