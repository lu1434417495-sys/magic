# 《袖剑机关：藏在袖子里的杀意》

## 基础信息

- **书籍 ID**：`book_weapons_0197`
- **关联技能**：`assassin_hidden_blade`, `rogue_sleeve_dagger`
- **使用效果**：阅读后解锁 `assassin_hidden_blade`；若已学会，提升该技能 `current_mastery +120`，并令从潜行状态发动的袖剑攻击暴击率提升 `20%`。
- **阅读要求**：角色职业标签含 `assassin` 或 `rogue`；基础 `敏捷 ≥ 13`、基础 `智力 ≥ 9`。
- **稀有度**：史诗（Epic）
- **建议投放**：刺客兄弟会密室、王室密探藏身处、暗杀大师传承任务。

## 书籍内容

袖剑的美妙之处在于它藏在最显眼的地方：衣袖之中。作者用大量篇幅讲解机关保养：弹簧力度、卡榫磨损、刀刃长度与出手角度，任何一个小问题都会让暗杀变成公开的搏斗。书中详细记录了三种常见袖剑型号：直弹式、侧滑式与双发式，每一种都对应不同的使用场景与伪装需求。后半部分讨论心理：袖剑使用者必须训练自己在最紧张的时刻保持手臂放松，因为肌肉僵硬会改变机关的触发时机。作者提醒读者，袖剑不是正面武器，它的价值在于敌人看到你微笑时，不会想到死亡已经从袖口滑出。作者提醒，袖剑弹簧必须每七天上油一次，因为关键时刻卡住的机关等于自杀。作者还提到，最优秀的刺客会在袖剑触发前先用眼神或微笑分散目标的注意。

## 设计意图

为刺客系提供高爆发潜行终结技，强调机关知识与时机把握，服务于隐秘刺杀幻想。
