# 《双持武器协调法》

## 基础信息

- **书籍 ID**：`book_武器专精_0026`
- **关联技能**：`warrior_dual_wield_stance`、`weapon_dual_stance`
- **使用效果**：阅读后解锁 `warrior_dual_wield_stance`；若已学会，提升 `current_mastery +100`，并减少双持时副手命中率惩罚 `3%`（一次性永久增益）。
- **阅读要求**：已装备两把单手武器；基础 `敏捷 ≥ 10`。
- **稀有度**：精良（Uncommon）
- **建议投放**：佣兵营地、武馆高级课程、狂战士训练场。

## 书籍内容

双持最大的敌人不是敌人，而是你另一只手。作者指出，人类本能地会让较强的一只手主导动作，导致另一只手沦为陪衬；真正协调的双持要求两只手各自独立又互相配合。书中介绍了一种基础练习：让一只手画圆，另一只手画方，直到两者能在不互相干扰的情况下同时进行。应用到战斗中，主手负责主要威胁，副手负责掩护、变招与追击。作者还强调，双持武器的站姿要略宽于正持，重心降低，以便在一只手挥空时另一只手能迅速补位。后半本比较了「同类型双持」与「异类型双持」的优劣：同类型容易形成连击，异类型则更难被预测。最后一页写着：「两只手各做一件事不难，难的是让它们看起来像一个人在战斗。作者建议初学者先用两只不同重量的木勺练习，直到能一只手搅粥、一只手敲蛋而不洒出任何东西。

## 设计意图

为双持战斗建立基础协调机制，降低副手惩罚，鼓励玩家尝试多样化武器组合。
