# 《瞄准中的风息》

## 基础信息

- **书籍 ID**：`book_武器专精_0082`
- **关联技能**：`archer_aimed_shot`
- **使用效果**：阅读后解锁 `archer_aimed_shot`；若已学会，提升该技能 `current_mastery +120`，并在下一次战斗中为射手提供首次射击 `+5%` 伤害加成。

- **建议投放**：风息哨塔藏书、弓手训练场、游侠委托奖励。

## 书籍内容

《瞄准中的风息》不是一本教你拉弓的书，而是一本教你等待的书。作者用前半本篇幅描述风：如何在箭羽上感受它的方向，如何判断它会在箭杆中段变强还是变弱，如何在拉满弓的十秒钟里重新校准三次呼吸。书中最著名的章节是静止的移动，它要求射手在扣弦时想象自己正在随风移动，而目标才是静止的那个点。这个反直觉的意象让许多新手射偏，却让老手在远距离上获得惊人的稳定。后半本收录了二十七种目标的弱点节奏：心脏不是总在同一个位置跳动，盔甲接缝会因为呼吸而轻微开合。末尾有一页被反复翻阅到起毛，上面只有一句话：弓弦松开前的最后一秒，你不是在瞄准，你是在和空气谈判。

书末附有一张被雨水打湿过的靶纸，靶心旁有一行颤抖的字：我在这里等了一整天，只为风停的那三秒。那三秒，我射出了这辈子最干净的一箭。字的墨迹被雨水晕开，像风本身。

## 设计意图

强化弓箭手精准远程收割的职业画像，首次射击加成让书籍奖励轻量可感知。
