# 《弯刀旋斩：沙暴》

## 基础信息

- **书籍 ID**：`book_武器专精_0128`
- **关联技能**：`weapon_scimitar_spin`

## 书籍内容

弯刀的弧线是为了在马上砍人，也是为了在人群中跳舞。《沙暴》把旋斩比喻成沙漠中的风：不是一股直吹过去，而是绕着目标打转，每一刀都借上一刀的余势。书中最重要的训练是"单脚旋"：以一只脚为轴，另一只脚画圆，同时让刀刃始终保持在腰部高度。这个练习极其容易头晕，作者建议在练习前先吃少量食物，"空腹旋斩会在战场上变成呕吐"。书中还提醒：弯刀旋斩结束后会有一段时间背对敌人，因此最后一刀必须落在能让你顺势脱离的位置。末页有一幅沙地图，上面用弯刀划痕标出了七条撤退路线。沙漠商队把弯刀旋斩称为沙暴舞，既是一种武技，也是一种驱邪仪式。他们在穿越沙暴前会演练，相信旋转能模仿风的轨迹以求庇佑。沙暴舞不仅是战斗技巧，也成为商队穿越荒漠时的精神支柱。

## 设计意图

为弯刀构建 AOE/机动的战斗风格，多目标伤害加成鼓励玩家冲入敌群。
