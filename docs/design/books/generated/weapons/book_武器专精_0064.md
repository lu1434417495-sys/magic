# 《枪盾共进：步步为营》

## 基础信息

- **书籍 ID**：`book_武器专精_0064`
- **关联技能**：`warrior_spear_shield_advance`
- **使用效果**：阅读后解锁 `warrior_spear_shield_advance`；若已学会，提升该技能 `current_mastery +120`。
- **阅读要求**：已装备长柄武器与盾牌；基础 `体质 ≥ 9`。
- **稀有度**：精良（Uncommon）
- **建议投放**：重装步兵营、要塞军械库、盾卫传承任务。

## 书籍内容

枪盾共进不是一个人端着两样武器往前冲，而是让盾牌成为枪的支点，让枪成为盾牌的延伸。书中第一章讲步伐：前进时盾牌先行半步，枪尖紧随其后，每一步都要让盾牌的边缘与枪身形成稳定的三角。第二章讲呼吸：举盾吸气，推枪呼气，这样力量才能从脚下经过躯干传到枪尖。作者特别强调，枪盾兵最忌讳贪功冒进，因为一旦枪刺出太远，盾牌就无法保护自己。后半本收录了多种阵型变换：从一字横队收拢为枪林，再散开为侧翼包抄。每一页都有墨迹画出的脚印，显示每一步该落在哪。末页写着：盾是你的门，枪是你的问候，不要同时把它们都送出去。

书中夹着一张褪色的阵图，显示了枪盾兵从一字横队变为菱形突阵的十二步脚印。每一步旁边都写着同两个字：稳住。作者说，这十二步练三年，战场上只能走十二次，每次都要赢。

## 设计意图

为前排重装职业提供稳定的推进技能，把防御与进攻整合为同步节奏。
