# 《拔刀一瞬：居合的呼吸与停顿》

## 基础信息

- **书籍 ID**：`book_weapons_0164`
- **关联技能**：`samurai_quick_draw`, `warrior_iai_strike`
- **使用效果**：阅读后解锁 `samurai_quick_draw`；若已学会，提升该技能 `current_mastery +150`，并在下一次战斗中令首次拔刀斩暴击率提升 `15%`。
- **阅读要求**：角色职业标签含 `samurai`、`warrior` 或 `duelist`；基础 `敏捷 ≥ 13`、基础 `意志 ≥ 10`。
- **稀有度**：史诗（Epic）
- **建议投放**：远东流亡武士遗物、神社密室、剑豪传承任务。

## 书籍内容

居合不是拔刀快，而是拔刀前的那口气已经决定了一切。作者用前半本书讲解"纳刀"——如何把身体调整到能在最短时间内完成拔刀、踏步、收刀三个动作。书中强调，居合使用者必须在刀仍未出鞘时就已经看清敌人的重心与破绽。中段收录了七种常见起手势的应对，包括对方先动、后撤、佯攻与僵持。作者特别花一章讲呼吸：吸气时蓄力，呼气时拔刀，收刀时屏息，这套节奏必须在日常生活中反复练习才能内化成本能。后半部分警告读者，居合最大的诱惑是追求一击必杀，但真正安全的居合是在命中后仍能从容收刀的居合。书中最后几页被烧毁大半，只剩反复写着的"无念"二字，墨迹深得像要穿透纸背。居合不是最快的刀，而是在最安静的呼吸中完成的最决定性的一刀。 书后附有作者手绘的握腕与转肩示意图，提醒习练者注意刃筋与发力的配合。

## 设计意图

为高门槛敏捷剑士职业提供爆发型起手技能，强调预判、呼吸与一次性高回报。
