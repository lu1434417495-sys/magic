# 《战锤崩山：从上而下的诚实》

## 基础信息

- **书籍 ID**：`book_weapons_0167`
- **关联技能**：`warrior_war_hammer_slam`, `warrior_overhead_crush`
- **使用效果**：阅读后解锁 `warrior_war_hammer_slam`；若已学会，提升该技能 `current_mastery +120`，并令下一次崩山击对护盾造成双倍伤害。
- **阅读要求**：角色职业标签含 `warrior` 或 `berserker`；基础 `力量 ≥ 13`。
- **稀有度**：稀有（Rare）
- **建议投放**：矮人锻造所、矿坑深处宝箱、巨人杀手任务奖励。

## 书籍内容

战锤没有剑的华丽，也没有矛的灵巧，它只有一种诚实的攻击方式：从高处落下，砸穿一切挡路的东西。作者认为战锤使用者必须学会"举高"——不是用肩膀举，而是用整个后背与双腿把锤顶到最高，然后在下落时让身体跟着锤走。书中详细讲解了三种崩山路线：正顶、斜劈与转身下砸，每一种都对应不同的敌人姿态。后半部分讨论护盾破坏：战锤的钝面冲击会把护盾的冲击力传导到持盾者的手臂与肩膀，连续命中同一面盾会让敌人逐渐无法维持格挡姿势。末页有一段用炭笔写的批注："剑骗不过山，锤不用骗。"作者记录了一位矮人将军的话："战锤的诚实在于它从不说谎，落下的重量就是落下的重量。"作者建议练习者先对着树桩挥锤一千次，直到手臂能自动找到最省力的落点。

## 设计意图

为纯力量战士提供破盾与高打击感的终结技，强化"正面碾压"的职业幻想。
