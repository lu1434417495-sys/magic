# 《长枪拒马：稳住，然后刺穿》

## 基础信息

- **书籍 ID**：`book_weapons_0184`
- **关联技能**：`spearman_pike_brace`, `warrior_anti_charge`
- **使用效果**：阅读后解锁 `spearman_pike_brace`；若已学会，提升该技能 `current_mastery +100`，并令架枪状态下对冲锋敌人伤害提升 `20%`。
- **阅读要求**：角色职业标签含 `spearman`、`warrior` 或 `soldier`；基础 `力量 ≥ 10`、基础 `体质 ≥ 9`。

- **建议投放**：边境要塞枪阵营、军团长枪教官、山道隘口据点。

## 书籍内容

长枪拒马是战场上最古老的反冲锋手段之一：把枪尾抵住地面，枪尖对准敌人冲来的方向，然后稳住身体等待撞击。作者用大量篇幅讲解站姿：双脚必须前后开立，后膝微屈，重心压低，枪身夹在腋下而不是用手臂硬撑。书中强调，拒马成功的关键不是刺得准，而是站得稳——骑兵的冲击会把没站稳的枪兵直接撞飞。后半部分讨论阵型配合：单根长枪很容易被马匹撞偏，但十根长枪交错形成的枪林会让任何冲锋付出惨重代价。作者提醒读者，架枪时不要盯着马头看，要盯着骑手胸口，那是枪尖该去的地方。书中附有一份阵亡名单，作者用星号标出了所有因脚步不稳而被马撞飞的枪兵名字。书中最后写道，拒马成功的秘密不在枪尖，而在持枪者脚下那片踩实的土地。 末页补了几种枪头保养与枪杆直度检查的方法，强调刺击准度来自日常维护。

## 设计意图

为长枪兵提供反冲锋专精，强化阵地战与团队防御中的长柄武器价值。
