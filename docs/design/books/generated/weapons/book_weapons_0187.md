# 《穿甲剑：专为一击而窄》

## 基础信息

- **书籍 ID**：`book_weapons_0187`
- **关联技能**：`duelist_estoc_thrust`, `warrior_armor_pierce`
- **使用效果**：阅读后解锁 `duelist_estoc_thrust`；若已学会，提升该技能 `current_mastery +130`，并令对重甲敌人的穿透伤害提升 `10%`。
- **阅读要求**：角色职业标签含 `duelist`、`warrior` 或 `rogue`；基础 `敏捷 ≥ 12`。
- **稀有度**：稀有（Rare）
- **建议投放**：旧帝国贵族藏室、决斗馆密室、盔甲收藏家宝库。

## 书籍内容

穿甲剑是细剑的极端版本，它的剑身窄到几乎像一根铁棍，但正是这种窄让它能挤进板甲的缝隙。作者认为，穿甲剑不是用于挥砍的武器，每一次出手都应该是直线刺击，目标明确且没有多余动作。书中详细讲解了人体在盔甲保护下的真正弱点：腋下、腹股沟、膝窝、颈侧与面甲视孔。后半部分讨论如何在敌人移动中寻找缝隙：盔甲的接缝只有在关节弯曲时才会张开，因此穿甲剑手必须学会预判敌人的步伐与姿态。作者提醒读者，穿甲剑的剑身脆弱，不能用于格挡，一旦刺偏就必须立刻撤离，等待下一次机会。作者提醒，穿甲剑的剑身极为脆弱，一旦误击硬甲便会弯曲，因此每一击都必须经过计算。作者附有一张甲胄匠人的秘密笔记，标注了七种常见板甲在动态中最易暴露的接缝。 书后附有作者手绘的握腕与转肩示意图，提醒习练者注意刃筋与发力的配合。

## 设计意图

为决斗者提供极端特化的反重甲选择，强调精准弱点打击与高风险一击。
