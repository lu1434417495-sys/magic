# 《轻剑突刺手札》

## 基础信息

- **书籍 ID**：`book_武器专精_0005`
- **关联技能**：`weapon_rapier_thrust`、`rogue_precise_stab`
- **使用效果**：阅读后随机解锁 `weapon_rapier_thrust` 或 `rogue_precise_stab` 中的一项；若均已学会，提升其中等级较低者 `current_mastery +130`。
- **阅读要求**：角色职业标签含 `rogue`、`warrior` 或 `duelist`；基础 `敏捷 ≥ 11`。

- **建议投放**：贵族决斗场、黑市商人、风息哨塔密室。

## 书籍内容

手札的作者是一位匿名决斗者，字里行间带着贵族沙龙里学来的刻薄。他把突刺定义为「最小的动作换取最大的威胁」，认为劈砍是农民才用的野蛮方式。书中最重要的概念是「藏尖」：剑尖不要一直指向敌人，而是要在移动中若隐若现，让对手无法判断你的真实攻击距离。作者还强调脚步远比手腕重要，真正决定突刺能否命中的是后脚蹬地的那一下，而不是手臂前伸。后半本记录了十二场著名决斗的复盘，每场都用一句话总结失败原因，例如「他以为第三下突刺会复制第二下」。最后一页只有一行被反复加深的字：「刺中之后不要停，要继续压进去，直到你听见盔甲叹气。手札的夹页里藏着一张决斗挑战书，败者的名字被墨水涂去，只剩挑战日期和一行小字：「第三刺，他眨了眼。」手札的装订线用的是一根极细的发丝，据说来自一位死在决斗场上的女剑士，象征着突刺的轻盈与决绝。

## 设计意图

服务于高敏捷职业的精准刺杀风格，将轻剑从「快速攻击」提升为距离欺骗与时机控制的技艺。
