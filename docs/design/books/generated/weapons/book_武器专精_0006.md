# 《弯刀弧线论》

## 基础信息

- **书籍 ID**：`book_武器专精_0006`
- **关联技能**：`weapon_scimitar_arc`、`warrior_slash`
- **使用效果**：阅读后解锁 `weapon_scimitar_arc`；若已学会，提升 `current_mastery +110`，并略微提高该技能的暴击触发范围。

## 书籍内容

弯刀的弧线不是装饰，而是为了绕过盾牌。作者用草图展示了直刃与曲刃在接触目标时的受力差异：直刃倾向于弹开或卡住，而弯刀会顺着切割方向滑入，把一次挥砍变成一段持续深入的伤口。书中把弯刀技法概括为「引、转、拖」三步：引是让刀尖先接触敌人防御最薄弱的边缘；转是在接触瞬间转动手腕，让刀刃贴合目标轮廓；拖则是在回抽时继续施压，扩大切口。作者特别警告，弯刀不适合格挡硬劈，它的优势在于连续的小角度骚扰，逼迫敌人自己露出空当。最后一页是一幅沙海作战图，弯刀战士正从敌人侧面切入，配文：「别和直线比谁硬，要让直线追不上你。作者在沙漠商队中收集了十七种弯刀的弧度数据，发现最接近完美的弧线正好与某种毒蝎尾巴的弯曲度一致。沙漠里的老骑手会在弯刀上系一根彩色布条，不是为了装饰，而是为了在挥砍时观察弧线是否足够干净。

## 设计意图

丰富近战武器的攻击形态，用弯刀的弧线特性强化「侧翼切入、持续出血」的战斗节奏。
