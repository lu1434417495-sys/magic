# 《十字弩装填要诀》

## 基础信息

- **书籍 ID**：`book_武器专精_0032`
- **关联技能**：`weapon_crossbow_reload`、`ranged_crossbow_shot`
- **使用效果**：阅读后解锁 `weapon_crossbow_reload`；若已学会，提升 `current_mastery +90`，并减少下一次战斗中首次装填时间 1 回合。
- **阅读要求**：已装备十字弩；基础 `敏捷 ≥ 7`。
- **稀有度**：普通（Common）
- **建议投放**：猎人营地、边境哨塔、普通商人货架。

## 书籍内容

十字弩的威力来自机械，但它的弱点也来自机械。作者详细讲解了装填流程中的每一个细节：脚踏环的位置、拉绳的角度、扣机机构的状态检查。书中指出，装填失败最常见的原因不是力量不够，而是拉绳时身体没有保持直线，导致弦滑脱或弩臂受力不均。作者还建议在弩臂上挂一个小记号，提醒自己检查弦是否已经正确挂入扣机槽。后半本讲如何在战斗中安全装填：尽量选择有掩体的位置，利用队友制造的窗口，永远不要把背部完全暴露给敌人。书中还对比了手拉、腰带钩与脚踏三种装填方式的适用场景。最后一页是一句被反复描粗的忠告：「装填时你是全场最脆弱的人，别让敌人知道这一点。手册里夹着一根磨损的拉绳，作者说这是他从第一把弩上保留下来的纪念品，提醒他多少次装填失败差点要了他的命。

## 设计意图

为十字弩使用者提供操作细节与节奏管理知识，降低远程物理职业的入门门槛。
