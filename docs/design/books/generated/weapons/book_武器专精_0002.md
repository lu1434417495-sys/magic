# 《单手剑架势十二式》

## 基础信息

- **书籍 ID**：`book_武器专精_0002`
- **关联技能**：`weapon_one_hand_stance`、`warrior_sword_slash`
- **使用效果**：阅读后解锁 `weapon_one_hand_stance`；若已学会，提升 `current_mastery +100`，并在下一次战斗中减少首次架势切换的 `stamina` 消耗 2 点。
- **阅读要求**：已装备单手剑；基础 `力量 ≥ 7`、`敏捷 ≥ 7`。
- **稀有度**：普通（Common）
- **建议投放**：风息哨塔藏书、剑术导师委托、低阶副本宝箱。

## 书籍内容

十二式并非十二种华丽招式，而是十二种站法。作者把每种架势都比喻成一种野兽：鹤式重心高、移动快，适合试探与撤退；虎式压低重心、剑尖上扬，用于正面压制；蛇式则把剑藏在身侧，引诱敌人误判攻击距离。书中不厌其烦地强调，架势切换本身比任何一式都重要——真正的高手在敌人逼近前就已经完成两次转换，让对手始终猜不到下一剑从哪个角度出现。每一式后都附有一张被水渍晕染的小图，画中人持剑姿势僵硬却目光专注。末尾作者写道：「架势是骗敌人的第一道谎，也是保护自己的最后一层皮。不要迷恋好看的姿势，要迷恋让敌人露出破绽的角度。十二式中最后一式名为「无式」，要求练习者放下前面十一式的记忆，只凭本能站立。 书后附有作者手绘的握腕与转肩示意图，提醒习练者注意刃筋与发力的配合。

## 设计意图

将单手剑从单一输出技能扩展为需要架势管理的战斗风格，为后续剑技连招提供前置知识与节奏感。
