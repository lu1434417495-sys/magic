# 《钉头锤创伤学》

## 基础信息

- **书籍 ID**：`book_武器专精_0023`
- **关联技能**：`weapon_mace_trauma`、`warrior_mace_strike`
- **使用效果**：阅读后提升 `weapon_mace_trauma` 的 `current_mastery +100`（若未学会则解锁该技能），并提高对重甲敌人的伤害加成 `+5%`（一次性永久增益）。
- **阅读要求**：已装备钝器；基础 `力量 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：战场医疗队藏书、前线营地商人、佣兵营地宝箱。

## 书籍内容

这本书用军医的冷静视角分析钝器造成的伤害。作者指出，钉头锤不像刀剑那样造成开放性伤口，而是通过钝击在皮下制造深部淤血、骨折与内脏震荡。书中前半部分讲解不同锤头形状的效果：圆头造成均匀冲击，适合破甲；尖头集中压强，适合对付锁子甲；带棱锤头则能在命中时撕裂皮肉，兼具钝击与切割特性。后半部分从治疗反推战斗，告诉读者哪些部位被钝器击中后最难恢复：膝盖外侧、肘关节内侧、肋骨下缘，以及后脑。作者还提醒，钝器使用者要学会「追打」——在敌人受击恍惚的瞬间补上第二下，往往比第一下更致命。最后一页是一张人体经络图，几个穴位被圈出，旁边写着：「这些地方，连最好的医师都会皱眉。书中夹着一张军医的验伤记录，详细记载了一名重甲骑士被钉头锤击中胸口后，肋骨骨折如何向内刺穿肺脏的过程。

## 设计意图

为钝器提供真实感与战术深度，用医学视角强化「重甲克星」的定位。
