# 《战斧破甲笔记》

## 基础信息

- **书籍 ID**：`book_武器专精_0105`
- **关联技能**：`weapon_axe_armor_break`
- **使用效果**：阅读后解锁 `weapon_axe_armor_break`；若已学会，提升 `current_mastery +120`，下一次战斗中首次命中重甲敌人时附加 `破甲` 层数 1 层。
- **阅读要求**：职业标签含 `warrior`；基础 `力量 ≥ 9`。
- **稀有度**：普通（Common）
- **建议投放**：北境战斧营寨、强盗铁匠窝点、铁矿深处宝箱。

## 书籍内容

笔记开头是一张手绘的板甲剖面图，作者用不同颜色标出肩甲、胸甲、裙甲的薄弱处。它的核心观点很简单：斧不是剑，不要追缝隙，要追铆钉。斧刃的弧线决定了它最适合打在盔甲的连接处，而不是试图切开整块金属。书中详细记录了三种握斧高度：高握用于劈开头盔顶部，中握用于砍断肩带，低握用于扫断膝盖。每种高度都配有作者自己的失败案例和当天受的伤。中间有一段关于"斧卡住怎么办"的急救指南，提醒读者不要本能地拔斧，而是借着斧柄杠杆把敌人拉近或推开。笔记最后一页写："最好的破甲不是斧头多利，是打中敌人最不想被打中的地方。"断桥营寨的老兵常在斧柄上缠一圈灰烬交界的焦布，他们说那能提醒自己：破甲的意义不是炫耀力量，而是让身后的同袍少挨一刀。斧柄上的焦布后来被模仿，却很少有人记得最初的含义。

## 设计意图

让战斧在战士build中拥有明确的反重甲定位，提供可感知的一次性破甲奖励。
