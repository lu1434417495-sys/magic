# 《飞刀精准术》

## 基础信息

- **书籍 ID**：`book_武器专精_0018`
- **关联技能**：`rogue_throwing_knife`、`weapon_thrown_dagger`

- **阅读要求**：角色职业标签含 `rogue`、`assassin` 或 `ranger`；基础 `敏捷 ≥ 11`。

## 书籍内容

飞刀的难点不在于命中，而在于让敌人相信你不会扔。作者把飞刀技术分为「持、瞄、放」三步，强调「瞄」不是用眼睛对准，而是用身体记住距离。书中指出，大多数人投掷时肩膀僵硬，导致刀身翻滚不稳定；正确做法是在出手前放松肩袖，让手臂像鞭子一样甩出，只在最后一刻握紧刀柄。作者还讨论了刀身重量分布对飞行轨迹的影响：重心靠前的刀直飞稳定，适合远距离；重心靠后的刀翻滚多，适合中距离命中躯干。后半本收录了数种快速拔刀手法，以及如何在袖中、腰后、靴筒藏刀而不影响行动。最后一页只有一句话：「刀出手后，你的眼睛要看的不是刀，而是敌人的反应。作者收集了一整盒被飞刀钉穿的树叶，每片叶子上都用细针标注了投掷时的风速与距离，盒底写着「一千次中的九百次失败」。 边角处写满刃口角度的批注，告诫读者出刃前务必确认手腕角度与回收路线。

## 设计意图

为敏捷职业提供远程骚扰与收割手段，把飞刀设计成需要距离感与出手节奏的精准技能。
