# 《投斧连掷：把斧子变成雨》

## 基础信息

- **书籍 ID**：`book_weapons_0198`
- **关联技能**：`berserker_thrown_axe`, `warrior_axe_volley`
- **使用效果**：阅读后解锁 `berserker_thrown_axe`；若已学会，提升该技能 `current_mastery +100`，并补充 `3` 柄轻型战斧至背包。
- **阅读要求**：角色职业标签含 `berserker`、`warrior` 或 `ranger`；基础 `力量 ≥ 11`。
- **稀有度**：普通（Common）
- **建议投放**：北方部族营地、维京式船冢、佣兵营地训练场。

## 书籍内容

投斧是把近战武器临时变成远程武器的粗暴艺术。作者认为，投斧的关键不在旋转，而在出手时让斧身保持水平——这样斧刃才会在飞行中始终朝前。书中详细讲解了三种投掷方式：直飞用于近距离精准打击，旋飞用于中距离，以及抛高让斧子从上方落下的障眼法。后半部分讨论连续投掷：投斧使用者通常会在腰间或背后挂多柄斧头，连续投掷时必须在斧头出手的瞬间开始取下一柄。作者提醒读者，投斧最危险的时刻是敌人冲到你面前而你的斧子已经全部丢完，因此总要留一柄在手里。书中建议，投斧手应在腰间挂上不同重量的斧头，以便根据距离快速选择合适的一柄。书中建议练习者先学会用左手投斧，因为敌人往往会防备持斧的主手。

## 设计意图

为狂战士与战士系提供中距离投掷爆发，强调资源消耗与连续压制。
