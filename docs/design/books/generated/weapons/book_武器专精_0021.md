# 《战锤破盾论》

## 基础信息

- **书籍 ID**：`book_武器专精_0021`
- **关联技能**：`warrior_mace_shield_break`、`weapon_mace_strike`
- **使用效果**：阅读后获得 `warrior_mace_shield_break` 解锁机会；若已学会，提升 `current_mastery +110`。
- **阅读要求**：已装备锤或链枷；基础 `力量 ≥ 10`。
- **稀有度**：精良（Uncommon）
- **建议投放**：军械库、前线营地、矮人锻造工坊任务奖励。

## 书籍内容

盾牌是战士最忠实的朋友，而战锤是专门背叛这份友谊的武器。作者把破盾分为「震、裂、碎」三个阶段：第一下重击要让盾牌后面那只手发麻，第二下集中攻击盾牌边缘或握把附近的金属件，第三下则要趁着敌人手臂疲劳时全力砸向盾牌中心。书中强调，战锤不需要锋利，它的重量与速度会在接触瞬间把动能透过盾牌传递到手臂与肩膀。作者还提醒，破盾的关键不是打碎盾牌，而是让持盾者无法继续稳定举盾——很多时候一次精准的震击比十次盲目的重砸更有效。后半本用图解展示了不同盾型的弱点：圆盾怕上方砸击，塔盾怕下方撩击，筝盾怕斜向角力。最后一页写道：「听见盾后面那声闷哼，你就知道下一次该往哪打了。作者在某次战役后用缴获的敌方盾牌做了一整年的破甲实验，每面盾牌上都用锤头敲出的凹痕编号，从一到六十四。

## 设计意图

为钝器使用者提供明确的战术定位：针对持盾敌人的压制与破防，强化前排职业的对抗深度。
