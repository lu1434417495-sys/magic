# 《拳刃格斗：指尖上的钢铁》

## 基础信息

- **书籍 ID**：`book_weapons_0171`
- **关联技能**：`rogue_claw_gloves`, `monk_tiger_claw`
- **使用效果**：阅读后解锁 `rogue_claw_gloves`；若已学会，提升该技能 `current_mastery +100`，并令下一次战斗中前三次连击各附加 `3` 点流血。
- **阅读要求**：角色职业标签含 `rogue`、`monk` 或 `assassin`；基础 `敏捷 ≥ 12`。
- **稀有度**：精良（Uncommon）
- **建议投放**：影武者藏身处、武馆暗室、暗杀者导师奖励。

## 书籍内容

拳刃把武器缩短到手掌的延伸，因此它的攻击节奏比任何刀剑都快。作者强调，拳刃使用者必须放弃"挥砍"的概念，转而使用抓、撕、勾、刺四种动作。书中详细讲解了如何利用指关节与腕关节的灵活度，在极近距离内连续改变攻击角度。后半部分讨论防御：拳刃几乎没有格挡能力，因此必须依靠闪避、贴身缠绕与打断敌人发力的时机来生存。作者提醒读者，拳刃最危险的使用方式是与敌人保持一臂距离——那正是刀剑最强的距离；拳刃必须冲入半臂之内，让对手的长武器失去作用。作者强调，拳刃使用者必须学会用肘部和肩部格挡，因为双手已经被改造成攻击器官。书中还提到，拳刃最致命的攻击不是刺，而是抓住敌人后向内一拧的撕裂。

## 设计意图

为近身敏捷职业提供超近距离武器选择，强调贴身、连击与状态附加。
