# 《长剑架势：山不动》

## 基础信息

- **书籍 ID**：`book_武器专精_0055`
- **关联技能**：`warrior_blade_wall_stance`
- **使用效果**：阅读后解锁 `warrior_blade_wall_stance`；若已学会，提升该技能 `current_mastery +120`。
- **阅读要求**：已装备剑类武器；基础 `体质 ≥ 8`。
- **稀有度**：精良（Uncommon）
- **建议投放**：断桥营寨、剑士宗门、防守演练场。

## 书籍内容

这本书只有三章，却要求练习者先站够三十天。第一章讲脚：双脚不是平行站立，而是前脚内扣、后脚斜放，让膝盖在任何方向冲击下都能弯曲卸力。第二章讲剑：剑身不必高举，保持剑尖指向敌人咽喉，手肘贴近肋骨，这样格挡时只需要最小的移动就能覆盖正面。第三章讲眼：不要看敌人的武器，要看敌人的重心，武器只是重心的延伸。作者把这套架势命名为山不动，因为山从不主动迎击，却让每一股撞上来的力量自己消耗掉。书的最后几页是练习记录，某人在第三十天写道：今天终于没有被自己的紧张推倒了。

书末夹着一根干枯的稻草，据说是某位宗师站完三十天后从鞋底取出的。稻草已经压扁，但纤维方向整齐，像被山压过的麦浪。有人说这根稻草现在比铁还硬，只是没人敢试。

 书后附有作者手绘的握腕与转肩示意图，提醒习练者注意刃筋与发力的配合。

## 设计意图

为剑士构建稳定的前排防守架势，把格挡从被动反应转变为主动姿态经营。
