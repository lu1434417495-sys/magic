# 《杖尖点穴：精准钝击》

## 书籍内容

杖尖点穴要求练习者在高速运动中把棍梢准确地送到敌人身体的某个小点上。这本书前半本讲眼力：不是看整个人，而是看肩、胯、膝这三个枢纽，因为枢纽动，全身才动。作者要求练习者先用棍梢轻触悬挂的铜钱，必须让铜钱发出清脆的响声而不是被打飞。后半本讲解穴位与效果的对应：击中肘弯能让手臂酸软，击中膝窝能让下盘不稳，击中肋下则能让呼吸受阻。书中还提醒，点穴不是致命技，它的价值在于让敌人暂时失去完整战斗力。末页写着：杖尖是棍的眼睛，点中穴，就是看见了敌人的破绽。

作者在最后提醒，点穴不是为了杀死对方，所以点中之后要立刻后退，给对方留出认输或倒地的时间。否则点穴就变成了另一种杀招。武僧们把这点称为慈悲，尽管对手并不领情。

寺里的武僧们在旁批注：点穴之后，记得合掌。

## 设计意图

为长棍/杖类武器提供精准控制技，把钝器从横扫扩展为针对关节与穴位的战术打击。
