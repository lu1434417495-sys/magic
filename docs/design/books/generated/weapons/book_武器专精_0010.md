# 《短柄斧投掷术》

## 基础信息

- **书籍 ID**：`book_武器专精_0010`
- **关联技能**：`weapon_axe_throw`、`ranged_thrown_mastery`
- **使用效果**：阅读后解锁 `weapon_axe_throw`；若已学会，提升 `current_mastery +120`，并提高下一次战斗中首次投掷斧的命中加成 `+10%。
- **阅读要求**：基础 `敏捷 ≥ 10` 或 `感知 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：蛮荒部落训练场、游侠导师、竞技场投掷项目奖励。

## 书籍内容

投掷斧是一门关于「放手时机」的艺术。作者把飞斧分为三类：重斧用于近距离破盾，轻斧用于中距离骚扰，双刃斧则能在命中后造成二次切割。书中反复强调，投掷不是抛，而是「释放」——你不需要把斧头甩出去，只需要在正确的时间停止握住它。作者用整整一章讲解身体旋转与手腕放松的关系：肩膀先转，手肘跟随，最后才是手腕自然弹开；任何一步用力过猛都会让斧头翻滚过度。后半本收录了不同距离下的瞄准修正表，但作者在每项数字旁都画了一个问号，暗示真正的投掷靠眼睛而非表格。最后一页是一张被血浸透的草图，标注着人体最容易被飞斧命中的三个区域，配文：「斧头在空中旋转时，会替你数剩下的时间。书的扉页贴着一张褪色的竞技场门票，座位区画着一个红圈，据说是作者第一次用飞斧赢得自由的位置。

## 设计意图

为远程/混合职业提供中距离爆发手段，把投掷斧设计成需要练习与距离判断的精准技能。
