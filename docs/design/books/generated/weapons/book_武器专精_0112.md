# 《匕首握法与藏刃》

## 基础信息

- **书籍 ID**：`book_武器专精_0112`
- **关联技能**：`weapon_dagger_grip`
- **使用效果**：阅读后解锁 `weapon_dagger_grip`；若已学会，提升 `current_mastery +100`，并提升背刺判定角度 5 度（一次性战斗增益）。
- **阅读要求**：职业标签含 `rogue`；基础 `敏捷 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：盗贼公会入门试炼、黑市商人、城市下水道宝箱。

## 书籍内容

这本书很薄，每一页都被裁成适合塞进袖口的尺寸。作者从握法讲起：正握适合突刺和精准割喉，反握更适合格挡与近身控制，而大多数新手握得太用力，导致出刀前手腕已经僵硬。藏刃章节教你如何让匕首在手掌中消失：不是真的不见，而是让敌人的目光停留在你的身体动作上，而不是刀上。书中还讨论了衣服的影响：宽松袖口能隐藏刀身，却也会在出刀时勾住护手。最后几页是一系列错误示范图，每张图下都标注了"死了"或"被抓了"，而唯一一张标注"活了"的图显示的是一个根本没拔刀的人。盗贼公会的入门考试要求新人在众目睽睽下藏起一把匕首，并走到考官面前递一杯水。过关者才明白，藏刃的最高境界是让人忘记你有刃。考试时那杯水的温度，被传言是判断过关的隐藏标准。

## 设计意图

盗贼系基础武器书，扩大背刺判定让玩家更早体会到匕首的核心爽点。
