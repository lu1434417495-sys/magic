# 《猎龙枪：对巨兽的傲慢》

## 基础信息

- **书籍 ID**：`book_weapons_0196`
- **关联技能**：`spearman_dragon_lance`, `warrior_anti_monster`
- **使用效果**：阅读后解锁 `spearman_dragon_lance`；若已学会，提升该技能 `current_mastery +150`，并令对大型目标伤害提升 `12%`。
- **阅读要求**：角色职业标签含 `spearman`、`dragoon` 或 `warrior`；基础 `力量 ≥ 14`。
- **稀有度**：史诗（Epic）
- **建议投放**：屠龙者遗迹、龙骑士营地、巨兽猎人任务最终奖励。

## 书籍内容

猎龙枪是人类对巨兽最傲慢的发明：一根比普通长枪更粗、更长、更重的金属杆，前端装有专门撕裂鳞片的宽刃。作者认为，使用猎龙枪不能依赖技巧，而是要依赖勇气与站位——你必须站在巨兽冲锋的路径上，在最后一刻把枪尾抵住地面，让巨兽自己的重量把枪尖送进体内。书中详细讲解了三种刺击角度：腹部软鳞、翼根关节与喉咙下方，每一处都需要不同的架枪高度。后半部分讨论脱身：猎龙枪一旦刺入巨兽体内就很难拔出，因此使用者必须准备好弃枪翻滚，或者借助枪杆攀爬躲避巨爪。末页有一行烫金小字："对龙举起枪的人，首先要承认自己可能会死。"书末是一张残缺的手绘龙图，心脏位置被反复戳破，旁边写着"这里，只有这里"。

## 设计意图

为长枪战士提供反大型怪物专精，高风险高回报，强化对巨型敌人的英雄感。
