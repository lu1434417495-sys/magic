# 《棍棒缴械术》

## 基础信息

- **书籍 ID**：`book_武器专精_0025`
- **关联技能**：`weapon_club_disarm`、`warrior_disarm`
- **使用效果**：阅读后解锁 `weapon_club_disarm`；若已学会，提升 `current_mastery +120`，并提高缴械成功判定范围 `+8%。
- **阅读要求**：已装备棍棒或短杖；基础 `敏捷 ≥ 9`、`感知 ≥ 8`。
- **稀有度**：稀有（Rare）
- **建议投放**：武馆藏书、竞技场技巧奖励、游侠导师委托。

## 书籍内容

缴械不是打掉敌人的武器，而是让敌人自己松开手。作者把缴械分为「锁、旋、夺」三步：先用棍棒压住敌人手腕或武器根部，限制其发力；然后顺着敌人用力的方向旋转棍身，放大其武器的惯性；最后在对方手指因反作用力松开的瞬间夺下武器。书中强调，缴械最需要的是时机而非力量——在敌人攻击挥到最远处、旧力已尽新力未生时出手，成功率最高。作者还提醒，缴械后不要贪恋缴获的武器，因为真正的危险在于缴械失败后的空当。后半本收录了针对不同武器的缴械变体：对剑要压腕，对斧要避锋，对长柄要近身。最后一页画着一根看似普通的木棍，配文：「它不能杀人，但能让杀你的人暂时无害。据说这套缴械术最初是为了让治安官在不杀人的情况下解除醉汉的武器，因此书中反复强调「让对方活着松手」。

## 设计意图

为控制型近战职业提供非致命但极具战术价值的技能，丰富正面战斗中的互动选择。
