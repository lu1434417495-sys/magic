# 《锁镰距离：一寸绳一寸命》

## 基础信息

- **书籍 ID**：`book_weapons_0186`
- **关联技能**：`rogue_kusarigama`, `rogue_chain_sickle`
- **使用效果**：阅读后解锁 `rogue_kusarigama`；若已学会，提升该技能 `current_mastery +120`，并令锁链缠住敌人后下一次镰刀攻击无视 `10%` 护甲。
- **阅读要求**：角色职业标签含 `rogue`、`assassin` 或 `monk`；基础 `敏捷 ≥ 13`。
- **稀有度**：史诗（Epic）
- **建议投放**：东方刺客行会、忍者秘所、海盗王藏宝室。

## 书籍内容

锁镰把镰刀与铁链结合在一起，既能远距离缠住敌人，又能在拉近后完成致命收割。作者认为，锁镰的精髓在于"距离欺骗"：敌人以为你手中的武器只有镰刀那么长，直到锁链突然飞出缠住他的手腕或脚踝。书中详细讲解了三种链技：缠腕、绊腿与绕颈，每一种都需要在甩链时配合身体的旋转。后半部分讨论镰刀近身用法：一旦把敌人拉近，锁镰就变成了短兵器，必须立刻放弃链控思维，改用割、钩、刺结束战斗。作者警告读者，锁镰是所有武器中最容易自缚的，练习时必须先学会如何在被自己的链缠住时快速解脱。书末附有一张解脱术的图示，专门讲解被自己的锁链缠住时如何用最小动作脱身。锁镰手的训练从解开自己的链结开始，因为能救自己的人，才有资格用它束缚别人。 书后追加了一段软兵收纳与绳索缠绕的心得，强调出手速度始于整理方式。

## 设计意图

为刺客与忍者系提供中距离控制-近身爆发组合，强调距离欺骗与技能切换。
