# 《左右互搏入门》

## 基础信息

- **书籍 ID**：`book_武器专精_0027`
- **关联技能**：`weapon_dual_ambidexterity`、`warrior_dual_wield_stance`
- **使用效果**：阅读后解锁 `weapon_dual_ambidexterity`；若已学会，提升 `current_mastery +130`，并允许副手技能享受主手同等部分加成。
- **阅读要求**：已装备两把单手武器；基础 `敏捷 ≥ 12`、`智力 ≥ 9`。
- **稀有度**：稀有（Rare）
- **建议投放**：武馆秘传、稀有导师、精英武术任务奖励。

## 书籍内容

左右互搏被许多人误解为「两只手一样强」，作者却认为它的本质是「让大脑同时处理两条攻击线」。书中前半部分讲训练方法：从最基础的双手同时写字、同时画不同图形开始，逐步过渡到双手各持一柄训练木剑进行对练。作者强调，左右互搏不是让两只手互相竞争，而是让它们各自拥有完整的意图：左手知道自己在做什么，右手也知道，而大脑只是旁观与微调。后半部分讲战斗应用：左右互搏使用者可以在同一回合内发起两次独立威胁，迫使敌人同时防守两个方向。但这种能力需要极高的专注力，一旦心浮气躁，两只手会立刻变回两只普通的手。最后一页是一句来自古籍的摘录：「一心二用不是分裂，是合一的另一种形式。书中引用了一位武僧的笔记，他声称左右互搏的最高境界是「忘了哪只手是左，哪只手是右」。

## 设计意图

作为双持体系的高级进阶，提升副手地位，为高投入玩家提供明显的操作与Build回报。
