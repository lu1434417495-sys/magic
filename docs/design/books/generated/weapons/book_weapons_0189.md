# 《铁手套殴击：拳头上的盔甲》

## 基础信息

- **书籍 ID**：`book_weapons_0189`
- **关联技能**：`warrior_gauntlet_strike`, `monk_iron_fist`
- **使用效果**：阅读后解锁 `warrior_gauntlet_strike`；若已学会，提升该技能 `current_mastery +100`，并令徒手或铁手套攻击对轻甲敌人伤害提升 `10%`。
- **阅读要求**：角色职业标签含 `warrior`、`monk` 或 `berserker`；基础 `力量 ≥ 11`。
- **稀有度**：普通（Common）
- **建议投放**：铁匠铺柜台、武馆基础教材、酒馆斗殴冠军奖励。

## 书籍内容

铁手套把拳头变成了可以正面砸向盔甲的钝器。作者认为，戴铁手套战斗不能沿用空手格斗的思路，因为重量会改变出拳速度与收拳节奏。书中详细讲解了三种基本拳法：直拳冲击面甲、摆拳砸向太阳穴、以及上钩拳击打下颌与胸甲接缝。后半部分讨论防御：铁手套可以格挡轻武器，但不应该用来硬接斧头与战锤；最好的用法是在敌人挥砍落空的瞬间用铁手套架开或砸偏对方的武器。作者提醒读者，铁手套最大的危险是让人误以为自己真的无敌，从而忘记躲避本该躲避的重击。作者附有一张酒馆斗殴赔偿账单，暗示这本书的前任主人可能因一拳过重而倾家荡产。作者提醒，铁手套的重量会让出拳变慢，因此必须比徒手格斗更注重时机而非速度。 附有几幅呼吸节奏图，说明出招时腰腹收紧比四肢挥动更决定劲道。

## 设计意图

为徒手/近战职业提供简单直接的武装格斗选项，强化轻甲打击与近身控制。
