# 《暴风雨中生火十戒》

## 基础信息

- **书籍 ID**：`book_通用生存_0017`
- **关联技能**：`survival_fire_steel`
- **使用效果**：阅读后解锁 `survival_fire_steel`；若已学会，提升 `current_mastery +90`，并在雨天战斗开始时为全队附加“干燥引火”（首次火系伤害 +5%）。
- **阅读要求**：无职业限制；基础 `敏捷 ≥ 7`。
- **稀有度**：精良（Uncommon）
- **建议投放**：灯塔据点、暴风雨求生任务、海岸商人。

## 书籍内容

在暴风雨中生火，是人与自然的正面交锋。这本书由灯塔看守者的学徒整理，十条戒律从选址到燃料层层递进。第一戒：不要在洼地生火；第二戒：先搭建挡风的石墙或土墙；第三戒：保留一把干燥的引火物贴身存放。书中强调，湿木可以烧，但必须切成薄片挂在火边预先烘干。最实用的技巧是“倒置火堆”：把粗木放在底层，细枝与引火物放在顶层，让火焰向下燃烧，这样湿木会被上方的热量持续烘烤。作者还教了一种用动物脂肪与木炭制作的“火种膏”，能在雨中燃烧数十息。最后一戒写在羊皮纸背面：“如果火还是灭了，先保存体温，保存希望。” 羊皮纸边缘被盐渍浸成褐色，像是从海风中抢救回来的遗物。 火焰在风雨中跳舞时，人要学会低头保护它。

## 设计意图

把恶劣天气下的生火变成可学习的战斗准备技能，提供一次性的火系增益出口。
