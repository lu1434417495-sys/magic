# 《流沙脱困七步法》

## 基础信息

- **书籍 ID**：`book_通用生存_0007`
- **关联技能**：`survival_quicksand_escape`
- **使用效果**：阅读后解锁 `survival_quicksand_escape`；若已学会，提升 `current_mastery +75`，并降低下次陷入地形控制效果时 1 回合持续时间。
- **阅读要求**：无职业限制；基础 `力量 ≥ 7` 或 `敏捷 ≥ 7`。
- **稀有度**：普通（Common）
- **建议投放**：砂海商队驿站、废墟图书馆、沙漠求生支线。

## 书籍内容

流沙不是泥潭，而是被伪装成地面的水。这本薄薄的手册来自砂海商队，封面上有一行醒目的红字：“挣扎得越凶，沉得越快。”七步法的第一步是丢掉负重，尤其是盾牌与金属护腿；第二步是仰面平躺，增大浮力面积；第三步到第五步是缓慢的腿部摆动，像游泳一样让泥沙重新液化。书中反复强调，脱困的关键是“与时间做朋友”：每次移动不超过一寸，宁可多等一炷香。中段记录了一个失败案例：一名战士因舍不得祖传护甲，最终被吞没到胸口，同伴只能割断他的绑带。最后一页只有一句话：“能再穿的装备才配叫装备。” 手册的最后一页被砂粒填满，翻开时会发出轻微的沙沙声，像在提醒读者。 砂海不会因为你的勇气而变硬。

## 设计意图

把流沙从即死地形改为可操作的逃脱小游戏，强化负重取舍决策。
