# 《骨白哨兵陷阱图鉴》

## 基础信息

- **书籍 ID**：`book_通用生存_0004`
- **关联技能**：`survival_trap_setting`
- **使用效果**：阅读后解锁 `survival_trap_setting`；若已学会，提升 `current_mastery +85`，并解锁陷阱图纸 `known_knowledge_id:trap_bone_sentry`。
- **阅读要求**：无职业限制；基础 `敏捷 ≥ 6`。
- **稀有度**：普通（Common）
- **建议投放**：骨白哨塔军械库、猎人公会、边境据点宝箱。

## 书籍内容

骨白哨兵是边境猎人最推崇的简易陷阱，既能捕获小型猎物，也能拖延追兵。图鉴用炭笔与兽血绘制，首页警告：所有陷阱在布置后的第一个黄昏最危险，因为你自己也会忘记它们的位置。书中依次拆解了套索、落石、尖桩与绊网的制作尺寸，并指出不同地面的伪装技巧。中段有一章专门讲“陷阱心理学”：猎物会绕开明显障碍，因此要把诱饵放在需要跨越障碍才能到达的地方。作者用红笔圈出了几种不该使用的场景：己方撤退路线、水源地下游、营地风口。最后一页画了一只被夹住后腿的骨鼠，旁边写着：“它教你的，比它肉的价值更高。” 图鉴的装订线里夹着一小段磨损的套索，似乎曾经真的困住过什么。 真正的好陷阱，布置者自己也要记住它在哪里。图鉴最后一页还有一句用血写就的警示：布置陷阱的人，第一个要学会避开它。

## 设计意图

提供猎人系与游击战的控场入口，把环境改造成可预习的战场。
