# 《伪装尸体与气味遮蔽》

## 基础信息

- **书籍 ID**：`book_通用生存_0035`
- **关联技能**：`survival_scent_mask`
- **使用效果**：阅读后解锁 `survival_scent_mask`；若已学会，提升 `current_mastery +100`，并在下次遭遇野兽敌人时降低其先手概率 10%（一次性）。
- **阅读要求**：角色职业标签含 `rogue` / `assassin`；基础 `敏捷 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：斥候遗物、暗杀任务密室、黑市商人。

## 书籍内容

在某些情况下，装死不是懦弱，而是最后一张牌。这本手册由一名从尸堆中爬出的斥候编写，教人如何在敌人扫荡时伪装成尸体。书中强调，成功的关键是“气味与姿态”：要让自己沾染周围的气味，并保持不自然的僵硬，因为真正的尸体不会摆出舒适的姿势。最实用的章节是“控制呼吸与心跳”：用极浅的呼吸配合缓慢的默数，降低被发现的几率。作者还警告，这种方法只对以视觉为主的敌人有效，对嗅觉灵敏的野兽则是自杀。书中夹有一片干枯的腐肉，用于让使用者提前适应气味。最后一页写着：“装死的人不是懦夫，他只是把活着这件事推迟了一会儿。” 斥候在末页夹着一小片腐肉干，警告初学者：气味比姿势更难伪装。

## 设计意图

为潜行职业提供遭遇前的先手控制权，强化斥候与刺客的生存戏剧感。
