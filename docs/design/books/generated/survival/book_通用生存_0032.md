# 《溺亡者归来：水中求生》

## 基础信息

- **书籍 ID**：`book_通用生存_0032`
- **关联技能**：`survival_drown_recovery`
- **使用效果**：阅读后解锁 `survival_drown_recovery`；若已学会，提升 `current_mastery +90`，并在下次水域战斗中溺水判定难度 -10。
- **阅读要求**：无职业限制；基础 `敏捷 ≥ 7`。
- **稀有度**：精良（Uncommon）
- **建议投放**：沉船海岸、水手公会、水域救援支线。

## 书籍内容

溺亡的人往往不是不会游泳，而是不会冷静。这本手册由一名从沉船中逃生的水手编写，开篇教人如何在落入激流后保持仰面漂浮，用最小的动作维持口鼻在水面之上。书中强调，衣物和靴子会吸水增重，但不要立刻脱除，因为它们能在最初提供一定的浮力。最实用的章节是“离岸流应对”：不要试图逆流而回，而是平行于海岸游动，脱离强流区域后再向岸前进。作者还提醒，冰冷的水会让人在几分钟内失去精细动作能力，因此入水前就要把鞋带、背包带整理好，避免被缠住。最后一页写着：“水是柔软的坟墓，但只要你还能呼吸，它就还不是你的。” 水手在最后一页画了一只仰面漂浮的小人，旁边写着：放松，水是床的另一种形式。手册在沉船海岸的水手公会里被翻得卷了边，每一页都沾着不同海域的盐渍。

## 设计意图

降低水域环境的即死风险，把溺水从失败判定改为技能判定。
