# 《潜行猎手的伪装衣》

## 基础信息

- **书籍 ID**：`book_通用生存_0013`
- **关联技能**：`survival_camouflage`
- **使用效果**：阅读后解锁 `survival_camouflage`；若已学会，提升 `current_mastery +100`，并在下一次战斗中首回合闪避率 +8%。
- **阅读要求**：角色职业标签含 `rogue` / `ranger` / `archer`；基础 `敏捷 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：潜行者据点、黑市商人、森林猎手任务。

## 书籍内容

最好的伪装不是颜色，是轮廓。这本手册由边境的独行猎手编写，教人用当地植物、泥土与灰烬制作临时伪装。书中强调，移动时人眼最容易捕捉的是直线与对称，因此要在肩部、头顶与四肢末端打破轮廓。最实用的章节是“分层伪装”：内层用吸汗的软布固定植物，外层用细绳让枝叶随动作自然晃动。作者还教了一种“气味消隐术”：用腐殖质与烟熏草摩擦衣物，可以掩盖人体气息，但代价是你会吸引食腐昆虫。书中夹有几片干枯的阔叶，叶脉被作者用针尖标注了最佳绑扎点。最后一页警告：伪装衣只在静止时有效，跑动时你只是一团会移动的灌木。 手册最后一页贴着一片干枯阔叶，叶背还留着当时绑扎的细绳痕迹。 最优秀的伪装，是让敌人忘记你的存在。

服务游侠与盗贼系，强化伏击与先手爆发的环境利用。
