# 《高空岩架攀爬》

## 书籍内容

垂直岩壁并非不可逾越，关键是找到正确的力学路径。这本书教读者如何利用岩缝、凸起和天然把手，以最小的体力攀爬高空岩架。作者强调，攀爬时不要依赖手臂拉力，而要依靠腿部蹬伸和身体的贴靠；手指的作用是固定方向，而不是承担全部体重。书中还讲如何使用绳索进行上方保护和下降，以及如何在没有岩钉时利用可塞入裂缝的木楔。进阶内容包括如何判断岩壁风化程度、如何处理松动的石块，以及落石时如何紧贴岩面保护头部。作者提醒，攀爬途中不要往下看，那是精神消耗而不是信息。最后写道：岩壁不怕你慢，它怕你手抖。
书末附有一张岩壁支点受力图，作者用红笔画出了最容易断裂的岩片位置。
作者用红笔在末页加了一句：手抖的时候，停下来，呼吸，再看一眼。
