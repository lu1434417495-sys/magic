# 《末日背包：最后十二件物品》

## 书籍内容

当世界只剩你一个人和一包东西时，选择比拥有更重要。这本书由一名穿越多个废墟的独行生存者编写，列出他宁愿丢下金币也要保留的十二件物品：锋利的刀、干燥的引火物、结实的绳索、净化水的药片、一顶防水斗篷、一卷绷带、一小瓶盐、针线、地图残片、哨子、耐磨的手套，以及一张家人的画像。书中没有讲具体用法，而是讲每件物品对应的一种能力：切割、生火、攀爬、净水、遮蔽、止血、调味、修补、导航、求救、劳作与希望。最珍贵的章节是“第十二件的重量”：作者认为那张画像不是负担，而是让你拒绝放弃的理由。书末附有一页空白，批注：“写下你自己的第十二件。” 独行生存者在空白页的角落画了一张小小的全家福，墨迹已被摩挲得模糊。
