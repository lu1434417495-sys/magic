# 《气味伪装与下风移动》

## 书籍内容

许多野兽的嗅觉远比视觉灵敏，想在它们附近活动，就必须学会管理自己的气味。这本书讲如何用泥土、灰烬、植物汁液和动物粪便来掩盖人体气味，并始终处于下风位置。作者提醒，完美的气味伪装不存在，目标是让气味变得模糊、多变、不像人类。书中详细介绍了不同环境下的伪装配方：森林里用腐殖质和松脂，草原上用干土和牛粪，灰烬边陲则用硫磺灰和烧焦的骨粉。进阶内容包括如何利用风向来接近猎物或避开掠食者，以及如何通过观察草木摆动判断风的瞬时变化。最后写道：在野兽的鼻子里，你不是一个名字，而是一团气味，别让它太好认。
附录中记录了数种野兽对不同气味的敏感距离，帮助读者判断伪装是否足够有效。最优秀的猎人会先花时间研究风，再花时间研究猎物，因为风决定他能不能靠近。

## 设计意图

深化猎人与潜行职业的接近能力，让风向和气味成为可控的战术变量。
