# 《断粮七日：荒野觅食录》

## 基础信息

- **书籍 ID**：`book_通用生存_0003`
- **关联技能**：`survival_foraging`
- **使用效果**：阅读后解锁 `survival_foraging`；若已学会，提升 `current_mastery +100`，且下次采集时必定发现一种额外可食用资源。
- **阅读要求**：无职业限制；基础 `感知 ≥ 6`。
- **稀有度**：稀有（Rare）
- **建议投放**：灰脊山脉游侠营地、商队任务奖励、野外采集导师。

## 书籍内容

断粮第七天，人才会真正理解“可食用”与“能救命”之间的鸿沟。作者以日记体记录了一次穿越灰脊山脉的经历：前三天靠昆虫与嫩芽维持，第五天开始尝试树皮内侧的甜浆。书中没有浪漫化的野果图鉴，只有一份“三日测试法”：新植物先碰皮肤，再舔嘴唇，最后含一小片，每次间隔一夜。最实用的章节是“地下根茎”：很多看似枯萎的藤蔓在地底藏有淀粉块，书中详细描述了挖掘角度与保存方式。作者也诚实写下了自己两次中毒的教训，警告读者不要因饥饿而加快测试。最后他写道：荒野从不会饿死有耐心的人，但会毒死贪婪的人。 作者在最后署名处画了一株嫩芽，旁边写着：饿不死的人，都是愿意等待的人。 那些把饥饿当成浪漫的人，往往会在第三天后沉默。

## 设计意图

将觅食从随机拾取升级为风险判断，控制探索收益与中毒惩罚的平衡。
