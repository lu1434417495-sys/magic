# 《绷带、血与石灰：战场包扎入门》

## 基础信息

- **书籍 ID**：`book_通用生存_0009`
- **关联技能**：`survival_wound_bind`
- **使用效果**：阅读后解锁 `survival_wound_bind`；若已学会，提升 `current_mastery +95`，并在阅读后立即恢复全队每人少量 `current_hp`。
- **阅读要求**：无职业限制；基础 `意志 ≥ 6`。
- **稀有度**：稀有（Rare）
- **建议投放**：断桥营寨军医帐篷、战场救护支线、老兵遗物。

## 书籍内容

战场上最珍贵的不是良药，而是知道什么时候该收紧绷带。这本书出自断桥营寨的老军医之手，开篇列出三种必须立即止血的伤口：喷血、冒泡的血、以及颜色发黑的血。作者详细讲解了压迫点、止血带与填充包扎的区别，并强调“不要试图把肠子塞回去，只要盖住它们”。书中有一章专门讲战场石灰：把煅烧石灰撒在伤口周围可以快速消毒，但绝不能撒进伤口内部。后半本记录了多种临时材料：干净的内衬、蛛网，甚至烫热的匕首用于烧灼止血。最后一页写着：“包扎不是治好他，是给他活到明天见医生的权利。” 老军医用红笔在扉页写：先止血，再讲道理。 在战场上，一根紧绷的绷带有时比一句祈祷更有用。 止血是算术，不是祈祷。老军医的帐篷里常年挂着一句话：救人的手要稳，心要冷，眼睛却要暖。

## 设计意图

作为前线续航的辅助入口，让非治疗职业也能承担轻伤自理。
