# 《虫群袭来的遮挡与撤离》

## 基础信息

- **书籍 ID**：`book_通用生存_0047`
- **关联技能**：`survival_swarm_escape`
- **使用效果**：阅读后解锁 `survival_swarm_escape`；若已学会，提升 `current_mastery +100`，并在虫群类敌人战斗中全队受到的首轮伤害减免 15%。
- **阅读要求**：无职业限制；基础 `敏捷 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：虫灾废墟、虫群撤离支线、幸存者商人。

## 书籍内容

单独的虫子不可怕，可怕的是它们同时决定攻击你。这本手册由虫灾幸存者编写，教人面对虫群时的求生策略。书中指出，多数虫群对震动、体味与光亮敏感，因此静止与遮蔽气味是第一步。最实用的章节是“应急斗篷”：用浸过泥水的厚布裹住头颈与双手，留出最小视野，可以大幅减少被叮咬的面积。作者还提醒，撤离时不要奔跑直线，要逆风、逆光源移动，并利用浓烟或火把制造隔离带。书中附有一张常见虫群行为表，标注了哪些虫群会追击、哪些只守卫领地。最后一页写着：“虫群不是军队，只是一阵风；风过去，你还站着，就赢了。” 幸存者在封底画了一只被厚布裹住的人形，批注：风会过去，布会留下。 虫群的风过去后，站着的人才能继续走路。

## 设计意图

为虫群遭遇战提供专项减伤，鼓励玩家针对敌人类型准备生存技能。
