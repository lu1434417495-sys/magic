# 《野蛮打击：本能之刃》

## 基础信息

- **书籍 ID**：`book_战士战技_0146`
- **关联技能**：`warrior_savage_blow`
- **使用效果**：阅读后解锁 `warrior_savage_blow`；若已学会，提升该技能 `current_mastery +100`。
- **阅读要求**：职业标签含 `warrior` 或 `berserker`；基础 `力量 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：蛮族营地、基础战技商人、低级敌人掉落。

## 书籍内容

野蛮打击不讲招式，只讲本能。作者认为，过于复杂的技巧在生死搏斗中往往来不及施展，反而是最原始的直接打击最有效。书中要求练习者放弃花哨的转身与虚招，专注于快速、直接、重复的斩击或砸击。作者提醒，野蛮打击需要极强的体能支撑，否则会在几轮后体力耗尽。作者还强调，野蛮打击的核心是“比敌人更快耗尽他的冷静”，通过连续不断的攻击让对手无法思考。书中建议练习者在固定节奏下连续击打木桩，直到手臂酸胀仍能保持速度。作者提醒，野蛮打击不适合对付训练有素的防御者，他们往往能用一次精准反击瓦解整套攻势。末尾画着一只挥斧的野兽图腾。

## 设计意图

用高频直接攻击压制敌人，为力量型战士提供低门槛输出循环。
