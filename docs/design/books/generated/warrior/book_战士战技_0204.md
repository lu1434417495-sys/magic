# 《灰烬血契：以血换火》

## 基础信息

- **书籍 ID**：`book_战士战技_0204`
- **关联技能**：`warrior_ashen_blood_pact`
- **使用效果**：阅读后解锁 `warrior_ashen_blood_pact`；若已学会，提升 `current_mastery +190`，并减少该技能首次使用的 `hp` 代价 5%（一次性战斗增益）。
- **阅读要求**：职业标签含 `warrior`；已掌握任意灰烬交界战技；基础 `体质 ≥ 14`。
- **稀有度**：传说（Legendary）
- **建议投放**：灰烬交界深层祭坛、余烬主教密室、传说战技宝箱。

## 书籍内容

这本典籍的纸页像被血与灰烬共同浸泡过，翻阅时会留下焦黑的指印，洗不掉。灰烬血契是一种古老的自残战法：战士在剑刃上划开掌心，让鲜血与灰烬领域的余火混合，换取短时间的毁灭性力量。书中反复强调三个禁忌——不能在雨中使用、不能在濒死时使用、不能在对同伴怀有愧疚时使用，因为灰烬会点燃意志中的裂缝。作者记录了自己十二次血契的经过，每次都在空白处画一只烧毁一半的手。最后一次记录只有一句话：“我终于听见火在教我唱歌。”后面附着半张烧焦的乐谱，无人能读。封底用灰烬写着第十四次的代价：他的左手。灰烬血契的代价从不重复，第二次失去的东西会比第一次更靠近心脏。血契的火焰会在使用者的血管里留下黑色纹路，那是无法洗去的烙印。黑色纹路在满月时会隐隐作痛，提醒使用者契约尚未结束。

## 设计意图

为灰烬交界高阶战士提供高风险高回报的爆发技能，强化世界观沉浸感。
