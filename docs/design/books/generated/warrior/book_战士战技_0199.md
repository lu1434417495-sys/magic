# 《天裂斩：劈开苍穹》

## 基础信息

- **书籍 ID**：`book_战士战技_0199`
- **关联技能**：`warrior_celestial_cleave`
- **使用效果**：阅读后解锁 `warrior_celestial_cleave`；若已学会，提升该技能 `current_mastery +160`。
- **阅读要求**：职业标签含 `warrior`；已学会 `warrior_true_dragon_slash` 或 `warrior_fissure_slash`。
- **稀有度**：史诗（Epic）
- **建议投放**：天空神殿、剑圣传承地、终极斩击试炼奖励。

## 书籍内容

《天裂斩》是一门传说中的终极斩击战技，据说修炼到极致可以劈开云层。作者认为，天裂斩不是单纯的力量释放，而是把战士毕生经验、意志和斗气凝聚于一剑。书中讲解了如何在平静中蓄力、在爆发时忘我、在斩出后保持残心。后半部分警告，天裂斩会消耗使用者几乎所有的体力，一击之后必须有人掩护或立刻脱离战场。作者还提醒，天裂斩的精髓不是斩得多高多远，而是在斩出那一刻没有一丝犹豫。书中建议在施展前凝视天空片刻，把意志提升到与剑刃同一高度，想象自己正在与天际线对齐。末页写着："当你的剑指向天空时，连命运都会为你的决心让路。"书末批注：天裂斩不是斩向天空，是把天空当作丈量自己决心的尺子。作者最后提醒，能斩开苍穹的剑，也必须准备好承受苍穹塌落时的重量。

## 设计意图

为顶级输出战士提供终极单体爆发斩击，强调一击必杀与资源耗尽的风险平衡。
