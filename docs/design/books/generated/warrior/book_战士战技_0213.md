# 《灼印烙印：伤口即标记》

## 基础信息

- **书籍 ID**：`book_战士战技_0213`
- **关联技能**：`warrior_burning_brand`
- **使用效果**：阅读后解锁 `warrior_burning_brand`；若已学会，提升 `current_mastery +170`。
- **阅读要求**：职业标签含 `warrior`；基础 `力量 ≥ 13`。
- **稀有度**：稀有（Rare）
- **建议投放**：灰烬边境集市、烙印骑士团、稀有战技商人。

## 书籍内容

灼印烙印不是杀敌技，而是一种让敌人记住你的恐吓战术。书中教授如何在武器加热后迅速触碰敌人盔甲或皮肤，留下无法磨灭的家族徽记或威胁符号。作者强调烙印的位置比深度更重要：额头、手背、胸口正面最佳，因为那些地方最难隐藏。书中还附有十七种灰烬符号的含义，从“下一个就是你”到“你的家族已被标记”。后半部分讨论心理战：一个满身灼印的敌人会不自觉地畏缩，而他的同伴会开始计算自己是否值得继续战斗。末页写着：“最好的烙印不是烫出来的，是让对手自己想象出来的。”旁边贴着一小块烧焦的皮肤，据说来自某位烙了七次都失败的练习者。

## 设计意图

为恐吓控制流战士提供标记型战技，扩展非致命战术选择。
