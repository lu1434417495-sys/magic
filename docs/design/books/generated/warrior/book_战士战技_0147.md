# 《泰坦之握：扼住命运》

## 基础信息

- **书籍 ID**：`book_战士战技_0147`
- **关联技能**：`warrior_titan_grasp`
- **使用效果**：阅读后解锁 `warrior_titan_grasp`；若已学会，提升该技能 `current_mastery +120`。
- **阅读要求**：职业标签含 `warrior`；基础 `力量 ≥ 9`。
- **稀有度**：精良（Uncommon）
- **建议投放**：巨人摔跤手、精英任务奖励、战技商人。

## 书籍内容

泰坦之握教战士如何用双手或单手锁住敌人的咽喉、关节或武器手腕，从而控制其行动。作者把抓握分为“硬握”与“软握”：硬握以力量压碎，软握以角度限制。书中强调，抓握不是终点，而是为了制造下一击的机会；一旦抓住敌人，就要立刻决定是摔投、折断还是推开。作者还提醒，泰坦之握对体型相差过大的敌人效果有限，因此多用于人形对手。书中附有一张手腕与肘关节的解剖图，标注着最佳抓握点。作者建议练习者先与同伴进行慢速对练，体会抓握与反抓握的力学关系。末尾有一行小字：“握住敌人的那一刻，你也握住了自己的命运。”

## 设计意图

为战士提供关节控制技，让高力量角色在近身缠斗中掌握主动权。
