# 《要塞姿态：钢铁囚笼》

## 书籍内容

要塞姿态比堡垒架势更进一步，它要求战士放弃主动进攻，把自己变成一座敌人必须绕过的障碍。书中教导如何把盾面倾斜以弹开箭矢，如何用肩膀抵住盾牌下沿承受冲撞，以及如何在原地转向而不暴露侧翼。作者形容这个姿态像“把自己折叠进盔甲里”，只有敌人露出巨大破绽时才从盾后刺出一剑。为了训练这个姿态，作者要求练习者在穿戴全套重甲的情况下连续站立数个时辰，期间由同伴从不同方向推撞。只有在被推撞时仍能保持正面朝向敌人、双脚不离原位，才算初步掌握。书中还附有一张要塞防御图，标注着盾牌角度与箭矢弹道的几何关系。据说真正掌握要塞姿态的人，能在十人围攻中守同一盏茶的时间而不退一步。

## 设计意图

为纯坦克战士打造极限防御姿态，让敌人被迫改变攻击目标。
