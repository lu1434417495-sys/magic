# 《龙魂共鸣：血脉里的战歌》

- **关联技能**：`warrior_dragon_soul_resonance`

- **建议投放**：古龙巢穴、龙血战士氏族、传说战技商人。

## 书籍内容

龙魂共鸣是一本要求使用者相信自己体内流淌着龙血的秘典。书中没有具体招式，只有一系列古老的吟唱与呼吸法，用来唤醒所谓“沉睡的血脉”。作者声称，当战士真正进入共鸣状态时，每一次心跳都会让武器微微震颤，而敌人的恐惧会成为另一种燃料。最神秘的一章用无法辨认的文字写成，但每页边缘都画着相同的眼睛——竖瞳、金黄、半睁。许多修行者把这一章称为“龙视”。书的封皮触感温热，像在发烧。扉页警告：“如果你内心没有龙的傲慢，共鸣只会把你烧成灰。”末页有一滴凝固的泪状晶石，据说来自第一位共鸣失败的人。

## 设计意图

为龙血传承战士提供传说级增益战技，强化角色扮演与Build深度。
