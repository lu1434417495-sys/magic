# 《破阵撕裂：撕开队形》

## 书籍内容

破阵撕裂是专门为打散密集队形设计的冲锋变体。作者认为，普通冲锋容易被长枪阵拦截，而破阵撕裂要求战士在冲入敌阵前的一瞬间侧身，用肩膀与盾牌撞开矛杆，同时用武器横向挥砍前排敌人的小腿。书中用三步图解展示了如何选择最薄弱的一列，以及冲入后如何立刻转身支援队友跟进。作者特别强调，破阵撕裂的使用者必须信任身后的队友，因为冲入敌阵后自己会被包围数秒。书中还记录了不同队形的破法：方阵怕角、圆阵怕切、长蛇阵怕断腰。作者建议练习者先用木矛与草人模拟各种阵型，直到能在冲锋中一眼找出最薄弱点。末尾有一张被矛尖刺穿的盾牌残片，作为勇敢的纪念。

## 设计意图

让冲锋具备拆散密集阵型的能力，强化战士在团队战中的开团价值。
