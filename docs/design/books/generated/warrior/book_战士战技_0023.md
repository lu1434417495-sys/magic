# 《龙震九天：战场号角》

- **书籍 ID**：`book_战士战技_0023`
- **关联技能**：`warrior_dragon_shake_heaven`
- **使用效果**：阅读后解锁 `warrior_dragon_shake_heaven`；若已学会，提升该技能 `current_mastery +150`，并标记为可核心化候选。
- **阅读要求**：已学会 `warrior_war_cry` 或 `warrior_true_dragon_slash`；基础 `力量 ≥ 11`、 `意志 ≥ 9`。

## 书籍内容

龙震九天不是普通的战吼，而是把龙威融入声音的战场级技能。这本书的每一页都像在微微震动，仿佛文字本身携带着残余的力量。作者描述了如何在发声时调动全身斗气，让声音不仅传入耳朵，还压迫敌人的神经。书中警告，第一次成功施展龙震九天的人往往会在之后陷入短暂失聪，因此必须逐步练习，不可一蹴而就。后半部分记录了龙震九天在不同战场环境下的效果：在封闭空间里回声会放大震慑，在开阔地带则更适合用来提振友军士气。最后一页是一幅古龙昂首咆哮的插画，下面有一行小字：“当你的声音能让大地颤抖时，你就不再需要证明你是谁。”

书页之间散发着淡淡的硫磺味，仿佛刚从龙息旁抢救出来。某位高阶战士在批注里警告："初学时会觉得这股味道很酷，直到你发现那是自己的斗气在燃烧。"

## 设计意图

作为战士传说级团队控场/增益技能，支撑顶级战士构筑中的领袖与威压定位。
