# 《重剑无锋：下劈基础》

## 基础信息

- **书籍 ID**：`book_战士战技_0001`
- **关联技能**：`warrior_heavy_strike`
- **使用效果**：阅读后解锁 `warrior_heavy_strike`；若已学会，提升该技能 `current_mastery +80`。
- **阅读要求**：角色职业标签含 `warrior` 或 `berserker`；基础 `力量 ≥ 6`。
- **稀有度**：普通（Common）
- **建议投放**：新兵营武器架、民兵训练任务、基础战技商人。

## 书籍内容

这本书的封面被一层厚厚的油脂浸透，仿佛每个翻阅它的人都刚刚练完一整天的下劈。开篇不讲招式，只讲握距：双手握柄时，后手应留出一拳宽，否则劈砍到一半会脱力。作者用大量篇幅纠正一个常见错误——把重击当成“用尽全力砸下去”。真正的重击是先把全身重量挂到剑上，再借腰胯一拧让剑自己落下。书中还附了一张人体简图，标注了发力时膝盖、髋部和肩膀该形成的三点一线。后半部分记录了七种常见靶位的下劈角度，从持盾敌人的肩窝到俯冲野兽的颈侧。每一页边角都有手写批注，最新一条写着：“别盯着剑锋看，盯着你要分开的东西。”

书的末页空白处有一行小字："下劈练到第三年，你才会发现最难劈开的不是木头，而是自己的急躁。"某位后来成为军团长的读者在旁补了一句："急躁劈开之后，才看得见真正的力量。"

## 设计意图

作为战士系最基础的伤害技能入口，把“重击”从无脑高伤重新定义为姿态与发力的必修课。
