# 《金刚不坏身》

## 基础信息

- **书籍 ID**：`book_战士战技_0202`
- **关联技能**：`warrior_adamantine_shell`
- **使用效果**：阅读后解锁 `warrior_adamantine_shell`；若已学会，提升 `current_mastery +160`，并延长该技能持续时间 1 回合。
- **阅读要求**：职业标签含 `warrior`；基础 `体质 ≥ 16`。

- **建议投放**：古武僧遗迹、精英重甲敌人、传说藏书库。

## 书籍内容

这本薄薄的小册子来自东方群山中的苦修者，他们认为战士的甲胄只是外物，真正的盾牌是绷紧的肌肉与呼出的气。金刚不坏身要求练习者在受击前一瞬屏住呼吸，把意识集中到即将被击中的部位，让皮肤下的血液像铁水一样凝固。书中详细列出每日的挨打训练：先用木棍，再用裹布的石头，最后让同伴用真剑鞘敲击。作者强调此法不是为了不痛，而是为了在痛中保持清醒。某位批注者写道：“练到第三层，你会开始享受被击中的感觉，因为那是你确认自己还活着的唯一证据。”末页画着一个盘坐铁人，身上布满旧伤疤。另一行小字提醒：“若某天你发现自己不再疼痛，说明你已经死了。”

## 设计意图

为纯肉盾战士提供以体质为核心的减伤技能，突出东方苦修风格。
