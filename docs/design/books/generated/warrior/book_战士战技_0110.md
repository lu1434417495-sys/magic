# 《致残猛砸：断骨之声》

## 基础信息

- **书籍 ID**：`book_战士战技_0110`
- **关联技能**：`warrior_crippling_slam`
- **使用效果**：阅读后解锁 `warrior_crippling_slam`；若已学会，提升该技能 `current_mastery +100`。
- **阅读要求**：职业标签含 `warrior`；基础 `力量 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：角斗士训练营、基础战技商人、低级敌人掉落。

## 书籍内容

致残猛砸的目标不是头颅也不是心脏，而是支撑敌人移动的关节与骨骼。作者用炭笔画出了膝盖、肘关节和肩锁，并指出这些部位一旦被重击，敌人的战斗力会立刻减半。书中建议选择钝器或战锤来施展此技，因为利刃容易被骨头卡住，而钝器能把冲击力直接送进关节深处。练习时要在木桩上标记出对应位置，连续击打直到能在奔跑中准确命中。作者还提醒，致残猛砸不应作为开场技，因为敌人状态良好时往往容易闪避。最佳使用时机是敌人已经受伤、移动受限，或正被队友吸引注意力时。书中末尾有一页被撕去一半，只剩半句话：“……永远记得，让敌人倒下的最好办法，是让他先站不稳。”他提醒练习者，致残不是目的，而是为了在混战中给自己争取一息时间。

## 设计意图

为战士提供控制型打击，让敌人因残疾而减速或失去武器使用能力。
