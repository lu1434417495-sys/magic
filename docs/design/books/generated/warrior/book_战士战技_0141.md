# 《动势斩：惯性即武器》

## 基础信息

- **书籍 ID**：`book_战士战技_0141`
- **关联技能**：`warrior_momentum_slash`
- **使用效果**：阅读后解锁 `warrior_momentum_slash`；若已学会，提升该技能 `current_mastery +100`。
- **阅读要求**：职业标签含 `warrior`；基础 `敏捷 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：骑兵训练营、战技商人、低级任务奖励。

## 书籍内容

动势斩教战士如何利用移动中的惯性增强斩击威力。作者认为，静止时的斩击只依赖肌肉，而奔跑中的斩击能把体重与速度一起加到刀刃上。书中把动势斩分为“顺斩”与“逆斩”：顺斩是在奔跑中顺势劈出，适合追击；逆斩是在急停时借助反作用力回砍，适合反扑。作者还提醒，动势斩最危险的时刻是脚步与挥剑节奏不一致，那会导致身体失去平衡。书中建议在直线上反复练习，从慢走挥刀开始，逐步过渡到冲刺斩击。作者还讨论了不同武器的惯性特点：重武器惯性大、难收回，轻武器则容易控制但威力不足。末尾画着一个奔跑中挥刀的战士剪影。

## 设计意图

把移动与攻击结合，为战士提供追击与反扑时的威力放大机制。
