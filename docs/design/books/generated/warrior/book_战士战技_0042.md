# 《破阵者：切开敌群》

## 书籍内容

破阵者的任务不是杀敌最多，而是让敌人的阵型从中间裂开。这本书讲解了如何识别敌方阵型的薄弱点：通常是两名士兵之间的连接处、指挥官所在的位置，或者地形造成的高低差。作者提出“楔入—撕裂—扩大”三步法：先用高速或重击楔入敌阵，然后横向移动制造混乱，最后让队友从两侧扩大缺口。书中还讨论了破阵者的心理准备：你必须习惯被包围，因为成功破阵意味着你会深入敌后。后半部分收录了几种经典战例，包括如何在长枪阵中找到突破口，以及如何在盾牌墙前制造第一个缺口。

书中有一张被箭射穿的地图，箭孔正好落在某个敌阵的薄弱点上。作者说这不是装饰，而是提醒："找到那个孔，然后让自己成为射穿它的箭。"

破阵者必须学会在缺口打开后立刻判断：是继续深入，还是停下来巩固阵地，这个选择决定生死。

## 设计意图

为战士提供团战切入与阵型破坏技能，强化大规模战斗中的战术价值。
