# 《骨锯回旋：不该存在的招式》

## 基础信息

- **书籍 ID**：`book_战士战技_0211`
- **关联技能**：`warrior_bone_saw_rotation`
- **使用效果**：阅读后解锁 `warrior_bone_saw_rotation`；若已学会，提升 `current_mastery +170`。
- **阅读要求**：职业标签含 `warrior`；基础 `力量 ≥ 13` 且 `体质 ≥ 12`。
- **稀有度**：稀有（Rare）
- **建议投放**：地下竞技场、亡命佣兵掉落、中级战技商人。

## 书籍内容

这本书没有作者署名，封面上只有一道干涸的血手印，指节处还粘着几根灰色的头发。骨锯回旋是一种利用重型刀刃的离心力连续旋转攻击的技巧，看起来像是舞者在跳一支失控的华尔兹。书中先教如何安全地启动：把剑提到腰侧，身体像上紧的发条一样扭转三圈，然后松手让惯性接管。作者警告最危险的不是敌人，而是停下来的时候——许多人学会了转，却没学会如何在不砍到自己的情况下停住。后半部分是一份伤亡名单，列出了二十七名练习者的死因，从“扭断脚踝”到“砍中自己的后背”。最后一页贴着一张残缺的医学会诊断书，结论栏只有两个字：“别练。”某位不信邪的读者在下面写了一行小字：“我练了，还活着。”字迹到此中断。

## 设计意图

为狂战士风格战士提供高风险连击技能，突出失控与力量的美学。
