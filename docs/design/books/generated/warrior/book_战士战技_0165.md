# 《致残打击：废其行动》

## 书籍内容

《致残打击》专门研究如何攻击敌人的运动系统，封面画着一副膝盖和脚踝的骨架。作者认为，让敌人失去移动能力比直接杀死他更安全，尤其是在面对多个敌人时。书中讲解了膝窝、脚踝、肘关节和手腕四个优先目标，并给出了不同武器的打击角度。后半部分讨论了致残打击后的战术选择：是继续追击还是转向下一个目标。作者提醒，这种战术容易引起敌人的仇恨，需要配合防御技能使用。末页写着："废掉一条腿，比砍中一百刀更有意义。"书末批注：跑得快的敌人最害怕的，是再也跑不起来。真正的致残打击，是让敌人从威胁变成累赘。

## 设计意图

为战士提供精准的功能性打击，强调控制移动而非纯伤害，丰富战术选择。
