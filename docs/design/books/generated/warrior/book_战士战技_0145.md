# 《蛮冲撞：玉石俱焚》

- **关联技能**：`warrior_reckless_slam`
- **使用效果**：阅读后解锁 `warrior_reckless_slam`；若已学会，提升该技能 `current_mastery +140`。

- **建议投放**：狂战士据点、高级任务奖励、精英宝箱。

## 书籍内容

蛮冲撞是一种放弃防御、全力撞击敌人的极端战技。作者毫不掩饰其危险性：使用者会以自身受伤为代价，把敌人撞飞或撞倒。书中教导如何在撞击时用肩膀而非头部接触敌人，以及如何在冲撞后立刻翻滚以减小反震。作者写道：“这是赌命的招式，只有抱着同归于尽决心的人才能用好它。”作者还提醒，蛮冲撞最适合在敌人阵型紧密、无法闪避时使用，因为一旦撞空，使用者会暴露巨大破绽。书中建议在冲锋前深吸一口气，把全身肌肉绷紧，像一枚炮弹一样直线冲出。作者还记录了如何用盾牌保护自己面部的技巧，以降低头部受伤的风险。末尾附有一张被折断的护肩残片。他还提醒，蛮冲撞最好正对墙壁或密集的敌人，空旷地带只会让你变成活靶。书的最后一页还夹着一张泛黄的纸条，上面写着：“真正的战技，只在生死之间学会。”

## 设计意图

以自伤换取强控的狂战士风格战技，适合绝境翻盘或强行开团。
