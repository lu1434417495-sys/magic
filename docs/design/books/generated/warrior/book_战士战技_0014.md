# 《真龙斩：一线天》

## 基础信息

- **书籍 ID**：`book_战士战技_0014`
- **关联技能**：`warrior_true_dragon_slash`
- **使用效果**：阅读后解锁 `warrior_true_dragon_slash`；若已学会，提升该技能 `current_mastery +150`。
- **阅读要求**：已学会 `warrior_jump_slash` 或 `warrior_execution_cleave`；基础 `力量 ≥ 10`、 `意志 ≥ 8`。
- **稀有度**：史诗（Epic）
- **建议投放**：龙陨战场遗迹、古龙信仰任务、传说级战士导师传承。

## 书籍内容

真龙斩不是凡人之技，而是模仿古龙吐息轨迹创出的直线大范围斩击。这本书开篇就警告：没有足够的力量和意志，强行练习只会撕裂自己的肌肉。作者详细讲解了如何把全身力量压缩到一剑之中，让剑锋在挥出瞬间形成一条近乎笔直的斩线。书中强调，真龙斩最难的不是伤害，而是“不歪”——一旦挥剑时手腕有一丝颤抖，斩线就会散开，变成普通的横扫。后半部分收录了几位习得者的笔记，其中一位写道：“我仿佛听见剑在哭，因为它终于知道自己能切开的不仅是肉体。”书的最后夹着一片黑色龙鳞，上面有一道浅白色的划痕。

书的装订线里嵌着一根细小的黑色龙须，触之微热。据说这根龙须来自一头被古龙选中的战士，它会提醒持书者：真龙斩不仅需要力量，还需要被龙认可的意志。

习得者笔记中有这样一句："挥出真龙斩时，你会觉得自己既是剑，也是龙，也是两者之间那道不可见的线。"

## 设计意图

作为战士高阶直线爆发技能的顶点，支撑战士核心化构筑中的“龙斩”流派。
