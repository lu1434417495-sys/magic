# 《命令锁链：谁动谁死》

## 基础信息

- **书籍 ID**：`book_战士战技_0215`
- **关联技能**：`warrior_chain_of_command`
- **使用效果**：阅读后解锁 `warrior_chain_of_command`；若已学会，提升 `current_mastery +160`。
- **阅读要求**：职业标签含 `warrior`；基础 `智力 ≥ 10` 且 `魅力 ≥ 10`。
- **稀有度**：史诗（Epic）
- **建议投放**：军团指挥官密室、战术学院、史诗战技商人。

## 书籍内容

这本书是写给那些必须一边战斗一边指挥的人看的。命令锁链不是直接攻击敌人，而是通过精准的指令与姿态压制，让己方单位形成无形的控制网。作者把战场分成若干“责任格”，每个格子由一名士兵负责，而战士本人就是移动的总枢纽。书中列出一整套手势与战吼代码，从“向左收缩”到“处决那个目标”。最精妙的部分是如何用一次佯攻牵动敌人移动，让敌方恰好踏入己方的责任格。某位帝国元帅在批注中写道：“真正的锁链不是铁做的，是士兵眼中对你的信任。”书的最后一页贴着一张被箭射穿的军旗，旗上绣着一个被划掉的军团编号。

## 设计意图

为战术型战士提供指挥控制技能，强化小队协同玩法。
