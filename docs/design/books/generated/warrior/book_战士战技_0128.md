# 《新月弧斩：弧线之美》

## 基础信息

- **书籍 ID**：`book_战士战技_0128`
- **关联技能**：`warrior_cleaving_arc`
- **使用效果**：阅读后解锁 `warrior_cleaving_arc`；若已学会，提升该技能 `current_mastery +100`。
- **阅读要求**：职业标签含 `warrior`；基础 `力量 ≥ 7`。
- **稀有度**：普通（Common）
- **建议投放**：民兵训练场、基础战技商人、低级野外遭遇。

## 书籍内容

新月弧斩追求的是一道完美的新月形斩击弧线。作者强调，斩击不是直线捅刺，而是让武器以腰为圆心划出一道弧线，这样可以用同样的力量覆盖更大的攻击范围。书中提供了不同身高的练习者如何调整站姿，以保证弧线最高点正好落在敌人颈侧或肋下。末尾有一句话：“最美的弧线，往往结束于敌人的惊讶之中。”作者还讨论了弧线斩击与步法的关系：只有脚步转动到位，腰胯才能释放最大力量，否则弧线会变成无力的横扫。他建议练习者先空挥三百次，感受武器在手中画出的轨迹，再逐步加入移动目标。书中附有一张新月图，标注着起刀点、最高点和收刀点。许多读者在这张图上写下了自己的修正笔记。作者在最后写道：“弧线不是装饰，它是效率的另一种形状。”书的最后一页还夹着一张泛黄的纸条，上面写着：“真正的战技，只在生死之间学会。”

## 设计意图

用优美的弧线扩大斩击范围，为战士提供中近距离的范围压制手段。
