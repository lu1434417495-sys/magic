# 《饥渴锋刃：越伤越凶》

## 书籍内容

饥渴锋刃的核心理念是：武器会在尝到血后变得更锋利。这本书教战士如何通过特定的握法与呼吸，让自己在命中敌人后进入一种嗜血的兴奋状态，下一次攻击会更快更重。作者把这种感觉比作“刀在替你催促”。书中还讨论了风险——过度依赖饥渴会让战士忽视防御，把每一次受伤都视为“再砍一刀的理由”。最诡异的一章讲述如何保养一柄“已经尝过血”的武器：不是用油，而是用更多血擦拭。书脊上嵌着一小块暗红色的石头，据说能感应到周围的杀意。末页写道：“刀饿了的时候，你也会饿。”旁边画着一张嘴，牙齿是刀锋的形状。饥渴锋刃练到后期，使用者会听见武器在梦里对他说话。饥渴锋刃的大师最后大多选择孤独终老，因为他们再也分不清哪些是真实的声音。饥渴锋刃的武器如果长期不饮血，会在深夜发出类似哭泣的嗡鸣。

## 设计意图

为吸血连击型战士提供成长型战技，强化正反馈循环。
