# 《重力斩：让剑变重的艺术》

## 基础信息

- **书籍 ID**：`book_战士战技_0235`
- **关联技能**：`warrior_gravity_slash`
- **使用效果**：阅读后解锁 `warrior_gravity_slash`；若已学会，提升 `current_mastery +170`。
- **阅读要求**：职业标签含 `warrior`；基础 `力量 ≥ 14` 且 `体质 ≥ 12`。

- **建议投放**：重力研究所废墟、魔导战士实验室、稀有战技商人。

## 书籍内容

重力斩是一门结合魔导装置与肌肉力量的现代战技，通过临时增强武器质量来打出超越常规的一击。书中先教如何调节附魔护手上的重力符文：符文越亮，武器越重，但挥舞速度也越慢。作者强调关键在于把握“增重瞬间”——不是在挥出前，而是在剑锋即将接触敌人的那一刹那。最危险的一章讲述如何在重力失控时弃剑，因为一柄过重的武器会把使用者一起带倒。书页里夹着一小块碎裂的符文石，旁边注明“失败样本七号”。末页警告：“让剑变重很容易，难的是让你的心不变重。”背面有人用细笔写：“我的心已经够重了。”重力斩的符文石每使用一次就会变轻一点，仿佛重量被记忆带走。重力斩的符文石越轻，说明它见证过的战斗越多，也越接近碎裂。重力斩的符文石碎裂时，会把储存的所有重量一次性释放，足以压垮一座小屋。

## 设计意图

为魔导战士提供爆发型斩击，引入装备附魔与时机配合。
