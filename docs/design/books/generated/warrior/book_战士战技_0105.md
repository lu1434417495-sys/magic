# 《裂颅猛击：颅骨回响》

- **书籍 ID**：`book_战士战技_0105`
- **关联技能**：`warrior_skull_splitter`
- **使用效果**：阅读后解锁 `warrior_skull_splitter`；若已学会，提升该技能 `current_mastery +140`。

- **建议投放**：黑市禁书、地下墓穴、高级敌人宝箱。

## 书籍内容

这是一本被教会列为禁书的战技手册，专讲针对头部的致命打击。作者毫不避讳地指出，头盔能挡住一次直击，却挡不住连续两次落在同一位置的震荡。裂颅猛击的核心是“先震后裂”：第一下用锤面或剑柄钝击让头盔内衬塌陷，第二下再用锋刃刺入裂缝。书中详细描写了不同头盔的弱点，以及如何从敌人的肩高判断最佳落点。作者反复强调，裂颅猛击只能用于生死搏杀，因为第二击几乎没有给对方留下任何生还余地。书中还记录了如何借助敌人的身高与姿态调整起击角度，以及如何在头盔已变形时判断下一击该落在何处。由于内容过于阴毒，正规军团拒绝将其列入教材，但在地下世界里，它一直是抢手货。因为内容危险，书页边缘被涂了薄薄一层蜡，以防血液浸透后字迹模糊。

## 设计意图

为战士提供高门槛的爆头终结技，针对重甲敌人的头盔防御做垂直击穿。
