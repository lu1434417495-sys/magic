# 《宏图横扫：一圈清场》

## 基础信息

- **书籍 ID**：`book_战士战技_0234`
- **关联技能**：`warrior_grand_sweep`
- **使用效果**：阅读后解锁 `warrior_grand_sweep`；若已学会，提升 `current_mastery +180`。
- **阅读要求**：职业标签含 `warrior`；基础 `力量 ≥ 15` 且 `敏捷 ≥ 12`。
- **稀有度**：史诗（Epic）
- **建议投放**：古代将军陵寝、军团演习场、史诗战技商人。

## 书籍内容

宏图横扫是专为长柄武器与大剑设计的战场清场技，要求使用者以自身为圆心挥出接近三百六十度的巨大弧线。书中先讲站位：圆心必须选在敌人最密集处，而挥击开始时要让武器尽量贴近地面，以利用反弹力量。作者用大量篇幅纠正一个错误——许多人以为横扫靠手臂，其实靠髋部旋转带动全身。后半部分讨论如何在挥击后利用惯性直接进入下一招，而不是停顿等待。书末附有一张古代战场的俯瞰图，某个位置被画上了重重的红圈，旁边写着：“他在这里转了一圈，然后战争就结束了。”红圈外还有许多小箭头，指向四面八方逃散的敌人。

## 设计意图

为长柄与大剑战士提供大范围清场技能，强化群体战斗体验。
