# 《弑君誓约：对强者的剑》

## 基础信息

- **书籍 ID**：`book_战士战技_0242`
- **关联技能**：`warrior_kingslayer_oath`
- **使用效果**：阅读后解锁 `warrior_kingslayer_oath`；若已学会，提升 `current_mastery +190`。
- **阅读要求**：职业标签含 `warrior`；基础 `力量 ≥ 14` 且 `敏捷 ≥ 12`。
- **稀有度**：传说（Legendary）
- **建议投放**：革命军密库、弑王者陵寝、传说战技宝箱。

## 书籍内容

弑君誓约是一种必须在对强者发起挑战前宣誓的战技，一旦宣誓，使用者对非目标敌人的伤害会降低，但对目标的杀伤力会大幅提升。作者认为真正的勇气不是杀得多，而是敢对看起来不可战胜的人拔剑。书中详细记录了誓约的措辞、手势与心理准备，强调任何犹豫都会让誓约失效。最感人的一章收录了历代弑君者的遗言，他们大多死于目标之手，但都没有在死前收回誓约。书的封面用某种黑色金属制成，中央凹陷，像是一个被取走的徽章留下的痕迹。末页写道：“君王也会流血，这是所有暴政最大的秘密。”

## 设计意图

为挑战型战士提供传说级单体爆发技能，强化首领战与英雄叙事。
