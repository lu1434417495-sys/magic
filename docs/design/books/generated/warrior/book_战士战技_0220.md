# 《死角斩：你看不到的一击》

## 基础信息

- **书籍 ID**：`book_战士战技_0220`
- **关联技能**：`warrior_dead_angle_slash`
- **使用效果**：阅读后解锁 `warrior_dead_angle_slash`；若已学会，提升 `current_mastery +170`。
- **阅读要求**：职业标签含 `warrior`；基础 `敏捷 ≥ 14`。
- **稀有度**：稀有（Rare）
- **建议投放**：影舞者训练营、地下格斗场、稀有战技商人。

## 书籍内容

死角斩研究的是如何利用敌人视野的盲区发动攻击。作者把人体视野分成三个区域：清晰区、模糊区与盲区，并指出大多数人把九成防御精力放在清晰区。书中教人如何通过低姿移动、借同伴身影掩护、利用光线方向，让自己从敌人的盲区接近。最关键的章节是如何在挥剑时不暴露剑身反光——可以用泥土、灰烬或敌人的血涂抹剑面。作者还建议练习者每天蒙眼训练一小时，以理解“看不见的对手”是什么样子。书末附有一张被戳破的眼罩，旁边写着：“当你开始从死角看世界，世界也会从死角看你。”另一页有人画了一只眼睛，瞳孔是空的。

## 设计意图

为高敏捷战士提供潜行突袭型战技，扩展刺客与战士的交叉玩法。
