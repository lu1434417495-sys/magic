# 《掠食者爪：撕开防线》

## 基础信息

- **书籍 ID**：`book_战士战技_0249`
- **关联技能**：`warrior_ravager_talons`
- **使用效果**：阅读后解锁 `warrior_ravager_talons`；若已学会，提升 `current_mastery +170`。
- **阅读要求**：职业标签含 `warrior` 或 `berserker`；基础 `力量 ≥ 13` 且 `敏捷 ≥ 14`。
- **稀有度**：稀有（Rare）
- **建议投放**：野兽猎场、掠夺者营地、稀有战技商人。

## 书籍内容

掠食者爪是一种模仿猛兽扑击的战技，要求战士用双手或双武器同时从不同角度撕裂敌人的防御。书中先教人如何像猫科动物一样压低身体蓄力，再在最短的时间内爆发前冲。作者强调爪击的关键不是长度，而是角度——两手必须同时到达，让敌人无法同时挡下两边。后半部分讨论如何在爪击后顺势翻滚脱离，避免被反击。书页里夹着一片弯曲的金属爪套，刃口有许多细小的锯齿。末页写着：“掠食者不撕碎猎物，它撕开的是猎物认为自己安全的幻觉。”

## 设计意图

为双持与野性战士提供多段破防技能，强化突袭与连击。
