# 《巨人步伐：踩出的地形》

## 书籍内容

巨人步伐是一种让战士在移动中改变地形的重装战技，传说源自曾与巨人同行的古代军团的步法。书中前半部分教人如何像巨人一样用脚跟先落地：不是轻轻踩下，而是把整条腿像桩子一样砸进地面，让冲击波向四周扩散。作者特别强调体重分配——重甲不是负担，而是制造震动的工具。后半部分讨论如何利用踩出的凹坑与裂缝限制敌人走位，把战场变成对自己有利的迷宫。书中夹着一片巴掌大的鳞片，据说是某位“步行如山”的教官留下的。末尾写道：“当你走路时敌人在躲你，你就学会了巨人步伐。”扉页上还有一行警告：“不要在家里练习。”

## 设计意图

为重装战士提供地形控制型移动技能，扩展战场改造维度。
