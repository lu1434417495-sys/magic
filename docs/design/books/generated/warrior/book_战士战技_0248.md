# 《震掌：隔着盔甲打断骨》

## 基础信息

- **书籍 ID**：`book_战士战技_0248`
- **关联技能**：`warrior_quaking_palm`
- **使用效果**：阅读后解锁 `warrior_quaking_palm`；若已学会，提升 `current_mastery +170`。
- **阅读要求**：职业标签含 `warrior` 或 `monk`；基础 `力量 ≥ 14` 且 `敏捷 ≥ 12`。

- **建议投放**：深山古刹、武僧与战士交流道场、稀有战技商人。

## 书籍内容

震掌是一门把冲击力穿过表面护甲直达内部的战技，适合对付重甲敌人。书中先教人如何在手掌接触目标的瞬间放松，让力量像水一样渗透进去，而不是在盔甲上反弹。作者强调“震”不是推，而是短促的爆发——一次正确的震掌会让敌人的内脏在零点几秒内承受多次震荡。最实用的章节是如何选择击打位置：胸甲中央、背脊、肋下是最有效的传导点。书里夹着一张被震裂的砖块照片，砖面完整但内部粉碎。末页批注：“盔甲保护的是皮肉，震掌问候的是骨头。”

## 设计意图

为内劲型战士提供破甲内伤技能，强化对重甲单位的克制。
