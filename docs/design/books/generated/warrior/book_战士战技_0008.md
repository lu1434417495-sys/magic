# 《后撤半步：战士的生存课》

## 书籍内容

这本书很薄，薄到很多人误以为它不重要。开篇第一句话是：“进攻让你赢，撤退让你活着再赢。”作者把后撤分成两种：一种是预判式后撤，在敌人攻击启动前就拉开距离；另一种是应激式后撤，在刀锋已经挥出时才匆忙后退。前者需要阅读敌人的肩膀和胯部，后者大多只能碰运气。书中用一整章讲解后撤的距离控制——撤得太远会丢失反击机会，撤得太近则无法脱离攻击范围。作者还提出“后撤步接重击”的组合思路：利用后撤让敌人挥空产生硬直，再用蓄力重击回敬。最后几页是一些手绘的脚印图，每一步都标着“吸气”“呼气”“踏地”。

书末附有一张被雨水泡烂的地图，上面用炭笔标着几个"可以后撤的格子"。作者在旁边解释："这些格子不是逃跑路线，是你下一轮进攻的起点。"

某位老兵在空白处补了一句："后撤不是认输，是让敌人的攻击落空，然后教他什么叫代价。"

## 设计意图

为战士补充基础生存能力，与灰烬翻滚形成“主动回避”技能矩阵。
