# 《猎巨者：放倒大山》

## 基础信息

- **书籍 ID**：`book_战士战技_0047`
- **关联技能**：`warrior_titan_slayer`
- **使用效果**：阅读后解锁 `warrior_titan_slayer`（待新增，标签 `battle_art`）；若已学会，提升该技能 `current_mastery +120`。
- **阅读要求**：基础 `力量 ≥ 10`、 `体质 ≥ 8`；已学会 `warrior_execution_cleave` 或 `warrior_bone_crusher`。
- **稀有度**：稀有（Rare）
- **建议投放**：巨人猎手营地、山岳巨兽战利品、传奇猎人委托。

## 书籍内容

对付比自己大三倍的敌人，力量和勇气都不够，你需要的是方法。这本书专门讨论如何狩猎巨型敌人：首先是位置，必须攻击它们的下盘、关节和视线盲区；其次是耐心，不要试图一次性造成大量伤害，而是要一点一点削弱它们的移动能力。作者详细讲解了如何利用钩索、长枪和战锤配合，让巨兽失去平衡。书中还讨论了团队配合：有人负责吸引注意力，有人负责切断肌腱，有人负责在巨兽倒地后攻击要害。后半部分是一份针对不同巨兽的弱点清单，从山岭巨人到古龙幼体。

某页画着一只巨人脚踝处的肌腱结构，旁边标注"先切这里"。作者用整整一页解释："放倒大山不是打败它，是让它自己因为站不稳而跪下。"

猎巨者最重要的装备不是大剑，而是耐心；让巨人自己犯错误，比强行攻击它的要害更安全。

## 设计意图

为战士提供反大型目标专精，扩展战士在特定遭遇战中的战术角色。
