# 《残心：收招即起招》

## 基础信息

- **书籍 ID**：`book_战士战技_0044`
- **关联技能**：`warrior_zanshin`
- **使用效果**：阅读后解锁 `warrior_zanshin`（待新增，标签 `passive`）；若已学会，提升该技能 `current_mastery +130`，并提升下一次战斗中使用任意战技后的 `stamina` 回复速度 5%（一次性战斗增益）。
- **阅读要求**：基础 `意志 ≥ 8`、 `敏捷 ≥ 7`；已学会至少三个战士近战技能。
- **稀有度**：稀有（Rare）
- **建议投放**：东方剑术大师委托、冥想武馆、精英决斗者宝箱。

## 书籍内容

残心是一种状态：即使你的攻击已经结束，你的精神和身体仍然保持着随时可以再次发动的准备。这本书不讲具体招式，只讲收招后的那一瞬间。作者认为，大多数战士的失败不是因为招式不够强，而是因为招式结束后的空档太长。书中详细讲解了如何在每次攻击后保持正确的姿势、呼吸和意识，让下一次攻击可以从任何位置启动。后半部分讨论了残心在团队战斗中的应用：当你不需要立刻追击时，如何用残心保护队友的侧翼或封锁敌人的移动路线。作者最后写道：“剑回到原位不是为了休息，是为了下一次出鞘更快。”

封面中央有一个小小的圆点，作者说那是"收招后意识应该停留的位置"。"大多数人收招后意识会散，"他解释，"让意识停在这个点上，下一击就会从那里自然生出。"

残心的高级境界是连收招后的呼吸都在为下一次攻击做准备，整个人像一张永远拉满的弓。

## 设计意图

为战士提供收招优化被动，支持高频率战技构筑与资源循环。
