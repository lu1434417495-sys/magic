# 《巨像打击：推倒高山》

## 基础信息

- **书籍 ID**：`book_战士战技_0129`
- **关联技能**：`warrior_colossus_strike`
- **使用效果**：阅读后解锁 `warrior_colossus_strike`；若已学会，提升该技能 `current_mastery +120`。
- **阅读要求**：职业标签含 `warrior`；基础 `力量 ≥ 9`。
- **稀有度**：精良（Uncommon）
- **建议投放**：猎巨人营地、精英敌人掉落、高级战技商人。

## 书籍内容

巨像打击专门用来对付体型庞大的敌人。作者指出，面对巨人或巨兽时，攻击头部往往够不着，而脚踝、膝盖与尾巴根部才是可靠目标。书中教导战士如何利用敌人的步幅预测其重心位置，并在它迈出下一步时击打支撑腿。作者还提醒，完成一次成功的巨像打击后必须立刻翻滚离开，因为倒下的巨物会砸出一大片危险区。作者还提到，巨像打击需要耐心，很多时候要在敌人脚下等待数个回合才能找到最佳时机。书中记录了不同巨兽的弱点：双足巨人怕膝弯，四足巨兽怕前腿，长尾怪物怕尾根。练习者要学会在巨兽的阴影下保持冷静，并把每一次攻击都当作最后一击来执行。末尾附有一张巨兽骨骼简图。他提醒，巨像倒下时会掀起尘土与碎石，那才是第二危险的敌人。书的最后一页还夹着一张泛黄的纸条，上面写着：“真正的战技，只在生死之间学会。”

## 设计意图

为战士提供对抗大型敌人的特化战技，打破大体型单位的天然优势。
