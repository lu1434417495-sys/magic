# 《凤凰再起：从灰烬里站起来》

## 书籍内容

凤凰再起是一种在濒死时自动触发的复活型战技，要求使用者在平时就把一部分生命力封存在灰烬之中。书中强调这不是永生，而是一次重来的机会——发动后会清空大部分负面状态，但也会让自己极度虚弱。作者用诗意语言描述死亡前一瞬的体验：世界变灰、声音远去、然后一点火星从胸口亮起。最关键的练习是如何在复活后的三秒内保持清醒，因为那时最容易被敌人再次击倒。书页里夹着一根烧焦的羽毛，触感温热，据说来自某位真正复活的战士。末页写道：“灰烬不是结束，是凤凰的枕头。”

## 设计意图

为灰烬战士提供传说级保命技能，强化高风险高回报的世界观主题。
