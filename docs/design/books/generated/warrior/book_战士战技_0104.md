# 《狂怒裂斩：血沸之刃》

## 基础信息

- **书籍 ID**：`book_战士战技_0104`
- **关联技能**：`warrior_raging_cleave`
- **使用效果**：阅读后解锁 `warrior_raging_cleave`；若已学会，提升该技能 `current_mastery +100`。
- **阅读要求**：职业标签含 `warrior` 或 `berserker`；基础 `力量 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：狂战士据点、战技商人、低级敌人掉落。

## 书籍内容

狂怒裂斩教战士如何把愤怒变成可控的火焰。书中开篇警告：无目的的狂怒只是自杀。作者要求练习者在劈砍前默念一个具体目标，把情绪聚焦成剑刃上的力道。发力时从脚跟拧起，经过腰胯、肩背，最后甩出双臂，让斧头或大刀画出一条略带弧线的纵劈。后半部收录了如何在受伤后借着肾上腺素提升斩击速度，并提醒狂怒最多持续三次呼吸，超时就要后撤重整。书中还对比了斧头与长刀在施展狂怒裂斩时的差异：斧头适合劈开护甲与盾牌，长刀更擅长切割皮肉与关节。作者建议练习者根据自己的武器调整弧线半径，并始终保留一条安全的撤退路线。结尾处用烧焦的笔迹写着：“火焰可以取暖，也可以焚身，区别在于你是否能把它关进剑里。”封底有一道烧焦的痕迹，据说是某位狂战士练到失控时留下的。

## 设计意图

给高力量战士一个以情绪驱动的高风险高回报斩击，强调时机而非无脑猛攻。
