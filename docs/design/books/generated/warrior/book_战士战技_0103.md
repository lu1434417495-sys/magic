# 《不屈壁垒：不动的山》

## 书籍内容

打开这本书，首先看到的是一行大字：“山不躲，所以山不会被砍倒。”不屈壁垒是一种防守心境，要求战士在遭受重击时把双脚钉入地面，把反震力导入小腿与大地。作者用整章篇幅讲解呼吸，吸气要在敌人举起武器时，呼气要在承受打击的瞬间，让肌肉在那一刹那如岩石般坚硬。书中还提到，真正的壁垒不是永远不被击退，而是退半步后立刻回到原位，让敌人觉得面对的是一面会自我修复的墙。为了训练这种姿态，作者设计了一套奇怪的练习：让两名同伴从正面与侧面交替推撞练习者，而练习者只能在原地用最小的位移化解力量。他声称，当练习者能在十次推撞中保持双脚不离开原先画出的圈时，才算初窥门径。书的最后粘着一片碎盾残片，像是某种无声的证明。许多盾卫把这句话抄在盾牌内侧，作为被围攻时的心理支柱。

## 设计意图

为前排战士提供高级硬度技能，让防守本身成为消耗敌人资源的核心策略。
