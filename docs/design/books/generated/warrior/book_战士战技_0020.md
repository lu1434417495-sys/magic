# 《跳劈重斩：从天而降的压迫》

## 基础信息

- **书籍 ID**：`book_战士战技_0020`
- **关联技能**：`ashen_leaping_cleave`
- **使用效果**：阅读后解锁 `ashen_leaping_cleave`；若已学会，提升该技能 `current_mastery +130`。
- **阅读要求**：已学会 `warrior_jump_slash` 或 `warrior_whirlwind_slash`；基础 `力量 ≥ 9`、 `敏捷 ≥ 7`。
- **稀有度**：稀有（Rare）
- **建议投放**：断桥营寨高阶战技传授、灰烬交界精英宝箱、跃斩大师委托。

## 书籍内容

跳劈重斩把跃进和砸击合二为一，是灰烬交界里最具压迫感的进场动作之一。作者认为，跳劈不是“跳得高”，而是“落得狠”。起跳前必须确认落点周围没有其他敌人，否则落地后的硬直会让你陷入包围。书中用大量篇幅讲解落点选择：最理想的位置是敌人阵型的边缘，这样中心目标会承受全额冲击，而周围敌人会被范围波及。作者还提出“空中变向”的高级技巧：利用腰腹力量在跃起后微调身体角度，让原本偏差的落点回到正确位置。最后几页是一份手写的训练计划，要求练习者连续一百次从矮墙上跳下，保持双脚同时着地且膝盖不超过脚尖。

书脊有一道深深的裂痕，像是被某种重物砸过。作者在前言里开玩笑说："如果这本书还能翻开，说明它和我一样，都学会了从高处摔下来而不碎。"

作者建议练习者先在沙坑中起跳，因为沙地能吸收错误落地时的冲击，给初学者的膝盖一条活路。

## 设计意图

为战士提供高风险高回报的跃进AOE手段，强化“进场拆阵型”的战术价值。
