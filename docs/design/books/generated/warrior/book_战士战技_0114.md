# 《夺命一击：必杀之点》

## 基础信息

- **书籍 ID**：`book_战士战技_0114`
- **关联技能**：`warrior_killing_blow`
- **使用效果**：阅读后解锁 `warrior_killing_blow`；若已学会，提升该技能 `current_mastery +140`。
- **阅读要求**：职业标签含 `warrior`；基础 `力量 ≥ 9`、`感知 ≥ 8`。
- **稀有度**：稀有（Rare）
- **建议投放**：刺客公会禁书、高级敌人掉落、精英宝箱。

## 书籍内容

夺命一击不是力量最大的攻击，而是最会找点的攻击。作者用人体图标注了咽喉、心窝、太阳穴与后腰四处要害，并说明不同身高与姿态下如何接近这些位置。书中指出，必杀一击往往出现在敌人旧力已尽、新力未生之际，此时防御最松懈。练习者要学会用假动作诱使敌人露出破绽，然后以最短路径送出致命的一刺或一劈。为了训练夺命一击，作者设计了一个残酷的练习：在稻草人身上用墨点标出要害，然后在移动中只攻击这些墨点。他要求练习者先在慢速中做到百发百中，再逐渐提升速度。书中警告，夺命一击最大的风险是失手后的巨大硬直，所以只有在确认破绽时才应出手。书的最后一页只有一行血字：“夺命一击出手之前，先夺自己的犹豫。”书的最后一页还夹着一张泛黄的纸条，上面写着：“真正的战技，只在生死之间学会。”

## 设计意图

为战士提供高感知要求的斩杀技，强调破绽捕捉与精准打击。
