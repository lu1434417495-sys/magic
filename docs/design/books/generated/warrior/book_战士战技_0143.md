# 《惩罚打击：以牙还牙》

## 书籍内容

惩罚打击专门用于回应敌人的偷袭或背叛。作者认为，战士的尊严不容挑衅，而这种战技会在自己受伤后的下一次攻击中附加额外伤害。书中强调，惩罚不是报复，而是让敌人明白越界代价的计算。练习者要学会在受击后立刻稳住心态，把疼痛转化为下一次出招的精准度。作者还提醒，惩罚打击需要极强的心理控制力，因为受伤后的本能是退缩或慌乱。书中提供了一套“痛苦锚定”练习：在受轻击时立刻默念一个关键词，把意识从疼痛拉回战斗。作者认为，只有能在疼痛中保持冷静的人，才能把惩罚打击的威力发挥到极致。末尾写着：“最好的复仇，是让对方后悔先动手。”

## 设计意图

引入受伤反击机制，让战士在被击中后获得一次高价值回报机会。
