# 《灾厄冲锋：同归于尽的路》

## 书籍内容

灾厄冲锋是一种把自己变成攻城锤的自杀式冲锋，书中开篇就列出使用该技能后的平均存活率：三成。作者不掩饰它的残酷，反而赞美这种“把命押在速度上”的诚实。技巧核心在于起步前的十步助跑：要慢、要稳、要让敌人误以为你只是在靠近，然后在第十步突然把全身重量抛出去。书中还教人如何在冲锋途中调整角度——不是用眼睛，而是用髋部的转向。最震撼的一章记录了一支百人队连续发动灾厄冲锋撕开敌方方阵的全过程，作者在最后写道：“他们倒下的时候，地上画出了通往胜利的沟。”书的封底用血画了一条直线，旁边标注：“从这里开始，不要停。”

## 设计意图

为高阶狂战士提供极端爆发突进技能，强调牺牲与战场定位。
