# 《武器保养：锋刃的寿命》

## 基础信息

- **书籍 ID**：`book_战士战技_0040`
- **关联技能**：`warrior_weapon_maintenance`
- **使用效果**：阅读后学会知识 `knowledge_weapon_care`；若已学会，提升阅读者所有近战武器相关技能 `current_mastery +30`（一次性永久调整）。
- **阅读要求**：无职业限制；基础 `智力 ≥ 5`。
- **稀有度**：普通（Common）
- **建议投放**：铁匠铺基础读物、军营后勤任务、商人出售。

## 书籍内容

一把钝刀不仅砍不动敌人，还会反过来拖累使用者的手腕。这本书从最基础的磨刀开始讲起：不同角度适合不同用途，太锋利容易崩口，太钝则费力。作者详细讲解了如何检查剑刃上的缺口和卷刃，如何用磨刀石修复轻微损伤，以及何时应该交给专业铁匠。书中还讨论了木质和皮质部件的保养：剑柄松动会在关键时刻让你握不住武器，皮 sheath 受潮会腐蚀金属。后半部分是一份简单的保养清单，作者建议每次战斗后都执行一次。虽然这本书不直接教你杀人，但作者写道：“保养武器就是保养你的命。”

书页间散发着淡淡的机油味，仿佛刚从铁匠铺的架子上取下来。作者建议读者在磨刀时把这本书放在旁边："让它也沾上铁屑，这样它才不会觉得自己只是个看客。"

作者在最后列出了三样每个战士都应该随身携带的东西：磨刀石、油布和一根备用的皮绳。

## 设计意图

作为知识类书籍，用 `known_knowledge_ids` 解锁机制强化战士的日常维护循环。
