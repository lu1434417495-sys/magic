# 《咆哮大地：声震三尺》

## 基础信息

- **书籍 ID**：`book_战士战技_0208`
- **关联技能**：`warrior_bellowing_earth`
- **使用效果**：阅读后解锁 `warrior_bellowing_earth`；若已学会，提升 `current_mastery +160`。
- **阅读要求**：职业标签含 `warrior`；基础 `体质 ≥ 14` 且 `力量 ≥ 12`。
- **稀有度**：稀有（Rare）
- **建议投放**：山脉巨民部落、地震裂谷营地、稀有战技商人。

## 书籍内容

北地蛮族相信大地本身会听从最强大的战吼。咆哮大地不是用声音伤人，而是用战吼引发脚下土地的共振，让附近的敌人失去平衡。书中前半部分是发声训练：如何让腹腔而非喉咙产生共鸣，如何让一个音节持续震动五秒以上。后半部分则教练习者感受地面反馈——脚底的震动会告诉你哪块石头松了、哪个敌人重心不稳。作者建议在最寒冷清晨练习，因为低温能让声带更接近极限。书页里夹着一根冻裂的牛角，据说是某位战吼者的遗物。最后一行批注写道：“当你能让雪从屋顶落下，你就入门了。”旁边画着一座被震塌的茅屋。

## 设计意图

为战吼系战士提供范围控制技能，扩展声音类战技的战术维度。
