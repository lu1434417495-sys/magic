# 《决斗宣告：单挑的仪式》

## 书籍内容

决斗不是街头斗殴，而是一种把多人混战压缩成一对一的仪式。这本书开篇讲述了不同文化中的决斗礼仪：北方部落用武器敲地三下，南方城邦用左手按胸，灰烬交界的战士则会大声喊出对手的名字。作者认为，决斗宣告的力量不在于恐吓，而在于“锁定”——让周围的人和敌人都知道，接下来这场交换只发生在你和你选中的对手之间。书中还讨论了如何选择决斗对象：优先选择对团队威胁最大但又被你克制的敌人。后半部分讲“宣告失败”的情况：如果敌人在你宣告后仍然攻击你的队友，说明他的意志或理智高于你的压制，这时需要重新评估战术。

书中收录了不同文化的决斗誓词，但作者建议读者永远不要照搬，要找到自己的声音。"誓词不是咒语，"他写道，"它是你把自己从混乱战场上剥离出来的刀。"

## 设计意图

服务于战士“星刃决斗”流派的单挑定位，把单体爆发与战术选择结合起来。
