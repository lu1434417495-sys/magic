# 《破势盾反：只开一次的门》

## 基础信息

- **书籍 ID**：`book_战士战技_0018`
- **关联技能**：`ashen_shield_parry`

## 书籍内容

盾不是墙，是一扇只开一次的门。这本笔记将盾反拆成三步：读势、沉肩、开门。读势不是看敌人的刀，而是看敌人的肩和胯——真正发力的地方永远比武器先动半拍。沉肩是为了把盾重心压低，让反震力沿着小腿灌进地面，而不是撞回自己的胸口。开门则是赌那一瞬：盾面先迎上攻击弧线，再顺着来劲的方向滑开一寸，把敌人的重心扯到空处。笔记后半画满了简笔小人，每个小人都在摔倒，旁边标注着“早了”“晚了”“对了”。笔记还专门讨论了盾反之后的“半步”：大多数人反制成功后急着追击，结果踩进敌人失衡时胡乱挥出的攻击范围。正确的做法是先踏出小半步确认对方真的失去重心，再决定是补刀、换位还是继续压制。

书的最后一页空白处画着一扇半开的门，门外站着一个跌倒的小人。图画旁边没有文字，但每个看过的盾卫都知道，那扇门只会在敌人攻击的瞬间打开一次。

## 设计意图

把盾反从“高伤反击”重新框定为“读招与反制”，与灰烬交界破势盾反的战技气质一致。
