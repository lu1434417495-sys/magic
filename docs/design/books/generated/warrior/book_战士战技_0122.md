# 《灰烬踏步：炭上生花》

## 基础信息

- **书籍 ID**：`book_战士战技_0122`
- **关联技能**：`ashen_ash_step`
- **使用效果**：阅读后解锁 `ashen_ash_step`；若已学会，提升该技能 `current_mastery +100`。
- **阅读要求**：无职业限制；基础 `敏捷 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：灰烬交界入口营地、通用战技商人、低级灰烬敌人掉落。

## 书籍内容

灰烬踏步不是普通步法，而是一种在灰烬与焦土上无声移动的技艺。书中教导战士如何利用松软的灰烬吸收脚步震动，以及如何在踏下时让脚掌先落外侧再滚到内侧，从而避免扬起灰尘。作者指出，灰烬交界的许多敌人靠震动定位猎物，学会在炭上生花，就等于获得了半条命。作者还提醒，灰烬踏步并非完全无声，而是把脚步声混入灰烬本身的微弱塌陷声中，让敌人难以分辨方位。练习时要在铺满灰烬的训练场上反复走动，直到同伴闭眼也能大致判断方向才算及格。书末附有一张脚印示意图，标注着脚掌落地的先后顺序与受力点。书的最后画着一双赤脚，旁边写着：“在灰烬中留下越少的痕迹，你活得越久。”

## 设计意图

为灰烬交界提供环境专属移动战技，强化潜行与生存能力。
