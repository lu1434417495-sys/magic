# 《肾上腺素：绝地提速》

## 书籍内容

肾上腺素不是药剂，而是身体在绝境中自动打开的阀门。这本薄册子教战士如何在重伤或包围中触发爆发性的反应速度。作者认为，真正的关键不在“快”，而在“先看清再动”——提速后的第一击必须命中，否则额外消耗的体力会让自己更快崩溃。书中列出一套简短的触发训练：屏息、收缩核心、把视线集中在敌人武器末端，然后比对方早半拍出招。书中还提到，肾上腺素爆发最适合用来摆脱控制或反制敌人的关键一击，而不是单纯追击。作者建议配合冥想中的呼吸法练习，以延长爆发后的稳定期。末尾有一张被汗水浸透的训练表，记录着一百次“绝地反击”的模拟结果，旁边只有一句话：“快零点三秒，就是生与死。”练习到后期，他建议让同伴突然从背后轻拍肩膀，训练惊吓中的反应。

## 设计意图

作为战士的逆境反扑技能，让低血量时有一次改变节奏的爆发窗口。
