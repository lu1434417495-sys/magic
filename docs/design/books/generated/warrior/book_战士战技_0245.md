# 《熔核击：把心脏的热量打出》

## 基础信息

- **书籍 ID**：`book_战士战技_0245`
- **关联技能**：`warrior_molten_core_strike`
- **使用效果**：阅读后解锁 `warrior_molten_core_strike`；若已学会，提升 `current_mastery +180`。
- **阅读要求**：职业标签含 `warrior`；基础 `力量 ≥ 15` 且 `体质 ≥ 13`。
- **稀有度**：史诗（Epic）
- **建议投放**：火山口锻炉、熔岩巨人巢穴、史诗战技宝箱。

## 书籍内容

熔核击是一种把体内热量通过武器一次性释放的战技，命中时会在敌人身上留下熔化的创口。书中警告练习者必须先学会控制体温：过热会灼伤自己的手掌，过冷则无法点燃熔核。作者详细描述了“找热”的过程——闭眼感受心脏跳动，把那份温热沿着手臂推到指尖，再导入剑身。最壮观的一章记录了一位战士在雪原上使用熔核击，蒸汽瞬间吞没了方圆十米。书页边缘有轻微烫卷，仿佛每次翻阅都会让纸变干。末页批注：“熔核不是火，是你愿意燃烧的部分。”

## 设计意图

为火山元素战士提供灼热爆发技能，强化内劲外放主题。
