# 《镜像姿态：战胜自己》

## 基础信息

- **关联技能**：`warrior_mirror_stance`

- **阅读要求**：已完成至少一次镜像对决；基础 `敏捷 ≥ 9`、 `感知 ≥ 8`。

- **建议投放**：万战圆环隐藏奖励、心灵试炼密室、自我挑战任务。

## 书籍内容

最难击败的敌人永远是你自己。这本书不讲招式，只讲“镜像”——如何把自己的动作当成对手的动作来阅读。作者认为，每个人的战斗习惯都会留下痕迹：攻击前总会微微吸气，突刺前总会后脚先动，重击前总会耸一下肩。当你能识别自己的这些痕迹，你就能识别所有和你有相似习惯的人。书中要求练习者对着镜子反复出招，直到能闭眼预判自己的下一步。后半部分进入更深的层面：镜像不仅是模仿，还是一种心理战术——让敌人觉得你熟悉他的节奏，从而迫使他改变节奏，而这正是你真正想要的。

封面的镜子涂层已经斑驳，偶尔还能照出一点模糊的影子。作者声称这是故意的："完美的镜子会让你分心看自己，斑驳的镜子才能让你看见动作的本质。"

镜像训练最难的部分不是看懂自己，而是承认自己的每一个习惯都可以被敌人利用。

## 设计意图

作为高阶战士的自我超越技能，强化对敌人行动模式的预判与反制。
