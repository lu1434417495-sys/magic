# 《余烬一击：灰烬复燃》

## 基础信息

- **书籍 ID**：`book_战士战技_0121`
- **关联技能**：`ashen_ember_strike`
- **使用效果**：阅读后解锁 `ashen_ember_strike`；若已学会，提升该技能 `current_mastery +120`，并减少该技能首次使用的 `stamina` 消耗 1 点（一次性战斗增益）。
- **阅读要求**：无职业限制；基础 `敏捷 ≥ 8`。
- **稀有度**：精良（Uncommon）
- **建议投放**：余烬祭所、灰烬交界入口营地、战技商人。

## 书籍内容

余烬一击是灰烬交界特有的战技，它要求战士在灰烬覆盖的空气中以极快的摩擦点燃武器表面的余烬。书中描写了一位没有法力的战士如何在灰烬祭所借用地脉残火，让剑刃在斩中敌人的瞬间爆出一蓬灼热的火星。作者提醒，余烬的温度不足以造成大面积烧伤，但能有效地点燃敌人的衣物与绷带，在心理上形成巨大压力。为了安全施展余烬一击，作者建议在武器护手处加装隔热布，并在攻击后立刻甩动武器散热。书中还记录了不同金属在余烬温度下的表现：铁剑最容易点燃但火星较小，陨铁剑则能在斩击中留下更持久的灼痕。末尾有一句灰烬居民的俗语：“火会记住每一把被它吻过的刀。”余烬祭所的看守者会在扉页盖一个火漆印，证明此书已被祝福。

## 设计意图

把灰烬交界的火焰元素引入战士近战，提供无职业限制的跨界战技入口。
