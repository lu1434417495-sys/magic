# 《业火跃：跳进地狱再回来》

## 书籍内容

业火跃是一种把跳跃与火焰爆发结合的高风险战技，使用者起跳时会在脚下点燃一圈火焰，落地时再度引爆。书中警告：第一次练习必须在有水的地方，因为许多人的裤脚会在起跳时被烧着。作者强调空中姿态决定了落地爆炸的方向，身体必须像一支箭头一样笔直，否则火焰会反噬自己。最刺激的一章教人如何在跳跃途中改变落点——通过在空中踢腿或收臂来调整重心。书页有轻微的焦痕，封面上画着一个被火焰包围的人影，姿态像飞鸟又像陨石。末页批注：“跳进地狱不难，难的是记得回来。”下面还有一行较小的字：“其实地狱也不想让你回来。”

## 设计意图

为火系机动战士提供突进爆发技能，强化视觉表现与操作风险。
