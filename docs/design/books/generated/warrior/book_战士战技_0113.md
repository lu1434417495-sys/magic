# 《钢铁韧性：忍痛的极限》

## 书籍内容

这本书不讲如何躲避疼痛，而讲如何在疼痛中继续战斗。作者认为，战士的韧性能否发挥，取决于受伤后的第一个念头。如果第一念头是“我受伤了”，肌肉会本能收缩；如果第一念头是“我还能动”，身体才会继续执行指令。书中提供了一套忍痛训练：在冷水或疲劳状态下完成基本挥砍，让神经系统习惯在不适中保持精确。作者进一步指出，钢铁韧性并非让战士感觉不到痛，而是让疼痛信号延迟抵达大脑。书中介绍了一种古老的呼吸法：在受伤瞬间短促吸气、缓慢呼气，把痛感稀释到下一次行动之后。末尾有一张苦行僧的画像，他满身伤痕却面带微笑，旁边写着：“痛是身体在说话，学会听，但不要被它牵着走。”末尾贴着一张冻得发青的拳头照片，作为苦行训练的纪念。

## 设计意图

提升战士的承伤与状态抗性，让轻伤不会立即削弱战斗输出。
