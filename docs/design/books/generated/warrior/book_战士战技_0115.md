# 《致残打击：废其手足》

## 书籍内容

致残打击是一门残酷的实用学问。作者主张在混战中优先废掉敌人的持械手或支撑腿，这样既能降低自身风险，又能制造后续击杀机会。书中详细讲解了如何判断敌人的惯用手，以及如何瞄准肘后与膝侧等防护薄弱处。作者提醒，致残不是虐杀，而是战术选择；一旦敌人失去战斗力，就应立刻转向下一个目标。作者还在书中讨论了致残打击的道德边界：对野兽与亡灵可以毫无顾忌，但对投降或已经失去战斗力的敌人继续使用则会被同行唾弃。他建议练习者在每次出手前问自己一句：“这一下是为了赢，还是为了爽？”书的最后一页贴着一张褪色的军令，禁止对俘虏使用此技。作者用括弧补充：战争中没有仁慈，但战士可以选择何时停止残忍。

## 设计意图

引入战术性残废打击，让战士在群战中优先瓦解敌人的输出与机动。
