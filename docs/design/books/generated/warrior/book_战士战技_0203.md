# 《顶猎者：站在食物链顶端》

## 基础信息

- **书籍 ID**：`book_战士战技_0203`
- **关联技能**：`warrior_apex_predator`
- **使用效果**：阅读后解锁 `warrior_apex_predator`；若已学会，提升 `current_mastery +170`。
- **阅读要求**：职业标签含 `warrior` 或 `berserker`；基础 `敏捷 ≥ 14` 且 `力量 ≥ 12`。

- **建议投放**：蛮荒猎场、兽王巢穴、高阶赏金任务。

## 书籍内容

猎手凯拉在退休后把毕生追踪心得写成此书，她拒绝承认自己是战士，只说“会杀人的野兽才是好战士”。顶猎者的核心不是快，而是让猎物相信自己更慢。书中教人如何通过脚步节奏误导敌人，如何在三次假动作后让对手产生“他不会从那边来”的错觉，再真正从那边来。凯拉花了整整一章描写呼吸控制：追击时呼吸要浅，出手的瞬间才猛地吐尽。她还在页边画满爪印，标注不同野兽的致命节奏。书的结尾是一句警告：“当你学会顶猎，你也会成为别人的猎物，因为食物链没有顶端，只有下一顿餐。”扉页上还有她用血画的一只独眼，据说是她最后一次狩猎留下的纪念。

## 设计意图

为猎杀型战士设计的高阶突击技能，强调心理欺骗与节奏掌控。
