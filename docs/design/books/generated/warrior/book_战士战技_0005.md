# 《裂甲斩：龟壳粉碎者》

## 书籍内容

这本书的装订用的是一种厚实的兽皮，书脊上有一道明显的砸痕，据说是作者用它挡过一次斧头。内容聚焦一个目标：让举着盾或缩在壳里的敌人露出破绽。作者把破防分成三段：压制、震击、撕裂。压制是用连续攻击让敌人不敢放下盾牌；震击是用剑柄、斧背或战锤头猛击盾面，把震动传到对方手臂；撕裂则是在对方因疼痛或失衡微微抬起盾牌时，从下方或侧面切进去。书中还讨论了不同武器对破防的贡献：战锤最擅长震击，长剑最擅长撕裂，斧头介于两者之间。最后几页被烧掉一半，只剩一句：“别试图砍穿盾牌，让你的敌人自己把盾牌移开。”

封底内侧贴着一张手绘的盾牌结构图，标注了不同材质盾面最容易被震裂的位置。图旁边有一行字："最好的破防不是砸穿盾牌，而是让拿盾牌的人希望他没有拿。"

## 设计意图

强化战士“开口子”的功能型角色定位，为团队输出创造窗口。
