# 《破甲突刺：缝隙寻踪》

## 基础信息

- **书籍 ID**：`book_战士战技_0004`
- **关联技能**：`warrior_piercing_thrust`
- **使用效果**：阅读后解锁 `warrior_piercing_thrust`；若已学会，提升该技能 `current_mastery +100`。
- **阅读要求**：角色职业标签含 `warrior` 或 `knight`；基础 `敏捷 ≥ 7`。
- **稀有度**：普通（Common）
- **建议投放**：长枪教习所、骑士侍从任务、板甲维护商人的收藏。

## 书籍内容

突刺是战士武器库里最诚实也最残酷的招式：它不要求你比敌人快很多，只要求你在对的瞬间比敌人长一寸。这本书从 armor 接缝讲起，列举了七种常见护甲的弱点位置，从板甲腋下的皮革缝隙到链甲肩部的受力死角。作者用“缝隙寻踪”四个字概括整门技艺：先观察敌人呼吸时护甲的轻微移动，再决定突刺角度。书中还强调了步法的重要性——突刺不是把身体送出去，而是把武器送出去，身体留在后面准备回收。后半部分收录了数名老兵的实战笔记，其中一条写道：“最好的突刺看起来像逃跑，直到敌人发现你已经在他胸口。”

某页边缘有干涸的血指印，似乎是前任读者在战场上最后一次翻阅时留下的。那一页正好讲如何在板甲腋下找到缝隙，指印的位置仿佛在为后人示范角度。

初学者常常急于寻找缝隙，却忘了缝隙只有在敌人移动时才会出现；耐心观察，比盲目突刺更重要。

## 设计意图

定位战士单体破甲与精准打击能力，与重击形成“力量vs精准”的互补路线。
