# 《长柄武器：一寸长一寸险》

## 基础信息

- **书籍 ID**：`book_战士战技_0029`
- **关联技能**：`warrior_polearm_mastery`
- **使用效果**：阅读后解锁 `warrior_polearm_mastery`（待新增，标签 `battle_art`）；若已学会，提升该技能 `current_mastery +110`。
- **阅读要求**：基础 `敏捷 ≥ 7`、 `感知 ≥ 6`；职业标签含 `warrior` 或 `knight`。
- **稀有度**：普通（Common）
- **建议投放**：长枪教习所、边境哨塔、民兵训练场。

## 书籍内容

长柄武器是战场上的篱笆：它让敌人无法靠近，但也要求使用者有足够的空间施展。这本书从握距开始教起：前手控制方向，后手控制距离，两手之间的距离决定攻击范围与收回速度。作者强调，长柄武器最忌讳被敌人贴身；一旦敌人进入内圈，长柄反而会成为累赘。因此书中用了整整一章讲解如何用柄部、尾部和步法把敌人推回外圈。后半部分讨论了不同长柄武器的特性：长枪适合突刺和阻止冲锋，戟适合劈砍和钩拉，棍棒适合打乱节奏。每一页都画满了距离标记，提醒读者时刻注意自己和敌人之间的“那几寸”。

书的长度比标准书本长出三分之一，据说也是为了提醒读者距离的重要性。某位骑士侍从在批注里抱怨："它太长，不好携带；但敌人也觉得我的长枪太长，不好躲避。"

长柄武器的使用者要习惯一件事：你的最佳攻击距离，往往也是敌人最不舒服的位置。

## 设计意图

为战士提供长柄武器专精，强化控距与反冲锋能力。
