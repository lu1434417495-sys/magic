# 《涤除玄览章》

## 基础信息

- **书籍 ID**：`book_meditation_0141`
- **关联技能**：`meditation_wash_mysterious`（待新增，标签 `meditation`）
- **使用效果**：阅读后解锁冥想技能 `meditation_wash_mysterious`（`practice_tier = master`）；若已学会，提升 `current_mastery +180`，并使自身每解除一个负面状态，恢复 5% 最大 MP。
- **阅读要求**：无职业限制；已掌握至少两种冥想技能；基础 `智力 ≥ 13` 或 `意志 ≥ 14`。
- **稀有度**：史诗（Epic）
- **建议投放**：清净圣地、老子遗迹、净化类任务奖励。

## 书籍内容

涤除玄览章要求修行者像擦拭一面古老的镜子一样，逐日清除意识上的尘埃。练习者需在冥想中回顾一天中被激怒、被诱惑、被恐惧沾染的瞬间，然后用水流的意象把它们冲洗掉。书中说，玄览是深不可测的观照能力，但它无法穿透厚厚的偏见与情绪垢层。作者设计了一套每日清洗仪式：把每个负面念头 named 后，想象它被溪水带走。最高境界者能在战斗中主动解除自身负面状态时，将原本消耗于对抗的能量回收为 MP。书末有一面铜镜的线描，题词：涤除玄览，能无疵乎。镜子不发光，但它能映出光；心若不染，万物皆可照见。修习此章的角色，每成功清除一个 debuff，都会感到魔力从被洗净的缝隙中回流。

## 设计意图

为净化与自救机制提供 MP 反馈，把老子的涤除玄览与负面状态解除联动，鼓励主动清除 debuff。
