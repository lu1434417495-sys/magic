# 《和光同尘录》

## 基础信息

- **书籍 ID**：`book_meditation_0145`
- **关联技能**：`meditation_harmonize_light_dust`（待新增，标签 `meditation`）
- **使用效果**：阅读后解锁冥想技能 `meditation_harmonize_light_dust`（`practice_tier = master`）；若已学会，提升 `current_mastery +180`，并使自身与盟友相邻时，双方 MP 回复速度均提高 6%。

## 书籍内容

和光同尘录主张修行者不应刻意闪耀，而应混同于尘世之中，像光与尘埃共同存在。练习者需在冥想中降低自己的存在感，同时提高对周围人能量波动的敏感度。书中说，最危险的不是黑暗，而是孤独的光；最温暖的是许多微弱的光彼此映照。在战斗中，修行此术者能让身边的盟友也进入更高效的冥想状态，从而共同回复 MP。作者记载，一支小队因全员修炼此术，在持久战中从未因魔力枯竭而败北。书末有一束阳光穿过尘埃的照片，题词：和其光，同其尘。真正的力量不是独自燃烧，而是让自己成为别人也能借用的光源。修习此录的辅助者，只要站在队友身旁，就能让双方的魔力循环相互催化，回复速度明显提升。

## 设计意图

为团队协同提供 MP 回复光环，把老子的和光同尘转化为组队增益，鼓励紧密站位与配合。
