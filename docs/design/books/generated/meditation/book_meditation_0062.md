# 《旧钟停摆录》

## 基础信息

- **书籍 ID**：`book_meditation_0062`
- **关联技能**：`meditation_stopped_clock`（待新增，标签 `meditation`）

- **建议投放**：废弃钟楼、时间裂隙、古董店密室。

## 书籍内容

旧钟停摆录的发现地是一座齿轮已经全部卡死的钟楼，书就摊开在停摆的钟摆下方。书中提出一个奇异的观点：时间不是流逝的，而是被‘下一刻’拉扯着前进；让钟停摆的方法，是让意识不再期待下一刻。练习者需要坐在任何有钟表的房间里，盯着秒针直到它似乎停住。前半本强调这不是幻觉，而是注意力压缩了主观时间。后半本则警告：停摆太久会被时间遗忘，曾有修行者在钟楼里冥想了三天，出来时城里的日历已经翻过了两周。书末用铅笔画着一个没有指针的钟面，配文：‘当没有指针，就没有迟到。’作者建议初学者先用沙漏练习，因为沙漏的流逝更容易被接受，而钟表的滴答声容易诱发焦虑。时间裂隙附近的居民把此书当作护身符，相信它能让人在异常时间流中保持清醒，避免被卷入过去或未来。

## 设计意图

以‘主观时间控制’为主题，为高端战斗提供控制减免机制，同时暗示游戏世界存在时间异常区域。
