# 《大直若屈录》

## 基础信息

- **书籍 ID**：`book_meditation_0130`
- **关联技能**：`meditation_great_straight_bent`（待新增，标签 `meditation`）
- **使用效果**：阅读后解锁冥想技能 `meditation_great_straight_bent`（`practice_tier = master`）；若已学会，提升 `current_mastery +170`，并使直线攻击或穿刺类技能的射程增加 1 格。
- **阅读要求**：无职业限制；已掌握至少两种冥想技能；基础 `智力 ≥ 12` 或 `意志 ≥ 13`。
- **稀有度**：稀有（Rare）
- **建议投放**：曲直迷宫、老子学派遗址、弓箭手训练场。

## 书籍内容

大直若屈录认为真正笔直的东西看起来像弯曲，因为它懂得绕过障碍而不是撞碎障碍。练习者需在冥想中把直线想象成一条柔软的绳子，它能抵达终点，却不拒绝必要的弧度。书中说，箭矢飞得最远的不是最硬的那支，而是懂得借助风势微微偏转的那支。作者警告，弯曲不是偏离目标，而是让目标在更远的距离上被命中。书末有一张被拉弯的弓图，弓弦却笔直如线，题词：弦直而弓屈，故力能及远。修行者若能接受过程中的退让，最终往往能抵达更直的结果。弓箭手与穿刺法师修习此录后，直线攻击的射程会增加一格，因为他们的意念已经学会了让攻击轨迹像弓弦一样既屈且直，绕过风的阻力抵达更远的目标，敌人往往在被命中后才意识到这一格的差距。这一格的差距，在战棋中往往就是生与死的距离。

## 设计意图

为直线攻击职业提供射程增益，把老子的大直若屈与战棋中的射程机制结合，拓展远程战术空间。
