# 《空心铸剑录》

## 基础信息

- **书籍 ID**：`book_meditation_0095`
- **关联技能**：`meditation_empty_sword`（待新增，标签 `meditation`）

## 书籍内容

空心铸剑录认为，最好的剑不是实心的铁块，而是中空的管道，让使用者的意志从中流过。书中要求练习者在冥想中铸造一柄不存在的剑：先用呼吸加热意识，再用专注力锤打，最后用‘空’来淬火。前半本教授如何把杂念锻打成剑身上的花纹，既美观又不影响剑的强度。后半本则讲述空心剑的危险：如果使用者心中有太多执念，气流会在剑身中发出刺耳的共鸣。书中夹着一张折叠的剑谱，展开后中央是空白的，批注写道：‘最锋利的部分我没画出来，因为它不在纸上。’作者提醒，此法需要同时精通冥想与武器使用，纯粹的法师可能难以发挥。古代剑冢中偶尔能见到按此法铸造的残剑，剑身中空却历经千年不锈，摸上去有微微的暖意。武道大会的冠军奖品有时就是这样一柄残剑。铸剑师秘境中保存着一柄完全按此法铸造的空心长剑。
