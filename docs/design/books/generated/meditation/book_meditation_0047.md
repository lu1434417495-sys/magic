# 《因果线断诀》

## 书籍内容

《因果线断诀》是一本关于解脱执念的极深造诣典籍。书中把人与人之间的纠葛比作无数根看不见的细线，这些线连接着恩怨、期望、债务与情感。作者认为，许多魔力淤堵都源于这些纠缠不清的因果线。修习者需要在深度冥想中观想自己站在一片虚空之中，无数细线从自己身上延伸出去，连接向四面八方。然后，用意识之火逐一审视这些线：哪些是必须承担的，哪些是可以放下的。对于可以放下者，以一次深长的呼气将其斩断。全书警告，斩线不是断绝关系，而是断绝关系中的执着；若带着怨恨斩线，只会形成新的因果。成功修习者会感到一种前所未有的轻盈，仿佛多年的重担被卸下，魔力流动也随之顺畅。

## 设计意图

用因果与执念概念设计一种状态清除型冥想，让玩家在战斗中或战斗后主动断开负面状态的纠缠，提供战略级净化能力。
