# 《无为而无不为书》

## 基础信息

- **书籍 ID**：`book_meditation_0147`
- **关联技能**：`meditation_wu_wei`（待新增，标签 `meditation`）
- **使用效果**：阅读后解锁冥想技能 `meditation_wu_wei`（`practice_tier = legendary`）；若已学会，提升 `current_mastery +200`，并使跳过行动回合时获得一层 MP 与下次伤害加成。
- **阅读要求**：无职业限制；已掌握至少五种冥想技能；基础 `智力 ≥ 15` 或 `意志 ≥ 16`。
- **稀有度**：传说（Legendary）
- **建议投放**：终焉图书馆、无为道观、隐藏传承任务。

## 书籍内容

无为而无不为书认为最高效的行动是不违背事物本性的行动。练习者需在冥想中学会区分哪些事需要用力，哪些事只需要让开。书中说，水从不选择方向，却能抵达最低处；一个好的决策者不是做最多决定的人，而是让正确决定自然发生的人。在战斗中，修行此术者有时会主动跳过回合，不为别的，只为等待最佳时机；而这份等待会转化为 MP 与下一次攻击的势能。作者警告，无为不是懒惰的借口，它需要极其清醒的觉察。书末有一幅空白的棋盘图，题词：无为而无不为，不是不下棋，而是让棋自己下到该下的位置。传说级棋手修习此书后，每一次主动的 pass 都会让下一手更具威力，因为他已经学会了让局势 itself 替他出牌。

## 设计意图

为战棋的 pass/等待机制提供收益，把老子的无为思想转化为战术选择，奖励耐心与时机判断。
