# 《得意忘言录》

## 基础信息

- **书籍 ID**：`book_meditation_0125`
- **关联技能**：`meditation_forget_words`（待新增，标签 `meditation`）

- **建议投放**：语言废墟、静默修道院、高阶法师传承。

## 书籍内容

得意忘言录认为，咒语只是法术的外壳，真正驱动法术的是咒语背后的那一点不可言说之意。练习者需先完整背诵一段咒语，然后在冥想中逐字消去，直到只剩下纯粹的意念。书中说，最高明的法师念咒时嘴唇不动，因为意义已经不需要音节作为桥梁。作者记载，有位法师在失去声音后反而施法更快，因为他终于绕过了语言的弯路。书末有一页被墨水涂黑的纸，黑墨之下隐约透出几个字，无法辨认，注释写道：当你能看见字后面的东西，字就可以扔掉了。得意忘言不是反对语言，而是不再被语言囚禁。精通此录的法师，咏唱时间明显缩短，因为他们的咒语已经从音节序列升华为直接的心意传递，张口之前法术已经成形，敌人往往来不及反应便已中招。当咒语彻底消失后，法师与魔法之间便只剩下最纯粹的约定。

## 设计意图

为施法速度提供增益，尤其适合需要吟唱的强力法术，与得意忘言录形成工具超越主题的姊妹篇。
