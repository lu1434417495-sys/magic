# 《将欲歙之录》

## 基础信息

- **书籍 ID**：`book_meditation_0135`
- **关联技能**：`meditation_about_to_contract`（待新增，标签 `meditation`）

- **建议投放**：老子遗迹、蓄力战士训练场、风箱工坊。

## 书籍内容

将欲歙之录取老子将欲歙之必固张之之意，讲述收缩与扩张的辩证法。练习者需在冥想中体验一种奇怪的呼吸：先极力扩张胸腔，然后允许它自然回弹。书中说，任何强力的释放之前都必须有一次更深的收敛，蓄力被打断并不可怕，可怕的是在扩张时失去回弹的能力。作者设计了一套能量保持练习，让修行者在蓄力被外力中断时仍保留部分势能。书末有一只古老风箱的剖面图，旁边写着：张是为了歙，歙是为了更猛地张。掌握这个节奏的人，即使在被打断的瞬间也不会一无所获。修习此录的战士，蓄力类技能若被敌人打断，已积蓄的能量会有相当一部分保留下来，等待下一次更猛烈的释放。

## 设计意图

为蓄力型技能提供打断保护，把老子的张歙辩证转化为战斗节奏保障，适合重击与爆发流派。
