# 《万法归冥书》

## 基础信息

- **书籍 ID**：`book_meditation_0100`
- **关联技能**：`meditation_all_laws_darkness`（待新增，标签 `meditation`）
- **使用效果**：阅读后解锁冥想技能 `meditation_all_laws_darkness`（`practice_tier = legendary`）；若已学会，提升 `current_mastery +200`，并解锁 `MP` 资源链的终极分支 `mp_resonance_dark`。
- **阅读要求**：无职业限制；已掌握至少六种冥想技能；基础 `智力 ≥ 15` 且 `意志 ≥ 15`。
- **稀有度**：传说（Legendary）
- **建议投放**：终焉图书馆、世界 BOSS 掉落、隐藏传承任务。

## 书籍内容

万法归冥书是冥想系列的至高典籍，它没有封面，因为封面就是最后一页。书中说，所有法术、所有呼吸、所有星辰最终都会归于一种原始的黑暗，那不是虚无，而是所有可能性尚未分化之前的静谧。练习者需要依次回顾自己曾经学过的每一种冥想，然后在意识中让它们逐一熄灭，像把蜡烛吹灭，直到只剩下黑暗本身。作者强调，这不是否定之前的修行，而是让它们回归本源。书中没有具体的动作指导，只有七十二个冥想名称排列成螺旋，每个名字后面都写着同一个字：‘冥’。最后一页是空白的，但据说在绝对黑暗中能看出淡淡的纹路。有人曾声称那些纹路是一张地图，但没有人能复制出来。终焉图书馆的管理员说，此书从未被真正读完，因为读到最后一页的人都已经不再需要文字，他们会把书轻轻放回架顶。

## 设计意图

作为冥想系列的顶点，承担解锁 MP 终极资源链的职责，为深度投入冥想系统的玩家提供标志性的成长终点。
