# 《含德之厚诀》

## 基础信息

- **书籍 ID**：`book_meditation_0139`
- **关联技能**：`meditation_holding_virtue`（待新增，标签 `meditation`）
- **使用效果**：阅读后解锁冥想技能 `meditation_holding_virtue`（`practice_tier = master`）；若已学会，提升 `current_mastery +180`，并使自身每持有一个正面 buff，MP 上限临时提高 2%。
- **阅读要求**：无职业限制；已掌握至少三种冥想技能；基础 `智力 ≥ 13` 且 `意志 ≥ 13`。
- **稀有度**：史诗（Epic）
- **建议投放**：道德圣地、老子遗迹、团队辅助试炼。

## 书籍内容

含德之厚诀认为，德行深厚的人像初生的婴儿，全身柔软却能紧握拳头。练习者需在冥想中回顾自己曾经做出的善意选择，把这些选择凝聚为一种内在的力量。书中说，每一次不图回报的帮助都会在身体里留下一层温润的光泽，当光泽足够厚时，buff 与祝福便成了身体的自然延伸。作者警告，此术不能通过假装善良获得，系统会识别意图的纯度。书末有一张婴儿握拳的素描，题词：含德之厚，比于赤子。真正的增益不是外界赐予，而是内在德性满溢后的自然外显。辅助型角色修习此诀后，身上每多一个正面 buff，MP 上限就会临时增加，仿佛德行丰厚者天然拥有更宽广的魔力容器，能够承载更多的祝福而不感到沉重，团队也因此受益良多。含德之厚诀在辅助者之间流传甚广，因为它让善良变成了一种可以量化的战斗力。

## 设计意图

为 buff 堆叠型 build 提供 MP 上限成长，把老子的厚德思想与正面状态机制结合，鼓励善行或团队配合。
