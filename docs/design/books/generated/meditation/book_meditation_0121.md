# 《白驹过隙章》

## 基础信息

- **书籍 ID**：`book_meditation_0121`
- **关联技能**：`meditation_white_horse_gap`（待新增，标签 `meditation`）
- **使用效果**：阅读后解锁冥想技能 `meditation_white_horse_gap`（`practice_tier = master`）；若已学会，提升 `current_mastery +170`，并使闪避或位移类技能的冷却时间减少 1 回合。
- **阅读要求**：无职业限制；已掌握任意进阶冥想；基础 `敏捷 ≥ 13` 或 `意志 ≥ 13`。

- **建议投放**：时间裂隙、白马遗迹、速度试炼奖励。

## 书籍内容

白驹过隙章把时间比作白色骏马穿过缝隙的瞬间，认为速度的本质不是快，而是对瞬息空隙的精确利用。练习者需在冥想中反复体验一次呼吸从开始到结束的完整过程，然后逐渐把感知压缩到更短的时间段。书中说，当练习者能在一次心跳内完成一次完整的意识收放，外界的动作在他眼中就会变慢。作者警告，此术不宜连续使用，过度压缩感知会导致现实感模糊。书末有一幅白马跃过石缝的速写，旁边写着：缝隙不是障碍，而是通道。白驹之所以快，不是因为它有力，而是因为它从不怀疑缝隙够不够宽。刺客与游侠修习此章后，闪避与位移的间隔会缩短，因为他们已经学会了在敌人眨眼的缝隙里完成自己的移动。

## 设计意图

为敏捷型角色提供位移与闪避冷却缩减，把庄子的时间感悟转化为战棋中的行动频率优势。
