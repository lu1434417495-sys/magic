# 《燃犀照夜录》

## 书籍内容

燃犀照夜录的名字来自一种传说中的兽角，点燃后能照见黑暗中的真相。书中要求练习者在绝对黑暗中冥想，想象自己的眉心有一支微微燃烧的犀角，光芒不向外扩散，只照亮自己前方一步之遥。前半本教授如何在黑暗中不依赖视觉而保持方向感，把恐惧转化为警觉。后半本则警告：光照见的真相往往比黑暗更可怕，修行者必须学会在看见之后保持不动。书中夹着一小块焦黑的角质碎片，不知是真是假，批注写道：‘它烧了三夜，照见了我床底的灰尘和心里的嫉妒。’作者建议初学者在安全的黑暗房间练习，不要在野外独自尝试，因为真正的黑暗里有东西会被火光吸引。古墓探险队把此书当作必备手册，因为墓穴中的隐形守卫对火光极为敏感，而此法的光芒只有修行者自己能看见。

## 设计意图

以‘破暗视物’为主题提供感知增益，服务于探索、潜行对抗与夜间战斗，拓展冥想的非战斗价值。
