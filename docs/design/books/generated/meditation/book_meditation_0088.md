# 《残像留守诀》

## 书籍内容

残像留守诀要求练习者在快速移动后突然静止，让意识停留在移动结束前的最后一个姿势。书中说，身体可以停下，但‘身体的印象’可以在空气中多停留一瞬。前半本教授如何在静止中保留运动的余韵，从手指到眼神都要像还在移动。后半本则讲述残像的危险：如果意识也残留在过去，真正的身体就会成为空壳。书中夹着一张模糊的照片，似乎拍到了两个重叠的人影，批注写道：‘左边是我，右边是我以为我还在的地方。’作者警告，此法需要极强的身体控制，肌肉劳损者不宜强行练习。影舞者训练场的毕业测试就是连续留下三个残像，让导师攻击错误的目标。据说最优秀的毕业生能让残像自己做出防御动作，而本体早已退到十步之外。真正的影舞者能让敌人在攻击残像后产生一瞬间的困惑。

## 设计意图

以‘残像’机制提供战斗中的误导与生存机会，适合高敏捷或幻象主题的角色构建。
