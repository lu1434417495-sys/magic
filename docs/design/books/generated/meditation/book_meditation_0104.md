# 《坐忘心斋录》

## 基础信息

- **书籍 ID**：`book_meditation_0104`
- **关联技能**：`meditation_sit_forget`（待新增，标签 `meditation`）
- **使用效果**：阅读后解锁冥想技能 `meditation_sit_forget`（`practice_tier = master`）；若已学会，提升 `current_mastery +180`，并使每次战斗开始时额外恢复 10% 最大 MP。
- **阅读要求**：无职业限制；已掌握至少三种冥想技能；基础 `意志 ≥ 15`。
- **稀有度**：史诗（Epic）
- **建议投放**：古道观遗址、心斋传承任务、沉钟书库顶层。

## 书籍内容

坐忘心斋录开篇即问：你能忘记自己正在忘记吗？书中把修行分为四阶：忘身、忘物、忘念、忘忘。最后一阶最难，因为一旦觉得自己已经忘了，便又记了起来。练习者需每日静坐，从忘掉脚趾的酸痛开始，逐步扩展到忘掉身份、记忆、甚至对冥想的执念。作者记载，有位老修行者在忘忘阶段坐了三日，醒来时发现自己把母语也忘了七成，花了三个月才重新学会说话。书中夹着一张泛黄的纸条，是后人补注：不要把坐忘当作逃避，它是为了让杯中的旧茶倒掉，好承接新的雨水。心斋不是空无一物，而是对所有到来之物说，请进，但不必久留。战前若能静坐片刻，修行者便能以充盈的 MP 迎接第一场交锋，仿佛整夜的睡眠都浓缩在了这短短几分钟里。

## 设计意图

强化冥想作为战前准备资源的作用，用庄子的坐忘概念包装，为投入多条冥想线的玩家提供开场 MP 优势。
