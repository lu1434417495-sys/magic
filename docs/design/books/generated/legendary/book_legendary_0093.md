# 《禁术：梦魇编织》

## 基础信息

- **书籍 ID**：`book_legendary_0093`
- **关联技能**：`legendary_nightmare_weave`
- **使用效果**：阅读后解锁 `legendary_nightmare_weave`；若已学会，提升 `current_mastery +160`，并允许将敌人的恐惧实体化为梦魇攻击其盟友。
- **阅读要求**：角色职业标签含 `warlock` 或 `mage`；基础 `智力 ≥ 16`、意志 `≥ 14`。
- **稀有度**：传说（Legendary）
- **建议投放**：梦魇王座、梦境商人、恐惧任务奖励、传说级宝箱。

## 书籍内容

梦魇编织是一本把噩梦从脑子里拉出来的书。书中记载，每个人最害怕的东西都沉睡在意识的深处，而施术者可以像抽丝一样把它抽出来，纺成一匹有形的黑布。那匹布会在敌人眼前变成他们最恐惧的形象，然后扑向离他们最近的人。古籍警告，抽出的噩梦不会完全听话，有时会反过来缠绕施术者。许多页面的边角画满了扭曲的笑脸，似乎那些噩梦在书被合上后仍在纸上蠕动。

梦魇编织抽出的噩梦若没有被及时释放，会在施术者枕边凝结成实体。许多初学者在第一次成功后不敢入睡，因为那些黑色的布条就挂在床帐上，像一件未完成的婚纱。

梦魇编织抽出的噩梦若被释放到城市里，会引发短暂的群体性恐慌。最著名的一次事件让整座城市熄灯三日，无人敢入睡。

经历过那次事件的城市至今保留着熄灯三日的传统，以纪念那场由噩梦引发的恐慌。

## 设计意图

提供恐惧利用型控制，将敌方心理状态转化为实际战场压力。
