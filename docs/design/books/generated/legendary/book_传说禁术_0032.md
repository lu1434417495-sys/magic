# 《血肉魔像》

## 基础信息

- **书籍 ID**：`book_传说禁术_0032`
- **关联技能**：`legendary_flesh_golem`
- **使用效果**：阅读后解锁 `legendary_flesh_golem`；若已学会，提升 `current_mastery +170`，并在下一次战斗中让魔像继承主人 20% 额外属性。
- **阅读要求**：角色职业标签含 `warlock` 或 `necromancer`；基础 `体质 ≥ 14`、智力 `≥ 12`。
- **稀有度**：传说（Legendary）
- **建议投放**：亡灵实验室、血肉工坊、禁忌召唤师营地、恶魔契约任务。

## 书籍内容

以自身血肉为材料召唤傀儡的禁术。书中记载，施术者割下一块皮肤或肌肉，注入意志后即可化作临时战斗傀儡。魔像会模仿主人的攻击，但存在时间越长，对主人身体的渴求越强。作者警告，不要在魔像耳边低语，它会把你的声音当成食物。书中夹着一张皱巴巴的画像，画中人缺少了一只耳朵。

血肉魔像的意志来自主人的一小块指骨，因此魔像永远不会真正背叛，却会不断索要更多。每一具魔像最终都会试图回到主人身边。

血肉魔像最终都会试图吞回主人的缺失部分，直到两者再次合二为一。

血肉魔像最终回到主人身边时，会首先寻找缺失的耳朵或手指，若找不到，便会开始啃食主人其他部位。

啃食从指尖开始，因为魔像最先记得的是那块骨头。

魔像低声呢喃。

代价极高。

切记。

血肉工坊的学徒入门第一课便是辨认魔像的饥饿眼神，一旦那眼神与主人相同，就必须立即焚毁。

## 设计意图

为术士/死灵系提供自残召唤物，强调血肉与声音的诡异代价。
