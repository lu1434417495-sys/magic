# 《禁术：霜狱囚笼》

- **书籍 ID**：`book_legendary_0075`
- **关联技能**：`legendary_frost_hell_cage`

## 书籍内容

霜狱囚笼是一本关于如何把温暖夺走的书。书中记载，极寒并非温度的低处，而是一种「存在拒绝运动」的状态。施术者需将周围的空气想象成一面面静止的墙，让水分在瞬息间凝结成无数细小的牢笼。被困者不会立刻冻死，但会越来越慢，直到连思维都被冻结。古籍警告，施术者自身也会受到低温侵蚀，若在囚笼中停留过久，自己的血液同样会结冰。书页边缘结着一层薄薄的白霜，翻书时手指会被粘住一瞬。

霜狱囚笼的中心温度理论上可达绝对零度，但古籍警告不要真正达到那个极限。曾有法师尝试，结果囚笼连同自己一起碎裂成无数静止的碎片，至今仍漂浮在遗址上空。

霜狱囚笼的遗址至今仍保持着极低温度，成为天然的冷藏库。冒险者常去那里保存食物，但无人敢在遗址中心停留超过一分钟。

## 设计意图

提供范围控制与减速领域，改变敌我机动性对比，适合阵地战。
