# 《禁术：死亡彩排》

## 基础信息

- **书籍 ID**：`book_legendary_0094`
- **关联技能**：`legendary_death_rehearsal`
- **使用效果**：阅读后解锁 `legendary_death_rehearsal`；若已学会，提升 `current_mastery +150`，并允许预演死亡，自动回避一次致命伤害并在原地留下残影。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `敏捷 ≥ 17`、感知 `≥ 14`。
- **稀有度**：传说（Legendary）
- **建议投放**：死神剧场、命运商人、暗杀任务奖励、传说级宝箱。

## 书籍内容

死亡彩排是一本教人先死一次的书。书中说，大多数人是被死亡突然袭击，而真正的行家会提前在想象中经历它，让真正的死亡找不到第一次。修习者需在战斗前闭眼想象自己最可能的死法——被斩首、被穿刺、被焚烧——然后在意识中一遍遍重复，直到那画面变得像旧戏一样熟悉。当真正的致命攻击来临时，身体会自动按照彩排好的方式闪开，只留下一个残影承受伤害。古籍警告，彩排太多次的人会对生存失去新鲜感。

死亡彩排的残影会保留施术者受击前的表情，有人专门收藏这些残影的画像。最昂贵的一幅描绘了一位刺客在最后一刻露出的微笑，买家称那是对死亡最优雅的嘲讽。

死亡彩排的残影数量过多时，会在原地形成一个模糊的人形轮廓。那轮廓被称为「未死者」，据说会向路人借火点烟。

## 设计意图

为刺客/盗贼提供一次致命闪避，强化高风险高机动的职业特性。
