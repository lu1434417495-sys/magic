# 《禁术：魔力暴走》

## 基础信息

- **书籍 ID**：`book_传说禁术_0045`
- **关联技能**：`legendary_mana_rampage`
- **使用效果**：阅读后解锁 `legendary_mana_rampage`；若已学会，提升 `current_mastery +190`，并在下一次战斗中让魔力暴走触发高阶法术的概率提升 15%。
- **阅读要求**：角色职业标签含 `mage` 或 `sorcerer`；基础 `智力 ≥ 16`、意志 `≥ 10`。
- **稀有度**：传说（Legendary）
- **建议投放**：暴走法师塔、元素裂隙、禁忌实验室、传说宝箱。

## 书籍内容

强行引爆体内所有魔力的禁术。书中描述，施术者可以放弃控制，让魔力以随机法术的形式倾泻而出。效果极其强大且无法预测，可能召唤陨石也可能治疗敌人。使用后 MP 清空并进入虚弱状态。作者强调，只有真正走投无路时才应使用。书页上满是烧焦和冻裂的痕迹，显示出无数次失控。

魔力暴走的失控记录填满半本书，每一页都记载着不同的灾难形状。作者建议使用时心中默念一个名字，这样即使失控，也能知道是为了什么。

魔力暴走的书中夹有一张未完成的遗书，署名处只画了一个颤抖的问号。

魔力暴走的遗书问号会在每次失控后变淡一分，当问号完全消失时，使用者将彻底忘记自己为何拿起这本书。

问号消失时书页空白，仿佛这本书从未被任何人写过。

问号是遗言。

勿忘。

## 设计意图

为法师提供极端随机爆发，以清空资源与虚弱作为终极赌博。
