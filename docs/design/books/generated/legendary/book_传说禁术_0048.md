# 《天罚箭》

- **关联技能**：`legendary_heaven_punishment_arrow`

## 书籍内容

以天雷为箭的弓手禁术。书中描述，射手需在雷暴中将箭矢高举过头，引导雷电附着于箭身。射出时，天罚箭会带着神明的愤怒贯穿敌人，造成巨大的雷电伤害。若未命中，雷电可能反噬射手。作者警告，心怀愧疚者无法引下天雷。书中夹着一根焦黑的箭杆，杆身还残留着微弱的电流。

天罚箭的箭杆必须用被雷劈过的树木制成，否则无法承载神罚。引雷时心中若有杂念，雷电会顺着箭杆直接窜入射手心脏。

天罚箭的焦黑箭杆若被重新削尖，会引来比上次更猛烈的雷电复仇。

天罚箭的焦黑箭杆若被埋入土中，会在雷雨天重新发芽，长出带有微弱电流的黑色树苗，成为下一个射手的目标。

树苗生长时雷声不断，那是天罚箭尚未释放的余怒。

雷电树苗生长时，会呼唤下一次风暴。

代价沉重。

雷神祭坛的守箭人会在每道雷雨后收集黑色树苗，移植到祭坛周围作为下一次天罚的引信。

## 设计意图

为弓箭手提供高伤雷电射击，以命中与反噬强化仪式感。
