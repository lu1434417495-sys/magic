# 《黑潮呼吸》

## 基础信息

- **书籍 ID**：`book_传说禁术_0017`
- **关联技能**：`legendary_black_tide_breath`
- **使用效果**：阅读后学会冥想技能 `legendary_black_tide_breath`（`practice_tier = legendary`），战斗中 MP 恢复速度提升 40%，但全元素抗性下降 15%（持续到战斗结束）。
- **阅读要求**：无职业限制；基础 `智力 ≥ 14` 或 `意志 ≥ 14`；已学会任意中级冥想。
- **稀有度**：传说（Legendary）
- **建议投放**：深海裂缝神殿、沉船图书馆、潮汐遗迹、黑潮隐士据点。

## 书籍内容

源自深海裂缝的冥想禁法。书中将 MP 比作潮水，而黑潮是潮水下被污染的部分。修习者通过特定呼吸节奏，可以引动黑潮快速补充魔力，但身体会被寒湿侵蚀，魔法抗性暂时下降。作者建议在雷雨天不要练习，因为黑潮会被闪电吸引上岸。书页潮湿柔软，像刚从海里捞出。封底画着一只半闭的眼睛，据说那是黑潮的源头。

黑潮呼吸的抄本长期保存在海水中，取出后仍会滴水数日。修习者若在梦中看见那只半闭的眼睛完全睁开，便再也不能回到陆地。

黑潮呼吸修习者的枕头常会莫名潮湿，梦中听见潮水在房间角落拍打。

黑潮呼吸的修习者若在无月之夜入梦，会发现自己漂浮在一只巨大眼睛的瞳孔中央，无法靠岸。

漂浮者最终放弃挣扎，任由黑潮将自己拖向更深处。

梦境冰冷刺骨。

沿海渔村至今流传着黑潮者的传说，说他们的瞳孔会在雷雨后变成深海般的墨蓝色。

## 设计意图

为法系提供战斗内高回蓝路线，用抗性惩罚制造明显 trade-off。
