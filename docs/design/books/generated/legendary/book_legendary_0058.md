# 《禁术：缄默法则》

## 基础信息

- **书籍 ID**：`book_legendary_0058`
- **关联技能**：`legendary_silence_law`
- **使用效果**：阅读后解锁 `legendary_silence_law`；若已学会，提升 `current_mastery +150`，并在下一次战斗中释放一次大范围法术静默，持续 5 秒。
- **阅读要求**：角色职业标签含 `mage` 或 `priest`；基础 `智力 ≥ 16`、意志 `≥ 14`。
- **稀有度**：传说（Legendary）
- **建议投放**：沉默图书馆、法则研究者、反法师任务奖励、传说级宝箱。

## 书籍内容

缄默法则是一条被写下来的禁令。书中没有咒语，只有一段反复修改的律文，核心意思是：「在这片区域内，言语不得成为力量的通道。」施术者将律文念完的瞬间，周围的一切法术都会像被掐住喉咙一样中断，魔力的流动被迫停滞，咒语的音节在空气中碎裂成无意义的响声。作者警告，缄默法则对施术者自己同样有效——在法则生效期间，你无法施展任何法术，只能依靠武器与肉体。书页上留有许多被涂改的痕迹，似乎每一代读者都在试图把「自己」排除在法则之外。

缄默法则的律文共有九十九个版本，每一版都比前一版多一句例外条款。最老的版本只剩半页，上面只有一句话：「唯一的例外，就是法则本身。」

有人声称找到了第一百版律文，但那一版只有一句话被反复书写：「闭嘴。」每一个「闭嘴」都比前一个大一号，直到填满整页。

## 设计意图

提供战术性反制手段，在法师对战中创造窗口期，改变资源消耗节奏。
