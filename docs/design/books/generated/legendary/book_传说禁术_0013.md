# 《破界斩》

## 基础信息

- **书籍 ID**：`book_传说禁术_0013`
- **关联技能**：`legendary_realm_slash`
- **使用效果**：阅读后解锁 `legendary_realm_slash`；若已学会，提升 `current_mastery +180`，并在下一次战斗中使首次破界斩无视目标护盾。
- **阅读要求**：角色职业标签含 `warrior` 或 `swordmaster`；基础 `力量 ≥ 16`、敏捷 `≥ 12`。
- **稀有度**：传说（Legendary）
- **建议投放**：剑冢禁地、异界裂缝战场、无名剑圣遗骸、传说武器任务。

## 书籍内容

战士禁剑，一剑斩开现实的边界。书中记载，真正的斩击不应停留在铠甲上，而应切穿敌人背后的空间。练习者需在瀑布下挥剑十万次，直到水珠不再沾身。成功后，普通盾牌在破界斩面前形同虚设。副作用是剑身会逐渐变轻，最终轻得像不存在，使用者会开始怀疑自己的手是否真实。书脊处有一道贯穿全书的切痕。末尾写道："界破了，人就回不来了。"

破界斩的修习地必须选在瀑布与悬崖之间，因为水雾能帮助辨识空间的褶皱。剑圣留下的最后一块试剑石已被切成两半，切面光滑如镜。

破界斩的试剑石切面能映照出另一片战场，有人声称看见了未来的自己。

破界斩的剑谱每一代只传一页，完整剑法需要集齐九位不同流派剑士手中的残页。

集齐残页者寥寥，多数人终生只掌握破界斩的半式。

## 设计意图

为高阶战士提供破盾与存在性叙事兼具的招牌斩击。
