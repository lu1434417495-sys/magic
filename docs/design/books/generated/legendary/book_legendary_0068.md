# 《禁术：逆鳞诀》

## 书籍内容

逆鳞诀是一本从龙族遗骨上拓印下来的战技书。书中说，龙有逆鳞，触之必怒，而人类若想习得这份愤怒，就必须先学会让自己受伤。修习者需在战斗中主动承受攻击，让每一次伤口都成为怒火的一部分。伤势越重，反击越狠，直至最后一击能撕裂钢铁。古籍警告，逆鳞的愤怒会模糊理智，许多战士在掌握这门技艺后，再也无法忍受任何挑衅。书页上残留着一片半透明的鳞片，摸起来滚烫，似乎仍在等待被触碰。

逆鳞诀修习者的血液会逐渐变得浑浊，像龙血一样在高温下蒸发成金色雾气。医者常误以为这是重病，只有极少数人知道那是龙怒在血管里沉淀。

逆鳞诀修习到深处，怒吼时会发出类似龙吟的低频震动，玻璃会碎裂，马匹会惊慌，甚至远处的山峰会传来隐约的回响。

龙族长老们将这本书列为最高级别的禁物，认为它亵渎了龙血的纯粹。
