# 《禁术：封魔刻印》

## 基础信息

- **书籍 ID**：`book_legendary_0090`
- **关联技能**：`legendary_magic_seal_brand`
- **使用效果**：阅读后解锁 `legendary_magic_seal_brand`；若已学会，提升 `current_mastery +160`，并允许在敌人身上刻下封魔印记，使其 5 秒内无法获得 MP/AURA。
- **阅读要求**：角色职业标签含 `mage` 或 `rogue`；基础 `智力 ≥ 15`、敏捷 `≥ 13`。
- **稀有度**：传说（Legendary）
- **建议投放**：封魔塔、猎魔商人、禁魔任务奖励、传说级宝箱。

## 书籍内容

封魔刻印是一本教人如何在敌人身上画句号的书。书中说，施法者的力量来自于他们与资源的连接，而刻印的作用就是在那根连接上烧出一个断点。施术者需以血为墨，在敌人暴露的皮肤上画出一枚 inverted triangle，那枚印记会在数秒内持续灼烧，切断敌人从环境中汲取 MP 或 AURA 的路径。古籍警告，画印的人也会被印记住，许多封魔师自己的魔力流动变得越来越迟缓。书页上有一枚反复拓印的三角形图案，边缘已经被血染成了深褐色。

封魔刻印的三角形在不同敌人身上会呈现不同颜色，魔法师为蓝，修炼者为红，信仰者为金。一名大师级的封魔师仅凭颜色就能判断敌人的力量来源。

封魔刻印的三角形若画在自己身上，可以暂时封印自己的魔力波动，躲避追踪。但这也会让施术者在短时间内无法感知任何资源。

## 设计意图

提供资源封锁型 debuff，针对法师/修炼者敌人的续航进行压制。
