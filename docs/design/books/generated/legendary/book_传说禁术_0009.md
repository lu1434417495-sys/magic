# 《禁术：时滞领域》

## 基础信息

- **书籍 ID**：`book_传说禁术_0009`
- **关联技能**：`legendary_temporal_stasis_field`
- **使用效果**：阅读后解锁 `legendary_temporal_stasis_field`；若已学会，提升 `current_mastery +180`，并减少该技能对自身衰老副作用 1 层。
- **阅读要求**：角色职业标签含 `mage` 或 `chrono_mage`；基础 `智力 ≥ 16`、意志 `≥ 14`。
- **稀有度**：传说（Legendary）
- **建议投放**：时间裂隙图书馆、钟表匠公会禁室、失落时计塔、传说任务奖励。

## 书籍内容

操控战场时间流速的禁忌。书中解释，时间不是河流而是织物，施术者可以抓住某一格并将其反复折叠。领域内敌人的动作会变得极慢，而施术者自身也会付出衰老的代价。每次使用后，头发会多出一缕灰白。作者附有一张自己年轻时的画像，画像旁是满是皱纹的手迹。书末警告：不要对同一个人连续使用三次，否则会把他从时间里彻底洗掉。

此书的时间印记错乱，封面有时显得崭新，有时却腐朽如千年古物。阅读者常在翻页时发现某些段落已经提前被未来自己批注。

时滞领域的研习者常会在镜子中看见自己以不同速度动作，那是被折叠的时间在抗议。

时滞领域的研究笔记末尾附有一面碎裂镜子，碎片中偶尔能看见不属于这个时代的街景。

街景中人影匆匆，却从未有人注意到镜子这边的窥视者。

## 设计意图

作为时间系禁术入口，用可累积的衰老代价制衡强力控场效果。
