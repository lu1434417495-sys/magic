# 《冥河咒》

## 书籍内容

召唤冥河之水的诅咒。书中描述，施术者在地面上撕开一条裂缝，让冥河的水流涌出。被水流触碰的敌人会陷入迟缓与虚弱，同时持续流失生命。河水也会侵蚀施术者的影子，使其逐渐变短。作者警告，不要让河水碰到自己的倒影，否则倒影会先一步溺亡。书中夹着一片黑色的水藻，触之冰凉。

冥河咒的裂缝必须在河边或沼泽绘制，否则涌出的只是普通黑水。被冥河触碰过的影子会逐渐变浅，直至完全消失。

冥河咒的黑色水藻若被栽种，会生长出与施术者倒影相似的细小叶片。

冥河咒的水藻若被放在月光下，会在午夜生长出细小的手臂，向着施术者的方向缓慢攀爬，直到被重新放回水中。

水藻手臂渴望回到水中，它们会在黎明前自行缩回。

倒影溺亡无声，水面却不再平静。

可怕。

难逃。

## 设计意图

为死灵/术士系提供场地控制 DoT，用影子侵蚀制造代价感。
