# 《虚无之触》

## 基础信息

- **书籍 ID**：`book_传说禁术_0033`
- **关联技能**：`legendary_void_touch`
- **使用效果**：阅读后解锁 `legendary_void_touch`；若已学会，提升 `current_mastery +180`，并在下一次战斗中让虚无之触命中后附加 1 层"存在剥离"易伤。
- **阅读要求**：角色职业标签含 `mage` 或 `warlock`；基础 `智力 ≥ 16`、意志 `≥ 12`。
- **稀有度**：传说（Legendary）
- **建议投放**：虚空裂缝、湮灭神殿、禁忌法师塔、世界尽头遗迹。

## 书籍内容

让物质化为虚无的禁术。书中描述，施术者的指尖会短暂变成通往虚无的裂口，触碰到的物体会被擦除存在。该术对敌我皆有效，且使用后会暂时失去触觉。作者强调，虚无不喜欢被频繁打扰，连续使用会让手指逐渐透明。书页上有一处空白，像是被手指按过。末页写道："摸到什么，就失去什么。"

虚无之触的练习对象通常是沙堆或落叶，因为有机生命会留下无法愈合的缺口。作者的手指在写完书后已变得半透明，字迹却越发清晰。

虚无之触作者的透明手指据说仍能翻动书页，只是肉眼已无法看见。

虚无之触的原稿上有一处永远无法填补的空白，那是作者在写完最后一个字时，用手指将自己名字从现实中擦除后留下的缺口。

空白页至今仍在扩大，像是有无形的手指还在书写。

空白持续吞噬。

## 设计意图

为法师提供高阶单体消除/易伤，用感官剥夺限制滥用。
