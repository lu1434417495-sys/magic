# 《影噬步》

## 基础信息

- **书籍 ID**：`book_传说禁术_0004`
- **关联技能**：`legendary_shadow_devour_step`
- **使用效果**：阅读后解锁 `legendary_shadow_devour_step`；若已学会，提升 `current_mastery +170`，并延长下一次战斗中影噬步的无敌帧 0.15 秒。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `敏捷 ≥ 15`、感知 `≥ 10`。
- **稀有度**：传说（Legendary）
- **建议投放**：影之集市、暗杀公会密室、盗贼传说任务、深渊宝箱。

## 书籍内容

盗贼的禁步，在阴影中啃食现实。书中说，暗影不是缺失的光，而是另一种饥饿的物质。施术者要学会把身体的一部分暂时交给影子保管，从而实现短距离瞬移。每次使用都会让影子多占据身体一分，最终有人会永远留在影子里。作者详细记录了七种"还身"仪式，但第七条被撕掉了。书脊渗出黑色黏液，触碰后指尖会短暂失去触感。末页以潦草笔迹警告："别在没光的地方使用，影子会不想还你。"

书中夹着半张手绘地图，标注了城市中所有“影子断裂处”——那些阳光与阴影交界极不稳定的地方。旧主人用颤抖的笔迹标注：“不要在断裂处停留超过三次心跳。”

影噬步的旧抄本总在午夜自动翻到第七页，仿佛被撕掉的那条仪式在寻找归还者。

城卫曾三次试图销毁此书，每次焚烧后书脊都会重新渗出新墨。

## 设计意图

强化盗贼/暗杀者的高机动与代价并存的定位，为极限闪避提供传说级选择。
