# 《穿云禁射》

## 基础信息

- **书籍 ID**：`book_传说禁术_0042`
- **关联技能**：`legendary_cloud_piercing_shot`
- **使用效果**：阅读后解锁 `legendary_cloud_piercing_shot`；若已学会，提升 `current_mastery +180`，并在下一次战斗中让穿云禁射的射程额外 +2 格。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；基础 `感知 ≥ 16`、力量 `≥ 12`。
- **稀有度**：传说（Legendary）
- **建议投放**：风暴之巅、云中国度遗迹、游侠宗师任务、雷霆宝箱。

## 书籍内容

射穿云层、直击天际敌人的超远程箭术。书中描述，射手需在风暴来临前引弓，将雷电之力积蓄在箭矢上。射出后，箭会穿透一切遮蔽，命中视野边缘的目标。代价是射手的手臂会在射击后短暂麻痹。作者提醒，雷电不认主人，若云层中已有雷兽游弋，箭可能会把雷兽引下来。书页上画着一道贯穿云层的亮线。

穿云禁射必须在雷暴将至未至时引弓，太早雷电会散，太晚则会被雷兽察觉。老射手的手臂上常留有一道闪电状疤痕作为徽章。

穿云禁射的闪电疤痕会在雷暴前发痒，提醒射手下一次风暴即将来临。

穿云禁射的老射手死后，他的闪电疤痕会发出微光，指引后辈找到下一次雷暴将至的山巅。

后辈循光登上山巅，在雷暴将至时继承那道闪电疤痕。

雷兽循箭而至。

戒之。

致命。

戒。

切记。

风暴之巅的岩石上刻满了闪电疤痕，那是历代射手在雷兽注视下留下的最后印记。

## 设计意图

为弓箭手提供超视距打击，用麻痹与随机雷击风险平衡强度。
