# 《不灭战意》

## 基础信息

- **书籍 ID**：`book_传说禁术_0044`
- **关联技能**：`legendary_indomitable_war_will`
- **使用效果**：阅读后解锁 `legendary_indomitable_war_will`；若已学会，提升 `current_mastery +180`，并在下一次战斗中让不死时间延长 1 秒。
- **阅读要求**：角色职业标签含 `warrior` 或 `berserker`；基础 `力量 ≥ 15`、意志 `≥ 14`。
- **稀有度**：传说（Legendary）
- **建议投放**：战神祭坛、远古竞技场、英雄陵墓、传说战士任务。

## 书籍内容

在死亡边缘维持战斗意志的战士禁术。书中记载，修习者需在濒死时守住一丝怒意，让战意代替心脏跳动。成功后，即使受到致命伤害也能继续战斗数秒，但战后必须立刻接受治疗。作者警告，不要将这几秒当作永生，许多战士因为迷恋濒死的力量而主动赴死。书脊处有一道深深的砍痕，像是被主人用来自证。

不灭战意的修习者需在濒死时抓住一把象征愤怒的灼热铁砂，掌心疤痕即为印记。战后若无法及时治疗，疤痕会裂开流出黑血。

不灭战意的黑血若滴落地面，会短暂燃烧成一朵无热的红色火花。

不灭战意的黑血火花会在施术者下葬后继续燃烧数年，直到最后一个记得他名字的人死去才终于熄灭。

火花等待最后的遗忘，那是战士一生战意的最后守夜。

火花永不熄灭。

难逃。

## 设计意图

为战士提供关键续命窗口，强化濒死反击与时间管理。
