# 《夜魇潜行》

## 基础信息

- **书籍 ID**：`book_传说禁术_0029`
- **关联技能**：`legendary_nightmare_stealth`
- **使用效果**：阅读后解锁 `legendary_nightmare_stealth`；若已学会，提升 `current_mastery +180`，并在下一次战斗中让首次攻击不打破潜行，但梦境能量消耗减少 1 层。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `敏捷 ≥ 16`、感知 `≥ 12`。
- **稀有度**：传说（Legendary）
- **建议投放**：梦魇集市、梦境裂缝、无声剧院、暗杀公会传说任务。

## 书籍内容

在噩梦中行走的盗贼禁术。书中记载，真正的潜行不是藏于黑暗，而是进入目标的噩梦。施术者需在目标入睡时与其梦境同步，然后在现实中同步消失。第一次攻击不会打破潜行，但会永久消耗一部分梦境能量。作者提醒，若目标没有做梦，施术者会被困在清醒与睡眠之间。书页散发着淡淡的催眠香气。

夜魇潜行需要收集目标枕边的头发，混入自己的影子中。若目标醒来，施术者会被困在两个梦境之间的灰色走廊，直到再次有人入睡。

夜魇潜行的灰色走廊中常有无面人徘徊，他们都是从目标噩梦中迷路的研究者。

夜魇潜行的灰色走廊没有尽头，曾有研究者为了逃离，不得不在自己手臂上刻下醒来的咒语，醒来时手臂已布满疤痕。

疤痕成为新的咒语，提醒研究者梦境与现实同样危险。

## 设计意图

为盗贼提供独特的梦境潜行机制，拓展控制与暗杀场景。
