# 《禁术：骸骨王座》

## 基础信息

- **书籍 ID**：`book_legendary_0060`
- **关联技能**：`legendary_bone_throne`
- **使用效果**：阅读后解锁 `legendary_bone_throne`；若已学会，提升 `current_mastery +180`，并在坐下/站桩时以骸骨构筑王座，获得 20% 全抗性加成与生命恢复。
- **阅读要求**：角色职业标签含 `warrior` 或 `necromancer`；基础 `体质 ≥ 16`、力量 `≥ 14`。
- **稀有度**：传说（Legendary）
- **建议投放**：骸骨殿堂、亡灵领主掉落、死亡商人、传说级宝箱。

## 书籍内容

骸骨王座是一门让死者为活人效劳的禁术。书中记载，施术者需在战斗中保持静止，以意志命令脚下的土地「献出」埋藏其中的骨骼。那些骨头会自行拼接成一座歪斜的王座，将施术者托举起来。坐在王座上的人会被亡者的执念包裹，伤口恢复速度加快，对痛苦也更加迟钝。但王座有一个致命的缺陷：只要离开它，所有借来的庇护会在一瞬间收回。一位古代将军在书中批注：「我赢得了一百场战役，却再也睡不惯柔软的床。」

骸骨王座拆解后会散落成普通的骨头，但骨头的主人往往无法辨认。有考古队曾在三座不同遗迹中发现同一个人的肱骨，而历史记载那人只死过一次。

坐在骸骨王座上的人若睡着了，骨骼会按照自己的记忆重新排列，有时会把王座变成一张躺椅，有时变成一只巨大的手。

## 设计意图

为坦克/前排提供阵地战强化，鼓励站桩防御与团队保护。
