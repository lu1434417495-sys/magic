# 《禁术：创世残篇》

## 基础信息

- **书籍 ID**：`book_legendary_0100`
- **关联技能**：`legendary_creation_fragment`
- **使用效果**：阅读后解锁 `legendary_creation_fragment`；若已学会，提升 `current_mastery +160`，并一次性解锁 3 条 `known_knowledge_ids`（创世学相关），同时允许重组一个已学禁术效果。
- **阅读要求**：无职业限制；基础 `智力 ≥ 17`、感知 `≥ 15`；角色 `known_knowledge_ids` 数量 ≥ 8。
- **稀有度**：传说（Legendary）
- **建议投放**：创世遗迹、古卷商人、终极知识任务奖励、世界核心宝箱。

## 书籍内容

创世残篇是一本据说来自世界诞生之初的书。书中没有完整的章节，只有一些零散的语句与图案，像是某位创世者在匆忙中留下的草稿。阅读这些残篇会让人隐约理解世界最初的规则：为什么火焰会向上，为什么死亡会向下，为什么时间会向前。古籍警告，知道得越多，越难再忍受普通的生活。许多收藏家在读完残篇后，会盯着自己的手掌发呆，仿佛那里曾有过创造万物的力量。书的最后一页是一片空白，只有中央有一个淡淡的指纹。

创世残篇的指纹会随着阅读次数增加而变得更清晰，当指纹完全成型时，读者会获得一次「创世余韵」——短暂地让周围一尺内的事物按自己的想象轻微改变。

创世残篇的空白页会逐渐浮现出读者的指纹，当两页指纹完全重合时，书会自行合拢，并在三年内拒绝再次向同一人敞开。

## 设计意图

作为知识型传说禁术，解锁高级 known_knowledge_ids 并为禁术重构提供可能。
