# 《禁术：镜面双生》

## 基础信息

- **书籍 ID**：`book_legendary_0079`
- **关联技能**：`legendary_mirror_twin`
- **使用效果**：阅读后解锁 `legendary_mirror_twin`；若已学会，提升 `current_mastery +170`，并召唤一个镜像分身复制下一次行动。
- **阅读要求**：角色职业标签含 `rogue` 或 `mage`；基础 `敏捷 ≥ 15`、智力 `≥ 14`。
- **稀有度**：传说（Legendary）
- **建议投放**：镜面迷宫、幻象商人、双生任务奖励、传说级宝箱。

## 书籍内容

镜面双生是一本教人从镜子里借一个自己的书。书中说，每个人在镜中的倒影都渴望走出来，只是大多数人从未问过它愿不愿意。施术者需在完整的镜面面前凝视自己的眼睛，然后在心中默许它离开。那道倒影会踏出镜框，模仿施术者的下一个动作——同一剑会挥出两次，同一法术会释放两次。古籍警告，倒影复制的不只是动作，还有意图；若施术者在那一刻心怀杀意，倒影可能会选择杀掉施术者本人。

镜面双生的倒影若在某次复制中死亡，本体会在左肩留下一道 mirror bruise。 bruise 的位置与倒影受伤处完全对称，且永远不会消失。

镜像双生若在同一面镜子前使用超过七次，镜子会开始拒绝映照施术者。从那以后，施术者只能在水面或他人眼中看见自己。

失去镜子的施术者会养成凝视水面的习惯，因为那是他们唯一还能确认自己存在的方式。

## 设计意图

提供一次性行动复制，增强爆发连招与关键技能双重收益。
