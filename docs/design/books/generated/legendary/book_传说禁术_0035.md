# 《千面盗影》

## 基础信息

- **书籍 ID**：`book_传说禁术_0035`
- **关联技能**：`legendary_thousand_face_shadow`
- **使用效果**：阅读后解锁 `legendary_thousand_face_shadow`；若已学会，提升 `current_mastery +170`，并在下一次战斗中让伪装持续时间延长 2 回合。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `敏捷 ≥ 15`、感知 `≥ 12`。
- **稀有度**：传说（Legendary）
- **建议投放**：千面剧院、盗贼公会密库、伪装大师任务、梦魇集市。

## 书籍内容

盗取他人影子来伪装的盗贼禁术。书中记载，施术者可以在击杀敌人后短暂夺取其影子，化作对方模样。伪装期间可以安全通过敌营，但每次转换都会让自己的真实面容模糊一分。作者警告，若连续盗取超过七个影子，会忘记自己原本是谁。书中夹着七张不同面孔的素描，每张都越来越不像人类。

千面盗影的素描页必须在月光下绘制，否则盗取的面孔会缺少眼睛。当第七张面孔完成时，镜子中将不再映出施术者本人。

千面盗影的第七张面孔一旦完成，镜子会裂开七道纹路，对应七张被夺走的脸。

千面盗影的第七张面孔完成者从未留下画像，因为所有镜子都在那一刻碎裂，碎片中映出的是七张同时微笑的脸。

七张脸共享同一微笑，却没有人知道原本属于谁。

面孔逐渐融合。

不可轻用。

## 设计意图

为盗贼系提供社交/潜入伪装能力，用身份侵蚀代价强化叙事。
