# 《禁术：灵肉剥离》

## 基础信息

- **书籍 ID**：`book_legendary_0066`
- **关联技能**：`legendary_soul_flesh_sever`
- **使用效果**：阅读后解锁 `legendary_soul_flesh_sever`；若已学会，提升 `current_mastery +170`，并允许灵魂出窍 3 秒，期间肉体无敌但灵魂可穿过障碍侦察/触发机关。
- **阅读要求**：角色职业标签含 `mage` 或 `rogue`；基础 `智力 ≥ 15`、敏捷 `≥ 14`。
- **稀有度**：传说（Legendary）
- **建议投放**：灵魂研究所、灵媒商人、探索向隐藏任务、传说级宝箱。

## 书籍内容

灵肉剥离是一本教人暂时不要当人的书。书中说，灵魂与肉体之所以黏在一起，只是因为大多数人从未想过它们可以分开。施术者需在极度安静的环境中闭上眼睛，想象自己是一缕轻烟，从头顶的缝隙中飘出去。成功后，灵魂会离开身体，可以穿过墙壁、门扉和敌人的阵列，但无法触碰到任何东西。古籍反复强调：肉体在灵魂离体时毫无防备，若被攻击，灵魂会永远失去归处。书页上画着一个盘腿而坐的人形，人形上方有一道虚线连接的半透明影子，影子旁边写着「不要回头」。

灵肉剥离成功后，肉体周围会出现一圈淡淡的霜气，那是灵魂离体时带走的余温。有经验的人会在灵魂归位前先检查身体是否被移动，因为归位的灵魂无法感知肉体移动时的惯性。

灵魂出窍期间，施术者可以看见其他游离的灵魂，有些是刚死去的人，有些是活了太久忘记回归肉体的老人。

## 设计意图

提供侦察与机关触发能力，服务于探索与解谜玩法，兼具战斗侦察价值。
