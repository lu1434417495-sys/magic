# 《禁术：因果逆转》

## 基础信息

- **书籍 ID**：`book_传说禁术_0031`
- **关联技能**：`legendary_causality_reversal`
- **使用效果**：阅读后解锁 `legendary_causality_reversal`；若已学会，提升 `current_mastery +180`，并在下一次战斗中让因果延迟爆发的回合数延后 1 回合。
- **阅读要求**：角色职业标签含 `mage` 或 `chrono_mage`；基础 `智力 ≥ 16`、感知 `≥ 12`。
- **稀有度**：传说（Legendary）
- **建议投放**：时间裂隙、因果律研究院废墟、命运纺织者密室、传说任务奖励。

## 书籍内容

在极短时间内颠倒因果的禁术。书中说，普通战斗遵循先因后果，而因果逆转可以让结果先发生。施术者可以在受伤后发动该术，让伤口回到未出现之前。但每次逆转都会把伤痛累积到未来某一刻。作者附有一本小账簿，记录着尚未偿还的"果"。末页警告：欠债总要还，而且利息是时间。

因果逆转的账簿会自动记录每次逆转，字迹由施术者未来的血写成。若账簿丢失，所有累积的果将在同一天爆发。

因果逆转的账簿页数永远比上次多一页，那是未来你继续欠债的证据。

因果逆转的账簿会在施术者死亡当天自动焚毁，灰烬中只留下一行未来的字迹：“此账已清，但你已无法读取。”

焚毁前一秒字迹会发光，那是未来者对过去最后的告别。

因果债务沉重，许多人在还清前便已老去。

不可逆。

时间裂隙研究院的废墟中仍散落着无数账簿残页，每一页都写满了尚未到期的债务与日期。

## 设计意图

为时间系法师提供紧急自保，但引入延迟伤害的高级策略。
