# 《追魂箭》

## 基础信息

- **书籍 ID**：`book_传说禁术_0036`
- **关联技能**：`legendary_soul_chasing_arrow`
- **使用效果**：阅读后解锁 `legendary_soul_chasing_arrow`；若已学会，提升 `current_mastery +170`，并在下一次战斗中让追魂箭的追踪距离增加 2 格。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；基础 `感知 ≥ 16`、意志 `≥ 10`。
- **稀有度**：传说（Legendary）
- **建议投放**：灵魂猎场、古老树灵祭坛、游侠复仇任务、月影宝箱。

## 书籍内容

射出后自动追踪灵魂的箭矢。书中描述，箭头需蘸取施术者的一滴眼泪，箭羽由思念编织而成。离弦后，箭会感应目标的灵魂波动，即使目标隐身或瞬移也无法摆脱。代价是射手会在箭命中前持续流失专注力。作者提醒，不要对深爱的人使用，思念会让箭飞得更慢，却也更难躲避。书页间缠着一根银色发丝。

追魂箭的泪水必须来自真诚悲伤，虚假的眼泪会让箭在离弦时折断。曾有射手为了复仇流下最后一滴泪，箭飞出后，他也永远失去了哭泣能力。

追魂箭的银色发丝会在箭命中时自燃，化作一束微光指引灵魂归去。

追魂箭的射手在失去哭泣能力后，眼泪会化作银色细沙从眼眶滑落，那些细沙被收集起来，成为下一代箭羽的材料。

细沙混入夜枭的眼泪，成为下一代追魂箭不可复制的材料。

## 设计意图

为弓箭手提供反隐身/追踪技能，用情感叙事包装命中机制。
