# 《神恩掠夺》

## 基础信息

- **书籍 ID**：`book_传说禁术_0046`
- **关联技能**：`legendary_divine_grace_plunder`
- **使用效果**：阅读后解锁 `legendary_divine_grace_plunder`；若已学会，提升 `current_mastery +170`，并在下一次战斗中让掠夺的增益效果持续时间 +1 回合。
- **阅读要求**：角色职业标签含 `priest` 或 `warlock`；基础 `意志 ≥ 15`、感知 `≥ 12`。
- **稀有度**：传说（Legendary）
- **建议投放**：被掠夺的神殿、异端审判所、黑市圣物商人、亵渎任务。

## 书籍内容

从敌人身上窃取神明赐福的禁术。书中说，祈祷建立的是单向通道，而掠夺术能把通道反转。施术者可以抽取敌人的增益效果并加持给自身，但会引起对应神明的注意。作者警告，被掠夺的神恩会附带原主人的祈祷杂音，长期使用会影响心智。书中夹着几根不同材质的护身符残片。

神恩掠夺的增益会在施术者身上留下原主人的气味，神明可通过气味追踪。长期使用的人会被不同神明的信徒同时敌视。

神恩掠夺者的气味会吸引野狗与信徒，使他们同时向施术者露出牙齿。

神恩掠夺者身上的混合气味会随着掠夺次数增多而变得复杂，最终连野兽都会在他们经过时犹豫该敬畏还是撕咬。

野兽最终选择撕咬，因为它们嗅到了不属于这个世界的神恩。

气味混杂成咒。

致命。

代价沉重。

## 设计意图

为圣职/术士系提供增益窃取，强化反制与资源转换玩法。
