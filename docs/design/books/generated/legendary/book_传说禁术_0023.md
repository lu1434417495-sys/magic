# 《猎命箭》

## 基础信息

- **书籍 ID**：`book_传说禁术_0023`
- **关联技能**：`legendary_life_hunt_arrow`
- **使用效果**：阅读后解锁 `legendary_life_hunt_arrow`；若已学会，提升 `current_mastery +170`，并在下一次战斗中让猎命箭击杀目标时恢复射手 10% 最大 HP。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；基础 `感知 ≥ 16`、敏捷 `≥ 12`。
- **稀有度**：传说（Legendary）
- **建议投放**：猎头者营地、古老猎场、游侠复仇任务、血月宝箱。

## 书籍内容

射出后追击生命气息的禁术箭。书中描述，箭杆需浸泡在猎物的泪水中，箭头刻上目标的真名。一旦离弦，箭会绕过障碍物追踪心跳，直到命中或能量耗尽。每支猎命箭都会消耗射手一部分生命力。作者强调，真名必须准确，若刻错名字，箭会调头寻找最近的活物。书中夹着一根羽毛笔，笔尖沾着干涸的血迹。

猎命箭的真名刻写必须用受术者亲属的眼泪稀释墨水，否则箭矢会在半空自燃。传说最老练的猎手能凭心跳声辨认目标真名。

猎命箭的真名羽毛笔只能书写七次，之后笔尖便会化为灰烬随风散去。

猎命箭的羽毛笔在使用七次后会留下灰烬笔迹，那些灰烬会在风中重新组成七个已被射杀者的名字。

灰烬名字在风中哭泣，那是被猎命箭射杀者最后的回响。

真名最为关键。

需谨慎。

## 设计意图

为弓箭手提供追踪/处决型技能，通过真名机制增加准备深度。
