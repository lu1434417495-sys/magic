# 《星陨齐射》

## 基础信息

- **书籍 ID**：`book_传说禁术_0030`
- **关联技能**：`legendary_meteor_volley`
- **使用效果**：阅读后解锁 `legendary_meteor_volley`；若已学会，提升 `current_mastery +180`，并在下一次战斗中让齐射范围扩大 1 格。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；基础 `感知 ≥ 15`、敏捷 `≥ 12`。
- **稀有度**：传说（Legendary）
- **建议投放**：观星台禁阁、星陨荒原、游侠占星任务、天际宝箱。

## 书籍内容

引动星辰坠落的群体箭术。书中描述，射手需在星空下排布箭阵，用箭羽指向特定星座。齐射时，箭矢会带着星光的残像从天而降，覆盖大片区域。该术只能在夜晚使用，且会让弓弦承受极大压力。作者警告，不要把箭头对准月亮，曾有射手因此被月光灼伤双目。书中夹着一张标满星座的羊皮纸。

星陨齐射必须在特定星座升起的夜晚练习，否则箭矢只会变成普通流光。传说第一位射手因此双目失明，却在失明后射落了月亮的一角。

星陨齐射的失明射手后来在沙漠中用耳辨位，据说射落了七只伪装成星星的怪物。

星陨齐射的失明射手临终前将箭囊抛入大海，多年后渔民在捕获的鱼腹中发现了仍能发出星光的箭羽。

星光在鱼腹中沉睡，直到被渔夫发现时才骤然亮起。

夜晚仅此一次。

## 设计意图

为弓箭手提供夜间限定 AOE，强化环境与职业特色结合。
