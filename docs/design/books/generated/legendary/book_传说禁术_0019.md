# 《禁术：生命分流》

## 基础信息

- **书籍 ID**：`book_传说禁术_0019`
- **关联技能**：`legendary_life_shunt`
- **使用效果**：阅读后解锁 `legendary_life_shunt`；若已学会，提升 `current_mastery +170`，并在下一次战斗中让首次分流对自身的反噬降低 25%。
- **阅读要求**：角色职业标签含 `priest` 或 `warlock`；基础 `意志 ≥ 14`、体质 `≥ 12`。
- **稀有度**：传说（Legendary）
- **建议投放**：吸血贵族古堡、禁忌医院、黑市医生营地、殉道者遗迹。

## 书籍内容

将自身生命转移给他人的禁忌治疗。书中记载，施术者以手掌按住伤者胸口，通过一根无形导管把 HP 输送给对方。输送过程中，两人会共享疼痛。作者警告，如果施术者心存犹豫，生命会在中途淤塞，导致双方同时受创。书中详细记录了分流的节奏与呼吸配合。夹页里有一片干枯的树叶，叶脉与人的血管惊人相似。末尾写道："给予生命的人，也要学会索取。"

分流的导管并非真实存在，而是由施术者与伤者之间的信任凝成。若伤者抗拒，导管会瞬间凝固成一根刺穿双方的骨针。

生命分流的树叶标本来自施术者与伤者共同触碰过的同一棵树，叶脉会随时间变红。

生命分流的树叶标本若被焚烧，会发出两人重叠的惨叫，因此历代持有者都选择将它深埋地下。

深埋是为避免惨叫，也是为了防止叶脉重新生长成血管。

## 设计意图

为治疗职业提供紧急单体救援手段，用共享疼痛强化情感与策略张力。
