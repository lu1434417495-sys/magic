# 《禁术：亵渎炼成》

## 基础信息

- **书籍 ID**：`book_legendary_0096`
- **关联技能**：`legendary_desecrate_alchemy`
- **使用效果**：阅读后解锁 `legendary_desecrate_alchemy`；若已学会，提升 `current_mastery +170`，并允许以战场尸体为材料临时炼成一名亡灵仆从。
- **阅读要求**：角色职业标签含 `necromancer` 或 `warlock`；基础 `智力 ≥ 15`、体质 `≥ 13`。
- **稀有度**：传说（Legendary）
- **建议投放**：亵渎实验室、亡灵商人、尸体收集任务奖励、传说级宝箱。

## 书籍内容

亵渎炼成是一本把尸体当材料的书。书中说，死亡只是物质换了一种排列方式，而炼金术师的任务就是重新排列它们。施术者需在战场上找到一具尚有残余魔力的尸体，然后按照书中的配方注入自己的 AURA 或 MP。尸体会像被无形的线牵引一样站起来，成为一具听从简单命令的仆从。古籍警告，仆从不会完全忘记生前，有时会突然停下动作，用空洞的眼眶望着施术者。书页上有一幅炼成阵图，阵图中央画着一个人形轮廓，轮廓的胸口处写着「借」。

亵渎炼成的仆从在命令结束后不会立刻倒下，而是会缓缓走回死亡的位置。有目击者称，它们在归位途中会低声哼唱生前的歌谣，旋律往往比战斗更让人不安。

亵渎炼成的仆从有时会保留生前最深的执念，比如寻找丢失的戒指或向某人说声抱歉。这些执念会让它们偏离命令，独自行动。

## 设计意图

提供战场召唤机制，强化亡灵术士的尸体利用与数量优势。
