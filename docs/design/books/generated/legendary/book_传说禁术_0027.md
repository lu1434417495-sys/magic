# 《冰封王座禁咒》

## 基础信息

- **书籍 ID**：`book_传说禁术_0027`
- **关联技能**：`legendary_frozen_throne_curse`
- **使用效果**：阅读后解锁 `legendary_frozen_throne_curse`；若已学会，提升 `current_mastery +190`，并在下一次战斗中让施术者自身结冰速度降低 25%。
- **阅读要求**：角色职业标签含 `mage` 或 `cryomancer`；基础 `智力 ≥ 16`、意志 `≥ 14`。
- **稀有度**：传说（Legendary）
- **建议投放**：永冻图书馆、冰霜巨龙巢穴、冰封王座遗迹、传说法师任务。

## 书籍内容

冻结一片区域的终极冰咒。书中描述，施术者需在心中构筑一座冰之王座，王座越冷，领域越大。咒语释放时，所有敌我都会被冰霜覆盖，行动迟缓。施术者自身也会逐渐结冰，若无法在王座崩塌前结束战斗，便会成为新的冰雕。书中夹着一片永不融化的雪花。末页警告：坐上王座的人，很难自己站起来。

冰封王座原典由永不融化的冰晶雕刻而成，阅读时必须隔着兽皮，否则指尖会被冻伤。王座的残影至今仍在某座雪山之巅若隐若现。

冰封王座禁咒的冰晶原典只在极寒环境中才能被阅读，常温下会渗出刺骨白雾。

冰封王座禁咒的冰晶原典若被带出雪山，会在三个昼夜内融化成一滩带有符文的水渍，再也无法复原。

水渍形状像王座，却无法再承载任何一位新的施术者。

寒冷伴随终身。

## 设计意图

为冰法提供大范围控场，但用自我冻结作为致命时间压力。
