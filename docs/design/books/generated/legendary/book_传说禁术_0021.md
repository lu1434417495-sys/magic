# 《神罚逆转》

## 基础信息

- **书籍 ID**：`book_传说禁术_0021`
- **关联技能**：`legendary_divine_retribution_reversal`
- **使用效果**：阅读后解锁 `legendary_divine_retribution_reversal`；若已学会，提升 `current_mastery +170`，并在下一次战斗中让逆转后的神罚伤害提高 20%。
- **阅读要求**：角色职业标签含 `priest` 或 `paladin`；基础 `意志 ≥ 15`、体质 `≥ 12`。
- **稀有度**：传说（Legendary）
- **建议投放**：被雷劈毁的神殿、审判所禁书库、圣骑士殉道地、传说宝箱。

## 书籍内容

将神明惩罚反弹给敌人的禁术。书中主张，祈祷不仅能接收恩典，也能储存神罚。修习者需在承受伤害时默念逆转祷言，把本应落在自己身上的天罚转嫁给攻击者。成功后会有一道金色闪电反噬敌人，但施术者会暂时失去信仰加成。作者提醒，逆转的对象不能太强，否则神罚会原路返回。书脊镶嵌着一小块焦黑的圣徽，据说来自被雷劈毁的神殿。

神罚逆转的祷言必须倒着书写，因此书中文字从右至左排列。每一页边缘都留有天雷击中的焦痕，仿佛神明在试图销毁此书。

神罚逆转的焦黑圣徽会在雷雨天发出低鸣，那是神明仍未原谅此书作者的证明。

神罚逆转的祷言若被普通人朗读，会引来方圆十里内的鸟群盘旋，仿佛天空也在等待闪电落下。

鸟群盘旋三日不散，直到第四日才有雷云聚集。

为圣职系提供反制型防御技能，鼓励玩家在受击窗口果断反击。
