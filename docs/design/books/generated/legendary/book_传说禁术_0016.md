# 《风陨箭》

## 基础信息

- **书籍 ID**：`book_传说禁术_0016`
- **关联技能**：`legendary_wind_meteor_arrow`
- **使用效果**：阅读后解锁 `legendary_wind_meteor_arrow`；若已学会，提升 `current_mastery +170`，并减少该技能对弓弦耐久消耗 50%。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；基础 `感知 ≥ 15`、力量 `≥ 10`。
- **稀有度**：传说（Legendary）
- **建议投放**：高山观星台、风息哨塔禁阁、陨落之地宝箱、游侠长老任务。

## 书籍内容

召唤陨落之风贯穿战场的箭术。书中描述，射手需在高山之巅引弓，感受风中的陨石记忆。箭矢离弦后会带着天体的重量坠落，对大范围内的敌人造成伤害。该箭无法精准瞄准，只能依赖风向判断落点。每次使用都会让弓弦老化，连续使用可能导致弓身碎裂。书中夹着一片黑色陨石碎片，触之温热。末页警告：风会记住每一支被射向地面的箭。

风陨箭的传承箭囊用陨石碎片装饰，每次使用后会多出一条裂纹。传说当箭囊碎裂时，使用者会听见天际传来陨落者的告别。

风陨箭的陨石碎片会在使用后轻颤，仿佛来自天体的不舍与责备。

风陨箭的陨石碎片会在使用者的葬礼上自行升空，向着来时的天际缓缓飞去，仿佛归还借用已久的记忆。

葬礼上空星光黯淡，仿佛天际也在归还这份沉重的记忆。

## 设计意图

为弓箭手提供 AOE 打击选择，同时用装备耐久风险限制滥用。
