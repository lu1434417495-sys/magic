# 《禁术：时砂之棺》

## 基础信息

- **书籍 ID**：`book_legendary_0063`
- **关联技能**：`legendary_hourglass_coffin`
- **使用效果**：阅读后解锁 `legendary_hourglass_coffin`；若已学会，提升 `current_mastery +160`，并可将一名敌人封印于时砂之棺中 4 秒，期间无法行动但无敌。
- **阅读要求**：角色职业标签含 `mage` 或 `chronomancer`；基础 `智力 ≥ 16`、意志 `≥ 14`。
- **稀有度**：传说（Legendary）
- **建议投放**：时计塔密室、时间商人、隐藏主线任务、传说级宝箱。

## 书籍内容

时砂之棺是一门把敌人装进时间里的禁术。书中教导施术者将目标的影子与地面上的沙漏图案重叠，然后念诵一段逆流的祷文。那一瞬间，目标的周围会凝结出无数细小的沙粒，像一口透明的棺材将其封存。被封印者不会受伤，也无法行动，只能眼睁睁看着外面的世界继续流动。古籍警告，时砂之棺最危险的不是敌人，而是施术者自己——若在棺材破碎前失去专注，时间的碎片会嵌入自己的身体。书页间夹着一张干枯的花瓣，旁边写着：「她被封印了三十年，出来时已不认识我。」

时砂之棺破碎后，被封印者会遗忘棺中经历，但眼角会多出细小的沙粒。有人收集这些沙粒，据说足够多时可以拼出施术者未来的死状。

时砂之棺的碎片散落在战场上，细小的沙粒会渗入土壤，使那片土地长出透明的水晶花。采花人会听见花蕊中传来低沉的心跳。

## 设计意图

提供单体控制与战术隔离，用于打断敌方核心单位或争取恢复时间。
