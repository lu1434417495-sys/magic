# 《狂血怒斩》

## 基础信息

- **书籍 ID**：`book_传说禁术_0026`
- **关联技能**：`legendary_berserk_blood_slash`
- **使用效果**：阅读后解锁 `legendary_berserk_blood_slash`；若已学会，提升 `current_mastery +180`，并在下一次战斗中让怒斩的连击次数上限 +1。
- **阅读要求**：角色职业标签含 `warrior` 或 `berserker`；基础 `力量 ≥ 16`、体质 `≥ 12`。
- **稀有度**：传说（Legendary）
- **建议投放**：狂战士圣坛、血斗场冠军奖励、远古战场遗迹、狂怒契约任务。

## 书籍内容

以狂暴血液驱动连续斩击的战士禁术。书中要求修习者在战斗前饮用一种由自己血液和战吼草混合的药剂。药效发作时，肌肉会记住愤怒，挥舞武器的速度大幅提升，但理智会逐渐流失。作者提醒，当视野边缘开始发红，必须立刻停止攻击，否则下一刀会砍向最近的人。书脊处有几道刀砍痕迹。末页写着："血让你更快，也让你更瞎。"

狂血药剂需在战斗前一刻配制，提前饮用会让药剂在体内发酵成毒。老练的狂战士能通过视野发红程度判断自己是否还有三刀理智。

狂血怒斩的老战士会在清醒后剪掉发红的指甲，因为那是药剂尚未排尽的标记。

狂血怒斩的老战士退役后会将指甲埋入战吼草丛中，希望药性随土地一同腐烂，不再找到下一个宿主。

战吼草因此变红，那是无数指甲中残留的血液染就。

## 设计意图

为狂战士提供多段连击爆发，用理智流失机制防止无脑使用。
