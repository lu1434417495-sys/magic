# 《蚀骨影刃》

## 基础信息

- **书籍 ID**：`book_传说禁术_0047`
- **关联技能**：`legendary_bone_eating_shadow_blade`
- **使用效果**：阅读后解锁 `legendary_bone_eating_shadow_blade`；若已学会，提升 `current_mastery +170`，并在下一次战斗中让影刃的腐蚀层数叠加效率提高 1 层。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `敏捷 ≥ 15`、智力 `≥ 10`。

## 书籍内容

给武器涂上影之毒的盗贼禁术。书中记载，施术者需在武器上涂抹由自己影子熬制的毒液。被影刃击中的敌人骨骼会被缓慢腐蚀，行动能力逐渐丧失。代价是持刃者的手指会先一步变黑。作者提醒，影毒无药可解，只能依靠时间慢慢排出。书页上有一道道刀刻的痕迹，像是有人在练习涂毒。

影刃的毒液来自施术者影子中最黑暗的部分，因此性格越阴郁，毒性越强。手指变黑后，施术者再也无法在正午清晰地看见自己的影子。

蚀骨影刃的变黑手指在月圆时会隐隐作痛，那是影子在提醒你毒液尚未耗尽。

蚀骨影刃的毒液在手指完全变黑后，会向心脏缓慢爬行，因此老练使用者会定期割破指尖，让毒液重新流向体外。

割破指尖成为仪式，也是延缓毒液侵蚀心脏的唯一方法。

仪式痛苦漫长。

影刃锻炉的墙壁上挂着数十只变黑的手套，那是无法坚持割破指尖者的最终归宿。

## 设计意图

为盗贼提供持续削弱型武器增益，用自身中毒风险限制使用。
