# 《归墟禁术》

## 基础信息

- **书籍 ID**：`book_传说禁术_0049`
- **关联技能**：`legendary_guixu_forbidden_art`
- **使用效果**：阅读后解锁 `legendary_guixu_forbidden_art`；若已学会，提升 `current_mastery +200`，并在下一次战斗中让归墟的 MP/AURA 消耗降低 20%。
- **阅读要求**：无职业限制；基础 `智力 ≥ 16`、意志 `≥ 16`；已学会至少 3 项传说禁术。
- **稀有度**：传说（Legendary）
- **建议投放**：世界尽头裂缝、归墟祭坛、终极传说宝箱、隐藏主线奖励。

## 书籍内容

将目标放逐至虚无尽头的终极禁术。书中说，归墟是世界尽头的一个点，所有存在在那里都会失去意义。施术者需消耗大量 MP 和 AURA，在目标脚下打开一道裂缝。被吞噬的敌人会直接从战场消失，无法复活。作者警告，归墟也会注视施术者，每次使用后都会有人做同样的梦：自己站在裂缝边缘，被一只无形的手推了下去。书封由某种未知金属制成，触之冰冷。

归墟禁术的最后一页空白，只有当你亲手放逐第一个存在时，字迹才会浮现。许多修习者终其一生只敢阅读前半部。

归墟禁术的空白页会在放逐后显现出被抹除者的名字，字迹由施术者的冷汗写成。

归墟禁术的修习者晚年常会无意识地走向高处边缘，仿佛那只无形的手仍在梦中等待推下他们的时机。

边缘站立者危险，因为那只无形的手从未真正离开。

## 设计意图

作为传说禁术线的终极技能，提供战场抹除级效果，但消耗与心理代价极高。
