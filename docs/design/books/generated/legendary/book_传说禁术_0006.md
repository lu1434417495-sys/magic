# 《虚空冥想法》

## 基础信息

- **书籍 ID**：`book_传说禁术_0006`
- **关联技能**：`legendary_void_meditation`
- **使用效果**：阅读后学会冥想技能 `legendary_void_meditation`（`practice_tier = legendary`），立即解锁 `MP` 资源链并按传说级公式提升 `mp_max/current_mp` 上限，但获得永久 `void_taint` 计数。
- **阅读要求**：无职业限制；基础 `智力 ≥ 14` 或 `意志 ≥ 14`；需先学会任意基础冥想。
- **稀有度**：传说（Legendary）
- **建议投放**：沉钟书库禁阅区、虚空裂缝据点、黑曜石冥想导师、世界尽头遗迹。

## 书籍内容

法师禁书，向虚空借贷魔力。书中将冥想比作在悬崖边取水，水面下是看不见底的黑暗。修习者每次进入冥想都会听见低语，低语承诺更多 MP，却要求开放意识的裂隙。初期效果显著，但长期使用会在梦境中看见陌生面孔。作者建议每次冥想后写下所见，若连续三次梦见同一张脸，必须立即停止。书末贴有一张被撕碎的星图，中心是一个不断旋转的空洞。

抄本由不知名材料制成，纸面在月光下会浮现出细密触须状纹路。曾有修行者将星图补全，却在当晚消失，只留下一页写满相同名字的日记。

虚空冥想者若连续梦见同一张脸七次，那张脸会在现实中出现在任何反光表面。

虚空冥想的修习者会在第七次梦见同一张脸时收到一封没有署名的信，信封里只有半截指甲。

这种恐惧常在深夜卷土重来，令人彻夜难眠。

## 设计意图

作为高风险冥想路线的终点，提供大量 MP 成长但埋下腐蚀叙事伏笔。
