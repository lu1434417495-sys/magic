# 《禁术：忘却川》

## 基础信息

- **书籍 ID**：`book_legendary_0084`
- **关联技能**：`legendary_river_forgetting`
- **使用效果**：阅读后解锁 `legendary_river_forgetting`；若已学会，提升 `current_mastery +160`，并允许让一名敌人暂时遗忘一个随机已学会技能，持续 6 秒。
- **阅读要求**：角色职业标签含 `mage` 或 `rogue`；基础 `智力 ≥ 16`、意志 `≥ 13`。
- **稀有度**：传说（Legendary）
- **建议投放**：忘川渡口、记忆商人、窃取记忆任务奖励、传说级宝箱。

## 书籍内容

忘却川是一本让敌人忘记自己会什么的书。书中记载，记忆像一条河，而每个人都站在河边。施术者需在敌人施法的瞬间，将一段虚假的「空白」注入对方的意识河流，让某个技能的名字被河水冲走。那几秒里，敌人会茫然地张着嘴，明明觉得自己应该会什么，却怎么也想不起来。古籍警告，玩弄记忆的人也会被记忆玩弄，许多修习者最终忘记了自己为什么开始战斗。书页上有一道水渍，形状像一条蜿蜒的河，河的尽头是一片空白。

忘却川冲刷掉的技能并非永久丢失，而是沉淀在意识的河床上。有潜水者专门进入他人的意识河流打捞这些失落技能，再高价卖给需要的人。

忘却川的河水会流入施术者自己的记忆深处，长期使用会让施术者开始遗忘一些不重要的日常细节，比如自己的名字或生日。

## 设计意图

提供技能封印型干扰，针对依赖核心技能的敌人或 PvP 场景。
