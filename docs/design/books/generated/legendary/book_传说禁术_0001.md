# 《血铸战魂》

## 基础信息

- **书籍 ID**：`book_传说禁术_0001`
- **关联技能**：`legendary_blood_forge_soul`
- **使用效果**：阅读后解锁 `legendary_blood_forge_soul`；若已学会，提升 `current_mastery +180`，并在下一次战斗中首次献祭生命值时额外获得 15% 伤害加成。
- **阅读要求**：角色职业标签含 `warrior` 或 `berserker`；基础 `力量 ≥ 14`、体质 `≥ 12`。
- **稀有度**：传说（Legendary）
- **建议投放**：远古战场遗迹、血祭商人、传说级宝箱、狂战士转职任务。

## 书籍内容

传说级禁术，以自身鲜血为燃料点燃战魂。书中记载，使用者需在月圆之夜将掌心割开，让血液滴落在一块被诅咒的黑铁上，铁块会发出低沉的嗡鸣。一旦共鸣建立，战士便能在战斗中以损失生命值为代价换取惊人破坏力。作者警告，这门技艺最危险的不是伤口，而是战魂会记住每一次献祭，逐渐渴望更多血液。古籍边缘满是褐色指印，似乎前任读者都没能控制住出血量。结尾附有一行小字："铸魂者，终将被魂所铸。"

古籍前半部已被血浸透，无法辨认原本墨色；后半部则用骨头碎片刻着战魂图谱。据说第一位写下此书的人，在最后一页未完成时便被自己的战魂吞噬殆尽。

许多尝试复刻此术的战士最终只留下一块锈黑铁与满地血迹，成为后来者最直观的警示。

后人用银链锁住此书，锁链却在三夜后尽数生锈。

## 设计意图

为狂战士/战士提供高风险高回报的爆发技能入口，以自残机制强化"向死而生"的职业气质。
