# 《龙血战躯》

## 基础信息

- **书籍 ID**：`book_传说禁术_0038`
- **关联技能**：`legendary_dragon_blood_body`
- **使用效果**：阅读后学会修炼技能 `legendary_dragon_blood_body`（`practice_tier = legendary`），AURA 上限提升 20%，并获得龙鳞减伤被动。
- **阅读要求**：角色职业标签含 `warrior` 或 `berserker`；基础 `力量 ≥ 16`、体质 `≥ 14`。
- **稀有度**：传说（Legendary）
- **建议投放**：龙血瀑布、古龙陨落之地、战士圣地、龙裔任务奖励。

## 书籍内容

以龙血淬炼肉体的战士禁术。书中记载，将稀释的龙血涂抹全身，在烈焰中冥想，可以让皮肤生长出类似龙鳞的甲片。成功者力量与体质大增，但会渴望高温，并逐渐长出尾骨。作者提醒，龙血只能使用三次，超过三次身体会发生不可逆的龙化。书页上沾着暗金色的鳞片碎屑。

龙血战躯的配方来自一头自愿献身的古龙，因此成功者会听见微弱的龙语低语。超过三次使用的人据说会在满月时梦见自己飞翔。

龙血战躯超过三次的使用者会在清晨发现自己的瞳孔变成了竖直的裂隙。

龙血战躯超过三次的使用者最终会被古龙一族的梦境召唤，在满月之夜不由自主地向最近的火山行进。

火山脚下常有龙吟回响，那是古龙在呼唤新生的族人。

龙化不可逆，终成孤独异类。

危险。

戒之。

慎。

龙血瀑布附近的部落会定期举行驱龙仪式，他们用歌声提醒那些竖瞳者：火山虽近，归途已断。

## 设计意图

为战士提供顶级防御向功法，用龙化风险限制长期收益。
