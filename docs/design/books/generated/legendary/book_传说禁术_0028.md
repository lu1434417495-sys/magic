# 《亵渎治疗》

## 基础信息

- **书籍 ID**：`book_传说禁术_0028`
- **关联技能**：`legendary_desecrated_healing`
- **使用效果**：阅读后解锁 `legendary_desecrated_healing`；若已学会，提升 `current_mastery +170`，并在下一次战斗中让生命窃取量提高 20%。
- **阅读要求**：角色职业标签含 `priest` 或 `heretic`；基础 `意志 ≥ 14`、智力 `≥ 12`。
- **稀有度**：传说（Legendary）
- **建议投放**：堕落疗养院、异端神殿、黑市医师营地、亵渎仪式任务。

## 书籍内容

从敌人身上窃取生命来治愈的禁术。书中说，治疗的本质是平衡，而亵渎治疗直接把敌人的生命抽过来填补缺口。施术者需在祈祷中加上一句反向祷言，圣光便会变成吸管。成功后盟友恢复 HP，敌人则持续流失生命。作者警告，若施术者仍有怜悯，反向祷言会反噬自身。书页上画着一只手握着心脏，心脏一半光明一半黑暗。

亵渎治疗的反向祷言读起来像圣歌的倒放，声音越温柔，抽取越猛烈。曾有牧师在施展后听见自己祈祷的对象发出冷笑。

亵渎治疗的反向祷言若被孩童听见，会让他们连续三夜梦见倒置的圣堂。

亵渎治疗的反向祷言若被完整抄录在圣器上，圣器会在七日内渗出黑色液体，那液体闻起来像腐败的蜂蜜。

黑色液体无法擦拭，只能用新的祷言一点点覆盖。

笑声回荡三日。

## 设计意图

为治疗职业提供进攻型续航，让牧师在输出与治疗之间切换。
