# 《净罪之火》

## 基础信息

- **书籍 ID**：`book_传说禁术_0040`
- **关联技能**：`legendary_fire_of_absolution`
- **使用效果**：阅读后解锁 `legendary_fire_of_absolution`；若已学会，提升 `current_mastery +170`，并在下一次战斗中让净罪之火额外清除 1 个队友负面状态。
- **阅读要求**：角色职业标签含 `priest` 或 `paladin`；基础 `意志 ≥ 15`、智力 `≥ 12`。
- **稀有度**：传说（Legendary）
- **建议投放**：净罪圣所、审判之火祭坛、圣骑士遗迹、传说宝箱。

## 书籍内容

以圣火焚尽一切异常状态的禁术。书中说，火焰可以烧毁罪恶，也可以烧毁疾病。施术者点燃自身，火焰会清除所有队友的负面状态，并对敌人造成持续灼烧。使用者会在火焰中暂时无法行动。作者提醒，净罪之火对心中无愧者最温和，对罪孽深重者最残酷。书页边缘有焦痕，像被无数次的点燃。

净罪之火点燃前，施术者需在心中背诵自己所有的过失，遗忘的罪会在火中重新显现。火焰越纯净，燃烧时越寂静无声。

净罪之火燃烧时若听见笑声，说明火中隐藏着施术者不愿承认的罪孽。

净罪之火的火焰若燃烧时带有颜色，说明施术者仍有未背诵出的罪孽；无色火焰才是最纯净也最致命的形态。

无色火焰只燃烧一次，却能焚尽所有需要被净化的罪。

无色之火最冷，烧尽罪也烧尽体温。

## 设计意图

为圣职系提供群体净化与持续伤害，强调信仰纯净度。
