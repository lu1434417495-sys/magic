# 《灵魂典当》

## 基础信息

- **书籍 ID**：`book_传说禁术_0010`
- **关联技能**：`legendary_soul_pawn`
- **使用效果**：阅读后解锁 `legendary_soul_pawn`；若已学会，提升 `current_mastery +170`，并降低该技能使用后记忆流失的触发概率 10%。

- **建议投放**：魔鬼商人交易单、地下当铺、禁忌拍卖行、深渊契约任务。

## 书籍内容

与未知存在交易灵魂的禁术。书中记载，施术者可以在战斗中典当部分灵魂，换取立刻满溢的 MP 或 AURA。典当的灵魂不会消失，而是成为债权人的收藏品。若不及时赎回，性格会逐渐变得冷漠。书中夹着几张当票，上面的文字不属于任何已知语言。作者提醒，赎回价格通常比想象中高，因为利息以记忆计算。最后一页写着："当你记不清母亲的脸，就是典当到期之时。"

债权人从不现身，只在每次交易后留下一枚冰冷硬币。当硬币集满七枚时，持有者会听见有人在门外轻轻数自己的名字。

灵魂典当的当票会在满月时发热，热得几乎能烫伤掌心，提醒你债务并未沉睡。

灵魂典当的债权人最喜欢的抵押物是名字，许多匿名英雄因此失去了被铭记的资格。

失去名字是最沉默的代价，因为无人能在祈祷中呼唤他们。

## 设计意图

打造资源危机时的"最后手段"，用叙事化的灵魂债务强化角色扮演。
