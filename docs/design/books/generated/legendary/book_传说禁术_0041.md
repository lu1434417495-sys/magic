# 《血影分身》

## 基础信息

- **书籍 ID**：`book_传说禁术_0041`
- **关联技能**：`legendary_blood_shadow_clone`
- **使用效果**：阅读后解锁 `legendary_blood_shadow_clone`；若已学会，提升 `current_mastery +170`，并在下一次战斗中让分身替本体承受 1 次致命伤害。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `敏捷 ≥ 15`、体质 `≥ 10`。
- **稀有度**：传说（Legendary）
- **建议投放**：血影剧院、暗杀公会密室、影舞者传承任务、深渊宝箱。

## 书籍内容

以血液制造分身的盗贼禁术。书中记载，施术者割破手掌，将血洒向地面，血液会凝结成一个与自己动作同步的影子分身。分身可以吸引攻击，但存在期间会持续消耗 HP。作者警告，分身受伤时本体也会感到疼痛，不要让它承受致命一击。书中夹着一片干涸的血迹，形状像奔跑的人影。

血影分身的动作与本体完全同步，却无法发出声音。当分身持续时间结束时，它会化作一滩血迹渗回施术者脚底，带来剧烈的疲惫。

血影分身的血迹回归时会短暂显露分身的面容，有时那表情比本体更悲伤。

血影分身的血迹回归后，施术者会在接下来三天内梦见分身的视角，看见自己曾经历过却早已被遗忘的瞬间。

梦境分身比本体更清醒，有时会在醒来后继续指点主人。

分身偶尔反客为主。

慎之。

勿忘。

血影剧院的镜子都被刻意打磨得模糊不清，因为曾经有人在其中看见了分身的独舞。

## 设计意图

为盗贼提供诱饵/替死机制，强化高风险高回报的操控玩法。
