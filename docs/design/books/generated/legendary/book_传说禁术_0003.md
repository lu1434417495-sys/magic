# 《噬圣祷言》

## 基础信息

- **书籍 ID**：`book_传说禁术_0003`
- **关联技能**：`legendary_holy_devouring_prayer`
- **使用效果**：阅读后解锁 `legendary_holy_devouring_prayer`；若已学会，提升 `current_mastery +160`，并在下一次战斗中让该技能的吸血比例提高 10%。
- **阅读要求**：角色职业标签含 `priest` 或 `dark_priest`；基础 `意志 ≥ 14`、智力 `≥ 10`。
- **稀有度**：传说（Legendary）
- **建议投放**：堕落神殿、异端审判密室、亡灵商人、牧师高阶转职试炼。

## 书籍内容

牧师的堕落禁术，以吞噬神圣之力为生。书中指出，真正的光并非无限，而是可以被咬碎、吞咽、转化为己用。祷文要求施术者在神殿废墟中收集残存的圣光碎屑，像饥饿者舔舐伤口般吸入体内。副作用是祷言会留下苦涩的金属味，并让所有治疗术带上暗色的边缘。作者用血红墨水标注：当你觉得圣光变甜，你就已经背叛了它。最后一页贴着一片枯萎的圣徽，背面只有一句话："神圣也会腐烂。"

此书的装订线来自某座被焚毁大教堂的窗帘流苏，每一页都沾染着烟熏气息。据说阅读时耳边会响起遥远的圣歌，但音调始终向下走调。

噬圣祷言原典的装帧线是用被折断的圣杖纤维编成，触碰时会有微弱刺痛。

书中偶尔会出现空白页，那是被大教堂正式删除的段落，据说每一页都对应一位叛教者的名字。

## 设计意图

为牧师系提供"以敌养己"的黑暗治疗路线，拓展圣职者的道德光谱。
