# 《禁术：暴君敕令》

## 基础信息

- **书籍 ID**：`book_legendary_0085`
- **关联技能**：`legendary_tyrant_edict`
- **使用效果**：阅读后解锁 `legendary_tyrant_edict`；若已学会，提升 `current_mastery +170`，并允许以威压强制命令一名敌人 1 秒内无法行动。
- **阅读要求**：角色职业标签含 `warrior` 或 `paladin`；基础 `力量 ≥ 16`、意志 `≥ 15`。
- **稀有度**：传说（Legendary）
- **建议投放**：暴君宫殿、征服者商人、统治任务奖励、传说级宝箱。

## 书籍内容

暴君敕令是一本教人用声音让人跪下的书。书中说，真正的命令不需要理由，只需要足够的意志去压垮对方的意志。施术者需在战斗中发出一声短促的低喝，那声音会化作无形的重锤，直接砸在敌人的精神上。被命中的人会感到自己的四肢不再属于自己，只能僵在原地，等待施术者的下一步。古籍警告，敕令的效果取决于施术者的自信——哪怕有一丝犹豫，命令就会反弹，让自己跪下。书页上盖满印章，每个印章都写着同一个词：「服从」。

暴君敕令的声音在墙壁间反射时会产生回声，那回声偶尔会先于原声到达敌人耳中。善于利用这一点的施术者能让敌人在听见命令前就开始服从。

暴君敕令修炼到高阶时，施术者可以让命令以文字形式写在空气中。那些文字会持续燃烧，直到被执行或被更强的意志撕碎。

## 设计意图

为力量型职业提供精神控制手段，强化威压与战场统治感。
