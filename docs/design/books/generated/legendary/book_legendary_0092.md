# 《禁术：泰坦之握》

## 基础信息

- **书籍 ID**：`book_legendary_0092`
- **关联技能**：`legendary_titan_grasp`
- **使用效果**：阅读后解锁 `legendary_titan_grasp`；若已学会，提升 `current_mastery +180`，并允许将一名敌人抓起投掷，造成撞击范围伤害。
- **阅读要求**：角色职业标签含 `warrior` 或 `berserker`；基础 `力量 ≥ 18`、体质 `≥ 14`。
- **稀有度**：传说（Legendary）
- **建议投放**：泰坦遗迹、力量商人、举鼎任务奖励、传说级宝箱。

## 书籍内容

泰坦之握是一本教人如何用双手握住命运的书。书中说，真正的力量不是挥拳的速度，而是抓住某个东西后，没有任何力量能让你松手。修习者需在冥想中想象自己的手掌越来越大，直至能握住山脊、河流乃至敌人的整个身体。战斗中，施术者可以抓住一名敌人，将其举过头顶，然后像投掷石块一样砸向地面。古籍警告，泰坦的力量会残留在手臂中，许多修习者的骨骼逐渐变形，最终连门把手都无法正常握住。

泰坦之握修习者的手掌骨骼会逐渐增生，最终形成类似爪子的结构。一位著名战士把这双手改造成了武器，但再也无法拿起酒杯或拥抱自己的孩子。

泰坦之握修习者的脚步声会变得沉重，走在木桥上会发出类似鼓点的回响。孩子们会跟着这节奏拍手，却不知道这是危险的信号。

## 设计意图

为力量型战士提供抓取控制与范围伤害，强化前排压迫感。
