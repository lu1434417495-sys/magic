# 《禁术：傀儡丝线》

## 基础信息

- **书籍 ID**：`book_legendary_0073`
- **关联技能**：`legendary_puppet_strings`
- **使用效果**：阅读后解锁 `legendary_puppet_strings`；若已学会，提升 `current_mastery +170`，并允许操控一名敌人 2 秒，使其攻击最近目标。
- **阅读要求**：角色职业标签含 `rogue` 或 `mage`；基础 `敏捷 ≥ 14`、智力 `≥ 14`。
- **稀有度**：传说（Legendary）
- **建议投放**：傀儡工坊、黑市商人、操控者任务奖励、传说级宝箱。

## 书籍内容

傀儡丝线是一本关于如何把人变成木偶的书。书中记载，人的关节之间本就存在着看不见的缝隙，只要用魔力凝结的丝线穿过这些缝隙，就能让最骄傲的战士像傀儡一样起舞。施术者需在指尖凝聚出近乎透明的细线，然后将它们射向敌人的手腕、膝盖与脊椎。古籍警告，操控活人的感觉会让人上瘾，许多修习者最终不再满足于控制敌人，而是开始控制朋友、亲人，最后甚至想控制自己。书末画着一个被丝线吊起的小人，小人脸上带着微笑。

傀儡丝线的练习通常从操控自己的手指开始，许多初学者会发现自己无法控制地做出精细动作。最严重的案例是一位画家，他的手在没有意识的情况下完成了十幅自画像。

傀儡丝线的高阶修习者可以同时操控自己的倒影，让它在镜中代替自己完成日常事务。但倒影有时会拒绝回到镜子里。

## 设计意图

提供单体心智控制，制造敌方内讧，增强盗贼/法师的战术控制手段。
