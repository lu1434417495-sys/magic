# 《灵魂灼烧》

## 基础信息

- **书籍 ID**：`book_传说禁术_0020`
- **关联技能**：`legendary_soul_scorch`
- **使用效果**：阅读后解锁 `legendary_soul_scorch`；若已学会，提升 `current_mastery +180`，并在下一次战斗中首次命中时额外燃烧目标 1 层灵魂易伤。
- **阅读要求**：角色职业标签含 `mage` 或 `warlock`；基础 `智力 ≥ 15`、意志 `≥ 12`。
- **稀有度**：传说（Legendary）
- **建议投放**：灵魂熔炉、亡灵法师塔、禁忌图书馆、恶魔契约任务。

## 书籍内容

直接点燃敌我灵魂的火焰咒术。书中说，普通火焰只能烧伤肉体，而灵魂之火以记忆为柴。施术者必须先献祭一段自己的记忆，才能将火焰投向敌人。记忆越珍贵，火焰越猛烈。许多使用者烧掉了初恋、故乡、甚至自己的名字。书页上有些段落字迹模糊，像是被什么烧过。末页只剩半句话："当你无物可烧，就……"

灵魂之火燃烧记忆时，空气中会弥漫着旧纸张与雨水混合的气味。许多施术者为了保留最后的名字，选择不再施放这门禁术。

灵魂灼烧的记忆火焰无法在雨中熄灭，却会在施术者入睡时自行复燃。

灵魂灼烧的最后记载者声称，只要烧掉所有名字，火焰便会熄灭；但他翻遍全书，发现连作者署名都已被自己提前焚毁。

他笑着烧掉了封底，连同自己的姓名一起化为灰烬。

灰烬仍在飞舞。

## 设计意图

为法师系提供跨抗性 DoT，用记忆代价包装独特的角色扮演体验。
