# 《太古冥想法》

## 基础信息

- **书籍 ID**：`book_传说禁术_0043`
- **关联技能**：`legendary_ancient_meditation`
- **使用效果**：阅读后学会冥想技能 `legendary_ancient_meditation`（`practice_tier = legendary`），永久提升 `mp_max` 上限 15%，并解锁 2 条 `known_knowledge_ids`（太古学相关）。
- **阅读要求**：无职业限制；基础 `智力 ≥ 15`、意志 `≥ 14`；已学会任意高级冥想。
- **稀有度**：传说（Legendary）
- **建议投放**：太古遗迹、沉没神庙、远古智者密室、世界尽头任务。

## 书籍内容

追溯魔力源头的冥想禁术。书中说，所有 MP 都来自一个古老的意识海洋，太古冥想可以让修习者短暂连接那片海洋。成功后魔力上限会显著提升，但意识海洋中有些存在会顺流而下，在你的梦中窥视。作者建议每次冥想后检查自己的瞳孔，若瞳孔中出现陌生图案，必须立刻停止。书中夹着一片刻有螺旋纹的贝壳。

太古冥想的贝壳媒介来自海底深渊，螺旋纹中藏着古老歌谣。每次连接意识海洋后，修习者会在耳边听见多出一种不属于任何活物的呼吸。

太古冥想的螺旋贝壳在月光下会发出极低鸣响，那是意识海洋潮起潮落的余音。

太古冥想的贝壳在连接意识海洋过久后，会从螺旋中心渗出一滴黑色液体，那是海洋深处某位存在凝视后的痕迹。

黑液不可直视，否则会看见自己从未经历过的死亡。

## 设计意图

作为冥想路线顶点，提供永久 MP 上限与知识解锁，但埋下古神注视伏笔。
