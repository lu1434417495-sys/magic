# 《逆血炼体》

## 基础信息

- **书籍 ID**：`book_传说禁术_0007`
- **关联技能**：`legendary_reverse_blood_cultivation`
- **使用效果**：阅读后学会修炼技能 `legendary_reverse_blood_cultivation`（`practice_tier = legendary`），立即解锁 `AURA` 资源链并按传说级公式提升 `aura_max/current_aura`，但每次修炼消耗少量 `current_hp`。
- **阅读要求**：无职业限制；基础 `力量 ≥ 14` 或 `体质 ≥ 14`；需先学会任意基础炼体。
- **稀有度**：传说（Legendary）
- **建议投放**：血池洞窟、武馆禁室、狂战士圣地、龙血瀑布据点。

## 书籍内容

炼体禁术，让斗气逆流于血脉。书中主张，AURA 不必从丹田生发，而是可以将血液逼入经脉，用痛楚逼迫斗气觉醒。练习者需在严寒中赤身打坐，感受血液如岩浆般倒流。成功者能快速解锁 AURA 资源链，但皮肤上会留下暗红色纹路，像被灼烧的地图。作者提醒，这些纹路一旦蔓延到心脏，便是走火入魔的前兆。书页背面画着人体经络，所有箭头都指向错误方向。

逆血炼体的古籍以冰晶石粉末压制而成，翻开时会释放出刺骨寒意。修习者必须在每章末尾用血写下自己的名字，否则斗气会在体内迷路。

逆血炼体的经络图每百年会改变一次方向，因此没有两代人的练法完全相同。

逆血炼体的成功者后背会出现一幅完整的人体地图，地图上的红点会随修炼进度移动。

红点移动时伴随刺痛，像是有活物在皮肤下游走。

## 设计意图

为非法系职业提供激进解锁 AURA 的路径，用 HP 代价制造戏剧性的成长节奏。
