# 《暗影丝线纺织》

## 基础信息

- **书籍 ID**：`book_工艺制作_0040`
- **关联技能**：`crafting_shadow_thread`
- **使用效果**：阅读后解锁 `crafting_shadow_thread`；若已学会，提升该技能 `current_mastery +110`，并提高暗影系斗篷的隐匿加成 5%。
- **阅读要求**：角色职业标签含 `rogue` 或 `mage`；已学会 `crafting_tailoring_basic` 或 `crafting_poison_coating`；基础 `敏捷 ≥ 8`。

- **建议投放**：暗影行会、幽暗地域聚落、刺客大师私人书架。

## 书籍内容

《暗影丝线纺织》教授如何把黑暗本身织入布料。书中说明暗影丝线的原料是夜蛛丝、黑曜石粉与少量墓苔汁液，纺线时必须在微光环境下进行，强光会让丝线脆化。作者强调经纬密度，过疏则无法吸附阴影，过密则布料沉重难穿。中段介绍染色技巧，天然黑色染料优于化学染剂，因为后者会在月光下泛出 unnatural 的蓝光。后半本讨论如何在斗篷边缘加入消音流苏，以及如何在口袋内衬缝制防止金属碰撞的软垫。最末一页附有一张穿暗影斗篷者的剪影图，作者标注："真正的隐匿不是看不见，而是看见了也记不住。"作者最后提醒，暗影织物在长期使用后会积累穿戴者的气息，若不及时以特殊药剂清洗，可能会在某些侦测法术下暴露位置。书中还提到，暗影丝线怕热，熨烫时必须隔着湿布用低温，否则会熔化变形。

## 设计意图

为暗影职业提供专属装备制作能力，把隐匿从数值变成需要特殊材料与工艺支持的 build 方向。
