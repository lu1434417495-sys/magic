# 《布甲缝线与内衬填充》

## 书籍内容

布甲缝线是一本讲解如何在柔软布料中隐藏防护力量的书。作者认为布甲的关键不在厚度，而在层次：外层耐磨、中层吸震、内层透气。书中详细介绍了多层布的缝合顺序，以及如何用菱格绗缝把棉絮固定成均匀的缓冲层。作者警告：针线太密会让布料变硬，太疏则填充物会聚集成团。后半本讲解了施法者长袍的特殊要求：袖口不能过紧以免妨碍手势，下摆要留有足够的活动余量。作者还建议在领口和腋下使用更轻薄的布料，因为这些部位最容易出汗，厚重的填充会影响施法者长时间保持专注。他进一步说明，一件精良的布甲应当在受击时发出闷响而不是脆响，闷响意味着冲击被填充层有效吸收。最后一页附了几种常见布料的耐魔性对照表，并写着：一件好的布甲应该让穿戴者忘记自己穿着护甲。

## 设计意图

为施法职业提供轻型护甲制作，强调舒适度与施法便利性，与重甲形成鲜明对比。
