# 《背包扩容缝制》

## 书籍内容

《背包扩容缝制》看起来像是给新手冒险者的实用手册，但作者显然有丰富的经验。全书从背负系统讲起，解释为什么扩容不能只加高度，否则会改变重心导致肩部受伤，合理的扩容应该先加宽度。第二章讲隔层设计：主袋、侧袋、隐藏袋与快速取用袋各有其尺寸比例要求。第三章介绍加固技术，包括双重缝线、金属扣环与皮革承托带的安装位置。书中还提醒，缝制背包时要考虑面料的伸缩方向，错误的方向会让背包在装满后变形。最后一章提到灰烬交界某种折叠空间材料，可以让同样大小的背包多装三成物品，但价格昂贵且需要特殊缝制手法。作者在书末总结，一个好的背包应该让负重消失，而不是让肩膀记住重量。背包的肩带内侧应使用吸汗布料，否则长途跋涉时皮肤很容易磨破。
