# 《卷轴抄写入门》

## 基础信息

- **书籍 ID**：`book_工艺制作_0108`
- **关联技能**：`crafting_scroll_scribing`
- **使用效果**：阅读后解锁 `crafting_scroll_scribing`；若已学会，提升 `current_mastery +80`，并使下一次抄写的卷轴施法者等级视为 +1。
- **阅读要求**：角色职业标签含 `mage` 或 `wizard`；基础 `智力 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：法师塔书房、魔法集市、学者任务奖励。

## 书籍内容

卷轴抄写入门的第一句话是：墨水会记住你抄写时的心情。作者认为，卷轴不仅是法术的容器，更是施术者精神状态的拓片。书中详细介绍了特制墨水的配方，包括研磨黑曜石粉、混合蒸馏夜露、以及滴入施术者自己的一滴血。抄写时要求手腕悬空、呼吸平稳，任何一个断笔都会让卷轴在激活时产生偏差。后半本讲解了如何折叠卷轴以便快速抽取，并附有几页失败案例：有的卷轴因墨水过稀而在雨水中晕开，有的因情绪波动太大而自燃。作者还提到，初学者应当从只有一个音节的简单法术开始抄写，妄图一步登天抄写高阶法术的人往往会在第一次激活时烧掉自己的眉毛。他建议每天最多抄写三张卷轴，超过这个数量精神力会大幅下降。最后一页写着：好的卷轴像一位安静的朋友，你不需要解释，它就知道你想做什么。

## 设计意图

为法师提供法术储备的制造方式，让非法师职业也能有限度地使用魔法道具，扩展战术选择。
