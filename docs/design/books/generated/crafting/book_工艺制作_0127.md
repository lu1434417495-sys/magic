# 《透镜研磨与侦测镜片》

## 书籍内容

透镜研磨是一门把粗糙玻璃变成清澈眼睛的技艺。作者从选料开始：普通石英砂适合练习，水晶碎片适合中级镜片，而龙晶粉末则是高级镜片的核心材料。书中详细描述了研磨的三个阶段：粗磨定形、细磨抛光、以及最后的镀膜处理。作者警告：每一个阶段都要彻底清洗镜片，否则上一阶段的磨料会划伤已经抛光的表面。后半本讲解了不同曲率对视野范围与放大倍率的影响，并附有一张根据目标距离选择镜片规格的表格。作者还建议在研磨最后阶段加入少量月光泉水，据说能让镜片在黑暗中捕捉到更微弱的光线。他进一步提醒，镜片边缘的厚度必须均匀，任何不规则都会导致成像出现彩虹状的色散。最后一页写着：好的镜片不是让你看得更远，而是让你更早看见那些正在靠近你的东西。

## 设计意图

引入侦察辅助道具制作，让感知属性与工艺系统产生联动，增强探索与先攻阶段的战术信息优势。
