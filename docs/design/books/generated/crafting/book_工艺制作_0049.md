# 《神器修复残篇》

## 基础信息

- **书籍 ID**：`book_工艺制作_0049`
- **关联技能**：`crafting_artifact_repair_fragment`
- **使用效果**：阅读后解锁 `crafting_artifact_repair_fragment`；若已学会，提升该技能 `current_mastery +120`，并恢复神器类装备 10% 的已损失耐久与属性。
- **阅读要求**：角色职业标签含 `warrior` 或 `mage`；已学会 `crafting_soul_hammer_stance` 或 `crafting_mana_circuit_etch`；基础 `智力 ≥ 10`。
- **稀有度**：传说（Legendary）
- **建议投放**：远古遗迹核心、失落工坊、世界任务终章奖励。

## 书籍内容

《神器修复残篇》只有半本，后半部分已被烧毁。书中说明神器不是普通装备，它们拥有自己的记忆与意志，修复时不能简单更换零件，而要先与器物沟通。作者强调使用与原材同源的材料，替代品会让神器产生排斥，轻则属性下降，重则彻底沉寂。中段介绍几种修复仪式：重锻唤醒金属记忆，符文重塑导魔路径，血誓则让修复者与器物建立临时契约。后半本因为残缺只剩下片段，提到"听它说话"、"不要强加你的形状"以及"最后一步需要放弃"。最末一页有一幅被烟熏黑的插图，似乎是一件破碎的王冠正在自行拼接。作者最后警告，修复神器时不要心存贪念，试图借机增强器物力量往往会触怒其沉睡的意志，招致反噬。书中还提到，修复后的神器需要一段时间的"静养"，在此期间不可频繁使用，否则新旧材料之间难以真正融合。

## 设计意图

为顶级工匠提供神器维护能力，让玩家珍惜稀有装备，延长传说级道具的使用寿命与故事感。
