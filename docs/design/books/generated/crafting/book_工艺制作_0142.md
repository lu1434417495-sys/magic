# 《精密连弩改造》

## 基础信息

- **书籍 ID**：`book_工艺制作_0142`
- **关联技能**：`crafting_repeating_crossbow`
- **使用效果**：阅读后解锁 `crafting_repeating_crossbow`；若已学会，提升 `current_mastery +140`，并使下一次改造的连弩装填动作 -1 行动点。
- **阅读要求**：角色职业标签含 `archer`、`rogue` 或 `engineer`；基础 `敏捷 ≥ 13`、智力 `≥ 10`。
- **稀有度**：史诗（Epic）
- **建议投放**：侏儒军械库、暗杀者工坊、攻城器械奖励。

## 书籍内容

精密连弩改造是一本讲解如何在有限空间内实现快速射击的机械手册。作者从弹匣结构开始，分析重力供弹与弹簧供弹的优缺点，指出重力供弹简单可靠但受姿态限制，弹簧供弹快速却容易卡壳。书中详细描述了弩机触发机构的微调：扳机行程太长会延误射击，太短则容易误发。后半本讲解了不同材质弩臂的蓄能效率，以及如何通过蜡煮增强韧性。作者还附有一张“常见卡箭故障排查”流程图。书中还提到，连弩的保养频率远高于普通弓弩，每次战斗后都必须清理弩槽中的碎屑和火药残渣，否则下一次装填就可能发生致命故障。他进一步建议，在潮湿环境中应当为连弩涂一层薄薄的鱼油防锈，但油量必须极少，过多会吸附灰尘。最后一页写着：连弩的价值不在于单发威力，而在于让敌人在还没反应过来之前就身中数箭。

## 设计意图

为远程职业提供高级武器改造，将行动效率与机械工艺结合，强化高频率输出的战斗风格。
