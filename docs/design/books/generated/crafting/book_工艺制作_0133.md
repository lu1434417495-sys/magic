# 《附魔武器：微光之锋》

## 基础信息

- **书籍 ID**：`book_工艺制作_0133`
- **关联技能**：`crafting_glimmer_weapon_enchant`
- **使用效果**：阅读后解锁 `crafting_glimmer_weapon_enchant`；若已学会，提升 `current_mastery +140`，并使下一次附魔的武器光属性伤害 +2。
- **阅读要求**：角色职业标签含 `mage` 或 `paladin`；基础 `智力 ≥ 12`。
- **稀有度**：史诗（Epic）
- **建议投放**：光之祭坛、高阶附魔师、圣骑士团宝库。

## 书籍内容

微光之锋是一种将纯净魔力固定在武器刃口的附魔技术。作者从净化武器开始，讲解如何用圣水清洗金属表面、用月光暴晒去除杂质、再用附魔底漆建立魔力锚点。书中强调注入魔力时要保持情绪稳定，因为愤怒会让光芒变得刺眼而难以控制，恐惧则会让光芒黯淡。后半本描述了符文的绘制顺序：先引光、再聚光、最后锁光，任何一步出错都会导致附魔在几天内衰减。作者还附有一张不同金属对光魔力亲和度的表格。书中还提到，微光之锋在完全黑暗的环境中会吸引某些喜光昆虫，因此经验丰富的使用者会在刀鞘内衬一层遮光绒布。他进一步提醒，附魔完成后应当在黎明时分进行第一次试斩，因为作者相信晨光能为新生的光芒祝福。最后一页写着：真正的光之武器在黑暗中不会炫耀，它只会在需要的时候亮起来。

## 设计意图

为中期玩家提供元素附魔武器制作，把光属性伤害与特定职业绑定，扩展装备Build的可能性。
