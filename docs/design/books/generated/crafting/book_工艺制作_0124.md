# 《附魔底漆与符文颜料》

## 基础信息

- **书籍 ID**：`book_工艺制作_0124`
- **关联技能**：`crafting_enchant_primer`
- **使用效果**：阅读后解锁 `crafting_enchant_primer`；若已学会，提升 `current_mastery +110`，并使下一次调制的附魔底漆持续时间 +1 场战斗。
- **阅读要求**：角色职业标签含 `mage` 或 `enchanter`；基础 `智力 ≥ 11`。
- **稀有度**：稀有（Rare）
- **建议投放**：魔法学院工坊、附魔塔、奥术任务奖励。

## 书籍内容

附魔底漆是连接普通物品与魔法能量的桥梁，这本书讲解的就是如何调制这层桥梁。作者从魔力溶剂开始：蒸馏月光花露、研磨奥术水晶粉、混合稳定用的银叶草汁液。书中强调三种成分的加入顺序不可颠倒，否则底漆会在涂抹时自燃或结晶。后半本讲解了底漆与不同材质的亲和性：金属需要氧化层打底，木材需要封闭孔隙，皮革则要先用弱酸处理。作者还附有一张常见失败现象的诊断表，包括“符文不发光”“发光后迅速熄灭”和“发光但无效果”。书中还建议在调配时轻声念诵材料名称，因为作者相信声音振动能帮助成分更均匀地融合。他进一步提醒，底漆涂刷后必须在月光下静置一夜，阳光直射会让底漆中的魔力成分过早固化。最后一页写着：附魔不是给物品涂上颜色，而是让物品学会一种新的呼吸方式。

## 设计意图

作为附魔系统的前置工艺，让玩家把制作与魔法强化结合，为装备附魔与技能强化铺平道路。
