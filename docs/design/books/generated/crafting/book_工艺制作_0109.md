# 《圣徽浇铸与祝福刻印》

## 基础信息

- **书籍 ID**：`book_工艺制作_0109`
- **关联技能**：`crafting_holy_symbol`
- **使用效果**：阅读后解锁 `crafting_holy_symbol`；若已学会，提升 `current_mastery +80`，并使下一次浇铸的圣徽对亡灵伤害加成 +5%。
- **阅读要求**：角色职业标签含 `priest` 或 `cleric`；基础 `意志 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：教堂工坊、圣骑士营地、信仰任务奖励。

## 书籍内容

圣徽浇铸与祝福刻印是一本同时讲解工艺与仪式的手册。作者强调，金属本身的纯度并不重要，重要的是铸造者是否在浇铸时保持虔诚。书中记录了从蜡模制作到熔银浇注的完整流程，并在每一页边缘都印有一句短祷文。刻印章节则详细介绍了神圣符文的笔画顺序，警告“逆序刻画会抵消祝福，甚至引来不洁之物”。后半本附有多种教派的徽记变体，说明圣徽的形态可以因信仰而异。作者还在书末补充说，真正的圣徽应当由使用者自己参与至少一道工序，哪怕是最后的打磨，因为陌生的圣徽在祈祷时就像借来的鞋子一样不合脚。他进一步写道，许多牧师会在圣徽背面刻上自己的守护圣徒之名，以增强精神共鸣。最后一页写着：圣徽不是护身符，它是你向世界宣告立场的声音。当亡灵逼近时，这声音比任何盔甲都响亮。

## 设计意图

为牧师系职业提供专属装备制作，把信仰表达与工艺步骤绑定，强化角色扮演与战斗增益的结合。
