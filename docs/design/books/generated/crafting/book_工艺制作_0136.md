# 《爆裂箭矢与火药填装》

## 基础信息

- **书籍 ID**：`book_工艺制作_0136`
- **关联技能**：`crafting_explosive_arrow`
- **使用效果**：阅读后解锁 `crafting_explosive_arrow`；若已学会，提升 `current_mastery +140`，并使下一次制作的爆裂箭爆炸半径 +1 格。
- **阅读要求**：角色职业标签含 `archer` 或 `engineer`；基础 `敏捷 ≥ 12`、智力 `≥ 10`。
- **稀有度**：史诗（Epic）
- **建议投放**：矮人军火库、攻城工坊、遗迹探险奖励。

## 书籍内容

爆裂箭矢是把远程射击与范围爆破结合的危险艺术。作者从箭杆减重开始，因为爆裂部会增加前端重量，影响飞行稳定性。书中详细讲解了火药腔的设计：太大会在发射时提前爆燃，太小则威力不足。作者强调引信的长度与燃烧速度必须匹配弓的射程，否则箭还没到目标就会在空中炸开。后半本记录了安全操作流程，包括“未装箭时不点燃引信”和“存放时箭尖朝下”。作者还附有一张不同弓型对应的配重建议表。书中还提到，爆裂箭在雨天极不稳定，因为湿气会改变火药燃烧速度，因此有经验的射手会随身携带油布包裹的干燥火药备用。他进一步警告，绝对不要用爆裂箭射杀小型飞行生物，因为它们在空中被击中后往往会拖着火焰坠落到意想不到的地方。最后一页写着：爆裂箭最危险的时刻不是命中，而是你把它从箭筒里抽出来的时候。

## 设计意图

为弓箭手提供范围伤害弹药，拓展远程职业的战术定位，强化战前准备与危险操作的张力。
