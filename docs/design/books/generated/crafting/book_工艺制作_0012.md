# 《软甲缝制指南》

## 基础信息

- **书籍 ID**：`book_工艺制作_0012`
- **关联技能**：`crafting_gambeson_sewing`
- **使用效果**：阅读后解锁 `crafting_gambeson_sewing`；若已学会，提升该技能 `current_mastery +90`，并提高软甲对切割伤害的减伤 2 点。
- **阅读要求**：无职业限制；已学会 `crafting_tailoring_basic`；基础 `敏捷 ≥ 6`。

- **建议投放**：民兵营地、佣兵后勤车、低级防具商人。

## 书籍内容

《软甲缝制指南》教授一种被重甲骑士轻视、却被普通士兵珍视的技艺。书中说明软甲由多层亚麻或棉布交叠缝制而成，层数越多防护越好，但也越重越闷热。作者推荐标准配置为十二层，前胸与后背加十六层补强。中段详细讲解菱形绗缝法，这种走线既能固定填充物，又能分散刀砍的冲击。后半本讨论如何清洗与晾晒软甲，强调不可拧干，否则内部棉絮会结块。最末一页附有各种身形的裁剪图，并提醒读者预留腋下褶皱，否则穿上后无法举剑过头。扉页上有一行血迹，似乎是某位前任主人留下的实战背书。作者最后指出，软甲的领口与袖口必须用双线加固，因为这些部位在战斗中磨损最快，一旦脱线便会让整层防护松脱。书中还提醒，缝软甲的线应选用结实的亚麻线，普通棉线经不起反复拉扯。

## 设计意图

为战士与牧师等前线职业提供廉价且有效的护甲选择，强化早期资源匮乏时的生存能力。
