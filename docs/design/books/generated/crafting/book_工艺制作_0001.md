# 《冶铁初阶：锻造基础》

## 基础信息

- **书籍 ID**：`book_工艺制作_0001`
- **关联技能**：`crafting_forge_basic`
- **使用效果**：阅读后解锁 `crafting_forge_basic`；若已学会，提升该技能 `current_mastery +80`，并降低初次锻造普通金属武器的失误率 10%。
- **阅读要求**：无职业限制；基础 `力量 ≥ 6`。
- **稀有度**：普通（Common）
- **建议投放**：新手村铁匠铺、初始据点工坊、通用技能商人。

## 书籍内容

《冶铁初阶》是学徒铁匠的第一本教材。书中从选矿开始讲起，分辨磁铁矿、赤铁矿与贫矿的区别，再教读者如何搭建简易鼓风炉，控制炉温让矿石软化而非熔化。作者反复强调火候：太旺则铁水含碳过高变脆，太弱则杂质无法排出。后半本记录了十余种常见锤纹，每一种纹路对应不同的韧性与锋利度。最后几页是护手、剑镡与矛头的基础模子，附注"先打一百把废铁，再谈成品"。许多老工匠在书边写满批注，提醒后人打铁时重心要稳，呼吸要匀，因为急躁的锤子会记住每一次颤抖。书中还附有一张炉温观察表，建议学徒在每次开炉时记录火焰颜色与工件状态，这些记录比任何口诀都更能培养真正的火候直觉。作者在最后告诫，冶铁最忌贪快，一次失败的淬火可能让数小时捶打造成的前功尽弃。
