# 《炼金火焰瓶》

## 基础信息

- **书籍 ID**：`book_工艺制作_0028`
- **关联技能**：`crafting_alchemy_fire_flask`
- **使用效果**：阅读后解锁 `crafting_alchemy_fire_flask`；若已学会，提升该技能 `current_mastery +100`，并提高火焰瓶的燃烧范围 1 格。
- **阅读要求**：无职业限制；已学会 `crafting_alchemy_basic`；基础 `智力 ≥ 7`。
- **稀有度**：精良（Uncommon）
- **建议投放**：炼金术士实验室、军械库、火焰地城入口。

## 书籍内容

《炼金火焰瓶》是一本热情洋溢但危险的读物。书中先讲瓶体选择，厚壁玻璃瓶能防止运输中意外破裂，但过厚会增加投掷重量。作者详细讲解燃烧剂的配方：松脂、硝石粉与少量金属粉末的混合物能在撞击时产生持久火焰。中段介绍引燃方式，布条引燃简单可靠，化学引燃则更难被水浇灭。后半本讨论投掷技巧与储存禁忌，强调不可与冰水药剂混放，温差会导致瓶体炸裂。最末一页是一份事故记录，某位学徒因把火焰瓶放在腰带内侧而付出了眉毛的代价。作者最后提醒，制作火焰瓶时应在通风良好的环境下操作，任何溅出的燃烧剂都可能在数秒内引燃工作台与衣物。书中还提到，火焰瓶投掷后应迅速转移位置，因为燃烧产生的热气流会暴露投掷者的方位。书中还建议，瓶口塞子应选用浸过蜡的软木，既能密封又能在撞击时碎裂释放燃烧剂。

## 设计意图

为玩家提供可控的范围持续伤害道具，扩展炼金术在战斗中的战术价值。
