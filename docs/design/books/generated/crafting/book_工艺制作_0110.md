# 《木工车削：法杖胚材》

## 基础信息

- **书籍 ID**：`book_工艺制作_0110`
- **关联技能**：`crafting_staff_woodwork`
- **使用效果**：阅读后解锁 `crafting_staff_woodwork`；若已学会，提升 `current_mastery +80`，并使下一次车削的法杖 MP 上限加成 +2。
- **阅读要求**：角色职业标签含 `mage`、`priest` 或 `druid`；基础 `智力 ≥ 6`。
- **稀有度**：普通（Common）
- **建议投放**：德鲁伊林地、法师塔仓库、林间匠人小屋。

## 书籍内容

法杖胚材的处理是一门被低估的学问，这本书试图纠正这种偏见。作者从选木开始讲起：橡木稳重、白蜡坚韧、紫杉敏感，而枯死的树枝即使看起来笔直也绝不能用。书中详细描述了如何用弯刀剥去树皮、用刨子修正弧度、用火烤法释放木材内部应力。作者强调，法杖不是死的工具，它会随着使用者的魔力流动而微微弯曲。后半本讲解了如何根据施法者的手掌尺寸调整握把粗细，以及如何在杖芯预留镶嵌水晶的凹槽。作者还提醒，砍伐用于法杖的树木最好在新月之夜进行，因为满月时树木体内的汁液过于活跃，制成的法杖容易在施法时产生不可控的共振。他补充说，真正与施法者契合的法杖会在第一次握住时让人感到轻微的温暖或清凉。最后一页写着：一根好法杖会在你第一次施法时发出叹息，那是木材终于找到归属的声音。

## 设计意图

为施法职业提供早期武器制作入口，将法杖视为魔力传导媒介，与冥想解锁的 MP 资源形成成长联动。
