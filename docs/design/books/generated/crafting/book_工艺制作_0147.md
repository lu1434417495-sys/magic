# 《禁断魔像核心》

## 基础信息

- **书籍 ID**：`book_工艺制作_0147`
- **关联技能**：`crafting_forbidden_golem_core`
- **使用效果**：阅读后解锁 `crafting_forbidden_golem_core`；若已学会，提升 `current_mastery +170`，并使下一次制作的魔像核心生命值 +15%。
- **阅读要求**：角色职业标签含 `mage`、`warlock` 或 `engineer`；基础 `智力 ≥ 15`、力量 `≥ 10`。
- **稀有度**：传说（Legendary）
- **建议投放**：古代魔像工坊、禁忌图书馆、深渊机械遗迹。

## 书籍内容

禁断魔像核心是一本讲解如何赋予无生命物体以行动能力的黑暗工艺书。作者从核心材料开始：灵魂石、活化金属、以及被封印的微小元素精魄。书中强调三个核心必须平衡：动力核心提供能量，控制核心接收指令，束缚核心防止暴走。任何一环失衡都会导致魔像在激活后攻击最近的活物。后半本详细描述了核心的封装仪式，需要在完全黑暗中进行，因为光线会干扰精魄与金属的融合。作者还附有一张“暴走征兆”表，包括不受控的颤抖、发出低语、以及眼睛发光颜色改变。书中还提到，古代魔像工匠会在每个核心深处埋藏一段禁口令，只有核心真正认可的主人才能安全激活它。他进一步警告，魔像在夜间会比白天更容易产生自主意识，因此日落前必须重新诵读束缚咒语。最后一页写着：当你创造一个仆人时，最好先想好如何销毁它。

## 设计意图

为召唤/机械系构筑提供传说级制作入口，让魔像成为可控的战场单位，同时用风险设定增加叙事张力。
