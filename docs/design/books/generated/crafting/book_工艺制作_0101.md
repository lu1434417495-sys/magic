# 《铁砧初鸣：短剑锻造札记》

## 基础信息

- **书籍 ID**：`book_工艺制作_0101`
- **关联技能**：`crafting_short_sword_smith`
- **使用效果**：阅读后解锁 `crafting_short_sword_smith`；若已学会，提升 `current_mastery +80`，并使你下一次锻造的短剑获得 +1 最小伤害。
- **阅读要求**：无职业限制；基础 `力量 ≥ 6`。
- **稀有度**：普通（Common）
- **建议投放**：新手铁匠铺、矿洞营地、通用工艺商人。

## 书籍内容

铁砧初鸣是学徒离开师傅庇护后的第一本实操笔记。它没有讲如何打造名剑，只教人把一块粗铁变成不会折断的短剑。作者反复强调三件事：炭火要均匀、锤击要沿着刃线、淬火时不能犹豫。书中夹着一张被油烟熏黄的草图，画的是短剑横截面从厚到薄的变化。后半部分记录了七种失败案例，包括“锤面过热导致晶粒粗大”和“收尾时反向弯曲造成暗裂”。书中还提到作者年轻时曾为一位骑士打造短剑，因急于求成而省略了回火步骤，结果剑在决斗中断裂，骑士因此失去三根手指。这段往事让他此后每把剑都要反复弯折测试。作者认为检验短剑是否合格的最佳方式，不是看它能否斩断稻草，而是看它能否在两块石头之间被压弯后仍恢复原状。最后一页写着：好的短剑不在于花纹，而在于第一次刺入敌人护甲时不会从根部折断。作者建议每个学徒先打造十把平庸的剑，再去追求自己的杰作。

## 设计意图

作为工艺制作系列的基础武器锻造入门书，降低玩家对锻造系统的认知门槛，用短剑这种泛用武器引导首次制作体验，并附带一次性激励效果鼓励立刻实践。
