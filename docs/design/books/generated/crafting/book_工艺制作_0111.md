# 《烹饪笔记：行军干粮》

## 基础信息

- **书籍 ID**：`book_工艺制作_0111`
- **关联技能**：`crafting_trail_rations`
- **使用效果**：阅读后解锁 `crafting_trail_rations`；若已学会，提升 `current_mastery +80`，并使下一次制作的干粮额外恢复 5 点体力。
- **阅读要求**：无职业限制；基础 `体质 ≥ 5`。
- **稀有度**：普通（Common）
- **建议投放**：军营厨房、旅行商人、营地篝火旁。

## 书籍内容

行军干粮不是美食，而是让队伍在恶劣环境中保持移动能力的燃料。作者从挑选耐储存食材开始：风干肉、硬奶酪、坚果、蜂蜜与粗麦饼。书中详细介绍了如何将肉切成一指厚的薄片，用盐与香草腌制后挂在通风处阴干，直到表面长出白色的盐霜。作者警告：千万不要用烟熏，烟味会引来野兽。后半本讲解了干粮的配比原则，强调碳水化合物与脂肪的比例要适合长途行军。作者还建议在干粮袋底部放一小包干燥木炭，既能吸湿又能掩盖食物气味，避免被嗅觉灵敏的怪物追踪。他进一步提醒，制作干粮时必须戴手套，因为手上的盐分会让肉干过早腐败，而这一点往往被新手忽视。一份合格的干粮应当能直接咬动，而不是硬到需要借助短剑劈开。最后一页附有一张清单，标题是“七日份口粮的标准配置”，并附注“如果队友抱怨难吃，说明他们还不太饿”。
