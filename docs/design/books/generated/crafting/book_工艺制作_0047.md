# 《活体护甲培育》

## 基础信息

- **书籍 ID**：`book_工艺制作_0047`
- **关联技能**：`crafting_living_armor_culture`
- **使用效果**：阅读后解锁 `crafting_living_armor_culture`；若已学会，提升该技能 `current_mastery +120`，并使护甲在战斗中缓慢自我修复耐久。
- **阅读要求**：角色职业标签含 `mage` 或 `rogue`；已学会 `crafting_leather_hardening` 或 `crafting_shadow_thread`；基础 `体质 ≥ 9`。
- **稀有度**：史诗（Epic）
- **建议投放**：远古德鲁伊圣地、共生体实验室、深渊边缘聚落。

## 书籍内容

《活体护甲培育》把制作变成养育。书中说明活体护甲的基底是一种能与宿主共生的菌丝或藤蔓，必须在穿戴者体温与汗液中培育数周才能定型。作者强调喂养比缝纫更重要，护甲需要定期以特定 nutrient 浸润，否则会枯萎变硬。中段讲解如何让护甲形成局部硬化区与柔软区，硬化区防护要害，柔软区保证行动。后半本讨论共生关系的风险，活体护甲可能因饥饿而反噬宿主，或因情绪波动而收缩。最末一页附有一份每日养护表，包括光照、湿度与营养液的精确剂量。书尾警告："这不是装备，是另一种生命，请善待它。"作者最后提醒，活体护甲在宿主死亡后会迅速干枯，无法转交给他人使用，因此每一件都是独一无二的存在。书中还提到，培育活体护甲的房间应远离普通布料，否则菌丝可能蔓延并污染其他衣物。

## 设计意图

引入非常规护甲制作工艺，为法师与盗贼等职业提供符合角色设定的强力装备来源。
