# 《魔纹护甲与抗蚀涂层》

## 基础信息

- **书籍 ID**：`book_工艺制作_0134`
- **关联技能**：`crafting_arcane_armor_coating`
- **使用效果**：阅读后解锁 `crafting_arcane_armor_coating`；若已学会，提升 `current_mastery +140`，并使下一次涂覆的护甲元素抗性 +5%。
- **阅读要求**：角色职业标签含 `mage`、`enchanter` 或 `warlock`；基础 `智力 ≥ 12`。
- **稀有度**：史诗（Epic）
- **建议投放**：奥术学院实验室、元素裂隙据点、高阶商人。

## 书籍内容

魔纹护甲与抗蚀涂层讲解如何在金属或皮革表面绘制微型魔法阵以抵御元素伤害。作者从涂层基底开始：普通金属需要酸洗以增加附着力，皮革则需要先涂一层隔离膜防止化学腐蚀。书中详细描述了四种基础抗蚀纹：火焰纹用锯齿线象征热度分散，寒冰纹用闭合环象征低温闭锁，闪电纹用分叉枝象征电荷导流，酸蚀纹则用螺旋纹引导液体滑落。后半本讲解了多层涂覆的顺序，警告不同元素纹不能直接接触，否则会互相中和。作者还附有一张“涂层厚度与耐久度关系图”。书中还提到，抗蚀涂层会随着使用逐渐磨损，因此作者建议在每次大战后用软布蘸取专用养护液轻轻擦拭，以延长涂层寿命。他进一步说明，涂层出现细小裂纹是正常的，但如果裂纹呈放射状扩散，说明该部位曾承受过接近极限的元素冲击。最后一页写着：护甲上的魔纹不是装饰，它们是你与元素之间谈判的筹码。

## 设计意图

为玩家提供元素防御向的护甲强化，让面对特定敌人时可以针对性准备，增强策略深度。
