# 《盗贼工具打磨》

## 基础信息

- **书籍 ID**：`book_工艺制作_0113`
- **关联技能**：`crafting_thieves_tools`
- **使用效果**：阅读后解锁 `crafting_thieves_tools`；若已学会，提升 `current_mastery +80`，并使下一次制作的撬锁工具成功率 +5%。
- **阅读要求**：角色职业标签含 `rogue` 或 `thief`；基础 `敏捷 ≥ 7`。
- **稀有度**：普通（Common）
- **建议投放**：盗贼公会、黑市工具摊、潜入任务奖励。

## 书籍内容

盗贼工具打磨是一本薄得可以塞进靴筒的小册子，讲解如何维护一套不起眼的金属工具。作者从撬棍的弧度开始讲起，指出太直会折断锁舌，太弯则无法插入锁孔。书中详细介绍了钩针、扭力扳手与探针的打磨角度，强调所有工具表面必须光滑，否则会在锁芯内留下刮痕。后半本讲解了工具的收纳方式：每根针都要独立固定，避免互相碰撞发出声响。作者还附了一张常见锁具内部结构的示意图，并在旁边标注“看见弹子，不要急着推，先听声音”。作者还建议在每次任务前用烛火微微烘烤工具尖端，这样不仅能去除湿气，还能让金属在黑暗中少一分反光。他进一步提醒，工具的长度要根据目标锁具的深度定制，过长会在锁芯内弯曲，过短则无法触到底部弹子。最后一页写着：最好的工具不是最贵的那套，而是你闭着眼睛也能摸到正确那一根的那套。
