# 《重甲关节锻造》

- **使用效果**：阅读后解锁 `crafting_plate_joint`；若已学会，提升该技能 `current_mastery +110`，并降低重甲对行动速度的惩罚 3%。
- **阅读要求**：角色职业标签含 `warrior` 或 `priest`；已学会 `crafting_forge_heat_control` 或 `crafting_chain_mail_ring`；基础 `力量 ≥ 8`。

## 书籍内容

《重甲关节锻造》解决一个核心矛盾：防护与灵活不可兼得，但可以通过精妙关节设计部分化解。书中说明肩甲、肘甲与膝甲必须使用多块弧形甲片交叠，既覆盖关节又不限制弯曲。作者强调铰链销的直径与材质，过细的销子会在反复运动中磨损，过粗则会压迫关节。中段介绍皮带与甲片的连接方式，内衬皮革能减少金属对皮肤的摩擦。后半本讨论全甲试穿后的微调，包括调整背带长度与腰封位置，让重量分散到肩胯而非单纯挂在肩上。最末一页是一套完整板甲的拆解图，标注了三十七个可动关节。作者最后提醒，关节处的甲片边缘必须打磨光滑，任何毛刺都会在穿戴者挥砍或奔跑时反复刮擦内衬，造成皮肉擦伤甚至感染。书中还建议，试穿板甲后应在模拟战斗姿态下活动十分钟，才能发现平时站立时察觉不到的压迫点。

## 设计意图

为重装职业提供进阶护甲制作能力，让板甲不仅是防御数字，更是需要精密工艺的装备类型。
