# 《淬毒小瓶与涂层》

## 基础信息

- **书籍 ID**：`book_工艺制作_0025`
- **关联技能**：`crafting_poison_coating`
- **使用效果**：阅读后解锁 `crafting_poison_coating`；若已学会，提升该技能 `current_mastery +100`，并延长武器淬毒持续时间 1 场战斗。
- **阅读要求**：角色职业标签含 `rogue` 或 `archer`；基础 `敏捷 ≥ 7`。
- **稀有度**：精良（Uncommon）
- **建议投放**：盗贼公会药房、刺客联络点、黑市炼金商。

## 书籍内容

《淬毒小瓶与涂层》是一本被蜡封住边缘的小册子，防止翻阅时中毒。书中先讲容器的密封：软木塞加蜂蜡是标准配置，但接触强腐蚀性毒液时必须使用琉璃瓶。作者强调涂层厚度，过厚会结成块状脱落，过薄则无法有效注入伤口。中段介绍植物毒、矿物毒与动物毒的不同特性，以及对应解药的携带建议。后半本讨论如何在刀刃、箭头与陷阱刺上均匀涂毒，并提醒读者切勿在进食前触碰涂毒器具。最末一页是一份免责声明，用极小字体写着："本书作者不对任何误伤、误舔与误用承担责任。"作者还在附录中警告，涂毒后的武器应单独存放，与普通装备混放可能导致毒素残留污染，令使用者在不知不觉中中毒。此外，书中还建议每次涂毒前检查武器表面是否有旧涂层残留，多层毒剂叠加可能产生不可控的化学反应。书中最后提醒，毒药瓶的标签必须用代码书写，以免被无关者误读或误拿。

## 设计意图

为盗贼与游侠提供战术耗材制作能力，让毒伤成为可控的战前准备环节而非单纯的技能效果。
