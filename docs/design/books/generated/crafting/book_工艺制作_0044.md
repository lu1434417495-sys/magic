# 《不朽防腐剂》

## 基础信息

- **书籍 ID**：`book_工艺制作_0044`
- **关联技能**：`crafting_everlasting_preservative`
- **使用效果**：阅读后解锁 `crafting_everlasting_preservative`；若已学会，提升该技能 `current_mastery +120`，并使药剂与食材的保质期变为永久。
- **阅读要求**：角色职业标签含 `mage` 或 `archer`；已学会 `crafting_alchemy_distillation` 与 `crafting_herb_grinding`；基础 `智力 ≥ 9`。
- **稀有度**：史诗（Epic）
- **建议投放**：炼金宗师密室、远古药剂库、时间位面商人。

## 书籍内容

《不朽防腐剂》挑战了所有食材都会腐败的常识。书中说明真正的防腐不是杀死生命，而是让生命停留在某个瞬间。作者使用月见草油、琥珀酸与微量时间砂为原料，调配出一种能让有机物保持原状的透明液体。中段讲解浸泡时间与浓度的关系，过浓会让材料变得僵硬如木，过稀则只能延缓腐败数年。后半本讨论防腐剂的伦理边界，保存尸体、食物与药材是一回事，但有人曾试图用它保存活人，结果只得到了一具不会腐烂的空壳。最末一页附有一份安全使用誓言，要求制作者承诺"只停驻物质，不囚禁灵魂"。作者最后提醒，时间砂极为稀有且难以控制，每次用量必须精确到厘克，过量会让被保存物缓慢向过去坍缩，最终化为虚无。书中还警告，被防腐剂处理过的食材不可长期食用，虽然不会变质，但其中的时间能量可能侵蚀食用者的生命力。

## 设计意图

为高级炼金师提供后勤神技，让稀有材料与高级补给可以长期储备，改变玩家的资源管理策略。
