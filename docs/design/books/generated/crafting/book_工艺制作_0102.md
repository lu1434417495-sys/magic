# 《皮料鞣制与轻型护具》

## 书籍内容

这本书从一张还连着毛的生皮开始讲起，作者认为鞣制的关键不在化学药剂，而在耐心。第一章教人如何用盐和木灰去除残肉，第二章讲解树皮鞣液的发酵时间，第三章才谈到裁剪。书中反复强调：皮革在鞣制过程中会收缩，所以下料时要预留指宽。作者画了一幅小型动物剥皮图，并在旁边标注“不要从腹部正中央下刀，那里的皮最薄”。后半本记录了三种常见错误：鞣液过酸导致皮革发脆、晾晒时阳光直射造成变色、以及用普通针线缝合未经打眼的边缘。作者还在附录里写了一段关于气味的笔记，说上等鞣制皮革应该散发淡淡的植物清香，而不是刺鼻的腐败味。他强调皮革的好坏在制成三年后才能真正判断，急功近利的鞣制会让成品在潮湿季节迅速霉变。最后一章附了一张护具版型，适合盗贼和游侠使用。

## 设计意图

面向需要轻甲的职业提供早期护甲制作入口，强调材料处理与版型知识，帮助玩家理解“原料预处理”在工艺链中的重要性。
