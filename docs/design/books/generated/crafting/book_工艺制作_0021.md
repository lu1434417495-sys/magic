# 《锁链环扣锻造》

## 书籍内容

《锁链环扣锻造》是一本考验耐心的教材。书中说明锁甲由无数小铁环交错扣合而成，每个环至少要与周围四环相连才能形成有效防护。作者推荐先绕制铁环，再用钳子剪开、交错套入、最后锻闭合。中段讨论环径与线径的取舍：细环轻便灵活但难制作，粗环结实却沉重。后半本介绍锁甲的局部修补法，用一组新环替换破损区域，而不是整件重做。最末一页附有锁甲手套与锁甲护喉的展开图，提醒读者这些部位最容易被忽视。书的扉页上写着："锁甲是无数个小决定叠成的安全。"作者在最后补充，闭合铁环时要注意火候，过热会让环变软易开，过冷则会因脆性而在穿戴时崩裂，理想的闭合点应呈现暗红色。书中还提到，制作锁甲时应在工作台旁准备一盏强光灯，以便看清每个环的闭合缝隙。

## 设计意图

为中甲职业提供进阶防具制作能力，让锁甲从商人商品变成可由玩家生产的战术装备。
