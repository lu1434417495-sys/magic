# 《布料染色秘要》

## 书籍内容

《布料染色秘要》的封面色彩斑斓，像被多种染料反复浸透。作者认为，染色不只是为了好看，而是布料获得"第二属性"的过程。全书从媒染剂讲起，解释为什么同一种染料在不同媒染剂下会呈现完全不同的色相。第二章介绍植物染、矿物染与动物染三大类，并给出对应的固色技巧。第三章专门讨论"渐变染"——如何让一块布料同时呈现数种颜色而不互相晕染，作者称之为"控制混乱的艺术"。书中还提到灰烬交界某些植物染料在月光下会改变颜色，适合制作伪装服饰，但日光下会恢复原色。最后一页贴着几片染过的布样，作为比色参考。作者在书末总结，染色的最高境界，是让布料自己决定想要成为什么颜色。作者认为，染色失败的布样不应丢弃，它们往往能组合成更独特也更耐看的实用图案。

## 设计意图

将外观定制与轻度属性增益结合，为装备系统增加生活 crafting 深度。月光变色染料与伪装机制绑定，服务潜行与探索玩法。
