# 《灵气场稳定器》

## 基础信息

- **书籍 ID**：`book_工艺制作_0036`
- **关联技能**：`crafting_aura_stabilizer`
- **使用效果**：阅读后解锁 `crafting_aura_stabilizer`；若已学会，提升该技能 `current_mastery +110`，并提高修炼时 AURA 的积累效率 10%。
- **阅读要求**：角色职业标签含 `warrior`；已解锁 `cultivation` 资源；基础 `体质 ≥ 8`。
- **稀有度**：稀有（Rare）
- **建议投放**：修炼洞府、武僧寺院、灵气节点营地。

## 书籍内容

《灵气场稳定器》讲述如何制作辅助 AURA 凝聚的器物。书中说明人体灵气如沸水，修炼时容易外散，稳定器的作用是在修炼者周围形成一个温和的引力场，帮助气息归元。作者推荐使用陨铁、寒玉与蚕丝三种材料，分别对应稳定、降温与导气。中段介绍稳定器的几何形态，圆形盘适合静坐，环形佩适合行走，塔状座则用于闭关。后半本讨论如何根据个人灵根属性调整材料比例，火灵根者需多加寒玉，水灵根者则需更多陨铁。最末一页是一份"布阵"简图，说明稳定器应放在修炼者的哪个方位。作者最后提醒，稳定器在使用前必须经过一次完整的净化仪式，否则其上残留的他人气息会干扰修炼者自身的灵气循环，严重时甚至会导致走火入魔。书中还提到，稳定器表面若有裂纹必须立即停用，因为那意味着内部灵气场已经开始崩解。

## 设计意图

把 cultivation 系统与工艺制作连接，为近战职业提供专属的修炼辅助道具制作线。
