# 《炼金初试：火焰药剂》

## 基础信息

- **书籍 ID**：`book_工艺制作_0123`
- **关联技能**：`crafting_fire_flask`
- **使用效果**：阅读后解锁 `crafting_fire_flask`；若已学会，提升 `current_mastery +110`，并使下一次调制的火焰药剂范围 +1 格。
- **阅读要求**：角色职业标签含 `mage`、`alchemist` 或 `rogue`；基础 `智力 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：炼金术士实验室、黑市药剂商、遗迹探险奖励。

## 书籍内容

火焰药剂配方被写在一本边角烧焦的册子里，仿佛在提醒读者它的危险性。作者从安全装置开始讲起：厚手套、护目镜、远离明火，以及永远不要把水直接倒入浓酸。书中详细描述了硝石、硫磺与树脂的配比原则，强调不同比例会得到燃烧、爆炸或黏附三种效果。后半本记录了温度控制的关键：反应容器必须均匀受热，局部过热会引发剧烈喷溅。作者还附了几种引信设计，从简单的布条到触发式玻璃瓶。书中还提到，熟练的炼金术士能通过药剂的颜色判断其稳定性：橙红稳定，蓝白活泼，而泛着绿光的则应当立刻丢弃。作者进一步警告，调配火焰药剂时房间内的温度会不知不觉升高，如果感到额头出汗，说明通风不足，应当立即停止操作。最后一页用红字写着：如果你闻到杏仁味却找不到来源，立刻离开房间并把所有门窗打开。

## 设计意图

为战斗提供范围伤害道具制作，把炼金术从恢复扩展到进攻，丰富法师与盗贼的战术选择。
