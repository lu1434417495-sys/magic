# 《金属镀层技法》

## 基础信息

- **书籍 ID**：`book_crafting_0076`
- **关联技能**：`crafting_metal_plating`（待新增，标签 `crafting`）
- **使用效果**：阅读后学会工艺技能 `crafting_metal_plating`（`practice_tier = basic`），解锁装备镀层改造，可为金属装备附加一种基础抗性镀层。

## 书籍内容

《金属镀层技法》的作者是一位追求"以劣替优"的节俭工匠。全书从镀金讲起，解释如何通过电解或热浸方式，在廉价金属表面覆盖一层贵金属。作者强调，镀层不是为了欺骗买家，而是为了让普通装备也能获得部分魔法亲和性。第二章介绍镀层前的表面处理：打磨、除油、酸洗、活化，任何一步偷懒都会导致镀层剥落。第三章是常见镀层材料的效果对比：镀金提升神圣抗性，镀银对亡灵有效，镀铜增强导电性，而灰烬交界的一种灰锡镀层能减弱魔力探测。书中还提醒，镀层厚度必须均匀，过厚会开裂，过薄则易磨损，作者建议用一枚铜币的边缘作为厚度参照。最后一页是镀层厚度对照表。作者在书末提醒，镀层再薄也是一层承诺，承诺不履行就会剥落。镀层完成后，作者会用一滴清水测试：若水在表面凝聚成珠，说明镀层合格。
