# 《磨刀石与刃口》

## 书籍内容

《磨刀石与刃口》很薄，但每一页都值得反复阅读。作者先教人分辨粗磨石、细磨石与抛光石的粒度差异，再讲解刃角：劈砍用阔角，刺击用锐角，通用型则取中间值。书中用大量篇幅纠正一个常见错误——磨刀不是把刀刃磨得越薄越好，太薄的刃口在格挡时会崩裂。中段附有磨刀手势图，要求磨刀者一手稳刀，一手沿固定弧度推拉，不可来回乱蹭。后半本讨论不同钢材的回火色泽，从麦秸黄到深稻草黄，对应不同的硬度区间。最后几页是应急磨刀法，包括在溪石、陶底甚至盔甲边缘临时恢复锋利度的技巧。书中最后提到，磨刀后的刀刃应以发丝或棉线测试锋利度，能无声切断者方为合格，切不断则说明角度仍有偏差。作者还提醒，磨石使用一段时间后必须重新整平，凹陷的石面会让刀刃磨成弧形。
