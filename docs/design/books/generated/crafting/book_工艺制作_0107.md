# 《基础毒药调制笔记》

## 基础信息

- **书籍 ID**：`book_工艺制作_0107`
- **关联技能**：`crafting_basic_poison`
- **使用效果**：阅读后解锁 `crafting_basic_poison`；若已学会，提升 `current_mastery +80`，并使下一次调制的毒药持续时间 +1 回合。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `智力 ≥ 6`。
- **稀有度**：普通（Common）
- **建议投放**：黑市商人、盗贼公会密室、暗杀任务奖励。

## 书籍内容

这本笔记的封皮已经发黏，似乎曾经沾染过什么不该沾的东西。作者从辨认有毒植物开始，逐一介绍毒芹、乌头与颠茄的采摘时节，并警告“手上有伤口时禁止调配”。书中把毒药制作分为萃取、浓缩、固定三步，每一步都标注了最危险的环节。后半部分记录了几种失败的调和案例，包括一次因使用铜锅导致毒药失效的事故，以及一次因过早加入稳定剂而使药性大减的教训。作者还特别强调，毒药在空气中暴露过久会氧化变质，因此调配完成后必须在阴凉处密封保存，并在瓶身贴上只有自己能看懂的暗记。他进一步解释，许多刺客的死亡并非来自敌人，而是来自自己误贴了标签的毒瓶。最后一页写着：真正的毒药不是让敌人立刻死去，而是让他在最不该减速的时候慢下来。笔记末尾还画了一只戴着手套的手，旁边写着“永远用工具，不要相信自己的皮肤”。

## 设计意图

为潜行职业提供异常状态制造手段，将毒药制作与智力属性挂钩，强调风险管控与步骤顺序。
