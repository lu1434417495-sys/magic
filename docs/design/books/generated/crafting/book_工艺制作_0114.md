# 《弓弦上蜡与张力调整》

## 基础信息

- **书籍 ID**：`book_工艺制作_0114`
- **关联技能**：`crafting_bow_string`
- **使用效果**：阅读后解锁 `crafting_bow_string`；若已学会，提升 `current_mastery +80`，并使下一次制作的弓弦攻击速度 +3%。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；基础 `敏捷 ≥ 7`。
- **稀有度**：普通（Common）
- **建议投放**：游侠营地、弓箭手公会、猎人小屋。

## 书籍内容

弓弦上蜡与张力调整专门讲解那根决定箭速的细线。作者认为弓弦是弓的灵魂，材料、股数与上蜡方式都会影响射击手感。书中比较了肠线、亚麻线与兽筋的优缺点，指出肠线弹性好但怕潮，兽筋强劲却难保养。上蜡章节强调要用蜂蜡均匀涂抹，并在炭火旁微微加热让蜡渗入纤维。后半本讲解了如何根据弓的拉距调整弦长，作者建议每次换弦后先空拉二十次，让弦找到稳定长度。作者还提醒，潮湿季节应当在弓弦上多涂一层蜡，而在极寒环境中则要避免蜡层过厚导致弓弦变硬发脆。他补充说，一张保养良好的弓弦在使用寿命末期会发出沉闷的嗡鸣，这就是更换的最佳时机。弓弦断裂前的最后一刻，往往会有肉眼难察的纤维起毛现象。最后一页画了一个简易张力测试法：将弦挂起，下端悬挂已知重物，测量伸长量是否落在安全区间。

## 设计意图

作为弓箭手装备维护的专属技能，让玩家关注弓的性能细节，与箭矢制作形成完整的远程战备循环。
