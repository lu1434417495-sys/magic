# 《爆炸陷阱组装》

## 基础信息

- **书籍 ID**：`book_工艺制作_0038`
- **关联技能**：`crafting_explosive_trap`
- **使用效果**：阅读后解锁 `crafting_explosive_trap`；若已学会，提升该技能 `current_mastery +110`，并提高陷阱触发后的爆炸伤害 10%。
- **阅读要求**：角色职业标签含 `rogue` 或 `archer`；已学会 `crafting_rope_weaving` 或 `crafting_alchemy_fire_flask`；基础 `敏捷 ≥ 8`。
- **稀有度**：稀有（Rare）
- **建议投放**：工程兵营地、陷阱大师藏身处、地城机关区。

## 书籍内容

《爆炸陷阱组装》把破坏力压缩进一个巴掌大的装置里。书中先讲触发机构：压力板适合通道，绊线适合林间，定时引信适合撤退时拖延追兵。作者强调装药量与外壳强度的平衡，药量过多会提前炸毁自己的陷阱，过少则无法造成有效杀伤。中段介绍如何在诱饵上隐藏引信，以及如何伪装装置气味，避免被野兽或经验丰富的敌人察觉。后半本讨论安全拆解流程，即使是制作者也可能因时间太久忘记机关细节。最末一页是一份"绝对不要做的事"清单，第一条是"不要在背着陷阱时奔跑"。作者最后提醒，组装爆炸陷阱时应远离火源与静电，任何微小的火花都可能让尚未封装的半成品提前引爆，造成无法挽回的后果。书中还附有一张延迟引信长度与爆炸时间对照表，方便使用者根据战场需要精确控制触发时机。

## 设计意图

扩展游侠与盗贼的控场与伏击手段，让陷阱成为战棋战场上可预置的战术要素。
