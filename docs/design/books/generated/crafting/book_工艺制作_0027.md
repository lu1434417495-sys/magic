# 《轻型弩机调试》

## 基础信息

- **书籍 ID**：`book_工艺制作_0027`
- **关联技能**：`crafting_crossbow_tune`
- **使用效果**：阅读后解锁 `crafting_crossbow_tune`；若已学会，提升该技能 `current_mastery +100`，并提高轻型弩的装填速度 8%。
- **阅读要求**：无职业限制；已学会 `crafting_carpentry_basic` 或 `crafting_bow_wood_seasoning`；基础 `敏捷 ≥ 7`。
- **稀有度**：精良（Uncommon）
- **建议投放**：工匠行会、军械库、弩手训练场。

## 书籍内容

《轻型弩机调试》把弩从简单武器变成精密器械。书中先讲解扳机机构，强调扣力要轻而明确，过重的扳机会在瞄准时造成抖动。作者详细说明弦槽与箭道的对中问题，偏差哪怕一丝都会导致箭矢侧飞。中段讨论弓臂的预紧度，预紧不足则威力小，预紧过度则机构寿命短。后半本介绍弩弦材料与更换周期，兽筋弦弹力好但怕潮，钢丝弦耐用却沉重。最末一页是一张弩机拆解图，标注了每个零件的名称与常见磨损位置。书尾建议："调试弩和调试性格一样，急不得。"作者最后提醒，弩机中的润滑油必须选用耐低温的品种，寒冷环境下普通油脂会凝固，导致扳机卡死或滑牙。作者还提醒，弩机调试好后应进行空放测试，观察扳机复位是否顺畅，稍有迟滞都可能在实战中造成致命延误。书中还附有一张箭道平直度检查图，帮助读者用细线快速判断弩身是否有轻微弯曲。

## 设计意图

为远程物理职业提供弩类专精维护能力，强化战术武器选择与制作分支差异。
