# 《简易药剂调和》

## 基础信息

- **书籍 ID**：`book_工艺制作_0005`
- **关联技能**：`crafting_alchemy_basic`
- **使用效果**：阅读后解锁 `crafting_alchemy_basic`；若已学会，提升该技能 `current_mastery +80`，并提高初级药水产出数量 1 瓶。
- **阅读要求**：无职业限制；基础 `智力 ≥ 6`。
- **稀有度**：普通（Common）
- **建议投放**：草药师小屋、炼金学徒桌、低级地精营地。

## 书籍内容

《简易药剂调和》是一本充满草药味的手抄本。开篇列出三项铁律：器皿干净、火候精确、投料顺序不可颠倒。作者用通俗语言讲解溶解、乳化与沉淀的区别，并附上一份基础治疗药水的配方：银叶草、清水与少量蜂蜡。中段的错误案例页最受欢迎，它记录了把止血草和兴奋菇同时下锅会产生的剧烈呕吐效果。后半本介绍研磨、过滤与装瓶技巧，强调深色玻璃瓶能延长药效。最末一页写着："药水不会替你战斗，但它会让你有机会继续战斗。"书角还有一行潦草笔记，警告读者不要在工作台前打瞌睡。作者在附录中列出了一份简易药剂师工具清单，从研钵到滴管，说明好的工具能让初学者的成功率提升近半。书中最后提醒，药剂师应养成记录配方的习惯，因为同一批草药因产地不同有效成分会有差异。

## 设计意图

让任何职业都能制作基础恢复药水，降低前期生存压力，为专职炼金术士铺垫素材认知。
