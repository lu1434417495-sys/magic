# 《制靴与鞋底加固》

## 基础信息

- **书籍 ID**：`book_工艺制作_0018`
- **关联技能**：`crafting_boot_reinforcement`
- **使用效果**：阅读后解锁 `crafting_boot_reinforcement`；若已学会，提升该技能 `current_mastery +90`，并提高靴子的耐久与移动豁免 5%。
- **阅读要求**：无职业限制；已学会 `crafting_leather_tanning` 或 `crafting_tailoring_basic`；基础 `敏捷 ≥ 6`。

- **建议投放**：军需官、旅行鞋匠、荒野商队。

## 书籍内容

《制靴与鞋底加固》认为一双好鞋决定了一次远征的成败。书中从量脚型开始，说明不同足弓需要不同的鞋垫弧度。接着讲解鞋面与鞋底的缝合方法，其中挪威缝法最防水，固特异沿条缝法最耐穿。中段介绍鞋底材料：皮革底安静但怕水，橡胶底耐磨却沉重，软木底舒适但不抗刺。后半本讨论如何在靴头与后跟加装金属护片，以及鞋带孔的加固技巧。最末一页附有一份长途行军前的检查清单，包括缝线、鞋钉与防水层。作者强调："脚上的泡比敌人的箭更让人掉队。"书中最后建议，新靴子上脚前应先用蜂蜡或皮革油充分浸润，既能软化皮革，又能在表面形成抵御泥水的保护膜。书中还提到，制作远行靴时应预留半指的宽松度，因为长时间行走后双脚会肿胀，过紧的靴子会磨出水泡甚至影响行动。作者还提醒，鞋底缝线应选用涂蜡的粗线，普通线材遇水膨胀后容易磨断。
