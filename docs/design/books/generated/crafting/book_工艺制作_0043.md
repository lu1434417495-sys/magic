# 《锻魂锤法》

## 书籍内容

《锻魂锤法》不讲金属，只讲锤与心的关系。书中说明真正的大师锻造时，每一锤都伴随呼吸与意志的贯注，金属因此记住锻造者的精神。作者要求读者先练站桩三年，再碰珍稀材料，否则只会打出空有形状而无灵性的凡铁。中段介绍三种锤意：沉锤定形、快锤去杂、轻锤引灵，分别对应不同锻造阶段。后半本讨论如何在淬火时保持心念集中，因为水温与心境同样影响成品的质地。最末一页只有八个大字："锤落有声，魂入无声。"许多读者翻到这里会沉默良久，意识到自己缺的不是材料，而是耐心。作者最后写道，锻造史诗武器的最后一步往往是在寂静中完成的，因为器物能否觉醒，取决于锻造者彼时的心境是否澄澈如水。书中还提到，锻魂锤法最忌被打断，一旦分神，前面积累的"魂意"便会散失大半。

## 设计意图

为工匠型战士提供终极锻造技艺，把制作从资源消耗转化为需要修炼与心境投入的深度玩法。
