# 《木盾拼接与箍紧》

- **书籍 ID**：`book_工艺制作_0020`
- **关联技能**：`crafting_shield_wood_lamination`
- **使用效果**：阅读后解锁 `crafting_shield_wood_lamination`；若已学会，提升该技能 `current_mastery +90`，并提高木盾格挡值 3 点。

## 书籍内容

《木盾拼接与箍紧》解释了为什么整块木板不如多层薄板压合结实。书中说明交叉纹理的木板叠压后，外力会被各层分散，不易沿单一纹理开裂。作者推荐三层结构：表层硬木抗砍，中层软木吸震，背层韧木固定把手。中段讲解铁箍的安装方法，环箍能防止盾面在重击下散架，但过紧会压迫木层。后半本讨论盾面蒙皮与涂漆，皮革蒙皮能防劈裂，桐油涂层能防潮防腐。最末一页是一份盾牌握把角度图，说明直角握把适合举盾推进，斜角握把适合快速格挡反击。书角被砍出一道浅痕，仿佛曾被当作临时盾牌使用。作者最后提醒，木盾制作完成后应在阴处放置数周，待胶完全固化并释放内部应力，才能承受实战中的冲击。作者还建议，新盾初次上战场前应先进行数次轻击测试，确认各层粘合牢固、箍环无松动。书中还提到，盾缘应额外包覆一层薄铜，防止敌人刀刃嵌入木纤维。

## 设计意图

强化早期战士与牧师的防御装备来源，让盾牌制作成为木工技艺的实战延伸。
