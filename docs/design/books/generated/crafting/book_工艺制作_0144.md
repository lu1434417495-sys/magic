# 《活体护甲缝合法》

## 基础信息

- **书籍 ID**：`book_工艺制作_0144`
- **关联技能**：`crafting_living_armor_stitch`
- **使用效果**：阅读后解锁 `crafting_living_armor_stitch`；若已学会，提升 `current_mastery +140`，并使下一次缝制的活体护甲每回合恢复 1 点耐久。
- **阅读要求**：角色职业标签含 `druid`、`ranger` 或 `shaman`；基础 `体质 ≥ 12`、意志 `≥ 10`。
- **稀有度**：史诗（Epic）
- **建议投放**：德鲁伊圣地、远古森林、自然之魂任务奖励。

## 书籍内容

活体护甲缝合法是一门让植物或菌丝与穿戴者共同生长的工艺。作者从选材开始：苔藓适合内衬因为它柔软吸汗，藤蔓适合外层因为它坚韧，而某些发光菌类则能提供微光照明。书中强调活体护甲不能用普通针线，而要用植物纤维或自身的细小根系作为缝合材料。养护部分讲解如何定期用水与阳光滋养护甲，缺乏养护的活体护甲会干枯脱落。后半本记录了如何让护甲适应穿戴者的体型：初次穿上时需要三天时间让它缓慢贴合。作者还附有一张根据季节调整养护频率的表格。书中还提到，活体护甲会在穿戴者情绪低落时变得黯淡无光，而在其充满斗志时叶片舒展。他进一步提醒，制作活体护甲时必须与植物建立精神联系，粗暴对待材料会导致成品在战斗中拒绝保护穿戴者。最后一页写着：活体护甲不是你在穿它，而是它在选择是否继续陪着你。

## 设计意图

为自然系职业提供独特的自我修复护甲，把德鲁伊等职业的主题与工艺系统结合，形成差异化装备路线。
