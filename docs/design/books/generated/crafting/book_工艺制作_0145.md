# 《时间沙漏与缓速尘》

## 基础信息

- **书籍 ID**：`book_工艺制作_0145`
- **关联技能**：`crafting_time_sand`
- **使用效果**：阅读后解锁 `crafting_time_sand`；若已学会，提升 `current_mastery +140`，并使下一次制作的缓速尘作用范围 +1 格。
- **阅读要求**：角色职业标签含 `mage`、`chronomancer` 或 `alchemist`；基础 `智力 ≥ 14`。
- **稀有度**：史诗（Epic）
- **建议投放**：时之塔、虚空遗迹、高阶炼金师。

## 书籍内容

时间沙漏与缓速尘涉及把时间碎片固化成可用物质的危险工艺。作者从沙漏容器的制作开始，强调必须使用不受时间侵蚀的材料，如星陨玻璃或龙骨粉烧制的陶瓷。书中详细讲解了如何捕捉时间裂隙中的“停滞尘”：需要在裂隙附近放置收集器，并在恰当时机封闭容器，太早会收集不到，太晚则容器会被回溯成原料。后半本记录了缓速尘的使用限制：同一区域内连续使用会导致效果递减，过量暴露会让使用者自己的动作变慢。作者还附有一张“时间污染症状”表。书中还提到，使用时间沙漏时必须保持目光稳定，眨眼频率过高的人不适合担任操作者，因为他们会无意识地与沙漏产生同步紊乱。他进一步警告，制作时间沙漏时绝对不能用自己生日对应的星座符号装饰，否则成品可能会与制作者的生命力产生绑定。最后一页写着：玩弄时间的人最终都会成为时间的债务人。

## 设计意图

引入时间主题的控制道具制作，为战斗提供独特的节奏操控手段，同时用风险机制平衡强大效果。
