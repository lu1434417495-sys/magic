# 《陷阱机关：绊索与压板》

## 基础信息

- **书籍 ID**：`book_工艺制作_0118`
- **关联技能**：`crafting_snare_trap`
- **使用效果**：阅读后解锁 `crafting_snare_trap`；若已学会，提升 `current_mastery +80`，并使下一次布置的陷阱触发范围 +1 格。
- **阅读要求**：角色职业标签含 `rogue`、`ranger` 或 `hunter`；基础 `敏捷 ≥ 7`。
- **稀有度**：普通（Common）
- **建议投放**：猎人营地、盗贼公会、野外生存训练。

## 书籍内容

陷阱机关是一本既教制作也教拆除的书，作者认为不懂拆陷阱的人就做不好陷阱。书中从最简单的绊索开始：选择不会反光且与背景色接近的细线，固定点的高度要针对目标脚踝或膝盖。压板机关则讲解了杠杆原理与触发重量的关系，作者提醒“太重不会触发，太轻会被落叶误触”。后半本记录了几种自然伪装技巧：把金属件埋在落叶下、用泥土覆盖新鲜刨痕、让触发线与藤蔓平行。作者还建议在陷阱附近故意留下一些无害的脚印或折断的枝条，引导敌人沿着你预设的路线行走，而不是让他们自由探索。他进一步提醒，设置复合陷阱时应当让第一个陷阱明显可见，真正的杀招则隐藏在敌人躲避第一个陷阱时必经的路径上。最后一页写着：最好的陷阱是敌人死前都没意识到存在的那种。旁边还有一句警告：设置后记得自己走过的路线，否则第一个受害者可能是你自己。

## 设计意图

为游侠与盗贼提供战场控制道具制作，增加战前布置与地形利用的战术深度。
