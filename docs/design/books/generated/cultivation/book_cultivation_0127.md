# 《吐纳隐匿：无影息》

## 书籍内容

无影息把呼吸与脚步、心跳、甚至意念波动都降到最低，让修炼者在环境中如同透明。书中说，真正被发现的原因往往不是视觉，而是「气场的扰动」——你呼吸带动的空气流动，你心跳引起的地面微震，你目光聚焦时产生的压迫感。第一章教人如何分解自己的存在感：呼吸无声、脚步无风、目光不锁定目标。第二章讲解如何在移动中保持「无影」状态：每一步都要踩在前一步留下的气场消散之后。中段描述了一位无影息大成者从守卫背后取走钥匙的全过程，书中以秒为单位记录了每个动作。后半本警告，无影息不能消除体温与气味，需要配合特殊衣物与药膏。末页只有一行极淡的字：「影子的影子，即是无影。」书中警告，无影息不能消除声音，需配合软底鞋与消音布。
