# 《桩功反震：不动岳》

## 书籍内容

不动岳把桩功的防御推向反击。书中要求练习者想象自己是一座真正的山峰：不是主动攻击，而是让撞上来的人自己受伤。第一章讲解「岳势」：双脚如峰基，腰脊如峰腰，双肩如峰肩，整个人把来力导向大地再反弹回去。第二章给出反震的条件：必须在被击中前的瞬间绷紧相应部位，过早会消耗过多体力，过晚则无法形成反震。中段以图示展示了不同攻击角度下的反震落点：正面直击反弹至胸口，斜向攻击反弹至肩膀。后半本讨论不动岳的极限：它可以反弹物理冲击，但对法术与毒素无效。末页画着五座相连的山峰，最中间那座最高，题字：「五岳归来不看山，不动岳前莫出手。」作者建议，反震成功后应立即调整桩势，准备下一次承受。山神祭坛的守护者传说，不动岳大成者曾让一头狂奔的巨兽撞断自己的角，而守护者纹丝未动。

## 设计意图

为站桩防御体系增加主动反击维度，让纯坦克build也能制造威胁。
