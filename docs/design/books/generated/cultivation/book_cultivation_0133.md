# 《桩功疗伤：自愈桩》

## 基础信息

- **书籍 ID**：`book_cultivation_0133`
- **关联技能**：`cultivation_self_healing_stance`（待新增，标签 `cultivation`）
- **使用效果**：阅读后学会修炼技能 `cultivation_self_healing_stance`（`practice_tier = master`），非战斗状态下站桩恢复 `current_hp`；若已学会，提升 `current_mastery +190`。
- **阅读要求**：已学会 `cultivation_spring_breath` 或 `cultivation_battle_stance_manual`；基础 `体质 ≥ 12` 且 `意志 ≥ 11`。
- **稀有度**：稀有（Rare）
- **建议投放**：药王谷禁地、隐士疗伤洞、古树中空处。

## 书籍内容

自愈桩把站桩从防御姿态转化为修复姿态。书中认为，人体本身就拥有惊人的自愈能力，只是日常的活动与紧张抑制了这种能力。通过特定的站姿，可以让气血自然流向受损部位。第一章给出三种自愈桩：仰卧桩适合内伤，侧卧桩适合肋部损伤，坐桩适合下肢不便者。第二章讲解呼吸配合：吸气时把意念引向伤口，呼气时想象浊血与瘀血被排出体外。中段记录了大量案例：骨折者在自愈桩中配合固定夹板，伤口愈合速度显著加快。后半本强调自愈桩不能替代医疗，对于毒伤、诅咒伤、致命伤必须寻求专业治疗。末页有一片干枯的树叶，夹在书中，旁注：「树断了枝也能长，因为它知道怎么站着等待。」作者建议配合温热药浴，以加速自愈桩的修复效果。古树中空处常有修炼者留下的刻痕，记录着他们在自愈桩中伤口愈合所需的天数。

## 设计意图

为修炼体系提供稳定的非战斗恢复手段，减少回城需求，增强探索连续性。
