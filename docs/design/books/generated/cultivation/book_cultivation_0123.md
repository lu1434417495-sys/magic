# 《桩功应战：战桩诀》

## 书籍内容

战桩诀把「站」与「打」合二为一。书中认为，真正的高手不是从某个漂亮的起手式开始战斗，而是在日常站姿中已经完成了发力的准备。第一章给出五种战斗起手桩：先锋桩、守势桩、诱敌桩、蓄势桩、游击桩，每种对应不同的战术意图。第二章讲解如何在敌人进入攻击范围的瞬间从桩态切换到攻击，要求动作没有多余预兆。中段以图示分解了「半步崩拳」的发力链：从脚底拧转，到腰胯开合，到肩臂甩出，最后拳头只是末端。后半本强调战桩诀的精髓是「藏劲于静」：越是不动的姿态，越能爆发出惊人的速度。末页有一段被血迹染红的批注：「我教了二十年桩，活下来的不是姿势最标准的，是最会站的那个人。」书中记载，战桩诀最适合在狭窄地形中发挥以静制动优势。

## 设计意图

把桩功从修炼场景延伸至战斗场景，为武术家与战士提供开场优势。
