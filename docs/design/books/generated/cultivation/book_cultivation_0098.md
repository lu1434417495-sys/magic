# 《总纲：桩功全录》

## 基础信息

- **书籍 ID**：`book_cultivation_0098`
- **关联技能**：`cultivation_stance_compendium`（待新增，标签 `cultivation`）

## 书籍内容

桩功全录收录了从入门到圆满的十二种桩功，并给出每种桩功的适应症与禁忌。书中强调，没有最好的桩功，只有最适合当下状态的桩功。第一章按难度排序：青石、磐石、守一、游龙、归元、万象等。第二章讨论站桩时长与 Aura 恢复的关系。第三章分析桩功对下盘稳定、上身放松、脊柱对齐的影响。后几章给出一份「桩功处方」：疲劳时站回元桩，战前站磐石桩，修炼瓶颈时站万象桩。末页画十二个简化人形，旁注：「桩为根基，功到自然成。」

## 设计意图

作为桩功体系总纲，提供全局站桩收益加成，帮助玩家在不同场景选择最优桩功。
