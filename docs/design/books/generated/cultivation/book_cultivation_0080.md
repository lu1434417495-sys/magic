# 《斗气凝兵：气刃诀》

## 书籍内容

气刃诀将斗气凝聚成锋锐的刃形外放。书中描述，高阶修炼者可以手为刀，隔空斩开草席。初学阶段只能让指尖斗气微微发亮，进阶可形成寸许气刃。作者强调，气刃的锋利不在于斗气多，而在于控制精；涣散的气刃不如拳头。中段给出训练方法：以纸为靶，先求划破，再求切口整齐。后几章讨论气刃诀对战士与盗贼的战术意义：破盾、断索、远程牵制。末页画一柄由气流构成的刀，旁注：「气为刃，心为柄。」

## 设计意图

为近战职业提供高阶斗气输出形态，使 Aura 可用于制造临时武器与远程斩击。
