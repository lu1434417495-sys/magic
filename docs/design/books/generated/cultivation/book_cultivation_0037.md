# 《斗气修复：养气回元》

## 书籍内容

养气回元是一本教人如何用斗气加速身体恢复的入门书。书中第一章讲解基础方法：在静坐或站桩时，把斗气引导至疲劳或轻微受伤的部位，配合深长呼吸，帮助局部血液循环。第二章强调修复不是治疗：它能缓解肌肉酸痛、轻微淤青和疲劳，但不能替代医者处理骨折或中毒。作者提醒，使用斗气修复时需要身体处于相对放松状态，战斗中很难同时维持。中段讨论修复效率与睡眠的关系：睡前进行十分钟的养气回元，往往能让第二天的状态更好。后半本给出几种针对不同部位的简化版引导法：肩部疲劳用环绕引导，小腿酸胀用推压引导，腰背僵硬用温热引导。末页写着：「气是身体的火，火太旺则燥，火太弱则寒；养气就是调火。」战后临时营地的老兵常把养气回元当作睡前仪式，比喝酒更能真正缓解一天的疲惫。此书适合所有需要频繁参与战斗的冒险者。

## 设计意图

为斗气增加恢复型应用，让 `AURA` 资源在战斗之外也有消耗渠道，鼓励玩家在非战斗场景中使用修炼技能。
