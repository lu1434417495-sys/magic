# 《五行炼体：炽火身》

## 基础信息

- **书籍 ID**：`book_cultivation_0121`
- **关联技能**：`cultivation_flame_body`（待新增，标签 `cultivation`）
- **使用效果**：阅读后学会修炼技能 `cultivation_flame_body`（`practice_tier = advanced`），近战攻击附加小额 `火焰伤害`；受击时对攻击者反弹少量火焰伤害；若已学会，提升 `current_mastery +175`。
- **阅读要求**：基础 `体质 ≥ 12` 且 `力量 ≥ 10`；职业标签含 `warrior` 或 `berserker`。
- **稀有度**：精良（Uncommon）
- **建议投放**：火山口遗迹、火元素祭坛、炎魔战场遗物。

## 书籍内容

炽火身把斗气点燃成贴身火焰，让修炼者成为一座行走的火炉。书中警告：这门功法极其危险，初学者必须有医师在旁，并备好灭火与止血药物。第一章教人如何在丹田处凝聚「火种」——一团极小但极稳定的斗气火焰。第二章讲解如何把火种缓慢扩散到四肢，让皮肤温度升高但不灼伤自己。中段描述练习者会经历的「焚心」阶段：心脏附近有灼烧感，必须靠意志力忍住，一旦退缩就会前功尽弃。后半本讨论炽火身的实战价值：近战时敌人会被灼伤，远程攻击者则会因热浪而难以瞄准。末页有一幅被烧得卷边的插图，画着一个人站在火海中微笑，旁注：「火不烧愿意成为火的人。」练习者必须在火盆旁备一桶沙，以防火焰失控蔓延。

## 设计意图

把五行炼体从纯防御转向攻防一体，为狂战士等高风险职业提供近战反伤机制。
