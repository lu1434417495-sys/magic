# 《斗气凝聚：聚气诀》

## 书籍内容

聚气诀教授如何把散乱的斗气收束到丹田。书中把斗气比作羊群，把意识比作牧人，若牧人不在，羊群便会四散，修炼者首先需要学会静坐。第一步是盘坐闭目，用意念从四肢末端向腹部聚拢气息；第二步是保持腹部温热而不燥热，既不可冰凉也不可灼烧。作者提醒，聚气时不可用力挤压，否则会气滞腹痛，初学者每次练习以九息为一组，每日三组即可。中段给出多个辅助姿势：仰卧聚气适合疲惫后恢复，站立聚气适合战前蓄势。后几章讨论聚气速度与 Aura 上限的关系：容量越大，聚拢所需时间越长，但爆发时也越持久。作者特别提醒，聚气过程中若出现腹部剧痛或头晕，应立即停止，并寻求医师或有经验的导师帮助。末页写着：「气不散，则力不竭；气不聚，则技不精。」战前聚气可在营火旁进行，借火光安定心神；若在阴湿洞穴中练习，应垫厚毡隔绝地气，否则易聚寒不散。

## 设计意图

作为 Aura 控制的基础教材，帮助玩家理解「聚气」是释放高阶斗气技的前置环节。
