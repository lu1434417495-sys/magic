# 《吐纳破限：真空息》

## 基础信息

- **书籍 ID**：`book_cultivation_0137`
- **关联技能**：`cultivation_void_breath`（待新增，标签 `cultivation`）
- **使用效果**：阅读后学会修炼技能 `cultivation_void_breath`（`practice_tier = legendary`），战斗中每回合有概率清除一个负面状态；若已学会，提升 `current_mastery +240`。
- **阅读要求**：已学会 `cultivation_shadowless_breath` 与 `cultivation_cloud_still_breath`；基础 `意志 ≥ 15`。
- **稀有度**：稀有（Rare）
- **建议投放**：虚空裂隙、天外遗迹、飞升者遗留洞府。

## 书籍内容

真空息追求一种「无呼吸」的境界：不是屏住呼吸，而是让身体不再需要呼吸。书中说，当斗气循环完美到可以替代氧气时，修炼者就能在真空中存活。第一章讲解如何把全身毛孔都变成呼吸通道，让皮肤直接从环境中吸收游离能量。第二章讨论真空息对状态异常的净化作用：因为没有常规呼吸，毒素与诅咒难以通过呼吸道侵入；斗气的持续循环又能把已侵入的异常慢慢冲刷出去。中段描述了一位真空息修炼者在瘟疫之城行走七日而不染病的经历。后半本警告，真空息会让修炼者的情绪变得极为淡漠，长期使用可能失去常人的喜怒哀乐。末页一片空白，只在角落写着：「息止而气不息，人在而心不在。」作者警告，真空息修行者应避免长期处于人群，以免情感钝化。飞升者遗留洞府中有一具端坐千年的尸骨，据说他因长期修行真空息而忘记了如何哭泣。

## 设计意图

作为吐纳路线的传奇顶点，提供状态净化能力，让高投入修炼者在异常状态环境中如履平地。
