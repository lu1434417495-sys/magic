# 《桩功秘传：归元桩》

## 基础信息

- **书籍 ID**：`book_cultivation_0076`
- **关联技能**：`cultivation_return_yuan_stance`（待新增，标签 `cultivation`）

## 书籍内容

归元桩是所有桩功的归总与提炼。书中要求练习者双脚平行、与肩同宽，膝微屈、臀微敛、头顶悬、肩下沉，全身无一处多余用力。作者认为，再高深的斗气技法，最终都要回到这一姿势中检验根基。第一章讲解如何在归元桩中让气从涌泉到百会循环一整圈。中段提供不同修炼阶段的检验标准：初学求不晃，进阶求不喘，高阶求不思。后几章讨论归元桩作为每日功课的重要性。末页只有四个字：「万法归桩。」

## 设计意图

作为桩功体系的中枢节点，让玩家在掌握多种桩功后回归统一根基，提升 Aura 循环效率。
