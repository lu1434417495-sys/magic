# 《桩功领域：镇域桩》

## 基础信息

- **书籍 ID**：`book_cultivation_0138`
- **关联技能**：`cultivation_domain_stance`（待新增，标签 `cultivation`）
- **使用效果**：阅读后学会修炼技能 `cultivation_domain_stance`（`practice_tier = legendary`），站在原地时给周围队友提供小额 `伤害减免`；若已学会，提升 `current_mastery +260`。

- **建议投放**：古战场中央祭坛、山门护山大阵核心、传说中的武道圣地。

## 书籍内容

镇域桩把一个人的站桩扩展为一片领域的稳定。书中说，当修炼者与大地、天光的联系足够深时，他的气场会影响周围的空间，让靠近他的人也变得沉稳。第一章讲解如何「铺开」自己的桩意：不是把斗气外放攻击，而是让它像地毯一样向四周延展。第二章讨论镇域桩的范围与强度：与大地连接越深，范围越大；自身越稳定，队友获得的保护越强。中段描述了一位镇域桩大成者独守关口的场景：他站在城门中央，周围数十名士兵都感到脚步沉重、心神安定，敌人的箭雨仿佛也变得缓慢。后半本警告，镇域桩会让修炼者成为最显眼的目标，必须有人保护侧翼与背后。末页画着一个巨人般的身影站在大地上，周围是无数 tiny 人影，题字：「一人镇域，万法不侵。」书中记载，镇域桩的范围与修炼者的体重和身高息息相关。

## 设计意图

把站桩从个人防御提升为团队光环，为终极坦克build提供战略级价值。
