# 《总纲：斗气本源》

## 基础信息

- **书籍 ID**：`book_cultivation_0100`
- **关联技能**：`cultivation_aura_origin`（待新增，标签 `cultivation`）
- **使用效果**：阅读后学会修炼技能 `cultivation_aura_origin`（`practice_tier = master`），立即解锁 `AURA` 资源链并注入起始 `aura_max/current_aura`；若已学会，提升 `current_mastery +130`。
- **阅读要求**：无职业限制；已学会任意三种斗气技能；基础 `意志 ≥ 12` 或 `智力 ≥ 12`。
- **稀有度**：史诗（Epic）
- **建议投放**：世界 boss 掉落、禁书总阁、终极传承任务。

## 书籍内容

斗气本源探讨 Aura 的本质与来源。书中提出，斗气并非凭空产生，而是生命力、意志力与自然能量在人体内的交汇，三者缺一不可。第一章追溯不同流派对本源的解读；第二章分析情绪对斗气的影响：愤怒可增爆发力，却减持久；平静可增恢复，却失锐气，需根据战况取舍。第三章给出一种「本源观想」：想象丹田处有一颗不断旋转的光球，随呼吸明暗变化。后几章讨论斗气本源与职业专精的关系：战士重意志、法师重感知、盗贼重敏捷，牧师则重信念。书中最后提醒，斗气本源的理解越深刻，越能在极端环境下保持冷静，因为你知道力量从何而来。书中附有一份「情绪与斗气对照表」，帮助修炼者识别自身状态并及时调整。末页写着：「知源者，用气不惑；惑源者，纵力强亦空。」斗气本源认为，濒死之际若有强烈执念，Aura 会短暂燃烧，留下永久损伤。因此修炼者平时须以冥想安定心神，避免情绪极端化，方能长久。

## 设计意图

作为修炼功法体系的哲学总纲，提升玩家对 Aura 系统的理解，并为全职业提供本源级加成。
