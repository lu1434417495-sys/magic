## 书籍内容

四息周天把一个完整的呼吸拆成吸、停、呼、停四个等长阶段，每阶段各数四拍。书中第一章用节拍器比喻：初学者可以心中默数一、二、三、四，让呼吸像乐曲一样有节奏。第二章讲解「停」的价值，认为人在吸满与呼尽之间的短暂静止，是意识最清醒、身体最稳定的时刻。作者提醒，停息不可勉强，若感到头晕应立即恢复自然呼吸。中段给出三个变式： calming cycle 四息用于睡前，power cycle 二息用于战前动员，recovery cycle 六息用于战后恢复。后半本用简单图示展示气息在胸腔与腹腔的流动路径。末页写着：「气息有四段，心境亦有四时；能调息者，方能调心。」道观里的初学者每天清晨都要面对东方练习四息周天，直到师父听不见他数拍子的声音，才说明节奏已经真正内化为身体记忆。此书是许多高级吐纳法的前置基础，尤其适合需要稳定情绪的职业。

## 设计意图

通过节拍化的呼吸训练，为玩家建立「呼吸节奏=战斗节奏」的直觉，为后续高阶吐纳技能提供入门阶梯。
