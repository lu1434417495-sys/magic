# 《呼吸秘要：龟息吐纳》

## 书籍内容

龟息吐纳讲究慢、长、藏。书中开篇即说：「常人呼吸如走马灯，修炼者呼吸如深潭水。」练习者需要把单次呼吸延长至常人的三到五倍，同时让胸腹起伏降到最低，使敌人无法从身体动作判断气息节奏。第一章教人如何在水下闭气时保持冷静，把恐慌转化为可控的斗气循环。第二章讨论龟息在战斗中的应用：屏息可以隐藏杀意，长呼可以稳定情绪，短促的吐纳则能在连续出招间快速补充斗气。中段记录了一位前辈在矿井坍塌后靠龟息存活七日的经历。后半本给出危险警告：龟息练过头会导致反应迟钝，必须配合「醒息法」每日破关。末页的插图是一只乌龟背着一座小山，题字：「沉得住气，才背得动命。」书中附有水下闭气的时间表，从十息开始，逐日递增。

## 设计意图

把吐纳从恢复手段拓展为战斗中的应急资源，强化修炼者在高压下的生存能力。
