# 《斗气回环：生生不息》

## 基础信息

- **书籍 ID**：`book_cultivation_0124`
- **关联技能**：`cultivation_endless_cycle`（待新增，标签 `cultivation`）
- **使用效果**：阅读后学会修炼技能 `cultivation_endless_cycle`（`practice_tier = advanced`），击杀敌人时恢复少量 `current_aura`；若已学会，提升 `current_mastery +180`。

- **建议投放**：轮回殿遗址、无尽战场、修罗竞技场。

## 书籍内容

生生不息探讨斗气在战斗中的循环：不是从自己身上榨取，而是从敌人的溃败中回收。书中开篇即说：「杀人不是终结，是能量的转移。」第一章讲解如何在击败对手的瞬间捕捉其消散的斗气余波，并通过任脉将其导入自身丹田。第二章讨论这种技法的伦理争议：有人视之为邪道，因为它利用了他人的死亡；作者则认为，与其让斗气白白消散，不如用来保护还活着的人。中段给出七种不同死亡方式下斗气消散的速度差异。后半本警告，回收斗气时必须过滤掉死者的情绪残渣，否则会导致心神不宁甚至走火入魔。末页画着一个首尾相接的圆，题字：「生尽则死，死尽则生；循环不息，是谓大道。」作者认为，只有心怀慈悲者才能真正驾驭这股循环之力。
