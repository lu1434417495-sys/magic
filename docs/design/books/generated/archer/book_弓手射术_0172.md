# 《散射要诀》

## 基础信息

- **书籍 ID**：`book_弓手射术_0172`
- **关联技能**：`archer_scatter_shot`（待新增）
- **使用效果**：阅读后解锁 `archer_scatter_shot`；若已学会，提升该技能 `current_mastery +90`，并使散射射击额外命中一个目标。
- **阅读要求**：职业标签含 `archer` 或 `ranger`；基础 `敏捷 ≥ 11` 且 `感知 ≥ 10`。
- **稀有度**：普通（Common）
- **建议投放**：游侠训练场、城防军、群战演练场。

## 书籍内容

《散射要诀》讲授在近距离同时压制多个敌人的扇形射击法。作者认为，散射不是乱放，而是将有限的箭矢均匀分配到预定扇面内。前半本讲解手腕动作：撒放时轻微摆动，使箭矢呈扇形散开。中章提供目标密度判断方法，敌群越密集，散射收益越高。后半本讨论弹药消耗与战术价值，散射适合阻滞冲锋，但不宜持续使用。书中还提到，散射时准心应放在敌群中心偏上位置，利用下坠覆盖更大区域。作者提醒，散射对单体精英效果有限，不可滥用。末尾附有三人小组配合散射的队形图，常用于城门防守。

书中用红笔画出了最常犯的失误：手腕摆动过大导致箭矢全部飞向一侧。纠正方法是先练习单箭扇形，再逐步增加箭数，直到能稳定覆盖预定扇面为止。

## 设计意图

为弓手提供群体压制技能，适合防守战与狭窄地形，强化AOE与控场能力。
