# 《游侠匿踪步法》

## 基础信息

- **书籍 ID**：`book_弓手射术_0057`
- **关联技能**：`archer_feather_step`、`archer_rapid_fire`
- **使用效果**：阅读后解锁 `archer_feather_step`；若已学会，提升 `current_mastery +110`，并在林地地形中首次进入隐匿状态时耐力消耗减半。
- **阅读要求**：角色职业标签含 `ranger` 或 `rogue`；基础 `敏捷 ≥ 10`。
- **稀有度**：普通（Common）
- **建议投放**：密林游侠营地、盗贼公会交换品、潜行训练委托。

## 书籍内容

《游侠匿踪步法》 teach 的不是隐身术，而是如何让自己成为环境的一部分。作者将脚步分为“落、转、收”三段，要求每一步都踩在前方落叶或石块的阴影里，避免直接踏碎枯枝。书中还记录了不同季节的林地气味管理：春天的花香会暴露位置，秋天的腐败落叶会吸附脚步声，夏天的蚊虫则是最烦人的告密者。进阶章节讲解如何利用风向隐藏体味，以及如何在移动中保持弓弦不发出声响。作者特别强调，真正高明的匿踪不是一动不动，而是让对方的眼角余光把你误判为灌木或岩石。书的扉页上有人用炭笔画了一只狐狸，旁边写着：“狐狸不会消失，它只是知道你怎么看东西。”许多盗贼试图偷学此法，却发现没有野外生存经验的人根本无法理解脚步与地形的配合。作者提醒，此法最怕的不是眼睛，而是受过训练的猎犬鼻子。

## 设计意图

将游侠的“远程+隐匿”职业画像具象化，为埋伏与首轮爆发提供战术基础。
