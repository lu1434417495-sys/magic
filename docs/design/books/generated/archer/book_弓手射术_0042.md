# 《空放的危害》

## 基础信息

- **书籍 ID**：`book_弓手射术_0042`
- **关联技能**：`archer_dry_fire`、`archer_bow_maintenance`
- **使用效果**：阅读后解锁 `archer_dry_fire`（知识类，防止空放）；若已学会，提升弓类武器耐久损耗抗性 10%。
- **阅读要求**：无职业限制；基础 `智力 ≥ 6`。
- **稀有度**：普通（Common）
- **建议投放**：新手训练场、弓匠警告海报、通用武馆书架。

## 书籍内容

《空放的危害》是一本薄薄的安全手册，却被老弓手视为必读。作者用惨痛的案例说明：没有搭箭就释放弓弦，会让弓臂承受全部能量，极可能导致开裂甚至折断。书中详细解释了空放的物理原理，并提供了检查自己是否已搭箭的几种习惯动作。作者还提醒，即使是练习用的低磅数弓，空放也会缩短其寿命。后半本讨论了如何在紧张战斗中避免因慌乱而空放，包括建立固定的拉弓前检查流程。最末页有一句话被加粗：空放一下，可能毁掉你最好的朋友。许多训练场会把这本书作为入学第一课，因为一次空放就足以让新手付出惨痛的代价，并且后悔很久，甚至永远失去那把陪伴自己的弓。许多老弓手会在扉页写下自己的心得，留给后来的学徒。它不大，也不厚，却能在关键时刻替弓手省下一支本可救命的箭。

## 设计意图

以安全知识的形式强化装备耐久系统，让新手玩家重视正确操作。
