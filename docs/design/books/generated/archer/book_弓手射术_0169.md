# 《回旋箭》

- **阅读要求**：职业标签含 `archer` 或 `ranger`；基础 `敏捷 ≥ 12` 且 `智力 ≥ 10`。

## 书籍内容

《回旋箭》收录一种能在击中目标后借助风力回旋的奇特箭术。作者坦言此法源自精灵游侠，需要特殊箭羽设计与精确的角度控制。前半本讲解箭羽造型：单侧螺旋羽让箭矢在飞行中旋转，命中后产生回弹力。中章提供发射角度表，要求射手根据距离选择不同的偏航角，否则箭矢无法返回。后半本讨论回收箭矢的实用性，在物资匮乏的远征中可大幅减少消耗。书中还提到，回旋箭威力较普通箭弱，适合骚扰与侦察而非致命狙杀。作者提醒，回旋箭在密林中容易缠绕树枝，开阔地形使用效果最佳。末尾附有羽毛裁剪模板。

一位精灵批注者在页边画了一片叶子，旁边写着：风会把它带回来，但你要先学会信任风。他还记录了十七种羽毛角度，对应不同的回旋距离与回收概率。

## 设计意图

为弓手提供资源回收与持续骚扰能力，适合长期远征与消耗战，增加玩法多样性。
