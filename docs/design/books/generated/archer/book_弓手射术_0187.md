# 《猎影步》

## 基础信息

- **书籍 ID**：`book_弓手射术_0187`
- **关联技能**：`archer_hunter_shadow_walk`（待新增）
- **使用效果**：阅读后解锁 `archer_hunter_shadow_walk`；若已学会，提升该技能 `current_mastery +110`，并在阴影中移动后下一回合获得 `+15%` 闪避。
- **阅读要求**：职业标签含 `archer` 或 `ranger`；基础 `敏捷 ≥ 13` 且 `感知 ≥ 11`。
- **稀有度**：稀有（Rare）
- **建议投放**：暗影猎手营地、遗迹密林、夜间委托。

## 书籍内容

《猎影步》是一种让弓手在阴影中无声移动的步法。作者将猎人比作影子，越是接近目标，越要融入黑暗。前半本讲解踩踏技巧：用脚掌外侧先着地，再缓缓放平，避免踩碎枯叶与碎石。中章介绍如何利用月光与火把的死角，让身体始终处于明暗交界处。后半本讨论移动与射击的衔接，要求在最暗处搭箭，在暴露前一瞬完成射击并退回阴影。书中还提到，猎影步在雪地和沙地效果较差，因为足迹会暴露行踪。作者提醒，长期使用阴影会让射手产生依赖，应学会在阳光正射时也能作战。末尾附有夜视训练法，帮助提高黑暗中的命中率。

书中有几页被撕掉，据说是某位暗影大师不愿公开的高级步法。残存的内容已经足够让普通弓手在黑暗中如鱼得水，但真正的猎影奥义或许早已失传。猎影步与夜色结合，方能发挥最大威力。

## 设计意图

为弓手提供潜行移动与夜间作战能力，强化刺客型弓手Build，增强环境利用。
