# 《龙脊长弓养护》

## 基础信息

- **书籍 ID**：`book_弓手射术_0094`
- **关联技能**：`archer_dragon_bow`、`archer_bow_crafting`
- **使用效果**：阅读后解锁 `archer_dragon_bow`；若已学会，提升 `current_mastery +250`，并使龙脊弓每日首次击杀精英敌人时耐久不损耗。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；已学会 `archer_bow_crafting`；基础 `力量 ≥ 15`，`感知 ≥ 13`。
- **稀有度**：传说（Legendary）
- **建议投放**：古龙陨落之地、传奇收藏家拍卖、龙裔长老馈赠。

## 书籍内容

龙脊长弓是弓手能触及的最顶级武器之一，但绝大多数人得到它后三年内就会毁掉它。《龙脊长弓养护》由一位龙裔铸弓师写成，他强调龙脊不是木料，而是有记忆的骨骼。书中要求使用者每天用特定频率拉动弓弦，让龙脊记住使用者的力量曲线；每隔七日要用龙血或替代药剂擦拭弓身，防止骨质干裂。最惊人的章节是“龙骨共鸣”：当射手与龙脊弓长期配合后，弓会在拉满时发出低沉的龙吟，此时射出的箭矢会带有微弱的龙焰。作者也警告，背叛龙脊弓的人会遭到反噬，因为龙骨会记住每一丝恶意。书的封面镶嵌着一片真正的龙鳞，触感温热。龙裔铸弓师临终前把最后一片龙鳞嵌入了书封面，他说这样龙骨就不会忘记回家的路。龙脊弓会记住第一任主人，转让后需重新建立数月默契。

## 设计意图

作为传奇级武器专精技能，为顶级弓手提供身份象征与长期养成目标。
