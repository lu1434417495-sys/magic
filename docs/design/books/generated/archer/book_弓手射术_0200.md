# 《灵风九射》

## 基础信息

- **书籍 ID**：`book_弓手射术_0200`
- **关联技能**：`archer_nine_wind_shots`（待新增）

- **建议投放**：传说宝箱、远古射手英灵试炼、世界之巅事件。

## 书籍内容

《灵风九射》是弓手射术的终极奥义之一，要求射手在瞬息之间射出九支箭，每一箭都借前一箭的风势加速。作者警告，此技对体能与感知要求极高，稍有差池便会筋疲力竭。前半本讲解起手式：九支箭分三排插于身前，以极快的速度依次取用。中章介绍风势借用，第二箭要瞄准第一箭的尾流，第三箭再借第二箭之力，依此类推。后半本讨论收势，九箭射完后必须立即调息，否则双臂会暂时失去知觉。书中还提到，灵风九射的第九箭威力可达第一箭的三倍，但命中率也会下降。作者提醒，此技不应在开局使用，留待决战方能一锤定音。末尾附有九支箭的飞行轨迹图。

传说练成此技者，能在九箭之内让山谷中的风都为之静止。作者最后写道，灵风九射的第九箭不应瞄准敌人，而应瞄准敌人心中的恐惧，方能不战而屈人之兵。

## 设计意图

作为弓手系的终极输出奥义，通过连射递增伤害塑造决战时刻的爆发体验，标志弓手巅峰之路。
