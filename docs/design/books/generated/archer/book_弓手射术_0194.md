# 《冥想·风息》

## 基础信息

- **书籍 ID**：`book_弓手射术_0194`
- **关联技能**：`archer_meditation_wind_breath`（待新增）
- **使用效果**：阅读后解锁 `archer_meditation_wind_breath`；若已学会，提升该技能 `current_mastery +120`，并使风息状态下远程技能 MP 消耗降低 `10%`。
- **阅读要求**：职业标签含 `archer` 或 `ranger`；已习得 `meditation ≥ 2`。
- **稀有度**：史诗（Epic）

## 书籍内容

《冥想·风息》将冥想中的呼吸法与弓术结合，创造出适合远程职业的魔力循环。作者认为，弓手消耗的魔力不多，但关键时刻的一点差距足以决定生死。前半本讲解坐姿与气息：想象自己是一根被风贯穿的芦苇，吸气时魔力入体，呼气时魔力沿手臂流向箭矢。中章介绍如何在战斗中快速进入风息状态，使下一次射击的魔力消耗大幅降低。后半本讨论风息与移动的关系，奔跑中难以冥想，但短暂停顿即可恢复一丝魔力。书中还提到，风息冥想对MP上限有温和提升，适合长期修炼。作者提醒，不可为省魔力而降低射击质量，否则得不偿失。末尾附有每日冥想时辰建议。

书页在风中会轻轻翻动，仿佛本身也在随呼吸起伏。作者建议练习者在日出前与日落后的微风时刻修炼，因为此时风息最为平稳，最容易进入状态。

## 设计意图

结合冥想系统为弓手提供资源续航能力，鼓励玩家投资冥想技能，拓展Build深度。
