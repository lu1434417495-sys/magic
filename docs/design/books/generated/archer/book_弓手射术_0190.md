# 《时隙之箭》

## 基础信息

- **书籍 ID**：`book_弓手射术_0190`
- **关联技能**：`archer_time_gap_arrow`（待新增）

- **建议投放**：传说宝箱、时空裂隙事件、远古试炼。

## 书籍内容

《时隙之箭》传说能捕捉到时间流中的微小缝隙，让箭矢在敌人来不及反应时命中。作者身份不明，书中夹有来自不同年代的批注，仿佛此书能穿越时空。前半本讲解感知时隙：在拉满弓的刹那，世界会变得缓慢，那一刻便是缝隙所在。中章介绍如何在缝隙中放箭，使箭矢几乎同时出现在起点与终点。后半本讨论风险，强行进入时隙会让射手短暂失神，甚至造成记忆错位。书中还提到，时隙之箭对机械构造体效果较弱，因其不在常规时间感知中。作者提醒，追逐时间者终会被时间追逐，此技每场战斗只能使用有限次数。末尾有一页无法阅读，只在月光下显现字迹。

传说最后一位读懂末页的人，从此再也没有在同一地方出现两次。有人说他迷失在了时间缝隙中，也有人说他找到了通往更高维度的入口，真相无人知晓。

## 设计意图

作为弓手系的传说技能，引入时间缝隙概念，提供额外行动机会，塑造高端战斗体验。
