# 《霜弦冰箭引》

## 基础信息

- **书籍 ID**：`book_弓手射术_0116`
- **关联技能**：`archer_ice_arrow`（待新增）
- **使用效果**：阅读后解锁 `archer_ice_arrow`；若已学会，提升该技能 `current_mastery +120`，并提升冰冻效果的触发概率。
- **阅读要求**：职业标签含 `archer` 或 `mage`；基础 `智力 ≥ 10`。
- **稀有度**：精良（Uncommon）
- **建议投放**：冰原法师塔、雪山隐士、元素商人。

## 书籍内容

霜弦冰箭引的封皮覆盖着一层永远不会融化的薄霜。作者将冰箭定义为"减速与控制"而非纯伤害。前半本讲解如何在箭镞上凝聚冰晶而不让箭身过重，以及低温对弓弦弹性的影响。中章分析冰箭的战术价值：射中敌人腿部可降低其移动速度，射中武器可让金属变脆，射中地面可制造滑行区域。后半本则是一本失败案例集，记录了因冰晶分布不均导致箭在空中碎裂的事故。作者提出"呼吸冻结"练习：在开弓呼气时，想象气息凝结成箭，以此训练专注力。作者在后记中提醒，冰箭在干燥环境中效果会大打折扣，因为冰晶容易碎裂，最理想的战场是潮湿的沼泽或雨后的林地。

呼吸冻结练习需要在寒冷环境中进行，但作者提醒不要在天寒地冻时过度练习，否则手指会失去知觉，反而无法正确扣弦。

## 设计意图

让弓手获得控制型元素射击，衔接法师冰系技能形成跨职业协同。
