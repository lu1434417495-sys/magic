# 《陷阱配合射法》

## 基础信息

- **书籍 ID**：`book_弓手射术_0019`
- **关联技能**：`archer_trap_synergy`、`archer_hunter_mark`
- **使用效果**：阅读后解锁 `archer_trap_synergy`；若已学会，提升 `current_mastery +100`，并使被陷阱减速的目标受到的下一次射击伤害 +10%。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；已学会 `archer_hunter_mark`；基础 `敏捷 ≥ 9`。
- **稀有度**：精良（Uncommon）
- **建议投放**：游侠陷阱师营地、猎人公会战术书架、野外伏击专家。

## 书籍内容

《陷阱配合射法》是为那些不满足于单纯射箭的弓手准备的。作者详细讲解了如何将陷阱与射击节奏结合：先以陷阱限制敌人移动，再在敌人挣扎时完成致命一击。书中列举了绊索、陷坑、尖桩与弓箭配合的经典案例，并强调陷阱不是替你杀人，是替你争取时间。后半本有一章专门讲诱敌，教射手如何用一箭故意打偏来吸引敌人踏入陷阱区。最末页画着一个简笔猎人，正站在安全距离外等待一头被绳索缠住的野兽，配文：耐心是陷阱的一部分，也是弓手的一部分。边境巡逻队的老兵常说，读懂这本书的人，布下的陷阱连野兽都会主动绕开，因为他们懂得利用猎物自己的选择，把战场变成一张精心编织的网。陷阱与箭的配合，本质上是把时间与空间都变成弓手手中的武器。在弓手的小圈子里，能背出这本书最后一句话的人总会赢得额外的尊重。

## 设计意图

拓展弓手战术维度，与盗贼/游侠的陷阱技能形成联动。
