# 《指套与扳指考》

## 基础信息

- **书籍 ID**：`book_弓手射术_0033`
- **关联技能**：`archer_finger_tab`、`archer_draw_power`
- **使用效果**：阅读后解锁 `archer_finger_tab`；若已学会，提升 `current_mastery +70`，并降低长时间拉弓对手指的磨损惩罚。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；基础 `敏捷 ≥ 7`。
- **稀有度**：普通（Common）
- **建议投放**：游侠装备商人、皮革工匠、初级射击训练场。

## 书籍内容

《指套与扳指考》是一本看似琐碎却极其实用的书。作者从手指保护的角度切入，比较了皮革指套、骨质扳指和金属扳指的优劣，并讲解了如何根据拉弦方式选择合适类型。书中强调，劣质护具不仅不能保护手指，还会改变放弦手感，导致射偏。作者还提供了自制简易指套的方法，让没有装备的射手也能应急。后半本讨论了不同气候下皮革的保养，以及如何判断护具何时需要更换。最末页有一句话：弓手的手指比箭更珍贵，因为手指断了，箭就再也射不出去了。许多射手在第一次手指磨出血后，才会真正重视这本书，并在护具上多花一些他们曾经舍不得的钱，换来的是更长久也更稳定的射击生涯。真正掌握它的人，往往会对自己的弓产生全新的理解。真正掌握它的人，往往会重新理解自己与弓之间那种沉默的默契。

## 设计意图

从细节装备切入，强化弓手职业的沉浸感与装备选择深度。
