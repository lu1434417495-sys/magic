# 《绊索箭与陷阱箭》

## 基础信息

- **书籍 ID**：`book_弓手射术_0041`
- **关联技能**：`archer_trip_arrow`、`archer_trap_synergy`
- **使用效果**：阅读后解锁 `archer_trip_arrow`；若已学会，提升 `current_mastery +100`，并提升陷阱触发范围 10%。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；已学会 `archer_trap_synergy`；基础 `敏捷 ≥ 9`。
- **稀有度**：精良（Uncommon）
- **建议投放**：游侠陷阱师、边境巡逻队、伏击破环任务奖励。

## 书籍内容

《绊索箭与陷阱箭》教弓手如何把箭本身变成陷阱。作者讲解了多种特殊箭矢：落地后展开绳索的绊索箭、插入地面后触发尖刺的地雷箭、以及携带诱饵吸引野兽的引诱箭。书中强调，这类箭矢的关键不是杀伤力，而是布置位置与触发时机。作者还提醒，使用绊索箭时必须记住自己布置的位置，否则会在撤退时自食其果。后半本收录了经典的伏击战例，分析如何利用地形让敌人主动踏入箭陷阱。最末页有一句话：最好的陷阱，是让猎物以为是自己在选择路线。许多边境游侠会在箭囊里专门留出一格给这些不寻常的箭，因为它们能在战斗开始前就结束战斗，让弓手少射很多不必要的箭。在风息哨塔的藏书架上，这本书总是被最早借走。无论是在森林、雪原还是沙漠，这本书教的原则都能派上用场。

## 设计意图

深化陷阱与射术的结合，为控场型弓手提供更多战术工具。
