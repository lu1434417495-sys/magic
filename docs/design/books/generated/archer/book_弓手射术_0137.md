# 《前臂耐力修炼》

## 书籍内容

前臂耐力修炼没有华丽的招式，只有枯燥的训练计划。作者认为，弓手最大的瓶颈往往不是技术，而是肌肉无法支撑长时间的稳定拉弓。前半本讲解前臂、肩膀和上背部的协同发力，以及如何避免代偿性损伤。中章提供渐进式训练方案：从轻弓开始，逐步增加拉弓保持时间，最后过渡到实战中的间歇射击。后半本讨论恢复：按摩、热敷、拉伸和休息日的重要性。作者严厉警告过度训练的危害，并提供了自测疲劳的方法。书中还附有一张"疲劳信号表"：当小臂开始发抖、呼吸变浅、眨眼频率增加时，意味着射手该换轻弓或停止射击。最后一页写着："耐力不是让你射得更多，是让你在需要射的时候还能射。"

疲劳信号表被印在一张可撕下的卡片上，方便射手随身携带。许多人把它贴在箭袋内侧，每次取箭时都能看到，提醒自己不要逞强。

## 设计意图

为弓手提供持续作战能力，解决长时间战斗中精准衰减的问题。
