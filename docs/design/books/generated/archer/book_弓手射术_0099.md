# 《虚无之弦》

## 基础信息

- **书籍 ID**：`book_弓手射术_0099`
- **关联技能**：`archer_void_string`、`archer_meteorite_arrow`
- **使用效果**：阅读后解锁 `archer_void_string`；若已学会，提升 `current_mastery +260`，并使虚无弦箭有 30% 几率穿透第一个目标后继续飞行。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；已学会 `archer_meteorite_arrow` 或任意 `ashen_` 前缀技能；基础 `感知 ≥ 16`，`意志 ≥ 15`。
- **稀有度**：传说（Legendary）
- **建议投放**：虚空裂隙边缘、异界商人终极货物、世界BOSS战利品。

## 书籍内容

《虚无之弦》没有实体书页，它的内容会随阅读者的理解程度自动显现或消失。作者身份不明，有人说是从虚空裂隙中逃出的幸存者，有人说是虚空本身的低语。书中教授的弦术要求射手用来自虚无的材料替换普通弓弦，这种弦没有重量、没有温度，也不会反射光线。拉满虚无之弦时，射手会听到一种类似深海般的寂静，所有外界声音都被吸收。作者警告，虚无弦会逐渐侵蚀使用者的存在感，长期使用的人会在镜中变得越来越模糊。最恐怖也最诱人的章节描述了“贯穿射”：虚无箭可以穿透第一个目标，继续飞向第二个、第三个，直到力量耗尽或射手主动终止。虚无裂隙附近的居民能辨认出使用虚无之弦的人：他们的影子比常人淡一些，笑声也轻一些。虚无之弦会缓慢吸收射手的存在感，使用者终将变得透明。

## 设计意图

作为传奇级异界弓术，为顶级弓手提供独特的穿透机制与存在代价。
