# 《断弦之击》

## 基础信息

- **书籍 ID**：`book_弓手射术_0184`
- **关联技能**：`archer_string_snap_shot`（待新增）
- **使用效果**：阅读后解锁 `archer_string_snap_shot`；若已学会，提升该技能 `current_mastery +110`，并使断弦一击伤害提升 `20%`，但会损耗当前弓弦。
- **阅读要求**：职业标签含 `archer` 或 `ranger`；基础 `力量 ≥ 13` 且 `敏捷 ≥ 11`。
- **稀有度**：稀有（Rare）
- **建议投放**：游侠大师书房、遗迹武库、绝境任务。

## 书籍内容

《断弦之击》记载一种以牺牲弓弦为代价释放极端力量的射法。作者警告，此技应只在生死关头使用，因为之后会失去远程攻击能力。前半本讲解蓄力方法：将弓弦拉至超出安全范围，让弓身承受极限张力。中章介绍释放技巧，必须在弦断的瞬间让箭矢获得最大推力，稍有迟疑便会空放。后半本讨论战前准备，包括携带备用弓弦与快速换弦工具。书中还提到，断弦之击对弓身有损伤，多次使用可能导致弓臂开裂。作者提醒，使用前应确认近战友军能掩护自己换弦。末尾附有一首古老战歌，据说吟唱时能让弓手忘记对弓弦断裂的恐惧。

书页间夹着一根断裂的弓弦，旁边用血写着：为了这一箭，值得。作者警告，断弦之击会让弓身产生微裂，累积三次以上便可能彻底报废一张好弓。

## 设计意图

为弓手提供绝境爆发手段，以装备损耗换取高额伤害，强化高风险高回报决策。
