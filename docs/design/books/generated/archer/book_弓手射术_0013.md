# 《弱点观察入门》

## 基础信息

- **书籍 ID**：`book_弓手射术_0013`
- **关联技能**：`archer_vital_spot`、`archer_aimed_shot`
- **使用效果**：阅读后解锁 `archer_vital_spot`；若已学会，提升 `current_mastery +90`，并提升对类人型敌人弱点部位的命中判定。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；基础 `感知 ≥ 9`。
- **稀有度**：普通（Common）
- **建议投放**：游侠战术书架、老兵弓手导师、战俘营审讯记录处。

## 书籍内容

《弱点观察入门》不教人射箭，只教人看。作者把人体和常见怪物身体分成若干区域，逐一分析哪里的护甲最薄、哪里的活动范围最大、哪里的神经最密集。书中强调，真正的弱点观察不是在拉弓时才做，而是在敌人移动的过程中就已经完成判断。作者设计了一套练习：观察一个移动目标，在心中默念三个可能的弱点，然后看自己的预测与实际命中点相差多少。后半本讨论了盔甲缝隙、关节连接处和呼吸起伏之间的关系。最末页有一句话被反复圈出：看见弱点，比射中弱点更难。许多刺客也会偷偷阅读这本书，因为对于任何远程职业来说，提前看见破绽都意味着生死之差，也意味着你不必在慌乱中浪费更多宝贵的箭矢。一位老兵在书边批注：先看见，再拉弓，箭自然会找到它该去的地方。有人说，这本书真正的价值不在于技巧，而在于它塑造的思维方式。

## 设计意图

为精准暴击与弱点系统奠定基础，让玩家从打中进化到打对地方。
