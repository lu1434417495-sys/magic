# 《短距速射七式》

## 基础信息

- **书籍 ID**：`book_弓手射术_0006`
- **关联技能**：`archer_rapid_fire`、`archer_short_shot`
- **使用效果**：阅读后解锁 `archer_short_shot`；若已学会，提升 `current_mastery +90`，并在下一次战斗中前三次射击攻速 +8%。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；已学会 `archer_basic_aim`；基础 `敏捷 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：风息哨塔进阶书架、近战弓手教官、森林巡逻队奖励。

## 书籍内容

《短距速射七式》专门解决一个问题：当敌人已经冲到眼前，弓手该怎么办。作者认为，短距离射击的关键不是精准度，而是节奏。书中把连续射击拆成七个微型动作：转腰、搭箭、拉半弦、松手、复位，每个动作都被压缩到最短。作者警告，短距速射时不要追求拉满，半弦射出的箭在十步内依然致命。后半本提供了七组固定靶练习，要求射手在规定节拍内完成指定次数的命中。书的边角处有一行潦草批注：第七式不是最快的，是最不慌的。许多老兵回忆说，正是这句话让他们在第一次遭遇近战时活了下来。真正掌握七式的人，能在敌人逼近时把恐惧转化为节拍，用连续不断的箭矢在生死之间筑起一道脆弱的防线。这套技法让弓手在被近身时不至于慌乱，因为节奏一旦建立，敌人的逼近反而成了催动箭矢的节拍器。

## 设计意图

为弓手提供近距离自保能力，弥补远程职业被贴身后的输出空档。
