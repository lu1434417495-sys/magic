# 《毒藤箭囊制作》

## 基础信息

- **书籍 ID**：`book_弓手射术_0054`
- **关联技能**：`archer_poison_arrow`、`archer_arrow_balance`
- **使用效果**：阅读后解锁 `archer_poison_arrow`；若已学会，提升 `current_mastery +130`，并解锁毒液材料 `vine_poison_gland` 的采集权限。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；基础 `感知 ≥ 9`，`智力 ≥ 7`。
- **稀有度**：精良（Uncommon）
- **建议投放**：毒藤沼泽据点、炼金游侠商店、边境黑市商人。

## 书籍内容

这本书的封面用晒干的毒藤皮包裹，翻阅时必须小心，因为部分页边仍残留刺激性汁液。作者是一位被逐出游侠公会的药剂师，他详细记录了如何从沼泽毒藤的腺体中提取稳定毒素，并将这种毒液封存在特制的陶制箭囊中。书中强调，毒素的关键不在致命，而在“减速”：让猎物在追逐中逐渐僵硬，比直接毒死更符合狩猎伦理。制作章节之后是道德警告，反复告诫不要在饮用水源附近使用毒箭，也不要对智慧生物使用浓缩配方。最令读者不安的是夹在其中的一封未寄出的信，收信人是作者的妹妹，内容只有一句话：“我没有杀他，我只是让他的腿停在了沼泽里。”这本书因此在许多国家被列为禁书，但在游侠黑市中流通极广。由于其危险性，多个城市明令禁止在城墙内制作毒藤箭囊，违者会被逐出游侠公会。
