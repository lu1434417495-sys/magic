# 《双弦齐发要诀》

## 基础信息

- **书籍 ID**：`book_弓手射术_0062`
- **关联技能**：`archer_dual_draw`、`archer_rapid_fire`
- **使用效果**：阅读后解锁 `archer_dual_draw`；若已学会，提升 `current_mastery +160`，并使双箭齐发的第二支箭伤害提升 10%。
- **阅读要求**：角色职业标签含 `archer`；已学会 `archer_rapid_fire`；基础 `敏捷 ≥ 12`，`力量 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：双弦大师隐居处、古代射术遗迹、高阶游侠试炼奖励。

## 书籍内容

能同时拉开两支箭的人不多，能同时命中两个目标的人更少。《双弦齐发要诀》的作者自称属于一个已经失传的射术流派，他强调双弦不是力量的炫耀，而是注意力的分配艺术。书中将双眼分别训练：左眼负责左侧目标，右眼负责右侧目标，最终让大脑同时处理两条弹道。初学者常常犯的错误是同时关注两支箭，结果两支都偏；正确做法是只关注第一支的落点，让第二支靠节奏自然跟出。作者还讲解了几种特殊的双箭搭法，包括平行式、分叉式和追尾式，每种对应不同的战术场景。书的最后几页已经破损，但还能辨认出一句话：“双弦真正的代价不是手臂，是你必须相信眼睛比自己诚实。”据说真正练成此法的人，左右眼视力会出现细微差异，这是大脑被迫分裂注意力的后遗症。修炼此法初期常出现复视，需配合特制眼罩逐步适应。

## 设计意图

为高阶弓手提供高风险高回报的多目标输出技能。
