# 《破空尖啸箭》

## 基础信息

- **书籍 ID**：`book_弓手射术_0069`
- **关联技能**：`archer_whistling_arrow`、`archer_tracking_shot`
- **使用效果**：阅读后解锁 `archer_whistling_arrow`；若已学会，提升 `current_mastery +110`，并使尖啸箭命中时降低目标 10% 命中率，持续 3 秒。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；基础 `感知 ≥ 9`。
- **稀有度**：普通（Common）
- **建议投放**：斥候营地、信号兵训练场、边境通讯站。

## 书籍内容

《破空尖啸箭》是一本关于“让箭发出声音”的书。作者最初是军队中的信号兵，他发现箭矢在飞行中发出的尖啸可以干扰敌人的判断，甚至让战马受惊。书中介绍了多种制作尖啸孔的方法：在箭杆侧面钻对称的小孔，或者在箭尾加装中空木哨。不同孔径和角度会产生不同音高，作者建议每位射手都找到自己最容易辨识的音调作为“个人信号”。后半本转向战术：如何用尖啸箭指示队友转移火力，如何用连续三声尖啸表示撤退，以及如何在对峙中用突如其来的尖啸打乱敌方施法节奏。作者也提醒，尖啸箭会暴露射手位置，因此射出后必须立刻移动。某些游牧部落把尖啸箭当作葬礼仪式的一部分，认为它能引导逝者的灵魂升天。某些骑士团的战马会接受尖啸箭脱敏训练，降低此招效果。抄本虽旧，却极为实用。

## 设计意图

引入功能性/信号型弓手技能，拓展弓手在团队指挥中的战术价值。
