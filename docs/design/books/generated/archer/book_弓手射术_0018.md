# 《猎手标记术》

## 基础信息

- **书籍 ID**：`book_弓手射术_0018`
- **关联技能**：`archer_hunter_mark`、`archer_tracking_shot`
- **使用效果**：阅读后解锁 `archer_hunter_mark`；若已学会，提升 `current_mastery +100`，并使标记目标在被集火时受到的伤害 +5%。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；基础 `感知 ≥ 9`。
- **稀有度**：精良（Uncommon）
- **建议投放**：猎人公会进阶任务、游侠队长奖励、森林据点的战术教官。

## 书籍内容

《猎手标记术》教给弓手的不是如何射得更狠，而是如何让别人射得更准。作者认为，一个优秀的猎手首先要让全队看见同一个目标。书中介绍了多种标记方式：颜料箭、响箭、光粉箭，以及在紧急情况下用口哨与手势配合。作者强调，标记必须清晰但不过度显眼，否则敌人也会注意到自己被标记。后半本讨论了标记时机，提醒读者不要在敌人准备冲锋时暴露自己的位置。最末页有一幅战场示意图，多个箭头指向同一个被红圈标出的敌人，旁边写着：最好的箭，是让队友的箭也变得更致命的箭。许多游侠队长会把这本书当作小队训练的第一本教材，因为它把个人射术变成了集体火力，也让每个射手明白自己不是孤军奋战。能够放下自我伤害、成全团队集火的人，才配得上标记者的称号。许多后来成名的弓手回忆，正是这本书让他们第一次觉得自己像个真正的射手。

## 设计意图

引入团队协同机制，让弓手在组队战斗中承担战术指挥与集火引导角色。
