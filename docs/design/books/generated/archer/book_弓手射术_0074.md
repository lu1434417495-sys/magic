# 《雾中抛射箭》

## 基础信息

- **书籍 ID**：`book_弓手射术_0074`
- **关联技能**：`archer_lob_shot`、`archer_aimed_shot`
- **使用效果**：阅读后解锁 `archer_lob_shot`；若已学会，提升 `current_mastery +110`，并使抛射箭在命中掩体后目标时无视 20% 护甲。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；基础 `感知 ≥ 9`。
- **稀有度**：普通（Common）
- **建议投放**：沼泽游侠据点、攻城器械师、迷雾湿地宝箱。

## 书籍内容

当视线受阻时，直线射击往往无能为力，而抛射箭可以越过障碍从天而降。《雾中抛射箭》的作者常年在沼泽和峡谷活动，他总结出不同距离下的仰角公式，并用简笔画标注了二十度、四十五度和七十度三种常用弹道。书中强调，抛射箭的关键是估算落点而非瞄准目标本身，射手需要在心中构建一个看不见的弧线。作者还讲解了如何利用雾气隐藏箭矢下落，以及如何通过听声音判断箭矢是否命中预定区域。一个常见错误是过度追求高抛，因为过高的箭矢会损失速度和穿透力。书末附有作者在雾天练习时画下的靶纸，上面布满了从上方扎入的箭孔，像一场小型流星雨。沼泽游侠会在箭尾绑上彩色布条，方便在雾中观察箭矢下落轨迹并及时修正。此法最考验射手对落点的想象力，常练者在晴天也能闭眼估算。

## 设计意图

为弓手提供绕过掩体的战术射击手段，强化环境利用能力。
