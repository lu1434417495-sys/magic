# 《兽群驱散箭》

## 基础信息

- **书籍 ID**：`book_弓手射术_0089`
- **关联技能**：`archer_scatter_shot`、`archer_volley`
- **使用效果**：阅读后解锁 `archer_scatter_shot`；若已学会，提升 `current_mastery +120`，并使散射箭对野兽额外造成 15% 伤害。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；基础 `感知 ≥ 9`。
- **稀有度**：普通（Common）
- **建议投放**：猎人公会、野兽出没区域营地、游侠补给箱。

## 书籍内容

面对成群扑来的野兽，单支箭往往无济于事。《兽群驱散箭》教授如何制作和使用能在空中分裂的多头箭，以及如何通过声响和火光让兽群产生混乱。作者是一位专门猎杀狼群的边境猎人，他发现野兽比人类更容易被突发噪音吓到，因此驱散箭的关键不是杀伤，而是制造足够大的声响和闪光。书中详细记录了不同野兽的恐惧反应：狼群会围绕领导者犹豫，野猪会盲目冲锋，而鸟群则会整体改变方向。作者还建议在箭囊中常备几支只装火药的“空响箭”，专门用来在关键时刻吓退扑来的掠食者。猎人行会规定，使用驱散箭时必须确保不会误伤普通家畜，违者会被吊销执照。驱散箭对受过训练的战马效果较差，但对野生动物几乎百试百灵。该书在民间有多个改编版本。有经验的猎人还会根据季节调整箭头声响，春季鸟类孵卵期尤其忌讳使用。

## 设计意图

为弓手提供面对多目标低级敌人时的清场与控场手段。
