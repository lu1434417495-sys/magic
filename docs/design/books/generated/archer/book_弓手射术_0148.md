# 《弓弦养护与选弦》

## 基础信息

- **书籍 ID**：`book_弓手射术_0148`
- **关联技能**：`archer_string_care`（待新增）
- **使用效果**：阅读后解锁 `archer_string_care`；若已学会，提升该技能 `current_mastery +70`，并延长弓弦在恶劣环境中的耐久。
- **阅读要求**：职业标签含 `archer` 或 `ranger`；基础 `智力 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：弓匠铺、军需官、猎人小屋。

## 书籍内容

弓弦养护与选弦比弦振校准录更偏向基础保养。作者用通俗语言讲解弓弦的生命周期：新弦需要拉伸定型，使用中需要清洁，存放时需要防潮防晒。前半本介绍蜡质保养法：如何用蜂蜡均匀涂抹弦身，如何避免蜡块堆积影响弹性。中章讲选弦原则：不同拉力、不同箭重、不同弓长都需要匹配不同弦料。后半本则是故障排查：断弦前的征兆、弦结松动的处理、紧急情况下的临时修复。作者在最后提醒，新弦上弓后的头三天是最危险的，因为弦料还在适应张力。这期间应避免满弓射击，只用半满弓让弦逐渐定型。最后一页是一幅漫画：一个新手因忽视保养而在关键时刻断弦。

新弦定型期间，作者建议射手用旧弓练习，避免让新弦承受不必要的磨损。这个看似矛盾的做法能显著延长弦的使用寿命。

## 设计意图

强化弓手的装备管理维度，让日常维护成为战斗可靠性的来源。
