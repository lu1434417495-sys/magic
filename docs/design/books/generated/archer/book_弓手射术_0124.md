# 《仰攻抛射指南》

## 书籍内容

仰攻抛射指南是一本被泥土和汗水浸透的小册子。作者记录了自己在山地战中从劣势位置反击的经验。仰攻时，射手必须拉得更满，因为箭矢需要克服额外的重力分量；同时提前量要大，因为箭在空中飞行时间更长。前半本用图示讲解不同坡度下的力度修正。中章讲如何利用地形遮蔽：岩石、树桩、陡坡都可以成为临时掩体。后半本讨论体力分配：仰攻射手比平地射手更快疲劳，因此必须精选射击时机。作者在后记中强调，仰攻时最危险的不是射不中，而是射中后被滚落的碎石或尸体砸到。他建议仰攻射手每次放箭后立即横向移动。最后一页写着："从下往上射，你不是在射目标，你是在和重力借钱。"

横向移动的要求看似违反直觉，因为射手本能会想后退。但作者用大量战例证明，横向移动能让敌人的仰攻姿态更难调整，反而更安全。

## 设计意图

为弓手提供劣势地形下的补偿能力，让远程职业在地形复杂的战斗中更有韧性。
