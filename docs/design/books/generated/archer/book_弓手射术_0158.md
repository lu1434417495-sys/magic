# 《曲射要诀》

## 基础信息

- **书籍 ID**：`book_弓手射术_0158`
- **关联技能**：`archer_curved_shot`（待新增）
- **使用效果**：阅读后解锁 `archer_curved_shot`；若已学会，提升该技能 `current_mastery +80`，并使曲射越过障碍时命中率提升 `12%`。
- **阅读要求**：职业标签含 `archer` 或 `ranger`；基础 `感知 ≥ 10`。
- **稀有度**：普通（Common）
- **建议投放**：游侠训练场、城防军教头、遗迹靶场。

## 书籍内容

《曲射要诀》专研绕过掩体与城墙的抛射箭术。作者从基础弹道学入手，说明箭矢在不同仰角下的落点变化。前半本要求射手熟记三十步、五十步、八十步三个基准距离的对应仰角，并通过反复练习形成肌肉记忆。中章讨论风速对曲射的放大效应，顺风时落点会远超预期，逆风则需抬高更多。后半本讲解如何利用曲射打击掩体后目标，关键是观察敌人影子、声音与露出的衣角来判断位置。书中收录了多个战例，最著名的是一箭越过城墙射中敌旗手的传说。作者提醒，曲射依赖预判，在移动目标上需要预留更大的提前量。

书中还附有一张简易抛物线表，但作者在边角注明：实战中的风，从不会按表格吹。真正熟练的射手，会在表格数字与个人经验之间找到属于自己的修正值。

## 设计意图

为弓手提供越障打击能力，扩展射击角度与战术空间，适合攻城战与复杂地形作战。
