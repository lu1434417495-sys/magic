# 《陨铁箭镞铸造》

## 基础信息

- **书籍 ID**：`book_弓手射术_0096`
- **关联技能**：`archer_meteorite_arrow`、`archer_piercing_shot`
- **使用效果**：阅读后解锁 `archer_meteorite_arrow`；若已学会，提升 `current_mastery +190`，并解锁陨铁箭镞锻造配方，对魔法护盾伤害 +25%。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；已学会 `archer_piercing_shot`；基础 `力量 ≥ 12`，`智力 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：陨铁工坊、占星塔地下室、古代兵器库。

## 书籍内容

陨铁来自天外，携带着这个世界不熟悉的魔力。《陨铁箭镞铸造》记录了如何将陨铁碎片锻造成箭镞，并让它在命中魔法护盾时产生奇特的“共鸣刺穿”效果。作者是一位痴迷于星象的铁匠，他发现不同陨落地点的陨铁性质不同：北方冻原的陨铁寒冷锋利，南方沙漠的陨铁炽热沉重，而东部海域的陨铁则带有潮汐般的脉动。书中详细描述了锻造温度、淬火介质和打磨角度的秘密，并强调陨铁与普通金属不能混用，否则会产生不稳定的魔力反冲。最珍贵的附录是一份古代陨落点地图，但很多坐标已经被海水淹没或城市覆盖。陨铁工坊的学徒必须先用三年时间学会辨认普通铁矿石，才有资格触碰来自天外的材料。陨铁在锻造时会发出低频共鸣，长期接触可能损伤听力。最适合在实战后反复研读。

## 设计意图

为弓手提供反魔法与高阶材料专精方向，连接采集-制造-战斗循环。
