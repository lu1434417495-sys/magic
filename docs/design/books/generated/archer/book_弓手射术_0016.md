# 《制箭：羽尾平衡法》

## 基础信息

- **书籍 ID**：`book_弓手射术_0016`
- **关联技能**：`archer_fletching_tune`、`archer_arrow_craft`

## 书籍内容

《制箭：羽尾平衡法》是制箭三部曲的第一部，专门讲解箭尾羽毛的选择与粘贴。作者指出，箭羽不仅提供飞行稳定，还会直接影响箭的旋转方向和落点。书中比较了直羽、斜羽和螺旋羽的适用场景，并详细说明了羽毛长度与箭杆重量的配比关系。作者还提醒，粘贴羽片时必须保证三片羽毛的对称，否则箭在空中会摇摆。后半本提供了一套简易的旋转测试：把箭搭在指尖上旋转，观察是否能平稳自转。最末页是一张羽毛图谱，标注了常见鸟类的羽毛硬度和耐久。许多猎人说，读懂这本书后，箭矢的命中率提升了一半。一位老制箭师在空白处批注：羽尾是箭的翅膀，不是装饰，再好的箭头配上歪斜的羽尾，也只会变成一支昂贵的偏离箭。自制箭矢的乐趣在于，每一支不完美却亲手调试的箭，都会比买来的昂贵箭矢更听你的话。
