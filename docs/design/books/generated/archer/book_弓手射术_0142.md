# 《移动射击：跑弦》

- **书籍 ID**：`book_弓手射术_0142`

## 书籍内容

移动射击：跑弦挑战了"射箭必须静止"的传统观念。作者认为，在真正的战斗中，静止的弓手是死的弓手。前半本讲解如何在跑动中保持上半身稳定：核心收紧、肩膀放松、视线始终超前。中章介绍"三步一箭"节奏：第一步取箭，第二步搭弦，第三步在落地瞬间发射。后半本讨论不同地形下的跑射：平地、上坡、下坡、林间小径，每种都需要微调节奏。作者在后记中强调，跑弦射击的命中率永远低于静止射击，因此必须优先选择 torso 等大面积目标，而不是强行追求头部或咽喉。作者还提供了一套避免自伤的注意事项。最后一页写着："跑起来射箭，不是为了帅，是为了让敌人永远猜不到你的下一箭。"

跑弦射击对鞋子的要求很高，鞋底太硬会震伤脚踝，太软则无法稳定发力。作者在附录中列出了几种适合跑射的鞋款，从草原软靴到山地皮靴。

## 设计意图

为弓手提供高机动输出能力，支撑风筝与游击战术。
