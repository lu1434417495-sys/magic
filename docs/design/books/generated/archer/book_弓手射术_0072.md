# 《弱点预判手册》

## 基础信息

- **书籍 ID**：`book_弓手射术_0072`
- **关联技能**：`archer_critical_eye`、`archer_eagle_eye`
- **使用效果**：阅读后解锁 `archer_critical_eye`；若已学会，提升 `current_mastery +140`，并使对敌人弱点的首次暴击伤害 +12%。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；已学会 `archer_eagle_eye`；基础 `感知 ≥ 12`。
- **稀有度**：精良（Uncommon）
- **建议投放**：刺客公会交换品、怪物解剖师藏书、高阶游侠奖励。

## 书籍内容

《弱点预判手册》的内容来自一百多具尸体的解剖记录。作者是一位厌恶近身战斗的外科医生，她习惯在敌人死后用箭矢测试各种部位的伤害效率。书中按敌人类型分类，详细标注了关节缝隙、眼球、咽喉、心脏投影点以及魔法核心的常见位置。作者特别强调，弱点不是静止的：呼吸会让胸甲起伏，走路会让膝盖角度变化，施法会让核心短暂暴露。因此预判的关键是观察节奏，而非死记硬背位置。后半本讲解了如何在高速移动中计算提前量，以及如何利用敌人的攻击前摇作为射击窗口。书的封底贴着一张纸条：“请先确保它死了再解剖，我因此失去过三根手指。”作者晚年因过度研究人体结构而变得沉默寡言，她最后的学生说老师“看人的方式像在看靶子”。作者晚年因过度观察人体而厌恶社交，这在书末附录中有迹可循。

## 设计意图

强化弓手“暴击弱点”的核心输出循环，将感知转化为暴击收益。
