# 《狂风中定身法》

## 基础信息

- **书籍 ID**：`book_弓手射术_0083`
- **关联技能**：`archer_wind_stance`、`archer_stance_foundation`
- **使用效果**：阅读后解锁 `archer_wind_stance`；若已学会，提升 `current_mastery +130`，并使强风天气下远程命中率 +10%。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；已学会 `archer_stance_foundation`；基础 `力量 ≥ 10`，`感知 ≥ 10`。
- **稀有度**：精良（Uncommon）
- **建议投放**：风暴哨塔、风元素领地据点、高崖游侠训练场。

## 书籍内容

普通弓手害怕风，优秀的弓手学会与风谈判，而顶尖的弓手能在狂风中定身。《狂风中定身法》的作者长年驻扎在世界边缘的风暴哨塔，他发现强风不是随机乱吹，而是有层次和节奏。书中教导读者如何利用身体作为挡风板，将弓身贴近身体一侧以减少晃动，以及如何在阵风的间隙完成拉弦。作者还发明了一套“风锚”步法：双脚呈特定角度斜对风向，膝盖微屈，让风力从身体两侧滑过而不是正面冲击。最艰难的练习是在风口站立一整天，只做拉弦动作而不放箭，直到能在风最大的一刻保持准星稳定。作者幽默地写道：“风会吹走你的帽子，但不应该吹走你的准星。”风暴哨塔的驻守者自称“风的囚徒”，因为他们每年只有寥寥数日能离开高崖。风暴哨塔的弓手自称听得见风的颜色，外人只当他们疯了。

## 设计意图

将天气系统纳入弓手成长，为恶劣环境战斗提供专项训练。
