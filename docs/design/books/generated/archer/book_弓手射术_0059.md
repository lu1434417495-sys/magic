# 《绊索箭布置术》

## 基础信息

- **书籍 ID**：`book_弓手射术_0059`
- **关联技能**：`archer_pinning_shot`、`archer_feather_step`
- **使用效果**：阅读后解锁 `archer_pinning_shot`；若已学会，提升 `current_mastery +120`，并解锁绊索材料 `spider_silk_rope` 的制作配方。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；已学会 `archer_feather_step`；基础 `感知 ≥ 10`，`智力 ≥ 8`。
- **稀有度**：精良（Uncommon）
- **建议投放**：边境陷阱大师、游侠据点密室、蛛网洞穴宝箱。

## 书籍内容

《绊索箭布置术》是一本关于“让敌人不要靠近你”的技术手册。作者将绊索箭分为三大类：定身型、牵引型和反馈型。定身型将目标钉在地面，适合对付冲锋中的敌人；牵引型会把目标拽向预设的尖刺或陷阱；反馈型则在目标挣脱时造成二次伤害。书中用大量俯视图讲解布置角度，强调绊索必须与射手逃跑路线呈钝角，这样敌人被绊倒时会背对射手。作者还提醒，不要在自己的退路附近设置绊索，因为慌乱中自己中招的弓手比被敌人杀死的还多。最有趣的章节是“心理陷阱”：有时故意留一条看似安全的通道，比完全封锁更能控制敌人的移动。书末夹着一张手绘地图，标注了某座森林中十七处绊索位置，但地图本身没有比例尺。边境要塞的守卫们最忌惮这种箭，因为被绊倒的往往不是士兵，而是战马和攻城器械。

## 设计意图

扩展弓手的战场控制能力，将地形利用与技能熟练度结合起来。
