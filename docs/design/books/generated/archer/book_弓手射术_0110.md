# 《重弓破甲诀》

## 书籍内容

重弓破甲诀的封面嵌着一小块被箭穿透的板甲碎片。作者开篇警告："破甲不是用蛮力，是用对地方。"书中详解重弓的选材、上弦与保养，以及如何挑选适合破甲的箭镞。前半本讲力学：箭速、箭重、箭头形状与装甲角度的关系。中章分析七种常见护甲的薄弱点，从链甲环隙到板甲腋下，再到头盔面甲与胸甲的接缝。后半本记录了一场矮人与人类联军的守城战，射手们用重弓在两百步外洞穿了敌方重骑兵的胸甲。书中还对比了不同箭镞材质：陨铁硬而脆适合近距离，黑钢重而稳适合远距离。作者特别提醒，重弓射手必须保护好自己的肩袖，过度训练会造成不可逆的损伤。

那场守城战的胜利让重弓手地位大增，但也导致许多新手盲目追求重弓。作者在结尾警告：没有足够力量的人使用重弓，只会让自己的肩袖提前报废。

## 设计意图

赋予弓手对抗重甲单位的手段，让远程职业在战场上的目标选择更加丰富。
