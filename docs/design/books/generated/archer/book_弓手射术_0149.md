# 《箭羽调校指南》

## 书籍内容

箭羽调校指南教射手如何为自己的箭矢装配和调整羽毛。作者认为，箭羽是箭矢的舵，直接决定飞行稳定与旋转。前半本讲解羽毛选材：鹅羽、鹰羽、人工合成羽，各自的硬度、重量和耐用性。中章讲粘羽角度：直羽适合近距离直射，螺旋羽适合远距离稳定，偏移角度过大会造成箭速损失。后半本提供调校步骤：裁剪、打磨、涂胶、固定、风干，以及如何用简易工具测试配重。书中还讨论了箭羽数量与飞行稳定的关系：三支羽毛适合大多数场景，四支羽毛能让箭更快稳定，但会损失速度和距离。作者建议根据战场远近选择配置。作者还讨论了在野外缺乏工具时的应急处理方法。

羽毛数量选择页还讨论了不同箭种的需求：猎箭用三支羽保证速度，靶箭用四支羽保证稳定，战箭则根据战场环境在两者之间取舍。

## 设计意图
