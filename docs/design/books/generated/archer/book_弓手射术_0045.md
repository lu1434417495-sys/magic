# 《恐惧与弓弦》

## 基础信息

- **书籍 ID**：`book_弓手射术_0045`
- **关联技能**：`archer_fear_control`、`archer_breath_control`
- **使用效果**：阅读后解锁 `archer_fear_control`；若已学会，提升 `current_mastery +90`，并在生命值低于 30% 时降低瞄准抖动。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；基础 `意志 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：老兵心理治疗师、战场幸存者营地、意志训练教官。

## 书籍内容

《恐惧与弓弦》直面弓手在实战中最难克服的敌人：恐惧。作者指出，恐惧会让呼吸急促、手指僵硬、视野收窄，而这些都会直接毁掉一箭。书中不鼓励压抑恐惧，而是教人如何与恐惧共处：承认它、观察它、然后让它成为警觉的一部分。作者设计了一套呼吸与自我对话结合的练习，帮助射手在压力下恢复稳定。后半本收录了几位从战场创伤中恢复的弓手的故事。最末页有一句话：恐惧不会消失，但你可以学会在它旁边拉弓。意志训练教官会把这本书放在课程最后，因为只有技术成熟的人，才配谈论如何与恐惧同行，而不被它拖垮，也不被它支配。猎人常说，读懂它比射中十只鹿更有价值。读完之后，你会发现射术不只是拉弓放箭，而是一种与世界对话的方式。最终，恐惧不再是敌人，而成为你最忠实的提醒者。

## 设计意图

引入意志属性与心理状态对战斗的影响，为高压力情境提供反制手段。
