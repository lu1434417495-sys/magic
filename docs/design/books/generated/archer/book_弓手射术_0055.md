# 《鹰目凝视训练》

## 基础信息

- **书籍 ID**：`book_弓手射术_0055`
- **关联技能**：`archer_eagle_eye`、`archer_aimed_shot`
- **使用效果**：阅读后解锁 `archer_eagle_eye`；若已学会，提升 `current_mastery +100`，并延长下一次战斗中远程锁定距离 5%。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；基础 `感知 ≥ 10`。
- **稀有度**：普通（Common）
- **建议投放**：高山鹰眼据点、游侠侦察训练场、鹰眼导师委托。

## 书籍内容

《鹰目凝视训练》并非教人看得更远，而是教人“看得更久”。作者发现，大多数弓手在远距离瞄准时会因为眨眼或走神而丢失目标，因此书中大部分练习都与眼睛耐力有关。开篇的“烛火凝视”要求读者在昏暗房间中盯着一根蜡烛芯，直到能在不眨眼的情况下数满六十次心跳。进阶练习则是追踪飞行中的麻雀，不是用箭射它，而是只观察它翅膀扇动的节奏。作者还介绍了如何利用余光判断侧翼威胁，避免在专注瞄准时被偷袭。书末附有十几种地形下的视线干扰对照表：沙漠的热浪、雪原的反光、雨林的阴影都会让距离判断产生偏差。一位使用者在空白处写道：“鹰眼不是天赋，是熬夜练出来的。”完成全部训练的人会发现，自己不仅能看得更远，还能在人群中快速识别出潜在的威胁。该训练的副作用是夜间对微光异常敏感，白天需戴眼罩过渡。

## 设计意图

强化弓手“感知”属性的价值，将视觉耐力转化为战斗中的有效射程。
