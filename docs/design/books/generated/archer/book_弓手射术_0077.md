# 《精准距离换算》

## 基础信息

- **书籍 ID**：`book_弓手射术_0077`
- **关联技能**：`archer_range_estimation`、`archer_aimed_shot`
- **使用效果**：阅读后解锁 `archer_range_estimation`；若已学会，提升 `current_mastery +100`，并使远距离射击的伤害衰减降低 8%。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；基础 `感知 ≥ 10`，`智力 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：测量师公会、军团弓手学院、远行商人。

## 书籍内容

眼睛会骗人，但数学不会。《精准距离换算》是一本罕见的偏重计算的弓手教材，作者用大量几何图示讲解如何通过目标大小、视角高度和参照物来估算距离。书中介绍了“拇指测距法”“影子比例法”和“步幅换算法”三种实用技巧，并指出在不同地形中需要进行修正：上坡会让目标看起来比实际近，下坡则相反。作者还设计了一套记忆口诀，帮助射手在紧张战斗中快速调用常见距离对应的仰角。虽然部分老游侠嘲笑这本书过于死板，但作者用战例证明，受过距离训练的弓手在百步以上的命中率比依赖直觉的同行高出近一倍。批评者认为过度依赖换算会让弓手失去直觉，但作者反驳说直觉也会背叛你，而勾股定理不会。书中最后提醒，所有公式都抵不过一支箭的实际飞行经验。书中所记至今仍有参考价值。

## 设计意图

用生活/知识系统强化弓手的远程输出，将感知与智力结合为战斗收益。
