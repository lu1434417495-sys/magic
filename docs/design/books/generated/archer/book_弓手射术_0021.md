# 《夜间射击指南》

## 基础信息

- **书籍 ID**：`book_弓手射术_0021`
- **关联技能**：`archer_night_shot`、`archer_basic_aim`
- **使用效果**：阅读后解锁 `archer_night_shot`；若已学会，提升 `current_mastery +100`，并在夜间战斗中降低瞄准惩罚 15%。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；基础 `感知 ≥ 10`。
- **稀有度**：普通（Common）
- **建议投放**：夜巡队营地、月光哨塔藏书、夜间猎手委托奖励。

## 书籍内容

《夜间射击指南》的第一句话是：夜晚不是白天的反面，它是另一种光线。作者认为，夜间射击的关键不是看得更清楚，而是学会利用有限的光源。书中讲解了如何利用月光、火把和敌人营地的光亮来判断距离与轮廓，以及如何在黑暗中保持对弓的感知。作者还提醒，夜间射箭时容易高估距离，因为黑暗会让目标显得比实际更远。后半本收录了夜视训练的几种方法，包括注视暗处后闭眼恢复、利用余光捕捉移动物体等。最末页是一张月相图，每个相位旁都标注了推荐的射击距离。作者写道：在夜里，弓手靠的不是眼睛，是记忆。守夜人把它放在枕边，每次轮值前都会翻几页，因为他们知道黑暗中的第一箭往往决定了一切。守夜人不会抱怨黑暗，因为他们知道在这片黑暗中，最先发现火光的人往往就是最先放箭的人。
