# 《仰射与俯射笔记》

## 基础信息

- **书籍 ID**：`book_弓手射术_0011`
- **关联技能**：`archer_elevated_shot`、`archer_basic_aim`
- **使用效果**：阅读后解锁 `archer_elevated_shot`；若已学会，提升 `current_mastery +90`，并使高处射击时射程增加 5%。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；基础 `感知 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：高地哨塔、城墙射手教官、山地游侠营地。

## 书籍内容

《仰射与俯射笔记》专门研究非水平射击。作者指出，仰射时最容易犯的错误是把目标当成水平距离来计算，忽视了重力对上升阶段和下降阶段的不对称影响；俯射时则要避免因地势陡峭而产生的俯视错觉，即把远处目标看得比实际更近。书中提供了简易的角度换算口诀，帮助射手在心跳加速时快速估算提前量。后半本收录了高地守城战中的射击案例，分析了何时应该抛射压制、何时应该直射点名。最末一页画着一个站在塔顶的弓手，箭矢以高抛弧线落入敌群，旁边写着：角度是距离的一种变装。守城教官会把这本书发给每一个新上墙的年轻射手，因为居高临下并不意味着更容易命中。守城战中，居高临下的射手必须比地面射手更冷静，因为角度的优势会同时放大自信与失误。

## 设计意图

将地形高度差引入弓手射击考量，为守城、山地和塔楼战斗提供技能支持。
