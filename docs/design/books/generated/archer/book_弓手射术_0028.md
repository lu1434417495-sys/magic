# 《驱赶射击要诀》

## 基础信息

- **书籍 ID**：`book_弓手射术_0028`
- **关联技能**：`archer_scaring_shot`、`archer_cover_fire`
- **使用效果**：阅读后解锁 `archer_scaring_shot`；若已学会，提升 `current_mastery +90`，并使对野兽的下一次恐吓射击成功率 +15%。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；基础 `感知 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：牧民营地、猎人公会、野兽驱赶任务奖励。

## 书籍内容

《驱赶射击要诀》讲的是如何让箭不伤人却达到目的。作者认为，驱赶野兽或散兵时，准确射中脚前地面比射中身体更有效，因为前者制造恐惧而不引发死斗。书中详细讲解了如何用破空声、落点位置和连续射击来控制目标的移动方向。作者还提醒，驱赶射击必须留一条逃生路，否则被逼入绝境的野兽会反扑。后半本收录了不同动物对声音和落点的反应差异。最末页有一句话：最好的驱赶箭，是让目标以为自己差点死掉。牧民用这本书保护畜群，游侠用它引导兽群远离营地，而城市守卫则用它驱散闹事人群，因为它教会人们箭矢可以是一种语言，而不只是武器，一种能控制局面的无声语言。驱赶的艺术在于控制，而不是征服，这正是弓手与战士的区别。许多弓手在第一次独自出任务前，都会把这本书郑重地放进背包。

## 设计意图

提供非致命控制手段，让玩家在面对野兽或平民冲突时有更多选择。
