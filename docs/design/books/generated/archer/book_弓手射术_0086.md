# 《隐匿狙击位》

## 基础信息

- **书籍 ID**：`book_弓手射术_0086`
- **关联技能**：`archer_snipe`、`archer_eagle_eye`
- **使用效果**：阅读后解锁 `archer_snipe`；若已学会，提升 `current_mastery +150`，并使完全蓄力的狙击箭忽视目标 15% 护甲。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；已学会 `archer_eagle_eye` 和 `archer_critical_eye`；基础 `感知 ≥ 13`。
- **稀有度**：精良（Uncommon）
- **建议投放**：狙击训练场、边境瞭望塔、暗杀委托奖励。

## 书籍内容

狙击不是射得远，而是选一个好位置。《隐匿狙击位》的作者是一位退休的边境守卫，他用毕生经验总结如何选择、布置和放弃一个狙击点。书中强调，最好的狙击位通常不是最高处，而是能控制入口、有退路、并且有自然遮蔽的中高处。作者详细介绍了如何利用树叶、岩石阴影和建筑结构制造“视觉陷阱”，让敌人即使直视也难以发现射手。他还讲解如何计算日照角度，避免弓身反光暴露位置。最实用的章节是“撤离路线”：一个优秀的狙击手在开弓前就已经规划好三条撤退路径，并在心中演练过每一种失败情况。书的扉页上写着：“最好的狙击是没人知道你在哪里。”狙击手的训练第一课不是射击，而是学会在一个位置静止不动地等待三个昼夜。一个好的狙击位往往要提前数天布置，包括清理落叶和调整视线。

## 设计意图

为弓手提供超远程单体爆发技能，强调位置选择与战场意识。
