# 《站姿力学：开弓五柱》

## 书籍内容

站姿力学：开弓五柱把人体比喻成五根柱子：双脚、髋部、脊柱、肩膀、后手。作者认为，射箭的力量不是来自某一块肌肉，而是这五根柱子能否连成一条稳定的线。前半本详细讲解每一柱的位置与感觉，以及常见的歪斜模式。中章提供自检方法：如何在无弓状态下感受五柱对齐，如何在拉弓时逐节调整。后半本则是不同体型射手的站姿微调建议，从高个子到矮个子，从轻装到重甲。作者在后半本加入了对"疲劳歪斜"的讨论：当体力下降时，髋部会无意识地前倾，脊柱会弯曲。他建议在训练时让同伴从背后观察，及时纠正五柱对齐。最后一页只有一句话："五柱不倒，箭不虚发。"

五柱对齐练习后来被改编成一种养生体操，在非战斗人员中也颇受欢迎。但作者强调，养生版失去了拉弓时的张力，不能替代实战训练。

## 设计意图

为弓手提供稳定射击的底层姿态技能，支撑后续所有精准射击类能力。
