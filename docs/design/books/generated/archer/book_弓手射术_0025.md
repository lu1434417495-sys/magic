# 《马上射箭入门》

## 基础信息

- **书籍 ID**：`book_弓手射术_0025`
- **关联技能**：`archer_mount_shot`、`archer_mobile_shot`
- **使用效果**：阅读后解锁 `archer_mount_shot`；若已学会，提升 `current_mastery +110`，并在骑乘状态下首次射击稳定度 +15%。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；基础 `敏捷 ≥ 10`。
- **稀有度**：普通（Common）
- **建议投放**：骑兵训练营、草原游侠据点、马场弓术教官。

## 书籍内容

《马上射箭入门》是为骑兵弓手准备的基础教材。作者认为，马背射击的难点不在弓，而在节奏。书中讲解了如何配合马匹的步伐在特定时机放箭，如何在奔驰中保持稳定的上半身，以及如何在转向时调整瞄准。作者还提醒，骑射时不要追求拉满，快速连发往往比单发重箭更有效。后半本讨论了不同马匹性格对射手的影响，并建议新手先使用性情稳定的矮马练习。最末页有一幅骑射图，弓手在马背上半转身放箭，配文：马动时你静，马静时你动。草原游侠常说，真正的好骑射手不是射得准，而是摔不下来还能继续射，因为马背上的稳定远比靶场上的稳定更难掌握，也更有价值。骑射的魅力在于，你永远在和另一个生命共同完成一次射击。它不会替你射中目标，但会让你离那个目标更近一点，也更稳一点。

## 设计意图

引入骑乘战斗维度，为草原游侠或骑兵弓手 build 提供基础技能。
