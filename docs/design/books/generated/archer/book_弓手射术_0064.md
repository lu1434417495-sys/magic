# 《后跃反击箭》

## 基础信息

- **书籍 ID**：`book_弓手射术_0064`
- **关联技能**：`archer_backflip_shot`、`archer_feather_step`
- **使用效果**：阅读后解锁 `archer_backflip_shot`；若已学会，提升 `current_mastery +150`，并使后跃过程中射出的箭矢附带 1 秒眩晕效果。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；已学会 `archer_feather_step`；基础 `敏捷 ≥ 12`。
- **稀有度**：精良（Uncommon）
- **建议投放**：杂技弓手行会、竞技场奖励、游侠闪避大师。

## 书籍内容

这本书的读者必须首先克服恐惧，因为后跃反击箭要求射手在被敌人近身的瞬间向后翻腾，并在空中完成拉弦与放箭。作者是一位曾在马戏团表演的游侠，他将动作拆解为“蹬地、转体、张弓、落点”四步，强调翻腾的旋转轴必须垂直，否则箭矢会大幅偏离。书中用夸张的线条画展示如何在半空中利用身体旋转带动弓弦拉开，以及落地时如何通过屈膝卸力。作者承认这一招在正面战场上华而不实，但在狭窄地形或一对一时极为致命，因为敌人往往会在你后跃时露出下巴和咽喉。最末页有一张褪色的演出海报，画中作者正在三只狮子扑来的瞬间后跃射箭，标题写着：“死亡马戏团：最后一季。”马戏团出身的作者后来在一次表演中失踪，有人说是被仇家追杀，也有人说他终于飞向了真正的天空。

## 设计意图

为弓手提供近身应急手段，强化“保持距离”的核心战斗循环。
