# 《腰射近身诀》

## 基础信息

- **书籍 ID**：`book_弓手射术_0144`
- **关联技能**：`archer_hip_shot`（待新增）
- **使用效果**：阅读后解锁 `archer_hip_shot`；若已学会，提升该技能 `current_mastery +90`，并提升极近距离射击的反应速度。
- **阅读要求**：职业标签含 `archer` 或 `ranger`；基础 `敏捷 ≥ 12`。
- **稀有度**：普通（Common）
- **建议投放**：城市守卫训练、地下竞技场、游侠应急课程。

## 书籍内容

腰射近身诀教弓手在来不及举弓时如何反击。作者指出，当敌人已经冲到眼前，完整的瞄准流程就是死刑宣告。腰射依靠身体记忆和近距离的容错率。前半本讲解腰射的基本姿势：弓身横于腰间、箭尾贴近脸颊、用身体转向瞄准。中章讨论不同距离下的腰射策略：五步内射躯干，三步内射面部，贴身时用箭杆推开敌人。后半本则是大量近身格斗配合技巧：如何用弓身格挡、如何在腰射后立刻后跳拉开距离。作者在最后提醒，腰射的有效距离不超过三步，超过这个距离就应该尝试完整的举弓瞄准。最后一页警告："腰射是救命用的，不是用来炫耀的。"

腰射虽然能救命，但作者严厉警告不要把它当作常规手段。真正的高手会在敌人进入三步之前就用完整的瞄准流程解决问题，而不是依赖腰射。

## 设计意图

为弓手提供最后的近身应急手段，完善其远近结合的战斗闭环。
