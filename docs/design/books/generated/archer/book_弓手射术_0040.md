# 《眩晕箭：钝头技法》

## 基础信息

- **书籍 ID**：`book_弓手射术_0040`
- **关联技能**：`archer_blunt_arrow`、`archer_arrow_craft`
- **使用效果**：阅读后解锁 `archer_blunt_arrow`；若已学会，提升 `current_mastery +90`，并解锁钝头箭配方 `blunt_arrow`。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；基础 `智力 ≥ 7`。
- **稀有度**：普通（Common）
- **建议投放**：城市守卫营、非致命武器教官、治安任务奖励。

## 书籍内容

《眩晕箭：钝头技法》是为需要活捉目标或避免杀生的射手准备的。作者讲解了钝头箭的设计原理：通过扩大撞击面积和增加头部重量，将动能传递到目标头部或关节，造成眩晕而非贯穿伤。书中详细介绍了不同钝头形状的效果：圆头适合击倒、平头适合破盾、凸头适合击晕。作者还提醒，钝头箭的射程较短，需要射手更靠近目标。后半本讨论了钝头箭在法律与道德层面的争议。最末页有一句话：不是每一支箭都需要夺走生命，有些箭只是让目标暂时安静。城市守卫用它来制止骚乱，猎户用它活捉珍稀野兽，游侠则用它避免不必要的杀戮，因为真正的射手懂得选择，而不是被弓弦上的杀意牵着走。选择让目标活下来，有时比选择让它死去需要更大的勇气。训练场上的教官们，总是把这本书放在最显眼的位置提醒每一个新人。
