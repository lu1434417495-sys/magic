# 《弓道终极：箭即心》

## 基础信息

- **书籍 ID**：`book_弓手射术_0100`
- **关联技能**：`archer_heart_arrow`、`archer_mind_eye`、`archer_spirit_bow`
- **使用效果**：阅读后解锁 `archer_heart_arrow`；若已学会，提升 `current_mastery +300`，并使“心箭”同时享受当前最高熟练度技能的加成效果。
- **阅读要求**：角色职业标签含 `archer`；已学会 `archer_mind_eye` 或 `archer_spirit_bow`；基础 `感知 ≥ 16`，`意志 ≥ 16`，`敏捷 ≥ 14`。
- **稀有度**：传说（Legendary）
- **建议投放**：弓道圣地最终试炼、传奇弓手传承、世界守护者的馈赠。

## 书籍内容

《弓道终极：箭即心》是所有弓手典籍中最薄也最重的一本。它没有讲任何具体技巧，因为到达这一境界的人不再需要技巧。作者只留下三段话：第一段说，弓是你意志的延伸，箭是你决心的形状；第二段说，当你不再区分自己与目标时，箭自然会到达；第三段说，每一支射出的箭都带着一部分你的心，因此要谨慎选择目标。据说真正读懂这本书的人会进入一种“无我”状态，在此状态下，无论多远的距离、多强的风、多厚的甲，都无法阻止一箭命中。书的封面上没有任何装饰，只有一个拉满弓的剪影，剪影的弓弦与心跳的波纹完全重合。读过此书的人都说，合上书后很长一段时间，耳边仍能听到一声若有若无的弦音。传说读完此书的人放箭时，箭矢会发出与心跳同频的轻鸣。读完此书，射术会有质的飞跃。

## 设计意图

作为弓手系传说级终极功法，将射术、冥想与意志融为一体，为走到成长终点的弓手提供“心箭合一”的巅峰体验与持续追求目标。
