# 《短弓速射七式》

## 基础信息

- **书籍 ID**：`book_弓手射术_0053`
- **关联技能**：`archer_rapid_fire`、`archer_stance_foundation`
- **使用效果**：阅读后解锁 `archer_rapid_fire`；若已学会，提升 `current_mastery +120`，并使下一次战斗中前三次速射各减少 1 点体力消耗。
- **阅读要求**：角色职业标签含 `archer`；已学会 `archer_stance_foundation`；基础 `敏捷 ≥ 10`。
- **稀有度**：精良（Uncommon）
- **建议投放**：边境斥候营地、短弓教官私藏、快速射击试炼奖励。

## 书籍内容

《短弓速射七式》的每一式都用一种动物命名：蜂刺、燕返、雨落、连珠、回风、骤电、残影。作者是一位曾在边境服役二十年的斥候，他强调速射的秘诀不在手指快，而在“预拉”——在上一支箭离弦之前，下一支箭已经搭在弦上。书中用大量图示展示如何在腰间箭囊中快速取箭而不被箭羽划伤，以及如何在移动中保持上半身稳定。第七式“残影”最为艰深，要求射手在两次射击之间不重新瞄准，而是依靠肌肉记忆完成连续命中。作者坦承自己只练成六式，第七式来自他的阵亡同袍，后者曾在被兽群包围时以一息七箭争取了撤退时间。书脊内侧有一行小字：“速射不是炫耀，是活下去的算术。”军方斥候部队至今仍用此书训练新兵，但完整掌握七式的士兵百中无一。完整版据说还有第八式，但作者战死后已无人能复原。

## 设计意图

为弓手提供中高频率输出选项，与慢速精准射击形成玩法对比。
