# 《断弦急救术》

## 基础信息

- **书籍 ID**：`book_弓手射术_0029`
- **关联技能**：`archer_string_repair`、`archer_bow_maintenance`
- **使用效果**：阅读后解锁 `archer_string_repair`；若已学会，提升 `current_mastery +80`，并使战斗中更换弓弦的时间缩短 30%。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；基础 `智力 ≥ 7`。
- **稀有度**：普通（Common）
- **建议投放**：游侠补给商人、野外生存教官、工匠行会基础书架。

## 书籍内容

《断弦急救术》是每位外出弓手都会随身携带的小册子。作者用亲身经历讲述了断弦后的绝望，以及如何通过预先准备的备用弦和快速上弦法恢复战斗力。书中讲解了临时弦的制作方法：用坚韧的植物纤维或兽筋缠绕，并在两端打结固定。作者还提醒，更换弦线后必须重新校准瞄准点，因为临时弦的弹性与原弦不同。后半本提供了几种常见断弦原因的预防措施，包括避免过度拉满、定期检查弦线老化等。最末页有一句话：弓弦会断，但战斗不会等你。许多弓手会在箭囊里备上两段不同长度的备用弦，就是这本书教的，因为他们知道战场不会给任何人重新准备的机会，哪怕只是一根弦。备用弦不是多余的负担，而是弓手对未知战场最起码的尊重。读完它，你会明白为什么老射手总是说：基础不牢，箭矢如山倒。

## 设计意图

为弓手提供装备故障应对能力，增强野外生存的紧张感与准备感。
