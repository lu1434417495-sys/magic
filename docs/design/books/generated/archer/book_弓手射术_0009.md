# 《逆风补偿射法》

## 基础信息

- **书籍 ID**：`book_弓手射术_0009`
- **关联技能**：`archer_wind_compensate`、`archer_pinning_shot`
- **使用效果**：阅读后解锁 `archer_wind_compensate`；若已学会，提升 `current_mastery +90`，并在逆风射击时降低下一次体力消耗 1 点。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；已学会 `archer_wind_reading`；基础 `感知 ≥ 9`。

- **建议投放**：风息哨塔高阶书架、边境游侠教官、逆风峡谷据点。

## 书籍内容

《逆风补偿射法》是《顺风箭要诀》的姊妹篇，但读起来要沉重得多。作者开宗明义：逆风射箭，首先拼的是体力。书中详细讲解如何在拉满弓时对抗风的推力，包括增加拉距、选择更重的箭头、降低射击频率等策略。作者特别强调，逆风时不要勉强追求远距离，能用三分力的近距离精准射击往往更有效。后半本有一章名为风的欺骗，列举了山谷、城墙和树林如何让风向发生突变。最末页只有一句话：逆风时，先活下来，再谈命中。这句话被无数弓手写在护臂内侧，作为提醒自己不要逞强的座右铭。边境游侠常说，读懂这本书的人，才配在风口站岗，因为大自然从不会因为你的骄傲而放慢脚步，它只会用刺骨的寒风教训每一个轻视它的人。真正懂得逆风的人，反而会在别人停手时找到属于自己的射击窗口。

## 设计意图

补全风向系统的另一侧，强调资源管理与环境适应，避免玩家在所有天气下使用同一套打法。
