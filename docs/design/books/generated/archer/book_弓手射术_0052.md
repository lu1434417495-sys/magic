# 《羽箭配重笔记》

## 基础信息

- **书籍 ID**：`book_弓手射术_0052`
- **关联技能**：`archer_arrow_balance`、`archer_aimed_shot`
- **使用效果**：阅读后解锁 `archer_arrow_balance`；若已学会，提升 `current_mastery +90`，并永久增加背包中普通羽箭的飞行稳定性。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；基础 `感知 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：猎人营地工坊、游侠杂货商、制箭师委托奖励。

## 书籍内容

这是一本由某位匿名制箭师在三十年间断断续续写成的笔记，纸页间夹着风干的羽毛和炭笔草图。作者认为，一支箭的杀伤力并非取决于箭头大小，而是重心是否落在箭杆前三分之一处。书中详细记录了七种常见木材的密度、不同禽羽的恢复速度，以及如何在缺乏工具时用手指关节粗略丈量重心。最有趣的章节是“补救歪斜”：当箭尾过重时，可以在箭头内侧嵌一小块铅；当箭头过重时，则要在尾羽根部缠细铜丝。作者还警告说，不要迷信“重箭穿透力强”，过重的箭会在远距离下坠过快，反而失去精确打击的意义。笔记最后夹着一张购物清单，上面写着“鹰羽十二片、桦木杆三十支、蜂蜡一罐”，仿佛作者随时会回来继续下一页。这本笔记的某些页边还留有作者用炭笔画的测试靶纸，上面密密麻麻记录着不同配比的下坠数据。

## 设计意图

把“配箭”包装成可成长的弓手副技能，强化装备与技能联动的养成深度。
