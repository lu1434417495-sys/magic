# 《双矢齐发》

- **关联技能**：`archer_twin_arrow`（待新增）

- **阅读要求**：职业标签含 `archer` 或 `ranger`；基础 `敏捷 ≥ 12` 且 `感知 ≥ 10`。

## 书籍内容

《双矢齐发》讲授同时搭两支箭并分射两个相邻目标的技艺。作者坦言此法难度极高，初学者往往两箭皆失，因此需要长期的指力与分神训练。前半本练习指法：用食指与中指各控一弦，靠位时保持两箭平行。中章讲述目标选择原则，两个目标距离不可超过三步，否则分散力道。后半本引入"主眼副眼"概念，要求射手用主眼瞄准主要目标，余光锁定次要目标。书中还提供了分弦撒放的诀窍，必须同时松手，稍有先后便会互相干扰。作者警告，双矢齐发适合乱战收割，不应在需要精确狙杀时使用。末尾附有每日指力训练的清单。

书中夹有一幅草图，展示了一位精灵游侠如何在跳跃中完成双矢齐发的姿态。那位游侠的双箭分别命中了两名敌军的眉心与咽喉，被视为此技的巅峰示范。双矢齐发需要极强的手指独立性。
