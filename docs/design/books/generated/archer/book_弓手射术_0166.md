# 《弓斗术入门》

## 基础信息

- **书籍 ID**：`book_弓手射术_0166`
- **关联技能**：`archer_bow_combat`（待新增）
- **使用效果**：阅读后解锁 `archer_bow_combat`；若已学会，提升该技能 `current_mastery +90`，并使弓身近战攻击伤害提升 `15%`。
- **阅读要求**：职业标签含 `archer` 或 `ranger`；基础 `力量 ≥ 11` 且 `敏捷 ≥ 10`。
- **稀有度**：普通（Common）
- **建议投放**：游侠训练场、佣兵营地、近身格斗馆。

## 书籍内容

《弓斗术入门》讲授弓手在近身被围时如何用弓身作战。作者指出，长弓不只是射击工具，其坚硬弓臂与紧绷弦线亦可成为武器。前半本介绍握弓姿势：一手握把，一手拉弦，利用弓弦绞锁敌人兵器。中章讲解基本招式：弓臂砸击、弦线割喉、弓把顶心，每一式都强调借力而非蛮力。后半本讨论何时应从射击转入近身，通常在敌人突破五步距离或箭囊已空时最为适宜。书中还提到保养问题，近战会损伤弓臂，战后必须仔细检查。作者提醒，弓斗术是最后手段，优秀弓手应尽量避免陷入近战。末尾附有简单的体能训练计划。

书页间夹着一张破损的弓弦，旁边写着：这把弦救过我的命，也替我挡过一剑。作者建议每名弓手都随身携带备用弦，因为你永远不知道何时需要贴身一战。

## 设计意图

为弓手提供近战应急手段，降低被贴脸时的无力感，鼓励力量型弓手Build。
