# 《林地隐蔽手册》

## 基础信息

- **书籍 ID**：`book_弓手射术_0020`
- **关联技能**：`archer_forest_stealth`、`archer_forest_lore`
- **使用效果**：阅读后解锁 `archer_forest_stealth`；若已学会，提升 `current_mastery +90`，并使森林地形首次射击前隐身时间延长 1 秒。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；基础 `敏捷 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：森林游侠营地、精灵遗迹书架、林地据点潜行教官。

## 书籍内容

《林地隐蔽手册》的作者据说能在落叶林中站立一整天而不被猎物发现。书中不讲魔法隐身，只讲如何利用光线、阴影和植被层次。作者提醒读者，移动时要避免触碰会发出声音的枝条，静止时要让自己成为树干轮廓的一部分。书中还讲解了不同季节树叶密度对隐蔽的影响，以及如何选择下风向避免气味暴露。后半本提供了一套三点固定练习：每次移动只动身体的一个部分，保持另外两个部分与周围环境融为一体。最末页有一句话：森林不会隐藏你，它只会奖励那些懂得模仿它的人。许多精灵游侠认为，这本书比任何潜行法术都更接近自然的本质，因为它教会你的不是欺骗眼睛，而是成为森林的一部分。森林里的猎物不会因为你的潜行技能而变慢，它只会因为你的动作不再像入侵者而放松警惕。

## 设计意图

为弓手提供地形相关的隐匿能力，强化游侠在森林场景中的主场优势。
