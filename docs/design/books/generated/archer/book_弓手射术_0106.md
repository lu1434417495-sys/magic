# 《移动靶预判要略》

## 基础信息

- **书籍 ID**：`book_弓手射术_0106`
- **关联技能**：`archer_leading_shot`（待新增）
- **使用效果**：阅读后解锁 `archer_leading_shot`；若已学会，提升该技能 `current_mastery +120`，并提高对移动目标的伤害加成。
- **阅读要求**：职业标签含 `archer` 或 `ranger`；基础 `敏捷 ≥ 11`。

- **建议投放**：猎人行会、荒野追踪任务、移动靶训练场。

## 书籍内容

预判要略的作者是一位退役竞技场猎手。他指出，射移动靶最大的错误是"追箭"——眼睛跟着目标跑，箭永远慢一拍。正确做法是预测目标在箭飞行时间后的位置，然后把视线固定在预测点上，等待目标自己撞上来。前半本用几何图示讲解角度、速度、距离三者的关系。中章分门别类：直线奔跑者、折返突进者、不规则闪躲者、骑乘目标，每一种都有不同的瞄准习惯。书中另有一章专门讨论"预测失败"时的补救：当目标突然变向，射手应立刻放弃原瞄准点，改射其前进方向上的狭窄通道。后半本则是大量实战手记，最著名的一段记录了他如何用一箭命中正在跳跃的霜狼咽喉。最后一页写着："不要追鸟，要追鸟将到之处；不要追人，要追人心慌时踏出的那一步。"

预测失败补救章节后面还有一页被撕掉的痕迹，旁注说"更高级的技巧不在本书范围内"。这引发了后人无数猜测，也催生了许多关于"追影箭"的传说。

## 设计意图

让弓手获得对机动目标的主动打击能力，弥补静态瞄准在实战中的局限。
