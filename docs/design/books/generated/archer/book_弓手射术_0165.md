# 《凝神一击》

## 书籍内容

《凝神一击》教授弓手在瞬息万变的战场上凝聚心神、射出决定性一箭的方法。作者认为，弓弦拉开后最危险的敌人不是对手，而是自己纷乱的念头。前半本提供止念口诀，要求射手在瞄准时只关注目标胸口的一点，屏蔽周遭喊杀。中章讲解如何利用一回合的蓄神状态，让下一箭获得更高的暴击伤害。后半本讨论失败后的快速恢复，避免因一箭失误而影响整场战斗。书中还提到，凝神并非僵硬不动，而是在动态中保持内心静止。作者建议每日冥想一刻钟，训练将注意力收束成一线。读完此书的射手往往能在最关键的时刻稳住手指。

作者在扉页写道：箭未离弦时，胜负已在心中分出。他认为，凝神一击的本质不是技术，而是将全部的意志压缩成一个不可动摇的念头。

## 设计意图

为高感知弓手提供爆发窗口，通过蓄神机制奖励耐心与专注，形成高风险高回报打法。
