# 《跪姿射击基础》

## 基础信息

- **书籍 ID**：`book_弓手射术_0010`
- **关联技能**：`archer_kneeling_shot`、`archer_stance_foundation`
- **使用效果**：阅读后解锁 `archer_kneeling_shot`；若已学会，提升 `current_mastery +80`，并在跪姿时小幅提升暴击率。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；基础 `敏捷 ≥ 7`。
- **稀有度**：普通（Common）
- **建议投放**：游侠训练场、伏击战术教官、低矮掩体据点。

## 书籍内容

《跪姿射击基础》告诉读者，跪姿不是为了好看，而是为了在低掩体后保持稳定。作者把跪姿分为单膝跪与双膝跪两种，前者便于快速起身，后者适合长时间瞄准。书中讲解了膝盖与脚趾的角度关系，提醒读者不要直接跪在硬石上，否则疼痛会传递到上半身影响瞄准。作者还设计了从跪姿到站姿的转换练习，要求射手在两秒内完成起身并射出第一箭。后半本讨论了草丛、矮墙和岩石作为掩体时的跪姿调整。最末页是一张姿势图，弓手单膝跪地，弓臂斜出掩体，配文：低一点，你活下来的机会就多一点。许多老兵会告诉你，跪姿是他们学会的第一种不会挨打的姿势，也是他们第一次意识到射术与生存之间关系的那一刻。很多年轻射手不喜欢跪姿，直到他们第一次躲在矮墙后看着敌人的箭从头顶飞过，才明白低姿态的价值。

## 设计意图

引入掩体与姿态系统，为弓手提供战场生存能力的基础操作选项。
