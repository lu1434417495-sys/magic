# 《追猎者步法》

## 基础信息

- **书籍 ID**：`book_弓手射术_0073`
- **关联技能**：`archer_hunting_step`、`archer_feather_step`
- **使用效果**：阅读后解锁 `archer_hunting_step`；若已学会，提升 `current_mastery +120`，并在追踪血迹时移动速度 +10%。
- **阅读要求**：角色职业标签含 `ranger`；已学会 `archer_feather_step`；基础 `敏捷 ≥ 10`，`感知 ≥ 9`。

- **建议投放**：荒野猎人营地、追踪大师委托、兽皮商人奖励。

## 书籍内容

追猎者知道，真正的狩猎在放箭之前就已经开始了。《追猎者步法》教授如何在各种地形中追踪受伤的猎物而不被察觉。作者将追踪分为“看、闻、听”三个阶段：看是指血迹的颜色和形状判断受伤时间，闻是指辨别恐惧和腐烂的气味，听是指判断猎物喘息的节奏。书中还记录了不同地面上的脚印差异：湿润泥土会夸大足迹，干燥岩石几乎不留痕迹，雪地则会暴露每一步的深度变化。作者提醒，追猎时最危险的不是猎物，而是自己的急躁；快速逼近会让受伤的野兽拼死反击。最实用的章节是“预判休息点”：大多数受伤动物会沿着水源或熟悉的路径移动，并在感到安全时停下舔舐伤口。最优秀的追猎者能通过一个脚印判断猎物的情绪：惊慌、疲惫或只是在散步。优秀追猎者能通过粪便判断猎物是否受伤以及伤口位置。

## 设计意图

为游侠提供探索与追踪能力，将战斗外技能与战斗收益衔接。
