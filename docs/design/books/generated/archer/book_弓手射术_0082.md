# 《影子射手心得》

## 基础信息

- **书籍 ID**：`book_弓手射术_0082`
- **关联技能**：`archer_shadow_shot`、`archer_feather_step`
- **使用效果**：阅读后解锁 `archer_shadow_shot`；若已学会，提升 `current_mastery +180`，并使从隐匿状态射出的第一箭暴击率 +15%。
- **阅读要求**：角色职业标签含 `ranger` 或 `rogue`；已学会 `archer_feather_step`；基础 `敏捷 ≥ 13`，`感知 ≥ 11`。
- **稀有度**：稀有（Rare）
- **建议投放**：影行者行会、黑暗游侠藏身处、刺客公会高阶奖励。

## 书籍内容

影子射手不是刺客，他们只是在敌人意识到危险之前完成射击。《影子射手心得》由一位不愿透露姓名的游侠写成，他强调隐匿射击的关键不是藏得多深，而是如何在射出第一箭后迅速再次消失。书中介绍了“阴影分割法”：将身体分为几个部分，每次只移动其中一个部分，让观察者的大脑无法拼凑出完整人形。作者还讲解了如何利用敌人自己的光源制造盲区，例如火把会让持火者夜盲，同时在他身后投下更深的影子。最危险的章节讨论“心理隐匿”：即使你的身体暴露了一半，只要对方的注意力被其他事物吸引，他仍会视而不见。书的封面有一个被划掉的徽记，似乎是某个已覆灭组织的标记。影行者行会从不公开承认拥有此书，但每个高级成员的书架上都能找到它。影子射手从不使用反光盔甲，因为那会让他们的隐匿毁于一旦。
