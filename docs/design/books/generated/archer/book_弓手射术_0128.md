# 《异界气息凝箭法》

## 基础信息

- **书籍 ID**：`book_弓手射术_0128`
- **关联技能**：`archer_ether_arrow`（待新增）
- **使用效果**：阅读后解锁 `archer_ether_arrow`；若已学会，提升该技能 `current_mastery +160`，并提升异界能量箭对实体敌人的穿透。
- **阅读要求**：职业标签含 `archer` 或 `mage`；基础 `智力 ≥ 13` 且 `感知 ≥ 11`。

## 书籍内容

异界气息凝箭法是一本用未知材料装订的书，书页在灯光下会微微发光。作者研究如何将灰烬交界的游离能量凝聚成箭矢。前半本讲原理：异界能量无法被普通弓弦承载，必须使用特殊材料制作箭杆，并在拉弓时用意念引导能量流动。中章详细描述凝箭过程：感知周围的能量密度、用呼吸牵引、在放弦瞬间让能量稳定释放。后半本则是一本实验日志，记录了成功与失败的案例，包括能量反噬造成的灼伤。作者在最后警告，凝箭失败时能量会从箭尾倒灌，轻者灼伤手掌，重者炸碎弓身。他要求读者先用十分之一的力量感应异界能量，绝不可急于求成。

实验日志的最后一页只有一句话："它看我的那一刻，我就知道这次凝聚太多了。"之后的内容全部空白，作者的下落无人知晓。作者在后记中强调，这些技巧需要反复练习才能内化为本能，急于求成只会事倍功半。

## 设计意图

为弓手提供高阶异界能量射击，连接灰烬交界与远程职业的顶端内容。
