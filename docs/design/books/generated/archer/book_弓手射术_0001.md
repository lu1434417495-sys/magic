# 《木弓养护与弦线调校》

## 基础信息

- **书籍 ID**：`book_弓手射术_0001`
- **关联技能**：`archer_bow_maintenance`、`archer_string_tune`
- **使用效果**：阅读后解锁 `archer_bow_maintenance`；若已学会，提升该技能 `current_mastery +60`，并永久降低木弓类武器耐久消耗 5%。
- **阅读要求**：无职业限制；基础 `敏捷 ≥ 6`。
- **稀有度**：普通（Common）
- **建议投放**：新手村杂货商、猎人小屋书架、初级弓术训练场。

## 书籍内容

《木弓养护与弦线调校》是大多数弓手接触的第一本教材。作者用粗粝的笔触告诉读者：一把好弓不是买来的，是养出来的。书中先讲木材的呼吸，提醒读者不可将弓长期放在干燥或潮湿的环境中，否则弓臂会开裂或失去弹性。接着是弦线的选择与上弦手法，从麻弦、筋弦到合成弦，各有优劣。作者特别强调上弦时必须对称，否则左右弓臂受力不均，久而久之会导致射偏。后半本收录了常见故障排查：弦结松脱、箭台磨损、握把打滑。最末一页画着一把被拆解成七部分的木弓，每部分旁都标注了养护周期。许多老猎人把它放在工具箱最上层，每次出猎前翻一翻。作者还在附录里列出了一份月度检查清单，建议弓手在每次跋涉后都花时间擦拭弓身、检查弦线张力，因为这些细节决定了关键一箭会不会偏离目标。

## 设计意图

作为弓手系最底层的装备认知书，将武器养护与长期成长绑定，让玩家从第一次摸弓就建立维护意识。
