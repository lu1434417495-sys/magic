# 《掩护射击讲义》

## 基础信息

- **书籍 ID**：`book_弓手射术_0024`
- **关联技能**：`archer_cover_fire`、`archer_mobile_shot`
- **使用效果**：阅读后解锁 `archer_cover_fire`；若已学会，提升 `current_mastery +100`，并使掩护射击时队友受到的远程伤害降低 10%。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；基础 `敏捷 ≥ 9`。
- **稀有度**：普通（Common）
- **建议投放**：边境哨塔战术室、游侠队长奖励、护送任务报酬。

## 书籍内容

《掩护射击讲义》强调弓手在团队中的支援角色。作者指出，掩护射击不是为了杀伤，而是为了压制：让敌人不敢抬头、不敢追击、不敢随意移动。书中讲解了如何分配射击区域，如何用连续不断的箭矢形成火力线，以及何时应该节省箭矢保留体力。作者还提醒，掩护射击时必须清楚队友的位置，避免误伤。后半本收录了几个经典战例，分析掩护射击成功与失败的原因。最末页有一句话：你的箭不一定要命中，但一定要让敌人知道你还在。许多前排战士会给学会这本书的弓手递上一杯酒，因为他们知道有人掩护意味着什么，也知道在撤退时那几支落在脚前的箭能救下多少条并肩作战的性命。懂得掩护的弓手，往往也是队伍中最受欢迎的同伴之一。真正读懂它的人，往往会在某个深夜突然意识到：射术其实是修心的开始。

## 设计意图

强化弓手的团队协作定位，让远程职业在保护队友方面有明确价值。
