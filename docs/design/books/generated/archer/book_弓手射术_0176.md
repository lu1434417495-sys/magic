# 《极速上弦》

## 基础信息

- **书籍 ID**：`book_弓手射术_0176`
- **关联技能**：`archer_speed_reload`（待新增）
- **使用效果**：阅读后解锁 `archer_speed_reload`；若已学会，提升该技能 `current_mastery +80`，并使上弦动作消耗的 AP 减少 `1` 点。
- **阅读要求**：职业标签含 `archer` 或 `ranger`；基础 `敏捷 ≥ 12`。
- **稀有度**：普通（Common）
- **建议投放**：游侠训练场、军械库、快速射击训练营。

## 书籍内容

《极速上弦》专攻缩短搭箭拉弦的时间，让弓手在同等时间内射出更多箭矢。作者从握箭手法开始，比较了两指夹箭、三指握箭与掌心托箭的优劣。中章讲解箭囊位置对取箭速度的影响，建议将最常用的箭放在最容易抽到的位置。后半本提供一套上弦训练：空手模拟搭箭一百次，再持弓实射，逐步形成肌肉记忆。书中还讨论了不同弓型对上弦速度的影响，短弓最快，长弓最慢，复合弓居中。作者提醒，追求极速不应牺牲安全，空放和滑弦是常见事故。末尾附有一分钟速射挑战记录表，供练习者追踪进步。熟练者可在数息之间完成三次完整射击。

一位速射冠军在空白处写道：快不是目的，快是为了让敌人没有反应时间。他在一场比赛中曾在一分钟内射出四十七支箭，全部命中移动靶，至今无人能破。
