# 《幻影足迹：时间残像》

## 基础信息

- **书籍 ID**：`book_探索_0036`
- **关联技能**：`exploration_temporal_tracks`（待新增，标签 `exploration`）
- **使用效果**：阅读后解锁探索技能 `exploration_temporal_tracks`；若已学会，提升 `current_mastery +90`，可看见数小时前经过该区域的人物或怪物残像，用于解谜。
- **阅读要求**：无职业限制；基础 `感知 ≥ 13`。
- **稀有度**：史诗（Epic）
- **建议投放**：时间裂隙、预言之眼、隐藏时间神殿。

## 书籍内容

这本书的纸张半透明，仿佛隔着一层薄雾。作者提出，在某些魔力浓郁或时间紊乱的区域，过去发生的事件会以残像形式短暂重现。书中教导读者如何调整自己的感知频率，看到数小时甚至数天前留下的幻影足迹。中段详细讲解了残像的解读方法，包括判断事件发生时间、参与者的情绪状态与关键物品的位置。后半部分涉及战斗与解谜应用，比如通过残像找到隐藏开关或追踪敌人的真实去向。书末的批注写道："看见过去不是为了改变它，而是为了不在同一个地方跌倒两次。"

作者在最后写道，时间残像最残酷之处在于，你能看见过去，却永远无法提醒过去的人，这种无力感是每一位时间观测者必须学会承担的重量；他建议不要试图与残像互动，因为那样只会让自己的时间线也变得混乱。

## 设计意图

作为史诗级解谜与追踪技能，引入时间叙事维度，服务于隐藏任务、密室解谜与剧情回溯玩法。
