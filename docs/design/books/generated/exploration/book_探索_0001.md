# 《野外求生手册：第一章》

## 基础信息

- **书籍 ID**：`book_探索_0001`
- **关联技能**：`exploration_wilderness_survival_basic`（待新增，标签 `exploration`）
- **使用效果**：阅读后解锁探索技能 `exploration_wilderness_survival_basic`；若已学会，提升 `current_mastery +40`，并在野外地图缓慢恢复移动耐力。
- **阅读要求**：无职业限制；基础 `感知 ≥ 6`。
- **稀有度**：普通（Common）
- **建议投放**：新手村训练师、野外商人、初级探险任务奖励。

## 书籍内容

这本手册的封皮被虫蛀出几个小孔，扉页写着"活下来，才有资格谈方向"。书中没有华丽辞藻，只有一条条用血改过的经验：如何在雨后识别可食用的菌伞，如何用树皮和藤蔓制作简易止血带，以及为什么永远不要在低洼处扎营。作者强调，野外探索最大的敌人不是野兽，而是自满。每一章结尾都附有一张空白页，标题是"我犯过的错"，显然希望读者继续补充。后半部分讲解了利用太阳、苔藓和蚁穴判断方向的土法，并警告这些方法在灰烬交界会全部失灵。最后几页已被撕去，只剩一句潦草的话："当你听见风声说话，立刻收起书，开始跑。"

此外，书末还夹着一张手绘的可食植物分布图，上面标注了不同季节的采集窗口，并提醒读者：再可靠的图鉴也比不上亲口尝过的经验，但尝之前一定要确认三次，第一次用眼睛，第二次用鼻子，第三次用一小片嘴唇。

## 设计意图

作为探索系列的基础入口，承担解锁野外生存与方向感知能力的职责，为后续复杂地形探索与异界行进提供认知基础。
