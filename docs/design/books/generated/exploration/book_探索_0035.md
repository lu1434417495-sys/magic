# 《废墟机械语言》

## 基础信息

- **书籍 ID**：`book_探索_0035`
- **关联技能**：`exploration_ruin_automaton_speak`（待新增，标签 `exploration`）
- **使用效果**：阅读后解锁探索技能 `exploration_ruin_automaton_speak`；若已学会，提升 `current_mastery +70`，可与古代守卫傀儡对话并避免部分战斗。
- **阅读要求**：法师或战士优先；基础 `智力 ≥ 11`。
- **稀有度**：稀有（Rare）
- **建议投放**：古代工厂、机械学者、傀儡核心宝箱。

## 书籍内容

这本书的封面是两块金属板夹成，打开时会发出齿轮转动的咔哒声。作者整理了古代机械文明留下的指令结构与信号代码，声称理解这些语言是与古代守卫傀儡对话的前提。书中从最简单的动力启动指令讲起，逐步介绍维护请求、警戒解除与路径指引等常用语句。中段讲解了不同型号傀儡的响应模式，有些对语音敏感，有些只认符文脉冲。后半部分涉及如何在遭遇古代守卫时通过正确指令避免战斗，甚至让它们成为临时盟友。书末贴着一张破损的指令卡："对机器说谎比对人说谎更难，因为它只认逻辑。"

书中还提到，古代机械最珍视的不是服从，而是正确的称呼，叫错名字的探索者往往会触发最高级别的警戒，语言在这里是钥匙也是武器；作者附上一份常见古代守卫的正式称谓表，要求背诵。

## 设计意图

将探索与社会交互系统结合，让玩家通过知识而非战斗解决古代机械敌人，丰富废墟副本的通关路径。
