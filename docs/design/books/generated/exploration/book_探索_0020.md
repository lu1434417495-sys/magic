# 《雪原御寒法》

## 基础信息

- **书籍 ID**：`book_探索_0020`
- **关联技能**：`exploration_snow_resistance`（待新增，标签 `exploration`）

- **稀有度**：普通（Common）
- **建议投放**：雪山营地、冰原猎人、北方部落。

## 书籍内容

这本手册来自北方猎户，封面用厚实的毛皮包裹。作者强调，雪原生存的关键不是穿得越多越好，而是保持干燥与层叠保暖。书中教导读者如何选择内层排汗、中层保温、外层防风的衣物组合，并解释为什么出汗比低温更致命。中段详细介绍了在雪中搭建庇护所、挖掘雪洞与制作简易雪鞋的方法。后半部分讲解了雪盲的预防、冻伤的分级处理，以及如何在白茫茫一片中判断地形起伏。书的最后几页记录了一次失败的远征，作者在最后写道："雪原不会主动杀死你，它只会耐心地等你犯错。"

作者在附录中画了一个简单的雪洞结构图，并标注：雪洞内的温度通常比外面高十度，前提是你要在日落前挖好，否则寒风会替你完成一半；他还提醒，雪洞入口必须背对风向。

他说，雪原上最温暖的地方，往往是同伴的呼吸之间。
