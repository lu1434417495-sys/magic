# 《迷宫标记法》

## 基础信息

- **书籍 ID**：`book_探索_0011`
- **关联技能**：`exploration_maze_marking`（待新增，标签 `exploration`）
- **使用效果**：阅读后解锁探索技能 `exploration_maze_marking`；若已学会，提升 `current_mastery +50`，在复杂地宫中自动标记已探索路径。
- **阅读要求**：无职业限制；基础 `智力 ≥ 7`。
- **稀有度**：普通（Common）
- **建议投放**：迷宫入口、探险家协会、学者 NPC。

## 书籍内容

这本薄薄的小册子被无数迷宫探索者奉为圣经，每一页的空白处都留有用炭笔做记号的示范。作者提出，进入迷宫的第一件事不是寻找出口，而是建立一套自己绝不会误解的标记系统。书中介绍了左右手法则、节点编号法与回退标记三种基础策略，并强调标记必须简单、持久、不容易被他人模仿或擦除。中段用几幅示意图展示了如何利用墙角、地面砖缝与天花板横梁留下只有本队能识别的符号。后半部分讨论了如何应对会移动墙体的活迷宫，作者建议在每次转弯处留下时间戳。书的结尾写道："迷宫最怕的不是复杂，而是探索者忘记自己从哪来。"

作者幽默地补充道，如果你发现标记开始重复自己却从未转弯，那很可能不是迷宫在动，而是你在原地绕圈，这时最好的策略是原地坐下等待冷静，因为恐慌会让任何迷宫都变得更大。

## 设计意图

作为迷宫探索的基础辅助技能，降低玩家在复杂地城中的认知负担，为后续地图记忆与空间解谜能力提供成长路径。
