# 《灵脉感知入门》

## 基础信息

- **书籍 ID**：`book_探索_0022`
- **关联技能**：`exploration_leyline_sense`（待新增，标签 `exploration`）
- **使用效果**：阅读后解锁探索技能 `exploration_leyline_sense`；若已学会，提升 `current_mastery +65`，可感知地图上的灵脉节点，站在节点上冥想或修炼效率提升。
- **阅读要求**：法师或牧师优先；基础 `智力 ≥ 10` 或 `感知 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：灵脉祭坛、修道院、神秘学者。

## 书籍内容

这本书的封面用灵蚕丝编织，散发着微弱的温热。作者认为灵脉是世界的血管，而感知灵脉是探索者最深层的能力。书中从静坐调息开始，教导读者如何在身体中建立对灵气的敏感度，再逐步扩展到感知周围环境中的灵脉节点。中段讲解了灵脉强弱与地形、天体位置的关系，以及如何辨别主脉与支脉。后半部分开始教授如何在灵脉节点上进行冥想与修炼，以提升 MP 恢复速度与 AURA 凝聚效率。作者在最后提醒，灵脉有时也会反噬贪婪的汲取者。书末的批注写道："听见大地的脉搏时，先别急着索取，先学会倾听。"

作者在最后写道，灵脉节点会记住每一个曾经汲取它的人，当你最需要力量时，它会决定是否回应你，贪婪者往往只听见沉默；他建议每次汲取后都要向大地归还一点东西，哪怕只是一滴水。

## 设计意图

将探索技能与冥想、修炼资源系统深度绑定，鼓励玩家在地图中寻找灵脉节点进行战略性休息与成长。
