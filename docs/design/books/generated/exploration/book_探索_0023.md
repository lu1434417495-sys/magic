# 《遁逸步法：脱离战斗》

## 基础信息

- **书籍 ID**：`book_探索_0023`
- **关联技能**：`exploration_disengage_step`（待新增，标签 `exploration`）
- **使用效果**：阅读后解锁探索技能 `exploration_disengage_step`；若已学会，提升 `current_mastery +60`，战斗中可消耗一点行动从相邻敌人身边安全撤离。
- **阅读要求**：盗贼或弓箭手；基础 `敏捷 ≥ 9`。
- **稀有度**：稀有（Rare）
- **建议投放**：刺客公会、游侠导师、战场逃兵。

## 书籍内容

这本书的装订松散，仿佛随时会散开，但每一页都写满了关于"离开"的艺术。作者强调，战斗中的撤退不是逃跑，而是战略性转移，关键在于把握敌人攻击后的硬直瞬间。书中教导读者如何通过观察敌人的重心变化预判其收招时机，并借助侧身、滑步与翻滚从包围中脱身。中段详细讲解了在不同地形下脱离接触的技巧，包括利用烟雾、拐角与高低差。后半部分介绍了如何为队友创造撤退窗口，以及撤退后如何迅速重组阵线。书的最后写着一句话："活着离开战场的人，才有资格总结胜负。"

书末贴有一张染血的笔记，上面只有一句话：“真正的撤退不是背对敌人，而是面向下一次胜利。”这句话被无数雇佣兵当作护身符；作者还画了一个简单的步法图，标注如何在转身时保持重心稳定。

他提醒，撤退时最忌讳回头，因为犹豫会拖慢脚步。

## 设计意图

为战棋战斗增加脱离机制，提升盗贼与弓箭手的机动生存价值，避免探索过程中因一次遭遇战导致全队覆灭。
