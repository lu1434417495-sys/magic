# 《急救草药图鉴》

## 基础信息

- **书籍 ID**：`book_探索_0007`
- **关联技能**：`exploration_herbal_first_aid`（待新增，标签 `exploration`）
- **使用效果**：阅读后解锁探索技能 `exploration_herbal_first_aid`；若已学会，提升 `current_mastery +45`，野外可采集草药并制作简易恢复道具。
- **阅读要求**：牧师或法师优先；基础 `智力 ≥ 7`。
- **稀有度**：普通（Common）
- **建议投放**：草药师小屋、森林据点、医疗营地。

## 书籍内容

这本图鉴的每一页都贴着干燥的叶片与花瓣，旁边用娟秀字迹标注着药性、剂量与禁忌。作者先从止血草与退烧花入手，强调野外急救的第一原则是"不要加重伤势"，其次才是治愈。书中教导读者如何通过叶片背面绒毛、茎部汁液颜色与气味来判断植物是否可入药，并列出十几种外观相似但毒性极强的混淆品种。中段用真实案例说明，一位探险者因为把毒芹当成薄荷煮汤，导致全队失明。后半部分介绍了如何在不同气候带寻找对应草药，以及干燥保存的方法。最后一页贴着一片发黄的便签："最好的草药常在最近的路边，但前提是你愿意蹲下来看。"

书脊里夹着一张泛黄的纸条，上面是某位母亲的字迹：“感谢这本书，让我的孩子在高烧第三夜活了下来。”这句话让每一页药材都多了温度，也提醒读者：野外急救的意义从来不只是救自己。

## 设计意图

为探索系列补充生存支援能力，让牧师与法师在野外具备资源自给能力，并与炼金、医疗系统形成联动。
