# 《荒野宿营：临时庇护所搭建》

## 基础信息

- **书籍 ID**：`book_探索_0110`
- **关联技能**：`exploration_wilderness_camp`（待新增，标签 `exploration`）
- **使用效果**：阅读后解锁探索技能 `exploration_wilderness_camp`；若已学会，提升 `current_mastery +90`，并减少野外休息时被夜间遭遇打断的概率。
- **阅读要求**：无职业限制；基础 `感知 ≥ 6` 或 `力量 ≥ 6`。
- **稀有度**：普通（Common）
- **建议投放**：猎人营地、新兵野外训练、基础探险任务奖励。

## 书籍内容

这本书的边角被篝火烧出许多半圆形缺口，显然被无数人带进过荒野。作者从最基础的选址开始：高处避水、背风避寒、远离枯树和动物路径。书中用插图详细展示了如何用树枝、藤蔓和落叶搭建三种不同等级的庇护所：应急的斜靠式、过夜的山墙式、可反复使用的半地穴式。中间章节讲述如何隐藏营地痕迹：避免金属反光、控制炊烟扩散、用泥土覆盖熄灭的火堆。后半本则记录了一系列真实案例，其中一起令人印象深刻：一支商队因为把营地建在山脊凸处而被雷暴击中，另一支因为把火生在风口而被敌对势力循烟追踪。最末页用粗体字写着："营帐不是家，是你在野外给自己造的一个临时谎言。"书中特别强调营火管理，一把小火能救命，也能在几里外告诉敌人你的位置；熄灭火堆时要把灰烬彻底打散，再盖上潮湿的落叶。

## 设计意图

作为探索系列的野外休整技能，把"宿营"从纯剧情行为转化为影响休息质量与遭遇概率的战术决策。
