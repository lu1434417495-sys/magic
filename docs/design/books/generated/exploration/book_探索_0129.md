# 《补给隐匿：野外藏物术》

## 基础信息

- **书籍 ID**：`book_探索_0129`
- **关联技能**：`exploration_supply_cache`（待新增，标签 `exploration`）
- **使用效果**：阅读后解锁探索技能 `exploration_supply_cache`；若已学会，提升 `current_mastery +90`，并可在野外设置 1 处隐藏补给点。
- **阅读要求**：无职业限制；基础 `感知 ≥ 7` 或 `智力 ≥ 7`。
- **稀有度**：普通（Common）
- **建议投放**：游侠营地、商队后勤、野外生存任务奖励。

## 书籍内容

《补给隐匿》的封面画着一个半埋在土里的陶罐，罐口露出半截防水油布。作者从选址开始讲：藏补给的地方必须同时满足"容易找到"和"不容易被找到"两个矛盾条件——对主人来说有明确地标，对陌生人来说毫无异常。书中列出理想的藏物点特征：地势稍高防水、周围有不可移动的大石或古树、从常走的路径上不可直视。中间章节详细讲解了三层封装法：内层密封食物与火种，中层防潮防虫，外层伪装成环境的一部分。后半本是一位游侠的笔记，他在边境各处藏了数十个补给点，却从未丢失过一个。最末页只有一句话："最好的藏物点不是最隐蔽的地方，而是即使被人看见，也不会被当作藏物点的地方。"书中还提到补给点的维护：每隔一段时间要回去检查密封是否完好、是否有动物光顾，以及环境变化是否让原来的地标失效。

## 设计意图

作为探索系列的资源管理技能，把野外补给从一次性携带转化为可预埋的战略资源，扩展长途探索与持久战的玩法空间。
