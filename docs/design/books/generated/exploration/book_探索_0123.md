# 《潜行踱步：无声移动的艺术》

- **书籍 ID**：`book_探索_0123`

## 书籍内容

这本书的纸张经过特殊处理，翻动时几乎不发出声音。作者从最基础的脚步开始教起：脚后跟先着地，然后缓慢过渡到脚掌外侧，最后才放下前脚掌；每一步之间都要停顿半拍，让周围的声波恢复平静。中间章节讲解了不同地面的无声行走技巧：落叶要踩叶柄而非叶面，碎石要找三点支撑，木地板要避开横梁连接处的吱呀点。后半本是一位成功潜入敌方要塞的间谍手记，他花了整整三个时辰移动了不到两百步，最后写道："无声不是因为没有声音，而是因为你的声音藏在了环境的声音里。"最末页只有一句话："最安静的脚步，是让别人以为那声音来自风。"书的后半部分还讲解了如何在移动中保持低姿态，以及如何利用周围环境的自然声响为自己的脚步打掩护，作者称之为"借声隐身"。作者提醒，无声移动最忌心急，环境突然安静时宁可原地静止，也不要在寂静中踏出暴露位置的一步。

## 设计意图

作为探索系列的移动隐蔽技能，把"无声移动"从潜行职业的天赋转化为可学习的通用探索能力，扩展非战斗互动空间。
