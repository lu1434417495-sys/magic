# 《古遗物鉴定学》

## 基础信息

- **书籍 ID**：`book_探索_0040`
- **关联技能**：`exploration_relic_appraisal`（待新增，标签 `exploration`）
- **使用效果**：阅读后解锁探索技能 `exploration_relic_appraisal`；若已学会，提升 `current_mastery +85`，拾取未知遗物时自动鉴定其真正价值与隐藏属性。
- **阅读要求**：法师或牧师优先；基础 `智力 ≥ 12`。
- **稀有度**：史诗（Epic）
- **建议投放**：古董商、遗迹鉴定师、皇家宝库。

## 书籍内容

这本书的封面镶嵌着数十枚来自不同文明的微型徽章。作者指出，古代遗物的价值往往不在于外表，而在于其符文结构、材质年代与魔力残留。书中教导读者如何通过观察磨损方式判断遗物的使用频率，通过氧化痕迹推断埋藏环境，通过魔力波动识别是否被诅咒。中段详细介绍了常见遗物的分类与估价标准，并警告不要盲目激活未知物品。后半部分涉及如何在灰烬交界中鉴别被异界力量污染的遗物。书末贴着一张烧焦的标签："每件遗物都背着它的过去，鉴定师的工作是听见它说话，而不是让它再次开口。"

作者在附录中列出了一张“最危险遗物”清单，排名第一的是一面看起来普通的镜子，因为它映照的不是现在，而是观看者最不愿面对的时刻；他警告，鉴定遗物时最该鉴定的其实是自己的心。

## 设计意图

作为史诗级后勤型探索技能，与经济、装备和诅咒系统联动，提升玩家对未知奖励的识别与风险判断能力。
