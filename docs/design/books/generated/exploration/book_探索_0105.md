# 《云与风：天候判读手札》

## 基础信息

## 书籍内容

手札的纸张被海盐和潮气浸得发卷，墨迹在边缘晕开成小小的云状。作者用极朴素的语言教会读者如何从云层形状、风向变化和空气湿度判断接下来几个时辰的天气。书中把云分成九种基本类型，并给每种配了一句农谚式的口诀，比如"鱼鳞天，不雨也风颠"、"乌云接日头，半夜雨不愁"。中间章节特别讨论了灰烬交界的天候异常：那里的云会逆向流动，风向会在毫无征兆的情况下反转，因此传统经验只能作为参考而非答案。后半本记录了一位商队领队的日记，他在一次穿越中因为误判天象而损失了半数货物，最后写道："天候不是敌人，是永远不会为你改变立场的对手。你能做的只有读它、等它、绕开它。"书末夹着一根干枯的芦苇，据说是作者用来测量风向的工具，他认为最简单的仪器往往比最精密的罗盘更可靠。

## 设计意图

作为探索系列的环境预判技能，把天气系统转化为可读可操作的信息，增强玩家在开放区域中的决策维度。
