# 《温差感知：环境中的热量信号》

## 基础信息

- **书籍 ID**：`book_探索_0141`
- **关联技能**：`exploration_temperature_read`（待新增，标签 `exploration`）
- **使用效果**：阅读后解锁探索技能 `exploration_temperature_read`；若已学会，提升 `current_mastery +80`，并可通过温度变化感知附近热源或冷源。
- **阅读要求**：无职业限制；基础 `感知 ≥ 7` 或 `意志 ≥ 7`。
- **稀有度**：普通（Common）
- **建议投放**：火山观测站、北境哨站、元素区域任务奖励。

## 书籍内容

这本书的封面用隔热材料包裹，翻开后能感觉到一股微弱的暖意或凉意，取决于你拿着它的方式。作者认为皮肤是人体最古老的环境传感器，能够感知到比意识更早察觉的温度变化。书中教读者如何利用脸颊、手背和后颈这些对温度敏感的部位判断周围是否存在隐蔽的热源：洞穴中的地下暗河、森林中的篝火余烬、灰烬交界中尚未冷却的异界裂隙。中间章节详细分析了温度梯度与距离的关系，并提醒读者温差也可能来自死去的生物或腐败的植物。后半本是一位巡山人的笔记，他靠感知空气温度的细微变化提前避开了多次火山气体喷发。最末页只有一句话："温度从不说谎，它只是说得比光慢一些。"书的后半部分记录了多种极端环境下的温度错觉案例，作者认为相信自己的皮肤比相信记忆更重要，因为记忆会被期待和恐惧修改。

## 设计意图

作为探索系列的环境感知技能，把温度信息转化为可读取的线索源，增强火山、冰原等极端区域的探索维度。
