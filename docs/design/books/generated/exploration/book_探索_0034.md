# 《深渊潜水要诀》

## 基础信息

- **书籍 ID**：`book_探索_0034`
- **关联技能**：`exploration_abyss_diving`（待新增，标签 `exploration`）
- **使用效果**：阅读后解锁探索技能 `exploration_abyss_diving`；若已学会，提升 `current_mastery +90`，深海区域探索不受压强影响，可发现隐藏深渊宝箱。
- **阅读要求**：无职业限制；基础 `体质 ≥ 12` 或 `意志 ≥ 12`。
- **稀有度**：史诗（Epic）
- **建议投放**：深海神殿、溺亡者遗物、水下古城。

## 书籍内容

这本书的封面用深海鱼皮包裹，翻开时会渗出几滴咸涩的水珠。作者指出，深渊潜水与普通水下探索完全不同，压强、寒冷与黑暗会同时侵蚀身体与意志。书中从强化呼吸节奏、耳压平衡与体温保护入手，逐步教授如何在无光源环境下保持冷静。中段讲解了如何利用水流、温度梯度与生物发光判断深度与方向，以及如何应对深海生物的突然袭击。后半部分涉及深渊遗迹中的特殊机关，它们往往需要用压力或温度来触发。书末的警告被水泡晕染："深渊从不拒绝下潜者，但它也从不主动放人回来。"

作者在最后一页画了一只深海生物的眼睛，并注释：“当你觉得黑暗在看你的时候，它确实在看你。”这句话让无数潜水员在深处不寒而栗；他还警告，深渊中没有真正的独处，只有尚未现身的观众。

## 设计意图

作为水下呼吸训练的高阶版本，解锁深海区域探索，为终极水下副本与深渊文明剧情提供能力门槛。
