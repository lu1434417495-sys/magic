# 《腐败抵抗：异界生存》

## 基础信息

- **书籍 ID**：`book_探索_0037`
- **关联技能**：`exploration_corruption_resist`（待新增，标签 `exploration`）

- **建议投放**：灰烬治疗师、异界净化者、腐蚀边界营地。

## 书籍内容

这本书的封面不断渗出黑色粉末，但内页却出奇地干净。作者认为，灰烬交界等异界对生物最大的威胁不是怪物，而是持续侵蚀现实的腐败气息。书中教导读者如何通过调节呼吸、皮肤接触与魔力屏障来减少腐败层数的累积。中段详细介绍了腐败的不同阶段症状，从轻微幻觉到肢体畸变，并提供了各阶段的应急处理方法。后半部分涉及如何在异界建立临时安全区，以及如何利用净化草药与符文延缓侵蚀。书末用颤抖的字迹写着："腐败不是病，它是异界在改写你的存在方式。"

书末用几乎无法辨认的字迹写着：“腐败不是从外面进来的，它是你内心深处某种东西的倒影。”这句话让读者在合上书本后久久沉默；作者还警告，长期在异界停留的人，回到现实后也要小心自己带回了什么。

他写道，抵抗腐败不是对抗异界，而是守护自己的形状。

## 设计意图

作为异界探索的防御向进阶，与灰烬边界步行形成生存组合，延长玩家在异界地图中的可持续探索时间。
