# 《迷雾驱散仪式》

## 基础信息

- **书籍 ID**：`book_探索_0093`
- **关联技能**：`exploration_fog_dispelling`（待新增，标签 `exploration`）
- **使用效果**：阅读后解锁 `exploration_fog_dispelling`；若已学会，提升 `current_mastery +110`，可在迷雾地图中消耗少量 MP 或 AURA 驱散一片区域的迷雾，持续数回合。
- **阅读要求**：角色已习得 `exploration_mist_pathfinding`；基础 `智力 ≥ 10`、感知 `≥ 9`。
- **稀有度**：史诗（Epic）
- **建议投放**：迷雾神殿、高阶游侠任务奖励、元素祭坛宝箱。

## 书籍内容

《迷雾驱散仪式》被认为是《迷雾探路者笔记》的高阶续篇，但它不再教人如何与雾共存，而是教人如何让雾暂时退却。书中记载，迷雾本质上是一种被元素力量扰动的湿气，只要找到正确的频率，就能用魔力或气场将其推开。作者详细描述了驱散仪式的步骤：先以固定节奏呼吸稳定自身气场，再用施术媒介画出一个简化的风向符文，最后以短促的能量释放打破雾气的平衡。书中警告，驱散只能作用于普通自然迷雾或低级魔法雾，面对异界灰烬迷雾时只能暂时清出一条窄路。作者提醒，驱散仪式会暂时暴露施术者的位置，使用时需谨慎选择时机。后半本附有多个符文的变体与适用场景。最后一页用银色墨水写着："雾不是敌人，它只是世界的一层面纱；学会掀开它，但不要以为自己能永远看穿它。"

## 设计意图

作为迷雾探索技能树的高阶能力，为玩家提供主动改变战场视野的手段，与冥想、修炼资源系统轻度联动，增强战棋战斗的策略维度。
