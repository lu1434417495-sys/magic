# 《遗迹机关图解》

## 基础信息

- **书籍 ID**：`book_探索_0052`
- **关联技能**：`exploration_ruin_mechanism`（待新增，标签 `exploration`）
- **使用效果**：阅读后解锁 `exploration_ruin_mechanism`；若已学会，则提升该技能 `current_mastery +100`，并在下一次进入遗迹地图时自动标记 1 个陷阱或机关位置。
- **阅读要求**：无职业限制；基础 `智力 ≥ 9`、感知 `≥ 7`。
- **稀有度**：稀有（Rare）
- **建议投放**：古代遗迹书架、机关学者声望奖励、地下城探索宝箱。

## 书籍内容

《遗迹机关图解》的扉页印着一句警告："看懂一本书只需要一天，看懂一扇门可能需要一辈子。"全书以三百余幅精细线稿拆解古代工匠常用的十六种机关：压力板、翻板、毒针、落石、水银触发槽、镜面折射锁、音叉共鸣门等。每种机关都配有触发原理、识别征兆和最低限度的解除思路。作者特别强调"观察先于动手"，建议在触碰任何可疑石砖前先检查相邻三块砖的磨损痕迹与缝隙积灰。书中还记载了"假机关"的概念：有些古代建造者会故意留下明显的陷阱特征，引诱入侵者绕开真正藏宝的暗格。后半部分收录了数十则短评，多由后世探险者用铅笔批注，记录着不同遗迹中实际遇到的变体。最后一章标题是"无解之门"，只有一句话："有些门不是让人打开的，是让人证明自己值得被放过。"许多读者在合上书后，会下意识放慢脚步，重新审视每一扇经过的门。

## 设计意图

为遗迹探索玩法提供主动的陷阱与机关交互能力，让玩家在战棋地图中通过知识而非纯属性检定规避风险，增强探索阶段的策略深度。
