# 《废墟语法：残垣中的信息》

## 书籍内容

这本书的封面压印着半枚看不清纹章的火漆，翻开之后满是被烟熏黄的拓片和手绘建筑剖面。作者认为废墟本身是一种语言，墙体的裂缝、石材的风化方向、灰烬堆积的厚度都在说话。书中教读者如何判断一座废墟是"被时间吃掉"还是"被暴力撕开"，并从这个判断推导里面是否还藏着未被洗劫的密室。中间章节列出二十七种常见遗迹符号，从代表"水源"的波纹三角到警告"诅咒"的断裂圆环。后半本是一位考古学徒的日记，他因为误读了一个"禁止入内"的符号而触发机关，却在伤愈后坚持认为那不是失误，而是"语法没学好"。最末页用烫金小字写着："每一块石头都在等一个会问问题的人。"附录中有一份"废墟优先级表"，教读者进入遗迹后应该先检查承重结构、通风口还是撤离路线，这张表被很多探险队抄在盾牌内侧。

## 设计意图

作为探索系列的文化解码技能，把废墟从战斗背景转化为信息来源，增加遗迹区域的探索回报与叙事深度。
