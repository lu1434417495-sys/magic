# 《攀爬者之手》

## 书籍内容

《攀爬者之手》的作者是一位失去三根手指却仍活跃在峭壁之间的老登山家。他在书中反复强调，攀爬不是手臂的工作，而是脚趾与重力的谈判。作者把岩壁分成四类：粗糙的火山岩、湿滑的页岩、布满缝隙的花岗岩，以及被风化侵蚀的砂岩，每一类都需要不同的抓握方式和重心分配。书中详细讲解了"三点固定法"：在任何时候，至少有三个肢体点稳定接触岩面，第四个肢体才允许移动。作者还提醒，下山比上山更危险，因为人的视觉会欺骗距离感，而疲劳会让判断力下降。他还提醒，攀岩前必须检查岩钉与绳索的老化程度，信任装备就是信任生命。后半本记录了许多著名崖壁的路线与危险季节，以及如何在坠落时利用绳索与岩钉自救。最后一页画着一只布满老茧的手，掌纹里嵌着沙石，旁边写着："山不拒绝任何人，但风会挑选。"

## 设计意图

为战棋地图增加垂直维度移动能力，让高地形与障碍物成为可利用的战术元素，同时扩展探索维度的可到达区域。
