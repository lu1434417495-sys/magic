# 《足迹学：泥土上的对话》

## 书籍内容

《足迹学》的扉页上有一行被雨水泡开的字："地面从不说谎，说谎的是读它的人。"全书用四十多幅木炭画展示不同鞋底、蹄爪与滑行痕迹在泥、沙、雪、灰四种介质上的形态。作者提出一个简单法则：看深浅知负重，看边缘知速度，看落点知跛健。书中特别花一章讲解如何区分野兽足迹与伪装足迹，并警告最危险的追踪不是跟丢，而是跟到被故意引到的陷阱。后半部分记录了几位传奇猎人的笔记，其中一段写道："狼会绕圈回到自己的气味上，人也会。区别只在于，狼是为了确认领地，人是为了确认自己还没迷路。"末尾附录有一张不完整的野兽足印对照表，旁边 scribbled 着："新增条目请用自己的血写，这样才不会忘记。"书的封底贴着一张褪色的猎户座星图，作者认为最好的追踪者同时也要是最好的天文学家，因为星辰能告诉你季节，季节能改变一切痕迹。

## 设计意图

作为探索系列的核心追踪技能入口，把"足迹"设计为可读取的环境信息源，强化玩家在野外场景中的侦查与反埋伏能力。
