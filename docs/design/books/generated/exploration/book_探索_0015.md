# 《高空呼吸法》

## 基础信息

- **书籍 ID**：`book_探索_0015`
- **关联技能**：`exploration_high_altitude_breath`（待新增，标签 `exploration`）
- **使用效果**：阅读后解锁探索技能 `exploration_high_altitude_breath`；若已学会，提升 `current_mastery +50`，高山地图移动力不下降并减少高原反应持续时间。

- **稀有度**：普通（Common）

## 书籍内容

这本手抄本来自高原部落，纸页因低气压而微微卷曲。书中提出，高海拔移动的最大障碍不是寒冷，而是氧气稀薄带来的意识模糊。作者教导读者如何通过深呼吸节奏、步伐控制与心理暗示来维持血氧，并警告任何剧烈运动都会让高原反应迅速恶化。中段详细介绍了在不同海拔高度调整呼吸频率的方法，以及出现头痛、恶心时应该立即下撤的原则。后半部分讲解如何在稀薄空气中保持战斗力，包括如何在战前调整呼吸以最大化输出。书末用红笔写着一句话："山峰会原谅你的傲慢，但不会原谅你的愚蠢。"

书末记录了一首高原部落的歌谣，歌词大意是：山神借给你空气，但只借给那些愿意慢下来的人， rushing 的人会被风夺走呼吸；作者用这首歌作为每次攀登前的仪式。

他还提醒，登山时不要追逐云彩，因为它们会把你引向悬崖。

## 设计意图

解锁高山地形探索能力，为后续垂直攀登与极端环境技能提供前置，强化体质与意志属性在探索中的价值。
