# 《地城生态图谱》

## 基础信息

- **书籍 ID**：`book_探索_0043`
- **关联技能**：`exploration_dungeon_ecology`（待新增，标签 `exploration`）
- **使用效果**：阅读后解锁探索技能 `exploration_dungeon_ecology`；若已学会，提升 `current_mastery +70`，进入地城时显示怪物弱点与生态习性并提升先手率。
- **阅读要求**：无职业限制；基础 `智力 ≥ 10` 或 `感知 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：地城学者、怪物图鉴商人、地下图书馆。

## 书籍内容

这本书的封面用某种生物甲壳压制而成，上面画满了地城怪物的剪影。作者认为，了解地城生态比记住怪物弱点更重要，因为生态决定了怪物的分布、巡逻路线与群体行为。书中教导读者如何通过粪便、抓痕与骨骼残骸判断附近栖息的物种与数量。中段详细介绍了常见地城怪物的社会结构，包括哥布林的哨兵体系与不死生物的巡逻规律。后半部分涉及如何利用生态知识设置陷阱、规避战斗或引导怪物自相残杀。书末写着："地城不是一堆怪物的仓库，它是一个活着的系统，而你是闯入者。"

书中还提到，地城怪物也会学习，同一个陷阱第二次使用的效果通常只有第一次的一半，所以聪明的探索者从不重复使用同一种把戏；作者建议每次进入地城都准备至少三套不同的战术。

他写道，读懂怪物，比杀死怪物更需要智慧。

## 设计意图

将探索与战斗信息优势结合，降低地城探索的盲目性，为策略型玩家提供以智取胜的路径。
