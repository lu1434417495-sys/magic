# 《环境伪装：与背景融为一体》

## 基础信息

- **书籍 ID**：`book_探索_0142`
- **关联技能**：`exploration_color_blending`（待新增，标签 `exploration`）
- **使用效果**：阅读后解锁探索技能 `exploration_color_blending`；若已学会，提升 `current_mastery +90`，并在静止不动时提升与自然环境的融合度。
- **阅读要求**：无职业限制；基础 `敏捷 ≥ 7` 或 `感知 ≥ 7`。
- **稀有度**：稀有（Rare）
- **建议投放**：游侠营地、刺客训练场、高级潜行任务奖励。

## 书籍内容

这本书的封面会根据光线角度改变颜色，仿佛它自己就是伪装的示范。作者提出伪装的核心原则：不是变成环境，而是打断自己的轮廓。书中教读者如何利用泥土、植物汁液和炭灰改变皮肤与装备的色调，如何在不同地形中选择静止姿势以最小化阴影，以及如何利用环境中的垂直线条打破人形轮廓。中间章节强调，伪装最大的敌人是移动：再完美的配色也会在移动中暴露。后半本是一位资深猎人的笔记，他记录了自己如何伪装成一根枯木长达六个时辰，最终等到目标进入射程。最末页只有一句话："不要试图欺骗眼睛，要欺骗的是大脑对'这里应该有什么'的预期。"书中还附有一页空白的人形轮廓图，作者让读者在上面画出自己装备在不同地形中的剪影，以练习如何用最少的改动融入背景。

## 设计意图

作为探索系列的隐蔽增强技能，把环境伪装从视觉表现转化为可训练的战术能力，为埋伏与侦察职业提供支持。
