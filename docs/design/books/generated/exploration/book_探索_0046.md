# 《异界门扉钥》

## 基础信息

- **书籍 ID**：`book_探索_0046`
- **关联技能**：`exploration_otherworld_key`（待新增，标签 `exploration`）
- **使用效果**：阅读后解锁探索技能 `exploration_otherworld_key`；若已学会，提升 `current_mastery +100`，可在特定地点开启通往灰烬交界的小型传送门，用于快速移动。
- **阅读要求**：法师或牧师；基础 `智力 ≥ 13` 或 `意志 ≥ 13`。

- **建议投放**：灰烬神殿核心、世界裂缝、隐藏异界主线奖励。

## 书籍内容

这本书的封面是一扇微缩青铜门，门缝中不时透出诡异的光芒。作者声称，灰烬交界与现实世界之间存在无数薄弱点，而掌握门扉钥的人可以在这些点上开启临时通道。书中从感知空间薄弱点开始，逐步讲解如何用魔力绘制开门符文、如何稳定通道入口与如何设定出口锚点。中段详细介绍了开门所需的代价，包括魔力消耗、精神负担与可能的异界污染。后半部分涉及战术应用，如快速转移队伍、绕过障碍或从异界侧突袭敌人。书末用银色墨水写着："每扇门都双向开启，你注视异界时，异界也在注视你。"

书末夹着一把生锈的小钥匙，作者注释说它并非真正的门钥，而是提醒每一位学习者：开门之前，先准备好关门的勇气，否则异界不会放你回来；他还附有一道简单的封印练习，要求能随手关闭自己打开的任何门。

## 设计意图

作为传说级异界通行技能，连接现实世界与灰烬交界，服务于后期快速旅行、异界副本与主线剧情推进。
