# 《毒藤识别：危险植物的图鉴》

- **书籍 ID**：`book_探索_0135`

## 书籍内容

这本书的每一页都配有一幅精细的植物插画，并在旁边用红色标注危险部位。作者把有毒植物分为接触毒、吸入毒和食入毒三类，并强调在野外"不认识的植物不要碰，认识的植物也要确认它没有长在不认识的地方"。中间章节用口诀帮助记忆："三片一起，距离远些；五瓣成簇，切勿触摸；乳汁白浆，洗手为王。"后半本是一位草药师的病例记录，她详细记载了多种中毒症状与应急处理方法，并特别警告灰烬交界的植物可能会随余烬污染改变毒性。最末页只有一句话："植物不会追你，所以只要你愿意停下来看一眼，它就很难伤害你。"附录里有作者手绘的"危险植物相似种对照"，专门指出哪些无毒植物长得极像有毒植物，作者认为误杀一株好植物和误食一株毒植物同样令人遗憾。作者最后用红字强调，戴手套接触毒藤后也要避免触碰眼睛，因为乳状汁液能在织物上残留很久。

## 设计意图

作为探索系列的野外生存技能，把有毒植物识别转化为可学习的知识，增强自然环境中的风险识别与资源利用。
