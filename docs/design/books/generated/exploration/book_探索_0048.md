# 《星界信标》

## 基础信息

- **书籍 ID**：`book_探索_0048`
- **关联技能**：`exploration_astral_beacon`（待新增，标签 `exploration`）
- **使用效果**：阅读后解锁探索技能 `exploration_astral_beacon`；若已学会，提升 `current_mastery +100`，可在任意地点设置信标，死亡或迷途时选择回归最近信标。
- **阅读要求**：无职业限制；基础 `意志 ≥ 14`。
- **稀有度**：传说（Legendary）
- **建议投放**：星界神殿、陨落旅者、宇宙观测站。

## 书籍内容

这本书的封面由星图织锦制成，翻开时仿佛有微光在纸页间流动。作者提出，探索者最大的恐惧不是死亡，而是在未知中迷失后连灵魂都无法归位。书中教导读者如何用自身魔力构建星界信标，在任意地点留下可回归的坐标。中段详细介绍了信标的维护、隐藏与紧急召回机制，以及如何防止敌人追踪信标信号。后半部分涉及团队合作，多个信标可以组成回归网络，覆盖大片未知区域。书末用发光的字体写着："无论走到哪里，都要给自己留一盏回家的灯。"

书的最后几页是空白的，作者在序言中解释：每一位探索者都必须用自己的坐标填满这些页，那才是属于你自己的星图，别人无法替你绘制；他建议每设立一个信标，都要在旁边留下只有自己能读懂的暗号。

他提醒，信标不仅指引归途，也记录你曾敢走多远。

## 设计意图

作为传说级安全保障技能，降低高难度探索的失败惩罚，鼓励玩家深入未知区域挑战终极内容。
