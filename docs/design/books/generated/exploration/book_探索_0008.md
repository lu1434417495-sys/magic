# 《潜行侦察要诀》

## 基础信息

- **书籍 ID**：`book_探索_0008`
- **关联技能**：`exploration_stealth_recon`（待新增，标签 `exploration`）
- **使用效果**：阅读后解锁探索技能 `exploration_stealth_recon`；若已学会，提升 `current_mastery +60`，可在不触发战斗的情况下侦察敌人数目与类型。
- **阅读要求**：盗贼或弓箭手；基础 `敏捷 ≥ 8`。
- **稀有度**：稀有（Rare）
- **建议投放**：暗影行会、边境哨站、间谍任务奖励。

## 书籍内容

此书由一位无名斥候写成，书脊内藏着几页薄如柳叶的隐形墨水附录。开篇即指出，侦察不是隐身，而是让对方"看见却不注意"。作者详细讲解了如何利用地形高低差、阴影移动规律与风向隐藏身形，并强调脚步落地时应像猫一样先用脚掌外侧着地。中段列出数十种常见地表的声音等级，从碎石路到落叶层，再到积水沼泽，每一步都需要调整步伐。后半部分开始教授如何在敌人营地外围收集情报，包括数清帐篷数量、判断炊烟时间推算士气。书的末尾写着一句话："带回错误情报的侦察员，比迷路的人更该死。"

作者在最后警告，最优秀的侦察员从不追求看得最多，而是追求把看到的东西活着带回来，信息只有在传递出去之后才真正具有价值；死人带不回的情报，只会成为敌人的战利品。

## 设计意图

作为稀有侦察技能书，服务于战前情报收集与副本探索，强化盗贼、弓箭手的辅助定位，减少盲目遭遇战的概率。
