# 《回声定位：洞穴中的耳地图》

## 基础信息

## 书籍内容

这本书的装订用了厚实的软皮，据说在洞穴中落地不会发出声响。作者把回声比作洞穴的呼吸：短促的弹舌声适合判断前方是否有开阔空间，低沉的哼鸣适合感知两侧的岩壁厚度，而连续的拍手则能帮助判断头顶是否有悬挂的空腔。书中警告，不同的岩质会欺骗耳朵：多孔石会吸声，钟乳石区会产生多重回声，而灰烬交界的洞穴壁有时会发出类似心跳的低频震动。后半本是一位盲眼矿工的口述记录，他靠回声在地下生活了十七年，能凭声音判断前方是否有水、是否有风、是否有活物。最末页只有一句话："在黑暗里，耳朵才是你的眼睛；在安静里，你自己的声音才是最好的灯笼。"附录有一份常见洞穴生物的叫声图鉴，作者提醒读者，当你听见回声开始改变节奏，那说明有东西正在改变洞穴的形状。

## 设计意图

作为探索系列的洞穴专精技能，把回声机制转化为空间感知能力，为地下探索与黑暗环境增加独特的侦查手段。
