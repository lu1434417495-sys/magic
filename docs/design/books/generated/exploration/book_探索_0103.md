# 《危险呼吸：陷阱感知入门》

## 书籍内容

这本书被皮革封面包得严严实实，据说是因为里面的插图太过"写实"。作者把陷阱分为三类：会动的、会响的、会等的。会动的靠眼睛，会响的靠耳朵，会等的只能靠一种说不清的直觉。书中教读者在进入陌生区域时先停三步，用目光扫过地面上的不协调之处——落叶的排列、石头的颜色、灰尘的厚度。中间章节详细分析了十几种经典陷阱的触发逻辑，并指出大多数陷阱不是为了杀死闯入者，而是为了让他们发出声音。后半本全是失败者的自述：有人踩中了没有盖的坑，有人拉动了不该拉的拉杆，有人因为太久没出事而忘记了先看再迈。最后一页用红字写着："陷阱最可怕的不是机关，而是你以为这里没有机关。"附录里有一份各地常见陷阱的清单，但作者在每个条目后都加了同一句话："清单只是开始，现场才是老师。"

## 设计意图

作为探索系列的安全保障技能，把"陷阱感知"包装成需要主动使用的侦查能力，鼓励玩家在危险区域放慢节奏、观察环境。
