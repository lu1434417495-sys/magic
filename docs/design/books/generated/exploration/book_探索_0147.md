# 《露水收集：干旱中的补给》

## 书籍内容

《露水收集》的封面画着一个倒置的锥形布篷，下方挂着一只正在接水的小陶罐。作者指出即使在最干旱的地区，空气中的水分也会在夜间凝结，关键在于如何把这些微量水分聚集起来。书中教读者制作简易露水收集器：用透明塑料布覆盖挖好的浅坑，中央放一块小石头让凝结水沿坡度流入容器；或者利用宽大的金属叶片在黎明前收集叶片背面的水珠。中间章节讨论了不同地表和植被对露水产量的影响，并提醒读者有些植物表面的露水带有刺激性物质，不能直接饮用。后半本是一位沙漠游牧民的生活记录，她靠露水收集在多雨季节之外度过了无数干季。最末页只有一句话："天空每天都给你一杯水，问题是大多数人不知道去拿什么接。"书的后记记录了一位游牧母亲如何利用露水收集为孩子换取活命的机会，作者说这是探索技能最温柔也最残酷的用途。

## 设计意图

作为探索系列的资源获取技能，把露水收集转化为干旱环境中的可持续补给手段，增强生存玩法与资源循环。
