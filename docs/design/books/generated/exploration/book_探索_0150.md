# 《界标刻印：探索者的签名》

## 基础信息

- **书籍 ID**：`book_探索_0150`
- **关联技能**：`exploration_boundary_mark`（待新增，标签 `exploration`）
- **使用效果**：阅读后解锁探索技能 `exploration_boundary_mark`；若已学会，提升 `current_mastery +90`，并可在探索过的区域留下个人界标以加速回程。
- **阅读要求**：无职业限制；基础 `智力 ≥ 7` 或 `感知 ≥ 7`。
- **稀有度**：稀有（Rare）
- **建议投放**：探险家协会、边境制图师、高级探索任务奖励。

## 书籍内容

这本书的最后一页是空白的，作者说那是留给读者设计自己界标的地方。界标刻印不是破坏环境，而是与环境达成一种默契：在特定位置留下只有自己和同伴能识别的微小记号，用来确认路径、标记危险或记录资源。书中列出了优秀界标的五个特征：隐蔽、耐久、明确、可逆、不误导他人。中间章节展示了多种传统界标形式：石堆的特定摆法、树皮的浅刻、草丛的编织结，以及灰烬交界常用的余烬碎片排列。后半本是一位传奇探险家的笔记，他在一生中刻下了上千个界标，临终前却说最值得骄傲的界标是"那些后来人永远找不到的"。最末页只有一句话："真正的探索者不是第一个到达的人，而是第一个知道怎么回来的人。"书的后记是一位传奇探险家的遗嘱片段，他要求自己的界标在他死后继续为后人指路，但永远不要告诉别人界标具体是什么。

## 设计意图

作为探索系列的收官之作，把界标刻印转化为玩家与环境之间的长期互动，强化探索的可复访性与个人痕迹感。
