# 《毒物辨识与中和》

## 基础信息

- **书籍 ID**：`book_探索_0024`
- **关联技能**：`exploration_poison_identify`（待新增，标签 `exploration`）
- **使用效果**：阅读后解锁探索技能 `exploration_poison_identify`；若已学会，提升 `current_mastery +60`，可辨识有毒区域并制作基础解毒剂。
- **阅读要求**：牧师或盗贼优先；基础 `智力 ≥ 8`。
- **稀有度**：稀有（Rare）
- **建议投放**：炼金术士、毒药师、沼泽遗迹。

## 书籍内容

这本书的封面用处理过的蛇皮包裹，内页按颜色分类列出上百种毒物。作者认为，辨识毒物的第一步是克服恐惧，因为慌乱会导致更多错误。书中从植物毒素、动物毒液到矿物粉末，逐一讲解其症状、发作时间与急救方法。中段重点介绍了如何用常见草药配制基础解毒剂，并强调每种解毒剂都有适用范围，没有万能解药。后半部分开始讨论毒气环境，包括如何用湿布、尿液或活性炭过滤空气。书末贴着一张褪色的药剂配方，旁边写着："大自然下毒时从不大声宣告，它总是悄悄把危险放进最熟悉的事物里。"

作者提醒，辨识毒物最危险的时刻不是看到它，而是以为自己已经认识了它，傲慢是解毒剂解不了的毒，也是野外最常见的死因；他在附录中列出了十种最容易被误认的相似植物，并反复用红笔圈出区别。

## 设计意图

将探索生存与状态抗性系统连接，提升沼泽、地牢等危险区域的探索容错率，为炼金与医疗玩法提供素材来源。
