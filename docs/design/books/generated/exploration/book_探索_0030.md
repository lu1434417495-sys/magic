# 《气息压制：静伏术》

## 基础信息

- **书籍 ID**：`book_探索_0030`
- **关联技能**：`exploration_still_presence`（待新增，标签 `exploration`）
- **使用效果**：阅读后解锁探索技能 `exploration_still_presence`；若已学会，提升 `current_mastery +70`，原地不动时极难被敌人侦测，适合伏击与侦察。
- **阅读要求**：盗贼或弓箭手；基础 `敏捷 ≥ 10` 或 `意志 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：暗影训练场、刺客导师、隐藏伏击点。

## 书籍内容

这本书的封面像树皮一样粗糙，翻开时几乎没有任何气味。作者强调，静伏术不是静止不动，而是让心跳、呼吸与魔力波动都降到最低。书中教导读者如何通过冥想调整心率、如何控制眼球转动以避免反光、如何让衣物与皮肤保持同样的温度。中段详细讲解了在不同地表上保持静止的技巧，包括草地、碎石与水面。后半部分开始涉及战斗中的伏击应用，如何在敌人经过的瞬间发动致命一击。书的最后几页是一位刺客的心得："伏低不是为了卑微，而是为了在正确的时刻，从阴影中站起来。"

作者在最后提醒，静伏术的最高境界不是让敌人看不见你，而是让他们在离开后完全想不起曾经经过这里，仿佛你只是一阵路过的风；他警告，达到这种境界的人往往会怀疑自己是否真实存在过。

他提醒，伏击者最大的敌人不是目标，而是自己的耐心。

## 设计意图

为盗贼与弓箭手提供高级伏击与侦察技能，强化战棋中的先手伏击玩法，与潜行侦察、遁逸步法形成机动战术闭环。
