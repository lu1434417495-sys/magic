# 《灵视：看破虚妄》

## 基础信息

- **书籍 ID**：`book_探索_0044`
- **关联技能**：`exploration_spirit_sight`（待新增，标签 `exploration`）
- **使用效果**：阅读后解锁探索技能 `exploration_spirit_sight`；若已学会，提升 `current_mastery +85`，可看破隐形、幻影与异界伪装，战斗中每四回合可主动开启一回合。
- **阅读要求**：牧师或法师优先；基础 `感知 ≥ 12` 或 `意志 ≥ 12`。
- **稀有度**：史诗（Epic）
- **建议投放**：灵魂神殿、驱魔人、圣光修道院。

## 书籍内容

这本书的封面镶嵌着一块浑浊的水晶，透过它看东西会有些扭曲。作者提出，肉眼所见只是世界的一层表皮，灵视能穿透伪装、幻象与异界投影。书中教导读者如何通过冥想开启灵视、如何控制灵视的持续时间来避免精神疲劳，以及如何分辨真实物体与魔力投影。中段详细讲解了常见幻术与伪装的破绽，包括光影不一致、声音延迟与温度异常。后半部分涉及灰烬交界中的异界伪装，那里的幻象往往基于观看者的记忆。书末的警告写道："看破虚妄之后，你会发现真实有时比幻象更难接受。"

作者在最后警告，灵视使用太久会让真实与幻象的界限模糊，有些使用者最终选择闭上眼睛生活，因为清醒比幻象更令人疲惫；他建议每日使用灵视不超过三次，每次不超过一盏茶的时间。

他提醒，灵视打开的越多，闭上的眼睛也越多。

## 设计意图

作为对抗幻术、隐形与异界伪装的史诗技能，服务于特定副本与敌人配置，强化牧师、法师的战术辅助价值。
