# 《古文字破译手册》

## 基础信息

- **书籍 ID**：`book_探索_0017`
- **关联技能**：`exploration_ancient_literacy`（待新增，标签 `exploration`）
- **使用效果**：阅读后解锁探索技能 `exploration_ancient_literacy`；若已学会，提升 `current_mastery +65`，可阅读遗迹碑文并解锁 `known_knowledge_ids`：失落文字。
- **阅读要求**：法师或牧师优先；基础 `智力 ≥ 9`。
- **稀有度**：稀有（Rare）
- **建议投放**：图书馆废墟、博学者、隐藏书房。

## 书籍内容

这本书的封面镶嵌着一片发黄的青铜残片，上面刻着无法辨认的符号。作者整理了十七种常见古代文字的基本构词规律，从象形、指事到会意，每一种都配有对照表。书中强调，破译古文字不是背诵符号，而是理解书写者的世界观：他们如何计数、如何表达时间、如何区分生死。中段用几段残碑实例展示如何从上下文推断未知字符，并警告不要孤立解读单个符号。后半部分涉及灰烬交界中发现的异界文字，它们的语法似乎会随着阅读者的心情变化。书末贴着一张纸条："有些文字被写下来，不是为了被读懂，而是为了被记住。"

书的夹层里藏着半张未完成的翻译，作者似乎在临终前仍在尝试解读一个词，那个词被红笔圈了又圈，至今无人能确定其含义；有人说那是“回家”的古称，也有人说那是“永别”。

## 设计意图

作为知识解锁型探索技能，与 known_knowledge_ids 系统对接，为遗迹解谜、隐藏剧情与传说禁术阅读提供前置条件。
