# 《地脉震动解读》

## 书籍内容

这本书的封面镶嵌着一小块矿石，翻开时能感觉到轻微的震动。作者提出，地脉不仅是灵气的通道，也是大地压力的释放网络，读懂震动就能预判危险。书中教导读者如何通过脚底感知、悬挂物摆动与水面波纹来判断震源方向与强度。中段详细解释了自然地震与机关触发震动的区别，前者杂乱而后者有规律。后半部分涉及如何在洞穴探险中利用震动信息避开坍塌区，以及如何在战斗中借助地震判断敌方大型单位的位置。书末的警告用粗体字写成："当地面开始低鸣，别问它为什么，先找能撑住头顶的地方。"

作者在最后强调，震动是大地说话的方式，听懂它的人能活下来，打断它的人只会被埋得更深，耐心是地底世界最硬的护甲；他建议每次进入洞穴前先静坐一分钟，感受脚下是否有微弱的震颤。

## 设计意图

为地城与洞穴环境增加环境感知维度，减少突发性环境伤害带来的挫败感，同时增强战士与法师的侦查定位能力。
