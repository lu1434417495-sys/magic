# 《地图记忆法》

## 基础信息

- **书籍 ID**：`book_探索_0045`
- **关联技能**：`exploration_cartographic_memory`（待新增，标签 `exploration`）
- **使用效果**：阅读后解锁探索技能 `exploration_cartographic_memory`；若已学会，提升 `current_mastery +70`，访问过的地图永久记录，即使未携带地图也能导航。
- **阅读要求**：无职业限制；基础 `智力 ≥ 9`。
- **稀有度**：稀有（Rare）
- **建议投放**：博学者公会、地图商人、记忆神殿。

## 书籍内容

这本书的封面像一本老相册，内页夹着许多手绘的迷你地图。作者认为，真正的方向感来自记忆而非纸张，优秀的探索者能在心中构建整座迷宫。书中教导读者如何通过联想、故事化与身体记忆来强化空间记忆，并提供了多种在脑中绘制路线的方法。中段详细讲解了如何在行进中快速记住岔路、地标与回头点，以及如何在黑暗或迷雾中依靠记忆导航。后半部分涉及与冥想结合的高级记忆法，可以提升 MP 恢复时的专注力。书末写着："地图会丢失、会焚毁、会被水浸泡，但记忆中的路永远不会背叛你。"

作者写道，记忆宫殿的每一块砖都是你曾经踏足的土地，建造得越高，你越不会在任何地方真正迷路，因为整个世界都在你的脑海之中；他还提醒，不要忘记给每块砖留下返回的标记。

他写道，记忆是探索者唯一不会丢失的地图。

## 设计意图

作为迷宫标记法的高级版本，降低玩家对道具地图的依赖，强化智力属性在探索中的长期回报。
