# 《足印解剖：辨识与反辨识》

## 基础信息

- **书籍 ID**：`book_探索_0106`
- **关联技能**：`exploration_footprint_read`（待新增，标签 `exploration`）
- **使用效果**：阅读后解锁探索技能 `exploration_footprint_read`；若已学会，提升 `current_mastery +100`，并可反向伪造一组误导性足迹一次。

- **建议投放**：盗贼行会藏书、军情斥候营地、高级游商货物。

## 书籍内容

这本书的装订方式很特别，每一章都比前一章薄，仿佛作者在越写越机密的地方越发谨慎。第一章讲如何读取足迹：压力分布看出负重，步幅变化看出疲劳，拖痕看出伤势。第二章讲如何反辨识：反穿鞋子、垫高鞋底、刻意改变步态。第三章则进入灰色地带——如何在追踪中故意留下假线索，又如何从敌人的假线索中识别破绽。书中反复强调，伪造足迹的难点不在于模仿外形，而在于模仿"疲惫"和"犹豫"。一个走得太直的假脚印，比真脚印更容易暴露。最末一页贴着一张泛黄的军令残片，命令某支部队"向东撤退，务必让敌军读出向西的意图"。旁注只有四个字："演技即生存。"封底有一段用密语写成的警告："若你发现两组足迹方向相反但深浅一致，那说明对方已经知道你跟来了。"读者需要对照附录才能破译。

## 设计意图

作为探索系列的双向追踪技能，把"足迹"从单向信息扩展为可操控的战术元素，服务于埋伏、诱敌与反追踪玩法。
