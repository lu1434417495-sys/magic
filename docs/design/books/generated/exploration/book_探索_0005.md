# 《绳索与岩壁》

## 基础信息

- **书籍 ID**：`book_探索_0005`
- **关联技能**：`exploration_rope_climbing`（待新增，标签 `exploration`）
- **使用效果**：阅读后解锁探索技能 `exploration_rope_climbing`；若已学会，提升 `current_mastery +50`，可攀爬垂直地形与跨越一格断崖。
- **阅读要求**：无职业限制；基础 `敏捷 ≥ 6`。
- **稀有度**：普通（Common）
- **建议投放**：山地村落、矿工公会、攀岩训练师。

## 书籍内容

这是一本被岩粉和汗水浸透的攀登手册，封面镶嵌着一小块磨圆的岩钉。书中从最简单的单结讲起，逐步过渡到普鲁士抓结、意大利半扣与自锁下降器，每一种绳结都配有作者手绘的错误示范。作者反复强调，攀登不是比力气，而是比耐心与平衡，真正危险的时刻往往是自以为安全的时候。中段讲解了如何寻找可靠的岩点、判断风化程度，以及如何处理松动的碎石。后半部分开始介绍垂直洞穴与冰壁的特殊技巧，包括如何在装备不足时利用冰镐与靴齿制造临时支点。书的最后夹有一张破损的照片，背面写着："献给所有没下来的朋友。"

书中夹着一小段磨损的旧绳索，末端打着奇怪的结，作者注释说这是他从一位坠崖者手中取下的“最后一课”，并告诫读者永远检查绳结，因为绳子不会背叛你，但你的匆忙会。

## 设计意图

扩展战棋地图的垂直移动维度，使高地、断崖等地形从障碍转变为战术资源，为全职业提供通用机动能力。
