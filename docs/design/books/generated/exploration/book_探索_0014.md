# 《矿物与矿脉识别》

## 基础信息

- **书籍 ID**：`book_探索_0014`
- **关联技能**：`exploration_ore_survey`（待新增，标签 `exploration`）

## 书籍内容

这本书的纸张粗糙，上面贴满了各种矿石碎片与岩石断面图。作者从最常见的铁矿锈迹讲起，逐步介绍铜矿、锡矿、银矿与几种稀有水晶的外观特征，并强调颜色与光泽往往具有欺骗性。书中教导读者如何通过岩石硬度、磁性反应与伴生植物来判断地下矿脉走向。中段用大量实例说明，许多看似普通的灰色石头切开后会露出惊人的金属脉络。后半部分涉及如何在野外安全取样、如何用简易工具判断矿石纯度，以及开采时需要注意的地质风险。书的最后写着："大地不会主动吐露秘密，但每一处褪色、每一丝磁吸，都是它在低声说话。"

作者在附录中列出了一份“矿脉谎言”清单，提醒读者警惕那些因氧化而呈现金属光泽的普通岩石，以及那些看似铁矿实为硫化物的陷阱；他说，大地会考验你的耐心，但不会原谅你的贪婪。
