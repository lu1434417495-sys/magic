# 《万象图录：终极探索者之书》

## 基础信息

- **书籍 ID**：`book_探索_0050`
- **关联技能**：`exploration_omniscient_atlas`（待新增，标签 `exploration`）
- **使用效果**：阅读后解锁探索技能 `exploration_omniscient_atlas`；若已学会，提升 `current_mastery +150`，解锁全部已知地图区域、隐藏路径与知识节点，并提升所有探索技能熟练度上限。
- **阅读要求**：所有职业；角色 `known_knowledge_ids` 数量 ≥ 15；基础 `感知 ≥ 16`、智力 `≥ 16`。
- **稀有度**：传说（Legendary）
- **建议投放**：全知者宝库、终极隐藏宝箱、探索者巅峰试炼。

## 书籍内容

这本书没有固定封面，每次翻开都会呈现当前最需要的地形图谱。作者已不可考，但传说中它是所有探索知识的汇总。书中记载了从荒野到异界、从深海到星界的全部探索法则，并能在阅读者脑海中构建一座无限扩展的知识宫殿。中段详细介绍了如何整合已掌握的所有探索技能，使它们相互增幅而非孤立存在。后半部分涉及解锁隐藏世界区域、发现失落的 known_knowledge_ids 与开启终极探索试炼。书末只有一句话："探索的终点不是抵达某个地方，而是承认世界比你想象的更大。"

据说这本书会自己增长页数，每当世界出现一片从未被记录的土地，它的下一页就会悄悄浮现出那片土地的轮廓，等待第一位读者的到来；作者在最后写道，探索者的命运就是被那些空白页不断召唤，直到生命尽头。

他提醒，真正的探索者从不抵达终点，只选择下一次出发。

## 设计意图

作为探索系列的终极传说奖励，整合全系列能力并解锁最终内容，为深度探索型玩家提供明确的终局构筑目标。
