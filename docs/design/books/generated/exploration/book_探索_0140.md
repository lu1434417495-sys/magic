# 《气味追踪：风中的线索》

## 基础信息

- **书籍 ID**：`book_探索_0140`
- **关联技能**：`exploration_scent_tracking`（待新增，标签 `exploration`）
- **使用效果**：阅读后解锁探索技能 `exploration_scent_tracking`；若已学会，提升 `current_mastery +90`，并可在下风向追踪特定目标的移动痕迹。

- **稀有度**：稀有（Rare）
- **建议投放**：猎人公会、德鲁伊长老、高级追踪任务奖励。

## 书籍内容

这本书的书脊浸过某种草药汁液，散发出淡淡的苦涩气息。作者认为气味是追踪中最被低估的线索：它不像足迹那样容易被伪造，也不会像声音那样迅速消散。书中教读者如何识别基本气味层：土壤、植物、动物、燃烧物和异界残留物，并学会判断这些气味的浓度梯度以确定目标距离。中间章节讲解了风对气味传播的影响，以及如何利用"气味走廊"——那些气流集中通过的通道——进行高效追踪。后半本是一位兽王的笔记，他能靠气味分辨出十天前经过的商队中是否有伤员。最末页只有一句话："风把秘密送给你，但你必须先学会停止用鼻子呼吸，改用整个身体去闻。"附录里有一份常见气味在风中传播距离的参考表，作者提醒读者，追踪时永远不要站在目标的下风口太久，否则你会先被发现。

## 设计意图

作为探索系列的嗅觉追踪技能，把气味信息转化为可用的追踪线索，为野外狩猎与目标追踪提供新的感知维度。
