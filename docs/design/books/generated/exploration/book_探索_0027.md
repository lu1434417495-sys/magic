# 《异界气息屏蔽》

## 基础信息

- **书籍 ID**：`book_探索_0027`
- **关联技能**：`exploration_otherworld_veil`（待新增，标签 `exploration`）
- **使用效果**：阅读后解锁探索技能 `exploration_otherworld_veil`；若已学会，提升 `current_mastery +80`，在灰烬交界等异界地图中降低被异界生物主动发现的概率。
- **阅读要求**：无职业限制；基础 `意志 ≥ 12`。
- **稀有度**：史诗（Epic）
- **建议投放**：异界学者、灰烬神殿、隐藏异界任务。

## 书籍内容

这本书的封面没有任何文字，只有一层不断变换色泽的薄膜。作者声称，灰烬交界等异界区域会对入侵者产生排斥，而屏蔽这种排斥的关键在于收敛自身存在感。书中教导读者如何通过调节呼吸、体温与魔力外溢，让自己在异界感知中变得"模糊"。中段详细介绍了在不同异界环境下调整屏蔽强度的方法，过弱会被发现，过强则会影响自己的感知。后半部分涉及如何在屏蔽状态下进行侦察与潜行，以及如何短暂地为队友扩展屏蔽范围。书的最后几页被撕去，只剩一句话："异界从不欢迎客人，所以最好的礼貌就是假装自己不存在。"

书的最后几页虽然被撕去，但残留的纸屑上仍能看到一个反复出现的词：“呼吸，呼吸，再呼吸。”这是异界屏蔽术的核心口诀；作者用不同字体重复书写，仿佛害怕读者在关键时刻忘记。

## 设计意图

作为异界探索的中级防御型技能，承接灰烬边界步行能力，为高风险异界区域提供主动生存策略，服务于后期异界副本。
