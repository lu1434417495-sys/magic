# 《虫洞捷径：异界折跃》

## 基础信息

- **书籍 ID**：`book_探索_0033`
- **关联技能**：`exploration_ashen_blink`（待新增，标签 `exploration`）
- **使用效果**：阅读后解锁探索技能 `exploration_ashen_blink`；若已学会，提升 `current_mastery +90`，在灰烬交界地图中可短距离瞬移至视线内灰烬漩涡，冷却三回合。
- **阅读要求**：法师或盗贼；基础 `智力 ≥ 12` 或 `敏捷 ≥ 12`。
- **稀有度**：史诗（Epic）
- **建议投放**：灰烬裂隙、虚空行者、异界折跃祭坛。

## 书籍内容

这本书的封面像被火烤过一样卷曲，内页画满了灰烬漩涡与空间裂缝的示意图。作者声称，灰烬交界中存在大量不稳定的小型虫洞，掌握规律后可以进行短距离折跃。书中从识别安全漩涡开始，逐步讲解如何计算折跃落点、如何避免被裂缝边缘撕碎，以及如何在折跃后保持方向感。中段详细介绍了折跃的冷却规律与失败后的反噬效果。后半部分涉及战斗应用，包括跨越障碍物、突袭敌人与紧急撤退。书末用烧焦的字体写着："空间不是墙，而是门，但每扇门后不一定都是房间。"

书末附有一张不断变换位置的星图，作者警告：若星图上的某个点开始发红，说明那扇门后面不是通道，而是饥饿，千万不要踏进去；他还提到，有些折跃失败的人会被永远地卡在门与门之间的缝隙里。

他提醒，折跃前要先确认落点是否依然存在。

## 设计意图

作为异界探索的高阶机动技能，将灰烬交界的地形特征转化为战术资源，为法师与盗贼提供独特的空间穿越能力。
