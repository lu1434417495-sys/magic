# 《灵能触须：远程拾取》

## 基础信息

- **书籍 ID**：`book_探索_0031`
- **关联技能**：`exploration_psychic_reach`（待新增，标签 `exploration`）
- **使用效果**：阅读后解锁探索技能 `exploration_psychic_reach`；若已学会，提升 `current_mastery +80`，可在两格外与物品、机关交互，战斗中不消耗移动。
- **阅读要求**：法师优先；基础 `智力 ≥ 11`。
- **稀有度**：史诗（Epic）
- **建议投放**：灵能塔、奥术学院、禁忌图书馆。

## 书籍内容

这本书的封面用灵能水晶粉末压制而成，触碰时会感到轻微的刺痛。作者认为，真正的探索者不应被手臂长度限制，灵能触须是意志的延伸。书中从感知身边物体的能量轮廓开始，逐步教授如何用意念包裹物体并平稳移动。中段讲解了不同材质对灵能传导的影响，金属最容易被牵引，而含有魔力的物品可能产生反噬。后半部分涉及战斗与解谜中的应用，包括远程触发机关、拾取危险物品与在战斗中夺取敌人武器。书末的警告用银色墨水写成："触须伸得太远，可能会碰到不该碰的东西，也可能被它拉住。"

书的封底用灵能墨水写着一行只有在黑暗中才能看见的字：“延伸意志之前，先确认你的意志属于你。”许多初学者因忽略这点而迷失自我；作者还画了一个简单的精神锚定练习，要求每日睡前重复三次。

## 设计意图

作为法师专属史诗探索技能，扩展远程交互与解谜维度，使智力属性在探索玩法中获得独特回报。
