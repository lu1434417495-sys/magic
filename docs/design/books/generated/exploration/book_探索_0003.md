# 《简易陷阱拆解》

## 基础信息

- **书籍 ID**：`book_探索_0003`
- **关联技能**：`exploration_trap_dismantle_basic`（待新增，标签 `exploration`）
- **使用效果**：阅读后解锁探索技能 `exploration_trap_dismantle_basic`；若已学会，提升 `current_mastery +45`，可拆除普通陷阱并回收部分材料。
- **阅读要求**：盗贼或弓箭手优先；基础 `敏捷 ≥ 7`。
- **稀有度**：普通（Common）
- **建议投放**：盗贼公会、废墟入口、工匠摊位。

## 书籍内容

全书由一名自称"活下来的盗贼"撰写，纸张上布满了被针尖刺过的小洞。开篇列出五种最常见的触发机关：压板、绊线、扭力夹与落石，每一种都配有拆解步骤图。作者反复强调，拆陷阱时呼吸比手更重要，手抖会触发机关，而屏住呼吸会让肌肉僵硬。中间章节讲解如何利用现场材料制作临时替代结构，让陷阱保持原样以便反制追兵。后半部分介绍了几种来自古代遗迹的复合型机关，它们往往同时包含物理与魔法触发器。书的最后一页被烧灼过半，只能辨认出一句话："永远不要相信你拆掉的最后一个陷阱，真正的杀招通常藏在它后面。"

扉页上有一道深深的划痕，旁边用不同笔迹写着“第一个人没死，第二个人才死了”，提醒每一位读者尊重机关背后的杀意与耐心；作者还画了一个简单的倒计时符号，意思是拆陷阱时数到十再动手。

## 设计意图

作为盗贼与弓箭手探索分支的前置技能书，将陷阱交互从被动承受转为主动破解，增加地城探索的策略维度。
