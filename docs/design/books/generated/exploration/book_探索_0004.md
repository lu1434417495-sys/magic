# 《夜行军指南》

## 基础信息

- **书籍 ID**：`book_探索_0004`
- **关联技能**：`exploration_night_march`（待新增，标签 `exploration`）
- **使用效果**：阅读后解锁探索技能 `exploration_night_march`；若已学会，提升 `current_mastery +50`，夜间移动不受视野惩罚并小幅提升先手率。
- **阅读要求**：无职业限制；基础 `感知 ≥ 8` 或 `意志 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：守夜人营地、夜间巡逻任务、边境哨站。

## 书籍内容

这本小册子由边境守夜人编写，专门教人如何在月光下安全移动。书中指出，夜行军的关键不是看清道路，而是学会用其他感官补偿视力：听脚步声在狭窄山谷中的回响，闻植物在夜间散发的不同气味，感受地面温度判断是否有水源。作者建议将队伍排成单列，每人只盯住前一人的脚后跟，以减少因黑暗造成的方向偏移。中段详细记录了不同月相下的可见距离与推荐速度，并警告在灰烬交界之夜，月光有时会指路，有时会把人引向深渊。末尾附有一张守夜人手写的夜行口令表，最后一行被涂黑，旁边写着："这句只在没有月亮的夜晚使用。"

作者还提醒，夜间最危险的声音不是敌人的脚步声，而是自己队伍中金属装备不经意的碰撞，一次清脆的撞击足以让埋伏者提前收网，因此他建议夜行军时用布条包裹所有可能发出声响的金属部件。

## 设计意图

强化夜间与低光环境下的探索能力，为夜间遭遇战和潜行任务提供战术支持，与战士、盗贼等职业的夜战流派形成联动。
