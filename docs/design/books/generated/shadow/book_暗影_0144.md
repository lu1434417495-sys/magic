# 《黯淡消逝：濒死脱影》

## 基础信息

- **书籍 ID**：`book_暗影_0144`
- **关联技能**：`shadow_fade_flicker`
- **使用效果**：阅读后解锁 `shadow_fade_flicker`；生命值低于 20% 时自动进入短暂隐身。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `敏捷 ≥ 13`。
- **稀有度**：稀有（Rare）
- **建议投放**：死斗竞技场奖励、刺客逃生大师传承、极限生存任务。

## 书籍内容

黯淡消逝是每位影行者都希望永远不要用上的保命技艺。作者在书中写道，真正的濒死脱影不是主动施放的技巧，而是身体在极度危险时与阴影达成的临时契约。当生命值跌到临界线，周围的阴影会主动向施术者聚拢，掩盖其身影并屏蔽其气息，持续数秒。书中强调，这段时间不是用来反击的，而是用来脱离战斗、寻找掩护或等待治疗的。初学者最常犯的错误是在隐身解除后立即回头再战，结果因为虚弱而更快倒下。后半部分是一份心理训练指南，教导读者如何在濒死时保持冷静，因为恐惧会让阴影契约提前破裂。作者还提醒，一天内只能触发一次黯淡消逝，过度依赖它会让自己变得鲁莽。黯淡消逝触发后，施术者的心跳会暂时变得极轻，难以被追踪。阴影并非虚无，而是光的缺席；修习者要学会在缺席中行动，让自身成为那道被忽略的暗角。

## 设计意图

逆境生存保命技能，用自动触发机制为脆皮职业提供容错，同时限制其反击滥用。
