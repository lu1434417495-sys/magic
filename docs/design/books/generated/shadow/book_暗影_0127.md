# 《虚空掌：隔影推击》

## 基础信息

- **书籍 ID**：`book_暗影_0127`
- **关联技能**：`shadow_palm_void`
- **使用效果**：阅读后解锁 `shadow_palm_void`；掌击可击退敌人并附加暗影伤害。
- **阅读要求**：角色职业标签含 `warrior` 或 `monk`；基础 `力量 ≥ 12`。
- **稀有度**：稀有（Rare）
- **建议投放**：暗影武馆、废弃寺庙藏经阁、近战大师传承。

## 书籍内容

虚空掌把战士的直拳与暗影的侵蚀结合，创造出一种隔着影子发力的打击方式。作者在书中解释，此术的关键不是肌肉爆发，而是让拳头在接触目标前的一瞬间"沉入"自己的影子，再从目标的影子里"浮出"，从而造成内外同时受创的效果。练习时需要在掌心涂抹少量暗影残渣，帮助感知影子的边界。书中警告，虚空掌不能用于没有影子的目标，比如某些灵体或强光下的幻象；同时，施术者自己的影子必须清晰可见，否则力量会在半途散失。后半部分比较了直线推击与弧线推击，前者适合破坏敌人架势，后者适合把敌人推入自己同伴的包围。作者还提醒，连续使用虚空掌会让手掌暂时发黑，需要休息恢复，否则会影响日常生活。曾有武僧在正午练习时失手，将影子打入自己的胸膛，咳出三天黑血才痊愈，此后此术被列为禁练项目。

## 设计意图

让近战职业拥有暗影内力输出，把击退控制与暗影伤害结合，丰富前排技能库。
