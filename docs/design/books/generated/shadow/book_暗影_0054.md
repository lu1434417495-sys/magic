# 《暗刃养护手册》

## 书籍内容

这是一本被油污、药渍和血迹浸透的册子，专门讲述如何让一柄匕首在黑暗中保持最佳状态。前半本讲金属：如何在不见光的房间里用软布与骨灰擦拭，如何在刃口留下极薄的哑光涂层，让反光不会泄露位置。后半本讲毒药：书中列出七种适合阴影作战的毒液，从使人犯困的夜茄汁到阻断呼吸的影蛛囊液，并强调涂毒不是越多越好，过量会让刃面发亮。最特别的一章讨论血的气味管理，建议每次任务后用醋与薄荷叶洗手，因为敌人的猎犬可能比守卫更危险。书脊里夹着一张泛黄的账单，记录着某位匿名顾客二十年间的购刀与维修费用。最后一行是手写的：最贵的不是刀，是让人记住你却又找不到你的成本。书页边缘还画着一柄被擦去多次的匕首轮廓，像是某位学徒的涂鸦。阴影并非虚无，而是光的缺席；修习者要学会在缺席中行动，让自身成为那道被忽略的暗角。

## 设计意图

把毒药与武器维护整合为阴影系资源循环，让玩家在战前准备阶段获得策略收益，同时通过稀有度控制投放节奏。
