# 《暗影打击精要》

## 基础信息

- **书籍 ID**：`book_shadow_0004`
- **关联技能**：`shadow_strike`（待新增，标签 `shadow`）
- **使用效果**：阅读后解锁 `shadow_strike`；对处于目标背后的敌人释放时，伤害提升 `15%` 并附加短暂减速。
- **阅读要求**：角色职业标签含 `rogue` 或 `warrior`；基础 `敏捷 ≥ 11`。
- **稀有度**：普通（Common）
- **建议投放**：近战训练师、暗杀任务奖励、阴影地牢宝箱。

## 书籍内容

暗影打击讲究从敌人视野死角发动一击，其核心不是力量而是落点的精确。书中将人体划分为九个阴影区，分别对应锁骨下、肋侧、膝弯等护甲最难覆盖的位置，每个区域都配有攻击角度与发力节奏的说明。作者特别指出，暗影打击最危险的敌人不是重甲战士，而是同样修习暗影的对手，因为双方都在读取光线的异常。中段收录了十余场暗杀笔记，记录目标在受伤瞬间的肌肉反应，帮助读者预判下一击该补向何处。书中还提醒修习者注意武器上的反光，即使是最轻微的金属光泽也可能在出手前暴露位置。书中还提醒，暗影打击在月光下最难施展，因为银色光线会让阴影边界变得过于清晰。最后一段用红笔圈出：暗影打击的终点不是死亡，而是让敌人再也分不清光源与危险。书中还记载，真正的暗影大师从不依赖单一技能取胜。

## 设计意图

把绕后与死角攻击转化为可学习的战斗技能，鼓励玩家通过走位与时机判断获取额外收益，并为反暗影对抗埋下伏笔。
