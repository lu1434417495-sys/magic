# 《影语低吟：静默沟通》

## 基础信息

- **书籍 ID**：`book_暗影_0142`
- **关联技能**：`shadow_hush_whisper`
- **使用效果**：阅读后解锁 `shadow_hush_whisper`；队伍成员处于同一片阴影中时可进行无声交流。
- **阅读要求**：无职业限制；基础 `意志 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：间谍网络接头点、情报商人、团队协作任务奖励。

## 书籍内容

影语低吟是一本少见的团队辅助型暗影书籍，它不提升个人战斗力，而是让共同潜入黑暗的人能够无声沟通。作者在书中解释，阴影之间是相连的，当一个人把话语"放入"自己脚下的影子时，同处一片阴影网络的同伴就能在心底听到。书中要求使用者学会把意念压缩成极短的词组，因为影语不适合传递复杂信息，最理想的内容是方向、数字与简单的"行动"或"等待"。后半部分是一份使用守则：不要在愤怒或恐惧时使用影语，强烈情绪会让话语在阴影中失真成噪音；也不要在圣光范围内尝试，因为那里的阴影过于稀薄。作者还提醒，影语的有效范围约为十米，超出后信息会支离破碎，因此队伍不能太分散。长时间的影语交流会让使用者感到轻微头晕，需要适时休整。阴影并非虚无，而是光的缺席；修习者要学会在缺席中行动，让自身成为那道被忽略的暗角。

## 设计意图

团队协作战术支持，把暗影机制延伸至多人配合，鼓励潜行队伍的信息共享。
