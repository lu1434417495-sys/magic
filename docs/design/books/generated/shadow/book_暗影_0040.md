# 《暗影闪烁：目光所及的影子》

## 基础信息

- **书籍 ID**：`book_shadow_0040`
- **关联技能**：`shadow_blink`（待新增，标签 `shadow`）
- **使用效果**：阅读后解锁短程瞬移技能 `shadow_blink`；落点必须在视野内的阴影格中，落地后短暂提升闪避。
- **阅读要求**：角色职业标签含 `rogue`、`mage` 或 `assassin`；基础 `敏捷 ≥ 12` 或 `智力 ≥ 12`。
- **稀有度**：稀有（Rare）
- **建议投放**：黑市商人、稀有宝箱、暗影导师任务。

## 书籍内容

暗影闪烁是短距离的瞬间移动，落点必须位于施术者视野内的阴影中。书中强调闪烁不是瞬移，而是把两点之间的空间折叠成一条暗影通道，因此通道中不能出现强光。作者建议提前布置光源或让队友熄灭灯火，以创造更多可用落点。中段有一章讨论闪烁的副作用：频繁使用会让施术者的影子出现短暂延迟，从而暴露真实位置。修习者需要训练在突进过程中选择落点，因为慌乱时往往会闪到更危险的区域。书中还提到，暗影闪烁可以携带一名队友同步移动，但前提是两人的影子必须提前重叠。闪烁后落地的瞬间会出现短暂僵直，熟练者会利用这段时间观察并准备下一次移动。书末用烧焦的字迹写着：别闪进你看不见尽头的影子。作者最后提醒，暗影技艺的精进不在一日之间。书中还强调，修习者必须学会在光明与黑暗之间找到平衡。

## 设计意图

为暗影系提供视野+阴影双重限制的短程位移，强调落点规划与资源管理，避免瞬移技能过度泛用。
