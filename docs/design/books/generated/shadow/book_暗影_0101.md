# 《影息入门：薄幕呼吸》

## 基础信息

- **书籍 ID**：`book_暗影_0101`
- **关联技能**：`shadow_breath_veil`
- **使用效果**：阅读后学会 `shadow_breath_veil`（`practice_tier = basic`），提升潜行状态下耐力恢复速度 10%。
- **阅读要求**：无职业限制；基础 `敏捷 ≥ 6` 或 `意志 ≥ 6`。
- **稀有度**：普通（Common）
- **建议投放**：新手镇旧书店、盗贼公会入门任务奖励、黑市地摊。

## 书籍内容

薄幕呼吸法是暗影系修行者公认的最安全入门，也是大多数影行者学习的第一课。书中要求练习者在黄昏时分站在室内外交界处，让一半身体被光照亮，另一半留在阴影里，然后以极慢的速度吸气，想象阴影像薄纱一样贴着皮肤滑入肺中。作者强调，初学者最常犯的错误是"用力去抓影子"，结果导致头晕、恶寒甚至短暂失明。真正的影息不是吞噬黑暗，而是让自己成为黑暗愿意停留的容器。书中详细记录了十二种不同的呼吸节奏，分别对应晴朗、多云、雨夜和灰烬交界的特殊天象。每种节奏旁都画有一个小小的警示符号，提醒读者在体力不支或情绪波动时必须停止练习。最后一页只有一句话：当你能感觉到自己的影子在呼吸时，才算真正读完这本书。阴影并非虚无，而是光的缺席；修习者要学会在缺席中行动，让自身成为那道被忽略的暗角。

## 设计意图

作为暗影系 101 号起点，承担"阴影作为可感知介质"的基础认知，为后续高阶影行、影袭技能提供资源恢复支撑。
