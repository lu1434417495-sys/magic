# 《潜行与光的边界》

## 书籍内容

作者开篇便挑战常识：潜行不是躲进黑暗，而是学会站在光与暗的交界处。边界处的亮度差异会欺骗眼睛，让观察者的瞳孔来不及调整焦距。书中把战场光源分为三类：硬光源制造清晰影子，软光源让影子模糊，而多重光源则会把影子切碎成可用的掩体。站在两个光源的中间线上，你会有两个影子，每个影子都不完整，敌人无法判断哪个是真人。后半本给出十六种常见地形的边界位置：门廊与烛台之间、月光照不到的台阶边缘、火把摇曳时的明暗交替带。作者建议随身携带一根细线，用来测量光锥角度。最后一章只有一句话，用红墨水写成：最危险的地方不是黑暗，是你自以为已经离开光明的那一步。书脊内侧贴着一张被烧掉一半的地图，上面标注了几个不知名城市的地下暗道。阴影并非虚无，而是光的缺席；修习者要学会在缺席中行动，让自身成为那道被忽略的暗角。

## 设计意图

以低成本通用技能引入“光影边界”机制，让非盗贼职业也能体验阴影走位，为战棋地图的光照设计提供玩法反馈。
