# 《夜瞳：低光视觉训练》

## 基础信息

- **书籍 ID**：`book_暗影_0111`
- **关联技能**：`shadow_eyes_night`
- **使用效果**：阅读后解锁 `shadow_eyes_night`；在夜间或低光环境下命中提升 10%。
- **阅读要求**：无职业限制；基础 `感知 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：猎人小屋书架、夜间巡逻任务奖励、老兵游侠。

## 书籍内容

夜瞳的训练从闭眼开始。作者认为，人在黑暗中之所以看不见，不是因为光太少，而是因为眼睛还在等待白昼。书中要求读者先用黑布蒙眼，在熟悉房间里靠记忆与听觉行走三日，然后逐渐降低室内亮度，让瞳孔学会在微弱光线中"抓取"轮廓而非细节。中段介绍了暗适应的生理节奏，提醒读者进入黑暗后不要立即四处张望，而应让视线停留在稍偏中心的位置，因为视网膜边缘对弱光更敏感。后半本列出了常见干扰：火光会让人暂时失明，闪电会让阴影暂时凝固，而灰烬交界某些区域的暗则会"吞噬"声音，让夜瞳使用者感到一种反常的寂静。作者建议初学者在完全熄灯前先学会面对一盏烛火。夜瞳的最终目标是能在没有一丝月光的山洞里辨别五米内的轮廓。阴影并非虚无，而是光的缺席；修习者要学会在缺席中行动，让自身成为那道被忽略的暗角。

## 设计意图

提供全职业可用的环境适应性，让低光场景从纯粹的劣势转为可利用的战术条件。
