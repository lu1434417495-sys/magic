# 《蚀光突刺：影锋穿刺》

## 基础信息

- **书籍 ID**：`book_暗影_0140`
- **关联技能**：`shadow_lunge_eclipse`
- **使用效果**：阅读后解锁 `shadow_lunge_eclipse`；沿直线突刺，对路径上处于阴影中的敌人造成伤害。
- **阅读要求**：角色职业标签含 `warrior` 或 `assassin`；基础 `力量 ≥ 12` 或 `敏捷 ≥ 12`。
- **稀有度**：稀有（Rare）
- **建议投放**：古代剑冢、影卫试炼场、高阶突进任务奖励。

## 书籍内容

蚀光突刺把直线冲锋与暗影路径结合，创造出一种只有在阴影中才能发挥全力的攻击方式。作者认为，直线突进最大的风险是可预测性，而暗影能让这条直线变得不可见。施术者需要在突刺前锁定路径上的阴影区域，让身体在移动过程中始终被影子覆盖，这样敌人既无法提前看到攻击者，也无法准确判断突刺距离。书中提供了几种起手姿势：剑士适合低姿突刺，刺客适合高跃下刺，而双持者则可以在突刺中途切换攻击目标。后半部分讨论了与队友的配合：正面吸引火力的人制造阴影，突刺者借助这些阴影完成侧翼打击。作者警告，突刺距离过长会让施术者在终点处失去阴影掩护，暴露在敌人反击之下。蚀光突刺的终点最好选在另一片阴影中，以便继续隐匿行踪。阴影并非虚无，而是光的缺席；修习者要学会在缺席中行动，让自身成为那道被忽略的暗角。

## 设计意图

直线范围突进技能，把冲锋路径与光照条件绑定，鼓励团队制造暗影走廊。
