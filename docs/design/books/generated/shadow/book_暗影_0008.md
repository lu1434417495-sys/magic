# 《暗影烈焰：冷与热的残骸》

## 基础信息

- **书籍 ID**：`book_shadow_0008`
- **关联技能**：`shadow_flame`（待新增，标签 `shadow`）
- **使用效果**：阅读后解锁范围伤害技能 `shadow_flame`；命中区域会短暂熄灭普通光源并造成持续暗影伤害。
- **阅读要求**：角色职业标签含 `mage` 或 `warlock`；基础 `智力 ≥ 12`。
- **稀有度**：稀有（Rare）
- **建议投放**：阴影法师塔、黑市商人、传说级宝箱。

## 书籍内容

暗影烈焰是一种看起来像火、摸起来像冰的黑色能量，它焚烧的不是血肉而是光芒。书中记载，被暗影烈焰舔舐过的区域会短暂陷入绝对黑暗，连火把都会熄灭数秒。施术者需要在掌心同时凝聚热与冷两种对立感知，让它们在失衡边缘相撞，才能点燃这团矛盾的火焰。作者警告，暗影烈焰对施术者自己的视力同样有害，许多初学者在释放后会被自己的黑暗吞没方向感。书中还介绍了一种练习方式：在完全黑暗中点燃一小团暗影烈焰，然后尝试用它照亮自己的手掌而不灼伤皮肤，以此训练对能量输出的精细控制。作者认为，暗影烈焰的真正价值不在于烧伤，而在于它能让战场暂时回归原始的黑暗。最后章节记录了一种高级用法：把暗影烈焰附着在武器上，使每一次斩击都留下一道短暂失明的伤口。

## 设计意图

为暗影法师提供兼具伤害与战场控制能力的范围技能，通过熄灭光源强化其他暗影技能，体现"暗影技能互相增益"的设计主题。
