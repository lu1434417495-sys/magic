# 《暗影汲取：向黑夜借取》

## 基础信息

- **书籍 ID**：`book_shadow_0029`
- **关联技能**：`shadow_leech`（待新增，标签 `shadow`）
- **使用效果**：阅读后解锁环境恢复技能 `shadow_leech`；在阴影格中每回合结束时恢复少量 `MP` 或 `AURA`。
- **阅读要求**：角色职业标签含 `mage` 或 `rogue`；已解锁 `MP` 或 `AURA` 资源链。
- **稀有度**：稀有（Rare）
- **建议投放**：黑市商人、冥想导师、阴影遗迹宝箱。

## 书籍内容

暗影汲取与环境中的黑暗建立连接，缓慢恢复施术者的魔力或体力。书中解释，这种恢复不是无限的，一片区域内的暗影能量被汲取殆尽后会需要很长时间才能复原。作者建议在战斗间隙或夜间使用，并避免在同一个地点反复汲取，否则会导致当地出现长期的光亮异常。中段有一章比较不同环境的效率：废墟、森林和洞穴效率最高，沙漠与雪地几乎无效。修习者需要学会辨别暗影能量的浓淡，就像品酒师辨别酒的层次。书中还提到，暗影汲取有时会附带环境记忆，例如从战场的阴影中汲取时，修习者可能会听见过去战斗的回声。长期在同一地点汲取暗影能量会让当地植物枯萎，因此暗影修习者常被视为不祥之人。书末附有一名隐士的笔记：不要只索取，有时你也要把自己的影子放回去一点。

## 设计意图

将暗影系与冥想/修炼资源系统连接，提供环境驱动的资源恢复，鼓励玩家关注战场中的阴影格与昼夜/地形变化。
