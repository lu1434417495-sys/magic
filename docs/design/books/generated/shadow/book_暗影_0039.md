# 《暗影收割：替黑暗收账》

## 基础信息

- **书籍 ID**：`book_shadow_0039`
- **关联技能**：`shadow_reap`（待新增，标签 `shadow`）
- **使用效果**：阅读后解锁终结技能 `shadow_reap`；目标生命值越低、身上暗影 debuff 越多，伤害越高。
- **阅读要求**：角色职业标签含 `rogue`、`assassin` 或 `warlock`；基础 `敏捷 ≥ 12` 或 `智力 ≥ 12`。
- **稀有度**：史诗（Epic）
- **建议投放**：黑市商人、暗杀大师传承、史诗级宝箱。

## 书籍内容

暗影收割是一记针对低血量目标的终结技，敌人体内残留的暗影能量越多，收割伤害越高。书中解释这一技能需要施术者感知目标体内的暗伤，像农夫感知麦穗的成熟度一样判断时机。作者建议在连续使用其他暗影技能削弱对手后再释放收割，单独使用往往效果平平。中段有一章记录不同敌人的暗伤阈值，从普通士兵到魔兽各不相同。修习者常被要求在战场上保持冷静，因为过早收割会暴露意图，过晚则可能错失机会。书中还提到，暗影收割在击杀目标后会将敌人的影子暂时撕裂，形成一个可供施术者短暂利用的阴影格。收割在敌人影子最浓重时伤害最高，因此黄昏与黎明前的战场最适合施展此技。书末附有一名收割者的话：我们不是杀手，只是替黑暗收账的人。书末还列有一份禁忌清单，提醒修习者哪些情况下绝不可使用此技。

## 设计意图

作为暗影系核心终结技，鼓励玩家通过 debuff 叠加与血量判断制造斩杀窗口，强化连招成就感与职业特色。
