# 《暮影漫步：边界穿行》

## 基础信息

- **书籍 ID**：`book_暗影_0147`
- **关联技能**：`shadow_stride_twilight`
- **使用效果**：阅读后解锁 `shadow_stride_twilight`；在黄昏地带可自由穿行部分障碍。
- **阅读要求**：角色职业标签含 `rogue` 或 `ranger`；基础 `敏捷 ≥ 13`。
- **稀有度**：稀有（Rare）
- **建议投放**：黄昏林地遗迹、边境探索任务奖励、游侠隐士手抄本。

## 书籍内容

暮影漫步是一种特殊地形穿越能力，让修习者在黄昏光线制造的模糊边界中获得超乎寻常的机动性。作者认为，黄昏时分的障碍物会同时存在"在"与"不在"两种状态：一道围栏在夕阳下投出长影，而施术者可以借助影子的延伸暂时绕过实体。书中要求练习者先学会判断哪些障碍物的影子足够长、足够浓，然后以特定角度跨入影中，再从影子的另一端迈出。初学者常犯的错误是试图在正午或深夜使用此术，那时阴影要么太短要么太硬，都会导致穿行失败。后半部分是一份各地黄昏时长表，帮助旅行者规划路线。作者警告，若穿行时受到攻击，身体可能会卡在障碍物中，造成致命伤害，因此穿行前必须确认周围没有敌人。暮影漫步穿行失败后，施术者会短暂眩晕，需要同伴掩护。阴影并非虚无，而是光的缺席；修习者要学会在缺席中行动，让自身成为那道被忽略的暗角。

## 设计意图

特殊地形穿越能力，进一步绑定时间系统与移动机制，提供独特的探索与逃生路径。
