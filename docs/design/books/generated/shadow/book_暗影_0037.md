# 《暗影护盾：流动的暗墙》

## 基础信息

- **书籍 ID**：`book_shadow_0037`
- **关联技能**：`shadow_shell`（待新增，标签 `shadow`）
- **使用效果**：阅读后解锁防御技能 `shadow_shell`；举盾期间减少来自正面的物理与魔法伤害，但背后无效。
- **阅读要求**：角色职业标签含 `warrior` 或 `rogue`；基础 `意志 ≥ 11`。
- **稀有度**：稀有（Rare）
- **建议投放**：黑市商人、守护任务奖励、阴影要塞宝箱。

## 书籍内容

暗影护盾是一面由流动黑暗构成的盾牌，能偏转物理攻击并吸收部分魔法伤害。书中解释护盾不是静止的，它需要跟随敌人的攻击方向旋转，始终保持最厚的一面迎向威胁。作者强调暗影护盾对钝器与重击效果较差，因为黑暗会被冲击力震散。中段有一章讲授如何边移动边维持护盾，要求修习者把一半注意力放在脚步上，另一半放在感知攻击来源。修习者常与战士对练，在无数次被击倒中学习偏转的角度。书中还提到，暗影护盾在吸收过多伤害后会暂时变薄，此时需要后撤到阴影中让其恢复。护盾在正面受到攻击时会变薄，但只要有阴影补充，它就能在数秒内恢复原状。书末附有一名守护者的信条：我持盾不是为了挡住光明，是为了在光明熄灭后还能站着。书中最后写道：影子是你的镜子，也是你最忠实的敌人。

## 设计意图

为前排职业提供方向型防御选择，通过"正面减伤、背后暴露"的设计强化站位意识，补充传统盾牌的战斗体验。
