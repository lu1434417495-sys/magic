# 《闪烁移位：残像脱战》

## 基础信息

- **书籍 ID**：`book_暗影_0125`
- **关联技能**：`shadow_shift_flicker`
- **使用效果**：阅读后解锁 `shadow_shift_flicker`；脱离战斗状态时进行一次短距离瞬移。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `敏捷 ≥ 13`。
- **稀有度**：稀有（Rare）
- **建议投放**：影舞者传承试炼、紧急撤离任务奖励、高阶潜行导师。

## 书籍内容

闪烁移位是影舞者一脉的招牌脱战技艺。作者在书中写道，真正危险的瞬间不是被发现，而是被发现后犹豫的那一拍。此术的原理是在敌人视网膜上留下一个残像，同时自己的身体借助阴影折叠到短距离内的另一处暗角。书中详细拆解了动作节奏：先做出一个明显的后撤假动作，在敌人视线追随残像的瞬间完成真实位移。初学者最常失败的原因是移动太远，导致残像与本体之间出现可被察觉的空隙。后半部分提供了训练方法：在挂满布帘的房间里练习，让自己每次闪烁后都能立刻躲入另一块阴影。附录里只有一句话：残像不是欺骗，是馈赠，但馈赠太多会让对方发现规律，从而预判你的落点。高手会在敌人眨眼的那一瞬间完成闪烁，让残像完美承接视线。阴影并非虚无，而是光的缺席；修习者要学会在缺席中行动，让自身成为那道被忽略的暗角。

## 设计意图

强化生存与机动性，把脱战机制与视觉残像结合，制造戏剧性的逃脱体验。
