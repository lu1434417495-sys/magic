# 《暗影穿刺：最薄的黑暗》

## 基础信息

- **书籍 ID**：`book_shadow_0036`
- **关联技能**：`shadow_puncture`（待新增，标签 `shadow`）
- **使用效果**：阅读后解锁破甲技能 `shadow_puncture`；对持有护盾或重甲的敌人造成额外穿透伤害。
- **阅读要求**：角色职业标签含 `rogue`、`assassin` 或 `mage`；基础 `敏捷 ≥ 12` 或 `智力 ≥ 12`。
- **稀有度**：稀有（Rare）
- **建议投放**：黑市商人、破甲训练任务、阴影遗迹宝箱。

## 书籍内容

暗影穿刺将黑暗集中于一点，贯穿敌人的护甲与魔力护盾。书中强调穿刺的穿透力来自极致的压缩，因此施法前需要一段短暂蓄力，这段时间内不能移动。作者建议由队友控制目标后再释放，或在敌人被其他技能牵制时使用。中段用图示说明不同厚度护甲的穿刺路径，强调要找接缝、铆钉与活动关节处的弱点。修习者需要通过冥想训练精神集中度，因为任何杂念都会让穿刺在命中前散开。书中还提到，暗影穿刺在命中后会留下一个细小暗影孔洞，使后续同类型伤害更容易穿透同一位置。穿刺在命中后会留下短暂暗影通道，使后续同类型攻击更容易命中同一位置。书末用银粉写着：最薄的黑暗，能刺穿最厚的盔甲。修习者需要反复观摩自己的影子，直到能预判它的下一步动作。书中还记载，真正的暗影大师从不依赖单一技能取胜。

## 设计意图

为暗影系提供针对高防御目标的破甲手段，通过蓄力与专注要求强化其战术价值，丰富反制重甲/护盾策略。
