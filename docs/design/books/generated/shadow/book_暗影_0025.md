# 《暗影裹尸布：延缓死亡的布》

## 基础信息

- **书籍 ID**：`book_shadow_0025`
- **关联技能**：`shadow_shroud`（待新增，标签 `shadow`）
- **使用效果**：阅读后解锁急救技能 `shadow_shroud`；对濒死队友使用时，延缓其死亡数回合，期间牧师治疗可将其救回。
- **阅读要求**：角色职业标签含 `rogue`、`priest` 或 `mage`；基础 `意志 ≥ 11`。
- **稀有度**：稀有（Rare）
- **建议投放**：黑市商人、阴影牧师任务、稀有宝箱。

## 书籍内容

暗影裹尸布覆盖在濒死者身上，能暂时封印其灵魂，延缓死亡的到来。书中说明这并非治疗，而是把死亡过程藏进阴影，为救治争取时间。作者强调裹尸布对生者同样有效，被覆盖者会感受到体温流失、呼吸变慢，仿佛提前体验死亡。修习者需要克服对死亡的恐惧，因为裹尸布会放大使用者自身的死亡焦虑。中段记载了几种仪式用法，例如在战场上为重伤员覆盖后再由牧师接手治疗。书中还提到，裹尸布无法阻止灵魂被光明魔法强制驱散，因此在面对圣职者敌人时，需优先保护被覆盖者。裹尸布覆盖时间越长，被覆盖者醒来后失去的近期记忆越多，有时这反而是仁慈。书末用苍白字迹写着：裹尸布不会救人，它只是让死亡走得慢一些，好让你来得及说声再见。作者认为，理解影子的本质比单纯模仿招式更重要。

## 设计意图

为暗影系提供独特的战场急救支援，强调"延缓而非治愈"，与牧师治疗体系形成互补，丰富团队战术选择。
