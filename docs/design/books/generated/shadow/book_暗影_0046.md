# 《暗影陷阱：等他们自己来》

## 基础信息

- **书籍 ID**：`book_shadow_0046`
- **关联技能**：`shadow_trap`（待新增，标签 `shadow`）
- **使用效果**：阅读后解锁布置技能 `shadow_trap`；敌人触发后受到暗影伤害并暴露视野，持续数回合。
- **阅读要求**：角色职业标签含 `rogue`、`ranger` 或 `assassin`；基础 `敏捷 ≥ 11`。

- **建议投放**：黑市商人、低级宝箱、猎手任务奖励。

## 书籍内容

暗影陷阱是在阴影中布置的触发式陷阱，一旦踩中便会释放暗影束缚或尖刺。书中指出陷阱的威力取决于布置时注入的暗影能量，但能量越多越容易被感知。作者建议把陷阱设在必经之路上，并用环境阴影掩盖其魔力波动。中段有一章讨论陷阱的伪装技巧，例如在陷阱上方放置落叶、碎石或敌人的尸体，以降低被发现几率。修习者需要记录自己布置的每一个陷阱位置，否则连自己都可能忘记。书中还提到，暗影陷阱可以被特意设计为连锁触发，当一个陷阱被踩中时，附近的其他陷阱会同时进入待命状态。陷阱在被发现后仍可引爆，但威力会大打折扣，因此伪装比触发机制本身更重要。书末写着：最好的陷阱不是最强的，是让敌人以为那里没有陷阱。修习者需要反复观摩自己的影子，直到能预判它的下一步动作。

## 设计意图

为暗影系提供预判型伤害陷阱，强调隐蔽性与位置选择，丰富探索与战斗中的伏击杀敌与视野控制手段。
