# 《暗影诅咒：让影子背叛主人》

## 基础信息

- **书籍 ID**：`book_shadow_0014`
- **关联技能**：`shadow_curse`（待新增，标签 `shadow`）
- **使用效果**：阅读后解锁减益技能 `shadow_curse`；受诅目标每回合受到暗影伤害，并降低治疗效率。
- **阅读要求**：角色职业标签含 `mage` 或 `warlock`；基础 `智力 ≥ 12`。
- **稀有度**：稀有（Rare）
- **建议投放**：黑市商人、诅咒学者任务、阴影遗迹宝箱。

## 书籍内容

暗影诅咒不像元素诅咒那样灼烧皮肉，而是让目标逐渐被自己的影子排斥。书中描述，受诅者的影子会开始滞后、扭曲，最终站立不稳，仿佛脚下的地面不再承认他的重量。施术者需要获取目标的随身物品或几滴血液，将其埋入暗处作为诅咒的锚点。作者强调诅咒生效需要时间，期间需不断用暗影能量滋养锚点，一旦中断便前功尽弃。书中还提到，在月蚀之夜施展暗影诅咒效果会翻倍，但施术者自己也会受到轻微反噬，表现为连续数日做梦看见自己的影子。诅咒最可怕之处在于，目标往往会在数日后才开始察觉自己的影子已经不属于自己。书末收录了七个失败的案例，其中最常见的原因是施术者无法忍受缓慢的反馈而提前现身。最后一行小字写着：诅咒是耐心的影子，你先认输，它才生效。

## 设计意图

为暗影系提供持续伤害与减疗机制，强调准备阶段与资源投入，契合战棋 RPG 中对高价值目标的持久削弱战术。
