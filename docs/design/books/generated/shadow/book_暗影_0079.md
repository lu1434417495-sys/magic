# 《暗影回溯》

## 基础信息

- **书籍 ID**：`book_shadow_0079`
- **关联技能**：`shadow_traceback`（待新增，标签 `shadow`）
- **使用效果**：阅读后学会技能 `shadow_traceback`；若已学会，则提升 `current_mastery +130`，并延长可读取的影子记忆时间至 `6` 小时。
- **阅读要求**：角色职业标签含 `rogue`、`ranger` 或 `shadowmancer`；基础 `感知 ≥ 11`。
- **稀有度**：稀有（Rare）
- **建议投放**：猎手营地、侦探事务所、暗影追踪者公会。

## 书籍内容

追踪者看脚印，暗影回溯者看影子。《暗影回溯》教授如何通过现场残留的影子碎片，还原过去数小时内发生过的事情。每一道被惊扰的影子都会留下微弱的涟漪，像水面的波纹一样逐渐消散；施术者通过特殊的冥想状态，可以读取这些涟漪中的情绪与动作。书中把影子记忆分为热影与冷影：热影来自激烈的战斗或强烈的恐惧，能保存更久；冷影则来自日常行走，几息之间就会散去。最实用的章节是反向追踪：当敌人试图误导你时，他的影子往往比脚印更诚实。最后一页贴着一张皱巴巴的地图，上面用炭笔圈出多个地点，配文：影子不会说谎，但读取它的人会。地图的边缘被烧掉一角，恰好遮住了标有起点的那座城市名。烧焦的纸边还残留着一丝烟火气味，提醒着这张地图曾经的遭遇。阴影并非虚无，而是光的缺席；修习者要学会在缺席中行动，让自身成为那道被忽略的暗角。

## 设计意图

为探索与侦查玩法提供阴影主题的信息恢复技能，让战场痕迹成为叙事与战术线索，增强玩家的调查体验。
