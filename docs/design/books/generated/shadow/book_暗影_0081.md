# 《影杀四式》

## 书籍内容

这本书用四幅简单的图概括了暗影杀戮的四个瞬间：潜、贴、刺、离。《影杀四式》把每个动作都拆成呼吸、重心与视线的配合。潜是进入敌人感知边缘而不触发警觉；贴是在最后一步把身体与目标的影子重合，让对方的本体感觉无法察觉外来体温；刺是选择最短路径穿过护甲缝隙；离则是在出血被发现之前退出原来的光线环境。作者强调四式必须连成一气，任何一式停顿都会让整套动作从艺术变成搏斗。书中每式后面都有一段口诀，例如贴如衣，刺如叹。最后一页用炭笔画了四个人形，分别处于四式的极端姿态，正中一行小字：四式之外，还有一式，叫做不杀。小字下方有一枚血指印，旁边标注：此页由第七代宗师补完。血指印的边缘已经发褐，说明它留下的时间远比印刷日期更早。阴影并非虚无，而是光的缺席；修习者要学会在缺席中行动，让自身成为那道被忽略的暗角。

## 设计意图

为暗杀职业提供可连招的核心技能，把单次背刺扩展为完整战术流程，同时以“不杀”选项保留角色扮演空间。
