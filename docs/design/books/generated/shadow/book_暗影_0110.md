# 《幽暗格挡：以影卸力》

## 基础信息

- **书籍 ID**：`book_暗影_0110`
- **关联技能**：`shadow_parry_gloom`
- **使用效果**：阅读后解锁 `shadow_parry_gloom`；若已学会，成功格挡后闪避技能冷却减少 1 秒。
- **阅读要求**：角色职业标签含 `warrior` 或 `rogue`；基础 `力量 ≥ 10` 或 `敏捷 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：佣兵营地教官、暗影决斗场奖励、遗迹战士雕像下。

## 书籍内容

幽暗格挡挑战了人们对暗影的固有认知：阴影不只是躲避之处，也可以成为卸力的缓冲层。作者在书中提出"影子不是空的，而是软的"，一个熟练掌握幽暗格挡的战士能在武器相接的瞬间让阴影包裹住接触点，把敌人的直线冲击转化为斜向滑移。书中用大量图示讲解手腕角度与肘部下沉，强调格挡后不要立即反击，而是借势滑入对方盲区。后半部分对比了盾牌格挡与空手格挡的差异，认为后者更适合配合暗影步法，因为盾牌本身会制造反光与声响。作者还提到，幽暗格挡对重武器的卸力效果优于轻武器，因为重武器的冲击更有"实体"可被阴影分流，练习时可以从同伴的木棍开始逐步升级。练习时可以从同伴的慢速攻击开始，逐步适应暗影包裹撞击的感觉。阴影并非虚无，而是光的缺席；修习者要学会在缺席中行动，让自身成为那道被忽略的暗角。

## 设计意图

让前排职业也能利用暗影机制防御，把格挡从被动减伤转为主动创造反击窗口。
