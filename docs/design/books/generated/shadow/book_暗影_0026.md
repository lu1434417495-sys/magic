# 《暗影尖刺：从地面长出荆棘》

## 基础信息

- **书籍 ID**：`book_shadow_0026`
- **关联技能**：`shadow_spike`（待新增，标签 `shadow`）
- **使用效果**：阅读后解锁陷阱/控制技能 `shadow_spike`；敌人在移动中触发尖刺时，本回合行动被迫终止。
- **阅读要求**：角色职业标签含 `rogue` 或 `mage`；基础 `敏捷 ≥ 10` 或 `智力 ≥ 10`。
- **稀有度**：普通（Common）
- **建议投放**：黑市商人、低级宝箱、盗贼公会训练奖励。

## 书籍内容

暗影尖刺从地面或墙面突然刺出，形成短距离的区域控制。书中指出尖刺的伤害并不致命，真正的威胁在于打断敌人的架势与移动节奏。作者建议在敌人冲刺、跳跃或蓄力时释放，因为动态中的目标最难调整重心。中段用图示说明三种尖刺形态：直刺用于单体拦截，斜刺封锁路线，环形刺则把目标困在原地。修习者需要学会感知地面的阴影纹理，因为尖刺只能从已有影子的边缘生长出来。书中还提到，在狭窄走廊中，尖刺可以借助墙面反射造成二次伤害，但施术者必须精确计算角度，否则也会误伤自己。尖刺在连续释放时会逐渐变弱，因为同一片地面的阴影能量无法被无限抽取。书末附有一名刺客的心得：最好的尖刺，是敌人自己踩上去的尖刺。修习者需要反复观摩自己的影子，直到能预判它的下一步动作。

## 设计意图

为暗影系提供低成本打断与地形控制，强调时机预判与阴影格利用，丰富战棋中的走位压制手段。
