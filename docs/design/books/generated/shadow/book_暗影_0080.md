# 《夜幕宣言》

## 书籍内容

黑暗中的领袖不需要火炬，只需要让追随者相信夜晚属于他们。《夜幕宣言》是一本关于阴影领导力的手册，教导如何在夜间行动、情报网络与秘密结社中建立权威。书中提出三条原则：第一，永远比部下更早知道危险；第二，把每次任务的成功归功于团队，失败独自承担；第三，不要在光明下做出承诺，因为光明会记住一切。后半本记录了七篇经典的夜间演说草稿，从简短的战前动员到复杂的背叛宣告，每篇都标注了语调、停顿与光影配合。最后一页只有一句话，用银粉写成：让他们在黑暗中听见你的声音，却看不见你的嘴唇。银粉在完全黑暗中会发出微弱的冷光，仿佛是专门给看不见的人读的。纸张边缘有些卷曲，显然曾被无数次在黑暗中摩挲。阴影并非虚无，而是光的缺席；修习者要学会在缺席中行动，让自身成为那道被忽略的暗角。

## 设计意图

把阴影主题延伸至团队指挥与阵营领导，让非前排职业也能通过信息与士气影响战局，丰富多人战术层次。
