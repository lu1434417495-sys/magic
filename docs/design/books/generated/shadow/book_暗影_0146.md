# 《虚空爪：暗影擒拿》

## 基础信息

- **书籍 ID**：`book_暗影_0146`
- **关联技能**：`shadow_talon_void`
- **使用效果**：阅读后解锁 `shadow_talon_void`；擒抱或抓取敌人时附加暗影禁锢效果。
- **阅读要求**：角色职业标签含 `warrior` 或 `monk`；基础 `力量 ≥ 13`。
- **稀有度**：稀有（Rare）
- **建议投放**：暗影武僧寺院、地下拳场冠军奖励、近战控制任务。

## 书籍内容

虚空爪把擒拿术与暗影禁锢结合，让近战职业在贴身控制时获得额外的束缚能力。作者在书中描述，施术者需要在抓住敌人的瞬间让五指附近的影子像爪子一样收紧，把对方关节与影子暂时锁在一起。这种禁锢不依赖蛮力，因此即便面对体型更大的对手也能生效数秒。书中详细讲解了三种擒拿姿势与虚空爪的配合：正面锁喉适合压制施法者，背后环抱适合控制战士，腋下反折则适合快速解除对方武器。后半部分讨论了能量消耗：每次使用虚空爪都会消耗一部分手部影子，连续使用会导致手掌发冷、动作变慢，需要回到阴影中恢复。作者提醒，虚空爪对没有影子的敌人无效，使用时要注意站位，确保自己和目标都有清晰的影子。虚空爪的禁锢效果在目标挣扎越剧烈时反而越牢固。

## 设计意图

强化近战控制与单点压制，把擒拿从物理对抗升级为带魔法效果的硬控手段。
