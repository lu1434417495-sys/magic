# 《深渊锁链：暗影禁锢》

## 基础信息

- **书籍 ID**：`book_暗影_0115`
- **关联技能**：`shadow_chains_abyss`
- **使用效果**：阅读后解锁 `shadow_chains_abyss`；若已学会，禁锢持续时间延长 1 秒。

## 书籍内容

深渊锁链是高阶暗影控场技艺，学习它需要先接受一个令人不安的前提：脚下的影子并不属于你，而是某个更古老存在的触须。作者在书中描述了完整的施法流程：先以自身影子为锚点，向目标影子投射一条细线，然后念出书中用褪色墨水写成的三段咒语，同时让意识沉入最深的恐惧。书中反复强调，施术者不能抗拒恐惧，而要学会 riding it—— riding 这个词被保留原文，因为译者找不到合适的词。锁链形成后，目标的双脚会与自己的影子融为一体，任何挣扎都会让锁链勒得更紧。附录里有一页被撕掉，只留下一句警告：不要让锁链存在超过七次心跳，否则那古老存在会顺着锁链看向你，甚至舔舐你的影子。深渊锁链的咒语并非人类语言，念错一个音节就可能让锁链转头锁住施术者自己，因此高阶法师会在施术前用银针刺破舌尖以保持清醒。

## 设计意图

高阶控场技能，服务法师型暗影构筑，通过恐惧主题深化暗影魔法的代价与风险。
