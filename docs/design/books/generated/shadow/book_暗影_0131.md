# 《影幕：遮蔽视野》

## 基础信息

- **书籍 ID**：`book_暗影_0131`
- **关联技能**：`shadow_shroud_mist`
- **使用效果**：阅读后解锁 `shadow_shroud_mist`；制造一片半径 4 格的视野受限暗影区域，持续 4 秒。
- **阅读要求**：角色职业标签含 `mage` 或 `rogue`；基础 `智力 ≥ 12` 或 `敏捷 ≥ 12`。
- **稀有度**：稀有（Rare）
- **建议投放**：影法师高塔、战场遗迹、团队战术任务奖励。

## 书籍内容

影幕是一种团队级环境控制技能，施术者以自身为中心向四周释放一层高密度暗影，让区域内所有生物的视野范围暂时收缩。作者在书中把影幕比作"把一块黑布盖在战场上"，但强调这块黑布对施术者及其同伴同样有效，因此需要配合夜瞳或其他低光视觉技能使用。书中详细讲解了影幕的释放时机：在敌人远程集火前使用可以打断瞄准，在己方冲锋前使用可以掩盖突进路线，在撤离时使用可以混淆追兵方向。后半部分讨论了影幕与光照的对抗关系：强光源会缩短持续时间，完全黑暗则会让影幕效果变得不稳定。作者提醒，影幕内所有声音都会被轻微放大，因此低声交流仍需谨慎，避免被敌人循声定位。影幕的边缘最为危险，施术者需要提前告知队友边界位置。阴影并非虚无，而是光的缺席；修习者要学会在缺席中行动，让自身成为那道被忽略的暗角。

## 设计意图

团队级环境控制，鼓励暗影队伍内部的技能协同与视野管理。
