# 《窃影者的账本》

## 基础信息

- **书籍 ID**：`book_shadow_0089`
- **关联技能**：`shadow_ledger`（待新增，标签 `shadow`）
- **使用效果**：阅读后学会技能 `shadow_ledger`；若已学会，则提升 `current_mastery +120`，并降低因影债过高导致的 NPC 敌对概率 `10%`。
- **阅读要求**：无职业限制；基础 `智力 ≥ 10` 或 `魅力 ≥ 9`。
- **稀有度**：普通（Common）
- **建议投放**：黑市账房、盗贼公会档案室、地下钱庄。

## 书籍内容

每一个在阴影中行走的人都会留下债务：欠同行的人情、欠雇主的秘密、欠影子商人的承诺。《窃影者的账本》不是讲偷窃，而是讲如何记录与管理这些隐形的债务。书中提出一套用符号标记风险的记账法，把每一次未完成的交易、每一个未兑现的谎言都转化为可量化的影债。影债过高会让 NPC 拒绝合作，甚至在关键时刻背叛你；影债过低则说明你太过老实，错过了很多机会。最实用的章节是债转股：如何把敌人的把柄变成自己的护身符。最后一页写着：账本记得越清楚的人，活得越久；但记得太清楚的人，也往往睡不好。账本最后一行是一行未完成的记录，墨迹新鲜，像是刚被中断。墨迹末端拖着一条细线，像是书写者突然被什么东西从房间里拖走。阴影并非虚无，而是光的缺席；修习者要学会在缺席中行动，让自身成为那道被忽略的暗角。

## 设计意图

为阴影阵营加入长期 reputation 与债务机制，让玩家的每次选择都产生持续的社会后果，增强叙事黏性。
