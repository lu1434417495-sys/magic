# 《幽影尖刺：幽灵贯穿》

## 基础信息

- **书籍 ID**：`book_暗影_0143`
- **关联技能**：`shadow_spike_specter`
- **使用效果**：阅读后解锁 `shadow_spike_specter`；从地面召唤暗影尖刺，对下盘敌人造成伤害并减速。
- **阅读要求**：角色职业标签含 `mage` 或 `rogue`；基础 `智力 ≥ 11` 或 `敏捷 ≥ 11`。
- **稀有度**：稀有（Rare）
- **建议投放**：古墓密室、暗影仪式现场、地穴探索任务奖励。

## 书籍内容

幽影尖刺是一门从地面发动突袭的暗影技艺，专门攻击敌人最难以防御的下盘。作者在书中把地面比作一张巨大的嘴，而施术者的任务是用意念让某块影子突然"咬"上去。书中详细描述了施术动作：单膝跪地，手掌平贴地面，然后想象力量像树根一样向下延伸，再从目标脚下破土而出。初学者常犯的错误是只关注目标位置而忽略了地面材质，松软的泥土会让尖刺提前暴露，坚硬的石板则需要更长的蓄力时间。后半部分列举了几种适合使用此术的地形：墓园草地、古堡石板裂缝、灰烬交界冷却的熔岩地面。作者提醒，幽影尖刺对飞行单位无效，对重装敌人的减速效果也会减弱，因此要根据敌人类型谨慎选择。幽影尖刺最适合对付下肢护甲薄弱的敌人，能造成有效牵制。阴影并非虚无，而是光的缺席；修习者要学会在缺席中行动，让自身成为那道被忽略的暗角。

## 设计意图

地形控制与区域伤害技能，把攻击维度从水平扩展到垂直，增加战场立体性。
