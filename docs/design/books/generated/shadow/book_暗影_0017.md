# 《暗影攫握：从地面升起的巨手》

## 基础信息

- **书籍 ID**：`book_shadow_0017`
- **关联技能**：`shadow_grasp`（待新增，标签 `shadow`）
- **使用效果**：阅读后解锁控制技能 `shadow_grasp`；巨手抓住目标时，使其本回合无法移动且攻击命中率下降。
- **阅读要求**：角色职业标签含 `mage` 或 `warlock`；基础 `智力 ≥ 11`。
- **稀有度**：稀有（Rare）
- **建议投放**：黑市商人、阴影法师塔、控制者任务奖励。

## 书籍内容

暗影攫握从地面升起一只由黑暗构成的大手，抓住敌人的脚踝或武器。书中指出，这只手的握力与施术者当时的情绪相关，愤怒会让它更有力却也更容易被敌人挣脱，冷静则能让它像钳子一样持久。作者详细说明了三种召唤位置：正前方用于正面拦截，侧后方用于配合队友夹击，目标脚下则用于直接限制移动。中段有一章讨论如何应对挣扎，建议在被抓者发力瞬间稍微松手，再趁其失衡时收紧。书中还提到，暗影攫握可以穿过盾牌抓住持盾者的手腕，但前提是施术者必须先预判盾牌的角度与光源方向。暗影攫握在抓住武器时能让敌人本回合无法攻击，但维持这种状态需要持续消耗魔力。书末附有一张手绘图，一只巨手正从一名骑士的影子中探出，图注写着：先抓影子，再抓人。书中最后写道：影子是你的镜子，也是你最忠实的敌人。

## 设计意图

为暗影系提供直观的单体控制能力，通过情绪与冷静度影响技能效果，增加战斗中的即时决策维度。
