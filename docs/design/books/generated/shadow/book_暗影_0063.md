# 《暗影契约：低语》

- **书籍 ID**：`book_shadow_0063`
- **关联技能**：`shadow_contract_whisper`（待新增，标签 `shadow`）

- **建议投放**：禁书区、暗影祭坛、异界裂隙奖励。

## 书籍内容

这是一本没有固定内容的书，每次翻开，纸面上的文字都会略有不同，仿佛书本身在与人协商。《暗影契约：低语》声称，阴影中居住着无数乐于交易的无名存在，它们不要金币，只要声音、记忆或一瞬间的选择。施术者可以在战斗前与某个阴影签订临时契约，以支付少量资源为代价，换取一次致命的辅助：可能是让敌人的影子突然绊倒他，也可能是在你濒死时替你承受一击。书中列出契约的三种语气：命令式会激怒阴影但效果直接，恳求式效果温和却更稳定，交换式则需在战后履行约定。最后一页始终空白，只印着一行字：你的签名已经在了，只是你自己还没看见。空白页在月光下会浮现出无数细小的手印，像是等待握手。契约书页散发着淡淡的霉味，仿佛已在某个潮湿角落躺了很久。阴影并非虚无，而是光的缺席；修习者要学会在缺席中行动，让自身成为那道被忽略的暗角。

## 设计意图

引入资源换随机增益的暗影契约机制，为法系阴影职业提供高风险高回报的战前决策，强化项目的异界神秘感。
