# 《暗影虹吸：借影还魂》

## 基础信息

- **书籍 ID**：`book_shadow_0022`
- **关联技能**：`shadow_siphon`（待新增，标签 `shadow`）
- **使用效果**：阅读后解锁吸血/吸蓝技能 `shadow_siphon`；对带有暗影印记的目标使用时，吸取效率提升 `25%`。
- **阅读要求**：角色职业标签含 `mage`、`warlock` 或 `rogue`；基础 `智力 ≥ 12`。
- **稀有度**：稀有（Rare）
- **建议投放**：黑市商人、吸血鬼猎人反向任务、阴影遗迹宝箱。

## 书籍内容

暗影虹吸通过连接自己与敌人的影子，窃取对方的生命力或魔力。书中警告，这种连接是双向的，若敌人的意志强于施术者，虹吸会反向进行。作者建议在施术前先削弱目标的意志，例如通过恐惧、疼痛或疲劳。中段有一章分析不同目标的虹吸效率：魔法师的魔力充沛但精神抵抗强，战士的生命力浑厚却回复缓慢，而同为暗影修习者则最难下手。修习者需要在虹吸过程中保持稳定的呼吸，任何贪婪导致的加速都会让连接出现裂纹。书中还提到，虹吸时施术者会看到目标近期最黑暗的记忆片段，许多人因此迷失自我。虹吸结束时必须缓慢断开连接，猛然切断会让部分被吸取的能量反冲回自身。书末用血写着：吸得越多，你越像他们。阴影并非虚无，而是光的缺席；修习者要学会在缺席中行动，让自身成为那道被忽略的暗角。

## 设计意图

为暗影系提供资源续航手段，通过双向风险与目标差异设计，避免虹吸成为无脑恢复技能，强化战斗中的节奏控制。
