# 《影纱初编：匿步》

## 基础信息

- **书籍 ID**：`book_shadow_0051`
- **关联技能**：`shadow_veil_step`（待新增，标签 `shadow`）
- **使用效果**：阅读后学会技能 `shadow_veil_step`；若已学会，则提升 `current_mastery +130`。
- **阅读要求**：角色职业标签含 `rogue`、`assassin` 或 `shadowmancer`；基础 `敏捷 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：黑市商人、盗贼公会密室、夜间巡逻宝箱。

## 书籍内容

这本书的封面没有任何文字，只有一层反复漂洗过的黑纱。作者自称“影纱学徒”，在第一页警告读者：不要试图在正午练习，阳光会让你的影子变薄，变薄就会背叛你。全书把匿步拆成三层：第一层是让影子贴近目标而不超前；第二层是让影子与目标的影子暂时重叠，使对方的边缘视觉无法判断你的轮廓；第三层则是跨影，利用两个光源之间的夹角，让自己的影子完全消失半秒。书中每章末尾都有手绘的人体姿态图，线条极细，仿佛用炭笔在夜色里描过。最后一页被撕去一半，只剩一行字：真正的匿步不是消失，是让对方的大脑替你决定不存在。末尾还夹着一张破损的采购单，上面列着厚底软靴、无烟炭、黑纱三丈，像是某种毕业清单。欺骗的秘诀在于先相信自己编织的故事，直到连影子都跟着说谎。

## 设计意图

为阴影系职业提供低门槛位移技能，把“潜行”从单纯隐身转化为对光源与影子的空间博弈，鼓励玩家在战棋格子上选择阴影路径。
