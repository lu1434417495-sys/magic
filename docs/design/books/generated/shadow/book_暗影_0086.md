# 《深影潜伏》

## 书籍内容

潜伏不是趴在地上不动，而是让自己成为环境的一部分。《深影潜伏》教授如何找到战场上最不易被注意的阴影位置，并在那里长时间保持静止。书中提出三层阴影理论：第一层是物体直接投下的黑影，最容易被检查；第二层是光线衰减形成的灰影，是大多数潜伏者的选择；第三层则是心理阴影，即敌人主观认为不会有人藏在那里的盲区。高级练习者要学会从第二层滑入第三层，让自己不被搜索。作者提醒：深影潜伏最大的敌人是时间，肌肉僵硬、呼吸变浅、甚至眨眼频率都会出卖你。最后一页只有一句话：当你觉得自己已经藏好，再等一轮。这句话的字迹越往后越轻，像是作者在写完时已经筋疲力尽。书页边角有反复折叠的痕迹，显示它被许多人当作最后的藏身指南。阴影并非虚无，而是光的缺席；修习者要学会在缺席中行动，让自身成为那道被忽略的暗角。

## 设计意图

为潜行玩法提供可持续的隐蔽状态，把潜伏从“进入隐身”深化为对敌人搜索心理与战场阴影层级的理解。
