# 《暗影面纱：认知迷雾》

## 基础信息

- **书籍 ID**：`book_shadow_0012`
- **关联技能**：`shadow_veil`（待新增，标签 `shadow`）
- **使用效果**：阅读后解锁社交/隐匿技能 `shadow_veil`；在城镇或营地中使用时，降低被守卫识破的几率。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `智力 ≥ 10`、意志 `≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：盗贼公会高级任务、黑市商人、间谍任务奖励。

## 书籍内容

暗影面纱覆盖在脸上，能让他人无法记住施术者的容貌。书中解释，它并非真正改变五官，而是在观察者脑海中制造一层认知迷雾，使其事后回忆时只剩下一团模糊的人形。作者警告这种技艺对意志坚定者效果有限，且在阳光下维持面纱需要持续消耗魔力。修习者需对着镜子反复练习，直到能在镜中看见自己，同时让镜子里的影像比真实面貌慢半拍。书中还介绍了一种应急技巧：当面纱被识破时，立刻让脸上的暗影向四周炸开，制造短暂视觉空白以争取逃跑时间。面纱在被识破时会产生刺痛感，这是修习者唯一能在别人开口前察觉失败的信号。书末记载了一项测试：戴上面纱走进熟悉的人群，若有人喊你的名字却不敢确认，便算合格；若有人完全无视你，则说明面纱过厚，需减薄。

## 设计意图

将暗影能力延伸至非战斗场景，为潜行、社交与任务分支提供支持，同时通过"阳光下消耗增加"平衡其泛用性。
