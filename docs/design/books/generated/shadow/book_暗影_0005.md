# 《影缚术：从影子到绞索》

## 基础信息

- **书籍 ID**：`book_shadow_0005`
- **关联技能**：`shadow_bind`（待新增，标签 `shadow`）
- **使用效果**：阅读后解锁控制技能 `shadow_bind`；成功束缚敌人时，使其下回合移动距离减半。
- **阅读要求**：角色职业标签含 `rogue` 或 `mage`；基础 `智力 ≥ 10` 或 `敏捷 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：黑市商人、阴影法师塔藏书、控制者任务奖励。

## 书籍内容

影缚术利用敌人脚下的影子作为锚点，将黑暗凝成绳索限制其行动。书中开篇即提醒，影缚对悬浮或强光照射的目标效果极差，因此施术前需先熄灭灯火、遮蔽天窗，或诱导敌人走入暗处。作者将影缚分为三阶：初阶只能绊住脚踝，中阶可缠绕腰腹，高阶则能把影子拉离地面化作实体绞索。修习者需要学会在施术时分散自己的注意力，因为过于专注会让影子颤动，反而暴露意图。书中还收录了几种辅助影缚的小技巧，例如在敌人眼前晃过一片布或一道光，让其影子在惊慌中变得更大、更易捕捉。作者建议修习者在施术前先用影镖测试风向，因为空气的流动会显著影响影缚的稳定性。书末附有一张残破的地图，标记着各地影子最长的时间段，标注者称之为缚影者的日历。作者认为，理解影子的本质比单纯模仿招式更重要。

## 设计意图

为暗影系提供可靠的单体控制手段，强调环境 setup 与地形利用，强化战棋战斗中"先控后打"的战术节奏。
