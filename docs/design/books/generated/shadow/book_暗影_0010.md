# 《影遁：沉入阴影维度》

## 基础信息

- **书籍 ID**：`book_shadow_0010`
- **关联技能**：`shadow_meld`（待新增，标签 `shadow`）
- **使用效果**：阅读后解锁高阶闪避技能 `shadow_meld`；首次成功闪避敌人攻击时，恢复少量 `MP`。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `敏捷 ≥ 13`、意志 `≥ 11`。
- **稀有度**：史诗（Epic）
- **建议投放**：黑市商人高价货物、暗杀大师传承、史诗级宝箱。

## 书籍内容

影遁不是消失，而是让自己的身体短暂沉入最近的阴影维度。书中指出，每次影遁都伴随一种下沉感，仿佛踩进一团看不见的水中，若停留超过一瞬，就会听见来自阴影深处的低语。作者建议初学者先从自己的影子开始练习，因为熟悉的轮廓能成为回归时的锚点；贸然遁入陌生阴影，极有可能在返回时丢失方向。中段记载了几种危险征兆：如果影子里出现多余的眼睛，或下沉感变成被拖拽感，必须立刻中止。书中还提到，高阶修习者能在影遁瞬间留下一个静止的残像，诱使敌人继续攻击空处。修习者需要在影遁后立刻判断自己的方位，因为阴影维度中没有固定的参照物。最后一页只有一句被反复描粗的警告：影子愿意借路，但从不希望你住下。作者最后提醒，暗影技艺的精进不在一日之间。

## 设计意图

作为暗影系高阶生存技能，承担"以闪避替代格挡"的战斗风格入口，结合 MP 资源链，为后续连续释放暗影技能提供续航支持。
