# 《暗影镰刀：行刑者的选择》

## 基础信息

- **书籍 ID**：`book_shadow_0047`
- **关联技能**：`shadow_scythe`（待新增，标签 `shadow`）
- **使用效果**：阅读后解锁大范围横扫技能 `shadow_scythe`；对聚集的敌人造成伤害，击杀敌人时返还部分 `MP`。
- **阅读要求**：角色职业标签含 `mage`、`warlock` 或 `rogue`；基础 `敏捷 ≥ 12` 或 `智力 ≥ 12`。
- **稀有度**：史诗（Epic）
- **建议投放**：黑市商人、史诗级宝箱、行刑者任务奖励。

## 书籍内容

暗影镰刀凝聚出一柄巨大的黑暗镰刀，适合中距离横扫与收割多个目标。书中强调镰刀的攻击范围虽大，但起手动作明显，需要预判敌人的聚集位置。作者建议在敌人被迫集合时使用，例如通过队友控制或地形限制。中段用图示说明三种挥砍方式：横挥覆盖最广，竖劈伤害最高，回旋斩则适合被包围时清场。修习者需要训练控制镰刀的实体程度，完全实体化威力大但速度慢，半实体化则可穿盾但伤害降低。书中还提到，暗影镰刀在收割生命时会发出低沉的嗡鸣，许多人误以为那是金属振动，实则是被斩断的影子在哀鸣。镰刀在收割生命时会短暂发出低鸣，这种声音会让周围敌人下意识地后退一步。书末附有一名行刑者的格言：镰刀不需要快，只需要在合适的时候挥出。书中最后写道：影子是你的镜子，也是你最忠实的敌人。

## 设计意图

为暗影系提供高消耗的范围收割技能，通过击杀返还能耗机制鼓励玩家寻找聚怪时机，强化团战收割体验。
