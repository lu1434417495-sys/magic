# 《虚空陷阱：影钉布置》

## 基础信息

- **书籍 ID**：`book_暗影_0112`
- **关联技能**：`shadow_trap_void`
- **使用效果**：阅读后解锁 `shadow_trap_void`；若已学会，陷阱触发范围提升 15%。
- **阅读要求**：角色职业标签含 `rogue`；基础 `敏捷 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：地下墓穴工匠台、工程盗贼工作台、遗迹机关室。

## 书籍内容

虚空陷阱把暗影从移动辅助变成了可预设的杀伤区域。作者在书中介绍了一种名为"影钉"的简易装置：一根经过哑光处理的细针，尖端涂抹从灰烬交界采集的暗影残渣，布置在地面裂缝或门槛边缘时几乎不可见。书中强调，好的影钉不在于有多锋利，而在于能否让敌人自己把影子送上去。当目标的影子覆盖影钉时，残渣会顺着影子攀附，造成短暂的麻痹与定位混乱。后半部分讨论了不同地面的隐蔽性：落叶地容易因移动而暴露，石板地需要借助灰尘伪装，而灰烬交界的浮灰则会让影钉几乎与环境融为一体。作者还提醒，布置者要记住每一根影钉的位置，否则撤退时可能会踩中自己的陷阱，最好做一套只有自己能看懂的暗记。老练的布置者会在影钉附近留下只有自己能看懂的细小记号。

## 设计意图

为盗贼增加区域控制与预设战场能力，把陷阱机制与暗影主题结合。
