# 《影换位：人与影的交换》

## 基础信息

- **书籍 ID**：`book_shadow_0028`
- **关联技能**：`shadow_swap`（待新增，标签 `shadow`）
- **使用效果**：阅读后解锁位移技能 `shadow_swap`；可与目标影子交换位置，对敌人释放时目标下回合移动速度降低。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `敏捷 ≥ 13`。
- **稀有度**：稀有（Rare）
- **建议投放**：黑市商人、暗杀大师传承、稀有宝箱。

## 书籍内容

影换位让施术者与一个目标的影子交换位置，常用于脱离包围或接近远程敌人。书中警告，换位时施术者会有一瞬暴露在新位置的光线中，因此需提前确认落点安全。作者详细说明了目标选择：敌人的影子最常用，但也可以与队友或自己的使魔换位。中段有一章分析距离限制，超过二十步的影子连接会变得不稳定，可能导致只交换部分身体。修习者常被要求在悬崖边练习，逼迫自己在换位瞬间保持冷静。书中还提到，影换位在穿过封印或结界时可能失效，因为某些结界会切断影子与本体之间的联系。换位失败最常见的后果是身体滞留在两个位置之间，造成剧烈疼痛与短暂瘫痪。书末写着：影换位救过你一次后，你会上瘾；但它只救那些不依赖它的人。作者建议，每次练习后都要在光明中静坐片刻，以确认自己仍是血肉之躯。

## 设计意图

为暗影系提供高机动战术位移，强调落点安全与距离判断，强化战棋中的空间拉扯与突进/撤退决策。
