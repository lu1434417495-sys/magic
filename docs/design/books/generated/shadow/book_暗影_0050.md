# 《暗影升华：与影子融为一体》

## 基础信息

- **书籍 ID**：`book_shadow_0050`
- **关联技能**：`shadow_ascension`（待新增，标签 `shadow`）
- **使用效果**：阅读后解锁终极技能 `shadow_ascension`；持续数回合大幅提升闪避与移动速度，结束后进入虚弱期。
- **阅读要求**：角色职业标签含 `rogue`、`assassin` 或 `mage`；已解锁 `MP` 与 `AURA` 资源链；基础 `敏捷 ≥ 15`、意志 `≥ 14`。
- **稀有度**：传说（Legendary）
- **建议投放**：传说级宝箱、暗影导师最终传承、黑市商人极稀有货物。

## 书籍内容

暗影升华是暗影系技能的终极形态之一，施术者短暂与自身影子完全融合，获得极高的速度与闪避。书中警告升华结束后会进入一段虚弱期，期间无法使用任何暗影技能。作者强调升华期间不能被强光直接照射，否则会提前解除并造成反噬。中段有一章记录了几位前辈的使用经验，他们都提到在升华中听见了影子的低语，有的认为那是祝福，有的则认为那是警告。修习者需要通过长期冥想与修炼才能达到升华的门槛，普通暗影修习者强行尝试只会被自己的影子吞噬。书中还提到，升华期间施术者可以穿越实体障碍，但每次穿越都会缩短升华持续时间。升华期间施术者无法使用常规治疗，因此必须在进入升华前确保自身状态足够支撑全程。书末用金漆写着：当你成为影子，别忘了你还要回到光里。

## 设计意图

作为暗影系传说级终极技能，承载资源投入与成长验证的终点体验。通过爆发后的虚弱与光明克制，确保其强大但不失控，并与冥想、修炼系统形成成长闭环。
