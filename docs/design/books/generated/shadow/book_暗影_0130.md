# 《蚀刃：暗影刀锋》

## 基础信息

- **书籍 ID**：`book_暗影_0130`
- **关联技能**：`shadow_blade_eclipse`
- **使用效果**：阅读后解锁 `shadow_blade_eclipse`；武器攻击附加暗影伤害，并降低目标命中 5%。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `敏捷 ≥ 14`。

## 书籍内容

蚀刃是暗影系武器附魔的高阶技艺，能够让普通刀刃在短时间内获得吞噬光线的能力。作者在书中描述，被蚀刃附魔的武器不会发光，反而会让周围一两寸的空间变得格外暗沉，就像刀刃上附着一个微型月食。附魔过程需要以施术者自身的影子为燃料，因此持续时间与施术者的意志成正比。书中警告，蚀刃会对使用者造成精神负担，长时间保持附魔状态会让影子变薄，甚至短暂失去潜行能力。后半部分讨论了不同武器与蚀刃的契合度：轻薄短刃效果最佳，重型斧头反而会因为挥动轨迹过大而提前暴露暗影波动。作者建议每次附魔不超过三十秒，并在阴影中休息以恢复影子厚度，否则会导致持续性头痛。使用蚀刃时，刀锋附近的光线会被微微扭曲，形成肉眼难察的暗环。阴影并非虚无，而是光的缺席；修习者要学会在缺席中行动，让自身成为那道被忽略的暗角。

## 设计意图

高阶武器附魔型暗影技能，把直接伤害与减益效果结合，构建刺客核心输出循环。
