# 《暗影沉默：吞没声音的黑》

## 基础信息

- **书籍 ID**：`book_shadow_0030`
- **关联技能**：`shadow_silence`（待新增，标签 `shadow`）
- **使用效果**：阅读后解锁反制技能 `shadow_silence`；命中目标后使其下回合无法施法或吟唱。
- **阅读要求**：角色职业标签含 `rogue` 或 `mage`；基础 `敏捷 ≥ 11` 或 `智力 ≥ 11`。
- **稀有度**：稀有（Rare）
- **建议投放**：黑市商人、法师猎人任务、阴影遗迹宝箱。

## 书籍内容

暗影沉默通过覆盖目标的影子，使其在短时间内无法发声或施法。书中说明沉默效果不是阻断声带，而是让声音在离开身体前被黑暗吸收。作者强调对施法者尤其有效，因为法术吟唱需要声音与魔力同步，一旦声音消失，法术构建便会崩溃。中段有一章讲授如何延长沉默时间，关键是在覆盖影子时同时压制目标脚下的光线。修习者需要在无声环境中练习，以体会真正的寂静是什么样子。书中还提到，暗影沉默对依赖肢体动作的战技使用者效果较弱，因为后者不需要声音来释放技能。沉默效果在覆盖目标影子中心时最强，偏斜则会留下部分声音逃逸的缝隙。书末用红笔圈出：暗影沉默对依赖内心咏唱的高级法师效果有限，对付他们要先打乱其节奏。作者最后提醒，暗影技艺的精进不在一日之间。

## 设计意图

为暗影系提供打断施法的反制手段，通过"覆盖影子"的主题化机制，丰富战棋中对法师职业的针对策略。
