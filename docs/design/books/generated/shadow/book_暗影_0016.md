# 《暗影形态：血肉的暗化》

## 基础信息

- **书籍 ID**：`book_shadow_0016`
- **关联技能**：`shadow_form`（待新增，标签 `shadow`）
- **使用效果**：阅读后解锁变身技能 `shadow_form`；形态期间免疫普通物理攻击，但受到光明伤害时加倍。
- **阅读要求**：角色职业标签含 `mage` 或 `warlock`；基础 `智力 ≥ 13`、意志 `≥ 12`。
- **稀有度**：史诗（Epic）
- **建议投放**：黑市商人、阴影神庙、史诗级宝箱。

## 书籍内容

暗影形态让施术者的身体部分转化为暗质，从而免疫普通物理攻击。书中警告，这种转化不能长时间维持，因为身体会逐渐忘记自己是血肉而非影子。作者把暗影形态分为两层：表层形态只让皮肤和肌肉暗化，用于抵挡刀剑；深层形态则让骨骼与内脏也融入阴影，可穿越栅栏与缝隙，但回归时会产生剧烈疼痛。修习者需要通过冥想不断确认自己的内脏位置，否则在形态解除后会出现短暂的功能紊乱。书中还提醒，深层形态下无法说话、无法品尝食物，甚至无法感受到自己的心跳，因此连续使用超过三次将对心智造成不可逆影响。书中警告，频繁进入深层形态会让修习者在阳光下产生眩晕，严重时甚至会短暂失明。书末附有一名前辈的血书：我在深层形态里待了太久，现在我的影子比我更像我。

## 设计意图

为暗影法师与术士提供战略性变身技能，通过"免疫物理但惧怕光明"的弱点设计，强化属性克制与战场决策深度。
