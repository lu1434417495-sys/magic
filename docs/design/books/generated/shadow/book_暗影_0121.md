# 《夜落尖刺：天顶暗影》

## 书籍内容

夜落尖刺是一门从"上方"发动攻击的暗影技艺。作者认为，大多数人只注意脚下的影子，却忽略了头顶夜空也是一片巨大的阴影。施术时，施术者先以自身为锚点向上投射一缕暗影，那缕暗影会在天顶凝聚成尖锐的坠物，然后在意念指引下垂直落下。书中详细描述了凝聚过程的四个阶段：拉升、塑形、锁定、坠落，每个阶段都需要保持绝对静止，否则尖刺会在形成中途溃散。后半部分讨论了天气影响，雨天会让尖刺下落更快但更难精准锁定，雷暴夜则会让尖刺带有微弱的电弧。最后几页是一份简短的发誓词，要求读者承诺不在有月光的夜晚对无辜者使用此术，因为月光会让施术者看清目标的面容，从而无法下手。占星台的修习者认为，星空越密集，尖刺凝聚的速度越快。阴影并非虚无，而是光的缺席；修习者要学会在缺席中行动，让自身成为那道被忽略的暗角。

## 设计意图

绑定夜间环境的高阶伤害技能，引入垂直打击维度与时间窗口限制。
