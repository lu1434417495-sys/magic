# 《暗影箭：初学者的暗矢》

## 基础信息

- **书籍 ID**：`book_shadow_0013`
- **关联技能**：`shadow_bolt`（待新增，标签 `shadow`）
- **使用效果**：阅读后解锁基础远程魔法 `shadow_bolt`；若目标处于阴影格中，命中率提升 `12%`。
- **阅读要求**：角色职业标签含 `mage` 或 `warlock`；基础 `智力 ≥ 9`。
- **稀有度**：普通（Common）
- **建议投放**：阴影法师学徒奖励、黑市商人、低级宝箱。

## 书籍内容

暗影箭是最常见的暗影魔法入门，将一团压缩的黑暗以直线射出。书中批评许多法师把暗影箭当成普通飞弹使用，忽视了它真正的价值在于命中后的视线遮蔽。作者建议在射箭前先观察环境光源，让暗影箭的飞行轨迹与真实阴影重合，这样敌人更难判断来向。中段有一章专门分析不同职业的应对习惯：战士倾向于举盾，盗贼会翻滚，而法师往往选择反制法球而非闪避。书中还提到，连续射出三发暗影箭并让它们在空中短暂融合，可以形成一发更大、更具穿透力的暗影矢，但会显著增加魔力消耗。书中还提醒，暗影箭在飞行时会留下细微黑线，高手可以通过这些线条反向追踪施术者。最后几页记录了一位前辈的改良公式，在箭尾加入螺旋轨迹，使暗影箭在命中后能短暂缠绕目标，形成微型影缚。

## 设计意图

作为暗影法师的基础输出技能，承担低消耗、高频率的远程打击职责，并通过阴影格加成鼓励玩家关注战场光照。
