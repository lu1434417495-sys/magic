# 《暗影斩：刀锋上的夜色》

## 基础信息

- **书籍 ID**：`book_shadow_0041`
- **关联技能**：`shadow_slash`（待新增，标签 `shadow`）
- **使用效果**：阅读后解锁中距离斩击技能 `shadow_slash`；斩击命中后留下暗影残渣，使目标后续受到的暗影伤害提升。
- **阅读要求**：角色职业标签含 `rogue`、`warrior` 或 `assassin`；基础 `敏捷 ≥ 11`。
- **稀有度**：普通（Common）
- **建议投放**：黑市商人、低级宝箱、盗贼公会训练奖励。

## 书籍内容

暗影斩将黑暗附着于刀刃，挥出一道弧线形的远程斩击。书中指出斩击的飞行速度不快，但能在命中后留下持续侵蚀伤口的暗影残渣。作者建议配合突进或换位使用，在敌人以为你够不到的瞬间释放。中段用图示说明三种斩击轨迹：水平斩封锁走位，斜斩制造破绽，垂直斩则适合对付跳跃中的目标。修习者需要训练控制刀上黑暗的量，过多会让刀刃过重，过少则斩击在飞行中消散。书中还提到，暗影残渣可以与其他暗影技能产生共鸣，当目标身上已有残渣时，后续影缚或诅咒的持续时间会延长。暗影斩在命中后会改变目标影子的形状，有经验的敌人能据此判断你的大致方位。书末附有一名刀客的笔记：真正的暗影斩，不是斩中敌人，是让敌人自己撞上来。书中还强调，修习者必须学会在光明与黑暗之间找到平衡。

## 设计意图

为近战暗影职业提供中距离起手与 debuff 叠加手段，强化"先削弱再收割"的连招循环，降低职业对贴身作战的依赖。
