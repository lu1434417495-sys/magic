# 《蚀月冲锋：暗影奔袭》

## 基础信息

- **书籍 ID**：`book_暗影_0119`
- **关联技能**：`shadow_rush_eclipse`
- **使用效果**：阅读后解锁 `shadow_rush_eclipse`；冲锋路径上的敌人受到暗影伤害。
- **阅读要求**：角色职业标签含 `warrior` 或 `assassin`；基础 `力量 ≥ 13` 或 `敏捷 ≥ 13`。
- **稀有度**：史诗（Epic）
- **建议投放**：月蚀事件奖励、古代战场遗迹、影武者传承。

## 书籍内容

蚀月冲锋把战士的直线突进与暗影的侵蚀特性合二为一。作者认为，真正的冲锋不应该像阳光下的骑兵那样耀眼，而应该像月蚀掠过大地——安静、不可阻挡、并且留下一条短暂的黑暗轨迹。书中要求练习者在冲锋前先锁定目标脚下的影子，让身体在突进过程中尽量贴近那条影子的延长线。这样做的好处是敌人难以判断你的真实速度，因为影子会替你隐藏一部分位移。后半部分讨论了武器选择：长柄武器适合在冲锋末端制造范围伤害，短刃则适合在穿过敌人身侧时补上一记割伤。附录中有一幅被血浸透的示意图，标题写着：不要在满月时使用此术，因为满月会让你的影子变得过于清晰，失去隐蔽效果，沦为普通冲锋。书中还提到，新月之夜是练习此术的最佳时机，影子最为浓密。阴影并非虚无，而是光的缺席；修习者要学会在缺席中行动，让自身成为那道被忽略的暗角。

## 设计意图

让战士与刺客获得突进型暗影技能，把冲锋从位移伤害扩展为路径控制与环境互动。
