# 《影阵：暗影协同》

## 基础信息

- **书籍 ID**：`book_暗影_0148`
- **关联技能**：`shadow_phalanx_shade`
- **使用效果**：阅读后解锁 `shadow_phalanx_shade`；多名队友在阴影中相邻时全属性提升 5%。
- **阅读要求**：角色职业标签含 `warrior` 或 `rogue`；基础 `体质 ≥ 12` 或 `敏捷 ≥ 12`。
- **稀有度**：史诗（Epic）
- **建议投放**：影卫军团遗产、协同战术训练奖励、团队副本宝箱。

## 书籍内容

影阵是一种团队站位增益技艺，源自古代影卫军团的战阵传统。作者在书中指出，单个影子是脆弱的，但当多个影子彼此相连时，它们会形成一片共同的暗影领域，身处其中的所有人都会获得力量、敏捷与意志的强化。书中详细描述了影阵的激活条件：至少两名队友站在同一片连续阴影中且彼此相邻，阵眼由队伍中暗影造诣最高者担任。阵势一旦形成，每个人的影子会微微向对方倾斜，像无数根手指互相扣紧。后半部分讨论了战术配合：前排战士吸引火力制造阴影，盗贼与刺客在阴影中输出，法师则在阵外提供控场。附录里有一句古军团格言：我们不站在光里，我们站在彼此的影子里。影阵在阴影连续中断时会立刻瓦解，队伍需要保持紧密站位。阴影并非虚无，而是光的缺席；修习者要学会在缺席中行动，让自身成为那道被忽略的暗角。

## 设计意图

团队站位增益，鼓励暗影阵型与职业协同，把多人站位转化为属性加成。
