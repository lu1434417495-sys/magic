# 《幽冥披风：伤害转移》

## 基础信息

- **书籍 ID**：`book_暗影_0141`
- **关联技能**：`shadow_mantle_gloom`
- **使用效果**：阅读后解锁 `shadow_mantle_gloom`；受到伤害的一部分由周围阴影承担。
- **阅读要求**：角色职业标签含 `warrior` 或 `warlock`；基础 `体质 ≥ 13` 或 `智力 ≥ 13`。
- **稀有度**：史诗（Epic）
- **建议投放**：幽冥领主掉落、深渊祭坛、高阶防御任务奖励。

## 书籍内容

幽冥披风是高阶防御向暗影技艺，它让施术者把自己受到的伤害分散到周围的阴影之中。作者在书中描述，施术时身上会浮现出一层不断流动的黑暗薄膜，像一件活披风一样覆盖肩背与四肢。当攻击命中时，薄膜会把冲击力导入最近的阴影区域，在地面或墙壁上留下细微的裂纹。书中警告，幽冥披风需要充足的阴影才能生效，在完全无阴影的强光环境下会迅速溃散；同时，它无法抵御纯粹的精神攻击或神圣伤害。后半部分讨论了与战士护甲的搭配：重甲可以吸收剩余伤害，让披风专注于分摊，而轻甲使用者则需要更频繁地移动以寻找阴影。作者建议始终背对光源站立，这样身后会有足够的影子供披风调用。幽冥披风在吸收过多伤害后，表面会浮现出细密的裂纹。阴影并非虚无，而是光的缺席；修习者要学会在缺席中行动，让自身成为那道被忽略的暗角。

## 设计意图

高阶防御向暗影技能，为前排提供新的减伤模型，强化暗影坦克构筑可能性。
