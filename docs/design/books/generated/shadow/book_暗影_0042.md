# 《暗影腐蚀：缓慢的死刑》

## 基础信息

- **书籍 ID**：`book_shadow_0042`
- **关联技能**：`shadow_corruption`（待新增，标签 `shadow`）
- **使用效果**：阅读后解锁持续减益技能 `shadow_corruption`；每回合降低目标防御与抗性，可叠加三层。
- **阅读要求**：角色职业标签含 `mage` 或 `warlock`；基础 `智力 ≥ 12`。
- **稀有度**：稀有（Rare）
- **建议投放**：黑市商人、诅咒学者任务、阴影遗迹宝箱。

## 书籍内容

暗影腐蚀通过持续注入黑暗能量，削弱敌人的护甲、抗性与治疗效果。书中解释腐蚀不像毒素那样随时间衰减，它会像霉菌一样在目标体内扎根，除非用光明魔法强行清除。作者建议在持久战开场就施加腐蚀，因为它需要数回合才能发挥最大效果。中段有一章分析不同材质护甲对腐蚀的敏感程度，皮革与布甲最易受影响，金属则需更长时间。修习者需要学会控制腐蚀强度，过强会触发敌人的痛苦本能使其爆发，过弱则容易被抵抗。书中还提到，暗影腐蚀对亡灵单位效果较差，因为它们体内缺少可供黑暗扎根的生命力。腐蚀在叠加到三层时会让目标产生幻觉，有时这会迫使敌人做出错误的战术判断。书末写着：腐蚀是缓慢的死刑，你需要做的只是不让它停下来。最后，作者用一行小字写下：唯有耐心，方能驾驭影子。

## 设计意图

为暗影系提供持久战核心 debuff，通过叠加与光明驱散机制，强化属性克制与战斗节奏规划的重要性。
