# 《影刃铸造手记》

## 基础信息

- **书籍 ID**：`book_shadow_0002`
- **关联技能**：`shadow_blade`（待新增，标签 `shadow`）
- **使用效果**：阅读后解锁暗影武器技能 `shadow_blade`；若已学会，提升 `current_mastery +80`。

## 书籍内容

影刃术将魔力凝聚为一把没有重量的漆黑短刃，握在手中时仿佛握着一团凝固的夜色。书中指出影刃的锋利不取决于施术者智力，而取决于对黑暗浓度的感知：在烛光摇曳处它削铁如泥，在正午烈日下却连布匹都难以划破。作者用三十页记录如何在移动中维持影刃形态，因为一旦奔跑过快，刃身就会像墨汁入水般散开。最有价值的一章讲授影刃的三种攻击角度：横斩留下迟缓伤口，直刺造成贯穿暗影，反手挑击则能割断敌人的魔力回路。书中还记载了在刀刃上附加个人影子碎片的方法，能让影刃短暂追踪目标，但会消耗使用者的部分体力。作者强调，影刃在释放后仍需持续注入意志，否则它会在命中前提前溃散。书末附有一张被血浸透的便签，写着：别把它当成武器，它是你影子的獠牙。

## 设计意图

为盗贼、暗杀者与暗影法师提供可成长的副手武器选项，强化其近战爆发与持续削弱能力，同时引入"环境光线影响暗影技能强度"的机制概念。
