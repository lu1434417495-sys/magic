# 《影匿斗篷编织法》

## 书籍内容

一件真正的影匿斗篷不是披风，而是包裹全身的稀薄暗幕。书中强调静止不过是基础，高阶用法是在移动中让暗幕跟随身体褶皱流动，使旁观者产生视野边缘出现黑点的错觉，从而主动忽略你的存在。作者详细拆解了七种常见光源下的匿踪效果，从火炬到月光再到魔法辉光，每一种都需要调整暗幕的厚度与折射角度。修习者常被要求连续三日只走在建筑的阴影里，以训练对光线边界的直觉。书中还记载了一项进阶训练：在人群中缓慢移动而不被发现，成功标准不是完全隐身，而是让目击者事后怀疑自己看花了眼。许多初学者在第一次成功隐匿后会忍不住微笑，而微笑正是让暗幕出现褶皱的最大原因。最后章节记载了一次失败的潜行：某位大师在完全隐匿的状态下回头看了目标一眼，就因为这一眼，暗幕碎裂，功亏一篑。

## 设计意图

服务于盗贼与暗杀者的隐匿定位，把"潜行"从二元状态提升为受环境光线与移动速度影响的动态资源管理玩法。
