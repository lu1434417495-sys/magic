# 《夜行者的礼仪》

- **书籍 ID**：`book_shadow_0072`
- **关联技能**：`shadow_night_etiquette`（待新增，标签 `shadow`）

## 书籍内容

在黑暗世界活动，有一套不成文的规矩。《夜行者的礼仪》把这些规矩整理成文，以免新手在还没学会杀人之前就先得罪人。书中列举了十七条禁忌：不在同行面前炫耀目标信息，不拆穿他人的伪装，不在任务结束后立刻返回接头点，不向光源祈祷，不把自己的真名告诉影子商人。最有趣的一章是失败的礼貌，讲述如何在不得不与同行冲突时，用特定手势表示这不是私人恩怨，从而减少被集体追杀的概率。作者也承认，这些礼仪大多时候没什么用，但它们构成了黑暗社会得以运转的最低信任。书的最后一页是一张空白契约，标题为：我已阅读并同意以上条款。契约下方有一行小字：违约者将被自己的影子从背后注视，直到偿还。欺骗的秘诀在于先相信自己编织的故事，直到连影子都跟着说谎。

## 设计意图

为阴影主题补充社交与阵营互动技能，让玩家在黑暗网络中获得非战斗收益，增强角色扮演的代入感。
