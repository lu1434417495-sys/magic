# 《暗影风暴：旋转的黑暗》

## 基础信息

- **书籍 ID**：`book_shadow_0045`
- **关联技能**：`shadow_storm`（待新增，标签 `shadow`）
- **使用效果**：阅读后解锁大型范围技能 `shadow_storm`；风暴持续吸引范围内敌人，并每回合造成切割伤害。
- **阅读要求**：角色职业标签含 `mage` 或 `warlock`；基础 `智力 ≥ 14`、意志 `≥ 12`。
- **稀有度**：史诗（Epic）
- **建议投放**：黑市商人、战场法师传承、史诗级宝箱。

## 书籍内容

暗影风暴召唤一片旋转的黑暗旋风，持续牵引并切割范围内的敌人。书中警告风暴会同时影响敌我，因此需要精确的释放位置与队友配合。作者建议在狭窄地形或敌人密集处使用，以最大化牵引效果。中段用图示说明风暴中心的低压区，聪明的敌人会试图向外逃离，因此外围需提前布置控制技能。修习者需要训练在维持风暴的同时移动，因为静止的风暴容易被远程攻击瓦解。书中还提到，暗影风暴可以吸收路径上的小型暗影技能，使自身范围与伤害略微扩大，但也会因此变得更加不稳定。风暴在吸收足够多小型暗影技能后可能失控扩大，因此使用时必须预留终止手段。书末附有一名战场法师的回忆录：暗影风暴结束后，地上只剩一圈没有影子的焦土。作者认为，理解影子的本质比单纯模仿招式更重要。

## 设计意图

作为暗影系高阶范围控制+伤害技能，通过牵引与敌我不分的设计，要求玩家精确站位与团队配合，体现高风险高回报。
