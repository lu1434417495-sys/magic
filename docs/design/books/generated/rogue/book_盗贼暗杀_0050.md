# 《刺客的镜子：认识你的目标》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0050`
- **关联技能**：`assassin_target_study`
- **使用效果**：阅读后解锁 `assassin_target_study`；若已学会，提升 `current_mastery +120`，并使对已研究目标的首次攻击伤害 `+5%`。
- **阅读要求**：角色职业标签含 `assassin`；基础 `感知 ≥ 11` 或 `智力 ≥ 11`。
- **稀有度**：精良（Uncommon）
- **建议投放**：情报商人、密探档案室、高级暗杀委托前置奖励。

## 书籍内容

镜子不是照自己，而是让你看见目标的倒影。作者认为，暗杀成功的七成在情报，三成在刀法。书中教授如何收集目标的日常规律：起床时间、饮食偏好、护卫换岗时间、最容易疏忽的时刻。中间章节讲解如何从目标的社交关系中寻找突破口，比如一个不被重视的仆人、一个心怀怨恨的亲属、一处经常独自前往的场所。后半本转入目标心理侧写，分析不同类型的人在面对威胁时的反应：贪婪者会被诱饵吸引，傲慢者会低估对手，恐惧者会做出过激防御。作者还提醒，研究目标过久可能会产生奇怪的共情，这种共情是刺客最危险的敌人。末页有一张空白页，上面只印着一行字：在你出手之前，先回答一个问题——他真的必须死吗？

附录是目标研究清单，从日常习惯到心理弱点都有条目可勾选。清单末写着：研究目标越久，你越接近其视角；记住你是猎人，不是他的传记作者。

## 设计意图

为刺客系提供情报收集与预战斗准备机制，研究目标后的伤害加成强化规划价值。
