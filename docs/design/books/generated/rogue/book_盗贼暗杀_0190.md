# 《灰烬双刃：异界火焰暗杀》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0190`
- **关联技能**：`ashen_dual_blade`
- **使用效果**：阅读后解锁 `ashen_dual_blade`；若已学会，提升 `current_mastery +150`，并使灰烬交界区域内双持攻击附加火焰伤害 `+8%`。
- **阅读要求**：无职业限制；基础 `敏捷 ≥ 13`；已装备双持武器。
- **稀有度**：史诗（Epic）
- **建议投放**：灰烬交界熔炉遗迹、余烬战士导师、异界BOSS掉落。

## 书籍内容

灰烬交界的高温会让普通武器变软，但也会唤醒某些金属中沉睡的火焰，这本书是在一座半熔化的铁砧旁发现的。这本书教授如何在双持武器上引导异界余烬，让每一次斩击都带上一缕灼热的灰焰。作者强调，这种技术需要精准的呼吸与节奏，否则火焰会反噬持刀者。中间章节讲解如何选择适合的武器材质、如何在战斗中保持灰烬附着、以及如何在连击中累积火焰伤害。作者提醒，灰焰对亡灵无效，因为它们的身体里已经没有可以被点燃的东西。后半本转入战术：利用火焰制造恐惧与混乱，让敌人在躲避光芒时暴露死角。末页画着两把交叉的短刀，刀刃上缠绕着类似灰烬的纹路，配文：在灰烬里，刀不是冷的，它是世界的余温。封面摸起来有轻微的温热感，仿佛余烬未熄。书中记载，灰焰会在使用者的梦境中继续燃烧，直到天亮。

## 设计意图

作为灰烬交界专题双持技能，把异界环境与战斗风格结合，提供区域限定加成。
