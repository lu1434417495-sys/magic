# 《视线的艺术：引导与切断注视》

## 书籍内容

大多数人以为躲藏就是不被看见，但这本书认为更高明的做法是控制别人看哪里，作者曾是一名舞台魔术师。作者指出，人类的视线会被运动、光亮、声音和异常形状吸引，盗贼可以主动制造这些诱饵，让敌人的目光离开真正的威胁。书中前半部讲解如何用石子、反光片或小型动物的叫声引导巡逻者的视线。中间章节转入反向应用：如何让自己在人群中显得不值得注视，包括放慢动作、避免眼神接触、让自己的轮廓融入背景节奏。作者把视线比作河流，而盗贼要学会在河床上开凿支流。后半本则探讨双人配合：一人吸引视线，另一人穿过盲区，以及如何通过连续诱饵把敌人一步步引入陷阱。末页有一幅被反复涂改的眼睛素描，配文：看见什么从来不是眼睛决定的，是注意力决定的。封面上画着一只被箭头环绕的眼睛。

## 设计意图

为高级潜行提供主动控场能力，让盗贼能够 manipulate 敌方巡逻与警戒。
