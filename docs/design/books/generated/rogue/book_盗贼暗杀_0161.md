# 《钩索百艺：城市攀援》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0161`
- **关联技能**：`rogue_grapple_mastery`
- **使用效果**：阅读后解锁 `rogue_grapple_mastery`；若已学会，提升 `current_mastery +110`，并使钩索投掷距离 `+15%`。
- **阅读要求**：角色职业标签含 `rogue`；基础 `敏捷 ≥ 10` 且 `力量 ≥ 8`。
- **稀有度**：精良（Uncommon）
- **建议投放**：城市盗贼公会、屋顶信使、工程商人。

## 书籍内容

城市是立体的战场，而钩索是盗贼在垂直方向上行走的第二双腿，作者是一名专偷贵族区的飞贼。这本书从钩爪的构造讲起：三爪、四爪、折叠爪各自适合什么样的屋檐、烟囱和窗框。中间章节教授投掷技巧：不是甩得越狠越好，而是要让钩子在你想让它停住的地方停住，这需要手腕的轻微抖动而非手臂的全力挥动。作者还教授如何在钩索上涂抹消音油脂，以及如何判断墙砖是否能承受体重。书中还详细记录了多种回收钩索的方法，以及如何在紧急情况下割断绳索避免被追踪。后半本转入城市路线规划：哪些屋顶相连、哪些墙壁有裂缝、哪些窗户常年不锁。末页夹着一根磨损的钩索和一张手绘的城市屋顶图，上面用虚线标出了一条从贫民区通往贵族区的路线，旁边写着：街道属于卫兵，屋顶才属于你。装订线里缠着一根细小的钩索残段。

## 设计意图

为盗贼系提供垂直机动与城市场景探索能力，扩大潜入路径选择。
