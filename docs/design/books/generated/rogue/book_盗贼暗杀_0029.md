# 《死亡预告：让目标知道自己会死》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0029`
- **关联技能**：`assassin_death_notice`
- **使用效果**：阅读后解锁 `assassin_death_notice`；若已学会，提升 `current_mastery +130`，并使收到预告的目标在接下来三场战斗中受到暴击率 `+5%`。
- **阅读要求**：角色职业标签含 `assassin`；基础 `智力 ≥ 11` 或 `意志 ≥ 11`。
- **稀有度**：史诗（Epic）
- **建议投放**：传奇刺客遗物、血盟最高议会、史诗级暗杀委托奖励。

## 书籍内容

死亡预告是一种危险的艺术：它让目标提前知道自己将被杀害，却又不得不继续生活。作者认为，预告的真正目的不是恐吓，而是削弱目标的判断能力。一个知道自己将死的人会在保镖选择上犯错，会在饮食上疏忽，会在最意想不到的地方露出破绽。书中记录了七种经典预告方式：夹在早餐里的黑羽毛、画在卧室镜子上的日期、混入马厩草料中的枯萎花。每一种都配有后续观察要点，因为预告是否成功，取决于目标是否真的按照你预期的方式改变行为。后半本转入失败案例，讨论那些因为预告而变得更加警觉、甚至反过来设下陷阱的目标。末页有一张空白的预告模板，只印着一句话：最可怕的预告，是让目标在死前仍然怀疑自己是不是读懂了它。

书中附空白预告模板，边缘印着七种经典预告方式图示。模板下写着：预告一旦发出，你便成目标故事的一部分，再也无法抽身。

## 设计意图

为刺客系提供独特的预战斗 debuff 机制，鼓励玩家在多阶段任务中规划暗杀流程。
