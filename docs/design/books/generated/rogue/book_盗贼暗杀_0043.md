# 《瞬杀：在敌人眨眼间完成》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0043`
- **关联技能**：`assassin_instant_kill`
- **使用效果**：阅读后解锁 `assassin_instant_kill`；若已学会，提升 `current_mastery +160`，并使该技能对生命值低于 `20%` 的目标额外 `+5%` 斩杀成功率。
- **阅读要求**：角色职业标签含 `assassin`；基础 `敏捷 ≥ 13`；已学会 `assassin_throat_slit` 或 `assassin_backstab`。
- **稀有度**：史诗（Epic）
- **建议投放**：传奇刺客传承、血盟最终试炼、史诗暗杀委托奖励。

## 书籍内容

瞬杀不是速度的简单堆砌，而是让敌人在意识到死亡之前就已经无法挽回。作者把瞬杀分为预动、入杀与收势三个阶段，其中预动占了全书一半的篇幅。作者认为，真正决定瞬杀成败的是出手前那一瞬的身体状态：肌肉不能过紧，呼吸不能过浅，眼神不能有任何预兆。中间章节讲解如何选择入杀角度，如何利用目标的眨眼、咳嗽或转头作为启动信号。后半本转入失败后的补救，因为瞬杀一旦失手，暗杀者往往会暴露在极近距离内。作者建议练习者准备至少两种脱身方案，并在训练时反复模拟失手场景。末页有一段被血染红的文字，勉强可辨：我花了十年学会一刀，又花了十年学会在刀不中时活下去。

书末附瞬杀训练表，从预动到收势每阶段都标注时间要求。表下写着：瞬杀不是快，是把所有时间压缩到敌人反应不过来的密度里。

## 设计意图

作为刺客系高阶斩杀技能入口，斩杀成功率强化低血量目标的收割能力。
