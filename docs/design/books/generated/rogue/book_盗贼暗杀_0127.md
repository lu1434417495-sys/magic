# 《诱饵：让别人替你死》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0127`
- **关联技能**：`rogue_decoy`
- **使用效果**：阅读后解锁 `rogue_decoy`；若已学会，提升 `current_mastery +110`，并使诱饵吸引敌人的时间延长 1 秒。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `智力 ≥ 9`。
- **稀有度**：精良（Uncommon）
- **建议投放**：猎户小屋、工程学徒摊位、军方废弃仓库。

## 书籍内容

诱饵不是替身，而是替身的影子。这本书教人如何制作简单的人体诱饵：用稻草、旧衣与气味源组成一个能在黑暗中骗过一眼的轮廓。作者强调，诱饵的价值不在于逼真，而在于合理——它应该出现在敌人预期会看到人的地方，比如拐角后、门边或窗边。书中还讲解了声音诱饵的用法：一枚石子、一段提前录下的脚步、甚至一只被惊飞的鸽子，都能让追兵的注意力偏移数秒。中间章节讨论高级用法：让诱饵在移动中被发现，引导敌人进入埋伏。末页画着一个被箭射穿的稻草人，稻草从伤口里露出来，旁边写着：最好的诱饵不会被识破，因为它在识破前就已经完成了任务。

末页粘着一小撮稻草，散发着淡淡的烟火味；书页边缘有人用炭笔画了十几个稻草人，每个姿态都不相同，像是在排练一场只有凶手才能看懂的戏。

## 设计意图

为盗贼系提供战术误导技能，服务于潜行、脱身与团队配合中的仇恨控制。
