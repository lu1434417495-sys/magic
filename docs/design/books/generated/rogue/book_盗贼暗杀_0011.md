# 《易容笔记：三十六张脸》

## 书籍内容

易容不是戴面具，而是让别人在看到你时自动补充出一张熟悉的脸。书中把人脸拆解成三组信息：轮廓、节奏、缺陷。轮廓决定远看像谁，节奏决定举止像谁，缺陷则是最容易被记住也最容易被忽略的部分。作者强调，完美的伪装往往失败，因为过于完美会引发警觉；保留一两个无伤大雅的瑕疵，比如轻微的跛脚或口头禅，反而能让目标的大脑完成自我说服。中间章节记录三十六种基础脸型，每一种都配有简易材料清单：蜂蜡、木炭、棉布、动物胶。后半本转入角色扮演技巧，教导如何根据伪装身份调整呼吸深浅、步幅大小和视线落点。末页有一张被撕去大半的脸谱草图，只剩一只眼睛和一句话：不要变成你扮演的人，除非你想留下来。

附录收录三张简陋脸谱模具，对应老人、乞丐与军官。背面写着：易容最高境界不是别人认不出你，而是别人认出后主动替你解释。
