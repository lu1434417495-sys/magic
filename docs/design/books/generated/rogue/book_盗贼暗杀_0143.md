# 《血刃：以血养锋》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0143`
- **关联技能**：`assassin_blood_blade`
- **使用效果**：阅读后解锁 `assassin_blood_blade`；若已学会，提升 `current_mastery +140`，并使连续击杀后的下一次攻击伤害 +6%。
- **阅读要求**：角色职业标签含 `assassin`；基础 `敏捷 ≥ 11` 或 `体质 ≥ 10`。
- **稀有度**：史诗（Epic）
- **建议投放**：血祭神殿、狂战士废墟、黑暗锻造炉。

## 书籍内容

刀刃会记住它喝过的血。这本书介绍了一种被禁忌的养刃法：在每次击杀后用目标的血擦拭刀刃，让武器逐渐沾染死亡的气息。作者警告，这种方法会让武器越来越强，也会让使用者越来越难以控制杀意。书中详细讲解了不同血液对刀刃的影响：战士的血增加锋利，法师的血增加破魔，无辜者的血则会让刀刃在夜晚低语。中间章节讨论了道德代价：许多使用者在晚年都无法入睡，因为他们能听见刀上亡魂的声音。末页贴着一片干涸的血迹，形状像一把弯曲的刀，旁边写着：血刃不是武器，是债。

书页边缘呈暗红色，仿佛被血水反复浸染过；封底画着一把弯曲的刀，刀刃上滴落的不是血而是墨，旁边写着："血刃不是武器，是债。"某页空白处有人用血画了一个小小的骷髅，骷髅的眼眶里各插着一把迷你血刃。

## 设计意图

为刺客系提供高风险高回报的成长型武器机制，通过连杀强化持续作战能力。
