# 《钱袋里的艺术》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0113`
- **关联技能**：`rogue_pickpocket`
- **使用效果**：阅读后解锁 `rogue_pickpocket`；若已学会，提升 `current_mastery +100`，并使从精英目标身上窃取的成功率 +5%。
- **阅读要求**：角色职业标签含 `rogue` 或 `thief`；基础 `敏捷 ≥ 9`。
- **稀有度**：普通（Common）
- **建议投放**：集市窃贼导师、贫民窟孤儿院、旅行马戏团。

## 书籍内容

偷钱袋的最高境界不是不让对方发现，而是让对方发现后怀疑自己的记忆。作者把扒窃分为三步：接近、分离、消失。接近要靠环境拥挤或身份伪装，分离要靠手指的轻触转移注意力，消失则要靠一个恰到好处的第三方比如摔倒的孩子或突然吠叫的狗。书中详细讲解如何用中指和食指夹取目标袋中的物件而不拉动袋绳，以及如何在得手后把赃物立刻转交给同伙。中间章节有一整页画了手的骨骼运动图。末页贴着一张褪色的通缉令，上面的人据说就是作者本人，脸被墨涂黑，旁边写着：最好的窃贼从不出现第二次。

内页贴着半张被撕碎的悬赏单，被窃者的名字已被墨水涂黑；空白处有人练习画钱袋，画了一百多个都不满意，每个钱袋的褶皱都略有不同。封底内侧贴着半张被撕碎的通缉令，上面的人据说就是这本书的上一任主人。

## 设计意图

为盗贼系提供非战斗资源获取手段，把扒窃设计成需要环境判断与分心的微型玩法。
