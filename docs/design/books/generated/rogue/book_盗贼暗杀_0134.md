# 《双人配合：影子与主人》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0134`
- **关联技能**：`rogue_paired_assault`
- **使用效果**：阅读后解锁 `rogue_paired_assault`；若已学会，提升 `current_mastery +130`，并使与队友同时攻击同一目标时的伤害 +4%。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `敏捷 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：佣兵双人组遗物、盗贼公会合击训练、黑暗兄弟会藏书。

## 书籍内容

一个人的影子是黑暗的延伸，两个人的配合是死亡的折叠。这本书假设两名盗贼协同作战，一人负责吸引注意，一人负责致命一击。作者强调，配合的关键不是同步，而是互补：正面的人要制造足够的声音与动作，让敌人无暇顾及侧面；侧面的人则要在最合适的瞬间切入，不给目标反应时间。书中还讲解了暗号系统：一个咳嗽、一次弹指、一个特定的脚步节奏，都能在不说话的情况下传递攻击意图。中间章节讨论了失败时的责任：正面的人如果退得太早，会把队友暴露在危险中。末页画着两个背靠背的人影，旁边写着：最好的双人组不是互相信任，是互相需要。

封面上画着两个背靠背的人影，姿态与书中描述完全一致；末页夹着两枚相同的徽章，是某对著名双人组的遗物，据说他们死于同一次任务的同一秒。

## 设计意图

为盗贼系提供团队配合向技能，鼓励多人协作中的战术分工与同步爆发。
