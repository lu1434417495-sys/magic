# 《指节碎骨：近身擒拿致命点》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0157`
- **关联技能**：`rogue_knuckle_strike`
- **使用效果**：阅读后解锁 `rogue_knuckle_strike`；若已学会，提升 `current_mastery +120`，并使空手或匕首近身时造成 `破甲` 的概率 `+8%`。
- **阅读要求**：角色职业标签含 `rogue`；基础 `力量 ≥ 10` 且 `敏捷 ≥ 10`。
- **稀有度**：精良（Uncommon）
- **建议投放**：地下拳馆教练、拷问者密室、近战刺客训练营。

## 书籍内容

指节碎骨不讲招式漂亮，只讲哪里能最快让对手失去战斗力，作者曾是一名地下拳场的冠军。作者把人体关节比作房屋的铰链，指出只要破坏正确的铰链，再强壮的建筑也会倒塌。书中详细标注了指关节、腕骨、肘窝、膝侧等部位的受力方向，每种都配有简洁的击打角度说明，并提醒攻击时要瞄准关节的极限反方向。作者认为，最强壮的敌人往往在关节处最脆弱。中间章节讲解如何在贴身搏斗中创造机会：用肩膀撞击让对方失衡，用膝盖压制对方大腿，再用指节猛击暴露的骨缝。后半本转入反握匕首的应用，说明碎骨不是目的，而是为了让敌人的护甲缝隙暴露出来。末页有一只用炭笔画的握拳图，五个指节被标红，旁边写着：拳头不是刀，但拳头知道刀该去哪里。封底印着一只握紧的拳头，指节处微微凸起。

## 设计意图

为近战型盗贼提供破甲与控制入口，强化徒手与短兵相接的战斗风格。
