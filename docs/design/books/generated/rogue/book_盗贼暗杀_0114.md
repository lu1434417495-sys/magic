# 《追迹与反追迹》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0114`
- **关联技能**：`rogue_counter_tracking`
- **使用效果**：阅读后解锁 `rogue_counter_tracking`；若已学会，提升 `current_mastery +120`，并延长自身脚印被敌人识破所需时间 20%。
- **阅读要求**：角色职业标签含 `rogue` 或 `ranger`；基础 `感知 ≥ 9`。
- **稀有度**：精良（Uncommon）
- **建议投放**：猎人小屋、边境哨站、走私者驿站。

## 书籍内容

留下脚印是本能，消除脚印是技术。这本书首先教人如何追踪：观察草茎倒伏方向、泥土翻动痕迹、蜘蛛网的断裂位置。然后立刻教人如何反追踪：倒退行走混淆步向、沿着硬地或溪流移动、用树枝扫去明显痕迹。作者特别强调气味，指出猎犬比眼睛更可靠，因此建议携带强烈气味的草药或腐肉来干扰追踪。中间章节讲了一个残酷案例：有人为了完全消除痕迹，故意把追兵引入沼泽，结果自己也未能生还。末页用血写着：反追迹的最高境界不是无迹可寻，而是让追迹者自己放弃。

封皮内侧贴着一小块不同质地的泥土样本，是作者用来训练识别地面材质的教具；末页还画着几根不同动物的毛发，作为追踪与反追踪的对照标本。末页夹着一小段被磨亮的铁丝，是某位前辈用来练习手指灵活度的工具。

## 设计意图

为盗贼系提供逃生与野外生存技能，把追踪逻辑反过来用于隐匿行踪，增加探索深度。
