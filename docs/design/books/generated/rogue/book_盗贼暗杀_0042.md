# 《陷阱编织者：把战场变成猎场》

## 书籍内容

陷阱编织者把设陷阱比作写诗：每一个机关都是一句谎言，目的是让读者相信前方是安全的。书中把陷阱分为诱骗型、拖延型与杀伤型，强调最优秀的陷阱往往同时是三者。中间章节详细讲解触发机制的选择：压力板适合必经之路，绊索适合视野盲区，定时机关适合需要精确配合的伏击。作者还提醒，陷阱最大的敌人不是被发现，而是被触发后没有后续：一个孤零零的陷阱只会让敌人更警惕，一连串的陷阱才能真正瓦解士气。后半本转入伪装技巧，教导如何让陷阱融入环境，比如用落叶掩盖、用影子遮蔽、用敌人的尸体作为诱饵。末页有一张未完成的陷阱图纸，旁边写着：最好的陷阱，是让目标在踩中之前就已经决定要走这条路。

附录详列基础陷阱触发机制与伪装思路，附 spike 陷阱图纸。背面写着：最好陷阱不是最隐蔽，而是让目标在看到前就已决定踩上去。

## 设计意图

为盗贼系提供战场控制与预置伤害能力，配方解锁连接制作与战斗循环。
