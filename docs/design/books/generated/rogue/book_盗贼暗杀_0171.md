# 《猎人与猎物的逆转》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0171`

## 书籍内容

盗贼最危险的时刻不是潜行时，而是被发现后，这本书的作者声称自己曾被一支军队追杀了整整七天。这本书教授如何把追击者变成猎物。作者认为，被追击者的优势在于信息：你知道自己的逃跑路线，而敌人只能跟随。书中教导如何利用这个不对称性设置简易陷阱、选择狭窄地形、制造假足迹。中间章节讲解心理逆转：让追击者从谨慎变成愤怒，从愤怒变成盲目，再从盲目变成尸体。作者认为，追击者最大的弱点是自负，他们很难相信自己追逐的目标会突然转身。后半本转入体能分配：何时该全力奔跑拉开距离，何时该突然停下反向冲刺。末页有一张被撕碎的地图，碎片上用箭头标出了几个反杀点，旁边写着：不要跑向安全，要跑向你能杀人的地方。封皮上沾着泥土和草屑，像刚从野外取回。

## 设计意图

为盗贼系提供被追反打能力，把劣势追击转化为爆发输出窗口。
