# 《毒龙涎：龙血与剧毒的融合》

- **书籍 ID**：`book_盗贼暗杀_0197`

## 书籍内容

龙血本身剧毒，而它与凡间毒草融合后会产生连龙族都难以承受的烈毒。这本书记载了采集龙血、稳定其活性并与常规毒素调和的禁忌配方，作者据说是一条垂死毒龙的最后仆人。作者强调，每一次调制都是在与死亡共舞，稍有不慎就会让毒师先一步化为脓血。中间章节讲解不同龙种的血液特性：火焰龙的血会燃烧、冰霜龙的血会冻结、暗影龙的血会吞噬光线。书中还记载，龙毒对龙族自身同样有效，这也是古代屠龙者最后的杀手锏。后半本转入应用：如何让武器承载这种不稳定的毒液，如何在战斗中避免被自己的毒反噬。末页有一片发黑的龙鳞被夹在书中，鳞片上仍残留着腐蚀痕迹，配文：凡人用毒杀人，勇者用龙毒弑神。书页间夹着一片发黑的龙鳞碎片。书中强调，龙毒调制必须在通风处进行，否则连空气都会变成毒。
