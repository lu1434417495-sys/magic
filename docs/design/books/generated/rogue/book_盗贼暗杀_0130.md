# 《暗影步：借影移动》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0130`
- **关联技能**：`rogue_shadow_step`
- **使用效果**：阅读后解锁 `rogue_shadow_step`；若已学会，提升 `current_mastery +150`，并使暗影步后的下一次背刺伤害 +6%。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `敏捷 ≥ 12` 或 `意志 ≥ 10`。
- **稀有度**：史诗（Epic）
- **建议投放**：暗影神殿核心、传奇刺客传承试炼、深渊裂隙宝箱。

## 书籍内容

阴影不是光的缺席，而是另一种地形。这本书教授一种古老的移动技巧：在阴影之间快速穿行，借助光线的边界缩短自己与目标的距离。作者警告，暗影步不是传送，而是把身体交给阴影的流动；如果在强光下强行发动，施术者会在半空中被灼伤。书中详细讲解了不同光源下的阴影质量：烛光最不稳定，月光最温和，正午的阳光则几乎没有可用之影。中间章节还讨论了心理准备：使用暗影步时必须放弃一部分自我意识，否则会被阴影中的低语干扰。末页是一整页的黑色，只在角落用银粉写着：走进去之前，先确认你愿意从另一边出来。

某些段落只有在烛光下才能看清，日光下只剩一片空白；封底用银粉画着一个人形轮廓，像是作者留下的最后练习，轮廓边缘已经因反复触摸而模糊。封底用银粉画着一个月亮，只有在完全黑暗的环境中才会显现完整轮廓。

## 设计意图

为盗贼系提供高阶位移技能，把光影环境转化为战略资源，与背刺体系形成连招。
