# 《千面幻术：化身任何人》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0198`
- **关联技能**：`rogue_thousand_faces`
- **使用效果**：阅读后解锁 `rogue_thousand_faces`；若已学会，提升 `current_mastery +160`，并使变身持续时间 `+25%`。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `魅力 ≥ 13` 且 `智力 ≥ 13`。

- **建议投放**：幻术师密室、无面者高阶传承、史诗级间谍任务奖励。

## 书籍内容

千面幻术不是戴上面具，而是让自己的血肉暂时相信它是另一个人，这本书的作者据传已经忘记了本来的模样。这本书教授如何借助魔法与心理暗示，在视觉上完全化身为目标或任意普通人。作者指出，幻术的弱点在于行为：如果你走路的方式不像那个人，再完美的脸也会暴露。中间章节讲解如何快速学习一个人的举止：抓握杯子的手势、坐下的角度、说话的停顿。后半本转入高级技巧：如何同时维持多个虚假身份，以及如何在身份切换时不留下记忆裂痕。作者提醒，幻术持续期间若受伤流血，血液会以原本形态出现，从而暴露真实身份。末页贴着三十六张小画像，每张都略有不同，配文：脸有一千种，但能让你活下来的，只有你最像的那一张。书的最后几页贴满了不同身份的小画像。作者警告，幻术无法伪造血液的流向，受伤时必须格外小心。

## 设计意图

为高阶盗贼提供完整变身能力，支持长期潜入与身份替换任务。
