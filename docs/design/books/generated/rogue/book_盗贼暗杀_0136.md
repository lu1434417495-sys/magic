# 《金蝉脱壳：预先退路》

## 书籍内容

进入一个地方之前，先找到三个出口。这本书强调，任何任务的成败都取决于退路是否可靠。作者把退路分为明退、暗退与死退：明退是正常通道，暗退是只有少数知道的密道，死退则是在无路可走时自己创造的出口。书中详细讲解了如何快速评估建筑结构：承重墙、通风管、天窗、地下排水口都可能成为生路。中间章节记录了多个城市据点的秘密通道，并提醒读者：一张地图只记录入口，出口永远要自己确认。末页用红笔画了一个圈，圈内写着：计划 A 是完成任务，计划 B 是活着离开，计划 C 是把计划 A 忘掉。

书脊中藏着一张更小的地图，标注了作者从未告诉任何人的密道；地图背面写着一句话："永远不要把所有出口画在同一张纸上"，墨迹已经晕开。书中还讲解了如何在撤退时故意留下假线索，让追兵走向完全相反的方向。
