# 《断指：拷问与情报提取》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0017`
- **关联技能**：`rogue_interrogation`
- **使用效果**：阅读后解锁 `rogue_interrogation`；若已学会，提升 `current_mastery +110`，并提高从俘虏或可疑 NPC 处获得情报的 `+7%` 成功率。
- **阅读要求**：基础 `意志 ≥ 10`；角色无 `holy` 标签。
- **稀有度**：精良（Uncommon）
- **建议投放**：地下审讯室、密探组织档案、战争罪犯遗物。

## 书籍内容

书名中的断指不是比喻，而是作者列出的三十七种逼供手段中排名最末的一项。作者认为，肉体的痛苦往往是最低效的情报来源，因为人在剧痛中会编造任何能中止痛苦的内容。真正有效的方法是瓦解目标的心理预期：先让对方以为你知道的比实际更多，再让其在填补空白的过程中暴露真相。中间章节详细讲解节奏控制，如何在长时间沉默与突然提问之间切换，如何利用目标之间的矛盾证言互相印证。后半本转入自我防护，提醒拷问者不要对自己的手段产生感情，也不要在事后追问情报的真实性。末页有一段被划掉的誓言，隐约可见：我发誓只对那些该受折磨的人使用这些方法。下面有人用另一种笔迹写道：谁该受折磨，由谁决定？

附录是情报评估表，含验证拷问所得真实性的 checklist。表末写道：痛苦让人说出一切，包括真相与谎言，区分二者才是拷问者真正的工作。

## 设计意图

为盗贼系提供情报获取与剧情推进能力，同时用伦理张力限制其泛用性。
