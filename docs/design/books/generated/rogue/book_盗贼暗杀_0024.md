# 《夜之眼：低光环境下的猎杀》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0024`
- **关联技能**：`rogue_night_vision`
- **使用效果**：阅读后解锁 `rogue_night_vision`；若已学会，提升 `current_mastery +100`，并使夜晚或昏暗区域首次攻击命中率 `+6%`。
- **阅读要求**：基础 `感知 ≥ 10`；角色职业标签含 `rogue` 或 `assassin`。

- **建议投放**：夜行猎人营地、地下墓穴入口、兽人斥候遗物。

## 书籍内容

夜之眼不是魔法，而是一套让眼睛习惯黑暗的方法。作者告诫读者，进入黑暗后不要立即寻找光源，因为瞳孔需要时间扩张，而任何突然的亮光都会重置这个过程。书中把夜间视物分为辨形与辨动：辨形依赖边缘视觉，直视反而看不清；辨动则依赖对光线变化的敏感，比如敌人移动时遮挡了远处的微弱光源。中间章节讲解如何利用对手的灯火反制对方，如何让自己始终处于对方光源之外，如何在必要时用一小块反光物误导敌人的视线。后半本转入保护视力的练习，因为长期夜间活动会损害色觉与远视能力。末页有一行被反复描粗的字：在黑暗中看清别人之前，先学会不让自己被看清。

附录是夜间活动后眼部保养清单，含洗眼液配方与避光建议。末页写着：夜视者的眼睛是资本，挥霍它的人终会在白天成为瞎子。

## 设计意图

为盗贼系提供环境适应技能，夜间命中率加成与潜行玩法形成天然协同。
