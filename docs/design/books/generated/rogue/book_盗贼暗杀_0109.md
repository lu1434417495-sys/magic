# 《烟幕：脱身与反制》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0109`
- **关联技能**：`rogue_smoke_bomb`
- **使用效果**：阅读后解锁 `rogue_smoke_bomb`；若已学会，提升 `current_mastery +120`，并使烟幕中的首次闪避 +8%。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `敏捷 ≥ 10`。
- **稀有度**：精良（Uncommon）
- **建议投放**：炼金商人、忍者流亡者、港口黑市。

## 书籍内容

烟幕是盗贼的逗号，让句子在不该停顿的地方停顿。这本书不仅讲如何扔烟幕弹，更讲什么时候不该扔：顺风时烟会飘向自己，密闭空间里烟会困住双方，而面对听觉敏锐的对手，烟幕反而会让你失去距离感。作者把烟幕用法分为脱身、分割、误导三类，每一类都配有配方与投掷角度图。书中特别警告，不要在烟幕中奔跑，脚步声会在烟雾里被放大；应该慢步移动，用触觉和记忆代替视觉。末页有一段被烧焦的附注：最高级的烟幕不是让敌人看不见你，而是让他们以为看见了你的影子。

封底内侧贴着一小块被烟薰黑的布片，据说是从某位成功脱身的刺客衣角上剪下的；书中还散落着几粒细小的沙砾，仿佛刚从某个沙漠据点取出。某页边缘画满了小烟雾图案，每个图案旁边都写着不同的风向与投掷角度。

## 设计意图

为盗贼系提供战术控场与逃生技能，强调烟幕是决策工具而非无脑保命符。
