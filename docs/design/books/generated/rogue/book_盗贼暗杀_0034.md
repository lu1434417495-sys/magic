# 《赌徒的匕首：运气与计算》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0034`
- **关联技能**：`rogue_gambit_strike`
- **使用效果**：阅读后解锁 `rogue_gambit_strike`；若已学会，提升 `current_mastery +130`，并使该技能在命中时 `+5%` 触发额外连击。
- **阅读要求**：基础 `敏捷 ≥ 10` 或 `幸运 ≥ 8`；角色职业标签含 `rogue`。
- **稀有度**：精良（Uncommon）
- **建议投放**：赌场后台、赌徒刺客、地下彩票商人。

## 书籍内容

赌徒的匕首把战斗比作一场永远无法预知结果的赌局。作者认为，最好的攻击不是确定能命中的攻击，而是让敌人必须猜测的攻击。书中教授如何在出手前制造多个真假难辨的威胁点，让敌人的防御选择变成一种赌博。中间章节讲解风险回报：高风险的招式一旦失败会暴露巨大破绽，但一旦成功则能瞬间扭转战局。作者建议读者在每次战斗前设定自己的止损线，知道什么时候该继续进攻，什么时候该收手撤离。后半本转入心理博弈，教导如何通过表情和动作让对手误判自己的下一步。末页有一枚被压扁的铜币，旁边写着：真正的赌徒不是靠运气赢，而是让对手以为你靠运气赢。

附录是风险评估表，教导计算赌局期望收益。表末写着：赌徒的敌人不是运气，而是误以为运气属于自己。

## 设计意图

为盗贼系提供高风险高回报的连击技能，概率触发强化战斗中的不确定性乐趣。
