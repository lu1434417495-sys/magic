# 《夹缝中的呼吸》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0104`
- **关联技能**：`rogue_stillness_breath`
- **使用效果**：阅读后解锁 `rogue_stillness_breath`；若已学会，提升 `current_mastery +130`，并使静止潜伏时的体力恢复速度提升 10%。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `体质 ≥ 8`。
- **稀有度**：精良（Uncommon）
- **建议投放**：阴影礼拜堂、密探藏身点、黑夜巡逻路线终点。

## 书籍内容

真正的藏匿不是躲进黑暗，而是成为黑暗的一部分。这本书教授一种特殊的呼吸法：吸气三拍、屏息六拍、呼气九拍，让呼吸周期与常人的心跳节奏错开，从而降低被感知的概率。作者声称，最高明的潜伏者连老鼠都不会惊动，因为他们闻起来像墙壁、听起来像空气。书中花了整整一章讨论体温：在寒冷环境中，呼出的白气会暴露位置；在炎热环境中，汗水滴落的声音同样致命。作者建议练习者含着一小块冰进行呼吸训练，直到能在不颤抖的前提下维持低速呼吸。末页被撕去一角，只剩一句话：当你觉得自己已经藏得很好时，再藏深一层。

书脊里夹着一小片炭，据说是在某座大教堂通风管中留下的；空白页画着呼吸节奏表，旁边标注着不同环境下的调整建议，以及几个被红笔圈出的错误示范。

## 设计意图

强化盗贼系潜伏与耐心玩法，把呼吸节奏与体力管理绑定，鼓励长期观察后再行动。
