# 《暗杀者的伦理：何时不该出手》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0041`
- **关联技能**：`assassin_restraint`
- **使用效果**：阅读后解锁 `assassin_restraint`；若已学会，提升 `current_mastery +100`，并使主动放弃一次不必要的击杀后，下一次暗杀伤害 `+8%`。
- **阅读要求**：角色职业标签含 `assassin`；基础 `意志 ≥ 12`。
- **稀有度**：稀有（Rare）
- **建议投放**：退隐刺客、修道院密藏、救赎任务奖励。

## 书籍内容

这本书在刺客群体中既被尊敬也被厌恶，因为它讨论的不是如何杀人，而是什么时候不该杀人。作者认为，无差别的杀戮会让暗杀者变成工具，而工具最终会被丢弃。书中列出五种不应出手的情况：目标身边有孩童、目标正在救治他人、目标已被击败且无反抗能力、契约本身来自更肮脏的权力、以及你发现自己享受杀戮本身。中间章节讲解如何在不杀的情况下完成任务，比如恐吓、盗窃证据或破坏计划。后半本转入自我审视，作者承认自己也杀过不该杀的人，并把这些经历作为警告而非荣耀。末页有一段用褪色墨水写的誓言：我的手属于阴影，但我的心必须保留一部分属于光明；否则，我杀的每一个人都会把我拖得更深。

书末附白鸦誓约复制品，列刺客不应出手的五种情况。复制品下写着：restrain 不是软弱，是把杀意存在合适处，等更有价值时再花出去。

## 设计意图

为刺客系提供机制化的克制与奖励，鼓励玩家在非必要时不滥杀，强化角色扮演深度。
