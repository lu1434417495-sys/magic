# 《肾上腺素：疼痛抑制剂》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0133`
- **关联技能**：`rogue_adrenaline_control`
- **使用效果**：阅读后解锁 `rogue_adrenaline_control`；若已学会，提升 `current_mastery +120`，并使生命值低于 25% 时的攻速 +5%。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `体质 ≥ 9`。
- **稀有度**：稀有（Rare）
- **建议投放**：战地医师私藏、角斗士训练营、刺客公会医疗室。

## 书籍内容

疼痛是身体的警报，但刺客有时需要把警报关掉。这本书教人如何在受伤后快速调动肾上腺素：通过控制呼吸、集中注意力和特定的肌肉收缩，让身体进入一种痛觉迟钝但动作敏捷的状态。作者警告，这种状态不能持续太久，否则会在效果结束后加倍反噬。书中还讲解了如何区分可以忽略的疼痛与必须处理的伤害：尖锐的刺痛往往是器官受损，钝痛则可能只是肌肉挫伤。中间章节有多个案例，记录了使用者在濒死边缘反杀的经历。末页用血写着：肾上腺素不是勇气，是身体借给你的高利贷。

书页边缘有牙印，据说是某位读者在训练时咬出来的；空白处用红笔写着："痛是信号，不是命令"，下面还有一行小字："但信号有时候比命令更响。"封底画着一颗正在剧烈跳动的心脏，旁边标注着"控制在此时此地"。

## 设计意图

为盗贼系提供低血量反击机制，强化高风险高回报的刺客战斗风格。
