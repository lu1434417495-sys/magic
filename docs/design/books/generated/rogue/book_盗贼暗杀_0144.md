# 《幻术：让自己看起来不在》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0144`
- **关联技能**：`rogue_misdirection`
- **使用效果**：阅读后解锁 `rogue_misdirection`；若已学会，提升 `current_mastery +120`，并使误导成功后自身的闪避率 +5% 持续 3 秒。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `智力 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：魔术师后台、幻术师塔楼、街头艺人营地。

## 书籍内容

最高明的消失不是让自己看不见，而是让别人看向他们以为你在的地方。这本书从街头魔术中借来了误导技巧：用大幅度的动作吸引注意，用突然的声音打断判断，用熟悉的场景降低警惕。作者强调，误导的核心不是快，而是合理——观众会自己脑补一个解释，你要做的只是给他们一个足够好的解释。书中还讲解了战斗中的误导：假装攻击左侧让敌人重心偏移，再从右侧切入；假装逃跑引追兵进入陷阱。中间章节有一整页只有一个词：看这里。末页画着一个空无一人的舞台，聚光灯下只有一顶帽子，旁边写着：最伟大的魔术，是让你怀疑自己是不是真的看过我。

某些插图从不同角度看会呈现不同图案，是练习误导的绝佳素材；末页用银粉写着："观众的眼睛会欺骗自己"，落款是一个从未被追查到的名字。

## 设计意图

为盗贼系提供高阶控场与闪避技能，强化心理战与空间欺骗的战斗维度。
