# 《毒镖：远程下毒》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0148`
- **关联技能**：`rogue_poison_dart`
- **使用效果**：阅读后解锁 `rogue_poison_dart`；若已学会，提升 `current_mastery +120`，并使毒镖的射程 +10%。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `敏捷 ≥ 10` 且 `智力 ≥ 8`。
- **稀有度**：精良（Uncommon）
- **建议投放**：炼金术士摊位、毒师工坊、丛林部落。

## 书籍内容

毒镖把死亡从近身推向远处，也把风险从刀尖推向风。这本书教人如何制作与使用毒镖：选择轻而稳定的镖身，在镖尖涂抹适量毒药，用吹管或短弩发射。作者强调，毒镖的难点在于剂量控制——太少无效，太多会在命中前滴落。书中还讲解了不同毒药的适用场景：麻痹毒适合活捉，剧痛毒适合瓦解斗志，慢性毒则适合制造自然死亡假象。中间章节警告，使用毒镖时必须注意风向，否则毒药可能反吹到自己脸上。末页画着一个被毒镖擦伤脖颈的守卫，他正低头查看伤口，旁边写着：等他发现时，已经没时间喊了。

书页用极薄的纸印刷，翻阅时几乎不会发出声音；封底用针刺着一句话："幽灵不是不存在，是不被记住"，旁边有人补了一句："而被记住的，都死了。"封底内侧贴着一小段被毒药染绿的布条，旁边写着"风向错误时的惨痛纪念"。

## 设计意图

为盗贼系提供远程毒伤技能，扩展毒药玩法的应用场景与战斗距离。
