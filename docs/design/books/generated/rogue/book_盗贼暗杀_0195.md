# 《终极隐身：存在感抹除》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0195`
- **关联技能**：`rogue_presence_erase`
- **使用效果**：阅读后解锁 `rogue_presence_erase`；若已学会，提升 `current_mastery +200`，并使进入战斗前 `3` 秒内完全移除自身存在感（对普通敌人无效化警戒）。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `敏捷 ≥ 16` 且 `意志 ≥ 14`。
- **稀有度**：传说（Legendary）
- **建议投放**：传说级影界试炼、世界BOSS掉落、隐藏传承任务。

## 书籍内容

终极隐身不是看不见，而是让整个世界在某个瞬间忘记你存在，这本书记载的技艺危险而古老，据说连神明的目光都能避开。通过极致的静止、呼吸控制和意志收缩，让自身存在感降至接近零。作者警告，这种状态下不能有任何攻击意图，否则会被立刻拉回现实。中间章节讲解如何在存在感抹除期间移动、如何穿过警戒区域、以及如何在必要时把存在感转移到一个物体上。书中警告，若连续三次在存在感抹除期间被攻击打断，施术者可能会短暂失去自我意识。后半本转入代价：频繁使用会让施术者在日常生活中也偶尔感到自己正在消失。末页几乎空白，只在中央写着一行小字：当你彻底消失时，要确认自己还想回来。书的重量似乎比同样厚度的书轻一些。作者认为，存在感抹除最危险的不是敌人，是自己可能会忘记回来的路。

## 设计意图

作为传说级潜行技能，提供短暂时机内的绝对通过能力，是盗贼系终极目标之一。
