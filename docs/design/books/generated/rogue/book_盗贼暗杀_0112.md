# 《夜游：黑暗适应训练》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0112`
- **关联技能**：`rogue_night_vision`
- **使用效果**：阅读后解锁 `rogue_night_vision`；若已学会，提升 `current_mastery +110`，并减少黑暗环境下的感知判定惩罚 1 级。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `感知 ≥ 9`。
- **稀有度**：精良（Uncommon）
- **建议投放**：夜行神殿、地下墓穴、无光迷宫宝箱。

## 书籍内容

人眼适应黑暗需要时间，但刺客没有那么多时间。这本书教授一种加速暗适应的方法：进入黑暗前先闭紧双眼三十秒，让瞳孔提前扩张；进入黑暗后不要直视光源，用余光捕捉移动。作者警告，绝对黑暗并不存在，总有微光从门缝、天花板或远处传来，要学会把这些微光当作地图上的等高线。书中还讨论了反制：当你知道敌人在适应黑暗时，一次短暂的闪光比持续照明更致命。末页有一段被反复涂抹的笔记，最终只剩一行：别让黑暗成为你的盟友太久，它会要求你留下眼睛。

书页在黑暗中会发出极微弱的磷光，只有完全暗适应后才能看见；封底用针刺出一句话："别让光找到你的眼睛"，字迹细如发丝，必须贴近才能辨认。某页空白处有人用银针扎出一片星空，标注着不同月光下阴影的最佳质量。

## 设计意图

为盗贼系提供环境感知技能，强化夜间与地下场景的作战优势，增加战术选择。
