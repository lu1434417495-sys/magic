# 《毒理笔记：七叶钩吻》

## 书籍内容

七叶钩吻不是最强的毒，却是最难被察觉的毒。这本笔记用草图和污迹记录了一位无名调配师几十年的实验，每一页都散发着淡淡的苦杏仁味。作者强调，下毒的关键不在于剂量，而在于时机与载体：清晨空腹时效果最好，混入温酒比冷水更难被味蕾捕捉。书中详细对比了叶片、根茎、花蜜三种取材方式的差异，指出花蜜毒性最弱却最容易让目标在数日内持续虚弱，适合制造他病死去的假象。中间有几页被烧焦，只能读到：过量会呕吐，呕吐会暴露一切。末页贴着一片干枯的七叶叶子，叶脉上用银针刺着一行小字：医者救人，我们救目标脱离生命。

末页夹着一张褪色药方，警告新手绝不可把钩吻与蜂蜜同煮；书脊内侧有褐色污渍，疑似某位前人实验时不慎沾染，旁边还粘着一小片干枯的七叶叶子作为标本。
