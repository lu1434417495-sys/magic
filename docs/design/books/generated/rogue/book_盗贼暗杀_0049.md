# 《影子分身：制造第二个自己》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0049`
- **关联技能**：`rogue_shadow_decoy`
- **使用效果**：阅读后解锁 `rogue_shadow_decoy`；若已学会，提升 `current_mastery +150`，并使分身存在时自身被单体技能选中的概率 `-10%`。
- **阅读要求**：基础 `敏捷 ≥ 12` 且 `智力 ≥ 10`；已学会 `rogue_shadow_cloak` 或 `rogue_shadow_step`。

- **建议投放**：影法师遗迹、暗影神殿藏书、高阶幻术黑市。

## 书籍内容

影子分身不是真正的分身，而是让敌人相信自己看到了两个你。作者把这项技术分为残影与诱影两种：残影利用快速移动留下的视觉残留，诱影则用斗篷、反光物或小型机关制造虚假轮廓。书中强调，最成功的分身不是最像人的那个，而是最符合敌人预期的那个。中间章节讲解如何控制分身的位置，让它处于敌人的攻击路径上，同时让自己处于敌人转身后的死角。后半本转入高级应用，教授如何在分身被识破后立刻切换到另一种欺骗方式。作者警告，长期使用影子分身会让暗杀者产生自己有两个身体的错觉，这种错觉在实战中极其危险。末页有一幅插图，一个人站在烛光下，墙上却映出两个影子， caption 写着：当你学会制造第二个自己时，别忘了哪一个才是真正的你。

书末附影子分身练习示意图，人影正与自己的倒影交换位置。图下写着：当你能制造第二个自己时，真正的危险是忘记哪一个才真实。

## 设计意图

为盗贼系提供高阶闪避与欺骗技能，概率降低被单体集火的风险。
