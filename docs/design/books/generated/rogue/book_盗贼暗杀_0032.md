# 《致命玩笑：毒药与喜剧的边界》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0032`
- **关联技能**：`rogue_laughing_gas`、`rogue_confusion_poison`
- **使用效果**：阅读后随机解锁 `rogue_laughing_gas` 或 `rogue_confusion_poison`；若均已学会，提升 `current_mastery +120`，并使混乱类毒剂影响目标数上限 `+1`。
- **阅读要求**：基础 `智力 ≥ 10`；已学会 `rogue_basic_poison`。
- **稀有度**：稀有（Rare）
- **建议投放**：疯狂炼金术士实验室、小丑刺客藏身处、狂欢节日隐藏商人。

## 书籍内容

这本书的作者显然精神状态不太稳定，因为他坚持把下毒变成一场表演。书中认为，让敌人发狂或互相猜忌，比直接杀死他们更有效，因为混乱会替你完成剩下的工作。笑气章节讲解如何让目标在不受伤的情况下丧失战斗力，强调剂量控制，因为笑过头的人会缺氧。混乱毒剂章节则教授如何让一群人开始怀疑身边的同伴，从微小幻觉到错误记忆。中间章节是一本笔记，记录作者在各种场合的实验结果，包括一次让整支巡逻队笑到脱力的成功案例。后半本转入风险提醒：混淆友军与敌人的界限，最终也可能混淆自己。末页有一段用彩色墨水写的宣言：死亡是最终的答案，但笑声是更好的问题。旁边有人用黑色墨水批注：这人最后被自己的笑话毒死了。

附录记录笑气与幻觉毒剂配方变体，但每种都缺关键剂量。页边写着：混乱是工具，但工具没有主人时，会反噬最近的所有人。

## 设计意图

扩展毒系技能的控制与混乱分支，增加战场扰乱与群体 debuff 选择。
