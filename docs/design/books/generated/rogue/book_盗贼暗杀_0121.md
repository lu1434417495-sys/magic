# 《玻璃行走：无声通过》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0121`
- **关联技能**：`rogue_glass_walk`
- **使用效果**：阅读后解锁 `rogue_glass_walk`；若已学会，提升 `current_mastery +100`，并使碎玻璃或类似地面上的移动噪音降低 50%。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `敏捷 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：贵族温室、珠宝商密室、玻璃工匠工坊。

## 书籍内容

真正的无声不是踩在柔软的东西上，而是踩在尖锐的东西上而不让它尖叫。这本书教人如何在碎玻璃、瓦砾与干枝上行走：重心的分配要慢而连续，脚掌先外侧着地再滚动到内侧，避免任何突然的垂直冲击。作者把这种方法称为喂地，意思是把体重一点一点交给地面，而不是一次性砸下去。书中还讲解了如何用披风或软布提前铺出临时通道，以及如何在行走时通过哼唱极低频的声音掩盖残余噪音。末页有一张用血指印按出的图，像是一只脚正踏在碎玻璃上，旁边批注：地面从不主动背叛你，除非你先背叛了它。

书页间夹着一块碎玻璃，棱角已被岁月磨圆；封底画着一只脚踏在碎玻璃上的简笔画，旁边标注"重心分散"，以及三个被圈出的错误落地姿势。某页空白处画着一个人正在倒退行走，旁边标注着"这是正确的反追踪步态"。

## 设计意图

为盗贼系提供高难度环境通过技能，把地形 hazard 转化为可控的移动挑战。
