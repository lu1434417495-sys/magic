# 《暗杀者的冥想：杀意归零》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0150`
- **关联技能**：`assassin_killing_intent_control`
- **使用效果**：阅读后解锁 `assassin_killing_intent_control`；若已学会，提升 `current_mastery +130`，并使目标感知到的杀意降低 15%。
- **阅读要求**：角色职业标签含 `assassin`；基础 `意志 ≥ 11`。
- **稀有度**：史诗（Epic）
- **建议投放**：暗影神庙冥想室、传奇刺客隐居地、高级暗杀传承。

## 书籍内容

杀意是有重量的，敏锐的目标能在你出手前就感觉到。这本书教授一种特殊的冥想技巧：在行动前把杀意压缩成一个极小的点，藏在意识的深处，直到需要释放的瞬间。作者把这种方法比作把刀收进最紧的鞘里，越紧，出鞘时越快。书中还讲解了如何在日常生活中保持这种控制：不对弱者流露轻视，不对强者流露敌意，让所有人觉得你只是一个影子。中间章节警告，长期压抑杀意会在梦中反噬，许多使用者在晚年都会被噩梦追逐。末页是一片空白，只在中央有一个墨点，旁边写着：当这个点消失时，你的刀就到了。

书中夹着几张不同城市的当票，背面写着各自的销赃联系人；末页用密码写着一个名字，据说是最可靠的买家，但没有人知道这个名字是否已经过期。书中还讲解了如何在冥想时区分真正的杀意与日常的愤怒，这是初学者最大的难关。

## 设计意图

为刺客系提供高阶反侦测能力，降低被感知型敌人发现的风险，强化暗杀成功率。
