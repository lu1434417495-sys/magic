# 《血钱：刺客的契约与报酬》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0047`
- **关联技能**：`assassin_contract_bond`
- **使用效果**：阅读后解锁 `assassin_contract_bond`；若已学会，提升 `current_mastery +120`，并使完成契约任务时获得的金币与声望 `+6%`。
- **阅读要求**：角色职业标签含 `assassin`；基础 `智力 ≥ 9`。
- **稀有度**：精良（Uncommon）
- **建议投放**：血盟财务室、契约商人、刺客公会奖励。

## 书籍内容

血钱不是教你如何杀人，而是如何把你的死亡手艺变成可持续的生意。作者从契约的书写开始讲起：目标描述必须精确到姓名、外貌与近期行踪，报酬结构要明确预付款与尾款比例，违约条款要比目标的生命更能约束双方。中间章节讲解如何评估一个契约是否值得接：目标的身份会引来多少追查，雇主是否有能力支付，失败后的代价是否高于成功后的收益。后半本转入职业道德，讨论刺客是否应该过问目标为何该死。作者认为不过问是保护双方，但完全不过问会让人变成纯粹的凶器。末页夹着一份泛黄的契约模板，上面的金额和名字都被涂黑，只剩一行：我取走他的命，你取走我的债；从此两清。

书末附简易契约模板，包括预付款、尾款与违约条款示例。模板下写着：血钱是刺客的尊严，也是刺客的枷锁。

## 设计意图

为刺客系提供经济循环与任务收益加成，契约机制强化角色扮演与成长反馈。
