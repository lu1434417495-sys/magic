# 《绷带下的匕首：医疗伪装》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0145`
- **关联技能**：`rogue_medical_disguise`
- **使用效果**：阅读后解锁 `rogue_medical_disguise`；若已学会，提升 `current_mastery +100`，并使医疗伪装身份下的搜查豁免 +5。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `智力 ≥ 9` 或 `魅力 ≥ 9`。
- **稀有度**：稀有（Rare）
- **建议投放**：战地医院、慈善修女会、贵族疗养院。

## 书籍内容

没有人会认真检查一个忙着救人的人。这本书教人如何伪装成医师、护士或草药师进入戒备森严的场所：从基本的包扎手法到常见的草药名称，从搀扶病人的姿势到安慰家属的语气。作者强调，医疗伪装最大的掩护不是服装，而是行为——一个真正救人的人会本能地避开危险区域，而这种回避恰恰能带你进入核心地带。书中还讲解了如何在药箱中藏武器、如何在绷带下固定短刀、以及如何在救治目标真手下时制造意外。末页有一张被药水渍染黄的处方，上面写着：救一个人可以藏起九十九个秘密。

书内夹着半张处方笺，笔迹与某位知名医师惊人相似；封底内侧贴着一小枚医师徽章，背面刻着伪造者的标记，以及一行小字"足以通过三家医院的检查"。书中还教人如何在医疗伪装被识破时，用一句正确的医学术语重新取回信任。

## 设计意图

为盗贼系提供剧情向身份伪装技能，扩展任务进入方式与社会渗透玩法。
