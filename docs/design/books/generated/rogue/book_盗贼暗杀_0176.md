# 《影子契约：召唤影兽》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0176`
- **关联技能**：`rogue_shadow_pact`
- **使用效果**：阅读后解锁 `rogue_shadow_pact`；若已学会，提升 `current_mastery +150`，并使影兽存在期间自身潜行效果 `+10%`。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `智力 ≥ 13` 且 `意志 ≥ 12`。
- **稀有度**：史诗（Epic）
- **建议投放**：影界裂隙、古代影法师陵墓、史诗级召唤任务奖励。

## 书籍内容

每个人都有影子，但只有少数人敢与自己的影子签订契约，这本书的每一页都像是从某种黑色薄膜上裁下来的。这本书教授如何从黑暗中召唤一只由自己影髓构成的野兽，它会听从简单的命令，也能在战斗中分散敌人注意。作者强调影兽不是宠物，而是另一个自己：你强它便强，你恐惧它便扭曲。中间章节讲解契约的代价：每次召唤都会消耗一部分体力与精神，连续召唤会让施术者的影子变薄。作者提醒，影兽受伤时施术者会在同样的位置感到刺痛。后半本转入指挥技巧：如何让影兽模仿自己的动作、如何让它发出声音引开守卫、如何在必要时让它替自己承受一次攻击。末页画着一只由黑色线条构成的狼，眼睛处留白，旁边写着：签下名字的时候，别忘了影子也在写。书的影子比书本身看起来更厚。

## 设计意图

为高阶盗贼提供召唤型辅助能力，拓展战术维度并增强诱敌与生存。
