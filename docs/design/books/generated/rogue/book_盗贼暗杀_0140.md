# 《悬赏单：目标评估》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0140`
- **关联技能**：`rogue_bounty_assess`
- **使用效果**：阅读后解锁 `rogue_bounty_assess`；若已学会，提升 `current_mastery +100`，并使接取暗杀委托时的奖励预判准确率 +10%。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `智力 ≥ 9` 或 `感知 ≥ 9`。
- **稀有度**：普通（Common）
- **建议投放**：佣兵公会、悬赏公告板、黑市任务中间人。

## 书籍内容

一张悬赏单上的信息，比它许诺的金币更值钱。这本书教人如何阅读委托背后的真相：报酬过高往往意味着目标棘手或雇主不可靠，描述模糊可能代表目标身份敏感，时间紧迫则暗示雇主自身处于危险中。作者还讲解了如何从中介的措辞中判断任务是否已被多人接手，以及如何通过地下网络核实目标背景。中间章节收录了几种常见骗局的特征：预付定金后消失的假雇主、用低报酬吸引新手去做替罪羊的真雇主、以及故意隐瞒目标实力的情报贩子。末页用浆糊贴着半张撕碎的悬赏单，上面只剩一句话：金币会撒谎，但风险不会。

末页贴着一张未完成的委托单，目标栏空白，报酬栏写着"面议"；书脊中夹着几枚不同城市的铜币，是作者收取定金时留下的，每枚都来自不同的雇主。某页边缘密密麻麻写满不同目标的日常习惯，从起床时间到如厕偏好无所不包。

## 设计意图

为盗贼系提供任务评估与资源规划技能，把委托系统从随机接取转化为风险收益判断。
