# 《毒刃保养：如何让刀口保持沉默》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0026`
- **关联技能**：`rogue_poisoned_blade`
- **使用效果**：阅读后解锁 `rogue_poisoned_blade`；若已学会，提升 `current_mastery +110`，并延长涂毒武器的有效攻击次数 `+1`。
- **阅读要求**：基础 `感知 ≥ 9`；已学会 `rogue_basic_poison`；已装备可涂毒武器。
- **稀有度**：精良（Uncommon）
- **建议投放**：毒药匠人作坊、刺客武器库、地下竞技场商人。

## 书籍内容

毒刃保养的作者认为，一把涂毒武器最大的敌人不是敌人，而是使用者自己的疏忽。书中开篇列出三种常见错误：涂毒后触摸刀刃、在干燥环境下存放毒剂、以及用同一把刀处理食物。中间章节详细讲解不同毒剂对金属的要求：酸性毒剂会腐蚀普通钢铁，神经毒剂需要保持低温，混合型毒剂则必须在临战前才涂抹。作者还提出一种名为薄霜涂法的技巧，用极薄的毒层覆盖刃口，既保证第一次命中的有效性，又避免毒剂在空气中过快失效。后半本转入实战维护，教导如何在战斗间隙快速补毒，如何判断毒剂是否已经失效。末页有一张保养清单，最后一项被圈出：每次任务结束后，先用油擦刀，再用酒擦手，顺序不能颠倒。

附录列出不同毒剂对金属腐蚀性的测试数据与刀刃保养周期表。表末写道：毒刃是双刃，一面朝向敌人，一面朝向不懂保养它的人。

## 设计意图

深化毒系武器的实战应用，延长涂毒次数让资源管理更具策略性。
