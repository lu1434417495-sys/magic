# 《沉默契约：不杀之约》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0147`
- **关联技能**：`rogue_pacifist_infiltration`
- **使用效果**：阅读后解锁 `rogue_pacifist_infiltration`；若已学会，提升 `current_mastery +100`，并使本次任务中不击杀任何人的额外奖励 +10%。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `意志 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：和平主义刺客教团、隐修院禁书区、特殊委托奖励。

## 书籍内容

不杀人比杀人难，因为你要让所有人继续正常生活。这本书介绍了一种极端的潜入哲学：通过观察、等待与精确 timing，在不伤害任何人的前提下完成任务目标。作者强调，不杀之约要求更高的耐心与规划——你不能依赖暴力解决意外，因此必须提前消除所有意外。书中还讲解了如何处理被发现的情况：不是灭口，而是制造足够的混乱让对方选择撤退或上报错误信息。中间章节讨论了心理压力：长期不杀会让同伴质疑你的忠诚，而你要学会把这种质疑也变成伪装。末页只有一句话：真正的幽灵，是所有人都记得见过，却没人能证明存在的人。

末页用血写着一行小字：不杀不是软弱，是让目标在余生里替你保守秘密；书页用极薄的纸印刷，翻阅时几乎不会发出任何声响，像是在配合主题。书中还讨论了如何在非致命任务中为敌人准备合理的"失踪理由"，减少后续追查。

## 设计意图

为盗贼系提供非致命流派的核心支撑，通过额外奖励鼓励道德选择与精密规划。
