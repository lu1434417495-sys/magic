# 《猫落：高处安全落地》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0146`
- **关联技能**：`rogue_cat_fall`
- **使用效果**：阅读后解锁 `rogue_cat_fall`；若已学会，提升 `current_mastery +110`，并使从高处跳下后的移动速度惩罚减少 30%。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `敏捷 ≥ 10`。
- **稀有度**：普通（Common）
- **建议投放**：城市跑酷导师、盗贼公会训练场、钟楼顶层。

## 书籍内容

猫从高处落下时不是摔下来的，是顺着空气滑下来的。这本书教人如何在坠落中调整姿态：身体放松、四肢展开、用腹部和背部承受主要冲击，落地瞬间顺势翻滚。作者强调，僵硬是坠落中最危险的状态，因为僵直的身体会把冲击力直接传导到骨骼。书中还讲解了不同高度下的应对策略：低处可以直腿缓冲，中等高度需要侧滚，极高处则要寻找中途借力点。中间章节有多个失败案例的骨骼图示，标注了错误姿势导致的骨折位置。末页画着一只四脚朝天的猫，旁边写着：向猫学习，但不要学它炫耀。

空白页画着一只猫的骨骼图，标注了落地时受力最小的姿势；书页边缘有人反复写着"放松"二字，字迹从紧张到流畅，显然经过长期的恐惧训练。空白处有人画着一只猫从三层楼高度落下的分解图，每个阶段都标注了角度。
