# 《麻痹针：点穴初解》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0126`
- **关联技能**：`rogue_paralysis_strike`
- **使用效果**：阅读后解锁 `rogue_paralysis_strike`；若已学会，提升 `current_mastery +120`，并使麻痹效果的触发几率 +4%。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `敏捷 ≥ 10` 或 `智力 ≥ 9`。

- **建议投放**：东方武馆禁书区、医术世家密室、流浪宗师手中。

## 书籍内容

人体有无数扇门，大多数门都没有锁，只需要知道按哪里。这本书介绍了一种用短针或指尖击打穴位造成局部麻痹的技术。作者从经络图讲起，标注了手臂、腿部与肩颈几处最容易见效的点位，并指出效果因人而异——肥胖者与肌肉发达者需要更深的刺激。书中还讲解了如何配合呼吸节奏出手：目标吸气时穴位会张开，呼气时则会收缩。中间章节警告，头部与脊柱附近的穴位极为危险，轻则致残重则致死，非生死关头不可轻易尝试。末页有一张被折痕分成两半的人体图，折痕处写着：点穴不是终点，是让对方给你一个终点的许可。

空白页画着穴位图，几个危险点被红笔打了叉；封底内侧贴着一小包银针，针尖已经氧化发黑，旁边写着"非生死关头不可用"。空白处画着一张手的穴位图，每个被点中的穴位旁都画着一个倒地的小人。

## 设计意图

为盗贼系提供控场单体技能，通过穴位机制扩展非致命战斗选择。
