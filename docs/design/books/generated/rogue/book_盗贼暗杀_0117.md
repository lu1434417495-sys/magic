# 《伪造笔迹与印章》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0117`
- **关联技能**：`rogue_forgery`
- **使用效果**：阅读后解锁 `rogue_forgery`；若已学会，提升 `current_mastery +100`，并使伪造文件的识破难度 +10%。
- **阅读要求**：角色职业标签含 `rogue`；基础 `智力 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：文书黑市、贵族书房、地下印刷所。

## 书籍内容

伪造一封信，先要伪造写信的人。这本书从纸张、墨水、笔迹、措辞四个层面拆解伪造技术：纸张需要匹配年代与保存环境，墨水需要考虑氧化后的颜色变化，笔迹需要模仿对方的书写习惯而非单字形状，措辞则要符合对方的身份与情绪。作者强调，最危险的不是笔迹不像，而是内容太像真的——过于完美的伪造反而会引起怀疑。中间章节收录了十几种贵族印章的拓印与仿刻要点。末页有一则用暗语写成的警告：印章可以复制，但印章背后的故事不能；永远要为你的伪造品准备一个能被查到的来源。

某页边缘留有半枚印章的压痕，像是作者故意留下的签名；空白处还有人模仿了七种不同的贵族签名，每一种都被反复涂改直到几乎以假乱真。封底画着一只握着羽毛笔的手，手腕上戴着一枚与书中某位贵族相同的戒指。

## 设计意图

为盗贼系提供剧情向伪造能力，服务于任务分支与身份伪装，强化非战斗成长路径。
