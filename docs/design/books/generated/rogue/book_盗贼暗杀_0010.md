# 《假死术：暂停生命的三日》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0010`
- **关联技能**：`rogue_feign_death`
- **使用效果**：阅读后解锁 `rogue_feign_death`；若已学会，提升 `current_mastery +150`，并在假死状态下解除时恢复少量 `stamina`。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `体质 ≥ 8` 且 `意志 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：殡仪馆密室、叛教医师藏身处、死囚逃脱任务奖励。

## 书籍内容

假死术不是幻术，也不是演技，而是一套让身体进入低代谢状态的功法。书中把过程分为三日：第一日降低呼吸与心跳，让脉搏弱到难以触及；第二日封闭毛孔，控制体温，使尸体该有的冰冷与僵硬按时出现；第三日则是最危险的时刻，因为搜尸者会检查眼睛、伤口和关节。作者强调，假死者的最大敌人不是敌人，而是同伴过早的哭泣与搬运。中间章节详细教授如何控制眼睑反应、如何制造 believable 的尸斑、如何在必要时让少量血液从嘴角流出。后半本是一本复活协议，记载如何在不被发现的情况下从棺木或尸堆中苏醒，如何判断周围的危险是否已经离开。末页用血画了一个符号，旁边写着：真正的假死者，连自己的恐惧都要骗过去。

封皮内侧印有免责声明：所述功法仅用于极端逃生，练习者自担被活埋、火化或误判死亡的风险。下面有人用血画了对勾。

## 设计意图

为盗贼系提供绝境求生技能，恢复 stamina 的设计让假死后的反击成为可能。
