# 《虚无之刃：穿过护甲的刺击》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0200`
- **关联技能**：`rogue_void_blade`
- **使用效果**：阅读后解锁 `rogue_void_blade`；若已学会，提升 `current_mastery +200`，并使匕首攻击无视 `15%` 护甲。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `敏捷 ≥ 16` 且 `智力 ≥ 12`。
- **稀有度**：传说（Legendary）
- **建议投放**：虚无裂隙深处、传说级刺客传承、终极BOSS掉落。

## 书籍内容

虚无之刃不是金属，而是把刀刃切入现实缝隙后留下的一道缺口。这本书记载了如何在刺击瞬间让武器短暂进入虚无，绕过护甲、肌肉和骨骼，直接损伤目标的生命力，作者是一名从虚无裂隙中归来的疯子。作者警告，这种技艺会磨损使用者对现实的感知，长期使用可能让手指偶尔穿过自己握住的物体。中间章节讲解如何控制切入虚无的深度：太浅会失效，太深会让刀永远消失。作者认为，虚无之刃的最高境界不是穿透护甲，而是穿透命运本身。后半本转入实战运用：如何在连击中寻找虚无的入口，如何在敌人挥盾防御时让刀从盾牌后方出现。末页画着一把匕首，刀刃部分是空白的，像被橡皮擦去，配文：真正的刀锋不在钢铁上，在现实愿意为你让路的那一刻。书页上匕首插图的位置是空白的，像被擦去。

## 设计意图

作为盗贼系终极破甲技能，提供护甲穿透，针对重甲目标与终局战斗设计。
