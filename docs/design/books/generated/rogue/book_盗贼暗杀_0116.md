# 《审讯：不说话的学问》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0116`
- **关联技能**：`rogue_interrogation`
- **使用效果**：阅读后解锁 `rogue_interrogation`；若已学会，提升 `current_mastery +90`，并使从俘虏处获得情报的质量提升一级。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `智力 ≥ 10` 或 `魅力 ≥ 9`。
- **稀有度**：稀有（Rare）
- **建议投放**：密探总部、监狱藏书、黑暗公会审讯室。

## 书籍内容

真正的审讯不是让人开口，而是让人急着开口。这本书反对暴力，认为疼痛会让目标混乱，而混乱的情报毫无价值。作者把审讯分为三个阶段：建立权威、制造不确定、提供出口。建立权威靠细节——你知道对方的名字、家人、昨日吃了什么；制造不确定靠沉默与矛盾的暗示；提供出口则是让对方相信，说出真相比继续隐藏更安全。书中还讲解了如何处理假情报：同一个问题隔一段时间再问，看细节是否一致。末页贴着一张泛黄的名单，大部分名字被划掉，只剩一句：最好的审讯者在目标开口前就已经知道答案。

书中夹着一枚生锈的铃铛，轻轻摇晃会发出极轻的声响，用来练习控制脚步力度；末页用暗语写着："最好的审讯者从不威胁，他们只负责递出镜子。"某页边缘有人用血写着：说谎者会重复你的问题，诚实者会立刻回答。

## 设计意图

为盗贼系提供情报获取与剧情交互技能，把审讯设计成社交与逻辑判断玩法。
