# 《影子契约：中间人法则》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0142`
- **关联技能**：`rogue_handler_relation`
- **使用效果**：阅读后解锁 `known_knowledge_id: underworld_network`，可在主要城市访问更多地下商人；若已学会，提升 `current_mastery +90`。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `魅力 ≥ 10` 或 `智力 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：地下交易所、情报商人手中、盗贼公会密室。

## 书籍内容

刺客不是独行侠，他的背后有一张看不见的网。这本书讲述如何与中间人、线人、买家和卖家打交道：永远不要让对方知道你的真实身份，永远保留一部分筹码，永远准备好第二条信息来源。作者强调，地下世界的信任建立在互惠而非感情上，一次违约可能会让整张网对你关闭。书中还讲解了如何识别可靠中间人：看他们是否愿意先垫付小额情报费用，是否在失败时主动提供补偿。中间章节警告，最危险的中间人不是骗子，而是过于能干的中间人——他们知道太多，随时可能把你卖掉。末页写着：你和中间人的关系，就像刀和鞘，互相保护，也互相限制。

书中夹着几枚不同势力的徽章，是进入各据点时的信物；空白处密密麻麻记录着十几个中间人的代号与偏好，有些名字旁边画着叉，有些画着圈。

## 设计意图

作为知识类书籍扩展盗贼系的经济与情报网络，让社交资源成为成长循环的一部分。
