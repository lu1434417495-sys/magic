# 《割喉者的左手》

## 书籍内容

这是一本只讲左手的书。作者认为大多数暗杀者失败，不是因为右手不够快，而是因为左手在制服目标时泄露了太多意图。书中把左手的工作分解为固定、引导与遮蔽三项：固定目标的下巴或后脑，引导其身体倒向不会发出声响的方向，遮蔽其视线以延迟呼救反应。每一动作都配有木刻插图，图中的左手像某种独立生物，早于右手抵达位置。中间章节讨论人喉的脆弱结构，作者反对浪漫化的轻轻一划，强调必须切断气管与一侧颈动脉的连接处，否则目标仍可能在数秒内发出求救声。后半本转入心理训练：如何在贴近一个活人时控制自己的心跳与呼吸，如何在闻到对方体味时保持动作稳定。末页贴有一张泛黄的契约残片，上面只有半个血指印。

书中插图细腻不似刺客手笔，每幅左手姿态都被反复勾勒。末页针尖刺出一句：当你能感觉到目标脉搏时，先稳住自己的脉搏，否则两人会一起颤抖。

## 设计意图

深化暗杀者的处决技能树，把割喉从单纯伤害动作重构为包含控制、遮蔽与心理稳定的复合技术。
