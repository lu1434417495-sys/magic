# 《静默处决：不留尸体的十七法》

- **书籍 ID**：`book_盗贼暗杀_0033`
- **关联技能**：`assassin_silent_execution`
- **使用效果**：阅读后解锁 `assassin_silent_execution`；若已学会，提升 `current_mastery +150`，并使处决未察觉目标时不发出声音的概率大幅提升。
- **阅读要求**：角色职业标签含 `assassin`；基础 `敏捷 ≥ 12` 且 `感知 ≥ 10`。

## 书籍内容

静默处决的核心不是如何杀死目标，而是如何让目标死亡时不发出任何能惊动他人的声音。作者列出十七种方法，从绞颈、刺入延髓到压迫颈动脉窦，每一种都标注了所需的接近角度、力量与时机。中间章节讲解如何处理尸体倒下的过程：扶住目标、引导其慢慢坐下或躺下，比让其直接倒地更能争取时间。后半本转入环境利用，教导如何让家具、地毯和门帘吸收声音，以及如何选择最不可能被发现的处决位置。作者还强调，真正干净的任务不是不留尸体，而是让尸体在很长一段时间内不被发现。末页有一张清单，标题是事后检查项，最后一项被重重圈出：确保你离开时，房间看起来像是目标自己决定消失的。

书中夹着磨细的绞颈绳，长度恰好适合从背后使用。绳子下压着一行字：最安静的死亡，是给目标一个来不及拒绝的拥抱。
