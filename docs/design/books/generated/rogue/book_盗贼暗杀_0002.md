# 《无声落足：瓦上行者的呼吸课》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0002`
- **关联技能**：`rogue_silent_step`
- **使用效果**：阅读后解锁 `rogue_silent_step`；若已学会，提升 `current_mastery +100`，并在下一次夜间战斗中使潜行判定 `+8%`。
- **阅读要求**：基础 `敏捷 ≥ 9`；已学会任意移动类战技。
- **稀有度**：普通（Common）
- **建议投放**：盗贼公会入门书架、屋顶哨兵遗物、贫民区旧货摊。

## 书籍内容

这本薄册子的作者自称瓦上行者，声称自己一生没有踩碎过一片瓦当。书中开篇便否定轻身术需要天赋的说法，坚持无声移动是一套可以量产的肌肉契约。作者把落脚拆成三个阶段：先以前脚掌寻找支撑点，再让脚跟像倒水一样缓慢注满压力，最后把整个身体的重心前移交给下一步。每一阶段都配有呼吸指令，吸对应试探，呼对应下沉，屏息则留给必须跨越碎玻璃或干草叶的险段。中间章节记录了七种常见屋顶材质的欺骗性：看似结实的青瓦中空易裂，腐朽木板反而能吸收震动，铁皮屋顶必须在风向最强时迈步。后半本是一本失败日志，记载作者四次从屋顶摔落的经历，每一次都归因于过度自信而非技巧缺失。末页用红笔写着：脚步越轻，呼吸越重；呼吸越重，心跳越响。

书末夹着泡烂的屋顶地图，标注安全落点与危险瓦区。背面潦草写道：我教的不是轻功，是信任瓦片与风，也信任最后一刻不犹豫。

## 设计意图

为盗贼系提供基础潜行与移动技能入口，夜间增益强化其环境适应性，鼓励玩家在合适地形触发优势。
