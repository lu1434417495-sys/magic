# 《盲斗：没有光的地方》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0138`
- **关联技能**：`rogue_blind_fight`
- **使用效果**：阅读后解锁 `rogue_blind_fight`；若已学会，提升 `current_mastery +130`，并使目盲状态下的命中惩罚减少 20%。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `感知 ≥ 11`。
- **稀有度**：稀有（Rare）
- **建议投放**：盲眼武师道场、地下格斗场、暗影神庙。

## 书籍内容

眼睛是战士的奢侈品，刺客要学会在黑暗中战斗。这本书教人如何依靠听觉、触觉与气流判断敌人的位置：敌人挥剑时会带动空气，呼吸会暴露胸膛起伏，脚步会预告下一次移动。作者要求练习者先蒙眼进行基础格挡训练，再逐步加入反击与移动。书中还讲解了如何利用敌人的恐惧：在黑暗中，看不见的一方往往比看得见的一方更冷静。中间章节讨论了心理战：故意发出声音引诱敌人攻击空处，再从反方向切入。末页用针刺出几个小孔组成一句话：光让你看见敌人，黑暗让敌人忘记看见你。

某些章节被刻意打孔，只有用手触摸才能"阅读"；书页间夹着一块黑布，是练习盲斗时蒙眼用的，布角绣着一个已经褪色的"盲"字。封底内侧粘着一小块黑绒布，布上绣着一个已经看不清名字的宗派标记。

## 设计意图

为盗贼系提供特殊环境下的战斗技能，强化烟幕、黑夜与致盲状态下的作战能力。
