# 《诱饵人偶：制造替身》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0188`
- **关联技能**：`rogue_decoy_doll`
- **使用效果**：阅读后解锁 `rogue_decoy_doll`；若已学会，提升 `current_mastery +130`，并使诱饵被识破所需时间 `+20%`。
- **阅读要求**：角色职业标签含 `rogue`；基础 `智力 ≥ 11` 且 `敏捷 ≥ 11`。
- **稀有度**：稀有（Rare）
- **建议投放**：机关工匠、魔术师藏身处、高阶潜入任务奖励。

## 书籍内容

有时候最安全的撤退，是让敌人以为你还在原地，这本书的作者同时也是一个失败的舞台木偶师。这本书教授如何制作和使用诱饵人偶：从最简单的稻草填充到能够模仿呼吸和体温的高级机关。作者认为，诱饵的价值不在于逼真，而在于出现在正确的时间和角度。中间章节讲解几种经典诱饵布置：靠在窗边的人影、从拐角跑过的背影、躺在床上隆起的被子。书中还教授如何为人偶注入少量自己的气息，让追踪犬误以为那就是你。后半本转入配合技巧：如何让诱饵与陷阱、暗器或同伴行动形成联动，让敌人在发现被骗之前就已经落入圈套。末页有一幅人偶内部结构图，弹簧与细线交错，旁边写着：最好的诱饵，是让敌人以为他抓住了你。书中夹着几根稻草和一小段细线。作者提醒，诱饵人偶最大的风险是让敌人以为你已经死了，从而提前庆祝。

## 设计意图

为盗贼系提供战术欺骗能力，强化诱敌与撤退的多样性。
