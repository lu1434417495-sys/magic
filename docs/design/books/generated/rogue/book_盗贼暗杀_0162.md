# 《暗杀者的冥想：杀意凝练》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0162`
- **关联技能**：`meditation_assassin_breath`
- **使用效果**：阅读后解锁 `meditation_assassin_breath`（标签 `meditation`）；若已学会，提升 `current_mastery +130`，并在暗杀前保持静止时获得少量 `MP` 回复。
- **阅读要求**：角色职业标签含 `assassin`；基础 `意志 ≥ 12` 且 `敏捷 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：沉钟书库密室、冥想导师、刺客传承任务。

## 书籍内容

普通冥想追求放空，暗杀者的冥想却要求把杀意压缩成一枚针尖大小的点，这本典籍来自一个已覆灭的东方教派。作者认为，真正的冷静不是没有情绪，而是让情绪凝聚到可以瞬间释放的程度。书中教授一种特殊的呼吸法：吸气时想象杀意从四肢收回胸口，呼气时把它压入丹田，反复循环直到身体变得像冰一样稳定。中间章节讲解如何在潜伏中维持这种状态数小时而不疲惫，以及如何在出手的一瞬间把压缩的杀意全部倾泻到刀尖。后半本转入失败案例：有人因为杀意外露被野兽感知，有人因为无法释放而在关键时刻手软。书中记载，修炼此法的人必须在墓园中静坐，直到不再恐惧死亡本身。末页写着：杀意是火，冥想是炉，没有炉的火会烧掉持火的人。书的纸张异常冰冷，仿佛刚从墓地取出。

把冥想系统与刺客职业结合，提供战前蓄力与资源回复机制。
