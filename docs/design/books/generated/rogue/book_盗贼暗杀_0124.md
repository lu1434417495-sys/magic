# 《袖箭：远程暗杀入门》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0124`
- **关联技能**：`assassin_sleeve_bolt`
- **使用效果**：阅读后解锁 `assassin_sleeve_bolt`；若已学会，提升 `current_mastery +130`，并使袖箭首次命中弱点时的伤害 +6%。
- **阅读要求**：角色职业标签含 `assassin`；基础 `敏捷 ≥ 11`。
- **稀有度**：稀有（Rare）
- **建议投放**：东方刺客工坊、机关师密室、远洋商船货舱。

## 书籍内容

袖箭把死亡藏在衣袖里，让挥手告别变成致命一击。这本书先讲机关：弹簧的力度、箭槽的顺滑度、扳机的灵敏度，任何一个参数偏差都会让箭矢偏离或卡壳。作者建议每把袖箭都要根据使用者的臂长和力量单独调校。中间章节转入射击：袖箭不是弓弩，有效距离极短，因此必须精确瞄准咽喉、眼眶或太阳穴。书中还讲解了如何在握手、拍肩、递酒等日常动作中自然出箭，让对方在毫无戒备中倒下。末页有一段用暗语写的誓词，翻译成白话是：袖箭出手时，你的身份已经死了。

封底刻着一行小字："机关出错的刺客，比靶子死得更快。"书页间夹着一枚生锈的弹簧，是某位前人换下的零件，弹簧上还缠着一根细细的头发。某页边缘有人用针刺出一行小字：袖箭的准星不在机关里，在你的心里。末页空白处还画着一只手腕的骨骼图，标注了最佳机关佩戴位置。

## 设计意图

为刺客系提供近战距离的远程爆发技能，强化社交场景中的暗杀能力。
