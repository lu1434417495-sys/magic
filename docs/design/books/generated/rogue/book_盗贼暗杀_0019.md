# 《盗亦有道：扒手的节拍器》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0019`
- **关联技能**：`rogue_pickpocket`
- **使用效果**：阅读后解锁 `rogue_pickpocket`；若已学会，提升 `current_mastery +100`，并使对醉酒或分心目标扒窃成功率 `+10%`。
- **阅读要求**：基础 `敏捷 ≥ 9`；角色职业标签含 `rogue`。
- **稀有度**：普通（Common）
- **建议投放**：贫民区老扒手、市集巡逻官收缴物、盗贼公会入门任务。

## 书籍内容

扒手的节拍器把偷窃比作音乐：成功不在于某一次出手有多快，而在于你的动作与目标的身体节奏是否合拍。书中把目标的动作分为强拍与弱拍，强拍时身体紧绷、警觉最高，弱拍时肩膀放松、呼吸下沉，那是手指进入袋口的唯一窗口。作者强调，真正的高手不是手快，而是知道什么时候不该出手。中间章节记录七种常见携带方式：外袋最易得手但价值低，内袋价值高但贴近身体感知，腰包居中但需要解开搭扣。后半本转入脱身技巧，教导如何在失手时被抓住手腕的刹那顺势旋转，把对方的愤怒化解为一次误会。末页有一段作者的自嘲：我偷过金杯、戒指、情书，但最难忘的是从一个醉汉口袋里摸出的半块面包，因为它让我想起了自己为什么开始。

封底内侧贴着人体口袋分布图，标注不同阶层常放贵重物的位置。图下写着：口袋是人的第二个表情，读懂它就能猜到主人的秘密。

## 设计意图

提供盗贼系的基础资源获取与互动技能，状态加成鼓励玩家观察环境再行动。
