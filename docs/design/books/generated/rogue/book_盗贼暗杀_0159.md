# 《血腥味管理：猎杀后的气息消除》

## 基础信息

- **书籍 ID**：`book_盗贼暗杀_0159`
- **关联技能**：`rogue_scent_mask`
- **使用效果**：阅读后解锁 `rogue_scent_mask`；若已学会，提升 `current_mastery +110`，并使暗杀后敌人追踪距离 `-15%`。
- **阅读要求**：角色职业标签含 `rogue` 或 `assassin`；基础 `感知 ≥ 10`。
- **稀有度**：精良（Uncommon）
- **建议投放**：猎人营地、兽人斥候导师、暗杀任务奖励。

## 书籍内容

人类也许闻不到，但野兽、猎犬和训练有素的追踪者能从血腥味里读出你的去向。这本书由一名兽人猎手与人类刺客合著，教授如何在猎杀后让自己闻起来像环境的一部分。作者从血液腐败的化学过程讲起，解释为什么清水洗不干净，以及为什么某些植物汁液能中和血腥味。中间章节讲解几种简易的气味掩盖配方：松脂、腐土、特定草药的混合物，以及何时该用强烈气味覆盖、何时该用无味药剂中和。后半本转入习惯层面：不要在同一处换衣服，不要让血渗进鞋底，不要在猎杀后立即进食。作者特别强调，洗手的水必须倒在远离营地的地方，因为血与水混合后的气味反而更明显。末页有一片干枯的薄荷叶，旁边写着：最好的消味剂不是盖住血，而是让追踪者相信自己追错了猎物。书页间夹着干枯的薄荷叶和几片兽毛。

## 设计意图

为潜行暗杀提供反追踪能力，降低任务结束后被追杀的风险。
