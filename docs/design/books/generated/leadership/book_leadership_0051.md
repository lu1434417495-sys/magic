# 《集结号令》

## 基础信息

- **书籍 ID**：`book_leadership_0051`
- **关联技能**：`leadership_rallying_cry`（待新增，标签 `leadership`）
- **使用效果**：阅读后学会指挥技能 `leadership_rallying_cry`，可在战斗中发出集结号令，使范围内友方单位下回合移动速度提升并获得一次协同攻击机会。
- **阅读要求**：无职业限制；基础 `魅力 ≥ 8` 或 `智力 ≥ 8`。
- **稀有度**：稀有（Rare）
- **建议投放**：指挥官训练营、前线据点任务奖励、军械库宝箱。

## 书籍内容

《集结号令》是一本讲述如何在混乱战场上重新聚拢队伍的薄册。作者认为，真正导致溃败的不是敌人的冲锋，而是士兵在失去彼此位置后产生的孤独感。书中将号令拆成三段：第一段是低沉的鼓点或号角，用于打断恐慌；第二段是高亢的短音，指示集合方向；第三段是重复的节律，让士兵在奔跑中重新校准步伐。作者强调，指挥官自己的位置比声音更重要——你必须站在一个所有人都能看见的地方，哪怕那意味着暴露自己。书中还记载了七种不同地形下的变奏：森林中用短促哨音，峡谷里用回声定位，平原上则依赖旗帜与号角配合。最后一章警告说，集结不是撤退，如果指挥官在号令中露出犹豫，士兵会用脚投票。末尾附有一张手绘图，画着一名指挥官站在石堆上，周围是向心奔跑的人影。

## 设计意图

作为指挥号令系列的基础技能书，承担引入 `leadership` 标签与团队协同机制的职责。通过移动速度与协同攻击的复合奖励，让非纯输出型角色也能在战棋中创造价值。
