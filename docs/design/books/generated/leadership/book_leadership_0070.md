# 《掩护射击》

## 基础信息

- **书籍 ID**：`book_leadership_0070`
- **关联技能**：`leadership_overwatch_command`（待新增，标签 `leadership`）
- **使用效果**：阅读后学会指挥技能 `leadership_overwatch_command`，可命令一名友方远程单位进入掩护射击姿态，对进入其射程的敌人自动发动攻击。
- **阅读要求**：角色职业标签含 `archer`、`ranger` 或 `gunslinger`；基础 `敏捷 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：射手公会、哨塔据点、边境防御任务。

## 书籍内容

《掩护射击》把弓箭手比作棋盘上的埋伏棋子，他们的价值不在于射出多少箭，而在于让敌人不敢轻易进入某些区域。作者认为，掩护射击的关键是预判与克制：你要猜出敌人下一步会走哪条路，然后忍住提前射击的冲动。书中将掩护区域分为"硬区"与"软区"：硬区是敌人必须通过的咽喉要道，软区则是可以绕开但会付出额外代价的位置。作者强调，掩护射击者在执行期间通常无法移动，因此需要队友保护其侧翼。书中还讨论了火力密度的平衡：覆盖太广会稀释威胁，覆盖太窄则容易被敌人察觉并规避。最后一章警告，掩护射击不是无限弹药，每一支箭都应该有明确的目标或威慑价值。作者补充说，掩护射击者最可靠的盟友不是自己的箭术，而是队友提供的视野与预警。书末附有一张简图，展示一名弓箭手如何利用地形死角封锁一条通道。

## 设计意图

为远程单位引入区域控制型姿态，让弓箭手与游侠能够用威胁而非直接输出来影响战场。掩护射击鼓励敌人改变移动路线，创造战术优势。
