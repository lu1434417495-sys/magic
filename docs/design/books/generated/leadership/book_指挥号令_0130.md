# 《传令兵训练》

## 基础信息

- **书籍 ID**：`book_指挥号令_0130`
- **关联技能**：`leadership_courier_drill`
- **使用效果**：阅读后解锁 `leadership_courier_drill`；若已学会，提升该技能 `current_mastery +90`，并使远距离命令传递失败率降低 15%。
- **阅读要求**：无职业限制；基础 `敏捷 ≥ 8` 或 `感知 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：军营训练场、传令任务奖励、通信兵书架。

## 书籍内容

《传令兵训练》是一本关于如何在战场上可靠传递命令的书。作者指出，再出色的战术，如果命令传不到执行者手中，也只是一纸空文。书中从选拔讲起，强调传令兵需要记忆力、方向感、骑术或跑速，以及最重要的冷静。手册详细介绍了命令的封装方式：口头复述、蜡封信件、记忆暗号、分段传递。后半部分讨论了传令兵在穿越敌阵或危险地形时的自我保护技巧，以及当传令兵未能按时返回时指挥官应如何解读。作者建议为传令兵制定多条备用路线，并规定超过时限未归就启用第二传令兵。书中还提醒，传令兵返回后应被允许简要复述命令，而不是直接交信离开，以防口头指令被遗忘。最末一章提醒读者，传令兵不是消耗品，他们的安全直接影响指挥链的完整。许多指挥官会为最优秀的传令兵配备最好的马匹和护甲。

## 设计意图

为大型战场和分散队形提供命令传递机制，降低因距离导致的指挥失效，增强战场真实感。
