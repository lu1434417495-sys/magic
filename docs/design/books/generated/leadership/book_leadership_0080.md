# 《先锋任命》

## 基础信息

- **书籍 ID**：`book_leadership_0080`
- **关联技能**：`leadership_vanguard_assignment`（待新增，标签 `leadership`）
- **使用效果**：阅读后学会指挥技能 `leadership_vanguard_assignment`，可任命一名友方为先锋，其首次进入战斗时获得先攻加成与首击伤害提升。
- **阅读要求**：角色职业标签含 `warrior`、`knight` 或 `cavalry`；基础 `力量 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：先锋营寨、骑士团选拔、冲锋演武奖励。

## 书籍内容

《先锋任命》认为，一支军队的锋芒不在于所有人，而在于被选中走在最前面的那几个人。作者将先锋分为"冲击先锋"与"侦察先锋"：前者负责撕开敌阵，后者负责探明危险并活着回来报告。书中强调，任命先锋不是惩罚，而是荣誉——被任命者会感受到全队的期待，这种心理负担有时比装备更重要。作者还讨论了先锋的装备选择：冲击先锋需要重甲与长兵器，侦察先锋则需要轻便与隐蔽。书中警告，不要让最适合指挥的人去当先锋，因为先锋可能无法活着完成指挥职责。最后一章讲述先锋与主力的节奏配合：先锋出击后，主力必须在精确的时间跟进，太早会拥挤，太晚会孤立。作者建议用三段号角作为同步信号，让先锋与主力在Noise与混乱中仍能保持节奏一致。书末附有一幅插图，画着一名骑士接受先锋旗帜的瞬间，身后是整装待发的队伍。

## 设计意图

为战斗开场提供明确的角色分工，让高力量角色在首回合就能打出决定性伤害。先攻与首击加成强化了"先锋"的仪式感与战术价值。
