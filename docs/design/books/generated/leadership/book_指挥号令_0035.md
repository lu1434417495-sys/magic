# 《重整旗鼓：从混乱中找回节奏》

## 基础信息

- **书籍 ID**：`book_指挥号令_0035`
- **关联技能**：`leadership_regroup_signal`
- **使用效果**：阅读后解锁 `leadership_regroup_signal`；若已学会，提升该技能 `current_mastery +90`，并减少下次重整所需的准备时间 1 回合（一次性）。
- **阅读要求**：无职业限制；基础 `魅力 ≥ 8` 或 `智力 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：军团参谋营、撤退路线终点、通用商人。

## 书籍内容

书的封面是一面被重新缝好的战旗，针脚粗糙但结实。作者把重整旗鼓定义为"承认混乱，然后给出一个比混乱更简单的选择"。书中指出，重整不是让所有人回到原点，而是让每个人都知道自己下一个动作该做什么。最有效的重整信号通常只有三种：一声长号表示"向我靠拢"，一面举起的旗帜表示"在这里重新编队"，一个重复的敲击声表示"停止追击，恢复防御"。作者警告指挥官，重整时不要同时下达多个命令，因为混乱中的大脑只能处理一个清晰指令。后半本记录了历史上几次著名重整案例，每次失败的原因都被归结为"指挥官想要一次性修复所有问题"。最末页只有一句话："鼓点Restart的那一刻，队伍才真正属于你。"书页边缘还粘着一小片被汗水浸透的鼓皮，来自某位在重整时敲断鼓槌的传令兵。

## 设计意图

为指挥者提供混乱后快速恢复团队结构的工具，将魅力/智力转化为秩序重建资源，强化持久战中的韧性。
