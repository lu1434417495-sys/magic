# 《秩序祷言：让信仰成为节拍器》

## 基础信息

- **书籍 ID**：`book_指挥号令_0045`
- **关联技能**：`leadership_prayer_of_orders`
- **使用效果**：阅读后解锁 `leadership_prayer_of_orders`；若已学会，提升该技能 `current_mastery +90`，并延长下次祷言的增益持续时间 1 回合（一次性）。
- **阅读要求**：角色职业标签含 `priest`、`paladin` 或 `cleric`；基础 `意志 ≥ 9` 或 `魅力 ≥ 9`。

- **建议投放**：大教堂唱诗班席、神圣军事学院、神圣商人。

## 书籍内容

书的封面是一张被圣水浸湿后重新晾干的羊皮纸，上面的文字因水渍而微微发亮。作者把秩序祷言定义为"用神圣语言为团队建立一个共享的节奏框架"。书中指出，祷言不是向神祈求胜利，而是让所有听到祷言的人在同一信仰频率下行动。当祷言响起时，战士的格挡、法师的施法、盗贼的潜行都会获得轻微但稳定的加成，因为每个人都在同一节拍上。第二章讲解了"祷言维护"：主持祷言的牧师必须保持自身不被打断，否则节奏崩溃会让全队出现短暂僵直。作者还记录了一种被称为"断句续唱"的应急技巧：当主祷者被攻击时，最近的两名信徒会自动接下后半句。最末页贴着一张被烛泪封住的赞美诗，旁边写着："神听的可能是词，但人听的是彼此的呼吸。"羊皮纸边缘还有一行被圣水晕开的字迹："祷言的力量不在于神是否回应，而在于诵念者相信彼此会回应。"

## 设计意图

为神职职业提供团队持续增益机制，将意志/魅力转化为行动节奏统一，与牧师治疗、守护圈形成完整支援体系。
