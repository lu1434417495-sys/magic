# 《陷阱布置信号》

## 书籍内容

《陷阱布置信号》是一本关于如何让陷阱为己方服务而不是伤害自己的手册。作者认为，布置陷阱最容易被忽视的问题是友军识别。书中介绍了一套简单的标记系统：用不同颜色的布条、石块排列或草木折弯方式，在陷阱周围留下只有己方知道的警告。手册前半部分讲解常见陷阱类型与对应标记，后半部分讨论如何在撤退时快速布设延迟陷阱、如何在伏击战中与陷阱配合、以及如何在夜间或雾中依靠触感识别标记。作者建议每次变更标记系统后，都要让全队实地演练一遍，因为书面记忆在紧张时刻往往会被遗忘。书中还提醒，陷阱标记应与自然痕迹融为一体，过于显眼的标记反而会暴露位置。最末一章警告：永远不要假设所有人都记住了信号，每次行动前都要重新确认。历史上太多胜利因为一名友军踩中自己的陷阱而变成笑话。

## 设计意图

为防御与伏击战术提供友军安全机制，鼓励玩家更积极地使用环境陷阱而不担心误伤。
