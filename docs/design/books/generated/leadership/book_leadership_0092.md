# 《骑兵召唤》

## 基础信息

- **书籍 ID**：`book_leadership_0092`
- **关联技能**：`leadership_cavalry_call`（待新增，标签 `leadership`）
- **使用效果**：阅读后学会指挥技能 `leadership_cavalry_call`，可在战斗中召唤一支骑兵预备队冲入战场，对指定路径上的敌人造成伤害与击退。
- **阅读要求**：角色职业标签含 `cavalry`、`knight` 或 `commander`；基础 `魅力 ≥ 10`。

- **建议投放**：骑兵统帅传承、史诗战役任务、传说级军营宝箱。

## 书籍内容

《骑兵召唤》把骑兵描述为战场上的雷霆：你无法一直拥有它，但当你听到它的轰鸣时，局势就已经改变。作者认为，骑兵的价值不在于持续作战，而在于关键时刻的毁灭性一击。书中将骑兵冲锋分为"蓄势""释放"与"脱离"：蓄势阶段骑兵隐藏在视野之外，释放阶段沿直线或开阔地形全力冲刺，脱离阶段则必须避免陷入混战。作者强调，召唤骑兵的时机决定了一切——太早会被敌方长枪阵迎头痛击，太晚则无法扭转败局。书中还讨论了地形与反制：森林、壕沟与拒马是骑兵的噩梦，指挥官必须在召唤前清除或规避这些障碍。最后一章警告，骑兵召唤通常是一次性的战略资源，用掉之后很长时间无法补充。作者建议在召唤骑兵前确保敌人没有密集长枪阵或深壕，否则骑兵的毁灭性一击可能会变成灾难性的碰撞。书末附有一幅骑兵冲锋插画，马蹄扬起的尘土遮住了半边天空。

## 设计意图

提供高稀有度的战场召唤能力，让指挥官能够投入决定性的外部力量。路径伤害与击退效果让骑兵冲锋成为改变战线的强力手段。
