# 《临终号令：声音比生命更长》

## 基础信息

- **书籍 ID**：`book_指挥号令_0049`
- **关联技能**：`leadership_final_command`
- **使用效果**：阅读后解锁 `leadership_final_command`；若已学会，提升该技能 `current_mastery +100`，并提高临终号令触发后的全队属性加成 5%（一次性）。
- **阅读要求**：无职业限制；基础 `意志 ≥ 10` 或 `魅力 ≥ 10`。
- **稀有度**：史诗（Epic）
- **建议投放**：英烈纪念馆、最终试炼奖励、传说商人。

## 书籍内容

书的封面是一只用苍白线条画出的手，手指正指向书脊的方向，仿佛在把什么交给下一位读者。作者把临终号令定义为"指挥官在倒下前留下的最后一道清晰意图"。书中指出，这道号令的力量不来自于命令本身，而来自于执行者知道"这是他最后的话"。临终号令可以是"继续进攻"，也可以是"活下去"，甚至只是一个名字，但只要足够清晰，就能让混乱中的队伍重新凝聚一回合。第二章讲解了如何训练自己在濒死时仍保持声音平稳——作者建议在每次演练中模拟重伤状态，强迫自己在疼痛中说出完整句子。最末页贴着一张被血浸透的纸条，上面只有三个字："别回头。"无数后来的指挥官把它抄在自己的护臂内侧。苍白手指的指尖还留着一滴干涸的血迹，像是某位前任拥有者在合上书的最后一刻留下的印记。

## 设计意图

作为指挥号令系列的高风险高收益技能，将指挥官牺牲转化为团队最后的爆发，强化牺牲主题与剧情张力。
