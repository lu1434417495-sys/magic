# 《快速轮转》

## 书籍内容

《快速轮转》是一本关于"在移动中战斗"的书。作者认为，固定位置是留给重甲者的奢侈，轻甲单位的价值在于不断调整位置以寻找最佳角度。书中将轮转分为"位置轮转"与"职责轮转"：前者只是交换站位，后者则让队员临时承担不同角色。作者强调，快速轮转需要大量训练与默契，否则会变成互相阻挡的混乱。书中详细讲解了如何在狭小空间内完成三人轮换：每个人只移动一步，但三步之后整个小队面向的方向与防御重点都已经改变。作者还警告，轮转不是逃跑——如果你只是为了远离敌人而移动，那不叫轮转，那叫溃散。最后一章讨论轮转的终点：最终目的是让敌人无法预测你的下一步，从而获得一次决定性的攻击机会。书末附有一组连续动作图，展示三名轻甲战士如何在三步内完成攻防转换。

## 设计意图

为高机动队伍提供位置重组与角色切换能力，增强战棋中的动态走位。适应性加成让轮转后的单位能够立即发挥新位置的优势。
