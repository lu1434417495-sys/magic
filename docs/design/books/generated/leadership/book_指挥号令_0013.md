# 《士气振奋：让心跳同频》

## 基础信息

- **书籍 ID**：`book_指挥号令_0013`
- **关联技能**：`leadership_morale_boost`
- **使用效果**：阅读后解锁 `leadership_morale_boost`；若已学会，提升该技能 `current_mastery +90`，并提高下次士气振奋的治疗效果 8%（一次性）。
- **阅读要求**：无职业限制；基础 `魅力 ≥ 8` 或 `意志 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：战地医院、随军牧师帐篷、基础商人。

## 书籍内容

这是一本被无数人翻阅过的小册子，书页边缘卷得像海浪。作者把士气比作一个看不见的容器，里面装着每个人的忍耐力、判断力和最后一搏的力气。书中指出，士气振奋不是让人们觉得自己会赢，而是让他们相信"现在还不是最糟的时刻"。最有效的振奋方式有三种：提及共同的过去、指出一个具体的小目标、以及让最疲惫的人先得到喘息。作者警告指挥官不要在伤亡最重的时候空谈荣誉，因为那会加速容器的破裂。后半本记录了数十个不同文化中的战前口号，每个都被翻译成通用语，但保留了原音。最末页只有一句话被反复描粗："士气不是从口号里长出来的，是从每个人被看见的感觉里长出来的。"旁边贴着一张被体温焐热的全家福，照片背面写着："让他们知道为何而战，比告诉他们怎么赢更重要。"

## 设计意图

为指挥号令系列提供情绪资源恢复机制，将魅力转化为团队续航力，与冥想/修炼资源体系形成互补。
