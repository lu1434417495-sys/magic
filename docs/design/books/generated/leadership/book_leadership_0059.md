# 《侦察分派》

## 基础信息

- **书籍 ID**：`book_leadership_0059`
- **关联技能**：`leadership_recon_dispatch`（待新增，标签 `leadership`）
- **使用效果**：阅读后学会指挥技能 `leadership_recon_dispatch`，可派出一名友方单位进行侦察，暴露其移动路径上的敌人并为全队提供短暂的命中加成。
- **阅读要求**：角色职业标签含 `rogue`、`ranger` 或 `archer`；基础 `敏捷 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：斥候公会、边境哨站任务、迷雾区域探索奖励。

## 书籍内容

《侦察分派》认为，信息是战场上唯一不会过重的装备。作者将侦察任务分为三类：路线侦察负责确认安全通道，区域侦察负责绘制敌人分布，接触侦察则是有意暴露自己以引诱敌人行动。书中详细讨论了侦察者的选拔标准：敏捷与隐蔽固然重要，但更重要的是判断力——知道什么时候该回来报告，什么时候该继续观察。作者警告，不要把最弱的士兵派去侦察，因为一旦他被俘，敌人会反过来获得你的情报。书中还提供了几组标准手势，用于无声传递"安全""危险""需要支援"等简单信息。作者提醒，侦察者在出发前应被告知本次任务的核心问题，否则他们会带回大量无关细节，反而淹没真正重要的情报。最后一章强调，侦察不是孤胆英雄的表演，而是整个指挥链条的第一环。书末附有一张空白地图模板，提醒读者：真正的侦察成果必须被记录下来，而不是只存在于侦察者的记忆中。

## 设计意图

强化战棋中的信息获取与视野控制。侦察分派让高机动角色在战斗前期就能创造价值，同时为后续集火与走位提供命中加成。
