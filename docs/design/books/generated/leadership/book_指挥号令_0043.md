# 《稳定瞄准：让呼吸成为命令》

## 基础信息

- **书籍 ID**：`book_指挥号令_0043`
- **关联技能**：`leadership_steady_aim`
- **使用效果**：阅读后解锁 `leadership_steady_aim`；若已学会，提升该技能 `current_mastery +90`，并提高下次稳定瞄准后的暴击率 8%（一次性）。
- **阅读要求**：角色职业标签含 `archer`、`ranger` 或 `rogue`；基础 `感知 ≥ 9` 或 `敏捷 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：射手营静室、狙击训练场、远程商人。

## 书籍内容

书的封面是一把被拆开的弓，弓弦被画成一条平稳的直线。作者把稳定瞄准定义为"让整支队伍的呼吸和扣箭时机同步"。书中指出，许多射手在紧张时会不自觉地加快呼吸，导致准星在关键瞬间晃动。指挥官通过低声给出固定节拍，可以帮助所有射手在同一呼气末段释放箭矢，从而大幅提高命中率。第二章讲解了"瞄准优先级"：当多个目标同时出现时，应优先射击那些即将对队友造成威胁的单位，而不是血量最低的单位。作者还记录了一种被称为"沉默瞄准"的技巧：在需要隐蔽时使用手势代替口令，避免暴露位置。最末页贴着一张被箭钉穿的靶心，靶心周围有一圈几乎重叠的孔洞，批注："十支箭如果落在同一个地方，比散开的百支箭更可怕。"弓臂内侧还刻着一行小字："稳住呼吸的人，才能稳住整支军队的命运。"

## 设计意图

为远程职业提供命中率协同技能，将感知/敏捷转化为团队稳定输出，强化狙击与集火玩法的精确度要求。
