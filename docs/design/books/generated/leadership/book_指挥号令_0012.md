# 《侧翼标记：把影子变成路标》

## 基础信息

- **书籍 ID**：`book_指挥号令_0012`
- **关联技能**：`leadership_flank_marking`
- **使用效果**：阅读后解锁 `leadership_flank_marking`；若已学会，提升该技能 `current_mastery +95`，并延长下次标记的可见时间 1 回合（一次性）。
- **阅读要求**：角色职业标签含 `rogue`、`ranger` 或 `archer`；基础 `感知 ≥ 8` 或 `敏捷 ≥ 8`。
- **稀有度**：稀有（Rare）
- **建议投放**：游侠营地、盗贼公会情报室、斥候商人。

## 书籍内容

这本书的每一页都泛着淡淡的荧光粉，据说是在夜间也能被看见的标记颜料。作者认为侧翼攻击的成功率取决于标记是否足够清晰、足够早。书中把标记分成"预置"和"即时"两种：预置标记在战斗开始前由潜入者布置，用于指定后续绕后的路线；即时标记在战斗打响后由指挥官或高感知角色给出，用于临时调动机动单位。第二章讲解如何避免标记误导——一个放在敌人影子里的标记，在太阳移动后会让整支队伍扑向错误方向。作者建议在标记旁加上方向符号，比如三道短线表示"从这边切"。最末页贴着一张被雨水泡皱的草图，上面用不同颜色标着敌阵两翼，红字批注："侧翼不是敌人的侧面，而是敌人来不及转身的那个角度。"草图背面画着一只被划掉的眼罩，批注道："标记是给队友的眼睛，不是给敌人的靶子。"

## 设计意图

服务高机动职业指挥官，将侧翼空间信息转化为全队可读的战术信号，提升包抄与绕后策略的协同效率。
