# 《胜利呐喊》

- **书籍 ID**：`book_leadership_0100`
- **关联技能**：`leadership_victory_cry`（待新增，标签 `leadership`）

## 书籍内容

《胜利呐喊》是一本关于如何把局部胜利变成整体优势的书。作者认为，战斗中真正的转折点往往不是第一次击杀，而是第一次击杀后队伍能否抓住势头继续扩大战果。书中将胜利呐喊分为"确认""宣告"与"乘胜"三个环节：确认是确保关键敌人确实倒下，宣告是用明确信号让所有人知道这一消息，乘胜则是把刚刚释放的心理能量转化为实际攻势。作者强调，胜利呐喊的时机至关重要——喊得太早会被反扑打脸，喊得太晚则错失激励效果。书中还讨论了不同文化中的胜利呐喊形式：从简单的战吼到复杂的军乐，从高举武器到点燃烽火。最后一章警告，胜利呐喊不能被滥用，如果每一次小胜都要呐喊，士兵会对其麻木。书末附有一幅辉煌的插画，画着一名统帅站在高处，下方是振臂欢呼的军队，敌人的旗帜正在远处倒下。

## 设计意图

作为指挥号令系列的压轴技能，将胜利时刻转化为团队续航与继续施压的能力。生命与资源恢复配合全属性提升，让关键击杀成为滚雪球的开端。
