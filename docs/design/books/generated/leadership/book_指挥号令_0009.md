# 《号角三声：战争号角的语法》

## 基础信息

- **书籍 ID**：`book_指挥号令_0009`
- **关联技能**：`leadership_war_horn`
- **使用效果**：阅读后解锁 `leadership_war_horn`；若已学会，提升该技能 `current_mastery +95`，并扩大下次号角的覆盖半径 1 格（一次性）。

- **建议投放**：军团乐师营、古战场号角架、声望商人。

## 书籍内容

书页间夹着三片不同长度的铜簧，据说是从破损号角中取出的样品。作者把号角语言分为"长音表状态，短音表动作，断续音表警告"三个层级。书中警告初学者最常见的错误：把冲锋号和撤退号的节奏记混，因为两者都是急促音，只是一个上扬一个下沉。第二章讲解如何在狭窄地形中使用号角——岩壁会把声音压扁，导致远端队友听错方向，这时应当配合旗帜或反光信号。作者还记录了一种被称为"血号"的禁忌吹法：当指挥官阵亡时，由副官吹响一种特殊的颤音，表示"各自为战，但目标不变"。书末的铜簧旁边刻着一行小字："号角的声音里没有谎话，因为说谎的人活不到学会它的那天。"铜簧下方压着一片被音波震裂的玻璃，据说是某位号手最后一次吹响血号时震碎的窗。玻璃碎片旁还粘着一小段被血染红的号绳，见证了那场无人归来的夜战。

## 设计意图

引入声音覆盖范围作为指挥资源，为指挥号令系列增加基于距离的信息传递机制，与旗帜、呐喊形成多维信号体系。
