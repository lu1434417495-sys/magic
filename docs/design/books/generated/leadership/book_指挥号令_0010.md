# 《统御气场：指挥官的沉默》

## 基础信息

- **书籍 ID**：`book_指挥号令_0010`
- **关联技能**：`leadership_command_presence`
- **使用效果**：阅读后解锁 `leadership_command_presence`；若已学会，提升该技能 `current_mastery +100`，并提高下次气场内队友的抗恐惧效果 12%（一次性）。
- **阅读要求**：无职业限制；基础 `魅力 ≥ 9` 或 `意志 ≥ 9`。
- **稀有度**：稀有（Rare）
- **建议投放**：指挥官书房、贵族军事学院、高级战术商人。

## 书籍内容

这是一本无字封面的精装书，只有在烛光下才能看见封面上压印的鹰徽。作者认为真正的统御力不靠音量，而靠存在感。书中教导读者如何在混乱中保持"静止的中心"——站姿端正、呼吸深长、目光始终落在地图或敌人身上，而不是左顾右盼。作者指出，当指挥官开始跑动或提高音量时，恐惧就已经开始传染；相反，一个缓慢而清晰的命令能让周围的人重新找回时间感。第二章讨论了"沉默命令"：在某些时刻，不说话比说话更有力，因为空白会让所有人自觉补全你的意图。最末页贴着一张褪色的画像，画中将军站在燃烧的攻城塔前，嘴微微张开，但手中剑尖稳稳指向一个方向，批注是："他的一句话让三千人安静下来。"画像背面有一行褪色的赠言："统御不是让人服从，而是让人愿意跟随。"精装书的扉页还夹着一根被磨亮的指挥棒，据说曾被那位将军握在手中直到最后一刻。

## 设计意图

构建以指挥官自身位置为核心的光环类技能，将魅力/意志属性转化为团队稳定性资源，为后续高级统御技能提供基础。
