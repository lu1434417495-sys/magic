# 《掩护指令：让每一枪都有退路》

## 基础信息

- **书籍 ID**：`book_指挥号令_0017`
- **关联技能**：`leadership_overwatch_call`
- **使用效果**：阅读后解锁 `leadership_overwatch_call`；若已学会，提升该技能 `current_mastery +95`，并延长下次掩护反应的触发范围 1 格（一次性）。
- **阅读要求**：无职业限制；基础 `感知 ≥ 9` 或 `智力 ≥ 8`。
- **稀有度**：稀有（Rare）
- **建议投放**：守夜人营地、高塔瞭望台、战术商人。

## 书籍内容

这本书的封面是一把拉开的弓和一面小盾交叠的图案，象征着攻守兼备。作者把掩护分成"视线掩护"和"火力掩护"两种：前者用身体或盾牌挡住敌人看向队友的直线，后者用预设攻击威慑敌人进入某条路线。书中强调，下达掩护指令时必须明确"掩护谁"、"从哪个方向"、"持续多久"，缺少任何一项都会导致被掩护者误判安全边界。第二章讲解如何设置"掩护交接"：当掩护者的弹药、体力或施法资源耗尽时，应提前两拍通知下一位接替者。最末页是一张被雨泡软的执勤表，上面有几个名字被划掉，旁边写着："他们不是因为没开枪而死的，是因为没人告诉他们已经被放弃了。"执勤表下方压着一枚生锈的哨子，据说是某位掩护者用尽最后一口气吹响交接信号后留下的。哨子旁边还粘着一片被打凹的护心镜，是那位掩护者留给被救者的最后礼物。

## 设计意图

为指挥号令系列引入反应型保护机制，将感知/智力属性转化为团队防御预警资源，强化阵地战中的层次感。
