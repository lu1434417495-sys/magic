# 《暗影网络：让看不见的人彼此看见》

- **书籍 ID**：`book_指挥号令_0046`

## 书籍内容

书的封面是一片会吸收光线的黑布，只有在特定角度才能看见上面绣着的细线网络。作者把暗影网络定义为"让分散在阴影中的成员共享视野与意图，而不暴露自己"。书中指出，传统的喊话和旗语在潜行任务中会暴露位置，因此暗影网络使用触觉信号、微光和预先约定的节奏来传递信息。第二章讲解了"节点传递"：每个成员只与最近的两个节点交换情报，这样即使某个节点被俘，也不会暴露整个网络。作者强调，暗影网络最忌临时增加新成员，因为不熟悉节奏的人会打乱整个系统的信任基础。最末页贴着一张被炭笔涂黑的地图，几个亮点用针刺出，批注："在黑暗中，知道同伴在哪里，比看见敌人更重要。"黑布夹层里还藏着一根被剪断的细线，是某个节点在最后时刻为保全网络而主动切断的联系。

## 设计意图

为潜行职业提供团队信息共享机制，将感知/敏捷转化为隐蔽协同能力，强化偷袭、侦察与情报战的战术深度。
