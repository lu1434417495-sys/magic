# 《加固阵地》

## 书籍内容

《加固阵地》认为，最好的防御不是人，而是让人更难被杀死的环境。作者将阵地加固分为"自然利用"与"人工改造"：前者是选择 rocks、壕沟与斜坡作为天然屏障，后者则是用木桩、拒马与沙袋填补缺口。书中强调，加固阵地需要时间，指挥官必须在战斗开始前或战斗间隙预留这段时间。作者还讨论了加固的优先级：首先是保护远程与施法者，其次是建立补给通道，最后才是前哨工事。书中警告，过度加固一处阵地可能导致部队不愿离开，从而失去机动性。最后一章讲述如何在加固阵地被突破时有序转移：提前规划第二道防线，让撤退不是溃退而是有组织的后撤。作者强调，加固阵地时应同步布置撤退用的标记物，否则混乱中士兵很难找到下一道防线。书末附有一张简易工事清单，标注了每种材料的防御效果与搭建时间。

## 设计意图

为持久战与防守战提供阵地建设机制，让辅助与工程型角色能够创造安全区域。多回合增益鼓励队伍围绕加固点进行防御作战。
