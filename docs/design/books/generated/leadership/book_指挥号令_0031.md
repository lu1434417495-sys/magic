# 《战士羁绊：前排之间的信任》

## 基础信息

- **书籍 ID**：`book_指挥号令_0031`
- **关联技能**：`leadership_warriors_bond`
- **使用效果**：阅读后解锁 `leadership_warriors_bond`；若已学会，提升该技能 `current_mastery +90`，并提高下次羁绊触发时的伤害分担比例 8%（一次性）。
- **阅读要求**：角色职业标签含 `warrior` 或 `berserker`；基础 `体质 ≥ 9` 或 `力量 ≥ 9`。
- **稀有度**：普通（Common）
- **建议投放**：兄弟会营地、角斗士训练场、近战商人。

## 书籍内容

书的封面是两个相互紧扣的护腕图案，金属部分已被磨得发亮。作者把战士羁绊定义为"愿意替对方承受本可躲开的伤害"。书中指出，真正的羁绊不是浪漫化的牺牲，而是经过计算的位置关系：两名战士相距不能超过一步，否则分担机制无法生效；也不能太近，否则会被同一范围攻击同时击中。第二章讲解了"换位呼吸"——当其中一人血量过低时，另一人主动前跨半步吸引火力，让前者有机会撤后恢复。作者警告说，羁绊最怕的是其中一方擅自追击敌人，因为距离一旦拉开，信任就会变成单方面的负担。最末页贴着一张被血浸透的战友情谊信，字迹潦草却完整："你替我挡的那一下，我记到下辈子。"信纸背面还画着两个歪歪扭扭的小人，手拉着手面对一头巨兽，旁边写着："下辈子还要一起挡。"护腕图案的内侧刻着一行小字："羁绊不是不受伤，而是受伤时知道谁在身边。"

## 设计意图

为前排战士提供双人羁绊机制，将体质/力量转化为互相保护能力，强化近战友谊与牺牲主题。
