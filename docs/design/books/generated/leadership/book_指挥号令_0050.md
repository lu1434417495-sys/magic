# 《君王敕令：一言既出，群山低头》

## 基础信息

- **书籍 ID**：`book_指挥号令_0050`
- **关联技能**：`leadership_sovereign_decree`
- **使用效果**：阅读后解锁 `leadership_sovereign_decree`；若已学会，提升该技能 `current_mastery +120`，并使下次敕令可覆盖的友方单位上限增加 2 名（一次性）。
- **阅读要求**：无职业限制；基础 `魅力 ≥ 12` 或 `意志 ≥ 12`。
- **稀有度**：传说（Legendary）
- **建议投放**：王座厅密室、传说级世界任务、最终商人。

## 书籍内容

这本书的封面是用整张龙皮装订而成，书脊处镶嵌着一枚刻有古老纹章的金扣。据说每一任拥有者都曾是改变过战争走向的人物。作者把君王敕令定义为"用绝对的权威把队伍从个体集合熔铸成单一意志"。敕令一旦发出，所有受令者在持续时间内会共享一种状态：如果命令是进攻，他们的攻击会彼此呼应；如果命令是防守，他们的身体会像城墙一样连锁。书中警告，敕令不能频繁使用，因为每一次都会消耗指挥官的一部分精神根基。第二章讲解了"敕令的代价"：下达敕令的人必须在事后承受等同于敕令影响力的虚弱，如果强行连续使用，可能会导致永久性失去领袖魅力。最末页只有一行被无数鲜血和墨水反复描过的字："真正的君王从不命令别人相信自己，他只是说出方向，然后第一个走向那里。"龙皮封底内侧还压着一片褪色的王冠残片，属于那位据说第一个写下这句话的君王。

## 设计意图

作为指挥号令系列的终极技能与集大成者，将魅力/意志推至极致，提供覆盖全队的强大但高代价号令，为顶级指挥官玩法提供目标与成就感。
