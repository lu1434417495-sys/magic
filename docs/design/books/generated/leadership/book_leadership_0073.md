# 《救援信号》

## 书籍内容

《救援信号》是一本关于如何不抛弃同伴的书。作者认为，救援最重要的不是到达，而是让被困者知道有人正在赶来——这个信念本身就能让人多撑一会儿。书中将救援信号设计得极为简单：一声长号代表"坚持"，两声短号代表"我来了"，三声急促的哨音则是"向我移动"。作者强调，救援者不能盲目冲入包围，而应该选择敌人最薄弱的一面切入，否则会变成第二个人需要被救援。书中还讨论了"虚假救援"的危害：如果你发出信号却无法到达，被困者会在希望破灭后更快崩溃。最后一章讲述救援后的处理：被救者往往需要重新整备，不能立刻投入最危险的位置。作者提醒，救援成功后应先确认被困者的伤势与资源状态，否则他可能在下一轮战斗中再次陷入绝境。书末附有一幅插图，画着一名骑士高举盾牌冲破敌阵，而被困的士兵正借着护盾向他靠近。

## 设计意图

为辅助与守护职业提供紧急救援机制，强化团队的凝聚力与容错率。临时护盾与免费移动的组合，让救援行为既有风险又有明确收益。
