# 《不屈意志》

## 基础信息

- **书籍 ID**：`book_leadership_0099`
- **关联技能**：`leadership_unbreakable_will`（待新增，标签 `leadership`）
- **使用效果**：阅读后学会指挥技能 `leadership_unbreakable_will`，可使一名友方单位在短时间内免疫控制、恐惧与士气崩溃，并将其受到的部分伤害转化为临时攻击加成。
- **阅读要求**：角色职业标签含 `paladin`、`warrior` 或 `berserker`；基础 `意志 ≥ 14`。

- **建议投放**：圣骑士神殿、狂战士试炼、绝境求生剧情奖励。

## 书籍内容

《不屈意志》认为，人体可以被击倒，但意志不是。作者将不屈描述为一种可以传染的状态：当一名士兵拒绝倒下时，他周围的人也会变得更难被击溃。书中将不屈意志分为"承受""转化"与"爆发"三个阶段：承受阶段是硬抗伤害而不动摇，转化阶段是将痛苦化为怒火，爆发阶段则是在极限时刻打出超越平常的一击。作者强调，不屈意志不是无痛，而是带着疼痛继续战斗，因此执行者需要有足够的体质支撑。书中还讨论了指挥官在不屈战术中的角色：你不能命令别人不屈，但你可以站在最前面，用自己的行动证明不屈是可能的。最后一章警告，长期依赖不屈意志会对身心造成不可逆的损伤，它应该是最后的底牌而非日常手段。书末附有一幅插图，画着一名浑身是伤却仍在前进的战士，背景是崩塌的城墙。

## 设计意图

提供针对控制与士气崩溃的强力反制，让高意志角色成为团队的精神支柱。伤害转化攻击的机制让承受压力本身变成一种输出资源。
