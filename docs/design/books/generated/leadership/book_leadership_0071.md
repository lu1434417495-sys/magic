# 《佯攻号令》

## 基础信息

- **书籍 ID**：`book_leadership_0071`
- **关联技能**：`leadership_feint_attack`（待新增，标签 `leadership`）
- **使用效果**：阅读后学会指挥技能 `leadership_feint_attack`，可命令一名友方发动佯攻，吸引敌人注意力并使其下回合对该单位防御下降，其他友方攻击该敌人时获得加成。
- **阅读要求**：角色职业标签含 `rogue`、`warrior` 或 `bard`；基础 `魅力 ≥ 8` 或 `敏捷 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：战术学院、吟游诗人公会、诡计任务奖励。

## 书籍内容

《佯攻号令》是一本关于"假装要做一件事"的艺术手册。作者认为，佯攻的精髓不在于演技多好，而在于让敌人自己得出结论。书中将佯攻分为"声势型"与"接触型"：前者靠大喊、旗帜和密集脚步制造主攻假象，后者则需要一名战士真正与敌人交锋后迅速脱离。作者强调，执行佯攻的人必须相信自己真的在进攻，因为犹豫会暴露意图；同时他又必须清楚自己的真实目标，否则佯攻会变成真打。书中还讨论了佯攻的代价：最好的佯攻往往需要牺牲小部分资源或暴露一名诱饵。最后一章警告，不要对同一敌人反复使用相同佯攻，聪明的对手会利用你的假动作反设陷阱。作者建议记录每次佯攻的效果，因为最成功的佯攻往往是那些与真实进攻几乎无法区分的行动。书末附有一幅战术图，展示左翼佯攻如何将敌方预备队调离真正的主攻方向。

## 设计意图

引入欺骗性指挥技能，让魅力型或敏捷型角色能够通过心理博弈创造输出窗口。防御下降与攻击加成形成明确的配合链条。
