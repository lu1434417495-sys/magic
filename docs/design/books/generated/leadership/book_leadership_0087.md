# 《钳形攻势》

- **书籍 ID**：`book_leadership_0087`

## 书籍内容

《钳形攻势》把战场比作一块铁，而你的两支部队就是夹住它的钳子。作者认为，钳形攻势的精髓不在于夹得有多紧，而在于让敌人相信任何方向都无法逃脱。书中将钳形攻势分为"合拢"与"压碎"两个阶段：合拢阶段需要保持隐蔽与速度，让敌人在意识到被包围之前两侧就已经到位；压碎阶段则需要同步推进，避免一侧过快导致敌人从另一侧突围。作者强调，钳形攻势对情报要求极高，你需要知道敌人的主力位置、可能的撤退路线以及两翼的地形限制。书中还讨论了钳形失败的原因：最常见是指挥官贪图合拢速度，导致两翼过于拉长而被敌人中央突破。最后一章警告，成功的钳形攻势往往会造成大量俘虏，如何处理这些俘虏有时比战斗本身更复杂。书末附有一张钳形攻势标准示意图，用两个箭头从两侧包向中央。

## 设计意图

为大规模战棋战斗提供高级包围战术，奖励多部队协同与地图控制能力。中央会合时的士气打击与伤害，让钳形攻势具备决战潜力。
