# 《战旗之下：旗帜号令入门》

## 基础信息

- **书籍 ID**：`book_指挥号令_0005`
- **关联技能**：`leadership_battle_banner`
- **使用效果**：阅读后解锁 `leadership_battle_banner`；若已学会，提升该技能 `current_mastery +90`，并使下一次战旗召唤的持续时间增加 1 回合（一次性）。
- **阅读要求**：无职业限制；基础 `魅力 ≥ 8` 或 `体质 ≥ 8`。
- **稀有度**：稀有（Rare）
- **建议投放**：军团旗帜库、战场遗迹、荣誉商人。

## 书籍内容

这本厚重的布面书每一页都缝着一小块不同颜色的战旗碎片，翻页时会发出金属环碰撞的轻响。作者认为战旗不是装饰品，而是战场上最慢但最稳定的通讯方式。书中记录了十二种基础旗语：前倾表示推进，后倾表示收缩，左右摆动表示转向，静止高举表示坚守。作者强调旗手的责任比指挥官更重，因为旗帜一旦歪斜，整支队伍都会误判意图。中间章节讲述如何在无风、雨天和灰烬交界的异常气流中保持旗帜可见。最末页只有一行大字："旗在，阵地在；旗倒，人心散。"旁边贴了一张残破的建制表，某个被涂黑的名字下方写着"他护住了旗，但没护住自己"。书脊里还藏着半枚被血浸透的旗扣，据说属于某位倒在旗下的传令兵，他死前最后一句话是："旗没倒，我就没倒。"布面书的最后一页空白处，有人用炭笔补了一句："旗语是给风里的人的，风停的时候，要靠人心继续传递。"

## 设计意图

引入旗帜作为指挥媒介，为指挥号令系列提供一种需要空间维护的持续增益机制，强化战场视觉沟通主题。
