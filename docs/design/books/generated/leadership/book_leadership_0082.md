# 《中枢控制》

## 基础信息

- **书籍 ID**：`book_leadership_0082`
- **关联技能**：`leadership_center_control`（待新增，标签 `leadership`）

## 书籍内容

《中枢控制》把战场比作人体，中央就是心脏。作者认为，控制中枢不意味着占领最中间的格子，而是让敌人始终感受到来自中央的压力。书中将中枢优势分为"实体中枢"与"心理中枢"：前者是地图上的关键地形，后者则是让敌人误以为中央很重要的假象。作者强调，争夺中枢时最忌讳分兵——你 either 全力拿下，or 主动放弃，半调子的投入只会被敌人各个击破。书中还讨论了中枢失守后的应对：不要试图立即夺回，而是先稳住两翼，让敌人为了守住中央而分散兵力。最后一章警告，过度重视中央会让你忽视侧翼奇袭，真正的高手会让敌人在中央投入过多，然后从边缘收割。作者还提醒，中枢控制需要持续投入资源维持，一旦放松，之前建立的压力会迅速消散。书末附有一张棋盘式战场图，中央格被标红，四周用箭头表示压力方向。

## 设计意图

强化战棋中央格子的战略价值，为指挥官提供围绕核心地形展开的增益机制。全属性加成让中枢控制成为值得投入资源争夺的目标。
