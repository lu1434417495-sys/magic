# 《治疗优先级：谁值得下一口呼吸》

## 基础信息

- **书籍 ID**：`book_指挥号令_0039`
- **关联技能**：`leadership_heal_priority`
- **使用效果**：阅读后解锁 `leadership_heal_priority`；若已学会，提升该技能 `current_mastery +90`，并提高下次优先级治疗对关键目标的加成 10%（一次性）。
- **阅读要求**：角色职业标签含 `priest`、`cleric` 或 `druid`；基础 `智力 ≥ 9` 或 `感知 ≥ 9`。
- **稀有度**：稀有（Rare）
- **建议投放**：战地医院、神庙藏书室、神圣商人。

## 书籍内容

书的封面是一把被绿叶缠绕的权杖，权杖顶端的水晶缺了一角。作者把治疗优先级定义为"在资源有限时，决定谁能继续为团队创造价值"。书中提出了"治疗四问"：这个人是否还在承担关键职责？他是否能在治疗后立即回归战线？是否有其他人可以替代他的位置？如果现在不救他，接下来三回合会损失多少？第二章讲解了如何识别"虚假濒死"——有些战士会故意压低血量以骗取治疗资源，而真正危险的人往往因为沉默而被忽略。作者还警告牧师不要被负罪感支配，因为一次错误的治疗可能让全队失去翻盘机会。最末页贴着一张被泪水泡花的手术记录，几个名字旁边画着不同符号，批注："我们救不了所有人，但可以让正确的选择救更多人。"权杖内侧还刻着一行小字："治疗之手也有重量，每一次抬起都要对得起放下的那一次。"

## 设计意图

为治疗职业提供团队资源调度技能，将智力/感知转化为治疗分配效率，强化战棋中的危机决策与资源管理。
