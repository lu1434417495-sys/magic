# 《复仇号令：以痛还痛的节奏》

## 基础信息

- **书籍 ID**：`book_指挥号令_0014`
- **关联技能**：`leadership_retribution_order`
- **使用效果**：阅读后解锁 `leadership_retribution_order`；若已学会，提升该技能 `current_mastery +95`，并提高下次复仇号令的伤害反射比例 8%（一次性）。
- **阅读要求**：角色职业标签含 `warrior`、`berserker` 或 `paladin`；基础 `力量 ≥ 9` 或 `意志 ≥ 9`。
- **稀有度**：稀有（Rare）
- **建议投放**：复仇骑士团、古战场纪念碑、声望商人。

## 书籍内容

这本书的封面用烫金压着一个被折断后重新接上的长矛，象征着以伤换伤。作者认为复仇号令不是情绪失控，而是一种精确计算过的反击节奏。书中提出"受击—确认—反制"三步：队友受到重创后，指挥官必须在下一次行动前给出明确信号，让周围的人把愤怒转化为同步的攻击窗口。第二章警告说，复仇号令最危险之处在于容易变成连锁牺牲——如果不设时限，队伍会为了"讨还"而不断扑向同一目标，忽视整体阵型。作者建议在号令中加入一个终止词，一旦听到就必须立刻恢复防御姿态。最末页是一幅被血染红的插画，画中骑士把剑刺入敌人胸口的同时，自己也被长枪贯穿，配文："复仇的代价永远由下令者和执行者共同支付。"插画边缘有一行后来补上的蝇头小楷："能按下复仇怒火的人，比点燃它的人更难得。"

## 设计意图

为近战职业指挥官设计反击型号令，将受到伤害转化为团队爆发窗口，强化战棋中的代价计算与风险回报。
