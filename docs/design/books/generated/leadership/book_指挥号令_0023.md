# 《地形把守：让高地成为朋友》

## 基础信息

- **书籍 ID**：`book_指挥号令_0023`
- **关联技能**：`leadership_terrain_hold`
- **使用效果**：阅读后解锁 `leadership_terrain_hold`；若已学会，提升该技能 `current_mastery +90`，并提高下次地形把守时的远程伤害加成 8%（一次性）。
- **阅读要求**：无职业限制；基础 `感知 ≥ 8` 或 `智力 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：山地据点、河流渡口、地图商人。

## 书籍内容

这本书的每一页都夹着一片不同地区的干树叶，从枫叶到针叶再到灰烬交界特有的灰晶叶。作者把地形分成"限制型"和"放大型"两种：限制型地形如窄桥、 doorway 能强迫敌人排队通过，放大型地形如高地、塔楼能增加己方射程和视野。书中指出，占据地形只是第一步，更重要的是"守住地形的入口"——一旦敌人进入平台或高地，优势就会瞬间逆转。第二章讲解了"地形轮换"：当敌人开始针对某个高地集结远程火力时，应提前把主力撤向第二处预备地形。最末页是一张被雨水模糊的等高线图，几个制高点被红笔圈出，旁边写着："不要爱上任何一个位置，所有地形都是借来的。"等高线图背面还有一行小字："地形不会背叛你，但你对地形的迷恋会。"灰晶叶的叶脉里还残留着一丝灰烬交界的余温，仿佛在提醒读者：有些地方的地形本身就在呼吸和变化。

## 设计意图

为指挥号令系列补充地形控制技能，将环境优势转化为团队战斗加成，鼓励玩家在战棋地图上主动争夺关键格。
