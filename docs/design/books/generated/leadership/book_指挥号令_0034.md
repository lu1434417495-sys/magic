# 《突破号令：在敌人的墙上凿出门》

## 基础信息

- **书籍 ID**：`book_指挥号令_0034`
- **关联技能**：`leadership_breakthrough_call`
- **使用效果**：阅读后解锁 `leadership_breakthrough_call`；若已学会，提升该技能 `current_mastery +95`，并提高下次突破时的护盾穿透 12%（一次性）。
- **阅读要求**：角色职业标签含 `warrior`、`berserker` 或 `knight`；基础 `力量 ≥ 9` 或 `体质 ≥ 9`。
- **稀有度**：稀有（Rare）
- **建议投放**：攻城营帐、角斗士冠军奖励、声望商人。

## 书籍内容

书的封面是一座被凿穿一半的城墙，砖石裂缝中露出后面的天空。作者把突破号令定义为"让团队在同一时间和同一地点把所有力量砸出去"。书中指出，突破成功的关键不是伤害总量，而是伤害密度——如果攻击分散在敌人防线的多个点上，防线会像水一样把压力卸掉。第二章讲解了"突破节拍"：第一波用重武器制造裂痕，第二波用尖锐攻击刺入裂痕，第三波负责扩大缺口并防止敌人合拢。作者警告说，突破最忌急躁，如果在第一波尚未破盾时就投入全部力量，后续敌人只需简单修补就能恢复。最末页贴着一张被攻城锤撞裂的木板，上面写着："墙最怕的不是大锤，而是所有大锤落在同一个地方。"木板下方还压着一块带血的城砖，刻着一个日期和一句话："今日此墙破，明日彼城开。"城砖背面还有一行小字："突破不是为了拆墙，是为了让墙后面的人看见我们的脸。"

## 设计意图

为力量型指挥官提供定向破防团队技能，将分散火力转化为破盾机制，强化攻坚与 Boss 战的战术深度。
