# 《散兵线：拉开又不断裂》

## 基础信息

- **书籍 ID**：`book_指挥号令_0016`
- **关联技能**：`leadership_skirmish_line`
- **使用效果**：阅读后解锁 `leadership_skirmish_line`；若已学会，提升该技能 `current_mastery +90`，并提高下次散兵线中远程伤害的加成 8%（一次性）。
- **阅读要求**：角色职业标签含 `archer`、`ranger` 或 `rogue`；基础 `敏捷 ≥ 8` 或 `感知 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：轻步兵营地、猎场训练场、通用商人。

## 书籍内容

书的每一页都画满了点与线，像一张被反复修改的蛛网。作者把散兵线定义为"既不被范围法术一锅端，又能互相呼应的最大间距"。书中给出了一条经验法则：相邻两人的距离应等于最慢者两回合的移动距离，这样任何一人遇袭时，最近队友都能及时赶到。第二章讲解"弹性收缩"——当敌人突入线内时，散兵不应向后直线逃跑，而应向两侧滑步，把突入者引入交叉火力。作者还记录了散兵线最致命的错误：为了躲避冲锋而散得太开，导致每个人都变成孤立的猎物。最末页贴着一张被箭钉穿的树皮，上面用炭笔画着不规则的点和线，批注："线不是用来站直的，是用来在断的时候还能连上的。"树皮背面还粘着一片被烧焦的羽毛，据说是某位散兵在火球术落下前最后一刻扑倒队友时留下的。羽毛旁边有一行小字："散兵不是逃兵，是把死亡分散到敌人追不上的人。"

## 设计意图

为轻甲远程职业设计分散站位增益，将传统密集阵型与机动游击结合，丰富战棋中的站位选择。
