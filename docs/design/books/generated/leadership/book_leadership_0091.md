# 《牵制战术》

## 基础信息

- **书籍 ID**：`book_leadership_0091`
- **关联技能**：`leadership_distraction_tactic`（待新增，标签 `leadership`）
- **使用效果**：阅读后学会指挥技能 `leadership_distraction_tactic`，可命令一名友方主动暴露或挑衅敌人，使敌方下回合优先攻击该单位，同时其他友方获得输出窗口。
- **阅读要求**：角色职业标签含 `rogue`、`bard` 或 `warrior`；基础 `魅力 ≥ 8` 或 `敏捷 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：吟游诗人学院、游击营地、诱敌任务奖励。

## 书籍内容

《牵制战术》认为，战场上最高明的不是打败敌人，而是让敌人自己决定做什么。作者将牵制分为"吸引"与"消耗"：吸引是把敌人的注意力拉向某个方向，消耗则是让敌人在追逐诱饵的过程中浪费行动与资源。书中强调，执行牵制的单位必须具备两项能力：足够的生存能力以承受一轮攻击，以及足够的机动性以在完成任务后脱离。作者还讨论了牵制的度：如果诱饵太强，敌人会优先清除其他目标；如果诱饵太弱，敌人会无视它。最后一章警告，牵制战术最忌弄假成真——当你的诱饵真的被杀死时，整个计划就会从战术变成悲剧。作者还提醒，牵制者必须随时保持与指挥官的沟通，一旦目标未被吸引就应立即中止行动。书末附有一幅简图，展示一名轻甲战士在敌阵边缘挑衅，而主力部队正从另一个方向悄然接近。

## 设计意图

引入仇恨操控与诱饵机制，让魅力型或高机动角色能够主动为队伍创造输出环境。优先攻击效果与友方输出窗口形成明确的战术交换。
