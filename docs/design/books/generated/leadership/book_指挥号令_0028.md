# 《法师聚焦：让魔力指向同一点》

## 基础信息

- **书籍 ID**：`book_指挥号令_0028`
- **关联技能**：`leadership_mages_focus`
- **使用效果**：阅读后解锁 `leadership_mages_focus`；若已学会，提升该技能 `current_mastery +95`，并提高下次聚焦时法术穿透 10%（一次性）。
- **阅读要求**：角色职业标签含 `mage`、`sorcerer` 或 `wizard`；基础 `智力 ≥ 10`。
- **稀有度**：稀有（Rare）
- **建议投放**：法师塔协作室、魔法学院高阶藏书、灵能商人。

## 书籍内容

书的封面上压着一片薄水晶，水晶内部有一道几乎看不见的裂纹，传说那是过度聚焦留下的痕迹。作者把法师聚焦比作多束阳光穿过同一枚透镜：单独一束只能发热，汇聚后却能点燃。书中要求参与聚焦的法师在施法前同步咒语的尾音，因为不同法师的魔力频率不同，只有找到共同节拍才能叠加而非抵消。第二章讲解了"聚焦衰减"——当目标移动时，聚焦点必须随之调整，否则魔力会从目标边缘滑开，造成大量浪费。作者警告说，聚焦最危险的是"过曝"，即多名法师同时把法术倾泻到已被击破的目标上。最末页贴着一张被烧穿的法术公式，残留的部分写着："不是每个人的火都更强，而是所有人的火在同一个地方更烫。"水晶下方还压着半片被烤焦的法师袍角，是某位过度聚焦者唯一留下的遗物。

## 设计意图

为法系职业设计团队法术放大机制，将智力协同转化为穿透与爆发收益，强化多法师阵容的战术可行性。
