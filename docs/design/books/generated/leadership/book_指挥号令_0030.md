# 《箭雨齐射：让天空变黑》

## 基础信息

- **书籍 ID**：`book_指挥号令_0030`
- **关联技能**：`leadership_archer_volley`
- **使用效果**：阅读后解锁 `leadership_archer_volley`；若已学会，提升该技能 `current_mastery +95`，并提高下次齐射对密集敌阵的溅射伤害 15%（一次性）。
- **阅读要求**：角色职业标签含 `archer` 或 `ranger`；基础 `敏捷 ≥ 9` 或 `感知 ≥ 8`。
- **稀有度**：稀有（Rare）
- **建议投放**：弓箭手营、城防弩台、远程商人。

## 书籍内容

书的封面是一张被无数箭孔穿透的厚纸，透过孔洞能看见下一页泛黄的纸背。作者把箭雨齐射比作一场需要指挥的暴雨：单支箭可能被盾牌挡开，但几十支箭同时落下时，盾牌只能保护很小一片区域。书中提出"仰角统一"原则：所有射手必须在同一角度拉弓，否则箭矢到达时间不一致，敌人就有空隙躲避。第二章讲解了"覆盖与集中"两种模式：覆盖模式分散落点压制大片区域，集中模式把所有箭射向同一格以清除关键目标。作者警告说，齐射最忌在己方近战单位冲入敌阵后使用，因为箭雨不会分辨敌我。最末页是一张被射穿的布靶，上面写着："真正的箭雨不是让敌人死，而是让敌人不敢抬头。"布靶背面还粘着一片被箭雨削断的军旗残角，记录着某次城墙保卫战中三百支箭同时升空的黎明。

## 设计意图

为弓箭手职业提供团队级范围压制技能，将个体射击扩展为需要协同的弹幕战术，丰富远程职业的战略价值。
