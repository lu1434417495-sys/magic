# 《战前会议》

## 基础信息

- **书籍 ID**：`book_leadership_0095`
- **关联技能**：`leadership_war_council`（待新增，标签 `leadership`）
- **使用效果**：阅读后学会指挥技能 `leadership_war_council`，可在战斗开始前召开战前会议，使所有参与会议的角色获得一项临时战斗加成，依据其职业与角色分配。
- **阅读要求**：无职业限制；基础 `魅力 ≥ 10`、智力 `≥ 10`。
- **稀有度**：史诗（Epic）
- **建议投放**：军事议会、阵营领袖任务、史诗级战略剧情奖励。

## 书籍内容

《战前会议》认为，战斗的胜利有三分之一是在会议室里决定的。作者将战前会议分为"情报汇总""角色确认"与"预案制定"三个环节：情报汇总确保每个人都知道敌人是谁，角色确认明确谁负责什么，预案制定则为两到三种可能情况准备应对方案。书中强调，战前会议最重要的不是制定完美计划，而是让每个人相信计划是被认真考虑过的。作者还讨论了会议的长度：太短会让人感觉不被重视，太长则会消耗战斗热情。书中警告，战前会议不能变成指挥官的独角戏——如果只有一个人说话，其他人的注意力会迅速流失。最后一章讲述如何处理会议中的分歧：允许不同意见存在，但最终必须有一个明确决定。作者建议在会议结束前让每个人复述自己的任务，以确保理解与执行之间没有偏差。书末附有一份战前会议议程模板，以及常见角色的职责清单。

## 设计意图

在战斗准备阶段提供团队增益机制，让魅力与智力型角色在非战斗场景也能创造价值。依据职业分配加成，鼓励多样化的队伍构成。
