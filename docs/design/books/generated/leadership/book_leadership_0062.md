# 《截击号令》

## 基础信息

- **书籍 ID**：`book_leadership_0062`
- **关联技能**：`leadership_intercept_order`（待新增，标签 `leadership`）
- **使用效果**：阅读后学会指挥技能 `leadership_intercept_order`，可命令一名友方单位对途经其威胁范围的敌人发动截击，造成额外伤害并中断其移动。
- **阅读要求**：角色职业标签含 `warrior`、`rogue` 或 `ranger`；基础 `敏捷 ≥ 10`。

- **建议投放**：边境守卫营、商队护卫任务、拦截战剧情奖励。

## 书籍内容

《截击号令》是一本写给擅长"打断"的人的指南。作者指出，战场上最高效的杀伤不是追逐，而是预测——在敌人必经之路上提前布置力量，让他自己撞上来。书中将截击分为"硬截"与"软截"：硬截依靠重甲单位正面阻挡，软截则依靠高机动单位侧翼突袭。作者强调，截击的关键是时机，太早会暴露意图，太晚则变成尾随。书中还讨论了截击位置的选择：狭窄通道、桥梁、楼梯拐角都是天然的截击点。作者提醒，执行截击的单位必须能够承受一轮反击，否则截击会变成自杀式冲锋。书中还提到，优秀的截击者往往会在行动前默数敌人的步频，以此判断最佳出手时机。最后一章是一份训练方案，从单人反应练习到小队协同埋伏都有涉及。书末有一幅示意图，用箭头标出敌人移动路线与截击者应该埋伏的阴影区域。

## 设计意图

为战棋引入主动的移动控制能力，让指挥官能够惩罚敌方的冒进或撤退。截击伤害与中断移动的效果强化了威胁范围的战略意义。
