# 《水战阵型指南》

## 基础信息

- **书籍 ID**：`book_指挥号令_0116`
- **关联技能**：`leadership_aquatic_formation`
- **使用效果**：阅读后解锁 `leadership_aquatic_formation`；若已学会，提升该技能 `current_mastery +100`，并使水域附近战斗时全队平衡检定获得优势。

## 书籍内容

《水战阵型指南》专门讨论在河流、湖泊与沼泽地带作战的指挥要点。作者认为，水战的关键不是游泳技术，而是对浮力、流速和立足点的理解。书中介绍了多种适合水战的阵型：雁行阵利用水流保持侧翼机动、鱼鳞阵适合狭窄河道、半月阵用于包围搁浅敌船。手册还详细说明了不同职业的装备调整：重装单位需要减少护甲或增加浮具，弓箭手需要防水箭囊，法师则要保护施法材料。后半部分讨论了潮汐、风向与雾气对战斗的影响，以及如何利用这些因素误导敌人。作者特别提到，水战中通信尤为重要，因为水声会掩盖号角，旗帜又容易被水雾模糊。书中还建议为所有参战人员准备漂浮装置，即使不善游泳者也能在落水后坚持到救援。最末一章警告指挥官不要低估水中体力的消耗，再精锐的士兵在冷水中也会迅速失温。

## 设计意图

为水域战场提供专属指挥技能，扩展战棋地图的环境机制，让不同地形成为战术选择的变量。
