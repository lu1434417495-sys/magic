# 《反冲锋：把敌人的势头还回去》

## 书籍内容

书的封面是两匹相向冲刺的战马，它们的马蹄在纸面上踏出浅浅的凹痕。作者把反冲锋定义为"不是迎上去，而是在敌人速度最大时切入其侧面的脆弱点"。书中指出，正面硬接冲锋是最愚蠢的选择，因为敌人的全部重量和速度都集中在正前方。正确的做法是在最后一刻向侧方闪开半步，同时用长兵器或绊索破坏其平衡，然后顺着敌人失去控制的方向追击。第二章讲解了"反冲锋阵型"：通常由重甲单位构成 shallow 的弧形正面，轻甲单位埋伏在两翼，等待敌人冲入弧形后合拢。作者警告说，反冲锋最忌过早暴露埋伏，否则敌人会减速或转向。最末页是一张被马蹄踏裂的旧战报，上面写着："最好的冲锋不是我们自己发起，而是让敌人把冲锋送到我们的刀口上。"战报背面还粘着一片被踩扁的野草，来自某位成功反冲锋后跪地喘息的骑士。

## 设计意图

为前排职业提供反制冲锋的团队技能，将力量/敏捷转化为反击窗口，强化防御型指挥官的主动反制能力。
