# 《补给线维护》

## 基础信息

- **书籍 ID**：`book_指挥号令_0113`
- **关联技能**：`leadership_supply_line`
- **使用效果**：阅读后解锁 `leadership_supply_line`；若已学会，提升该技能 `current_mastery +90`，并使长途战斗中全队物资消耗速度降低 8%。
- **阅读要求**：无职业限制；基础 `智力 ≥ 7`。
- **稀有度**：普通（Common）
- **建议投放**：商队营地、后勤任务奖励、物资官书架。

## 书籍内容

这本书用朴实的语言讲述了军队背后的生命线。作者认为，大多数战败在补给线断裂时就已经注定，只是士兵要到三天后才会感觉到饥饿。《补给线维护》从选择路线开始，讲解了如何避开危险地形、如何设置中转站、如何用最小人力保护运输队。书中还讨论了不同季节的补给重点：夏季缺水、冬季缺粮、雨季道路泥泞、旱季尘土飞扬。后半部分涉及应急方案：当补给线被切断时如何就地征集、如何 rationing、如何在士气崩溃前恢复供应。作者特别强调，补给车队必须与战斗部队保持通信，一旦失联就要立即派出搜索队，因为补给往往比增援更迫切。作者特别指出，补给线的安全不仅靠护卫，也靠伪装和分散，让敌人无法判断真正的运输路线。最末一页是一张空白表格，供读者根据自己队伍的实际需求填写补给清单。许多指挥官在出发前会把这张表格抄一份交给副官。

## 设计意图

把资源管理转化为可学习的指挥技能，为持久探索和远征玩法提供续航支撑，强化策略准备阶段的重要性。
