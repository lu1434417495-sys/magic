# 《伏击布置》

## 基础信息

- **书籍 ID**：`book_leadership_0072`
- **关联技能**：`leadership_ambush_setup`（待新增，标签 `leadership`）
- **使用效果**：阅读后学会指挥技能 `leadership_ambush_setup`，可在战斗开始前或特定地形上布置伏击，使首轮攻击的友方获得先手、暴击与伤害加成。
- **阅读要求**：角色职业标签含 `rogue`、`ranger` 或 `archer`；基础 `敏捷 ≥ 10`。

## 书籍内容

《伏击布置》认为，胜利在敌人进入视野之前就已经开始了。作者将伏击分为三个阶段：选择地形、分配目标、控制出手时机。书中强调，最好的伏击点不是最隐蔽的地方，而是敌人不得不经过、又因为大意而疏于防备的地方。作者详细讲解了如何分配首轮攻击目标：最强的一击应该留给最能改变战局的敌人，而不是最容易杀死的。书中还讨论了"过度伏击"的风险：如果第一轮没有把敌人打垮，伏兵就会失去位置优势，陷入被动。最后一章提醒，伏击成功后的首要任务是打乱敌人阵型而非追击残敌——一个被分割的敌人比一个被追杀的敌人更容易对付。作者还建议在伏击圈中预留一条"放行通道"，让部分敌人逃入其中，从而拉长其队伍并制造更多侧翼。书末附有一张林地伏击示意图，用不同符号标注了射手、近战与诱饵的埋伏位置。

## 设计意图

强化战棋中的先攻与地形准备机制，让高机动与隐蔽职业在战斗前期获得显著优势。伏击加成鼓励玩家在遭遇战前主动侦察与布阵。
