# 《嘲讽协同》

## 基础信息

- **书籍 ID**：`book_leadership_0068`
- **关联技能**：`leadership_taunt_coordination`（待新增，标签 `leadership`）

- **阅读要求**：角色职业标签含 `warrior`、`knight` 或 `guardian`；基础 `体质 ≥ 10`。

## 书籍内容

《嘲讽协同》把嘲讽重新定义为一种团队资源，而非坦克的个人表演。作者认为，最好的嘲讽不是让敌人想打你，而是让敌人打你之后会吃亏。书中将协同拆成两步：第一步由前排制造威胁或侮辱，吸引敌人注意；第二步由侧翼的队友准备好反击姿态，等待敌人上当。作者强调，执行嘲讽的人必须足够耐打，否则还没等队友反击就已经倒下。书中还讨论了嘲讽的时机：在敌人即将攻击后排时嘲讽最有效，因为那时的敌人处于决策最脆弱的状态。最后一章提醒，过度依赖嘲讽会让队伍失去主动——有时候让敌人攻击一个准备好的坦克，比强行改变其目标更划算。作者还指出，嘲讽的内容往往比音量更重要，一句恰到好处的挑衅能让理智的敌人也失去冷静。书末附有一幅双人配合图，画着一名盾卫举盾挑衅，而一名剑士在他身后蓄势待发。

## 设计意图

将坦克的仇恨机制升级为团队配合行为，让嘲讽不再是单纯的目标强制，而是创造反击机会的策略支点。
