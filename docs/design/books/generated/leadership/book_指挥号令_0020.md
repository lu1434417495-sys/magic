# 《背水一战：绝境中的最后号令》

## 基础信息

- **书籍 ID**：`book_指挥号令_0020`
- **关联技能**：`leadership_last_stand`
- **使用效果**：阅读后解锁 `leadership_last_stand`；若已学会，提升该技能 `current_mastery +100`，并提高下次背水一战触发时的全属性加成 5%（一次性）。
- **阅读要求**：角色职业标签含 `warrior`、`paladin` 或 `knight`；基础 `意志 ≥ 10`。

- **建议投放**：绝境试炼奖励、古战场英灵祭坛、传说商人。

## 书籍内容

这本书没有封面，只有一层被无数手掌磨亮的皮革，书页边缘发卷发黑。作者在开篇就警告：背水一战不是鼓励去死，而是把"没有退路"变成可以燃烧的资源。书中要求指挥官在下达最后号令前完成三件事：清点剩余资源、确认退路确实不存在、以及让所有队员自愿留下。任何强迫都会在关键时刻瓦解意志。第二章讲述了如何在最后阵地中布置"延迟死亡"的站位：最强者站在最暴露的位置吸引火力，治疗者和远程单位藏在最稳固的死角，而指挥官自己必须能被所有人看见。最末页只有一句话，被不同年代的人用不同笔迹重复书写："我们不是因为没有地方去才站在这里，我们是因为选择站在这里才没有地方去。"皮革封底内侧刻着许多名字，最深处的一道划痕旁写着："愿后来者记住，我们曾选择站在这里。"

## 设计意图

作为指挥号令系列的高风险高收益技能，将绝境转化为团队爆发窗口，为硬核防守/牺牲主题提供终极出口。
