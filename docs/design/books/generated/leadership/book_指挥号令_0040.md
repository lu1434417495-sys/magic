# 《陷阱协同：让地面也会说话》

## 基础信息

- **书籍 ID**：`book_指挥号令_0040`
- **关联技能**：`leadership_trap_coordination`
- **使用效果**：阅读后解锁 `leadership_trap_coordination`；若已学会，提升该技能 `current_mastery +95`，并提高下次陷阱触发时的团队连携伤害 12%（一次性）。
- **阅读要求**：角色职业标签含 `rogue`、`ranger` 或 `hunter`；基础 `感知 ≥ 9` 或 `敏捷 ≥ 8`。
- **稀有度**：稀有（Rare）
- **建议投放**：猎人小屋、地下城探索者营地、陷阱商人。

## 书籍内容

书的封面是一张被翻出毛边的地图，上面用针孔标满了密密麻麻的陷阱位置。作者把陷阱协同定义为"让地面成为队伍计划的一部分"。书中指出，最致命的陷阱不是伤害最高的那个，而是能让敌人恰好走进队友攻击范围的那个。第二章讲解了"诱敌入阱"的三种方式：用远程攻击激怒敌人使其直线追击，用假撤退把敌人引入狭窄通道，用噪音或光源吸引敌人注意力。作者强调，布置陷阱时必须让所有队友知道位置，否则猎人会变成自己的猎物。后半本记录了各种地形与陷阱的最佳搭配：湿滑地面配绊索，高处配落石，门口配延迟触发。最末页贴着一张被泥土弄脏的草图，一个箭头指向陷阱，旁边写着："最好的陷阱不是藏着，是让敌人以为没藏着。"地图背面还画着一只被陷阱夹住的旧靴子，批注："连你自己都要记住它在哪里。"

## 设计意图

为游侠/盗贼类职业提供团队环境陷阱协同，将感知/敏捷转化为控场与爆发结合点，强化战棋地图互动深度。
