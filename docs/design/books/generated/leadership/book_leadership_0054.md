# 《集中火力号令》

## 基础信息

- **书籍 ID**：`book_leadership_0054`
- **关联技能**：`leadership_focus_fire`（待新增，标签 `leadership`）
- **使用效果**：阅读后学会指挥技能 `leadership_focus_fire`，可标记一名敌方目标，使下回合所有友方对该目标的首次攻击获得命中与暴击加成。
- **阅读要求**：无职业限制；基础 `敏捷 ≥ 8` 或 `智力 ≥ 8`。

## 书籍内容

《集中火力号令》开篇就指出，战场上最常见的浪费不是miss，而是五个人同时攻击五个不同的敌人，结果谁也没死。作者将集火分为三个步骤：首先是指示目标，通常用涂红的箭矢或高亮的魔法印记；其次是压制其掩体，让目标无法从容规避；最后是同步出手，确保伤害在同一窗口内倾泻完毕。书中强调，指挥官必须克制贪多——一次集火只标记一个目标，否则标记会退化成无意义的提醒。作者还讨论了优先级的艺术：治疗者、控场者和残血高威胁单位往往比最前排的坦克更值得集火。最后一章是一份失败案例集，记录了因为标记过晚、队友射程不足或目标拥有瞬间位移而导致集火落空的战例。作者在每个案例后都附了一句简短复盘，提醒读者集火是团队契约，而非指挥官的单方面愿望。书末附有一张简表，列出常见敌人的弱点部位与推荐攻击顺序。

## 设计意图

将战棋中的集火决策系统化，降低多人协作的认知成本。通过命中与暴击加成，让快速清除高威胁目标成为指挥轨道的核心战术价值。
