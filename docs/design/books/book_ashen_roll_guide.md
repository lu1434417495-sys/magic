# 《灰烬交界翻滚指南》

## 基础信息

- **书籍 ID**：`book_ashen_roll_guide`
- **关联技能**：`ashen_roll`
- **使用效果**：阅读后解锁 `ashen_roll`；若已学会，提升 `current_mastery +140`，并减少该技能首次使用的 `stamina` 消耗 1 点（一次性战斗增益，最多累计 3 次）。
- **阅读要求**：无职业限制；基础 `敏捷 ≥ 8`。
- **稀有度**：普通（Common）
- **建议投放**：余烬祭所基础传授、灰烬交界入口营地、通用战技商人。

## 书籍内容

这本小册子是灰烬交界对新人最友好的读物，也是死亡率最高区域的入门教材。它没有讲翻滚的姿势，因为姿势因人而异；它讲的是翻滚的决策。"翻滚不是逃跑，是重新买一张位置票。"作者把战场分成"危险格"和"机会格"，并指出大多数死者不是因为翻得不够远，而是因为翻到了另一个危险格的中心。书中建议每次翻滚前先问自己三个问题：翻过去之后谁在我背后？谁在我的侧面？我下一次出手能不能打到我想打的人？指南中间夹着一张被烧掉一半的地图，上面用炭笔标着几个点，旁边写着"这里翻，别跑"。指南特别强调翻滚结束时的姿态：双脚必须同时落地，膝盖弯曲吸收冲击，目光始终锁定敌人而不是地面。一个常见的死亡姿势是翻滚后单膝跪地，那会让你在零点几秒内无法再次移动。最后一页画了一个简笔小人，正以极不雅观的姿势滚向一个更大的简笔怪物，配文："姿态难看但活着，比死得漂亮有用。"

## 设计意图

灰烬翻滚是灰烬交界最泛用的生存战技，这本书作为该区域的入门读物，降低学习门槛同时保留决策深度。一次性 stamina 减免鼓励玩家在获得书籍后尽快进入战斗验证。
